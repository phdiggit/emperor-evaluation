# 证据裁量总则（讨论版 v0.1）

## 一、定位

本总则用于规范“史料证据如何进入评分体系”的中间流程。

它不直接定档、不直接定分、不替代各大项标尺，而是负责把原始史料转化为可被标尺读取的“净证据”。

标准流程为：

原始史料  
→ 原子证据卡  
→ 五轴裁量  
→ 必要时进入触发式裁判模块  
→ 证据组裁量结论  
→ 净证据池  
→ 标尺定档定分

## 二、基本概念

### 1. 原子证据卡

原子证据卡是最小史料单位。

每张原子证据卡必须对应明确史料来源，包含：

- 来源；
- 短摘；
- 史料含义；
- 正负方向；
- 所属大项/子项；
- 五轴裁量结果；
- 候选强度；
- 相邻项切分；
- 是否需触发裁判模块。

原子证据卡只记录史料和单证裁量，不得直接推出最终定档。

### 2. 五轴裁量

五轴裁量是所有证据必经的常规量化步骤。

五轴包括：

1. 归项直接度；
2. 行为关键性；
3. 持续性 / 结构性；
4. 后果外溢度；
5. 相邻项剥离后剩余强度。

五轴裁量用于判断单条证据的候选强度：弱、中、强、极。

### 3. 触发式裁判模块

触发式裁判模块不是所有证据都要进入。

只有当证据属于高风险、易混项、易高估、易低估或需要封顶/降权/上探的类型时，才进入对应模块。

例如：

- 杀功臣 / 能臣 / 谏臣；
- 谋反真假；
- 宠信佞臣；
- 后宫、男宠、宦官干预用人；
- 错用将相；
- 系统性清洗；
- 大规模株连；
- 身后追责是否外溢。

触发式模块的作用是修正五轴初判，不是取代五轴。

### 4. 证据组裁量结论

多张原子证据卡可以汇总为一个证据组裁量结论。

证据组裁量结论不是新史料，而是对多张原子证据的综合判断。

它必须列明：

- 依据哪些原子证据；
- 覆盖哪些维度；
- 是否形成结构性表现；
- 正负证之间如何抵消或强化；
- 汇总层面候选强度。

例如，单条“任李靖”为中正候选，但若同时有房杜、魏征、李靖、李勣、谏臣反馈入口等多维证据，则可以形成“体系级用人结构”的证据组裁量结论。

### 5. 净证据池

净证据池是进入标尺定档前的证据集合。

只有完成以下步骤的证据，才能进入净证据池：

- 已回源；
- 已归项；
- 已完成五轴裁量；
- 已完成相邻项切分；
- 若触发模块，则已完成模块裁判；
- 已标明候选强度；
- 已标明是否仍待人工裁判。

未完成裁量的原始史料不得直接入分。

## 三、总执行规则

### 1. 原始史料不得直接入分

任何史料，即使正负方向非常明显，也必须先转化为原子证据卡，并完成五轴裁量。

### 2. 单证强度不等于最终档位

单条强正证据不必然支撑强档；多条中正证据若覆盖多个维度，可能在证据组层面支撑强档。

单条极负证据可能触发负证拦截，但必须人工裁判。

### 3. 相邻项切分优先于强度判断

任何证据在给出候选强度前，必须先剥离相邻项内容。

例如：

- 战果不得回填用人项；
- 盛世光环不得回填行政项；
- 政策效果不得回填识人授权；
- 政治残酷性不得直接混入用人生态；
- 军事失败结果不得直接等同于错用将相。

### 4. 极级证据必须人工裁判

极正、极负不是常规档。

任何原子证据卡或证据组裁量结论若拟进入极级，必须标记为人工裁判候选，不得由自动流程直接入分。

### 5. 反转材料必须记录

若存在追悔、纠错、平反、恢复评价、复官、复碑、补救等反转材料，必须在证据卡或证据组裁量结论中记录。

反转材料不必然抵消原证据，但必须影响候选强度或标为待人工裁判。

## 四、与评分标尺的关系

证据裁量总则不替代评分标尺。

评分标尺只读取已完成裁量的净证据，包括：

- 单条证据候选强度；
- 证据组裁量结论；
- 正负证抵消关系；
- 负证拦截结果；
- 人工裁判状态。

最终定档定分仍由各大项/子项标尺完成。
