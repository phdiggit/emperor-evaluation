# 证据裁量总则（讨论版 v0.2）

## 一、定位

本总则用于规范“史料证据如何进入评分体系”的中间流程。

它不直接定档、不直接定分、不替代各大项标尺，而是负责把原始史料转化为可被标尺读取的“净证据”。

标准流程为：

```text
原始史料
→ 原子证据卡
→ 五轴裁量
→ 触发式裁判模块
→ 证据组裁量结论
→ 净证据池
→ 定档前人工裁判清单
→ 标尺定档定分
```

## 二、基本概念

### 1. 原子证据卡

原子证据卡是最小史料单位。每张卡必须有明确来源、短摘、人物、子项、正负方向、候选强度、相邻项切分和裁判状态。

原子证据卡只记录史料和单证裁量，不得直接推出最终定档。

### 2. 五轴裁量

五轴裁量是所有证据必经的常规裁量步骤：

1. 归项直接度；
2. 行为关键性；
3. 持续性 / 结构性；
4. 后果外溢度；
5. 相邻项剥离后剩余强度。

五轴裁量用于判断单条证据候选强度：弱、中、强、极。

### 3. 触发式裁判模块

触发式裁判模块不是所有证据都要进入。只有当证据属于高风险、易混项、易高估、易低估或需要封顶/降权/上探的类型时，才进入对应模块。

常见触发项包括：

- 强正、强负、极正、极负候选；
- 杀功臣、压制能臣、压制谏臣；
- 谋反真假或政权安全混入；
- 宠信佞臣、酷吏、近幸、外戚、宦官；
- 错用将相；
- 系统性清洗或大规模牵连；
- 同一对象前期重用、后期安全预期破裂；
- 正负证据组均强，且不能机械抵消。

触发式模块的作用是修正五轴初判，不是取代五轴。

### 4. 证据组裁量结论

证据组不是新史料，而是对一组原子证据的结构性判断。

证据组必须列明：

- 依据哪些原子证据；
- 覆盖哪些维度；
- 是否形成结构性表现；
- 与相邻项切分后的剩余影响；
- 汇总层面候选强度；
- 是否需要人工裁判。

单条强证可形成证据组；多条中证若覆盖多个维度，也可形成证据组。多条同类材料不得按条数机械加分。

### 5. 净证据池

净证据池是进入标尺定档前的证据集合。只有完成回源、归项、五轴裁量、相邻项切分和必要裁判的材料，才能进入净证据池。

净证据池不是最终定档表。它只回答：

```text
哪些正证成立？
哪些负证成立？
正负关系如何？
是否存在高档位拦截或上探限制？
哪些问题仍需人工裁判？
```

## 三、正负证据组净裁量语法

正负证据组进入定档前，统一按以下语法处理：

```text
通用裁量语法
+ 分项专用规则
+ 触发式人工裁判
```

### 1. 通用裁量语法

所有子项都应先判断：

1. 正负证据是否属于同一维度；
2. 是否处于同一阶段，还是存在前期/后期反转；
3. 是否一方是能力证据，另一方是安全/稳定性证据；
4. 是否存在结构性外溢，而不是个案孤证；
5. 相邻项剥离后，本项剩余影响是否仍强；
6. 是否触发高档位拦截、极档人工裁判或反向检索。

### 2. 不得简单抵消的情况

以下情况通常不得简单抵消：

- 正证证明能力，负证证明安全生态或稳定性；
- 正证发生在前期，负证显示后期反转；
- 同一核心对象前期被重用、后期安全预期破裂；
- 负证有群体外溢或寒蝉效应；
- 负证虽有相邻项背景，但剥离后仍保留本项强影响。

这类情形应写成“分维度共存”，进入定档前人工裁判。

### 3. 可以部分抵消的情况

以下情况可考虑部分抵消：

- 正负证据指向同一维度、同一时期、同类行为；
- 负证有明确反转、纠错、赦免、恢复、平反或持续补救；
- 正证只是单点亮点，负证只是同类单点失误，均未形成结构性。

即使可以部分抵消，也应保留抵消依据，不得把负证从记录中删除。

### 4. 高档位拦截

若存在强负或极负证据组，并且满足下列任一条件，应触发高档位拦截：

- 负证直接破坏本项核心定义；
- 负证与正证属于同一对象或同一制度链条的反转；
- 负证具有群体外溢或长期结构性；
- 正证强但高度依赖结果论、光环或相邻项成果。

高档位拦截不等于低档。它只表示：不得因强正证据直接上探极高档。

## 四、对象层级与对象画像的轻量规则

某些子项会涉及“被任用者”“被处置者”“受影响对象”的层级。对象层级会影响证据权重，但不得另建完整臣子评分体系。

### 1. 对象层级只作证据权重标签

可使用轻量标签：

```text
顶级 / 高级 / 中级 / 普通 / 存疑
```

对象性质可标为：

```text
能臣 / 名臣 / 谏臣 / 将帅 / 技术官僚 / 酷吏 / 佞臣 / 近幸 / 外戚 / 宦官 / 旧敌转用 / 异质人才
```

这些标签只服务证据裁量，不评价该臣子的总历史地位，不形成独立臣子排行榜。

### 2. 对象层级如何影响强度

- 任用顶级能臣、将帅、谏臣，可提高正向证据权重；但必须剥离其具体战功、政绩、政策成效。
- 任用顶级佞臣、酷吏、近幸、权奸，可提高负向证据权重；但必须剥离司法残酷、政策后果、政权安全案件本身，只保留对本项的剩余影响。
- 迫害、压制或安全预期破裂的对象若为顶级能臣、核心功臣或顶级谏臣，负证权重高于普通对象。

### 3. 同一对象正负反转

若同一顶级对象前期被重用、后期安全预期破裂，应分维度处理：

```text
前期重用 → 识人/授权能力正证
后期反转 → 授权稳定性/人才安全生态负证
```

二者不得简单抵消。该类材料通常触发人工裁判，并可能构成高档位上探拦截。

## 五、证据饱和与代表性覆盖

当某人物在某子项已经覆盖核心维度，并且已有强级或极级候选证据组时，后续同类型正证默认只作为元数据厚度补充，不自动提高候选强度。

证据饱和不是停止检索。即使已出现代表性覆盖，仍应保留最低限度的关键人物扫查和反向检索，以防遗漏结构性反证、新维度证据或相邻项切分问题。

## 六、总执行规则

### 1. 原始史料不得直接入分

任何史料，即使正负方向非常明显，也必须先转化为原子证据卡，并完成五轴裁量。

### 2. 单证强度不等于最终档位

单条强正证据不必然支撑强档；多条中正证据若覆盖多个维度，可能在证据组层面支撑强档。

单条极负证据可能触发负证拦截，但必须人工裁判。

### 3. 相邻项切分优先于强度判断

任何证据在给出候选强度前，必须先剥离相邻项内容。

例如：

- 战果不得回填用人项；
- 盛世光环不得回填行政项；
- 政策效果不得回填识人授权；
- 政治残酷性不得直接混入用人生态；
- 军事失败结果不得直接等同于错用将相。

### 4. 极级证据必须人工裁判

极正、极负不是常规档。任何原子证据卡或证据组裁量结论若拟进入极级，必须标记为人工裁判候选，不得由自动流程直接入分。

### 5. 反转材料必须记录

若存在追悔、纠错、平反、恢复评价、复官、复碑、补救等反转材料，必须在证据卡或证据组裁量结论中记录。

反转材料不必然抵消原证据，但必须影响候选强度或标为待人工裁判。

### 6. 人工裁判触发边界

只有以下情况必须进入人工裁判：

- 拟进入极档或高位档；
- 强正与强负并存；
- 正负关系不能按同维度抵消处理；
- 负证可能构成高档位拦截；
- 对象层级或同一对象正负反转影响强度；
- 相邻项切分后剩余影响仍有争议。

普通弱证、中证、重复材料和低价值线索不应全部交给人工裁判。

## 七、与评分标尺的关系

证据裁量总则不替代评分标尺。

评分标尺只读取已完成裁量的净证据，包括：

- 单条证据候选强度；
- 证据组裁量结论；
- 正负证关系；
- 负证拦截或高档位上探限制；
- 对象层级/同一对象反转的人工裁判状态；
- 是否仍有未决人工裁判项。

最终定档定分仍由各大项/子项标尺完成。
