## 一、财政、民生、工程与灾害

- **江南水灾、真定以南旱灾造成饥荒与大规模流移。** 至元十九年八月江南水、饥民众；真定以南旱，民多流移，朝廷发廪赈济。九月又赈真定饥民，并给已经流移江南者粮食使还乡。原文定位：`P0007`“江南水，民饥者众；真定以南旱，民多流移”；`P0010`“给之粮，使还乡里”。
- **云南赋税用金、贝折纳，同时继续强化金矿征取。** 规定云南赋税以金为则、贝予折纳；又遣使括云南所产金，设打金洞达鲁花赤。至后文先后罢淮安、淮南淘金机构、放回民籍，却又设怀来淘金司；云南还明禁课官超额多取余钱，并罢造卖金箔规措所。原文定位：`P0013`、`P0016`、`P0067`、`P0084`、`P0086`、`P0097`、`P0100`。
- **征日本重新形成超大规模造船—征粮—征兵—征役链。** 高丽先请造船150艘；九月又令平滦、高丽、耽罗及扬州、隆兴、泉州造大小船3000艘。至元二十年令高丽备军粮20万石，发五卫军2万人，伐船材14.2万余件并起军贴户丁壮5000、民夫3000运输；又陆续发侍卫亲军2万、征习舟楫军官、调黎兵，并从江北重囚中谪人征日。原文定位：`P0004`、`P0014`、`P0052—P0053`、`P0059—P0065`、`P0072—P0073`、`P0090`。
- **征日动员已明确激化江南社会骚动。** 崔彧指出江南盗贼“凡二百余所”，直接归因于拘刷水手、兴造海船使“民不聊生，激而成变”；六月又明言因征日本“民间骚动，盗贼窃发”。这组材料应作为战争社会成本底账，而不是虚构成对日战役伤亡。原文定位：`P0057`“凡二百余所，皆由拘刷水手，兴造海船，民不聊生，激而成变”；`P0078`。
- **朝廷在征日压力下数次减役，但并未立即停止计划。** 御史台指平滦造船、五台山伐木造寺、南城建寺合役4万人，最终罢伐木、建寺，造船另议；五月免五卫军征日、放平滦造船军归耕；七月令征日船“少缓”，所拘商船尽还；史弼又请求不再向民间科500艘船，改修旧船并给钞募水手；至次年二月才罢高丽造征日船。原文定位：`P0064`、`P0076`、`P0082`、`P0087`、`P0119`。
- **灾年税粮曾被基层—台察体系迫使停征。** 至元二十年正月，御史台指出燕南、河北、山东去年旱灾已勘验，却未奏免税粮，质问“民何以堪”；诏权停征，并规定地方官灾伤不及时申报、按察司不及时检视皆治罪。原文定位：`P0054`。
- **河北流民南渡求食一度被官方阻断，程思廉坚持放行。** 朝廷派人阻止流民渡河，程思廉以“天下一家，河北、河南皆吾民也”强令纵行，体现灾荒救济与治安管控之间的冲突。原文定位：`P0055`。
- **崔彧留下极重要的全国赋役—流民底账：内地已有十五万户避赋役流入江南。** 他直指“赋重政繁，驱之至此”，建议招回复业，免后五年科役、蠲积欠、即日归还产业，并以户口增耗考核地方官；还主张抄没奸党财物归帑藏供岁计。原文定位：`P0056`“流移江南避赋役者，已十五万户”。
- **土地清丈、畜牧核查被担忧误农；岁取室女制度因此再被罢。** 崔彧称通行核实军民地亩、取勘畜牧数目已引发浮言并“恐失农时”，同时再请罢各路每岁选室女，获准。原文定位：`P0058`。
- **官吏俸禄两次上调，理由明确与抑制贪腐相关。** 崔彧认为百官月俸不足赡养，增俸虽最终出自民赋，但若能减少贪墨仍可使民受惠；朝廷据此增内外官吏俸。至元二十一年六月再次规定低俸官按比例增给。原文定位：`P0080`、`P0147`。
- **酒禁、盐禁在财政与社会控制之间反复。** 四月严酒禁，私造者没财产、女子并配役，另申私盐禁；九月因“岁登”又开诸路酒禁。卷末卢世荣再建议由官府垄断京师酒酤，称一个月可办过去全年课额，获准。原文定位：`P0075`、`P0091`、`P0177`。
- **济州河、海运与新河试验体现漕运制度转型及其民生代价。** 济州新开河完成并设运司；王积翁等开新河通漕，但候潮而入导致船多损坏，“民亦苦之”，遂转重海道并设海运万户府；然而又分军士水手、船只到扬州、平滦运粮，并命三省造船2000艘用于济州河，显示海河并用的过渡状态。原文定位：`P0088`、`P0103`。
- **常平、屯田、河工继续扩张。** 开云南驿路；军民同筑堤堰以利五卫屯田；涿州巨马河决，冲突30余里；以侍卫亲军1万人修大都城；立常平仓，给50万石价钞；修滦河道；又以丁壮1万人开神山河并立万户府管理。原文定位：`P0083`、`P0131—P0132`、`P0145`、`P0163—P0164`、`P0176`。
- **江南出现实质性减税、清欠与放良民籍。** 至元二十一年五月蠲江南当年田赋十分之二，至元十八年以前逋欠尽免；此前从江南民户拨出的30万匠户，经核定实际工匠后，剩余19万900余户准许恢复民籍。原文定位：`P0139—P0140`。
- **无籍军曾借“杀掠”之名剽劫平民，被强制遣返。** 御史台称这些人初时借以张渡江兵威，后来各持弓矢剽劫平民，若不处理恐生变，最终诏遣还家。原文定位：`P0153`。
- **卢世荣入中书后重新提出强力聚敛路线，朝臣已明确预警“日剪羊毛”。** 他自称可救钞法、增课额而“不损民”；董文用反驳民财有限，若日日剪毛将使羊尽死。博果密亦以桑弘羊、宇文融为戒，称聚敛最终会“国与民俱困”，但帝仍暂不纳。原文定位：`P0167`、`P0171`、`P0182`。
- **湖广约苏穆尔的追征暴政造成直接人命损失。** 他据传闻追索旧银，令民自实，沿途设狱株连、酷刑拷掠，“民以拷掠瘐死者载道”，所得又被其侵吞。永州判官乌克逊泽通过厚待、劝谕来使，使本郡免受此害。原文定位：`P0183—P0184`。其中宝庆、武冈实际讨盗另入战役卡，本条只记征敛暴政与永州避害。

## 二、政治秩序、外交与人口变化

- **阿哈马特死后启动系统性反腐与官制整顿。** 诏严惩受贿、侵盗及知情不纠的台察官；建“墨簿”记录阿哈马特党人，部分奸党伏诛；又诏将其罪恶颁告中书，凡民间利病“即与兴除之”。原文定位：`P0012`、`P0018—P0019`、`P0030`。
- **沿河豪商阻遏官民船只被列为重罪。** 因势家从商阻断航运，设沿河巡禁军，犯者没家。原文定位：`P0031`。
- **文天祥被杀及其家属后续在本卷完整收束。** 元廷因谣言、变乱恐惧及劝降失败，最终在燕京柴市杀文天祥；其妻欧阳氏自刭，友人张千载收其遗骨归葬。此为司法—政治处决，不进入战争P。原文定位：`P0033—P0037`。
- **宋宗室被继续纳入元朝控制体系。** 赵与芮留大都，瀛国公赵㬎等处置另定；赵与{票灬}多次进言江南科敛急督、宋陵暴露等问题。至元二十一年又将故宋宗室及已仕大臣迁入内地。原文定位：`P0038—P0039`、`P0127`。
- **御史台独立性一度得到维护。** 崔彧要求台臣对国政、生民、百官皆可纠察，并主张台察官自选；江淮省臣拟使行台隶行省时，董文用强烈反对，最终未从。原文定位：`P0040—P0041`。
- **官僚体系继续压缩、整顿与专业化。** 罢屯田总管府并归枢密院；两广福建五品以下由行省铨注；立云南按察司、增蒙古监察御史；多次改革军官选法、赃罪法和奏事程序。原文定位：`P0025—P0026`、`P0062`、`P0066`、`P0069`、`P0109—P0111`。
- **对民间采选室女的制度开始限额并最终取消。** 耶律铸先建议大郡岁取3人、小郡2人，合格者厚赐父母，不合即遣还；次年崔彧再请彻底罢各路岁取室女，获准。原文定位：`P0027`、`P0058`。
- **孔氏南北宗问题以孔洙主动逊位曲阜一支告结。** 元廷任孔洙为国子祭酒兼提举浙东学校，并给禄护持林庙。原文定位：`P0028—P0029`。
- **俱蓝等海外外交继续扩展。** 杨廷璧三次招谕后，远方俱蓝国入贡宝货及黑猿；高丽王与公主、世子亦来朝。原文定位：`P0011`、`P0134`。
- **王积翁出使日本途中被随行船主任甲杀害并掠资逃走。** 这是外交使团内部的杀人—劫掠事件，原文未写成两军武装接战，故不立战役卡；但它使对日外交再次失败。原文定位：`P0115`。
- **“宋宗室反”诬告被鄂尔根萨里及时阻止。** 他指出江南初定，若因仇人浮言即捕宗室，会使人人自危；查明果为债务仇杀诬告。原文定位：`P0104`。
- **元廷开始以高投入招揽儒士、扩充国学。** 鄂尔根萨里建议用儒术治天下、招山泽之士，设集贤馆；来应诏者给养丰厚，即使不称旨也赐遣。又立国子监、增博士弟子员并优给廪饩。原文定位：`P0158—P0160`。
- **科举议再起而未成。** 和尔果斯等主张蒙古、儒吏、阴阳、医、巫皆可试举，以改变刀笔吏仕进偏重，但因和尔果斯旋罢，议遂寝。原文定位：`P0172`。
- **江南官田侵占问题被重新清理。** 对权豪、寺观欺隐的官田，免积年收入并设期限许自首，逾限被告则征收并以半给告者。原文定位：`P0173`。
- **卢世荣用事导致中枢权力重组。** 和尔果斯、张雄飞等罢，安图复右丞相，卢世荣升右丞；崔彧反对卢世荣任相被下吏后旋罢，显示财政路线已转化为高层政治斗争。原文定位：`P0166—P0175`。

## 三、跨卷连续性

- **向前—日本：** 卷185已闭合1281年远征灾难。卷186全部征日船、粮、兵、民船和水手征发均属新一轮准备，不重复卷185十万级人员与舰队损失。
- **向前—占城：** 卷185末“占城既服复叛、发军五千与战船”在卷186 `P0077`进入实战；本卷又见索多军溃、占城再表请回军，说明初期“大胜—降附”并未稳定。
- **向前—缅甸：** 卷185只见再征部署；卷186出现拔江头城、太公城及后续被缅军冲溃，形成同一战争父链的胜—败两阶段。
- **向后—安南：** 卷186 `P0179`只是脱欢进入安南、万劫取胜的开端；卷187继续富良江大战、短暂入城、疫病与撤退、李恒和索多战死，必须沿同一 `campaign_group` 继续。
- **向后—九溪十八峒：** 卷186已讨平并改置州县，但卷187又见四路军大规模进讨，说明“叛服不常”的区域威胁并未因本卷一次设治彻底终结；本卷SB不得写成永久结构性终结。
- **向后—日本：** 卷186二月虽罢高丽造船，但征日并未终止；卷187又重设征东行省、造迎风船、征高丽兵船、储米，直到至元二十三年正月才因“重困民力”正式罢征。
