## 一、财政、民生、工程与灾害

- 至大三年初裁中书官吏，自客省使以下共一百八十一员。原文定位：`SRC-XUZIZHITONGJIAN-197-2334246-P0003`。
- 禁近侍擅自增加课额或另进贡物干扰既定财政制度。原文定位：`P0005`。
- 五台寺继续营造，役工匠一千四百、军士三千五百。原文定位：`P0007`。
- 税课法把大德十一年旧额与此前“增额”合并为新正额，并以增收三成、五成、七成、九成设置考核奖等，意味着一时增羡被制度化为后续征收基准。原文定位：`P0009`。
- 浚会通河，给钞四千八百锭、粮二万一千石以募民施工。原文定位：`P0013`。
- 至大银钞实行后，朝廷决定将至元钞收入万亿库并销毁旧钞版，仅保留至大钞与铜钱并行。原文定位：`P0015`。
- 银冶试采得银六百五十两，随即设置上都、中都等处银冶提举司。原文定位：`P0026`。
- 荆门州大水并山崩，毁官廨民居二万余间，死亡二千余人；汝州、六安州亦大水，循州随后又有大水漂没庐舍。原文定位：`P0029—P0030`。
- 朝廷给亲民长吏建立考功印历，由监治官逐年记录政绩，再交廉访司、御史台、尚书礼部考校升黜。原文定位：`P0031`。
- 禁权要挟圣旨、懿旨、令旨干扰会通河民间搬运。原文定位：`P0032`。
- 皇帝认为本年颁赉过多，命尚书省把各位奏请赐财物者列名，再亲自裁汰。原文定位：`P0035`。
- 刘夔乘驿省亲江南，“大扰平民”，且两年不归，皇太子上言后被罢。原文定位：`P0037`。
- 张养浩十条时政疏提供本卷最系统的财政民生总诊断：他指泛赏所用皆来自百姓长期劳作与采玉、煎盐、运输；山东、河南连年蝗旱后“十室九空”，父子兄弟夫妇甚至相鬻为食，而中都、南寺、五台、宫殿仍大兴土木，括匠调军、远程伐木取材，役者因瘴疠、崩压、溺水死亡“无日无之”。原文定位：`P0038—P0045`。
- 张养浩又批评税额增添、钞币随支出滥造、墨敕开幸门、宗教支出膨胀等，甚至估计国家经费“三分为率，僧居二焉”；其疏因触怒执政而被排斥。原文定位：`P0039`、`P0046—P0051`。
- 朱清、张瑄财产籍没后，民间已经偿清的旧借券也被官府据券重复征理，吴鼎力为辨白后才获免。原文定位：`P0056`。
- 宣徽院日常供给增长过快，皇帝注意到后宫饮膳规格竟与皇帝相同，下令核实减省。原文定位：`P0057`。
- 晋王获准收回世祖旧赐地土、金银铜冶，并另赐钞赈其部贫民。原文定位：`P0061`。
- 海漕规模增至三百万石后出现明显运力危机：漕户因“赋敛横出”困乏逃亡，官府到浙东、福建和雇船只，引发“百姓骚动”；最终增给顾直并重整海道运粮万户府。原文定位：`P0062`。
- 河南水灾，死者由官给棺木，屋舍漂毁者给钞，按人口赈粮两月，并免当年租赋。原文定位：`P0065`。
- 尚书省建立以后“赐予无节，迁叙无法，财用日耗，名爵日滥”；托克托要求恢复旧制，皇帝命滥受宣敕者缴回。原文定位：`P0066`。
- 城中都继续用牛车运土并令各部卫士助役。原文定位：`P0070`。
- 武宗死后，皇太子不愿再按旧例大作佛事，反而提出“发府库以赈鳏寡”。原文定位：`P0081`。
- 皇太子立即罢尚书省，并停止城中都、各处营造；禁止百官役军人营造、守护私第。原文定位：`P0082—P0089`。
- 还中都此前所占民田；又以萧珍城中都“徼功毒民”，追夺符印并拘禁。原文定位：`P0095—P0096`。
- 江浙左丞相托克托到杭州后询问民间利病，疏浚久废便河以通舟楫、平物价；虽有禁土功诏，仍以实际利民为由一个月内完工。原文定位：`P0105`。
- 仁宗即位诏再次禁止诸王、驸马经过州郡非理需索，并要求和顾、和卖即时给价。原文定位：`P0107`。
- 赐大都九十岁以上二千三百余人每人帛二匹，八十岁以上八千三百余人每人帛一匹。原文定位：`P0113`。
- 至大银钞、铜钱施行未满两年即被全面停止。诏书承认银钞倍数失宜、铜钱供应不足且新旧并用导致弊端加重，并撤销资国院、泉货监等机构，恢复民间铜器自由买卖。原文定位：`P0117`。
- 李孟称仁宗即位后物价立即下降，皇帝直接否定这种迎合，指出秋收尚未可知，“践阼曾未逾月，宁有物价顿减之理”。原文定位：`P0118`。
- 尚书省曾把河汴官民土地冒报为无主，设田粮府岁收数万石；仁宗即位后撤府、遣流建言者，并命归还原业。原文定位：`P0120`。
- 钱钞制度切换时，河南右丞王约按本省实际需用，把税收改为至大、至元钞各半；中书认可后推广天下，反映中央诏令与地方支付条件之间的务实调整。原文定位：`P0121`。
- 仁宗表示“五谷丰熟，百姓安业，乃为瑞”，否定以异兽为祥瑞。原文定位：`P0129`。
- 秋稼正盛时，太后要求鹰坊、驼人、卫士不要先行返大都，以免害稼扰民，皇帝下令禁止。原文定位：`P0138`。
- 大同宣宁县雨雹积五寸，“苗稼尽损”。原文定位：`P0146`。
- 原拟从杭州取龙舟，省臣以违背即位诏中的禁奢原则进谏，皇帝停止。原文定位：`P0151`。
- 江陵路水灾漂毁民居并有溺死者。原文定位：`P0152`。
- 大普庆寺一次获赐黄金一千两、白银五千两、钞一万锭、各类织物一万端、田八百亩、邸舍四百间；随后又禁止僧寺冒侵民田。原文定位：`P0154—P0155`。
- 本卷最关键的国库底账在十一月集中披露：李孟称每年支钞六百余万锭，土木营缮百余处再耗数百万锭，内降赏赐三百余万锭，北边军需又六七百万锭，而国库现存“止十一万余锭”。仁宗采纳建议，停止一切不急营缮。原文定位：`P0158`。
- 京城增设米肆十所，每日平粜八百石赈贫。原文定位：`P0160`。
- 至大银钞最终由官监视焚毁。原文定位：`P0161`。
- 海运制度回顾显示：旧海道一万三千三百五十里，新航路可在顺风时十余日抵京，但“粮船漂溺者，无岁无之”；船坏弃米要由运官赔偿，直到“人船俱溺”才免赔。与河漕相比成本仍较低，但风险长期由运输系统承担。原文定位：`P0166—P0167`。

## 二、政治秩序、外交与人口变化

- 宁王库库楚与越王图喇之子被控“谋为不轨”，但审理中平章特尔格力辨其诬，库库楚最终免死流高丽；相关西僧二十四人被磔。原文未载起兵、调军或宫禁争夺，不进入战争账户。原文定位：`P0016`。
- 海都旧分地五户丝此前积存二十余年，至其后代彻伯尔入朝后才按世祖旧意赐还；这同时构成卷196“漠北悉平”之后北边归附持续的政治后效。原文定位：`P0019`、`P0027`。
- 三宝努曾谋推动改立武宗之子为皇太子，托克托坚持既有兄终弟及安排；后来三宝努等又继续图摇东宫，但均属储位政治而非实际军事政变。原文定位：`P0025`、`P0071`。
- 张养浩因直言尚书省、赏赐、法禁、土木、宗教等十弊，被执政排斥、构罪，最后改名逃亡。原文定位：`P0038—P0051`。
- 御史台追查江浙平章乌讷尔派人违法释放绍兴狱中赃吏，皇帝命派员讯问并强调不得徇私。原文定位：`P0054`。
- 武宗末年，郑阿尔斯兰等十七人被诬作“图为不轨”，全部弃市且籍没家产，“中外冤之”；仍无实际武装阶段，不进战役卡。原文定位：`P0072`。
- 武宗死后，皇太子迅速清算尚书省核心执政者，托克托、三宝努等伏诛，其他党附者流放或罢黜，行尚书省恢复为行中书省。此为政治清洗，不把处刑人数伪装成战争人员损失。原文定位：`P0082—P0083`。
- 仁宗即位前后持续恢复“百官庶政悉归中书”的制度，非亲奉的传旨不得执行。原文定位：`P0090`、`P0107`。
- 白云宗系统中有发为僧者被指避役损民，朝廷追收玺书银印、勒还民籍；又罢各处僧录、僧正、都纲司，僧人诉讼归有司。原文定位：`P0099`、`P0102`。
- 仁宗于大明殿即位，诏令禁止僥幸献地、山场、窑冶和奇宝，并重申诸王驸马不得扰民。原文定位：`P0106—P0107`。
- 皇帝命汇集中统、至元以来法令，交熟悉法律的老臣统一轻重，减少司法冤抑。原文定位：`P0111`。
- 李邦宁曾主张武宗立子而非传弟，仁宗即位后群臣请诛，仁宗以“帝王历数，自有天命”拒绝报复。原文定位：`P0112`。
- 仁宗要求近侍不得擅传旨中书，违者可直接捕送刑部；又规定诸司奏事须有殿中侍御史在侧。原文定位：`P0130`、`P0135`。
- 居庸关四十三条古道只有十三处有人防守，朝廷设隆镇万户府加强守备；本段属于边防建制，未发生战斗。原文定位：`P0139`。
- 朝廷继续削减京朝诸司员数，恢复至元三十年旧额。原文定位：`P0147`。
- 僧寺民田侵占被禁止，宣政院审理僧人词讼的权限也被取消。原文定位：`P0155—P0156`。
- 中书指出本年春以来内降旨除官已逾一千人，严重破坏选法；皇帝下令此后一概不行。原文定位：`P0162`。

- 向前承卷196：察八儿等来降后称“漠北悉平”，本卷P0019又见其子彻伯尔“感慕德化，归觐朝廷”，P0027再公开陈述西北诸藩“始离终合”，支持卷196北边平定后效在本卷继续保持；不另造战役卡。
- 卷196末八百媳妇、大小彻里作乱且招谕失败，本卷P0123正式“遣兵击八百媳妇”，命云南王、阿固岱率众讨之，已转入战役裁决；本卷没有结果，必须留给卷198续核。
- 卷195—196留下的琼州王文何候选，到本卷仍未出现更详武装过程，继续保持待核状态。
