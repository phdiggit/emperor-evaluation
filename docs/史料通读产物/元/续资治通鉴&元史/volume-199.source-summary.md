## 一、财政、民生、工程与灾害

- 宣徽院为尚膳派人到归德打猎，仁宗以扰民下令停止。原文定位：`SRC-XUZIZHITONGJIAN-199-2334510-P0009`。
- 特们德尔推动括田后，各省执行“苛急烦扰”，江西尤甚。本卷记新丰一县因经理田粮拆民屋一千九百区、夷墓扬骨、虚张田亩；朝廷最终停止经理及冒括田租。该政策同时成为本卷重大社会冲突的直接诱因，具体武装过程另见战役裁决。原文定位：`P0010`、`P0024`。
- 秦州成纪县出现山体移动，陷没民居，朝廷遣官核验赈恤；六月黄河又决郑州。原文定位：`P0013`、`P0016`。
- 济宁、益都亢旱，朝廷削减卫士刍粟消耗；畿内随后大雨，漷州、昌平、香河、宝坻等地水灾，淹没民田庐。原文定位：`P0017`、`P0021`。
- 江南、湖广廉访司公田被指出“多取民租”，朝廷命恢复旧制。原文定位：`P0019`。
- 江浙行省平章章律因括田逼死九人，被敕令审讯。原文定位：`P0030`。
- 星变后朝廷减免各路差税，并要求臣下凡有“可以安百姓者”都应直言；尉迟德诚又建议立常平、汰僧道、救钞法、裁冗官。原文定位：`P0036—P0037`。
- 延祐三年初汉阳、河间等处连续饥荒获赈；真定、保定连年饥，因而禁猎。原文定位：`P0048`、`P0050`、`P0053`。
- 海口屯储汉军改隶临清运粮万户府，继续承担转漕。原文定位：`P0052`。
- 鹰坊人员在大同扰民，朝廷追回其所奉玺书；全国春季田猎也被禁止，且原拟死刑的处罚被减轻。原文定位：`P0058—P0059`。
- 郭守敬卒后，史文集中追述其水利功绩：三白渠灌田、汶泗接江淮、白浮斗闸通漕均有节省陆运、充军储等效果；另有黄河分流、灌溉图志未能充分采用。原文定位：`P0061`。
- 河南流民群聚渡江、沿途扰害，朝廷以现存赃钞赈济。此段未见持兵或军队讨击，作为流民救济与治安问题保留，不进战役卡。原文定位：`P0062`。
- 辽阳、盖州、南丰州及衡、永等路先后饥荒并获赈。原文定位：`P0066`、`P0070`。
- 黄河决汴梁、淹民居，朝廷发粮赈济。原文定位：`P0074`。
- 五台灵鹫寺另设铁冶提举司，宗教机构继续直接取得矿冶经营权。原文定位：`P0087`。
- 延祐四年初，仁宗因“百姓乏食”反省政令，明确提出“省刑薄赋”；立皇太子后又赐鳏寡孤独钞并减免各路租税。原文定位：`P0102`、`P0105`。
- 郡县各社恢复设置义仓，以备荒年。原文定位：`P0108`。
- 德安旱灾，屯田租获免。原文定位：`P0112`。
- 特们德尔被弹劾时，罪状包括侵占晋王田、卫兵牧地、巨额受贿、家奴凌虐官府，并称其专政造成“百姓流亡”；虽然弹劾带有政治修辞，其私家巨富和侵占事实可作为权臣经济侵夺材料。原文定位：`P0122`。
- 成纪县山崩，毁田稼庐舍并压死居民；朝廷又发现蒙古诸部困乏，常有人卖子女为婢，遂命官府赎回。原文定位：`P0130`、`P0132`。
- 仁宗亲见一名边镇戍守超过十五年的卫士衣敝而贫，命赐钱帛，并要求以后此类久戍困乏必须上报。原文定位：`P0133`。
- 秦州灾民再次获赈。原文定位：`P0140`。
- 饶州大饥、米价腾踊，总管王都中不待江浙行省回报即把官米低价再减二成平粜，理由是“人七日不食则死”；他同时核实金户贫富并纠正包银超征，原规定每户不过二两而州县竟加征十倍。原文定位：`P0145`。
- 四明倭人互市时，王克敬撤去以往严兵戒备，以恩意维持贸易秩序；日本战争中陷倭的吴地旧军士随商人归来，也获准返回本乡。原文定位：`P0146—P0147`。
- 诸王位下民在大都者，被要求与普通民户均役。原文定位：`P0152`。
- 黄河小黄村口长期南流，陈、颍膏腴地被淹、百姓流散且威胁汴城；朝廷在农隙修治，二月开工、三月完工。原文定位：`P0155`。
- 曹伯启整顿江浙盐法，撤检校官、设六仓和专门运盐官，明确运输、出纳时限和船户仓吏责任，随后著为制度。原文定位：`P0156`。
- 二月命中书省裁汰不急工役；上都寺院和权豪商贸货物一律输税。原文定位：`P0162—P0163`。
- 一次书写金字《维摩经》用金三千两；内廷佛事年度消耗又被量化为面四十万九千五百斤、油七万九千斤、酥蜜五万余斤。佛事名目由至元三十年的约一百零二项，大德七年后增至五百余，本卷称岁费较大德时“不知几倍”。原文定位：`P0164—P0165`。
- 怀孟、南阳居民原因解州盐池水坏被迫远食陕西红盐，后来已改食沧盐却仍须向陕西缴盐课，民不堪命，朝廷遂免。原文定位：`P0173`。
- 陇西县大雨山崩压死居民，给粮赈济；多地随后又接连山崩、覆没畜产。原文定位：`P0181`、`P0191`、`P0194`。
- 御史台复查此前江浙、江西、河南经理田粮，明确承认虚增粮数“流毒生民”；到三年征租期时，河南新增部分减半征收。原文定位：`P0183`。
- 河南行省左丞陈英等所括民田被全部停止，只按旧例输税，进一步收缩此前括田政策。原文定位：`P0190`。
- 《栽桑图说》刊印一千帙散给民间，属于农桑技术推广。原文定位：`P0195`。
- 雩都里胥刘景周因有司征括田新租而聚众作乱，朝廷随即免征新租并招谕。原文没有兵器、军队调动或接战，故不直接造战役卡，但它是括田政策继续诱发基层反弹的重要材料。原文定位：`P0204`。
- 江西茶课长期急增：从世祖时二万四千锭逐步升至十九万二千八百锭，本卷又改法增额至二十八万九千余锭；原文称郡县竭尽山谷茶产仍“不足其半”，余数长期向民间强取，州县且受转运司杖决压制。原文定位：`P0206—P0207`。
- 重庆江津、巴县设置屯田，因此每年可省成都漕粮一万二千石。原文定位：`P0208`。

## 二、政治秩序、行政、外交与社会变化

- 诸王分地仍由流官任达鲁噶齐，各王府自辟者只能任副职，中央继续保留地方行政主官权。原文定位：`P0006`。
- 纳琳因言事忤旨一度面临重罚，中丞杨多尔济反复力救，并借《贞观政要》论“直由太宗”，最终促使仁宗赦免；另有上书触怒宰相者也因此获释。原文定位：`P0028`。
- 蔡五九之乱平定后，朝廷赏军士并录用死事官员子孙；战役过程另见JSON。原文定位：`P0031`。
- 周王和世㻋被出镇云南，是仁宗改立皇子硕迪巴拉为太子的储位政治背景；到延祐三年，围绕和世㻋已经出现实际关中发兵和河中袭杀，军事阶段另见战役裁决。原文定位：`P0038—P0040`、`P0056`、`P0089—P0091`。
- 特们德尔权势日重，至延祐四年被御史系统以巨额贪赃、侵田、纵奴害官等罪集中弹劾。仁宗震怒并逮问，但特们德尔藏匿于兴圣宫近侍之家；因太后干预，最终只罢相，主劾者杨多尔济反被调离御史台。原文定位：`P0068`、`P0121—P0122`。
- 皇子硕迪巴拉正式立为皇太子，并开府置官。原文定位：`P0095—P0096`。
- 仁宗再次强调中书、法令和宰相执行责任，称“未有法不立而天下治者”；马祖常同时劝其减少饮酒、常出视朝。原文定位：`P0135—P0136`。
- 宿卫出入宫禁被重新限制，未经旨意不得上殿，随从人数也受控。原文定位：`P0143`。
- 术者赵子玉等准备兵器、衣甲、旗鼓并航海赴高丽，谋迎魏王阿穆尔克回大都，但在利津即被发现处死；因尚未迎得魏王、未返京发动、未争夺军政节点，按合同属于未发动阴谋，不进入战争账户。原文定位：`P0184`。
- 播州南宁长官洛么曾“作乱”，经思州守臣诏谕后遣人入贡；原文未写武装过程或调军接战，保留为政治—治安旁录。原文定位：`P0201`。
- 近侍、诸院寺监长期可自行奏除属官，造成富民以贿入仕；敬俨推动把此类滥授一律追夺并立为制度。原文定位：`P0175`。
- 御史台再次裁减无功太尉、司徒、司空等滥爵，仁宗批准。原文定位：`P0178`。
- 白云宗、寺院及近侍印信干预有司的行为持续被收束。原文定位：`P0093`、`P0126`、`P0170`。
- 仁宗朝科举继续举行，延祐五年廷试又赐五十人及第、出身。原文定位：`P0153`、`P0167`。

## 三、跨卷连续性

- 向前承卷198：八百媳妇—大小彻里在卷198`P0051`停征招谕并献物，本卷没有再出现同集团复叛或重新出征材料，可记为相邻卷窗口未见反转；仍不足以把卷198的短期`SB1`升级为长期结构性终结。
- 卷198末吴干道辰沅为寇—调兵捕讨，在本卷没有实名后续，继续待核，不能因史料沉默判定已经平定。
- 卷198江南经理田粮的民众逃窜和虚粮问题，在本卷直接恶化为江西括田苛扰；台臣明确把蔡五九之变归因于经理田粮与郡县酷暴。朝廷停止该役后民心转变、叛势渐衰，说明财政政策与治安安全存在直接因果链。
- 蔡五九虽于本卷九月平定，但同一“征括田新租—聚众作乱”机制到延祐五年`P0204`又在赣州雩都出现，故本卷军事平定的安全收益只宜按局部阶段改善，不认作此类社会反弹结构性终结。
- 周王和世㻋支持集团的关中军行动在河中被内部倒戈制止，但和世㻋本人西走金山并获西北诸王来附；原文又称此后十余年边境宁谧。后卷如出现新的储位战争，应区分中央继承冲突与西北边境实际军事状态。
- 本卷广西猺蛮、眈罗猎户、西番土寇等多条未闭合地方武装线，均须卷200以后继续核实际捕讨结果。
