## 一、财政、民生、工程与灾害

### 1. 粮政、饥荒与赈济

- 至顺元年二月，朝廷以输粟换官，江南输万石可补正七品，陕西一千五百石、河南二千一百石及江南五千石等各有品级，四川富民运粟江陵亦依河南例；不愿仕者可封父母，僧道输粟则加师号。这是直接以官爵和宗教名号吸纳地方粮食。原文定位：`P0014`。
- 江浙发生饥荒后，当年海运定为米二百万石，不足部分准来年补运；常德、澧州、淮安、茶陵等地亦先后赈饥。原文定位：`P0019—P0020`、`P0026`、`P0033`。
- 九月，入粟补官例被罢，显示这项非常筹粮措施只维持了有限时段。原文定位：`P0079`。
- 衡州连续旱蝗后又遭大水，百姓“食草木殆尽”，并有严重疫疠；湖南道宣慰司请求赈粮一万石，获准。原文定位：`P0149`。
- 至顺三年，四川驿户因前期军兴而“消乏”，朝廷命官会同行省量加救济；远戍军官死后归葬，也准比照民官给付道路费用。原文定位：`P0211`。
- 云南战后，朝廷免行省田租三年，属于明确的战后税负减免。原文定位：`P0219`。

### 2. 财政紧张、裁费与宫廷支出

- 四月，中书省指出官分与宿卫年赐原额一万人，上一年已增四千人，后来人数继续增加，请恢复旧额并裁省。原文定位：`P0044`。
- 七月，中书省直言“近岁帑廪空虚”，列出五项主要费用：赏赐、佛事、创置衙门、冒滥支领、续增卫士与鹰坊，并要求中书、枢密、御史台共同裁减。原文定位：`P0061`。
- 八月形成了数量极具体的裁员方案：大内四宿卫每宿不超过四百人，累朝宿卫各不超过二百人；鹰坊一万四千零二十四人裁四千；内饔九百九十人压减；累朝宫分饔人三千二百二十四人留一千一百二十；媵臣、怯怜口一万人留六千。被汰者归本部著籍应役，并严惩宿卫继续容匿汉、南、高丽人或奴隶冒充的行为。原文定位：`P0078`。
- 十一月，有臣请求按旧制足给鹰坊刍粟，文宗明确拒绝，称“国用皆百姓所供，当量入为出”，不愿因鹰坊利益加重民困。原文定位：`P0097`。
- 至顺二年正月，英宗未完工寺院又获中书拨钞十万锭继续施工；同月印造岁额钞本，至元钞八十九万五千锭、中统钞五千锭。原文定位：`P0112—P0113`。
- 四月又发卫卒三千助大承天护圣寺工役；此前后还有五台、雾灵山佛事、寺院及鹰鹘设施等支出。原文定位：`P0137`、`P0140`、`P0143`。
- 至顺三年正月，朝廷下令罢诸建造工役，只保留城郭、河渠、桥道和仓库等公共必要工程。原文定位：`P0197`。
- 陈思谦又因“兵荒之余”反对兴建报严寺，主张“罢土木以舒民力”，文宗嘉纳其谏。原文定位：`P0193`。

### 3. 寺院、权贵与国家土地资源转移

- 朝廷购买故瀛国公赵㬎之田赐龙翔集庆寺；御史台曾主张不必给价，文宗坚持“取人田而不予直，非朕志也”。原文定位：`P0032`。
- 所籍张珪诸子田四百顷赐大承天护圣寺；又在益都、般阳、宁海间括田十六万余顷赐同寺，规模极大。原文定位：`P0045`、`P0047`。
- 蔚州广灵县新发现银矿后，岁入银直接归大承天护圣寺。原文定位：`P0075`。
- 龙庆州流杯园池、水碾、上田赐燕帖木儿；嘉兴、平江、松江、江阴等处官籍芦场、荡山、沙涂、沙田又改赐燕帖木儿。原文定位：`P0132`、`P0135`。
- 全宁民献银矿后设银场提举司，隶中政院；平江官田五百顷另设稻田提举司，隶宫相都总管府，显示矿税与官田继续向宫廷、权贵机构集中。原文定位：`P0136`、`P0150`。
- 燕帖木儿邸舍商贷税获免征。原文定位：`P0167`。
- 至顺三年，燕帖木儿把平江、松江淀山湖圩田五百余顷改作承佃安排：原额官粮七千七百石，表示愿增为一万石，余米供其弟撒敦。原文定位：`P0212`。

### 4. 苛课、矿冶、盐课与基层破产

- 富州本不产金，却因奸民倡议募淘金户三百户到外郡采金，岁课从四两逐渐增至四十九两；倡议者死后，三百户“所存无什一”，且贫不聊生，有司又转责普通役民代输，致“民多以是破产”。经揭傒斯陈言后，朝廷最终蠲除此征，百姓“赖以甦”。原文定位：`P0108`。
- 邛州金凤、茅地二盐井在天历地震后盐水涌溢，州民侯坤自备器具煮盐纳课，后由四川转运盐司接管。原文定位：`P0210`。
- 河南行省规定，民间自实田土粮税在不通舟楫处可用钞代输，降低了实物运输要求。原文定位：`P0098`。

### 5. 水旱、地震、虫灾与工程

- 大名路黄河溢；江南随后大水，江浙、湖广尤甚。原文定位：`P0055`、`P0071`。
- 通渭山崩、大宁路地震，真定武陟又持续地震逾月。原文定位：`P0058`、`P0080`、`P0142`。
- 冠州虫害食桑四十余万株，直接损害蚕桑生产。原文定位：`P0129`。
- 江浙水灾毁田四十八万八千余顷，是本卷最明确的大规模农业损失数字。原文定位：`P0168`。
- 湖州安吉久雨、太湖溢，漂没居民，朝廷赈济；吴江又遭大风雨、太湖溢，漂没庐舍，江浙行省奉命救济。原文定位：`P0173`、`P0178`。
- 洛水溢；汴梁睢州、陈州及开封兰阳、封丘等县河水溢，滹沱河决。原文定位：`P0213`、`P0226`。
- 漷州、柳林海子堤堰由诸卫卒修筑；至顺三年又调军士修柳林海子桥道。原文定位：`P0060`、`P0231`。
- 楚丘县河堤坏，直接发民丁修筑。原文定位：`P0240`。

### 6. 军役、戍役与运输负担的非战斗材料

- 江西、建昌万户府军戍广海，原先一年一更，因往来劳苦，恢复至元旧制为二年一更，减少频繁轮换。原文定位：`P0059`。
- 芒部九村夷人主动提出自备粮四百石、民丁一千人助征，说明云南用兵正在吸纳地方粮役。原文定位：`P0065`。
- 云南军中两名士卒非临阵逃归，依法本拟处死；文宗认为非战阵逃亡不应轻易杀人，改杖流。原文定位：`P0066`。
- 云南战事后仍须长期留驻诸王部众一至二年镇守，其余军队才遣还；后续又因局势不稳要求边关戍军不得轻撤。原文定位：`P0145`、`P0157`。
- 四川行省参政马铬曾发粮六千石供云南军，却中途擅还，后来因此连同其他问题被罢，反映军粮转输责任。原文定位：`P0171`。
- 伊奇布锡所牧国马原需云南盐供给，叛乱后盐道中断，马匹“大多病死”，朝廷改令四川供盐。原文定位：`P0181`。

## 二、政治秩序、制度、外交与社会

### 1. 权力集中、监察与官僚治理

- 文宗命纂《经世大典》，后因久未成书，专门组织蒙古文典章译为汉语，再由赵世延、虞集等纂修；至顺二年五月终于完成。原文定位：`P0003`、`P0016—P0017`、`P0148`、`P0151`。
- 燕帖木儿获得前所未有的宰相集权：左丞相不再设置，号令、刑名、选法、钱粮、造作等中书政务均由其总裁，并禁止诸王、公主、驸马、近侍越级奏事。原文定位：`P0029`。
- 多名御史先后弹劾贪污、滥爵和不称职官员，平章多尔济、辽阳平章哈喇帖木儿、岭北平章哈玛尔图、苏苏等被罢黜或远徙；对家人代受财也改按赃数论罪。原文定位：`P0023`、`P0082—P0085`、`P0091`。
- 监察御史秦起宗坚持追究中丞和尚受妇女、贱买官屋案，即使遇立太子大赦仍继续奏劾，最终使其伏罪。原文定位：`P0104`。
- 贿赂关说制度进一步加重：官员在职或候任替人行贿关说而取财者按赃论罪，吏员终身不叙；即使未取财但操纵诉讼，也加等治罪。原文定位：`P0156`。
- 陈思谦提出减并至元三十年后冗滥衙门、建立荐举责任制、打通内外官经历、限制京官连续任期等系统铨政改革，文宗命中书议行。原文定位：`P0192`。
- 苏天爵赴湖北虑囚，发现此前巡审多“应故事”，遂逐案细究冤滞，即使盛暑仍夜间治文书。原文定位：`P0229—P0230`。

### 2. 司法、民权与基层治理

- 范梈在福建发现文绣局征取良家女子为绣工且男女混杂，作诗揭弊后上闻，所有女工被罢遣，制度遂革。原文定位：`P0106`。
- 泾县张道杀人案中，其弟张吉因“从而不加功”被囚七年未决，文宗因其母老无他子，免死杖释使养母。原文定位：`P0144`。
- 江西平章岳柱拒绝执行对富民所谓欠永宁王官帑银八百余锭的追征，认为“民为邦本，伤本以敛怨”；复查证明原告诬罔，朝廷惩处告者。原文定位：`P0190`。
- 桂阳州二千余人聚众，地方请求发兵。岳柱先派人查因，查明系两巡检司逼迫所致，遂劝众复业而未兴兵，使“一方以宁”。这是本卷非常重要的低成本基层纠纷处置材料。原文定位：`P0191`。
- 文宗曾欲阅本朝国史，编修吕思诚以“国史纪当代人君善恶，自古天子无观阅之者”力争，皇帝遂止。原文定位：`P0194`。

### 3. 宗教、学校、礼制与社会政策

- 文宗、皇后、皇子及明宗皇子相继受佛戒；仁和殿佛事从四月至十二月持续，另有多处佛事。原文定位：`P0021—P0022`、`P0043`。
- 至顺二年又设广教总管府十六所、正三品，专管僧尼，形成规模不小的宗教行政体系。原文定位：`P0120`。
- 蒙古字学被重新兴举；国子监学生积分及格者，由省、台、集贤院、奎章阁共同考试后试官。原文定位：`P0077`、`P0100`。
- 御史建议扩大国子学生员，打破蒙古、色目、汉人固定名额；又建议对父母年老且无他丁者优先近地迁调，两项均未获答复。原文定位：`P0154`。
- 官员服丧被频繁“夺情起复”，陈思谦主张非军事紧急不得夺情，遂著为令。原文定位：`P0193`。
- 朝廷议定限制非祀典神祠滥加封号。原文定位：`P0224`。

### 4. 皇位继承与中枢秩序

- 文宗一度为立己子而采用明宗皇子乳母夫之说，将妥欢帖睦尔黜往江南，并要求写入国史文书，反映储位竞争与史书书写的直接政治干预。原文定位：`P0052`。
- 皇太子喇特纳答剌于至顺二年正月去世。原文定位：`P0115`。
- 文宗临终承认“和世㻋之事”为平生大错，要求改立明宗之子；燕帖木儿因自身参与明宗之死而秘不发诏，导致皇位长期虚悬。原文定位：`P0233—P0234`。
- 皇位空缺期间，燕帖木儿一度主张立文宗幼子，皇太后坚持先立明宗次子懿璘质班；宁宗即位仅四十三日即崩。随后太后又拒绝立幼子燕帖古思，决定迎十三岁的明宗长子妥欢帖睦尔。原文定位：`P0238`、`P0242`、`P0244`。
- 嗣君未立时，燕地有人虚告部使者谋反；张起岩主张迅速惩治虚告者以稳定危疑人心。原文定位：`P0243`。

### 5. 对外与边疆行政的非战斗变化

- 四川招抚怀德府驴谷、什用等四洞及生蛮十二洞内附，升怀德府为宣抚司，各洞设长官司、巡检司，并令归还所掠人口。原文定位：`P0121`。
- 麓川设军民总管府，哈喇火州恢复总管府，属于边疆设治调整。原文定位：`P0084`。
- 高丽王位因王焘病愈而复归其本人。原文定位：`P0196`。
- 安南王陈益稷死后仍获追赠开府仪同三司、湖广行省平章及原王爵。原文定位：`P0067`。

## 三、跨卷连续性

- 向前：卷205已经出现灾多、帑藏空虚与寺院土木扰民的警报；卷206以“帑廪空虚”五项费用清单、宿卫鹰坊裁员、矿课导致民户破产、江浙毁田四十八万八千余顷等材料进一步量化了财政与民生压力。
- 本卷财政主线：一面以输粟补官、海运、盐矿、官田和货币发行补充国家资源，一面又持续把大批田地、矿利、税免和劳役投向寺院与权贵；朝廷内部同时不断出现量入为出、裁冗、停土木、减役和蠲免的纠偏。
- 战役连续性：本文件不记录各战线胜负与后效，相关跨卷事项全部移入 `volume-206.battle-adjudications.json`；这里只保留免云南田租三年、边戍轮换与军粮等非战斗政策事实。
- 向后：宁宗四十三日即崩后，皇太后已遣使迎妥欢帖睦尔，卷207将进入顺帝即位及燕帖木儿死后新的权力结构。
