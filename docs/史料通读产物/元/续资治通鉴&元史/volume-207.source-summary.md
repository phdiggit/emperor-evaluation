## 一、财政、民生、工程与灾害

### 1. 即位初年的灾害与饥荒

- 元统元年六月即位前后，京畿大霖雨，平地水深丈余；泾水溢造成关中水灾，黄河大溢造成河南水灾，两淮同时旱荒，“民大饥”。这是顺帝即位时最直接的民生底色。原文定位：`P0009`。
- 七月继续霖雨，八月巩昌徽州山崩；十一月巩昌成纪县地裂山崩，朝廷命有司赈被灾人民。原文定位：`P0012—P0013`、`P0027`。
- 元统二年二月，滦河、漆河溢，永平诸县水灾；三月起湖广持续不雨至八月，四月起河南亦持续不雨至八月。原文定位：`P0057`、`P0065`、`P0076`。
- 六月淮水涨，山阳满浦、清冈等处民畜、房舍多被漂溺。原文定位：`P0083`。
- 八月京师地震，鸡鸣山崩陷成百里之池，“人死者甚众”；南康路又旱蝗，朝廷赈济。原文定位：`P0096`、`P0098`。
- 至元元年三月，河州路大雪十日，积雪深八尺，牛羊驼马冻死“十九”，民大饥。此“十九”按原文保留，不自行改字；它至少说明畜牧损失和饥荒极重。原文定位：`P0119`。
- 至元二年五月，南阳、邓州大霖雨延续至六月，湍河、白河大溢，“大为灾”；涇水亦溢。原文定位：`P0195`、`P0200`。
- 黄州蝗灾，地方督民捕蝗，规定每日五斗。原文定位：`P0203`。
- 江州诸县饥荒时，总管王大中向富户借粟赈贫，以免富户杂徭作为利息，约丰年归还，结果“民不病饥”。这是本卷最具体的地方赈荒融资案例。原文定位：`P0212`。
- 同年江浙自春至八月不雨，“民大饥”。原文定位：`P0214`。
- 至元三年二月，朝廷发钞四十万锭，赈江浙等处饥民四十万户，同时开放山场、河泊禁令，让百姓樵采以自给。原文定位：`P0226`。
- 六月连日大霖雨，御河、黄河、沁河、浑河皆溢，淹没人畜、庐舍甚众；彰德府大水，平地深一丈。原文定位：`P0241`、`P0243`。
- 卫辉府自六月淫雨至七月，平地水深二丈余，人民房舍漂没，百姓多栖树上；郡守僧嘉努用船载饭，并将老弱移至城头，每日给粮，持续月余至水退。原文定位：`P0248`。
- 八月京畿大地震，太庙梁柱、墙壁及祭器严重损坏，人民损失甚众；河南亦震。原文定位：`P0249—P0250`。
- 至元四年六月，邵武路大雨，水入城郭，平地二丈，民居几乎尽漂；七月奉圣州大震毁民居，巩昌府山裂压死人民；八月宣德府、京师又连续地震。原文定位：`P0282`、`P0286—P0291`。
- 因宣德、奉圣多次地震，朝廷分别改名顺宁府、保安州，属于直接以灾异改地名的行政反应。原文定位：`P0291`。

### 2. 赋税、粮运与救荒制度

- 元统元年九月免儒人役。原文定位：`P0019`。
- 江西、湖广、江浙、河南恢复榷茶运司，茶税专卖机构重新建立。原文定位：`P0031`。
- 元统元年岁末，顺帝即位后每日御膳原定五羊，主动减半，全年节省羊三百五十余只。原文定位：`P0042`。
- 王克敬任江浙参知政事后，请罢富民承佃江、淮田；又处理松江大姓生前每年献漕米一万石之遗留负担：其本人死、子孙贫困后，官府仍岁征，不足部分摊入松江田赋由全郡包纳。王克敬认为“不可使一郡之人均受其害”，遂奏免此额。原文定位：`P0044`。
- 同段又记岭海用兵时行省军粮发给有差，朝廷听闻后令江西、湖广两省亦照此给粮，显示跨省出兵的粮给标准化。原文定位：`P0044`。
- 元统二年四月，在京师南北城立盐局，由官府自行卖盐，名义是革除专利之弊。原文定位：`P0072`。
- 五月，皇后经宦者传旨，取盐十万引入中政院，国家盐利再被宫廷机构大量截取。原文定位：`P0077`。
- 十月给皇太后上尊号时赦天下，并免当年民租之半。原文定位：`P0106`。
- 至元元年六月，请对甘肃撒里畏产出的金银设官征税。原文定位：`P0131`。
- 同月罢江淮财赋总管府所辖杭州、平江、集庆三处提举司，将事务归有司，属于财政机构撤并。原文定位：`P0133`。
- 至元元年岁末又“赐天下田租之半”，本卷原文仅如此记载，按事实保留为全国性田租减免材料，不额外推定执行细节。原文定位：`P0175`。
- 至元二年三月恢复四川盐茶之禁。原文定位：`P0190`。
- 七月严禁越过中书口传敕旨、冒支钱粮，直接针对绕开正式财政审批的支出。原文定位：`P0201`。
- 十月，江浙行省丞相绰斯戩主持海运，漕米三百余万石全部到达京师，“无耗折者”；这是本卷最清楚的国家级粮运效率数字。原文定位：`P0256`。
- 十一月在雄州立屯田。原文定位：`P0258`。

### 3. 民役、船户、寺院与隐役人口

- 元统二年三月，朝廷下诏“罢造作四年”，直接暂停多数宫廷营造。原文定位：`P0059`。
- 四月中书省认为佛事布施“费用太广”，除累朝周年忌日外其余佛事悉罢。原文定位：`P0073`。
- 御史多尔济巴勒指出天下财赋皆出于民，民力已竭而国用仍不足，请专派中书官督户部减省，罢不急工役、无名赏赐、禁中佛事和冗官，并提出均公田、铸钱、罢山东田赋总管府、蠲河南自实田粮等建议；这些属于财政诊断和改革建议，并非全部已经施行。原文定位：`P0094`。
- 禁止私人新创寺观庵院；僧道出家需交钱五十贯取得度牒。原文定位：`P0113`。
- 至元元年二月革冗官。原文定位：`P0117`。
- 御史以赤县之民“供给敏劳”、春耕方兴为由劝止柳林畋猎，顺帝接受。原文定位：`P0118`。
- 至元二年八月规定边远官死后不能归葬者，由有司给粮、舟车送归；无亲属者由官府安葬。原文定位：`P0205`。
- 至元三年二月设船户提举司十处、提领二十处，并定船户科差：一千料以上大船每年纳钞六锭，以下递减。原文定位：`P0223`。
- 采珠提举司此前因烦扰已在泰定间被罢，至元三年又恢复，并把蜑户四万赐给巴延，意味着大量专业户与赋役资源被划入权臣体系。原文定位：`P0228`。
- 嘉兴一路寺院私庇“道人、道民、行童”等逃避徭役人口，经劄实勘核已有二千七百人；朝廷采纳其建议，勒令归本族、恢复承担皇赋，以减轻其他民户分摊的役负。原文定位：`P0263`。

### 4. 学田、宿卫与财政资源错配

- 至元元年十一月，朝廷把各地儒学贡士庄田租改给宿卫粮用。原文定位：`P0155`。
- 紧接着罢科举，徹里帖木儿推动此议时又主张以学田租供卫士衣粮，并试图减少太庙祭祀；许有壬反驳称全国通事、知印等已有三千三百余名，半年内白身补官受宣者七十三人，而科举一年仅三十余人，不能把选法壅滞归罪科举。原文定位：`P0156—P0157`。
- 罢科举后，巴延又要求内外官一律循资铨注，不得保举。原文定位：`P0159`。

### 5. 土地、矿产与权贵资源

- 元统元年十一月，燕帖木儿原获赐的平江田五百顷复赐其子腾吉斯。原文定位：`P0033`。
- 至元二年二月，把世祖曾赐王积翁而后收入官的田八十顷归还其子。原文定位：`P0184`。
- 六月将汴梁、大名诸路图卜台地土赐巴延。原文定位：`P0198`。
- 至元三年正月，豫王喇特纳实里购买池州铜陵产银地，以私财冶炼并向官府纳课，获准。原文定位：`P0219`。
- 九月宁夏设皮货所，置提领使、副主其事。原文定位：`P0253`。

### 6. 人口恢复与地方行政

- 至元四年十一月立绍熙府军民宣抚都总使司。此地国初因荒废而撤治，到此时已恢复到居民二十余万，辖六州、二十县、一百五十二镇，因人口回升重新设府，是本卷最明确的长期人口恢复材料。原文定位：`P0296`。
- 邦牙等处因极边酋长按旧制来贡，朝廷设宣慰司都元帅府并总管府，属边疆行政制度化。原文定位：`P0299`。

## 二、政治秩序、制度、外交与社会

### 1. 顺帝即位与中枢权力结构

- 妥欢帖睦尔自静江北来，燕帖木儿因担忧明宗暴崩旧案迟迟不愿立帝；数月间国事皆由燕帖木儿裁决，再奏皇太后施行。燕帖木儿随后因长期荒纵而病死，皇太后才与大臣确定立妥欢帖睦尔。原文定位：`P0004—P0006`。
- 顺帝即位后任巴延为太师、右丞相，撒敦为太傅、左丞相；又听明宗旧臣阿鲁辉帖木儿之言，深居宫中，将政务几乎完全委给宰相。原文定位：`P0007—P0008`。
- 九月明令巴延、撒敦专理国家大事，其余不得兼领三职；十一月又令二人“总百官，总庶政”。原文定位：`P0018`、`P0034`。
- 皇太后徽政院设置官属三百六十六员，体现后宫机构规模扩张。原文定位：`P0037`。
- 至元元年七月以后，巴延独任右丞相，左丞相不置；随后又清退燕帖木儿、腾吉斯所举用之人，并对相关宗王、家族进行流徙处置。武装政变本身另见战役裁决卡。原文定位：`P0140—P0143`、`P0151`。
- 九月御史台请求把内府“不下千余”的执事人员按旧制裁减，理由直指冗滥和糜费，获准。原文定位：`P0148`。
- 至元二年十月形成内廷—中书双层议政：巴延、太保定珠等每日在内廷聚议，其他平章、右丞、参政在中书聚议。原文定位：`P0208`。

### 2. 民族性任官、法制与社会控制

- 至元三年四月，朝廷规定省、院、台、部、宣慰司、廉访司及部府幕官长官均用蒙古、色目人，并禁止汉人、南人学习蒙古、色目文字。原文定位：`P0234`。
- 同月又禁汉人、南人、高丽人持有军器，有马者没收入官；八月后仅放宽高丽人持械禁令。原文定位：`P0230`、`P0251`。
- 至元三年岁末，巴延甚至请求杀张、王、刘、李、赵五姓汉人，顺帝没有同意。原文定位：`P0261`。
- 元统二年三月规定蒙古、色目犯奸盗诈伪由宗正府管，汉人、南人由普通有司管；七月又规定蒙古、色目盗罪免刺，体现司法身份差别。原文定位：`P0064`、`P0092`。
- 至元二年八月制定严酷盗窃刑罚：强盗皆死，盗牛马者劓，盗驴骡、羊豕等按再犯次数黥、劓甚至处死，并定三年一次大审。原文定位：`P0206`。
- 王结反对南北罪犯远徙万里、途中多死的旧例，请改为离乡千里外，悔过可还乡，遂著为令；又反对对犯罪职官一概过重，以维护士人廉耻。原文定位：`P0122`。
- 李好文录囚河东，释放十四年不决且犯罪状况不明的李拜拜；对依势踢人致死的王傅撒都剌则坚持按杀人置死，形成宽严并用。原文定位：`P0165`。
- 陈思谦推动修改杀人法律，将故杀、加功等情节重新明确加重。原文定位：`P0138`。
- 至元四年设考功官，专门考校天下郡县官属功过。原文定位：`P0280`。

### 3. 科举、学校与文化政策

- 元统元年限制一般官员递升，以疏通选法。原文定位：`P0017`。
- 元统二年二月命内外兴学；三月又恢复科举、国子监积分、膳学钱粮、儒人免役等累朝旧制，并要求学校官选德行学问兼备者。原文定位：`P0054`、`P0058`。
- 至元元年十一月，巴延集团正式罢科举，许有壬虽力争但失败；翌年礼部侍郎呼勒岱请求恢复，也未获准。原文定位：`P0156—P0157`、`P0199`。
- 至元元年建立常平仓。原文定位：`P0166`。
- 至元元年末蒙古国子监建成。原文定位：`P0172`。
- 至元四年，昂吉尔监修《至正条格》，法典编修启动。原文定位：`P0274`。

### 4. 宗教与礼制

- 元统二年四月，因佛事布施过广而大幅裁撤；至元元年又禁私创寺观，并以五十贯度牒费规范出家。原文定位：`P0073`、`P0113`。
- 至元元年，朝廷一度规定有妻室僧人还俗为民，随后又允许其继续为僧，政策发生反复。原文定位：`P0176`。
- 高丽因元廷近年屡派使者选择媵妾，已出现“生女不举，女长不嫁”的严重社会后果；御史奏请禁止，朝廷采纳。原文定位：`P0120`。
- 至元四年八月再次申明禁止从高丽索取女子和阉人。原文定位：`P0289`。

### 5. 监察、言路与纠错

- 多尔济巴勒多次上疏，既要求整肃刑政、安盗赈饥，又直接指出民力枯竭、工役赏赐佛事冗官造成财政压力。原文定位：`P0038`、`P0094`。
- 监察御史台布哈反对给皇太后加徽号，太后一度欲杀谏者，最终承认“风宪有臣如此”并奖赏，虽其意见未被采用。原文定位：`P0107`。
- 库库在经筵反复以宋徽宗亡国等故事劝顺帝专务人君本职，并坚持“宰相不得言则台谏言之，台谏不敢言则经筵言之”。原文定位：`P0152`。
- 李好文反对重复使用世祖“至元”年号，并列举当时政弊与世祖时期不如处，未被采纳。原文定位：`P0163—P0164`。
- 陕西御史劄实上十条封事，要求法祖宗、揽权纲、惜名器、开言路、复科举、宽禁网等，并敢于按劾地方权臣私人。原文定位：`P0213`。
- 至元四年托克托任御史大夫，原文称“大振纲纪，中外肃然”。原文定位：`P0276`。
- 顺帝行猎时，托克托以帝王应与大臣宿儒讲求治道、飞鹰走狗非本职相谏，顺帝接受。原文定位：`P0297`。

### 6. 外交与边疆的非战斗事实

- 高丽使者经过辽阳，向行省官各送布四匹及私书，达尔玛认为以国印封私书属欺诈而拒收。原文定位：`P0041`。
- 安南世子陈端午获封安南国王。原文定位：`P0123`。
- 至元元年九月，乌撒、乌蒙改隶四川行省。这与卷206云南长期战乱有连续性，但本段只是行政隶属调整，不能反推前卷祿余等武装问题已经永久平定。原文定位：`P0149`。
- 燕帖木儿、腾吉斯、达朗达赉此前夺取的高丽田宅归还高丽王喇特纳实里。原文定位：`P0161`。
- 邦牙等处来贡后，朝廷按世祖旧制建立宣慰、都元帅与总管机构。原文定位：`P0299`。
