## 一、财政、民生、工程与灾害

### 1. 粮价、赈济、税役与基层汲取

- 至正六年留守大都时，旧有官仓“红帖米”“散筹米”被人收买筹帖套利；特穆尔达实另发米二十万石，直接在市肆按五十文一斗出售，原文称“奸弊遂绝”。这是本卷很具体的城市粮食平粜与堵塞中间套利材料。原文定位：`P0016`“別發米二十萬石”“使人持五十文即得米一斗，奸弊遂絕”。
- 江西田赋提举司因“扰民”被直接裁撤，说明专门田赋机构的征收方式已形成明确基层负担。原文定位：`P0019`“江西田賦提舉司擾民，罷之”。
- 闰十月大赦时普免差税三分之一，水旱灾区全免。原文定位：`P0039`“免差稅三分，水旱之地全免”。
- 盖苗反对给角抵者钞万贯，理由是“诸处告饥，不蒙赈恤”，将巨额娱乐赏赐与饥民未获救济直接对照；此前又阻止扩建两京驰道毁民田庐。原文定位：`P0047`“請毀民田廬廣之…乃罷”“諸處告饑，不蒙賑恤；力戲何功，獲此重賞乎”。
- 甘肃每年中粮“奸弊百端”，盖苗请粮、钞兼给，原文称可使“军民兼利”，朝廷采纳。原文定位：`P0047`“甘肅每歲中糧奸弊百端”“以糧鈔兼給，則軍民兼利矣”。
- 河东大旱，“民多饥死”，朝廷遣使赈济；彰德又大饥至“民相食”。原文定位：`P0069`“河東大旱，民多饑死”；`P0076`“彰德路大饑，民相食”。
- 特穆尔达实任相时分海漕米四十万石置沿河诸仓“以备凶荒”，并恢复僧人与齐民同受官役的旧法。原文定位：`P0082`“分海漕米四十萬石，置沿河諸倉，以備凶荒”“僧人與齊民均受役於官”。
- 户部至正七年明确把财政困境与灾害、战乱联结起来：各地水旱、田禾不收，湖广云南盗贼蜂起，“兵费不给”，同时各位集赛冗食甚多；但裁减被皇帝推迟三年。原文定位：`P0094`“各處水旱，田禾不收…兵費不給”“集賽冗食甚多”“令三年後減之”。
- 山东十六万二千余顷土地划归大承天护圣寺，是巨量土地资源向寺院转移的直接材料。原文定位：`P0093`“撥山東十六萬二千餘頃地，屬大承天護聖寺”。
- 至正七年末因连年水旱、民多失业，朝廷选二十六名台阁名臣外任守令，允许密封报告民间利害，显示中央已把灾荒失业视作地方治理的首要背景。原文定位：`P0105`“連年水旱，民多失業”“選臺閣名臣二十六人出為守令”。
- 顺江酋长请求内附并设十三处郡县时，归旸反对，理由是远地有事若救则“疲中国以事外夷”，主张只授宣抚、不给贡赋压力并赐金帛遣返；此议被采纳，是对边远扩张财政—军事负担的明确节制。原文定位：`P0103`“救之，則疲中國以事外夷”“勿責其貢賦”。
- 京师严寒时丞相原拟把官藏皮服尽给贫民，归旸认为数量有限，主张先登记饥寒者再赈，丞相采纳。原文定位：`P0103`“莫若錄饑寒者賑之”。
- 永平岁饥，贾惟贞请求发钞四万余锭赈济。原文定位：`P0124`“請降鈔四萬餘錠賑之”。
- 河间等路因连年河决、水旱相仍，已经出现“户口消耗”，地方请求减盐额，朝廷准许。这是灾害、人口减少与盐课承载能力直接挂钩的材料。原文定位：`P0135`“連年河決，水旱相仍，戶口消耗，乞減鹽額”。
- 平江、松江水灾，朝廷调海运粮十万石赈济。原文定位：`P0140`“給海運糧十萬石賑之”。
- 山东大水、民饥，朝廷赈济；胶州又大饥至“人相食”。原文定位：`P0153`“山東大水，民飢，賑之”；`P0175`“膠州大饑，人相食”。
- 彰德至正十年清明前仍大雪三尺，“民多冻馁死”，显示灾荒与严寒直接造成民众死亡。原文定位：`P0223`“雨雪三尺，民多凍餒死”。
- 至正十年十一月罢辽阳滨海民煎熬野盐，属于对地方盐业生产方式的直接干预。原文定位：`P0240`“罷遼陽濱海民煎熬野鹽”。

### 2. 河患、水利、运输与劳役

- 黄河决口后先立河南、山东都水监；至正八年黄河再决，济宁路甚至被迫迁治济州；至正九年又立山东河南行都水监专治河患。原文定位：`P0023`、`P0116`、`P0171`。
- 至正九年坝河浅涩，征军士一万、民夫一万疏浚；白茅河造成巨浸后修金堤，民夫按日给钞三贯。两条材料都明确给出河工劳力和付酬方式。原文定位：`P0173`“軍士、民夫各一萬浚之”；`P0182`“民夫日給鈔三貫”。
- 同年黄河北溃，高唐州城被水淹没，江汉溢水漂没民居、禾稼，归德府霖雨十旬；蜀江大溢又浸汉阳城并导致民大饥。原文定位：`P0174`、`P0183`、`P0195`。
- 至正十年河决已“五年不能塞，方数千里，民被其患”，托克托决定亲任其事。贾鲁提出“修北堤”与“疏塞并举、挽河东行复故道”两策，后者费用大，朝廷最终仍在持续论证阶段。原文定位：`P0243`“河決五年不能塞，方數千里，民被其患”；`P0244`“其功費甚大”。
- 漕运使贾鲁提出二十余项便益，朝廷采用八项，涉及京畿和籴、漕户优恤、接运委官、通州总治、坝夫与船户矛盾、海粮损坏、运河疏浚及船户归漕司节制，反映漕运系统已存在多环节制度性摩擦。原文定位：`P0214`“船戶困于壩夫，海糧壞於壩戶”等。
- 至正十年九月又用军士五百修筑白河堤，属于军人投入公共河工。原文定位：`P0232`“以軍士五百修築白河堤”。

### 3. 灾害死亡与生产破坏

- 至正六年山东地震连续七日；高苑地震坏民居；罗浮山崩水涌溺死百余人；临淄大雹后“野无青草，赤地如赭”，直接破坏植被与农业。原文定位：`P0005`、`P0010`、`P0026`、`P0035`。
- 至正七年河东地坼、泉涌、崩城陷屋并伤人；山东地震坏城郭。原文定位：`P0054`、`P0073`。
- 至正八年五月广西山崩、水涌，漓江溢，平地水深二丈余，房屋、人畜漂没；钱塘江潮异常高涨，沿江居民被迫迁居。原文定位：`P0147`、`P0148`。
- 永嘉大风将海舟吹上平陆二三十里，“死者千数”；中兴路松滋骤雨暴涨，漂没六十余里，死亡一千五百人。两处均为本卷罕见的有明确千人级灾害死亡材料。原文定位：`P0150`“死者千數”；`P0152`“死者一千五百人”。
- 至正九年大霖雨淹高唐州城、江汉溢水毁民居禾稼；至正十年宁州、上高又有山崩。原文定位：`P0195`、`P0228`、`P0229`。

### 4. 钞法恶化与财政信用

- 至正十年托克托推动更钞，吕思诚强烈反对“以虚换实”，指出新交钞同样会被伪造，并以此前金口河失败警告改革责任风险；因反对而被左迁。原文定位：`P0235—P0236`“我有三字策，曰行不得”“如向日開金口河”。
- 新钞议最终实行：中统交钞一贯折铜钱一千文、准至元宝钞二贯，同时铸钱并行。原文明确记载不久“物价腾踊至逾十倍”；兵兴后各地转为以物易物，公私旧积货币皆不行，“国用由是大乏”。这是本卷最重要的货币—财政崩坏材料。原文定位：`P0237`“物價騰踴至逾十倍”“皆以物貸相貿易”“國用由是大乏”。

## 二、政治秩序、制度、社会与外交

### 1. 监察、用人与行政约束

- 多尔济巴勒拒绝皇帝把善音乐的幸臣直接塞入崇文监清选，宁愿自认“他拟一人”之罪，皇帝反而擢为右丞。原文定位：`P0030`“用幸臣居清選，恐後世以此議陛下”。
- 京畿奉使鼎鼎、湖广道巴实在各道奉使与台宪多相互掩蔽的背景下仍“纠举无避”，构成监察失灵中的少数反例。原文定位：`P0031`。
- 至正六年已有司因赏赉泛滥，要求恩赐先经省、台、院拟议。原文定位：`P0043`“賞賚氾濫”。
- 盖苗连续反对毁民田扩驰道、以郡守职位“养贫”宿卫、巨赏角抵者，并因“每事相抗”遭宰相排斥，最终外调。原文定位：`P0047`。
- 阿鲁图被御史弹劾即自行离任，不以丞相权力对抗御史制度；博尔济布哈也不久罢职。原文定位：`P0053`。
- 至正七年请求恢复给事中记录省台院奏事以供国史纂修，朝廷采纳；这与卷208“全无所书，史事遂废”形成制度性纠偏。原文定位：`P0057`。
- 特穆尔达实任相时恢复朝官外补陛辞、地方贤吏入补朝阙、老臣预议大政等制度，半年间“补偏救弊之政，以次兴举”。原文定位：`P0082`。
- 至正七年末朱公迁屡劝皇帝亲贤远奸、抑豪强、省冗费、修德恤民，警告国家之忧“近在旦夕”；皇帝虽称嘉纳，执政者却因其切直而排挤外任。原文定位：`P0111`。
- 桑节任江南行台御史大夫后强调御史行部；到湖广又约束威顺王长期出猎扰民、经营广乐园牟利，以及胡僧“小住持”恃宠凌轹官府，原文称其后“豪强敛手”。原文定位：`P0122—P0123`。
- 守令制度继续加强：廉勤者获旌；社长专责劝课农桑；京官三品以上每岁举守令一人，守令到任三月也须举自代者；至正九年又建立路督府、府督州、州督县的督摄法。原文定位：`P0126`、`P0138—P0139`、`P0181`。
- 成遵奉使山东、淮北，查得循良守令九人、贪懦二十一人，前者升赏，后者全部黜退。原文定位：`P0163`。
- 至正九年哈玛尔、舒苏倚宠受贿、出入庶母皇后宫等事被御史弹劾，皇帝最初震怒拒绝，后仅夺官；弹劾者反被外调。托克托复相后又因哈玛尔曾维护自己而重新援引其入枢密。原文定位：`P0185—P0187`、`P0201`。
- 泰费音所拔孔思立等被托克托集团诬罪黜去，泰费音本人也受攻击；其拒绝自杀，称“吾无罪，当听于天”。原文定位：`P0200`。
- 至正十年托克托居母忧仍被命出理庶务，随后把大小事务大量交给少数腹心，“事行而群臣不知”，反映中书决策明显内圈化。原文定位：`P0226`。
- 吏部选格条目繁多到足以让铨选者任意高下，托克托请统一编类成书。原文定位：`P0233`。

### 2. 教育、史政与皇太子培养

- 朝廷要求中书左右司、六部吏员午后讲习经史。原文定位：`P0017`。
- 至正七年编《六条政类》，至正八年成书；国子监会食弟子员经考试后补路府及各卫学正。原文定位：`P0059—P0060`、`P0133`。
- 皇太子阿裕实哩达喇先学畏兀儿文字，后又奉命学汉文；李好文、归旸等负责经学教育。奇皇后明确反驳“学孔子之教会坏佛法真性”的说法，称治天下“须用孔子之道”。原文定位：`P0120`、`P0188—P0190`。
- 至正九年十月太子正式入端本堂肄业，李好文所进《经训要义》及后续帝王治乱教材被用于东宫教育。原文定位：`P0208—P0209`。
- 翰林国史院继续纂修后妃、功臣列传。原文定位：`P0118`。

### 3. 宗王、社会负担与制度性消费

- 威顺王岁常出猎使湖广民众受苦，又经营广乐园聚名倡巨贾牟取厚利；桑节面责后，王“悉罢其所为”。原文定位：`P0123`“威順王歲嘗出獵，民病之”“廣樂園…以網大利”。
- 至正六年盖苗还反对把宿卫士一律外放作郡长官“以养贫”，强调郡长是“牧民”岗位，不能成为安置贫困权贵的福利职位。原文定位：`P0047`。
- 至正九年诏汰冗官、均俸禄，并赐致仕官、高年帛。原文定位：`P0213`。

### 4. 战乱背景下的军事行政，但不作为战役卡重复计战

- 元廷因河南盗乱，分拨军队守河南水陆关隘，自徐、邳至夹马营遇贼掩捕；因山东寇又在沂州设分元帅府。两者均属防务部署，未见本段实际接战。原文定位：`P0106`、`P0162`。
- 福建盗起后，因地远难于讨捕，在汀、漳设分元帅府；沅、靖、柳、桂猺獠长期活动后，又设三分省、靖州军民安抚司及万户府、增戍兵。这些材料反映地方治安恶化已经迫使军政机构常设化。原文定位：`P0129`、`P0216`。
- 至正十年南阳、大名、东平、济南、徐州设五处兵马指挥司捕“上马贼”，但原文明确说“终不能禁”；实际劫户、劫官库部分已进入战役裁决卡，此处只保留机构化反应。原文定位：`P0238`。

## 三、跨卷连续性

- **灾害—财政—盗乱的链条进一步成形。** 卷208已经出现多地“人相食”、国用不足、黄河连续决口；卷209继续见河东饥死、彰德与胶州人相食、河决五年不塞、户口消耗。与此同时，户部已经直接写出水旱、盗贼与“兵费不给”的关系。到至正十年更钞后物价十倍、货币失灵，“国用由是大乏”，财政问题进入更严重阶段。
- **漕运安全从治安问题升级为国家供给风险。** P0007仅四十骑即可劫三百商船而无人能捕；P0092沿江盗舰往来、万数官军败于三十六花山劫贼；P0165方国珍又直接劫掠漕运、击溃官军舟师。卷209因此不能把“盗起”一律视作普通地方治安，而需区分已经伤及国家运输体系的实际武装阶段。
- **湖广—广西猺乱继续否定此前所有“平定=结构性终结”的解释。** 本卷吴天保连续攻陷黔阳、武冈、溆浦、辰溪、靖州、辰州，并以六万众掠全州；即使若干次被“击走”或元军“献捷”，威胁仍迅速复发。沿用卷208既有 `campaign_group` 作为稳定主键，不因年份后移另起一条虚假战争链。
- **方国珍成为新的重点跨卷战争父链。** 至正八年已由私人盐海活动转成数千人海上武装，能劫漕、擒海道千户、击溃官军并俘省级主帅；朝廷授官求和后他并不赴命。至正十年又明确“复叛，寇温州”，证明第一次招降没有形成持续安全收益。后卷应优先核其陆上治所、州县控制及割据政权真正成形的阶段。
- **沃济野人、死可伐、西番等线仍有未闭合事项。** 沃济线本卷新增元军统帅遇害，但后续多次遣将仍无终局；死可伐仅见“献捷”，没有全部收地和本人结局；西番二百余所武装陷哈剌火州后也未见收复。上述均已写入 JSON `cross_volume_followups`，不提前倒灌后效。
