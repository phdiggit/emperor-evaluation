# 史料通读产物与通读卡

本目录保存可由多个评分项共同消费的史料通读总结和卡片定位索引。它是证据事实层，不属于任何单一评分项；各评分项负责自己的准入、归责、去重、档位和计分。

当前评分依据：

- [`唐以前编年/README.md`](唐以前编年/README.md)：《资治通鉴》秦至唐260卷通读总结卷表；
- [`唐以前编年/00-战争卡审计索引.md`](唐以前编年/00-战争卡审计索引.md)：`WAR-*`卡号到卷文件和标题行的人工审计入口；
- [`唐以前编年/00-战争卡审计索引.json`](唐以前编年/00-战争卡审计索引.json)：同一索引的机器读取入口。
- [`五代十国/资治通鉴/`](五代十国/资治通鉴/)：《资治通鉴》卷263—294的32份非战役通读总结与32份战役裁决；两类文件按卷一一配对并共享 `source_unit_id`、`revision_ref` 和 `raw_sha256`，作为五代十国后续评分的新证据入口。

原 `唐以后编年/**` 批次未达到第二项、第三项结算证据要求，已经整体退役并从当前工作树删除；其事件 JSON、registry、Markdown 阅读视图、manifest 和审计展开均不得作为正式结算依据或重新进入 Git。新五代十国入口只消费上述64份重新验收的总结与裁决，不继承旧批次状态。

通读产物可被多个评分项共同引用，但不同评分项不得重复加总同一事实。创业统一、财政民生、军事边疆、文明整合和历史负债仍分别依照各自规则消费。
