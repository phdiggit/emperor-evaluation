## 二、政治秩序、外交与人口变化

### 1. 晋辽一度尝试修复关系但议和条件无法接受

- 后晋在辽军撤北后遣使通辽；桑维翰又主张卑辞谢罪，张晖向辽称臣谢罪。辽方要求交出景延广、桑维翰并割镇州、定州，后晋无法接受，战争遂继续。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0006`“晉遣使如遼”；`P0008`“景延廣、桑維翰來，割鎮、定兩州，則可和。晉不能從”。

### 2. 孙方简由后晋方面转投辽

- 孙方简“叛晋归辽”。本段没有起兵、据城或接战过程，故不单独进入战争成本账。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0011`“孫方簡叛晉歸遼”。

### 3. 晋帝欲亲征但被劝止

- 杜威军危急时，后晋帝想亲征救援，被李彦韬、李守贞等认为会动摇京师而劝止。实际没有形成这一轮亲征，故只保留为决策事实。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0020`“晉帝欲自將兵救之……乃止”。

### 4. 大梁失守后的政治处刑与清算

- 张彦泽入大梁后拘捕桑维翰，最终将其缢杀并诬报自经；这属于占领后的政治杀害，不计作破城战斗伤亡。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0031`“遂殺維翰，以帛加頸，令左右登屋，以白帝，云自經死”。
- 景延广被辽军捕送北方途中自杀。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0033`“景延廣……自殺死”。
- 辽帝进入大梁后处死杨承勋；随后又将张彦泽处死，市人争食其肉。均属战后司法/政治清算。原文定位：`SRC-QIDANGUOZHI-003-2258704-P0035`、`P0036`。

## 三、跨卷连续性

1. 卷002末启动的 `QGZ-LIAO-JIN-WAR-945-NEXT-OFFENSIVE` 在本卷经历邢洺磁深入、榆林店、祁州、阳城白团村等阶段并北撤；卷003后半又进入 `QGZ-LIAO-JIN-WAR-946-947-FINAL`，最终造成杜威大军投降和后晋覆亡。
2. 辽取得大梁及后晋多数藩镇后，本卷已经出现相州、澶州反抗和严重占领暴力，因此“灭晋”与“稳定统治中原”必须分开。卷004如出现辽军撤出、州县复汉或占领体系崩解，应只在卷004新阶段反转 `BCP/BCN`。
3. 太宗在卷末北归病死，永康王兀欲继立。卷004应优先核述律太后是否接受继位、是否发生武装继承冲突，以及这种内争是否影响辽的中原控制。
4. 后晋降帝一家已被迁往辽境，后续生活、人口损失和处置属于政治/人口连续线，除非发生实际武装事件，否则不进入战争成本账。
