## 一、财政、民生、工程与灾害

- **本卷没有独立于战争和约之外的新税制、赈济、灾害或民用工程事实。** 澶渊每年绢二十万匹、银十万两，以及庆历关南交涉再增绢十万匹、银十万两，都是战争结束或军事威慑形成的持续财政结果，已经完整进入 JSON，避免在非战役总结重复。
- **熙宁七年的边界争议涉及边境铺舍、戍垒与居民空间，但本卷没有可独立确认的民生损失数字。** 辽方要求撤去越界设施，宋方答应复核；最终另有“宋割弃地五百里”的结果，但人口迁徙、税源或生产后效均未载。原文定位：`SRC-QIDANGUOZHI-020-2258648-P0019—P0023`。

## 二、政治秩序、外交与人口变化

- **熙宁七年宋辽以专使和国书处理代北边界争端，最终形成一次无战事的实质划界调整。** 道宗遣萧禧赴宋，称代北对境有侵地，请双方遣使分画；其后原文明载“宋割弃地五百里，以分水岭为界”。由于本卷没有军队攻取或武装强夺，按外交领土调整而非战役处理。原文定位：`P0019`。
- **辽在咸雍十年国书中提出蔚、应、朔三州边境的铺舍、戍垒和居舍越界问题，要求共同检照并拆除。** 这是辽方的边界主张与外交交涉事实，不能把单方指控直接转写为战争损害。原文定位：`P0020—P0021`。
- **宋方答书接受联合复核的原则，但没有无条件承认全部辽方说法。** 宋称若边界状况“事由夙昔”则难从辽请；若确有侵越，则可以改正，并再次要求边吏遵守历来誓约。原文定位：`P0022—P0023`。
- **本卷文书显示宋辽长期关系高度制度化。** 澶渊与关南誓书均把边界、逃人、耕作、城池、塘淀、兵马增屯和交割地点写入固定文本；这些条款的战争安全与财政效果已在 JSON 计账，这里不重复裁决。

## 三、跨卷非战役连续性

- **熙宁七年划界属于此前宋辽长期盟约框架下的新一轮外交边界调整。** 本卷只确认萧禧交涉、宋方实际割弃地五百里并以分水岭为界；人口迁徙、税源变化和地方治理后效均未载，后续只能在出现新证据时补充。
- **蔚、应、朔边界争议当前停留在国书与联合复核层面。** 辽方的侵界指控和宋方的条件性答复都不能在缺乏实地核验材料时直接当成事实损害。
