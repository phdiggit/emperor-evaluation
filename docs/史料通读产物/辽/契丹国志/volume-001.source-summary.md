## 一、财政、民生、工程与灾害

### 1. 韩延徽安置汉人、建城市里与垦荒

- 唐末藩镇混战造成燕地军民持续流入契丹。韩延徽入契丹后，教其“建牙开府”，并筑城郭、立市里安置汉人，使汉人各有配偶，又组织垦艺荒田；原文明言此后“汉人各安生业，逃亡者益少”。这是一条较清楚的移民定居—生产恢复—减少逃亡链。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0004`“筑城郭，立市里以处汉人，使各有配偶，垦艺荒田。由是汉人各安生业，逃亡者益少”。

### 2. 渝关旧防务的田租、军衣与清野制度

- 渝关至进牛口一线旧置八防御军，募土兵守险；当地田租直接供军食，又每年输送缯纩供军衣。防务上配合早收与清野，契丹兵来则坚壁不战，退时再据险邀击。此段反映边地农业税收、军粮与衣料供应被纳入常设边防体系；后来周德威不修边备，旧制度失效的军事后果另入战役裁决卡。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0008`“募土兵守之，田租皆供军食，岁致缯纩以供衣。每岁早获，清野以待”。

### 3. 文字、寺院、四楼与上京空间建设

- 平渤海后，契丹制作文字“三千余言”；在大部落置天雄寺，在木叶山、大部落东、北及部落内部设南楼、东楼、北楼、西楼，西楼后来成为上京。城与宫殿正门皆向东，皇帝四季游猎往来四楼之间。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0027`“乃製契丹文字三千餘言……大部落之內置樓，謂之西樓，今上京是”。

### 4. 天象记录

- 天赞元年六月朔日食。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0012`“夏六月朔，日食”。
- 天赞三年十月朔日食，并见彗星“出舆鬼，长丈余”。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0016`“冬十月朔，日食。彗星見，出輿鬼，長丈餘”。
- 天赞五年四月朔日食。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0021`“夏四月朔，日食”。
- 太祖死后八月朔又记日食。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0030`“八月朔，日食”。

## 二、政治秩序、外交与人口变化

### 1. 太祖出身、部落声望与称帝建国

- 阿保机之父斡里任夷离巾；原文形容阿保机成年后勇武善射、为部落畏服。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0001`“父斡里，為夷離巾……部落憚其雄勇，莫不畏而服之”。
- 神册元年，阿保机自称皇帝，以述律氏为皇后，置百官、建元神册，国号契丹。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0003`“置百官，建元曰神冊，國號契丹”。

### 2. 对梁、晋的交聘与大额礼物交换

- 太祖时期契丹与后梁互遣使臣通好；又与晋王李存勗面会，约为兄弟并约共同攻梁。李存勗赠金缯数万，阿保机回赠马三千匹及杂畜万计；归国后又转而与梁修好。其间的军事行动另见战役账。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0002`“梁遣太府少卿高頎、軍將郎公遠報聘……晉王贈以金繒數萬。太祖留馬三千匹、雜畜萬計以酬之。太祖既歸國，更通好于梁”。

### 3. 韩延徽的政治任用

- 韩延徽一度逃归晋地，因在晋幕府不安，又借省母返回契丹；太祖反而更加厚待，最终任为相，累迁中书令、平章事。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0004`“遂復入契丹，太祖待之益厚。至是以為相，累官遷中書令、平章事”。

### 4. 新州失政、卢文进投契丹

- 威塞军节度使李存矩在新州“骄惰不治”，边人嗟怨，后被小校宫彦璋谋杀；其裨将卢文进率部投契丹。卢文进随后引契丹军攻新州的实际战事另入裁决卡。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0005`“驕惰不治，邊人嗟怨，為小校宮彥璋謀殺。其裨將盧文進，帥其衆奔契丹”。

### 5. 撒剌阿泼谋乱败露与出奔

- 神册三年，太祖弟撒剌阿泼谋乱，事觉后被囚，一年后释放；其后率众奔晋，晋王厚遇，收为假子并任刺史。原文未记该阴谋阶段发生实际交战，故不入战争成本账。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0009`“謀亂。事覺……乃囚之，期年而釋之。撒剌阿潑帥其衆奔晉”。

### 6. 后唐建国规模与后梁终结

- 天赞三年，李存勗在魏州称帝，国号唐；魏州为东京、太原为西京、镇州为北都，当时有十三节度、五十州。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0015`“時唐國所有，凡十三節度、五十州”。
- 同年十月，梁主均王自杀。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0017`“是月，梁主均王自殺死”。

### 7. 庄宗死后的契丹—后唐交涉

- 后唐遣姚坤赴契丹告哀。太祖一面哀悼庄宗并批评其“专好声色游畋，不恤军民”，称自己闻讯后停酒、遣伶人、放鹰犬；另一方面向新唐廷索求黄河以北，后降为镇、定、幽州。姚坤拒绝代写割地状后被囚，因韩延徽劝谏免死。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0023`“若與我大河之北，吾不復南侵矣……得鎮、定、幽州亦可也……用韓延徽之諫，乃復囚之”。

### 8. 太祖死、陵寝设置与述律后清洗

- 太祖在夫余城去世。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0028`“太祖於夫餘城崩”。
- 述律后以“往见先帝”为名杀诸酋长；其后又反复杀身边“桀黠者”于墓所，原文称前后被杀“以百数”。赵思温以“亲近莫如后”反诘得免，述律后则断自己一腕置墓中。此属继承期政治清洗与仪式性暴力，未形成军队交战，不进入战役账。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0029`“果思之，宜往見之。遂殺之”；`SRC-QIDANGUOZHI-001-2258555-P0032`“前後所殺者以百數……乃斷其一腕，令置墓中”。
- 九月葬太祖于木叶山，在墓侧置祖州，谥大圣皇帝、庙号太祖。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0031`“置州墳側，名曰祖州……廟號太祖”。
- 同月述律后中子德光即位。原文定位：`SRC-QIDANGUOZHI-001-2258555-P0033`“述律后中子德光立”。

## 三、跨卷连续性

1. 卷001末德光即位，卷002将继续展开述律后主导的继承安排、东丹王突欲与新帝之间的关系；本卷只记到即位，不倒灌卷002后续。
2. 渤海灭亡、东丹国设置及夫余城控制属于本卷战役成果，连续性移交 `volume-001.battle-adjudications.json`；卷002需核东丹王突欲出奔后，东丹控制与辽东治理是否受实质影响。
3. 卢文进据平州、奚骑岁入卢龙形成的长期边患亦移交战役 JSON；卷002开篇卢文进率众归唐将构成该战线的重要后续核验点。
4. 天赞四年攻幽州、蔚州在本卷只见出兵而无战果，后卷如出现控制、撤军或安全后效，应沿用对应 `campaign_group` 继续核验。
