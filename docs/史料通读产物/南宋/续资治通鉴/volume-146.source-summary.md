## 一、财政、民生、工程与灾害

### 1. 农民赋役、追呼与基层摊派

- 朝臣集中列举州县“五害农”：农忙时追逮农民；乡村一事牵连近邻数十人并可拘留旬月；修桥、造馆舍及官员经过时强驱农民充工役丁夫；富户欠税而官吏“舍强就弱”，把欠额均摊给租户；巡尉、催科胥吏下乡侵扰，甚至“鸡犬为空”。朝廷下诏要求州县不得妨农务。原文定位：`P0021`；短引：“此其害農一也……此其害農五也。”
- 明令禁止州县以“预借”填补当年财政缺口。奏疏指出名为借次年税赋，实际“终无还期”，前官预借后官又不肯承认，形成滚动加征。原文定位：`P0037`；短引：“一年稅賦支遣不足，而又預借于明年……終無還期。”
- 丁税执行同时存在除籍与输纳两类弊端：老病、年满六十者长期不销籍，新增壮丁反被乡司隐匿取利；六丁税本可合输一匹绢，却被强作单名独钞，附加头子、勘合、市例等费用，且已纳者不及时销簿而被重复追呼。朝廷准许重整丁籍并要求缴足即销簿。原文定位：`P0038`；短引：“久年系籍與疾病之丁，無時銷落”“重疊追呼。”
- 四川夏秋税绢折科长期按旧额高估。胡元质称承平时每缣约二贯，兵兴后每缣至十贯；虽已裁为七贯五百，但此前减额只落实成都一路，其余州县仍旧。朝廷要求四川总领、转运司核实各州军继续裁减。原文定位：`P0048`；短引：“當承平時，每縑不過二貫，兵興以來，每縑乃至十貫。”
- 绍兴府原准备支四十万贯供御前激赏，孝宗改令以此钱替人户代纳当年和买、身丁之半，是把一笔御前支用直接转为减轻民户负担。原文定位：`P0052`。
- 两税征收中又出现把本色强折钱并抬高折价的问题。孝宗指出谷、丝虽丰收，耕夫蚕妇“卖钱不足以偿其劳”，禁止地方把本应输本色的税强迫高价折钱，并命刻石遍示监司、帅守、郡守。原文定位：`P0079`；短引：“終歲勤動，賣錢不足以償其勞”“毋以重價強之折錢。”
- 浙、闽推排物力甚至把耕牛、租牛计入家业，朝廷重申一律免计。孝宗明确说“国以农为本，农以牛为命”，要求监司查处借此科扰者。原文定位：`P0100`。
- 南康军有人请把沿江鱼池设为放生池，孝宗以沿江居民赖捕鱼为生而拒绝，直接以民生作为限制政策的理由。原文定位：`P0106`；短引：“沿江之民，以魚為生，今禁之，恐妨民也。”
- 临安府请复置西溪栏税，孝宗以“关市讥而不征”、距城五十里外不应再置栏税为由否决。原文定位：`P0109`。
- 广西盐政曾改行钞法，转运司所得仅二分，不能给各州岁计，继而以高折秋苗等方式转嫁缺口。恢复官搬官卖后，朝廷要求长期遵守，并明确停止折米招籴等“为民害者”。原文定位：`P0110`。

### 2. 四川茶、盐、军费与纸币：本卷财政民生主线

- 胡元质称四川“为蜀民之病者，惟茶、盐、酒三事为最”。茶自熙宁后由通商转官榷，原课息岁四十余万；建炎军兴后改卖引，“比之熙宁已增五倍”。后又出现无茶园仍被强承茶额、茶少额多、按月追息等现象，茶园百姓“愈更穷困”。朝廷命茶马司、总领司与制置司重新措置，拟停无茶户额、减茶少额多户。原文定位：`P0026`。
- 盐课问题比茶更重。大井深六七十丈，需数十人牵绳汲卤；井老泉枯、井筒崩坏、洪水淡化、柴本不足乃至借贷煎盐时，旧额仍不能自动蠲减，导致“官课未偿，私债已重”。胡元质提出按各井实际盈亏重新分等增减。原文定位：`P0027`。
- 简州此前减盐额五万四千余缗，却按井平均削减，结果富户一户可减数千缗，下户一二十井仍无人承额、继续虚欠受催。胡元质要求再分配已减额度，并限制上户单户减免不超过二千贯，使减负真正下沉。原文定位：`P0028`。
- 湖广总领周嗣武概括四川军费结构：“自屯兵蜀口，五十年間，竭全蜀之力，僅足供給軍食。”他同时指出蜀中钱引由天圣每界约一百二十五万道，增至现行两界合四千五百余万道，另有钱银会子折合六十三万道；若继续增印，价格下落风险极大。孝宗决定不再增印，并留八百万道在蜀备急。原文定位：`P0070`。
- 阶、成、西和、凤州及长举县营田连续三年收入仅四万九千余缗，支出却达一百七万缗，财政投入约为收入二十余倍。吴挺请把田地召民耕佃、军兵抽回教阅，获准。原文定位：`P0073`；短引：“所得才四萬九千餘緡，而所費乃百七萬緡。”
- 夔路被明确称为“民最贫”，仍承担科买上供金、银、绢三色。胡元质、韩㬇利用大宁监盐课增羡，先代购金银以尽免九州岁买，再免当年买绢，并把余钱作为以后贴助；孝宗肯定“实惠及民”。原文定位：`P0120`。
- 另有直接减负：蠲夔州上供金银（`P0117`）；此前绍兴年间四川折科裁减继续向各州推开（`P0048`）。

### 3. 货币、仓储与财政制度

- 会子定为一千万缗一界，并准两界相会行，显示纸币发行额被设置界限而旧新两界并行。原文定位：`P0049`。
- 孝宗下令诸路州县新创场务一律罢除，抑制地方通过新增征榷机构扩张收入。原文定位：`P0061`。
- 镇江、建康置转般仓，用于东南粮运中转。原文定位：`P0076`。
- 内侍省向库务取物恢复双合同凭由：一份交传宣使臣，一份密封送库务核验，支供后合同缴奏，旨在防止内廷口传取索侵蚀库务。原文定位：`P0116`。
- 金朝对亏课院务官的处罚引出制度反思，金主直言“法敝则当更张”，并考虑采用唐、宋可行之法调整辽制承荫者主榷沽的旧规。原文定位：`P0134`。

### 4. 水利、农业基础设施、灾害与赈济

- 浙东此前新建湖浦塘埭斗门二十处，增修开浚溪浦埂堰六十三处，奏称可灌民田二十四万九千二百六十六亩；朝廷要求提举官核实。原文定位：`P0023`。
- 金朝免中都、河北、河东、山东、河南、陕西此前受灾租税。原文定位：`P0032`。
- 淮东高邮、宝应田长期水涝。旧有长堤二百余里、涵洞一百八十所、石堰斗门三十六座，战乱后“尽皆废坏”，湖水漫流。建议在农隙由官给米募夫，重修堤、堰、闸门并常态巡察。原文定位：`P0072`。
- 金赈西南、西北两路饥（`P0075`）；宋赈淮东饥（`P0115`）；金又免去年水旱民田租税（`P0132`）。
- 广西置义仓，强化地方灾荒储备。原文定位：`P0137`。
- 镇江以石修湖闸、浚海鲜河，兼顾船舶停泊和水路交通，孝宗称“惠利甚厚”。原文定位：`P0138`。
- 高邮、通、泰等州因田鼠灾获赈；金又赈西南路招讨司所部民。原文定位：`P0144`、`P0145`。

### 5. 金朝北幸成本：和平状态下的军民负担

- 梁襄谏阻金主金莲川—松林巡幸，系统列出成本：供养物资远途飞挽、费用数倍；车骑拥塞造成牛马逸失、奴仆逃亡、蹂躏；贫困官兵露宿、饥寒染病；战马暴雨受损、军士疲瘵、衣甲弓刀湿坏；秋归时人疲马弱、粮空衣敝，仍继续远猎。原文甚至称病死“何异刃杀”。金主最终采纳，罢北幸。原文定位：`P0148—P0151`。
- 此段提供罕见的和平时期帝王巡幸对财政、转运、牲畜、军队健康和基层劳役的复合成本材料，但未进入实际战争阶段，故不计战役成本轴。

## 二、政治秩序、外交与人口变化

- 宋军管理继续收紧：军中逃亡、事故付身依有无家累分别批凿或焚毁；升差、拣汰离军人员须赴枢密院审察，旨在压低主帅私相升黜。原文定位：`P0014—P0016`。
- 金主要求各路将“差科之烦细”上报，明确以避免重敛困民为政策目标。原文定位：`P0018`。
- 金朝把史官纳入屏人议事，理由是天子言动应有史官记录并形成约束；仅在机密问题上要求择慎密者。原文定位：`P0031`。
- 宋廷整顿请托与关节。曾植称省部理诉、仓库出纳、刑狱、州县争讼“无一不用关节”，朝廷接受从近处执行公法的建议。原文定位：`P0062`。
- 王友直因募兵扰民被连续降官，随后军民喧哄者被送大理寺；孝宗又坚持按军法处置，史浩以“民不可律以军法”反对而未获采纳。这里反映募兵对地方秩序的直接扰动及军法外推争议；无原文证据显示发生武装接战，故不列战役。原文定位：`P0092`、`P0096`。
- 陈俊卿连续批评曾觌、王抃、甘昪结党招权、纳赂和用“中批”绕过有司法令；又指出数百里外直接使用无印白劄处理军国机密、钱物、调军和边防，存在伪造与误事风险。孝宗对其奏议予以奖谢。原文定位：`P0088—P0089`。
- 金主反对因宗室身份放宽郡守任用，明确说“一境休戚”取决于守臣才干；又批评宰臣受曹王请托恢复有罪官员。原文定位：`P0095`、`P0102`。
- 孝宗要求监司、郡守任用“不可轻授”，并重申戚里未经铨试不得破法添差。原文定位：`P0105`、`P0119`。
- 钱良臣等因保举贪官茹驤受连坐降官，茹驤本人因侵盗官钱被编管、籍家；显示保举责任被实质追究。原文定位：`P0123—P0125`。
- 《淳熙条法事类》开始按事类汇编现行敕、令、格、式，孝宗明确目标是“开卷则尽见之”，减少胥吏舞文欺官。原文定位：`P0128`。
- 广西义仓、四川雄边军增设以及关外四州增募忠勇军都属于制度性边防与社会组织变化，本卷未见这些建制自身形成独立武装接战。原文定位：`P0082`、`P0101`、`P0137`。

## 三、跨卷连续性

- 向前：卷145已经显示四川免和籴一年后麦熟倍常、民力稍舒；卷146进一步揭示茶、盐、折科、军粮和钱引的长期结构性压力，构成同一条“蜀中军费—财政—民力”连续链。
- 向后：陈峒之乱在本卷 `P0153` 已以“斩峒等，郴州平”收束。卷147 `P0006` 的王佐、冯湛升赏属于战后奖叙，不重复产生战果、WC、SB、WR或BCP。
- 向后：四川钱引被明确禁止继续增印，茶盐与折科减额方案仍处于执行阶段；卷147继续出现四川盐课蠲免、货币和军费问题，应追踪政策是否真正下沉至民户。
- 向后：威州蛮在本卷仅见“寇边，讨降之”，后效窗口很短；若后卷同一部族或同一复叛结构再犯，应据后续事实复核本卷 `SB2` 的持续性，而不把未来结果倒灌进本卷。
