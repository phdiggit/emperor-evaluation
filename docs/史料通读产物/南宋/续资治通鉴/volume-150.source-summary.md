## 一、财政、民生、工程与灾害

### 1. 养兵、冗官与财政结构

- 殿中侍御史陈贾指出军费中“额外将佐”开支异常：殿前司额外自统制至准备将一百二十员，步军司又十八员；两司除本俸外，供给茶汤“犹不下一千万缗”。朝廷接受停止继续差置、甄别沙汰冗员的建议。这里是本卷最强的军费结构性证据之一。原文定位：`P0018`“供給茶湯猶不下一千萬緡”“額外重費，又復如此”。
- 淮东总领吴琚奏镇江诸军被激赏铺、军须子铺拖欠布帛钱，要求一并除放，使官兵能够取得完整俸给赡家；孝宗称军政“刻削”自杨存中以来即有此弊，并要求其他类似侵刻、营运钱也归还。原文定位：`P0049`。
- 卷后又清查淮东、淮西、湖广总所及沿江、襄阳、江陵大军库金银钱会，并规定非朝旨不得擅支，属于对军费存量的集中核账与封桩。原文定位：`P0111`、`P0119`。
- 盛雄飞因不亲临教阅且添置回易营运被降官，说明军队内部经营、营运仍被视为军纪与财政问题。原文定位：`P0103`。
- 省冗采取“自然减员、不再补额”的渐进办法：百司冗吏、冗兵暂不突然裁撤，待离职、事故后不再补；卷末敕令所裁减吏额同样采取“依旧存留、将来不作额”。原文定位：`P0086`、`P0161`。
- 临安府一次罢逐额外胥吏百余人，另有未经根括、姓名不在册者约二百余人；朝廷由此要求县级也按绍兴旧额清理冗吏。原文定位：`P0132`。
- 金亦把亲军裁定为二千人，并要求和平时期持续训练，以免“一旦有警，兵不可用”。原文定位：`P0082`、`P0158`。这属于兵制与训练，不是本卷实际战役。

### 2. 广西、汀州盐法与丁税：基层负担仍很集中

- 邕州虽已改行钞法，仍保留江左永平、太平二寨以物帛博买交趾私盐并夹卖官盐的旧制，溪洞居民也随之贩交盐；经略司最后主张保留博易场，只严禁私贩侵夺官课。原文定位：`P0006`。
- 广西“民最贫”，沿海诸郡却把身丁钱变成巧取之资：该销落的老疾丁口长期不销，钱额加收、米额加耗，一丁又拆出钞纸钱、息本钱、公库糜费等附加。原文明确记民众为避丁税而改作女户、迁徙异乡、舍农为工匠、泛海经商，已经改变户籍、居住与职业选择。朝廷命恢复收附销落旧制并按劾科扰。原文定位：`P0023`；短引：“或改作女戶，或徙居異鄉，或舍農而為工匠，或泛海而逐商販。”
- 二广盐务是否合并一司，朝廷顾虑广西漕司一旦退出盐务便失去通融钱物、地方财政可能“支吾不行”，因此没有草率定案。原文定位：`P0063`。
- 淮、浙盐场亭户纳盐时，朝廷要求官府即时称量、立即支付本钱，并禁止花带钱、上户兜请折除等掊克，允许亭户越诉。原文定位：`P0136`。
- 汀州六县分食福盐、漳盐，旧有科盐造成州县困乏。新方案蠲旧欠、减盐价，并由主管机关自行补足缺口；奏称六县每年可“减于民者三万九千缗有奇”，官课约减一万余缗而由其他办法补足。原文定位：`P0162`。这是本卷最明确的盐政减负数字。
- 安吉县夏税绢长期要求细丝织造，造成民困；此前虽恢复屑织粗丝，产绢仍用细丝，本卷最终允许产绢亦依旧用粗丝。原文定位：`P0030`。

### 3. 差役、税场、版帐与地方财政

- 差役制度暴露土地兼并与隐寄问题：豪贵把田产隐寄狭户，一乡真正承担上户差役者所剩无几；贫民下户为避役甚至“弃鬻”田产、不敢蓄有顷亩。孝宗提出不分官户民户，一律按等第轮差，交户部、给舍、台谏详议。原文定位：`P0066`。
- 荆门军浰河、武宁、黄泥税场因豪民买扑扰民被罢；继而常德府、复州以及江都、泰兴、山阳、天长、高邮税场也被罢。孝宗称这类“有益于民之事”若每日做一件，全年即多。原文定位：`P0055`、`P0059`。
- 两浙版帐钱额被认为与江西月桩一样沉重，州郡和属县都受困；朝廷准许转运使与郡守斟酌削减，并愿由户部适当补助，以求“苏民力”。原文定位：`P0060`。
- 监司巡阅本身也形成地方负担：随行吏卒诛求，一县往往要花数百缗应办，否则可能被“捃摭生事”；朝廷要求吏卒由各州分段交替供应，以减骚扰。原文定位：`P0062`。
- 内藏库催和州、无为军、常德府欠分钱时，揭出和州曾用三千缗贿内侍求免五千缗的请托，相关守臣被展磨勘并继续限期足额上纳。原文定位：`P0056`。
- 前知绵州史祁把本州现钱冒称“羡余”献总领所求荐，被降官放罢；反映地方为求政绩、荐举而挪移本地财赋的逆向激励。原文定位：`P0080`。
- 隆兴府把百姓旧欠税苗以自身节余承担，不亏公家而直接蠲民欠，获准并出榜；孝宗把这归因于守臣“不妄用”使财赋有余。原文定位：`P0085`。
- 简州新任官丁逢指出财赋窠名繁多、养兵费重、民力有限，而州县吏借名色侵移重困民力；孝宗要求他到任后践行所言。原文定位：`P0098`。
- 江陵高陂河渡官课被全部废除，改由附近居民自备舟船渡载，以防豪民垄断并减少民众受迫胁、阻滞。原文定位：`P0100`。
- 江西安抚司请求把上供米折钱，孝宗拒绝，强调“本是纳米，今教纳钱”会改变原有实物财政性质。原文定位：`P0147`。

### 4. 蠲免、债务与灾后恢复

- 吉州太和、吉水、庐陵三县因旱伤严重，现欠夏税全部蠲放。原文定位：`P0016`。
- 会稽所借官米、兰溪所借常平钱购买稻种均获蠲免。原文定位：`P0070—P0071`。
- 两淮及沿边州军归正人请占官田后原有差税免除期满，本卷又延免三年。原文定位：`P0083`。
- 金在会宁府免当年租税，并给七十岁以上百姓补官。原文定位：`P0027`。
- 咸平自“斡罕乱”后二十余年民业仍未完全恢复，金主任完颜守道归乡任咸平尹时明确以“安辑一境”为目的。原文定位：`P0125`。这是长期战争/叛乱后社会恢复迟缓的后效材料，不重新登记旧战役成本。
- 利州路饥，朝廷赈济。原文定位：`P0167`。

### 5. 粮储、纸币与价格

- 孝宗区分赈籴与军粮封桩：赈籴可以逐年循环备荒，而封桩米必须留在要害屯军处，使“军民皆有其备”。原文定位：`P0043`。
- 太平州、采石镇此前因民间艰食缺乏储备，本卷趁淮上秋成，预拨会子在采石仓和籴。原文定位：`P0054`。
- 封桩库会子又分别拨淮东、淮西、湖广总领所及浙西，用于当年和籴、封桩米本钱。原文定位：`P0064—P0065`。
- 舒、蕲二州铁钱监各定年铸二十万贯。原文定位：`P0107`。
- 诸路州县开始以现钱、会子各半交收。孝宗称军民反而愿要会子，认为纸币信用已改善，但同时重申“会子不可更增见在之数”。原文定位：`P0135`。
- 金主驻上京超过一年，右丞相指出仓储日少、市场采购渐贵，禁卫及局署人员大量逃亡；说明长期巡幸已经直接抬高粮食与行政维持成本。金主采纳意见。原文定位：`P0025`。

### 6. 水利、河患、工程与农业

- 明州东钱湖灌田五十余万亩；茭葑淤积后形成三百余亩佃田，朝廷担心继续围垦会妨蓄水，命把葑地重新开湖。原文定位：`P0007`。
- 金主出猎见田垄不治即笞种田者，反映强制性农业督课。原文定位：`P0044`。
- 襄阳木渠屯田二麦“下种不少、收获甚薄”，孝宗要求查明原因，并统一各屯田麦、稻收成上报时限。原文定位：`P0079`。
- 宕昌马场远蕃入中马多蹄黄、怯瘦，若直接排拨容易死亡，故在西和州置丰草监、良马监休养。原文定位：`P0095`。
- 卢沟前次显通寨决口曾发中都三百里内民夫堵塞，本卷再次决口后，议者认为继续施工恐“枉费工物”，最终停止治理。原文定位：`P0129`。这里同时有既往大范围民夫动员和本轮止损。
- 河决卫州并毁城，金廷决定把卫州迁至胙城县；户部侍郎王寂赴灾区却不救灾、专事网鱼取官物，引发民怨并被贬，另派刘玮接办。原文定位：`P0141`。
- 新筑江陵城完成。原文定位：`P0143`。属防御工程，不是实际战役。
- 金主晚年自省“颇喜兴土木之工”，宣布今后不再营作。原文定位：`P0160`。
- 金方又因河水泛滥、被灾民“资产皆空”，反对在邻水区域继续推排资产，认为受惊扰迁避者也不可能仍有余产。原文定位：`P0165`。

### 7. 市场、劳役与宫廷消费

- 金有司购买物资不能及时付价，金主责罚监察官未举劾，说明官府采购拖欠民价已进入问责。原文定位：`P0102`。
- 金主称御膳即便每日用五十羊也不难，但“皆民之脂膏”，坚持简省；属于君主节用的明确自述。原文定位：`P0123`。
- 金廷为给皇帝供应新鲜荔枝，在道路特别设置铺递；经谏官指出后立即停止，金主承认此前不知此事。原文定位：`P0163`。
- 宋廷讨论恢复景祐时期服饰、器用、车舆等奢侈禁令，以“用度有制，民力自宽”为目标。原文定位：`P0094`。本卷只见讨论和下礼部核议，不当作已全面执行结果。

## 二、政治秩序、外交与人口变化

### 1. 决策机制与监督

- 孝宗明确强调监司、郡守选人不应只看资序，不足任者宁可降用；显示他把地方治理质量归结为监司、守令选任。原文定位：`P0014`。
- 杨万里在地震求言中批评“临御久，事皆上决，宰执唯奉旨而行，臣下多恐惧顾望”，徐谊也以“人主日圣，则人臣日愚”进谏；孝宗没有采用徐谊意见。原文定位：`P0037—P0039`。这是本卷关于高度个人化决策的强负面旁证。
- 吏部选官中“法”与“例”相互冲突，朝廷要求条法明确者依律施行，不得以已有惯例废法。原文定位：`P0051`。
- 孝宗多次主张少下繁碎指挥、只抓“大者要者”，认为政令过多会导致玩渎、不再可信；卷末再次以“择人才、正纪纲、明赏罚”为要务。原文定位：`P0154—P0155`。
- 对慢于考察郡守的浙东帅臣、提举分别降官；知州差注也要求长贰共同衡量人材并先保明。原文定位：`P0052`、`P0077`。
- 金主也多次要求宰臣荐举人才，批评只拘资级；对亲军、宗室涉赃则表示即使子弟亦不宽贷。原文定位：`P0120`、`P0133`、`P0140`。

### 2. 金朝储位与继承秩序

- 金太子允恭六月去世。侍卫军士、百姓大量哀悼，枢密使图克坦克宁严整宫卫并保护皇孙，防止储位空虚时出现宫禁失序。原文定位：`P0045—P0048`。
- 克宁随后力请立金源郡王玛达格，认为拖延会“起觊觎之心、来谗佞之言”，金主先让玛达格判大兴尹、进封原王，至次年十一月正式立为皇太孙。原文定位：`P0096`、`P0127`、`P0152`、`P0156`。
- 这一继承安排属于政治秩序，不进入战争成本账；本卷没有因储位问题形成武装政变。

### 3. 边防情报与外交风险判断

- 边谍曾报西辽假道西夏伐金，孝宗密令吴挺、留正议策；周必大劝持重，后证实情报完全虚妄。原文定位：`P0029`。因此不能把它记录成金、西辽或西夏实际战争。
- 杨万里在金宋使节一度中断、金主北归背景下长疏警告两淮、荆襄、四川边防，并主张不要弃淮守江；这是战略意见而非已经发生的战争行动。原文定位：`P0032—P0036`。
- 宜州王侃因“尽心边备，蛮猺知畏”获升官再任，但没有本卷具体袭击、接战或控制变化，故仍属于边防治理成效，不另立战役。原文定位：`P0148`。

### 4. 官吏约束与基层秩序

- 福建地震后，朝廷要求帅臣赵汝愚察守令、择兵官并预防盗贼；这是灾后治安部署，未见具体盗乱。原文定位：`P0040`。
- 建康秋教中胡斌醉后无礼、德安巡检张革慢弃职守辱骂守臣，均被降官放罢，体现军政纪律问责。原文定位：`P0068—P0069`。
- 文思院制造中皇城司亲从官借监作身份脅持、索取“常例”，朝廷撤销该差遣。原文定位：`P0087`。
- 金主认为年老护卫字尚不能书却授临民官会害百姓，要求用人以实际能力而非恩荫。原文定位：`P0084`。
- 金左相等因擅增东京皇孙食料被削阶，地方官员和亲近集团亦未完全免于财政纪律。原文定位：`P0099`。
- 大理寺岁末再次奏狱空。原文定位：`P0166`。

## 三、跨卷连续性

- **卷149蒙光渐线**：本卷没有蒙光渐余部或明确同一安化蛮结构再犯。`P0148`仅称宜州王侃“蛮猺知畏”，不能无锚点关联地归入蒙光渐战役群，也不足以把卷149 `SB2`上调。
- **卷149“小路蛮击虚恨”**：本卷没有补出胜负、伤亡、宋军介入或控制结果，该低信息战役卡继续保持 `UNKNOWN` 后效。
- **卷149温台海贼候选**：本卷没有补出温州、台州捕海贼首领的实际接战过程，仍不转正；同时不能与卷148姜太獠事件机械合并。
- **青羌安静砦线**：本卷已经明确“据安静砦—侵汉地几百里—擒努儿结—尽俘其党—青羌平”，本卷内可以闭合主要实际阶段；后卷仅用于验证同一青羌结构是否复发，不把未来沉默提前换成更高安全收益。
- **呼喇台线**：金方已经出兵讨伐，但两名统帅“不待见敌而还”，本轮军事行动无战果。卷151若再见呼喇台或同一集团窥边，应用同一 `campaign_group` 承接。
