## 一、财政、民生、工程与灾害

### 1. 战争后财政与地方民力：从“田里疾苦”到军费追偿

- 鄂州危机暂解后，牟子才仍直陈“田里疾苦”，提醒朝廷不能把前线暂退视为天下已安；这说明战争退潮并未自动消除基层负担。原文定位：`P0027`。
- 蒙古张文谦在大旱背景下反对因新朝经费需求继续满征，主张先安百姓，最终蠲常赋十分之四、商酒税十分之一。原文定位：`P0040`“民困日久，况当大旱”“蠲常赋十之四，商酒税十之一”。
- 蒙古中统初年征需仍很重。李昶指出按丁巳旧籍征税，比现实在户甚至“加多十七八”，又让现户包补逃亡、死亡户欠额，会造成严重困难；随后省府蠲免逋户之赋。原文定位：`P0066`。
- 景定二年蒙古又减免民间差发；秦蜀行省曾向民间借钱供军，改以当年税赋偿还，表明军费一度直接以民间垫资方式筹集。原文定位：`P0076`。
- 史天泽整顿占役户：蒙古宪宗初括户百余万，到本卷时其中“大半”被各类势力占役，遂下令悉罢。其意义在于把被权势私占的人户重新纳入常规民政、税役体系。原文定位：`P0089`。
- 严忠济任东平时曾借贷替部民缴逋赋；离任后债主持券索偿，蒙古主以国库代偿。原文定位：`P0091`。
- 贾似道在宋方推行“打算法”，把军兴时将帅支取官物追作侵盗、隐匿，赵葵、史岩之、杜庶等被罢官征偿；向士璧被逮责偿，妻妾也被拘追，最终死于此案。原文定位：`P0114`。
- 马光祖又以赵葵上元张灯宴设钱三万缗为“放散官物”上报；汪立信反对以战时勤劳将帅作清算对象。谢枋得因募民兵守御、钱粟会计，自己偿万缗以免累赵葵。原文定位：`P0115—P0116`。
- 景定三年，朝廷赐贾似道宅第、家庙，直接给缗钱一百万，属于非常显著的中央财政赏赐。原文定位：`P0152`。
- 李璮被围后，宋廷实际给银五万两赴益都犒军，并遣青阳梦炎率师救援；梦炎到山东后“不敢进而还”。此项银支已发生，但没有接战，故只作为军事财政与无效动员底账，不进入单场战役A轴。原文定位：`P0179`。

### 2. 货币、税收与市场制度

- 蒙古开始行中统宝钞：以交钞、丝钞和中统元宝建立折价关系，宝钞不限年月诸路通行，赋税允许收钞，并同时加强私盐、酒醋、面货等禁令；另拟文绫银货但未行即罢。原文定位：`P0059—P0060`。
- 在颍州、涟水、光化军设互市，说明货币制度与边境贸易同时调整。原文定位：`P0060`。
- 蒙古罢平阳安邑岁贡葡萄酒，属于削减地方固定贡输。原文定位：`P0095`。
- 蒙古统一颁行斗斛衡量，属于市场、赋税与行政计量标准化。原文定位：`P0123`。

### 3. 赈济、灾害与粮食

- 扬州发生大火。原文定位：`P0020`。
- 蒙古以常平仓赈益都、济南、滨、棣饥民。原文定位：`P0063`。
- 宋境霖雨、水患持续：景定二年六月因霖雨避殿减膳，近畿水灾尤以安吉为甚，朝廷要求急行荒政；九月湖州、秀州再有水灾，命守令劝分、监司严行荒政。原文定位：`P0090`、`P0092`、`P0125`。
- 景定三年临安饥。马光祖强请荣王与芮开仓，掌握其仓储实数后迫其出米“三十万”，分给饥民，原文称“活饥民其众”。原文定位：`P0159`。
- 同期杨文仲又称天目洪水、苏湖兵变，且军中“兵疲赤籍挂虚之冗”，把水灾、军队疲敝和虚额兵籍并列为国家承压问题。原文定位：`P0160`。
- 蒙古真定、顺天、邢州发生蝗灾。原文定位：`P0177`。

### 4. 劳役、农业、水利与生产恢复

- 蒙古中书省一度命诸路饲养禁卫羸马数万，并预备草料器具；徐世隆判断此举不会实际发生，拒绝提前骚扰地方，后来马果不至，避免了一次数万匹军马的无效前置负担。原文定位：`P0057`。
- 蒙古罢金、银、铜、铁、丹粉、锡、碌等坑冶所役民夫，以及河南舞阳姜户、藤花户，归还州县；又放出工局绣女，听其婚嫁。原文定位：`P0100`。
- 怀孟广济渠开成，灌田四百六十余所。原文定位：`P0101`。
- 蒙古设置巡行劝农使，随后又要求地方官开垦田土、种桑枣，不得擅兴不急之务妨夺农时。原文定位：`P0121`、`P0170`。

## 二、政治秩序、外交与人口变化

### 1. 鄂州撤军后的政治包装与宋廷权力集中

- 贾似道隐瞒议和、纳币过程，以杀获俘卒、殿兵包装成“诸路大捷、江汉肃清”，理宗据此授以“再造”之功并厚赏。原文定位：`P0010`、`P0024`。
- 吴潜因迁幸建议、立储意见及与贾似道矛盾被罢，后不断远谪；贾似道入相后又借台谏清洗丁大全、吴潜相关人员，权力“倾中外”。原文定位：`P0021—P0026`、`P0058`、`P0062`、`P0082`。
- 王坚、高达、曹世雄、向士璧等前线有功将领先后受到贾似道打压、清算或外放，形成严重的战后军政逆向激励。原文定位：`P0025`、`P0114`、`P0117`。
- 吴潜最终在循州暴卒；本卷记载贾似道欲杀潜、刘宗申下毒的传闻性叙事，后贾似道又贬刘宗申以塞外议。原文定位：`P0181—P0182`。

### 2. 忽必烈即位与蒙古中央制度成形

- 忽必烈在开平即位；其后以中书省总政务、枢密院掌兵、御史台司黜陟，内外监寺行省、宣慰等官制逐步定型，旧臣、遗逸被录用，史文明言“一代之制始备”。原文定位：`P0014—P0015`、`P0018`、`P0029`。
- 阿里不哥随后在和林自称帝，六盘等地响应，构成蒙古内部汗位战争的政治起点；具体战斗已分流战役卡。原文定位：`P0030`。
- 蒙古建元“中统”，并先后设十路宣抚司、左右部、军储都转运使司、翰林国史院等机构。原文定位：`P0037`、`P0039`、`P0080`、`P0104—P0105`。
- 史天泽入相后定省规、清占役；景定三年蒙古又始定中外官俸。原文定位：`P0087—P0089`、`P0155`。

### 3. 军民关系与被俘人口处置

- 郝经出使时概括南北长期战争后果为“弱者被俘略，壮者死原野，兵连祸结久矣”，是本卷直接反映战争人口成本的重要总述。原文定位：`P0019`。
- 蒙古命宣撫司劝农桑、问民疾苦、礼高年，同时考察官吏汙滥；这些是新政权整合基层的制度动作。原文定位：`P0084`。
- 淮、蜀士人因战争被俘后多没为奴，高智耀请赎儒士为民，实际检出数千人。原文定位：`P0083`。
- 蒙古多次约束军队与使臣扰民：先命都元帅所过不得擅掠官吏，后又要求军马、使臣不得入州城、村居、镇市侵扰良民。原文定位：`P0052`、`P0168`。

### 4. 高丽、宋蒙使节与停战失败

- 廉希宪建议送高丽世子归国继位，蒙古赦其境内；高丽因憲宗时期“兵日见加，国大困”，新王遂请求附贡并迁都出岛就陆。原文定位：`P0016`、`P0068`。
- 蒙古派郝经来宋通报忽必烈即位并追问此前和议。贾似道因担心隐瞒议和曝光，以李璮为借口让李庭芝将郝经拘在真州；理宗虽知北使到来，仍未解决。原文定位：`P0048`、`P0085`、`P0128`。
- 蒙古在景定二年以郝经久留、边境侵扰为由发布南伐诏，显示此前停战窗口正式恶化；本段仅为动员命令，不当作已发生战役。原文定位：`P0112`。

### 5. 皇储与行政监察

- 理宗立忠王禥为皇太子，并以严格日课、参决政事、讲经史方式训练储君。原文定位：`P0042`。
- 宋廷要求监司、守臣定期举劾赃吏，并按举劾多少赏罚；同时申饬官员尽言。原文定位：`P0070`、`P0148`。
- 皇太子妃最终册全氏；其父全昭孙殁于王事，全氏曾称“淮、湖百姓尤可念”，被理宗作为择后的德行理由。原文定位：`P0132`、`P0146`。

## 三、跨卷连续性

- 向前：卷175鄂州、潭州撤围与蒙古继承危机相连。本卷P0005、P0011只记录北撤后新发生的尾击，不回填卷175；贾似道反而把和议、撤军包装为纯军事大捷。
- 本卷闭合：刘整献泸州后，俞兴反攻失败，但景定三年刘整率部赴蒙古时吕文德又恢复泸州；这一控制收益已在本卷内部逆转。
- 向后：李璮于卷末起兵，益都、淄州及涟海三城发生大范围控制变化，随后在济南遭长期合围；卷177必须继续核验济南终局、三齐归属及宋方所得三城能否保持。
- 向后：阿里不哥在实默图诺尔大败北遁，但尚未正式投降；卷177需核汗位内战是否结构性终结。
