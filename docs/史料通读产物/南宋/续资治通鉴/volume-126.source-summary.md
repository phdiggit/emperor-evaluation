## 二、战争、边防与安全相关的非战役事实

- 宋金使节往来已经制度化：正旦、报谢、贺生辰等逐年成例；金正旦使向宋赠金酒器六事、绫罗纱縠三百段、马六匹。原文定位：`P0065`、`P0070`、`P0074—P0077`、`P0105`、`P0115—P0119`、`P0168—P0169`。
- 金主把“去年宋币”赏赐宗室，说明和议财货已转化为金廷内部可分配资源。原文定位：`P0075`“金主以去年宋幣賜宗室”。
- 韩世忠以两国讲和为由，请停发自己按宰执标准领取的俸赐，并愿把背嵬使臣三十员、官兵七十人交朝廷使用；朝廷只准使臣交割。原文定位：`P0078`。
- 川口仍屯兵十万，吴璘、杨政、郭浩分别驻兴州、兴元、金州；利州改分东西两路。和议虽“方坚”，吴璘仍日以敌至为虞，原文称“西路兵为天下最”。原文定位：`P0143—P0145`。
- 金六月“初置骁毅军”；宋年底把殿前马步诸军冬月阅试定为“内教场”。原文定位：`P0037`、`P0158`。
- 濠州新守李观民赴任时，高宗明确告诫不得招集流亡，以免金方认为挑衅而启衅。原文定位：`P0127`。

## 三、财政、民生、工程与灾害事实

- **韩世忠补缴历年未输税。** 他请求把私产及皇帝所赐田产历年未输之税一并核缴官府，朝廷准许；其进封郡王与此直接相连。原文定位：`P0004`、`P0013`。
- **景灵宫形成固定财政消耗。** 利用刘光世赐第筑三殿，常置僧、道十人、吏卒二百七十六人；上元搭灯楼、帘幕岁一易，全年酌献用羊二百四十只，帝后忌辰另用僧道四十七人作法事。原文定位：`P0017`。
- **圜丘与大礼规模很大。** 圜丘四成、十三陛七十二级；冬至合祀从祀神七百七十一、祭器九千二百零五、卤簿一万二千二百二十人。因行在条件有限，部分铜玉器改用陶木、文绣改用纈，也未另建斋宫。原文定位：`P0022`、`P0064`。
- **南方养马被当作节支办法。** 高宗称实行二三年已得驹数百，比从川、广买马可少病马和沿路费用。原文定位：`P0030`。
- **财务簿书审计加强。** 周执羔要求监司巡按检查财用出入簿书，无簿书押署的支出按不职追责。原文定位：`P0036`。
- **军衣发放存在中间侵蚀。** 经手使臣常以弊朽之帛换走良缣，军士最终只拿到怯薄衣料；朝廷改由户部封记，并令总领所、本军共同领取。原文定位：`P0133`。
- **江浙福建发生本卷最严重灾害。** 同日大水，建州水入城、深数丈，“公私廬舍盡壞”，溺死数千；衢、信、处、婺也“民之死者甚众”。高宗要求监司亲赴、赈济不得为文具。原文定位：`P0122—P0123`。
- **严州救灾形成鲜明对比。** 洪水几乎没城，通判洪光祖集舟救人、把百姓转移山阜并供薪粥，最终“卒无溺者”。原文定位：`P0123`。
- **金有多项直接救济。** 巡幸熏风殿附近及所过沿线复民一年；又设借贷饥民酬赏格。河朔地震后免民一年、官为敛葬压死者；蒲、解、汝、蔡等郡县饥民质卖为奴婢者，由官给绢赎为良民并放归乡里。原文定位：`P0147`、`P0151`、`P0154`。
- **宋恢复漏泽园。** 临安及诸郡重新设置收瘗无主贫民尸骨的设施。原文定位：`P0162`。

## 四、政治秩序、外交与人口变动旁录

- 岳飞旧宅改国子监、太学，先设十二斋；高闶重新规定经义、诗赋、子史论、时务策三场教学与地方学校入太学资格。国子监又置博士、正、录，绍兴十四年定宗学生百人。原文定位：`P0008`、`P0016`、`P0032`、`P0094`。
- 洪皓、张邵、朱弁获准南归；原文称渡江后奉使金国者近三十人，“生還者三人而已”。张邵、朱弁又集中报告陈过庭、司马朴等死节者，司马朴后来获追赠与银帛三百匹两。原文定位：`P0038—P0050`、`P0059`。
- 王伦被拘六年后拒绝接受金方河间、平、滦三路都转运使之职，称自己奉使而来并非投降，最终被缢杀；临死南向再拜恸哭。原文定位：`P0079—P0080`。这是政治处刑，不进入战役成本。
- 洪皓反对无条件把赵彬等三十人家属交金，主张以钦宗及宗室归还为条件，又提及秦桧在完颜昌军中旧事，随即触怒秦桧而外放。原文定位：`P0053—P0055`。
- 万俟禼因拒绝替秦桧借金人口吻奏事、又不肯在秦桧私批“上旨”任官文件上签名，遭弹劾而去。原文定位：`P0092—P0093`。
- 解潜、辛永宗因反和议或被指“倡为异说”远调；高闶因高宗问及张九成，被秦桧疑为荐人，也遭弹劾外放。原文定位：`P0100`、`P0111—P0113`。
- 白锷因称洪皓名闻中外而不用、批评朝政，被刺面配万安军；张伯麟因题太学壁讥讽秦桧而杖脊刺配。洪皓又受连坐处分。原文定位：`P0124—P0126`。
- 赵鼎继续被指为“诛首”，从潮州再移吉阳军安置。原文定位：`P0148`。
- 年末原文直接总结秦桧用人：每荐执政，多选“世無名譽、柔佞易制”者，不使预事；百官不敢谒执政、州县不敢通书问，罢后还常被置千里外并受伺察。原文定位：`P0163—P0165`。
- 金颁《皇统新律》千余条，多仿南朝；金主又为希尹平反并录其孙，但绍兴十四年亲杀魏王道济。原文定位：`P0071—P0072`、`P0138`。
- 完颜亮出任中京留守后“专务立威以压伏小民”，并与萧裕深相结，已出现后续夺权的重要政治前兆。原文定位：`P0172—P0173`。

## 五、跨卷连续性

- **金蒙战争进入新父链。** 本卷蒙古与胜花都郎君旧部相连并取二十余团寨，金方不能制；具体成本、控制和收益见战役JSON。卷127须继续核金军长期征讨、失地与议和结果。
- **卷125丰山寨链未闭合。** 卷126没有丰山寨恢复、盗众受抚或讨平材料。
- **卷125邵隆越界劫掠链未闭合。** 本卷没有新的越界行动或金方反击锚点；后卷人物死亡不能倒填战争结果。
- **宋金新边界总体保持。** 本卷没有唐邓、商秦等地重新争夺，并明确限制濠州招集流亡以免启衅。
- **川口高驻军成本继续向后承接。** 十万兵仍分三帅驻屯，吴璘持续严备；后卷若见裁军、财政压缩或再战，应沿同一驻防链记录。
- **秦桧专政继续强化。** 本卷末已出现对执政、台谏、州县交通的系统性控制，卷127继续观察其政治与财政后效。
