## 一、财政、民生、工程与灾害

- **广惠仓由户绝田租课建立，并在本卷内制度化为冬春常态救济。** 嘉祐二年八月，韩琦请停止出卖诸路户绝田，改募民承佃，以夏秋租课救济城中老幼贫乏不能自存者；各路提刑专领，岁终向三司报收支。嘉祐四年二月又改隶司农寺，各州专官管理，每年十月核定受助名单，自十一月至次年二月，成人日给米一升、幼者半升，每三日发一次，有余再按县大小均给。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0008`“以夏秋所輸之課給在城老幼貧乏不能自存者”；`P0120`“自次月一日給米一升，幼者半升”。

- **河北大水后赈粮继续，且出现对粮食品种和运输时效的纠偏。** 朝廷原拟从太仓拨粳米六十万斛赈河北，薛向认为北人不便食粳、漕路又远，主张改用本司米四十万石。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0021`“民乏食”“請出本司米四十萬石以代之”。

- **京畿灾情持续：河决、连年旱与雨雪饥寒先后出现。** 嘉祐三年七月广济河溢、原武县河决，朝廷遣官查看民田并赈恤；八月又称京师比岁旱、屡蠲民租，并拨十万缗助籴军储。嘉祐四年正月则追记自上年雨雪不止，“民飢寒死道路甚眾”，朝廷分遣官员在京赈恤，并依欧阳修请罢上元放灯。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0070`、`P0077`、`P0115`。

- **东南盐课名义规模大而运输不足，朝廷另设专司整顿。** 三司称商旅在榷货务入现钱算东南盐，岁课四百万缗，但诸路般运不足而课入日亏，遂置江、淮南、荆湖制置司专管运盐。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0018`“歲課四百萬緡，諸路般運不足而課益虧”。

- **盐政同时出现局部减负与边区通商。** 范祥复任制置解盐；河北坊郭客户“干食盐钱”被免；李师中在广南主张通盐商、恢复邕州和市场以充实边地，多获施行。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0072`、`P0084`、`P0088`。

- **茶禁旧制的民生与财政副作用被完整揭出。** 原文称茶禁尤其腊茶最严，告捕有赏，但“約束愈密而冒禁愈蕃”，岁报刑辟不可胜数；园户被征取和官吏侵扰，出现破产、逃匿，而官茶陈积、县官获利无几。何鬲、王嘉麟、沈立等因此主张弛禁通商。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0083`“以至破產、逃匿者，歲比有之”“官茶所在陳積，縣官獲利無幾”。

- **弛茶禁后并非完全取消税负，而是改为固定租钱。** 六路调查均称弛禁便利；三司原拟按旧息钱把六十八万余缗均赋茶户，因较旧制负担“出幾倍”而被朝廷减半，定为岁输三十三万八千余缗租钱；除腊茶外其余茶可自由交易，租钱与诸路本钱储作边籴。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0119`“凡為緡錢六十八萬有奇”“為損其半”“歲輸緡錢三十三萬八千有奇”。

- **省减冗费、停止民间科率和不急营造进入制度化办理。** 韩绛、陈旭、吕景初与三司详定省减冗费；张昪此前请罢民间科率及不急营造，场库缺物改由官钱收市，三司遂置省减司，原文称“自是多所裁損”；嘉祐四年三月又命韩绛、陈旭、唐介与三司继续减定民间科率。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0091`、`P0092`、`P0125`。

- **宗室礼制工程也有直接停建。** 睦亲宅祖宗神御殿停止修建，源于欧阳修此前建议。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0051`“罷修睦親宅祖宗神御殿”。

- **漕运制度长期集中化造成舟卒终身服役、吏胥受赂和籍册空名。** 旧制下江湖粮纲到转般仓后舟卒可返乡轮休，汴舟冬涸也可“放冻”；发运使权重后六路粮纲集中，文移繁杂，吏胥受赂分配航线，江、汴舟混转，出现“挽舟卒有終身不還其家、老死河路者，籍多空名”。本卷再严令江淮、两浙一年内造船补卒，规定自嘉祐五年起汴纲不得再出江。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0098`。

- **广南灵渠工程显著改善水运能力。** 兴安灵渠十八里内原有三十六斗门，单舟载量不过百斛；李师中募工焚石凿渠，废斗门二十六，三旬完工，“舟楫以通”。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0085`。

- **财政统计开始按三年总会天下岁赋盈亏。** 三司每年仍上岁赋数，但以后每三年汇总一次亏赢奏报。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0100`。

- **驿传成本与规则开始统一编订。** 依韩琦建议，三司编天下《驿券则例》；至嘉祐四年张方平上三卷，赐名《嘉祐驿令》。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0048`、`P0116`。

- **内藏继续直接支援军粮。** 十月出内藏库紬绢十万，下河东转运司助籴军储；此前京师旱年又拨十万缗给本路助籴。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0087`、`P0077`。

- **王安石万言书把“财力日困”归因于法度与人才体系失灵。** 其称“天下之財力日以困窮，而風俗日以衰壞”，又主张“因天下之力以生天下之財，取天下之財以供天下之費”，同时把人才教、养、取、任视作制度问题。此为政策主张，不等同于统计事实，但可作为当时财政与治理危机的 contemporaneous 观察。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0090`。

## 二、政治秩序、外交与人口变化

- **编敕累积已出现明显冲突。** 韩琦指出庆历四年以来十五年续降编敕四千三百余件，“前後多抵牾”，遂命富弼、曾公亮等删定。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0005`。

- **内降请托虽被正式纳入二府控制，但执行仍反复失效。** 陈旭因内降营求恩赏者甚多，请二府推劾干请人；十二月正式立“内降关白二府法”。然而欧阳修权知开封不到两月仍承受内降十次，府中再三奏报仍不能止，又请追究幕后干求人。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0009`、`P0028`、`P0074`。

- **仁宗储位继续长期悬空。** 欧阳修因兖国公主出嫁后深宫亲近者减少，请从宗室选材贤者录为皇子；吴及、范镇、包拯又先后要求选宗室子备储副、早定大计，包拯直问“東宮虛位”何以久不决。至本卷末仍未正式立嗣。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0010`、`P0040`、`P0046`、`P0061`。

- **内臣军政权与收养制度受到收紧。** 各路内臣任钤辖、都监者限制为一员；吴及又请恢复开宝旧制，限制内侍收养嗣子。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0012`、`P0040`。

- **科举改为间岁，解额减半并强化品行保任。** 进士、诸科以后间岁贡举，解额减半，另置明经、罢说书；寓户应举限制更严，县州逐级察行义并承担保任责任，省试文辞纰缪还追究原考官。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0026`。

- **科举增频后又主动降低高第者晋升速度。** 因高第人数倍增，朝廷重定制科、进士不同等第的初授与后续升迁路径；原文直接评价“驟顯者鮮”，但所得人才及风迹“比舊亦寢衰”。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0107`。

- **馆职荐举与考课也趋向制度化。** 大臣所举馆职先由中书登记，待员额少后再择文行众推者考试；吴及又请恢复三司判官御前印纸历子考绩，岁终按功过升黜。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0029`、`P0052`。

- **文彦博退相、韩琦入相，贾昌朝因女谒与宦官关系失势。** 郭申锡、张伯玉攻击文彦博虽经查不实，文彦博仍屡请退而罢相；韩琦入相。谏官又集中攻击贾昌朝交通女谒、以姑事温成皇后乳母贾氏及纵宦官矫制，贾昌朝遂罢。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0054`、`P0056`—`P0058`。

- **包拯提出提高诏令稳定性。** 他称近年制敕刚下不久即更改，民众会因此认为命令不足信，请重大政策先经两制集议、能经久者再颁行；关于宗室教育、监司属官荐举等建议亦多被施行。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0061`。

- **地方司法仍有长官阻挠复核的案例。** 应天府误入平民死罪，通判孙世宁辨正；刘沆却包庇责任吏员并阻止提刑韩宗彦调查，韩宗彦上疏后责任吏最终依法治罪。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0110`。

- **福州教育与社会风俗治理同步推进。** 蔡襄荐周希孟教授经术，亲临学舍讲问并礼遇陈烈等；又禁止丧葬崇佛奢侈至破家，严断巫觋主病、蛊毒杀人，原文称“閩俗以變”。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0067`。

- **馆阁藏书管理暴露内臣监库后的亡失问题。** 吴及称馆阁书籍被借出后亡失已多、简编脱略、书吏补写不精；朝廷置专官分馆编定，禁止私借，访求遗书，并以黄纸印写元本防蠹。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0121`、`P0122`。

- **僧尼度弟子政策再次放宽。** 旧制百僧岁度一人，一度放宽后复旧；本卷又以中旨改为五十僧度一人，并取消京师寺院收徒的乡贯保任要求，僧徒大喜。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0130`。

- **辽对地方官经商、内藏盗窃与死刑覆审均作制度调整。** 辽禁职官在本部假贷贸易；内藏库官盗两贯以上准奴婢告发；死刑即使狱具仍须别州县复案，称冤者具奏。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0027`、`P0041`、`P0068`。

- **辽钦哀太皇太后死后，原文集中追述其干预司法的负面后果。** 家奴诬告主人、官员强掠女子等案都因其干预而轻处，并称兴宗末“政刑廢弛，亦多由欽哀使然”。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0030`。

- **辽宗室内部已出现未发动的叛逆隐患。** 皇太叔重元妻因受皇后训戒而煽动重元反抗，其子尼噜古“素有異志”；本卷未形成实际武装行动，只作政治安全旁证。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0106`。

- **宋辽、高丽与交趾外交仍频繁。** 辽请求仁宗御容，宋答应由贺正使衣箧中交付；辽太后去世后遣使告丧，仁宗发哀停朝七日；高丽向辽进贡。交趾进献所谓“麒麟”，杜植辨为山犀，建议回诏只称“异兽”，既不受欺又不伤怀远之意。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0015`、`P0025`、`P0039`、`P0065`。

- **日食与长期雨雪继续触发礼制和政治问责。** 刘敞先反对提前十余日避殿减膳，真正日食后又反对祭社不合古礼；吴及则借日食批评近幸、将帅与地方治理。原文定位：`SRC-XUZIZHITONGJIAN-057-2299550-P0108`、`P0113`—`P0114`。

## 三、跨卷连续性

- **向前：** 卷056遗留的边事在本卷出现受降、责任追究等后续，但实际武装阶段及其成本收益统一承接在本卷战役 JSON；本总结只保留庞籍、司马光等问责事实。
- **向后：** 茶法已经从严禁转为除腊茶外通商征租，但新租钱、商税和边籴效果尚未经过后卷检验；广惠仓已形成冬春固定给粮制度，也需继续观察执行。
- **向后：** 仁宗储位仍未正式确定；包拯已掌三司，韩琦居相位，省减冗费、民间科率、漕运与财政统计改革均处于持续执行期。
- **向后：** 河北义勇本卷只确定就地训练、岁阅籍数、临警再统驭的方案；尚未进入实际战斗，不进战争账。卷末另有未闭合的南边武装事项，其后续只在战役 JSON 中续核。
