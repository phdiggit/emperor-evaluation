## 一、财政、民生、工程与灾害

- 澶州战后，河北诸州因辽军蹂践获明确善后：河北死罪以下赦免，受蹂践民户给复二年，阵亡官吏追录子孙；真宗阅报又见“诸州多被蹂践，通利军伤残尤甚”而下罪己诏。原文定位：`P0035`“民經遼師蹂踐者，給復二年”；`P0050`“諸州多被蹂踐，通利軍傷殘尤甚”。
- 两河已有民众陷于辽境，王旦曾建议出金帛数十万赎回，但因有人反对而停止；陈贯后来又称被驱掠“良民数十万”，主张趁和议初成以内府金帛赎人，卷内未见实施结果。原文定位：`P0038`、`P0079`。
- 回銮遇严寒，真宗赐道路贫民襦袴。原文定位：`P0039`“大寒，賜道傍貧民襦袴”。
- 景德二年正月，河北诸州强壮被解除战时身份、放归农业，官府另购耕牛发给，属于战争后直接恢复生产的措施。原文定位：`P0056`“放河北諸州強壯歸農，令有司市耕牛給之”。
- 和议后大规模复员：罢诸路行营，北面部署、钤辖、都监、使臣裁去二百九十余员；河东又省百余使臣，河北诸州戍兵减半、缘边减三分之一。原文定位：`P0057`、`P0061`、`P0066`。
- 朝廷并未因停战完全撤防。真宗亲择河北重要州军守臣，又令修葺敌楼战栅、河北城池；禁军人数已“逾倍”，原拟汰老疾，但担心军士把裁兵理解为“去兵惜费”，因此先由下军选勇者补上军，再待秋冬裁汰。原文定位：`P0059`、`P0082`、`P0090`、`P0108`。
- 河北聚兵造成长期军粮压力，朝廷恢复“入粟实边授官”：民间向河北边地进粮可按等授官，且扩至陕西。真宗担忧滥爵，宰相以旧制可循力主施行。原文定位：`P0070`“河北諸州聚兵，糧饋勞費”“定入粟實邊授官等級”。
- 宋辽和后边贸恢复。辽在振武军复置榷场，以羸老羊、皮毛换南方绢；赵延祚建议宋在榷场稍优待辽方下层，使其从互市获利以巩固和好。原文定位：`P0071`、`P0081`。
- 国子监印书裁纸余料原可出售补监中杂费；邢昺请求把这笔钱归三司后，“学者公费不给，讲官亦厌其寥落”，显示集中财政收入反而直接压缩教育机构日常经费。原文定位：`P0094`。
- 诏天下榷利机构不得把额外“羡余”固定为新的征收额，明确限制以临时增收制造永久税额。原文定位：`P0105`“天下榷利者，弗許增羨為額”。
- 曹玮提出西北弓箭手制度：边民应募者给境内闲田并永免其租；二顷出甲士一人，三顷另出战马一匹，并设堡戍、列部伍、置巡检统辖。此制随后扩至鄜延、环庆、泾原及河东州军，兼具军役、土地与税收安排。原文定位：`P0097`。
- 《景德农田敕》五卷雕印颁行，原文称“民间咸以为便”。原文定位：`P0119`。
- 澶渊约定的岁币在本卷开始实际制度化：绢二十万匹、银十万两，十一月前后已“赍至辽界”，并记“自是岁以为常”。这是长期固定财政支出，而非一次性礼物。原文定位：`P0027`、`P0122`。
- 朝廷开始规定致仕官给半俸，改变唐制及宋初“非特敕则不给俸”的常态。原文定位：`P0129`。
- 雷有终生前多用私财犒军，曾借库钱数百万，死后尚负百余万，最终由官府代偿；张凝同样把赏赐多用于犒师、家无余资。两段可见高级武臣私人财力与公家军费之间的混用。原文定位：`P0095`、`P0096`。

## 二、政治秩序、外交与人口变化

- 和议后设置国信司，由宦者领，宋辽往来由战时使节逐步转成专门机构管理。原文定位：`P0068`。
- 真宗虽与辽通好，仍要求边州继续侦察辽情；以后捕获辽间谍不再处死，而是羁留内地，必要时作为对等交涉筹码，以避免宋方先坏和约之名。原文定位：`P0074`。
- 宋辽使节礼仪迅速制度化。孙仅使辽时，从州县迎谒、父老献酒到辽主亲来幽州宴接均有完整程序；宋方何承矩又条上辽使入境的接伴、驻留和待遇原则，获准未尽事宜便宜裁处。原文定位：`P0072`、`P0106`。
- 辽使来贺承天节时，馆伴李宗谔按令式要求解佩刀；真宗认为戎人佩刀是常礼，不必强禁，辽使因而感悦。原文定位：`P0125`。
- 岁币之外，宋每年派遣辽主生辰、辽太后正旦、辽主正旦使，宋辽关系转入常态化礼聘。原文定位：`P0121`。
- 赵德明九月首次遣白文寿来宋进贡，显示西北关系也从李继迁时期长期冲突转入新的入贡阶段；本卷尚未出现后续正式盟誓。原文定位：`P0116`。
- 河北贡举人因战争耽误常规考试，朝廷另设礼部贡院别试并由真宗亲试，属于战争对教育机会造成延误后的补偿措施。原文定位：`P0102`。
- 景德二年春亲试，得进士二百四十六、特奏名一百十一，诸科五百七十、特奏名七十五；真宗批评糊名复核后考官为避嫌而“过抑等第”，并强调李迪文最优。原文定位：`P0075`。
- 李迪与贾边均因礼部未取而特覆核；王旦认为李迪落韵属疏失，贾边舍注疏自立异论会使士子无所准，最终取李迪而黜贾边。原文定位：`P0076`。
- 十四岁晏殊、十二岁姜盖被特召试。寇准欲因晏殊为江左人而抑之，真宗答“四海一家，惟才是求”；晏殊又主动说明赋题曾私习，改题仍佳，遂获进身并在秘阁读书。原文定位：`P0103`。
- 朝廷恢复贤良方正直言极谏、博通坟典、才识体用以及武足安边、军谋、将帅等多类制科，允许文武群臣与草泽隐逸应试。原文定位：`P0111`。
- 诏官吏能“雪活人命”者一并计劳绩，把平反冤狱直接纳入官员考绩正向指标。原文定位：`P0104`。
- 曹州赵谏、赵谔不法案中，真宗起初欲追查与其交游七十余人；御史中丞吕文仲以大规模逮捕将动人听、实际也未必尽诛为由，建议先籍其名、遇事再治，真宗采纳。原文定位：`P0107`。
- 刘师道、陈尧咨因科举作弊受责：陈尧咨为弟刘几道密作卷面识号，案发后几道落籍并永不许赴举，刘师道与陈尧咨均被贬。原文定位：`P0086`、`P0087`。
- 王钦若与寇准不协，自天雄归后求罢参政；朝廷新置资政殿学士安置王钦若，后又创“资政殿大学士”以提高其班次，原文同时直言王钦若“善迎人主意”。原文定位：`P0091`、`P0127`。
- 西川将吏民众请求留知益州张咏，朝廷褒奖，并借巡抚使传谕“得卿在彼，朕无西顾忧”。原文定位：`P0113`。
- 辽以金帛赐阵亡将士家属；高丽、准布又因宋辽和议成功遣使向辽称贺，反映和议对辽周边外交关系的外溢影响。原文定位：`P0101`。
- 辽党项、女真、回鹘、达旦等部族与国家继续来往贡聘；这些非战斗外交行为均未直接制造新的控制变化。原文定位：`P0085`、`P0109`、`P0110`、`P0112`。
- 毕士安卒后获高规格追赠，原文称其“未尝殖产为子孙计”；吕蒙正则归洛养老并劝真宗“惟愿以百姓为念”。两段分别保留宰相廉俭与息民政治观。原文定位：`P0073`、`P0120`。

## 三、跨卷连续性

- 向前：卷024末辽军大举南侵、宋廷决定亲征并已发生多处河北战斗；卷025从景德元年十一月继续这一战争。实际战斗、城寨得失和停战撤军均在本卷战役 JSON 承接，本文只保留战后减免、复农、裁军、岁币和机构化往来。
- 向后：至卷末，宋辽岁币与互使已常态化，河北军政进入“减员但不弛备”的状态；赵德明刚正式入贡，真正誓约、册封与贸易条件仍待卷026。财政方面，入粟实边、榷利禁增额、弓箭手给田免租和《景德农田敕》已经形成制度节点，后续效果需继续观察。
