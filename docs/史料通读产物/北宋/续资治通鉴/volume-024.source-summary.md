## 一、财政、民生、工程与灾害

- 盐铁、度支、户部三司的“句院”再度合并为一，由陈尧咨兼判，属于三司内部勾稽机构的继续整合。原文定位：`P0003`。
- 朝廷对战争受害家庭和农田发放直接实物补偿：环庆秋田被寇践伤者，每顷给粟十五斛；民众有人被掠者，每口给米一斛。同时棣州民租减免十分之三。原文定位：`P0009`。
- 九月，朝廷“出内府缯帛市谷实边”，以皇室内府绢帛购买粮食补充边储。原文定位：`P0013`。
- 秋季募近京“强壮”补入禁卫，并由高琼训练阵势。真宗观看后称“昨日村民，皆为精锐矣”。该条是实际征募和训练制度，不属于某一单场战役。原文定位：`P0016`。
- 静戎军已在军城东新河之北开掘纵横相距约五尺、深七尺的“方田”，以连锁沟壕限制骑兵。宰相建议顺安、威虏仿行，并提出施工时可选兵五万人分据险要防敌；朝廷最终下诏三地均置方田、凿河遏骑。五万人只是防施工遇袭的建议，不按已实际投入结算。原文定位：`P0018`。
- 宋军建立“传信牌”：以可合契的漆木牌分持，传令时署写内容、由军吏携带，抵达后合契、署名并覆命，以减少战场口令失真和奸诈冒令。原文定位：`P0020`。
- 王继忠在辽任职后劝辽太后议和，其财政民生理由非常直接：宋辽每年敌对，使辽“每岁赋车籍马，国内骚然，未见其利”，不如恢复旧盟、休兵解甲、息民。原文定位：`P0024`。
- 明德皇太后不豫时大赦，死罪降一等、流以下释放，并“除五年逋租”。原文定位：`P0032`。
- 真宗亲自审阅逋负名籍，释放因欠负被系者四千一百零六人，蠲赋八万三千；有人担心蠲放过多、三司会以亏国计为由反对，真宗明确说“非理害民之事，朝廷决不可行”，要求百姓真正得到减免。原文定位：`P0033`。
- 真宗随后把边防与赋役负担直接联系起来：河北、关西“戍兵未息，民甚劳苦”，而三司、转运使“赋敛益繁”，要求宰辅把民弊列为条目，大者减省、小者蠲免。又废除重罪犯家属一并赴阙的做法，指出家属因此弃置资产、流离道路，今后只送本人。原文定位：`P0035`。
- 辽罢三京诸道贡。原文定位：`P0034`。
- 李沆去世后原文追记其政治理念。他在真宗即位初年每天把四方水旱、盗贼上奏，使年轻皇帝知道民间疾苦，以免沉溺声色、土木、甲兵、祷祠；又说自己做宰相仍未能完全做到《论语》所谓“节用而爱人，使民以时”。原文定位：`P0062`。
- 卞衮长期掌财赋，以明敏有吏干著称，但原文同时记其“性惨毒，掊克严峻，专行箠楚”，甚至被称“大虫”，是财政官吏以严酷催征获得“称职”声誉的反面材料。原文定位：`P0064`。
- 宋雄因熟悉河渠，长期负责汴口、均节水势以济江淮漕运，十余年不易其任，原文称“朝廷赖焉”。原文定位：`P0065`。
- 寿州饥荒时，陈尧佐先自行拿出米煮粥给饥民，官吏与民众随后争相出米，共“活数万人”；他说明自己并非行私惠，而是以身先率众。原文定位：`P0070`。
- 河北战争进入高压阶段后，朝廷从内府拨银三十万两给河北转运使，用于购买军粮，是本卷金额最大的明确军粮财政投入之一。原文定位：`P0081`。
- 因敌兵侵入，河北近南州县民众被令进入城寨避难，是大规模战时人口疏散措施；人数失载，不把其虚构为死亡或固定流民数字。原文定位：`P0088`。
- 朝廷严禁府州此后擅自发兵进入唐龙镇管内剽掠；若蕃、汉逃亡者在当地，需要由诏令遣还。该条直接限制边军以追逃为名越界掠夺。原文定位：`P0089`。
- 辽军稍向南深入时，沿线民众惊慌奔向杨刘渡，舟人乘机索取高价、拖延渡送。丁谓以极严厉手段震慑舟人，随后民众才全部渡河；又沿河设置旗帜、刁斗制造声势。因该段没有实际武装接触，本轮不作为战役卡，而作为战时疏散、市场逐利与行政强制材料保留。原文定位：`P0100`。
- 随驾军士先赴澶州，以及天雄军、沿河驻泊军士，均获赐“装钱”。该项属于实际军费支出，不提前并入后卷澶州战役的单场资产成本。原文定位：`P0104`。

## 二、政治秩序、外交与人口变化

- 辽来降供奉官李信向宋提供较完整的辽军编制和地理情报：幽州汉骑约一万八千余，山后四镇等诸军约十万八千余骑，其中称可即时南侵者九万三千九百五十；并详述幽州至平州、辽阳及高丽、女真方向距离。宋授其供奉官并赐器币冠带。原文定位：`P0004`。
- 兖王元杰去世，追封安王、谥文惠。原文定位：`P0005`。
- 辽以耶律实噜为南院大王；原文追记其早年随军略燕、赵有功。该旧战功不作为本卷新战役。原文定位：`P0006`。
- 原、渭等州报告西蕃八部、二十五族“纳质来归”；这里只能确认政治归附和质子关系，不能据此虚构实际领土控制。原文定位：`P0008`。
- 高丽王遣使入贡并请求宋军驻边牵制辽，理由是自石晋割幽蓟后辽屡攻高丽、求取无厌。宋只以诏书优答，本卷没有实际出兵。原文定位：`P0012`。
- 吕蒙正七次上表求退，最终罢相为太子太师、封莱国公。原文定位：`P0014`。
- 辽任皇弟楚王隆祐为西南面招讨使。原文定位：`P0019`。
- 钱若水卒，真宗赠户部尚书、谥宣靖，并特遣中使存问其母、赐白金五百两。原文定位：`P0021`。
- 辽耶律休格之子道士怒、高九等谋叛，尚未形成实际武装阶段即被诛，按合同只列政治秩序，不进入战役账。原文定位：`P0022`。
- 辽通括南院部民，是一次人口、户籍性清查。原文定位：`P0023`。
- 真宗因彗星求直言，并在田锡去世后高度评价其“不顾其身，惟国家是忧”；命录其事布告天下，并给其子俸禄终丧。原文定位：`P0027`、`P0029—P0030`。
- 万安太后病重后，真宗求良医；其后明德皇太后崩，真宗哀毁过甚，李沆等以“西北用兵，机务不可暂旷”多次请其恢复听政。原文定位：`P0031`、`P0052—P0053`。
- 景德元年初刘氏、杨氏分别封美人、才人。原文详载刘氏入王府、被乳母斥出后再召等经历，是后续后宫与继承史的重要前置材料。原文定位：`P0041`。
- 京师正月三次地震；冀、益、黎、雅州又地震，邢州地震不止，瀛州亦震。真宗把京师地震解释为自己“听览不明”所致。原文定位：`P0042`、`P0048`、`P0054`、`P0056`。
- 宋廷二月才正式得知李继迁死亡，认为其子李德明尚幼，辅臣建议招谕其部众并厚加爵赏；鄜延钤辖张崇贵已先与李德明通信。五月向敏中出任鄜延路缘边安抚使，在保安北筑台、召李氏方面信任的戎人定盟约。原文定位：`P0044`、`P0055`。
- 辽南院枢密使邢抱朴卒。原文称其奉命甄别守令颇得人望，两次处理滞狱使“民无冤滥”。原文定位：`P0045`。
- 查道任度支副使时因治剧非长、对本部事务竟未预先了解，在殿上被问时不能答，随后罢职；原文称其始终不自辩也不愠。原文定位：`P0049`。
- 丁谓在夔州路招抚溪洞“颇著威惠”，当地部民请求留任，五年不得代；后来由其举薛颜自代、自己入朝。原文定位：`P0050`。
- 新校写御书达二万四千一百六十二卷。原文定位：`P0051`。
- 真宗限制民众直接进京举留地方官：若官吏确有善政，应由转运使举陈；民众越级举留的首倡者将依法处理。原文定位：`P0057`。
- 真宗秘密选取二十四名“有闻望”官员，逐一在崇政殿引对，有时试文艺，再分别加馆职、省府判官或升差遣。原文定位：`P0058`。
- 朝廷罢川峡、闽广州军承天节入贡，并规定此后三千里以外者一律免贡，直接减少远地节庆性贡运。原文定位：`P0059`。
- 梁颢夜对时称赵安仁“材识兼茂”，真宗后来任赵安仁翰林学士。原文定位：`P0060`。
- 李沆病逝，真宗两次亲临其第并痛哭，追赠太尉、中书令、谥文靖，并广录其亲属。原文同时借其生平强调少兴事、知民疾苦的政治风格。原文定位：`P0061—P0062`。
- 真宗拟用寇准入相，毕士安明确称寇准“忠义、能断大事”，又为其刚强好气辩护，认为北方未服正宜用此人；八月毕士安、寇准并拜平章事。原文定位：`P0063`、`P0067`。
- 辽封李德明为西平王。结合本卷前段宋方招谕、定盟可见，李德明继承后的政治地位同时受到宋辽两边经营。原文定位：`P0066`。
- 八月寇准观察契丹游骑常深入祁州一带、小不利即去，判断这是在使宋军习以为常，主张练将、简锐、分据要害。该段是敌情模式和备战判断，没有一场可独立裁决的完整战斗。原文定位：`P0067`。
- 王继英升枢密使，冯拯、陈尧叟签署枢密院事；刘师道后来权三司使公事，此后三司除使多采用这种形式。原文定位：`P0068—P0069`。
- 准布部长朝辽并请婚，辽主不许。原文定位：`P0071`。
- 边臣报契丹将大举入侵后，宋把镇州所屯河东广锐兵和近南州军预先分屯兵调赴定州。原文定位：`P0072`。
- 朝廷建立转运使、副考核三等制：公勤廉干且惠及民为上，能办事但无廉誉或清白无治声为次，畏懦贪猥为下，要求逐人列状上报。原文定位：`P0073`。
- 真宗多次收到契丹将南侵情报后，明确提出亲征；毕士安主张若亲行宜暂驻澶渊，寇准则认为进发不可缓，枢密院也赞成以车驾壮兵威但不可越澶州。原文定位：`P0075`。
- 真宗规定边奏虽属枢密，但中书总文武大政，毕士安、寇准也必须详阅、共同参决，不得因事涉枢密而被排除。原文定位：`P0076`。
- 陕西转运使杨覃、朱台符因一人欲守旧、一人好更张而长期互相论奏，真宗派御史调查后两人同时罢使。原文定位：`P0077`。
- 辽令楚王隆祐留守京师；宋则以周莹代王显为天雄军都部署。原文定位：`P0078—P0079`。

- 朝廷下诏修葺历代圣贤陵墓。原文定位：`P0093`。
- 何承矩因“知书、爱声名，以才能自许”获选美名州号，领英州团练使。原文定位：`P0094`。
- 雷有终等原拟走土门路与大军会合，后因敌军逼武强县而改赴镇州；随后又命多路深入敌境、腹背纵击以分敌势。原文定位：`P0096—P0097`。
- 明德皇后神主最终与懿德皇后并祔太宗室，原文称“二后并配自是始”。原文定位：`P0099`。

- 永兴有禁卒拟借大傩作乱，尚未发动即被告发；向敏中伏甲擒获，果然搜出短刃，当席处死。按合同这是被预先阻止的谋乱计划，不作为战争人员损失。原文定位：`P0103`。
- 六谷首领廝铎督被任为朔方军节度、灵州西面巡检和西凉府六谷大首领，继续体现宋对河西部族体系的经营。原文定位：`P0105`。

- 雍王元份任东京留守；同时初置龙图阁待制，以杜镐、戚纶为之；李重贵任大内都部署。原文定位：`P0108—P0110`。

## 三、跨卷连续性

- 向前：卷023末已经确认蒲阴被围、宋重新布置定州—唐河大阵；卷024进入景德元年后，辽南侵从沧州、威虏、顺安、北平、保州、遂城一路发展到瀛州、祁州等更深地区。蒲阴本身在本卷仍没有明确终局，因此继续保持待核。
- 向前：李继迁已在卷023中箭败归并死，李德明继立。本卷宋先招谕并在保安方向议定盟约，辽又封其为西平王，说明李氏政权并未因李继迁死亡立即崩解；其后续稳定性应在后卷继续观察，不能把父辈死亡直接判成李氏威胁结构终结。
- 向后：卷末宋辽已经从王继忠私下劝和推进到曹利用正式出使，但战争仍在进行。卷025才会出现澶州方向的关键战斗、和议条款、撤军与岁币履约；这些后果不得倒灌到本卷瀛州、祁州等阶段。
- 向后：财政民生账户同样没有因准备议和而自动改善。本卷仍明确存在河北关西戍兵未息、赋敛益繁、内府出银三十万两购军粮、民众入城避难等成本；下一卷必须单独核停战后减役、复业、岁币和边境长期安全之间的实际交换。
