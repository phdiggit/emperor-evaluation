## 一、财政、民生、工程与灾害

- 华州知州张舒与官属率民出钱修孔庙，被民告发后均坐赎金；真宗由此下全国性禁令，州县文宣王庙修葺以后由官府出钱，不得擅自向民间摊派。原文定位：`P0003`“自今並官給錢完葺，無得輒賦民財”。
- 文武官月俸中原本折支实物的部分改为给实钱，愿领他物者仍可，属于官俸支付方式直接货币化。原文定位：`P0005`“應折支者並給實錢”。
- 真宗总结内藏与国家财政关系：乾德、开宝以来，用兵、水旱赈给、庆赐赏赉造成度支不足时，即向内藏借款；淳化后二十年每年多借百万，最高达三百万，累年不能偿者即除籍。其明确指出“计司有阙，必取于民”，因此内藏本应作为经费缓冲，节用可减少再向民间取给。原文定位：`P0010`“歲貸百萬，有至三百萬者”“計司有闕，必取於民；苟非節用，何以獲救”。
- 辽在饶州发生饥荒，朝廷发放赈济。原文定位：`P0024`“遼賑饒州饑民”。
- 诸路上报军储数量以后须先交枢密院登记再送中书，原因是每次遣戍都要预先估算驻地资粮丰歉，体现边防调兵与粮储信息开始制度化联动。原文定位：`P0026`“凡遣戍兵，必預度所在資廩豐約”。
- 夏州当年饥馑，真宗已下令榷场不得禁止西蕃购买粮食；赵德明随后以民饥上表求粮数百万，辅臣欲责其违约，王旦改建议在京积粟百万、令赵德明自己来取，赵收到诏书后停止请求。本卷没有实际发粮结果，不能把百万粟记成已支出。原文定位：`P0034`“今歲夏州饑饉”“榷場勿禁西蕃市粒食者”；`P0035`“在京積粟百萬，令德明自來取之……乃止”。
- 真宗估计京师士庶把金熔作服饰器玩、金箔的耗费每年“不下十万两”，命丁谓申明旧禁、赏举报者，并令宫中乘舆服御也停用涂金、绣金，形成由上及下的奢侈品金耗约束。原文定位：`P0041`“計所費歲不下十萬兩”“乘輿服御塗金、繡金之類亦不須用”。
- 泰山封禅筹备以“经费足”为前提，但实际涉及大规模跨区物资组织：泰山路粮草、行营道路、金帛刍粮均由三司筹度；其他所需从京师转输，明确禁止地方临时科率；陕西上供木材由黄河浮筏至郓州，并给沿途置顿费用。原文定位：`P0046`“悉自京輦致，無得輒有科率”“發陝西上供木，由黃河浮筏鄆州，給置頓之費”。
- 同一封禅筹备又设置数项减扰民限制：泰山禁樵采；山下工程不得调民丁，只许用兖、郓州兵；行宫除前后殿外多用帷幕；沿途修建不得侵占民田，扈驾步骑践踏苗稼者由御史纠察。原文定位：`P0046—P0047`。
- 河北转运使李士衡此前奏罢内帑助钱八万缗，又请把本路金帛刍粟四十九万转赴京东以助封禅；三司另向内藏库借银十万两。封禅财政并非仅靠常规岁入，而是同时动用了地方转输与内帑信用。原文定位：`P0057`、`P0062`。
- 王旦告诫新任江南转运使张士逊“朝廷榷利至矣”；原文称张士逊后来转任广西、河北，每思此言，不敢妄兴建，显示转运使增财与扰民之间已被明确作为行政边界。原文定位：`P0054`。
- 金玉辂过于高大，原拟拆修沿途城门、桥道；真宗以此“劳人”为由，改令从城外绕行并避坟墓，直接取消一项因礼仪车辆引发的地方工程。原文定位：`P0061`“若此，則勞人矣。可於城外過”。
- 封禅仪式本体仍有大量制作与运输：圜坛、燎坛、山下封祀坛、社首坛、瘗坎、玉牒玉册、金玉匮等成套建造；另采岳州三脊茅三十束，并多次演习、修改仪注。原文定位：`P0052`、`P0058—P0059`、`P0065`。
- 登山阶段，道路从回马岭至天门“险绝”，先行官员由从卒推引；正式登山时卫士、亲从卒沿盘道约两步一人，导从有人疲顿。此处属于封禅礼仪人力与交通负担，不属于战争成本。原文定位：`P0091—P0092`“導從者或至疲頓”。
- 九月全国多个主要地区同时报大稔：京东、京西、河北、河东、江淮两浙、荆湖、福建、广南等，米斗仅七文，是本卷范围最广、价格最具体的丰收记录。原文定位：`P0083`“皆大稔，米斗錢七文”。
- 东巡前诏沿路调查民间不便、市物价格、权衡度量；鳏寡茕独不能自存者量加赈恤，另要求官员上报民间利病。原文定位：`P0085`。
- 封禅后泰山下七里继续禁止樵采；同时宴泰山父老并赐时服、茶帛。原文定位：`P0095`。
- 十二月令江淮发运司所属各地留下三年储粮，以备水旱。此前江淮米主要运京，此举直接把部分粮储留在产粮区作灾害缓冲。原文定位：`P0108`“各留三年之儲以備水旱”。
- 东京新城外民居增多，旧由赤县尉管理已不足，遂设置八厢、置厢吏并由开封府统辖，是城市扩张后的基层行政调整。原文定位：`P0109`。

## 二、政治秩序、外交与人口变化

- 真宗选杭州长官时，以宜州此前因长吏虐下而酿成武装事件为反例，认为重地若长吏得人可使“小寇不能为患”；最终以王济有吏干而出知杭州。该段保留的是地方治理归因与用人标准，实际平叛另见战役 JSON。原文定位：`P0007`。
- 诏群臣家藏太祖旧《实录》全部上史馆，不得隐匿，属于主动征集早期国史材料。原文定位：`P0006`。
- 晁迥等上《考试进士新格》并颁行。原文批评陈彭年所改条制虽能杜绝请托，却把取士从文行转成“止较一日之艺”，甲等亦未必孚众望。原文定位：`P0012—P0013`。
- 十月毁弃诸道非法讯囚刑具，明确禁止超出法定科条的拷掠。原文定位：`P0015`“非法訊囚之具，一切毀棄”。
- 全国贡举人数已达一万三千余，常例约十一取一；真宗因淘汰人数过万而强调知举与封印官必须慎选，并首次命礼部封印卷首。原文定位：`P0023`。
- 王钦若先以澶渊和议刺激真宗羞耻感；当真宗明确表示河朔百姓刚获休息、不忍再驱之死地后，王钦若转而提出封禅作为“大功业”，又以“神道设教”解释河图洛书。王旦随后不再反对，天书、封禅政治由此启动。这里属于政治决策链，不把未实施的幽蓟用兵建议算作战争。原文定位：`P0019`。
- 辽使耶律元在京听见鼓声，询问是否练战阵；真宗命如实说明诸军虽无征战仍常阅武，认为这样反而可显示宋辽“无间”。原文定位：`P0021`。
- 大中祥符元年正月，真宗公开叙述神人预告及“天书”降于承天门，继而亲迎、启封、告祭、大赦改元；六月又出现第二次泰山“天书”。这些事件把此前政治构想转成国家仪式与年号体系。原文定位：`P0029—P0033`、`P0067`。
- 封禅请愿逐步扩大：兖州父老1287人、诸路进士840人，再到王旦等率文武百官、军将、州县官、蕃夷、僧道、耆寿24370人五上表；四月才正式诏定十月封禅。原文定位：`P0042—P0046`。
- 亲试进士时，真宗亲临考场并令八考官精审，姚晔等及第；贡举初用糊名后，张士逊因亲戚应试主动避嫌，遂形成“有亲嫌者移试别头”的制度。原文定位：`P0048`、`P0054`。
- 有人以“两汉贤良多因兵荒灾变询阙政、今受瑞建封不应复设”为由上言，朝廷遂悉罢吏部科目，说明祥瑞政治直接影响选官制度。原文定位：`P0050`。
- 五月放后宫120人，并厚给资遣。原文定位：`P0064`。
- 宋决定封禅后专遣孙奭至辽境通报；东巡途中，占城、大食使者沿路献方物，大食蕃客李麻勿献祖传玉圭。原文定位：`P0066`、`P0089`。
- 九月丁谓奏“双鹤度天书辇，飞舞良久”，真宗指出实际只是从辇上飞过，要求改奏；丁谓反请把这次更正写入《时政记》。原文定位：`P0079`“若云飛舞良久，恐不為實，卿當易此奏也”。
- 封禅期间刑政多次随礼仪调整：六月曲赦兖州流罪以下；九月暂停奏大辟案；封禅完成后大赦天下，连常赦不原者也获除。原文定位：`P0069`、`P0076`、`P0095`。
- 封禅后兖州升大都督府；真宗又在曲阜礼孔，加孔子谥“玄圣文宣王”，修祠、给十户奉塋庙，赐孔氏钱三十万、帛三百匹并录用后裔；随后赐《九经》《三史》并令选儒生讲说。原文定位：`P0097—P0100`。
- 定正月三日为天庆节，令丁谓把祥瑞编次、撰赞、绘入昭应宫，并命编修《封禅记》，一次性封禅被转成持续礼制、图像和文本生产。原文定位：`P0102`、`P0106`。
- 寇准被任为知天雄军兼驻泊都部署；辽使问其为何不在中书，寇准答称北门锁钥非己不可，反映澶渊和后天雄仍是北防重镇。原文定位：`P0110`。
- 进奏院被禁止“非时供报朝廷事”，五名进奏官互保，违者按违制罪论，属于朝廷信息传递节制。原文定位：`P0113`。
- 辽本卷另有巡幸、皇室加谥和科举；岁末录取进士史克忠等十三人。具体辽西北战事移入战役 JSON。原文定位：`P0011`、`P0038`、`P0055`、`P0063`、`P0071`、`P0084`、`P0115`。

## 三、跨卷连续性

- 向前：卷026末宜州陈进已杀知州、拥卢成均称王据城，宋仅下令曹利用等进讨；卷027开篇直接出现象州围攻和平叛结果，相关武装阶段沿用 `XZTJ-YIZHOU-CHENJIN-REBELLION-1007`，不把卷026未发生的战斗倒补进去。卷026刚形成祥瑞政治，本卷则把它扩展为天书、改元、封禅和昭应宫。
- 向后：卷末泰山封禅已经完成，天庆节、昭应宫、祥瑞图像与文本生产继续；江淮三年储粮、东京外八厢、天雄北防均进入新阶段。西北方面，本卷赵德明已令张浦率数千骑侵扰回鹘，其连续武装链需由卷028继续核验；辽讨甘州回鹘虽见其王请降，但辽军随后“抚慰而还”，名义服从是否稳定不能在本卷抬成长期控制。
