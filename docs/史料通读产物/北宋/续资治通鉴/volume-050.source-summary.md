## 一、财政、民生、工程与灾害

- **黄河商胡决口成为本卷最重的民生—财政冲击。** 六月河决澶州商胡埽；其后河北、京东西连续水灾，朝廷罢秋宴、罢上元灯乐。年底贾昌朝追溯国朝河患，称上一年德、博间已决二十一处，本年商胡决后河水贯御河、经冀瀛至海，大量民田被淹；沧、棣、滨、齐原是河北防务与军需的重要财源，横陇决后“财利耗半”，商胡再决后“十失八九”。他建议东复故道、修旧堤，并提出发近县夫开河，朝廷另派官员复勘。原文锚点：`P0018`、`P0032`、`P0058`、`P0062`、`P0070`。短引：“自古河决为害，莫甚于此”；“商胡之败，十失其八九。”
- **灾年出现“募饥民为军”的逆周期扩军。** 七月河北水灾后，州县获准把饥民招募为军；富弼救灾中另有流民万余人被募兵。此处只记录人口与财政事实，不把募兵本身当战果。原文锚点：`P0026`、`P0082`。短引：“令州县募饥民为军”；“募而为兵者又万余人。”
- **盗铸导致钱文混乱和物价上涨，钱法数变又反过来损耗兵民资产。** 河东小铁钱易被盗铸，利润可达十分之六；当地民户多有冶具，契丹又能铸铁钱换走边境铜钱。朝廷先改小铁钱比价、停官炉，后停商州清黄铜钱，再把陕西大铜钱、大铁钱统一一当二，盗铸才止。但原文明言“令数变，兵民耗于资用，类多咨怨”。原文锚点：`P0024`—`P0025`。短引：“钱文大乱，物价翔涌”；“令数变，兵民耗于资用。”
- **辽南京贫户获免租税。** 辽在出兵富努里同段先记“复南京贫户租税”，属于独立的民生财政事实。原文锚点：`P0031`。短引：“辽复南京贫户租税。”
- **江淮漕米二百万斛转供河北。** 九月三司把当年江、淮所运米二百万斛转给河北州军，显示水灾、边储与军食已联动挤占跨区粮食。原文锚点：`P0035`。短引：“以今年江、淮所运米二百万斛转给河北州军。”
- **韶州铜矿形成稳定铸币资源点。** 天兴场岁采铜二十五万斤，设永通监铸钱。原文锚点：`P0037`。短引：“铜岁采二十五万斤。”
- **范祥解盐新法最初被记为减役便民，后又暴露盐价、课利与刑狱反弹。** 新法开放部分旧禁盐地通商，把九州军刍粟入中改为实钱，商人入钱领券到盐池取盐，并“尽弛兵民辇运之役”；同时严禁沿边青白私盐和部分旧入中物。原文先称数年后“关内之民得安其业，公私以为便”。但皇祐元年十月，何郯又报告官盐涨价使商旅利润过薄、陕西盐课已亏百余万贯，私盐案件与刑禁增加，朝廷遂命包拯复议。原文锚点：`P0040`—`P0041`、`P0143`。短引：“尽弛兵民辇运之役”；“陕西一路，已亏损课利百余万贯。”
- **畿内物价上涨时由官府设十二场平价济贫。** 十一月因“物价翔贵”，新城外设十二场，由官府出物并裁价。原文锚点：`P0056`。短引：“官出物，裁其价以济贫民。”
- **河北流民救济从粮食、住宿、税费、收养到返乡复业形成多层措施。** 不能自存的流民男女可由他人收养，原家日后不得复取；出内藏钱帛给三司买粮，沿途官给住宿，携带物免收算税；灾民复业者又免租赋二年。原文锚点：`P0053`、`P0059`、`P0108`。短引：“民流离道路，男女不能自存者，听人收养之”；“所赍物无收算”；“蠲河北民复业者租赋二年。”
- **谷种赈济直接面向灾后复产。** 皇祐元年正月出二十万缗购买谷种，分给河北贫民。原文锚点：`P0073`。短引：“以缗钱二十万市谷种，分给河北贫民。”
- **河北疫病出现后由中央遣使颁药。** 原文锚点：`P0078`。短引：“以河北疫，遣使颁药。”
- **刘夔以开仓赈饥压低盗贼，而不是单纯增兵。** 京东因河北流民大量进入而盗贼多起，仁宗原想益兵；刘夔到郓州后“发廪赈饥民”，存活者甚众，盗贼随即衰止。原文锚点：`P0079`—`P0080`。短引：“发廪赈饥民，赖全活者甚众，盗贼衰止。”
- **富弼青州赈灾是本卷最完整的大规模救荒案例。** 他选辖区五个丰稔州劝民出粟十五万斛并加官粮，准备公私房舍十余万区分散安置流民，给参与救济的待阙、寄居官吏发俸并记录功劳；开放山林陂泽资源供流民自取生计，五日一犒救济人员；死者集中安葬，返乡者按路程给粮。原文称共“活五十余万人”。同时明确批评旧式把饥民聚在城郭煮粥，容易造成疫病、踩踏和等粥而死。原文锚点：`P0081`—`P0082`。短引：“凡活五十余万人”；“名为救而实杀之。”
- **救灾后仍有禁军十指挥赴京东西防盗，富弼担心反而摇动人心。** 富弼只愿量增一二指挥，朝廷以军队已上路为由暂留，承诺待岁丰后还京。原文锚点：`P0083`。短引：“虑摇人心”；“俟将来岁丰，令还京师。”
- **包拯把河北缺粮驻军南移，同时把牧地一万五千顷还民。** 缺粮地区士兵、戍兵暂徙近南州军，待边储恢复再还；广平两临马牧共占邢、洺、赵民田一万五千顷，包拯请把仍被占的漳河沃壤全部赋民，获准。原文锚点：`P0090`、`P0094`。短引：“候经置边储有备，复令还屯”；“请悉以赋民，从之。”
- **省冗官、汰不任役军士已从议论转为行政任务。** 四月命包拯与河北四路安抚使、转运司共同讨论省冗官和淘汰不能任役军士。原文锚点：`P0098`。短引：“议省冗官及汰军士之不任役者。”
- **劝农被要求从虚衔转成可考核的田亩、户口、水利台账。** 钱彦远建议置劝农司，先登记垦田顷亩、户口、陂塘、山泽、沟洫、桑柘，再由官员“除害兴利”，岁末由转运司考较赏罚，仁宗嘉纳。原文锚点：`P0101`。短引：“徒有虚文，无劝导之实”；“先以垦田顷亩及户口数……著之于籍。”
- **仁宗欲以五十万内库金帛救河东匮乏，任颛以职责在经制财用为由辞却。** 原文锚点：`P0102`。短引：“委以经制财用，而遽乞金帛以往，不可。”
- **宫苑种麦被用来强调“知稼穑不易”。** 仁宗称宝岐殿不植花卉、年年种麦，是为亲知农业艰难。原文锚点：`P0104`。短引：“庶知稼穑之不易也。”
- **省兵最终落地为三万五千余人归农，每年省二百四十五万缗。** 何郯先建议陕西保捷兵五十岁以上及短弱者放归农，并按乡社登记以备边急；年底正式执行，放归三万五千余人，“皆欢呼反其家”，仍在籍五万余人反而悲涕。原文给出每名保捷兵边区年费七十缗，裁撤后岁省二百四十五万缗，并直称“陕西之民力稍苏”。文彦博、庞籍此前面对“退兵会聚盗”之议，以“臣请以死当之”担保；后来又出现士兵故意缩颈曲膕冒充短弱求退，反证归农意愿。原文锚点：`P0147`、`P0153`—`P0154`。短引：“岁省缗钱二百四十五万”；“陕西之民力稍苏。”
- **高龄、笃疾贫民另有定额救助。** 河北被灾民中八十岁以上及笃疾、贫不能自存者，每人赐米一石、酒一斗。原文锚点：`P0150`。短引：“人赐米一石，酒一斗。”
- **贫民诉讼获得下沉通道。** 无力赴京申冤者可向监司申诉，由监司奏闻。原文锚点：`P0151`。短引：“贫不能诣阙者，听诉于监司以闻。”
- **驿传速度定量化。** 马铺昼夜四百里，急脚递五百里。原文锚点：`P0146`。短引：“马铺以昼夜行四百里，急脚递五百里。”

## 二、政治秩序、外交与人口变化

- **宋廷正式册封三月大的谅祚，放弃趁西夏幼主、诸将不和时分裂其势。** 有人主张以节度使命诸将、分弱西夏；程琳、孙沔认为“幸人之丧”不合中国体，仁宗采纳并催行册礼。原文锚点：`P0003`—`P0004`。短引：“幸人之丧，非所以示德。”
- **贝州之后中枢继续重组。** 丁度罢参知政事，明镐入参政，叶清臣权三司使；何郯持续攻击夏竦在宿卫案中包庇杨怀敏，夏竦最终罢枢密使。原文锚点：`P0005`—`P0006`、`P0013`—`P0016`。短引：“今怀敏黜而竦独留，中外之心，无不愤激。”
- **科举改革出现一次明显回摆。** 贡院认为废弥封、誉录会恢复旧人、虚誉与请托，新制先策论又难稳定筛选数千举人；仁宗遂令科场沿用先朝旧条，暂不实行宋祁等新制。原文锚点：`P0007`。短引：“科场旧条皆先朝所定，宜一切无易。”
- **河北四路安抚体系正式建立。** 韩琦知定州、王拱辰知瀛州、鱼周询知成德军并兼各路安抚使。原文锚点：`P0010`。短引：“置河北四路安抚使。”
- **馆阁官被要求先有一任亲民经历。** 未亲民一任者，不得径入省府及任转运、提点刑狱。原文锚点：`P0022`。短引：“须亲民一任，方许入省府。”
- **言路一度因“风闻”问题明显收紧。** 杨察主张御史旧例可风闻言事，却因多次忤陈执中与张昪同被黜；皇祐元年正月又正式规定，非朝廷得失、民间利病不得以风闻弹奏，张祹反对未获回应。原文锚点：`P0028`—`P0029`、`P0074`。短引：“臣恐台谏官畏罪缄默”；“非朝廷得失，民间利病，毋得以风闻弹奏。”
- **吴育公开反对法外诏狱与过度羞辱官员。** 杨仪案依法只属普通请托，却被械缚过市并遭特旨重处；吴育认为这会伤士大夫廉耻、使“下民轻视其上”，主张除重大蠹害外应交有司依法论断。原文锚点：`P0030`。短引：“毋轻置诏狱”；“不必法外重行。”
- **大臣子弟求馆职、求出身开始被考试程序约束。** 先规定合恩例者集中送学士院试诗、赋、论，封弥、誉录；后又规定即使考中，也只给转官或出身，不再直接授馆阁职。原文锚点：`P0036`、`P0118`。短引：“仍封弥、誉录考试”；“更不除馆阁。”
- **张贵妃得宠与台谏、制诰程序发生多重牵连。** 王贽曾借宿卫案意图动摇中宫，后获张氏巨量私赐并被称“我家谏官”；宋祁在贵妃册告中绕过中书提前用印，被贬。何郯则多次反对借宫变尊张氏。原文锚点：`P0038`、`P0042`—`P0043`、`P0050`—`P0052`、`P0060`。短引：“我家谏官也”；“此奸人之谋，不可不察。”
- **宦官朝会礼遇受到抵制。** 王守忠拟按正任班在殿上预宴，何郯、钱晦均称祖宗无此例，恐为“四夷所笑”；王守忠最终辞不赴。后又下诏禁止臣僚保荐要近内臣。原文锚点：`P0047`—`P0048`、`P0123`。短引：“祖宗典法，未尝有内臣殿上预宴之事。”
- **辽宗室权力失控出现“赌城”荒诞记录。** 辽主曾酒后许日后传位太弟重元，又以双陆赌居民城邑，前后输掉数城；朝臣因重元恃宠无敢言，直到伶人讥谏才停止。原文锚点：`P0055`。短引：“前后已偿数城。”
- **辽告伐夏后，宋廷外交立场仍以拒绝额外索求为主。** 辽扣留夏贺正使并向宋正式通告出兵。叶清臣回顾庆历初辽使刘六符使宋“坐致二十万物”，主张此次若辽再借伐夏索取，应以誓书“彼此无求”为据拒绝；若辽转而侵宋，他提出利用河北灾后难以因粮的条件坚壁待敌，此处属于未实施的战略建议，不作战果。原文锚点：`P0067`、`P0087`、`P0096`。短引：“彼此无求”；“匮膏血以奉外敌。”
- **灾异被多次转化为求言、罢相和节用理由。** 皇祐元年日食、持续一百一十四日的彗星及太白犯南斗先后出现；彗星后仁宗不御正殿、减常膳并令中外极言切务。陈执中则在河决、流民和多次灾异后因无所建明、反接卜相术士及用人争议被罢相。原文锚点：`P0066`、`P0076`、`P0130`、`P0141`。短引：“不御正殿”；“中外臣僚，极言当世切务。”
- **私人书信被用于告讦的做法受到限制。** 李兑、何郯、陈旭等指出把亲友往来简尺缴朝廷追究会造成“告讦之俗”，遂规定除涉“不顺”外不得缴奏。原文锚点：`P0117`。短引：“遂使圣时成告讦之俗。”
- **对转运、提刑荐补官吏建立连带监督责任。** 所补官吏若受赃而主管失察，转运使、提点刑狱本人也要降黜。原文锚点：`P0121`。短引：“所补官吏受赃，失觉察者降黜。”
- **张锡借讲书直接以“节嗜欲、审刑罚”讽谏贵妃宠幸。** 仁宗改容称善。原文锚点：`P0124`。短引：“节嗜欲者，治身之本；审刑罚者，治国之本。”
- **北边屯田侵民再次被翻出。** 吴奎曾反对杨怀敏扩大北边屯田、夺民谷地，并替因争屯田而遭构陷的王果力辩；本卷把这作为其贤良方正材料追叙。原文锚点：`P0132`。短引：“增广北边屯田，至夺民谷地。”
- **又一次禁卫风险在实际发动前被截断。** 卫士王安把刀暗藏衣箱，由杨景宗引入禁门时即被门者发现，杨景宗又隐匿不奏；郭劝、何郯长期争论后，杨景宗被外安置。因未形成实际袭击，不进入战役卡。原文锚点：`P0133`。短引：“阴置刃衣箧中”；“既为阍者所得。”
- **张尧佐以后宫亲身份掌三司继续遭反对。** 陈旭认为其“不宜使制国用”，仁宗未听。原文锚点：`P0136`。短引：“以后宫亲，不宜使制国用。”
- **辽夏开战后宋只加强河东、河北边要防备。** 九月诏经略安抚司严选将佐、加强备御，本卷未记宋由此与辽、夏发生实际接战。原文锚点：`P0137`。短引：“其边要之地，选委将佐，严加备御。”
- **广源州的名义归属与实际服役对象并不一致。** 原文说明广源在邕州西南、产黄金丹砂，有邑居聚落；虽名为宋邕管羁縻州，交趾据安南后“其实服役于交趾”。实际武装入寇及侬氏政权演变另入战役裁决卡。原文锚点：`P0138`。短引：“虽号邕管西羁縻州，其实服役于交趾。”
- **妇女服饰禁令出现明显的执法过度与社会嘲讽。** 因宫中流行白角“内样”冠梳，民间竞相模仿，朝廷严定冠、梳尺寸和材质；执行后“妇人多被刑责”，为识者所嗤并出现讽刺歌谣。原文锚点：`P0144`—`P0145`。短引：“妇人多被刑责，大为识者所嗤。”
