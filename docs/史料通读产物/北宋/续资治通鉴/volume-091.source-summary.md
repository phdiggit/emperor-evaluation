## 一、财政、民生、工程与灾害

- 政和元年二月，陕西、河东一度恢复铸造夹锡钱，四月即罢；五月又把现行当十钱统一改作当三行使，显示大钱、夹锡钱制度仍在反复调整。原文定位：`SRC-XUZIZHITONGJIAN-091-2299565-P0010`、`P0018`、`P0022`。
- 朝廷要求监司督促州县长吏劝民增植桑柘，并以多寡定赏罚；随后又立守令劝农黜陟法。政和二年又令县令以十二事劝农、亲行阡陌督察勤惰。原文定位：`P0015`、`P0020`、`P0064`。
- 四川“羡余钱物”被要求统一归入左藏库，地方额外财政结余进一步上收中央。原文定位：`P0021`。
- 张商英执政时把蔡京所铸当十大钱改为当三以平泉货，恢复转般仓、停止直达，实行盐钞法以通商旅，并“蠲横敛以宽民力”，同时劝徽宗节华侈、息土木。原文定位：`P0032`。
- 乌尔古、德埒勒部叛辽后，耶律棠古未用兵而谕降，随后出私财并动用富民积蓄赈济困乏，使部民“大悦”。本段反映边部困乏与临时赈济，但没有可证武装接战。原文定位：`P0044`。
- 政和二年复行方田。到十一月，徽宗手诏承认执行中“货赂公行”，豪右形势之家多被免除赋役而负担转移给下户，导致百姓流徙、常赋收入反而大量亏额，遂权罢方量，并要求按旧额处理争议、招诱流民归业。这是本卷最直接的赋役—流民—财政联动材料。原文定位：`P0065`、`P0092`。
- 蔡京再起后大兴延福宫，童贯等五人分任工役，竞相追求“侈丽高广”；每年冬至后至上元前放灯不禁夜，并迁市民行铺夹道而居，形成持续性的宫廷工程与城市扰动。原文定位：`P0099`。
- 因诸路马食储积困难，朝廷开始令诸路给地牧马，并要求陕西沿边城寨分番出牧、夜间带草归营，以节省官刍。原文定位：`P0100`。
- 辽政和三年正月直接赐南京贫民钱；同月辽主严寒中出猎，“大寒，猎人多死”。原文定位：`P0106`、`P0110`。
- 徽宗又建保和殿七十五间，随后在福宁殿东建玉清和阳宫；本卷宫室、宗教建筑仍持续增加。原文定位：`P0128`、`P0130`。
- 大盈仓发生火灾，原文未载损失数量。原文定位：`P0140`。
- 十一月连续十余日大雪，平地积雪八尺余，冰滑至人马不能行，百官被允许乘轿入朝。原文定位：`P0178`。
- 本卷记江东旱灾，未载赈济规模。原文定位：`P0188`。
- 政和四年，水磨茶场岁收约四百万贯以上，已为旧额三倍；尚书省又提出每月固定进奉五万贯，称余款仍足，朝廷批准自当月执行。该项显示专卖/茶场收入显著增长并形成固定月进。原文定位：`P0203`。
- 置广西溪洞地为隆、兑二州；原文只载行政建置，不载本段武装夺取。原文定位：`P0209`。
- 朝廷置保寿粹和馆收养患病宫人；又焚毁苑东门所储“可以杀人”之药，并禁止再贡。原文定位：`P0210`、`P0211`。
- 诸路在京应役士兵被统一规定十月初一遣归，反映京师轮役的阶段性解除。原文定位：`P0218`。
- 女真军制方面，部民平时无徭役，壮者皆兵，战时武器和糗粮自备；明安、穆昆分别为千夫长、百夫长性质的军政编制。该制度是后续判断女真战争动员成本的重要非战斗背景。原文定位：`P0223`。
- 广南市舶司被要求每年固定进贡真珠、犀角、象牙，外贸系统承担宫廷贡物任务。原文定位：`P0233`。

## 二、政治秩序、外交与人口社会变化

- 陈瓘《尊尧集》因批评绍圣史官和王安石《日录》被禁毁；陈瓘本人遭勒停、台州羁管、兵甲押送、持续监视和搜检，后地方官甚至以狱具胁迫。原文定位：`P0007`、`P0025`、`P0036`、`P0050`。
- 童贯借贺辽生辰使身份赴辽窥察，宋方携带大量珍奇馈赠，辽主亦厚遗童贯。返程后辽人马植随童贯入宋，提出联结女真夹攻辽、取燕云之策；徽宗最终接受其基本判断，“图燕之议自此始”，但本卷尚未实际出兵。原文定位：`P0037`—`P0038`、`P0052`—`P0053`。
- 辽东北路官萧乌纳长期观察女真后上书称其“志非小”，主张先发制人，多次上奏均未被采纳。原文定位：`P0051`。
- 辽主在头鱼宴上因阿骨打拒舞而一度考虑借边事诛杀，萧奉先以女真“小国”不足为虑劝止；这一轻敌判断成为辽—女真关系恶化的政治背景。原文定位：`P0060`。
- 蔡京专政后大量通过“御笔手诏”绕过中书、门下议令程序，违者以违制论，甚至出现内侍杨球代书的“书杨”，使贵戚近臣得以借御笔推动私请。原文定位：`P0074`。
- 政和二年更定官名、机构和武阶，但原文同时批评“员既滥冗，名且紊杂”，甚至道士亦滥入朝品，元丰官制因而大坏。原文定位：`P0084`—`P0085`。
- 崇恩皇太后刘氏因被认为干预外事且行为失谨，徽宗与辅臣议废；其后在左右逼迫下自缢。原文定位：`P0116`。
- 阿骨打率五百骑突然抵辽咸州，引发吏民惊惧；次日与赵三等当庭争辩后逃走，自此辽廷再召不至。本段有武装随从和政治对抗，但未载攻击、死伤或争夺军政节点，故不单列战役卡。原文定位：`P0126`。
- 辽主欲以严刑威众，李洪以“左道聚众为乱”后被支解并分示五京；原文没有可确认的武装交战过程。原文定位：`P0137`。
- 学校治理暴露基层行政失灵：尚书省称部分县学学生斗殴争讼甚至杀人，原因被归于令佐、州学和提举官放任不治，朝廷因此另立整饬法。原文定位：`P0147`。
- 辽知枢密院事耶律俨死后，萧奉先荐其侄李处温为相；原文称李处温“贪污尤甚”，所接引多为小人，显示辽中枢用人和廉政继续恶化。原文定位：`P0183`。
- 女真对辽的不满有明确社会经济背景：辽主长期遣使经生女真地区索取海东青，辽使“贪纵，征索无艺”，女真“厌苦之”；乌雅舒、阿骨打又反复要求辽交还阿苏而被拒。到政和四年，阿骨打开始整备城堡、军器并确认辽宁江州实际兵力，本卷随后进入正式战争阶段。原文定位：`P0213`。
- 辽因女真威胁已显而仍存在明显决策迟缓：宁江州失陷前，辽主在庆州射鹿，对前线急报仅遣海州刺史高仙寿率渤海军救援；出河店大败后，萧奉先又为兄萧嗣先开脱，主张赦免溃军，形成“战则有死无功，退则有生无罪”的军心后效。具体战果及损失见战役 JSON。原文定位：`P0222`、`P0227`。

## 三、跨卷连续性

- 向前承卷090：卷090已经出现辽因珠鹰征索压迫女真、女真对辽积怨加深，以及宋廷开始酝酿利用辽衰取燕的背景。本卷把两条线推进到实质转折：宋仍停留在战略谋议，女真则由部族整合转入正式伐辽。
- 女真—辽线：本卷末已形成“旁近部族整合 → 宁江州首战与攻城 → 出河店歼破辽援军 → 斡论泺再袭 → 宾、咸、祥三州及铁骊降附”的连续父链；阿骨打尚未在本卷称帝。卷092需继续核1115年建国、辽东北控制崩解范围以及这些新降地区的保持情况。
- 宋夏线：定远遭西夏万人围攻而未见城陷，但李阿雅卜率部万余人归夏，西夏又筑臧底河城，宋随即命童贯为陕西经略使讨之；后续军事反击和控制结果留待卷092核验。
- 财政民生线：方田在本卷已经因贿赂、豪右转嫁赋役、下户流徙和常赋亏额而被权罢；茶场岁入与固定月进、宫室和宗教工程则继续扩张。后卷需观察这些汲取和工程是否继续加重。
