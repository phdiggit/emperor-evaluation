## 一、财政、民生、工程与灾害

- 建隆元年正月，汴京高度依赖漕运。此前每年调丁夫疏浚河渠，口粮由民自备；宋廷改为由官府供给，并因河北丰收谷贱而提高官籴价格。这同时减少河役期间民户自备粮负担，并以较高收购价吸纳河北余粮。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0012`“糗粮皆民自僃；丁未，詔悉從官給”“命高其價以糴之”。
- 正月，朝廷遣使分赴诸州赈济。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0017`“遣使分賑諸州”。
- 三月，宿州大火焚毁民居一万余区，朝廷遣中使安抚。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0040`“燔民廬舍萬餘區，遣中使安撫之”。
- 平定泽州后，宋廷免泽州当年田租。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0068`“免澤州今年田租”。
- 平定潞州后，宋廷免潞州城周三十里当年田租，录用阵亡将校子孙，并给参战丁夫三年复除。该条反映战后税役减免与军民抚恤，不计入战役本身的收益。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0070`“免附潞三十里今年田租，錄陣歿將校子孫，丁夫給復三年”。
- 九月，朝廷制作新权衡并颁行天下，禁止私造，属于度量衡统一。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0093`“作新權衡，頒於天下，禁私造者”。
- 吴越开始实行酒类专卖。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0107`“吳越始榷酒酤”。
- 十月，黄河先后在棣州厌次县、滑州灵河县决口，形成跨州河患；该事项向卷002承接。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0109`“河決棣州猒次縣，又決滑州靈河縣”。
- 荆罕儒任泰州时掌握煮盐之利，“岁入巨万”；朝廷允许其十取其八，但其散财养士仍“不足”。这是边将以地方盐利维持私人/军政网络的财政线索。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0111`“有煮鹽之利，歲入鉅萬，詔聽十收其八，用猶不足”。
- 扬州攻取后，宋廷向城中居民按人口给米，十岁以下减半；被胁迫编入军队者给衣履遣还，李重进家属、部曲亦获释罪。这是战后即时赈济和复员政策。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0114`“賑揚州城中民，人米一斛，十歲以下半之”“脅隸爲軍者，賜衣屨遣還”。
- 扬州经历兵火后“阖境凋敝”，李处耘权知扬州，采取勤于抚绥、轻徭薄赋的恢复政策，原文称“扬州遂安”。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0117`“兵火之餘，闔境凋敝”“輕徭薄賦，揚州遂安”。
- 宋初制作“受命宝”，并铸“宋通元宝”钱，属于新政权货币与国家象征建设。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0122`“初作受命寶。鑄宋通元寶錢”。

## 二、政治秩序、外交与人口变化

- 宋建国后追赠韩通中书令并礼葬；赵匡胤虽愤怒王彦升擅杀，但因开国之初暂不治罪。该条显示新政权对前朝死节者与本方擅杀将领的差别处置。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0013`。
- 宋向南唐发诏，并放还后周时期的江南降将周成等三十四人。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0014`、`P0016`。
- 新朝对石守信、高怀德、张令铎、王审琦等宿卫将领大幅进官进爵，同时继续以韩令坤、慕容延钊等掌兵；北边原有将领在政权更替后接受宋命。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0015`、`P0019`。
- 宋继续祭祀后周宗庙、陵寝，并规定按时朝拜，体现政权更替后的礼制承接。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0018`。
- 赵普因佐命升右谏议大夫、枢密直学士；刘熙古、吕余庆、沈义伦等原宋州幕府成员亦被召入中央。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0021`。
- 宋定宗庙四亲制度、五享、祫禘等礼制；二月尊杜氏为皇太后，杜太后以“为君难”告诫赵匡胤。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0025`、`P0029`。
- 宋优礼后周范质、王溥、魏仁浦三相，但原有宰相坐而议政的制度因三相主动改为具札进呈而废，政务奏议方式发生变化。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0030`、`P0031`。
- 钱俶由天下兵马都元帅进为天下兵马大元帅；吴越、南唐持续遣使祝贺宋帝登极、长春节。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0032`、`P0037`、`P0039`。
- 宋初科举由扈蒙主持，本次取杨砺等十九人，自此形成按年贡举的常例。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0034`“自是歲以爲常”。
- 南汉宦官陈延寿以先帝杀诸弟作为刘鋹得立的理由，刘鋹遂杀其弟桂王璇兴，显示南汉皇室安全高度依赖内部清洗。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0038`。
- 宋追尊四代祖考并确定庙号、陵号，又定承周木德而以火德王、尚赤，完成新王朝正统礼制建构。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0041`、`P0042`。
- 王彦升夜至宰相王溥私第求货，王溥密奏后，赵匡胤将王彦升外放唐州团练使，同时把唐州由刺史州升为团练州。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0047`。
- 西京周六庙建成，宋遣郭玘奉迁神主；杨承信来朝后，宋廷设宴，此后成为朝觐惯例。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0062`、`P0063`。
- 李筠平定后，其性暴而事母孝的轶事被追述；北汉赵华因先前反对援助李筠而获准请老终身食禄，赵宏入相。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0071`、`P0072`。
- 被俘的北汉宰相卫融拒绝背弃刘氏，赵匡胤先怒而击伤，后又称其忠臣、疗伤并使其致书北汉；北汉不接受宋方要求，宋最终任卫融太府卿。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0076`。
- 辽政事令耶律寿远、太尉库阿布等因谋反被诛；该事件未出现军队调动或武装争夺，属于政治清洗而非战役。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0079`。
- 成德节度使郭崇因追念周室而被监军密奏，宋廷遣使察访后确认“无它”，未以疑反直接处置。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0081`。
- 昝居润权知镇州，原文明确称“初以知州易方镇也”，是宋初以文官/中央任命知州替代藩镇权力的制度节点。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0082`。
- 宋整编殿前、侍卫两司与各州兵，抽选骁勇补禁军，并立更戍法，使将领不得专兵、军士轮换边城。这是新朝收兵权、强化中央禁军控制的核心制度。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0084`。
- 宋恢复入阁仪、待制候对与廊下食等朝仪。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0085`。
- 袁彦在宋初“日夜缮甲治兵”，赵匡胤派潘美单骑入城劝其入朝，随后调离原镇；杨承信亦因被告谋反而经使者察访，确认无反状后得以终身守镇。两案均显示宋初对藩镇疑反采取“察访—调任/保留”的差异化处置。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0088`、`P0089`。
- 张永德针对北汉提出长期扰田、离间辽援、待其孤立后再图的战略，赵匡胤认可；此处是战略讨论，未形成当卷战役。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0090`。
- 赵匡胤立王氏为皇后；赵普因泽潞平叛后论功升兵部侍郎、枢密使。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0092`、`P0094`。

- 辽穆宗嗜杀，因小故杀近侍古格，此后多名内侍及供役人员“以非罪死”。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0097`。
- 文臣赵行逢在泽潞亲征时畏险诈伤、留怀州不行，班师后又称病求在私第草制，被御史追劾贬官。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0100`。
- 吴越因有人告吴延福有异图，钱俶派薛温率兵围其私第并收捕兄弟五人；其亲属吴延遇自杀。钱俶最终未杀吴延福兄弟，改为除名徙州。该案虽动用兵力，但没有形成对立武装、战斗或节点争夺，本卷按政治强制事件处理。原文定位：`SRC-XUZIZHITONGJIAN-001-2603334-P0104`。

## 三、跨卷连续性

- 向后：`P0109`棣州、滑州黄河决口在卷002出现直接后续，卷002七月记陈承昭堵塞棣、滑决河工程完成，应视为同一河患—河工链。
- 向后：`P0116`南唐因疆土蹙弱及宋军压力决定迁都，卷002开篇继续写李景定迁南昌、李从嘉守金陵及迁都后的役事、空间不足与群臣思归。
- 向后：宋初收兵权、以知州易方镇、更戍与禁军集中仍处制度展开阶段；卷002继续出现殿前都点检不再授、石守信等解除禁军实权等收束动作。
- 本卷两场主要内乱——李筠泽潞之乱、李重进扬州之乱——均在本卷形成军事终局；战后地方恢复政策已分别见 `P0068/P0070` 与 `P0114/P0117`，不向后卷倒灌战果。
