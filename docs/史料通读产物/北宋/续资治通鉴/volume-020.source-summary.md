## 三、跨卷连续性

- 向前：卷019末宋恢复李继迁官爵并给五州；卷020随即出现赵保吉“归顺”、绥银流民返乡和弟继瑗入谢，说明政策已进入和抚善后。但卷020 `P0019`又提供上年灵州之役十五万余关西民死亡这一重大追记，已在战役 JSON 作为同一父链的新成本证据处理。
- 向前：卷019的西北战争财政压力，在本卷的流民赈给、逋欠大规模清理、停止无名力役及边军长期馈饷中仍能看到恢复性政策，但这些项目没有简单归因于单一战役，故保持为非战役事实。
- 向后：辽已在 `P0036`告祭“来岁南伐”，何承矩到 `P0108`又报告辽有入边计划；本卷尚未发生实际南侵，卷021必须核是否转化为真实战役、兵力与控制后果。
- 向后：宋辽同时存在修和议论和坚守拒马河塘泊防务的双轨状态；卷021若开战，不得把本卷外交主张或敌情预警倒算成已发生战争收益／成本。
- 向后：赵保吉本卷仍处归顺、入谢阶段；卷021需核其是否再次侵边，以及卷019所授五州的实际控制、税源与人口恢复是否稳定。
