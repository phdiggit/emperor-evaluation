## 一、财政、民生、工程与灾害

- 景德三年正月始置常平仓。各州按户口从上供钱中留一千至二万贯为本，转运使择官管理、司农寺总领且三司不得移用；夏秋加价收籴、谷贵时减价出粜。大率万户岁籴万石、最多五万石；三年以上未粜的旧粟转粮廪并补新粟，十年有增羡再还三司本钱。原文定位：`P0002`、`P0003`。
- 丁谓等反对另设劝农判官，理由是会增加烦扰；改令知州、通判、转运使等兼领劝农职责，“劝农使”官衔由此开始。原文定位：`P0004`。
- 复置都大发运使；同年又把江淮每年输京漕米正式定额为六百万石，过去并无固定岁额。原文定位：`P0007`、`P0056`。
- 关右解盐弛禁后，旧卖盐年额仍分摊永兴、同、华、耀四州军。李士衡称永兴负担尤重，请减四成，真宗直接诏该项分摊全部免除。原文定位：`P0024`。
- 陕西军资原由内帑每年补钱三十万缗；李士衡任转运使后认为当地岁计可自办，遂停拨。他又献粟五十万斛、输京西三十万斛，因此被认为长于财计。原文定位：`P0025`。
- 真宗预备朝陵时，王旦称行宫损坏需修；真宗认为会“劳民”，于是只许修饰馆驿、不许新建行宫，并削减侍从百司与供御。原文定位：`P0041`。
- 景德四年朝陵沿途在中牟等地除逋负、释囚、赐父老衣币；亲祭诸陵后又对西京及诸路赦流罪以下、释逋欠、减畿县租税。原文定位：`P0062`、`P0063`。
- 西京罢榷酤，改用官卖曲制度。原文定位：`P0069`。
- 王旦指出转运使及酒税检举官竞以增加课利为功，造成“烦扰特甚”；真宗明确称官吏“贪劳绩，不恤民困”，遂以一年中等之数立为定额，禁止再议增课。原文定位：`P0083`。
- 闰月减剑、陇等三十九州军岁贡物，夔、驾等二十七州军全部罢贡，是本卷最大一组直接贡赋减负。原文定位：`P0091`。
- 初置杂卖场。原文定位：`P0090`。
- 丁谓统计景德三年新收户较咸平六年增加五十五万余，赋入增加三百四十六万余；朝廷决定以后以咸平六年户口赋入为基准，逐年比较并上史馆。原文定位：`P0106`。
- 八月丰收后菽麦价格很低、富民大量收蓄，朝廷从府库拨五十万贯给三司收买菽麦，以托住农价、惠及农民；同月诸路均报“大稔”。原文定位：`P0115`、`P0122`。
- 益州八月发生地震。原文定位：`P0114`。
- 本卷另记客星、日食、周伯星、太白昼见、五星同伏、庆云等多次天象；王济、张知白多次借“祥瑞”劝真宗以家给人足、居安虑危为真正上瑞。原文定位：`P0014`、`P0020`、`P0021`、`P0033`、`P0036`、`P0053`、`P0084`、`P0094`、`P0096`。
- 权三司使丁谓卷末上《景德会计录》六卷获奖，显示国家财政数据与会计文本开始更制度化汇编。原文定位：`P0121`。

## 二、政治秩序、外交与人口变化

- 澶渊和后，王钦若以“城下之盟”“孤注”贬低寇准，真宗对寇准眷顾由此下降；不久寇准罢相知陕州，王旦拜相，冯拯、王钦若、陈尧叟等进入枢密体系。原文定位：`P0009`、`P0011`、`P0013`。
- 寇准任相时偏用寒俊、御史多取敢言者，并拒绝照“例簿”机械用人，称宰相职责在进贤退不肖；张咏则借《霍光传》“不学无术”提醒其学术不足。原文定位：`P0010`、`P0012`。
- 任随批评谏官“充位尸禄”，主张定员、优俸、限迁并以言事实效奖惩；真宗嘉纳，并恢复群臣转对。原文定位：`P0014`、`P0019`。
- 遣六使巡抚益、利、梓、夔、福建等路，既犒将吏、问父老，也疏决系囚并察官吏能否与民间利害；谢涛举官三十余并愿连坐，奉使举吏连坐自此始。原文定位：`P0017`。
- 赵德明继续遣使修贡，宋夏誓约主要卡在回图贸易、青盐、质子等条件。朝廷已同意不要求归还灵州，并要求其不劫西路进奉、蕃部争竞交宋裁断；真宗因德明反复难信，对进一步让步仍较谨慎。原文定位：`P0022`。
- 秦翰、曹玮曾请求趁赵德明初立出兵擒灭，真宗因德明屡贡、恐失诚信而拒绝；这一“未执行”的进攻建议不计入战役。原文定位：`P0028`。
- 九月赵德明进誓表并请藏盟府；十月获授定难节度使兼侍中、西平王、给俸如内地。宋又赐银一万两、绢一万匹、钱二万贯、茶二万斤等；但要求子弟入质时，德明以非先世故事拒绝，只献驼马谢恩。原文定位：`P0047`、`P0050`、`P0051`。
- 黎桓死后交趾继承危机出现，有司请求宋军介入；真宗以黎桓素修职贡、不可“伐丧”为由拒绝，只遣沿海安抚使晓谕。后黎龙延遣弟入贡，宋授其静海节度使、交趾郡王，赐名至忠并给旌节。交趾实际内战过程另见战役 JSON。原文定位：`P0032`、`P0107`。
- 邵晔献邕州至交趾水陆路线及宜州山川图，真宗明确称祖宗疆土已广，“惟当慎守”，不应贪无用之地而劳兵。原文定位：`P0037`。
- 何承矩因老疾离雄州并荐李允则代任；其死后缘边乃至涿、易州民众皆哀悼。原文追记其熟戎事、善抚异俗，所谓“爱蓼花”实为经营塘泊水防的掩饰。原文定位：`P0046`。
- 真宗要求内臣班秩赏赐不得过分、有罪不贷；史崇贵出使后所举一贪一廉两名地方官，仍须转运使复核，不许仅凭内臣一句话直接赏罚。原文定位：`P0067`。
- 裴愈向交州使索示稀有龙花蕊并声称奉诏，真宗否认曾有宣索，命御史台劾问、把龙花蕊退还交州并贬裴愈。原文定位：`P0101`、`P0102`。
- 王旦在弟王旭任用上反复避嫌，真宗则称朝廷用才不可因宰相亲属而使其淹滞；王旦又坚持任中正继张咏治理益州，任中正五年遵旧规而“人甚便之”。原文定位：`P0034`、`P0035`。
- 中书与枢密院因重复差遣杨士元而建立“互报法”，凡涉及军机、民政之事必须相互通报。原文定位：`P0093`。
- 真宗改鼓司为登闻鼓院、登闻院为登闻检院并撤内臣管理，形成鼓院→检院→邀车驾→御史台的递进申诉路径；同时他又以无效词状过多为由收束面奏程序。原文定位：`P0086`、`P0087`。
- 此前限制无名札子与非公事面奏已产生反作用：戚纶称疏远之人难以面奏，王旦也直言“近日论利害者差少”；王钦若反主张严格追究违规章疏。原文定位：`P0118`。
- 复置诸路提点刑狱官，以使臣副之，要求巡察囚禁、审详案牒并奏劾贪浊弛慢官员。原文定位：`P0110`。
- 诏翰林画工分赴诸路绘山川形势、地理远近，交枢密院供发兵屯戍与移徙租赋时检阅；这是军事与财政行政共同依赖的地理信息建设。原文定位：`P0109`。
- 置群牧制置使，由陈尧叟兼领，随后增判官一员，马政机构进一步专门化。原文定位：`P0111`。
- 汀州黥卒王捷所称“真君”被认定为“圣祖”，原文明言“祥瑞之事起矣”；其后五星同伏、庆云等继续被送史馆，祥瑞政治由此成为新线索。原文定位：`P0088`、`P0094`、`P0096`。
- 修史制度继续扩张：王钦若、陈尧叟同修《时政记》，后又诏修太祖、太宗正史，王旦监修；另置龙图阁直学士。原文定位：`P0023`、`P0119`、`P0120`。
- 皇后郭氏去世。原文强调其谦约戒奢、不为族属求恩、不肯进入国库观宝受赐；庄穆皇后其后葬永熙陵西北并祔别庙。原文定位：`P0082`、`P0095`、`P0100`。
- 科举与文教方面，真宗明确要求贤良方正策问“经义参时务”，以识别实际治事能力；孔子守茔增二十户，孔圣佑获同学究出身，邢昺以侍讲学士身份外任知曹州。原文定位：`P0092`、`P0089`、`P0116`、`P0117`。
- 辽在七金山土河开始营建中京；这是大型都城建设，但本卷没有给出劳役、财政或施工人数，不能凭“建都”二字推定高成本。原文定位：`P0064`。
- 辽廷对皇太妃集团继续清洗：先幽禁皇太妃与夫人、余党生瘗，景德四年六月又令皇太妃死于幽所。这是宫廷政治清洗，不进入战争成本账。原文定位：`P0030`、`P0099`。

## 三、跨卷连续性

- 向前：卷025已完成澶渊停战、首年岁币和河北大规模复员；卷026重点转入战后财政复常、常平仓与减赋，同时寇准因澶渊政治评价变化而罢相。赵德明在卷025仅初次正式入贡，本卷则推进到誓表、册封和厚赐。
- 向后：常平仓、六百万石漕额、课利定额、岁贡减免、官收菽麦等财政民生制度已形成；另一方面，“圣祖”祥瑞叙事刚开始，限制无名札子后的言路收缩已被王旦点出。宜州陈进据城后的宋军进讨尚未在本卷发生实际战斗，后续战役结果需卷027继续核验，详见本卷战役 JSON 的 `carry_out`。
