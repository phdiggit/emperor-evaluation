## 一、财政、民生、工程与灾害

- **古渭寨买马场每年耗费十余万缗，被直接撤销。** 韩琦指出古渭寨买马会场“凡岁用缗钱十余万，实耗国用”，朝廷恢复永宁寨旧场，蕃部马改直接赴秦州出售。原文定位：`SRC-XUZIZHITONGJIAN-061-2311112-P0006`。

- **仁宗晚年宫廷自奉仍有明确节用材料。** 仁宗病中所用幄席、裀褥“质素暗弊，久而不易”，并向韩琦等直言“此亦生民之膏血也，可轻费之哉”。原文定位：`P0012`。

- **仁宗去世后，山陵与新朝赏赉立即形成巨额财政支出。** 三司请出内藏库钱**一百五十万贯**、绸绢**二百五十万匹**、银**五万两**，用于山陵及赏赉，获准。原文定位：`P0026`。

- **赏军支出已向地方财政和民间转嫁。** 司马光称国家用度本已窘迫，大丧后“累世所藏，几乎扫地”，部分州军官库无钱，甚至“借贷民钱以供赏给，一朝取办，逼以棰楚”；郑獬又称近来赏军已见“横敛”，富室嗟怨。原文定位：`P0036`、`P0046`。

- **山陵直接征发诸路卒四万六千余人。** 原文定位：`P0040`“發諸路卒四萬六千餘人修奉山陵”。

- **山陵规模在“从俭”争论后只得到有限压缩。** 王陶、吴充、楚建中、田棐、苏洵等要求遵仁宗遗诏从俭、屏去金玉珍宝；最终仅削减乾兴时新增明器，其余仍大体沿用永定陵制度。原文定位：`P0045`。

- **“官给、勿扰民”的诏令没有消除实际役负。** 五月诏山陵钱物从官给、不得扰民，但原文紧接“调役未尝损”。三司又估计山陵需钱粮**五十万贯石**而无法备足，一度欲改变陕西缘边入中盐安排；薛向提出五不可并承担相应筹措。原文定位：`P0060`。

- **山陵供亿存在数倍超调和大量闲置。** 韩琦发现诸顿所调物过多，命楚建中专门裁量；原文称蔡襄总应奉时“凡调度供亿皆数倍，劳费既广，已而多不用”。原文定位：`P0075`。

- **山陵结束后出现针对役户和沿途居民的直接减免。** 东、西二京罪囚减一等，山陵役户及灵驾所过居民免租。原文定位：`P0110`。

- **郑州因灵驾经过获得额外公使钱五百贯。** 原文定位：`P0062`。

- **仁宗祔庙同时带来太庙扩建。** 朝廷最终保留僖祖、增太庙为八室，蔡襄又请将庙室及夹室扩为**十八间**，获准。原文定位：`P0066`—`P0069`。

- **地方官亲属进贺表一律推恩被批评为滥官，但本卷未改。** 司马光、郑獬认为爵禄应给贤才与有功者，建议收紧进表亲属授官；执政以诏令已行难改为由搁置。原文定位：`P0078`。

- **辽在本卷有直接金属流通管制。** 辽禁止民间卖铜。原文定位：`P0008`。

## 二、政治秩序、外交与人口变化

- **仁宗二月起病，先以减刑应对。** 天下囚罪降一等，徒刑以下释放；其后旧医久治无效，孙兆、单驤被特召诊脉，宋安道等医官遭问责。原文定位：`P0009`、`P0013`—`P0016`。

- **仁宗三月晦夜间猝崩，皇后先控制宫门与信息流。** 皇后拒绝夜开宫门，只密谕辅臣黎明入禁中，并控制医官进出；次日由皇后、辅臣共同召皇子、披御服，召殿前马步军高级将领与宗室入殿，完成遗制与即位程序。原文定位：`P0020`—`P0022`。

- **新君即位初出现禁卫赏赐传言，但未形成兵变。** 禁卫传言乾兴旧例赐食中藏金，发现无金后纷纷议论；李璋以“敢喧者斩”压下。没有持兵起事、争夺军政节点或武装死伤，故不进战争账。原文定位：`P0023`。

- **公卿子弟幼年授官的待遇开始按实际任职计算。** 王端请服色等奖励自真正莅职日起算，遂著为令。原文定位：`P0024`。

- **英宗即位数日后突发严重精神与身体异常，直接改变最高权力运作。** 他一度“不知人，语言失次”，仁宗大敛时又“号呼狂走”，韩琦入帘抱持；朝廷遂请曹太后权同处分，形成太后垂帘、中书枢密奏政制度。原文定位：`P0031`、`P0033`。

- **病中政务实际采取“两府先见帝、再奏太后”的双重结构。** 太后内东门小殿垂帘，两府先候问英宗、奏军国事，再向太后覆奏；王珪一度草还政书但未实行。六月英宗复病不出时，这一结构再次恢复。原文定位：`P0035`、`P0043`、`P0065`。

- **司马光在摄政初期明确要求曹太后自抑礼数、至公用人并待英宗康复后还政。** 原文定位：`P0038`。

- **英宗初政的继统礼法已开始争论。** 司马光要求年中不改元、宫禁音乐宴游尽量守三年丧，并主张英宗既为仁宗之后，就不应追尊本生祖父母，以免“大宗、小宗”混淆。原文定位：`P0049`—`P0054`。

- **高氏被正式立为皇后。** 她是曹太后外甥女，幼年曾与英宗同育禁中，仁宗早有配婚之意。原文定位：`P0056`。

- **内侍都知人数一度增至五人，随后明确不再补足。** 石全育加入后，诏以后有缺不补。原文定位：`P0057`。

- **英宗疾病与宦官不满共同造成两宫嫌隙。** 原文明确说英宗因忧疑得疾、举措失常且对宦官少恩，左右多不悦，遂“共为谗间”，曹太后与英宗之间由此生隙；韩琦公开拒信宫中夸大的过失传言。原文定位：`P0073`—`P0074`。

- **七月英宗终于重新御紫宸殿。** 自六月停朝后，此时始见百官；其后只日前殿、双日后殿，至仁宗祔庙后才恢复旧制。原文定位：`P0079`。

- **宋夏名号和入对礼持续摩擦，但仍停留在外交层面。** 谅祚进奉人使用拟宋制官号被责，后来表章又改姓李；夏使来吊仁宗时固求入对未获准。原文定位：`P0004`、`P0080`。

- **宋辽在国丧、即位阶段保持外交连续。** 宋遣使告哀；辽贺节使恰逢国丧仍获准进书祭奠，后另遣使祭仁宗、贺英宗即位。周沆还从辽使口中探得辽主年龄。原文定位：`P0025`、`P0034`、`P0081`、`P0112`。

- **人君日常细务是否应亲决成为明确的行政分权议题。** 司马光提出皇帝应集中精力于任官、赏功、刑罪三职，胥吏鞭罚、厢镇补授、军人武艺、国马刍秣等细务交有司，以免政务过碎。原文定位：`P0093`—`P0094`。

- **英宗虽恢复视朝，仍被王畴批评长期少决大政。** 王畴称半年以来“未闻开发听断”，要求日与二府讲评国论、明确可否。原文定位：`P0101`。

- **仁宗葬永昭陵并祔太庙，丧礼制度同时调整。** 本卷议定仁宗谥“神文圣武明孝”、庙号仁宗；英宗又首次依吕夏卿议行“卒哭”，王曾、吕夷简、曹玮配享仁宗庙庭。原文定位：`P0091`、`P0098`、`P0104`、`P0108`—`P0109`。

- **两宫矛盾在仁宗葬后仍未结束。** 曹太后把记录英宗病中过失的文书交韩琦，韩琦当使者面焚毁并称皆疾病所致；欧阳修也劝太后包容。另一面英宗称“太后待我无恩”，韩琦以舜孝反劝，英宗以后不再公开言太后之短。原文定位：`P0117`—`P0118`。

- **司马光、吕诲把限制病中信息上闻作为修复两宫关系的手段。** 司马光建议精择一二医工，并严戒左右不得把英宗病中失常言语一一报太后；同时劝英宗病愈后亲往太后阁谢过。吕诲也要求两宫去除“间言”，并请早建东宫。原文定位：`P0114`—`P0116`。

- **经筵最终没有因寒暑和丧期长期停废。** 司马光劝英宗帝王以学为首务，十二月迩英阁开讲《论语》、读《史记》；吕公著、刘敞借修德、孝友之义进行劝谏，英宗改容，曹太后闻之亦喜。原文定位：`P0119`—`P0120`。

- **淮阳王頊正式出阁，此后每日两次入朝。** 原文定位：`P0121`。

- **修史、藏书继续推进。** 仁宗御书藏宝文阁；王珪、贾黯、范镇奉命撰《仁宗实录》，宋敏求、吕夏卿、韩维为检讨官。原文定位：`P0122`—`P0123`。

- **辽西北路在本卷末出现非战斗性的军政整顿成效。** 萧珠泽复任招讨使后训练士卒、增器械、省追呼、严号令，原文称“边境晏然”；这是军政整顿后效，不是本卷新战役。原文定位：`P0124`。

## 三、跨卷连续性

- **向前：** 卷060末赵曙已被正式立为皇子并入宫，本卷三月仁宗骤崩后完成皇位交接；卷060还只是政治渗透的辽重元集团，本卷则正式转入武装阶段，具体裁决全部置于战役 JSON。
- **向后：** 英宗虽已恢复前后殿和经筵，但疾病及与曹太后的嫌隙仍未完全解决；卷062需继续核太后是否还政、皇帝是否真正亲决。
- **向后：** 山陵本卷已完成葬、祔庙并对役户、沿途居民减免，但巨额内藏支出、地方借民钱和超调供亿已经发生，不能因事后减租反向抹去本卷成本。
- **向后：** 辽重元集团的武装阶段已被平定，后续清洗、封赏与边防整顿不再倒灌为战斗人员损失；如后卷没有同一余党复起，安全收益维持本卷裁决。
