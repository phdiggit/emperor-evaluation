## 一、财政、民生、工程与灾害

- **仁宗年初暴病期间即有灾税蠲免。** 正月大赦，同时蠲免被灾田租及倚阁税；又罢上元张灯。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0008`、`P0009`。

- **六塔河在卷055发三十万丁后很快“复决”。** 嘉祐元年四月正文只用一句记“六塔河复决”，直接证明前卷的大规模回河工程未形成稳定结果。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0029`。

- **延州城防工程在暑热中以强制方式推进。** 夏安期到任后见州东北阻山无城、存在骑兵乘隙风险，立即大筑城；士卒因暑热有怨言，他不仅扩建数百步，还下令“敢有一言动众者斩”，亲自督役，不到一月筑成、周长六里。此段无当前接战，属于防御工程与军役负担。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0037`。

- **辽补充边戍军籍。** 六月命有司“籍军补边戍”，是新朝边防人力补充，但正文未给人数。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0040`。

- **嘉祐元年京师及诸路发生大规模洪灾，河北尤重。** 京师自五月大雨不止，水漫安上门并折门关，毁官私庐舍**数万区**，城中需系筏渡人；诸路江河也决溢，河北“民多流亡”。朝廷命辅臣分行诸门、诸地赈救。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0047`。

- **灾中城市管制也考虑到民众恐慌与通行。** 马军都指挥使范恪奉诏欲障朱雀门，知开封府王素以仁宗不豫、军民庐舍多覆压为由制止，认为封门会“惑众”，并妨碍后来者入城。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0047`。

- **洪灾触发多层次赈贷、安置与蠲税。** 七月命京东、西、荆湖北路转运使、提点刑狱分行赈贷；漂荡庐舍者可寄居寺院、官屋；另遣官体量减免当年税，已经倚阁者不再重复检覆。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0053`。

- **河北灾民获得按人、按死亡家庭的定额救助。** 因水灾迁往他处者每人给米**五斗**；压溺死者，其父、母、妻各赐钱**三千**，其余亲属**二千**。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0055`。

- **内藏再次直接用于河北赈灾。** 七月出内藏库银绢**三十万**赈贷河北；随后又贷被水灾民麦种，用于恢复生产。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0060`、`P0063`。

- **辽地方巡行把税负、农业、军备与治安一起处理。** 道宗遣使分道“平赋税，缮戎器，劝农桑，禁盗贼”。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0054`。

- **辽南京同时出现蝗蝻灾。** 原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0049`。

- **张方平在蜀直接削减战后横赋与铸钱负担。** 原文称“自西鄙用兵，两蜀多所调发”，张方平在益州奏免横赋**四十万贯匹**，又减兴、嘉、邛州铸钱**十余万**，蜀人“便之”。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0071`。

- **京师粮储一度显著下滑。** 张方平早年主计时京师有**三年粮**、马粟又倍之；到本卷时“马粟仅足一岁，而粮亦减半”。他认为京师无山河险固，只能依重兵，而兵粮完全依赖汴河漕运。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0072`。

- **长期以“省役省费”为功导致汴河淤塞。** 天圣以前每年发民浚汴，后因疏导京东积水而停汴夫，此后又不断以裁减费役为政绩，张方平称河道遂日益湮塞。此处同时展示了“减役”与基础设施维护之间的真实权衡。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0072`。

- **漕运十四策很快改善首都储备。** 张方平提出十四策，富弼称为“国计之大本”，朝廷全部按其建议施行；原文称不到一年，京师已有**五年之蓄**。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0072`。

- **河北一边赈灾，一边仍需维持大额军储。** 十月出内藏库银**十万两**、绢**二十万匹**、钱**十万贯**下河北市籴军储。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0087`。

- **包拯处理京师水患时直接拆除权贵侵河建筑。** 他发现中官、势族园榭多跨惠民河，导致河道壅塞，遂悉数拆除；持地券自辩者若有虚增步数，也审验后弹劾。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0105`。

- **灾异仍密集出现。** 年初有大雨雪、木冰；客星自至和元年五月至嘉祐元年三月才没；七月彗星出紫微垣，八月日食；嘉祐二年雄、霸州地震，辽南京同年七月也地震并赦境内。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0013`、`P0020`、`P0064`、`P0065`、`P0122`、`P0145`。

- **辽货币继续扩展。** 原文追述圣宗时铸太平钱、新旧互用，开泰中官钱充足到春秋可用官钱宴将士；本卷始行东京所铸钱。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0027`。

## 二、君主健康、中枢应急与继承

- **仁宗正月初一大朝会突发严重风眩。** 前夜大雪，仁宗跣足祷天；次日百官就列时暴感风眩，冠冕欹侧、口涎外出，稍愈后勉强行礼即罢。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0002`。

- **病中最先暴露的是禁中信息控制。** 辽使辞行时仁宗再次发病，史志聪等以禁中事不得泄为由拒告病情，文彦博怒斥并命其到中书受军令，此后皇帝病势增损必须报告宰相，皇城闭锁也须向宰相申报。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0004`。

- **仁宗一度不能省事，两府以非常方式维持政务。** 两府自行议定政事、称诏施行；为获得留宿禁中名义，文彦博、富弼以大庆殿设醮祈福、两府监醮为由昼夜留宿。史志聪称无此故事，文彦博答“此岂论故事时邪”。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0005`。

- **两府进一步取得直接入寝殿奏事权。** 富弼以“宰相安可一日不见天子”迫使内侍让步，两府始入福宁殿卧内奏事。仁宗病势稍缓后逐步恢复视朝，二月已御延和殿，百官称贺。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0006`、`P0007`、`P0017`。

- **病中曾出现虚假谋变告发。** 禁卒告都虞候欲变，文彦博先询问被告平素，判断为挟怨诬告，反斩告发者以靖众；刘沆后来想以此攻击文彦博，文彦博出示由刘沆亲署的判状才释疑。正文未见真实武装叛乱，故不进入战争账。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0012`。

- **仁宗病中一度实际同意早立嗣。** 文彦博、刘沆、富弼劝早立嗣，仁宗“可之”；因宗实幼养宫中、皇帝皇后视如己子，宰执遂定议立宗实并拟好章稿，但未及进呈，仁宗病情好转，事情中止。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0034`。

- **立储由范镇、司马光等持续推进。** 范镇主张从近族择最贤者置左右并参与政务；赵抃、司马光、欧阳修、吴奎、吕景初又先后从宗庙、社稷、人心与防邪谋角度要求择宗室贤者。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0035`、`P0041`、`P0045`、`P0056`—`P0058`。

- **洪灾、彗星和日食被反复用于催促立储。** 范镇把宗庙“承祧”与水灾相连，又以彗星白色、七星主兵催皇帝速决；司马光多次上疏。范镇至十一月前后上章**十九次**、待罪近百日、须发尽白，仁宗虽哭称“朕知卿言是也”，仍说再等二三年，范镇遂辞言职。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0051`、`P0066`、`P0069`、`P0082`、`P0091`。

- **杜衍临终遗疏也把立储列为国政要务。** 其遗疏只谈“无以久安而忽边防，无以既富而轻财用，宜早建储副以安人心”，不及私事。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0119`。

## 三、政治秩序、言路与官僚制度

- **仁宗病后逐步恢复群臣上殿。** 病中一度只有两府得奏事；七月才恢复三司、开封府、台谏、审刑院上殿，并日引一班。此前张昪已指责中书拖延台谏上殿请求。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0043`、`P0052`。

- **狄青出枢密主要源于军望与政治安全忧惧，而非真实叛乱。** 欧阳修、吕景初、刘敞等先后指出狄青出自行伍、掌枢密且“得军情”，京城百姓每见其出入便聚观壅路；仁宗病后都人更注目。京师大水时狄青避水住相国寺殿上，舆论大哗，执政遂以熟状出判陈州。正文没有狄青谋反或举兵事实，故不进入战争账。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0056`、`P0059`、`P0070`。

- **台谏与刘沆冲突最终导致刘沆罢相。** 原文称刘沆“深疾言事官”，借御史满三年外任之格将曾攻其短的范师道、赵抃外放；张昪等称其“挟私出御史”。后张昪等前后上章十七次，刘沆自请外守，十二月罢相。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0085`、`P0101`、`P0102`。

- **张昪把“皇帝孤立”反指为官僚持禄养交。** 仁宗称张昪“孤立”，张昪答自己仰托圣主并不孤，真正孤立的是皇帝，因为“持禄养交者多，忠心谋国者少”，仁宗为之感动。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0103`。

- **包拯降低开封府诉讼门槛。** 旧制诉者不得径至庭下，由府吏坐门先收状牒，称“牌司”；包拯开正门，让当事人直接到庭自陈曲直，减少吏胥欺蔽。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0105`。

- **大臣为子弟亲旧求科名被禁止。** 八月诏大臣不得再为子弟、亲旧乞赐进士出身。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0068`。

- **胡宿荐官坚持把候选人的小过也如实上报。** 一名候选人因河北水灾亏课，胡宿仍将此事说明并称其才可惜；仁宗答“果得才，小累何恤”，予以任用。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0075`。

- **王尧臣入执政后执行亲属回避。** 王洙、刘敞分别为其从父、姑子，均因王尧臣执政而调整职任；程戡与文彦博为姻家，也从参知政事改枢密副使。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0022`、`P0024`。

- **范师道把补摄官从吏胥随意处置改为按籍次第。** 旧制完全委吏胥，无先后远近之差，范师道任广南东路转运使后开始置籍排序。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0129`。

- **转运使、提刑考课最后没有形成升黜。** 张旭提出选用、责任、考课三法，朝廷命孙抃、张昪磨勘转运使、提点刑狱课绩，但原文收束为“卒亦无所进退”。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0147`。

## 四、礼乐、教育、科举、外交与辽政

- **新乐技术问题被重新揭出并暂时回退。** 李照新乐被指音太浊，歌工甚至私赂铸工减少铜配比才稍清；古编钟反与王朴旧钟音、侧垂形制相合。范镇又以日食、星变、冬雷秋电及仁宗元日发病为据请求复旧，仁宗最终令恭谢礼使用旧乐。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0076`—`P0078`。

- **欧阳修知贡举强力打击“太学体”。** 当时士子尚险怪奇涩之文，欧阳修痛加排抑；榜出后被士子聚众诋斥甚至投祭文于其家，但原文称文体自此改变。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0112`。

- **嘉祐二年开始出现“殿试者皆不落”。** 章衡等进士及第，同年进士与殿试者“始皆不落”；诸科及特奏名也获得相应出身、补官。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0124`。

- **制科因四年无人应试而放宽荐举渠道。** 仁宗认为可能待士不至，孙抃等建议太常博士以下、选人、草泽人可由待制以上奏举，草泽也可由转运使举；被举者行不副学则连坐举主，同时限制援旧例超擢。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0140`。

- **胡瑗太学教育法已经制度化。** 原文追述其湖州教授制度严密、盛暑仍公服坐堂、弟子常数百；庆历兴太学时直接取湖州法著为令，后其徒众多到太学不能容，并强调因材施教及衣服容止规范。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0107`。

- **辽司法一方面下放，史官信息权另一方面收紧。** 道宗令诸郡长吏与僚属共同决囚，强盗事实明确者可地方即决，以防久系瘐死；六月又取消史官直接参与朝议的旧制，改为问宰相后书。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0003`、`P0046`。

- **辽道宗开始重用耶律伊逊。** 原文追述伊逊从贫家牧羊子、文班吏、掌印与笔砚吏逐步受兴宗、仁懿皇后赏识；道宗即位后使同知点检司事，常召决疑，受委任自此始。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0021`。

- **辽宗室军政权继续重排。** 皇太叔重元升天下兵马大元帅，扎拉、尼噜古等宗王持续调整军政职位；萧阿喇与萧革同掌国政后因反对萧革谄谀不法而遭道宗厌恶、外放东京。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0096`、`P0100`、`P0123`、`P0143`。

- **宋辽御容交换出现礼序争执。** 辽再请宋帝御容，胡宿认为此前既已答应，不给会伤信；张昪使辽时则以兴宗为弟、宋帝如伯父之尊为由，要求辽先致新主画像，辽人无以答。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0125`。

- **高丽、准布、五国部长继续向辽朝贡。** 原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0042`、`P0044`、`P0114`。

- **西夏幼主宫廷发生连环杀戮，但正文不构成战役。** 密藏氏与李守贵、吃多已关系引发李守贵杀吃多已及密藏氏，随后谅祚母族鄂特彭又族杀李守贵、保养九岁的谅祚并以女妻之。此为宫廷/家族暴力，没有军队交战或区域武装争夺，故不进战争账。原文定位：`SRC-XUZIZHITONGJIAN-056-2605960-P0108`。

## 五、跨卷连续性

- **向前：** 卷055末六塔河发三十万丁施工，本卷四月即“复决”，构成明确工程后果；后续如继续修河、赔役、赈灾或问责，应沿工程财政链继续，不转入战役账。
- **向前：** 卷055遗留的下溪州事项在本卷只出现“招抚彭仕羲”和“彭仕羲未降”两条非战斗后续；实际武装链的连续性统一留在战争 JSON 中复核。
