## 一、财政、民生、工程与灾害

- **“宽恤民力”由设司转入全国调查。** 卷058三司已设宽恤民力司，本卷六月进一步遣官分行天下，专访可以宽恤民力的事项，说明减负议题开始由中枢机构走向地方信息收集。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0009`“遣官分行天下，访宽恤民力事”。

- **后宫经常性俸给因人数、请俸增长而重新定额。** 三司减省冗费所报告“比岁内人请俸倍多”，请求参照天圣初年嫔御以下人数设固定员额，仁宗批准。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0011`“比岁内人请俸倍多……著为定额”。

- **唐州垦殖形成完整的“水利—土地—农资—人口”正向链。** 当时全国人口增加、田野拓辟，而唐、邓间仍多旷土。知唐州赵尚宽反对废州或单纯以卒屯田，依召信臣故迹恢复**三大陂、一大渠**，灌田**万余顷**，又教民自开支渠数十；继而按人口授荒田、贷官钱买牛。三年后“废田尽为膏腴”，新增户口**万余户**，因此获留任。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0017`“复三大陂、一大渠，皆溉田万余顷”“贷民官钱买牛”“增户万余”。

- **陕西解盐面对西夏青盐低价竞争，采取降价并缩减过剩生产。** 薛向接掌解盐时，西夏青盐私贩价格低，而官售解盐价高、滞销；他先降官盐价格。盐池每年还要调畦夫数千人种盐，而库存已“支十年未售”，遂奏减盐工与生产规模，当时称便。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0021`“盐池岁调畦夫数千种盐，而盐支十年未售”“向奏损其数，当时便之”。

- **盐财政被直接接入马政。** 朝廷令薛向专领陕西监牧和买马，拟在原州、渭州、德顺军设场，并把陕西财赋、解盐交引与购马结合。欧阳修同时指出唐代旧牧地多已陷蕃或成为民田，主张优先调查河东、京西荒地，避免重新侵占既成民田。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0025`—`P0026`。

- **秦州券马成本高而品质仍差，朝廷改用解盐交引吸引蕃商供马。** 薛向称秦州券马连同道路费用，一匹“当钱数万”，仍只能取得中杂马；他请求在原、渭、德顺置场，以盐交引招蕃商出售良马**八千匹**，其中**三千匹**给沿边骑军、**五千匹**入群牧司，获准。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0027`。

- **范祥解盐法的财政效果被追认。** 包拯称范祥陕西盐法施行十年，每年使榷货务少支缗钱**四百万**，朝廷据此录用其子孙。此为对旧法财政效果的当时官方评价。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0040`“行之十年，岁减榷货务缗钱四百万”。

- **关中歉收、流民与均税丈量发生直接冲突。** 刘敞赴永兴前已称关中“岁比不登，民多流移”，请发仓赈济。到任后发现孙琳在河中以方田法丈量均税，百姓恐增租而砍伐桑柘；万泉一县丈量“近须一年乃毕”。后来河中果有**数万户**申诉增减不平。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0046`“民多流移”“百姓惊骇，各恐增起租税，因此斫伐桑柘”“凡数万户”。

- **均税执行还出现“均旧额”变成“生新税”的偏差。** 欧阳修指出卫州、通利军把民间冒佃田另立新税，背离朝廷只在既有税额内调轻重的原意，请免新生税数、远年虚数，并暂停尚未推行地区。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0046`“却生立税数配之，此非朝廷之意”。

- **包拯把供上物的地方科率改为市场和买。** 包拯掌三司后，发现诸管库供上物旧由外郡科率，长期困民，遂专设场和市，使民免于强制供输；同时释放因负官钱帛官吏逃亡而被械系的妻子家属。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0064`“旧皆科率外郡，积以困民。拯特置场和市，民得无扰”。

- **侬智高战争的遗属与流落家口仍在善后。** 岭南官吏死于侬智高之乱而家属流落、不能自行归乡者，由所在地供给食物并护送返乡。此为战争后社会救济，不再计入本卷战役阶段成本。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0065`“所在给食护送还乡”。

- **泗州淮水泛滥，随后淮南、江、浙水灾触发蠲税。** 七月先记泗州淮水溢，次日即下令对淮南、江、浙水灾差官体量并减免赋税。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0095`—`P0096`。

- **均税由多人“详定”进一步转入条约、监司执行与绩效奖惩。** 吕景初、司马光相继参与详定；司马光立条约下诸路监司，并要求按执行结果奖惩，举秦植均德州五县税而“并无词诉”为正例。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0073`、`P0100`。

- **河北军储再次动用内藏。** 七月出内藏库绢**二十万匹**下河北助籴军储。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0102`。

- **大规模拣军的家庭与服役成本被司马光直接指出。** 他称京城被选兵“往往咨嗟悲怨，父子相泣”，外方兵士还须远离乡里、诀别亲戚，因此主张以后“大段招拣”须由两府共同衡量财用丰耗与事势缓急。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0105`。

- **苏辙制科策把宫廷赏赐与国家总负担并置。** 其称宫中贵姬“至以千数”、赐予无艺，而国家同时有养士、养兵与契丹、西夏之奉，认为“海内穷困，生民怨苦”。这是臣僚当时的财政政治批评，不等同于独立统计。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0112`。

- **灾异、民有菜色时，司马光等再要求削减宫中宴饮赏赐。** 其称“今岁灾异屡臻，民多菜色”，而道路传言宫中宴饮赏赉“动以万计”，请求罢宴饮并约束后宫奢纵；仁宗嘉纳。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0114`。

- **课利场务旧额过高的问题改按五年实际重定。** 旧制场务岁课亏损时只不断考罚主典，却不调整旧额；仁宗命杨畋取天下场务最近五年增亏，在一月内另立新额。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0115`。

- **地方官任期开始与“实惠及民”挂钩。** 转运使、副使、提点刑狱先按新条目考绩；随后规定知州军监、知县县令若“清白不扰而实惠及民”，由监司保荐再任，政绩尤异者奖擢，理由是任期过短不足以完成兴利除害。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0116`—`P0117`。

## 二、政治秩序、外交与人口变化

- **仁宗试图区分台谏风闻监督与普通臣僚告讦。** 卷初依吕诲建议，禁止臣僚越职揭发赦前旧事及台谏攻击“不关政体”的小过；其后又数次戒止士大夫借私憎、流言和台谏之门中伤他人。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0005`、`P0018`、`P0097`、`P0101`。

- **辽中京设国子监；耶律仁先复任北院大王时出现罕见的地方民意反馈。** 原文称仁先前任有惠政，本次百姓迎数百里“如见父母”。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0007`、`P0010`。

- **京西一分为二，地方安抚体系重新布局。** 许、陈、郑等九州军属北路，邓、襄、随等九州军属南路，各置安抚使，由许、邓守臣兼任，河南府不隶。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0012`。

- **何郯实际运用封驳阻止唐介外放。** 唐介自请知荆南，何郯封还敕书，称其为谏官、有补朝廷，不应出外，仁宗遂令唐介仍知谏院。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0014`。

- **欧阳修等完成《唐书》二百五十卷，馆阁继续以高赏格访求遗书。** 士庶每进馆阁缺书一卷给绢一匹，五百卷可授文资官；其后又专门整理秘阁兵书与七史。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0015`、`P0024`、`P0068`、`P0107`。

- **诸路监察机构因武臣不习法令和侵盗问题改制。** 朝廷取消诸路同提点刑狱使臣，理由包括有人盗用公用银器、倡优首饰且多不习法令民事；江南、荆湖、两广、福建及川峡等十一转运路增转运判官，三年一任。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0028`。

- **十八个“烦剧”州改由中书直接择守。** 齐、登、密、华等十八州以后由中书选知州，潮州还须本路转运、提刑共同保荐。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0032`。

- **兖国公主婚姻纠纷升级为宫禁制度问题。** 公主夜开皇城门入禁中诉李玮，李玮一度被降，后改罚铜三千斤。王陶、唐介、吕诲等要求追究沿途皇城、宫殿监门官未辨真伪即开门的责任，但仁宗未报。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0034`—`P0035`。

- **公主宅内臣因人数过多和行为不谨被裁减。** 梁全一等外置监当、梁怀吉配西京洒扫班；以后公主宅不再置都监，只选四内臣句当，且不得与驸马接坐。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0037`。

- **外戚无功迁官再度受到封驳。** 杨畋认为李珣、刘永年“无尺寸功”而仅以外戚升迁有损名器，拒草制；范镇继续要求朝廷明确是非，最终均未获采纳。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0039`。

- **宋庠因公主案、内臣关系及徇私等弹劾罢枢密使。** 曾公亮继任枢密使，张昪、孙抃参知政事，欧阳修、陈旭、赵概入枢密。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0041`。

- **成都军纪以极端个案强制执行。** 一营卒犯法当杖却称“宁请剑，不能受杖”，吕公弼先杖后按其自请斩之，原文称“军中肃然”。这是军纪与司法处置，不是战役。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0045`。

- **两制与台官之间的交往限制进一步解除。** 王畴称台官不可能凭一二人周知天下事，两制侍从皆国之选，不应偶相见即互疑，仁宗准两制与台官相见。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0052`。

- **任守忠在宗室葬事中索受馈遗并操纵惩罚。** 他护濮安懿王葬事时凌蔑诸子，所得馈遗近**万缗**仍不满足；宗懿后因葬父礼节获罪，原文直称“守忠实为之”。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0053`。

- **良民子弟被诱入军籍者获得有限退出权。** 入籍百日内，父母诉官且查明来历者可还家，是对军籍扩张的一项人身保护。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0056`。

- **富弼坚持平时不得援“金革”夺情起复。** 母丧去位后，仁宗五遣使强起为相，富弼认为战争变礼不可用于承平，始终不拜；卷末仁宗再给半俸，他也坚辞。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0060`、`P0088`、`P0122`。

- **陈旭入枢密引发言官与皇帝持续拉锯。** 唐介等指其结宦官、旧日阿附贵戚、贱买富民马及纵亲属请托；陈旭请付吏辨劾、居家求罢，仁宗手诏召出。言官多次闭门待罪仍继续论列，最终陈旭与多名言官同时外出。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0069`—`P0070`。

- **地方“行义文学”荐举另开一条取士渠道。** 各路敦遣二十三人，到京十六人、馆于太学并试论策，七人赐进士出身、四人同出身，其余授试校书郎；另有服丧、死亡和辞试者获得相应安排。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0071`。

- **宋祁遗奏仍请早建储。** 原文还记其自作《治戒》等授子，其子遵遗戒不主动请谥，后经张方平建议才谥景文。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0074`。

- **张茂实被解除宿卫兵权，核心理由是政治安全疑虑而非真实兵变。** 赵概、刘敞等认为其特殊身世易被流言利用，又有公使贸易及部卒杀人等弹劾，最终张茂实以老自请解兵、出知曹州。原文没有其谋反或起兵事实。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0075`。

- **辽道宗因萧革构陷而杀萧阿喇，太后营救不及。** 阿喇陈时务激切，萧革借机称其慢上，道宗命缢死殿下；太后大恸。原文又追评阿喇若不死，后来的重元、耶律伊逊之祸可能不会发生。此为中枢政治清洗，不进战争账。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0079`。

- **萧革—萧呼敦关系网继续扩张。** 萧呼敦借献珍玩畜产结萧革并卖权，推荐迪里、萧呼都；萧呼都在陷害阿喇时暗中相助。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0054`、`P0080`。

- **日食时朝廷拒绝用“京师云蔽”宣布无灾称贺。** 王畴、司马光认为京师不见不代表四方不见，预报食分不准反应追究历官，仁宗令百官不得称贺。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0081`—`P0082`。

- **王安石反对削弱舍人院对诏令的程序性审查。** 他认为若舍人不得申改除授文字，就会一听大臣所为，强势执政甚至可“挟上旨以造令”，由此与执政不合。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0093`。

- **中书、枢密恢复逐月撰进《时政记》。** 原文称此前“累年未修”，本卷重新制度化即时政务记录。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0099`。

- **司马光把仁宗问题概括为仁厚而决断不足，并批评按年资、频繁调任的用人法。** 《君德》称群臣奏事多一概首肯；《御臣》主张量能授职、有功加赏而不轻徙、无功降黜。原文定位：`SRC-XUZIZHITONGJIAN-059-2270782-P0103`—`P0104`。
