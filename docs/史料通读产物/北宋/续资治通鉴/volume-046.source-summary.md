## 一、财政、民生、工程与灾害

### 1. 庆历新政直接涉及赋役、农桑与地方治理

- `P0003`：仁宗反复督范仲淹、韩琦、富弼条奏当世务，范仲淹、富弼在天章阁提出十事：明黜陟、抑侥幸、精贡举、择官长、均公田、**厚农桑、减徭役**、修武备、覃恩信、重命令。除府兵被辅臣共同反对外，多数次第颁行，说明新政从一开始就把农业与役负列为核心。
- `P0023`：范仲淹、富弼把守宰失职与“**赋税不均，狱讼不平，水旱不得救，盗贼不得除，民无所告诉**”直接联系，要求二府择转运、转运择知州、知州择知县，不任者奏罢，良吏久任。这是以地方行政质量解决民生与治安问题的制度链。
- `P0025`：肥乡县田赋长期不平，郭諮、孙琳用千步方田法清丈后，**免无地而纳租者四百家，补正有地无租者百家，收通赋八十万，流民复归**。上蔡又清出田二万六千九百三十余顷并均赋；但因州县逃田过多、难以尽括而停止扩展。此条既有均税效果，也暴露逃田规模和土地登记缺陷。
- `P0046`：诏限制职田；与均公田、方田及收紧恩荫并看，官僚利益与土地财政都在新政调整范围内。
- `P0115`：省河南府颍阳、寿安、偃师、缑氏、河青五县为镇，并改隶王层县，开始落实范仲淹有关地方行政缩减的建议，属于降低行政层级/成本的具体动作。

### 2. 陕西大饥、大旱、人口流徙与大规模赈济

- `P0057`：韩琦至陕西时“**岁大饥**”，冬又大旱，河中、同、华等州饥民“**相率东徙**”。韩琦选官分赴州县、开省仓赈济，另令许宗寿专提举蒲、华、同三州；原文称三州“**所活凡二百五十四万余人，它州称是**”。无论史文统计口径如何，这都是本卷最强的饥荒与赈济数量材料。
- 同段 `P0057`：韩琦又蠲赋役、考察官吏，并因禁军中疲老者“耗用度”而 **停放一万二千余人**。赈灾、减税与裁减低效军额同时展开，直接联系财政与民力。
- `P0066`：次年二月再从奉宸库拨 **银三万两** 下陕西，籴谷麦赈济饥民，说明灾荒并未在上一冬完全结束。
- `P0113`：淮南另有饥荒，朝廷允许募人纳粟赈济，形成以社会输粟换取救荒资源的机制。
- `P0043`：辽上京岁俭，免复当地民租税，属于辽方灾荒减负材料。

### 3. 战乱受害者减免、军纪赔偿与边地民力

- `P0085`：衡州、道州、桂阳监居民因遭猺乱劫掠者，**免赋役一年**。战斗本身已移战役卡，此处只保留独立的灾后财政减免。
- `P0092`：湖南居民被征猺军误杀者，朝廷“**赐帛存抚其家**”；误杀人员成本记入战役卡，本处只记赔偿与抚恤政策。
- `P0096`：因有人称河东刍粮不继而屡请废麟州，仁宗命欧阳修实地计度；同时晋州铁钱盗铸、礬岁课亏损也一并调查。边防存废、货币失序和矿税下降在同一财政审查中出现。
- `P0112`：欧阳修实地考察后认为麟州城壁坚完、地形高险，不宜移废；但主张 **减寨卒以纾民力**，以土豪协助防御，体现“保战略节点而降常驻成本”的折衷。

### 4. 水洛城：工程收益、蕃部关系与决策冲突（武装骚乱另入战役卡）

- `P0033`：德顺军生户元甯等献水洛城，郑戩称其通秦州道路、两水环绕、田沃数百里，杂氐十余落愿纳质受汉官；如筑城可得蕃兵三五万人及弓箭手协防。水洛城从一开始就是 **道路、肥田、部族招附与边防工程** 的复合项目。
- `P0080`：围绕是否续筑，韩琦、尹洙、狄青主张不便，郑戩坚持。尹洙召还许迁、命刘滬董士廉停役，刘董因蕃部愿自备财力且官物已投入而继续工程；狄青遂将二人械送德顺军狱。其后发生蕃部武装骚乱已入战役卡；本处只记 **军令分歧、工程沉没成本和新附部族对主持人的依赖**。
- `P0081`：范仲淹指出刘滬、董士廉原奉四路都部署节制筑城，并非擅兴；刘滬有累次战功、董士廉为京官，不宜轻弃或同样枷勘，请派中使查明。
- `P0100`：刘滬、董士廉获释后复往水洛完役。欧阳修、余靖认为刘滬对新附蕃部具有不可替代的安抚作用，甚至主张若需调离一方，宁移狄青也不可移刘滬。
- `P0105`：鱼周询、郑戩奏水洛城只剩女墙未完，此时废弃可惜；朝廷最终命卒城，并派内使催修。工程在本卷完成政策闭合，但实际长期控制与成本收益仍需后卷观察。

### 5. 货币、矿税、学产与财政资产

- `P0022`：把玉清昭应宫田二十二顷赐国子监；`P0069` 又以上清宫田园、邸店赐国子监，官学资产明显增加。
- `P0096`：晋州铸铁钱后民间多盗铸，晋州礬岁课又持续亏损；反映边区货币信用与资源税收问题。
- `P0101`：张掞奉命赴江淮、两浙转运司体问利害，中央继续对主要财赋区进行转运复核。
- `P0110`：抚州进金谿县所得“生金山”三百二十四两，被收入龙图阁瑞物库；原文将其按瑞物收藏而非普通财政收入处理。

### 6. 灾异、火灾与节用

- `P0036`：上清宫失火后，朝廷没有恢复原宫观，而把旧址改为禁军营，属于灾后用途转换。
- `P0056`：河北降赤雪，河东地震五六日不止；孙甫请求 **省后宫浮费** 以应灾谴，仁宗采纳，灾异被用作财政节用理由。
- `P0123`：开宝寺灵宝塔遭火，余靖请不要再营造，避免灾后重建支出；仁宗虽私下嫌其暑天奏对汗臭、唾沫喷面，仍未因此治罪。
- `P0055`：澧州献木纹“太平之道”的瑞木，欧阳修以外患、百姓困弊和盗乱并存反对祥瑞政治，请禁各地再进奇兽异禽草木，获准。
- `P0048`：司天监以五星在东方占“中国大安”，仅作天象记录，不据此推定实际民生改善。

## 二、政治秩序、外交、人口与社会变化

### 1. 庆历新政的制度化展开

- `P0004`：吕夷简正式致仕后，欧阳修仍担心其暗中递文干政；监修国史职转交章得象，标志旧相权力进一步退出。
- `P0005`：仁宗奖励王素、余靖、欧阳修、蔡襄“数论事无所避”，给相应品服，明确鼓励谏争。
- `P0026`、`P0029`：二府共同选诸路提点刑狱，又共同选转运判官，中央对地方监察和财计人事的控制加强。
- `P0031`：范仲淹指出官员进状常被中书、枢密批送各司后无人作决定，形成“**送杀**”；诏令各司以后必须明确勘会可行者上呈、不可行者告知本人，减少重复上状与行政积压。
- `P0032`：新定磨勘式，“**自是法密于旧**”；官员考课明显趋严。
- `P0041—P0042`：馆职须两府两省保举后召试，高官不得为亲属求馆职；荫补年龄提高，“**任子之恩稍杀**”。
- `P0064`：进一步禁止臣僚用奏荐恩泽替亲属求科名、转官、升差遣或牵复，甚至针对更名规避荫补限制设重罚。
- `P0076`：曾公亮删定审官、三班院、流内铨条贯；`P0131` 又规定转运、提刑荐举有治绩官，若所举不实，推荐者连坐。新政把用人、考课与荐举责任串成闭环。

### 2. 学校、科举与教育制度

- `P0053`：南京府学升为国子监；`P0054`：广州获准立学，学校网络向地方扩展。
- `P0082`：下诏州县皆立学；教授一般三年一代，官员不足可取乡里宿学；士通常须在学 **三百日** 方可秋赋，旧曾充赋者一百日。考试改先策、次论、次诗赋并通考，罢贴经墨义，并重设经术、三史、明法的实际理解标准。这是卷内最完整的教育改革文本。
- `P0089`：改革期间权停贡举。
- `P0099`：因国子监狭小，改锡庆院为太学、修讲殿备临幸，又以潞王宫为新的锡庆院，伴随明确校舍工程。
- `P0109`：仁宗亲幸国子监，对孔子破旧仪行再拜，又谒武成王庙、观玉津园种稻；孙复虽获褒擢，后因讲说多异先儒而罢迩英阁说书。

### 3. 朋党论、政治构陷与新政受阻

- `P0094`：仁宗问“君子亦有党乎”，范仲淹以边地好战、怯战各自成党为比，认为“朋而为善”不害国家。
- `P0095`：夏竦等因《庆历圣德诗》制造朋党论，欧阳修上《朋党论》，把小人逐利之合与君子道义之朋区别；内侍蓝元震又指范仲淹、欧阳修、尹洙、余靖、蔡襄相互提挈，仁宗当时不信。
- `P0125`：史文明列新政反作用：按察使多所举劾使人心不安，任子恩薄、磨勘法密使侥幸者不便，朋党谤毁渐盛；范仲淹、富弼仍守所议不变。
- `P0126`：夏竦令人长期模仿石介笔迹，把“伊、周”篡为“伊、霍”，伪造石介为富弼撰废立诏草。仁宗虽不信，范仲淹、富弼却因此惧祸求出，最终范仲淹外任陕河宣抚。此条是新政由制度争议升级到政治安全风险的关键材料。
- `P0007`：欧阳修持续攻击李淑依附吕夷简并要求外放，甚至批评中书因避怨而拖延；新旧政治网络冲突已直接影响人事执行。

### 4. 外戚、恩荫与言论处置

- `P0079`：张尧佐为张修媛世父，获任提点开封府诸县镇公事；余靖反对外戚进用过速，仁宗口头称若物议不允可改外郡，但张尧佐最终未出。
- `P0111`：丘浚因诗讪谤，执政欲重诛，仁宗以“**狂夫之言，圣人择焉**”从轻，只降官监税。
- `P0123`：余靖因塔灾请勿重建时奏对仪态令仁宗不悦，仍未受罪；史文以此称其“优容谏臣”。
- `P0045`：欧阳修建议上殿臣僚退后稍留，由修起居注官当面记录圣语，朝廷采纳，强化君臣奏对记录程序。

### 5. 宋夏和议已出现名义转折，但边境安全未同步闭合

- `P0044`、`P0050`：宋夏议和未决时，韩琦、田况是否回朝仍被视为边防问题；张子奭、王正伦因多次使夏获奖。
- `P0114`：五月元昊 **正式称臣，自号夏国主**，并再遣尹与则、杨守素来议事。此为外交名分的实质转折，但同月仍发生青涧实际边战（已入战役卡），两者不得相互替代。
- `P0117`：范仲淹仍称西夏“变诈难信”，请求罢参知政事而出守边郡，说明和议尚未转化为完全可信的边境安全状态。

### 6. 宋辽边防、人口迁徙与对辽判断

- `P0091`：李京报告辽在西北新筑二城，南接代郡、西交元昊，并把沿边生户以及丰州、麟州被掳人口迁入，以断其归宋之路；宋方拟依旧盟交涉。此条是明确的 **边地人口强制配置** 材料。
- `P0102`：辽属党项等部叛附西夏后，辽方对威塞州户作出“**富者遣行，余留屯田天德军**”的分流安排；武装控制变化已入战役卡，本处只记人口迁送和屯田政策。
- `P0127`：辽军为讨西夏方向将从河东境外经过，范仲淹疑其背盟想大调兵；富弼判断即使辽背盟也更可能寇河北，杜衍亦认为不可妄发。最终宋军没有大调发，体现情报判断避免了一轮未必要的军事征发。
- `P0128`：富弼上河北守御十二策，称自己十余次往返河北、广询沿边土豪和内地故老、并考载籍后形成，要求两府逐项会商可行者速行。

### 7. 辽朝内政、司法与社会政策

- `P0020`：萧孝穆卒，辽廷高规格追赠；其弟萧孝友升南院枢密使。`P0035` 萧惠改北院枢密使，`P0075` 杜防升南府宰相，`P0087` 杨佶参知政事，辽中枢连续调整。
- `P0051`：辽把政事省改名中书省，属于官制变化。
- `P0021`：辽令各路上报重囚并遣官详审；`P0090` 因辽人犯法过去多由汉人禁勘导致受枉，皇太弟重元请五京各置警巡使，获准；`P0122` 再录囚。司法复核和机构改革并行。
- `P0027`：杜防揭刘六符曾受宋赂，韩绍芳、刘六符被外放，杜防更受亲任，反映宋辽交往也卷入辽廷内部政治。
- `P0088`、`P0121`：高丽两次贡辽；`P0062` 西蕃摩戩贡宋，作为区域外交常态记录。

### 8. 宗室、礼制、修史与制度知识

- `P0063`：荆王元俨卒，仁宗病中亲至调药，死后高规格追赠；原文以其谨约、好儒文及对元昊未平的关切记其性行。
- `P0129`：依富弼建议，德文、允让等十名宗室次第封王、公，并调整班次，宗室秩序制度化。
- `P0012—P0013`：《祖宗故实》由富弼倡议设置编修体系，以三朝典故和诸司可用文书为两府模范；次年成九十六门、二十卷。
- `P0098`：章得象上新修《国朝会要》；`P0119` 辽亦命官编辑上世以来事迹，宋辽都在进行制度史知识整理。
- `P0030`：宋修兵书；`P0065` 上新修《太常新礼》《庆历祀仪》；`P0086` 仁宗又从《答迩英圣问》中选六项大事交二府奉行。

## 三、跨卷连续性

- **向前**：承卷45吕夷简退场、范仲淹富弼入执政、宋夏议和未定。本卷开篇即把“御边”与“更天下弊事”合流为庆历十事改革；内地治安问题则继续推动地方官责任、赏罚与守宰选任改革。
- **向后**：卷末元昊已称臣为夏国主，但边境安全后效仍未闭合；辽夏关系也转入更高强度对立，实际武装阶段由战役裁决卡继续承接。水洛城续筑后新附蕃部能否稳定、庆历新政在朋党论和伪废立诏草压力下如何收束，均交卷47核验。
