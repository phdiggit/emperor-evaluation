## 一、财政、民生、工程与灾害

### 1. 连年灾荒后的减税、赈粮与农业恢复
- `P0003`：永州大雪持续六昼夜，江陵溪鱼全部冻死，显示南方亦遭异常寒灾。
- `P0007`：各路灾伤州军统一设粥、低价出售官粮以济贫民。
- `P0017`：此前州县贷给贫民的粮种，直接下令停止追收，相当于把灾后农业贷款转为豁免。
- `P0018`：辽分别赈济川州、饶州饥民及中京贫乏者。
- `P0021`：灾伤地区去年夏秋税及借粮种全部除放；本年夏税一般免三成，大名府及登、莱、潍、密、青、渭州免四成，并禁止折变、支移。欠负暂缓到丰熟后渐催；各地为上供制造物品而征集百姓工匠、妨碍农业者一律暂罢，只有供军急需事项留待次年另奏。这是本卷最完整的一组灾后减负政策。
- `P0124`：针对地方“苗长即报丰稔、后来霜旱蝗螟却隐匿”的做法，规定灾伤必须即时上报，丰收也须等夏秋真正收成后再报；隐灾不报者论罪。
- `P0130`：派使安抚水灾州军，凡需宽恤或调整事项，由使者与转运使及地方长吏共同议决。
- `P0157`：遣使安抚淮南、江浙、利州饥民。
- `P0160`：开放唐、邓等八州常平仓赈济贫民。
- `P0164`：益、梓州路物价暴涨，吕夷简、曹仪驰驿赈恤；愿出粮救饥者可由使者持空名告敕即时酬奖，继续沿用“国家给名位、社会出粮”的赈济机制。
- `P0189`：大雨造成积水泛滥，公私房舍大半受淹，并有压死者，卷末仍有新的重大城市灾害。

### 2. 军费、冗兵、粮储与内藏财政
- `P0013`：真宗称边境安静，向敏中却指出兵数未减、冗费仍重；君臣议裁京师军兵、停止继续募兵、淘汰疲老。原文明确把军额膨胀与“农民转耗”联系起来，是本卷军事财政对民生影响的重要非战役材料。
- `P0020`：江淮丰稔时，朝廷要求额外留下二三百万粮储充军食，目的之一明确是避免临时征发“扰民”。
- `P0054`：三司向内藏借银十万两。
- `P0067`：澶、魏丰熟，吕夷简请求出内藏钱二十万贯就地购买刍粮，获准。
- `P0083`：三司再向内藏借银十三万。
- `P0089`：河东转运使进贡钱三十万贯、粮一百二十万石，获朝廷嘉奖。
- `P0118`：三司向内藏借钱五十万贯、绢十万匹。
- `P0121`：三司又向内藏借钱帛二百四十五万。连续多次大额借支显示内藏仍是中央财政的重要调剂池，而非只承担宫廷私用。
- `P0051`：皇太子每月给钱二千贯，东宫财政正式固定化。

### 3. 茶法、行政取物与反聚敛
- `P0040`：李士衡任三司使，真宗作《宽财利论》赐之，表明当时中央仍以“宽财利”作为财计政策的公开口径。
- `P0062`：孙奭批评茶法反复变更、有损政府信用，要求重定经久且宽简的制度；真宗令其与三司详定，但孙奭很快外任，改革中止。
- `P0063`：孙奭还曾批评天庆等节天下设斋醮、张宴耗费过广，请裁省浮费，未获采纳。
- `P0079`：三司指出内廷使臣过去只凭口头“传宣”即可取物，容易借机盗取钱财，遂设传宣合同司，以书面凭证堵塞宫廷取物漏洞。
- `P0134`：有人建议把曾犯赃的官员一律发往广南、川峡恶地任职。真宗明确说“广南犹吾民也”，不应把当地百姓当作惩罚贪官的承受者；改为由转运使严查，二次贪赃者永不录用。

### 4. 宗教工程、大礼与灾年争议
- `P0026`：皇城司报告“圣水”能治疫病，朝廷决定在泉旁建祥源观；士女徒跣奔走瞻拜。任布认为不应以神怪炫惑百姓，未被采纳。
- `P0031-P0032`：王钦若负责祥源观工程；刘煜在盛夏亢旱时反对为神怪兴不急土木，仍未获采纳。
- `P0043`、`P0057`：因秋收丰稔，补办此前延后的赐酺，连续五日。
- `P0058`：祥源观建成，共六百一十三区。
- `P0128`：天安殿大会释、道一万三千余人并建道场，真宗以药银铸大钱亲自赐予。
- `P0123-P0125`、`P0142-P0143`：尊号、天书、南郊、大赦等礼制活动持续进行。
- `P0087-P0088`：朱能伪造“天书”，周怀政等迎合。鲁宗道指出“奸臣肆其诞妄”，孙奭更直言天下皆知朱能造假，要求斩朱能谢天下。真宗未采纳，但也未处罚孙奭。此段是天书政治内部反弹的强材料。

### 5. 水利、漕运与公共工程
- `P0102`：江淮发运使贾宗指出真、扬至淮、汴旧漕路历五堰，粮食反复剥卸、民众疲于牵挽、船只也易损坏。开扬州古河、废三堰后水路畅通，原文称每年可省官费十万，且“公私大称其便”。这是本卷最明确的降运输成本工程。
- `P0154`：正式开扬州运河，承接前述工程。
- `P0115`、`P0126`：黄河在滑州决口，泛及澶、濮、郓、齐、徐等境；朝廷派使救援溺水者并抚恤家属。
- `P0159`：滑州报告河塞成功。堵河工程向诸州征薪石、楗橛、茭竹共一千六百万件，动用兵夫九万人；朝廷虽大加赏赐和纪功，但这一数字也直接反映治河的巨额物资与役力成本。

### 6. 雄州边境建设兼具民生与军备双重属性
- `P0105-P0112`：李允则在雄州十四年，即使宋辽停战仍持续修城。他合并瓮城、浚壕筑堤，并取西山木材建仓廪营舍；又教民烧瓦、整顿里巷和市场，扩大屯田、架桥引水、修堤道，改善安肃、广信、顺安之间交通。
- 同组材料还显示其把旧陷马坑改作军中蔬圃、植榆柳荆棘兼顾防御，修井渠畦垄，并持续掌握边民和辽方情报。甲仗库失火后，他迅速从瀛州调运器甲补足，而未使军中惊乱。
- 这组事实虽带边防色彩，但本卷没有发生宋辽战斗，因此不进入战争成本卡；作为长期公共—军用基础设施与边政能力保留。

## 二、政治秩序、储位、吏治与刑政

### 1. 皇太子确立与皇帝健康恶化
- `P0010-P0012`：寿春郡王受益先加太保、封升王；刘煜、鲁宗道等谏官获准升殿面奏。
- `P0041-P0044`：真宗已多病、年长，大臣此前不敢直言建储；陈执中以“早定根本”进言。群臣三上表后，升王受益正式立为皇太子、改名禎，并大赦天下。
- `P0045-P0053`：册太子礼制迅速完备，设宾客、规范百官答拜、作《元良箴》，九月正式册立。
- `P0135-P0140`：李迪、寇准称太子言动谨慎；大礼班次明确太子位在宰相之上，太子推让后，寇准等仍坚持遵守储副尊位。
- `P0156`：天禧四年真宗病重，不视朝。
- `P0182-P0192`：原文明确说皇帝“不豫，艰于语言，政事多中宫所决”，此后寇准、丁谓、曹利用、钱惟演、李迪等围绕太子监国和宰执配置激烈角力，说明健康恶化已直接影响最高决策结构。

### 2. 寇准—丁谓冲突与中枢失序
- `P0098-P0113`：寇准再次入朝并拜相，丁谓任参知政事。两人从“拂须”事件开始结怨，丁谓随后逐渐形成倾构。
- `P0180-P0192`：丁谓、曹利用与钱惟演共同排斥寇准。寇准曾密请太子监国并要求排除丁谓，因酒后泄露而遭罢相；真宗病中对宰相、枢密任命多有反复，甚至出现一度三名枢密使并立的异常局面。
- `P0190-P0192`：李迪最终拜相；钱惟演又促成丁谓平章事、曹利用加同平章事。寇准入对揭发丁谓、曹利用“交通踪迹”，君臣争论进一步激化。
- 这一连串事实显示真宗末年储位虽已确定，但中枢权力分配和病中决策稳定性明显恶化。

### 3. 周怀政未遂政变：严重但不进入战争账
- `P0193-P0197`：周怀政因真宗病重和自身被疏远，谋杀丁谓等、复相寇准、尊真宗为太上皇、传位太子并废皇后，约定二十五日发动。
- 发动前一夜，杨崇勋、杨怀吉告变；曹利用次日入奏，周怀政即在宫中被卫士擒获，审讯后处死。随后朱能伪天书案一并发作。
- 按战争合同，本案虽属重大宫廷政变阴谋，但在调兵、攻宫、武装死伤或争夺节点之前即被制止，因此作为政治秩序事实保留，不填 `P/S/M/A/WC`。

### 4. 刑政、言路与地方豪强
- `P0015-P0016`：鲁宗道要求死刑案件加强覆核；真宗虽一度厌其进言频繁，仍慰留并称其“鲁直”。
- `P0024`：李溥因私役兵健为姻家起宅、利用官船贩材等十余事被治罪。刘随追劾该案；其旧任永康军时改用数十万株柳树代替反复伐木立栅，减少民力消耗，并整治受贿县令和买马吏卒勒索。
- `P0033-P0035`：西京至京师出现“帽妖”谣言，居民夜间聚族戒备，军营尤甚。朝廷捕僧、术士三人弃市，但史文直言谣言“实无其状”；王曾在应天府反而令夜开里门、捕造谣者，很快压住恐慌。
- `P0038`：因彗星赦流以下、死罪减一等。
- `P0075-P0078`：科举中既有郭桢冒丧应举和同保连坐，也有滑州落第者越级复核事件。崔立旧案显示役兵运官物遇险时集资雇船，虽有“率敛”形式，但因非为私利最终只按杖罪处理，避免三人死刑。
- `P0137`：辽规定诸道已处理事项无论大小，每三月汇总上奏一次。
- `P0139`：宋在京及诸路一度仅有三件断案可奏，朝廷将“狱空”作为司法绩效予以奖赏。
- `P0158`：鲁宗道要求除枉法受赃外，对“计赃而情可悯”的案件允许奏裁；刑部、大理定罪不一时交审刑院快速裁定。
- `P0171-P0172`：地方豪强麻士瑶因聚敛、私蓄禁书兵器、杀人等罪被杖杀，亲属家僮受黥配并籍家；原文追溯其家族财富始于专事掊克聚敛。
- `P0173`：胡顺之任县令时敢于杖责不输租豪富，又拒绝因高丽贡使经过而向中贵人主持的郊迎行拜礼，朝廷认可其处理。
- `P0174`：祁暐母丧三年守墓至冻坏脚趾，获诏旌表并赐粟帛。

## 三、科举、行政与农业治理制度

- `P0039`：锁厅应举官员须先由所在地长吏考核，若礼部复试不及格，现职也受处分；前后考官、举送长吏一并追责，科举推荐责任明显加重。
- `P0074-P0076`：贡举人四千三百人入见；郭桢冒缌麻丧参加科举被停三举。王洙明知承认担保会受罚仍不改口，与郭桢同罢。滑州考卷争议则强调转运使不能越过中央奏裁程序。
- `P0084`：亲试贡举人，进士及第六十三人、同出身八十六人，另有学究诸科若干。
- `P0119`：确立科场亲属回避，胥偃因与主考盛度、钱惟演有亲嫌，改送舍人院考试，此后形成常例。
- `P0155`：把诸路提点刑狱改为“劝农使、副使兼提点刑狱”，要求核查户籍差等、整顿不合规定者，劝农耕垦、招集逃散、检括陷税，凡农田事务均由其统领。这是本卷最重要的农业行政制度变化。
- `P0163`：川峡、广南举人不再受固定取解名额限制。
- `P0169`：江南转运使分东西两路，理由是便于按巡，加强地方财政监察覆盖。

## 四、外交、人口迁徙与社会秩序

- `P0027`：吐蕃向辽请求今后朝贡时借道夏国，辽主准许，反映辽—夏—吐蕃间的通贡交通安排。
- `P0097`：辽把宁州、渤海户迁到辽河、土河之间，是明确的人口迁置。
- `P0144`：富州蛮首向光泽声称愿献疆土，真宗认为“朝廷得之安用”，怀疑只是亲族不容；查验后果然如此。中央没有因“献地”名义轻率扩张。
- `P0147`：李渎、魏野两名隐士死后，国家赐其家米帛、长期存恤，并令二税以外免差役。
- `P0149`：高丽王询派使赴辽请求恢复贡方物，辽主准纳。
- `P0150`：燕地发生饥荒和疫病，民众大量流亡、饿死。杨佶开仓赈济绝乏；贫民卖子者，由官府按雇佣价赎出，属于本卷最直接的灾荒人口保护措施之一。
- `P0177-P0178`：被高丽扣留六年的辽使耶律资忠归国，辽主亲迎并优礼；高丽王询随后表请称藩纳贡，辽主同意。该政治关系变化属于战争后外交结果，但不是战役本身，不把“称藩”虚构为本卷某一场战斗的直接 `WR` 或 `BCP`。

## 五、卷内非战役趋势判断

1. **灾后恢复政策相当密集，而且多次直接保护农业生产。** 免税三至四成、粮种免追、暂停妨农上供制造、常平仓赈济、物价暴涨时驰驿赈恤，均是可落实到民户的措施。
2. **中央财政继续高度依赖内藏调剂。** 单卷连续出现十万两银、十三万银、五十万贯加十万匹绢、二百四十五万钱帛等借支，说明“大礼—灾荒—常规国用”并行时三司资金需求持续偏紧。
3. **治河与漕运呈现一正一负两种公共工程成本。** 扬州运河减少五堰装卸、岁省十万官费；滑州堵河则一次征集一千六百万件材料和九万兵夫，工程有效但役力代价极大。
4. **真宗末年政治秩序明显转差。** 太子终于确立是稳定因素，但皇帝病重、中宫介入、寇准与丁谓曹利用相争、周怀政未遂政变，使最高决策层进入高风险状态。
5. **符瑞政治到本卷已出现更强公开反弹。** 鲁宗道、孙奭直接指出朱能天书为奸诈伪造，且真宗虽不采纳，也未治罪。
6. **对外战争的实际成本与结果必须同外交分开。** 辽—高丽本卷大战详见战役 JSON；高丽后来称藩纳贡只按后续外交事实记录，不倒灌为茶陀二河战败一方的战争收益。

## 六、跨卷连续性

- 向前承卷033：辽上一轮攻兴化城九日不克、败返。本卷再次征马、任新统帅发动东征，必须沿同一 `XZTJ-LIAO-GORYEO-WAR-1010-1019` 父链续判。
- 德埒勒线承卷032的歼丁壮、强迁和胪朐河筑城；本卷又出现“讨叛命者，灭之”，说明此前强制重组后仍有残余反抗，不能把卷032提前判成结构性终结。
- 向后：本卷辽—高丽大战后已出现高丽重新向辽称藩纳贡，但长期边界、安全结构及后续是否复战仍须继续观察，不把单一外交动作直接定为永久终局。
- 真宗已经病重，太子禎虽地位稳定，丁谓、曹利用、李迪及中宫之间的权力结构仍未闭合；卷035应继续跟踪皇帝健康、宰执斗争及最终交接。
