## 一、财政、民生、工程与灾害

- 田锡直接报告北边民生损失：霸州、乾宁军已有“死伤人户”，莫州一次报饿死十六口，沧州则有一家十七口全部饿死。他把这种情况上升为“危乱之萌不独在边防而在内地”，明确要求皇帝和宰相承担救民责任。原文定位：`P0012`“莫州奏餓殺一十六口，滄州奏全家餓死一十七口”。
- 丁谓在峡路重新设计地方防务与粮盐运输：险要处置寨、籍居民自守，有事会防、无事归田；忠、万等州军移夔州就食。施州粮少、巫山盐难运，遂自巫山至施州每三十里设一铺、每铺三十卒，以接力方式一面运粟、一面运盐；商人在巫山取盐较从他州省约一半劳费，再以入粟施州换盐，使施州粮源得到改善。原文定位：`P0015`。
- 京城街巷扩宽时，谢德权先拆权贵邸舍，面对停工诏仍当面指出阻挠者只是“权豪辈”惜租；最终恢复长安旧制的道路尺度、禁鼓时刻并立籍定界，禁止民户继续侵占街道。原文定位：`P0017`。
- 真宗明确否定“羡余”财政考课：仓库官不得以多收羡余邀绩。焦守节监香药榷易院年增十余万，本可迁更高武职，真宗以“缘财利羡余”不能与边功同赏，只给较低迁转。原文定位：`P0018`“多收羨餘以為課績……此可責而不可獎”。
- 宋廷规定，边兵因疾病或战死者，冬春衣赐可以转给家属，是持续边役下的直接军人家庭抚恤。原文定位：`P0021`。
- 钱若水实地反对重筑绥州，把边防工程的财政—民力成本写得很具体：绥州户口已凋残，重建工程预计用工百余万，屯戍又须比旧时加倍；刍粮全部仰给河东，却隔黄河、大小铁碣山及无定河，运输困难；旧城又已烧毁、附近木材匮乏。真宗接受其停止工程的意见。原文定位：`P0030`“用工計百餘萬”“又須廣屯戍兵，倍於曩日”“芻糧之給，全仰河東”。
- 陕西民众替沿边挽送刍粮者，朝廷减免其租一半，属于对西北战争运输负担的直接税收补偿。原文定位：`P0031`。
- 河北裁减冗官。原文定位：`P0035`。
- 杨覃上报天下已蠲放逋欠八百万，并获准把此事送史馆记录。原文定位：`P0038`。
- 西北边军屡次要求增兵时，辅臣一度建议把河北“强壮”改充军。真宗指出当初明确承诺“永不充军”，因此没有直接违背这项承诺，而改从河南籍丁壮为兵；田锡仍批评点集乡兵使“人情不安，实伤和气”。原文定位：`P0041`。
- 麟、府驻有重兵，军粮均由河东转输。虽地理距离不远，却被黄河阻隔、当地渡运设施少，导致刍粟涨价；真宗遂命郑文宝在定羌军、府州河上经度建桥，原文称“人以为便”。原文定位：`P0062`。
- 田锡十月长疏把财政和民生危机集中列出：中书、枢密互相卸责，“帑藏无余财，仓廪无积粟”，只顾急备边而缺少经国之谋，结果“地愈荒而黎民愈贫，事弥繁而资货弥少”；又把水旱、盗贼和边患并列为系统风险。原文定位：`P0067`。
- 麟州给复一年。该减免发生在边州高压之后，但作为独立战后税役政策保留，不重复进入单场战役成本。原文定位：`P0068`。
- 陕西诸州增酒榷课，李士衡、李溥奉命办理，此后每年增加收入二十五万钱。原文定位：`P0069`“自是歲益錢二十五萬”。
- 圜丘合祭后大赦，并除天下逋负钱粮。原文定位：`P0070`。
- 白州百余岁黄受获赐粟帛，不久京城百岁老人祝道嵒又获赐爵一级。原文定位：`P0071`。
- 咸平六年二月，朝廷遣使赈济京东、京西、淮南水灾。原文定位：`P0084`。
- 田锡随后指出近畿自去年秋以来霖雨水潦，所谓检覆灾伤“乃是虚名”、赈贷“且非实事”；更严重的是，国家从曹、单、宋、亳、陈、蔡、汝、颍间抽选五七万强壮，最初承诺只守本城，后来却全部押赴京师。田锡认为这既是失信，也使五七万人离开农田，在灾害后进一步损伤“邦本”和粮食生产。原文定位：`P0086`“五七萬人並離農畝”。
- 河东新置神锐、神虎军共一万三千余人，编为指挥并长期训练。该条是常态军制扩张，不提前并入任何单场战役M轴。原文定位：`P0089`。
- 马知节在成都处理两项与民生直接相关的问题。其一，所谓龙骑军谋变案一度牵连千余人，他秘密调查后只杀首恶七人，避免大规模株连；其二，蜀地自平定后每年上供紈绮万计，过去强籍里民分段舟运，沉覆近半、民户常破产赔偿。马知节改为二十舟一纲、每纲二人专管、三年轮代考课，此后沉覆显著减少。原文定位：`P0091`。
- 真宗禁止士庶私自黥刺家僮。理由是当时僮使“本佣雇良民”，其盗主财则由国家司法依法杖、黥、配，不再允许主人私刑。原文定位：`P0092`。
- 卷末财政机构发生结构性整合：盐铁、度支、户部此前互不统摄、彼此争财，真宗常需亲自裁决；六月首次合三部为一使，以寇准为三司使，同时保留三部副使分判日常事务，副使自此开始预内朝。原文定位：`P0112`。
- 陈恕掌三司十余年，多有利病条例改革。离任时荐寇准；寇准接任后把陈恕历年改创分门成册，并把旧榜帖重新誊写，请陈恕逐项署名，三司此后多沿其旧制。原文定位：`P0113`。

## 二、政治秩序、外交与人口变化

- 真宗把上元前谒启圣院太宗神御殿、望夕再幸他寺固定为礼制。原文定位：`P0004`。
- 张齐贤一度被授邠、宁、环、庆、泾、原、仪、渭、镇戎军经略使，专置“经略使”自此开始；不久又改判永兴军、兼马步军部署并罢经略使职。原文定位：`P0005`、`P0010`。
- 田锡再掌银台并兼门下封驳，凡天下章疏涉及民饥、盗起或诏敕不便，均逐项条奏，真宗称其“得争臣之体”。原文定位：`P0007`。
- 女真宰相伊勒希达入贡辽，后又有女真子弟朝辽及女真使臣再贡，显示辽与女真保持连续政治往来。原文定位：`P0008`、`P0020`、`P0090`。
- 真宗认为将臣多无“奇策”，命中书与枢密院分别条列当年防边办法，反映边防决策并非只归枢密单线。原文定位：`P0011`。
- 孙全照称绥州筑城不便，朝论亦多异同，真宗先派钱若水、陈兴实地详度；随后钱若水的高成本反对意见获采纳。原文定位：`P0019`、`P0030`。
- 本年亲试礼部举人，录王曾以下进士三十八人、九经诸科一百八十一人。陈恕知贡举取士很少而以王曾为首，糊名后王曾仍得甲科。原文定位：`P0026—P0027`。
- 田锡兼侍御史知杂事，并请求清查三院御史二十一人：有贪猥过犯者不得留宪职，清严勤干而外任者应召还。原文定位：`P0032`、`P0034`。
- 朝廷置宪州。原文定位：`P0036`。
- 代州进士李光辅善击剑来京求用，真宗担心奖用会使民众普遍好剑，遣还。原文定位：`P0037`。
- 真宗禁止指挥使马翰再插手京城捕盗，明确列出其三项权力滥用：豪民厚赂以免纠察、截留超过定罪所需的赃物、豢养十余无赖侦察扰民；以后捕盗只委开封府。原文定位：`P0040`。
- 陈若拙因期待三司使而嫌潭州远、反复辞任，真宗批其“贪进择禄”，并强调大藩任职不低于转运使、用人不以亲疏。原文定位：`P0042—P0043`。
- 辽大林砦使王昭敏等来降。原文只说人员来降，没有证明大林砦本身随之易手，故不虚构控制变化。原文定位：`P0058`。
- 群臣三次请上尊号，真宗不允。原文定位：`P0059`。
- 种放被张齐贤再次举荐，真宗遣使赴终南山礼召，并给绢百匹、钱十万。种放入见后提出“明王之治，爱民而已，惟徐而化之”，获授左司谏、直昭文馆及宅第、服带、御诗；后来请求暂还山中，又被优礼饯行。原文定位：`P0057`、`P0063`、`P0088`。
- 向敏中、张齐贤十月同时被罢，直接缘于婚姻、房产和相互揭告。柴氏拟嫁张齐贤，其继子薛安上告发；柴氏又反告向敏中贱买故宅并曾求婚，王嗣宗因旧怨再揭向敏中另议婚。真宗以向敏中对答不直罢相；宋白又借起草罢制报此前借金被拒之怨。原文定位：`P0065—P0066`。
- 乐史七十余岁仍因笃学著书复直史馆，并与其子同在史馆。原文定位：`P0073`。
- 张知白连续上三项制度建议：一是决狱宜主要放在孟秋中气后至秋分前；二是刑法只是治具，须与德教并用；三是进士考试应返归经典、正史并先策论后诗赋。真宗嘉纳，召试后任左正言。原文定位：`P0074—P0076`。
- 麟州内属人口被迁往楼烦。原文定位：`P0077`。
- 田锡警告真宗即位五年仍未建储，可能“开窥觎之端”，要求慎重处理储位。原文定位：`P0078`。
- 辽奚王府五帐六节度献七金山、土河川地，辽主回赐金帛；这是辽内部土地归附，非宋方战果。原文定位：`P0079`。
- 辽本年录进士邢祥等六人。原文定位：`P0080`。
- 六谷首领巴勒结称已集骑兵六万，请与宋军合力收复灵州，真宗准其合作并授朔方军节度、灵州西面都巡检使；本段只是联盟与拟出兵，不能提前作为实际战果。原文定位：`P0085`。
- 辽主命修日历官“不书细事”，是一条直接限制官方日历记事范围的史官制度材料。原文定位：`P0087`。
- 王佑之丁母忧仅一月即连续上五状求进，被王钦若弹劾后削三任、配郴州，并榜朝堂示众。原文定位：`P0093`。
- 九岁的信国公元祐病死，十五日后另一个出生两月的皇子也夭折，真宗随后取宗室子养于宫中；此前田锡已对长期未建储提出警告。原文定位：`P0096`。
- 成都缺守，朝廷认为张咏此前治蜀明肃、勤于安集，再任其知益州；原文称蜀民闻其重来“皆鼓舞相庆”。原文定位：`P0097`。
- 真宗升田锡左谏议大夫，并特许其安心著述、不轻易外差，欲升殿可先奏。原文定位：`P0100`。
- 王继忠被俘后没有死亡，而是被辽太后任为户部使并赐妻室，后来转而为辽效力；宋廷此前却误报其战死并追赠、官其三子，显示前线情报存在严重误差。原文定位：`P0101`。
- 宋廷录用望都战没将士子孙，并追查临阵不护主帅、先行逃跑者；李福削籍流封州，王升杖配琼州，并诏戒诸路将帅。原文定位：`P0102—P0103`。
- 真宗随后制定详细北边阵图：镇、定、高阳三路会定州夹唐河为大阵，另分威虏、保州、北平、宁边、邢州诸军按敌军走向互相夹击、截辎重、断归路。这是下一轮战争的制度化部署，不提前作为战果。原文定位：`P0105`。
- 岭南流放命官获给缗钱归葬。原文定位：`P0106`。
- 陇山西首领秃逋等贡马，并愿附宋大军作战；本卷只见政治、军事合作意向。原文定位：`P0108`。
- 辽追赠李继迁尚书令并派丁振吊慰；党项入贡辽，准布诸部亦附辽。原文定位：`P0109—P0110`。
- 蒲阴因处于高阳关会兵路而被命修城。谢德权提出沿边百姓多举家入城、兵力不宜过度集中，应分戍镇、定、高阳并加修澶州北城、德清壕堑；其后的实际围城已移入战役JSON。原文定位：`P0111`。

## 三、跨卷连续性

- 向前：卷022的清远军失陷、河外砦降西夏和六万援灵州，到本卷得到明确结果：护粮行动此前已败没，灵州后来因饷道断绝、救军未至而陷落。清远与灵州必须分别结算，不能把本卷补证重复叠加到卷022已经登记的清远BCN。
- 向后：李继迁在本卷取得灵州、改西平府后，攻西凉又遭六谷反击，中箭败归并死亡；李德明继立后立即又遭丰州诸族击败。卷024要继续核李德明能否稳定继承西平军政基础，以及宋、辽对其招谕、册封后的实际状态。
- 向后：宋辽方面，本卷望都—康村失利后，宋已重新配置定州—唐河大阵，蒲阴又被实际围攻但结果不明。卷024将进入景德元年更大规模南侵，不能因后来的澶渊议和倒灌本卷SB。
- 向后：财政民生压力仍在上升。田锡已同时记录帑藏、仓廪不足、土地荒芜、百姓贫困和五七万强壮离农；卷末三司刚完成合并。下一卷应继续观察边役、军粮、赋敛、蠲欠与灾赈是否真正改变这些压力。
