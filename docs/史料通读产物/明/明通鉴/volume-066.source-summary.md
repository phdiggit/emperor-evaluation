## 一、财政、民生、工程与灾害

- **辽东遭遇持续三年的全镇性大饥荒。** 嘉靖三十八年，巡抚侯汝谅称辽左“全镇被灾，三岁不登”，巷无炊烟、野多暴骨，斗米曾至银八钱，并出现“母弃生儿，父食死子”。朝廷发太仓银六万两籴粮转运，岁末另给五万两备来春种具。这是本卷最强的民生负证之一；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0212—L0215`。

- **辽东饥荒推动重新试行海运粮。** 朝廷准从天津海道转粟入辽，先动赈银五千两造船二百艘，每舟约载粟一百五十石；登莱海道另待勘议。该项是救荒运输与财政工程，不计入任何具体战役M/A；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0256—L0260`。

- **受寇地区另有专项赈济。** 蓟州、遵化、丰润、玉田等地因前段受寇，发通仓米一万石、太仓银二万两赈济；这是战后独立政策，不重复进入战争账户。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0194`。

- **嘉靖三十八年连续蠲免河南、顺天、河间、保定、永平、大同、苏松及浙江杭嘉湖金华等被灾税粮。** 原文定位：`SRC-MINGTONGJIAN-066-2550870-L0226—L0234`。

- **太仓开始实行两月一报收支。** 嘉靖三十八年七月，令仓场侍郎每两月具报太仓出纳，显示中央财政库存已需要更高频监督；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0188`。

- **顺天、永平饥荒继续动用通仓。** 嘉靖三十九年二月，发通仓米二万五千石赈二府；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0304`。

- **鄢懋卿总理四运司盐政后急剧增课。** 两淮余盐旧额约六十万两，后连同工本等增至九十万，鄢懋卿又推至百万；另搜括四司残盐，使新增额合计逾百万。史文同时记其所至驿骚。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0307—L0309`。

- **倭患军需存在大额侵盗。** 嘉靖三十九年六月查核，自倭患以来赵文华被指侵军需十万四千、周珫二万七千、胡宗宪三万三千、阮鹗五万八千，其他亦有万计、数千计者；皇帝以胡宗宪有功而不问。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0359—L0361`。

- **山西三关饥荒与军饷并行拨款。** 朝廷发太仓银八万两，其中七万给军饷、一万赈饥民，显示边镇军费与民生救济同时挤压中央财力；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0346`。

- **中原财政民生困局被明确概括为“征敛繁急、贪吏肆行、水潦荐至、民不堪命”。** 章涣把中原盗起与赋役、吏治、水灾联系起来，并警告黄河大工一兴便会聚众数万、进一步增加风险。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0372—L0379`。

- **京师严寒导致贫民冻饿死亡。** 嘉靖三十九年十二月，朝廷发仓米一万石煮粥，并命五城掩埋暴骸；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0430`。

- **广东推行“均平里甲”，减少基层杂役盘剥。** 潘季驯按州县冲僻核定公费，由民按丁力输钱于官，供应过客和公费改由官府发银，里长仅负责公务勾摄，甲首放归农业；史文明言“广人便之”。他又指出岭南官吏把地方视作“利薮”、屠剥导致百姓怨而为盗。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0449—L0450`。

- **山东济南等六府饥荒获五万石仓粮赈济。** 临清、德州二仓出三万石，徐州仓出二万石；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0456`。

- **京师嘉靖四十年再发饥荒与疫病。** 三月先发米一万二千石赈京师饥民；四月京师疫，流民大量入京，又发京仓米四千石、内库制钱三百万，按归程远近给路费。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0467`、`L0481`。

- **山西、陕西大地震造成城垣、墩台、房屋普遍倒塌。** 宁夏、固原尤重，史文称“压死军民无算”；此为自然灾害人员损失，不进入战争P。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0511`。

- **九边粮饷继续形成大规模中央支出。** 嘉靖四十年六月，太仓先发十五万两赴宣大收籴，另给大同主兵三万、宣府和辽东各二万，以及山西、延绥、宁夏、固原、甘肃、蓟州、密云等多镇银两；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0513`。

- **边费申报存在明显虚冒。** 许论奏密云、昌平防秋须银三十余万，经给事中核查取得虚冒证据，遂被夺官；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0517—L0519`。

- **江南七府发生大水，平地积水数尺。** 苏、松、常、镇、杭、嘉、湖获破例赈济并免本年秋粮；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0558`。

- **陕西固原、宁夏地震后拨银一万一千两用于修筑与赈济。** 太仓八千、省内事例银三千；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0560`。

- **永寿宫火灾毁掉乘舆服御和先世宝物。** 随后又以此前三殿大工余材迅速重建，十旬完成新西苑宫；这反映连续宫殿工程仍在消耗国家工程能力和材料。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0581—L0588`、`L0642—L0644`。

- **辽东、江南继续赈灾。** 嘉靖四十年七月发太仓银二万两赈辽东；江南水患则允许留苏松常镇开纳事例银以及浒墅、北新关船料银备赈。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0528`。

- **九边秋防另增四万两机动饷金。** 杨博要求宣大互相策应并确保主客兵饷不断，皇帝令户部在年例外另发四万两；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0548`。

- **嘉靖四十一年陕西、宁夏地震又造成边墙倾圮。** 朝廷发太仓银二万二千两兼作修筑和赈济；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0637`。

- **甘州增设茶马司，以四川保宁茶课全征本色助易番马。** 这是边疆财政与马政制度调整；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0648—L0649`。

- **嘉靖四十一年理财十四事的重点转向“省兵食”。** 皇帝又因边饷侵冒多端，要求抚按严革积弊；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0715`。

- **龙涎香采购显示内廷奢用与财政尺度失衡。** 户部尚书高燿从禁中购得八两龙涎香用于万寿建醮，给价银七百六十两，并因此获升赏；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0720—L0722`。

- **《永乐大典》因三殿火灾险些毁失，遂启动百余人重录工程。** 高拱、张居正等参与校录；这是大型文化与行政工程，但与战役无关。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0726—L0729`。

- **三殿重建完成并全面改名。** 奉天殿改皇极、华盖改中极、谨身改建极等；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0730—L0738`。

- **中央又发内帑钱七百万籴谷入京、通二仓。** 外地赃罚银也统一用于籴谷入仓，属于扩大储备的财政措施；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0742`。

- **东南倭患造成长期额外加派，名为“提编”。** 南畿、浙闽均有额外提编，江南单项达到四十万；虽议裁革，史文直言“提编之额卒不减”。何煃同时列举养兵银、料价、募兵、壮丁、乡兵、采木颜料、预征等多重负担。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0749—L0750`。

- **宗藩禄米规模被指出远超京师年度粮赋。** 林润称天下财赋岁供京师粮约四百万石，而各王府禄米合计八百五十三万石，要求按十年平均重新核算兵荒蠲免、王府禄米与国家费用。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0765—L0767`。

- **两淮盐课加派最终被撤回。** 徐爌指出余盐从六十万增至九十万、再至百万，导致“官追于商，商追于灶，逃亡日多”；户部同意恢复六十万旧额。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0787—L0789`。

- **福建受寇州县获免税。** 嘉靖四十一年十一月，免福建被寇各州县税粮；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0782`。

## 二、政治秩序、外交与人口变化

- **胡宗宪在嘉靖三十八年遭系统性弹劾，但因“有功”未被追究。** 罗嘉宾等列举养寇、饰功、贿权门、侵边饷等多项问题；皇帝最终不问。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0196—L0199`。

- **王忬因蓟镇失事被严嵩集团借机处死。** 原判戍边后，皇帝改论斩；史文明确把严嵩、严世蕃与王世贞父子旧怨列为重要政治背景。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0168`、`L0179—L0183`。

- **任环在倭患中开放苏州城门收容被寇乡民，“全活以数万计”。** 这是战争背景下的平民保护事实，但并非新的武装阶段，故留在非战役旁录。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0254`。

- **戚继光开始建立独立训练体系。** 他认为卫所军不习战，募义乌、金华三千人，训练击刺、长短兵和适应南方地形的阵法，并整顿战舰火器，遂形成“戚家军”。这是军事制度建设，不是单场战役。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0289`。

- **南京振武营军变的直接制度诱因得到朝廷承认。** 科道认为军变始于马坤削减粮饷折色，马坤因而被罢黜；实际军变本身见战役JSON。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0320`。

- **辽东开放登莱海路民间贸易并免税。** 居民可自备船只领文引往来，地方仅负责稽察异常；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0322`。

- **福建叛兵、地方群盗与中原盗起都被史文反复联系到财政和治理失灵。** 章涣指出征敛、贪吏、水灾使民“往往聚而为盗”；福建募广兵又因行粮被扣而与盗合流。前者为社会治理判断，后者实际武装阶段见JSON。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0379`、`L0434—L0437`。

- **陶仲文、陆炳相继死亡。** 陶仲文以方术获宠近二十年；陆炳长期与严嵩集团共掌权势，文武大吏争走其门，“岁入不赀”。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0420—L0426`。

- **潘季驯直陈岭南吏治与盗乱因果。** 他称地方官把岭南视为“利薮”，“屠剥万状”，百姓怨而易动，故请求把均平里甲制度固定为全省通制。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0449—L0450`。

- **鄢懋卿盐政伴随严重贪污与压迫。** 林润列举其需索馈遗、受状取富民财、宴会日费千金、虐杀平民、加派盐商几至激变；海瑞、霍与瑕因不肯厚供接待反遭打击。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0539—L0543`。

- **严嵩集团在嘉靖四十一年终于倒台。** 邹应龙弹劾严世蕃公开卖官：项治元以一万二千金转吏部、潘鸿业以二千二百金得知州；严氏在南京、扬州等处广置田宅数十所，地方仆役仗势侵夺，史文把“民穷财尽”直接联系到其贪婪和官场买官成本向百姓转嫁。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0670—L0690`。

- **严嵩罢相后，嘉靖仍一度提出传位、退居西内专祈长生。** 徐阶等坚决反对；皇帝同时威胁再言严嵩案者与邹应龙同斩。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0692—L0696`。

- **献俘礼被再次废止。** 张琏、萧雪峰被擒后，兵部请送京献俘，皇帝以赵文华曾“假贼冒功”为由，令就地处置，并称“自是遂罢献俘”。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0709—L0711`。

- **严嵩集团倒台后出现一轮党附官员清理。** 多名与严氏有姻亲、请托、贿赂关系的官员被革职闲住或追夺官荫；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0743—L0747`。

- **岭南、苏松基层盘剥被再次指为盗乱根源。** 陈瓒称岭南官职成为“渔猎”百姓的肥缺，苏松粮长、坊长、库役又承担代逋、迎送、宴馈等额外成本，直言“弭盗之策，无急于此”。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0769`。

- **嘉靖晚年求方术进一步扩大。** 命御史分行天下搜求方士、符箓、秘书，两年后得法秘数千册并荐方士多人；原文定位：`SRC-MINGTONGJIAN-066-2550870-L0774—L0778`。

- **胡宗宪在卷末被罢总督并械送京师，但皇帝最终以其平汪直有功释放闲住。** 浙直总督此后罢而不补。原文定位：`SRC-MINGTONGJIAN-066-2550870-L0780`、`L0803`。

## 三、跨卷连续性

- **福建倭患在卷末进入更严重阶段，未闭合。** 兴化府被攻陷，是此前东南倭患首次攻破重要府城；卷067必须沿 `MTJ-MING-XINGHUA-WOKOU-1562-1563` 核俞大猷、戚继光、刘显、谭纶会剿、兴化收复及福建海防后效。

- **宁德—横屿链尚未完全闭合。** 本卷一面有戚继光克横屿、牛田和六十营，另一方面新倭持续到来并最终陷兴化；不能把横屿一胜倒灌为福建整体SB4。

- **东川阿堂本人已死，但东川控制权仍未稳定。** 府印流向不明，安万铨留水西兵三千并私分印信；卷067继续核禄氏承袭和水西是否形成实际控制变化。

- **黄启荐惠潮山贼、江西若干流贼尚无明确终局。** 后卷如出现平定、招抚或再次攻城，应沿各自campaign_group续写，不能把本卷短期击退视为终结。

- **北边俺答、济农、土默特诸威胁均仍存在。** 本卷虽有灰河、宣府居庸、半坡山等局部胜利，但辽东、宁夏仍遭大股入侵，土默特甚至攻破锦川营并伏杀黑春；后卷继续核同一战略方向。

- **南京军变已暂定但兵纪后效未闭合。** 原文记“兵自此益骄”；后卷若有留都军兵再次冲突，应沿军饷—军纪链承接。

- **张琏三饶、容山韩甸、程乡潮寇三条内乱链在本卷有明确终局。** 后卷如仅追叙，不再重复创建终局战役卡。
