## 一、财政、民生、工程与灾害

- **边饷告急后，纳粟、纳豆、输马与入监、冠带、复职直接挂钩，并由宣大扩至两畿、诸布政司和辽东。** 郭佑指出此举源于“国用耗乏”，强调“藏富在民”；曹凯反对以四千石豆换世袭指挥，称会以“生民膏血”长期供养无功子孙。景帝最后只禁止以后新授世袭，既授者不追夺。原文定位：`SRC-MINGTONGJIAN-029-2504695-P0139`。
- **灾荒蠲免连续实施。** 正月免大名、真定、开封、卫辉被灾税粮；三月因旱免畿内逋赋及夏税；五月免山西被灾税粮；十月又免畿内逋赋。原文定位：`P0146`、`P0169`、`P0194`、`P0243`。
- **对土木后被掳人口设置强力返还激励。** 自还军人免差役三年、民人免徭役终身，并给银布；另设杀敌与杀额森、巴延特穆尔、喜宁的高额赏格。此属人口回流和军事奖励政策，不把赏格本身当战果。原文定位：`P0151`。
- **军功冒滥已成为明确的财政、军政问题。** 罗通指边将常夸大战果并质疑德胜门后升赏过滥；于谦反驳其夸张数字，但景帝随后敕令录功不得再冒滥。原文定位：`P0159`。其中“阵亡三千余人”属于卷028旧战的后见增证，已在战役 JSON 的跨卷复核中处理。
- **山东饥荒、畿内受寇州县及大同被寇军民先后获得赈济。** 原文定位：`P0187`、`P0201`。
- **山西同时遭遇兵灾与荒歉。** 原文直称“山西兼遘兵荒”，朱鉴一面整边备、一面抚灾民；景泰二年十月又免山西被灾税粮一百零八万二千余石。原文定位：`P0196`、`P0306`。
- **南京出现流民集中与荒年转化为治安风险的忧虑。** 于谦称“中原多流民”，若再遇岁荒可能啸聚，要求南京守备、巡抚预先抚辑。原文定位：`P0181`。
- **西南长期用兵影响近畿人口与兵源安排。** 永乐以来安置近畿的降人，在额森入寇时有内应者；于谦借西南征调把其中精骑陆续外派，再迁其家属，以分散潜在内患。原文定位：`P0238`。
- **黜退朝觐官被改作口外运粮劳役。** 这是把官员处分直接转为边粮运输负担。原文定位：`P0260`。
- **一次度僧、道五万余人，与人口流徙和边军缺员形成直接冲突。** 于谦反对称“四方多流徙之民，三边缺战守之士”，未被采纳。原文定位：`P0262`。
- **朝廷以授荒田、贷牛种恢复京畿和山东农业。** 命巡抚举廉能官专司劝农，给民荒田并借耕牛、种子。原文定位：`P0268`。
- **陕西再饥时，地方军民主动请求陈镒复任。** 其理由正是陈镒此前蠲租、赈贷有效，军民万余人向监司请愿“得陈公活我”。原文定位：`P0278`。
- **贵州在连续苗乱后被要求恢复卫所屯田。** 目的兼具军粮、生产和守备恢复。原文定位：`P0285`。
- **景泰二年六月明确免京军余丁，以“资生业”。** 这直接承认军户额外丁役对家庭生计的挤压。原文定位：`P0287`。

## 二、政治秩序、外交与人口变化

- **喜宁被诱至野狐岭拘捕并处死后，上皇判断边境会“稍宁”。** 本段无武装交战，故不立战役卡；它作为情报网络被切断和司法处置事实保留。原文定位：`P0155`。
- **迎还上皇经历多轮廷议和外交。** 李实、杨善等先后出使，景帝多次不愿在敕书中明确奉迎；杨善最终说服额森送还，上皇八月回京并被安置南宫。原文定位：`P0218`、`P0221—P0223`、`P0228`。
- **上皇归国没有恢复帝位。** 景帝亲迎后双方互述授受，随后百官朝谒上皇并大赦，南宫遂成为新的政治安排。原文定位：`P0228`。
- **金英失势暴露内官网络的市恩、家人中盐与官员贿赂问题。** 金英最终被禁锢不用；石璞因曾行贿被论斩，后获宥改理大同军饷。原文定位：`P0246`。
- **景泰二年对瓦剌恢复岁贡但不愿恢复对等报使。** 托克脱不花使者还送被掠招抚使高能等，王直等主张报使，景帝仍坚持不遣。原文定位：`P0281`。
- **岷藩广通王、阳宗王的谋逆计划在全面发动前败露。** 伪敕、银印、诱苗计划未获多数苗首响应，两王被削爵幽禁；只有蒙能已经率苗兵行动并转叛广西的武装部分进入战役卡。原文定位：`P0309`。
- **言路在景泰初一度较开，但何观因批评大臣等言论被下狱杖谪。** 林聪、叶盛等曾以刘球旧案为戒，阻止把言事再变成死罪。原文定位：`P0315`。
