# 《明通鉴》卷051非战役事实通读总结

- **范围与版本**：固定修订 `2550854`，正文锚点 `SRC-MINGTONGJIAN-051-2550854-L0112`—`L0356`。本文件只保留非战役事实；具体交战、武装攻掠、战果与战争回报全部移入同卷 battle adjudications。

## 财政、赋役与民生

1. **陕西已出现极重的灾乱叠加与人口流移，而朝廷仍增设织造。** 任忠称陕西地瘠早寒，沿边郡县屡遭寇掠，耕牧旷废；腹里地区又因调集士马、挽运刍粮而疲敝，兼有麦槁、苗稼雪霜之灾，至“逃窜流移，十室而九”。在此背景下增派中官织造，单项费用“辄数万”，催督又急，任忠明确判断“民不堪命”，奏疏未获回应。〔L0127〕
2. **灾区有局部蠲免，但与织造扩张并行。** 二月免陕西巩昌府及秦、陇等受灾州县上年税粮；三月又免大同府所属受灾州县税粮。〔L0129、L0131〕
3. **陕西织造进一步挪用盐课。** 镇巡官请求把两淮、浙江、四川、河东盐课拨作陕西织造经费，获准。此举意味着织造并非只由陕西本地承担，而开始吸收跨区域盐课财政资源。〔L0134〕
4. **京城民居因宫廷工程/空间需求被直接拆毁。** 朝廷毁积庆、鸣玉二坊民居，给事中请求停止而未获采纳。〔L0140〕
5. **湖广大范围水灾获专员赈济。** 武昌、汉阳、荆州、岳州、黄州、襄阳、德安、常德、安陆、沔阳等府州及所属受水灾，巡抚请求特遣大臣并发银赈济，朝廷任吴廷举办理。〔L0174〕
6. **武宗驻宣府直接扰动城市生活。** 江彬营“镇国府”，将豹房珍玩、女御运入；武宗夜入高门大户索妇女，富民往往厚赂江彬求免。随从军士柴薪不足，直接拆民房作燃料，造成“市肆萧然，白昼户闭”。〔L0181〕
7. **河决城武。** 黄河水患继续构成地方灾害压力。〔L0183〕
8. **巡边征发绕开常规财政程序。** 武宗自署“威武大将军”，凡征发皆用所谓“钧帖”，内阁指出旧制军马钱粮须奉敕旨，担忧此种非常规凭证导致冒领、诈取和地方无法核验。〔L0185〕
9. **宣府一次性赏劳预算高达银一百万两，户部抵制后仍实发五十万两。** 这是本卷最明确的大额中央财政支出之一。〔L0187〕
10. **京畿与北直隶水灾、歉收、流民继续扩大。** 正德十三年初，顺天、保定、河间灾情最重，真定、大名等五府次之，“人民艰食，流移日多”。此前虽已发户部银、德州仓粮并遣官赈济，奏疏仍判断数量不足，遂另设大臣分道赈济并请求蠲免。〔L0224〕
11. **徐、淮以南出现千里饥馑。** 南京官员称去冬雨雪成灾，民众无衣无食，父子流移、兄弟离散，并有自尽者；材料把民穷与潜在盗乱直接联系起来。〔L0232—L0234〕
12. **大水灾区获得较大规模粮银留拨。** 庐州、凤阳、淮安、扬州及徐州留兑运粮五万五千石；另留折粮阳脚价银四万两，并拨淮盐、浙盐价银各三万两，合计明确银额十万两，分给受灾府州县。〔L0239〕
13. **全国性灾情与财政压力被内阁再次概括。** 杨廷和等称“四方水旱相仍，饿殍载道”，朝廷屡差官赈济尚恐不及，并明确反对继续劳师费财。〔L0242〕
14. **山东水灾继续赈济；京师流民按人给米三斗，并掩埋死者。** 这是少见的明确人均救济口径。〔L0246〕
15. **巡幸造成基层恐慌与征索预期。** 武宗赴密云时，民间盛传将搜括子女、财物用于进奉，百姓纷纷躲避；永平知府毛思义试图禁止无正式文书的扰民征索，反被逮捕降官。〔L0277〕
16. **供应名义下的科扰侵盗受到压制者反被治罪。** 武宗巡幸河西务时，指挥黄勋以“供应”为名科扰侵盗；巡按御史刘士元追究后遭权幸中伤，被野外重杖并系狱。〔L0285〕
17. **大规模巡幸谣言本身已引发逃亡与非正常婚嫁。** 正德十三年九月，内阁称民间听闻武宗将巡山陕、河南、山东及南北直隶后，“扶老携幼，逃避山谷”；窦明等又指出乾清、坤宁二宫营建已向南北直隶、山东、河南征取物料，地方再为迎驾科敛，百姓流移，甚至匆忙把幼女嫁出以避搜取。近侍沿途先掠良家女子，至数十车，在途已有死亡；地方还需另备女衣首饰作赏赉。〔L0315—L0316〕
18. **武宗自封镇国公并令岁支禄米五千石。** 此项自设名号同时带来固定俸粮支出。〔L0318〕
19. **河间受灾州县再获税粮蠲免。** 〔L0323〕
20. **皇帝长期在外使司法决策出现积压。** 内阁称重囚三覆、处决均须圣裁，前一年因驾外出而监候；至本年冬至前，案件继续积压，监狱“已不能容”，既不能依法决断，也不能放心交臣下处置。〔L0330〕
21. **“火牌”成为大规模非常规调遣工具。** 一次调西官厅勇士及四卫营兵六千二百余人、马六千五百余匹赴宣大，又征太监九十一人赴延绥，家人匠役均给驿传。内阁指出此法绕过正常旨意与司礼监流程，也把京师宿卫抽向边外；材料称此后竟“遂以为常”。〔L0338—L0340〕
22. **年末继续集中蠲免与赈饥。** 水灾后免江西南昌等七府夏税，并免应天及安、宁、池、太等五府税粮；又免山东济南等六府受灾州县秋粮，赈杭州、嘉兴、湖州三府饥荒。〔L0344、L0350、L0352〕

## 政务、权力结构与制度

23. 王守仁到赣州后停止反复征调狼兵、土军的旧做法，称此前每次动辄经年且“糜费逾万，有损无益”，转而从江西、福建、广东、湖广分省精选少量兵力，并建立十家牌法、情报网和新的军队编组。此处只记制度与成本判断，具体作战另见战役裁决。〔L0123、L0161〕
24. 宁王宸濠谋逆的内部告发在正德十二年已出现，但内外权贵多受其贿，告变者反遭处罚，风险未被正式处置。〔L0144〕
25. 钱宁等权幸显著侵蚀司法独立：厂卫校卒对三法司官员不逊，处理校卒的官员反被下锦衣卫狱；材料直称各部卿佐对厂卫校卒也需降颜礼遇。〔L0160〕
26. 武宗长期巡边和微服出行造成中央礼制、决策和治安责任反复悬空；多次郊祀、太庙等典礼由臣下代行，京官甚至被禁止出城。〔L0211—L0215等〕
27. 钱宁、江彬体系继续借诏狱和厂卫打击执法官员。张士隆、许完因查办权幸相关案件被构陷；董相、郑懋德、林桂等也因惩治江彬部卒或追查权幸案件而入诏狱。〔L0253、L0264—L0265〕
28. 宁王势力继续通过地方礼仪、镇守中官和诏狱压制监察。江西巡按范辂反对宁王僭用朝服礼仪并弹劾宁府伶人、镇守太监毕真，最终反被诬陷下狱。〔L0286〕
29. 钦天监因多年日月食推算误差提出修历，主张结合古法、新法、西域《九执历》及各省土圭测候进行校验；礼部最终同意继续参验而非立即废旧法。〔L0356〕

## 本卷非战役底色

正德十二至十三年的非战役材料呈现出很清晰的叠加结构：**北边战争和皇帝巡边并没有替代原有财政负担，而是与织造、宫殿营建、盐课挪用、非常规军费和沿途征索叠加；与此同时，陕西、北直隶、徐淮、山东、江南连续出现灾荒、人口流移与赈免。** 史料中既有百万两级军费请求，也有五万五千石赈粮、十万两灾银以及“十室而九”流移这类高强度民生指标。制度层面则表现为皇帝长期在外、厂卫权幸干政、非常规军令和地方供应压力同时扩张。
