## 一、财政、民生、工程与灾害

- **哈密贡使与贡马数量已被朝廷明确视为无益财政负担。** 一次贡马二百匹却有使者二百六十人，沿途供给浩繁；商辂等直言这是用“中国有限之财”供“外蕃无益之费”，最终规定哈密岁贡马不得过二百、使者不得过四十。原文定位：`SRC-MINGTONGJIAN-034-2575925-P0137`。
- **两广大举用兵再次以纳粟筹饷。** 朝廷开纳粟例以备两广军饷，属于战争引出的独立财政筹措，不把这笔制度性征集重复塞入某一场战役的 `M/A`。原文定位：`P0138`。
- **陕西延安等地旱灾继续蠲粮。** 成化元年三月免陕西延安等府州县被灾税粮八十七万一千余石。原文定位：`P0156`。
- **边镇屯粮负担被统一减免三成。** 五月规定各边军民应输屯粮俱减十分之三，显示长期边防供给已需要中央直接缓解。原文定位：`P0173`。
- **两畿、湖广、浙江、河南出现大范围饥荒，南阳—荆襄流民尤多。** 原文称老弱转死、壮者流移，南阳、荆襄一带流民达到十余万；朝廷命地方安抚并赈济。原文定位：`P0174`。
- **地方官若在灾荒时仍催科会被追责。** 饥荒背景下，有司仍追征税粮者受到朝廷处分，体现至少在政策层面把灾年催科与地方失职直接关联。原文定位：`P0178`。
- **京军名额与实际战斗力严重脱节。** 京师号称军士三十余万，但相当部分被权贵私役或以月钱买闲，真正操练的反而多为老弱；同时马瘦、器械不利。朝廷随后从中选十四万精壮重新编练。这里是军费、兵籍、私人役使和实际国防能力脱节的一条重要底账。原文定位：`P0202`。
- **京畿饥荒继续动用赈济。** 成化二年正月赈京畿饥民。原文定位：`P0211`。
- **延庆等地编民丁五千余为土兵，并以减免户租补偿服役。** 这是一条把地方兵役和赋税减免直接挂钩的军民制度材料，不属于单场战役。原文定位：`P0224`。
- **江淮旱荒出现人相食，朝廷调粮四十万石赈济。** 原文称江、淮大旱，民饥甚而有相食者；朝廷从淮、徐等仓发粮四十万石，并安排苏、松等处漕粮借支救急。原文定位：`P0226`。
- **边镇屯粮又一次统一减免三成。** 成化二年九月再令各边军民屯粮减十分之三，说明该负担并非一次性调整。原文定位：`P0239`。
- **延绥防线进行大规模节点迁置和工程化重构。** 原边长二千余里、居民和军士散处塞外，朝廷迁置十九堡，设三十四墩台，并修沟墙、联络守望。其工程和长期守备负担属于独立边防建设，而不是某次入寇的单场战役资产。原文定位：`P0254`。
- **军中私人役使和权贵庇护继续侵蚀军纪。** 太监韦朗私役军士、失律获罪，却因宫中关系获得赦免，构成军队公共人力被私人占用而问责失效的实例。原文定位：`P0267`。
- **商辂等提出包括社仓在内的一组救荒和基层治理建议。** 其内容试图把灾荒救济、地方储备与官员责任制度化，成化帝令有关部门议行。原文定位：`P0292`。
- **浙江、福建、四川、云南银场再次由中官督办开采。** 这延续了前期因国用不足而重启矿课的路径，重新把地方劳役、矿产与内廷监采结合。原文定位：`P0296`。
- **四川十个月内记录地震三百七十五次。** 这是本卷最密集的自然灾害记录之一。原文定位：`P0301`。
- **两畿水旱、四川和广东兵后残破叠加时，臣下明确称“公私困极”。** 奏疏要求停金银、花木等采办和宴乐以纾民力，但并未全部获准。原文定位：`P0307`。
- **河南一度停止额外采办。** 这是对地方非经常性征取的一次直接收缩。原文定位：`P0317`。
- **江西积欠税粮严重，中央反而增派官员专督征收。** 这一处体现灾荒、流民背景下财政追征压力并未普遍放松。原文定位：`P0321`。
- **湖广、江西饥荒继续得到赈济。** 原文定位：`P0325`。
- **四川、辽东有警、江西湖广灾荒之际，宫廷仍计划大放烟火。** 臣下请求把相关费用转用于赈饥，反遭廷杖、贬谪；该事同时反映宫廷娱乐支出、灾荒财政优先级和谏诤成本。原文定位：`P0335`。
- **成化初冗官问题继续累积。** 吏部待选、候补人员至八千余，朝廷考汰其中数百，显示传奉、冗授与正常铨选体系已经形成明显拥塞。原文定位：`P0337`。

## 二、政治秩序、外交与人口变化

- **于谦获得平反性质的政治恢复。** 成化初重新承认其保卫京师功绩，并恢复相关名誉处置，是夺门后政治清算的一次逆转。原文定位：`P0146`。
- **“夺门”功臣的特殊爵赏继续被削除。** 相关封爵逐步撤销，进一步否定天顺初以夺门为政治资本的大规模封赏。原文定位：`P0169`。
- **大藤峡战争结束后的封赏很快遭到质疑。** 赵辅等以平贼奏捷受赏，但实际残余很快复起，韩雍又指出虚报、冒功和善后不足；这些属于战后问责与功赏政治，不把封赏本身记成战争回报。原文定位：`P0257`。
- **刘通、石龙、刘长子等被捕后的市刑、族属处置属于司法清算。** 实际武装阶段已在战役 JSON 内闭合；后续处刑、家属连坐不反向追加战斗 `P`。原文定位：`P0261`。
- **草原内部继续发生首领更替与互相杀害，但不少段落只足以确认政治继承，不足以拆成明朝战争卡。** 本卷对保喇、玛拉噶、小王子等关系的叙述显示边患主体持续重组，并与朝贡往来并存。原文定位：`P0283`。
- **商辂等在灾异中请求召还此前因言获罪的官员，部分得到恢复。** 这构成成化初言路纠偏的一条材料。原文定位：`P0292`。
- **景泰帝庙号、祭祀名义仍有争议，且相关讨论受到政治限制。** 反映夺门以后对景泰朝历史定性的长期延续。原文定位：`P0310`。
- **“翰林四谏”因反对灾荒时仍事宴游、烟火而受杖谪。** 该事件不仅是财政问题，也是成化初言官与宫廷决策冲突的直接样本。原文定位：`P0335`。
- **扬州盐寇平定后的盐政整顿与宦官私盐案相连。** 高明依法没收内官私盐、整顿沿江巡逻和盐务，显示地方治安、盐政与内官特权互相交织；武装平寇本身已转入战役 JSON。原文定位：`P0338`。

## 三、跨卷连续性

- 向前：卷033末赵铎四川叛乱在朱家河击杀何洪、刘雄，本卷完成赵铎终局；大藤峡与两广乱事则由前卷的反复袭扰升级为十六万大军总攻。
- 向后：大藤峡主力虽被重创，但班师、散军后浔州、洛容、北流即再失，广西残余仍未彻底清除；石康在本卷一度被黄公汉攻陷，六菊山反击后实际归属没有写明，均留卷035核验。
- 山都掌父链在本卷急剧恶化到“陷合江等九县、所过屠城、赤地千里”，卷末只写朝廷决定大举发兵，实际进剿和终局必须由卷035继续。
- 玛拉噶在榆林、延绥、固原、宁夏、大同等方向连续活动，河套常驻带来的长期边防问题仍未闭合；开城已经实际陷落且县治迁往固原，属于本卷确认的持续退控。
