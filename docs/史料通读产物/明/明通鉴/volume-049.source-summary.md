## 一、财政、民生、工程与灾害

- **旱灾后连续蠲免陕西与南直隶受灾州县税粮。** 正德八年正月即因旱免西安、延安等府及凤阳等府受灾州县税粮，显示卷首已经处在灾荒—减免状态。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0129`“以旱灾，免……被灾州县税粮”。
- **浙江水灾直接冲击盐业人口与盐课。** 灶丁多有溺死，朝廷免岁办盐课八千九百余引，并命巡视官酌量赈济。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0135`“灶丁多溺死者……免岁办盐课八千九百余引”。
- **平乱封赏扩大为权幸亲属的长期俸禄。** 谷大用弟谷大亮、陆訚侄陆永并非前线主将，却获封伯、岁禄千石；兵部两度反对未能阻止。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0137`“坐而得之……岁食禄千石”。
- **黄陵冈河决后，专任治河仍未控制灾情。** 刘恺把河道南徙归功祭神而治水无策，曹、单一带“被害日甚”。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0158`“恺于治水束手无策……曹、单间被害日甚”。
- **丰城大火造成极大住房损失。** 官民庐舍被焚二万余间，三十余人死亡，户部要求查勘分等赈济。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0165`“焚官民庐舍二万余间，死于火者三十余人”。
- **财政中枢明确出现“征讨烦急 + 岁凶 + 正用不足”的组合压力。** 户部尚书孙交优先保障急需，并对各地饥荒反复请求蠲免、赈济；同时反对云南采银和南京织造追加费用。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0167`“调度烦急，加以岁凶，正用不足……四方告饥，辄请蠲振”。
- **南畿水灾获免税。** 原文定位：`SRC-MINGTONGJIAN-049-2550852-L0174`“免南畿水灾税粮”。
- **大同、河南等地因旱继续分等减免。** 正德八年九月免大同州县卫所夏税之半，并减免河南开封等府、睢阳等卫夏税。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0185`。
- **浙江宁波、衢州一带一次减免秋粮十八万石有奇。** 原文定位：`SRC-MINGTONGJIAN-049-2550852-L0197`“秋粮十八万石有奇”。
- **江西遭遇夏至冬不雨、反复火灾、温疫与盗扰叠加。** 朝廷动用本地预备仓，并拨两淮、浙江盐课银十万两赈济。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0204`“自夏徂冬不雨……温疫流行……盐课银十万两备振”。
- **平凉等六州县水灾再减夏税一万六千三百余石。** 原文定位：`SRC-MINGTONGJIAN-049-2550852-L0208`。
- **宁王宸濠的经济侵夺已显著妨害江西民生与商业。** 御史称其侵夺肥田、掊克富户，控制省城至乡境利益，“商旅不敢出入，舟楫不敢停泊”；要求恢复被侵占田产房舍，但没有得到处置。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0215`。
- **乾清宫火灾源于长期游乐与烟火布置。** 史文称每岁张设费用“浮数万”，宁王又进奇巧，火药误燃使乾清宫内尽焚；灾后虽下罪己诏，但结构性开支只有限调整。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0219`。
- **灾后大臣集中要求停止皇店、边兵滞京、不急工程与织造。** 杨廷和等明确把“罢皇店以通商贾、停不急之工以纾民力、减免各处织造以节民财”列为修政重点，但实际只获少量回应。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0220`。
- **顺天、河间、真定、保定等地饥荒赈济，动用应运京边粮二三成并减逋税。** 原文定位：`SRC-MINGTONGJIAN-049-2550852-L0251`“发存留本年起运京边粮十之二三……又减免逋税”。
- **云南银矿在户部明确警告“贫民赔纳、利归奸徒”后仍被重开。** 采办短额会派给贫民赔纳，过去已因弊害封闭，仍由太监梁裕等主持开采。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0263`“多派贫民赔纳，而利归奸徒”。
- **华北多地继续因灾减税。** 顺天、河间、保定因旱免税；山西平阳受灾免税，真定等四府减半；西安二十一州县、庐凤淮扬等地亦先后获免。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0270`、`L0283`、`L0285`、`L0292`、`L0296`。
- **陕西镇守太监制造一百六十二间铺花毡幄，借差事“朘削”数万金。** 巡抚陈寿把该款扣留备赈，由此得罪廖堂。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0299`“堂以此朘削，赢金数万……寿檄所司留备振”。
- **乾清、坤宁宫重建扩大为多省采木与采购。** 工部从四川、湖广、贵州采木，又在浙江、江西、直隶、徽州买竹木，形成跨区域工程征求。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0302`。
- **河南开封等二十四州县受灾再免秋粮。** 原文定位：`SRC-MINGTONGJIAN-049-2550852-L0316`。
- **宫室重建最终追加全国性白银一百万两，并要求一年征完。** 工部原拟每年带征二成、暂借内帑半数，武宗拒绝动用内帑，命一年内尽征，史文直书“催科旁午，海内骚然”。这是本卷最重的独立财政—民生负面之一。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0321`“计直白金百万两……于一岁中尽征之……海内骚然”。

## 二、政治秩序、外交与人口社会变化

- **降附蒙古人被直接编入御马监勇士，边防大臣担忧其出入禁闼。** 何鉴主张迁置远方，未被采纳。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0120`。
- **边将江彬、许泰获赐国姓并分领京营，边军长期集中京师。** “四镇兵”“外四家”开始成为宫廷军事结构的一部分。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0126`。
- **宁王宸濠势力对江西正常行政的侵蚀已被公开指出。** 胡世宁称宁府屡借火灾夺民市廛、采办扰及旁郡，地方官“承奉太过”，恐使良民因失业受扰转为盗乱。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0238`。
- **宁王以巨额金帛打通权幸，恢复护卫与屯田。** 六科、十三道及南京给事中均反对，指出其已剥削商民、阻断舟航、使邑里萧条，但仍获准恢复。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0242—L0250`。
- **江西官场内斗在“多事之秋”发展到互讦、下狱。** 相关官员互相借宁府与巡按关系打击对方，万余诸生为李梦阳讼冤亦不被采纳。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0257—L0258`。
- **言官因反对权幸与制度弊病反复获罪。** 韩邦靖因要求恢复采纳谏言被下锦衣狱并罢为民，后又下令“凡言事黜谪者，毋再起用”。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0265`。
- **归善王当沍被诬谋反案显示司法受近幸邀功推动。** 查无实据后仍因旧弓弩被废为庶人，牵连者多死狱中，当沍最终触墙自尽。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0309—L0312`。
- **周广因直斥钱宁、番僧、义子等被贬，后又遭郭勋箠击几死。** 反映言路与权幸压制进一步恶化。原文定位：`SRC-MINGTONGJIAN-049-2550852-L0324—L0325`。

## 三、跨卷连续性

- **向前：** 本卷江西姚源、东乡、万年与四川廖麻子等战线均承接卷048以前的招抚—复叛链；卷内多次出现“抚后复叛”，因此战役 JSON 按实际阶段拆卡，不把先前招抚结果当成永久安全收益。
- **向后：** 哈密在本卷正德八年被吐鲁番再据，正德九年派彭泽经略但未闭合；卷050继续出现赤斤、苦峪受掠、哈密城印暂时归还及再次失守。北边小王子、额布勒方向也在卷050继续升级。
- **宁王链：** 本卷护卫、屯田恢复和大规模经济侵夺属于政治—经济事实，不提前算作武装叛乱；若后卷实际起兵，须从实际武装阶段另立战役卡。
