## 一、财政、民生、工程与灾害

1. **建文元年二月的普遍惠民诏覆盖高龄、贫困、灾民和军户。** 高龄者给米、肉、絮、帛，鳏寡孤独、残疾不能自存者由官牧养；同时重农桑、兴学校、赈灾贫民、瘗暴骨、蠲荒田租，卫所军户绝嗣者免再勾补。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0138`“鰥寡孤獨廢疾者，官為牧養”“蠲荒田租”“軍戶絕者除勿勾”。
2. **京师地震后，建文帝下令罢天下诸司“不急之务”。** 这是灾异触发的全国性停缓非急政务措施。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0146`。
3. **江浙重赋田再次获减。** 建文二年下诏均江浙田赋，苏、松、嘉、湖等极重田亩减到“亩不得过一斗”；原文同时明确记载靖难后该地区重赋恢复，因此本阶段的减负本身成立，但持续性有限。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0198`。
4. **战争以外的常规财政民生材料在本卷很少，真正的大规模社会负担主要来自靖难本身。** “前后调兵不下五十余万”“中原赤子困于转输，民不聊生”、彰德拆屋为薪、北平耕牧受扰、徐沛粮运被焚等都属于战争直接成本，已按合同进入战役JSON，未在本总结重复记账。
5. **建文朝对洪武功臣罪废者后裔进行恢复性处理。** 九月下诏录用洪武功臣因罪废黜者的后人，属于政治—社会身份恢复。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0225`。
6. **本卷没有出现新的全国税制、货币制度或大型非军事水利工程。** 财政民生评价不能因战争叙事占篇幅而遗漏这一“常规治理材料稀少、战争汲取极重”的结构差异。

## 二、政治秩序、外交与人口变化

1. **《太祖实录》在建文元年开始纂修，建文三年卷末完成《太祖宝录》。** 首次修史征集董伦、王景、方孝孺、杨士奇等人；后续靖难将改变这一史料体系。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0137`、`SRC-MINGTONGJIAN-016-2445865-L0272`。
2. **建文帝追尊父母、立后与太子，并进一步削弱藩王制度权力。** 二月规定诸王不得节制文武吏士。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0138`、`SRC-MINGTONGJIAN-016-2445865-L0140`。
3. **方孝孺主导大规模复古官制改革。** 六部、都察院、通政司、大理寺、詹事府、翰林院及内外官阶大量改名改制；当时即有人认为属于“不急之务”，建文帝仍全面采纳。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0142`。
4. **削藩继续升级并造成湘王自焚、齐代岷诸王被废。** 这些事件本身没有形成双方军队争夺节点的实战，故仍归政治秩序而非战争成本。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0154`、`SRC-MINGTONGJIAN-016-2445865-L0157`。
5. **靖难真正爆发前，中央已进行针对燕王的军事准备，但三月阶段尚未开战。** 宋忠率三万屯开平，耿瓛、徐凯分练山海关、临清，北平和永清卫被调离，并密令张昺、谢贵防燕；这是战争前置部署，实际武装冲突从七月围燕府开始。原文定位：`SRC-MINGTONGJIAN-016-2445865-L0150`。

## 三、跨卷连续性

- **靖难父链正式建立。** 卷015仅有练兵、内应与监控，本卷 `L0159—L0160`首次出现围燕府、射箭、杀张昺谢贵、夺九门和公开称兵，故靖难战争成本从这里起算。
- **建国启动账：** 燕王在北平夺取可持续军政中心后进入 `REGIME_EMERGENCE`；随后通蓟居庸怀来、大宁三卫和保定等阶段按实际控制分别记录 `TERRITORIAL_EXPANSION/REGIME_CONSOLIDATION`，没有把1402年最终夺位倒灌到1399—1401年的阶段。
- **控制持续性强制复核：** 本卷末作者明确总结，燕军三年间“所克城邑，兵去旋复为朝廷守”，当时真正稳定据有的只有北平、保定、永平三郡。因此沧州、顺德、广平、大名等此前阶段性BCP在JSON中均标明 `REVERSED` 或短期，不虚构为长期扩张。
- **战争财政：** 建文朝前期已出现五十余万调兵与中原转输困敝，后期又新募淮南民兵号四十万；卷017必须继续核这些动员是否投入下一轮南下、是否造成新的人员和财政损害。
- **燕军南下：** 卷末燕军烧真定军储后再次南下，并决定“毋下城邑，疾趋京师”；实际跨淮—灵璧—南京终局尚未发生，交卷017继续。
- **麓川：** 卷015刀幹孟已被斩、七万众降，本卷未见同一集团复起，可作为一卷期内 `SB4` 持续旁证，但不能仅凭沉默外推永久稳定。
- **倭寇：** 卷末又有倭寇登陆象山并杀知县，说明卷015山东—浙江沿海袭扰并未形成结构性终结；两卷应保持同一沿海安全风险主线。
