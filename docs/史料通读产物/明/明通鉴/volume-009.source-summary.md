## 一、财政、民生、工程与灾害

- **连续蠲免北方及边区灾伤田租。** 洪武六年正月先免辽东金、复二州旱灾税；六月又免北平、河间、河南、开封、延安、汾州被灾田租；七月命户部追稽渡江以来各省水旱灾伤，按灾情分数优恤。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0131`、`L0163—L0165`。
- **真定等地出现严重饥荒，百姓已食草实、木皮。** 饶阳知县郭樌上报后，朝廷查知晋、冀等州亦饥，遣兵部尚书刘仁分赴州县赈济并蠲租。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0190`。
- **拒绝地方贡品以免劳民。** 潞州进人参时，朱元璋称此前金华香米、太原葡萄酒都已停止，国家以养民为务，不应因口腹之欲加重采办运输。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0193`。
- **《大明律》六百零六条颁行，立法叙述仍强调刑罚只是“药石”。** 朱元璋把仁义比作充饥膏粱、刑罚比作治病药石，要求新律“务合轻重之宜”；但同卷又明言自己因惩元末“宽纵”而颇用重典，形成明显张力。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0179`、`L0199`。
- **精简僧道机构，直接以“蠹财耗民”为理由。** 天下府州县只留大观寺一处集中僧道，无戒行、不能通经典者不得领取度牒，四十岁以下女子不得出家为尼。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0203`。
- **军士训练开始按骑射、步射成绩制度化考核。** 能者奖赏，不合格军士遣回，自都指挥以下将官降官、夺俸有差。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0210`。
- **北方军屯明确以“苏民困而实军储”为目标。** 彰德、济宁、真定等处实行三分守城、七分耕作，每人授田五十亩、给牛种，官税亩一斗；朱元璋直言边镇长期食租于民会令“民力日疲、军政日惰”。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0219`。
- **为备倭一度拟把温、台、庆元三府十一万一千七百余人编军，后因牵连平民而立即撤销。** 吴祯最初籍方国珍旧部、无田粮沿海民及旧船户入卫，宁海知县王士宏指出执行中挟私牵引平民，朝廷随即罢止；随后转而增造多橹快船、以四水军卫巡海。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0220`。
- **海贸与海禁在同一政策链中反复。** 一度恢复宁波、泉州、广州等市舶司，海外贡船可附载方物贸易；对日本因“叛服不常”限定十年一通市、人数和船数受限，随后又因担心沿海军民私通取赂而暂罢市舶司。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0220`。
- **松江水灾赈八千余户，每户给钱五千。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0222`。
- **真定等四十二府州灾区免租，苏州饥民赈三十万户，并减苏、松、嘉、湖极重田租之半。** 这是本卷最大规模的直接赈济和减税记录之一。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0242`。
- **陕西、山西、山东、北平、河南多地雹蝗并蠲田租。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0249`。
- **建立战殁军士遗属、避兵流散者和远宦死者家属救助。** 阵亡军士父母妻子无力自存者由官赡养；避兵离散或客死遗下老幼者资遣还乡；远宦卒官而家属不能归者，由有司给舟车。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0260`。
- **河间、广平、顺德、真定再因饥荒获赈并蠲租税。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0264`。
- **洪武八年建立面向“穷民无告者”的最低生活救助原则。** 命地方对无告穷民给屋舍、衣食，朱元璋以自己早年亲见鳏寡孤独饥寒为由，要求“不可以使天下有一夫不获”。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0294`。
- **黄河决开封大黄堤，发民夫三万堵决。** 这是本卷规模最大的明确工程徭役数字。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0302`。
- **刑罚与劳役结合继续扩大。** 各处人民杂犯死罪以下者改为终身工役；官吏犯私罪，轻者屯种、重者工役，均谪凤阳。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0306`。
- **钞法正式实行，同时留下强制收铜的民生负面。** 此前严禁私铸并责民出铜，民众常毁器皿输官而“颇以为苦”；洪武八年造大明宝钞，一贯准钱千文、银一两，四贯准黄金一两，并禁止民间直接以金银货易。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0312`。
- **彰德、大名、临洮、平凉、河州灾区免租，并停止中都营建。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0322`。
- **朱亮祖曾欲以军法强征济宁五千人浚临清河，方克勤拒绝骤役百姓。** 恰逢大雨使河水上涨、舟师得行，拟征五千民夫遂免。该条清楚展示军用交通与地方民力之间的冲突。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0324`。
- **河州茶马贸易因货币变更受阻后改以绫绢、巴茶购马。** 钞法改变后番人不便、马匹来市减少，朝廷遣中官携丝织物和茶至河州交易；史文明言中官外使自此开始。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0326`。
- **高邮州水灾免租六万三百余石，并同时赈济。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0331`。
- **开封、祥符等多县及淮安、盐城水灾均免租。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0353`。
- **苏州、湖州、嘉兴、松江、常州、太平、宁国、杭州水灾均遣使赈济。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0362`。
- **粮长获得特殊刑罚优免。** 杂犯死罪、流徙者止杖，不输作使，仍掌税粮；又允许部分犯罪纳铜赎罪。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0366`。

## 二、政治秩序、外交与人口变化

- **暂停科举十年期由洪武六年开始。** 朱元璋认为有司所取多能作文而不能措诸实事，故暂停科举，改以察举德行为本、文艺次之；另开文华堂、历事监生等途径培养和试用人才。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0136`、`L0139`、`L0154`。
- **对地方官展开全国考察黜陟。** 御史台及按察使负责考察天下有司，朱元璋区分“过误可恕”与“小人诡计百端”，要求后者依法去除。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0141`。
- **魏观在苏州推翻陈宁苛政、兴学修水利，后因重建张士诚旧宫址被诬，连高启、王彝一并获罪处死。** 这既是地方治理正线，也是明显的政治清洗负线。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0153`。
- **《昭鉴录》《祖训录》完成并颁行。** 前者汇编历代藩王事迹供太子诸王鉴戒；后者涵盖国政、法律、兵卫、营缮、供用、内官等十三目。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0151`、`L0157`。
- **胡惟庸正式拜右丞相并形成用人集团。** 汪广洋罢相后，胡惟庸已专决省事，拜相后又荐陈宁、商暠等党人。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0166`。
- **地方行政报表由月报改季报、再汇为岁报，以减轻文书与转递费用。** 同时把一般案件交府州县按律直接断决，减少层层转发和行贿改判空间，由御史、按察使纠枉。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0182`。
- **设置内正司专纠内官不法。** 原文定位：`SRC-MINGTONGJIAN-009-2445858-L0186`。
- **京师内外城完成：内城周九十六里、外城周一百八十里。** 原文未给工程人数和财政额，不据规模自行推算。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0212`。
- **北方因民稀事简而裁地方官三百零八人。** 朱元璋指出同样设置繁多官员只会使地方承担不必要禄给。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0217`。
- **元皇孙密迪哩巴拉获送北还。** 朱元璋明确以其为亡国君主后裔、不忍使父子久失为由遣归，并命宦者沿途护送。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0267`。
- **高丽王颛被权相李仁任所杀，辛禑被立。** 高丽请求恢复每岁一贡亦未获准。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0282`。
- **西番撒里辉和尔等入贡后设置安定、阿端等部卫。** 但这是政治纳入和建制变化，不等同于逐地军事征服。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0288`。
- **全国建立社学。** 各地按古家塾、党庠设社学，教乡村子弟，并要求读御制书及新定律令。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0300`。
- **马政被列为国家军政重点，同时要求避免过度使用战马。** 畿内民养马由有司督牧，将士不得私乘战马或载杂物，朱元璋以“使其力有余而不尽”为原则。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0311`。
- **廖永忠因僭用龙凤等事被赐死。** 史文又追述其韩林儿旧案、杨宪关系及后续追思；这是战后政治处刑，不反填任何战争P。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0313`。
- **选国子生三百六十六人分教北方。** 理由是北方丧乱后“人鲜知学”。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0314`。
- **刘基病卒前后存在胡惟庸构陷、投药嫌疑叙事。** 原文写胡惟庸因谈洋巡检事构陷刘基，后遣医诊治，刘基服药后觉胸中如拳石，并曾上告皇帝而未被处理。该材料属于政治权力与司法安全，不属战役。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0321`。
- **百官奔父母丧不再等待原籍核报。** 原制近者一月、远者半年才可奔丧，洪武八年改为闻丧即行、随后核实。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0341`。
- **库库特穆尔自然病卒。** 史文追述其长期拒绝明廷招降，朱元璋称其为“奇男子”；其死亡不是战斗损害，不进入战役P。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0344`。
- **云南招谕使吴云被元使铁知院等诱迫后杀害。** 继王祎之后又一名招谕云南使臣遇害，说明云南政治安全恶化；但本段没有军队接战，故不列战役卡。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0348`。
- **军区制度重整为十三都司、两行都司。** 北平、陕西、山西、浙江等十三都指挥使司，甘州、大同两行都司，均隶大都督府。原文定位：`SRC-MINGTONGJIAN-009-2445858-L0356`。

## 三、跨卷连续性

- **北元主线：** 卷008岭北惨败后，卷009已转为“守边、勿穷追”的谨慎口径，但仍有三岔山、雁门、大同、高州、丰州等局部出击。库库洪武八年自然病卒后，其本人父链闭合，但北元本体及新主仍存；卷010继续按新威胁主体处理。
- **倭寇父链继续反复：** 卷009六月胶东追倭失败，百户许彰战死；七月吴祯出海追至珍珠大洋并取得俘船，只是一次反击。沿海十一万余人强行编军计划虽撤销，造船、四卫巡海和海贸限制已转为长期海防制度。
- **辽东纳克楚父链未闭合：** 洪武七年仅见“犯辽阳”而无终局；洪武八年十二月纳克楚悉众再犯，金州—柞河伏击使其大溃、本人仅免，但卷010仍需观察是否复犯及辽东控制能否稳定。
- **云南仍未开战。** 王祎、吴云两名招谕使先后被杀，说明和平招谕路线恶化，但截至本卷仍没有正式征云南实际战斗；卷010若继续招谕或出现战事须从这一状态续接。
- **谈洋逃军/盐盗叛乱：** 刘基传中只追叙“奸民挟逃军反”，没有本卷明确平定终局，列入 JSON 的未闭合武装阶段；后卷若出现谈洋巡检、复叛或平定需继续核。
- **宿州与神山寨罗友贤两个旧缺口，本卷仍无明确终局句，继续保留定向补证。**
