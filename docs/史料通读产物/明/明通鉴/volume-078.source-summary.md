## 一、财政、民生、灾害与战争财政

- **万历三十六年开篇即有山东、河南与南直淮安、凤阳、徐州、扬州水旱，户部请求发内帑赈济而“不报”。** 六月南畿又发生被称为“二百年来未有”的大水，从南京到苏、松、常、镇皆被淹；再次请赈仍不报。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0118`、`L0128—L0130`。
- **辽东税监高淮把税务搜括与边军军粮直接搅在一起。** 原文称其搜括士民至数十万金，拥有三百余家丁并继续募死士，同时扣除军士月粮。这里只记录矿税、私人武装化执行和欠粮这一军政财政背景；实际军变过程完全分流至战役 JSON。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0133—L0135`。
- **李成梁长期侵蚀辽东军政资源的追叙很重。** 史文称其岁取军资、马价、盐课、市赏“不赀”，几乎笼尽辽东商民之利；麾下将领又层层掊克，使“士马为之消耗”。这是多年制度性军费耗损追叙，不倒灌为本卷任何单场战役A轴。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0138`。
- **蓟镇紧急守备进一步暴露“边饷急需而度支告匮”。** 李化龙请求三十万两补蓟镇缺饷并修守备，户部建议暂借内库矿税银，神宗不愿；最终只发太仆马价十万、户部银十万。这里只记录军饷筹措与内库隔离，不复述触发此次支出的具体战斗。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0172—L0175`。
- **万历三十七年自然灾害连续冲击人口与边防设施。** 福建大水使建宁等府“丁口失者殆十万”；甘肃地震压死军民八百四十余，边墩毁坏八百七十里，山崩又阻绝河流数日；同年山西、宣府饥，江西大水，山东蝗，多省大风岁歉。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0209`、`L0213—L0215`。
- **灾荒与军饷被迫从同一税银池中分配。** 十二月朝廷准留畿内、山东等省税银三分之一赈民；户部又借太仆马价二十五万、工部税银十五万给各镇，并把北直等七省应解内帑税银分成“两分军饷、一分赈饥”。这是非常清楚的“边饷—赈灾争夺有限财政资源”记录。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0227—L0228`。
- **州县官长期不升转也造成直接民生行政成本。** 孙丕扬称原本三四年升转的州县官，如今八九年不得转，人员疲弊；即使短期复任，也要反复产生道路公私费用及吏民迎送负担。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0247`。
- **万历三十八年大旱饥荒已经出现卖儿鬻妻。** 礼部奏疏称内帑山积而民间“半菽不充”，父卖子、夫鬻妻；五月中央终于发内帑十万两、米三十万石赈畿辅，并留四川、福建春夏税银赈灾。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0256`、`L0269—L0271`。
- **司法行政空缺也把财政负担转嫁民间。** 刑部掌印长期无人，狱囚积至千人，囚粮增加竟由铺户包赔；热审、恤刑亦被拖延。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0273`。
- **户部无人掌印使国家财政“咽喉哽塞”。** 各边请饷无人给发，各处解银无人批收；六七百名外国贡使也因礼部缺官无法遣返，每多留一日就增加本已匮乏的光禄寺供给。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0279`。
- **卷中第一次给出三大征的明确总银耗追叙。** 宁夏之役费帑金二百余万，援朝首尾八年七百余万，播州二三百万；又叠加宫殿火灾和营建，财政官员“束手”，矿税由此大兴。但史文同时指出矿监实际搜括进入公帑者“不及什一”，内府却“藏冠绝千古”，天下因而萧然。该材料只用于长期财政总账，不 retroactively 改写前卷每张战役卡。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0295—L0296`。
- **万历三十九年北直、山东、山西、河南连岁旱饥已出现极端生存危机。** 御史称民间卖女鬻儿，甚至“食妻啖子”，并警告饥民可能一呼四应、聚为盗众；同月朝廷设置边镇常平仓。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0325—L0329`。
- **同年两广、两畿、湖广又发生大水，而请求停榷税以苏民命仍“不省”。** 河南开封、归德、汝宁等府又遭持续洪水与飞蝗，万历三十年以来积欠已达三十九万余，巡按请求全免并留秋冬税银赈灾，同样不报。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0336—L0338`、`L0344—L0346`。
- **万历四十年京师已集中大量顺天流民，户部以给米煮粥赈济。** 这是连续北方饥荒向首都人口流动的直接结果。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0386—L0388`。
- **黄河徐州段再次大决。** 三山决口冲毁缕堤二百八十丈、遥堤一百七十余丈，梨林铺以下二十里正河反成平陆，邳、睢河水耗竭，朝廷另开韩家坝小渠引水归故道。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0413—L0416`。
- **朝鲜请求明军再次赴朝训练时，明廷明确以“馈饷不继”拒绝。** 王象乾主张由朝鲜自行招募、训练、修器造船，显示前次援朝的跨境驻军后勤记忆仍直接约束政策。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0435—L0437`。
- **沿海倭警使淮、扬新增十四万六千余两田赋，并调六百兵驻防廖角嘴等处。** 这是尚未形成新具体大战时就已实际发生的防务附加税与驻军成本；不把它伪装成某场战役WC。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0450—L0453`。
- **福王要求庄田四万顷构成极大的土地财政与民生风险。** 叶向高指出一个大郡方有约四万顷、小郡仅一二万顷；若强行搜足，百姓与朝廷都会无田，并会诱发投献、报怨和中州齐楚有田者不安。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0455—L0459`。
- **广东珠池在停采多年后重新开放。** 郭尚宾极论开采之害仍不被采纳，显示矿采型额外汲取并未因前期多地民变彻底退出。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0481`。
- **万历四十一年灾害与蠲免仍密集。** 宣府雹杀禾稼；两畿、江西、河南大水，山东、湖广、广西又大水；辽东亦大水。朝廷最终对各省灾区施赈，并蠲苏松积逋、停征黄梅等县兵工二部旧税，折征南直兑军米及屯粮。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0488—L0496`、`L0508—L0510`。

## 二、政治秩序、行政能力与外交

- **中央高级官缺已经进入“整部无人”状态。** 万历三十七年吏、礼两部长贰一度全部无人；随后长期出现都察院、刑部无正官，甚至刑部封印半年、狱案无人裁决。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0181—L0183`、`L0254`。
- **章奏留中与官缺互相强化。** 朱赓月上数十疏“十不获一下”；叶向高反复请求补阁臣、九卿和言官，仍长期不行。至万历四十年，六卿一度仅赵焕一人且兼多个部院，都察院八年无正官，地方巡按十余年不得代，郡守缺五六成。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0163—L0164`、`L0411`。
- **朋党攻讦已从意见冲突升级为日常行政消耗。** 宣昆、齐、楚、浙诸党与东林相互攻排，官员因一疏即去、考察被卷入派争；国政在无人补缺与反复辞官中进一步停顿。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0297—L0321`。
- **西洋历法开始正式进入明廷历务。** 日食推算争议后，庞迪峨、熊三拔等与徐光启、李之藻等被建议共同译法、修仪器；邢云路、李之藻后来入京参预历事，史文称“西法入中国自此始”。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0290—L0293`。
- **琉球中山王尚宁在万历四十年遣使报告归国，礼部同时指出其国残破。** 明廷据此拟改为十年一贡，但次年仍照旧修贡。这一条只记录战后外交与贡期制度变化。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0431`。
- **朝鲜仍持续受到日本再犯威胁，但明廷改以自助防务为主。** 朝鲜王请求明将赴朝训练，明廷因饷运困难拒绝，要求其自行整军备船；这表明万历援朝后的同盟责任已明显收缩。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0435—L0437`。
- **福王之国一再被推迟，并与四万顷庄田要求捆绑。** 叶向高反复指出此举既越祖制又可能激化土地矛盾；皇太子辍讲、福王频见皇帝的差异又持续制造储位政治猜疑。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0429—L0430`、`L0455—L0459`、`L0478`。
- **王曰乾“放炮上疏”案没有形成军事夺权或宫禁战斗。** 虽用火器制造震动并牵涉拥立福王的指控，叶向高主张按妖书类司法审讯处置，最终未形成军队调动、夺宫或武装死伤，故不进入战争账户。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0479`。
- **卷末行政空缺虽一度补科道六十余人，整体仍未恢复。** 内阁、六部、都察院、外省督抚监司长期缺员，文武待选官数千滞京，甚至攀执政车舆哀诉。原文定位：`SRC-MINGTONGJIAN-078-2550884-L0411`。

## 三、非战役跨卷连续性

- **矿税与军饷：** 高淮被召回后，辽东税务仍由张晔兼领；名义停矿并未自动消除中使、税务与边饷之间的制度冲突，卷079继续核实际撤使与征收变化。
- **灾荒财政：** 本卷反复出现“不报”赈济请求、内帑与国赋分置、税银在军饷和赈灾间分配；卷079继续优先记录实际拨付、蠲免和民生恢复，而非只记诏令。
- **中央行政：** 六部、都察院、内阁及地方官长期缺员，章奏留中与官员径去并存；卷079继续观察这种空缺是否直接拖累财政、司法、边饷和荒政。
- **海防附加：** 淮、扬新增十四万六千余两防倭田赋及六百驻防兵已经形成新的常态化地方负担；后卷继续核是否裁撤、延续或加码。
- **福王庄田：** 四万顷庄田要求尚未真正解决，土地搜括风险与福王之国时间继续绑定；卷079需追踪实际授田规模及对河南、山东民田的影响。
- **朝鲜与琉球：** 明廷对朝鲜转为要求其自行训练防务；琉球贡期与战后恢复亦仍在调整。两者的外交、财政后效继续记入非战役总结，具体军事事件另入 JSON。
