## 一、财政、民生、工程与灾害

- **延绥治所迁榆林并增兵、器械后，边地出现可见的生产恢复。** 余子俊把镇治由绥德外移榆林，强化兵卫与攻守器具，原文称敌骑抄掠渐稀，军民得以安耕牧。其后大规模边墙工程另见本卷成化十年。原文定位：`P0136`。
- **九江、苏州、杭州钞关因京库岁用钞不足而恢复。** 成化初曾撤销，至成化七年因财政需求重设。原文定位：`P0139`。
- **竹木抽分逐步货币化并不断加码，直接用于宫中营缮。** 芜湖、沙市、杭州城南等地原先只收钞，后来改收银，渐增至数万两。原文定位：`P0143`。
- **京师连年饥馑时，太仓平粜累计达到八十万石。** 最初发五十万、继发二十万，再增十万；豪猾趁机射利后，陈俊改为按升斗、小额发卖，每人不过一石，使饥民能够直接受惠。原文定位：`P0147`。
- **成化七年五月京师“岁饥，大疫，民多道死”。** 朝廷设置六所漏泽园掩埋死者，并要求病者由官收恤；军余、匠役若亲属无力赡养，可送养济院。原文定位：`P0155`。
- **茶马政策一次换得番马八千余匹以供边用。** 属边防资源筹措，不是单一战役缴获。原文定位：`P0156`。
- **涿州、良乡等京畿县出现“产业已尽，征赋犹存”的恶性税籍问题。** 饥寒与徭役迫使居民隐匿税粮、虚卖田地，田野多流亡，而里甲仍被迫代偿；御史梁昉请求清查归户以清赋税，获准。原文定位：`P0158`。
- **项忠自报荆襄流民复业九十三万余，并获三年复役。** 本书考异明确警告项忠报数存在夸张可能，因此这里只记为“项忠自报”，不把九十三万当作无争议实数。原文定位：`P0159`。
- **山东七府、浙江嘉湖杭绍四府水灾造成庐舍、人畜漂没无算，中央遣员勘灾蠲赈。** 原文定位：`P0160`。
- **钱塘江潮溢冲决江岸千余丈，居民、田宅大量漂没。** 随后朝廷遣工部侍郎祭海并修筑塘岸。原文定位：`P0164`、`P0168`。
- **漕运“长运法”正式定型。** 由运军直接渡江到江南水次受兑，替代部分由民户长途运至瓜洲、淮安的旧方式；其后成化九年又把四仓剩余七十万石支运全部改兑，四百万余石长运额遂成一代常制。原文定位：`P0165`、`P0303—P0304`。
- **魏骥临终拒绝官给葬费，请把赐金用于赈饥民，获准。** 原文定位：`P0166`。
- **运河淤塞威胁漕运后，首次形成较明确的“总理河道”专职。** 王恕受命总理河道，计划把通州至仪真、瓜洲二三千里分三道治理，并以三年考绩。原文定位：`P0169`。
- **彗星修省时，彭时、姚夔等把财政民生问题直接列为急务。** 所列包括禁佛事糜金钱、减少近幸赐予和工匠冒官、清退势要庄田，以及禁采办、恤军匠、减力役、抚流民、节冗费；其中多项“并见采纳”。原文定位：`P0178`。
- **荆襄平乱后的流民处置造成严重次生伤害。** 项忠下令逐流民，连洪武以来已落籍者亦在驱逐之列；地方执行中“不前即杀”，被发戍者舟行又多疫死。白圭后来主张已成业者随地著籍。此属战后行政和人口政策，不倒灌为竹山战斗的P。原文定位：`P0211`。
- **陕西、山西、河南夏税统一减免十分之二。** 原文定位：`P0213`。
- **成化八年南畿、浙江发生极重水灾。** 南畿大风雨毁郊坛、孝陵建筑，苏松扬及浙江杭绍嘉湖甬等八郡田禾、官民庐舍畜产大量淹没，溺死二万八千四百六十余人。原文定位：`P0220`。
- **隆善寺修成后，三十八名工匠直接因工程授官，书碑官员也升秩。** 这是营缮工程与冗赏相连的明确材料。原文定位：`P0221`。
- **畿辅防务因频年边警分设东西两巡抚，并把紫荆、倒马等关纳入分区管理。** 属行政—边防制度调整。原文定位：`P0226`。
- **进京漕粮被定为四百万石常额。** 同段确立长运制度后的固定供给基线。原文定位：`P0226`。
- **湖广灾粮免三十二万余石。** 原文定位：`P0237`。
- **江西真人张元吉擅杀四十余人，原已论死，却经夤缘先改戍、后又几乎获释。** 言官明确指出同样被杀者亦有老亲幼子，最终虽称终养后遣戍，实际上又“竟释为民”。这是司法特权的一条强负材料。原文定位：`P0244—P0246`。
- **云南银课减半。** 原文定位：`P0257`。
- **成化九年山东饥荒达到“骼无遗胔”的程度。** 中央同时赈畿内、山东。稍后又宣布山东当年税粮全部蠲免。原文定位：`P0259`、`P0275`。
- **山东救荒采取仓储、平籴、盐引、漕粮和棉布多渠道并用。** 牟俸请求发济南仓储、临清关税兼收米麦，开中淮浙盐百万引、蠲州县逋课，移临清仓粟十万石，并允许截留漕粮贷饥民；十月又把寄库银易米赈济，并请求贷贫民布棉，均获准。原文定位：`P0278`、`P0308`。
- **山西继续赈饥，陕西免灾夏税。** 原文定位：`P0284`、`P0286`。
- **浙江镇守中官李义因索贿不满杖死指挥马璋，最终未被追究。** 原文定位：`P0295`。
- **灾区民间马课获暂停。** 畿内、山东、河南等水旱后，朝廷令南直隶等灾区暂停征马。原文定位：`P0315`。
- **谢铎对成化政务作了高度集中的负面底账。** 他称名义上虽屡有恤军民、减省、蠲免、考察、简练，实际却“兴作每疲于奔命”“征敛每困于追呼”，幸门日开、私挠日众，赏罚失当；皇帝嘉纳而不能实行。原文定位：`P0324`。
- **成化十年初继续赈京师贫民，二月免南畿、湖广灾粮。** 原文定位：`P0329`、`P0342`。
- **边功核查确认存在滥杀邀功与虚报首级。** 韩文勘还后称张谨所劾部分属实，甚至有“所报首功百五十仅十九级”的情况；皇帝以“今寇已平”只戒饬而未深究。该材料用于战争卡的证据置信度复核，同时也是军功监督失灵的行政事实。原文定位：`P0353`。
- **山西太原、平阳免灾粮八十二万余，陕西西安免夏税四十五万余。** 原文定位：`P0362`。
- **余子俊延绥边墙工程规模巨大但形成明确屯田产出。** 工程东起清水营、西至花马池，长一千七百七十里，建城堡十一、边墩十五、小墩七十八、崖寨八百十九；役军四万，不三月完工，墙内土地分屯后岁得粮六万余石。原文定位：`P0366—P0367`。
- **江西南昌等府免灾秋粮八十六万余石。** 原文定位：`P0372`。
- **苏松常镇等水灾区免秋粮四十三万四千余石。** 原文定位：`P0385`。
- **河南免灾税粮三十四万余石。** 原文定位：`P0394`。
- **成化十年采金成为本卷最重的劳役财政反例。** 因“内费日侈，帑金不足”，湖广宝庆等郡开矿，岁役民夫五十五万人，“死者无算”，却只得金三十余两；辽东旧例六千人开采三个月也只得金八两。地方请求停止后，朝廷最终把相关采金之役全部罢除。原文定位：`P0400—P0402`。
- **山东年末再次饥荒，继续发仓赈贷。** 原文称牟俸任内虽治尚烦苛，但尽心荒政，所全活甚众。原文定位：`P0409—P0411`。

## 二、政治秩序、行政与社会

- **成化七年恢复由五品以上京官、给事御史举荐州县官的正统旧例。** 原文定位：`P0132`。
- **皇太子祐极在成化八年正月去世，史文记有“传者以为万贵妃害之”的说法。** 该说法按原文保留为传闻，不作确定事实。原文定位：`P0196`。
- **彗星事件暴露阁臣与皇帝直接沟通的衰弱。** 好不容易恢复一次召见，大臣发言极少，万安率先只呼万岁，随后被讥为“万岁阁老”；原文称皇帝自此“不复召见大臣”。原文定位：`P0173`。
- **成化九年尹旻通过中官关系得到吏部尚书。** 原文定位：`P0261—P0263`。
- **成化十年首次建立三边总制。** 以固原为制府，延绥、甘肃、宁夏的总兵、巡抚等统一受王越节制，用于解决过去各自为政、遇警不相救援的问题。原文定位：`P0333`。
- **韩雍最终在两广权力冲突中致仕。** 镇守中官黄沁与地方官员共同攻讦，调查结果为“虚实交半”；其去职与两广复乱、军功奏报和中官矛盾交织。原文定位：`P0348—P0352`。
- **军功审查虽查出严重问题，但处理极轻。** 这是与P0353财政军政监督相连的一条制度性负面。
- **孔镛、陶鲁、林锦因长期两广治理和御寇获诰命。** 其中孔镛“平猺贼十余部”已在战役JSON以无日期回叙卡保存并标记跨卷去重；其余重复战果不在本总结重复。原文定位：`P0378—P0381`。
- **安南灭占城后的外交压力无效。** 明廷要求黎灏归还侵地、国王，安南拒绝并继续控制占城；这些是征服后的外交和占领持续性后效，实际战争本身已入JSON。原文定位：`P0225`、`P0405—P0407`。

## 三、跨卷连续性

- 本卷的战争父链、实际控制变化与后卷待核事项全部保存在 `volume-036.battle-adjudications.json` 的 `carry_in / carry_out / review.cross_volume_followups` 中；本总结不重复复述战役结果。
- 非战役线上，漕粮长运法已逐步定型，河道专职治理、延绥边墙与屯田也形成较稳定制度，后卷需继续观察其财政、运输与地方民力后效。
- 成化七年至十年的灾荒赈济、蠲粮和平粜连续不断；山东、京畿、江南等灾区的恢复与仓储政策仍需后续材料检验。
- 荆襄战后流民驱逐、戍边与重新落籍造成严重人口治理问题，后卷如再见复业、迁返或地方社会后效，应继续承接。
- 成化十年已因成本畸高、收益极低而停止部分采金，后卷需继续观察矿课、内廷采办与财政支出的变化。
