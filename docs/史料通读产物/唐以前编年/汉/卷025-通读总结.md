## 二、第一遍：战争事实树与结果来源

### WAR-LEAD-HAN-CHESHI-67-64｜车师争夺、屯田与撤迁

**① 战前状态、起因与可证目标**

- 昭帝时匈奴曾遣四千骑在车师屯田；五将军攻匈奴后屯田者惊走，车师一度复通汉。匈奴要求车师太子军宿入质，军宿逃往焉耆；继位的乌贵转与匈奴婚姻，并协助遮断汉通乌孙道路。汉方可证目标是恢复西域交通、压制车师对汉道的阻断并建立屯田支点；匈奴目标则是阻止汉在肥美且近匈奴的车师积谷立足。（地节三年条10；元康二年条5）
- 这是汉、匈奴围绕同一通道和农业补给点的持续竞争，不把车师人口视为战利品，也不把匈奴后来东迁车师余民写成汉方控制成果。

**② 决策、授权、反对意见及责任人**

- 前67，侍郎郑吉与校尉司马憙奉命经营渠犁屯田，并动用免刑罪人及城郭诸国兵攻车师；本卷未载更具体的中央授权文书。（地节三年条10）
- 前64郑吉被围后请增田卒。宣帝与赵充国等一度考虑乘匈奴衰弱攻击其右地，使其不能再扰西域。丞相魏相明确反对：匈奴此前未犯边、车师屯田之争不足以发动远征；边郡困乏，父子共衣犬羊裘、食草莱，且水旱与社会失序并存。宣帝接受反对意见，停止攻击匈奴本土，改为撤出前沿人员。（元康二年条5）
- 责任链分明：郑吉负责前线屯田、救援和上奏；宣帝决定是否升级远征并最终采纳止兵；魏相承担反对扩大行动的政策责任；常惠负责率张掖、酒泉骑接应撤出。

**③ 动员兵力、统帅、分路与部署**

- 前67郑吉、司马憙率自身田卒一千五百人，并发西域城郭诸国兵万余人，合力攻击车师；攻克后先留一候、二十卒守护车师王，随后增派吏卒三百人在车师故地屯田，其余退回渠犁。（地节三年条10）
- 前64郑吉率渠犁田卒七千余赴援车师屯田者，遭匈奴包围。中央没有按原议另发大军进攻匈奴右地，而令常惠率张掖、酒泉骑兵接应；骑兵确数本卷未载。（元康二年条5）

**④ 按时间因果展开的交战阶段和攻守转换**

1. **汉方进攻车师**：前67汉与诸国联军攻破车师，乌贵请降；这是汉方军事行动直接造成的阶段性胜利。（地节三年条10；结果来源：汉方军事行动）
2. **匈奴援军止步**：匈奴发兵攻车师，郑吉、司马憙北上迎击；匈奴不敢前进。本卷未载实际接战和伤亡，不能写成汉军歼敌。（地节三年条10；结果来源：敌方临阵止进）
3. **汉军收缩而双方改立车师王**：汉只留二十人守王后主力回渠犁；乌贵担心匈奴再至而轻骑奔乌孙，汉接送其妻子至长安。匈奴另立兜莫并把余民东迁，车师故地因此空出；汉再派三百人屯田。（地节三年条10；结果来源：双方政治与人口处置）
4. **匈奴持续攻屯田点**：至前64，匈奴以车师地肥美、汉若多田积谷将威胁本国为由，多次攻击汉屯田者。郑吉率七千余田卒赴救，被匈奴包围。（元康二年条5；结果来源：敌方军事行动）
5. **汉方放弃升级、实施撤离**：中央否决进攻匈奴右地，常惠率河西骑兵接回郑吉及吏士。汉召军宿立为车师王，却把车师国民尽迁渠犁，将故地让给匈奴。（元康二年条5；结果来源：汉方战略撤退与行政处置）

**⑤ 粮运、道路、地形、天气、军械如何实际作用**

- 车师靠近匈奴且土地肥美，屯田积谷本身就是争夺核心；汉以渠犁为后方，车师距渠犁千余里，郑吉明确报告两点相距过远、渠犁兵少，无法相互救援。距离在此通过“救援困难和前沿支点不可维持”进入S/M/A事实，不作为轴外加档。（元康二年条5）
- 汉使用免刑罪人屯田、城郭诸国兵作战，随后以三百吏卒实地耕作；前64救援又投入七千余田卒。原文未载粮耗数、车马损失、军械损毁和天气作用，故不造数。（地节三年条10；元康二年条5）

**⑥ 收束、控制、威胁变化、持续性与跨卷更新**

- 汉成功接回被围吏士，避免继续增兵，但撤弃车师屯田支点并将故地让匈奴。所立军宿及迁入渠犁的车师人口成为安置责任，不能等同持续控制车师故地。（元康二年条5）
- 安全结果只可认定为前67短期打通、前64有序撤人；战略通道没有稳定转为长期低威胁。卷后西羌又谋攻鄯善、敦煌断道，显示西域交通风险持续，后续卷须更新而不能在本卷高档结算。

**财政民生后果与父级去重**

- 本父卡唯一持有：一千五百田卒、万余盟军、二十守卒、三百屯田吏卒、七千余救援田卒和河西援骑的已发生动员；渠犁—车师千余里补给、屯田建设与最终撤弃；车师全体迁渠犁的生产重置与安置责任。魏相所述边郡困乏是阻止战争升级的现实背景，不据谏言推定全国额外损失。

### WAR-LEAD-HAN-SHACHE-65｜莎车叛乱、南道断绝与复通

**① 战前状态、起因与可证目标**

- 莎车王死而无子，莎车人希望借汉与乌孙之势，请立乌孙公主少子万年。汉准请并派使者奚充国护送；万年暴恶，国人不服。故王弟呼屠徵联合旁国杀万年及奚充国，自立为王。（元康元年条10）
- 莎车继而宣称北道诸国已属匈奴，攻劫南道、强迫诸国歃盟叛汉，使鄯善以西全部断绝。汉方可证目标是制止莎车继续扩大、恢复南北道交通和诸国关系；并非无因主动吞并莎车。（元康元年条10）

**② 决策、授权、反对意见及责任人**

- 宣帝命群臣推举可出使西域者，前将军韩增举冯奉世；奉世原任务只是持节护送大宛等国客人至伊循城。（元康元年条10）
- 叛乱发生时，都护郑吉、校尉司马憙均在北道诸国之间。冯奉世与副使严昌判断若不急击，莎车将日强并危及全西域，遂凭使节自行谕告诸国、发兵作战，属于前线擅制而非预先获准的专项出兵。（元康元年条10）
- 战后丞相、将军主张封赏，少府萧望之反对：若奖赏奉使者擅发兵，会诱导后来者在万里外争功生事。宣帝接受，未封冯奉世，只授光禄大夫。责任与制度反馈均需保留。（元康元年条10）

**③ 动员兵力、统帅、分路与部署**

- 冯奉世、严昌以汉节号召南、北两道诸国，合兵一万五千人进攻莎车；原文未分别列各国兵数、汉籍兵数、兵种、攻城器械或粮运组织。（元康元年条10）
- 汉都护郑吉与司马憙身在北道，但本卷未载二人是否直接统率攻莎车部队；不得把其官职自动写成战役统帅。

**④ 按时间因果展开的交战阶段和攻守转换**

1. **政变与杀使**：呼屠徵联合旁国杀万年及汉使，自立；汉方首先承受使者死亡及所立秩序崩解。（元康元年条10；结果来源：莎车内部与敌对行动）
2. **南道扩张**：莎车借匈奴声势攻劫南道，迫诸国结盟，鄯善以西交通全部断绝，局势由一国内乱转为区域性叛汉。（元康元年条10；结果来源：莎车军事胁迫）
3. **冯奉世临机动员**：奉世与严昌未等待中央新令，以使节发动南北道诸国一万五千人，形成联军向莎车推进。（元康元年条10；结果来源：汉方前线决策）
4. **攻城收束**：联军攻拔莎车城，呼屠徵自杀；冯奉世传首长安，改立其宗族另一人为王，诸国悉平。（元康元年条10；结果来源：汉方及盟军军事行动、继以政治重建）
5. **后续威慑**：奉世继续至大宛；大宛因其斩莎车王而格外敬畏，并使其取得名马“象龙”返汉。（元康元年条10；结果来源：战果产生的外交威慑）

**⑤ 粮运、道路、地形、天气、军械如何实际作用**

- 南北道分别构成动员和交通网络，莎车“从鄯善以西皆绝不通”说明道路控制直接决定汉使与诸国联系；冯奉世能同时发动两道兵力，反过来使莎车陷于合击。（元康元年条10）
- 本卷未载攻城持续时间、伤亡、粮草、车辆、城防器械、天气和地形细节；万里外用兵是萧望之讨论制度风险的空间背景，不据距离另抬成本。
