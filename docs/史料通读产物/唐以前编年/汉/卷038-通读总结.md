## 二、战争、外交与国防详卡

### WAR-LEAD-XIN-XIONGNU-15-22 北边二十万屯兵、复征与持续入寇

- **① 战前状态、起因与目标**：卷037改名辱单于、杀侍子和三十万分道计划已使边患恶化；15年王莽以金珍、送还侍子尸体求和，单于因贪币表面接受改号，却“寇盗如故”。新莽目标是用外交和全国调发迫立须卜当、取代现单于。
- **② 决策、异议与责任**：王莽杀先议诛侍子的陈钦以安使团，又强迫须卜云、当入长安，反使匈奴愈怒。严尤明确主张须卜当留在匈奴更有用、应先处理山东群盗，均被拒绝并免职；大战未发是调度失败，不是主动止战。
- **③ 动员与部署**：边军二十余万仰食县官；16年宋弘、任萌屯边；19年再募丁男、死囚、奴隶为“猪突豨勇”，拟由严尤、廉丹出击；21年向西河、五原、朔方、渔阳各转谷帛百万计。
- **④ 阶段与攻守转换**：金帛和亲未止入寇；五原代郡受军费毒害，数千民众转入旁郡为盗，孔仁合击一年余才定。须卜当被强迎后，匈奴并入北边为寇；新莽军始终停在筹募、屯边而未形成反攻。
- **⑤ 后勤环境实际作用**：二十余万长期衣食、三十分之一军税、官吏养马和四郡百万谷帛均已发生；谷价腾跃、田荒不耕是实际挤压，不把幻想“百万师”或未出车队计为战果。
- **⑥ 收束与持续性**：至22年新莽仍未出塞且匈奴入寇不止；23年政权覆亡使本评价主体不再能延续该战争，终端结果为战略失败。
- 边兵二十余万人长期仰食县官，五原、代郡受害尤深，民众数千为群流入旁郡，孔仁率军与郡县合击一年余才平。匈奴虽收金帛、表面和亲，仍持续寇盗。
- 王莽反复屯撤：天凤元年后再屯，天凤六年又募天下丁男、死囚及官私奴为锐卒，普征财产三十分之一和缣帛，公卿至郡县官按秩养军马；地皇二年再转天下谷帛至西河、五原、朔方、渔阳，每郡以百万计。实际大军出塞仍未成。
- 财政民生后果：二十余万边军衣食、长期驻屯、全国性丁男死囚奴隶征募、三十分一军税、军马摊派及四边郡百万级粮帛转输由本卡唯一持有；军费导致的五原代郡民变也在本父级去重，不另造纯FIN战争投影。

- 成本四轴：评价主体为新莽；`P=P3估`（五原、代郡民众数千流亡，另有边民被杀被获，按流亡五分之一仅立可证P2下界）；`S=S5`（北边多郡长期军费、民变和匈奴入寇共同重创军政生产）；`M=M5`（二十余万长期边军，跨年反复全国征募丁男、死囚与奴隶并持续补给）；`A=A4`（三十分之一军税、官员养马及四边郡百万级谷帛转输规模巨大，但仍服务同一北边军费—转输系统）。`base=max(P3,S5,M5,A4)=5`，P、S不同时等于基础最高档，不升档，最终 `WC5`。`SB0`（匈奴寇边愈甚，筹集的大规模出兵始终未成）；`WR0`；置信度：`P中、S/M/A/WC/SB/WR高`。

### WAR-LEAD-XIN-SOUTHWEST-16-22 西南三十万人役与疫亡

- **① 战前状态、起因与目标**：句町等反抗延续近十年，新莽目标始终为恢复西南郡县控制。
- **② 决策、异议与责任**：冯茂失败下狱死后，王莽改授廉丹、史熊并反复加调。冯英以山险毒疫、费以亿计、死者什七为据，建议罢兵屯田、明设购赏，被免官；其预警随后被饥疫和粮运失序证实。
- **③ 动员与部署**：首军规模未载；继发天水陇西骑士、广汉巴蜀犍为吏民十万，另有转输二十万，廉丹、史熊统率；后又由郭兴、李晔继续进讨。
- **④ 阶段与转换**：冯茂军疫死六七成仍不克；廉丹军初斩数千，继因粮不相及、饥疫停滞。任贵、栋蚕、若豆、大牟继续杀守、杀略吏民，郭兴等到22年仍不能克。
- **⑤ 后勤环境实际作用**：僰道以南山险毒气促成疾病，前后军粮脱节直接造成饥疫；取民财十之五、十之四和数亿费用使梁益虚耗，均为实际成本。
- **⑥ 收束与持续性**：新莽覆亡前西南控制未恢复；评价主体随23年政权终结，战争以失败关闭而非悬置。
- 冯茂击句町，史载士卒疫死十之六七、民财十取五，益州虚耗而不能克。王莽继调天水、陇西骑士及广汉、巴、蜀、犍为吏民十万人，转输者二十万人；初斩数千后粮运断续，士卒饥疫，又取民十之四。
- 粤巂任贵杀太守自立；其后栋蚕、若豆、大牟等再起，杀郡守、杀略吏民。廉丹、郭兴、李晔等连续进军仍不能克，军吏放纵、百姓重困。
- 财政民生后果：冯茂部疫死六七成因基数不明不强换算；后续十万兵、二十万转输、四至五成重敛、数亿军费、饥疫与梁州益州虚耗均为已经发生的本方成本。敌方被斩数千不进入本方WC。
- P推定：评价主体=新莽；P_observed=冯茂部士卒疫死十之六七，后续十万出征军又发生饥疫；推定人数区间=10,000—90,000死亡当量；几何中心=30,000；P_scoring=P4估；推定依据=成建制首军已有六七成疫亡，后续十万兵又因粮运不继发生饥疫，七年战争中人员损害具有万人级受损群体边界；上限理由=冯茂部确数及后军饥疫死亡比例失载，不把十万兵全部视为死亡，不上P5；置信度=中低。
- 成本四轴：评价主体为新莽；`P=P4估`（冯茂部明确疫死十之六七，后续十万兵又发生饥疫，按上述有约束区间正式计分）；`S=S5`（益州、梁州多个区域长期虚耗，郡守被杀且百姓重困）；`M=M5`（七年战争中前后多军反复投入，后续又有十万兵、二十万转输）；`A=A4`（四至五成重敛、数亿军费及粮运断续，仍是同一西南战争供给系统）。`base=max(P4,S5,M5,A4)=5`，P、S不同时等于基础最高档，不升档，最终 `WC5`。`SB0`（多年军费与伤亡后仍不能平）；`WR0`；置信度：`P中低、S/M/A/WC/SB/WR高`。
- 父级去重：承接卷037西南 `campaign_group`；各将领、各郡调发和多支蛮夷反抗按同一地区—生产体系结算，不逐将拆卡。

### WAR-LEAD-XIN-WESTERNREGIONS-16 焉耆伏击与西域覆军

- **① 战前状态、起因与目标**：卷037车师、焉耆杀官降匈奴，西域驻治已瓦解；王莽派王骏、李崇、郭钦意图以诸国兵谷恢复控制。
- **② 决策、授权与责任**：王骏主动谋袭焉耆，未识破诈降；李崇任都护、郭钦任戊己校尉。原文未载中央异议。
- **③ 动员与部署**：莎车、龟兹兵七千余分为数部，郭钦、何封在后；李崇所在部队数量未载。
- **④ 阶段与转换**：焉耆伏兵截王骏，姑墨、封犁、危须又反戈，前军皆死；郭钦因后到，趁焉耆主力未返袭杀老弱后退车师；李崇收余众保龟兹，及莽败亦没。
- **⑤ 后勤环境实际作用**：诸国曾郊迎并送兵谷，反戈使这些在地供给和盟军立即转化为风险；本卷未载道路、天气和远程粮绝。
- **⑥ 收束与持续性**：23年新莽亡、李崇没，“西域遂绝”，提供明确终局；无安全收益和可控回报。
- 王骏、李崇、郭钦出西域，诸国供兵谷；王骏率莎车、龟兹兵七千余分部进入焉耆，遭焉耆伏兵截击，姑墨、封犁、危须兵又反戈，王骏等所部皆被杀。
- 郭钦后到，趁焉耆兵未返袭杀老弱，从车师退回；李崇收余士守龟兹，西域联系此后仅勉强残存。
- 财政民生后果：七千余联军覆没为明确数量级的人员损失；诸国兵粮、残军退守及郭钦杀老弱的人道负面由本卡记录。敌方老弱死亡不作本方成本或战果收益。
- 成本四轴：评价主体为新莽联军；`P=P3`（王骏所部七千余明确皆被杀；敌方老弱死亡不并入本方P）；`S=S4`（西域行政联系在既有瓦解上再遭覆军，仅余龟兹残守）；`M=M2`（七千余联军及分路兵谷）；`A=A3`（整支七千余部军资覆失并退守残余据点）。`base=max(P3,S4,M2,A3)=4`，P、S不同时等于基础最高档，不升档，最终 `WC4`。`SB0`（未恢复都护体系）；`WR0`；置信度：`P/S/M/A/WC/SB/WR高`。

### WAR-LEAD-XIN-COLLAPSE-17-22 赤眉绿林与舂陵兵全国性内战

- **① 战前状态、起因与目标**：六筦、苛法、重役与连年旱蝗使农桑和山泽生计失效，地方官掩盗；各群体先求生与报复官吏，至舂陵兵则明确提出复汉。新莽目标为跨州镇压、保住东方与南阳。
- **② 决策、异议与责任**：费兴主张贷牛种、宽租赋招抚，被王莽免官；田况以四万余兵尚能拒赤眉，却被调离。廉丹建议十万军在无盐战后休整，王匡强令追击，导致成昌败亡。
- **③ 动员与部署**：反军由数百扩至多支数万；荆州牧二万、田况四万余、王匡廉丹十余万、甄阜梁丘赐精兵十万并行。刘縯刘秀七八千与新市、平林、下江合军后分六部。
- **④ 阶段与转换**：绿林云杜破二万官军并取辎重，疫死近半后分为下江、新市；赤眉在青徐扩张，官军无盐胜后成昌覆败；舂陵兵先拔棘阳、小长安惨败，继而联合下江，休兵三日、夜袭蓝乡尽取辎重，攻守再次转换。
- **⑤ 后勤环境实际作用**：饥民与流民是兵源，库粮和官军辎重维持反军；官军沿途侵害、养赡粮被盗和青徐老弱死道路削弱国家供给。密雾直接参与小长安败战。
- **⑥ 收束与持续性**：22年末各路仍扩大，卷039昆阳与长安才构成新莽灭亡终局；本卡为阶段卡，不机器累计。
