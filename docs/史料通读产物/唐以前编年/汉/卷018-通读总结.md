## 二、战争详卡

### WAR-LEAD-HAN-MAYI-133 马邑之谋

- 决策背景：匈奴和亲后亲信边境，聂壹、王恢主张诱单于到边城伏击；韩安国以高祖休养天下和远征风险反对。王恢明确表示不是深入追击，而是边境伏击，武帝采纳
- 动员：韩安国、李广、公孙贺、王恢、李息五将，率车骑与材官三十余万埋伏马邑附近；王恢另领三万人准备攻击辎重
- 敌方：单于率十万骑穿塞，距马邑百余里发现牲畜无人放牧，攻亭取得汉尉史并获知伏兵，遂撤退
- 实际结果：汉军追至边塞判断追不上，全部罢兵；王恢因敌军多而未攻击辎重，保全三万人，但主目标与次目标均无所得
- 直接成本：三十余万军队集结、隐蔽、粮运和时间成本已经发生；本卷未载汉军死亡，不能因动员巨大推定伤亡
- 决策与归责：武帝采纳并发动；王恢首倡并承担执行责任。王恢不以三万击十万有保存兵力的合理性，但其方案失败属实；武帝以“无以谢天下”坚持追责，王恢自杀
- 战略后果：匈奴由此绝和亲，频繁攻击交通要塞和边郡；关市仍未中断。失败不是零结果，而是以巨量动员换来安全关系恶化
- 史源：元光二年条4
- 财政民生后果：五将三十余万及王恢三万人部署、马邑隐蔽集结和粮运均由本父卡持有；无本方战死记载，不因规模大虚构伤亡。王恢事后自杀属问责处刑链，不计战场 `P/WC`。
- WC四轴迁移（评价主体：汉）：`P=P0/明确未交战或不战而降`（未接战，王恢事后自杀不计战场P）；`S=S1`（边亭尉史被获及安全关系恶化，但未见汉境生产行政体系破坏）；`M=M3`（五将三十余万及王恢三万实际隐蔽集结、粮运与追塞，属十万级大军动员）；`A=A0`（三十余万伏兵与三万别军只进入M；未载本方粮秣、马匹、军械、府库或工事的可识别数量）。公式`max(P0,S1,M3,A0)=3`，故`WC3`；`SB0`；`WR0`；置信度：`P高、S/M/A/WC/SB/WR高`。
- 父级去重：马邑诱击 `campaign_group`；五将伏兵、单于入塞、泄密、追塞与罢军为同一父卡，不按军路拆分。
- 父级收束字段：`campaign_group=HAN-MAYI-133`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-HAN-MAYI-133`；`machine_settlement=yes`；`settlement_status=closed`。


### WAR-LEAD-HAN-SOUTHWEST-130 西南夷开拓

- 目标：唐蒙以巴蜀资源和夜郎十余万兵为基础，开牂柯江通道以制南越；武帝批准置吏、设犍为郡并继续扩展邛筰等地
- 首轮规模：唐蒙率兵一千、携带万余人的粮重进入；厚赐夜郎后约置官。随后巴蜀发卒修路，自僰道至牂柯江，作者数万人
- 直接伤害：修路士卒多人死亡、逃亡；唐蒙用军兴法诛杀逃亡首领，巴蜀民众大惊恐。武帝遣司马相如声称这不是皇帝本意，但工程与惩罚已经发生
- 扩张延伸：以巴蜀官府财物贿赂西夷，撤关、拓边、修零关道、桥接孙水，置一都尉十余县
- 数年结果：千余里戍卒和转运连续供饷，数年道路仍不通；士卒疲惫饥饿、因暑湿死亡甚众，西南夷反复叛乱，继续发兵，费用以巨万计而无功
- 收缩：公孙弘考察后力陈无用；前126罢西夷，只留南夷、夜郎二县一都尉，令犍为逐步自保
- 归责：武帝批准和持续扩张，唐蒙主持早期工程并执行严酷军法；武帝“非上意”的告谕只能作为纠偏表态，不能免除最终政策责任
- 史源：元光五年条2、条9末，元朔三年条2、8
- 财政民生后果：千兵、万余后勤、数万修路者、千余里戍转、军兴法处刑、士卒多物故逃亡、疲饿暑湿死者甚众、巴蜀惊恐与巨万费用均由本父卡持有；距离与水土只解释核查，已发生死亡和转饷才进入成本。
- P推定：P_observed=死亡甚众、逃亡明确而人数未载）；推定人数区间=10000—90000死亡当量；几何中心=30000；P_scoring=P4估；推定依据=卡内明确万级受损群体并载死亡、未归或整建制覆没结果；上限理由=不把敌军兵数、区域失控或持续时间叠加为更高档；置信度=中。
- WC四轴迁移（评价主体：汉）：`P=P4估`（修路与暑湿使士卒死亡甚众、逃亡明确而人数未载）；`S=S4`（巴蜀数万役工、长期千里转饷、反复叛乱与区域生产行政受扰达到区域体系级）；`M=M3`（数万修路者、千余里戍转、数年反复发兵且实际疲饿）；`A=A3`（费用巨万而无功，长期道路桥梁与转饷资产形成重大财政重建负担）。公式`max(P1,S4,M3,A3)=4`，故`WC5`；`SB0`；`WR0`；置信度：`P低、S/M/A/WC/SB/WR高`。
- 父级去重：西南夷开拓 `campaign_group`；夜郎置吏、道路桥梁、郡县扩张、反叛与收缩为同一父级，不另建工程财政投影。
- 父级收束字段：`campaign_group=HAN-SOUTHWEST-130-111`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-HAN-SOUTHWEST-111`；`machine_settlement=no`；`settlement_status=absorbed`。

### WAR-LEAD-HAN-CANGHAI 苍海郡

- 前128濊君南闾等二十八万人降汉，设置苍海郡
- 成本结果：人员运输和费用“拟于南夷”，使燕齐之间骚动；具体兵役、运粮、死亡和金额未知，但明确是跨区域重大负担
- 持续期：约两年后在集中资源经营朔方时撤销，长期控制收益未形成
- 净事实：接纳二十八万人并短期扩展名义疆域为收益；高成本、区域骚动和迅速撤销为负债，二者分列而不互相抵消
- 史源：元朔元年条6、元朔三年条2
- 财政民生后果：二十八万人内附首先形成运输、安置和设郡责任；燕齐人徒费用与骚动是实际成本，人口不作战利品。
- WC四轴迁移（评价主体：汉）：`P=P0/设郡迁置、未发生交战`（二十八万人内附迁置不等同死亡、未归、被俘、流亡或伤残）；`S=S2`（燕齐之间明确骚动但未见主要行政生产体系持续失效）；`M=M3`（二十八万人跨区运输安置、设郡与约两年经营，形成显著区域服役负担）；`A=A2`（费用拟于南夷为可观财政资产支出，未达国家级系统损失）。公式`max(P0,S2,M3,A2)=3`，故`WC3`；`SB0`；`WR0`；置信度：`P高、S/M/A/WC中高、SB/WR高`。
- 父级去重：苍海设郡 `DEF` 父卡；内附、设郡、人徒骚动与撤销为同一阶段，不将人口当作回报或另抄财政卡。
- 父级收束字段：`campaign_group=HAN-CANGHAI`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-HAN-CANGHAI`；`machine_settlement=yes`；`settlement_status=closed`。


### WAR-LEAD-HAN-HENAN-SHUFANG 河南地、朔方城与旧秦塞

- 前127军事行动：卫青、李息从云中向西至陇西，击走楼烦、白羊王，获首虏数千、牛羊百余万，取得黄河以南土地
- 战略收益：河南地肥沃且以黄河为屏障；主父偃主张可减少原有戍卒和漕运、扩大中国。汉同时把上谷偏远的造阳地让给匈奴，实施边界资源置换
- 工程动员：苏建兴十余万人修筑朔方城，恢复秦代蒙恬所建塞垣；另募十万口迁居朔方
- 财政成本：漕运距离极远，山东地区普遍承劳；费用“数十百巨万”，导致府库并虚。这是明确国家财政结果，不只是工程预算预测
- 民生外延：山东民众承担转漕，十万人参与工程、十万口迁徙；役期、死亡、逃亡、安置条件和征地未知
- 持续收益：取得河南地、建立朔方郡及修塞在本卷已完成；是否长期减少侵掠与转输，须由后卷检验，不能因主父偃预期直接判定

## 六、证据与不确定性

- “三十余万”“十万”“十余万”“数万人”等可能包含概数，且不排除同一时期役卒重复征发；保留原口径，不相加为全国唯一人数。
