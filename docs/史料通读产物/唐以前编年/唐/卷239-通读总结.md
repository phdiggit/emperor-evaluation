## 战争、外交、边防与战略详卡

### 军政秩序旁录：魏博六州归朝、制度接管与四年保持

- 当前状态：卷238魏博转型父链的收束卡；长期世袭割据结构被实质拆除，至少到816年仍持续履行朝廷军事义务。
- 时间范围：812年八月至816年。
- 地理范围：魏博六州及河北相邻成德、兖郓、宣武方向。
- 共享事件 ID：`EVT-ZZTJ-238-239-WEIBO-INTEGRATION`；独立给复与军赏政策见 `FIN-LEAD-239-01`。
- 授权时机：田兴军中受拥后等待诏命。李绛力主不待中使请命、立即以节度使厚授，使恩命出自朝廷；宪宗最终在宣慰使返回前正式任命，田兴与军士感激。
- 整合措施：朝廷以一百五十万缗赏军，六州百姓给复一年；田兴请朝廷任副使，申报九十员缺官由有司注拟，行朝廷法令并输赋税，拒居田承嗣以来僭侈宅第。
- 外部威慑与内部保持：成德、兖郓使者见军民受赏而失色；李师道谋联成德讨魏博，韩弘明确威胁其渡河即取曹州，使其不敢动。郓、蔡、恒百般游说，田兴均不听。
- 后续校验：814年朝廷因魏博归附将河阳重兵移汝州，田弘正认为此举比再赐军钱二十万缗更可喜；815年遣子田布率三千助讨淮西，816年又持续参与成德战争，表明归朝至少四年保持。
- 整合投入与政治旁证：中央为稳定整合支出一百五十万缗并给复六州一年，后又赐军钱二十万缗；父链处置蒋士则等十余人属和平交镇中的政治暴力，不进入战争成本。
- C 已实现结果：五十余年未受中央制度的六州开始输赋、接受官吏与法令，且连续参加国家战争；田氏旧有世袭宅第与独立任官机制被放弃。
- 准入边界：卷238—239为和平拥立、申版籍、置官输税及持续履行朝命，未发生起兵、据城交战或武装死伤；依事件准入规则取消正式WAR及WC/SB/WR三账。其六州整合成果与四年保持仍作为军政秩序事实保留，不把和平行政接管伪装为战争回报。
- 证据：`revision_ref=2536891`；正文锚点“魏博五十餘年不沾皇化”；“行朝廷法令，輸賦稅”；“田弘正遣其子布將兵三千”。
