### WAR-LEAD-229-01 奉天围城总攻、援军与解围

- 父级收束：`campaign_group=PARENT-JINGYUAN-FENGTIAN-783-784`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-231-02`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件 ID：`EVT-ZZTJ-229-FENGTIAN-SIEGE`。
- 当前状态：奉天防御战役群在本卷收束；朱泚退守长安。
- 时间范围：783年十一月。
- 地理范围：奉天、漠谷、乾陵、鸡子堆、蒲城、澧泉、东中渭桥、蓝田、华州、昭应。
- 主要对手：朱泚军。
- **①战前状态、起因与可证目标**：承卷228，奉天已被围一月，城内粮资俱尽、御用仅糙米二斛；朱泚目标是攻破行在，唐方目标是守住皇帝并等候外援解围。定位：`#供御才有糲米二斛`。
- **②决策、授权与责任人**：杜希全等万人来援，浑瑊主张走乾陵北据鸡子堆，卢杞以惊陵为由坚持漠谷，德宗采卢议导致伏击。李怀光、李晟、尚可孤、骆元光分方向增援；浑瑊等设计地道与火攻守梯。定位：`#請道乾陵之北`；`#上從杞議`。
- **③动员与部署**：漠谷四军合万人；李怀光汇兵五万，李晟由四千增至万余，尚可孤三千取蓝田，骆元光万余守华州，马燧五千屯中渭桥。朱泚云梯载壮士五百并有轒轀掩护；其他攻城总兵已见卷228数万。定位：`#合兵萬人`；`#西屯蒲城有眾五萬`。
- **④阶段序列与攻守转换**：四军走漠谷遭高处大弩巨石伏击，城中接应亦败；朱泚环壕并占乾陵高地，继造巨梯、填壕总攻东北。守军预凿地道，梯轮陷落后地下纵火；北风中风向转变，城上投苇炬、松脂膏油，云梯焚毁；守军由三门出击。张韶负伤送达援军书，李怀光在澧泉破敌，朱泚撤回长安。定位：`#果爲賊所邀`；`#雲梯及梯上人皆爲灰燼`；`#敗泚兵於澧泉`。
- **⑤后勤与环境的实际作用**：城内断粮、守军冻馁已直接逼近失守；漠谷狭险和敌居高使援军大败。守军地道使梯轮下陷，油脂薪苇与风向转变完成火攻；解围后金商运路重开、贡赋再至。定位：`#夜縋人於城外采蕪菁根`；`#風回焰轉`；`#諸道貢賦繼至`。
- **⑥收束与后续控制**：奉天、皇帝与行在保全，朱泚退回长安，金商交通恢复；但首都仍失，战争父级尚未终结，安全收益止于重大阶段改善SB3。定位：`#泚退歸長安`。
- 战前状态：奉天已被围一月，粮资俱尽；城内御用糙米二斛，夜采芜菁根。朱泚环城掘壕、占乾陵高地观察。
- 漠谷援军决策：杜希全等合兵一万。浑瑊建议经乾陵北、据鸡子堆与城掎角；卢杞以惊陵为由坚持险近漠谷。德宗采卢议，援军果遭居高大弩巨石伏击，死伤甚众，城中接应亦败，四军溃退。
- 后续集结：李怀光汇军五万，李晟从四千扩至万余；尚可孤三千由武关取蓝田；骆元光募至万余守华州，阻朱泚东出；马燧另遣五千屯中渭桥。
- 云梯总攻：朱泚造高广数丈、载五百壮士的巨梯，以湿毡水囊防火、轒轀掩护、薪土填壕。守军预凿地道、储油脂薪苇；北风中敌登城，城内死伤不可胜数，守军冻饿。云梯轮陷地道后，地下火出、风向转，城上投苇炬松脂膏油焚毁云梯，三门出击，敌死数千。
- 解围：张韶中数十箭送达李怀光蜡丸表，稳定城心；李怀光在澧泉破敌，朱泚撤长安。正文判断若再迟三日城即不守，属编纂者反事实总结，不计实际损失。
- B 实际成本：漠谷援军死伤甚众、四军溃败并失辎重；奉天守军冻馁、总攻时死伤不可胜数；朱泚总攻死数千；张韶中数十箭。城中粮尽并采野菜维生。
- C 成果：奉天守住、皇帝未被俘，朱泚撤围；金商运路重开、贡赋恢复。长安仍在朱泚手中。
- D 可归责失误：卢杞压过军事统帅关于路线和要地的具体建议，所选漠谷伏击风险立即兑现；责任链明确。守城火攻和援军倍道形成止损。
- 财政民生后果：援军与守城双方死亡伤残、城中断粮冻馁，以及解围后金商运路重开、贡赋恢复，均只在本WAR卡结算。
- 影子定位：`P3/S5/M3/A3→base_WC5→WC5`〔评价主体：唐内战体系。P3：朱泚总攻死数千，援军守军另有死伤甚众，均属内战人口；无万人明数不上推P4。S5：奉天行在围困一月、粮尽，京畿粮运贡赋和中央军政濒临崩溃。M3：多支数万军跨区驰援、长期围守。A3：四军失辎重、巨梯攻具焚毁、城中粮资耗尽。最高S5，P不与S同档，不升档；置信度高〕；SB3〔奉天守住、皇帝保全并重开金商运路，但长安仍失〕；WR2〔奉天城防与运路实际保持恢复；置信度：高〕。
- 父级去重：`PARENT-JINGYUAN-FENGTIAN-783-784`奉天收束子卡，卷228围城过程不重复累计。
- SB/WR依据：`SB3`〔评价主体为唐，威胁对象为朱泚摧毁奉天行在与中央政权的攻势，受益方向为奉天、皇帝安全及金商运输；围城解除、朱泚退长安、运路贡赋恢复，形成重大阶段改善，但首都仍失且朱泚政权尚存，不到结构性解决。本卡作为奉天阶段父级吸收卷228过程；置信度高〕；`WR2`〔奉天节点保持、金商交通恢复为可识别且已运行的控制回报；没有新增外部资产，且不把保住皇帝本身当资产；置信度高〕。
- 设施收益：卷226所筑奉天城经持续围攻与巨型攻具检验仍守住，兑现国家安全收益；同时城小粮少暴露承载限制。

### 政治军政旁录：李怀光驰援后的拒见与军政裂痕

- 当前状态：奉天解围功臣与中央关系恶化线；本卷未正式反叛。
- 时间范围：783年十一月—十二月。
- 战前责任与贡献：李怀光从山东数千里倍道赴难，集众五万，澧泉破朱泚并解奉天重围。
- 决策过程：李怀光沿途公开归罪卢杞、赵赞、白志贞。卢杞等恐其见帝揭罪，以乘胜攻长安为理由建议不召见；德宗命其直屯便桥。
- 实际结果：李怀光因近在咫尺不得见而怨，行至鲁店停两日；后来顿军不进、上表公开三臣罪恶。德宗最终贬三人并杀翟文秀。
- C 目标未完成：朱泚仍据长安；李怀光与中央关系未修复。
- D 可归责失误：卢杞以自保动机影响战后接见与用兵，造成已证怨愤停军；德宗采纳。李怀光以大军施压中央也形成新的安全风险，后果待后卷。
- 准入边界：本卷只见停军、上表与人事处分，李怀光尚未起兵、据城或同官军交战；本卡只作下一卷反叛的政治秩序前因，不进入战争三账。
- 证据：`revision_ref=1120589`；正文锚点“咫尺不得見天子，意殊怏怏”（编纂者纪事，实际反应）；“頓兵不進，數上表暴揚盧杞等罪惡”（编纂者纪事，行动）。

### WAR-LEAD-229-03 李希烈陷大梁、称帝与江淮攻势受挫

- 父级收束：`campaign_group=PARENT-LIXILIE-HUAIXI-782-786`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-232-02`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件 ID：`EVT-ZZTJ-229-LIXILIE-DALIANG`。
- 当前状态：淮西战争升级为僭帝战争；夺取大梁但江淮方向受阻，未收束。
- 时间范围：783年十二月—784年正月。
- 地理范围：汴州、大梁、襄邑、宁陵、寿州、霍丘秋栅、蕲黄、永安戍、蕲口、鄂州、夏口。
- 主要对手：李希烈军；唐方李勉、刘洽、高翼、张建封、曹王皋、伊慎、李兼等。
- **①战前状态、起因与可证目标**：李希烈已据许、陷襄城，转而攻大梁并谋取江淮；唐方目标是守汴、寿、蕲黄、鄂等交通财赋节点并阻其扩张。定位：`#李希烈攻李勉於汴州`。
- **②决策、授权与责任人**：李希烈直接命令驱民筑垒、以人填道，并派杜少诚万余、董侍七千进攻江淮；李勉守大梁数月无援后撤。张建封斩来使拒降，曹王皋遣伊慎七千，李兼闭门诱敌后出战。定位：`#並人填之謂之濕薪`；`#伊慎將兵七千拒之`。
- **③动员与部署**：李勉撤军万余；高翼精兵五千守襄邑；杜少诚步骑万余攻寿，伊慎七千守永安戍；董侍死士七千袭鄂。大梁守军初数、李希烈主力和各地预备队本卷未载。定位：`#將其眾萬餘人奔宋州`；`#募死士七千人襲鄂州`。
- **④阶段序列与攻守转换**：李希烈驱民运土木筑垒道，李勉久守无援后退，大梁陷；继拔襄邑、逼宁陵。兴元赦令分化三镇，李希烈反而称帝。杜少诚攻寿受霍丘秋栅阻挡，转攻蕲黄，在永安戍被伊慎大破；董侍拆屋焚鄂州门，李兼由闭守转出击再破。定位：`#希烈陷大梁`；`#少誠竟不能過`；`#兼帥士卒出戰大破之`。
- **⑤后勤与环境的实际作用**：大梁外援不至导致李勉撤守；强迫民众运输土木并填入垒道，是攻城后勤直接转化的人身损害。董侍拆民房取木焚门；永安戍控制江路并使包佶财赋船得以前进。定位：`#外救不至`；`#撤屋材以焚門`；`#包佶乃得前`。
