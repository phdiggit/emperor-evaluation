- 537年西魏取恒农后在当地馆谷五十余日；薛琡也明确把关中连年饥馑、恒农仓粟作为战略判断依据，说明灾荒已经直接制约军队与政权生存。
- 本卷未载系统赈济；这里只保留史料缺口，不把“未赈”推定为一项新的财政成本。
- **史源定位**：卷157，536年末关中大饥；537年闰九月恒农馆谷与薛琡建议段。

### FIN-LEAD-157-04 寺塔动作与夺材杀人

- 梁武帝为文帝追福“作皇基寺”，命有司求良材；孟少卿为取弘氏购买的巨材，诬其为盗、杀人并没收木材。皇帝下令求材、下级诬杀夺材及实际死亡须分开归责。
- 梁武帝“修长干寺阿育王塔”，并出佛爪发舍利、行幸设食；原文明确是修塔，不写成从零新建，行幸也不重复计工程。
- **已证毛成本**：弘氏被诬杀、木材被没；皇基寺因夺材获得材料。
- **史源定位**：卷157，536年正月皇基寺段；537年八月修长干寺塔段。
