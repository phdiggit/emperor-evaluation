- 可证目标：刘宋公开要求恢复河南旧境；兵力包括到彦之甲卒五万、段宏精骑八千、刘德武一万及义欣三万声援，是否全数同时进入前线未知
- 后勤与行军：舟师由淮入泗因水浅日行仅十里，四月至七月才至须昌；夏季湿热与水路困难是明确环境条件。魏军依既定方案撤四镇、聚兵待冬
- 阶段收益：宋不战接收碻磝、滑台、洛阳、虎牢，沿河南岸至潼关布防，司兖短期恢复；王仲德当时即警告魏是聚力待河冻，此为风险预判
- 反攻与损失：八月姚耸夫渡河败、死者甚众；十月洛阳因城坏粮缺而失，魏杀守军五千余，虎牢继失。到彦之眼疾、军中疫病，焚舟弃甲退回彭城；湖陆守军再死五千余
- 毛成本：明确死亡至少洛阳五千余、湖陆五千余，另有渡河“甚众”及疫病；这些群体可能分属不同部队。舰船、甲兵和军资委弃殆尽，直接导致宋府藏、武库为空
- 目标完成度：河南四镇短暂取得后除滑台尚在围中外基本丧失，恢复河南总体未成；不以短期接收抹去终局，也不抹去短期领土事实
- 责任：宋文帝发起并调度；到彦之负责主力迟进与撤退。垣护之提出保存滑台、利用青州粮运的替代方案未被采纳；姚耸夫受杜骥诱入不可守金墉后撤，宋文帝将失败单归其并处死，责任存在争议
- 北魏决策：崔浩主张夏季避战、秋凉河冻后反攻并反对先杀河北流民，魏主采纳撤戍与秋攻；其天象论证与实际军事条件分开记录
- 持续性：滑台战线延续至卷122；终局为滑台失陷、宋军撤回，北魏亦因久战劳敝没有立即越河南进
