### WAR-LEAD-SUI-NANNING-597 南宁羌战争与爨玩复叛

### WAR-LEAD-SUI-GUIZHOU-597 桂州反乱、白石洞追剿与十七州整合

- 父级收束：`campaign_group=SUI-LEAD-SUI-GUIZHOU-597`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-SUI-GUIZHOU-597`；`machine_settlement=yes`；`settlement_status=closed`。

- 李光仕战线：李光仕起兵后，王世积发岭北兵、周法尚发岭南兵，约会尹州；王军遭瘴停衡州，周法尚独进。光仕战败后率劲兵保白石洞，周法尚先控制其家口；对来降者逐一归还妻子，十日内受降数千，光仕部众溃散，追击中光仕被斩。
- 招降与设治：何稠另募兵，招降莫崇等并承制授首领州县官；不是把投降人口视为战利，而是通过职位将地方组织纳入国家体系。
- 行政整合：令狐熙任桂州总管、统十七州军事，可承制补官。他以书信劝谕溪洞首领，使其相率归附；把长期不到任的州县官实际派赴任所，营建城邑、开设学校，并以恩信使宁猛力入府请谒。城邑与学校为新建，欽州则是安州改名，二者区分。
- 李世贤续乱：同年桂州李世贤反，朝廷以虞庆则为桂州道行军总管讨平；原文未展开兵力与战术，保留为同一地区再次武装冲突。庆则返程后因赵什住诬告其据险谋反被处死，是政治清洗，不作战役成本。
- 财政民生后果：王世积部实际受瘴阻滞；光仕家口被控制后归还，数千降者家庭得到保全；地方官赴任、城邑与学校建设是已实现整合。

- 父级去重：李光仕、李世贤与令狐熙整合合为桂州—岭南父链，战斗和战后设治分别保存但只结算一次。
- 史源定位：`資治通鑑/卷178@2031186#桂州俚帥李光仕作亂—熙奏改安州為欽州`；`#秋七月桂州人李世賢反—討平之`。

### WAR-LEAD-SUI-GOGURYEO-598 开皇十八年高丽战争

- 父级收束：`campaign_group=SUI-LEAD-SUI-GOGURYEO-598`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-SUI-GOGURYEO-598`；`machine_settlement=yes`；`settlement_status=closed`。

- 战前威慑与册封：高丽因陈亡而治兵积谷，文帝以诏书责其藩礼不尽，并以长江、陈国作军事威慑；高丽王汤惶恐准备谢罪但病死，元继位后受隋册封并获准封王。诏书所称“命一将军”只是威胁性自述，不作已发生战果，但这一威慑—册封链构成本役的战前关系状态。
- 战争触发：高丽王元率靺鞨万余寇辽西，营州总管迎击并迫其退走；隋文帝随即黜高丽王官爵，任汉王杨谅、王世积为行军元帅，高颎任长史、周罗睺统水军。
- 集结部署：水陆总兵三十万。陆军由临渝关东进，水军自东莱泛海趋平壤；三十万是全军明确基数，不与先前高丽万余寇兵相加。
- 陆路崩解：六月出临渝关时遭水潦，馈运不继，军中乏食，继而发生疾疫；未形成深入攻城、会师或占领。
- 海路崩解：周罗睺船队遭大风，船多漂没；落水、船损已经发生，但不再与全军死亡比例重复累加。
- 撤军与外交：九月全军还师，死者什八九。高丽王遣使谢罪，自称“辽东粪土臣元”；文帝罢兵、恢复原待遇。百济曾请作军导，隋因高丽谢罪拒绝继续进攻；高丽得知后侵掠百济，说明战争外溢至盟友安全。
- 财政民生后果：三十万水陆军已经出动；馈运失败、乏食、疾疫、船舶漂没和死亡均为隋方实际成本。按明确基数，“死者什八九”约为二十四万至二十七万；水潦、疾疫、漂没只解释机制，不另加人数。
- **战争成本影子定位（评价主体：隋）**：P5 / S0 / M4 / A3 → WC5（试算旧档已废止→新档WC5；高置信度）：
  - P5：水陆军明确基数三十万，“死者什八九”，即隋方约二十四万至二十七万人死亡；水潦、疾疫、漂没是死亡机制，不另加人数。
  - S0：本役未在隋本土造成可证的地区生产、财政、交通或行政系统破坏；馈运不继归入M，不能反推S。
  - M3：三十万水陆军分由临渝关、东莱出发，跨陆海组织远征且实际发生馈运中断，属于大规模跨区动员与运输失败；距离和持续时间不另加档。
  - A3：海军“船多漂没”，构成显著舰船资产损失；原文未给船数或价值，不上推A4。
  - 公式：基础档 `max(P5,S0,M3,A3)=5`；P、S不同为基础最高档，不升档，故WC5。SB0、WR0维持：高丽军事政治结构未变且后续复发，谢罪未带来土地、府库或军用资产。置信度：高。
- 父级去重：本役与611—614三征间隔十三年，单独结算；营州击退入寇只是本战争触发阶段，不另计一次收益。

## 三、财政、赋役、土地、灾荒与民生详卡

### FIN-LEAD-SUI-TAX-LAND-592 减租免调与狭乡均田不足

- 府库已满、廊庑堆积后，文帝表示“宁积于人，无藏府库”，实际下令河北、河东当年田租减三分之一，兵役减半、调全免。
- 京辅、三河地少人多、衣食不足，朝廷派使者四出均田；狭乡每丁仅得二十亩，老少更少。前者是已执行减负，后者显示土地供给仍不能满足制度额定，不把户口增长自动等同民生改善。
- 史源定位：`資治通鑑/卷178@2031186#有司上言府藏皆滿—老少又少焉`。

### FIN-LEAD-SUI-RENSHOU-PALACE-593-595 仁寿宫新建与役夫死亡

- 工程性质：593年诏在岐州北新营仁寿宫，杨素监工、宇文恺检校将作、封德彝任土木监；夷山、填谷后建宫殿、崇台和连属楼榭，明确是新建而非修缮。
- 实际代价：督役严急，丁夫多死；疲惫倒毙者被推入坑坎、覆土石后直接筑平，死者以万数。595年宫成、文帝行幸时天气暑热，役夫又相继死于道路，杨素命全部焚除尸体。
- 决策与奖惩：文帝初见壮丽工程，责杨素“殚民力为离宫”；独孤后随后称赞其为帝后娱老，赏杨素钱百万、锦绢三千段。批评没有逆转工程，赏赐和使用均已发生。
- 史源定位：`資治通鑑/卷178@2031186#詔營仁壽宮於岐州之北—賜錢百萬錦絹三千段`。

### FIN-LEAD-SUI-PUBLIC-FUNDS-594 公廨钱禁绝与职田替代

- 台省府寺和州郡原以公廨钱放贷取息供给机关，苏孝慈指出官府经营放贷扰民败俗；朝廷接受，禁止官司经营，并以土地供机关农业。

- 史源定位：`資治通鑑/卷178@2031186#台省府寺及諸州皆置公廨錢—毋得治生與民爭利`。

### FIN-LEAD-SUI-FAMINE-594 关中旱饥与赴洛阳就食

- 灾情：关中大旱、民众饥饿；近臣取得豆屑杂糠的民食上呈。文帝流泪自责，近一年不御酒肉，是皇帝自述与个人节制，不替代救济措施。
- 已执行救济：八月文帝率民赴洛阳就食；命斥候不得驱逼，百姓可与仗卫混行，遇扶老携幼者避马慰问，险路负担者由左右扶助。核心成果是组织人口向有粮地区迁移并降低沿途强制。
- 本卷未载发仓数量，不据“就食”推定官府供粮额。
- 史源定位：`資治通鑑/卷178@2031186#關中大旱民饑—令左右扶助之`。

### FIN-LEAD-SUI-RENSHOU-PALACES-598 京师—仁寿宫十二行宫
