### WAR-LEAD-JIN-RETURN-305 东海王越迎帝与关东西大战

- 父级收束：`campaign_group=CAMPAIGN-JIN-EIGHT-PRINCES-YONGJIA-291-316`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-FALL-CHANGAN-316`；`machine_settlement=no`；`settlement_status=absorbed`。本卡保留阶段事实，机器三账由唯一终局父卡结算。

#### A. 关东联盟形成和内部分裂

- 阶段序列：
  1. 305年七月东海王越以张方劫驾为由传檄关东，获范阳王虓、王浚等推为盟主；自率甲士三万屯萧县
  2. 东海王越承制调刘乔为冀州、以司马虓领豫州；刘乔以非皇帝诏拒绝，发兵攻许昌，子刘祐在灵壁堵越，使三万军不能进
  3. 河间王顒得刘乔奏报后以朝廷名义令张方统十万会许昌，另令成都王颖、石超据河桥援刘乔；形成西台与刘乔联盟
  4. 刘弘致书双方停战并上表指出边备空、民困而宗王互攻，河间王因依赖刘乔不纳
  5. 刘乔乘虚攻破许昌；刘琨、司马虓、刘舆逃河北。刘弘判断张方残暴、西台必败，转派刘盘受东海王节度
  6. 刘琨从王浚借鲜卑乌桓突骑，先杀王阐、斩石超；再击东平王楙使退，最后在谯击败刘祐，刘乔军崩溃
- 实际结果：关东盟军打通西进道路，刘乔失去军势；大量外族突骑进入中原战争。各战伤亡不载

#### B. 杀张方与关中决战

- 阶段序列：
  1. 河间王顒在刘乔败后欲和，因怕张方反对，采繆播等建议除张方；毕垣诱郅辅谎证张方谋反
  2. 郅辅持书入张方帐，趁守卫信任斩首；河间王把首级送东海王求和，东海王仍不接受
  3. 宋冑袭河桥、刘琨用张方首劝降吕朗；祁弘、宋冑、司马纂统鲜卑西迎惠帝
  4. 河间王后悔杀张方，派彭随、刁默在湖县迎击；五月被祁弘军大破，马瞻、郭伟又在霸水败，河间王单骑逃太白山
  5. 关东鲜卑军入长安大掠，杀二万余人；百官逃山中拾橡实充食
  6. 五月己亥以牛车奉惠帝东返，六月到洛阳复羊后；关中后续马瞻等反攻、再被裴廙等击杀，转服东海王
- 毛成本：长安杀二万余为直接死亡
- 已实现收益：惠帝回洛、西台瓦解，东海王越成为最高实权者；但长安遭外军大掠，不能以“迎驾成功”抵消
- 责任：东海王越坚持军事解决；河间王顒杀张方后反复；祁弘等直接带鲜卑入关并承担抢掠后果
- 史源：永兴二年七月至光熙元年六月连续条
- 财政民生后果：关东三万、关西十万及多路鲜卑乌桓军卷入内战；关东鲜卑入长安大掠、杀二万余，百官逃山食橡实。惠帝返洛是政治安全结果，不能冲销首都人命与民生损害
- 影子定位：`P4/S5/M4/A3 → base_WC5 → WC5`〔评价主体为晋国家体系，关东、关西及受召鲜卑乌桓军均纳入晋内战父卡；长安被杀二万余为P4；关东西大战、长安陷掠与百官逃山使多个核心军政区广泛危机为S5；关东、关西多路军及三万、十万级主力共同实际参战，构成一次国家级内战动员M4；首都大掠与供给崩坏为A3。P、S不同档，不升档；置信度：高〕；SB1〔事实依据：惠帝回洛、西台瓦解，形成短时中央统一，但东海王专权与全国战争并未终止；置信度：高〕；WR0〔事实依据：皇帝、首都与兵权均属内部争夺，长安掠夺不构成国家新增财富；置信度：高〕。
- 三账结算层级：八王之乱阶段父卡；关东迎帝与关中决战统一结算，最终内战安全状态留总父级。

### WAR-LEAD-JIN-CHENMIN-305 陈敏江东割据与覆亡

- 父级收束：`campaign_group=CAMPAIGN-V086-JIN-CHENMIN-305`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-JIN-CHENMIN-305`；`machine_settlement=yes`；`settlement_status=closed`。本卡为独立事件或本战争树唯一终局，机器三账仅在此结算。

#### 第一遍：事实树与因果来源

- **评价主体与边界**：以晋国家体系为成本主体。陈敏自305年末据历阳，分兵取得江州及江东诸郡，晋扬、江官员弃守；至307年三月才因顾荣、周玘、甘卓、钱广倒戈而覆亡，覆盖近两年完整区域失控父链。
- **本方/敌方行动**：陈敏建立割据、任将守并以舟军抗荆州；陶侃等由夏口多次击败其军。本地士族倒戈、断朱雀桥并收船，陈敏万余军最终溃散；倒戈属于晋体系内部反转，不是第三方替晋收复。
- **控制与系统后果**：江东不是孤立城塞，扬、江多郡及舟运网络持续脱离中央控制，原刺史太守体系弃守，完整区域行政—战略网络实际失效。史料未载大规模死亡和生产毁坏，但S轴可由成片持续失控独立达到S4。
- **持续与父级**：割据覆亡后郡县控制恢复，未见陈敏同类集团复起；全国八王之乱仍在，故区域恢复不等于全国安全结构解决。本卡独占陈敏父链，外部宗王战争另账。

#### 第二遍：独立三账裁决

- **晋方成本视图**：评价主体为晋国家体系。P1：武装倒戈阶段钱广杀陈昶，形成至少一名可证死亡；陈敏被捕后处刑及夷三族属于战后处刑，不并入战争人员轴，其余交战伤亡未知不计。S4：江东多郡近两年持续失控，州郡行政和舟运网络实际失效。M2：陈昶数万、陈敏万余等部持续服役并发生水陆作战，但未见十万级以上大军、显著民夫转输或国家级反复征发。A1：倒戈时实际断朱雀桥；官运船改作战舰及收船属于使用、控制转换，不按损失重复计算。固定公式为`P1/S4/M2/A1 → base_WC 4 → WC4`，P、S不并列最高，不升档。
- **安全与回报**：本地倒戈和晋军行动使陈敏割据瓦解、区域控制恢复，SB2；江东郡县、兵船和府库均是内部恢复，WR0。

- 前置：陈敏平石冰后自负，趁东海王军败东归集兵，据历阳叛；借伪皇太弟命任扬州刺史，遣弟分取江州与江东诸郡，晋扬江官员弃守
