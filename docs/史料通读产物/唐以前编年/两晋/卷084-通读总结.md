## 二、战争、边防与安全详卡

### SEC-LEAD-JIN-ZHAOLUN-301 赵王伦篡位

- 前置：赵伦、孙秀已掌中外军、相府和宿卫；本卷以伪造司马懿神语制造天命，推进禅让
- 阶段序列：
  1. 赵奉诈传宣帝神语，称赵伦应早入西宫；义阳王威兼侍中，逼夺惠帝玺绶并制作禅诏
  2. 满奋持节奉玺绶让位；王舆、司马雅等率甲士入殿，向三部司马宣示威赏，无人反抗，张林守各宫门
  3. 正月乙丑赵伦以完整法驾入宫即位，惠帝从华林西门被迁金墉，由张衡带兵看守
  4. 赵伦尊惠帝为太上皇、废皇太孙，封诸子为王且领兵，孙秀掌中书与军权
- 已实现结果：篡位在洛阳无战斗完成；正规玺绶、法驾和禁军服从被利用。赵伦政权没有获得地方宗王普遍承认，很快爆发战争
- 史源：永宁元年春正月条

### WAR-LEAD-JIN-THREEPRINCES-301 三王讨赵伦

- 父级收束：`campaign_group=CAMPAIGN-JIN-EIGHT-PRINCES-YONGJIA-291-316`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-FALL-CHANGAN-316`；`machine_settlement=no`；`settlement_status=absorbed`。本卡保留阶段事实，机器三账由唯一终局父卡结算。

#### 第一遍：事实树与因果来源

- **本方/敌方边界**：这是同一晋政权体系内战，齐王冏、成都王颖等宗王联军与赵伦—孙秀控制的中央宿卫均属晋方；双方战死、军资和核心区破坏在父级合并为本国成本，不按胜方、败方互相转嫁。【定位：永宁元年三月至四月全段】
- **起兵与军令**：齐王冏发檄联络诸王州郡，成都王颖等响应；赵伦分兵廷寿、崿阪、成皋三关及黄桥方向，河间王顒先助赵伦、见联军盛后转向。【定位：`#齊王冏謀討趙王倫`起】
- **交战阶段**：阳翟初战赵军占优—错误军情导致赵伦反复调军—黄桥颖军大败后卢志整军—湨水反攻逆转—洛阳王舆七百入宫斩孙秀—各路赵军解体投降。【定位：三月至四月连续阶段】
- **本方治理与收束**：王舆逼赵伦下诏解兵、迎惠帝复位；成都王颖随后赈阳翟米十五万斛、造棺八千余并瘗一万四千余死者，是独立战后救济与殡葬执行。【定位：辛酉复位及战后FIN卡】
- **第三方/自然外生结果**：本父链没有第三方军队或自然灾害替联军消灭赵伦；宫内三部司马响应是晋内战内部倒戈，不另造一份SB。
- **持续与复发**：赵伦政权覆灭、惠帝复位，但齐、成都、河间诸王军权反而膨胀，卷内即记武号森列，卷085以后同类宗王内战继续；安全只短时恢复。
- **事件边界**：本卡只结算讨赵伦阶段；301—306八王之乱总成本由更高父级汇总，长沙王乂等后续子战不得与本卡死亡重复累计。

#### 第二遍：独立三账裁决

- **WC评价主体**：晋国家体系；齐王、成都王等联军与赵伦宿卫均属同一国家，双方损失在本父卡合并去重。
- **P4**：原文明载六十余日“死者近十万人”；黄桥万余包含于该总量，不重复累加。接近但未达到十万，按固定阈值为P4；后续赐死、族诛不冒充战斗死亡。
- **S5**：洛阳中央、三关、阳翟—黄桥—湨水及多个州军卷入全国宗王内战，中央军政与跨区行政秩序发生广泛危机；此轴依据区域和系统后果，不由死亡数字反推。
- **M3**：成都王军至朝歌二十余万，赵伦另有七千、九千、八千、三万、八千等多路宿卫州军，跨区连续作战六十余日；兵数不进入P，只证明十万级以上实际动员与服役转输。
- **A0**：本卡未载可量化的战马、舟船、粮秣、军械、府库或防御资产实际损失；未知不计分。
- **固定公式**：`P4/S5/M3/A0 → base_WC=5`；P与S没有同时等于基础最高档，不升档，`WC5`。
- **本国安全变化**：赵伦当次篡位集团被清除、惠帝复位，但宗王武装结构未拆且迅速复发，只定SB1；不能把一次恢复首都控制写成SB4。
- **本国战争回报**：首都、府库、兵权和官位均为国内控制转移，战后赈米是恢复政策而非战利资产，定WR0。

- 起兵与联盟：齐王冏以讨孙秀、赵伦为名，联络成都王颖、河间王顒、常山王乂、新野王歆及各州郡；河间王顒最初杀响应者并助赵伦，见二王兵盛后召回张方转附
- 阶段序列：
  1. **地方响应与内耗**：成都王颖采卢志意见出兵，以王彦、李毅、赵骧、石超为前锋，至朝歌众二十余万；扬州官郗隆犹豫六日，被部众攻杀，州军转附齐王
  2. **赵伦三关部署**：孙辅、李严七千出廷寿关；张泓、蔡璜、闾和九千出崿阪关；司马雅、莫原八千出成皋关拒齐王；孙会、士猗、许超带宿卫三万拒成都王；另派赵伦二子八千继援
  3. **阳翟初战**：张泓据阳翟多次击败齐王，推进到颖阴；孙辅、徐建部夜乱逃洛，误报齐军不可当和张泓已没。赵伦一度召回援军，后收张泓捷报又发回，指挥被错误军情扰动
  4. **颍水再战**：张泓等渡颍攻齐营，齐王击败孙髦、司马谭别部，张泓退；孙秀却假称已擒齐王并让百官庆贺，形成虚假战报
  5. **黄桥大败**：成都王颖前锋在黄桥被孙会等击败，杀伤万余，军心震动；颖拟退朝歌
  6. **重整与奇进**：卢志、王彦主张战有胜负、不可退损士气，选精兵倍道疾进出其不意；成都王采纳
  7. **赵军协同崩解**：孙会、士猗、许超都因黄桥功持节，互不服从；又恃胜不设防
  8. **湨水决战**：成都王颖率军攻击，双方在湨水大战；孙会等大败、弃军南逃，颖军乘胜渡河长驱
  9. **洛阳内部反转**：孙秀与败将商议再战、焚宫挟赵伦南逃或入海，未决；王舆、司马漼带营兵七百余由南掖门入宫，三部司马内应，在中书省斩孙秀、许超、士猗等
  10. **解军复位**：王舆屯云龙门，逼赵伦下诏称受孙秀误导，持驺虞幡令军队解兵；赵伦父子离宫，数千甲士迎惠帝自金墉复位，百姓称万岁
  11. **追击与投降**：赵伦父子被赐死/诛杀；赵骧、石超助齐王继续攻阳翟，张泓等投降；张衡、闾和等被杀，蔡璜自杀
- 总成本：从起兵至收束六十余日，战斗死亡近十万人，是全战役总量；黄桥万余属于其中一段，不再相加。还发生扬州地方官族诛及孟观等被杀
- 兵力口径：成都王朝歌二十余万，赵伦分路七千、九千、八千、三万、八千均为部署，可能属于其既有宿卫/各军，不与战争总死亡混作总兵。齐王后入洛甲士数十万是胜后军势口径
- 已实现收益：惠帝复位、赵伦政权覆灭；地方宗王军权反而扩大，齐、成都、河间三府武号森列，原文即提示战争未止
- 责任：赵伦、孙秀篡位；齐王冏发檄，成都王颖在黄桥败后采卢志等重整并完成关键湨水胜利；王舆七百兵利用宫内响应完成斩首
- 史源：永宁元年三月至六月连续条
- 财政民生后果：晋内战六十余日战斗死亡近十万人，黄桥万余已包含其中，不重复相加；扬州地方官被攻杀及族诛另列，事后赐死处刑不冒充战场死亡。惠帝复位属于政治安全结果，不作财政收益
- 影子定位：`P4/S5/M4/A0 → base_WC5 → WC5`〔评价主体为晋国家体系；近十万战斗死亡为P4，多核心与中央广泛危机为S5，多个州军、中央宿卫与十万级以上兵力跨区多路投入，构成一次国家级内战动员M4；未见可证资产损失为A0；P、S不同档，不触发升档；置信度：高〕；SB1〔赵伦政权覆灭、惠帝复位，但宗王军权扩大且战争迅速复发；置信度：高〕；WR0〔兵权、府库与首都控制均属内部转移；置信度：高〕。
- 三账结算层级：八王之乱阶段父卡；结算讨赵伦一役，最终全国安全状态留八王之乱总父级，不与后续宗王战重复累计。

### WAR-LEAD-JIN-LITE-301 李特益州战争（301—302）

- 父级收束：`campaign_group=CAMPAIGN-JIN-YIZHOU-LI-300-OPEN`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-JIN-CHENGDU-303`；`machine_settlement=no`；`settlement_status=absorbed`。本卡保留阶段事实，机器三账由唯一终局父卡结算。

- 事件范围：赵廞杀李庠后，李特从反赵廞转为与新任益州刺史罗尚冲突，经历石亭夜袭、成都与广汉、北道和多城攻守

#### A. 攻灭赵廞

- 阶段序列：
  1. 赵廞因李庠得众且劝称帝而杀李庠及子侄十余；李特、李流当时在外领兵，表面仍被任督将，实怀怨退绵竹
  2. 赵廞腹心杜淑、张粲、许弇互杀，核心指挥集团崩解
  3. 赵廞令费远、李苾、常俊带万余人断北道，屯绵竹石亭
  4. 李特秘密募得七千余，夜袭并焚石亭营，赵廞军死十之八九；该比例基于万余屯军，不能换成精确数字
  5. 李特乘胜进攻成都；费远等斩关夜逃，文武官散尽，赵廞带妻子乘小船逃广都，被随从杀
  6. 李特入成都后纵兵大掠，再遣使赴洛阳陈赵廞罪；大掠是明确负面，不因其讨叛名义消除
- 结果：赵廞政权覆灭；成都受掠，李特军成为当地最大武装

#### B. 罗尚入蜀与移民政策激化

- 罗尚率王敦、徐俭、辛冉等七千余入蜀；李特派李骧献珍玩并以牛酒劳军。王敦、辛冉建议会面时斩李氏，罗尚不听
- 朝廷令秦雍流民返乡，李特多次求延期；流民分散梁益为佣，正值水潦、庄稼未熟，无行资。罗尚先受贿许缓，后采辛冉等意见限七月上路，并在要道设关搜财
- 李特在绵竹建大营安置流民，旬月聚众超过二万；李流另聚数千。十月分北、东两营，修甲兵戒严

#### C. 三万夜袭中伏与据广汉

- 阶段序列：
  1. 辛冉、李苾绕过罗尚，命曾元、张显、刘并潜率步骑三万夜袭李特营；罗尚得讯后仍派田佐协助
  2. 李特面对敌军到来继续卧营不动，待官军半数进入伏击范围才发兵
  3. 官军死者甚众，田佐、曾元、张显被杀，首级送示罗尚、辛冉；具体普通死亡不载
  4. 六郡流民推李特、李流为镇北/镇东大将军；李特攻辛冉于广汉，晋援李苾、费远惧不进
  5. 辛冉多次出战失败，突围逃德阳；李特据广汉、任李超太守，进逼成都
  6. 罗尚依郫水作七百里连营与李特相拒，并向梁州、南夷校尉求援；“七百里”为防线延伸口径，非连续实体城墙长度

#### D. 302年北援失败与成都压力

- 阶段序列：
  1. 河间王顒派衙博军到梓潼；张微屯德阳，张龟屯繁城，形成多点救援
  2. 李荡袭衙博，李特亲击张龟并破之；李荡在阳沔败衙博，梓潼太守弃城，巴西郡降
  3. 李荡追攻葭萌，衙博逃、部众全降；李特自称大将军、益州牧，控制进一步扩大
