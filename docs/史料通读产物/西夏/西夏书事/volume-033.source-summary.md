## 一、财政、民生、工程与灾害

- **宋夏长期进筑已经形成明确的民力负担。** 本卷回顾熙宁以来宋在陕西、河东连续建州、军、关、城、砦、堡，到崇宁、政和仍继续进筑；史文明言“雖夏人寖衰，而中國之民力亦重困矣”。这不是某一场战斗的战利，而是长期边防工程、驻戍与供应对民力的累积压力。原文定位：`P0020`“中國之民力亦重困矣”。
- **长期前沿军镇体系暴露出高成本后效。** 震武地处山峡，“熙、秦兩路不能餉”，反复受兵后又使两路“疲于奔命，蕃、漢苦之”；史臣进一步称所筑诸城砦多在不毛之地、关辅为之萧条。具体战斗成本进入裁决卡，这里只保留持续性财政—民生后效。原文定位：`P0018`“熙、秦兩路不能餉”；`P0024`“熙、秦兩路疲于奔命，蕃、漢苦之”“關輔爲之蕭條”。
- **多年战争把双方都推入明显的承受极限。** 议和时刘韐判断“兵興累年，中國尚不支，況小邦乎”；西夏此前依赖的茶山盐铁之利和横山诸族帐又因宋方持续进筑而失去，呈现财政资源、边疆兵源与战争持续能力同时收缩。原文定位：`P0030`。
- **议和后陕西六路军实际罢兵。** 西夏纳款后“陝西六路兵皆罷”，说明此前多路长期动员在本卷出现一次明确停止点；不得把停战后的减负倒灌冲减此前各战役WC。原文定位：`P0032`“陝西六路兵皆罷”。
- **熙河、泾原、环庆同日地震并引发民心慌乱。** 地震本身是独立灾害事实，虽被西夏用作围震武的时机，也不等同于战争造成的S轴破坏。原文定位：`P0018`“熙河、涇原、環慶同日地震，民心慌亂”。

## 二、政治秩序、外交与人口变化

- **1119年前后宋夏由高强度边战转入议和，但信任很弱。** 西夏以辽国书向鄜延请和，宋廷准许；西夏随后进誓表，却拒受童贯所给誓诏并在归境途中弃置，童贯一度欲再请合兵征讨。原文定位：`P0029—P0034`。
- **乾顺朝内部继续调整皇室与宗室结构。** 宣和二年立曹氏为妃；仁忠、仁礼因父祖旧功与自身仕历受封濮王、舒王。原文定位：`P0036—P0039`。
- **宋金夹攻辽使西夏的外交重心发生根本变化。** 乾顺最初仍主动援辽：先遣五千人赴西京而未及，后使李良辅三万军救辽，并在宜水败后仍派兵到可敦馆声援；同时遣曹价问辽主起居、馈粮，且一度请求迎辽主入境。实际接战另见战役JSON，未接战的部署与外交援助保留于此。原文定位：`P0042—P0057`。
- **至宣和六年，乾顺正式臣金并以此换取辽西北旧地。** 西夏上表称藩，金方割“下塞以北、陰山以南、乙室耶剌部吐淥濼西之地”，双方誓约还规定岁时朝贡、遇辽主须执送、金方征兵时西夏应援。此为外交领土转让，不作为战役WR/BCP。原文定位：`P0061—P0067`。
- **臣金关系在礼制上明显降格。** 乾顺要求按事辽旧礼接使，金使拒绝，最终乾顺改以臣礼起立受诏，此后成为常制。原文定位：`P0066—P0068`。
- **受赐地并未立即稳定。** 乾顺向金申诉宋侵其新受割地并求援，金廷仅命西南、北两路都统府从宜处理；说明名义获地与实际控制仍有落差。原文定位：`P0073—P0074`。
- **辽亡过程中存在显著人口与财产转移。** 乾顺曾乘辽衰侵掠沿边户口资孥；臣金后虽曾约定归还非本境人口，却久不执行，最终在金廷强令下“悉归之”。人口本身不视作资产收益。原文定位：`P0078—P0079`。
- **对金的常规朝贡礼仪逐渐固定。** 本卷出现西夏始贺金天清节、始贺金正旦，并参与金太祖葬礼、金太宗即位等朝聘活动；使节位次变化也反映臣属层级。原文定位：`P0075—P0086`。
- **金夏安全关系在辽亡后迅速出现裂缝。** 金军因误传乾顺将与耶律大石合取山西而越境侵掠；乾顺责问婁室后，金廷虽命严备，但事件本身显示臣金并未换来稳定边境。实际侵掠另见战役JSON。原文定位：`P0087—P0089`。
- **皇位继承出现一次重要转折。** 世子仁爱在辽亡、乾顺臣金后长期郁结而死；辽成安公主又因伤辽亡、痛世子而绝食去世。仁孝则已于宣和六年出生，成为后续继承链核心。原文定位：`P0071—P0072`、`P0090—P0095`。
- **卷末西夏仍维持对宋的使节往来，并带有情报侦察目的。** 钦宗即位后乾顺遣使表贺，同时“覘虛實”。原文定位：`P0099—P0101`。

## 三、跨卷连续性

- 向前：承卷032宋夏边界进筑与反复攻防。本卷把此前累积后效明确写成“民力重困”“关辅萧条”，但只作为本卷新增后效，不回改卷032已经完成的阶段裁决。
- 本卷全部战役连续性、控制变化与待核事项均已转入 `volume-033.battle-adjudications.json`，本总结不重复战役事实。
- 向后：臣金后的受赐地、宋方实际占有与金方重新分配之间仍存在明显落差；卷034需继续区分外交割地与军事控制，避免把名义授予直接当作战争回报。
- 辽亡后西夏已从援辽转入臣金，同时对宋、金均保留现实性外交操作；这一多边关系是卷034的直接政治边界。
