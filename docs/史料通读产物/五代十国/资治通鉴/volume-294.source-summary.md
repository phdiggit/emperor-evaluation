## 二、政治秩序、外交与人口变化

## 三、跨卷连续性

- 向前：卷293末后周已在楚州克月城并继续江北第三次南征。卷294前段的楚州城破、海州、静海军、舒州及最后四州交割均按同一淮南战争父链在战役 JSON 中承接，不重复卷293紫金山、濠泗水战和扬州焦土等既有成本。
- 淮南战争在本卷三月形成明确政治—财政终局：南唐尽失江北、改称国主、奉周正朔、持续进贡；此后江南出现府藏空竭、钱少物贵和铸大钱等长期财政后效。本总结记录这些非战斗后果，战役 JSON 只记实际战争成本、回报、安全与控制变化。
- 显德六年关南北伐形成另一个独立战争阶段，实际进军、投降州关、筑防、对北汉作战均在 JSON 分阶段记账；本文件仅保留后续行政、人事和漕运、田租、赈济等治理事实。
- 世宗去世、恭帝幼年即位后，后周军事集团的权力重新配置，但本卷正文止于显德六年十二月，尚未进入次年陈桥兵变；不得以宋朝后续结果倒灌本卷。
- 本卷是《资治通鉴》历史正文终卷，P0119以后为进书跋文而非五代事件；因此无下一卷历史正文可继续承接，战役 JSON 的跨卷事项只保留“需外部后续史料核验”而不虚构卷295。
