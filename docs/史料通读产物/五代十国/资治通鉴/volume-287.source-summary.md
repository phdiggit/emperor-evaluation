## 一、财政、民生、工程与灾害

- 后汉南下前讨论进军路线时，郭威以“上黨山路險澀，粟少民殘，無以供億”为由反对走上党，直接反映该区战后人口、粮食和供给承载力不足。原文定位：`SRC-ZZTJ-287-1329024-P0015`。
- 萧翰撤离大梁前，刘审交称当地已“大亂之餘，公私窮竭，遺民無幾”，若再守城受围一月恐“無噍類”；这是经历契丹占领与连续战争后首都社会经济状态的直接描述。原文定位：`SRC-ZZTJ-287-1329024-P0024`。
- 杜重威叛乱期间，原文称“兵荒之餘，公私匱竭”，而北来军与朝廷军合并后人数骤增数倍。三司使王章请求罢不急之务、省无益之费以供军，结果“用度克贍”。这是独立财政紧缩政策，不把具体战役征调重复写入本总结。原文定位：`SRC-ZZTJ-287-1329024-P0046`。
- 恒州麻荅实际所留契丹兵不足二千，却按一万四千人冒领军粮并侵吞余额，又削减汉军口粮供胡兵；这种占领财政侵吞直接加剧汉军怨愤。其强夺民间珍货、美妇女及酷刑杀人，另作为占领统治暴政记录。原文定位：`SRC-ZZTJ-287-1329024-P0048`、`P0049`。
- 恒州兵变结束后，白再荣又欲向李崧、和凝强索家财，甚至欲杀二人灭口；继而还想向全城率财给军，均被李谷力争阻止。白再荣随后拘捕曾事麻荅者夺财，恒州人因此称其“白麻荅”。原文定位：`SRC-ZZTJ-287-1329024-P0051`。
- 契丹灭晋时曾驱战马二万匹北归，后汉因此军马不足，下诏在河南未遭剽掠的诸道向士民收买马匹。原文定位：`SRC-ZZTJ-287-1329024-P0058`。
- 吴越王钱弘倧大阅水军时，把赏赐提高为旧制两倍；胡进思以财用为由力谏，钱弘倧则称“吾之財與士卒共之”，反映军赏政策与财政约束之间的冲突。原文定位：`SRC-ZZTJ-287-1329024-P0073`。

## 二、政治秩序、外交与人口变化

- 耶律兀欲先在宴饮中诱赵延寿入内，以谋反名义锁禁，并否认耶律德光曾遗命赵延寿掌“南朝军国”；数日后又宣称奉德光遗制，在中京即帝位。兀欲本人也明知没有述律太后授权，继承合法性并不稳固。原文定位：`SRC-ZZTJ-287-1329024-P0012`、`P0013`、`P0026`。
- 楚王马希范死后，张少敌、拓跋恒均主张尊长立马希萼或至少先行礼让，并预警强立马希广会引发兄弟争端；刘彦瑫等仍以“军政在手”为由拥立马希广，张少敌、拓跋恒遂称疾退避。原文定位：`SRC-ZZTJ-287-1329024-P0018`。
- 滋德宫有宫人五十余，萧翰强行索取；宦者张环拒绝，被以烧红铁器灼腹致死。原文定位：`SRC-ZZTJ-287-1329024-P0023`。
- 萧翰离开大梁前强立李从益，王淑妃始终认为母子只是被契丹挟持。刘知远入洛阳后虽下令对受契丹补署的普通官员“一切勿疑”，却同时密令郭从义杀李从益、王淑妃；形成宽宥一般官僚而清除潜在皇位象征的两轨处置。原文定位：`SRC-ZZTJ-287-1329024-P0024`、`P0033`、`P0037`。
- 萧翰、麻荅以铁骑围张砺宅，萧翰列举张砺曾反对胡人为节度使、反对自己居宫、批评其掠人子女等言论欲杀之；张砺直承皆出于“国家大体”。麻荅阻止专杀大臣，张砺获释后当夜愤恚而死。原文定位：`SRC-ZZTJ-287-1329024-P0029`。
- 吴越钱弘佐死后遗命钱弘倧继位；钱弘倧随后任弟钱弘俶同参相府事。其本人性刚严，试图纠正前朝“容养诸将、政非己出”的局面，与内牙统军使胡进思的矛盾不断激化。原文定位：`SRC-ZZTJ-287-1329024-P0032`、`P0036`、`P0043`、`P0082`、`P0083`。
- 刘知远入大梁后大赦，契丹所任节度使以下将吏一律安于原职，复汴州为东京并正式改国号为汉，仍沿用天福年号；又建立六庙，以汉高祖、光武帝为百世不迁之祖。原文定位：`SRC-ZZTJ-287-1329024-P0037`、`P0047`。
- 契丹相州军府出现复杂的阵营转换：高唐英原拟举镇归汉，却被王继弘、樊晖杀死；王继弘随后自称留后，而后汉反以其为彰德留后。此处实际武装杀官进入战役 JSON；其后朝廷承认既成军府安排的政治事实保留于此。原文定位：`SRC-ZZTJ-287-1329024-P0039`。
- 南唐主闻耶律德光死、萧翰弃汴，宣称中原为“本朝故地”，一度任李金全为北面行营招讨使筹划北进；得知刘知远已经入大梁即停止行动。原文定位：`SRC-ZZTJ-287-1329024-P0040`。
- 郭威借传言赵延寿已死建议招抚赵匡赞；杜重威、李守贞也先后奉表归命，后汉以移镇、保官等方式重新安排杜重威、李守贞、赵匡赞。原文同时追记赵延寿实际上后二年才死于契丹。原文定位：`SRC-ZZTJ-287-1329024-P0042`。
- 后汉因“四方盗贼多”把盗窃不论赃数一律定死罪，并遣使逐捕；苏逢吉起草诏书时甚至欲把四邻同保一并处死，原拟“全族”后才被迫删去。执行中捕贼使张令柔杀平阴十七村民。原文定位：`SRC-ZZTJ-287-1329024-P0055`。
- 苏逢吉在河东幕府时曾借“静狱祈福”把狱囚尽杀；入相后与苏禹珪掌百司庶务，任免处置多凭个人意志、不拘旧制。苏逢吉又公开求财，甚至因庶兄未经通报见其诸子而暗托郭威借事杖杀。原文定位：`SRC-ZZTJ-287-1329024-P0056`。
- 马希广不忍依周廷诲建议杀兄马希萼，只厚赠遣还朗州；马希崇则持续把长沙内部言行动静通报马希萼并约为内应，使楚国继承矛盾继续积累。原文定位：`SRC-ZZTJ-287-1329024-P0057`。
- 荆南长期利用身处湖南、岭南、福建交通之间的地理条件，掠夺过境朝贡使团财物；遭交涉或兵威后才返还。高从诲又在多个强国间反复称臣求赏，被诸国称为“高無賴”。原文定位：`SRC-ZZTJ-287-1329024-P0061`。
- 南汉主担心诸弟与自己的儿子争位，一次杀齐王弘弼等八弟，尽杀诸王之子并把其女纳入后宫；又建离宫千余间，以珠宝装饰，设置镬汤、铁床、刳剔等酷刑，号“生地狱”。原文定位：`SRC-ZZTJ-287-1329024-P0063`。
- 邺都平定后，杜重威本人获授太傅兼中书令、楚国公；但郭威请求把其牙将百余人处死并籍没杜家资产赏军，朝廷批准。张琏先获“准归乡里”的信誓，投降后其将校数十仍被杀。司马光因此专门批评刘知远“非仁、非信、非刑”。这些战后处刑不计作战斗 P，作为赏罚与信用事实留于本总结。原文定位：`SRC-ZZTJ-287-1329024-P0070`、`P0071`。
- 福州李孺贇赴钱塘后曾以金笋二十株及杂宝贿胡进思求归；其后与吴越戍将冲突的武装结局另入战役卡。原文定位：`SRC-ZZTJ-287-1329024-P0044`。
- 钱弘倧被胡进思军事政变废黜后，钱弘俶即位的明确条件是必须保全兄长；钱弘俶将钱弘倧迁居衣锦军，并暗令薛温若遇“非常处分”须以死拒绝。具体政变与后续武装刺杀未遂进入战役 JSON。原文定位：`SRC-ZZTJ-287-1329024-P0084`、`P0093`、`P0103`。
- 刘知远因魏王刘承训死而悲痛成疾，病危时召苏逢吉、杨邠、史弘肇、郭威受顾命，特别嘱咐“善防重威”；当日去世。顾命诸臣秘不发丧，随后借诏处死杜重威及三子；二月十八岁的刘承祐即位，李皇后升皇太后。原文定位：`SRC-ZZTJ-287-1329024-P0094`、`P0097`、`P0098`、`P0100`。
- 史弘肇遭母丧后仅数日即恢复朝参。原文定位：`SRC-ZZTJ-287-1329024-P0106`。

## 三、跨卷连续性

- 向前：卷286末耶律德光死于北归途中，兀欲已掌恒州门钥仓库、赵延寿仍声称掌南朝军国；后汉则已由河东向中原扩张。本卷先闭合兀欲夺位与赵延寿失势，再写刘知远南下接管洛汴、河南契丹军北撤和恒州反契丹兵变。
- 向后：卷末刘知远已经死亡、刘承祐即位；侯益已入朝、王景崇掌凤翔门户，赵思绾随赵匡赞牙兵仍在长安，后蜀关中远征刚失败撤回。吴越钱弘俶虽已即位并保住兄长，军中权力结构仍受胡进思政变余波影响。卷288须继续核验凤翔、长安、河中三镇如何转为公开叛乱，以及定州、河北反契丹控制是否彻底闭合。
