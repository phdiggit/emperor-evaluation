- 周行逢拒绝为女婿唐德私授官职，认为其才不堪任吏；若徇私任用，将来又不能依法惩处，反伤亲戚之恩，遂仅给耕牛、农具令其务农。原文定位：`SRC-ZZTJ-293-1502955-P0046`“與之耕牛、農具而遣之”。

## 二、政治秩序、外交与人口变化

- 南唐在寿州压力下连续求和。三月先遣孙晟、王崇质奉表，表示愿比两浙、湖南奉周正朔、保守现疆，并献金千两、银十万两、罗绮二千匹；随后又提出去帝号、割寿濠泗楚光海六州、岁输金帛百万。世宗认为淮南已半入周且捷报不断，坚持“诸郡悉来”方停兵，但一度明确表示可允许南唐保留帝号。原文定位：`SRC-ZZTJ-293-1502955-P0014`“獻金千兩，銀十萬兩，羅綺二千匹”；`SRC-ZZTJ-293-1502955-P0022`“請去帝號，割壽、濠、泗、楚、光、海六州之地”。

## 三、跨卷连续性

- 向前：卷292已经开启寿州长期围攻、吴越东线与后周—南唐淮南战争。本卷所有实际新增攻守、撤退、军资损耗、州县反复、紫金山决战及第三次南征均在战役 JSON 中承接，未重复卷292既有数十万丁夫、正阳东等旧成本。
- 本卷内：淮南民政呈现明显的“战时占领—战后修复”并行状态。后周一面通过赦罪、除不合理赋役、开仓赈饥和召民复业建立新治理，另一方面战争过程中的将帅俘掠与南唐自身营田弊政仍造成严重民怨；这些非战斗制度事实与战役卡中的白甲军、城市焦土等武装后果严格分账。
- 向后：卷末后周已经推进至楚州并克月城，南唐江北防御尚未全部闭合；卷294需继续核楚州最终城破、海州与静海军、舒州及最后四州交割，并在同一淮南战争父链内去重。
- 向后：卷末契丹—北汉南侵潞州仅形成短促入境后退；卷294又出现契丹乘后周南征入寇及后周北伐关南，需区分新的战略阶段，不把不同年份边境行动合并成同一场伤亡。
