- 后周改革漕运损耗制度，规定每斛给耗一斗。原文追叙晋、汉以来不给斗耗，运输自然亏欠常由纲吏赔偿，甚至多人因此抵死；新制直接承认运输合理耗损。`SRC-ZZTJ-292-1769707-P0038`
- 后周规划扩建大梁外城，先立标界，规定只在冬季农隙施工，春耕开始即停，次年再续；标界内坟墓迁到七里外，除街衢、仓场、营廨外，其余土地允许百姓自由建屋。显德三年正月实际征开封府及曹、滑、郑州民十余万筑城。`SRC-ZZTJ-292-1769707-P0050` `SRC-ZZTJ-292-1769707-P0080`

## 三、跨卷连续性

- 卷291末的太原军事链在卷292前段闭合为退兵；人员、动员、焚粮和控制反转均在战役 JSON 中按新阶段承接，非战役文件不重复累计。
- 世宗在太原退军后转入大规模整军、责任制选官、求言、司法复核、财政和宗教制度整顿，本卷已经形成较清晰的亲政治理轮廓。
- 秦、凤、阶、成归周后的减役、遣俘和后蜀铁钱财政后果在本卷有明确政策落点；后续如出现户籍、税制或地方恢复新材料，可继续作为非战役事实承接。
- 淮南战争到卷末仍未闭合，寿州、吴越东线等军事事项已在 JSON 的 `cross_volume_followups` 指向卷293；本文件只保留称臣求和、求援、地方接管司法等非战役后效。
- 湖南王逵之后由周行逢接掌军府，潘叔嗣又被诱杀；后卷需继续核周行逢政权的行政稳定、财政民生和非战役整合，不在本卷预判。
