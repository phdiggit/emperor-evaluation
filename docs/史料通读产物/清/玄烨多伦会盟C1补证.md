# 玄烨多伦会盟 C1/M2 有界补证

## 用途与边界

本卡补人物画像C1“战略判断与风险控制”和M2“外交博弈与对外联盟能力”共同缺失的1691年多伦会盟节点。M2消费喀尔喀诸部的利益交换、政治承认、封授编旗与承诺执行；C1只消费危机后政治整合、行政安置与军事收束的目标排序、路径组合和风险隔离。两轴不得按后来疆域或噶尔丹军事战果重复抬档。

## 直接定位

- `DOLON-1691-SHIZU-V151`：《清圣祖实录》卷151，康熙三十年四月至五月多伦诺尔会阅段。可从[维基文库《清实录·圣祖仁皇帝实录》](https://zh.wikisource.org/wiki/康熙實錄)卷目反查；卷151所载核心安排包括本人亲临会阅、调解喀尔喀内部旧怨、按内蒙古四十九旗同例编设旗号与札萨克、分设参领佐领并安插游牧。
- `DOLON-1691-DPM-CHRONOLOGY`：[故宫博物院康熙皇帝年表](https://www.dpm.org.cn/court/lineage/226256.html)，康熙三十年条。年表明确记录四月因喀尔喀内附而亲临边外举行多伦会盟，五月传谕按四十九旗同例编设各处札萨克、管辖稽查。
- `DOLON-1691-NEAC-CONTEXT`：[国家民委“道中华”清代一统志专题](https://www.neac.gov.cn/seac/c103391/202303/1161920.shtml)，明确记录康熙三十年亲临多伦诺尔，与喀尔喀及漠南王公会盟，并实施编盟旗、定疆界与制法律。

## C1父链裁决

- 战略问题：喀尔喀人口与政治中心在噶尔丹打击下南迁，单纯追击无法同时解决内部分裂、安置和北部缓冲失稳。
- 已知信息与备选：清廷已知喀尔喀内争、内徙与赈济压力，也已知乌兰布通未能终结威胁；可选路径包括拒纳、仅军事追击、临时救济后遣返，或接纳并制度化安置后再军事收束。
- 本人选择与资源边界：玄烨先准内徙、运米赈抚，继而亲临多伦，以调解旧怨、封爵、旗盟札萨克和游牧安置建立可治理缓冲；没有把会盟本身当成噶尔丹威胁已经消失。
- 风险隔离与反馈：旗盟安置把流动人群、内部冲突和北部安全拆成可治理层次；1690后续袭扰证明军事风险尚存，1696—1697再以分路、亲征、追击和招降收束，而不是因会盟完成即停止防备。
- 结果验证与归责：喀尔喀政治承认和行政安置由本人主持、批准并持续执行；噶尔丹军事终局只验证排序有效，不继承费扬古等人的战役解题信用。

据此，该链方向为`POSITIVE`，强度为`MI3_SUSTAINED_SYSTEMIC`：它跨越1688—1697，覆盖危机接纳、1691制度化安置和后续军事终局三个阶段，并有直接过程定位。不得因后来疆域或历史意义升为MI4；其反证是乌兰布通后威胁复发与长期军事成本。

## M2父链裁决

- 自主对象与利益：喀尔喀三部在周期起点保有独立选择和拒绝能力；噶尔丹进攻后需要安全、赈济、游牧地和内部秩序，清廷需要北部缓冲、稳定承诺和对噶尔丹的政治孤立。
- 条件与本人归责：玄烨亲临多伦诺尔，调解旧怨，保留汗、诺颜、台吉等既有地位，并按内蒙古四十九旗同例封授札萨克、编设旗号及参领佐领、安插游牧；这不是臣下独立完成的终端结果。
- 执行与复验：会盟条件随后进入编旗、分路、赈抚和游牧安置；1690后噶尔丹仍能袭扰，证明会盟没有被误写成军事威胁已经终止，1696—1697战果只验证联盟与缓冲结构的安全后效。
- 轴内边界：M2只消费喀尔喀利益交换、政治承认和承诺执行；征噶尔丹的战役统筹归M1，安全与控制收益归第三、第四项，C1另消费手段排序。

据此，`M2-P075-KHALKHA`由`MIXED_POSITIVE / MI3`重裁为`POSITIVE / MI3`。多伦会盟补齐了原父链缺少的协商—封授—编旗—执行核心，不能另拆第三条父链，也不足以升为MI4。玄烨M2保留`G4`，档内由`LOW`调至`MID`；尼布楚具体边界条件仍未充分展开，故不升`G4-HIGH`或`G5`。
