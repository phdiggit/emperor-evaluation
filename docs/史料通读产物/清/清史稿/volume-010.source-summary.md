# 清史稿·卷010 通读总结（非战役事实）

- **范围**：本纪十·高宗本纪一，雍正十三年八月至乾隆十年。
- **固定来源**：维基文库修订版 `2433565`；锚点格式 `SRC-QINGSHIGAO-010-2433565-Lxxxx`。
- **口径**：只收非战役事实；苗疆、瞻对、安南及其他实际武装冲突另见 `volume-010.battle-adjudications.json`。本文件以财政民生为重点。

## 一、即位初年的减赋与苗疆善后

1. 乾隆即位后迅速再免民欠丁赋，并宣布相关官吏侵蚀项也不再转向百姓追征；同时贵州被苗乱扰及州县免额赋，未受扰地区停征（SRC-QINGSHIGAO-010-2433565-L0122）。
2. 十月又免江南等省漕粮、芦课、学租和杂税，并对贵州降苗赦罪、三年内免耗羡（SRC-QINGSHIGAO-010-2433565-L0123）。这使政权交接初期呈现明显的减征与战争善后色彩。
3. 乾隆元年苗疆仍有大量流民赴湖南沅州就食，朝廷因此免沅州额赋；随后免贵州通省本年额赋并除古州等处苗赋（SRC-QINGSHIGAO-010-2433565-L0133）。这一组措施直接反映雍正末苗疆战争的社会后效。

## 二、灾荒赈济成为本卷最高频行政事项

1. 乾隆元年至十年，几乎每月可见水、旱、雹、风、蝗、地震后的赈济或免赋。二年永定河决后，朝廷派员分赴卢沟桥、良乡、文安、霸州等处抚恤；并规定已纳而后遇蠲免者可抵作次年正赋，著为定例（SRC-QINGSHIGAO-010-2433565-L0153）。
2. 三年以后对灾情的处理更加密集，山东、河南、江南、安徽、甘肃、福建、广东、湖北等地反复出现停征新旧钱粮、免漕、发仓粮和平粜（SRC-QINGSHIGAO-010-2433565-L0165—SRC-QINGSHIGAO-010-2433565-L0169、SRC-QINGSHIGAO-010-2433565-L0191—SRC-QINGSHIGAO-010-2433565-L0196）。
3. 七年江南灾情严重，中央一次拨江苏、安徽赈银二百五十万两有奇，并免两省灾区本年额赋（SRC-QINGSHIGAO-010-2433565-L0253）；九月统计赈恤又达银二百九十万两、米谷二百二十万石有奇，另拨邻省银一百万两备次春接济（SRC-QINGSHIGAO-010-2433565-L0254）。
4. 同一轮救荒还持续从山东、河南、江南及沿河仓调运数十万石粮食（SRC-QINGSHIGAO-010-2433565-L0255），并要求水退后保护耕牛、必要时给资饲养，防止灾民因短期困难损失恢复生产最重要的畜力（SRC-QINGSHIGAO-010-2433565-L0258）。
5. 六年甘肃报灾争议中，御史所报虽被认为不实，乾隆仍表示“与其惩言官而开讳灾之端，宁从宽假以广耳目”，选择不以重罚造成地方隐瞒灾情的激励（SRC-QINGSHIGAO-010-2433565-L0238）。

## 三、普免、杂税与基层减负

1. 二年除广东开建、恩平米税及湖南永州等处额外税，并免山东正项钱粮一百万两（SRC-QINGSHIGAO-010-2433565-L0151）。以后又屡除荒地、水冲地、坍没田荡和多种地方杂税。
2. 五年广西宜山平乱同月，乾隆检查江南岁额钱粮杂办款目，认为不少项目沿自前明且赋役全书都未编定，决定“悉予豁免”（SRC-QINGSHIGAO-010-2433565-L0214）。这是本卷对历史性杂派的一次集中清理。
3. 七年顺天、保定等八府缺雨时直接停征新旧钱粮（SRC-QINGSHIGAO-010-2433565-L0248）；八、九年仍大量免除历年逋赋和受灾地区本赋（SRC-QINGSHIGAO-010-2433565-L0281、SRC-QINGSHIGAO-010-2433565-L0284）。
4. 乾隆十年六月宣布**普免全国钱粮**，理由是国库有余而“天下之财，不聚于上，即散于下”；同月对安徽连年受灾地区耗羡亦予免除（SRC-QINGSHIGAO-010-2433565-L0291）。九月又命各省以历年存余银抵补岁需，说明普免并非只是一纸诏令，还配套处理省级年度支出缺口（SRC-QINGSHIGAO-010-2433565-L0295）。

## 四、边防与战争动员的财政后效

1. 尽管乾隆初与准噶尔逐渐进入议界阶段，西北仍长期维持军营和驻防。七年为援应北路军营，绥远、右卫、归化城、察哈尔及内札萨克分批挑兵；那克素三十九部番民因替“准噶尔进藏官兵”备办驼马而获免本年额赋（SRC-QINGSHIGAO-010-2433565-L0241）。这是边防动员直接换成赋税减免的实例。
2. 早年沿鄂尔海西拉乌苏、鄂尔坤河、额尔德尼招、乌里雅苏台等方向持续分兵驻守准噶尔（SRC-QINGSHIGAO-010-2433565-L0191），即使没有会战，驻军、屯田与补给仍构成长期财政成本。
3. 本卷在没有大规模清准决战的年份仍多次整顿边军、屯田和军需，说明“无战”不等于“无成本”；但这些只进入本文件的战争财政后效，不倒填具体战役P/S。

## 五、河工、水利与生产恢复

1. 二年疏浚清口和江南运河（SRC-QINGSHIGAO-010-2433565-L0150），随后永定河决即派员勘工（SRC-QINGSHIGAO-010-2433565-L0153）；海宁则继续改筑鱼鳞大石海塘（SRC-QINGSHIGAO-010-2433565-L0154、SRC-QINGSHIGAO-010-2433565-L0188）。
2. 五年黄、淮交涨后，中央把救荒与水利勘修并行，派高斌、周学健查办灾赈、水利（SRC-QINGSHIGAO-010-2433565-L0251—SRC-QINGSHIGAO-010-2433565-L0254）。
3. 九年依刘于义勘议拨银五十万两兴修直隶水利（SRC-QINGSHIGAO-010-2433565-L0284）；十年又发江南帑银五十六万两浚河道（SRC-QINGSHIGAO-010-2433565-L0288）。公共水利支出在乾隆初仍是中央财政的重要项目。
4. 对灾后农业恢复的关注相当具体：除保护耕牛外，还多次除水冲、坍没土地的额赋，并要求督抚经画地利、实心办理平粜（SRC-QINGSHIGAO-010-2433565-L0248—SRC-QINGSHIGAO-010-2433565-L0250）。

## 六、巡幸、行围与民力约束

1. 乾隆自六年起秋狝，明确对经过州县减免额赋十分之三，并称以后每年照行（SRC-QINGSHIGAO-010-2433565-L0232）。八年巡幸又明令扈从护军不得践踏田禾（SRC-QINGSHIGAO-010-2433565-L0264）。
2. 八年奉皇太后赴盛京谒陵时，再免经过直隶、奉天地方钱粮，同时调通仓米四十万石赈直隶旱灾（SRC-QINGSHIGAO-010-2433565-L0266）。巡幸本身有财政成本，但本纪不断配套减赋和纪律约束以降低对沿途民户的直接扰动。
3. 这与雍正卷中“不要为御道洒水而忽视牧民”的表述形成连续性：皇帝出行的礼仪需求在制度表达上应让位于田禾、灾荒和地方生计。

## 七、行政监督与救荒信息

1. 乾隆初反复要求臣工举贤、条奏地方利弊，同时也对考官舞弊、贪污、军需剥削等严厉处分。二年安西镇总兵张嘉翰因剥削军需被论斩（SRC-QINGSHIGAO-010-2433565-L0159）。
2. 六年查甘肃“匿灾”并派员勘核（SRC-QINGSHIGAO-010-2433565-L0230），五年又明确不愿因处罚言官而诱发讳灾（SRC-QINGSHIGAO-010-2433565-L0238）。对财政民生而言，灾情信息能否上达被视为治理链条本身的一部分。
3. 九年登州镇总兵马世龙因科派兵丁被论绞（SRC-QINGSHIGAO-010-2433565-L0284），显示对军队内部额外摊派也有直接追责。

## 八、综合观察

卷010的最突出特征不是战争扩张，而是**高密度财政减免和灾荒管理**。乾隆初承接雍正末苗疆战争留下的流民、受扰州县和财政压力，随后在水旱灾频发背景下大量使用停征、免赋、截漕、拨银、调仓、平粜等组合政策。乾隆七年江南水灾所动用的银粮规模尤其大，十年又在“左藏有余”的判断下普免全国钱粮。与此同时，北路军营、驻防、驼马和屯田说明西北安全仍持续消耗资源。因此本卷呈现的是一种“**长期边防成本仍在，但中央依靠较充裕财政扩大赈灾、减赋和公共工程支出**”的格局。
