# 清史稿·卷012 通读总结（非战役事实）

- **范围**：本纪十二·高宗本纪三，乾隆二十一年至三十年。
- **固定来源**：维基文库修订版 `2433575`；锚点格式 `SRC-QINGSHIGAO-012-2433575-Lxxxx`。
- **口径**：只收非战役事实；准噶尔、哈萨克、回部、乌什及第三方战争另见 `volume-012.battle-adjudications.json`。财政民生、战争后勤、战后治理与边疆行政优先。

## 一、西北战争的后勤与财政压力

1. 乾隆二十一年西北战局反复时，黄廷桂奏备马三万匹，并增兵驻哈密等处（SRC-QINGSHIGAO-012-2433575-L0133）。这是本卷最直接的大战后勤数字之一，说明即使单场战斗伤亡不明，军马和远程驻防成本仍非常高。
2. 同年九月免甘肃乾隆元年至十五年积欠，并减免宁夏、安西等二十二州县卫本年额赋（SRC-QINGSHIGAO-012-2433575-L0129）。战争沿线长期财政压力与旧欠清理明显并行。
3. 回部战争期间甘肃连续受旱，又承担西师转运。乾隆二十三年免甘肃兰州等府州县乾隆三年至十年逋赋，随后又免甘肃通省二十四年额赋（SRC-QINGSHIGAO-012-2433575-L0159、SRC-QINGSHIGAO-012-2433575-L0161）。
4. 西师凯旋后，乾隆二十五年再次免来岁甘肃额赋，并命乌鲁木齐屯田；同年又派员清查甘肃各州县办理军需（SRC-QINGSHIGAO-012-2433575-L0194、SRC-QINGSHIGAO-012-2433575-L0195）。这说明战争结束后仍需通过减赋、屯田和军需审计消化财政后效。

## 二、灾荒赈济与农业恢复

1. 本卷十年间水、旱、雹、霜、蝗灾仍极频繁，江苏、安徽、山东、甘肃、陕西、山西、直隶等省几乎逐年见赈济与蠲赋。
2. 乾隆二十四年前后陕甘大旱与西部战争同时发生，朝廷反复祈雨、赈济、免赋，并延长灾赈；西北既是战争运输区，也是严重旱灾区，民力压力具有叠加性。
3. 乾隆二十六年河南丹、沁河水灾造成重大人员损失，朝廷随后赈恤；类似灾害仍通过停征、发粮和工程修治组合处理。
4. 捕蝗政策也强调不得借机派累民间。乾隆二十四年明确禁止州县捕蝗时把费用摊派给百姓（SRC-QINGSHIGAO-012-2433575-L0189），延续了此前对“救灾措施反而扰民”的警惕。

## 三、战后回疆与伊犁治理

1. 回部平定后，清廷首先废除霍集占等在回城的苛敛（SRC-QINGSHIGAO-012-2433575-L0188），这属于征服后的税役调整，而不是战场物质回报。
2. 乾隆二十五年开始乌鲁木齐屯田（SRC-QINGSHIGAO-012-2433575-L0194）；之后持续建设伊犁、乌鲁木齐和喀什噶尔的行政与军事城市。二十七年伊犁固勒札、乌哈尔里克两城分别赐名绥定、安远，乌鲁木齐又建宁边、辑怀等城堡（SRC-QINGSHIGAO-012-2433575-L0243、SRC-QINGSHIGAO-012-2433575-L0245）。
3. 同年设置总管伊犁等处将军，随后又设伊犁参赞、领队大臣；二十八年设置伊犁额鲁特总管、副总管等职（SRC-QINGSHIGAO-012-2433575-L0246、SRC-QINGSHIGAO-012-2433575-L0252）。军事征服开始转化为常设行政和驻防体系。
4. 喀什噶尔新城、乌鲁木齐后改名迪化等建设，说明清廷在西域采取了“驻防—屯田—筑城—官制”的连续整合方式。应当与战役BCP区分：前者是战后治理持续性的证据，后者只计战场阶段已经实现的控制。

## 四、边疆人口与刑罚性移民

1. 平定准、回后，乾隆提出将部分罪犯迁往新辟边地，使其从事耕作。这是一种把刑罚、移民与边疆开发结合的政策，不宜简单视作自愿移民或纯民生改善。
2. 伊犁、乌鲁木齐的屯田与新城建设需要持续人口、粮食和驻防资源，说明征服后国家仍承担长期建设成本；这些成本不能在战役卡中一次性忽略。
3. 与此同时，对主动归附的各部、伯克和边疆人口又频繁赐爵、给粮、安置，形成军事压制与政治吸纳并行的治理方式。

## 五、南巡、河工与赋税减免

1. 乾隆二十二年南巡时，免江苏、安徽、浙江累年逋赋，并对经过直隶、山东地区按例减赋；同时继续阅河、修堤和处理江南水利（SRC-QINGSHIGAO-012-2433575-L0136）。
2. 二十七年再次南巡，仍大规模减免沿途与灾区钱粮，并督办高家堰、运河和直隶水利。战争结束后，财政注意力迅速回到河工与农业水利。
3. 二十七年后伊犁、乌鲁木齐筑城与内地河工并行，说明国家基础设施支出并没有因西师结束而显著下降，而是从战时军需转向新边疆建设与常规河工。

## 六、乌什之乱暴露的基层治理问题

1. 乾隆三十年乌什起事后，朝廷追查发现办事大臣素诚“贪淫激变”，并籍没其产、戍其子（SRC-QINGSHIGAO-012-2433575-L0294）。这说明本纪明确承认地方官侵扰是叛乱直接诱因之一。
2. 同一时期和阗办事大臣和诚也因婪索回人被夺职，后经审实正法（SRC-QINGSHIGAO-012-2433575-L0293、SRC-QINGSHIGAO-012-2433575-L0297）。新征服地区并非只有军事反抗，基层官员的盘剥本身构成治理风险。
3. 乌什叛军投降后又被“尽诛附逆回众”（SRC-QINGSHIGAO-012-2433575-L0308）。这在战役卡中记录为人道损害；在治理层面则显示清廷对新边疆叛乱采取了极严厉的惩罚性政策，与此前废除霍集占苛敛的安抚措施形成强烈反差。

## 七、贡物与地方负担约束

1. 乾隆二十四年明令禁织造进贡过度精巧的絺绣（SRC-QINGSHIGAO-012-2433575-L0178），二十七年又规定各回城非盛典不必进方物。至少在制度表达上，朝廷试图限制地方以奢侈贡物形式承担额外负担。
2. 富德后来因索取蒙古王公马畜被褫职逮问（SRC-QINGSHIGAO-012-2433575-L0245），也说明边疆军政大员向属部额外取用牲畜并非当然合法。

## 八、综合观察

卷012的核心变化，是乾隆中期从**长期战争动员**转向**征服后的制度化边疆治理**。前半卷西北战场仍高度反复：伊犁数次得失、哈萨克与准噶尔残余交战、回部战争长期拖延；甘肃因战争和灾荒叠加而连续获得大规模蠲免。到二十四、二十五年后，政策重点逐步转向屯田、筑城、设置伊犁将军和回城官制，同时清理霍集占苛敛。可是乌什之乱又暴露新治理体系内部的官员盘剥和暴力镇压问题。因此本卷不能被概括为单纯“西域平定”：**军事征服完成后，财政、驻防、人口安置、基层官员约束和新城建设才开始形成更长期的国家成本。**
