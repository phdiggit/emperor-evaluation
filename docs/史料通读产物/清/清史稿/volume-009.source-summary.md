# 清史稿·卷009 通读总结（非战役事实）

- **范围**：本纪九·世宗本纪，康熙六十一年十一月至雍正十三年。
- **固定来源**：维基文库修订版 `1794968`；锚点格式 `SRC-QINGSHIGAO-009-1794968-Lxxxx`。
- **口径**：只写非战役事实；实际战斗、平乱和武装袭击另见 `volume-009.battle-adjudications.json`。本文件优先财政、赋役、灾荒、河工、战争后效与基层民生。

## 一、亏空清理与地方财政

1. 雍正即位之初即要求直省仓库亏空三年补足（SRC-QINGSHIGAO-009-1794968-L0147），但同时否决以州县当年岁入替前任弥补积亏，理由是州县须留有余地才能“尽心兴举”，不能把旧亏硬压给现任及地方（SRC-QINGSHIGAO-009-1794968-L0159）。这构成本卷财政整饬的一条基本张力：中央严追亏空，但反复警惕追补转嫁给基层。
2. 雍正三年蠲苏、松“浮粮”四十五万两（SRC-QINGSHIGAO-009-1794968-L0211）；七年清查江南逋赋时，又明确批评把官侵错算成民欠、令富户摊赔、加增火耗、征收原已停征项目，指出“惠民之政，转而扰民”（SRC-QINGSHIGAO-009-1794968-L0334）。
3. 六年朝廷以内帑九十四万两代西征军士赔偿追款（SRC-QINGSHIGAO-009-1794968-L0305），同时发帑十万犒滇、黔兵。这反映军务造成的个人债负和中央财政吸收成本，而不能只从年度田赋看到战争支出。
4. 八年命各省解部银两留一半充地方公用（SRC-QINGSHIGAO-009-1794968-L0362），说明中央在高强度军政时期也为地方日常行政保留一定财政空间。

## 二、丁银、耗羡与赋役结构

1. 雍正二年先命山西将丁银摊入地粮，其后各省渐行（SRC-QINGSHIGAO-009-1794968-L0195）；四年又明确河南、陕西、四川均摊丁银入地并征（SRC-QINGSHIGAO-009-1794968-L0254）。本纪呈现出“丁随地征”的逐省推广过程。
2. 对耗羡，六年诏书承认地方官私征耗羡难以骤然裁革，同时担心制度化后出现重复取民，要求督抚审慎控制（SRC-QINGSHIGAO-009-1794968-L0295）；十三年又命户部清查各省耗羡（SRC-QINGSHIGAO-009-1794968-L0491）。就本卷原文而言，重点在防止耗羡转化为新的重复负担。
3. 七年江南逋赋清查所暴露的问题尤其重要：中央原意在区分官侵、民欠，但执行中出现摊赔、火耗与恢复停征等做法，说明财政整顿本身可能制造新的基层成本（SRC-QINGSHIGAO-009-1794968-L0334）。
4. 雍正元年仍列“永不加赋后滋生人丁”四十八万余，并记录田赋、盐课年度数额（SRC-QINGSHIGAO-009-1794968-L0173），显示康熙末形成的人丁不加赋口径继续沿用。

## 三、战争动员对地方财政与民力的压力

1. 准噶尔战争扩大后，七年规定出征官兵除行粮外另给坐粮（SRC-QINGSHIGAO-009-1794968-L0318）；同年北路配置旗兵六千、三省兵八千、蒙古兵八百，西路又有车骑营兵八千（SRC-QINGSHIGAO-009-1794968-L0319），随后继续增加八旗家人二千并专设西路粮饷督运（SRC-QINGSHIGAO-009-1794968-L0375、SRC-QINGSHIGAO-009-1794968-L0379）。
2. 对战争转输的社会成本，本卷有直接财政反应：甘肃、四川、云南、贵州、广西因“转输劳费”免次年全年额赋，陕西免十分之三（SRC-QINGSHIGAO-009-1794968-L0324）。这属于战争公共成本后效，不倒填某一场战斗的S轴。
3. 十年北路战局再紧张时，朝廷拨帑银二百万两解赴军前备赏（SRC-QINGSHIGAO-009-1794968-L0413）；十二年平郡王又进马五百匹供军（SRC-QINGSHIGAO-009-1794968-L0452）。雍正晚年的西北战争并非只消耗前线兵员，还长期吸收银、马、粮饷和地方运输能力。
4. 十二年面对“西北二路用兵年久”，朝廷最终在继续直进与遣使之间选择遣使（SRC-QINGSHIGAO-009-1794968-L0463），可以视为对长期战争成本的一次明确政策收缩。

## 四、灾荒赈济与减免

1. 本卷几乎逐年存在灾赋减免。雍正九年，扬州盐义仓拨谷二十万石加赈邳、宿灾民；又从通仓、奉天及采买合计调米四十万石以上备山东赈济（SRC-QINGSHIGAO-009-1794968-L0371—SRC-QINGSHIGAO-009-1794968-L0373）。
2. 雍正八年山东水灾较重，特免全省漕粮（SRC-QINGSHIGAO-009-1794968-L0355—SRC-QINGSHIGAO-009-1794968-L0357）；地震后则给百官半俸、八旗各银三万两（SRC-QINGSHIGAO-009-1794968-L0358），救济对象既有民众也包括旗属体系。
3. 十年以后仍持续对直隶、江南、河南、福建、陕西、湖南、广西、甘肃等地灾赋减免（SRC-QINGSHIGAO-009-1794968-L0393、SRC-QINGSHIGAO-009-1794968-L0422、SRC-QINGSHIGAO-009-1794968-L0447），财政减免是常态化救荒工具，而非偶发特恩。
4. 十三年苗疆治理失败造成居民被抢掠后，贵州本年钱粮通行蠲免，受扰州县更蠲免三年（SRC-QINGSHIGAO-009-1794968-L0494）。这是本卷战争后效与民生救济结合最直接的一条。

## 五、河工、水利与公共工程

1. 五年太仓七浦士民请求自费疏浚，雍正明确拒绝，称“民间之生计，即国计”，在国用充裕时应由国家发帑承担（SRC-QINGSHIGAO-009-1794968-L0283）。这是一条非常明确的公共工程财政责任表述。
2. 七年发帑金一百万两修高家堰石工（SRC-QINGSHIGAO-009-1794968-L0335），河工投入规模很大；十一年继续命海望、李卫察勘浙江海塘并修范公堤（SRC-QINGSHIGAO-009-1794968-L0427）。
3. 十年又诏修云南嵩明、寻甸水利（SRC-QINGSHIGAO-009-1794968-L0404），说明水利治理并不限于黄淮主河道。

## 六、基层治理、旗民与土司政策

1. 雍正元年明确要求直隶巡抚整治旗人暴横、不得因王公勋戚而畏避，并允许旗人受本旗王公刁难时控诉（SRC-QINGSHIGAO-009-1794968-L0161），反映旗民杂处地区的基层司法与权力约束问题。
2. 对土司，二年诏责其苛待属人、生杀任性，要求督抚严饬（SRC-QINGSHIGAO-009-1794968-L0187）；但六年又警告湖广许多土司本已与流官一样供职输将，不许督抚轻率一概改流（SRC-QINGSHIGAO-009-1794968-L0305）。本卷因此不是简单“全面改土归流”，而是行政接管与保留土司并行。
3. 十一年巡幸途中见地方官沿途设水缸洒道，雍正直接要求地方官把奉上之心转用于“牧养生民”（SRC-QINGSHIGAO-009-1794968-L0429）；十三年论保甲又强调必须顺从舆情、不可严急累及善良，且“不得其人，虽良法美意…于民无济”（SRC-QINGSHIGAO-009-1794968-L0483）。
4. 闽省械斗、漳泉聚族械斗等基层暴力问题反复进入诏令，说明东南地方治安并未因全国性大局稳定而自然消失（SRC-QINGSHIGAO-009-1794968-L0289、SRC-QINGSHIGAO-009-1794968-L0471）。

## 七、综合观察

卷009的财政民生线与战争线高度纠缠。雍正朝一方面严查亏空、逐步推行丁银摊地、清理逋赋与耗羡，另一方面又多次明确阻止**把财政整顿成本转嫁给州县、富户和普通纳税人**。准噶尔与苗疆战争则造成大规模粮饷、银两、马匹与跨省转输需求，朝廷通过内帑补偿、地方留银和成片免赋吸收部分公共成本。河工方面同样倾向在中央财政充裕时由国家承担，而不轻易让民间自筹。到雍正十三年，皇帝甚至公开承认苗疆“安民”政策因执行不善反成“虐民之政”，是本卷非常重要的治理失败自认。
