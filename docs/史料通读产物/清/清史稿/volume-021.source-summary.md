## 一、财政、民生、工程与灾害

- **同治政权建立时即以“物力维艰”为由压缩宫廷与热河工程。** 十月懿旨要求内务府宫闱器用“力行节俭”，并令热河未竟工程立即停止；同月停止各省方物贡献。原文定位：`SRC-QINGSHIGAO-021-1814546-L0122`、`L0125`。
- **军费压力下反复要求清理厘捐、津贴与浮费。** 同治元年三月讨论限制津贴、抽厘以筹军实；四月明令统兵大臣“慎重餉糈，汰除浮費”；闰八月又命各省裁革州县浮费并催解京饷。原文定位：`L0130`、`L0131`、`L0136`。
- **亩捐出现明确停撤。** 同治二年四月停四川亩捐；三年二月停山东亩捐。战争性临时征收并非只增不减，中央已在部分地区回撤。原文定位：`L0146`、`L0159`。
- **战后普遍以蠲免旧欠恢复税基。** 浙江、江苏、安徽、江西、山东、陕西、贵州、广东、福建等大量被扰州县反复获免新旧额赋、逋赋、灶课或仓粮；江宁收复后又豁所属粮赋三年。原文定位：`L0146`、`L0154`、`L0160`、`L0164`、`L0168`、`L0199`、`L0201`。
- **苏松常镇太等东南重赋区连续减征。** 同治四年十一月减征米豆五十四万石有奇；五年七月又减苏、松、常、太浮收米三十七万余石、浮收钱一百六十七万余贯。原文定位：`L0184`、`L0196`。
- **江苏摊赔银被永久禁止。** 江宁战后，诏免江苏历年州县摊赔银两，并“永禁派摊名目”。原文定位：`L0168`。
- **盐税和漕粮继续承担财政调度功能。** 淮盐招商、河南长芦盐厘、潞盐课票等并行；苏松太漕粮减价折征，江北新漕讨论河海并运。原文定位：`L0122`、`L0136`、`L0154`、`L0180`、`L0182`。
- **内廷支出并未单向下降。** 同治四年十二月户部拨盐课等款，增内廷用费三十万，与前期“物力维艰、力行节俭”形成明显张力。原文定位：`L0185`。
- **灾害救济与战后赈抚并行。** 旱灾期间多次祈雨；苏松杭嘉湖水灾获赈，杭州收复后专令收养难民；受扰地区同时蠲赋。原文定位：`L0130`、`L0146`、`L0160`、`L0180`。
- **黄河、海塘与农业工程仍持续。** 统筹黄河下游支渠、培堤，修浙江海塘、海宁石塘；河南黄河北趋后又要求直鲁豫三省会筹堤工。直隶新城一带开垦稻田。原文定位：`L0146`、`L0154`、`L0169`、`L0201`、`L0204`。

## 二、政治秩序、外交与人口社会变化

- **辛酉政变改变最高权力结构，但本卷没有实际武装接战。** 载垣、端华、肃顺等被罢黜、逮问和处死；年号由“祺祥”改为“同治”，两宫垂帘章程确立，恭亲王进入军机。按事件准入边界，该事件只作政治秩序事实，不把事后处刑伪装为战争人员损失。原文定位：`L0124—L0125`。
- **幼帝教育和垂帘行政制度化。** 皇帝在弘德殿入学，祁俊藻、翁心存授读；编纂《治平宝鉴》，并多次要求讲读经史与古今政治。原文定位：`L0129—L0130`。
- **对军事奏报粉饰、军费浮冒持续整饬。** 多次申诫统兵大臣不得粉饰迁延，要求实核功罪；将领因谎报、失机、克扣勇粮等被处分。原文定位：`L0125`、`L0136`、`L0161`、`L0174`。
- **同文馆与近代军事工业继续发展。** 京师同文馆设立；上海设机器局；福建开始建厂试造轮船，随后明确船政总司及章程。原文定位：`L0134`、`L0180`、`L0195`、`L0201—L0202`。
- **绿营出现“减兵加饷、就饷练兵”的结构调整。** 同治五年左宗棠请将闽浙绿营减兵加饷，获准；京畿兵额亦被要求严核。原文定位：`L0199`、`L0201`。
- **长江下游战后撤减军船并解除封江。** 这是交通和军政正常化措施，不重复写成战役收益。原文定位：`L0161`。
- **中外通商和换约成为常态行政。** 比利时、普鲁士、荷兰、西班牙、意大利等换约或谈约持续进行，总理衙门承担经常性处理。原文定位：`L0140`、`L0150`、`L0178`、`L0196`、`L0199`。
- **俄国方向既有勘界，也有越境压力。** 清廷持续派员按条约地图会勘北路边界；俄兵入科布多卡伦并扣押人员因本卷无完整接战与终局，列入 JSON 的未登记战役候选。原文定位：`L0132`、`L0150`、`L0164`。
- **地方行政重建随战后恢复推进。** 安徽道制调整，恢复两淮盐务、裁江北厘金；多次要求新复州县慎选牧令、薄赋轻徭、删烦苛。原文定位：`L0144`、`L0164`、`L0178`。
- **对军中和地方暴力的约束继续加强。** 都兴阿因部勇肆杀被处分；田兴恕因惨杀教民遣戍；谭胜达因克扣勇粮褫职。原文定位：`L0174`、`L0190`。
- **西北后勤开始制度化屯垦与粮运。** 乌鲁木齐等处闲荒马厂开垦升科济饷并分给屯兵；后又积粟张家口、绥远转运新疆以济民食。原文定位：`L0144`、`L0198`。
