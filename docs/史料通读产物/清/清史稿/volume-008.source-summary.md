## 一、赋役制度与财政减免

- 康熙后期最重要的赋役政策之一，是康熙四十九年宣布分三年轮免天下钱粮，并把历年逋赋一并豁除；五十年继续轮免山西、河南、陕西、甘肃、湖北、湖南六省，并免台湾次年应征稻谷。原文定位：`SRC-QINGSHIGAO-008-2606645-L0385`、`SRC-QINGSHIGAO-008-2606645-L0410`。
- 蠲赋利益在业主与佃户间形成明文分配：蠲免之年，业主免七分、佃户免三分。这对判断减税是否真正向佃户传导尤其重要。原文定位：`SRC-QINGSHIGAO-008-2606645-L0386`。
- 康熙五十一年规定以后滋生人丁不再新增丁钱，以当时丁数为定额。到六十年统计时，另列永不加赋后滋生人丁四十六万七千八百五十，说明制度已进入人口财政统计。原文定位：`SRC-QINGSHIGAO-008-2606645-L0423`、`SRC-QINGSHIGAO-008-2606645-L0689`。
- 对江南数十万两地方亏空的讨论中，康熙承认部分可能与历次南巡地方挪用有关，并担心用官俸、工食抵补最终仍累及百姓，倾向直接豁免。原文定位：`SRC-QINGSHIGAO-008-2606645-L0385`。
- 八旗借支多次大额豁免：四十四年免借支兵饷七十万两，四十五年免官兵贷官银约三百九十五万六千六百两，五十六年又免借支银二百万两。原文定位：`SRC-QINGSHIGAO-008-2606645-L0238`、`SRC-QINGSHIGAO-008-2606645-L0272`、`SRC-QINGSHIGAO-008-2606645-L0574`。
- 康熙六十一年，年羹尧、噶什图建议加火耗以补地方亏帑，康熙明确反对加征，认为火耗只可议减；同时指出地方亏空常由用兵、官兵过境馈助和挪用公款累积，改由户部库帑拨送西安。原文定位：`SRC-QINGSHIGAO-008-2606645-L0709`。

## 二、灾荒、赈济、粮食与仓储

- 康熙四十二年山东大雨后，先遣官分赈，再发帑银三十万两、截漕五十万石，且对不理荒政的地方官暂停升转。原文定位：`SRC-QINGSHIGAO-008-2606645-L0183`。
- 四十六年江浙旱灾，采取发帑买米平粜、截漕放赈、免逋赋，再免次年丁钱和灾区正赋，并要求兴修水利以备旱涝。原文定位：`SRC-QINGSHIGAO-008-2606645-L0298`—`SRC-QINGSHIGAO-008-2606645-L0300`。
- 四十九年福建漳泉旱灾，调江浙漕粮三十万石并免未完额赋；五十三年江南旱、浙江米贵、河南歉收，再截漕三十万石分运三省，冬季又截漕三十余万石备赈。原文定位：`SRC-QINGSHIGAO-008-2606645-L0382`、`SRC-QINGSHIGAO-008-2606645-L0483`、`SRC-QINGSHIGAO-008-2606645-L0490`。
- 五十五年京畿旱，发京仓米二十万石赈顺天、永平，延长粥厂开放并发仓米平粜，另预发八旗兵粮。原文定位：`SRC-QINGSHIGAO-008-2606645-L0532`、`SRC-QINGSHIGAO-008-2606645-L0536`。
- 五十八年截漕四十三万石留江苏、安徽备荒；五十九年陕西饥荒又运河南积谷救济，随后继续银粮兼赈。跨省粮运和截漕已成为常态化救荒工具。原文定位：`SRC-QINGSHIGAO-008-2606645-L0611`、`SRC-QINGSHIGAO-008-2606645-L0649`、`SRC-QINGSHIGAO-008-2606645-L0656`。
- 六十一年奉天连岁丰稔，弛海禁；又因暹罗米价低，允许进口内地并免税，同时直隶截漕二十万石备赈，粮食政策表现出较强的区域调剂取向。原文定位：`SRC-QINGSHIGAO-008-2606645-L0704`。
- 广西仓谷亏空案中，康熙指出南方卑湿、无仓廒即易朽烂，要求重订仓储规则而非一味追赔；奉天府尹把九州县米豆改征银两、造成仓储空缺，则被黜。原文定位：`SRC-QINGSHIGAO-008-2606645-L0164`、`SRC-QINGSHIGAO-008-2606645-L0541`。
- 临终前仍命皇子和大臣察视仓廒，仓储安全一直延续到晚年政务收尾。原文定位：`SRC-QINGSHIGAO-008-2606645-L0711`。

## 三、河工、水利与工程约束

- 南巡仍以阅河为重要任务，但多次要求停供张、禁科敛、不修行宫、勿妨农。原文定位：`SRC-QINGSHIGAO-008-2606645-L0161`、`SRC-QINGSHIGAO-008-2606645-L0225`、`SRC-QINGSHIGAO-008-2606645-L0227`。
- 康熙四十六年阅河时发现原拟河道将毁坏大量民居、坟墓，立即停止工程，反映重大河工会因社会拆迁成本被否决。原文定位：`SRC-QINGSHIGAO-008-2606645-L0283`。
- 河决仍反复发生，四十四年有清水沟、韩庄决口；六十年武陟决口入沁水，随后组织筑口并导沁水入运河。原文定位：`SRC-QINGSHIGAO-008-2606645-L0236`、`SRC-QINGSHIGAO-008-2606645-L0680`、`SRC-QINGSHIGAO-008-2606645-L0682`。
- 海宁石塘、直隶堤防、通州河堤等工程持续推进，说明康熙晚年水利维护仍占较高行政权重。原文定位：`SRC-QINGSHIGAO-008-2606645-L0586`、`SRC-QINGSHIGAO-008-2606645-L0395`。

## 四、市场、财政治理与部门约束

- 康熙四十五年规定部寺咨取钱粮若未经奏请，户部须按月汇总其数上报，加强中央对部门资金调用的可见性。原文定位：`SRC-QINGSHIGAO-008-2606645-L0263`。
- 户部购办草豆银积年亏蚀四十余万，涉及历任尚书侍郎百二十人；处理方式主要是限期偿还，而非全面逮问。原文定位：`SRC-QINGSHIGAO-008-2606645-L0383`。
- 康熙五十三年讨论钱法时仍把是否便民作为主要判断标准，反对仅靠严禁维持不便于民的货币安排。原文定位：`SRC-QINGSHIGAO-008-2606645-L0475`。
- 对矿税和资源开发亦保持审慎，如停止广东采矿，并拒绝增加云南矿课。原文定位：`SRC-QINGSHIGAO-008-2606645-L0234`、`SRC-QINGSHIGAO-008-2606645-L0298`。

## 五、人口、基层民生与社会政策

- 康熙四十三年诏书直接估算三十亩农户在输租赋后约余二十石，还要承担衣食与丁徭，指出若再遇官吏横征，则民生无所依托，把察吏与养民直接联系。原文定位：`SRC-QINGSHIGAO-008-2606645-L0199`。
- 四十五年诏各直省建育婴堂；四十九年普免钱粮诏又把养民作为政策论证核心。原文定位：`SRC-QINGSHIGAO-008-2606645-L0257`、`SRC-QINGSHIGAO-008-2606645-L0385`。
- 对海防管制是否扰民有明确否决。有人建议渔船限制单桅、不得越省并纳入水师约束，康熙认为这样会给兵弁侵欺渔民留下空间，主张只实行确实有益于民者。原文定位：`SRC-QINGSHIGAO-008-2606645-L0423`。
- 五十四年巡畿甸时，既关注田间耘耨、防风霾，也要求穷僻乡里广设义学，把农业生产和基层教育并置。原文定位：`SRC-QINGSHIGAO-008-2606645-L0501`。
- 外藩、边疆人口继续通过归附、安插和编制进入行政体系，但仅有投降人数本身不在战役 JSON 中当作战争回报资产。

## 六、储位、奏折制度、边疆政治与海上治理

- 康熙四十七年第一次废黜皇太子胤礽并幽禁；随后围绕胤禩等人的建储活动出现大规模廷臣卷入。四十八年三月复立胤礽，五十一年九月又再次废黜并禁于咸安宫，五十二年面对再建太子的奏请则明确表示储位大事不可轻定。原文定位：`SRC-QINGSHIGAO-008-2606645-L0326`—`SRC-QINGSHIGAO-008-2606645-L0330`、`SRC-QINGSHIGAO-008-2606645-L0342`、`SRC-QINGSHIGAO-008-2606645-L0434`、`SRC-QINGSHIGAO-008-2606645-L0448`。这一连续事件是本卷最重要的非战役政治风险之一。
- 康熙五十一年命内外大臣具折陈事，本纪明确记为奏折自此开始，是中央信息上达制度的重要变化。原文定位：`SRC-QINGSHIGAO-008-2606645-L0421`。
- 西藏方面，四十五年已出现拉藏汗杀第巴、伪达赖问题上报；四十八年又派赫寿驻藏协办藏事，清廷在大规模军事介入前已有持续政治介入。原文定位：`SRC-QINGSHIGAO-008-2606645-L0272`、`SRC-QINGSHIGAO-008-2606645-L0338`。
- 海上治安更多采用招抚、安插而非一律军事剿灭。四十三年广东海盗阿保位等二百三十七人受抚后编为兵；五十二年海寇陈尚义受抚后被安置金州并设水师营。这些因本卷未见实际交战，故不列战役卡。原文定位：`SRC-QINGSHIGAO-008-2606645-L0211`、`SRC-QINGSHIGAO-008-2606645-L0454`。
- 对朝鲜贡赋也继续减轻：五十年免白金、豹皮岁贡；五十九年朝鲜国王李焞去世后准王子继封，并将所进贡物退还。原文定位：`SRC-QINGSHIGAO-008-2606645-L0410`、`SRC-QINGSHIGAO-008-2606645-L0656`。

## 七、西陲战争的财政民生后效

- 西北军事行动扩大后，清廷反复承认运输和驻军对地方民力的压力。五十五年因飞刍挽粟经过边境，免山西、陕西、甘肃四十八州县卫次年银米谷草及旧欠；五十七年又因大兵远驻西边、征缮使秦民劳苦，免陕甘次年地丁粮税和旧欠。原文定位：`SRC-QINGSHIGAO-008-2606645-L0545`、`SRC-QINGSHIGAO-008-2606645-L0597`。
- 五十八年因比年西讨，沿边居民承担居送行赍，再免沿边六十六州县卫所次年额征银米。原文定位：`SRC-QINGSHIGAO-008-2606645-L0632`。
- 五十九年进藏运输延误导致云贵总督、巡抚被罢，但军粮仍继续入藏，显示长距离军需已成为行政能力与地方财政的重大压力测试。原文定位：`SRC-QINGSHIGAO-008-2606645-L0654`。
- 六十年康熙拒绝庆贺时直接承认西陲用兵使士兵长期暴露、百姓苦于转输；六十一年又把地方亏空与官兵过境、军需联系起来。原文定位：`SRC-QINGSHIGAO-008-2606645-L0670`、`SRC-QINGSHIGAO-008-2606645-L0709`。
- 因而本卷的战争成本不能只从具体战斗伤亡理解：长期转输、驻军和地方垫款的民生后效非常明确，但按合同应在本总结保留，不伪装成某一场战斗的 S 或 A。

## 八、综合观察

卷008的财政民生信息密度很高。一方面，普免钱粮、永不加赋、佃户分沾蠲赋、反复截漕赈灾和抑制额外征敛形成持续减负线；另一方面，西陲长期用兵又使陕甘及运输沿线承担军粮、馈助和挪款压力，并最终显化为地方亏空与火耗争论。更准确的图景不是单纯“轻徭薄赋”，而是中央持续以蠲免、帑银、库款和跨省粮运吸收灾荒与战争成本，同时基层财政、仓储和执行亏空不断暴露。

- 向前：卷007连山瑶乱在本卷完成受降和安插；本卷所见杜芳伤死作为对前期损害的后见事实，不倒灌修改卷007当时未知的阶段回报。
- 向后：准噶尔—西藏战争虽在康熙五十九年取得西藏控制终局，但西北主战线并未结束；卷009须继续核乌兰古木、吐鲁番、巴尔库尔等方向。

- 向后：西陲军费形成的地方亏空、转输和火耗争议将直接进入雍正朝财政整顿背景，后卷应作为治理连续性继续追踪，不倒填到本卷具体战役卡。
