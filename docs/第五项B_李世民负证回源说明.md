# 第五项B_李世民负证回源说明

本任务只处理李世民两条第五项B负证线索：`SRCH-I5B-LISHIMIN-NEG-YIJI-001` 与 `SRCH-I5B-LISHIMIN-NEG-WEIZHENG-001`。不处理李世民正证，不处理刘秀、刘庄。

本任务不定档、不定分、不排名。不能机械把杀功臣、处置功臣、死后信任逆转等同强负；必须先看谋反风险、司法争议、处置扩大化、追悔/恢复评价和对人才安全感的实际影响。

## 已成功回源

- `EVD-I5B-LISHIMIN-NEG-ZHANGLIANG-001`：据《旧唐书》卷六十九《张亮传》，张亮案有方术、图谶、义儿五百等政治风险材料；同时李道裕称“反形未具”，太宗后来追悔。按005R机制写为中负候选。
- `EVD-I5B-LISHIMIN-NEG-HOUJUNJI-001`：据《旧唐书》卷六十九《侯君集传》，侯君集参与太子承乾谋反链条，不能视为无端杀功臣；太宗念其旧功，曾有不忍置法的表态。按005R机制写为弱负候选。
- `EVD-I5B-LISHIMIN-NEG-WEIZHENG-001`：据《资治通鉴》卷一百九十七、卷一百九十八，魏征身后因荐人、示史官事被疑阿党，出现停婚、仆碑；但征辽后太宗深悔“魏徵若在，不使我有是行也”，并复立所制碑、劳赐其妻子。按更新后的对象锚点规则写为“谏臣身后信用反转”中负候选，并设置不得上探强负的封顶。

## 仍待继续回源

张亮、侯君集、魏征身后三个分案均已找到公开古籍文本来源。后续可继续补充《新唐书》《贞观政要》对照，但本任务不再扩展范围。

## 相邻项切分摘要

- 张亮案：B项只计功臣处置争议和人才安全感受损；谋反/图谶/政权安全风险切第五项C，司法严酷切第五项D。
- 侯君集案：B项只计功臣处置严厉对功臣预期的弱影响；太子谋反链条切第五项C，刑罚严酷切第五项D，战功不回填B项加分。
- 魏征身后：B项只计顶级谏臣身后政治信用与表达安全预期的中负剩余；魏征生前纳谏正证不在本任务处理，政策纠错效果切第二项B2，皇帝认知/反思能力切第五项E；复碑和恢复评价材料只作减轻与封顶因素。

## 人工裁判状态

三案均为候选证据，不得直接入分：

- 张亮：中负候选。
- 侯君集：弱负候选。
- 魏征身后：中负候选，且不得上探强负。

若后续发现新的罗织、扩大化、平反或其他反转材料，应另行回源并更新分案字段。
