# 重要制度发展节点链

本登记是制度行政A项的重要制度谱系公共入口，也是唐以后人物继续登记、续接或重构制度节点的当前基线。它不按制度名称堆节点：只有同一问题、核心接口和主要规则连续时才续接同一谱系；核心规则被替换时必须新建谱系。

当前登记47个重要建设节点、36条制度谱系，其中17个通过长期基线门禁计入S，30个属于非S重大建设、重建或权威化节点。

## 续接合同

1. 唐以后新人物先按制度问题、核心接口和主要规则匹配`lineage_id`，不得只按名称相似续接。
2. 新节点必须说明相对前一节点是创设、结构性重组、重大重建、权威化定型还是普通维护；普通维护不进入本登记。
3. R3/R4必须新增更晚时点的实际采用证据，并明确被保留的核心规则；短期接续、同名官署和后世相似制度均不足。
4. `PROVISIONAL_GENERIC_LINEAGE`只表示当前重要节点的临时归类，不建立跨人物前后继关系；补证后应细分到可审计谱系。
5. 既有节点只在归责、核心接口或材料裁决变化时更新；一般新增后继节点采用追加方式。
