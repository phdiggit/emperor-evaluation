# 制度行政公共成果

本目录保存制度行政计分材料、人物—子项使用索引和重要制度发展节点链。正式结算、唐以后制度续接、复核和回源审查必须从本目录进入；`.tmp/**`、模型摘要、试算展开和旧批影子底账只可作为生成线索，不得成为正式消费者的回源入口。

- `01-制度行政计分材料登记.json`：唯一材料主登记 manifest。正文按朝代分片保存在同名目录；每项保存材料 ID、机制语义、归责、回源状态和逐条史源。
- `01-制度行政计分材料登记.md`：完整人工审查视图。每项材料独立成节，每条证据独占一行。
- `02-秦至唐95人计分材料使用索引.json`：95人、380卡对公共材料的机器引用索引，不复制史料正文。
- `02-秦至唐95人计分材料使用索引.md`：人物—子项—材料 ID 的完整人工索引。
- `03-重要制度发展节点链.json`：A项重要制度节点与跨时代谱系的机器当前值；保存稳定谱系ID、节点角色、S门禁、前后继关系和唐以后追加合同。
- `03-重要制度发展节点链.md`：按谱系展示秦至唐当前47个重要制度节点；`PROVISIONAL_GENERIC_LINEAGE`只作临时归类，不伪造跨人物连续关系。

## 固定门禁

1. 结算行必须引用已存在的唯一 `material_id`；禁止只写标题或把临时节点摘要当作回源。
2. `BACKSOURCE_CLOSED` 只表示已经登记逐字引文和稳定史源定位；它不自动证明归责、方向、M 强度、R 值或子项映射正确，这些仍须在正式结算审查中逐项裁决。
3. `BACKSOURCE_BLOCKED` 可以保留在公共登记和影子使用索引中，但不得静默进入正式分数与排名。
4. 同一历史材料只在主登记保存一次。人物、子项和重复投影只通过使用索引引用，不复制材料正文。
5. 公共登记不得保存 `.tmp/**` 作为正式史源定位。需要迁入的证据必须登记固定页、版本号、逐字引文，或指向受 Git 管理的正式史料文件。
6. 唐以后新增重要制度必须先匹配`03`中的核心问题和制度接口，再追加创设、重组、重建或权威化节点；名称沿用、普通维护和后世相似制度不得续接既有谱系。
