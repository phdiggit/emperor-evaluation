# 金朝陇右—秦凤空间与交班依据

本材料支持第三项B1的当前逐区域裁决。地域、覆盖及计分值以[正式AB记录](../../评分结算/净收益/第三项军事与边疆净收益/国防安全/01-皇帝AB项正式结算.json)为准；固定空间权重见[统一锚点表](../../分项规则/第三项军事与边疆净收益/国防安全/01-B1统一空间锚点表.md)。下列覆盖判断是现存史料精度内的军政网络粗档，不是面积比例或逐县统计。

## 1. 区域对象与排除

陇右—秦凤边疆走廊采用临洮、兰州、河州、巩州、秦州及德顺、镇戎、关陇门户相接的区域军政网络。凤翔用于辨认东端支撑及通道，不能因此把稳定关中核心全部计入。商、虢、汝、陕等恢复记录另辨其实际位置；“十六州”不是本锚的面积或完整节点清单。

[《金史》卷26地理下](https://skqs.dazhishi.com/show_qpywnjrbdv.html)列临洮路及兰、巩、会、河等州，兰州西关明确“临黄河、夏边”。[张掖市史志办《西夏在张掖的军政建制》](https://www.zhangye.gov.cn/szb/dzdt/gjzy/202202/t20220221_793983.html)记甘、凉、肃属于西夏军政体系，1196年甘肃军司防地仍由西夏宗王掌握。不能把金陇右边疆写成金朝完整控制河西。

该区域在固定目录中单列为`LONGYOU_QINFENG_FRONTIER`，按一个连片区域边疆网络与辽东、松外0.5锚同级校准，低于兼含更广空间的河西—陇右0.8及关中—陇右1.2复合锚。不由“十六州”的州数、现代省面积或人物目标得分反推权重。与上述复合锚、吐谷浑—青海及汉中—秦岭锚涉及同一段空间时必须排重；本次金朝账不叠加这些区域。

## 2. 1161—1163：不能把任中低谷倒放到接班

### 1161年接班前已发生的损失

[《宋史》卷32高宗九](https://www.quanxue.cn/ls_zhengshi/songshi/songshi32.html)在绍兴三十一年九月记：

- 甲午，吴璘遣刘海复秦州，金守将萧济降；
- 丙申，曹㳜复洮州；
- 己亥，兰州王宏杀金刺史来降，彭青复陇州。

这些结果早于完颜雍十月即位，不能全部解释为其任内才发生的损失。秦、洮、兰、陇的实际退出使完整区域网络出现大块缺口。

### 1161年并非全线归零

同卷在绍兴三十二年二月记“姚仲攻巩州不下”，其后转围德顺；三月才记吴璘复德顺、严忠取环州以及王宏取会州。[《宋史》卷366吴璘、吴挺传](https://zh.wikisource.org/zh-hant/宋史/卷366)也将德顺、巩州的主要攻取放在次年，并记金军仍能由平凉、凤翔集结增援。因此不能由1163年“十六州皆复”倒推1161年全部西线已失。

在固定区域内，1161年末采用“约半个主要网络仍可执行”的粗档：秦、洮、兰、陇已有明确损失，巩、德顺等仍有金方守御，既不取完整或大部无缺，也不取全零。该档适用于海陵交班与世宗全国接管的粗粒度节点；二人1161年十月至十一月的竞争掌权不是无条件直接传位。两端同档只说明已证变化未再跨本区域覆盖阶梯，不表示全部州城在两端完全一致。

### 世宗任内低谷与恢复

[《金史》卷6世宗上](https://www.quanxue.cn/ls_zhengshi/jinshi/jinshi06.html)记大定二年七月复原州，九月复汝州；三年正月“复取德顺州”，四月取商、虢、环州并总称“宋所侵一十六州至是皆复”。这些日期与《宋史》的次年攻取相接，说明“先失后复”跨越多个阶段。

世宗B1只比较可比接班与交班，不能将1162年的更低控制态代作1161年起点，再把全部回升记成净新增。实际恢复过程仍可用于本项B2、B4及相应军事能力、成本审查，但不另叠加B1空间信用。到1189年交班，以已恢复并由后续州县、驻防运行支持的区域网络作为终点；不声称曾取得西夏河西。

## 3. 1224年前后：前沿受损不等于只余孤立西线节点

[《金史》卷16宣宗下](https://www.quanxue.cn/ls_zhengshi/jinshi/jinshi16.html)记西宁、会州及积石蕃部等损失，同时记巩州军队作战、陕西行省还治平凉、兰州提控抵御夏兵，以及元光二年二月“凤翔围解”。这些资料支持区域有明显缺口，不能支持整体仅剩零散据点。

[《金史》卷123忠义三](https://www.quanxue.cn/ls_zhengshi/jinshi/jinshi123.html)记陀满胡土门正大三年复任临洮总管、四年五月城破；爱申在正大四年守德顺百二十昼夜后城破。[《金史》卷17哀宗上](https://www.quanxue.cn/ls_zhengshi/jinshi/jinshi17.html)又记正大八年凤翔受围及陷落。后继时期材料只用于核对节点何时失去及前后连续性，不把后来的毁损倒算给宣宗。

因此，宣宗交班、哀宗接班采用“大部军政网络仍有效但有明显缺口”；宣宗的蒙古、西夏压力与已经发生的退控仍保留。哀宗本人窗口内后续临洮、德顺、凤翔等相继失陷，至1234年无可移交控制，终点归零。

## 4. 统一主链及北方属部的独立边界

完颜晟的第一项消费1123—1127年灭辽、攻宋及北方大块控制；第三项只保留其后独立的陕西—汉中方向。边界见[第一项合同§7](../../分项规则/第一项政权奠基与统一贡献及能力/00-规则与计分合同.md#7-逐人主链边界)。本账保留完整客观交班快照供继任者读取，但本人的漠南、淮河取得不能凭客观快照再次获B1信用；陇右—秦凤独立后续结果另计，不按旧分倒填排除余额。

V2.27包只提供拆账线索。其关中、陇右范围参数及前后任镜像守恒不是史料证明，也不进入现行分值。关中稳定核心不因包中有原子就纳入B1；V2.32的粗面积、覆盖等效端点和评级门槛不用于本次裁决。

### 北方属部的军政控制与漠南覆盖

- **1161年交班。** 海陵征发西北路契丹丁壮，撒八等杀招讨使、夺司藏甲，山前山后群牧及五院司部分响应，乌古敌烈招讨使也被杀。金军仍有临潢据点。窝斡东返后围临潢、攻泰州属于世宗即位后的阶段，泰州未陷。接班前可确认的是部分属部动员及官署失控，不能从后来战场的分布推算1161年的漠南退控范围。[《金史》卷6世宗上](https://zh.wikisource.org/zh-hant/金史/卷6) [《金史》卷133窝斡传](https://zh.wikisource.org/zh-hant/金史/卷133#窩斡)
- **世宗平乱及晚期交班。** 1162年世宗调军驰援、招纳叛众，窝斡余部入奚地、扰古北口一带，同年首领被擒、官军追收余众。平乱后仍有西北路招讨都监、乌古十垒部族节度使等实任。地理志还记西段丰州原管部族和军马归西南路招讨司，1178年置净州，桓州军兵归西北路招讨司。1181年泰州与临潢旧堡群整饬、安排驻戍与开壕，部分建设因饥荒暂缓，壕沟有沙雪淤塞。这些材料支持可征调、派官和驻防的区域网络延续，但无法以拟设堡数或据点间画线给出完整范围。[《金史》卷133窝斡传](https://zh.wikisource.org/zh-hant/金史/卷133#窩斡) [《金史》卷94夹谷清臣传](https://www.quanxue.cn/ls_zhengshi/jinshi/jinshi94.html) [《金史》卷24地理上](https://zh.wikisource.org/zh-hant/金史/卷24)
- **章宗与卫绍王阶段。** 章宗朝临潢以西的边堡和壕线有续建及驻军记载，跨越临潢、金山和北方诸州外缘的边界概述见《金史》地理志。各段成形时点有别，不能整体倒推至1189年。1211年后原网络发生实质解体，耶律留哥由金北边千户转为附蒙古、自立军政中心即是一例。脱离的属部和仍守城镇应分辨，边防失守也不能代替每一子区的退控证据。[《金史》卷24地理上](https://zh.wikisource.org/zh-hant/金史/卷24) [《金史》卷94完颜襄传](https://zh.wikisource.org/wiki/金史/卷94) [《元史》卷149耶律留哥传](https://zh.wikisource.org/wiki/元史/卷149)

现采0.75和1.00分别代表标准网络大部有效和整体有效。上述材料已能界定一批可执行节点，但西段及草原腹地的同窗实控、边堡与属部重叠、1123—1127年已由第一项消费的空间，尚不足以连成可在各次交班间比较的粗档。现采北方数值保留为待复核基准，未量化影响依[证据解释登记](../../../config/common/evidence-interpretation-cases.json)披露。
