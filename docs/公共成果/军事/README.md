# 军事公共成果

本目录保存秦至清战役登记、武将人才等级与军事行动成本和收益登记的当前 canonical 结果，只保留当前值，历史变更由 Git 承担。文件名沿用既有稳定入口；JSON 内的 `scope` 与分区摘要声明当前实际覆盖范围。

- `01-战役登记.json`：机器读取的完整父战役登记。
- `01-战役登记.md`：战役登记人工阅读视图。
- `02-武将人才等级.json`：只消费最新战役登记生成的人才等级结果。
- `02-武将人才等级.md`：按等级与净值展示的人才等级阅读视图。
- `03-军事行动成本和收益登记.json`：秦至清“评价主体—任期窗口—父投资周期”的九轴历史裁决与审计入口，不再自动生成D档。
- `03-军事行动成本和收益登记.md`：军事行动成本和收益周期的全量精炼索引与统计阅读视图。

`01-战役登记`只保存跨评分项复用的中性战役事实，不包含九轴。`03-军事行动成本和收益登记`与战役登记物理分离，不得回写、覆盖或作为字段并入 `01-战役登记`。

当前仓库不再保留战役登记、武将人才等级或旧线性Q的D生成器；这些登记作为已验收 canonical 当前值或审计lineage保留。第三项D正式JSON是裁决唯一真源，可用轻量命令校验：

```powershell
python v4.py third-item-d-verify
```

该命令只读取D正式JSON与同值Markdown，检查人物唯一性、战略链证据、跨项去重、档位点值映射和汇总计数；不会读取AB、C或公共登记，也不会改写正式结果。

本目录不是并行历史库，不保留旧版、运行展开、checkpoint或审计中间结果。

统一链横向总档改为消费“被实际击败的独立战争机器”，不再由净控制量公式决定。对手分 `O1-O6`：从地方部众、大型流动军、成建制方面军、成熟区域战争机器、同级全国竞争极到持续压制奠基政权的超越型强敌；不按国号、农民军、部族或旧国家出身定档，只看交战当时已经兑现的统一指挥、财政补给、兵员再生、根据地纵深、持续战争能力以及相对奠基政权的实际军事能量。统一链再按最高对手层级、同级数量和复合终局落入 `H1-H5`，不做复杂数值加总；终结一个O6可直接命中H1。

统一链对手体系唯一裁决位于 `config/military/unification-chain-opponent-calibrations.json`。同一体系复起或残余只增强原体系韧性，不重新完整消费；内部兵变、政治交付和不可归责瓦解不产生军事击败信用。时期化区域 `S/M/R` 与战争净控制量继续保留：它们只证明对手根据地能支撑何种战争体系、以及战果是否真正落地；高价值地区里的松散流动军不能自动吃满该地区的军事能量。

秦至清17条统一链在战役登记 JSON 中只使用一个 `unification_campaign_portfolios` 当前合同，秦至唐与唐以后顶层字段完全一致；时期性的控制快照、区域增量和战役群控制效果只放在同构的 `control_audit` 子对象中，不保留唐前/唐后两套业务结构。

当前对手含金量总档为：`H1` 秦、西汉、唐、元；`H2` 东汉、北宋、金灭辽破宋链、明、清创业链；`H3` 晋、清再统一链；`H4` 辽；`H5` 隋与金前史石鲁整合；两个元先世局部兼并低于 `H5`，高丽链不进入当前横向比较。西汉因终结持续压制汉集团的项羽O6进入H1；唐以洛阳—虎牢复合终结王世充、窦建德两个O5进入H1，东突厥O6只进入A项统一环境压力，不因未在本统一链终结而计入H档；东汉由公孙述、隗嚣、张步、李宪四个O4命中H2，没有O5；隋灭陈对象为O4，统一后残余不另计，故为H5。净控制量仍逐区可审计，但只是辅助结果。所有统一与创业兼并记录仍只进入战役底账，国防消费为 `EXCLUDED_UNIFICATION`，不生成成本收益或安全收益结算。

单项战役与普通战役使用同一对手上限：单项实际击毁O6主力或体系，或同一连续战役群复合闭合两套O5，才可到 `S+`；单项实际击毁O5主力或体系，上限 `S`；O4上限 `S-`；O3通常上限 `A`；O1/O2通常不高于 `B`，只有建立国家核心等额外战略结果才可到 `A`。所属国家是O5/O6不表示偏师、守军、复起或残部也是同档；O档只给上限，结果闭合、对手状态和实际主力效果仍可继续下调。普通高档160项已经逐项写入对手信用审计，当前保留高档136项；残部、孤立远征军、局部守军、短期联盟和机械合并的多个政权不得冒充O4。元灭宋与明灭张士诚的父群/跨书终局已各合并一项，不重复消费。

五代十国 45 个 A 级父项已完成人物归责终态：37项按行动句、结果句和定点事实组拆成63条本人子结果及13条败责，8项因缺稳定人物身份或不能闭合单一统帅而登记 `PERSON_COMMAND_UNKNOWN`。辽朝 11 个 A 级父项也已闭合：5项形成5条本人子结果及1条败责，6项保持 `PERSON_COMMAND_UNKNOWN`。两个批次均不再保留 `PERSON_DETAIL_PENDING`。人物子结果另行裁决 `result_tier` 与 `combat_difficulty`，不得继承父项等级；`stage_executor`、`terminal_finisher` 只消费本人完成部分。人才视图中的唐以后人物均为 `evidence_lower_bound`，不冒充冻结终值。

唐以后 S 档复核已改为独立硬 Gate，并先于后续人物归责执行。九个分区原365个A项已完成结构复核，进一步应用O档上限和重复消费校验后，当前唐以后公共战役为 `S` 26项、`S-` 49项，`PENDING_S_TIER_REVIEW=0`，没有可验收的 `S+`。秦至清当前合计 `S+` 2项、`S` 48项、`S-` 150项。统一组合净控制量不会产生S档；人物子结果也不继承父级升档。当前公开战役已无 `PERSON_DETAIL_PENDING`；跨书同一终局只保留一个公共战果和一份人才信用。
