# 军事公共成果

本目录保存秦至清战役登记与武将人才等级的当前 canonical 结果，只保留当前值，历史变更由 Git 承担。文件名沿用既有稳定入口；JSON 内的 `scope` 与分区摘要声明当前实际覆盖范围。

- `01-秦至唐战役登记.json`：机器读取的完整父战役登记。
- `01-秦至唐战役登记.md`：战役登记人工阅读视图。
- `02-秦至唐武将人才等级.json`：只消费最新战役登记生成的人才等级结果。
- `02-秦至唐武将人才等级.md`：按等级与净值展示的人才等级阅读视图。

重建命令：

```powershell
python v4.py battle-parent-contract-registry
python v4.py military-talent-grade-registry
```

本目录不是并行历史库，不保留旧版、运行展开、checkpoint或审计中间结果。

统一链横向总档改为消费“被实际击败的独立战争机器”，不再由净控制量公式决定。对手只分 `O1-O5`：从地方部众、大型流动军、成建制方面军、成熟区域国家到全国第一梯队国家机器；不按农民军、部族或旧国家出身定档，只看交战当时已经兑现的统一指挥、财政补给、兵员再生、根据地纵深和持续战争能力。统一链再按最高对手层级、同级数量和复合终局落入 `H1-H5`，不做复杂数值加总。

统一链对手体系唯一裁决位于 `config/unification-chain-opponent-calibrations.json`。同一体系复起或残余只增强原体系韧性，不重新完整消费；内部兵变、政治交付和不可归责瓦解不产生军事击败信用。时期化区域 `S/M/R` 与战争净控制量继续保留：它们只证明对手根据地能支撑何种战争体系、以及战果是否真正落地；高价值地区里的松散流动军不能自动吃满该地区的军事能量。

秦至清17条统一链在战役登记 JSON 中只使用一个 `unification_campaign_portfolios` 当前合同，秦至唐与唐以后顶层字段完全一致；时期性的控制快照、区域增量和战役群控制效果只放在同构的 `control_audit` 子对象中，不保留唐前/唐后两套业务结构。

当前对手含金量总档为：`H1` 秦、唐、元；`H2` 西汉、北宋、金灭辽破宋链、明、清创业链；`H3` 东汉、晋、隋、清再统一链；`H4` 辽；`H5` 金前史石鲁整合；两个元先世局部兼并低于 `H5`，高丽链不进入当前横向比较。唐以洛阳—虎牢同一连续战役群复合终结王世充、窦建德两个 `O5`，故进入 `H1`；东汉只有公孙述明确达到 `O5`，隗嚣为 `O4`，赤眉及多支中原流动军不再凭所处区域吃满国家机器档，故为 `H3`。净控制量仍逐区可审计，但只是辅助结果，不再形成“东汉825高于唐760”的主档结论。所有统一与创业兼并记录仍只进入战役底账，国防消费为 `EXCLUDED_UNIFICATION`，不生成成本收益或安全收益结算。

单项战役与普通战役使用同一对手上限：同一连续战役群复合闭合两套 `O5`，或完整闭合外部霸权体系，才可到 `S+`；单项实际击毁 `O5` 主力或体系，上限 `S`；`O4` 上限 `S-`；`O3` 通常上限 `A`；`O1/O2` 通常不高于 `B`，只有建立国家核心等额外战略结果才可到 `A`。所属国家是 `O5` 不表示偏师、守军、复起或残部也是 `O5`；O档只给上限，结果闭合、对手状态和实际主力效果仍可继续下调。普通高档129项已经逐项写入对手信用审计，当前保留高档121项；元灭宋与明灭张士诚的父群/跨书终局已各合并一项，不重复消费。

五代十国 45 个 A 级父项已完成人物归责终态：37项按行动句、结果句和定点事实组拆成63条本人子结果及13条败责，8项因缺稳定人物身份或不能闭合单一统帅而登记 `PERSON_COMMAND_UNKNOWN`。辽朝 11 个 A 级父项也已闭合：5项形成5条本人子结果及1条败责，6项保持 `PERSON_COMMAND_UNKNOWN`。两个批次均不再保留 `PERSON_DETAIL_PENDING`。人物子结果另行裁决 `result_tier` 与 `combat_difficulty`，不得继承父项等级；`stage_executor`、`terminal_finisher` 只消费本人完成部分。人才视图中的唐以后人物均为 `evidence_lower_bound`，不冒充冻结终值。

唐以后 S 档复核已改为独立硬 Gate，并先于后续人物归责执行。九个分区原365个A项已完成结构复核，进一步应用O档上限和重复消费校验后，当前唐以后公共战役为 `S` 21项、`S-` 34项，`PENDING_S_TIER_REVIEW=0`，没有可验收的 `S+`。秦至清当前合计 `S+` 2项、`S` 43项、`S-` 138项。统一组合净控制量不会产生S档；人物子结果也不继承父级升档。没有完整人物裁决的S档父项保持 `PERSON_DETAIL_PENDING`；跨书同一终局只保留一个公共战果和一份人才信用。
