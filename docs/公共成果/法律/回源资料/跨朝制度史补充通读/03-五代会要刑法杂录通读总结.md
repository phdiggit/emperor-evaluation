# 《五代会要》卷十“刑法杂录”通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

## 一、材料定位

本次通读《五代会要》卷十“刑法杂录”。本卷按诏令日期保存后唐、后晋、后周的死刑复核、录囚、医囚、法源公开、籍没、官当、刑讯和监狱供给规则；相比《旧五代史·刑法志》，它对具体年月、提议者和制度细部的补充尤其显著。

本卷后半的历法、天象材料不属于法律治理；灾异、降雨、日食与赦宥之间的附会全部排除。

## 二、主要节点和归责

### 1. 后唐录囚、覆奏与复核程序

庄宗同光三年规定：轻罪及时疏理，重罪依秋冬行法；魏逅提出州府选择清强判官每月引问、外县羁押三日以上须报州府，获准施行。

明宗天成二年，王爵援引唐制，指出近年死刑全不覆奏，甚至赦令已下而人已被杀，推动京城死刑在决前、决日各覆奏一次；次年又规定：

- 案成后必须当面录问；
- 供述有异即移司别勘，并追究原推勘官吏；
- 未经录问不得详断；
- 事理不明不得施加责情杖。

这不是泛泛“慎刑”，而是月度录囚、死刑覆奏、口供复核和异议转勘的程序链。

- **方向与运行**：`P3·L2`。
- **归责**：李存勖对同光制度采用 `+R4`，魏逅 `+R4`；李嗣源对天成制度采用 `+R4`，王爵 `+R4`。普通执行者不登记。

### 2. 后唐医囚、法源可见与死者收葬

明宗长兴二年命各州府设病囚院，病囚即时诊疗，夏季每五日洗刷枷杻；又要求百司把适用的律令格式、六典抄写成卷并书于公厅，新任官必须自行抄读。长兴四年采张仁瑑奏，允许死刑犯与亲故辞别，死后由亲故收葬；无亲属者官给棺、埋葬并标识姓名。

这些规则分别改善羁押健康、执法法源可见性和死刑执行后的基本人格待遇，可以合并为一个狱政与法源透明节点：

- **方向与运行**：`P2·L2`。
- **归责**：李嗣源 `+R4`；张仁瑑在收葬规则上 `+R3`。病囚院和法源公开的具体建议者未见，不虚构。

### 3. 后晋禁止无依据籍没并继续医囚

石敬瑭朝明确：

- 囚犯染病由医工诊治并公费给药，轻罪者可由家人看护，杖刑待痊愈后执行；
- 相州以旧例籍没盗贼财产、格律无明文，朝廷下令一律按格定罪，不得没收家资；
- 自残申冤者的自残罪与所诉案件分别审理，不能以自残为由拒绝审查实体冤情；
- 笞杖须由清强官员监视。

这是对后唐狱政的重大延伸和对地方律外处分的明确纠正，可并入既有后晋“报核、上讞并禁止律外刑”节点；石敬瑭的采用责任应由 `+R3`提高为 `+R4`。

李象提议所有散官不得官当、赎罪，详定院最后只排除部分无品职员，保留有品官依法当赎。该材料可用于官当身份差异的跨朝校准，但不能把未被完整采纳的李象方案登记为成果。

### 4. 后周限制籍没、增加死刑可追溯性

郭威朝明确规定除反逆外不得没籍家产、诛及骨肉；又要求州府执行死刑后上报原案、推司官、详断检法官姓名，并用朱书列明所据法条。这既缩小无罪亲属受罚，也建立死刑责任与法源的事后可追溯性。

- **方向与运行**：可把既有节点扩为“限制连坐籍没＋死刑责任可追溯”，仍为 `P3·L2`。
- **归责**：郭威 `+R4`；中书门下对限制连坐籍没 `+R3`。死刑报核具体建议者未见。

### 5. 后周监狱供给、刑讯限制与累犯死刑

柴荣朝规定无家属供食的囚犯每日由官给米、水浆，定期清洁枷杻，患病者看护医治；责情杖不得超过臀十五杖，致死必须上报。这是狱政保障和刑讯边界的重大延续。

同一时期又规定盗窃者三次经官断罪，不论赦前赦后和赃物多少，一律处死。该规则把不区分数额和具体危害的累犯盗窃统一升为死刑，是明确的本朝新增重刑：

- **方向与运行**：`N2·L0`，法令已交付但本卷未见案件运行结果。
- **归责**：柴荣 `-R4`；具体建议者不明。
- **边界**：不能用柴荣编成《大周刑统》的正向责任冲淡这一独立负向采用责任。

## 三、对现有五代底账的修订结论

1. 后唐改革族提高为 `P3·L2`，补入魏逅、王爵的关键设计责任，并把两位皇帝各自采用范围写清。
2. 新增后唐“医囚、法源公开与死者收葬”节点，补张仁瑑。
3. 后晋正向节点补入公费医囚、禁止无明文籍没、实体申冤必须审查和杖刑监督；石敬瑭提高为 `+R4`。
4. 后周郭威节点补入死刑执行后上报承办人员和法条的可追溯制度。
5. 新增柴荣“三犯盗窃不论赃数一律处死”负向节点。
6. 各朝赦令、节令停刑、灾异解释不按次数计分；仍然服刑、戍边或受杖不是减刑节点的附加负面。
