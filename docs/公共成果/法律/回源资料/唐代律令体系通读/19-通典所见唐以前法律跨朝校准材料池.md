# 《通典》所见唐以前法律跨朝校准材料池

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

用途：保存本轮唐代法律阅读顺带取得的唐以前材料，供以后各朝法律治理总结和跨朝横向校准使用。

边界：

- 本文件不进入唐代计分链路，也不直接给前朝套用唐代综合档位。
- 各朝制度形态、律令结构和史料口径不同；所属朝代通读时负责吸收、补证、定档和归责。
- 同一历史节点最终只登记一次；本文件只保存线索和《通典》出站证据。
- 审计回源读取本目录 `05、06、08、09、11` 号通读总结及 `source-texts/通典-卷163—170.txt`。
