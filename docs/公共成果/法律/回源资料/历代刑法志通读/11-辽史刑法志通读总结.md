# 《辽史·刑法志》通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

> 状态：上下两卷通读完成。辽与五代、宋长期并行，采用“草原旧俗＋汉地律令”的双制度基线，不把宋法机械当作辽的单一前朝法。

## 一、中心论旨

《辽史》认为辽起于武力，早期以重刑和临时处分维持扩张；景宗、圣宗逐步把刑政引向复核、平等适用和较稳定法制；兴宗以后频繁赦免、权臣诬狱和法条膨胀又破坏统一秩序，天祚末年回到任意酷刑并随国家崩溃。

## 二、主要节点

### 1. 早期双轨法与酷刑

太祖为契丹及诸部另定法，汉人依律令，太宗又使渤海人依汉法，并恢复钟院使民众可以申冤。这是把扩张中的多族群纳入可识别司法辖区的治理能力，但同时产生身份法差异；早期梟磔、生瘗、支解、籍没和奴属化远重于唐五代基线。世宗朝同一谋反案件中四人罪同而刑罚各异，正是“双轨和权宜”已经造成同罪不同罚的直接运行证据。

应拆分为：

- 多元辖区的制度建立：`positive / significant` 的国家治理能力；
- 族属不同法和非常酷刑：`negative / structural`。

### 2. 穆宗的法外暴虐

穆宗因狩猎、饮食和近侍小过使用炮烙、铁梳、肢解等刑，杀百余人；一次又把六十五名猎役人员全部提出，杀四十四人、重杖其余。史书所记百余是累计概数，六十五与四十四则是具体处分规模，二者不应相加成精确总数。

穆宗口头允许醒后覆奏醉中不当处分，却没有真正改变。它是皇帝个人意旨直接架空法制的 `negative / structural`，不能用“主要伤害近侍”降低公共方向，也不能用偶发悔言登记纠偏成果。

### 3. 景宗恢复申冤，圣宗推进同罪同法

景宗恢复被穆宗废掉的钟院并亲录囚徒，使申冤渠道重新运转；但他也因判断奴告吴王为诬而不经审问直接杀告发者，说明恢复救济并未消除皇帝亲断的任意性。

圣宗时期：

- 契丹与汉人斗殴致死改为同罪；
- 契丹十恶依律；
- 贵戚犯罪按问，减少身份例外；
- 建立大理寺专官、复核和巡回审狱；
- 减轻部分盗罪死刑和尸市羞辱；
- 禁止主人擅杀奴婢。

圣宗还把盗窃首犯死刑门槛由十贯提高到二十五贯，并建立三犯、四犯刺配、五犯处死的递进规则；对擅自杖杀部民的首领夺官，使其他官吏不敢再酷。史书以南京等地“狱空”概括运行效果，可以支持当时刑狱明显减少的方向，却不能单独证明全国无犯罪或所有裁判公正。

这是辽代正向主峰，相对于早期双轨与贵戚优免，属于 `positive / structural`。南北院分治仍存，圣宗也仍有特赦后处死近侍等严厉个案，这是改革限制，不足以抹去同罪同法和复核的实际增量。

### 4. 兴宗的成文整合与任意宽免

重熙五年把太祖以来法令参古制整理为五百四十七条，具有 `positive / significant-to-structural` 的制度化价值；此前又提高若干盗罪死刑门槛、取消终身徒同时受杖和面黥的三重处罚。

但兴宗随后屡因皇亲、节庆和个人好恶宽免：枉法受赃、伪造敕书、盗贡物等重罪也可免死，贵族强掠妇女又因太后干预减免，普通人在禁地射鹿反受更重杖刑。钦哀后更制造仁德皇后大狱，四十余名姻亲受牵连，皇后最终被杀。成文整合、实体减刑、任意宽免和政治大狱必须分别登记。

### 5. 道宗统一法努力、条文膨胀和乙辛诬狱

道宗提出契丹、汉人国法不应异施，命耶律乙辛等更定条制，是明确正向方向。死刑曾下放地方即时处决，因担心枉杀又恢复附近官司覆问，显示程序纠偏确实发生。

但统一法编纂从五百余条扩展到七百八十九条、继而增重至千余条。关键不是数字本身，而是史文明言官吏不能遍习、百姓无所避、犯法增多、奸吏乘机舞文，最终道宗撤销新增条目、恢复旧法。

统一法努力可判 `positive / significant`，但因复杂化失败，不升结构性。乙辛随后利用告首奖励和由本人主持的专案审讯构陷皇后、太子，杀三十五名相关人员并继续杀害子弟、籍没妇女幼童和家产，最终皇后、太子皆死。这里有具体人数支持案件规模，但结构性判断来自告首激励、审讯者利益冲突、家属牵连和皇帝持续轻信的完整机制，不只是“死了数十人”。

### 6. 天祚末期

天祚虽恢复部分乙辛旧案受害者官爵和财产，却又掘墓戮尸、诛其子孙，使平反夹带报复性株连。此后贿赂者可以免罪，失城者可能只免官，禁地射鹿者反被处死；盗乱加剧后又恢复投崖、炮掷、钉割、脔杀等酷刑，并因萧奉先构陷杀死有声望的皇子敖卢斡。

篇章明确把严刑、骨肉相残和政权崩溃相连。严谨归因是：赏罚失序和法外酷刑破坏官僚信任与皇位继承，是末期国家能力衰败的重要机制；辽亡仍有战争和政治等多重原因，故暂列 `negative / era_shaping` 候选而非单因结论。

## 五、辽宋金元比较意义

辽证明“多元辖区”与“身份不平等”必须分开判断。后来的金、元也采取族属和辖区分治；只有当适用差异造成同罪不同罚、特权免刑或救济障碍时，才登记负向结果，不能把文化多元本身判负。

## 六、证据限度与理解闭合

本篇的“狱空”“人重犯法”等是史家对阶段运行的总结，必须依附同罪同法、提高死刑门槛、复核和惩治酷吏等具体制度使用；不能直接转成跨朝犯罪率。兴宗、道宗、天祚时期的政治大狱则有明确人员、程序和家属处分，足以判断方向与结构，不必继续逐名考证所有受害者。

东汉至辽反复出现同一规律：法条统一若同时制造过多条目，可能降低可知性并扩大奸吏裁量。辽的特殊贡献是提供了族属双轨逐步向同罪同法收束的完整案例，为金、元比较建立直接基线。
