# 《隋书·刑法志》通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

> 状态：篇章通读及南北朝→隋直接基线校准完成。《隋书·刑法志》本身连续保存梁、陈、北齐、北周制度，另以《魏书·刑罚志》补足北魏长线。

## 一、篇章范围与中心论旨

《隋书》卷二十五从梁、陈、北齐、北周法律沿革写到隋，不是只记隋代。前朝内容为开皇律提供制度来源和反面基线，不能直接登记为隋朝成果。

全篇最明确的论旨是：成文法的宽简与实际政治用法必须分开。隋高祖能够制定当时最简明、减刑幅度很大的开皇律，却又因猜忌、喜怒和自负不断在法律之外杀人；炀帝也先制定较轻的大业律，随后在战争、征发和盗乱中抛弃律典，转向即时处斩和族诛。法律文本的进步不能掩盖统治者摧毁法律运行的事实。

## 二、南北朝至隋的复合基线

隋的直接制度起点不是单一王朝：其统治核心承接北周，统一后又吸收北齐、梁陈传统。《隋书》本篇已经提供北周宣帝严刑乱政、北齐律制、梁陈制度的连续比较，《魏书·刑罚志》则显示北魏早已历经成文化、减刑与法外诏杀的反复。

因此，开皇律不应称为“全国刑罚结构的第一次重构”。更准确的判断是：它在已有十二篇、五刑和官僚司法传统上，完成统一帝国范围的重新整合，并相对北周末年显著废除酷刑、缩减刑等、规范刑讯和申诉。其正向 `structural` 强度成立，但原创性低于其统一与运行价值。

## 三、开皇刑法改革

### 1. 从北周末年刑政失序转入统一法典

北周宣帝时期政令反复，先以宽法取众心，继而设置《刑经圣制》、天杖和极端惩罚，公卿、妃后均受鞭楚，国家上下无所适从。杨坚为相后先行宽大之典，删略旧律，为受禅后的开皇改革准备基线。

开皇元年，高颎、郑译、杨素、常明、韩濬、李谔、柳雄亮等奉诏重定新律。新律确立死、流、徒、杖、笞五刑，废除鞭刑、枭首和轘裂，减轻流徒年限，并规范赎刑。

这不是单纯编书，而是对南北多源法制的全国性重新整合。

### 2. 取消法外刑讯并建立申诉程序

前代讯囚常使用大棒、车辐、鞋底压踝等法外手段，造成大量诬服。开皇初明确废除苛惨讯法，限制讯囚总数，规范枷杖尺寸和行刑人，并允许县、郡、州、省逐级申诉，最终可击登闻鼓。

这同时改变了：

- 刑讯边界；
- 司法程序；
- 申诉通道；
- 官吏以刑逼供的操作空间。

属于能够独立运行的结构性程序改革。

### 3. 开皇三年再次删律

高祖看到断狱仍达万条，判断原因是律法过密，命苏威、牛弘等重新删定：

- 删除死罪八十一条；
- 删除流罪一百五十四条；
- 删除徒杖等千余条；
- 最终只保留五百条、十二篇。

原文评价“刑网简要，疏而不失”。同时设置法律教学，重大案件先确定所据律文；后来又废除容易形成小吏司法垄断的律博士、律生系统，要求各曹判决时完整写出律文。

这里既有简化法律的进步，也有一个值得审查的问题：废除专业律官是否降低专业化、增加一般官员误判，需要结合后续运行材料判断，不能只按皇帝诏旨判正面。

### 4. 连坐减免和死刑复核

开皇六年将北周叛乱者被没入的家口赎为编户，废除孥戮相坐；又规定州县死囚不得立即驰驿处决。开皇十二年，死罪必须移大理复核；十五年实行死刑三奏。

这些可以形成两个层次：

- 缩小家属连坐，是权利义务的独立正向改变；
- 死刑集中复核和三奏，是独立司法程序成果。

## 三、开皇法制内部的身份差序

开皇律保留八议，七品以上减罪，九品以上可赎，官员可以官当徒刑。这是全国法制的一部分，明确制造身份差序。

但评分时不能简单采用现代平等标准把整部开皇律判为 mixed。应比较本次改革相对于北周旧制是否新建、扩大或缩小这些特权：

- 若主要继承前制而未扩大，作为制度限制；
- 若改革以扩大官贵免责为重要增量，则形成独立负向轴；
- 无法确定增量时，不用现代价值补猜。

## 四、高祖后期：皇帝亲自破坏自己建立的法律

### 1. 殿廷法外杖杀

高祖性格猜忌，常令左右侦察小过，以重罪处置，在殿廷直接杖人、杀人。高颎、柳彧、冯基等多次劝谏，皇帝有时追悔，却反复恢复殿杖。

这不是开皇律的执行成本，而是与正式律典相分离的法外统治方式。因为机制、责任和运行阶段可独立定位，应另立负向成果，不能将开皇律整体改成 mixed。

### 2. 以诱捕和告发治理盗窃

高祖用赃家产业奖励告发者，短期内盗情似乎平息，但很快出现无赖故意遗物、诱使富家子弟拾取后送官领赏的系统性陷害。随后又规定盗一钱即死、知情不告也可至死，出现多人偷一瓜、一榱即处决的结果。

这一链条完整说明：

> 以财产奖励告发 → 告发者制造案件 → 无辜者被陷 → 刑罚极端化 → 社会普遍恐惧。

它与唐代武周罗织、明代厂卫“买事件”具有跨朝可比性，是典型的结构性负向治理。

### 3. 律外裁量和深文官僚激励

开皇十七年允许对属官“于律外斟酌决杖”，结果是上下相驱、以残暴为干能、以守法为懦弱。仁寿年间高祖不再依律科断，杨远、刘子通等以深文承旨得到重用，杨素又能干预案件轻重，无罪而死者不可胜数。

这说明开皇后期的核心倒退不是法条突然消失，而是：

- 皇帝示范法外用刑；
- 官员因顺旨重判获得晋升；
- 权臣可以影响案件；
- 正式律典丧失约束最高权力的能力。

因此高祖刑法治理必须形成“结构性正向立法”和“结构性负向运行”两个独立结果，在皇帝第二项评分中净结算。

## 五、炀帝：轻法开局与全面弃法

### 1. 大业律的轻刑改革

炀帝即位后，以开皇后期禁网深刻为由修律，形成五百条、十八篇的大业律，二百余条从轻，刑讯和枷杖制度也轻于旧制。原文记百姓久厌严刻，对刑宽表示欢迎。

该成果有制度文本和社会反应，但是否长期运行非常有限，因此初步只能判显著正向，不能因全国颁行直接判结构性稳定成果。

### 2. 战争和征敛使律典失效

此后炀帝外征四夷、内穷嗜欲，兵役、赋敛日繁。官员为完成临时任务抛弃法律，贿赂公开，贫民无告而聚为盗贼。皇帝又规定盗窃无论轻重无需奏报一律处斩，继而没收家属；杨玄感反后恢复族诛、轘裂、枭首甚至命公卿食肉等已被开皇律废除的酷刑。

因果链是：

> 战争与征敛提高社会压力 → 盗贼增加 → 临时严刑替代正式法律 → 官员获得任意生杀权 → 群盗更盛 → 国家崩溃。

大业律的轻刑文本和后期实际运行方向完全相反。它们具有不同阶段、不同措施和不同结果，应分别登记，不能用一个 mixed 标签掩盖弃法造成的结构性灾难。

## 六、皇帝与重要臣子参与程度

参与程度只描述本篇可支持的决策、设计、执行和破坏角色；集体列名不自动等于领衔，更不自动共享整个法典成果。

| 治理节点 | 皇帝参与程度 | 重要臣子参与程度 | 当前归责边界 |
| --- | --- | --- | --- |
| 开皇初定新律 | 隋高祖杨坚确定宽简方向、下诏修律并采用，属直接主导 | 高颎、郑译、杨素、常明、韩濬、李谔、柳雄亮等奉诏参与；本篇列名不足以区分核心设计量 | 杨坚承担决策和采用责任；臣子暂按集体编修，待本传或奏议补领衔证据 |
| 开皇三年删定五百条 | 杨坚因断狱仍繁再次下令删定，直接推动 | 苏威、牛弘等承担删律方案的领衔责任候选 | 皇帝主导问题识别与授权；苏威、牛弘的实际设计量待补证 |
| 刑讯规范、逐级申诉 | 杨坚批准并颁行，参与程度高 | 具体制度设计者在本篇中未充分区分 | 皇帝直接制度责任；臣子不凭修律列名自动共享 |
| 废孥戮相坐、死刑复核与三奏 | 杨坚分阶段下令，属直接决策 | 本篇未见可独立归责的臣子主导 | 暂归皇帝直接主导 |
| 殿廷法外杖杀 | 杨坚亲自命令并反复恢复，属直接实施和维持 | 高颎、柳彧、冯基等多次劝阻；劝阻不等于已经形成制度纠偏 | 负向责任直接归杨坚；臣子保留制止责任候选 |
| 告发奖励、盗一钱死 | 杨坚直接制定激励和极端刑罚 | 执行官员未形成独立设计证据 | 皇帝直接主导和运行责任 |
| 仁寿深文司法 | 杨坚不依律科断并以深文承旨者为能，属直接用人和运行责任 | 杨远、刘子通等执行深文；杨素干预案件轻重 | 皇帝承担激励结构责任，相关臣子承担执行或干预责任 |
| 依法劝阻法外杀人 | 杨坚多次拒绝或暂时接受劝阻，不能据此卸责 | 赵绰持续依法抗辩，是关键纠偏执行者候选 | 赵绰能否形成公共成果须跨个案验证 |
| 大业律从轻 | 隋炀帝杨广以禁网深刻为由下令修律并采用，直接主导 | 具体编修领衔者须另补史源 | 皇帝承担改革决策责任 |
| 炀帝弃法、盗罪皆斩及族诛 | 杨广直接改变处置规则并容许正式律典失效，参与程度最高 | 地方官和执行者承担实施责任，现有总结未逐人闭合 | 皇帝直接负向责任；臣子责任待个案和本传 |

## 八、对治理登记的验证意义

隋代样本证明：

- A1制度创设和A2制度运行可以出现相反评价；
- 同一皇帝的正向法典与后期法外严刑应拆成独立成果，再在皇帝评分中净结算；
- 全国规模、法典完成和结构性文明进步不是同义词；
- 告发奖励必须检查告发者的利益和制造案件的激励；
- 皇帝追悔、偶尔采纳劝谏不能抵消反复法外杀人的结构性结果；
- 同一人物可以同时承担修律责任和法外司法责任，不能用其中一面覆盖另一面。

北魏及梁、陈、北齐、北周的复合前制基线已经独立成篇，因此可以确认：开皇改革大量继承北齐十二篇、重罪体系和北周五刑传统，其主要结构增量在统一整合、删酷减等、规范刑讯申诉和死刑复核，而非凭空创制。以上仍是篇章内强度和责任候选；最终分数须待所有朝代同颗粒度横向校准，正式人物归责再按必要史源补强。
