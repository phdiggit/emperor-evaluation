# 《旧五代史·刑法志》通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

> 状态：篇章通读完成。原志已佚，今本为《永乐大典》等辑佚，材料不完整；结论适合作为唐末→五代→宋初基线，不宜据篇幅缺失推断某朝“无治理”。

## 一、中心论旨

五代刑法史的主线不是新法典不断进步，而是战乱中法书反复散失、重抄、恢复和重新编纂：

> 唐法仍是权威基准，但政治更替、地方军权和临时敕令使统一适用屡次中断；后周才把散乱材料整理为可直接检索的《大周刑统》，成为宋初刑统的近直接前身。

## 二、主要节点

### 1. 后梁删改与后唐复唐法

朱温命李燕等重定律令格式，形成律、式、格、目录、律疏共一百零三卷的“大梁新定格式律令”，并颁行。后唐法司则明确批评梁法“重货财、轻人命”，又称梁廷曾追缴焚毁唐朝法书；因定州尚存副本，朝廷抄回二百八十六卷唐代律令格式，随后另编《同光刑律统类》。

这些数量首先说明法源保存、散失和重编的规模，不代表条文越多越先进。梁修法已经实际颁行，属于制度重建能力；但现存辑文同时留下重财轻命和焚毁旧法的负面评价，缺少足够运行样本，不能直接判为正向主峰。后唐恢复唐法相对于梁末属于 `positive / significant` 的纠偏恢复，不是法律首创；它也没有消除五代此后反复出现的法外刑和地方任意司法。

### 2. 反复疏狱、限期和死刑复奏

后唐、后晋、后汉、后周反复下诏要求长官亲录囚、轻罪速放、死刑覆奏、病囚给医和禁止法外酷刑。其中存在几个已落地的制度增量：

- 后唐恢复京城死刑至少前一日一覆奏，并奖励雪冤活人者；
- 设置病囚院、医药和定期洗刷枷械，直接针对病死被伪报为自然死亡；
- 后晋要求各地大辟按季报刑部，疑案讞大理寺或尚书省；
- 禁止地方以长钉贯手足、短刀割肉等律外刑；
- 后周把清洁监狱、供水、患病者由家属或医工照料写入反复申令。

这些不是只有价值口号，已改变复核层级、医疗责任和刑具边界。

但史文不断重复“不得淹滞”，并明确说年月稍远后长官不再亲录、胥吏借追证勒索，甚至有案件百余日不决。这些重复诏令同时构成执行失败的证据。故该改革族可判 `positive / significant`，并保留长期 `implementation_weakness`；只有实际形成稳定复核和狱政机构后，宋代才可能升为结构性运行成果。

### 3. 后晋、后汉的重刑倒退

后晋一度规定和奸男女皆死，后周才恢复按律处断；地方又有无律文依据的籍没、钉贯手足、割肉等律外刑。后晋中央曾明令盗案不得沿地方旧例籍没家产，也说明这些做法并非合法的统一制度。

后汉藩镇“奏刑杀不究其实”，出现部曲诬告、灭族等案件。其结构问题是中央在军镇奏报后不复核事实，使私人冲突可直接转化为国家刑罚，而不只是某一藩镇残暴。

这些不是唐法普通沿用，而是临时敕和藩镇任意扩张，属于 `negative / structural` 的运行倒退。

### 4. 后周限制连坐与《大周刑统》

郭威明令除反逆外不得诛骨肉、籍家产，并撤销和奸死刑。这两项均改变了明确适用人群，是相对后晋、后汉的实际正向纠偏。

柴荣时期面对律、令、式、格、统类和历朝编敕相互重叠，命张湜等以律为正，解释难文、删除已废格敕、补充新条并归类中央禁令和州县常科，编成二十一卷《大周刑统》。随后由张昭等复核、范质和王溥评议，颁行天下；被吸收的旧统类、格和编敕停止另行作为法司依据。它真实减少的是并行检索入口和矛盾法源，而不只是把材料换一本书。

相对于五代法书散失和格敕重叠，这是 `positive / structural` 的整合成果。它的历史角色是承唐启宋的 `institutional_consolidation`，不是重新发明唐律。史源确认编成、复核、颁行和旧法源退出，生命周期已经闭合；但没有提供全国适用效果，故结构性判断主要来自法源统一，而非可证明的低冤狱率。

## 五、宋初基线

宋初承接的不是完整稳定的唐法，而是“唐律基础＋五代编敕＋后周刑统＋地方任意司法”的复合基线。宋代若建立中央复核和提刑体系，属于超越五代运行的真实进步；若只是沿用刑统条文，则只能算制度承接。

## 六、证据限度与理解闭合

今本刑法志为辑佚文本，后周《刑统》以后还明确标有原本缺佚。因此，本篇可以支持法书散失与恢复、羁押复核改革族、后晋后汉重刑运行以及后周整合四条主线，却不能据缺文推断各政权其他时期没有改革。

归责上只保留朱温、李存勖、郭威、柴荣等实际授权采纳者，以及张湜、李燕等领衔编修者和提出独立程序的臣子。多朝反复下达同类录囚诏令，不给每位沿用者重复开创贡献；是否给运行责任，取决于其朝是否有实施或纠偏结果。
