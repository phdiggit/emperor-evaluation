# 《魏书·刑罚志》通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

> 状态：篇章通读完成；以晋末法制崩解和北方战乱为起始基线，并与《隋书·刑法志》中的北齐、北周沿革连续衔接。

## 一、中心论旨

本篇把北魏刑法史写成“草创简法—战争峻法—成文制度化—孝文重构—末期失序”的循环。它最重要的学术价值，是证明北魏并非从习惯法一步直达成熟法典，而是在统一扩张、民族治理、官僚化和政治危机中反复调整。

全篇还反复展示同一种运行张力：皇帝希望用严刑肃吏或平乱，官僚便以深文、侦伺和刑讯求功，实际犯罪和贪腐未必减少；皇帝随后再删刑、限讯或恢复常律。故不能只登记一连串“颁律”“减死”，必须追踪制度为何反转、纠偏是否真正执行。

## 二、主要节点

### 1. 道武帝的简法恢复

拓跋珪定中原后命王德删除酷切、约定科令，相对于晋末和十六国战乱中的临时军令，恢复了基本规则，属于 `positive / significant` 的秩序恢复。史文把战后民众畏法求安、处罚从轻和社会接受联系起来，可作运行方向支持，但“兆庶欣戴”仍是史家概括，不是犯罪率统计。

道武帝对大臣执法仍严，晚年又因疾病和政治失序转为滥酷。因此该节点必须形成“前期简法恢复”和“晚年运行反转”两段，不以开国功绩覆盖后果。

### 2. 太武帝时期的成文法与严刑并进

太武帝命崔浩定律，区分斩、绞等死刑，规定孕妇产后百日行刑、十四岁以下减刑、八十岁及九岁者除杀人外不坐、刑讯不超过四十九，并建立地方大辟先报、皇帝亲问和登闻鼓。相对于战时裁断，这些规则把责任能力、行刑时点、刑讯和死刑复核写入成文程序，具有结构性正向增量。

与此同时，新律保留腰斩、族诛、宫刑、巫蛊极刑和以官当刑；贫者不能赎刑还要加鞭，身份与财富直接改变实际刑罚。盗罪一度由四十匹降到三匹即死，结果不是盗罪收敛，而是史书明言“刑网大密，犯者更众”，后来才恢复旧阈值。告举牧守制度又使凶悖者专找长官过失、胁迫在位并在乡里取利；长吏只求自免，贪暴依旧。这是“监督激励反转”的完整运行链。

- 程序与成文法建立：`positive / structural`；
- 过密死刑、门诛及失控告讦：`negative / structural`。

这两者不是不可拆的 mixed，因为措施、运行链和结果可以分别定位。

### 3. 献文帝的连坐与刑具纠偏

献文帝罢除大逆以外的门房之诛，要求案件据律定名，减少口传诏敕造成的矫擅；又规范荆杖尺寸和刑讯方法，明确针对法官用大杖陷人、造成诬服和杖下死亡。它相对于太武以来严制是 `positive / significant` 的组合纠偏。

但献文帝为防仓促滥判，案件反复覆鞫，囚犯可能积年不决。史文认为最终刑罚“多得其所”，仍不能把长期羁押本身算成正面。这里应同时保留裁判审慎的收益和审前拘禁过长的成本。

### 4. 孝文帝改革

孝文帝推动的组合包括：

- 禁止裸体处决，区分斩、绞；
- 撤销大批侦伺官，减少以细过罗织；
- 命高闾等重修律令；
- 限制重枷和悬石逼供；
- 再议删除门房族刑；
- 班禄后严惩贪污，并大量减死徙边。

撤销千余侦伺者后改留数百人维持街道秩序，史书明确说吏民安业；限制重枷则直接针对伤骨、轮番殴打和诬服。班禄以后，孝文帝把受贿门槛改为义赃一匹、枉法无论多少皆死，巡察中四十余名守宰因赃处死。史称受禄者恐惧、请托路径一度几乎断绝；与此同时，皇帝对一般死案多降死徙边，每年保全生命以千计，京师年终处决通常不超过五六人。

这些数字来自志书的时期总述，可以证明“严惩贪腐＋一般死刑多减”的双轨运行，却不能作为现代精确年度统计。它仍揭示了孝文改革并非笼统宽刑：一般刑罚趋于审慎，官员枉法则采取极低阈值死刑。后者在短期反腐上有可观察效果，但生命代价和比例失衡明显，应单列负向限制，不能被正向主峰吞并。

总体而言，孝文改革形成实体刑、程序、侦察组织、官僚激励和法律文本的组合变化，是本篇正向主峰，宜判 `positive / structural`。

### 5. 宣武、孝明时期的法官抗辩与特旨司法

张回转卖良女案显示，法官围绕父卖女、买者转卖和掠卖良人的差异展开细致论证，最终孝明帝没有机械适用死刑，而判转卖者五年刑并特免因贫卖女葬母者。它证明律文争议能进入公开议论并改变结果，但皇帝“特原”的道德判断也显示常法并非唯一依据。

刘辉案更清楚地暴露边界。崔纂、游肇等依据律文反对把通奸者处死、把已出嫁女子之罪连坐兄弟，并反对用追捕反逆者的高额赏格追捕普通逃犯。皇帝承认已出嫁女子原则上不应牵连兄弟，却仍以“特敕诏狱、不拘恒司”维持加重处理，并处罚坚持常法的官员。这里应登记 `negative / significant` 的特旨侵蚀；法官的抗辩是重要纠偏行为，却没有形成稳定制度胜利。

### 6. 末期失序

孝昌以后法令不恒、尔朱氏擅权、官员以深酷为能。盗法一度在正式律令之外增设重刑、悬赏和家属配役，孙腾指出新条越繁、盗贼反越多，建议恢复常律，朝廷实际采纳。这是末期少数完成闭环的纠偏。

东魏迁邺初年百司不奉法、贿赂公行；高澄辅政后以公平整肃，至武定年间史称法令严明。它说明末期并非全程直线崩坏，但局部恢复没有改变北魏后段长期由权臣、战争和临时严制支配的结构。总结应记录这次恢复，不把它夸成稳定跨期成果。

## 五、隋代基线意义

《魏书》与《隋书》合读后，隋开皇律不能再描述为从无到有：北魏已具法典、死刑奏报、申诉、刑讯限制和老幼减免；北齐、北周又继续改造。开皇的真实贡献，是在分裂法制基础上完成全国统一、进一步删酷、稳定复核并压缩前代繁重结构。

## 六、证据限度与理解闭合

《魏书》常以“百姓晏然”“吏民安业”“四海知治”概括运行，应结合前后具体制度使用，不单独证明全国犯罪率或普遍满意。反之，“岁以千计”“死者四十余人”等数字有明确事项和时期，可支持方向与规模感，但不承担现代统计精度。

本篇已经足以区分道武恢复、太武制度化与严刑、献文纠偏、孝文主峰、特敕侵法和末期反复。后续只有当某一人物是否属于核心编律者、或某项特旨是否改变正式归责时，才需要定向补本纪、本传；不再逐案扩写。
