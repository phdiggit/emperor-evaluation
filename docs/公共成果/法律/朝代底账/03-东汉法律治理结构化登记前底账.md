# 东汉法律治理结构化登记前底账

用途：本文件保存东汉法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

《后汉书》没有独立《刑法志》。本稿以《晋书·刑法志》汉段为连续主篇，以《后汉书·郭陈列传》《应奉列传》《党锢列传》和《通典》保存的案件、制度沿革互证。材料足以确定主要变革、运行结果和核心人物，但不能复原一部完整东汉律典。

## 一、东汉法律治理总判断

东汉法律治理主线是：

> 从王莽末年旧章散失、法网弛纵中恢复中央审判 → 明帝亲自监督司法而裁断趋于苛碎 → 章帝、和帝时期由寒朗、郭躬、陈宠等推动宽平复核、删酷法和案件分类，形成全朝正向高峰 → 陈忠继续缩小宫刑、代际禁锢和若干重刑适用，但总删律仍未完成 → 献帝时应劭在战乱中保存旧章 → 桓、灵两次党锢把告发、政治身份、终身禁锢、狱死和亲属牵连连成持续二十余年的政治司法系统。

其最大正向成果不是法典首创，而是中期职业法官把从轻解释、案件分类、赦令一致适用和疑狱复核落实到实际生全。最大倒退也不是一般司法腐败，而是党锢把没有稳定犯罪事实的政治身份转化为全国追捕和跨代禁锢。

- 西汉末已经存在律令、死罪条款和决事比繁密问题，元、成删律未成；新莽末又造成正式文本和统一运行受损。东汉初恢复听讼首先属于战乱后恢复，不是法律制度从无到有。
- 《晋书》提供东汉连续法制骨架；《后汉书》列传提供郭躬四十一事、陈宠《辞讼比》、陈忠实体减刑及党锢人数、范围和持续时间。
- 《通典》补入楚狱释放千余人、阻止增科、废轻侮复仇比等材料。杜佑的议论用于理解，不能代替本朝行为和运行事实。
- “人俗和平”“狱法和平”只能与具体删法、复核和生全记录合用；其中祥瑞、旱灾等灾异解释一律不作为运行效果。
- 《后汉书》记陈忠《决事比》二十三条，《晋书》《通典》记三十三条。数字异文不影响“多项改革已经施行”，不得据此复制成两项成果。
- 党锢的“二十余年”是运行持续证据；不能进一步把黄巾起义或东汉灭亡单因归结于党锢。

## 三、法律运行档位在东汉的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 文献、法令或制度已经交付，未见实际适用结果 |
| L1 | 至少一次明确裁断、执行、释放或免除 |
| L2 | 常规程序、跨机关反复运行或成批规则适用 |
| L3 | 群体、区域或系统层面出现明确方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有灾异附会、祥瑞、抽象称颂或无法核定的推断 |

陈宠改革链达到L4，不是因为《辞讼比》或法令存在时间长，而是同方向运行横跨三个阶段：公府按类处理积案、章帝朝删酷法后“狱法和平”、和帝朝亲审疑狱“济活甚众”且深文之弊减退。党锢达到L4，则有两次全国追捕、跨二十余年持续、刑罚扩大至门生故吏和五属等直接证据。

## 四、方向、归责与去重原则

- 光武、明帝亲自听讼只计算实际恢复或运行风格，不虚构法典创制。
- 梁统恢复重法、陈宠总删一千九百八十九事等未获实施方案不登记成果；成功阻止增科只作朝廷没有倒退的证据，不重复制造一个法典改革。
- 章帝楚狱必须保留完整上下文：皇帝震怒造成官吏竞相牵连，后因寒朗揭发而释放千余人；不能只把释放登记成皇帝纯正面成果。
- 陈宠的《辞讼比》、章帝朝删酷法和和帝朝宽平复核合成一个改革生命周期；不按七卷、五十余事或获救个案拆碎计分。
- 章帝一度把杀人复仇减死，后来扩成四五百条轻侮比。和帝采纳张敏意见废止，正向价值在于关闭可被任意扩张的杀人豁免和统一罪名边界，不是因为死刑本身更文明。
- 桓、灵两次党锢分开结算，因为皇帝、发动者、规模和运行阶段不同；各次有限释放和最终解除另以低强度纠偏合并登记，不能冲淡原有结构性责任。

## 六、未纳入联合底账的材料

- 梁统恢复更重刑制：反复倡议而未获采纳，只保留为决策背景。
- 杜林阻止增加禁科：确有采纳，但没有产生独立新制度或可观察运行结果，作为章帝朝未进一步扩张法网的审计证据。
- 陈宠拟删一千九百八十九事：总删律未及施行即中止，不登记正向成果；已落地改革不受影响。
- 郭、陈家族的法律传承和门徒规模：证明职业法学形成，不按家族声望或学生人数计分。
- “人俗和平”后的祥瑞与旱灾等：全部排除，只有具体法令、案件和生全结果进入运行档。
- 黄巾起义和东汉灭亡：党锢确实损伤官僚人才、政治信任和纠错环境，但不能承担全部因果责任。
