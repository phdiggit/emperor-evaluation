# 明代法律治理结构化登记前底账

用途：本文件保存明代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

当前范围覆盖法源结构、刑罚、司法组织、复核审录、狱政及法外政治司法。户婚、田土、财政、军政等《大明律》分领域规范仍应在相应治理领域吸收，不能把本文件误作明代全部法律生活的完备总结。

## 一、明代法律治理总判断

明代法律治理的主线是：

> 元末法源和司法失序 → 洪武长期修律、统一裁判规范 → 同期以《大诰》、大狱和株连建立重典政治 → 三法司、驳正、会审和死刑覆奏逐步常规化 → 永乐一面加强普通案件复核，一面恢复诏狱并设东厂 → 仁宣形成正式司法运行高峰 → 廷杖、厂卫和特旨司法反复扩张 → 万历后期停审淹狱、天启厂卫达到负向高峰。

明代不能压成一个 `mixed` 节点。其两条主线都达到结构性规模：

1. 《大明律》和全国复核体系结束了元末规则失序，建立长期可用的正式司法秩序；
2. 皇帝又通过《大诰》、大狱、廷杖、厂卫和诏狱建立绕开正式法司的第二司法系统。

评分时必须逐节点分账，再按同一人物的主动创设、扩张、运行、纠偏和消极维持净结算；不得用有限纠偏冲淡其已经造成的大规模伤害。

## 二、材料分工与直接基线

- [《明史·刑法志》通读总结](../回源资料/历代刑法志通读/03-明史刑法志通读总结.md)是三卷连续通读后的上下文主干；固定正文为《明史》卷九十三至九十五。
- 本目录固定的《明会典（四库全书本）·全览6》补强司法机构运行：大理寺对刑部、都察院等拟罪进行准拟、照驳、再问和圆审；重囚有霜降审录、五年审录、外地审录及临刑诉冤停决；锦衣卫、东厂又实际接入侦缉、会问、监决和诏狱链。
- 《大明律》尚无中央史源缓存可安全使用的精确页名。本版不据二手印象补造条文，只登记《明史》已能证明的法典形成、统一施用和制度后果；将来补入固定法典正文时，主要用于完善规范领域地图，不自动增加成果数量或人物责任。
- 元代直接基线由《元史》《新元史》刑法材料互证：已有覆奏、刑讯限制和条格整理，但法源长期多头并行，后期还有肉刑恢复和运行崩坏。明代法典结构承接唐宋技术，其新增贡献在统一、稳定和实际施用，不占“发明法典”全量。

同一事实被《明史》《明会典》共同记载时只结算一次；政书补充的是程序细节和运行可信度，不生成重复成果。

## 三、法律运行档位的审计解释

| 档位 | 审计含义 | 明代典型证据 |
|---|---|---|
| L0 | 已提出、制定、颁行或撤销，尚无实际适用结果 | 宽法诏议、条例编定 |
| L1 | 至少有一次明确适用、改判、释放、处分或执行 | 个案驳正、临刑停决 |
| L2 | 多案援例、常规程序化、跨机关反复执行或形成稳定先例 | 大理寺常规驳正、三覆奏、军徒编发 |
| L3 | 出现全国、区域或系统层面的汇总结果和方向性后果 | 大规模释放、株连、廷杖死亡、厂卫广泛罗织 |
| L4 | 系统结果跨多年、跨区域或跨阶段持续 | 长期会审体系、世袭勾军、厂卫诏狱、停审淹狱 |
| LX | 不能证明法律运行 | 灾异附会、祥瑞或无法核定的颂扬 |

制度交付与运行结果分开。L0可以进入制度创设评价，但不能冒充实际成效；**制度长期存在或法典长期沿用本身不构成L4，必须有正负方向一致的运行结果跨多年、跨区域或跨阶段持续。**刑罚数量减少若源于停审，也不得登记为宽政。

## 四、归责、净变化与拆分边界

- R档只表示人物对该节点的责任强度：主动发起、最终决定、核心设计或长期维持通常为R4；不可替代的领衔设计和关键纠偏为R3；重要支持为R2；普通参修、署名和例行执行为R1；普通沿用为R0。
- 《大明律》创制、三法司建立、仁宣时期实际运行分别结算；制度创设者不自动占有后世运行成果，后世普通沿用者也不登记。
- 同一罪责、同一人群由死刑改为赎、徒、流、充军或工役，剩余刑罚只限制正向幅度，不另生负向。
- 只有新增受罚场景、扩大受罚人群、加重同一罪责，或产生新的实际净伤害，才登记负向部分。充军由本人减死扩展为子孙世袭、勾补亲邻，即属于新的负向节点。
- 法典稳定收益在《大明律》统一施用中结算一次；“祖制不可改”只计算它后来造成的适应障碍、条例膨胀和裁量扩张，不重复领取稳定收益。
- 建文宽法、条例清理及厂卫内部纠偏如只有主张或有限个案，不纳入联合底账；不得为了凑齐正负面而抬高。

## 五、明代法律治理结构化底账

### 节点原档字段合同

- 综合档位固定写为 `方向强度·运行档·状态`。
- 方向强度：`P3/P2/P1`＝结构性/显著/有限正向；`N3/N2/N1`＝结构性/显著/有限负向；`M3/M2/M1`＝正负并存且规模相应；`U`＝方向未定。
- 运行档：`L0—L4` 沿用法律领域运行档位；档位后的括号只作审计解释，不参与机器读取。
- 状态：`READY`＝该节点可进入计分校准；`HOLD`＝节点成立，但人物归责、因果或相对基线尚不足，暂不进入个人计分。
- 人物归责固定写为 `姓名:+R档`、`姓名:-R档` 或 `姓名:±R档`；`R?` 表示尚不能定档。
- `READY` 行只把已有明确R1—R4的人物送入个人计分；同一行的R?只保留待补，不因次要参与者未闭合而阻断已闭合的开创者或重大变革者。

## 六、暂未纳入联合底账的补强事项

- 《大明律》固定正文：用于确认法典内部规范地图和相对元代的具体增删；若只重复《明史》已证明的统一施用，不新增成果。
- 赎刑财政化和无力者拘系：须补原刑与新增负担，才能判断九十六人死亡等结果应记负向还是仅记改革覆盖失败。
- 永远充军与嘉靖扩张：须补创设永远制、二百十三条条例的领衔设计者和皇帝主动采用程度，不能把整个生命周期平均归责。
- 弘治、嘉靖、万历问刑条例整理：先判断是有效清理、仅纸面编定，还是继续放大例破律，再决定是否形成独立正向节点。
- 何乔新、彭韶、白昂、闵珪等持法行为及朱希孝、朱骥、王佐、骆养性等厂卫内部纠偏：只有形成跨个案结果才登记公共成果；仅有忠直评价或单次建议不计。
