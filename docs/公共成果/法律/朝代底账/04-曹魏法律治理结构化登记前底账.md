# 曹魏法律治理结构化登记前底账

用途：本文件保存曹魏法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以220年曹丕受禅至266年魏亡为朝代边界。曹操建安时期的甲子科、复肉刑争论和半减措施只作为起点基线，不转记为曹魏皇帝成果；司马师辅政时期仍属曹魏国家制度，按实际掌权者、名义皇帝和方案提出者分别归责。

## 一、曹魏法律治理总判断

曹魏法律治理主线是：

> 承接东汉末法源散乱和曹操时期临时科令 → 文帝作有限减死调整但复肉刑争论未成 → 明帝先统一解释、设置律博士，再以十八篇新律重排刑名和事类，形成主要结构成果 → 法典技术进步仍未消除附轻附重、司法寻租及宫室工期案件中的仓促处死 → 高柔以证据重查冤案并把身份恢复规则颁为全国范例 → 司马师辅政时缩小已婚妇女因父族谋反受死刑连坐的范围。

曹魏最大的历史增量是把秦汉以来交错的律、令、科和多家章句重新组织成更可识别的法典结构，并建立官方解释和职业教学。它仍没有完成法源总清理，也没有因拥有新律而自动形成稳定、宽平的司法运行。

- 东汉已经形成宽平解释、案件分类和职业司法，但没有完成总删律；曹操时期又以科补律并多次讨论复肉刑。这是曹魏直接基线。
- 《晋书》所列二万六千余条、七百七十三万余言用于证明材料繁复和实际难以阅览，不按现代规范数量直接计分。
- 新律篇数增加本身不是进步；正向价值来自刑名总则前置、按事类分篇、清除虚设旧文、统一解释和培养法官。
- 高柔案以债务线索、口供和尸体验证查明真凶；观察神色只是一段侦查过程，不能被包装为“神断”方法。

## 三、法律运行档位在曹魏的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法令、法典或机构已经交付，未见实际适用 |
| L1 | 至少一次明确适用、改判、释放或身份恢复 |
| L2 | 全国法源、职业教学、常规程序或范例反复适用 |
| L3 | 群体、区域或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有抽象称颂、理论争议或无法核定的推断 |

魏律十八篇达到L2，是因为新律、官方章句和律博士实际进入国家法源与教学体系；没有明确的全国司法结果汇总，不能抬到L3。窦礼案达到L2，是因为除恢复妻儿身份外，又“班下天下，以为体式”，已从单案转成全国裁判范例。

## 四、方向、归责与去重原则

- 曹操时期措施只作为直接基线；曹丕、曹叡继承的部分不重复登记开创责任。
- 文帝“怨毒杀人减死”按同一罪责由死刑降为输作判断为有限正向；剩余劳役不另判负面。没有新增受罚场景或新的实际伤害证据时，不因犯罪严重就反向扣分。
- 郑氏章句、律博士和十八篇新律共同解决“多家解释、人员不学法、事类交错”问题，合并成一个法源改革生命周期。
- 明帝宫室工期案件已有实际仓促处死，独立登记负向；王肃的反对未见完成纠偏，不生成正分。
- 高柔案只归实际重查、身份恢复和全国示范；前级机关长期不理申诉保留为制度背景，未具名者不分配个人责任。
- 司马师辅政时期改律仍属曹魏节点；曹髦是否主动参与缺证，不因名义诏令自动获得R4。

## 六、未纳入联合底账的材料

- 曹操两次复肉刑争论、甲子科和依律科半：发生在220年前，只作曹魏起点基线。
- 曹丕、曹芳时期多次复肉刑讨论：均未实施，不能累计成治理成果；论证只供刑罚结构审计。
- 曹叡改士庶罚金及男女处分：文本解释、原刑基线和实际适用结果不足，暂不生成方向不清的补丁条目。
- 范洪、刘象附轻附重及“轻枉相继”：证明新律前后司法寻租仍在，但不能在缺少新增机制和皇帝主动责任时另造一项帝王负分。
- 魏律中其余单条增删：已并入十八篇新律的结构改革，不按篇名和罪名逐条拆分。
