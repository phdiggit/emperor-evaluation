# 西汉法律治理结构化登记前底账

用途：本文件保存西汉法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以《汉书·刑法志》为连续主篇，以《通典》卷一百六十三、一百六十六保存的法典沿革和案件补充互证。它覆盖刑罚、法源、司法复核和连坐边界，仍不是西汉全部民事、行政和经济法律的完备地图。

## 一、西汉法律治理总判断

西汉法律治理主线是：

> 从秦末高压刑政和法制失序中删苛、恢复全国规范 → 惠帝、吕后和文帝逐步缩小言论罪、族诛与亲属收孥 → 文帝废肉刑因替代刑设计失当造成实际死亡 → 景帝以减笞和规范刑具完成纠偏 → 武帝在财政军事压力下扩张律令、决事比和深文督责，造成法源失控与同罪异判 → 宣帝以廷平和宽平法吏改善运行，但未解决律令繁密根源 → 元、成虽认识到问题而删律未成，哀、平再作有限的罪名和连坐边界纠正。

因此，西汉不能被压成“由秦酷法走向儒家宽刑”的单线叙事。其文明进步主要体现在缩小无罪者牵连、减少政治表达入罪和纠正致死笞刑；主要倒退则是武帝以后把复杂法源、官吏问责和重判激励结合成系统性司法风险。

- 高祖不是从无到有发明成文法，而是删取秦法、恢复帝国法律秩序。秦已有全国法权统一的结构收益不得再算作汉初原创。
- “约法三章”不能遮蔽高祖时期仍有夷三族和具五刑；汉初恢复秩序的正分不抵消这些遗留，但普通沿用者也不另登记开创责任。
- “断狱四百”“刑狱平”等可作为有界运行证据；不得把前者外推为全国犯罪率，也不得用后者证明律令繁密已经解决。
- 昭、宣以后死刑和耐罪人口比例是强运行指标，但原文同时明确郡国仍有冤死，故只能描述阶段司法负担，不能自动归为某位皇帝的正向成果。
- 个案只有在实际裁断并明确改变死刑、政治罪名或连坐边界时才进入一个合并节点；纯粹法律意见和未被采用的主张不单独计分。

## 三、法律运行档位在西汉的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法令、法典或制度已经交付，未见具体适用结果 |
| L1 | 至少一次明确裁断、执行、释放或免除 |
| L2 | 全国法源、常规程序或跨机关反复运行 |
| L3 | 群体、区域或系统层面出现明确方向性结果 |
| L4 | 同方向运行结果跨多年、跨区域或跨阶段持续 |
| LX | 只有政治颂辞、史家抽象归因或无法核定的推断 |

法典存在时间长不等于L4。武帝节点达到L4，是因为律令与决事比膨胀、郡国同罪异判、主管者不能遍读和重判激励在后续阶段仍持续存在；宣帝节点只到L3，是因为“刑狱平”能证明一阶段系统改善，却没有证明跨阶段稳定延续。

## 四、方向、归责与去重原则

- 同一罪责、同一人群由死刑改为徙边、城旦或其他生刑，属于减刑；剩余刑罚只限制正向幅度，不另造负向责任。
- 文帝废肉刑判为 `mixed`，不是因为替代刑仍然是刑罚，而是同一适用场景中确有一部分人免于残肢并存活，另一部分人却因笞三百、五百而死亡，出现相对原基线更重的实际后果。
- 景帝减笞与定箠令是对文帝改革运行失败的独立纠偏，不与文帝平均分账。
- 皇帝直接下令、最终采用或持续推动为R4；领衔编法、设计替代刑或作出决定性法律解释可为R3—R4；触发改革但不掌握方案和采用权者不自动分享主导责任。
- 元帝、成帝删律意图未形成一代明制，不进入正向评分。普通沿用九章律或既有连坐规则者不登记。
- 哀帝时期两个个案只作为“限制政治罪名升格和已绝婚姻连坐”的运行证据合并结算，不把每名罪犯、每种剩余刑罚拆成独立治理条目。

## 六、未纳入联合底账的材料

- 高祖时期仍存的具五刑和三族诛：它们是秦制遗留及本朝局限，不另虚构为高祖开创；若有本朝主动扩张证据再登记。
- 惠帝对爵位、宗室和老幼的合并减刑：老幼保护与身份特权并存，当前材料不足以形成干净的同一方向节点。
- 景帝时期刘彻参与继母杀父案：已发生个案纠偏，但未见形成稳定法条，且刘彻当时不是最终决策者，不单独生成皇帝治理成果。
- 元帝、成帝删律诏令：问题识别明确而改革没有完成，不登记正向结果；也不因普通未能纠偏而追加开创性负责。
- 班固关于礼教、贫困、豪强和官吏激励的篇末分析：用于解释刑狱繁多，不把跨领域原因全部归入法律计分。
- 班固恢复部分肉刑的主张：属于作者方案，不是西汉已经实施的治理成果。
