# 清代法律治理结构化登记前底账

用途：本文件保存清代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、清代法律治理总判断

清代法律治理的主线是：

> 顺治沿用明律并编成本朝律例，康熙、雍正完成满汉规则和多管辖整合 → 秋审、朝审、分类勾决和死刑复核在明制基础上高度细化并真实改变处决结果 → 旗人、宗室、蒙古等多元管辖同时造成同罪异罚和救济差等 → 乾隆以后因案立例、例压律和多套则例冲突削弱法源可知性 → 刑讯、检验和审限被规范但逼供制度仍存 → 咸丰以后就地正法由战争例外变为战后常态 → 光绪末至宣统实际废除多种酷刑、缩减缘坐刺字并建立法部、大理院和新式法院，但实施期很短。

清代的正向主峰不是“另有一部律”，而是死刑复核的制度深化和晚清已经生效的酷刑废除、司法行政分离；负向主峰是成例压过律文以及就地正法绕开清代最重要的中央死刑复核。

## 三、法律运行档位在清代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典、条例或草案已经形成，未见施行 |
| L1 | 至少一次明确改判、减免、处分或执行 |
| L2 | 全国法源、常规会审或新机构进入运行 |
| L3 | 群体、区域、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

秋审朝审跨多朝、层级和案件长期改变死刑结果，且乾隆朝已有数千人批次减等的强运行指标，定L4；例压律和就地正法均跨多年、地区及阶段持续，定L4；晚清改革虽已生效但仅运行约一年、地方覆盖不足，定L2而不冒充全国转型完成。

## 四、方向、归责与去重原则

- 清初律例整合与秋审复核分别结算；前者是法源，后者是实际生命复核程序。
- 多元管辖的治理能力与同罪异罚、救济差等分别登记，不把文化多元本身判负。
- 乾隆完善个案分类与其推动成例膨胀、缩减覆奏分账，正向程序不能冲销法源倒退。
- 就地正法区分最初战争授权、后续扩张和战后维持；普通依既定规则办案者不登记开创责任。
- 晚清废酷刑和司法行政分离机制不同，分别登记；共享改革者不等于重复计算同一公共收益。

## 六、未纳入联合底账的材料

- 每次秋审勾决和皇帝个案宽免：只作为程序真实改变结果的证据，不按人数或次数累计。
- 八旗、宗室、蒙古等多元管辖具有治理能力，也长期伴随同罪异罚和救济差等；尚未切出具名重大创设或扩大者前，不进入人物评分，更不把普通沿用者登记为开创者。
- 笞杖折减、留养承祀、尸图覆检和分级审限保留作制度背景；其中部分真实减害已被死刑复核或清初废残酷刑节点吸收，其他部分运行不足，不再以宽泛 `HOLD` 行占据联合底账。
- 例文从三百余至一千八百余条：数字本身不判负，只有冲突、律外加重、择例出入和法律不可知进入负向。
- 许可夹棍、拶指和仍有刺配：只限制既有规范化改革的幅度；若未新增场景，不机械生成一条“采用残余刑罚”责任。
- 新刑律分则、刑事民事诉讼律等多数未核准草案：只证明设计方向，不登记已实现公共结果。
- 清末改革持续时间短、地方新式审判和监狱覆盖不全：作为L2限制，不据中央颁布推断全国完成。
