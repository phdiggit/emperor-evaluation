# 元代法律治理结构化登记前底账

用途：本文件保存元代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、元代法律治理总判断

元代法律治理的主线是：

> 太祖、窝阔台把征服期军政长官的专杀和占有家属财产权逐步收归中央 → 忽必烈建立重囚待报、怒时缓奏、刑讯限制和《至元新格》，同时又以特旨、阿合马和桑哥重刑突破稳定规则 → 仁宗、英宗以《大元通制》整理诏制、条格和断例并依法拒绝私恩，但未消除多头法源 → 族群、军事和宗教复合管辖兼有治理能力与权利差等 → 中后期宗教赦免反复干预刑罚 → 文宗缩小籍没妻女，顺帝后期又恢复盗窃劓、黥等肉刑链。

元代的正向核心是把征服秩序纳入中央复核、条格和狱政约束；负向核心是特旨与多头法源长期压过稳定规则，身份法造成同案异程序异罚，以及后期把肉刑新增到此前不受肉刑的盗窃场景。

## 三、法律运行档位在元代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法令、条格或汇编已经形成，未见适用 |
| L1 | 至少一次明确改判、禁断、释放或处分 |
| L2 | 全国法源、中央复核或跨机关程序进入运行 |
| L3 | 群体、区域、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

阿合马、桑哥重刑与特旨任意用法跨世祖中后期、多机构和多类案件持续，定L4；身份差等和多头法源贯穿多个时期，事实运行定L4。默认只结算忽必烈可确认的开创责任，后世普通沿用者不平均归责。

## 四、方向、归责与去重原则

- 太祖、窝阔台、世祖限制专杀按各自重大增量归责；普通延续重囚待报者不重复登记。
- 忽必烈的程序建设和特旨酷刑分账，不能合成正负各半。
- 《至元新格》《大元通制》分别是两轮法源整理；只计整理与采用，不把所收旧条文重新算作原创。
- 后期劓黥不是“以肉刑代死”：它对未证明原应处死的盗窃场景新增割鼻、黥刺和身体标记，构成独立负向。
- 天历缩小籍没妻女与后至元再次申明属于同一改革生命周期，首创者计分，普通重申者只作运行支持。

## 六、未纳入联合底账的材料

- 世祖每一次怒时缓奏、单案减刑和酷刑禁断：由程序建设或法外重刑主节点吸收。
- 《大元通制》的条数：只说明法源类型和整理规模，不以数量判断文明进步。
- 英宗依法拒绝近侍、太后私恩的每个个案：作为汇编和反私恩已经运行的证据，不逐案计分。
- 后至元六年再次禁止没妻女：作为天历改革的运行和反复证据，普通重申不另立成果。
- “百年乂宁”“仁厚”等史家总评：不能替代重囚待报、同案异断、家属籍没和肉刑场景等运行证据。
