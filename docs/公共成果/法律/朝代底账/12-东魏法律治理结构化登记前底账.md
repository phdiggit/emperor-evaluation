# 东魏法律治理结构化登记前底账

用途：本文件保存东魏法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以534年元善见即位、迁都邺城至550年高洋代魏为朝代边界。东魏没有另立完整新律的明确材料，现有主线是迁邺初法令失效、恢复常律的一次纠偏，以及高澄辅政后的整肃。

## 一、东魏法律治理总判断

> 迁邺草创时百司多不奉法、贿赂公开流行 → 临时盗法在常律外增设重刑和家属配役，孙腾推动恢复常律并获采纳 → 高澄辅政后以公平整肃，到武定年间形成法令严明的阶段结果。

东魏的增量不是创制新法典，而是从迁都失序和临时严制回到相对统一的常律运行；其成果持续时间有限，不能抬成跨阶段L4。

## 三、法律运行档位在东魏的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 制度已经形成，未见适用 |
| L1 | 至少一次明确采纳、撤销或改判 |
| L2 | 常规规则进入重复适用 |
| L3 | 阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张或无法核定的推断 |

孙腾恢复常律有明确“诏从之”，定L1；迁邺失序和武定整肃均有阶段性系统结论，定L3。

## 四、方向、归责与去重原则

- 名义皇帝元善见未见主动设计，不因诏令形式自动获得R4；实际辅政者按可见主导行为归责。
- 孙腾恢复常律是对律外重刑的完成纠偏，不把其奏议拆成多个减刑节点。
- 高澄整肃只计算实际改变运行风气，不把随后建立北齐的成果提前归入东魏。

## 五、东魏法律治理结构化底账

### 节点原档字段合同

- 综合档位固定写为 `方向强度·运行档·状态`。
- `P/N/M1—3`、`U`、`L0—L4/LX`、`READY/HOLD` 和R档沿用法律领域共同合同。
- `READY` 行只把已有明确R1—R4的人物送入个人计分；R?人物只保留待补。

| 综合档位 | 治理节点 | 皇帝归责档 | 臣子归责档 | 审计说明 |
|---|---|---|---|---|
| `N3·L3·READY` | 迁邺初百司不奉法与贿赂公行 | 元善见:-R? | 高欢:-R3；失职及受贿百司:-R? | （天平以后迁都草创，中央机关多不遵法、货贿公行，形成阶段性系统失序；皇帝主动参与不足） |
| `P2·L1·READY` | 孙腾废律外盗法并恢复常律 | 元善见:+R? | 孙腾:+R4；实际采纳者:+R? | （律外严制扩大死刑和家属配役却使盗贼更多，孙腾要求所有盗案回归律令并获诏从） |
| `P2·L3·READY` | 高澄辅政后以公平整肃法令运行 | 元善见:+R? | 高澄:+R4 | （兴和初高澄入辅后改变迁邺初风气，至武定年间形成法令严明的阶段结果；持续不足以升L4） |

## 六、未纳入联合底账的材料

- 沿用北魏旧律：只作直接法源，不登记为东魏创新。
- 北齐建立后的变法从事、设棒和齐律编纂：均归北齐底账。
- “四海知治”：不单独生成治理节点，也不承担精确犯罪率含义。
