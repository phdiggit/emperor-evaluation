# 宋代法律治理结构化登记前底账

用途：本文件保存宋代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、宋代法律治理总判断

宋代法律治理的主线是：

> 宋初承接《显德刑统》，恢复全国统一法源并以折杖、多层死刑复核超越五代运行崩解 → 真宗、仁宗把提刑、病囚、疑狱上请、误判问责和生存性盗粮减死接入实际运行 → 神宗以后以盗贼重法、重法地、刺配扩张和临时诏狱侵蚀一般法 → 徽宗、蔡京使御笔和特旨制度化凌驾常法并封闭申诉 → 高宗、孝宗恢复特旨复核、狱政指标和检验程序，但政治案件另成负向链 → 理宗以后地方酷讯、久系、索贿和狱死造假形成长期执行崩坏。

宋代的正向主峰不是原创一部法典，而是把五代后的法源恢复推进成全国多层复核、狱政监督和可观察纠错；负向主峰是特别重法、御笔司法及南宋后期监督失灵把成文法和救济程序架空。

- 单年死案、病死比例和“全活甚众”是强运行证据，但不推导全国犯罪率或全朝常态。

## 三、法律运行档位在宋代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典、编敕或命令已经形成，未见适用 |
| L1 | 至少一次明确改判、释放、处分或执行 |
| L2 | 全国法源、跨机关复核或常规程序进入运行 |
| L3 | 群体、区域、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

真宗、仁宗程序改革有跨两朝、多机构和多类实际纠错，定L4；盗贼重法扩展到多路并持续改变家属、包庇者和赦后处置，定L4；南宋末执行失灵跨理宗至度宗、跨地区和机制持续，定L4。

## 四、方向、归责与去重原则

- 宋初法源、折杖和中央复核是不同机制，分别登记；各机制内部不按每道诏令和个案碎分。
- 饥民盗粮减死只覆盖生存性、未严重伤人的场景，不扩展为所有强盗宽免。
- 死刑改刺配可救生，但刺配后来扩至原本不适用的数百条，是新增场景和人群，另记负向。
- 高宗一般狱政恢复与秦桧政治案件分账；一般宽刑不能抵销特定政治司法责任。
- 后期执行崩坏的事实方向已经闭合；默认只给理宗、度宗有限系统监督责任，不把匿名提刑、地方官和狱吏列入个人计分。

## 六、未纳入联合底账的材料

- 每次疏决、单案平反和个别近臣请托：只作为相应程序是否运行的验证，不按次数累计。
- 宁宗朝一千八百一十一名死案中处死一百八十一人：是单年中央减死强指标，未证明宁宗另创重大机制，不给普通沿用重复开项。
- 司马光、范纯仁等未被采纳的反滥刑意见：可用于判断决策能力，不登记公共运行成果。
- 高宗、孝宗的每项狱具、供饭、月报和尸检细则：由程序恢复主节点吸收。
- 南宋灭亡：不是法律治理的单因结果；只登记基层司法可信度和中央纠偏能力已经持续受损。
