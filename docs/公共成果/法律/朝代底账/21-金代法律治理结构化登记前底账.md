# 金代法律治理结构化登记前底账

用途：本文件保存金代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、金代法律治理总判断

金代法律治理的主线是：

> 女真旧制简约却保留重刑、赎命、奴属化和地牢 → 熙宗以《皇统制》整合女真、隋唐、辽宋多源规则并颁行中外，同时本人仍有法外杀戮 → 海陵《续降制书》与旧制并行，轻重冲突扩大奸吏裁量 → 世宗以刑讯冤案纠错、减死、反特权和《大定重修制条》形成正向主峰 → 章宗完成《明昌律义》《泰和律义》等法典成熟化，却维持关键法令不公开，译审失真与贿赂长期存在 → 贞祐以后官僚杖责和考绩结合，形成制度性身体羞辱。

金代真正的进步是把本部族制、被征服地区旧法和战时权宜规则整合成相对统一的跨地域秩序，并在世宗时期形成可观察纠错；主要倒退是并行法源、法律不可及、跨语言司法失真和后期以杖责驱动行政。

## 三、法律运行档位在金代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法令或法典已经形成，未见适用 |
| L1 | 至少一次明确适用、纠错、释放或处分 |
| L2 | 全国颁行、跨机关程序或统一法源进入运行 |
| L3 | 群体、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

世宗改革横跨法源、刑罚阈值、刑讯、特权和审录责任，且有冤案补偿、官员问责等实际运行，定L4；译审贿赂和后期官僚杖责有长期、广域表现，事实运行可定L4。前者不虚构个人主责，后者按贞祐制度建立归宣宗。

## 四、方向、归责与去重原则

- 早期旧制只登记金统治者实际建立或维持的公共规则，不把所有女真习俗追责给普通沿用者。
- 《皇统制》整合与熙宗法外杀戮分账；正向法典不能抵销本人实际任意处置。
- 世宗的减死、刑讯纠错、反特权和重修制条共同构成一轮相互支持的系统改革，不逐案拆分计分。
- 章宗法典成熟、禁止民间藏制书、译审失真作用机制不同，分别登记。
- 未获采纳的张汝霖公开法典主张只用于决策审计，不登记为公共成果。

## 六、未纳入联合底账的材料

- 世宗每项个案减刑、孝义特减和审录诏令：由系统改革主节点吸收，不按个案数量累计。
- 海陵限制部分私刑的零散措施：不足以抵销其并行法源与任意处分主线，也未形成独立重大变革。
- 章宗时期每次颁杖式、恢复御史报告和约束译人的命令：作为运行失败及纠偏证据，不在成效未闭合前重复开项。
- 法典条数本身不决定方向；只有消除冲突、提高可知性或反向造成不可知等实际机制进入评分。
- 金亡不是法律治理单因结果，不作为独立节点。
