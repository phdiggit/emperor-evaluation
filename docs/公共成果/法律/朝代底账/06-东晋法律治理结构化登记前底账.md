# 东晋法律治理结构化登记前底账

用途：本文件保存东晋法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以317年司马睿称帝至420年刘裕代晋为朝代边界。西晋已经具备成熟的泰始律、注律和法源边界制度，但惠帝时期又出现多年裁判分裂；东晋的比较重点不是是否仍有法典，而是战时权宜、掌权者裁量和私人权力是否继续架空成法。

## 一、东晋法律治理总判断

东晋法律治理的主线是：

> 元帝草创时期不循律令、临事改制并使用牵连无行为亲属的战时诏书 → 卫展推动清理不合责任原则的诏书，但只完成议除启动 → 成帝朝庾冰在繁细纠察与宽纵之间摆动，使律令失去约束力 → 孝武帝时期司马道子及其党羽经营卖官私狱，法律运行进一步被私人权力俘获。

东晋没有出现可与泰始律相比的成典成果。其最重要的法律史信息反而是运行性：成熟法典在军兴权宜、宽严任意和权臣私狱下失效。两次恢复肉刑的长篇争论都没有实施，不得用奏议篇幅伪装成公共成果。

- 西晋已建立律、令、故事分流和“正文—名例—不论”的法源边界；东晋草创时期的临事改制是相对这条直接基线的倒退。
- 元帝时期材料明确列出鞭打父母追问子女、子孙逃亡而斩家长等牵连无行为亲属的命令，负向判断不是由“战时”标签直接得出。
- “晋图南徙，百有二年……挹其流润”是史家对晋律延续的总论，不能证明东晋百年一直依法运行，更不能抵销同篇记录的律令无用和私狱。

## 三、法律运行档位在东晋的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 议决或清理程序已经启动，未见完成适用 |
| L1 | 至少一次明确裁判或责任结果 |
| L2 | 稳定程序、全国法源或重复范例进入实际适用 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

元帝草创期、咸康期和孝武帝期各自只有阶段性或系统性汇总，均定L3；三段之间机制和责任主体不同，不能拼接成一个虚假的“东晋百年L4”。卫展清诏只有会议启动，未形成公共结果，留在审计层。邵广案是一次明确终局裁判，定L1。

## 四、方向、归责与去重原则

- 元帝节点把法外裁断、朝令夕改和亲属替罪合并为同一战时法源失序，不把每一种诏书拆开重复扣分。
- 熊远的循法建议未获采纳，不生成正分；卫展获得皇帝同意议除，但删改范围和实际施行不明，只保留审计材料，不纳入联合底账。
- 邵广案的负向在于对非杀人盗取官物维持死刑。候选改判中的五年刑是同一行为由死刑降为生刑，不另判负；但把两名未成年儿子没为官奴属于新增亲属惩罚，也不能包装成正向改革。该候选未被采纳，最终只登记维持死刑的实际责任。
- 庾冰、司马道子是直接改变运行者；成帝、孝武帝分别按可见的监督和最高统治责任归档，不用臣子直接责任稀释皇帝应负方向。

## 六、未纳入联合底账的材料

- 熊远要求议断必须引用律令、经传和故事：元帝因权宜治理未采纳，只作负向节点的纠偏审计。
- 元帝朝恢复肉刑争论：元帝倾向实施，王敦阻止，最终未行；不把支持、反对或停止讨论自动折算成公共成果。
- 桓玄再次提出斩左右趾以代部分死刑：百官争论后未实施，不因议论充分而计分。
- 何承天反对误射未伤人处死：现存篇章未交代最终裁判，不登记成已经完成的纠偏。
- “江左百有二年挹晋律流润”等总论：只证明制度传承认知，不能替代具体运行证据。
