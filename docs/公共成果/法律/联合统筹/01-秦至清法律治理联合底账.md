# 秦至清法律治理联合底账

> 法律治理联合底账当前值。第四节提供结算组层的综合治理画像；第五节提供节点档位、人物归责与回源明细。各朝原底账是审计事实源；本表不复制审计说明，不直接换算数值分。

## 一、读取合同

- 每行只登记一个已在单朝底账验收的治理节点；节点编号在原底账行序不变时稳定。
- `READY` 才能进入跨朝校准；不存在可评分公共结果的提议、未实施命令和纯知识保存不进入本表。
- `CLOSED` 表示不存在 `R?`；`PARTIAL` 表示已定档人物可计、`R?` 人物排除；`BLOCKED` 对应整行 `HOLD`。
- 一个节点可以进入多个机制组；各组节点数允许重叠。机制组只建立同类比较池，不等于认定朝代间直接继承。
- `无个人结算` 表示公共结果成立但现有材料不能公平定位开创者或重大变革者，不向普通沿用者摊派。
- 相同 `结算组` 属于同一改革或制度生命周期，但不压成一个总档。组内按相互独立的治理机制形成档位向量、运行向量、广度档和整合度；具体归入总则哪个评分项留给后续评分环节。
- 机制数量不等于标签数量。只有移除后会损失一项独立公共收益或成本的机制才计数；同一机制的制定、传播和结果通常合并为一个机制，并由运行证据提高L档。
- 人物只取得自己拥有明确R档的机制组合子集，不能继承同组其他人的治理广度；皇帝若对多个独立机制分别拥有最终决定责任，可以取得相应的综合治理广度。
