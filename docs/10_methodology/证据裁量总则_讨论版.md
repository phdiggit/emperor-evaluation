# 证据裁量总则（讨论版 v0.3）

## 一、定位

本总则用于规范“史料证据如何进入评分体系”的中间流程。

它不直接定档、不直接定分、不替代各大项标尺，而是负责把原始史料转化为可被标尺读取的“净证据”。

标准流程为：

```text
原始史料
→ 原子证据卡
→ 五轴裁量
→ 触发式裁判模块
→ 证据组裁量结论
→ 净证据池
→ 自动结算规则敏感点清单
→ 自动结算草案
→ 定档前人工裁判清单
→ 标尺定档定分
```

## 二、基本概念

### 1. 原子证据卡

原子证据卡是最小史料单位。每张卡必须有明确来源、短摘、人物、子项、正负方向、候选强度、相邻项切分和裁判状态。

原子证据卡只记录史料和单证裁量，不得直接推出最终定档。

### 2. 五轴裁量

五轴裁量是所有证据必经的常规裁量步骤：

1. 归项直接度；
2. 行为关键性；
3. 持续性 / 结构性；
4. 后果外溢度；
5. 相邻项剥离后剩余强度。

五轴裁量用于判断单条证据候选强度：弱、中、强、极。

### 3. 触发式裁判模块

触发式裁判模块不是所有证据都要进入。只有当证据属于高风险、易混项、易高估、易低估或需要封顶/降权/上探的类型时，才进入对应模块。

在第五项B这类成熟子项中，触发式裁判模块之后可以继续进入自动结算层。自动结算层不生成最终分数，也不直接生成正式定档；它负责替代常规人物级/证据簇级人工裁判，输出自动带位方向、置信度和规则敏感点。人工只复核规则是否合理、是否命中，原则上不回到人物个案。

常见触发项包括：

- 强正、强负、极正、极负候选；
- 关键对象层级显著影响证据强度；
- 同一对象前期正向、后期反转；
- 谋反真假或政权安全混入；
- 宠信佞臣、酷吏、近幸、外戚、宦官；
- 错用将相；
- 系统性清洗或大规模牵连；
- 正负证据组均强，且不能机械抵消。

触发式模块的作用是修正五轴初判，不是取代五轴。

### 4. 证据组裁量结论

证据组不是新史料，而是对一组原子证据的结构性判断。

证据组必须列明：

- 依据哪些原子证据；
- 覆盖哪些维度；
- 是否形成结构性表现；
- 与相邻项切分后的剩余影响；
- 汇总层面候选强度；
- 是否需要人工裁判。

单条强证可形成证据组；多条中证若覆盖多个维度，也可形成证据组。多条同类材料不得按条数机械加分。

### 5. 净证据池

净证据池是进入标尺定档前的证据集合。只有完成回源、归项、五轴裁量、相邻项切分和必要裁判的材料，才能进入净证据池。

净证据池不是最终定档表。它只回答：

```text
哪些正证成立？
哪些负证成立？
正负关系如何？
是否存在高档位拦截或上探限制？
哪些问题仍需人工裁判？
```

自动结算草案只回答更细一层的问题：

```text
哪些证据簇命中规则敏感点？
哪些证据组只保留带位方向？
哪些边界问题应后移到规则层而不是逐人裁判？
```

第五项B当前的自动结算重点包括：

- 弱负升中负边界只降置信度，不阻断极正；
- 中负升强负边界阻断极正/高位上探；
- 单一维度强正若有三个强正核心，可上探极正候选；
- 相邻项主导的大案剥离后，默认只保留中负剩余，除非有直接寒蝉硬证；
- 强正底盘遇到强负核心时，保留底盘但阻断极正上探。

## 三、正负证据组净裁量语法

正负证据组进入定档前，统一按以下语法处理：

```text
通用裁量语法
+ 分项专用规则
+ 触发式人工裁判
```

### 1. 通用裁量语法

所有子项都应先判断：

1. 正负证据是否属于同一维度；
2. 是否处于同一阶段，还是存在前期/后期反转；
3. 是否一方是能力证据，另一方是安全/稳定性证据；
4. 是否存在结构性外溢，而不是个案孤证；
5. 相邻项剥离后，本项剩余影响是否仍强；
6. 是否触发高档位拦截、极档人工裁判或反向检索。

### 2. 不得简单抵消的情况

以下情况通常不得简单抵消：

- 正证证明能力，负证证明安全生态或稳定性；
- 正证发生在前期，负证显示后期反转；
- 同一核心对象前期正向、后期反转；
- 负证有群体外溢或寒蝉效应；
- 负证虽有相邻项背景，但剥离后仍保留本项强影响。

这类情形应写成“分维度共存”，进入定档前人工裁判。

### 3. 可以部分抵消的情况

以下情况可考虑部分抵消：

- 正负证据指向同一维度、同一时期、同类行为；
- 负证有明确反转、纠错、赦免、恢复、平反或持续补救；
- 正证只是单点亮点，负证只是同类单点失误，均未形成结构性。

即使可以部分抵消，也应保留抵消依据，不得把负证从记录中删除。

### 4. 高档位拦截

若存在强负或极负证据组，并且满足下列任一条件，应触发高档位拦截：

- 负证直接破坏本项核心定义；
- 负证与正证属于同一对象或同一制度链条的反转；
- 负证具有群体外溢或长期结构性；
- 正证强但高度依赖结果论、光环或相邻项成果。

高档位拦截不等于低档。它只表示：不得因强正证据直接上探极高档。

## 四、对象锚点与证据权重标签规则

对象锚点用于校准证据强度，不单独构成评分体系，也不应扩展成独立的多轴计算层。

“对象”不限于人物，也可以是指标、空间、机制、事件类型或其他被证据指向的核心承载物。对象锚点只回答：

```text
这个证据涉及的对象，在本项目里是普通对象、高价值对象、顶级对象，还是高危负向对象？
```

它不回答：

```text
这个对象本身综合排名第几？
```

### 1. 对象锚点的四类常用形态

#### A. 人物对象

用于用人、授权、谏诤、功臣安全、佞臣/酷吏/近幸等裁量。

常见标签：

```text
顶级 / 高级 / 中级 / 普通 / 存疑
能臣 / 名臣 / 谏臣 / 将帅 / 技术官僚 / 酷吏 / 佞臣 / 近幸 / 外戚 / 宦官 / 旧敌转用 / 异质人才
```

#### B. 指标对象

用于民生、财政、人口、仓储、社会韧性等裁量。

常见标签：

```text
粮价 / 户口 / 人口增长率 / 仓储 / 赋役负担 / 流民规模 / 饥荒程度 / 财政透支 / 战损比
轻微 / 中等 / 严重 / 极端 / 存疑
```

#### C. 空间对象

用于开国、国防、战略、治理覆盖等裁量。

常见标签：

```text
关中 / 河北 / 江南 / 河套 / 辽东 / 河西 / 中原 / 战略通道 / 边疆缓冲区 / 都城圈
普通区域 / 重要区域 / 战略要地 / 顶级枢纽 / 存疑
```

#### D. 行为与机制对象

用于纠错、纳谏、制度建设、授权机制、反馈入口等裁量。

常见标签：

```text
纳谏 / 纠错 / 诏令反转 / 制度覆盖 / 监察反馈 / 长期授权 / 政策撤回 / 处罚反转
偶发 / 多次 / 稳定机制 / 结构性机制 / 存疑
```

### 2. 对象锚点如何进入证据权重

对象锚点可以写入证据卡的 `interpretation`、`trigger_terms`、`note`，或在后续 schema 稳定后再考虑增设轻量字段。

不得把对象锚点写成：

```text
对象等级 × 责任基础 × 处置强度 × 外溢范围
→ 独立计算或半计算出证据强度
```

正确用法是：

```text
史料保真
→ 单证自动四档定级
→ 用少量对象/角色标签保留边界信息
→ 证据组处理累计效应和结构效应
→ 标尺层定档定分
```

建议轻量表达为：

```text
object_type：人物/指标/空间/机制
object_level：顶级/高级/中级/普通/极端/战略要地/稳定机制等
object_relevance：与本项直接相关/相邻项较强/仅作背景
object_weight_note：为什么该对象会影响候选强度
```

当前阶段不强制扩展 JSONL schema，避免为所有项目一次性增加维护负担。

若需记录人才安全处置锚点，优先使用轻量标签，例如：

```text
object_anchor
evidence_role
mitigation_flag
upper_bound_flag
cluster_role
```

这些标签只保留裁量边界，不改变四档证据强度框架。

### 3. 对象锚点使用边界

对象锚点只能影响证据候选强度，不能越过归项、相邻项剥离、行为归因和人工裁判，直接推出档位。

例如：

- 任用顶级将帅，可提高用人/授权正证权重；但战役胜负不能回填用人项。
- 拿下顶级战略要地，可提高开国/战略证据权重；但必须判断本人贡献和具体归项。
- 粮价或户口出现极端指标，可提高民生/社会证据权重；但必须判断范围、持续时间、责任归属和恢复情况。
- 多次纳谏可提高反馈机制权重；但必须区分偶然采纳和稳定表达安全。

### 4. 何时必须标对象锚点

只有以下情况强制标对象层级或对象锚点：

- 强证、极证候选；
- 高档位或低档位候选；
- 负证拦截或高档位上探限制；
- 同类横向争议；
- 同一对象正负反转；
- 相邻项切分后对象权重仍影响本项剩余强度。

普通弱证、中证、重复材料可不标对象锚点。

### 5. 最小对象池原则

各项目可以建立自己的最小对象池，但不得一开始建立全量对象评分体系。

最小对象池只保留：

```text
顶级锚点
中级锚点
低级锚点
负向极端锚点
若干争议锚点
```

对象池用于校准证据，不服务排名。若某对象池尚未稳定，可先放在子项模板、专题锚点池、批次文件或 PR 说明中，待稳定后再合并进正式规则。

### 6. 同一对象正负反转

若同一高价值对象前期形成正证、后期形成负证，应分维度处理：

```text
前期正向 → 对应能力/收益/机制正证
后期反转 → 稳定性/安全性/持续性负证
```

二者不得简单抵消。单证层应先自动完成弱/中/强/极定级，再用对象锚点标签保留边界信息；只有证据组结算、高档位拦截或相邻项剥离后的剩余强度仍有争议时，才进入人工裁判。

## 五、证据饱和与代表性覆盖

当某人物在某子项已经覆盖核心维度，并且已有强级或极级候选证据组时，后续同类型正证默认只作为元数据厚度补充，不自动提高候选强度。

证据饱和不是停止检索。即使已出现代表性覆盖，仍应保留最低限度的关键人物扫查和反向检索，以防遗漏结构性反证、新维度证据或相邻项切分问题。

## 六、总执行规则

### 1. 原始史料不得直接入分

任何史料，即使正负方向非常明显，也必须先转化为原子证据卡，并完成五轴裁量。

### 2. 单证强度不等于最终档位

单条强正证据不必然支撑强档；多条中正证据若覆盖多个维度，可能在证据组层面支撑强档。

单条极负证据可能触发负证拦截，但必须人工裁判。

### 3. 相邻项切分优先于强度判断

任何证据在给出候选强度前，必须先剥离相邻项内容。

例如：

- 战果不得回填用人项；
- 盛世光环不得回填行政项；
- 政策效果不得回填识人授权；
- 政治残酷性不得直接混入用人生态；
- 军事失败结果不得直接等同于错用将相。

### 4. 极级证据必须人工裁判

极正、极负不是常规档。任何原子证据卡或证据组裁量结论若拟进入极级，必须标记为人工裁判候选，不得由自动流程直接入分。

### 5. 反转材料必须记录

若存在追悔、纠错、平反、恢复评价、复官、复碑、补救等反转材料，必须在证据卡或证据组裁量结论中记录。

反转材料不必然抵消原证据，但必须影响候选强度或标为待人工裁判。

### 6. 自动结算与人工裁判的分界

自动结算层只处理抽象规则可解释的部分，例如：

- 中负边界是否阻断极正上探；
- 单一维度强正是否封顶；
- 强负核心是否压制强正；
- 相邻项剥离后的剩余强度如何默认处理。

若规则已足够解释结论，人工只需复核规则是否命中，不必回到逐人裁判。若规则仍无法稳定抽象，才进入人工裁判。

### 7. 人工裁判触发边界

只有以下情况必须进入人工裁判：

- 拟进入极档或高位档；
- 强正与强负并存；
- 正负关系不能按同维度抵消处理；
- 负证可能构成高档位拦截；
- 对象锚点或同一对象正负反转使证据组结算、高档位拦截或相邻项剩余强度仍存在争议；
- 相邻项切分后剩余影响仍有争议。

普通弱证、中证、重复材料和低价值线索不应全部交给人工裁判。

## 七、与评分标尺的关系

证据裁量总则不替代评分标尺。

评分标尺只读取已完成裁量的净证据，包括：

- 单条证据候选强度；
- 证据组裁量结论；
- 正负证关系；
- 负证拦截或高档位上探限制；
- 对象锚点/同一对象反转的人工裁判状态；
- 是否仍有未决人工裁判项。

最终定档定分仍由各大项/子项标尺完成。
