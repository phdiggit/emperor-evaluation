# 《资治通鉴》五代十国原文阅读包

本目录提供《资治通鉴》卷 263—294 的固定修订原文，供网页端逐卷通读。每卷文件开头保留来源 URL、修订号和原文 SHA-256；每个非空原文段落前的方括号锚点行是稳定位置锚点。维基页面标记被保留，以免清洗丢失原文段落。

- `manifest.jsonl`：一卷一行的机器清单与内容 hash。
- `卷NNN.md`：唯一网页端输入文本。不得以本目录外的摘要代替它。
- 阅读、总结、接收和拒收要求见 [`../../证据规则/编年体史料通读工作流.md`](../../证据规则/编年体史料通读工作流.md)。

使用时一次只给 ChatGPT 网页端一卷原文、对应 manifest 行及上一卷边界摘要。网页端输出只能是带原文锚点的中性通读总结；战役父卡、窗口绑定、成本收益档与人物评分均在后置规则链完成。

卷264、266、269、283 的原缓存为单行渲染文本，无法保留段落边界；本包对其定点读取固定 wikitext revision。对应 manifest 行以 `source_text_origin`、`cache_revision_ref` 和 `cache_raw_sha256` 明示该差异。

本目录保留来源 URL 和署名线索；再次分发或改变使用范围前，应在对应来源页核验许可条件。
