## 一、财政、民生、工程与灾害

- 王建与李茂贞修好后，李茂贞屡求财货、甲兵，王建皆给与；同段又明载“王建賦斂重，人莫敢言”。冯涓借王建生日献颂，先颂功德、后陈“生民之苦”，王建惭谢，自此“賦斂稍損”。这是本卷最直接的赋役民生事实。原文定位：`SRC-ZZTJ-265-803276-P0016`“茂貞數求貨及甲兵於建，建皆與之”“王建賦斂重，人莫敢言”“自是賦斂稍損”。
- 河东都押牙盖寓临终遗书劝李克用“省營繕，薄賦斂，求賢俊”。原文只见政策建议，未写本卷已经实行，故只作治理思想旁录，不把它当成已经实现的减役减税。原文定位：`SRC-ZZTJ-265-803276-P0050`“遺書勸李克用省營繕，薄賦斂，求賢俊”。
- 四月西北出现彗星；五月又记彗星“長竟天”。原文没有直接记载由此发生的农业、人口或财政灾损；后续柳璨等借星变推动政治清洗，属政治秩序事实。原文定位：`SRC-ZZTJ-265-803276-P0050`“有彗星出西北”；`SRC-ZZTJ-265-803276-P0053`“彗星長竟天”。
- 朝廷先定昭宣帝十月南郊，后改十一月，又因朱全忠不满而推至来年正月，最终再以“宮禁內亂”罢郊庙礼。这里反映中央礼制反复受政治局势牵制，并非工程或战争成本。原文定位：`SRC-ZZTJ-265-803276-P0052`、`P0073`、`P0085`、`P0091`。
- 朱全忠被授盐铁、度支、户部“三司都制置使”，原文明言“三司之名始於此”，但朱全忠辞不受。原文定位：`SRC-ZZTJ-265-803276-P0106`“三司之名始於此。全忠辭不受”。
- 本卷多次调整军镇与州郡隶属：改昭信军为戎昭军并以均州隶之；后废戎昭军、均房改隶忠义军；又复忠义军为山南东道；闰月废镇国军兴德府复为华州，并重新调整金、商等州隶属。均属行政区划与军镇建制变更。原文定位：`SRC-ZZTJ-265-803276-P0078`、`P0113`、`P0115`、`P0133`。
- 王建在蜀“始立行台”，宣称因唐廷制命不通，仿李晟、郑畋故事承制封拜，并以榜帖告谕所部藩镇州县。这是西川政权自行建立任官与行政权源的制度性步骤。原文定位：`SRC-ZZTJ-265-803276-P0126`“請權立行台……承製封拜”。

## 二、政治秩序、外交与人口变化

- 昭宗在洛阳宴朱全忠，罢外殿宴后再召入内殿，朱全忠因疑惧拒绝，随后东返大梁，显示君臣之间已高度互疑。原文定位：`SRC-ZZTJ-265-803276-P0013`“全忠疑，不入”。
- 王建拒绝诸将乘李茂贞衰弱夺凤翔的建议，采纳冯涓“凤翔为蜀籓蔽”的判断，与李茂贞修好并联姻；李茂贞以侄李继崇求婚，王建以女妻之。该段同时形成蜀—岐互供财甲、以凤翔为缓冲的外交关系。原文定位：`SRC-ZZTJ-265-803276-P0016`“鳳翔，蜀之籓蔽，不若與之和親”“建以女妻之”。
- 昭宗迁洛后日日担忧不测，朱全忠令枢密使蒋玄晖监视其动静；昭宗曾为德王裕将遭杀害而哭诉。原文定位：`SRC-ZZTJ-265-803276-P0017`“全忠使樞密使蔣玄暉伺察帝，動靜皆知之”。
- 朱全忠因昭宗仍有号召力、外镇又多以“兴复”为名，谋立幼君以便禅代；实际夜入宫禁弑帝的武装阶段已另入战役裁决卡。原文定位：`SRC-ZZTJ-265-803276-P0018`“欲立幼君，易謀禪代”。
- 昭宗死后，蒋玄晖矫诏立辉王祚为太子并更名柷，随后十三岁的昭宣帝即位；宫中“恐懼，不敢出聲哭”。原文定位：`SRC-ZZTJ-265-803276-P0020`。
- 李克用重新以张承业为监军。原文定位：`SRC-ZZTJ-265-803276-P0021`。
- 朱全忠得知昭宗被弑后公开痛哭，自称并非己意，并以军士扰市为名贬杀朱友恭、氏叔琮；李彦威临刑直言自己是被用来“塞天下之謗”。这是弑帝后的责任转嫁与政治清算。原文定位：`SRC-ZZTJ-265-803276-P0025`。
- 钱镠暗遣叶让谋杀衢州刺史陈璋，事情泄露后陈璋斩叶让并转而归附杨行密；后续衢婺战争另入战役裁决卡。原文定位：`SRC-ZZTJ-265-803276-P0029`。
- 杨行密主动遣马賨归长沙，自己亲自郊送；马殷随后任马賨为节度副使。马賨劝马殷与杨行密结好，理由包括“缓急之授”与“通商旅之利”，马殷则坚持朝廷名义。原文定位：`SRC-ZZTJ-265-803276-P0030`、`P0031`。
- 清海节度使徐彦若死后曾荐刘隐权留后；朝廷原命崔远继任，但崔远畏岭南盗乱及刘隐拒代而不敢前。刘隐又以重赂结朱全忠，最终获奏为清海节度使。原文定位：`SRC-ZZTJ-265-803276-P0032`。
- 王师范战后举族西迁，朱全忠仍以宾客待之，并以李振为青州留后；这是山东战事结束后的人员与地方权力安置。原文定位：`SRC-ZZTJ-265-803276-P0038`、`P0040`。
- 朱全忠以“德王等”九名昭宗诸子置酒九曲池，酒酣后悉数缢杀并投尸池中。此为无双方武装争夺的政治处刑，按合同不进入战争账户。原文定位：`SRC-ZZTJ-265-803276-P0042`“悉縊殺之，投屍池中”。
- 三月以后，裴枢、崔远、独孤损等先后被罢相或外贬。柳璨因私怨与迎合朱全忠不断构陷朝士，李振又主张清除“衣冠浮薄之徒”；星变被用作“诛杀以应之”的理由，三省台阁中声名稍著者接连被贬，“搢紳為之一空”。原文定位：`SRC-ZZTJ-265-803276-P0046`—`P0054`。
- 六月，裴枢、独孤损、崔远、陆扆、王溥、赵崇、王赞等奉敕赐死；朱全忠又把白马驿聚集的三十余名被贬朝士一夜杀尽、投尸黄河。李振以自己屡试进士不第而深恶士绅，提出“清流”投入黄河成为“浊流”。原文定位：`SRC-ZZTJ-265-803276-P0056`—`P0058`。
- 朱全忠曾因游人附和“柳木宜为车毂”而命左右将附和者数十人全部扑杀；司空致仕裴贽随后又被贬而赐死。张文蔚力解，才阻止柳璨再牵连十余人。原文定位：`SRC-ZZTJ-265-803276-P0059`—`P0061`。
- 因士大夫避乱多不入朝，朝廷命各州县督促赴朝、不得稽留；李延古居平泉庄，也因未应诏被责授卫尉寺主簿。原文定位：`SRC-ZZTJ-265-803276-P0062`。
- 司空图此前屡征不起，柳璨再诏征入洛；司空图故作衰野、失仪，最终获准“放还山”。原文定位：`SRC-ZZTJ-265-803276-P0068`。
- 杨行密病重时，围绕继承发生公开分歧。周隐认为杨渥“轻易信谗，喜击球饮酒”，主张由刘威暂领军府；徐温、张颢坚持杨氏子孙承袭。严可求发现召杨渥的牒仍压在周隐案上，便与徐温取牒发使，终于把杨渥召回广陵。原文定位：`SRC-ZZTJ-265-803276-P0076`。
- 昭宗谥号被苏楷建议重新议定，太常据张廷范奏改为“恭灵庄愍孝皇帝”，庙号“襄宗”。原文定位：`SRC-ZZTJ-265-803276-P0080`。
- 杨渥抵广陵后，杨行密承制以其为淮南留后；十一月杨行密去世，将佐又请李俨承制授杨渥淮南节度使、东南诸道行营都统等职。原文定位：`SRC-ZZTJ-265-803276-P0081`、`P0088`。
- 朱全忠禅代程序反复。蒋玄晖、柳璨原拟依魏晋故事先封大国、加九锡再受禅，朱全忠嫌其迟缓；何太后又托宫人求传禅后母子保全。王殷、赵殷衡借机诬陷蒋玄晖等图“兴复唐祚”，蒋玄晖、应頊、朱建武被杀，枢密使及宣徽南院使等机构随之调整。原文定位：`SRC-ZZTJ-265-803276-P0085`、`P0089`。
- 朱全忠先被进封魏王、加九锡，又三表辞让；但原文同时明记其“大梁府舍为宫阙”已经修成，显示拒命主要属于禅代程序。原文定位：`SRC-ZZTJ-265-803276-P0089`“全忠已修大梁府捨為宮闕矣”。
- 何太后随后被王殷、赵殷衡进一步诬为与蒋玄晖私通，朱全忠密令杀于积善宫，追废为庶人；宫人阿秋、阿虔也被扑杀。原文定位：`SRC-ZZTJ-265-803276-P0090`。
- 柳璨被贬后斩于上东门外，张廷范被车裂于都市；这是政争清算，不计战争成本。原文定位：`SRC-ZZTJ-265-803276-P0092`。
- 李茂贞遣其子李侃为质于西川，王建任李侃知彭州，蜀—岐关系由婚姻继续发展到人质安排。原文定位：`SRC-ZZTJ-265-803276-P0119`。
- 钟传死后，镇南军拥立其子钟匡时为留后；养子钟延规因不得立而遣使降淮南。该继承裂变直接成为后续江西战争的政治起点，实际战斗另入裁决卡。原文定位：`SRC-ZZTJ-265-803276-P0111`。
- 朱全忠以长安邻近邠、岐、屡有战争为由，奏调佑国节度使韩建至淄青、王重师移镇佑国；这里仅记录官镇调换，相关战争成本不在本总结重复。原文定位：`SRC-ZZTJ-265-803276-P0116`。
- 湖州刺史高彦卒，其子高澧继任；钱镠又表荐王景仁，朝廷以其领宁国节度使。原文定位：`SRC-ZZTJ-265-803276-P0130`、`P0131`。
- 吉州刺史彭玕遣使向湖南请降。原文只见政治归附，未记本段发生战斗。原文定位：`SRC-ZZTJ-265-803276-P0138`。

## 三、跨卷连续性

- 向前：卷264留下的鄂州、润州安仁义、睦州陈询、赵匡凝荆南控制等武装父链均在本卷继续发展，已统一放入 `volume-265.battle-adjudications.json` 收束；非战役政治主线则承接昭宗迁洛后被朱全忠严密控制、唐廷官僚体系持续遭清洗的状态。
- 向后：卷末唐廷禅代已进入最后阶段，朱全忠虽反复辞魏王、九锡，实际已在大梁营造宫阙；杨行密已死而杨渥继位，王建已在蜀自行立行台并承制封拜。卷266将进入后梁开平元年，须继续观察梁的正式建国、蜀的称帝、淮南继承危机以及河东北方秩序的重组。
- 武装跨卷待核事项另见本卷 JSON `review.cross_volume_followups`，包括归州、温州—处州、岳州、雷彦恭荆南线、潞州、幽沧兄弟体系及衢州等。
