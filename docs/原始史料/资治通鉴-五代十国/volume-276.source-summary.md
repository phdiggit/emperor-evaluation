## 一、财政、民生、工程与灾害

- 天成二年十月，明宗下诏免除三司逋负近二百万缗。原文定位：`SRC-ZZTJ-276-1767667-P0024`“免三司逋負近二百萬緡”。
- 孟知祥十二月发民丁二十万修成都城，是本卷规模最大的明确徭役工程；这一工程发生在两川与中央关系尚未正式开战之前，因此独立留在非战役账。原文定位：`SRC-ZZTJ-276-1767667-P0031`“發民丁二十萬修成都城”。
- 蔚、代沿边粟价低，每斗不超过十钱。原文定位：`SRC-ZZTJ-276-1767667-P0036`。
- 孟知祥与董璋争盐利，在汉州设置三个税场对东川盐重征，每年得钱七万缗，同时使商旅不再前往东川。原文定位：`SRC-ZZTJ-276-1767667-P0047`“歲得錢七萬緡，商旅不復之東川”。
- 西川原奉诏由毛重威率三千人戍夔州。孟知祥以夔、忠、万已平、继续驻戍增加馈运为由请撤，朝廷不许，于是暗中诱导军士鼓噪逃归，事后再为其请免罪。这里没有双方交战，作为军粮与中央—西川军权矛盾保留。原文定位：`SRC-ZZTJ-276-1767667-P0057`“請召戍兵還，以省饋運”。
- 东都原对私造酒曲者甚至族诛，随后改制为允许百姓造曲，并在秋税中每亩加收五钱。原文定位：`SRC-ZZTJ-276-1767667-P0060`。
- 定州战争中的三州租税、长期馈运属于战争实际成本，已进入战役JSON；但战后王晏球入朝时只自责“久烦馈运”，没有夸功，作为军政作风亦可见于 `SRC-ZZTJ-276-1767667-P0097`。
- 后唐四月禁止铁钱、锡钱。原文明言湖南专用锡钱，一枚铜钱价值锡钱百，锡钱大量流入中原且“法不能禁”，显示区域货币价差和跨境货币流动问题。原文定位：`SRC-ZZTJ-276-1767667-P0100`。
- 朝廷把党项贡马改为缘边设场直接购买，不再准其借贡马入阙。此前除马价外还需承担馆谷、赏赐，岁费五十余万缗，改制目的明确是减少财政耗蠹。原文定位：`SRC-ZZTJ-276-1767667-P0102`“歲費五十餘萬緡”。
- 南郊前，后唐要求西川献钱一百万缗、东川五十万缗；两川都以军用不足拒绝足额，最后西川献五十万、东川十万。原文定位：`SRC-ZZTJ-276-1767667-P0107`。
- 西川长期被要求向峡路输送刍粮。孟知祥以本道兵多、财力不足为由屡次拒绝，朝廷反复催督后仍正式奏称不能奉诏。原文定位：`SRC-ZZTJ-276-1767667-P0120`。
- 冯道在丰年向明宗指出农民并非自然富足：荒年会流殍，丰年也会因谷贱受害，并引用“二月卖新丝，五月粜新谷；医得眼下疮，剜却心头肉”说明农户以未来产出救眼前急迫的困境。明宗命左右抄录、常加讽诵。原文定位：`SRC-ZZTJ-276-1767667-P0114`。
- 孟知祥部下孟容之弟任资州税官，因自盗判死；即使冯璩、王处回求情，孟知祥仍称连自己弟弟犯法也不可赦，拒绝徇私。原文定位：`SRC-ZZTJ-276-1767667-P0116`。
- 八月和次年二月均发生日食。原文定位：`SRC-ZZTJ-276-1767667-P0017`、`P0041`。

## 二、政治秩序、外交与人口变化

- 卷初因此前把夔、忠、万三州给高季兴，豆卢革、韦说被赐死；段凝、温韬、刘训分别流放，任圜则获准致仕居磁州。后来朱守殷反时，安重诲又以防失职者乘乱为由奏杀任圜，赵凤当面痛斥其“滥刑”，仍未能救止。原文定位：`SRC-ZZTJ-276-1767667-P0014`—`P0016`、`P0022`。
- 楚王马殷正式建国，建立宫殿与百官体系，大体仿天子制度但稍改官名，如翰林学士称文苑学士、枢密院称左右机要司；群下称其“殿下”。原文定位：`SRC-ZZTJ-276-1767667-P0018`。
- 明宗发现从荣左右有人矫称皇帝旨意，禁止从荣接近儒生，认为这会削弱皇子志气；原欲斩其人，经安重诲劝止只严戒。后来从荣在河东又因嫉妒从厚声望而多募部曲、修甲兵自固，冯赟密奏；明宗召杨思权入朝，却因顾忌从荣没有治罪。原文定位：`SRC-ZZTJ-276-1767667-P0018`、`P0089`、`P0091`、`P0103`。
- 契丹九月主动请求修好，后唐遣使报聘。定州战后明宗又赦惕隐等酋长五十人、置于亲卫，却斩其余六百俘虏；契丹随后再遣使入贡。俘虏处刑属于战后处置，不反算战斗P。原文定位：`SRC-ZZTJ-276-1767667-P0021`、`P0068`、`P0069`。
- 徐温死前，吴内部长期争论应由徐知诰还是亲子徐知询执政。严可求、徐玠屡劝以知询代知诰，徐温因知诰孝谨及陈夫人反对没有采纳；死后徐知询急归金陵，吴主追赠徐温齐王、谥忠武。原文定位：`SRC-ZZTJ-276-1767667-P0025`。
- 张筠久病不见将佐，引发副使苻彦琳等怀疑其已死并请求暂交符印；张筠反诬众人谋反。朝廷把他们押至中央审查，确认无状后释放，并把张筠调为西都留守。原文定位：`SRC-ZZTJ-276-1767667-P0026`。
- 杨溥十一月即皇帝位，吴由王制转入帝制，随后大赦、改元乾贞、尊王氏为皇太后，并重新配置徐知询、徐知诰等军政权力。安重诲曾主张因此伐吴，明宗不从。原文定位：`SRC-ZZTJ-276-1767667-P0028`—`P0030`。
- 明宗想召曾预言自己贵不可言的相者周玄豹入京，赵凤认为术士入京会吸引轻躁狂险者聚集问吉凶，容易制造政治灾祸，明宗采纳，只就地给周玄豹光禄卿致仕并厚赐。原文定位：`SRC-ZZTJ-276-1767667-P0033`。
- 明宗另讨论亲庙制度，最后决定在应州旧宅立庙，并把高祖考妣以下追谥为皇帝、皇后，墓称陵。原文定位：`SRC-ZZTJ-276-1767667-P0034`。
- 昭义毛璋骄僭暴虐，时穿赭袍、纵酒嬉戏，甚至剖开谏者心脏观看；明宗得知后把他征入朝任右金吾卫上将军。其本人虽有练兵修械背景，但最终没有武装抗命，故不立战役卡。原文定位：`SRC-ZZTJ-276-1767667-P0039`。
- 明宗原想赴邺都，但扈驾军家属刚迁大梁，又听说将再迁，军中不悦、流言汹汹；明宗得知后取消行程。原文定位：`SRC-ZZTJ-276-1767667-P0042`。
- 吴自庄宗灭梁以来一直与后唐保持使节往来。安重诲认为吴敢与朝廷抗礼且使者带窥探性质，拒不接纳，从此双方断交。原文定位：`SRC-ZZTJ-276-1767667-P0043`。
- 安重诲、孔循、王建立之间的中枢权争在天成三年春集中爆发。孔循借王德妃与皇子婚姻构筑关系，安重诲将其外放；王建立则入朝攻击安重诲、张延朗结婚结党。明宗一度准备把安重诲调出枢密，后经朱弘昭劝阻收回，最终王建立入相并判三司。原文定位：`SRC-ZZTJ-276-1767667-P0046`。
- 钱镠通过让诸子自陈功劳来择嗣，最终兄弟共同推钱传瓘；朝廷正式授钱传瓘镇海、镇东两镇节度使。原文定位：`SRC-ZZTJ-276-1767667-P0067`。
- 王都战争中明宗对被俘契丹采取区别处置：以“杀之则虏绝望”为由赦惕隐等五十名酋长，置于亲卫，却把其余六百人全部处死。原文定位：`SRC-ZZTJ-276-1767667-P0068`。
- 王都曾让宫中旧养子李继陶穿黄袍、假称庄宗之子，试图以先朝名义动摇王晏球。王晏球完全不受，直接告诉王都只有决战或投降两条路。原文定位：`SRC-ZZTJ-276-1767667-P0064`。
- 王建立因自己不识字请求辞去判三司，明宗不许。原文定位：`SRC-ZZTJ-276-1767667-P0065`。
- 吴大赦；吴王太后去世。原文定位：`SRC-ZZTJ-276-1767667-P0066`、`P0071`。
- 温韬因发掘诸陵、段凝因反复，被朝廷下令就地处死。原文定位：`SRC-ZZTJ-276-1767667-P0073`。
- 皇子从厚娶孔循女，孔循借此厚结王德妃之党并请求留大梁；安重诲强力排斥，婚礼结束即催其归镇。原文定位：`SRC-ZZTJ-276-1767667-P0082`。
- 明宗询问铁券意义，想到前朝郭崇韬、朱友谦等受铁券仍遭族灭而长叹；赵凤回答真正重要的是帝王心存大信，而不是刻在金石。原文定位：`SRC-ZZTJ-276-1767667-P0084`。
- 高季兴病重后让高从诲权知军府，随后去世；吴先任高从诲为荆南节度使。高从诲继位后认为“唐近而吴远”，主动转向后唐，请楚王马殷、安元信代为谢罪保奏，最终正式内附，后唐罢荆南招讨使。实际前期战事与归州争夺均已入战役JSON。原文定位：`SRC-ZZTJ-276-1767667-P0086`、`P0108`、`P0111`。
- 张昭远上疏批评先朝皇弟、皇子好俳优、饰姬妾、夸仆马，要求为皇子选择重德师傅，并明确嫡庶、长幼秩序以堵继承祸乱。明宗赞叹其言，却未能实行。原文定位：`SRC-ZZTJ-276-1767667-P0087`。
- 闽王王延钧一次度民二万人为僧，原文明言“由是闽中多僧”。原文定位：`SRC-ZZTJ-276-1767667-P0088`。
- 楚王马殷令儿子马希声知政事并总录内外诸军，此后国政先经过马希声再上报马殷。原文定位：`SRC-ZZTJ-276-1767667-P0099`。
- 太常曾给唐哀帝改谥并拟庙号景宗，但因既称“宗”却不入太庙不合礼制，最终去掉庙号。原文定位：`SRC-ZZTJ-276-1767667-P0106`。
- 南郊献钱争议使两川与中央关系进一步恶化。使者李仁矩在梓州恃恩迟宴、拥妓饮酒，被董璋部下持兵入驿辱骂，厚赂后才解；回朝又称董璋不法。之后李彦珣赴东川，也因礼节失当被扣从者、自己逃回。原文定位：`SRC-ZZTJ-276-1767667-P0107`。
- 后唐六月取消“邺都”称号，恢复魏州，并停留守、皇城使。原文定位：`SRC-ZZTJ-276-1767667-P0110`。
- 吴内部徐知询与徐知诰权力斗争继续升级。李简死后，徐知询擅留其亲兵二千在金陵并想干预武昌继承；后来徐知誥利用徐知询与诸弟不和、收受龙凤饰物等弱点，把他诱入江都后留为统军，另收金陵兵，自此“始专吴政”，并斩两面输款的周廷望。原文定位：`SRC-ZZTJ-276-1767667-P0112`、`P0121`。
- 楚高郁因长期辅佐马殷富国而功高，被马希声和杨昭遂连续构陷。马殷明确反对杀高郁，马希声仍先削其兵权，再矫父命杀高郁并族诛。马殷次日才知，痛哭称“政非己出”。原文定位：`SRC-ZZTJ-276-1767667-P0113`。
- 鄜州戍东川兵应归本道时，董璋擅自扣留其中强壮者，只把老弱放回，并收走他们的甲兵。这是军权侵夺和中央控制裂痕，但原文未发生双方交战。原文定位：`SRC-ZZTJ-276-1767667-P0115`。
- 吴越与后唐关系急剧恶化。钱镠对使者礼遇随奉承程度而变，又给安重诲写倨傲书信；同使韩玫诬告乌昭遇向钱镠称臣、泄露国事，安重诲奏杀乌昭遇。朝廷随后削钱镠官爵并拘治吴越进奏官、使者、纲吏，钱传瓘等申冤不被理会。原文定位：`SRC-ZZTJ-276-1767667-P0117`。

- 吴主加尊号并改元大和。原文定位：`SRC-ZZTJ-276-1767667-P0122`。

## 三、跨卷连续性

- 向前：承卷275，后唐虽在峡中复取夔、忠、万，但荆南—三峡控制仍反复；卷276归州数次易手、楚荆水战继续，直到高季兴死后高从诲转而重新归唐，后唐才取消荆南招讨。
- 向后：卷末最重要的未闭合线已经转为两川。中央通过增设保宁军、加强遂州城防、派亲信侦察、持续索取钱粮逐步压缩两川空间；董璋、孟知祥由互相争盐转为联姻并谋共同拒朝廷。真正的两川—后唐战争尚未在本卷发动，必须从卷277开始另立父链，不得把本卷备战和猜忌提前当成战争收益或成本。
