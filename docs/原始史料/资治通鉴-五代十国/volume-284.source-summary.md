## 一、财政、民生、工程与灾害

- 晋帝服丧期满一年即在宫中奏细声女乐；出师时又常令左右奏三弦琵琶、羌笛并击鼓歌舞，却自辩“此非樂也”。百官后来正式上表请听乐，反被下诏不许。原文定位：`SRC-ZZTJ-284-803293-P0016`。
- 契丹入寇使晋“國用愈竭”，朝廷再派三十六使分道括率民财。使者多带吏卒、锁械、刀仗入民家，原文称“小大驚懼，求死無地”，州县吏又借机为奸。河南府出二十万缗；景延广一度欲率三十七万缗，经卢亿劝止。兖州安审信此前借修楼堞敛民财入私藏，括率使张仁愿到州再赋十万缗，并直接从其私藏取足。原文定位：`SRC-ZZTJ-284-803293-P0028`。
- 晋籍乡兵，规定每七户共出兵械资一卒；随后正式号“武定军”，共七万余人。原文将此置于“兵荒之餘”，直书“復有此擾，民不聊生”；后又改名天威军。原文定位：`SRC-ZZTJ-284-803293-P0025`、`P0030`、`P0064`。
- 滑州黄河决口，浸汴、曹、单、濮、郓五州之境，绕梁山汇于汶水；朝廷大征数道丁夫堵塞。晋帝欲刻碑纪功，中书舍人杨昭俭劝其与其颂功不如发哀痛、罪己之诏，帝接受并停止刻碑。原文定位：`SRC-ZZTJ-284-803293-P0037`。
- 契丹欲把河西居民尽徙辽东以实其地，府州人大恐；折从远依险拒命。折从远后续军事反击另入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0038`。
- 因此前契丹入寇时澶州、鄴都间城戍俱陷，晋议在两地中途重新筑德清军城以联络南北，并合德清、南乐之民迁入充实城防。原文定位：`SRC-ZZTJ-284-803293-P0072`。
- 杜威久镇恒州，以备边为名敛吏民钱帛充私藏，见富室有珍货、名姝、骏马即攫取，甚至诬罪杀人、籍没其家。其面对契丹袭扰不救及辖境战争损害另入战役裁决卡。杜威见所部残弊、民怨又惧契丹，未等朝命即擅离边镇入朝。桑维翰主张趁机废黜，至少勿再授雄藩，晋帝以其为密亲拒绝。原文定位：`SRC-ZZTJ-284-803293-P0082`。
- 杜威入朝后献部曲步骑四千及铠仗，又称献本道粟十万斛、刍二十万束。其兵已编入禁军后，他仍要求作为本人牙队，而禀赐全部由县官承担；又借宋国长公主向帝求天雄节钺并获准。原文定位：`SRC-ZZTJ-284-803293-P0084`、`P0086`。
- 契丹连年入寇，原文总括“中国疲於奔命，邊民塗地”；契丹自身“人畜亦多死，國人厭苦之”。这是一条跨年社会成本总括，不另建独立战役阶段，以免与各具体战役重复累计。原文定位：`SRC-ZZTJ-284-803293-P0087`。
- 九月日食。原文定位：`SRC-ZZTJ-284-803293-P0046`。

## 二、政治秩序、外交与人口变化

- 开运元年二月晋廷先分命石贇、何重建、白再荣、安彦威守黄河渡口与河阳，并令李守贞等率兵沿河推进；这些部署所接续的实际马家口、戚城战斗均进入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0012`。
- 杨光远欲西会契丹后，晋另命刘知远自土门出恒州并会杜威、马全节于邢州，刘知远引兵屯乐平不进。原文定位：`SRC-ZZTJ-284-803293-P0015`。
- 南汉主命越王刘弘昌谒烈宗陵，途中使盗杀之；后又幽齐王刘弘弼于私第，十月毒杀镇王刘弘泽于邕州。三事均属宗室清洗，不属于军队交战。原文定位：`SRC-ZZTJ-284-803293-P0020`、`P0035`、`P0048`。
- 晋令太原、恒、定兵各还本镇；具体泰州攻取另入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0023`。
- 南汉以户部侍郎陈偓同平章事。原文定位：`SRC-ZZTJ-284-803293-P0027`。
- 高行周、王周留镇澶州，晋帝自澶州返大梁。景延广因上下皆恶其不逊、帝亦惮其难制，加侍中后出为西京留守；高行周接侍卫马步都指挥使。景延广失势后见契丹强盛，忧国破身危，日夜纵酒。原文定位：`SRC-ZZTJ-284-803293-P0028`。
- 朱文进遣使南唐，唐主囚其使并一度准备出兵，因天暑、疾疫而止；后来的实际南唐伐殷另入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0032`。
- 冯道虽为首相，在危局中“依違兩可，無所操決”，被讥为只适合承平，遂出镇匡国。晋帝随后复置枢密院，以桑维翰为中书令兼枢密使，事无大小悉委，数月间“朝廷差治”。原文定位：`SRC-ZZTJ-284-803293-P0034`、`P0036`。
- 晋复置翰林学士，任李慎仪为承旨，刘温叟、徐台符、李澣、范质等为学士；七月大赦改元，刘昫任司空兼门下侍郎、同平章事。原文定位：`SRC-ZZTJ-284-803293-P0039`—`P0041`。
- 刘知远任北面行营都统、杜威任都招讨使，督十三节度备契丹。桑维翰一制可约束十五节度，百司及使者请示纷至时能随事裁断，事后复议亦难更改；但其一饭之恩、睚眦之怨必报，也受时人非议。原文定位：`SRC-ZZTJ-284-803293-P0042`。
- 朔方冯晖因制书未调自己而上章自陈未老可用，桑维翰答称朔方重地非其不能弹压，使其释然。晋帝则因刘知远两次会兵山东后期不至而疑其异图，虽授都统却不给实际临制权、不让参预密谋；郭威以河东险固、尚武、多战马、农战兼备劝刘知远自安。原文定位：`SRC-ZZTJ-284-803293-P0042`。
- 朱文进向后晋称藩，先获授威武节度使、知闽国事，后又加同平章事、封闽国王；其政权的实际武装建立与覆灭另见战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0043`、`P0050`。
- 晋在澶州置镇宁军，以濮州隶之。原文定位：`SRC-ZZTJ-284-803293-P0044`。
- 南唐濠州刘氏三代相承军镇。刘崇俊厚赂权要，求兼寿州；唐主看穿其意，反把他调任清淮节度使，另派刘彦贞驰往接濠州，刘崇俊后悔。原文定位：`SRC-ZZTJ-284-803293-P0045`。
- 开运二年正月，晋多次调整赵在礼、马全节、张彦泽、景延广等驻防；契丹逼近后又令滑州、鄴都复进军。具体交战与撤退混乱均进入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0057`。
- 张从恩权东京留守。原文定位：`SRC-ZZTJ-284-803293-P0061`。
- 晋帝病稍愈，认为河北相继告急“此非安寢之時”，开始部署亲征。马全节等依据降者情报建议乘契丹散归部落而大举袭幽州，晋帝接受，征诸道兵并下诏亲征。刘知远明确反对，称中国疲弊、自守尚恐不足，主动挑战强胡“勝之猶有後患，況不勝乎”。原文定位：`SRC-ZZTJ-284-803293-P0063`、`P0065`、`P0067`。
- 闽旧臣在朱文进覆亡后共迎王延政归福州并恢复国号“闽”；因南唐兵仍在境，王延政暂不迁都，命王继昌镇福州，并发南都侍卫及两军甲士一万五千赴建州。后者属于战役动员，在 JSON 相应建州战争链中记录。林仁翰虽直接促成朱文进覆亡，受赏甚薄且从不自言其功。原文定位：`SRC-ZZTJ-284-803293-P0066`。
- 冯玉、李彦韬凭宠用事并屡毁桑维翰。晋帝虽一度被李崧、刘昫劝止罢相，仍以中旨授冯玉枢密使分桑之权。李彦韬与嬖幸相结，蒙蔽帝听，连将相升黜也能参与，并公开声称文官无用、欲逐步尽去。原文定位：`SRC-ZZTJ-284-803293-P0070`。
- 福州李仁达、陈继珣均有反复改投经历；王继昌昏弱嗜酒、不恤将士，军士多怨，最终为兵变提供条件。具体兵变另入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0073`。
- 晋军北伐结束后，泰州划隶定州；晋帝四月从澶州回大梁，并恢复鄴都旧名“天雄军”。原文定位：`SRC-ZZTJ-284-803293-P0077`—`P0079`。
- 福州东关战后，李仁达听闻黄仁讽自责往事，又使人诬告黄仁讽、陈继珣谋反并将二人杀死，福州兵权由此尽归李仁达。具体东关战斗本身另入战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0080`。
- 五月大赦。原文定位：`SRC-ZZTJ-284-803293-P0081`。
- 杜威擅离恒州后，桑维翰再次劝帝废之或改授近京小镇，帝以杜威是密亲拒绝；桑自此不敢再言国事，以足疾辞位。原文定位：`SRC-ZZTJ-284-803293-P0082`。
- 李仁达借阅兵暗使军士刺杀卓岩明后，自称威武留后，并杀卓岩明之父；继而改用南唐保大年号，向南唐称藩并获授威武节度使、同平章事，赐名弘义、编入属籍；同时仍向后晋入贡，并与吴越修好。实际武装弑立另见战役裁决卡。原文定位：`SRC-ZZTJ-284-803293-P0083`。
- 契丹连年战争后，述律太后明确劝契丹主不要图为汉主，认为即使取得汉地也不能长居，并表示晋若“回意”即可议和。桑维翰屡劝晋帝复请和，晋遣张晖奉表称臣、卑辞谢过；契丹要求景延广、桑维翰亲至并割镇、定两道，晋廷认为条件过甚而停止议和。原文定位：`SRC-ZZTJ-284-803293-P0087`。
- 王延政在建州战线恶化后向吴越奉表称臣，请为附庸以求救。原文定位：`SRC-ZZTJ-284-803293-P0090`。
- 楚王马希范疑静江节度使、知朗州马希杲得人心，遣人侦察；马希杲惧而称疾求归不许，最终被遣医毒杀。原文定位：`SRC-ZZTJ-284-803293-P0091`。

## 三、跨卷连续性

- 向前：卷283末契丹已陷贝州、博州，周儒引敌渡马家口，杨光远与契丹相通。卷284二月直接承接这一态势；相关 `campaign_group` 继续沿用卷283的晋—契丹、杨光远战争链，不把卷283末的取失与本卷重复累计。
- 向后：卷末仍有三条未闭合链。第一，晋—契丹虽在白团卫形成重大逆转并尝试议和，但多年战争、边民损失和双方疲弊并未结束；第二，南唐仍围建州并已取鐔州，王延政向吴越求援；第三，福州已由李仁达掌权并同时向南唐、后晋、吴越周旋。均交卷285继续核验，不以卷285结果倒填本卷。
