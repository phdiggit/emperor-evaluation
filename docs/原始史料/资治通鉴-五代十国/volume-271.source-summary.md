- 前卷边界：卷270止于贞明五年九月，梁、晋仍隔河争衡，吴、吴越刚进入休兵，而庐江公杨濛已对徐温掌权表示不满。本卷从同年十月杨濛被外放楚州、晋王赴魏州扩建德胜北城继续展开。
- 后卷边界：本卷止于龙德二年末。镇州之乱已经被晋军平定，契丹此次南侵亦退，但梁、晋边界战争与晋王称帝准备均未终结；吴徐温父子专政、蜀主奢纵等政治线也仍在延续，后续只由卷272承接。

## 五、跨卷连续性

- 向前：卷270末梁、晋正在德胜、杨村一线夹河筑垒、建桥对峙，吴与吴越刚转入休兵，杨濛又已表现对徐温专权的不满。卷271开头立即承接为杨濛外放楚州、晋扩建德胜北城并与梁百余战，随后又发展出潘张粮运、濮阳和德胜多轮攻防。
- 向后：本卷截至龙德二年末，镇州之乱虽已由晋攻破并重组成德，王处直也已死，契丹南侵被击退；但梁、晋仍在河南—河北边界争夺，梁刚凭卫州等地收复部分区域、晋仍准备进一步南向。晋王称帝准备已经从劝进转为购玉法物、搜唐旧臣与接收传国宝，但本卷尚未写到正式即帝位。吴徐温父子继续专政，蜀主奢纵与侵扰臣民也仍在发展，均须由卷272继续承接。
