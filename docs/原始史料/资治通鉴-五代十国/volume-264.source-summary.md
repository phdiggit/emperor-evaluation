## 一、财政、民生、工程与灾害

- 王建长期补充蜀中军马。朱全忠使者称蜀“甲兵诚多，但乏马”，王建遂在星宿山大阅，集官马八千、私马四千；原文追记其得蜀以后持续在文、黎、维、茂买马，十年积至此数。这是独立于当卷具体战斗结果的军备与市场采购事实。原文定位：`SRC-ZZTJ-264-1775896-P0029`“官马八千，私马四千”“于文、黎、维、茂州市胡马，十年之间，遂及兹数”。
- 崔胤以左右龙武、羽林、神策等军“名存实亡、侍卫单寡”为由，请各军重新召募步骑，合计六千六百人，由郑元规等在市立格招募。后来崔胤与朱全忠相疑，又与郑元规等“缮治兵仗，日夜不息”；朱全忠暗令麾下壮士混入应募以监视。天祐元年崔胤被清除后，这批新募军全部纵遣。原文定位：`SRC-ZZTJ-264-1775896-P0034`、`P0065`、`P0067`。
- 诸道对唐廷的财政关系已明显松弛。原文称“天子微弱，诸道财赋多不上供”，只有赵匡凝兄弟仍持续输送财赋。原文定位：`SRC-ZZTJ-264-1775896-P0058`“诸道财赋多不上供，惟匡凝兄弟委输不绝”。
- 武泰军旧治黔州，王宗本以当地“多瘴疠”为由请求把治所迁到涪州，王建准许。此处只记录战后行政治所与自然环境选择，不重复前置军事取得事实。原文定位：`SRC-ZZTJ-264-1775896-P0055`“其地多瘴疠，请徙治涪州，建许之”。
- 天祐元年迁都过程中，长安士民被强制东迁，“号哭满路”，老幼相连一个多月不断；张廷范又奉朱全忠命毁长安宫室、百司及民间庐舍，把木材浮渭东运，原文总结“长安自此遂丘墟矣”。这是强制迁徙、城市拆毁和民生破坏，虽以军事威慑为背景，但本段没有形成双方战斗，故不写入战役卡。原文定位：`SRC-ZZTJ-264-1775896-P0068`“驱徙士民，号哭满路”“毁长安宫室百司及民间庐舍”“长安自此遂丘墟矣”。
- 修建洛阳宫室又形成跨区域工程征发：朱全忠调河南、河北诸镇丁匠数万，由张全义治东都宫室；江、浙、湖、岭等附朱全忠诸镇同时输送货财。原文定位：`SRC-ZZTJ-264-1775896-P0068`“发河南、北诸镇丁匠数万”“皆输货财以助之”。

## 二、政治秩序、外交与人口变化

- 昭宗返京后立即停止凤翔时期所授官职。此前宦官大批被杀，张承业、张居翰、程匡柔、鱼全禋及致仕严遵美分别被李克用、刘仁恭、杨行密、王建藏匿而得免，各镇另斩囚犯应诏。陆扆因主张不可完全排斥李茂贞而被崔胤奏贬；韩全诲所献宫人十一人及与宦官亲厚的僧道二十余人又被京兆杖杀。原文定位：`SRC-ZZTJ-264-1775896-P0012`—`P0013`。
- 昭宗问韩偓如何看崔胤，韩偓答“为天下者”不宜以机数欺人，主张推诚直致。此为当时君臣对崔胤政治风格的直接议论。原文定位：`SRC-ZZTJ-264-1775896-P0014`。
- 崔胤借朱全忠势力清洗朝臣：苏检、卢光启被赐自尽，王溥被贬；从昭宗幸凤翔者有三十余人遭贬逐。与此同时朱全忠获“回天再造”等功臣号、守太尉、诸道兵马副元帅及梁王，崔胤升司徒兼侍中。原文直称崔胤“专权自恣，天子动静皆禀之”“刑赏系其爱憎”。原文定位：`SRC-ZZTJ-264-1775896-P0015`。
- 昭宗一度欲以韩偓为相，韩偓荐赵崇、王赞自代；崔胤担心分权，令朱全忠入见反对。昭宗在朱全忠盛怒下被迫贬韩偓为濮州司马，私下与之泣别。原文定位：`SRC-ZZTJ-264-1775896-P0016`。
- 昭宗令朱全忠向李茂贞索回平原公主，李茂贞不敢违抗而归之。原文定位：`SRC-ZZTJ-264-1775896-P0017`。

## 三、跨卷连续性

- 向前：卷263末形成的昭宗返长安后宦官体系被摧毁、崔胤依托朱全忠掌权的政治格局，在本卷迅速转成朱全忠对禁卫、宫苑、皇城与京辅的直接渗透；相关战役线不在本总结重复，均以 `campaign_group` 在裁决 JSON 中承接。
- 向后：卷末昭宗已被强迁洛阳，原随驾二百余人被杀并由朱全忠所置人员冒名替换，内诸司和六军宿卫亦由其腹心重组。李神福再攻杜洪的鄂岳军事阶段仍未闭合，需由卷265继续核验；政治上则应继续观察洛阳朝廷控制、昭宗及宗室命运与禅代进程。
