## 二、战争、边防与安全事实

### 1. 王景仁南侵与霍丘败退

- 本卷直接承接卷268末王景仁万余人侵庐、寿。吴军尚未集时，徐温仅以四千余人战于赵步而败退，陈绍返马力战才止住追兵；兵集后吴军在霍丘反败梁军。梁军此前在淮河浅津立标，霍丘守将朱景暗将标木移到深处；败军照标渡淮，溺死过半，吴军甚至把梁尸堆成京观。原文定位：`SRC-ZZTJ-269-1765765-P0012`“吳兵既集，復戰於霍丘，梁兵大敗”及“徙置深淵……溺死者太半”。

### 2. 荆南、蜀与岐南诏诸战线

- 高季昌试图夺取原属荆南的夔、万、忠、涪，先以水军攻夔州并用火船焚蜀浮桥。蜀以铁丝横江拒船，风向倒转使荆南军自受火攻，焚溺者甚众，俘斩五千；高季昌战舰中石受损，只能换小舟逃走。原文定位：`SRC-ZZTJ-269-1765765-P0020`“會風反，荊南兵焚溺死者甚眾……俘斬五千級”。
- 南诏寇黎州后，蜀军连续在潘仓嶂、山口城、武侯岭十三寨及大度河获胜。大度河一役明确记“浮斩数万级”，败兵争桥逃渡又因桥断溺死数万人；蜀将准备造浮桥继续追击时，蜀主下令撤军。原文定位：`SRC-ZZTJ-269-1765765-P0030`。
- 蜀对岐的推进从阶州、固镇、长城关等寨堡开始，继而在贞明元年取得固镇、阶州、成州、秦州、凤州；刘知俊围邠州半年不克，在秦州降蜀、家属已迁成都后率七十亲兵斩关投蜀。原文定位：`SRC-ZZTJ-269-1765765-P0031`；`SRC-ZZTJ-269-1765765-P0063`。
- 贞明二年蜀再次发动大规模伐岐，凤州一路十万、秦州一路十二万，合计二十二万。十月王宗绾军出大散关，大败岐军并取宝鸡；李继岌率二万人弃陇州投蜀，蜀军继围凤翔，但因大雪被召还。原文定位：`SRC-ZZTJ-269-1765765-P0085`“將兵十萬……將兵十二萬”；`SRC-ZZTJ-269-1765765-P0094`“俘斬萬計……帥其眾二萬”。

### 3. 魏博分镇、军变与梁晋河朔大战

- 贝州张源德不附晋并屡断镇定粮道，晋王先用五百骑昼夜袭取德州以孤立沧、贝，又夜取澶州；后李存审以五千围贝州，并应当地百姓请求征八县丁夫挖壕，使张源德三千兵不能夜夜出掠而妨碍耕作。原文定位：`SRC-ZZTJ-269-1765765-P0048`；`SRC-ZZTJ-269-1765765-P0053`。
- 刘鄩曾以空城草人欺敌，秘密经黄泽道西袭晋阳；连旬大雨使道路泥深，士卒患腹疾足肿，坠崖死者十之二三，马匹往返死近半。晋阳已有防备且刘军粮尽，奇袭失败；随后双方围绕临清、贝州、堂邑、莘县和粮道持续争夺。原文定位：`SRC-ZZTJ-269-1765765-P0050`。

### 4. 契丹扩张与幽州边防崩坏

## 五、跨卷连续性

- 向前：卷268最后一条即王景仁率万余兵侵庐、寿，本卷首段从徐温、朱瑾迎击王景仁继续展开并写到霍丘大败；卷268末刘守光逃离幽州，本卷随即写其途中被田父张师造擒获、最终在晋阳被处死。两条主线都严格按卷界续接。
- 向后：本卷末最明显的未决主线是契丹围幽州。周德威已告急，晋王在李嗣源等劝说下决定救援，李嗣源已军涞水、阎宝率镇定兵继进，但战果尚未出现；吴方面徐温迁镇升州、徐知诰转润州后的权力变化也刚展开。以上均只记录到本卷所见状态。
