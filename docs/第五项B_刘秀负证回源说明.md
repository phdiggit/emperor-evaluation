# 第五项B_刘秀负证回源说明

本任务只处理刘秀三条第五项B负证线索：韩歆、桓谭、申屠刚/廷杖刑辱。不处理李世民、刘庄，也不处理刘秀正证。

本任务不定档、不定分、不排名。

## 已成功回源

- `EVD-I5B-LIUXIU-NEG-HANXIN-001`：据《资治通鉴》卷四十三，建武十五年韩歆因直言被免，刘秀仍遣使责之，韩歆父子自杀，材料可支撑“不能容直言、谏臣保护失败”。
- `EVD-I5B-LIUXIU-NEG-HUANTAN-001`：据《后汉书》卷二十八上，桓谭极言谶非经，刘秀怒称“非圣无法，将下斩之”，材料可支撑“思想/谏诤型人才因反谶受到压制”。
- `EVD-I5B-LIUXIU-NEG-TINGZHANG-001`：据《后汉书》卷二十九，尚书近臣至于捶扑牵曳于前，群臣莫敢正言，材料可支撑“臣下表达安全与近臣系统受辱”。

## 仍待继续回源

本任务范围内三条刘秀负证均已找到公开古籍文本来源并转为证据卡。后续仍可继续复核不同版本文字和断句，但不得在本任务中拔高为极负。

## 相邻项切分摘要

- 韩歆线：B项只计不能容直言、谏臣保护失败、人才安全感破坏；灾异/饥凶预测及政策判断切第五项E或第二项B2。
- 桓谭线：B项只计思想/谏诤型人才因反谶受到压制；谶纬信念本身切第五项E，政治残酷性另切第五项D。
- 廷杖线：B项只计臣下表达安全、近臣/尚书系统受辱、群臣不敢正言；法理严察或政治残酷性分别切行政执行或第五项D。

三条证据卡均为 `strength=3`、`human_level=强负`，不得直接入分，待人工裁判。
