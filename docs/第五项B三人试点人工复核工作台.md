# 第五项B三人试点人工复核工作台

## 0. 使用说明

本文档是第五项B三人试点的人工复核工作台，不是正式评分表，不生成正式分数，不生成最终排名，不改写自动结算结论，也不替代人工裁判。

本文档基于当前 I5B 自动结算草案、split 详情页和 display-only warning 整理。自动结算只提供复核入口和阅读线索，正式定档必须由人工确认。

复核时必须遵守第五项B子项纯度：不得把战功、治绩、盛世光环、政权安全、司法残酷、边疆收益等跨项内容回填到第五项B。相邻项剥离只用于确认第五项B剩余影响，不用于扩大本项结论。

本轮只做三人试点：李世民 / 刘秀 / 刘庄。

建议人工裁判阅读顺序：

1. 先读本文档的总览和逐人复核清单。
2. 再打开 split 详情页，逐项核验自动特征、证据簇、`linked_*`、`cross_item_split_signals` 和 warning `matched_fields`。
3. 对每个待决策点标注“可采纳 / 需回源 / 需剥离 / 暂不进入正式定档”。
