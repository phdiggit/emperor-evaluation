# 总规则

本文件是阶段性执行总则。评分结构、总分、七大项边界与最终档位以 `docs/皇帝综合评价体系评分标准.md` 为上位标准；阶段性禁出分、禁排名和证据门槛仍按本文件执行。

## 总原则

先规则，后证据，再评分。任何评分都不得先继承旧结论，再倒找证据。

新体系的评价顺序是：

规则定义 → 子项边界 → 正负证触发词 → 检索留痕 → 回源证据卡 → 相邻项切分 → 负证拦截 → 定档定分

## 子项纯度校验

每条证据必须先判断落入哪个 item 与 subitem。证据不得因为人物整体印象、朝代整体成败或其他子项表现而跨项加分或扣分。

如果一条材料同时影响多个子项，必须记录 cross_item_split 或 scoring_effect，说明它在相邻项之间如何切分。

## 光环剥离

人物的知名度、开国身份、庙号谥号、后世评价、总体功业或总体恶名，不得直接替代具体证据。

正面光环不能自动覆盖负证；负面标签也不能自动抹除正证。每个子项必须回到可验证证据卡。

## 正负证双向检索

每个子项必须同时检索正证与负证。不能只检索支持既定印象的一侧。

矩阵检索至少区分：

- 人物 × 正证触发词
- 人物 × 负证触发词

检索结果必须能落到 search_logs 或 evidence_cards，不能只写“正证很多”“负证较少”这类不可审计表述。

## 证据强度与人工层级

正证层级：

- 极正
- 强正
- 中正
- 弱正

负证层级：

- 极负
- 强负
- 中负
- 弱负

`strength=4` 且 `polarity=positive` 时，`human_level` 必须是 `极正`。

`strength=4` 且 `polarity=negative` 时，`human_level` 必须是 `极负`。

## 负证拦截

负证拦截是全体系通用流程。任何子项只要出现强负或极负线索，都必须进入事件级拆分和相邻项切分。

强负/极负不得只作为笼统扣分依据，必须说明：

- 事件是什么。
- 行为主体是谁。
- 归因链条是否明确。
- 影响落在哪个子项。
- 是否切入相邻项。
- 是否足以触发定档拦截。

## 功臣与能臣处置

功臣、能臣相关负证必须先做分案归因，不能直接从“被杀”“被贬”“失势”推出极负。

至少需要区分：

- 皇帝主动清洗。
- 制度性处置。
- 战争或叛乱背景。
- 权臣、外戚、宦官、地方势力介入。
- 当事人自身违法、谋反、失职或政治站队。
- 史料叙述中的后见评价与事件事实。

只有完成分案归因后，才能判断是否构成对应子项的强负或极负。

## 旧账本隔离

旧评分不得回填新评分。旧排名、旧加总和旧正式定档结论不得进入新体系事实源。

旧资料如需保留，只能作为历史归档，不得作为评分依据。

## 全局总标尺口径

当前阶段采用方案 C 作为阶段性全局总标尺口径。

其规则是：

1. 先保留各子项相对档位和相对区间。
2. 不进入跨项数值总分。
3. 待七大项完成后统一映射。
4. 在此之前不生成总分排名、阶段总榜或总榜。
5. 第五项 B 仍不得正式出分。

该口径是阶段性规则，不是正式出分结果。

## 展示规则

默认不展示阶段总榜，除非用户明确要求。阶段性材料应优先展示证据卡、矩阵留痕、相邻项切分和负证拦截结果。
