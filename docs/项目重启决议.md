# 项目重启决议

皇帝综合评价体系进入重构阶段。旧版所有评分、加总、排名、正式定档结果全部废弃。

## 旧数据处置

旧数据只可作为历史归档，不得作为新评分依据，不得迁入新项目事实源，不得参与新评分流程。

废弃范围包括：

- 旧评分
- 旧加总
- 旧排名
- 旧正式定档结果

## 保留范围

新项目只保留可用于重建评价体系的方法和证据基础：

- 规则
- 标尺
- 方法论
- 子项边界
- 已回源史料短摘
- 来源定位
- 可验证证据卡

上述内容进入新体系时，必须能被审阅、复核和追溯。旧评分结论本身不具备继承效力。

## 新事实源与视图

新项目以 JSONL 为事实源、SQLite 为运行库、Markdown 为审阅导出视图。

- `data/*.jsonl` 保存可审计事实。
- `evidence_cache.sqlite` 由脚本生成，只用于运行和查询。
- Markdown 由脚本导出，只用于审阅，不作为手工维护主源。

## 新评分前置流程

所有新评分必须经过以下流程：

规则 → 正负证矩阵 → 证据卡 → 相邻项切分 → 负证拦截 → 定档定分

未经过矩阵检索、回源证据卡、相邻项切分和负证拦截的结论，不得进入正式定档定分。
