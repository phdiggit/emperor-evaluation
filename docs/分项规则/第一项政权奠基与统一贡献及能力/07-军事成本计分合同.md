# 第一项军事成本计分合同

本文件是第一项军事成本消费与换分的主题合同，承接[第一项规则](00-规则与计分合同.md)原§7.2；主链划分另读原§7.1、§8。只核对换分时读取本文件及其扣分映射；涉及C档重裁时再读共同认定合同。综合附加公式以[总纲§4.5](../../项目总纲/皇帝综合评价体系评分标准.md#45-综合分计入公式)为准。

### 7.2 成本认定与消费

第一项统一使用[军事成本评估合同](../../证据规则/军事成本评估合同.md)认定C0—C7、位置、状态、归责和阶段归并；成本C档与本项C1/C2能力子项不同。

- **范围**：本项主链内本人可归责的军事投入、军队损耗、组织毁损与重建负担归第一项。效率闭合点、A无新增或A=0不自动终止成本窗口。
- **排除不等于零**：第三项不适用状态不能代替第一项成本档；排除记录只能定位待核事实，不能直接转成裁决。
- **去重**：先按主链和个人责任阶段归并，再形成个人整体成本档，不逐战相加，不按A分账比例分成本，不向多人全额复制同一阶段。
- **独立评价**：成本档不机械降低五轴；失败能力反证与军力损耗分别举证。民生财政、社会及文明后果分别按第二、第四项实际窗口承接，不假定已覆盖，也不重复扣同一后果；平民死亡不转写为军队损失。
- **换分**：第一项拟在五轴合计端独立固定分档扣减，以0为原始分下限，再入条件附加公式；具体扣分映射另定，不引入第三项扣分表、ML负尾或E/EN安全结果。

**已启用扣分**：扣分映射、全池逐人成本裁决和去重核对已完成，正式结算与综合榜同步消费第一项净分。后续若裁决退回未闭合状态，正式读取必须阻断，不默认缺失成本为C0。

扣分最高80原始分，占240分量尺的三分之一；C0—C3保持低档，C4起随国家尺度承载与核心军事能力断裂递增加重。先保留五轴原始合计，再按下表扣除；净分下限为0，扣后按四舍五入保留一位小数。综合折算仍使用既有公式，以生效后的第一项净分作为S1。

执行入口：[逐人成本裁决](../../评分结算/第一项政权奠基与统一贡献及能力/06-军事成本正式裁决.json)及其[阅读视图](../../评分结算/第一项政权奠基与统一贡献及能力/06-军事成本正式裁决.md)；[扣分映射](../../../config/first-item/military-cost-debits.json)已确认。`first-item-cost-verify`只读校验并计算已闭合对象；`PROVISIONAL`或`LOWER_BOUND`均不生成确定净分，并报告未就绪，不写正式总分或总榜。全池裁决及去重闭合后，按`max(0, A+B1+B2+C1+C2−成本扣分)`同步正式结算与综合榜，不混合展示部分人物的净分与其他人物的未扣成本分。
