# 第一项：政权奠基与统一贡献及能力

五轴毛分上限240，正式净分扣除军事成本；人物裁决与去重由正式入口维护。

## 1. 适用范围与结构

第一项属于条件附加项。评建国、复国、统一主链的本人贡献及条件、组织、军事能力；只适用有实际可归责贡献者。既成王朝内部单纯皇权转移不适用，不表示夺权能力低。

窗口从本人首次参与并有贡献至相关贡献终止或核心链闭合；称帝受禅不自动切断。闭合后成熟扩张、防务归第三项。

| 子项 | 名称 | 上限 | 评价内容 |
|---|---|---:|---|
| A | 统一主链客观贡献 | 100 | 最终留下的稳定控制成果 |
| B1 | 创业难度与战略效率 | 50 | 起点、对手与完成速度 |
| B2 | 创业组织与政治整合 | 30 | 并行执行、专业覆盖与异质整合 |
| C1 | 本人军事统帅能力 | 40 | 本人战争组织、统帅与军事判断 |
| C2 | 本人前线指挥能力 | 20 | 本人亲临战区后的直接指挥兑现 |

事实可证不同能力，成果规模只在A计一次；部将结果可证A/B2，不转本人C1/C2。不适用不同于A=0，折算见[总则](../../项目总纲/皇帝综合评价体系评分标准.md)。

## 2. A：统一主链客观贡献（100）

### 2.1 尺度与公式

A只读主链最终稳定控制成果。起点、对手、速度、组织和本人能力分别由B1、B2、C承接；称帝、受禅、宫廷夺权或形式建国本身不产生A。

```text
macroregion = 100；major_region = 60；全国核心统一尺度 = 1000
有效控制信用 U = 新增稳定空间控制 + 50% × 恢复稳定空间控制
项目A池 = 100 × (min(1000, U) / 1000) ^ 0.65
```

区域覆盖可取0.05、0.10、0.25、0.50、0.75等比例，`ROUND_HALF_UP`一位小数。

### 2.2 基线、终点与共同创业

- **基线（baseline）**：只扣入链前已稳定拥有/继承/交付的控制，不将同链自获成果因后来受封称帝倒切为外生起点。
- **终点**：不取峰值；退出前已丧失且未被后继项目有效继承的不计，失败可A=0。
- **共同创业**：先合并有效控制、生成一次非线性A池，再按个人信用零和分账，不分人重跑0.65次方。只有同属第一项对象且有独立成果者参与，普通下属执行不分走最高责任中心A。
- **域外**：目录无法覆盖时用`external_equivalent_block`裁等价稳定规模，不另建全球州县库。

## 3. B1：创业难度与战略效率（50）

`B1 = 起点难度15 + 对手难度15 + 完成效率20`。

### 3.1 起点难度（15）

按本人入链时可调用军政资源裁起点；出身不换分，自建集团不倒灌，继承/摄政/禅代须计成熟机器。

| R档 | 定义 | 分值 |
|---|---|---:|
| R0 | 无有效独立资源 | 15 |
| R1 | 极小个人集团 | 13 |
| R2 | 地方据点或小型成建制部众 | 11 |
| R3 | 成熟区域军政机器 | 8 |
| R4 | 强藩、大型方面军或大区域机器 | 5 |
| R5 | 全国主要竞争机器 | 2 |
| R6 | 接近统一的成熟国家机器 | 0 |

### 3.2 对手难度（15）

O档的语义、实际窗口、体系边界、去重与最小证据统一使用[军事对手战争机器O档合同](../../证据规则/军事对手战争机器O档合同.md)。本项只按对手在实际竞争阶段相对己方形成的主链压力换分：取最强两个独立战争机器，第一强全值，第二强按50%。

| O档 | 本项分值 |
|---|---:|
| `O6` | 10 |
| `O5` | 8 |
| `O4` | 6 |
| `O3` | 4 |
| `O2` | 2 |
| `O1` | 1 |

母体、偏师、复起、外援与去重按公共O合同；外援改变竞争后，不同时取介入前高压力与介入后高效率。

### 3.3 完成效率（20）

**核心闭合点`T_core`**取最早同时满足下列条件的时点，不以最后一个残余被消灭为准：

1. 已取得并最终保持或传承的成果达到该阶段最终有效成果约90%。
2. 不再存在能争夺主链的O5/O6独立战争机器。
3. 尚存O4不再控制使核心统一不能成立的关键中心。
4. 剩余不超过约10%只属边缘尾项、局部残余或不能逆转格局的收尾。

尾项仍计A、不延长效率工期；成果回落至90%以下或O5/O6竞争极复起，原闭合点失效。

```text
期望完成年 = 4 + 8 × sqrt(效率阶段有效控制信用 / 1000)
速度比 = 实际阶段年数 / 期望完成年
```

| 速度比 | 效率分 |
|---:|---:|
| ≤0.75 | 20 |
| ≤1.00 | 18 |
| ≤1.25 | 16 |
| ≤1.50 | 14 |
| ≤2.00 | 11 |
| ≤2.50 | 8 |
| ≤3.00 | 5 |
| ≤4.00 | 2 |
| >4.00 | 0 |

阶段处理：

- **多阶段目标**：前一独立目标已闭合，随后转向新目标时，各阶段单算。个人最终效率分为`Σ（阶段效率分 × 阶段A有效控制信用）/ Σ阶段A有效控制信用`；铁木真等长期多目标项目不得从首次起兵一直计到最后扩张。
- **同代共同创业**：窗口高度重合且个人成果节点未拆清时，共用项目规模和`T_core`；不得因A分账少而缩短个人期望工期、机械判慢。
- **A终点信用为0**：效率分为0，真实起点难度与外部独立战争机器压力仍计分；快速夺权、称帝或最终全部丧失的短期占领不获效率分。
- **小型项目**：低起点、强敌、快速完成有限目标，可以A低而B1高，不能再次因规模小压低B1。

## 4. B2：创业组织与政治整合（30）

`B2 = 并行执行能力10 + 团队能力覆盖与组织杠杆10 + 异质整合能力10`。每轴L0—L5对应0、2、4、6、8、10分，评价组织如何运行，不累计团队绝对战果。

### 4.1 并行执行能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 主要靠本人逐项处理 |
| L1 | 2 | 有助手，但不能独立闭合关键方向 |
| L2 | 4 | 至少一个稳定独立责任中心 |
| L3 | 6 | 两个稳定责任中心，或主要国家功能可以并行 |
| L4 | 8 | 至少三个稳定责任中心，可跨战区/功能同时推进 |
| L5 | 10 | 多中心运行体系化，多个关键方向可长期同时推进，本人无需逐项现场控制 |

名将、官位和团队人数不直接计分。

### 4.2 专业覆盖与组织杠杆

检查能否把高难任务交给高级专业责任中心，以较低本人时间、现场控制和资源消耗取得高质量结果。关键领域包括战略、前线统帅、后勤财政兵员、行政接收、外交联盟情报、制度与国家组织。

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 缺少能独立承担关键任务的高级责任中心 |
| L1 | 2 | 只有单一助手或一般执行者 |
| L2 | 4 | 有一个高质量专业中心，但覆盖窄 |
| L3 | 6 | 至少两个重要领域有高级独立责任中心 |
| L4 | 8 | 多个高级领域形成稳定覆盖，可独立完成高难任务，本人主要承担最高层决策 |
| L5 | 10 | 多个关键领域均有高等级责任中心，并在高难竞争中反复以较低本人干预兑现关键结果 |

稳定、高效、低成本完成高难任务是正证；实际责任链断裂、集团失控和高额协调损失是负证。死亡、退出或换将不是高档前置条件。

### 4.3 异质整合能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 核心集团即严重排斥或分裂，无法形成共同执行 |
| L1 | 2 | 只能维持单一核心集团，外来力量多为短期依附 |
| L2 | 4 | 成功吸收一类外来或旧政权力量，但职责有限 |
| L3 | 6 | 多地域/旧集团可以共同工作，但仍明显分层或高度独立 |
| L4 | 8 | 多个异质集团能稳定承担核心军政职责 |
| L5 | 10 | 跨地域、族群、旧政权与降附机器被体系化重组，并持续为同一创业目标独立兑现成果 |

须证明稳定共同执行结果，不能只列族群、降将、士族或旧臣名单。

### 4.4 归责与证据

- 继承团队按实际调用，不因继承加减；后继高档须本人窗口新增、重组、再授权或高难调度，不重复算新建。
- B2不作A式零和，按各人的真实控制链举证，下级责任中心不复制国家全机器。
- 团队成果只证结构；A成果、B1环境、B2执行、C本人能力分别消费，主链外治理或人才表现不倒灌。

## 5. C1：本人军事统帅能力（40）

### 5.1 准入与证据

按公共战役的本人结果、角色、战役档、难度及人物归责取证，武将等级作横向复验；断链才回源，全生涯等级不直接换本项分数。

准入实际主帅、独立主将或具体后方战争统筹；后者须目标顺序、路线、多路/兵力后勤、进退、重组等决策与结果闭合因果。

普通遣将、选将任命批准、宽泛政治意图、事后奖惩、下属独立战术判断，以及无独立指挥责任的普通参战均不进入。战争必须属于本人主链；时间重合本身不够。

窗口按§7—§8；其他政权效力、主链后或独立战争不入本项能力。

### 5.2 档位与正负证据

| 档位 | 核心含义 | 分值 |
|---|---|---:|
| C1-0 | 无可用本人军事统帅责任证据 | 0 |
| C1-1-LOW / MID / HIGH | 基础统帅 | 4 / 7 / 10 |
| C1-2-LOW / MID / HIGH | 重要统帅 | 12 / 15 / 18 |
| C1-3-LOW / MID / HIGH | 优秀统帅 | 20 / 23 / 26 |
| C1-4-LOW / MID / HIGH | 顶级统帅 | 28 / 31 / 34 |
| C1-5-LOW / MID / HIGH | 历史级统帅 | 36 / 38 / 40 |

至多三个独立最高正锚，核对结果、难度D、角色、判断和跨情境复验；普通胜仗不堆历史级，单S级无复验不自动C1-5。

本人重大失败限高，同错复发压档，正负同强并存限稳定性；灾害、强令、史源冲突或归责未证不作败责，不设逐败固定扣分。

### 5.3 后方上限与缺证处理

全部合格证据均为后方统筹、没有本人实际战区或前线指挥时，最高`C1-2-HIGH = 18`；因缺少战场反馈下的统帅复验，不得进入优秀统帅及以上。

公共档案缺失不等于C1=0；有父战役/史料责任证据先补人物链，复核仍无责任才结算0。

## 6. C2：本人前线指挥能力（20）

### 6.1 准入

须主链内亲临战区、实际接战攻守进退指挥及结果闭合；随军、名义亲征、勇武、遣将或下属成果不代证。

### 6.2 计分

`C2 = 前线峰值P（0—12）+ 前线复验R（0—8）− 重大可归责负证N（0—4）`，最终限制在0—20。

**P：前线峰值**

| P | 典型能力锚 |
|---:|---|
| 0 | 无合格本人前线锚 |
| 3 | C/B级、D0—D1有限前线责任，或C/D2下限 |
| 5 | B/D2或A/D0—D1 |
| 7 | B/D3或A/D2 |
| 9 | A/D3或S-/D2 |
| 11 | A/D4、S-/D3或S/D2 |
| 12 | S-/D4、S/D3及以上极高前线锚 |

结果档和难度同时读取，国家终局不自动抬高P。

**R：前线复验**

| R | 复验要求 |
|---:|---|
| 0 | 只有一个可用前线锚 |
| 2 | 一个独立B/D2以上复验 |
| 4 | 第二个A/D2以上，或两个稳定中档复验 |
| 5—6 | 第二个高质量A/D3、S-/D2以上锚，并有其他稳定复验 |
| 7—8 | 多个独立A/D3以上高质量锚，跨战区、对手或战争形态持续成立 |

同一父战役吸收阶段不得拆成多个复验。

**N：重大可归责负证**

| N | 负证结构 |
|---:|---|
| 0 | 无明显可归责重大前线失败 |
| 1 | 单个较轻失败或单个mixed结果 |
| 2 | 一次A级重大失败，或两次普通失败 |
| 3 | 一次重大失败叠加其他失败，或三次以上普通失败 |
| 4 | S级灾难性失败、明确重大指挥过失，或多次重大失败形成稳定性问题 |

外部灾害、上级强令、史源冲突、已判非本人责任，以及与军事能力无关的伦理、屠杀或战争行为负面不进入N。

### 6.3 结果与C1边界

| 档位 | 分数 | 含义 |
|---|---:|---|
| C2-5 | 17—20 | 历史级前线指挥 |
| C2-4 | 13—16 | 顶级前线指挥 |
| C2-3 | 9—12 | 优秀前线指挥 |
| C2-2 | 5—8 | 重要前线指挥 |
| C2-1 | 1—4 | 有限前线能力 |
| C2-0 | 0 | 无合格本人前线证据，或有限正向被重大负证完全抵消 |

C2=0须区分没有本人责任、战绩在窗外、下属战果不能转写、有限正向被重大负证抵消，不能统称“没有军事能力”。

同战可分别证C1综合统帅和C2前线；后方只证C1，任将不代前线，有限P可被N抵至0。

## 7. 跨项与军事成本边界

### 7.1 主链归属

五轴共用主链窗口；`T_core`只结束效率计时，不排同链后续贡献/失败。成熟扩张、防务及独立外征归第三项，不按时间重合并链。

第一项成果、控制、成本退出第三项A/B/D，C只留`capability-only`；独立后续链另按第三项准入。逐人切分见§8。

### 7.2 成本认定与消费

见[军事成本计分合同](07-军事成本计分合同.md#first-cost)。
