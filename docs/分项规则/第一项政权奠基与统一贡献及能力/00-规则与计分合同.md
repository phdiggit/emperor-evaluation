# 第一项：政权奠基与统一贡献及能力

当前执行合同。A、B1、B2、C1、C2已完成全量裁决，原始量尺合计240分。军事成本共用认定合同，扣分映射、全池逐人裁决及跨项去重均已闭合；正式总分为五轴合计扣除军事成本后的净分。

## 1. 适用范围与结构

本项评价本人在建国、复国或统一主链中的实际贡献，以及完成贡献时的起点、竞争条件、组织和军事能力。第一项属于条件附加项，只适用于存在实际可归责贡献者；既成王朝内部单纯的个人皇权转移不适用，不表示夺权能力低下。

**责任窗口**从本人首次进入本条主链并产生可归责贡献开始，至本人相关贡献终止或核心建国、统一主链闭合。称帝、称王、称汗、受禅不自动截断；闭合后的成熟帝国扩张、国防与边疆经营原则上进入第三项。

| 子项 | 名称 | 上限 | 评价内容 |
|---|---|---:|---|
| A | 统一主链客观贡献 | 100 | 最终留下的稳定控制成果 |
| B1 | 创业难度与战略效率 | 50 | 起点、对手与完成速度 |
| B2 | 创业组织与政治整合 | 30 | 并行执行、专业覆盖与异质整合 |
| C1 | 本人军事统帅能力 | 40 | 本人战争组织、统帅与军事判断 |
| C2 | 本人前线指挥能力 | 20 | 本人亲临战区后的直接指挥兑现 |

同一事实可以证明不同能力，但客观成果规模只在A结算一次。部将战果可支持A和B2，不能转写为君主个人C1/C2能力。第一项不适用与A=0不同，综合换算按[评分总则](../../项目总纲/皇帝综合评价体系评分标准.md)执行。

阅读顺序：A成果 → B1难度与速度 → B2组织 → C1/C2能力 → 跨项与成本边界 → 逐人主链边界。

## 2. A：统一主链客观贡献（100）

### 2.1 尺度与公式

A只读主链最终稳定控制成果。起点、对手、速度、组织和本人能力分别由B1、B2、C承接；称帝、受禅、宫廷夺权或形式建国本身不产生A。

```text
macroregion = 100；major_region = 60；全国核心统一尺度 = 1000
有效控制信用 U = 新增稳定空间控制 + 50% × 恢复稳定空间控制
项目A池 = 100 × (min(1000, U) / 1000) ^ 0.65
```

区域内部允许0.05、0.10、0.25、0.50、0.75等稳定覆盖比例；结果按`ROUND_HALF_UP`保留1位。固定空间单位避免跨时代人口、财赋估算失真；恢复按50%折算，0.65次方体现规模递减收益，避免过度抬高小型项目。

### 2.2 基线、终点与共同创业

- **基线（baseline）**：仅扣除进入连续责任链前已稳定拥有、继承或被正式交付的控制。同链亲手取得的成果不能因后来受封、称王、称帝而倒切为外生起点。嬴政继承秦国、杨坚接管北周属基线；刘邦从沛县起兵后取得的关中、巴蜀仍属本人同链贡献。
- **终点**：不取历史峰值。本人退出前已彻底丧失且未被后继项目有效继承的成果不计，失败创业可为A=0。苻坚须考虑383—385年的崩解，不能锁定376年北方统一峰值。
- **共同创业**：同一连续项目先汇总有效控制信用，只生成一次非线性A池，再按个人客观控制信用零和分账；不得分人重跑0.65次方。普通下属执行不自动扣减最高责任中心的A，只有同属第一项评价对象且具有独立可归责成果者参与分账。
- **域外项目**：中国区域目录不能覆盖时，可建`external_equivalent_block`，按等价稳定控制规模裁决，不要求建立全球州县数据库。

共同创业包括李渊/李世民、宇文泰/宇文邕、司马昭/司马炎、李克用/李存勖/李嗣源、铁木真/窝阔台/蒙哥/忽必烈，以及努尔哈赤/皇太极/多尔衮/福临/玄烨。

## 3. B1：创业难度与战略效率（50）

`B1 = 起点难度15 + 对手难度15 + 完成效率20`。

### 3.1 起点难度（15）

按本人首次进入主链并承担可归责贡献时可直接调用的军政资源裁决。贫寒出身不直接加分，后来亲手形成的集团不能倒灌为先天资源；继承、摄政、辅政、禅代者必须计入当时可调用的成熟国家机器。

| R档 | 定义 | 分值 |
|---|---|---:|
| R0 | 无有效独立资源 | 15 |
| R1 | 极小个人集团 | 13 |
| R2 | 地方据点或小型成建制部众 | 11 |
| R3 | 成熟区域军政机器 | 8 |
| R4 | 强藩、大型方面军或大区域机器 | 5 |
| R5 | 全国主要竞争机器 | 2 |
| R6 | 接近统一的成熟国家机器 | 0 |

### 3.2 对手难度（15）

O档的语义、实际窗口、体系边界、去重与最小证据统一使用[军事对手战争机器O档合同](../../证据规则/军事对手战争机器O档合同.md)。本项只按对手在实际竞争阶段相对己方形成的主链压力换分：取最强两个独立战争机器，第一强全值，第二强按50%。

| O档 | 本项分值 |
|---|---:|
| `O6` | 10 |
| `O5` | 8 |
| `O4` | 6 |
| `O3` | 4 |
| `O2` | 2 |
| `O1` | 1 |

典型消费锚：项羽之于刘邦、唐初东突厥之于李唐为O6；窦建德、王世充之于唐及袁绍之于曹操为O5；秦统一总攻期楚、赵原则上为O4。这些锚不替代公共六档定义。母体与偏师、复起残部、外援及同体系去重按公共合同；外援改变竞争结构时，不得同时取介入前高O压力和介入后高效率。

### 3.3 完成效率（20）

**核心闭合点`T_core`**取最早同时满足下列条件的时点，不以最后一个残余被消灭为准：

1. 已取得并最终保持或传承的成果达到该阶段最终有效成果约90%。
2. 不再存在能争夺主链的O5/O6独立战争机器。
3. 尚存O4不再控制使核心统一不能成立的关键中心。
4. 剩余不超过约10%只属边缘尾项、局部残余或不能逆转格局的收尾。

唐取624年前后，628梁师都属尾项；刘邦须到前202年项羽终局；刘秀不能在公孙述仍据巴蜀核心时凭面积提前闭合。尾项仍计A，不延长本阶段效率工期；若成果跌回90%以下或O5/O6竞争极复起，原闭合点失效。

```text
期望完成年 = 4 + 8 × sqrt(效率阶段有效控制信用 / 1000)
速度比 = 实际阶段年数 / 期望完成年
```

| 速度比 | 效率分 |
|---:|---:|
| ≤0.75 | 20 |
| ≤1.00 | 18 |
| ≤1.25 | 16 |
| ≤1.50 | 14 |
| ≤2.00 | 11 |
| ≤2.50 | 8 |
| ≤3.00 | 5 |
| ≤4.00 | 2 |
| >4.00 | 0 |

全国级项目期望12年；U=100约6.5年，U=50约5.8年。另按以下情形处理：

- **多阶段目标**：前一独立目标已闭合，随后转向新目标时，各阶段单算。个人最终效率分为`Σ（阶段效率分 × 阶段A有效控制信用）/ Σ阶段A有效控制信用`；铁木真等长期多目标项目不得从首次起兵一直计到最后扩张。
- **同代共同创业**：窗口高度重合且个人成果节点未拆清时，共用项目规模和`T_core`；不得因A分账少而缩短个人期望工期、机械判慢。
- **A终点信用为0**：效率分为0，真实起点难度与外部独立战争机器压力仍计分；快速夺权、称帝或最终全部丧失的短期占领不获效率分。
- **小型项目**：低起点、强敌、快速完成有限目标，可以A低而B1高，不能再次因规模小压低B1。

## 4. B2：创业组织与政治整合（30）

`B2 = 并行执行能力10 + 团队能力覆盖与组织杠杆10 + 异质整合能力10`。每轴L0—L5对应0、2、4、6、8、10分，评价组织如何运行，不累计团队绝对战果。

### 4.1 并行执行能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 主要靠本人逐项处理 |
| L1 | 2 | 有助手，但不能独立闭合关键方向 |
| L2 | 4 | 至少一个稳定独立责任中心 |
| L3 | 6 | 两个稳定责任中心，或主要国家功能可以并行 |
| L4 | 8 | 至少三个稳定责任中心，可跨战区/功能同时推进 |
| L5 | 10 | 多中心运行体系化，多个关键方向可长期同时推进，本人无需逐项现场控制 |

名将、官位和团队人数不直接计分。

### 4.2 专业覆盖与组织杠杆

检查能否把高难任务交给高级专业责任中心，以较低本人时间、现场控制和资源消耗取得高质量结果。关键领域包括战略、前线统帅、后勤财政兵员、行政接收、外交联盟情报、制度与国家组织。

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 缺少能独立承担关键任务的高级责任中心 |
| L1 | 2 | 只有单一助手或一般执行者 |
| L2 | 4 | 有一个高质量专业中心，但覆盖窄 |
| L3 | 6 | 至少两个重要领域有高级独立责任中心 |
| L4 | 8 | 多个高级领域形成稳定覆盖，可独立完成高难任务，本人主要承担最高层决策 |
| L5 | 10 | 多个关键领域均有高等级责任中心，并在高难竞争中反复以较低本人干预兑现关键结果 |

稳定、高效、低成本完成高难任务是正证；实际责任链断裂、集团失控和高额协调损失是负证。死亡、退出或换将不是高档前置条件。

### 4.3 异质整合能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 核心集团即严重排斥或分裂，无法形成共同执行 |
| L1 | 2 | 只能维持单一核心集团，外来力量多为短期依附 |
| L2 | 4 | 成功吸收一类外来或旧政权力量，但职责有限 |
| L3 | 6 | 多地域/旧集团可以共同工作，但仍明显分层或高度独立 |
| L4 | 8 | 多个异质集团能稳定承担核心军政职责 |
| L5 | 10 | 跨地域、族群、旧政权与降附机器被体系化重组，并持续为同一创业目标独立兑现成果 |

须证明稳定共同执行结果，不能只列族群、降将、士族或旧臣名单。

### 4.4 归责与证据

- **继承团队**：继承本身不加减分，实际调用既有责任中心完成高难任务可以证明能力；人才多不等于L5。连续多代不能把同一机器都算作本人新建，后继高档须有本人窗口内的新增、重组、再授权或高难调度。
- **共同创业**：B2不作A式零和分账，同一团队可按不同人物的实际控制关系分别举证。李渊可评价其对李世民、李靖等责任中心的使用；李世民限秦王府、行台及直接责任链，不能复制中央整套机器。
- **证据边界**：团队成果可证明责任中心，但不再构成独立成果加分。A读成果、B1读环境、B2读执行结构、C读本人能力，各取不同含义。主链闭合后的治理、远征、边疆组织和后续人才表现不得倒灌。

## 5. C1：本人军事统帅能力（40）

### 5.1 准入与证据

C1评价本人在主链中的战争组织、统帅与军事判断。证据依次取公共战役登记的本人结果、角色、战役档和难度，已完成人物路由与归责，公共武将等级横向校验；断链时回到已通读史料补责任。全生涯武将等级不能直接换算本项分数。

合格责任包括实际主帅、可验证的独立主将方向，以及虽在后方但可追踪的**具体战争统筹**。后者须以目标顺序、进军路线、多路配置、兵力后勤、接战撤退时机、指挥链重组或阶段目标等具体决策，与战争结果闭合因果链。

普通遣将、选将任命批准、宽泛政治意图、事后奖惩、下属独立战术判断，以及无独立指挥责任的普通参战均不进入。战争必须属于本人主链；时间重合本身不够。

窗口例外：赵匡胤后周淮南战绩不入北宋创业；耶律阿保机916年后灭渤海转第三项；皇太极朝鲜、铁木真及窝阔台中西亚、杨坚突厥战争不入各自中国统一链；淝水之战在苻坚北方统一闭合后，不倒灌C1。

### 5.2 档位与正负证据

| 档位 | 核心含义 | 分值 |
|---|---|---:|
| C1-0 | 无可用本人军事统帅责任证据 | 0 |
| C1-1-LOW / MID / HIGH | 基础统帅 | 4 / 7 / 10 |
| C1-2-LOW / MID / HIGH | 重要统帅 | 12 / 15 / 18 |
| C1-3-LOW / MID / HIGH | 优秀统帅 | 20 / 23 / 26 |
| C1-4-LOW / MID / HIGH | 顶级统帅 | 28 / 31 / 34 |
| C1-5-LOW / MID / HIGH | 历史级统帅 | 36 / 38 / 40 |

每人优先读至多三个独立最高正向锚，同时核对结果、难度D、本人角色、关键判断及跨对手、战区或战争形态复验。战果数量不累加；多个普通B级胜仗不能堆成历史级，单个著名S级胜仗无复验也不自动达C1-5。

主链内可归责失败、混合结果和错误判断必须纳入：重大败绩限制高档，同类错误反复进一步压档，同等级正负长期并存下调稳定性。外部灾害、上级强令、史源冲突或无法证明本人责任的结果不作能力败责；不设固定“败一次扣X分”。

### 5.3 后方上限与缺证处理

全部合格证据均为后方统筹、没有本人实际战区或前线指挥时，最高`C1-2-HIGH = 18`；因缺少战场反馈下的统帅复验，不得进入优秀统帅及以上。

执行锚：司马炎灭吴全国统筹18；李渊晋阳南下与关中统筹12；玄烨三藩—台湾统筹12，不继承图海、赖塔、施琅前线难度。嬴政未闭合具体战争统筹为0；杨坚突厥统筹在窗外、灭陈未闭合本人统帅责任为0。

公共人物登记缺失不等于C1=0；父战役、通读史料或已验收材料能证明责任时，先补人物链再裁决。李雄补出破孙阜、郫城诱伏、断成都运道和取成都后为26。只有复核后仍无可用本人责任，才可结算0。

## 6. C2：本人前线指挥能力（20）

### 6.1 准入

须同时满足主链内战争、本人亲临相关战区、实际承担接战攻守进退部署或临场指挥责任，以及结果可由战役登记或已验收史料闭合。仅随军、名义亲征、个人勇武、遣将批准选将、后方统筹、团队成果或下属独立判断均不进入，主链后的第三项战争也不进入。

### 6.2 计分

`C2 = 前线峰值P（0—12）+ 前线复验R（0—8）− 重大可归责负证N（0—4）`，最终限制在0—20。

**P：前线峰值**

| P | 典型能力锚 |
|---:|---|
| 0 | 无合格本人前线锚 |
| 3 | C/B级、D0—D1有限前线责任，或C/D2下限 |
| 5 | B/D2或A/D0—D1 |
| 7 | B/D3或A/D2 |
| 9 | A/D3或S-/D2 |
| 11 | A/D4、S-/D3或S/D2 |
| 12 | S-/D4、S/D3及以上极高前线锚 |

结果档和难度同时读取，国家终局不自动抬高P。

**R：前线复验**

| R | 复验要求 |
|---:|---|
| 0 | 只有一个可用前线锚 |
| 2 | 一个独立B/D2以上复验 |
| 4 | 第二个A/D2以上，或两个稳定中档复验 |
| 5—6 | 第二个高质量A/D3、S-/D2以上锚，并有其他稳定复验 |
| 7—8 | 多个独立A/D3以上高质量锚，跨战区、对手或战争形态持续成立 |

同一父战役吸收阶段不得拆成多个复验。

**N：重大可归责负证**

| N | 负证结构 |
|---:|---|
| 0 | 无明显可归责重大前线失败 |
| 1 | 单个较轻失败或单个mixed结果 |
| 2 | 一次A级重大失败，或两次普通失败 |
| 3 | 一次重大失败叠加其他失败，或三次以上普通失败 |
| 4 | S级灾难性失败、明确重大指挥过失，或多次重大失败形成稳定性问题 |

外部灾害、上级强令、史源冲突、已判非本人责任，以及与军事能力无关的伦理、屠杀或战争行为负面不进入N。

### 6.3 结果与C1边界

| 档位 | 分数 | 含义 |
|---|---:|---|
| C2-5 | 17—20 | 历史级前线指挥 |
| C2-4 | 13—16 | 顶级前线指挥 |
| C2-3 | 9—12 | 优秀前线指挥 |
| C2-2 | 5—8 | 重要前线指挥 |
| C2-1 | 1—4 | 有限前线能力 |
| C2-0 | 0 | 无合格本人前线证据，或有限正向被重大负证完全抵消 |

C2=0须区分没有本人责任、战绩在窗外、下属战果不能转写、有限正向被重大负证抵消，不能统称“没有军事能力”。

同一战役可分别证明C1综合统帅能力与C2直接前线兑现。后方统筹只能支持C1，因此司马炎、李渊、玄烨可有C1而C2=0；嬴政用将不代替王翦、王贲前线能力；刘崇即使有P，也可被重大负证抵消至0。

## 7. 跨项与军事成本边界

### 7.1 主链归属

五轴共用第一项主链窗口。`T_core`只结束对应成果的效率计时，后续同链取得、整合、指挥及失败仍按各轴消费；A无新增或为0不排除同链失败。成熟帝国扩张、边疆、国防、外部征服和常态军事制度运行原则上归第三项，独立战争不因时间重合并入第一项。

第一项父链的结果、控制与成本退出第三项A/B/D；第三项C仅可保留`capability-only`能力佐证，不作当前结果任务。后续及独立链仍须按第三项各轴合同成立，不能自动得分。逐人切分见第8节。

### 7.2 成本认定与消费

第一项统一使用[军事成本评估合同](../../证据规则/军事成本评估合同.md)认定C0—C7、位置、状态、归责和阶段归并；成本C档与本项C1/C2能力子项不同。

- **范围**：本项主链内本人可归责的军事投入、军队损耗、组织毁损与重建负担归第一项。效率闭合点、A无新增或A=0不自动终止成本窗口。
- **排除不等于零**：第三项不适用状态不能代替第一项成本档；排除记录只能定位待核事实，不能直接转成裁决。
- **去重**：先按主链和个人责任阶段归并，再形成个人整体成本档，不逐战相加，不按A分账比例分成本，不向多人全额复制同一阶段。
- **独立评价**：成本档不机械降低五轴；失败能力反证与军力损耗分别举证。民生财政、社会及文明后果分别按第二、第四项实际窗口承接，不假定已覆盖，也不重复扣同一后果；平民死亡不转写为军队损失。
- **换分**：第一项拟在五轴合计端独立固定分档扣减，以0为原始分下限，再入条件附加公式；具体扣分映射另定，不引入第三项扣分表、ML负尾或E/EN安全结果。

**已启用扣分**：扣分映射、全池逐人成本裁决和去重核对已完成，正式结算与综合榜同步消费第一项净分。后续若裁决退回未闭合状态，正式读取必须阻断，不默认缺失成本为C0。

扣分最高40原始分，占240分量尺的六分之一；常规投入低扣，长期国家尺度承载与核心军事能力断裂递增。先保留五轴原始合计，再按下表扣除；净分下限为0，扣后按四舍五入保留一位小数。综合折算仍使用既有公式，以生效后的第一项净分作为S1。
