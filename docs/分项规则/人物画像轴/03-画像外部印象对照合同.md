# 画像外部印象对照合同

> 本文是[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)的职责拆分章节；共同字段与发布边界见[共同数据与发布合同](00-共同数据与发布合同.md)。本次拆分只改变合同物理位置，不改变评分语义、正式数据或验收结论。

视频或大众印象对照必须逐字段映射，不能拿外部总名次作标准答案：

| 外部常见指标 | 本画像允许对照 | 禁止做法 |
|---|---|---|
| 智 | C1、C2分别对照 | 用“聪明”总评替代战略与纠错证据 |
| 劳 | 非计分履职侧写及各轴落实深度 | 用工作时长、诏令数量或本人超负荷替代任何能力轴 |
| 人事管理 | C3 | 只列名臣，或因英主名望豁免错误清洗和授权失控 |
| 军事外交 | M1、M2分别对照；可另生成临时映射 | 把国力、版图、名将、历史影响和本人能力混为一分 |
| 经济、财政、民生 | 净收益第二项 | 不设置独立画像结果档；财政行为另证战略、学习、设计或组织能力命题后进入相应轴，不从结果换算能力 |
| 民心、社会联盟 | M4及第四项A结果旁证 | 用第四项总分、开国团队承担率或宣传性民心叙事直接换分 |
| 欲望自控 | 辅助特质标签 | 把普通爱好道德化，或把株连、集权等C5事实混入 |
| 德、气量、尊严 | 只能拆成C2、C5、M4或非计分标签 | 直接映射为一个道德分 |
| 国力、历史影响 | 不属于人物画像主轴 | 从国家结果反推人物能力或人格 |

外部对照报告固定分为：`方向一致`、`强度差异`、`构念错位`、`证据不足`、`明显反转`。不得用“项目不符合大众印象”本身判定项目错误，也不得以项目分数天然正确为前提回避合同漏项。
