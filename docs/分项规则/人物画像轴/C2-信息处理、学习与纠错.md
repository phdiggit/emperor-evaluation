# 人物画像分项规则：C2 信息处理、学习与纠错

本轴不只评价“犯错以后能否认错”。“能否获得真实信息”是独立准入机制；每条`SCORING_PARENT`必须先按其真实过程裁为下列一种生命周期，不得强迫所有材料套入同一个“原判断错误—纳谏—改正”模板：

1. `TRUTH_ACQUISITION`：存在真实的不确定问题或失真信息风险；本人主动调查、复核、交叉核验、比较相互冲突的报告，或识别表面指标背后的真实代价；本人据此形成或修正判断并落实为选择，且有后续事实、复核或同类事项验证。此类父链不要求本人先犯错，但只有设置渠道、一般求言、获得一份正确报告或臣下独立查明事实而未见本人如何辨别，均不能准入。
2. `ERROR_CORRECTION`：本人已有判断、政策或行为；可信反馈、反证或结果信号明确到达；材料能够说明本人如何理解该反馈、判断或行为如何改变，并由执行、复验或后续同类事项证明更新真实发生。一次纳谏、一次认错、罪己诏、被迫服从制度复核或笼统“从善如流”，至多形成候选，不能自动成为闭合父链。
3. `REFUSAL_OR_RECURRENCE`：本人有现实的信息或反证获取机会，可信反馈已经到达，却选择性采信、曲解、拒绝核验、只换人不改认知机制，或在可比条件下同构错误复发。必须闭合本人归责与可行替代；材料稀疏、没有反馈机会、臣下主导、政策失败或信息渠道不安全本身都不是C2负证。

同一事件可同时含信息获取、认知更新和权力处置，但必须拆清独立命题：C2只消费本人如何求真、理解、更新或拒绝更新；进谏者是否安全、惩罚是否合比例、是否报复清洗以及最高权力是否受程序约束统一留C5。只有两个命题各自闭合时才允许辅助投影，不能因“纳谏”一事在C2、C5重复取得同一方向收益。

C2强度采用绝对表现而非相对盛衰判断。人物级裁决须人工比较：合格生命周期在真实观察机会中的出现频率、独立对象与领域、覆盖阶段、本人辨别和理解份额、更新是否落实、后续是否避免复发，以及正负生命周期的全生涯分布。“早年善纳谏、晚年退化”只可作为阶段描述；除非晚年闭合具体的拒绝反馈或同构复发，不能单独作为负证。反过来，长期“纳谏很多”若没有列出具体求真或知错能改周期，也不能作为正向绝对强度。

`G4/G5`必须列出多个具名、相互独立的合格生命周期及各自直接锚点，并完成反例暴露和后续复验；其中至少应能够观察真实信息的取得或辨别，而不能全部由一般进谏次数构成。`G5`还须证明这种能力跨领域、跨主要阶段及不同约束反复成立并达到历史罕见，不能以父链条数、最高`MI`、名望或一句持续性概括替代。单一完整周期通常只能证明该能力曾出现；多个同一政策、同一战争或同一谏臣的转述仍只算一个生命周期。

本地规范入口是发现和反查入口，不是均匀的全生涯观察样本。第二项B2只证明制度化信息与纠错接口是否运行；第五项A2已经闭合的本人行为链可以直接复用；C1、M1、M2、C5及五项其他材料只有在同一事件另行闭合上述C2命题时才可辅助投影，任何既有档位、分数、方向或`MI`均不得换算。拟发布`G4/G5`时，若本地材料不能覆盖主动求真、反馈纠错、主要阶段和可暴露反例的观察窗口，必须沿已有史源通读或作有界联网补证；仍无法闭合时标为`MATERIAL_DENSITY_LIMITED`，不得发布高置信度高档。

C2必须采用“编年观察机会—决策状态转移”覆盖账。先以实际掌权窗口按年代排出阅读队列，再按“生涯阶段×决策领域”记录真实观察机会；不得先以正负方向、名望或关键词筛人。每个稳定入口或等价事实单元只能进入`SCORING_PARENT`、`BACKGROUND_VALIDATION`、`AXIS_OUT_WITH_REASON`、`UNRESOLVED_EVIDENCE_GAP`四态之一；正向与反向观察窗分别记录。`SCORING_PARENT`必须能够逐段回答“原认知或不确定问题—新信息或反证—本人解释—判断或行为是否改变—执行—后续复验或同构复发”。只见行为变化、战后换路、政策结果、一次‘从之’或一般信息渠道时，不得倒推认知状态。

C2潜在高档重开采用统一的史源预算上界：每名候选先完整消费全部本地规范入口，再最多新增四个一手材料单元，二者取并集；本地规范入口不占新增配额，也不得被四单元补读替换或丢弃。短任且君主中心正文不超过四卷时连续读完整实际掌权窗口；长任在阅读前固定早期、中期、晚期和最大压力或失败四个连续卷或本纪年段，不以关键词命中选择。若本纪只载结果、确实不能定位认知过程，可用一个具体事件列传替换其中一个单元，但新增总数仍不得超过四。为保持人物间史源口径一致，不使用专为单一君主编纂的政要、言行汇编或同类专人型材料；《贞观政要》不进入C2父链或覆盖并集。达到上界后正负观察窗或阶段领域仍未闭合，必须保留`EVIDENCE_LIMITED`并登记缺口，不得为升档继续追加史料；该预算只约束同轮潜在高档复核，不把四个单元或读满预算换算为档位。

本地财政民生、军事行动或其他定向摘要即使已经逐份消费，也只能证明相应入口已检查，不能证明用人、司法、继承宗室、宫廷信息、调查核验等非定向窗口已经覆盖。人物若只完成定向摘要回读，最多发布`E1/E2`有界画像；只有主要适用阶段、主要决策领域、正向与反向观察窗均由连续君主中心正文或稳定等价直接材料覆盖，才可发布全貌级`E3`。无合格父链或主要窗口仍空缺者必须标`EVIDENCE_LIMITED`，并具体说明已观察模式、未覆盖阶段或领域，以及什么新增材料可能改档；不得用统一中性档填补空白。

无合格父链或只有稀薄材料时仍按合同发布低置信度档位，但该档位只能概括已观察到的模式，不得把“没有材料”解释为能力低下，不得把所有无父链人物统一放入同一默认档位。`grade_basis`与`position_basis`必须分别写明本人已观察事实、适用边界、缺口以及什么新增材料可能改变裁决。
