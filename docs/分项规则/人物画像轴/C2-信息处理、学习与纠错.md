# 人物画像分项规则：C2 信息处理、学习与纠错

C2评求真与认知更新；`SCORING_PARENT`按真实过程选以下生命周期，不要求先犯错：

1. `TRUTH_ACQUISITION`：不确定问题/失真风险—本人调查、复核或辨别冲突—形成/修正判断并作选择—后续验证。只有渠道、求言、正确报告或臣下查明而无本人辨别不准入。
2. `ERROR_CORRECTION`：本人原判断/行为—可信反馈到达—本人理解与更新—执行/后续复验。一次纳谏、认错、罪己诏或被迫复核只作候选。
3. `REFUSAL_OR_RECURRENCE`：有信息机会且反馈已达，却选择性采信、曲解、拒核、只换人不改机制或同构复发；须证本人归责与可行替代。缺料、无反馈机会、臣下主导、政策失败或渠道不安全本身不算负证。

同事件拆独立命题：求真、理解与更新归C2；进谏安全、惩罚比例、报复及程序约束归C5。两命题分别闭合才可辅助投影，不重复消费纳谏收益。

按绝对表现人工比较生命周期频率、真实观察机会、独立领域、阶段、本人理解份额、更新落实、复发及全生涯正负分布。早善晚退须具体拒绝反馈/复发才作负证；“纳谏多”须有具体周期才作正证。

`G4/G5`须多个具名独立生命周期与直接锚，完成反例和后续复验，至少含真实信息的取得/辨别，不只计进谏次数。`G5`另证跨域、主要阶段、不同约束下反复历史罕见；父链数、最高`MI`或名望不代证。同政策、战争或谏臣转述只计一周期。

`G5`不要求无错、无负链或穷尽全域。`G5-LOW`可有同构复发、晚退或缺窗，但主动求真、重开决定、纠错制度化须跨阶段与约束反复成立，困难情境未推翻主模式；反证限制其进入`G5-MID/HIGH`。仅个案、一般纳谏或名臣纠偏不准入。全池`G5=0`须检查门槛是否不可达，不按名额抬档。

本地入口不是均匀观察样本：B2只证制度接口，五A2已闭合本人链可复用，其他轴须另证C2命题；不转换档位、分数、方向或`MI`。`G4/G5`缺求真、纠错、主要阶段或反例窗口时，沿史源通读/有界联网补证；仍不足标`MATERIAL_DENSITY_LIMITED`，不发布高置信度高档。

按实际掌权年代排队，以“阶段×领域”记录正反观察机会，不先按方向、名望或关键词筛人。每个稳定事实单元只进`SCORING_PARENT`、`BACKGROUND_VALIDATION`、`AXIS_OUT_WITH_REASON`、`UNRESOLVED_EVIDENCE_GAP`之一。计分链须闭合“原认知/问题—新信息—本人解释—判断/行为变化—执行—复验/复发”；行为变化、结果或一次从之不反推认知。

潜在高档同轮重开：全部本地入口＋最多四个新增一手单元，本地不占配额且不得被替代。短任君主中心正文≤四卷时通读实际窗口；长任预定早、中、晚、最大压力/失败四个连续卷或本纪年段，不按命中选卷。正文仅载结果时，可用一件列传替换一单元，总数仍≤四。不用专人政要、言行汇编；《贞观政要》不入C2父链或覆盖并集。到上限仍缺窗须留`EVIDENCE_LIMITED`及缺口，不为升档加料，也不以读满预算换档。

定向摘要只证对应入口已查，不代用人、司法、继承宗室、宫廷信息、调查核验覆盖；仅完成摘要者最高`E1/E2`。主要阶段、领域及正反窗口由连续君主正文或稳定等价直接材料覆盖才可`E3`。无合格父链或缺主要窗口须`EVIDENCE_LIMITED`，说明已见模式、缺口与可改档材料，不默认中性档。

无父链或材料薄者仍发布低置信度档位，仅概括已观察模式，不以缺料判低或统一默认档。`grade_basis`与`position_basis`分别写已见事实、适用边界、缺口及重开条件。

`EVIDENCE_FLOOR`表示直接状态转移材料可支持的下限，不等于全生涯短板；阅读页显示状态及重开条件。分布或雷达观感不触发放宽或统一抬G3；改区间/缺测须统一修订八轴输出及消费者，C2不能单独改。
