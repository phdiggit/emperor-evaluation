# 人物画像分项规则：C2 信息处理、学习与纠错

> `FORMAL-V1.0`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么，怎样取证

C2评价本人求真和更新认识的能力，不要求先犯错。计分证据`SCORING_PARENT`按实际过程分三类：

| 类型 | 所需过程 |
|---|---|
| `TRUTH_ACQUISITION` | 面对不确定问题或失真风险，本人调查、复核或辨别冲突，形成/修正判断并选择，得到后续验证 |
| `ERROR_CORRECTION` | 本人原判断或行为 → 可信反馈到达 → 本人理解与更新 → 执行及后续复验 |
| `REFUSAL_OR_RECURRENCE` | 有信息机会且反馈已达，本人仍选择性采信、曲解、拒核、只换人不改机制或重复同错；须证明归责与可行替代 |

只有渠道、求言、正确报告或臣下查明，不能证明本人求真；一次纳谏、认错、罪己诏、被迫复核只是候选。政策失败、渠道不安全、缺料或无反馈机会本身不算负证。不能仅从行为变化、结果或一句“从之”反推认知。

同一事件中，求真、理解和更新归C2；进谏安全、惩罚比例、报复和程序约束归C5。两种命题各有证据才可辅助投影，不重复计纳谏收益。

## 2. 怎样定档

按绝对表现比较真实观察机会、独立领域与阶段、本人理解份额、更新落实、复发及全生涯正反分布。“纳谏多”须有具体周期，早善晚退须有拒绝反馈或复发事实。同政策、战争或谏臣转述只计一个周期。

G4/G5须有多个具名独立周期和直接来源，检查反例及后续表现，至少包含本人取得或辨别真实信息。G5还须在不同领域、主要阶段和约束下反复达到历史罕见水平，不能靠父链数、最高MI或名望证明。

G5不要求无错、无负链或穷尽全域。G5-LOW可有复发、晚退或观察缺口，但主动求真、重开决定和制度化纠错须跨阶段、跨约束反复成立，困难情境未推翻主模式；反证限制进入MID/HIGH。一般纳谏、个案或名臣纠偏不足。全池无G5时检查门槛是否不可达，不按名额抬档。

## 3. 覆盖范围与补证预算

按实际掌权年代审查，以“阶段×领域”记录正反观察机会，不先按名望、方向或关键词筛人。本地入口并非均匀样本：B2只证明制度安排，归档第五项A2已有本人行为证据可复用，其他轴须另证C2命题，不继承档位、分数、方向或MI。

潜在高档须在同轮检查全部本地入口，并最多新增四个一手材料单元。本地材料不占配额，也不能被新增材料替代：

- 按史料密度和可归责事件，优先选择早、中、晚、最大压力/失败等不同阶段的连续正文，不按命中挑卷，不以任期或亲政身份截断检索。
- 正文仅载结果时，可用一件列传替换一单元，总数仍不超过四。
- 不用专人政要、言行汇编；《贞观政要》不进入C2父链或覆盖并集。

G4/G5若缺求真、纠错、主要阶段或反例覆盖，沿史源通读或有界联网补证；仍不足记`MATERIAL_DENSITY_LIMITED`，不发布高置信度高档。预算用尽仍有关键阶段/反例缺口，保留`EVIDENCE_LIMITED`，不为升档加料，也不以读满预算换档。

## 4. 证据等级与发布

每个稳定事实单元只归入`SCORING_PARENT`、`BACKGROUND_VALIDATION`、`AXIS_OUT_WITH_REASON`、`UNRESOLVED_EVIDENCE_GAP`之一。计分链须说明原认知/问题、新信息、本人解释、判断/行为变化、执行及复验/复发。

定向摘要只证明对应入口已查，不能代替用人、司法、继承宗室、宫廷信息、调查核验的覆盖；仅完成摘要最高E1/E2。主要阶段、领域及正反证由连续君主正文或稳定等价直接材料覆盖，才可E3。

无合格父链或缺主要阶段/反例覆盖时，仍发布低置信度有界档位并标`EVIDENCE_LIMITED`，只描述已观察模式，不因缺料判低或默认中性。`grade_basis`与`position_basis`分别说明已见事实、适用边界、缺口和可改档材料。

`EVIDENCE_FLOOR`是直接状态转移材料支持的下限，不代表全生涯短板；阅读页显示状态和重开条件。分布或雷达观感不能触发放宽、统一抬G3；改用区间/缺测须统一修订八个能力轴及其消费者，不能只改C2。
