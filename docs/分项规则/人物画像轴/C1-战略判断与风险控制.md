# 人物画像分项规则：C1 战略判断与风险控制

C1评价决策当时的信息条件下，本人识别主要矛盾、选择目标与优先级、匹配路径时序与资源、隔离风险及反馈后调整的能力。结果只作验证，不以版图、国力、寿命、成败或名望换分。

`SCORING_PARENT`应闭合：问题—已知信息—可行备选—本人选择—资源边界—预案/退出—反馈—调整/加码—结果—归责。低档须证明替代可行且反馈可达；继承困局或失败本身不判低，优势败坏、反馈后扩大风险从严。臣下独立成果不全归本人。

正负证采用同一构念准入门；仅有结果、资源、臣下成果或跨轴概括的，列`BACKGROUND_VALIDATION`或`AXIS_OUT_WITH_REASON`。不转换其他项档位或总分，但须消费其中闭合的本人战略选择；机会难度扣除继承资源和自致逆风，臣下设计只计本人目标、授权与反馈决策。

机制：`PROBLEM_PRIORITY`（矛盾与优先级）、`GOAL_RESOURCE_FIT`（目标路径与资源）、`RISK_OPTIONALITY`（备选、隔离与退出）、`FEEDBACK_RECOURSE`（反馈后调整或合理维持）。入口须连接第一项A、第二项重大治理选择、第三项战争安全决策、第五项A2及M1/M2同构念父链。仅引汇总结算最高暂定`MI2_LIFECYCLE`；`MI3_SUSTAINED_SYSTEMIC`、`MI4_CROSS_PHASE_SYSTEMIC`须有直接过程定位。

主路由：战略目标、优先级、风险与退出归C1；战争确定后的统帅、战区与战役解题归M1；外部利益、谈判联盟与承诺归M2；信息反证更新归C2。M3只承接第二项C1—C4结果；财政选择另证战略或更新构念才入C1/C2。组织执行只按共同“落实深度与受阻重组”门复验主轴。同事件仅一个能力主路由；辅助投影须另证构念并写`secondary_projection_reason`，不读其他轴档位、雷达值或总分。

双向复核：`G4/G5`查反例、好牌低产和晚期退化；`G0/G1`查继承困局、可行替代与止损。缺高光、臣下主导、材料稀疏或无逆风复验只记`LIMITATION`/`BACKGROUND_VALIDATION`；一次极败或亡国不直接定历史级低档。

`MI`仅表覆盖持续性，不由其高低、父链数量或正负合成直接定档。能力剖面另评矛盾识别、目标资源、路径时序、风险退出，并记机会厚度、独立周期、约束、兑现率、好牌低产、坏牌止损、跨域迁移与跨期稳定。`G4`须有两个独立重大周期，或一条有直接定位、跨域多阶段并覆盖四机制的父链；`MI4_CROSS_PHASE_SYSTEMIC`不自动支持高档。`G5`还须在多领域、阶段和约束下历史罕见且通过高难反例复验；不得用`G5-LOW`安置未达准入者。

能力诊断另设人工语义量尺，不得由`MI`、成果大小或父链数量生成：

- 正证诊断作用：`PS0`仅为结果、臣下或资源背景；`PS1`为局部正确选择；`PS2`为完整独立决策周期；`PS3`为跨对象或跨阶段可迁移的强模式；`PS4`为不同约束下反复兑现、达到历史罕见。`G4`主体须达到`PS3`，`G5`须达到`PS4`。
- 负证诊断作用：`DW0`为坏结果但无本人错误归责或核心属于别轴；`DW1`为单次局部误判、及时纠正且未复发；`DW2`为本人归责、存在可行替代并造成显著损失，但有效恢复或未同构复发；`DW3`为同一核心机制重复失败、反馈后继续加码，或优势条件下造成高诊断力崩盘；`DW4`为多机制、多阶段的历史级稳定失能。负证不得机械封死`G5`，正证也不得因`MI4`或成果巨大自动进入`G5`。

每个独立周期须有可反查事件锚；一条`MI4`可含多周期，但不得凭概括拆数。`direct_process_refs`只用真实文件、卷次史源锚或可反查`material_id`，不用日期、枚举、状态或结论替代。`grade_basis`、`position_basis`、`limitations`、`counterpattern`与父链须同义；无准入负链不得以跨轴负证暗降`position`。

正式C1记录以`parent_chains`保存完整父链，以`representative_parent_ids`声明阅读层展开项；不得把完整父链对象复制到代表字段。投影单元须绑定来源轴真实稳定锚；`MISSING`、空锚、以人物ID代替已有父链或来源中不存在的锚均不通过。无`parent_chains`数组时，从正式上下文、诊断引用及规范入口覆盖取稳定父链并集。`independent_cycles`及剖面周期只计正向`SCORING_PARENT`，不计背景或轴外对象。

先驱性须证明本人兑现罕见可行路径并解决结构问题；影响、新名与象征意义不另加分。
