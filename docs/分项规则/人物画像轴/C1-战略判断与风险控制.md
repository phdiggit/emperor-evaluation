# 人物画像分项规则：C1 战略判断与风险控制

> `FORMAL-V1.0`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么，怎样取证

C1评价本人在当时信息条件下识别主要问题、选择目标与优先级、安排路径和资源、控制风险及按反馈调整的能力。版图、国力、寿命、成败和名望不能直接换分。

计分证据`SCORING_PARENT`须说明：

> 问题与已知信息 → 可行备选 → 本人选择与资源边界 → 预案/退出 → 反馈 → 调整/加码 → 结果与归责。

正反证适用同一要求。低档须证明本人有可行替代、能收到反馈；继承困局或失败本身不足判低，优势败坏、反馈后扩大风险从严。臣下方案只计本人目标、授权和反馈决策；难度判断扣除继承资源与自致逆风。

机制分为`PROBLEM_PRIORITY`（问题与优先级）、`GOAL_RESOURCE_FIT`（目标路径与资源）、`RISK_OPTIONALITY`（备选、隔离与退出）、`FEEDBACK_RECOURSE`（调整或合理维持）。取证须连接重大治理选择、战争安全、既有战略事实及M1/M2中的相关过程。仅引汇总结算最高暂定MI2；MI3/MI4须能直接定位过程。

只有结果、资源、臣下成果或跨轴概括的材料，记`BACKGROUND_VALIDATION`或`AXIS_OUT_WITH_REASON`；其中有证据的本人战略选择仍须审查，不继承其他项目的档位和总分。

## 2. 与其他轴的边界

战略目标、优先级、风险与退出归C1；战争确定后的统帅与战役解题归M1；外部利益、谈判联盟和承诺归M2；信息辨别与更新归C2。财政民生结果作背景，具体财政选择须另证战略或认知更新才能进入C1/C2。组织落实只按总合同的“落实深度与受阻重组”要求复验原主轴。

同一事件只有一个能力主路由。辅助投影须另证能力命题并写`secondary_projection_reason`，不读取其他轴档位、雷达值或总分。

## 3. 定档与交叉复核

MI只表示证据持续性，不按其高低、父链数或正负相加定档。分别比较问题识别、目标资源、路径时序、风险退出，记录观察机会、独立周期、约束、兑现率、优势利用、困境止损、跨域迁移和跨期稳定。

| 档位 | 必要条件 |
|---|---|
| G4 | 两个独立重大周期，或一条可直接定位、跨域多阶段并覆盖四机制的父链；主体正证达到PS3 |
| G5 | 多领域、阶段和约束下反复达到历史罕见水平，通过高难反例复验，正证达到PS4；未达准入者不能放入G5-LOW |

能力诊断由人工判断，不由MI、成果规模或父链数生成：

| 量尺 | 含义 |
|---|---|
| PS0 | 只有结果、臣下或资源背景 |
| PS1 | 局部正确选择 |
| PS2 | 完整独立决策周期 |
| PS3 | 跨对象或阶段可迁移的强模式 |
| PS4 | 在不同约束下反复兑现，达到历史罕见 |
| DW0 | 坏结果无本人错误归责，或核心属于别轴 |
| DW1 | 单次局部误判，及时纠正且未复发 |
| DW2 | 本人有可行替代却造成显著损失，但有效恢复或未重复同类错误 |
| DW3 | 核心机制重复失败、反馈后继续加码，或优势下出现足以说明能力问题的崩盘 |
| DW4 | 多机制、多阶段稳定失能，达到历史级程度 |

负证不机械封死G5，MI4或巨大成果也不自动支持高档。G4/G5须查反例、优势低效和晚期退化；G0/G1须查继承困局、可行替代和止损。缺高光、臣下主导、材料少或无逆风复验只记`LIMITATION`/`BACKGROUND_VALIDATION`；一次极败或亡国不能直接定历史级低档。先驱性须有本人兑现罕见可行路径、解决结构问题的证据，新名与象征影响不加分。

## 4. 正式记录

每个独立周期须有可反查事件锚；一条MI4可含多周期，不能凭概括拆数。`direct_process_refs`须为真实文件、卷次史源锚或可反查`material_id`，不能用日期、状态、枚举或结论代替。

`parent_chains`保存完整父链，`representative_parent_ids`只列阅读层展开ID，不复制对象。无`parent_chains`数组时，从正式上下文、诊断引用和规范入口覆盖取稳定父链并集。`independent_cycles`及能力剖面只计正向`SCORING_PARENT`周期。

跨轴投影须绑定来源中的真实稳定锚；空锚、`MISSING`、用人物ID替代已有父链或来源不存在的锚均不合格。`grade_basis`、`position_basis`、`limitations`、`counterpattern`须与父链同义；无合格负链，不能借跨轴负证暗降档内位置。
