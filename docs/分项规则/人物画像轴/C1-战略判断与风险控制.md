# 人物画像分项规则：C1 战略判断与风险控制

C1只评价本人在决策当时可获得的信息条件下，能否识别主要矛盾，选择可行目标与优先级，使路径、时序和资源承载相匹配，设置风险隔离、备选与退出条件，并在反馈到达后止损、换路或有理由地维持。结果只用于验证判断，不以版图、统一、国力、政权寿命、最终成败、后世历史意义或“雄才大略”名望换算能力。

每条`SCORING_PARENT`应尽量闭合：战略问题、决策时已知信息、当时可行备选、本人选择、目标与资源边界、风险预案或退出条件、反馈到达、调整或加码、结果验证和本人归责。拟判低档时必须确认可行替代真实存在且反馈能够到达；继承坏牌或在坏牌下失败不机械判低，好牌打坏、反馈后继续扩大暴露则从严。臣下独立设计与执行的成果不得全部归给皇帝。

正证和负证必须先通过同一构念准入门；仅有好坏结果、国家资源、版图、臣下成果、其他轴行为或事后概括时，只能进入`BACKGROUND_VALIDATION`或`AXIS_OUT_WITH_REASON`。第一、第二、第三项的档位、名次和汇总值不得转换为C1，但其中闭合了本人战略层选择的底层具体事件必须消费。机会难度须扣除继承资源与本人自致逆风；臣下设计只计本人可证的目标选择、授权边界和反馈决策。

计入：

- 对主要目标、优先级、时机、路径与退出条件的本人判断；
- 面对不确定性时的备选方案、试错成本与风险隔离；
- 对长期后果、承载能力和资源边界的预判；
- 重大误判后的止损、调整或继续加码。

主要机制固定为：`PROBLEM_PRIORITY`（主要矛盾与优先级）、`GOAL_RESOURCE_FIT`（目标—路径—资源承载匹配）、`RISK_OPTIONALITY`（风险隔离、备选与退出条件）、`FEEDBACK_RECOURSE`（反馈后的止损、换路或合理维持）。主要既有入口至少完整连接第一项A、第二项重大治理选择、第三项战争与安全决策、第五项A2，以及M1/M2已闭合父链中可投影到C1的同构念事实；只引用五项或画像汇总结算的父链最高暂定`MI2_LIFECYCLE`，`MI3_SUSTAINED_SYSTEMIC`和`MI4_CROSS_PHASE_SYSTEMIC`必须具有可反查的直接过程定位。

不计入：

- 版图、国力、政权寿命和最终成功本身；
- 已由臣下独立完成、没有本人决策锚的成果；
- 后世以结果反推的“雄才大略”；
- 纯军事战役解题，归M1；一般信息吸收和纠错模式，归C2。

跨轴主路由按问题而非材料目录确定：C1回答“要不要做、先做什么、做到何种程度、承担何种风险、何时退出”；M1回答战争确定后的统帅、战区与战役解题；M2回答外部对象利益、谈判、联盟和承诺；M3回答财政经济约束与工具适配；C2回答信息与反证更新模式。组织执行不再独立路由，只按“跨轴落实深度与受阻重组证据门”增强或限制上述主轴父链。同一事件只能有一个主路由；辅助投影必须保存独立构念和`secondary_projection_reason`，不得读取M1/M2档位、雷达值或五项总分。

C1的高低档另设双向门。拟`G4/G5`必须复核反例、资源优势下的低产和晚期退化；拟`G0/G1`必须复核继承坏牌、当时可行替代和反馈后的止损。没有高光、臣下主导、材料稀疏或缺少逆风复验只形成`LIMITATION`或`BACKGROUND_VALIDATION`，不得冒充负证。一次极端失败或亡国不得直接生成历史级低档。

C1不得以正负父链合成、最高`MI`、父链条数或单条概括链直接决定档位。`MI`只描述材料覆盖的持续性，与能力等级正交；全生涯裁决必须另存能力剖面，分别检查主要矛盾识别、目标—资源匹配、路径与时序组合、风险隔离与退出，并记录决策机会厚度、实质独立重大决策周期、难度与约束、成功兑现率、好牌低产、坏牌止损、跨领域迁移和跨阶段稳定。`G4`至少需要两个实质独立的重大决策周期，或一条具有直接过程定位、跨领域且多阶段并覆盖上述四机制的父链；单一父链即使达到`MI4_CROSS_PHASE_SYSTEMIC`，也只能证明稳定模式，不能自动达到`G4/G5`。`G5`还须在多领域、多阶段和不同约束下保持历史罕见表现，并通过高难反例复验；`G5-LOW`不得作为证据厚度不足或门禁未闭合的常规安置。

能力诊断另设人工语义量尺，不得由`MI`、成果大小或父链数量生成：

- 正证诊断作用：`PS0`仅为结果、臣下或资源背景；`PS1`为局部正确选择；`PS2`为完整独立决策周期；`PS3`为跨对象或跨阶段可迁移的强模式；`PS4`为不同约束下反复兑现、达到历史罕见。`G4`主体须达到`PS3`，`G5`须达到`PS4`。
- 负证诊断作用：`DW0`为坏结果但无本人错误归责或核心属于别轴；`DW1`为单次局部误判、及时纠正且未复发；`DW2`为本人归责、存在可行替代并造成显著损失，但有效恢复或未同构复发；`DW3`为同一核心机制重复失败、反馈后继续加码，或优势条件下造成高诊断力崩盘；`DW4`为多机制、多阶段的历史级稳定失能。负证不得机械封死`G5`，正证也不得因`MI4`或成果巨大自动进入`G5`。

每个声称的独立决策周期必须列出真实可反查的事件定位；一条`MI4`父链可以统摄多个周期，但不得用概括叙述拆出没有稳定锚的周期数。`direct_process_refs`只允许真实存在的仓库文件定位、带卷次与锚点的史源定位或能够在所引来源中反查的稳定`material_id`；日期、状态角色、枚举值、限制说明和汇总结论不得伪装成直接过程定位。`grade_basis`、`position_basis`、`limitations`、`counterpattern`和父链必须同值同义；没有准入负向父链时，不得让跨轴负证暗中决定`position`。

C1入口审计中的投影单元必须绑定来源轴已有的真实稳定引用；`MISSING`、空锚、仅以人物ID代替已存在父链，或锚值不在所引文件中出现，均不得通过覆盖门。来源轴没有`parents`数组时，应从其正式稳定上下文、诊断引用和规范入口覆盖中的稳定父链引用并集重建单元。`BACKGROUND_VALIDATION`与`AXIS_OUT_WITH_REASON`只完成覆盖或边界说明，不得计入`independent_cycles`；能力剖面的周期锚只允许来自正向`SCORING_PARENT`。

“先驱性”只有在本人提出并兑现此前罕见的可行路径、且能够说明解决了什么结构问题时才构成正证。历史影响、新颖名称和后世象征意义不形成先驱性加分。
