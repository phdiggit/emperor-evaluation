# 画像校准与首轮校准合同

> 共同规则见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)与[共同数据与发布合同](00-共同数据与发布合同.md)。

校准组用于检查不同能力结构能否解释清楚，不预定人物分数；正式验收仍覆盖全池。

| 主题 | 校准人物 | 必须回答的问题 |
|---|---|---|
| 军事能力上沿 | 李世民、铁木真、忽必烈 | 如何区分稳定历史级、多战役极端高峰、重大失败和军事净成本？ |
| 军事声望高于本人证据 | 刘彻、嬴政 | 如何剥离国力、名将成果、扩张规模、先驱叙事和历史影响？ |
| 大众低估军事能力 | 耶律阿保机 | 本人多战役能力能否在不借既有名次倒推的情况下进入强档？ |
| 军事与外交非对称 | 赵恒、刘邦、玄烨 | 如何区分本人统帅、战略授权、谈判、守约和长期安全收益？ |
| 人事正果与完整周期 | 刘邦、李世民、弘历、朱元璋、胤禛 | 怎样分别评价人才成果、授权过程、负面反馈和退出处置？ |
| 财政经济专业判断 | 胤禛、玄烨、刘询、朱元璋 | 如何区分专业工具判断、治理结果、继承繁荣和反馈后继续错误？ |
| 政治联盟全窗口 | 刘秀、李世民、刘邦 | 如何区分开国从属权限、最高权力后的联盟重组、功臣退出和晚期信用反转？ |
| 大众名望豁免 | 刘邦、朱元璋、嬴政、刘彻 | 是否把清洗和株连因英主叙事改写为必要乃至正面？ |
| 欲望自控辅助标签 | 刘邦、刘秀、朱元璋、拓跋宏、李世民、玄烨、胤禛 | 普通爱好是否保持中性，只有极端消费和跨阶段主动克制才生成标签？ |
| 治绩反推人格 | 完颜雍、萧绰 | 是否把治理结果直接换成气量、自控、学习或用人能力？ |
