# 人物画像分项规则：C5 权力运用风格与克制

C5评本人权力边界，不评治国结果或私人美德。方向中立消费第五项A/B/C及其他正式入口的同构念行为链；材料所在分项不决定排除，不限第五项C1—C4，也不先搜宽暴案例互相封顶。

适用于有实际最高权力、摄政权或等价强制权的正式对象。本地材料不足须有界联网补证并发布低置信度档位，不因稀疏停在`UNRESOLVED`。

评价包括：

- 惩罚、株连、报复和强制措施是否符合对象、证据与比例；
- 是否保护无辜者、异议者和依法履职者；
- 在强烈个人利益、愤怒、猜疑或政治压力下是否保留程序和纠正空间；
- 是否把公共权力、资源和制度持续用于私人特权；
- 伤害反馈到达后是收束、补救还是继续扩大。

声誉与“所杀皆恶”不豁免逐案取证，批评也不代归责。C5不反改C3：识人授权强与权力克制低可以并存。

## 政治斗争与现实安全威胁边界

“现实政敌、叛乱者、夺权者”只排除为解除**当时仍在持续的现实威胁**所必需的战斗、制伏、缴械和拘捕切片，不豁免整个对象、整个案件或其后全部处分。每条相关父链须按处分发生时点记录`threat_state = ACTIVE / CONTROLLED / ENDED / UNCERTAIN`，再裁C5：

1. `ACTIVE`：正在交战、刺杀、举兵、实施政变或仍实际控制武装与权力资源时，必要的军事镇压、当场制伏和拘捕不因敌对身份本身计负；战争成败仍归M1/C1等主轴。
2. `CONTROLLED`：本人已经被捕、缴械、失去即时行动能力，但其既有谋逆事实与残余组织仍可核实时，死刑或重刑不得因“政敌”自动计负，也不得自动退出C5；须继续审证据、历史情境下可行比例、程序、酷刑、报复性和替代方案。正常且有充分事实基础的安全处分可以记为中性背景。
3. `ENDED`：投降、被俘后长期羁押、退位、解除武装、失去现实组织能力或战争已经结束后，安全豁免终止；此后的法外处死、酷刑、羞辱、私人报复、追杀和其他明显过度处分直接回到C5比例审查。
4. 家属、宗族、旧部和普通人口不继承首谋者的豁免。只有逐人闭合其直接参与现实威胁，才可按本人`threat_state`另裁；仅凭亲属、集团或地域身份实施株连、灭族、屠城、籍没或身份处罚，仍属C5强制边界事实。
5. 同一政治案件按生命周期只建一个父情境，内部拆分“现实威胁处置”和“威胁解除后处分”，不得把前者的正当性覆盖后者，也不得把后者反向污名化必要的战斗行为。
6. 拒绝秘密暗杀、法外报复或无差别扩大，可以形成正向C5证据，但必须证明本人确有可行便利而主动选择更公开、可复核或比例更低的路径；普通的“没有杀政敌”只是基线，不自动加分。其负向对称项是同条件下实际采用秘密暗杀、报复或扩大处分，而不是公开战斗本身。

因此，政治斗争身份只是**处分时点和比例审查的输入变量**，不是自动豁免标签；“威胁是否仍现实存在”与“处分是否仍有必要且合比例”必须分别回答。

### 全池政治斗争与清算覆盖门

政治斗争不是仅在已知负证中被动复核，而是C5对全部正式对象的强制覆盖域。每个适用人物在发布或复核C5时必须单列`political_conflict_scope_status = NO_MAJOR_CONFLICT / CONFLICTS_REVIEWED / UNRESOLVED`；不得以当前C5材料已经足够、人物档位已经很低或旧入口没有命中为由跳过。

最低检索范围包括本人实际权力窗口内的：

- 夺位、篡位、宫廷政变、摄政权争夺和王朝取代；
- 皇位继承、储位、宗室竞争与废立；
- 已发生或被本人认定为现实威胁的叛乱、谋反、地方割据和平叛善后；
- 开国、改朝换代、复辟和政变后的前朝皇族、旧主、旧臣处置；
- 功臣、权臣、外戚、近幸、军事集团与政治派系的大规模清洗或退出；
- 受降、投降、被俘、解除武装或失去实际权力后的政治对象处置。

候选事件不得只从现有C5父链反查。至少交叉读取：第五项强制权力事实、M4集团整合与退出事实、第一项/规范池中的建国和夺权事实、第二项制度行政中的政治司法事实；其中任一入口出现君主级权力斗争、株连或政治清算线索，都必须进入C5覆盖审计。现有入口不足时，再用编年史、本纪、列传或其他可定位史源补证。

每个政治斗争父情境至少记录：`conflict_id`、冲突类型与阶段、首要政治对象、其处分时的`threat_state`、本人处置、家属处置、宗族处置、旧部/党附处置、普通人口处置、财产/身份处置、反馈与后续扩大/收束、本人归责、史源及最终C5消费状态。没有家属或扩大处置也须明确记`NO_EXPANSION_FOUND`，不得以未记录代替已复核。

正式审计特别检查四类遗漏：

1. **首谋遮蔽**：史料只写首谋罪名，裁决因此忽略其家属、宗族、旧部与普通人口的后续处分；
2. **战争遮蔽**：以事件起源于战争或叛乱为由，把城破、受降、拘捕、幽禁后的处死和扩大清算一并排除；
3. **低档遮蔽**：人物已有G0/G1或其他深负链，因此不再登记独立政治清洗；低档不免除事实完整性与父链完整性；
4. **入口遮蔽**：第五项、M4或旧C5未登记，就误判为没有政治斗争；全池覆盖以实际生涯事件为对象，不以某个既有项目是否命中为对象。

只有`NO_MAJOR_CONFLICT`或全部已识别冲突均达到`CONFLICTS_REVIEWED`，政治斗争覆盖门才算关闭。`UNRESOLVED`表示仍有足以改变档位的清算范围、本人归责或威胁状态未闭合；不得继续以旧高档材料密度审查替代本门。

长期让宫中、司法、近幸命令接受有司等不同角色实际复核，属`MI3_SUSTAINED_SYSTEMIC`，跨阶段复验后可`MI4_CROSS_PHASE_SYSTEMIC`；单次宽免、纳谏或保护履职者通常为`MI1_CASE`/`MI2_LIFECYCLE`。制度主锚不能被拆成若干等权个案。

C5正向材料的强度优先按以下语义判断，不设置可相加的数值权重：

1. 在权力、私人利益、愤怒、猜疑或政治压力下，跨阶段、跨对象反复主动克制，并实际放弃报复、特权或绕过程序的便利；
2. 建立能够约束本人、宗室、近幸或权贵的制度化自缚接口，且该接口已经在不利于本人或特权集团的案件中实际运行，本人接受其复核、否决或纠正结果；
3. 多个独立案件中的比例克制、异议与履职保护、伤害反馈后的持续收束；
4. 单次宽免、一般减刑、一般司法改革或只有制度文本的自限表态。

第一层通常最强；制度自限须闭合规则、运行、触及特权和本人接受结果才达同等强度，不能因法律属性、运行年限或第二项`M3`自动入高。

第二项A提供制度边界候选，B1验持续执行，B2验信息异议可达并改变决定；稳定`material_id`及父链须逐条消费/排除，不转换分数、档位、名次或位置。C5只取本人/特权者实际受约束且本人接受不利复核的切片，标`ACTIVE_SELF_RESTRAINT`、`OPERATING_SELF_BINDING_INSTITUTION`或`GENERAL_JUDICIAL_GOVERNANCE`。一般法典、机构或司法复核未证本人自缚和逆风运行，不独立支持高档/`E3`。

先连接规范池全体人物的第二项A/B1/B2和第五项A/B/C入口，再逐事实单元裁决；分离`SCORING_PARENT`与`BACKGROUND_VALIDATION`，父案只消费一次。正负证记`MI1_CASE`至`MI4_CROSS_PHASE_SYSTEMIC`、归责、程序比例、可逆性、反馈、纠正/扩大、复发及同构念关系。及时纠正的轻错通常只影响位置；单次极端不可逆事件可形成深下沿，但推翻长期模式须达`PATTERN_CHANGING_COUNTEREVIDENCE`，不按著名个案数覆盖。

`G4/G5`只有正证或缺实质反证时触发`SOURCE_DENSITY_ASYMMETRY_REVIEW`：覆盖全部入口、实际窗口、跨轴同构念强链及至少一个可暴露反例的编年/官修史入口，不以搜到黑点即停。结果为`COVERAGE_CLOSED`、`COUNTEREVIDENCE_FOUND`或`MATERIAL_DENSITY_LIMITED`；最后一种须留`latent_high_grade_hypothesis`，正式`axis_grade`最高`G3-HIGH`，待反例门闭合，不共用完整高档雷达值。

`E3`须复验主要机制与阶段：一条`MI4_CROSS_PHASE_SYSTEMIC`，或两条独立父链且一条≥`MI3_SUSTAINED_SYSTEMIC`并复核异常情境。单一`MI2`/`MI3`最高`E2 / MEDIUM / BOUNDED_PROFILE`。方向单一不自动降档，但须跨阶段强度或反例审查排除保存偏差。
