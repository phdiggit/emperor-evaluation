# 人物画像分项规则：C5 权力运用风格与克制

C5评本人权力边界，不评治国结果或私人美德。方向中立消费第五项A/B/C及其他正式入口的同构念行为链；材料所在分项不决定排除，不限第五项C1—C4，也不先搜宽暴案例互相封顶。

适用于有实际最高权力、摄政权或等价强制权的正式对象。本地材料不足须有界联网补证并发布低置信度档位，不因稀疏停在`UNRESOLVED`。

评价包括：

- 惩罚、株连、报复和强制措施是否符合对象、证据与比例；
- 是否保护无辜者、异议者和依法履职者；
- 在强烈个人利益、愤怒、猜疑或政治压力下是否保留程序和纠正空间；
- 是否把公共权力、资源和制度持续用于私人特权；
- 伤害反馈到达后是收束、补救还是继续扩大。

声誉与“所杀皆恶”不豁免逐案取证，批评也不代归责。C5不反改C3：识人授权强与权力克制低可以并存。

长期让宫中、司法、近幸命令接受有司等不同角色实际复核，属`MI3_SUSTAINED_SYSTEMIC`，跨阶段复验后可`MI4_CROSS_PHASE_SYSTEMIC`；单次宽免、纳谏或保护履职者通常为`MI1_CASE`/`MI2_LIFECYCLE`。制度主锚不能被拆成若干等权个案。

C5正向材料的强度优先按以下语义判断，不设置可相加的数值权重：

1. 在权力、私人利益、愤怒、猜疑或政治压力下，跨阶段、跨对象反复主动克制，并实际放弃报复、特权或绕过程序的便利；
2. 建立能够约束本人、宗室、近幸或权贵的制度化自缚接口，且该接口已经在不利于本人或特权集团的案件中实际运行，本人接受其复核、否决或纠正结果；
3. 多个独立案件中的比例克制、异议与履职保护、伤害反馈后的持续收束；
4. 单次宽免、一般减刑、一般司法改革或只有制度文本的自限表态。

第一层通常最强；制度自限须闭合规则、运行、触及特权和本人接受结果才达同等强度，不能因法律属性、运行年限或第二项`M3`自动入高。

第二项A提供制度边界候选，B1验持续执行，B2验信息异议可达并改变决定；稳定`material_id`及父链须逐条消费/排除，不转换分数、档位、名次或位置。C5只取本人/特权者实际受约束且本人接受不利复核的切片，标`ACTIVE_SELF_RESTRAINT`、`OPERATING_SELF_BINDING_INSTITUTION`或`GENERAL_JUDICIAL_GOVERNANCE`。一般法典、机构或司法复核未证本人自缚和逆风运行，不独立支持高档/`E3`。

先连接规范池全体人物的第二项A/B1/B2和第五项A/B/C入口，再逐事实单元裁决；分离`SCORING_PARENT`与`BACKGROUND_VALIDATION`，父案只消费一次。正负证记`MI1_CASE`至`MI4_CROSS_PHASE_SYSTEMIC`、归责、程序比例、可逆性、反馈、纠正/扩大、复发及同构念关系。及时纠正的轻错通常只影响位置；单次极端不可逆事件可形成深下沿，但推翻长期模式须达`PATTERN_CHANGING_COUNTEREVIDENCE`，不按著名个案数覆盖。

`G4/G5`只有正证或缺实质反证时触发`SOURCE_DENSITY_ASYMMETRY_REVIEW`：覆盖全部入口、实际窗口、跨轴同构念强链及至少一个可暴露反例的编年/官修史入口，不以搜到黑点即停。结果为`COVERAGE_CLOSED`、`COUNTEREVIDENCE_FOUND`或`MATERIAL_DENSITY_LIMITED`；最后一种须留`latent_high_grade_hypothesis`，正式`axis_grade`最高`G3-HIGH`，待反例门闭合，不共用完整高档雷达值。

`E3`须复验主要机制与阶段：一条`MI4_CROSS_PHASE_SYSTEMIC`，或两条独立父链且一条≥`MI3_SUSTAINED_SYSTEMIC`并复核异常情境。单一`MI2`/`MI3`最高`E2 / MEDIUM / BOUNDED_PROFILE`。方向单一不自动降档，但须跨阶段强度或反例审查排除保存偏差。
