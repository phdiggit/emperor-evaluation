# 人物画像分项规则：C5 权力运用风格与克制

> `FORMAL-V1.2`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么

C5评价本人怎样使用和约束权力，不评价治国结果或私人美德。主要看惩罚与强制是否有证据、合比例，是否保护无辜者、异议者和履职者，能否在私人利益或政治压力下接受程序与纠正，是否持续将公共权力、资源和制度用于私人特权，以及伤害反馈后是收束还是扩大。

生涯中有可归责的强制、处分、特权配置、程序豁免等权力使用机会，即适用C5。即位前、称帝前、从属或退位后的真实权力行为也计入；全生涯确无机会才可不适用。本地材料不足时作有界联网补证，发布低置信度档位，不因稀疏停在`UNRESOLVED`。

从归档第五项A/B/C及其他正式入口读取相关权力行为，不由材料原属项目或正负名望筛选。制度行政和权力行为入口须覆盖规范池全体人物，稳定`material_id`逐条判断；正反证据均须指向本人行为。声誉、“所杀皆恶”或批评本身不能代替证据，C5也不反改C3的识人授权结论。

## 政治斗争与现实安全威胁边界

安全处置的豁免只适用于解除当时持续威胁所必需的战斗、制伏、缴械和拘捕，不豁免整起案件。按处分时点记录`threat_state = ACTIVE / CONTROLLED / ENDED / UNCERTAIN`，分别判断威胁和处分比例：

| 状态 | 审查办法 |
|---|---|
| `ACTIVE` | 正在交战、刺杀、举兵、政变，或仍控制武装和权力资源时，必要战斗、制伏与拘捕不因敌对身份计负；战争成败归M1/C1等轴 |
| `CONTROLLED` | 已被捕、缴械或失去即时行动能力，但谋逆事实和残余组织仍可核实。继续审证据、历史情境下可行的比例与替代方案、程序、酷刑和报复性；有充分事实基础的正常安全处分可作中性背景 |
| `ENDED` | 投降、长期羁押、退位、解除武装、失去组织能力或战争结束后，安全豁免终止。法外处死、酷刑、羞辱、私人报复、追杀及过度处分进入C5比例审查 |

家属、宗族、旧部和普通人口不继承首谋的豁免，须逐人证明参与现实威胁；仅凭亲属、集团、地域身份施加株连、灭族、屠城、籍没或身份处罚，仍属C5事实。

同一案件只建一个完整父情境，分别说明威胁处置和解除威胁后的处分，不能互相抵消。拒绝暗杀、法外报复或无差别扩大，须证明本人原有可行便利而主动选择公开、可复核或比例更低的办法，才算正证；普通“没有杀”不加分。同条件下实际采用暗杀、报复或扩大处分是对应负证，公开战斗本身不是。

### 政治清算扩大半径统一尺度

`expansion_radius_level`只描述从首要威胁对象向无独立威胁归责对象扩大的广度，与烈度、持续时间、MI强度和G档分开判断：

| 代码 | 扩大范围 |
|---|---|
| `R0_NO_EXPANSION` | 未发现扩大，或本人主动阻止；必要战斗、制伏和对直接参与者处分不算扩大 |
| `R1_LIMITED` | 极少数邻接对象，未形成家庭、宗族、党附或群体清算 |
| `R2_BOUNDED` | 一个家庭、直系子嗣、窄亲属群或单一小型政治单元，仍限于一次案件/一个家庭圈层 |
| `R3_BROAD` | 三族/宗族、多支皇族、较广党附官僚网络、重复跨家庭清算，或规模较大但边界明确的政治、族群、军政群体 |
| `R4_SYSTEMIC_EXTREME` | 越过特定政治/安全类别，波及一般民众、无关群体、跨地区普通人口，或形成可复制、跨案件运行的制度化清洗/恐怖机制 |

人物半径取最远已证层级。重复、跨阶段、纠正与复发由MI和总档判断；来源冲突、收束速度、烈度等写入`semantic_adjudication`，不另造`expansion_radius_code`。

### 全池政治斗争与清算覆盖门

每位适用人物都须检查全生涯已知且可归责的夺权、清算、处分、特权及其他强制权力事件，记录`political_conflict_scope_status = NO_MAJOR_CONFLICT / CONFLICTS_REVIEWED / UNRESOLVED`。范围包括：

- 夺位、篡位、政变、摄政争夺、王朝取代与复辟；
- 继承、储位、宗室竞争和废立；
- 实际发生或被本人认定的叛乱、谋反、割据及善后；
- 前朝皇族、旧主旧臣、功臣权臣、外戚近幸、军事集团及派系的清洗或退出；
- 受降、被俘、缴械或失去权力后的处分。

候选不能只查现有C5记录；至少交叉查强制权力事实、M4整合与退出、规范池建国夺权事实、制度行政政治司法事实。任一入口出现君主级斗争、株连或清算线索，都须审查；不足再沿编年史、本纪、列传等可定位史源补证。

每个情境保存`conflict_id`、类型阶段、首要对象及处分时威胁状态、本人/家属/宗族/旧部党附/普通人口的处置、财产身份处罚、反馈与扩大收束、本人归责、史源和最终C5用途。未发现家属或扩大处分须明记`NO_EXPANSION_FOUND`，不能以空记录代替审查。

核对时不能因首谋有罪、起因是战争、人物已在低档或旧入口未命中而漏掉后续清算。无重大冲突，或全部已识别冲突均已审完，才关闭覆盖检查；足以改变档位的范围、归责或威胁状态未明，记`UNRESOLVED`，不能用高档材料密度审查替代。

## 3. 如何判断正反证据的强度

正向证据通常依次为：

1. 面对私人利益、愤怒、猜疑或政治压力，跨阶段、跨对象反复主动克制，放弃报复、特权或绕过程序的便利。
2. 制度实际约束本人、宗室、近幸或权贵，并在对其不利的案件中运行，本人接受复核、否决或纠正。规则、运行、触及特权和接受结果都有证据，才可与第一类等强。
3. 多个独立案件中的比例克制、异议/履职保护及伤害反馈后的持续收束。
4. 单次宽免、一般减刑、普通司法改革或只有文本的自限表态。

长期让宫中、司法、近幸命令接受有司等不同角色复核，可为`MI3_SUSTAINED_SYSTEMIC`，跨阶段复验后可为`MI4_CROSS_PHASE_SYSTEMIC`；单次宽免、纳谏、履职保护通常为`MI1_CASE`/`MI2_LIFECYCLE`。制度性证据不拆成多个等权个案，法律属性和运行年限也不自动支持高档。

制度材料分别标`ACTIVE_SELF_RESTRAINT`、`OPERATING_SELF_BINDING_INSTITUTION`或`GENERAL_JUDICIAL_GOVERNANCE`。只有本人/特权者实际受约束且接受不利复核的行为，才能证明制度自限；一般法典、机构或司法复核不能独立支持高档或E3。

每个父案只计一次，区分`SCORING_PARENT`与`BACKGROUND_VALIDATION`；正反证均记MI1—MI4、归责、程序比例、可逆性、反馈、纠正/扩大、复发及与本轴的关系，不转换来源分数和档位。及时纠正的轻错通常只限档内；单次极端不可逆事件可构成严重短板，但推翻长期模式须达到`PATTERN_CHANGING_COUNTEREVIDENCE`，不按著名个案数量决定。

## 4. 高档与证据等级

G4/G5若只有正证或缺实质反证，须做`SOURCE_DENSITY_ASYMMETRY_REVIEW`：查全部入口、全生涯已知相关权力事件、跨阶段反例、其他轴中涉及权力克制的强证据，并至少查一个可能揭示反例的编年/官修史入口，不因找到一项负面事实就停止。

结果记`COVERAGE_CLOSED`、`COUNTEREVIDENCE_FOUND`或`MATERIAL_DENSITY_LIMITED`。最后一种须保留`latent_high_grade_hypothesis`，正式`axis_grade`最高G3-HIGH，不能使用完整高档雷达值。

E3须覆盖主要机制与阶段：一条MI4，或两条独立父链且一条至少MI3，并复核异常情境。单一MI2/MI3最高`E2 / MEDIUM / BOUNDED_PROFILE`。证据方向单一不自动降档，但须用跨阶段强度或反例审查排除保存偏差。
