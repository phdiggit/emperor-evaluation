# 人物画像分项规则：C5 权力运用风格与克制

C5方向中立地复用第五项A、B、C各轴及其他正式材料中已经闭合的本人权力行为链，评价本人使用权力的边界，而不是评价治国成果或私人生活美德。材料原先位于“用人授权”“制度纠错”或其他分项，不构成排除理由；刘长式惩罚扩大、邓通式公共特权私授、酷吏或近幸的长期授权，都必须先判断其核心命题是否属于C5。不得只从第五项C1—C4取材，也不得先搜宽仁或暴虐案例再互相封顶。

C5对所有拥有实际最高权力、摄政权或等价强制权力的正式评价对象适用。不能因本地材料稀疏将人物留在`UNRESOLVED`；完成本地材料检索后仍不足时，必须进行有界联网补证并给出低置信度档位。

评价包括：

- 惩罚、株连、报复和强制措施是否符合对象、证据与比例；
- 是否保护无辜者、异议者和依法履职者；
- 在强烈个人利益、愤怒、猜疑或政治压力下是否保留程序和纠正空间；
- 是否把公共权力、资源和制度持续用于私人特权；
- 伤害反馈到达后是收束、补救还是继续扩大。

大众赞誉、王朝正当性和“杀的是贪官、叛臣、功臣集团”等概括不能豁免逐案审查；大众批评也不能替代本人归责和史源。C5不得反向污染C3：人物可以同时具备顶级识人授权能力和较低权力克制。

C5中特别区分制度性权力自限与个案宽纵：长期允许内降、宫中传命、司法命令或近幸请求进入正式复核，并由有司、台谏、二府等不同角色实际约束最高权力，属于`MI3_SUSTAINED_SYSTEMIC`或在跨阶段复验后属于`MI4_CROSS_PHASE_SYSTEMIC`；一次减刑、一次纳谏或一次保护履职者通常只是`MI1_CASE`或`MI2_LIFECYCLE`。例如赵祯第二项B2已经闭合的“内降与宫中命令纳入有司、台谏和二府复核”是C5强长板的制度性主锚，灾荒减死、冤案补偿及唐介案反馈后改轻用于跨对象复验和限定下沿，不得反过来把制度主锚降格为若干等权个案。

C5正向材料的强度优先按以下语义判断，不设置可相加的数值权重：

1. 在权力、私人利益、愤怒、猜疑或政治压力下，跨阶段、跨对象反复主动克制，并实际放弃报复、特权或绕过程序的便利；
2. 建立能够约束本人、宗室、近幸或权贵的制度化自缚接口，且该接口已经在不利于本人或特权集团的案件中实际运行，本人接受其复核、否决或纠正结果；
3. 多个独立案件中的比例克制、异议与履职保护、伤害反馈后的持续收束；
4. 单次宽免、一般减刑、一般司法改革或只有制度文本的自限表态。

第一层通常是最高质量材料；第二层只有同时闭合规则、行政运行、触及特权时的实际约束和本人接受结果，才可达到同等级强度。不能因为材料属于法律司法、运行多年或在第二项达到`M3`，就自动成为C5高强度正证。

第二项各入口对C5制度材料的角色固定为：A只证明制度建设、规则结构与最高权力边界候选；B1验证官僚组织、司法机关与行政程序是否真实、持续执行；B2验证信息、异议、监督和纠错是否能够到达并改变决定。A、B1、B2的分数、档位、名次和位置均不得换算C5，但其稳定`material_id`及父链必须逐条消费或明确排除。C5最终只消费其中“本人实际受约束、宗室近幸或特权者实际受约束、本人接受复核/驳回/不利结果”这一构念切片，不读取A、B1、B2档位或分数。一般法典编纂、司法机构建设、多法域组织、释放特定身份群体或普通死刑复核，若未闭合本人受约束和逆风运行，只属于`GENERAL_JUDICIAL_GOVERNANCE`，不得独立支持C5高档或`E3`；应分别标明`ACTIVE_SELF_RESTRAINT`、`OPERATING_SELF_BINDING_INSTITUTION`或`GENERAL_JUDICIAL_GOVERNANCE`。

C5实施时不得以人物级概括替代第二项A/B1/B2和第五项A/B/C的事实单元处置。先对184名正式准入人物机械连接全部规范入口，再逐人、逐父链完成语义裁决；`SCORING_PARENT`与`BACKGROUND_VALIDATION`必须分离，同一父案只消费一次。正证和负证均须记录`MI1_CASE`至`MI4_CROSS_PHASE_SYSTEMIC`的材料强度及本人归责、程序、比例、可逆性、反馈到达、纠正或扩大、复发与同构念关系。单次已及时纠正的轻微失误通常只改变档内位置；单次不可逆极端事件可形成深下沿，但推翻MI3/MI4长期正向模式必须满足`PATTERN_CHANGING_COUNTEREVIDENCE`，不得按著名个案条数机械覆盖制度模式。

拟定`G4/G5`且代表父链只有正证、或没有实质反证时，必须触发`SOURCE_DENSITY_ASYMMETRY_REVIEW`。统一检索预算覆盖全部规范入口、完整实际权力窗口、其他轴同构念强父链以及至少一个能暴露反例的编年或官修史入口，结果只能为`COVERAGE_CLOSED`、`COUNTEREVIDENCE_FOUND`或`MATERIAL_DENSITY_LIMITED`。检索不得以“搜到黑点”为停止条件。正式高档必须能够区分“反例复核后仍成立”与“尚未充分暴露反例”：`MATERIAL_DENSITY_LIMITED`时保留`latent_high_grade_hypothesis`记录可能达到的高档，但当前正式`axis_grade`最高发布`G3-HIGH`，直至反例暴露门闭合；不得让证据受限假设与完整高档共享同一雷达值。

C5的`E3`还要求主要机制和主要阶段已经复验：至少一条`MI4_CROSS_PHASE_SYSTEMIC`父链，或两条实质独立父链且至少一条达到`MI3_SUSTAINED_SYSTEMIC`并完成异常情境复核。只有单一`MI2`或`MI3`父链者最高为`E2 / MEDIUM / BOUNDED_PROFILE`；材料方向单一不自动降档，但必须由跨阶段强度或反例暴露审查证明其不是保存偏差。
