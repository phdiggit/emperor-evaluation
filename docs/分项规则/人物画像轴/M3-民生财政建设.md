## 1. 轴命题与四类事实

> 接手何种民生、经济财政、社会安全和制度盘面后，本人通过创设、维持、停止、修正或反馈后再选择，形成了怎样的建设、承压或恶化轨迹，并留下何种交班局面？

| 入口 | M3中的作用 | 禁止用法 |
|---|---|---|
| `I2.C1` | 判断生活、生产、税役负担和基本民生的绝对局面及阶段变化 | 不按80分比例换成M3 |
| `I2.C2` | 判断经济活力、财政健康、货币信用、市场与储备的绝对局面 | 不以财政高分覆盖民生或安全短板 |
| `I2.C3` | 判断人身财产、社会秩序、流亡饥荒与基本安全局面 | 不把安全后果重复计入`I2.C4` |
| `I2.C4` | 判断恢复、承压、恶化的方向、幅度、外生因素与本人可归责增量 | 不把一次命令当成已经实现的恢复 |

同一损益只取一次核心含义，M3评整体建设模式，不另计四项得分。

## 2. 四步能力裁决

### 2.1 建设难度与恢复量：第一判断轴

先看`I2.C4`闭合的`接手→任内最高已实现局面`，判断本人实际建设量。

- 逐轴只消费C1、C2、C3已证实的实际局面变化，不把诏令、政策名称或意图当成恢复；
- 跨档不是等距的：跨越越高档界，所需的财政、生产、救济与秩序能力通常越强；
- 三类局面同时恢复，强于单一通道改善；同一结果不得在多个通道重复计功；
- 接手低谷只有在前任遗留、战争灾害和本人选择的归责边界闭合后才能形成难度信用，不能因起点低自动加分；
- 窗口起点必须与实际最高权力责任窗口一致。若本人在名义窗口前已经拥有足以制造局面的实际最高权力，其先前选择造成的低谷不得作为本人恢复难度信用；应先前移责任窗口，或从恢复信用中扣除本人自造部分。窗口和归责未闭合者冻结相关档位，不以低起点保档；
- `1→4`与`4→4`不等价，`2→5`通常强于`3→5`；但恢复量仍须接受实现高度、稳定交班和主动成本复核。

正式恢复量沿用`I2.C4`逐轴难度加权事实：民生、经济财政、社会安全权重分别为`0.5 / 0.2 / 0.3`，跨越`1→2`至`5→6`的档界难度依次为`0.6 / 0.8 / 1.0 / 1.3 / 1.6`。这些数值只刻画已实现恢复的难度，不是把`I2.C1—I2.C4`相加，也不直接按连续分数切M3档。

#### 2.1.1 同档结构建设的待建边界

“同档结构建设”尚未启用独立晋档。启用须本人主导、全国/主要区域覆盖、机制实质变化、结果已实现、交班保留及超出名称诏令的证据，并经全池敏感性复核；此前不按政策数换恢复分或自动升档。

同档结构建设候选不改变当前C2/M3正式裁决，不得以待建候选宣称重裁完成。

### 2.2 达成的绝对高度：实现约束而非基准档

联合观察C1、C2、C3的正式主态，不求和，只判断本人最终证明系统可以运行到何种宽度：

| 组合层级 | 实质含义 |
|---|---|
| A5 | 至少两类达到五档，另一类不低于四档；形成罕见广泛高位 |
| A4 | 三类均不低于四档，或两类不低于四档且另一类不低于三档；形成广泛健康局面 |
| A3 | 三类均不低于三档，或两类不低于三档且另一类不低于二档；总体可用但存在明显不均衡 |
| A2 | 主要局面在二档附近，仍保留局部可用机制或阶段 |
| A1 | 两类以上落入一档，或整体已进入严重失保、失序与低安全状态 |

绝对高度只限实现上限，不供基准档；同主态须按建设量、压力、交班与成本允许跨档，高位继承不等于强建设。

### 2.3 稳定兑现与交班

再看`任内最高已实现局面 → 交班局面`、稳定兑现分、压力吸收和阶段反转：

- 建起来并稳定交班，才构成完整能力兑现；
- 在高压下守住高位可以证明强守成能力，但普通继承维持不能与大幅重建近似等价；
- 终局回落必须显著压档，尤其是本人反馈后继续错误选择造成的回落；
- 稳定失败不能抹去已经发生的建设。`A3→A5→A1`应表达“建设极强但持续治理与风险控制极差”，最终净化为低档时仍须保留前段能力事实。

M3直接读取三轴正式记录中的`stability_class_diagnostic_only`，仅将其中历史稳定诊断作为既有lineage，不读取C4的稳定诊断字段或稳定正分。第二项L只修正绝对状态，不机械换算M3档位或稳定分。`stability_score_18`仍为M3逐人裁决的持续、承压与保留度，不回写第二项。同步三锚、L、恢复、恶化与DA事实后，仅在实际触发本轴准入或保护门时局部重裁。

M3正式JSON只保留`stability_k_basis`作为三轴历史诊断的逐人投影；它只记录来源轴、来源字段和值，不参与任何M3数值或档位计算。

为便于全池复核，C4动态标签继续保留：

- `RARE_RECOVERY_OR_STEADY_BUILD`：罕见恢复，或在强压力下守住高位并留下明显余量；
- `SUBSTANTIAL_BUILD`：跨主要局面形成实质建设或恢复；
- `POSITIVE_MAINTENANCE`：正向守成或温和改善；
- `LIMITED_OR_MIXED_MAINTENANCE`：维持有限，正负结果并存；
- `ATTRIBUTABLE_OR_MIXED_DECLINE`：出现可归责或外生与本人共同造成的退步；
- `SEVERE_DECLINE`：主要局面出现严重退步；
- `COLLAPSE_OR_EXTREME_DECLINE`：出现崩坏或极端退步。

### 长期高位兑现保护门

`S_main`达到A4以上、由跨阶段材料证明为实际权力窗口内长期代表性主态，且本人已在该状态持续治理时，M3稳定分0仅表示交班稳定失败，不得改写为“未实现能力”。交班A3最低`G3-LOW`，交班A2最低`G2-LOW`；交班A1不适用。DA3、净下降和本人可归责末期恶化只压档内位置；DA4或本人直接造成的系统性崩坏可突破本门。本门不提供G4/G5准入，也不抵消回落或交班失败。

外生冲击恢复回到既有基线，只作高压守成、韧性和压力吸收证据；M3的强建设/重建门只消费相对`S0`保留下来的新建设。

### 2.4 本人主动制造的成本

M3不重新定义DA0—DA6。DA只读C4正式残余主动成本，不由战争、工程、反馈次数或名望重定档；M3据此限制档位、位置与保留度。外生因素须闭合时间、范围、机制，不自动免责，也不凭背景压力制造本人扣分。

结合既有过程父链与四子项材料复核：

1. 接手压力与可行替代；
2. 本人创设、维持、停止、拒绝、修改或知情不作为；
3. 工具如何落到税役、国库、币制、市场、粮储、工程和战争供给；
4. 反馈到达后本人是否再选择；
5. 成本由谁承担，是否重复转嫁；
6. 交班时的民生、财政、经济、安全和制度承载。

过程解释结果与归责，不脱离`I2.C1—I2.C4`制造高档；缺料者据已闭合状态与方向克制定档，明列过程缺口。

## 3. 五条档界

共同六档尺度下，本轴五条档界为：

| 边界 | M3实质含义 |
|---|---|
| G5 / G4 | G5要求罕见重建，或强建设达到高位并稳定兑现；强压力下长期守住罕见高位也可进入，但普通高位继承维持止于G4。罕见建设若交班、持续性或主动成本存在清楚限制，落G4或G5-LOW |
| G4 / G3 | G4要求跨主要档界的强建设/恢复，或达到较高实现高度且形成稳定强长板；只有一般改善、中位守成或高位但建设证据有限者为G3 |
| G3 / G2 | G3要求可辨认的实质建设，或在中高位形成有压力含量的稳定兑现；只有局部改善、普通维持、结构失衡或成本已明显侵蚀能力净表现者为G2 |
| G2 / G1 | G2仍保留有限但实际实现的建设、纠错或可用阶段；没有可保留建设、主要局面长期低位或严重退步成为主模式者为G1 |
| G1 / G0 | G0要求本人选择造成或放大的罕见、稳定且难恢复的失能或崩坏；普通低位、短窗口失败、材料不足或外生冲击占主因不得机械压入G0 |

顺序：建设恢复量→绝对高度→稳定交班→主动成本。主态不供基准档，成本和终局限制不抹去已实现建设。

记录`起点→主态→交班`三轴向量，另取C4最高实现向量；主态不当峰值。轨迹只验路线、高度和保留度，不再次计建设量，不自动生成档位/位置。

| 能力路线 | 语义准入 |
|---|---|
| 罕见广泛重建 | 起点整体不高于A2，既有C4恢复分达到罕见重建强度；逐轴变化只解释建设覆盖面，不另造建设量 |
| 高位建设 | 达到A5，至少两轴改善，但不满足低谷广泛重建 |
| 高压高位守成 | 通常要求接手和交班三轴均不低于四档、至少一轴达到五档，稳定分达到12，峰值回落不超过一轴，且有独立压力、主动应对和反馈纠正；若接手完整A4、本人把至少一轴推到五档，随后仅因未归责于本人的外生冲击使交班一轴落到三档，而整体仍为A4，恢复分达到6、稳定分达到6且没有独立恶化，也按受限高位守成处理，不与普通继承维持混同 |
| 实质建设 | 至少两轴实际改善，并在交班时保留主要成果 |
| 有限改善 | 只有单轴改善，或多轴改善但大部未能保留 |
| 普通维持 | 没有独立建设量，仅保持可用局面 |
| 停滞或失败 | 没有可保留改善，主要局面长期低位或恶化 |

G5只有两条建设准入：其一，正式C4恢复分至少22，接手整体不高于A2，达到至少A4、交班仍为A4以上且至少两轴保留净改善；其二，高位建设达到并以A5交班，恢复分至少12、至少两轴保留改善且稳定分至少14。第二条只允许“建设量不及深度重建、但A5保留度高”的模式进入G5下沿，不能进入G5-MID/HIGH。普通A5守成不自动进入G5；高压守成只有在压力和主动纠错链独立闭合后才可另行竞争。

G4必须命中下列抽象准入路线之一，不能只凭“低起点恢复很多”“任内达到过高位”或语义印象进入：

1. **强建设路线**：正式C4恢复分至少15，至少两轴实际改善、至少两轴在交班时仍保留净改善，交班不低于A3，稳定分至少6，且**交班保留恢复量≥12**。交班保留恢复量按同一跨档难度规则只计算`S0→S_end`仍为正的档界，现场核算、不写入JSON；
2. **完整A4建设路线**：三轴均以四档以上交班，恢复分至少10、稳定分至少8，且至少两轴保留净改善；
3. **高位守成路线**：接手与交班均不低于A4，在至少一个主要压力阶段闭合本人主动应对与反馈链；若以A5交班，稳定分至少12。若仅因不归责于本人的外生冲击使一轴交班落到三档，仍须整体保持A4、恢复分至少6、稳定分至少6、没有独立恶化且残余主动成本不高于DA1。**高压守成不得消费本人自造压力**：正向压力须来自外生、继承或必要安全约束；本人主动发动的可选择战争、工程或额外汲取只能进入成本复核，不能同时成为守成信用；
4. **A5实现下限路线**：以A5交班且没有严重恶化或DA4残余成本，但建设量未达到G5，只能进入G4。

恢复分处于12至不足15的低起点人物，若没有完成第二、第三或第四条，不得以“多轴恢复”“低谷重建”或“最终可用”替代第一条，最高为G3。命中G4必要条件后仍须复核规模、峰值回落、本人主动成本和过程链；必要条件不是自动定档器。

交班封顶必须读取三轴实际交班向量，不能拿C4T档替代绝对终局。实际交班A1通常封顶G1；A1且恶化扣减达到极端或主动成本为DA4者通常进入G0。**强建设事实保留例外**优先于该一般G0门：恢复分至少15、至少两轴改善且任内主态达到A4以上，已经证明长期实质建设成立；即使后来由本人自毁到A1且DA4，也固定表达为G2-LOW，不再适用“A1+DA4进入G0”。实际交班A2封顶G2，A3封顶G4。DA4在上述裁决后保留独立降一档效力；DA1—DA3主要限制晋档上限或档内位置，不得把起点—峰值—交班已经证明且仍被保留的建设改写为失败。

#### 实现表现下限硬门

实现表现下限已完成184人全池例外复核并正式启用：没有多轴严重净下降、`SEVERE_DECLINE`或更严重动态、DA4残余成本，以及本合同另列的交班封顶或规模门例外时，实际以A5交班不低于G4、以A4交班不低于G3、以A3交班不低于G2；曾达到A4以上、最终仍以A3以上交班、相对接手没有净下降且恶化未达严重者不低于G3。颙琰、司马师、孟昶、萧鸾已按该门完成逐人重裁，无需回退。该下限不读取名望，也不保护峰值或主态高而交班崩坏者；李隆基式`A5→A1`、李治式高位接手后明显退步，仍按回落、交班和归责重罚。

额外破坏归责与轨迹恶化不得重复消费同一后果。若某项战争、工程、征发或制度失灵已经通过交班回落、稳定分下降或恶化扣减进入能力轨迹，DA只能结算尚未被这些结果变量吸收的剩余主动成本；复核M3时，同一DA不得既把人物降整档，又在降档后再次强制置于LOW。只有DA4，或DA3与交班相对接手出现真实净下降轴，或DA与独立的广泛回落、低位交班、可归责恶化共同成立时，才允许成本改变整档。

政权规模是建设难度约束，不改变`I2.C1—I2.C4`对本政权内部结果的原始判断。第二项`I2.C4`以统一逐人字段`m3_governance_scale_adjudication`区分四类上游裁决：`FULL_OR_MAJOR_ACTUAL_SCALE`、`LIMITED_ACTUAL_SCALE`、`MATERIAL_SCOPE_LIMIT_ONLY`、`UNRESOLVED`；M3再投影为`LIMITED_REGIONAL`、`FULL_OR_MAJOR_REGIONAL`、`UNRESOLVED_NOT_HIGH_GRADE_GATE`三种规模门状态。只有正式子项明确实际治理尺度有限，或本人窗口的实际控制范围破碎，才能进入`LIMITED_ACTUAL_SCALE`并触发`LIMITED_REGIONAL`。材料只覆盖局部地域、单一群体或短时段，只能记为`MATERIAL_SCOPE_LIMIT_ONLY`，降低证据外推范围，不能伪装成小政权；C1复杂度`MEDIUM`属于主要区域，不得解释为有限尺度。每条已解决裁决必须保存正式子项字段路径、逐人依据和正式文件引用；不得把关键词缺失解释成`FULL_OR_MAJOR_REGIONAL`。`LIMITED_REGIONAL`且没有任何一轴形成历史罕见六档主态者最高止于G4，即使恢复幅度较大，也不能与完整或主要区域复杂度下的五档建设者平齐；达到六档主态者才解除该封顶，仍须通过建设、保留和成本复核。`UNRESOLVED_NOT_HIGH_GRADE_GATE`只允许用于G3及以下；拟进入G4/G5者必须先取得正式子项支持的明确规模裁决。规模门不得由人物姓名、朝代标签、政权名称、知名度或材料数量临时触发。

档内`LOW / MID / HIGH`继续比较既有恢复分、实现高度、保留度、回落和成本。G0内部不得再由“一档交班”单独强制置于LOW：LOW要求DA4残余主动成本，或本人窗口内至少两轴相对接手发生净下坠；严重但部分归责、没有多轴净下坠者置于MID；接手即一档、全窗没有净下坠且没有残余主动成本者不得与本人主动制造多轴崩坏者同分。G5恢复分低于22、峰值未达A5、存在多轴回落或DA3以上成本者止于LOW。恢复分至少22、达到A5且只发生有限单轴回落者可进入MID，即使交班组合因该回落落到A4；只有恢复分至少25、A5完整保留、稳定兑现充分且没有明显成本限制者才能进入HIGH。G4恢复分至少15、三轴均以四档以上交班、回落不超过一轴且主动成本不高于DA2者进入HIGH；完整A4建设或高位守成达到G4而未满足该强端者置于MID，有限区域规模、明显回落、DA3或独立恶化者置于LOW。

### 3.1 非规范示例

人物示例不构成规则或保档依据；上游变化后统一重验抽象条件。

G3还接纳一条“完整A3稳定交班”路线：即使只有单轴改善，只要交班三轴均不低于三档、改善得到保留、没有峰值回落且稳定分达到6，也不再视为明显短板。G3内部，A4交班且稳定分达到12、相对接手没有净下降，完整A4交班且恢复分达到10，或A4交班、恢复分达到6、没有独立恶化且残余主动成本不高于DA1者，应优先置于HIGH；恢复分达到8且三轴改善全部保留，或恢复分达到8、至少两轴保留且稳定分达到8者，同样进入HIGH。恢复分达到4、至少两轴保留、稳定分达到7.5者，在DA不高于DA2时也可置于HIGH。完整A3稳定交班者在DA不高于DA2时可置于HIGH，DA3则限制在MID，使“明确向上但尚未构成强长板”与停滞、失衡人物形成可见区分。稳定分偏低不得单独把完整三轴向上轨迹压出G3或压入LOW；LOW须另有多轴回落、独立恶化、低位交班，或低位且未稳定兑现。G2内部同理：DA3不得单独触发LOW；三轴保留且恢复分达到6，或中位局面得到长期稳定维持者，可优先置于HIGH，但交班仍在A1/A2者继续受实现高度限制。逐轴跨档数只用于说明建设覆盖和回落结构，不得再次替代恢复分计量建设量。小政权因规模门落G4者固定止于G4-LOW。最终雷达值仍按总合同固定表投影，本轮不修改统一投影，不按分位数、正态化、人物姓名、政策数量或材料数量决定档位及位置。

## 4. 全池敏感性与边界复核

档界变更先筛当前规范池全体正式记录，再重审全部命中及同类语义影响对象；不自动重算无影响者。报告：

- 新旧档位分布和全部跨档人物；
- 每条边界的`LOW / HIGH`人物，不只列著名人物；
- 建设型、高位守成型、正负抵消型、低位停滞型和崩坏型锚点；
- 同一绝对局面组合因任内动态、归责或交班不同而分档的对照；
- 四子项是否发生实际调整及证据原因；没有新证据时不得为配合M3反向改分。

历史由Git保留；当前只发布正式JSON及同值Markdown，不留旧敏感性或阶段摘要镜像。

## 5. 旧检索材料与去重

既有检索、覆盖与父链继续按以下用途消费：

1. 能补充生活、生产、税役、财政健康、市场、币制、粮储、公共工程或社会安全结果者，先进入对应C1、C2或C3正式裁决；
2. 能闭合本人接受、拒绝、维持、停止、修改、反馈后再选择及可归责成本者，进入C4和M3行为链复核；
3. 泛朝代制度史、错人物、错时间窗、只有建议未执行或无法绑定本人实权窗口者继续保持背景或轴外；
4. 同一材料在一人内部只保留一个父级行为链，不因税收、民生、市场和财政多个标签重复计功或扣责；
5. M3不得把已在`I2.C1—I2.C4`消费的同一结果再次称作独立收益或损害。
