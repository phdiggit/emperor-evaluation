# M3 民生财政建设

> 状态：`FORMAL-V2.0 / FORMAL_CURRENT`。M3不再评价“是否能找到本人财政动作”或“财政工具理解能力”，而是把第二项财政民生的C1、C2、C3、C4统合为人物卡上的民生财政建设轴。四子项先在第二项完成正式裁决，M3只做确定性同步，不另设结果之外的能力加减分。

## 1. 轴命题

M3回答：

> 本人实际权力窗口内，民生绝对状态、经济与财政健康、社会安全，以及可归责的恢复、承压和恶化合并后，形成怎样的民生财政建设表现？

四个组成部分固定为：

| 子项 | 满量程 | 构念 |
|---|---:|---|
| C1 | 80 | 民生福祉绝对状态 |
| C2 | 35 | 经济活力与财政健康绝对状态 |
| C3 | 60 | 社会安全绝对状态 |
| C4 | -45—45 | 社会恢复、稳定承压与可归责恶化 |

M3不构成第二项的重复计分项，不进入五项综合总榜；它只是把已经正式结算的治理结果映射到人物画像和人物卡。

## 2. 唯一公式

先在第二项计算：

```text
governance_result_220 = C1_80 + C2_35 + C3_60 + C4_signed_-45_to_45
```

再同步到画像轴：

```text
M3_100 = clamp(round(governance_result_220 / 220 * 100), 0, 100)
```

负向C4可能使治理结果低于0；人物卡雷达轴下限固定为0，因此只在最后一步截断并四舍五入为标准整数雷达刻度。C1—C4原分与220分合计仍逐项保留，不得增加姓名覆写、朝代修正、分布归一、政策数量、材料数量或旧M3能力分。

## 3. 档位与档内位置

连续雷达值按下列阈值生成阅读档位：

| 档位 | M3值 |
|---|---:|
| G0 | 0—<15 |
| G1 | 15—<35 |
| G2 | 35—<55 |
| G3 | 55—<75 |
| G4 | 75—<90 |
| G5 | 90—100 |

每档内部按本档数值区间等宽三分为`LOW / MID / HIGH`。档位和位置只服务人物卡阅读，不生成轴内排名。

## 4. 旧M3材料的保留与补正

旧M3全池检索、覆盖矩阵和316条语义复核候选不作废，但角色统一改变为：

1. 补充C1的生活状态、税役负担、赈济、公共工程与家庭生产证据；
2. 补充C2的预算国库、币制信用、市场贸易、粮储与财政可持续性证据；
3. 只有直接闭合社会安全、人身财产保护、流亡、强迁、饥荒或秩序后果时，才可补充C3；不得从财政政策名称反推社会安全；
4. 本人接受、拒绝、维持、停止、修改及反馈后再选择，可补充C4归责、外生冲击分解和负向尾部；不得仅凭一次政策命令生成恢复分；
5. 泛朝代制度史、错人物、错时间窗、只有建议未执行或不能绑定本人实权窗口的材料，明确记为轴外或背景；
6. 没有旧M3候选不构成负证，也不阻止M3生成，因为正式值由C1—C4保证全池非空。

逐人处置源为：

- `config/profile/m3-c1-c4-supplement-adjudications.json`：184人和全部旧候选的四子项路由；
- `config/profile/m3-c1-c4-missing-ruler-adjudications.json`：原财政民生快照缺失10人的人工窗口裁决；
- `config/profile/m3-semantic-review-decisions.json`：旧候选原始语义复核来源；
- `config/profile/m3-coverage-matrix.json`：旧全池检索覆盖来源。

旧材料的处置状态固定为：

- `APPLIED_SCORE_CHANGE_NEW_FORMAL_RECORD`
- `APPLIED_EVIDENCE_SUPPLEMENT_NO_SCORE_CHANGE`
- `APPLIED_ATTRIBUTION_SUPPLEMENT_NO_SCORE_CHANGE`
- `ALREADY_COVERED_RESULT_CONTEXT`
- `CONTEXT_ONLY`
- `REVIEWED_NO_APPLICABLE_SCORE_OR_EVIDENCE_CHANGE`
- `SEARCHED_NO_OLD_M3_CANDIDATE`
- `AXIS_OUT_WITH_REASON`
- `AXIS_OUT_WRONG_WINDOW`
- `AXIS_OUT_UNBOUND_DYNASTIC_TREATISE`

## 5. 窗口、归责与正负一致性

C1、C2、C3必须使用同一人的实际权力窗口和绝对状态曲线；C4在同一窗口内区分自然灾害、战争、继承盘面、权臣或摄政责任与本人可归责选择。正向建设和负向恶化使用同一证据门：

- 外生灾害不能自动记为本人负分；
- 有赈济、减负或改革命令不能自动记为恢复；
- 本人持续维持失效制度、拒绝纠正、以错误工具放大冲击或向基层转嫁，必须进入C4负向归责；
- 高位守成可由C1—C3高位和C4稳定分共同体现，不要求另找改革动作；
- 低信息人物也必须有非空值，但其C1—C4裁决要明确史源限制，不能统一给默认档。
