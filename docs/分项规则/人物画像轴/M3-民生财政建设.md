# M3 民生财政建设

> 状态：`FORMAL-V3.0 / FORMAL_CURRENT`。M3以第二项财政民生C1、C2、C3、C4的正式逐人裁决为事实底座，统合判断本人实际权力窗口内的民生财政建设能力实现；它不把四项相加，不按总分线性折算，也不把任一子项档位一对一换成M3。旧M3全池检索材料继续用于补充行为、反馈、归责和交班链。

## 1. 轴命题与四类事实

M3回答：

> 接手何种民生、经济财政、社会安全和制度盘面后，本人通过创设、维持、停止、修正或反馈后再选择，形成了怎样的建设、承压或恶化轨迹，并留下何种交班局面？

四类正式事实的角色不同：

| 入口 | M3中的作用 | 禁止用法 |
|---|---|---|
| C1 | 判断生活、生产、税役负担和基本民生的绝对局面及阶段变化 | 不按80分比例换成M3 |
| C2 | 判断经济活力、财政健康、货币信用、市场与储备的绝对局面 | 不以财政高分覆盖民生或安全短板 |
| C3 | 判断人身财产、社会秩序、流亡饥荒与基本安全局面 | 不把安全后果重复计入C4 |
| C4 | 判断恢复、承压、恶化的方向、幅度、外生因素与本人可归责增量 | 不把一次命令当成已经实现的恢复 |

M3不是四项的第五次计分。四项提供不同命题的事实约束，M3重新回答整体建设模式；同一损益只保留一次核心含义。

## 2. 四步能力裁决

### 2.1 建设难度与恢复量：第一判断轴

先读C4已经闭合的`接手局面 → 任内最高已实现局面`。这是M3定档的第一判断轴，因为它最直接回答本人把既有盘面改变到何种程度，而不是只描述治下状态。

- 逐轴只消费C1、C2、C3已证实的实际局面变化，不把诏令、政策名称或意图当成恢复；
- 跨档不是等距的：跨越越高档界，所需的财政、生产、救济与秩序能力通常越强；
- 三类局面同时恢复，强于单一通道改善；同一结果不得在多个通道重复计功；
- 接手低谷只有在前任遗留、战争灾害和本人选择的归责边界闭合后才能形成难度信用，不能因起点低自动加分；
- `1→4`与`4→4`不等价，`2→5`通常强于`3→5`；但恢复量仍须接受实现高度、稳定交班和主动成本复核。

正式恢复量沿用C4逐轴难度加权事实：民生、经济财政、社会安全权重分别为`0.5 / 0.2 / 0.3`，跨越`1→2`至`5→6`的档界难度依次为`0.6 / 0.8 / 1.0 / 1.3 / 1.6`。这些数值只刻画已实现恢复的难度，不是把C1、C2、C3、C4相加，也不直接按连续分数切M3档。

### 2.2 达成的绝对高度：实现约束而非基准档

联合观察C1、C2、C3的正式主态，不求和，只判断本人最终证明系统可以运行到何种宽度：

| 组合层级 | 实质含义 |
|---|---|
| A5 | 至少两类达到五档，另一类不低于四档；形成罕见广泛高位 |
| A4 | 三类均不低于四档，或两类不低于四档且另一类不低于三档；形成广泛健康局面 |
| A3 | 三类均不低于三档，或两类不低于三档且另一类不低于二档；总体可用但存在明显不均衡 |
| A2 | 主要局面在二档附近，仍保留局部可用机制或阶段 |
| A1 | 两类以上落入一档，或整体已进入严重失保、失序与低安全状态 |

这一步只约束能力实现高度，不能提供M3基准档。A5不自动成为G5候选，A4也不自动成为G4候选：高位可能主要来自前任遗产并在本人任内普通维持或被透支；中位则可能是在崩坏盘面上完成罕见重建。主态相同者必须因建设量、压力、交班和成本不同而允许跨档。

### 2.3 稳定兑现与交班

再看`任内最高已实现局面 → 交班局面`、稳定兑现分、压力吸收和阶段反转：

- 建起来并稳定交班，才构成完整能力兑现；
- 在高压下守住高位可以证明强守成能力，但普通继承维持不能与大幅重建近似等价；
- 终局回落必须显著压档，尤其是本人反馈后继续错误选择造成的回落；
- 稳定失败不能抹去已经发生的建设。`A3→A5→A1`应表达“建设极强但持续治理与风险控制极差”，最终净化为低档时仍须保留前段能力事实。

为便于全池复核，C4动态标签继续保留：

- `RARE_RECOVERY_OR_STEADY_BUILD`：罕见恢复，或在强压力下守住高位并留下明显余量；
- `SUBSTANTIAL_BUILD`：跨主要局面形成实质建设或恢复；
- `POSITIVE_MAINTENANCE`：正向守成或温和改善；
- `LIMITED_OR_MIXED_MAINTENANCE`：维持有限，正负结果并存；
- `ATTRIBUTABLE_OR_MIXED_DECLINE`：出现可归责或外生与本人共同造成的退步；
- `SEVERE_DECLINE`：主要局面出现严重退步；
- `COLLAPSE_OR_EXTREME_DECLINE`：出现崩坏或极端退步。

### 2.4 本人主动制造的成本

最后扣除本人可选择且已实现的额外成本，包括大规模可选择兵役、财政转嫁、失效制度继续维持、反馈后继续加码以及跨通道放大。自然灾害、战争、贸易环境、前任遗留和权臣责任只有在时间、范围和机制闭合后才能解释变化。外生冲击不能自动免责；但未闭合到本人选择与残余后果的背景压力也不能反向制造扣分。

行为链复核同时检查：

最后读取旧M3已经保留的过程父链及四子项补正材料，检查：

1. 接手压力与可行替代；
2. 本人创设、维持、停止、拒绝、修改或知情不作为；
3. 工具如何落到税役、国库、币制、市场、粮储、工程和战争供给；
4. 反馈到达后本人是否再选择；
5. 成本由谁承担，是否重复转嫁；
6. 交班时的民生、财政、经济、安全和制度承载。

行为链用于解释局面变化和归责，不能脱离C1—C4结果单独制造高档。反过来，史料不足者仍须依据已闭合的绝对局面和结果方向给出克制档位，并明确过程缺口，不得套用统一默认文案。

## 3. 五条档界

六档尺度沿用人物画像总合同；本轴重订的是相邻六档之间的五条实质边界：

| 边界 | M3实质含义 |
|---|---|
| G5 / G4 | G5要求罕见重建，或强建设达到高位并稳定兑现；强压力下长期守住罕见高位也可进入，但普通高位继承维持止于G4。罕见建设若交班、持续性或主动成本存在清楚限制，落G4或G5-LOW |
| G4 / G3 | G4要求跨主要档界的强建设/恢复，或达到较高实现高度且形成稳定强长板；只有一般改善、中位守成或高位但建设证据有限者为G3 |
| G3 / G2 | G3要求可辨认的实质建设，或在中高位形成有压力含量的稳定兑现；只有局部改善、普通维持、结构失衡或成本已明显侵蚀能力净表现者为G2 |
| G2 / G1 | G2仍保留有限但实际实现的建设、纠错或可用阶段；没有可保留建设、主要局面长期低位或严重退步成为主模式者为G1 |
| G1 / G0 | G0要求本人选择造成或放大的罕见、稳定且难恢复的失能或崩坏；普通低位、短窗口失败、材料不足或外生冲击占主因不得机械压入G0 |

定档顺序固定为：先按建设/恢复量识别能力模式，再以绝对高度判断实现上限，以稳定兑现和交班判断能否保留，最后以本人主动成本净扣减。绝对主态不得决定基准档；终局封顶和主动成本也不得把已经完成的建设改写成“从未发生”。罕见重建者可越过其主态组合对应的旧档，高位普通守成者则可能低于重建型人物。

机器裁决先把三轴写成`起点向量 → 主态向量 → 交班向量`，并从C4现有`highest_achieved_band`另取最高实现向量；主态不得冒充峰值。再生成最高实现改善、交班保留和峰值回落三个向量。C4恢复分是建设恢复量的唯一正式计量，轨迹向量只判断路线、实现高度和保留度，不再次供应建设量。能力路线固定为：

| 能力路线 | 语义准入 |
|---|---|
| 罕见广泛重建 | 起点整体不高于A2，既有C4恢复分达到罕见重建强度；逐轴变化只解释建设覆盖面，不另造建设量 |
| 高位建设 | 达到A5，至少两轴改善，但不满足低谷广泛重建 |
| 高压高位守成 | 通常要求接手和交班三轴均不低于四档、至少一轴达到五档，稳定分达到12，峰值回落不超过一轴，且有独立压力、主动应对和反馈纠正；若接手完整A4、本人把至少一轴推到五档，随后仅因未归责于本人的外生冲击使交班一轴落到三档，而整体仍为A4，恢复分达到6、稳定分达到6且没有独立恶化，也按受限高位守成处理，不与普通继承维持混同 |
| 实质建设 | 至少两轴实际改善，并在交班时保留主要成果 |
| 有限改善 | 只有单轴改善，或多轴改善但大部未能保留 |
| 普通维持 | 没有独立建设量，仅保持可用局面 |
| 停滞或失败 | 没有可保留改善，主要局面长期低位或恶化 |

G5只有两条建设准入：其一，正式C4恢复分至少22，接手整体不高于A2，达到至少A4、交班仍为A4以上且至少两轴保留净改善；其二，高位建设达到并以A5交班，恢复分至少12、至少两轴保留改善且稳定分至少14。后一条允许刘询式“建设量不及深度重建、但A5保留度高”的模式进入G5下沿，却不能进入G5-MID/HIGH。普通A5守成不自动进入G5；高压守成只有在压力和主动纠错链独立闭合后才可另行竞争。

G4容纳强而不完整的建设：罕见重建或高位建设只达到A3/A4交班；达到A5但建设较浅或发生多轴回落；三轴完整建设并以四档交班、恢复分达到10且稳定分达到8；以及证据充分但未到历史罕见程度的高压守成。胤禛式高位接手、任内承压维持并以`4/4/5`交班者，不因净新增档差较小而退回一般改善路线。刘庄式`4/4/4→5/4/4→3/4/4`在末年回落已经确认以天灾为主、没有独立恶化或残余主动成本时，属于受限高位守成，进入G4；但建设只发生在单轴且交班仍有外生缺口，固定止于G4-LOW。赵昚式`4/4/3→5/5/4→4/4/4`属于峰值较高、建设较浅且两轴回落，落G4而非G5。

交班封顶必须读取三轴实际交班向量，不能拿C4T档替代绝对终局。实际交班A1通常封顶G1，但罕见广泛重建或高位建设已经形成、恢复难度达到强建设级别后再自毁者，保留G2上限；A1且恶化扣减达到极端或主动成本为DA4者进入G0。实际交班A2封顶G2，A3封顶G4。DA4在上述裁决后保留独立降一档效力；DA1—DA3主要限制晋档上限或档内位置，不得把起点—峰值—交班已经证明且仍被保留的建设改写为失败。

为避免能力画像与实际治理结果发生反直觉冲突，另设“实现表现下限”。它不是以主态定基准档，而只在初步能力裁决明显低于已实现交班局面时纠偏：没有严重恶化且没有DA4残余成本时，实际以A5交班通常不得低于G4，以A4交班通常不得低于G3，以A3交班通常不得低于G2；曾达到A4以上、最终仍以A3以上交班、相对接手没有净下降且恶化未达严重者，通常不得低于G3。该下限不读取名望，也不保护峰值或主态高而交班崩坏者；李隆基式`A5→A1`、李治式高位接手后明显退步，仍按回落、交班和归责重罚。

额外破坏归责与轨迹恶化不得重复消费同一后果。若某项战争、工程、征发或制度失灵已经通过交班回落、稳定分下降或恶化扣减进入能力轨迹，DA只能结算尚未被这些结果变量吸收的剩余主动成本；生成M3时，同一DA不得既把人物降整档，又在降档后再次强制置于LOW。只有DA4，或DA3与交班相对接手出现真实净下降轴，或DA与独立的广泛回落、低位交班、可归责恶化共同成立时，才允许成本改变整档。

政权规模是建设难度约束，不改变C1—C4对本政权内部结果的原始判断。正式子项已经明确“小政权尺度/规模”者，M3标为`LIMITED_REGIONAL`：没有任何一轴形成历史罕见的六档主态时，最高止于G4；即使恢复幅度较大，也不能与大政权五档建设者平齐。达到六档主态者才解除该封顶，仍须通过建设、保留和成本复核。规模门不得由人物姓名、朝代标签或知名度临时触发，只能读取正式子项中的尺度裁决。

档内`LOW / MID / HIGH`继续比较既有恢复分、实现高度、保留度、回落和成本。G0内部不得再由“一档交班”单独强制置于LOW：LOW要求DA4残余主动成本，或本人窗口内至少两轴相对接手发生净下坠；严重但部分归责、没有多轴净下坠者置于MID；接手即一档、全窗没有净下坠且没有残余主动成本者不得与本人主动制造多轴崩坏者同分。G5恢复分低于22、峰值未达A5、存在多轴回落或DA3以上成本者止于LOW。恢复分至少22、达到A5且只发生有限单轴回落者可进入MID，即使交班组合因该回落落到A4；只有恢复分至少25、A5完整保留、稳定兑现充分且没有明显成本限制者才能进入HIGH。G4恢复分至少15、三轴均以四档以上交班、回落不超过一轴且主动成本不高于DA2者进入HIGH；完整A4建设或高位守成达到G4而未满足该强端者置于MID，有限区域规模、明显回落、DA3或独立恶化者置于LOW。

G3还接纳一条“完整A3稳定交班”路线：即使只有单轴改善，只要交班三轴均不低于三档、改善得到保留、没有峰值回落且稳定分达到6，也不再视为明显短板。G3内部，A4交班且稳定分达到12、相对接手没有净下降，完整A4交班且恢复分达到10，或A4交班、恢复分达到6、没有独立恶化且残余主动成本不高于DA1者，应优先置于HIGH；恢复分达到8且三轴改善全部保留，或恢复分达到8、至少两轴保留且稳定分达到8者，同样进入HIGH。恢复分达到4、至少两轴保留、稳定分达到7.5者，在DA不高于DA2时也可置于HIGH。完整A3稳定交班者在DA不高于DA2时可置于HIGH，DA3则限制在MID，使“明确向上但尚未构成强长板”与停滞、失衡人物形成可见区分。稳定分偏低不得单独把完整三轴向上轨迹压出G3或压入LOW；LOW须另有多轴回落、独立恶化、低位交班，或低位且未稳定兑现。G2内部同理：DA3不得单独触发LOW；三轴保留且恢复分达到6，或中位局面得到长期稳定维持者，可优先置于HIGH，但交班仍在A1/A2者继续受实现高度限制。逐轴跨档数只用于说明建设覆盖和回落结构，不得再次替代恢复分计量建设量。小政权因规模门落G4者固定止于G4-LOW。最终雷达值仍按总合同固定表投影，本轮不修改统一投影，不按分位数、正态化、人物姓名、政策数量或材料数量决定档位及位置。

## 4. 全池敏感性与边界复核

每次档界变更必须对184人全池同时运行，并发布：

- 新旧档位分布和全部跨档人物；
- 每条边界的`LOW / HIGH`人物，不只列著名人物；
- 建设型、高位守成型、正负抵消型、低位停滞型和崩坏型锚点；
- 同一绝对局面组合因任内动态、归责或交班不同而分档的对照；
- 四子项是否发生实际调整及证据原因；没有新证据时不得为配合M3反向改分。

敏感性审计位于`docs/评分结算/皇帝人物画像/M3/30-M3对第二项C1-C4逐人补正审计.json`。它保存旧线性档位、新语义档位、跨档记录、边界人物和典型锚点，但旧档位不进入正式人物记录。

## 5. 旧检索材料与去重

旧全池检索、覆盖矩阵、316条语义候选和204条父行为链均不作废：

1. 能补充生活、生产、税役、财政健康、市场、币制、粮储、公共工程或社会安全结果者，先进入对应C1、C2或C3正式裁决；
2. 能闭合本人接受、拒绝、维持、停止、修改、反馈后再选择及可归责成本者，进入C4和M3行为链复核；
3. 泛朝代制度史、错人物、错时间窗、只有建议未执行或无法绑定本人实权窗口者继续保持背景或轴外；
4. 同一材料在一人内部只保留一个父级行为链，不因税收、民生、市场和财政多个标签重复计功或扣责；
5. M3不得把已在C1—C4消费的同一结果再次称作独立收益或损害。

逐人机器裁决源为`config/profile/m3-livelihood-adjudications.json`；旧材料路由源仍为`config/profile/m3-c1-c4-supplement-adjudications.json`、`config/profile/m3-semantic-review-decisions.json`和`config/profile/m3-coverage-matrix.json`。
