# 人物画像分项规则：M3 财政经济约束理解与工具适配

M3评价本人对财政经济约束的理解、工具选择和克制，而不是第二项治理净收益的另一种写法，也不是“改革力度”或政策创新数量。固定观察：

1. 税役、货币、预算、国库、市场、贸易、粮储、赈济和公共工程之间的约束识别；
2. 政策目标、替代方案、受益者、承担者、执行转嫁与时间成本是否明确；
3. 面对战争、灾荒、价格、亏空和既有制度惯性时如何排序、止损或维持；
4. 市场、基层、官僚和财政反馈到达后是否修正工具；
5. 工具能否在不同压力场景复验，而非只凭一次措施、改革名目或后世繁荣。

M3必须把`intervention_intensity`与`judgment_quality`正交处理。改革、立法、专卖、工程和新机构的数量只描述干预强度，不进入档位公式；积极干预增加的是可观察机会和潜在反证，不自动形成正证。守成、延续稳定制度、拒绝币制折腾、停止不经济工程、保留财政余量或在没有合适工具时克制行动，只要闭合当时压力、可行替代、本人理由与后续验证，同样可以构成强正证。没有改革机会或未见经济建设措施只形成材料或机会限制，不冒充负证。

第二项A/B/C及财政民生事实同时承担事件导航和结果复验，但第二项总分、单项分数或档位不得按比例换算M3。C1/C2状态曲线、现C4恢复/恶化归责，以及旧D2留下的交班窗口材料共同组成`RESULT_VALIDATION`；旧D2分数已退役，只可消费其底层交班材料。结果账不能凭空生成本人理由、备选方案和反馈后选择，却必须参与三件事：为弱行为材料提供有界低置信推断、校验行为链的实际方向、触发“行为判断与长期结果矛盾”复核。同一恢复成果不得拆成税收、民生、市场和财政四次证明。货币、税制、专卖、贸易或公共工程出现反证时，必须闭合本人是否收到反馈及反馈后的选择；后世崩坏只作脆弱性验证，不把继任期全部结果倒算本人。

## 过程证据与显现能力双通道

M3不能把“史书明确记载了多少财政决策”当作能力本身。正式裁决必须同时建立两条相互约束的证据通道：

1. `PROCESS_CHANNEL`：压力、备选、本人接受/拒绝/修改/停止/维持、工具与承担者、执行、反馈和再选择；回答能力通过什么机制显现。
2. `REVEALED_CAPABILITY_CHANNEL`：C1/C2从可比起点到主态、终点的变化，现C4识别的恢复或恶化，旧D2底层材料反映的交班承载；回答本人窗口出现了多大、多久、是否可持续的财政经济超额结果。

结果通道不是把C1/C2/D2档位复制成M3档位，而是做反事实解释。每人须保存：

- `observed_transition`：C1/C2的`S0 → S_avg → S_end`及达到主态所需时间；
- `natural_recovery_envelope`：同类战争结束、低基数、和平、气候和前任制度成熟在没有额外高水平判断时，通常能够解释的恢复范围；
- `alternative_explanations`：丰收、人口回流、贸易环境、前任制度、官僚自治等已闭合替代原因；
- `unexplained_result_residual`：观察结果扣除自然恢复包络和替代原因后仍需解释的部分；
- `terminal_validation`：C1/C2终点、现C4动态和旧D2交班材料是否支持该能力具有持续性。

当`unexplained_result_residual`显著为正时，不能因为缺少政策名目就把人物放回统一中性值。裁决者必须二选一：要么以史料闭合足以解释超额结果的其他原因，要么登记`REVEALED_CAPABILITY_WITH_MECHANISM_GAP`，把超额结果作为低于同等过程直证、但高于纯背景的M3正证。反之，若过程材料看似优秀而C1/C2持续恶化、C4负向或交班承载下降，必须解释外生冲击；解释不了就不能维持高档。

负向残差必须与正向残差完全对称处理。若本人实际权力窗口内C1、C2或旧D2底层交班状态发生跨档退步，而当前M3没有对应负向举措、拒绝纠正、错误工具、财政转嫁或失控运行链，不得据此宣布“未见负证”，必须登记`NEGATIVE_EXPLANATORY_COVERAGE_GAP`并反向回搜。回搜从发生退步的阶段和机制出发，至少覆盖：

1. 加税、加派、横征、役使、工程和战争供给是否超过民力与财政承载；
2. 币制、信用、价格、专卖、贸易和储备工具是否发生反复、失配或透支；
3. 地方亏空、官僚转嫁、豪强侵蚀、征收失真和救济失灵是否已被中央知悉；
4. 收到奏议、市场、灾荒或基层反馈后，本人是否不从、不纳、拖延、反复恢复原政策或仅作局部止损；
5. 即使没有一纸明确“负面新政”，是否因维持已失效制度、拒绝必要调整、财政优先级错误或放任执行转嫁而形成负向能力证据。

回搜后须把下降拆为`EXOGENOUS_EXPLAINED`、`INHERITED_OR_SCOPE_EFFECT`、`RULER_ATTRIBUTABLE`和`UNRESOLVED_RESIDUAL`四部分。战争、灾害、气候、疫病、贸易环境和前任遗留只有在时间、范围和作用机制闭合时才能解释下降，不能作为笼统免责项。现C4已经闭合本人造成或显著放大的负向结果时，应优先定位相应过程链；若仍找不到具体举措，允许登记`REVEALED_NEGATIVE_CAPABILITY_WITH_MECHANISM_GAP`，以低于同等过程直证的置信度形成负向M3证据，但不得继续保留与结果明显冲突的高档。材料缺口描述的是机制尚未找到，不是损害没有发生。

自然恢复包络必须由同起点、同压力类型和相近窗口的全池参照组建立，不能凭直觉给“战后自然恢复”无限上限。低基数反弹通常能解释从崩坏到基本恢复，却不能自动解释快速进入全池罕见高位、跨多年维持并留下可承接余量。极端结果的稀有度本身就是反事实证据，但材料稀有度和结果稀有度均不得单独决定G档。

检索顺序因此不是“先搜到多少政策，再看能打几分”，而是双向迭代：先由压力事件建立过程候选；再由C1/C2/C4/D2结果曲线识别过程材料解释不了的超额恢复、异常恶化或交班断裂；随后针对该残差回搜税役、币制、预算、工程、战争供给、储备、市场与地方执行机制。若结果残差很大而检索只得到一个著名政策，必须判定为`EXPLANATORY_COVERAGE_GAP`，不能把该政策当作全部因果，也不能把其余残差当作自然恢复自动抹除。

过程厚度与结果残差分别定级，不先压成一个机械分数：

| 级别 | 过程通道 | 结果通道 |
|---|---|---|
| 0 | `P0`：没有可归责选择 | `R0`：低于可比包络，或绝对退步已越过负向阈值 |
| 1 | `P1`：一个决策片段或单次止损 | `R1`：位于包络内、持续性不足，或因`SOURCE_UNAVAILABLE`只能有界判断 |
| 2 | `P2`：两个独立机制，或一条闭合反馈生命周期 | `R2`：多轴或快速超出包络，并有阶段持续性 |
| 3 | `P3`：闭合`REGIME_CHAIN`，含落实、反馈和反例 | `R3`：全池罕见的建设跃迁或高位承压，且交班材料基本支持 |
| 4 | `P4`：跨阶段、跨压力复验且主动修正反向机制 | `R4`：罕见结果跨阶段稳定并形成强交班余量 |

G档由两通道的组合语义裁决：`P0`即使出现高`R`也只能发布有机制缺口的G3上限；`P1`不能仅因结果很强直接越过G3，因为单一事件无法解释整个残差；`P2 + R2/R3`且方向一致时才进入G4候选；`P3`与`R2`以上收敛、反例受控时支持G4；只有`P4 + R3/R4`且退出窗口不破坏主模式时才进入G5候选。过程与结果方向相反时不得取较高一侧，必须先完成矛盾归因。负向结果若主要由外生灾害或战争造成、现C4未闭合本人放大，不得倒推低能力。

正式阈值先由`R0—R3`及组内残差确定结果基准，再按`P0—P2`与过程方向作有限步进；方向矛盾统一下调一步，且`P0—P2`封顶`G3-HIGH`。`P3+R3`只有在非负向主导、闭合`REGIME_CHAIN`并通过高档复核时落`G4-LOW`；`P3+R0`负向运行链封顶`G0-HIGH`。`P4`缺席时不产生G5。完整步进表、特殊门和验收门只在`config/profile/m3-calibration-thresholds.json`维护，任何姓名覆盖、第二项档位换算或政策数量加分均为非法输入。

李世民是本轮首个强制校准例：当前结果曲线为`C1 2→5→4`、`C2 3→4→4`、现C4四档、旧D2交班四档；在正式池中，他是唯一一个C1从二档以下进入五档主态者。这个跃迁不能由一个义仓事件解释，也不能全部塞进“战后自然恢复”。过程回搜至少应覆盖拒修长城、停止洛阳宫役、停止河西招慰、义仓、因民力与仓廪停止封禅及外使供亿、因山东凋敝两次暂缓高丽战争，以及晚期军旅宫室反向加压。若这些跨税役、储备、工程、外交供亿和战争财政的选择闭合为阶段运行组合，则应按`P3 + R3`的G4候选审查，而不是按政策数量加分。李治当前只有一条停止造船止损链，却承接`C1/C2 4/4`后交班降至`3/2`、现C4负向、旧D2三档；在没有更多过程链和外生解释前，不得与李世民同档同位。刘启的高位守成则须按低税制选择、七国之乱与灾害承压、`C1/C2 5/5`和旧D2四档另建守成型组合，不能因建设增量较小自动降档，也不能与李世民共享同一理由。

拟`G4/G5`不能靠改革密度、措施广度或一个著名改革包成立，必须在至少两类不同财政经济约束下闭合本人理解—工具—落实—反馈生命周期，并复核改革转嫁、货币信用、长期财政承载或对市场与基层的反作用。材料若只覆盖财政民生结果、缺少工具设计和本人判断过程，最高只能发布`E1/E2`有界画像，不得用盛世、恢复幅度或改革名望补成全貌级高档。

M3与C1、C2采用主命题去重：跨领域资源优先级归C1，稳定的信息更新模式归C2，财政经济约束与工具适配归M3。落实深度只增强M3父链，不生成撤销的画像C4收益。同一事件可作辅助复验，但不得消费同一正向或负向收益两次。

## 规范检索入口与压力事件法

M3不以第二项C1/C2为母表生成父链。全池检索至少并行覆盖以下入口：

1. 历代正史《食货志》及性质相同的财政制度志、会要食货门；
2. 本纪、编年与实录中的灾荒、战争军费、国用不足、价格与钱荒、币制/加税/工程建议、漕运困难、地方亏空和财政反馈；
3. 已登记的制度、财政、工程材料，用于发现候选决策；
4. 第二项财政民生结果用于发现压力、建立低置信结果先验和复验后果，原记录固定记作`BACKGROUND_VALIDATION`；若其中附有可定位的本人选择原文，则须脱离原档位重新按M3字段裁决，生成独立的`SECOND_ITEM_NAVIGATION_RECUT`单元，原记录本身仍不得成为`SCORING_PARENT`。

跨档升降只是加深检索的触发器，不是进入M3检索的门槛。无论C1/C2/D2是否跨档，每名人物都必须建立“阶段×机制×选择类型×史源入口”覆盖矩阵：

- 阶段：权力起点、早期、中期、晚期、退出/交班；
- 机制：税役、预算与国库、币制信用、市场贸易、粮储赈济、公共工程、战争财政、中央—地方财政转嫁；
- 选择类型：创设、维持、停止、拒绝、修改、收到反馈后再选择，以及知情后不作为；
- 史源入口：本纪与编年、正史《食货志》及会要、制度行政登记、第二项A/B1/B2/C1/C2/C4、旧D2底层材料、本地通读缓存和可定位专题史料。

每个格子必须保存`SCORING_PROCESS_FOUND`、`REGIME_CONTEXT_FOUND`、`RESULT_VALIDATION_ONLY`、`SEARCHED_NO_HIT`、`SOURCE_UNAVAILABLE`或`AXIS_OUT_WITH_REASON`之一。`SEARCHED_NO_HIT`证明完成了规定检索，不证明本人没有采取行动；`SOURCE_UNAVAILABLE`必须进入时代覆盖偏差统计。不得用预先挑选的候选ID白名单决定谁可以进入语义复核，也不得因为一个人物没有跨档就停止搜索。

召回须同时采用三条路径：按人物讳名、庙号、年号、帝号和实际权力窗口检索；按在位时间内的财政经济主题检索，即使段落没有再次写出皇帝姓名；按C1/C2/C4/D2阶段结果回溯可能机制。只有三路合并后才做逐条语义处置，关键词和命中数量均不裁档。

结果曲线表面持平也必须区分至少四类：`HIGH_LEVEL_MAINTENANCE_UNDER_PRESSURE`表示在灾荒、战争或财政压力下守住高位；`NO_PRESSURE_STABILITY`表示缺少压力测试，只形成弱证；`OFFSETTING_POSITIVE_AND_NEGATIVE`表示改善与损害相互抵消，不能用净零掩盖两组行为；`LOW_LEVEL_STAGNATION_WITH_OPPORTUNITY`表示存在改善窗口却长期停滞，须回搜工具缺失、优先级错误或执行转嫁。高位守成、低位停滞和正负抵消都可能没有跨档，但其M3含义完全不同。

程序不得把候选摘要改写成“本人窗口内的可定位选择”，不得用“所载选择及其反面”代替真实备选方案，也不得把同一摘要尾部复制为反馈。任何一个字段没有独立史料内容就必须保留缺口。命中决策词、结果词或具名窗口只完成召回，不能自动形成父链。

候选事件采用分层闭合，不以完整生命周期作为所有材料的准入门槛：

1. `DECISION_FRAGMENT / MI1_CASE`：至少闭合财政经济压力或约束、可归责到本人的接受/拒绝/修改/停止/维持选择、所用机制与史源。理由、完整备选、承担者或反馈暂缺时必须逐项记入`evidence_gaps`，只能证明该判断曾出现；
2. `DECISION_CHAIN / MI2_LIFECYCLE`：在上述基础上，进一步闭合可行替代、理由或承担边界，并有执行反馈；
3. `RETESTED_LIFECYCLE / MI3_SUSTAINED_SYSTEMIC`：反馈到达后有可定位的再选择，或同一约束在独立场景中复验，才可作为长期典型模式锚点；
4. `SUSTAINED_SYSTEM / MI4_CROSS_PHASE_SYSTEMIC`：跨阶段、跨机制稳定成立，且反证检索不能推翻主模式。

除离散事件链外，M3必须允许建立`REGIME_CHAIN`。它不是把若干政策名目相加，而是重建同一阶段反复出现的财政经济运行组合，例如：稳定税役上限、避免额外征调、维持币制、在宫室/战争/外交供亿与民力之间持续排序、建立储备与赈济接口、让地方执行和反馈能够纠偏。`REGIME_CHAIN`至少需要：

1. 两种以上独立财政经济约束；
2. 三个以上不同时间点的本人选择或明确维持；
3. 至少一条落实或反馈材料；
4. 对应的C1/C2阶段结果及替代原因审查；
5. 同阶段反例和退出窗口。

`REGIME_CHAIN`解决的是“持续运行组合如何产生超额结果”，不能由改革名称、结果摘要或A/B治理手段总档自动生成。A/B材料只能切出其中与财政经济工具直接相关的执行、地方传导和反馈部分。

因此，缺少反馈不应把一条可归责命令排除出M3，只会限制其材料强度、证据等级和档位上沿；反过来，只有宏观结果、制度沿用或压力叙述而没有本人选择，不能成为`PROCESS_CHANNEL`父链，但可以在扣除自然恢复包络和替代解释后进入`REVEALED_CAPABILITY_CHANNEL`。不得用结果账补齐缺失的过程字段。

检索词须同时覆盖积极干预与克制行为。基础决策词包括“罢、止、不许、勿增、不增、不加、不加赋、仍旧、照旧、不可、不便、从其议、却之、缓、省、减、蠲、免、裁、撤、禁、许、听从、采纳、改、更张、诏、命、行、置、建、增、加”。其中“免”不得孤立命中：只有与税、赋、役、租、粮、逋欠、债、征、输等财政对象近距离共现，或上下文明确为减免财政负担时，才进入M3候选；赦免、免官等一律排除。

《食货志》中的跨任期繁荣、户口、仓储、岁入或市场总评不能直接成为过程父链，但可作为结果曲线和超额残差的史源。只有能绑定到具体皇帝窗口并至少闭合压力、本人裁决、财政机制和史源的段落，才可能作为`MI1_CASE`过程父链；建议/方案、理由、承担边界、执行反馈与反馈后再选择的闭合程度，决定其能否升为`MI2`以上，而不是决定它能否被看见。食货志卷次覆盖、关键词命中数和改革条目数均不参与档位计算。

`E1`通常由一个闭合到本人选择的`MI1_CASE`成立；`E2`须有两个独立机制/情境的`MI1_CASE`，或一条真正闭合反馈的`MI2_LIFECYCLE`；`E3`须覆盖主要阶段和机制，并有复验型父链。正式池任何人物都必须发布轴值：完成规定检索后仍找不到可归责选择时，允许发布`E1/RESULT_CONSTRAINED_INFERENCE`低信息轴值，但必须同时满足以下限制：

1. 禁止全员统一中性落点。必须同时读取C1/C2起点、主态、终点，现C4动态方向及可得的旧D2交班材料，区分强建设、健康守成、混合结果、持续低位与显著恶化；
2. 结果材料只形成窄幅、低置信的推断先验，不生成能力父链，不允许仅凭结果进入G4/G5，也不得把C1/C2/D2原档位一对一复制为M3档位；
3. 必须保存`result_validation`、`value_mode = RESULT_CONSTRAINED_INFERENCE`、结果与本人能力之间的归责缺口，以及未观察到本人选择的明确限制；
4. 一旦补得可归责行为链，必须退出基线模式并按行为与过程重新裁档。

对已有行为链者，行为与过程决定能力主档，`RESULT_VALIDATION`决定置信度、档内位置和矛盾复核，不能被完全隔离。单条止损命令不得因命中“停止、减负”直接达到多机制持续复验者的档位；强行为正证若与C1/C2终点、C4动态或D2交班材料明显冲突，必须解释外生冲击、时段错位或反向机制，解释不了就降置信度或重裁。相同分值若对应显著不同的结果轨迹与行为厚度，必须逐对给出等值理由，不能依赖硬编码表或默认值。

因此，`E0`只表示规定检索尚未完成的工作状态，不得进入正式输出；默认延续、和平恢复或“未找到正证”仍不能写成本人高水平、普通或负向能力事实。
