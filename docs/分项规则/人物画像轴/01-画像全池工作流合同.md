# 画像全池工作流合同

> 本文是[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)的职责拆分章节；共同字段与发布边界见[共同数据与发布合同](00-共同数据与发布合同.md)。本次拆分只改变合同物理位置，不改变评分语义、正式数据或验收结论。

按[画像总合同第2.7节](../../项目总纲/皇帝人物画像评估体系合同.md#27-机械筛选与语义裁决隔离)先建全池清单，再做有范围的语义复核。全池清单用于防漏，不等于穷尽史料。

1. 以稳定`task_code = PROFILE-{axis_code}-{ruler_id}`建立人物—轴矩阵；
2. 按轴连接相关且可取得的正式入口，记录不适用、不可得、未命中和背景材料；
3. 优先闭合有诊断力的父情境，记录人物、阶段、行为、归责、反馈、结果和史源；
4. 以代表性样本和风险对象做横向校准，再发布有界的单人人物画像；
5. 外部反差只作校准，不先改分数再回填规则；
6. 共同合同、schema、轴边界或高风险规则变化才重跑全池影响矩阵，局部修改只复核受影响轴和人物。

矩阵、外部对照与日志放`.tmp/`，不自动升正式。
