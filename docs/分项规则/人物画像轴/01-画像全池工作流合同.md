# 画像全池工作流合同

> 评价原则见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)，字段和发布方式见[共同数据合同](00-共同数据与发布合同.md)。

全池清单用来防漏人，不要求查遍每个人的全部史料。按以下顺序工作：

1. 为每个人、每个轴建立稳定`task_code = PROFILE-{axis_code}-{ruler_id}`。
2. 连接相关且可取得的材料，注明不适用、不可得、未找到和背景材料。
3. 优先整理最能判断本轴的经历，说清本人行为、阶段、责任、反馈、结果与史源。
4. 用代表人物和疑难对象作同轴比较，形成逐人裁决并说明适用范围。
5. 外部印象只提醒核查，不先改分再找理由。
6. 局部修改只复核受影响的人物与轴；共同合同、数据结构、轴边界或高风险规则变化才重查全池影响。

矩阵、对照和日志放`.tmp/`，当前裁决及必要依据写回正式记录。
