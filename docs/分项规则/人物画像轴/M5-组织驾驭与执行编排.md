# M5 复杂组织驾驭与执行编排能力评估合同

> `DRAFT-G2 / COMPLEX-ORGANIZATION-ORCHESTRATION`

本轴评价本人能否把复杂国家任务拆解到多个责任中心，通过授权、协调、监督、信息回流、替补和故障处理，使组织在本人无需逐项亲自操作的情况下持续协同执行。

本轴评价的是**本人驾驭复杂组织的过程能力**，不是行政结果本身。

## 1. 适用性与评价对象

本人实际控制行政、军事或混合组织，并有机会决定任务分工、责任中心、权限、协调和监督方式时适用。

极短窗口、纯名义统治、被完全架空且没有实际组织调度权时，可以判 `NOT_APPLICABLE`。

组织规模小不自动降档；但高档必须存在足以测试多中心协调的复杂任务。

## 2. 核心问题

每个G2父情境至少回答：

1. 当时需要完成什么复杂任务？
2. 任务包含哪些相互依赖的子问题？
3. 本人如何拆分任务和责任？
4. 设置了哪些真实责任中心？
5. 各中心获得什么权限、资源和自主空间？
6. 多中心之间如何协调、传递信息和处理冲突？
7. 本人如何监督进度而不把全部事务重新收回最高层？
8. 某中心失败、失职、失联或环境变化后如何替补和调整？
9. 整套安排能否持续完成任务？
10. 成功究竟来自本人编排，还是某一名臣、成熟官僚机器或资源优势自行兑现？

## 3. 主判维度

### A. 任务分解

能否把复杂问题拆成边界清楚、相互衔接的责任包，而不是所有事务混在最高权力中心。

### B. 权责匹配

是否把真实权限、资源和责任同时交给执行中心。

只任命负责人但不给权限，不构成强正证。

### C. 多中心协调

能否处理部门、地区、军政、中央地方或不同专业中心之间的信息、资源和目标冲突。

### D. 监督与信息回流

最高权力是否能获得足以判断执行状态的信息，并在不摧毁正常授权结构的情况下监督。

### E. 故障与替补

负责人失能、执行失败、地方阻滞或资源条件变化时，能否及时换人、改任务、增减权限或重组接口。

### F. 去个人依赖

组织能否在本人不逐项亲自处理的情况下完成任务。

“本人特别勤奋、事必躬亲”不自动形成高G2；若持续造成最高层吞吐瓶颈，反而是负证。

## 4. 不得直接替代G2的事实

以下均不能单独换档：

* 国家行政结果很好；
* 官僚机器历史上成熟；
* 名臣很多；
* 本人非常勤政；
* 命令很多、批阅很多；
* 一个特别优秀的宰相或将领成功；
* 战争最终胜利；
* 国家财政或人口规模巨大；
* 单次授权成功；
* 机构设置数量多。

结果只能验证组织编排是否工作，不能代替本人过程证据。

## 5. 与“用人能力”的区别

C3父链主要是：

**任务 → 人选 → 岗位 → 权限 → 个人交付 → 反馈 → 续用/调整**

G2父链主要是：

**复杂任务 → 多任务分解 → 多责任中心 → 权责结构 → 横向协调 → 信息监督 → 故障替补 → 系统交付**

因此：

* 选中萧何，是C3问题；
* 把关中留守、粮运、前线、诸侯协调构造成能够同时工作的责任体系，是G2问题。

一个统治者可以C3极高但G2一般：很会找人，却不会让多个强人共同工作。

也可以C3普通但G2较高：个人识人未必历史级，却善于依靠稳定规则、岗位和替补机制使组织持续运行。

## 6. 正负证据

### 强正证

* 同时维持三个以上高依赖责任中心，并能持续闭合复杂任务；
* 跨中央—地方、军—政、财政—行政或多个专业中心形成稳定协调；
* 能给予足够自主权，又保持可用监督和信息回流；
* 一个核心负责人失效后能迅速找到替补而系统不停摆；
* 多个不同任务或阶段反复证明同类组织驾驭能力；
* 高压力下仍能保持责任边界和执行秩序，而不是临时全部收回本人。

### 强负证

* 事权长期过度集中于本人，形成明显决策吞吐瓶颈；
* 权责不匹配，负责人有责无权或有权无监督；
* 多个机构并行却反复冲突、互相否决或争夺资源；
* 依赖单一名臣或单一亲信，核心人物退出后系统明显失灵；
* 反馈到达后仍无法修复执行结构；
* 频繁越过正式责任中心下达矛盾命令；
* 组织失灵后只能靠非常动员、个人亲自处理或持续清洗维持；
* 不同阶段重复出现相同的协调和替补故障。

## 7. G0—G5轴内门槛

| 档位     | G2语义                                                                       |
| ------ | -------------------------------------------------------------------------- |
| **G5** | 在多个独立高复杂度任务和主要阶段，反复表现出历史罕见的任务分解、授权、协调、监督和替补能力；多个责任中心可长期独立工作，局部失效不致使系统整体停摆。 |
| **G4** | 明显强于一般合格统治者，能够稳定驾驭多中心复杂组织，并在主要故障中完成调整；但跨任务迁移、冗余替补、长期稳定或极高压力下表现尚未达到历史罕见。    |
| **G3** | 多数复杂任务能够依靠责任中心完成，基本授权、监督和协调机制可用；但系统仍明显依赖少数关键人物、本人亲自干预或临时性补救。               |
| **G2** | 存在真实组织编排和局部成功，但多中心协调、权责匹配、信息回流或替补能力经常失衡。                                   |
| **G1** | 主要复杂任务反复发生责任不清、冲突、失控或最高层瓶颈，组织只能依靠少数个人、临时非常措施或事后补救运行。                       |
| **G0** | 在主要适用阶段呈现罕见而稳定的复杂组织驾驭失能：命令链、责任中心、协调和替补系统广泛失效，且本人反复扩大同类故障。                  |

## 8. 与其他轴及五项评分的边界

* **与第二项B1行政执行**：B1评价行政机器实际上有没有持续交付；G2评价本人如何编排机器。B1高不能直接换G2高。
* **与S1-B2**：S1-B2只消费创业统一父链中的组织整合；G2覆盖全部实际权力窗口中的独立组织驾驭情境。若使用同一创业事件，必须证明独立命题并避免重复展示。
* **与C3**：个人识人、岗位选择和授权归C3；多个责任中心如何共同工作归G2。
* **与M4**：政治集团愿不愿意合作、信用和退出归M4；合作以后组织是否高效编排归G2。
* **与C1**：战略目标和资源优先级归C1；战略决定以后如何拆任务执行归G2。
* **与C2**：本人是否理解新信息归C2；理解以后是否调整组织结构归G2。
* **与G1**：G1设计制度和组织结构；G2在既定结构下驾驭执行。
* **与M1**：本人军事统帅和战争解题归M1；跨战区后勤、行政、财政等多责任中心的组织编排只有在命题独立时进入G2。

同一行政结果不得同时作为B1高档理由和G2高档理由。G2必须出现本人任务分解、授权、协调、监督或故障处理的直接过程锚。

## 9. 特殊裁决

### 继承成熟机器

继承高水平官僚系统不自动形成高G2。必须看到本人实际如何配置、协调、监督和调整。

### 强名臣依赖

一个或两个历史级臣下可以证明本人存在授权能力，但不足以独立支持G5。须观察跨人物、跨任务或替补后的系统表现。

### 最高权力高度集中

集中本身不自动判低。若本人能够维持高吞吐、清晰分工和稳定执行，可保持较高档；只有出现持续决策拥塞、下级等待裁决、责任中心空心化或替补失效时才构成负证。

### 危机临时集中

战争、叛乱或紧急状态下短期收权不自动降档；须看危机过后能否恢复有效责任体系。

## 10. 最低证据与高档复核

G4/G5至少需要：

* 两个以上独立复杂任务父情境；
* 至少一个多责任中心并行案例；
* 至少一个故障、替补或高压复验案例；
* 明确区分本人编排与成熟国家机器、名臣个人能力；
* 主动检查最高层瓶颈、核心人物退出和跨阶段稳定性。

如果现有材料只能证明“行政结果很好”，而看不到本人如何编排执行，则最多发布有界画像，不因结果自动补高档。

证据厚度、置信度、LOW/MID/HIGH及正式发布字段继承人物画像共同合同。
