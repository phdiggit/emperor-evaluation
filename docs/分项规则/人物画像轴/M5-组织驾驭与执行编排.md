# M5 组织驾驭与执行编排能力评估合同

> `FORMAL-V1.0 / COMPLEX-ORGANIZATION-ORCHESTRATION`。共同字段、证据等级、置信度、档内投影和发布规则继承[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)与[共同数据合同](00-共同数据与发布合同.md)。

## 1. 对象与适用性

评价本人能否把复杂国家任务拆给多个责任中心，配置权责与资源、协调依赖和冲突、监督信息回流，并通过替补或重排维持执行，使组织不必等待最高统治者逐项操作。

复杂性来自责任中心相互依赖、资源约束、信息差或时序冲突，不按疆域、机构、名臣、奏章或战果数量判定。正常掌握最高权力者原则上适用；只有没有实际组织控制权，或窗口短至没有任何调度机会，才可判不适用。缺少著名大工程或高压事件只限制证据外推，不等于不适用。

实际权力窗口读取规范人物池；共享、摄政、从属与受限阶段单独说明归责。窗口外或臣下自主产生的组织交付不得整段归本人。

## 2. 证据与归责

以独立复杂任务为父情境，保存最小充分链：

> 任务与依赖 → 本人分工 → 责任中心及权责资源 → 协调与监督 → 执行、反馈及后续调整。

涉及故障时说明替补、恢复或扩散；涉及高档时说明自主空间、关键人依赖和跨任务/阶段复验。缺失环节如实列为限制，不补写现代组织流程，不把同一任务的多人、多战区拆成多票。

本人拆任务、定边界、配置权限资源、处理冲突、维持授权或故障后重排，才形成归责锚。成熟机器、名臣方案和资源优势须剥离；结果只验证运行，不能代替本人过程。主要入口为C3、C4及第二项B1等正式事实与其史源，也可使用可定位直接史料；不得继承其档位、分数或材料强度。

主判任务分解、权责资源匹配、横向协调、监督信息、故障替补、授权稳定与去个人依赖、跨任务迁移，不设子分或相加算法。

## 3. 分档与高档门

| 档位 | 整体组织模式 |
|---|---|
| G5 | 多任务或主要阶段反复出现历史罕见的多中心自主协作，稳定编排或故障恢复路径完整；主要下沿不足以改变整体模式。 |
| G4 | 稳定驾驭复杂多中心任务，具有独立复验和重要压力下的有效调整；迁移、冗余、稳定性或自主性仍有明显上限。 |
| G3 | 多数复杂任务依靠真实责任中心完成，基本授权监督协调可用；仍依赖关键人、本人介入或临时补救。 |
| G2 | 有真实编排和局部成功，但主要阶段的协调、信息、权责资源或替补反复失衡，需要明显补救。 |
| G1 | 失灵成为主要组织方式，关键接口长期受俘获、瓶颈或责任错配支配；仍可存在正常独立中心和局部交付。 |
| G0 | 主要阶段或足以改变全生涯判断的终端窗口中，命令、信息、任用、军政协同、地方执行或替补等多个核心功能同步失效，故障向全系统扩散且本人无法恢复。 |

**G4必要条件：**至少两个独立复杂任务父情境，都能定位本人编排；至少一个多中心并行案例；至少一次故障、替补、高压或资源冲突中的有效调整。必须复核成熟机器、单一强臣、最高层瓶颈和关键人退出。第二父情境不得只是同一主链增添成员。

**G5必要条件：**先过G4门，再有跨任务类型或主要阶段复验、多中心真实自主空间，不主要依靠单一名臣、成熟机器或本人超负荷勤政；主要下沿不存在改变整体模式的同构念系统性失能。另须满足任一路径：

- **稳定编排：**长期、高压、资源冲突或正常负责人更替中，多中心持续协作，关键变化不致整体失速；不强制先发生失败。
- **故障恢复：**重要局部故障后，通过替补、重分工、重配置或协调恢复，未造成整体停摆。

**档内判别：**G4-LOW已过硬门，但成熟机器信用、共享归责、关键接口反转、替补成本或第二链厚度有显著限制；MID需要多个较完整过程及更稳定的压力复验。HIGH除共同合同要求外，应已具明显G5特征，主要缺口集中于一个维度；不得以巨大危机或规模掩盖多个独立缺口。G5位置按共同合同的范围、阶段一致性、下沿和迁移性判定。

G3/G2看主要模式是否总体可用；一次恢复不自动升G3，晚期一次重错也不自动抹除长期可用模式。G1/G0须区分严重跨接口失灵与多核心功能同步崩解，亡国、战败或暴政本身不触发G0。总体与重要阶段反转同时表达，不作无依据的时间加权。

## 4. 特殊边界与去重

| 相邻命题 | M5只消费的部分 |
|---|---|
| C4长期机构、固定权责与制度性接口设计 | **C4设计机器，M5驾驭机器。**既定结构中的任务分配、临时增减权限、督办、增援、换人和恢复归M5；长期结构修改归C4。两段行为独立闭合才可分别使用。 |
| C3识人、岗位配置及个人授权 | 多责任中心之间如何共同工作、互补与接续；不能累加用人个案。 |
| C1目标风险、C2认知纠错 | 目标和判断之后实际发生的责任资源重排与执行恢复。 |
| M4内部集团信用、M2外部谈判联盟 | 国内执行中心的协调，不重复合作意愿或外交交换。 |
| M1战争判断和作战操作 | 独立闭合的跨战区、后勤、财政、行政等组织编排命题，不用战果替代。 |
| M3与五项治理、创业、军事结果；C5权力伦理 | 本人组织过程；结果和惩罚伦理不重复换档。 |

集权、勤政或危机短期收权不自动判低；只有造成持续拥塞、责任空心化、授权失效或离场停摆才是负证。短期集中能改善协调、随后恢复责任体系可作正证。清洗、频繁换人不等于恢复，要看责任体系是否接续及同类故障是否复发。

## 5. 正式记录与维护

每人保存共同身份、窗口和决策字段，以及适用性、任务父链、本人归责、正反证、主要阶段、跨轴剥离、来源、材料限制、裁档与档内理由。过程不够只发布相应置信度的有界画像，不用行政结果补高档或缺料补G3。

`parent_chains`保存当前有效过程与可反查来源；阅读页可节选，不复制旧档、批次表和历史审计。正式JSON是唯一裁决真源，入口由`config/project.yml`登记。程序仅校验身份、窗口、引用、共同投影、当前裁决字段和阅读同值，不从文字、关键词、条数或其他轴自动定档。不设画像总分、轴内排名，不改五项综合总榜。
