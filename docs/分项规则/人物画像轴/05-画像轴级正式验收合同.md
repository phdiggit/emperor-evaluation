# 画像轴级正式验收合同

> 共同评价要求见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)，数据和发布要求见[共同数据合同](00-共同数据与发布合同.md)。

一个轴正式发布前，确认：

1. 本轴定义、跨轴分工和阶段规则已经确定，不能为待结算轴改写其他已结算轴。
2. 已完成本轴最低证据要求，说明本人作用、主要表现、范围与限制；按总合同发布档位、位置、雷达值及来源，影响结论的未决证据问题不能混入正式计分。
3. 身份、角色、本人责任和跨项输入已核对，同一事实没有重复计分。
4. JSON与Markdown一致，任务ID、排序与来源可追溯，不要求其他轴跟着同步文件哈希。
5. 数据可解析、UTF-8无BOM，相关编译、测试和入口检查通过。共同合同、schema或轴边界变化才要求全量测试。
6. 同一事实的冲突、单向材料风险按触发条件复核，明确公布证据受限状态和可能改档的缺口。

现行九轴的正式入口见`config/project.yml`。
