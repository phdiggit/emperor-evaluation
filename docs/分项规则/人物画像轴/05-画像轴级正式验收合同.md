# 画像轴级正式验收合同

> 本文是[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)的职责拆分章节；共同字段与发布边界见[共同数据与发布合同](00-共同数据与发布合同.md)。本次拆分只改变合同物理位置，不改变评分语义、正式数据或验收结论。

任一画像轴晋升为正式结算时，必须同时满足：

1. 画像总合同第1—4节中的九轴定义、主路由、跨轴去重和分阶段规则已经冻结；待结算轴不得反向改写已结算轴；
2. 该轴完成本轴声明的最低证据范围，并说明主要机制、证据范围和限制；每条正式记录均有G档、位置、雷达值和可定位依据；影响结论的`UNRESOLVED_EVIDENCE_GAP`不得进入正式计分链；
3. 轴特有的身份、角色、归责和跨项输入已完成必要核对；不以材料数量或名望机械计分；
4. JSON与Markdown同值，稳定`task_code`、排序键和来源 lineage 齐全；不建立跨轴哈希同步门；
5. JSON/YAML解析、UTF-8无BOM、轴内编译、聚焦测试和入口检查通过；全量测试仅在共同合同、schema或轴边界变化时要求；
6. 同链冲突和材料偏窄只在触发时复核，不以五项总分、名次或一般倒挂自动改档；
7. 明确不参与五项综合总榜、不设画像总分，并发布证据受限状态和可改档缺口。

M1、M2、M3、M4、C1、C2、C3、C4与C5均满足上述轴级门禁，入口见`config/project.yml`；仍不得生成画像总分、轴内排名或写入五项综合榜。
