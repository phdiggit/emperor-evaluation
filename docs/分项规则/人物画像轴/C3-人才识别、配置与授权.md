# 人物画像分项规则：C3 人才识别、配置与授权

C3同时看正面成果和授权生命周期，但不把“处置臣子”本身当作能力或道德扣分。固定审查：

1. 是否识别出与任务相匹配的人；
2. 是否配置到合适岗位；
3. 是否给予完成任务所需的真实权限；
4. 受任者是否形成可归责交付；
5. 副作用或不适任反馈到达后，是否监督、纠偏、收权、替换或继续误用；
6. 处置是否实质损害人才供给、团队信任、反馈安全或继任组织能力。

C3不要求穷尽全部识人和任命。全池裁决以“重大任务组合”为观察宇宙：至少覆盖人物实际拥有机会的军事、财政、行政、司法、外交或继承等核心任务，以及主要掌权阶段中的关键责任中心。每个准入父链仍须闭合“任务—人选—岗位—真实权限—交付—反馈—监督、收权、替换或继续授权”，不能按名臣人数、官职数量或最终治绩计分。

单一著名名臣、开国团队总成果或一个长期强臣只能证明窄场景；拟`G4/G5`须跨任务类型或阶段复验，并方向中立地检查重大误用、长期不适任、授权失控、错误清洗和继任人才结构。未穷尽普通任命不构成材料缺口，但主要任务类型或晚期用人窗口未暴露时不得发布高置信度历史级结论。具体个人的识别配置归C3；集团间身份、利益与政治信用归M4；惩罚伦理、株连和异议安全归C5。

军事或其他高风险责任中心的正向授权链须区分`STRONG_AUTHORIZATION_CHAIN`与`EXCEPTIONAL_AUTHORIZATION_CHAIN`。前者要求人选—岗位—真实权限—可归责交付—反馈或后续处置闭合，并在一个重大任务组合内形成强交付；后者还须在同一责任中心组合内证明至少三项相互可区分、跨方向或跨阶段的重大交付，其中至少一项为本人实际授权下的`S-`及以上结果，且不能把同一战役的子阶段、同一将领反复叙述或最终治绩拆数。极强链不是自动G4门票：仍须有另一独立任务或阶段的合格正链，且不得被同构的持续误用推翻；但在总体仍为G3时，不能与仅有一个普通或材料受限生命周期机械同置`LOW`，应以其授权范围、交付层级、反馈后的维持或纠偏和反证强度裁定`MID/HIGH`。每轮C3校准必须列出命中极强链者及至少两类同构对象，禁止按名臣人数、战争规模或国家最终成功换算。

以下事实不自动降低C3：撤职、处死臣下、严格问责、压制派系或收回权力。只有闭合明显误判、猜忌、授权失控、错误清洗、无替代损失、人才逃亡、团队崩解、反馈堵塞或同类错误复发时，才作为C3负证。惩罚的比例、株连、司法伦理和异议保护统一归C5。

不得接受“功臣必反”“所杀皆贪官污吏”“英主清洗必有必要”等人物声望叙事替代逐案证据。反过来，也不得因存在清洗就抹除此前已经闭合的历史级识人、配置与授权成果。
