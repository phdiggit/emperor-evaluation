# 人物画像分项规则：C3 人才识别、配置与授权

> `FORMAL-V1.0`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么

C3评价本人能否为任务选对人、配对岗位、授予真实权限，并根据交付和反馈监督、纠偏、收权、替换或继续授权。以重大任务组合为范围，覆盖实际拥有用人机会的军事、财政、行政、司法、外交、继承等核心任务，不要求穷尽普通任命。

每条证据须说明“任务—人选—岗位—真实权限—交付—反馈—后续处置”，不按名臣、官职数量或最终治绩计分。个人配置归C3，集团利益与信用归M4，惩罚伦理和异议安全归C5。

## 2. 高档与独立复验

G4/G5须经跨任务或阶段复验，并检查误用、不适任、授权失控、错误清洗及继任结构。缺主要任务、后期或退出阶段的观察，不能作高置信度历史级结论；单一名臣、强臣或开国团队成果只证明窄场景。

G4的独立复验按任务、权限、交付和反馈区分，不强制第三责任中心、不同领域、同等规模或从零发现人才；续认、扩责和纠偏也可证明本人配置。

| 高风险责任中心证据 | 条件 |
|---|---|
| `STRONG_AUTHORIZATION_CHAIN` | 人选、岗位、权限、交付、反馈/处置完整，在重大任务中充分兑现 |
| `EXCEPTIONAL_AUTHORIZATION_CHAIN` | 同一责任中心组合至少三项独立、跨方向或阶段的重大交付，其中一项为本人授权下S-及以上结果；不拆同战子阶段，不重复将领叙述或终局治绩 |

极强链支持G4仍须另一独立任务/阶段正链，且未被持续同类误用推翻。总体G3时，据范围、交付、反馈和反证判断MID/HIGH，不与单一普通或受限链机械同置LOW。校准列出极强链对象及至少两类相似能力结构的比较对象，不按人数、规模或国家成败换分。

## 3. 负证怎样影响结论

撤职、处死、问责、压制派系或收权本身不扣分。须证明误判、猜忌、授权失控、错误清洗、无替代损失、人才流失、团队崩解、反馈堵塞或错误复发，才能成为C3负证；核对处置是否实质损害人才供给、团队信任、反馈安全或继任组织能力。比例、株连和司法伦理另归C5。

负证须说明怎样改变全生涯模式。持续同类误用、关键责任体系反转或交班结构失配可阻断G4；严重个案既不自动降档，也不因“仅此一例”而豁免。保留G4须解释为何只限档内，保留G3须说明独立证据缺口或反转机制。

“功臣必反”“清洗必要”等叙事不能替代逐案证据，清洗也不抹去此前已证的识人授权成果。
