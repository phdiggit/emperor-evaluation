# 人物画像分项规则：C3 人才识别、配置与授权

C3审查识人、配置与授权生命周期；处置臣子本身不扣分。

1. 是否识别出与任务相匹配的人；
2. 是否配置到合适岗位；
3. 是否给予完成任务所需的真实权限；
4. 受任者是否形成可归责交付；
5. 副作用或不适任反馈到达后，是否监督、纠偏、收权、替换或继续误用；
6. 处置是否实质损害人才供给、团队信任、反馈安全或继任组织能力。

以重大任务组合为观察范围，覆盖实际有机会的军事、财政、行政、司法、外交、继承等核心任务及各掌权阶段责任中心，不要求穷尽普通任命。父链须闭合“任务—人选—岗位—真实权限—交付—反馈—监督/收权/替换/续授权”；不按名臣数、官职数或终局治绩计分。

`G4/G5`须跨任务或阶段复验，检查误用、不适任、授权失控、错误清洗与继任结构；主要任务或晚期窗口缺失时不作高置信度历史级结论。单一名臣、强臣或开国团队成果只证窄场景。个人配置归C3，集团利益信用归M4，惩罚伦理与异议安全归C5。

高风险责任中心分`STRONG_AUTHORIZATION_CHAIN`与`EXCEPTIONAL_AUTHORIZATION_CHAIN`：前者须闭合人选、岗位、权限、交付、反馈/处置并在重大任务内强兑现；后者须在同一责任中心组合中有至少三项独立、跨方向或阶段的重大交付，其中一项为本人授权下`S-`及以上结果，不拆同战子阶段、重复将领叙述或终局治绩。极强链支持G4仍须另一独立任务/阶段正链，且不被持续同构误用推翻；总体G3时须据范围、交付、反馈和反证判`MID/HIGH`，不与单一普通或受限链机械同置`LOW`。校准列出极强链命中者及至少两类同构对象，不以人数、规模或国家成败换分。

撤职、处死、问责、压派系或收权，只有闭合误判、猜忌、授权失控、错误清洗、无替代损失、人才流失、团队崩解、反馈堵塞或错误复发才构成C3负证；比例、株连与司法伦理归C5。

逐案证据不被“功臣必反”“清洗必要”等声望叙事替代；清洗也不抹除此前已闭合的识人授权成果。
