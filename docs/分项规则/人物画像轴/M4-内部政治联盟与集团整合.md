# 人物画像分项规则：M4 内部政治联盟与集团整合

M4评价本人在实际权限内把统治共同体内部利益、身份和政治经历不同的群体组织为可持续合作关系的能力，不评价一般口才、宣传能力、抽象民心或所有社会关系。固定展示四个子面：

| 子面 | 内容 |
|---|---|
| M4.1 | 联盟建立：吸收旧敌、地方集团、宗室、军功集团、官僚、士人及重要社会群体 |
| M4.2 | 利益与地位配置：权力、荣誉、资源、身份和参与渠道能否形成可接受安排 |
| M4.3 | 内部政治信用：协商、承诺、参与渠道和重复博弈是否可信 |
| M4.4 | 联盟维护与退出：成功后如何处理冲突、功臣退出、派系竞争、储位与安全预期 |

M4以集团级重大关系生命周期为观察宇宙，至少包括人物实际经历的夺权或建国联盟、征服后的旧政权与地方集团吸收、中枢重组、宗室和军功集团安置、重大派系重组、重要地域或身份集团整合，以及储位与交接导致的联盟变化。零散宴饮、单次赏赐、一般告谕、一个臣子的任免和宣传性“得民心”不得拆成联盟父链。

M4必须覆盖完整实际权力窗口。`FOUNDING_SUBORDINATE`阶段只评价本人实际掌握的府署、战区和属官；最高权力属于他人时，国家级政治联盟用武空间有限，不因缺少此类事件扣分。取得最高权力后的中枢重组、成熟统治和晚期交接不得被开国阶段材料替代。拟`G4/G5`必须系统重建主要集团结构、利益与安全预期、本人安排、合作兑现、冲突处理和退出结果；碎片化个案、开国团队成果汇总或单一著名联盟不能支持高档。

M2与M4使用相同的联盟生命周期骨架，但按事件中的实际关系唯一主路由：外国、独立政权及以条约、战争、对外交换为核心的关系归M2；官僚、士人、宗室、军功集团、旧政权精英、地方势力及国内重要社会集团归M4。边疆部族、藩镇、册封政权等双重身份对象，按该父链实际运行的是外部谈判关系，还是授官、身份吸收、内部利益与政治参与关系裁决；同一父链不得在M2、M4重复计分。

第一项B衡量开国团队成果与非本人承担份额，不能直接换算M4；本人亲自承担较多导致第一项B较低，不构成政治联盟短板。第四项A可以复验社会整合结果，但共同体净收益、教育、文化结果和后世正统叙事不能替代联盟经营过程。C3评价具体个人的识别配置，M4评价集团间利益组合和政治信用；C5评价权力边界，不因联盟在功利上有效就豁免伦理反证。执行持续性只增强M4父链，不生成撤销的画像C4收益。
