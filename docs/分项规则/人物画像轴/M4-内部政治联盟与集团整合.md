# 人物画像分项规则：M4 内部政治联盟与集团整合

> `FORMAL-V1.0`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么

M4评价本人在实际权限内，让统治共同体中不同利益、身份和经历的集团持续合作的能力。一般口才、宣传或抽象民心不属于本轴。

| 子面 | 内容 |
|---|---|
| M4.1 | 联盟建立：吸收旧敌、地方集团、宗室、军功集团、官僚、士人及重要社会群体 |
| M4.2 | 利益与地位配置：权力、荣誉、资源、身份和参与渠道能否形成可接受安排 |
| M4.3 | 内部政治信用：协商、承诺、参与渠道和重复博弈是否可信 |
| M4.4 | 联盟维护与退出：成功后如何处理冲突、功臣退出、派系竞争、储位与安全预期 |

## 2. 观察范围与高档要求

以重大集团关系的完整周期取证，覆盖主要政治生涯中的创业联盟、征服后吸收、中枢重组、宗室军功安置、派系和地域整合、储位交接。宴饮、赏赐、告谕或单人任免不能独立证明联盟能力。

本人有真实吸收、配置、承诺、协商、冲突处理或退出处置权，即按实际归责评价。`FOUNDING_SUBORDINATE`只评本人府署、战区和属官，不因没有国家级权限扣分；开国材料也不能替代成熟统治和晚期交接。

G4/G5须说明主要集团、利益与安全预期、本人安排、合作兑现、冲突和退出。零散片段、团队总成果或单一著名联盟不足以支持高档。

## 3. 与其他轴的边界

M2与M4都按完整关系周期取证：对外条约、战争与交换归M2，国内身份吸收、授官、利益和政治参与归M4。部族、藩镇、册封政权等双重身份按实际关系划界，同一部分不重复计分。

C3评个人配置，M4评集团利益与信用，C5评权力边界。团队成果、非本人份额和社会整合结果只作复验，不能替代经营过程；本人亲自承担较多也不算联盟短板。功利有效不豁免C5审查，执行持续性只复验M4，不另计C4能力。
