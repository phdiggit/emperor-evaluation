# 人物画像分项规则：M4 内部政治联盟与集团整合

M4评价本人在实际权限内，使统治共同体中不同利益、身份与经历的集团持续合作的能力；不评一般口才、宣传或抽象民心。

| 子面 | 内容 |
|---|---|
| M4.1 | 联盟建立：吸收旧敌、地方集团、宗室、军功集团、官僚、士人及重要社会群体 |
| M4.2 | 利益与地位配置：权力、荣誉、资源、身份和参与渠道能否形成可接受安排 |
| M4.3 | 内部政治信用：协商、承诺、参与渠道和重复博弈是否可信 |
| M4.4 | 联盟维护与退出：成功后如何处理冲突、功臣退出、派系竞争、储位与安全预期 |

观察集团级重大关系生命周期：创业联盟、征服后吸收、中枢重组、宗室军功安置、派系及地域身份整合、储位交接。宴饮、赏赐、告谕或单人任免不独立成联盟父链。

覆盖完整权力窗口。`FOUNDING_SUBORDINATE`只评本人府署、战区与属官，不因未掌国家权力而缺国家级联盟扣分；开国材料不替代成熟统治与晚期交接。`G4/G5`须重建主要集团、利益安全预期、本人安排、合作兑现、冲突与退出，不由碎片、团队总成果或单一著名联盟支持。

M2/M4共用生命周期骨架：对外条约、战争与交换归M2；国内身份吸收、授官、利益与政治参与归M4。部族、藩镇、册封政权等双重身份按该父链实际关系归属，同链不重复计分。

第一项B的团队成果及非本人份额不换算M4；本人亲自承担较多导致B低不算联盟短板。第四项A只复验整合结果，不能代替经营过程。C3评个人配置，M4评集团利益信用，C5评权力边界；功利有效不豁免伦理反证。执行持续性只复验M4，不生成已撤画像C4收益。
