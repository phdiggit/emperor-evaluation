# C4 治理架构与制度设计能力评估合同

> `FORMAL-V2.2 / ARCHITECTURE-MAGNITUDE-GATE`；共同证据、档位投影与发布字段继承[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)及[共同数据合同](00-共同数据与发布合同.md)。

## 1. 对象与适用性

C4评价本人面对治理结构问题，识别约束并设计、选择、整合或重构组织、权责、信息、责任与资源接口，形成可运行治理架构的能力。原创不是高档必要条件；单纯沿袭、礼仪性批准、机构改名、政策数量、勤政、名臣或历史名望不能替代结构设计。

本人在实际权力窗口内有真实制度选择、维护或调整权即原则上适用。仅在极短窗口没有真实选择、纯名义且完全架空，或材料能够确认无可归责选择机会时判`NOT_APPLICABLE`；没有著名改革、材料不足不等于不适用，也不得把不适用换成零分。

## 2. 父链、归责与反证

父链：**结构问题 → 现实约束 → 可行方案 → 本人结构选择 → 权责/信息/组织接口 → 实际运行 → 机制反馈 →〔重大故障发生时：结构修订 → 再运行〕→ 归责边界**。

至少定位本人选择、接口变化、运行及来源；替代方案须为当时现实可行方案。综合考察问题识别、目标与机制匹配、系统协调、现实适配、反馈修订、稳定与迁移，不拆固定子分。

本人可因原创、重大重构、方案取舍与系统整合、适配性扩展取得信用；前制、臣下技术设计、时代积累与继任者贡献须切分。名义批准不产生高档信用；非原创但本人实质选择和整合闭合时，不因不是亲自发明而降档。

目标评价须涵盖其直接依赖的决策吞吐、责任落实、信息回流、财政供给与中央地方接口。只纳入有直接机制联系的一阶结构代价：权责冲突、信息堵塞、责任真空、最高层拥塞、频繁反转，以及长期依赖越制、强人或非常动员才能运行。不得缩窄目标以掩盖同一系统内部失配；伦理负面、社会净损害、外部冲击或继任改制不自动成为C4负证。

设计质量可由两条路径证明：

- **A：高难构造—稳定复验**。接口真实运行，跨地区、责任中心、阶段或压力保持有效，不靠个人逐项填坑或持续非常手段维持。
- **B：故障—诊断—结构修订—再运行**。修订长期规则、权责或信息接口，并经运行验证；单纯换人、督办不构成结构修订。

两条路径不须兼具，且都不能替代架构量级门。未发生重大故障不因缺修订记录扣档；故障已发生、反馈到达且本人有权及现实替代路径，仍长期维持或加码失配结构，才形成明确反证。早期材料可用本人取舍、同期运行和后继直接接收闭合路径A；材料密度只限制置信与外推，不自动抬降档。

## 3. 架构量级

| 量级 | 准入含义 |
|---|---|
| AM1 局部接口 | 单部门、程序、地区或责任接口，通常支持G2/G3。 |
| AM2 全国重要子系统 | 全国性但功能较单一的考试学校、法典编修、司法复核、仓储赈济、监察奏事或专项财政模块。 |
| AM3 国家核心系统 | 实际改变多层责任关系，重写中央地方、选任考课升黜、核心税基、法律管辖司法、军政户籍人口、帝国区域层级或常设决策信息执行中枢的一条主干；新机构名称本身不足。 |
| AM4 国家基本运行架构重构 | 一套整合架构同时重写至少三个核心功能之间的关系；或至少两个AM3在同一治理逻辑下协同重构，形成新的国家运行范式。 |

多个AM2、制度数量或后世名望不能机械相加为AM4；须证明跨系统关系与共同治理逻辑。单一父链可闭合AM4，不得为凑独立链拆分同一改革包，也不得因不可拆分而压回G3。

## 4. 档位门槛

| 档位 | 本轴语义 |
|---|---|
| G0 | 主要适用阶段稳定呈现罕见结构失能：关键接口广泛失效、制度大规模冲突或持续推动已明确失败的系统，难以恢复。 |
| G1 | 主要设计反复失配、失灵或反转，已知故障缺乏有效修订，少量成功不足改变主模式。 |
| G2 | 有真实尝试与局部有效接口，但适配、一致性或持续运行明显受限，需要外部补救。 |
| G3 | 有效选择、重构或适配使主要结构通常可用，但依赖既有框架、臣下方案或局部修补，未形成稳定强长板。 |
| G4 | 强设计能力，按下列量级、归责与运行门定位。 |
| G5 | 历史罕见的国家架构设计能力，必须同时通过全部硬门。 |

### G4

- **LOW**：一条强AM2/AM3加第二有效父链，或高质量恢复修补型设计。
- **MID**：至少两条高质量AM2，或一条AM3加较弱第二链。
- **HIGH**：至少一条AM3加独立AM2/AM3验证；或AM4级尝试因归责、稳定或适配失败封顶。

一般要求两条独立、本人结构选择可归责的有效父链，至少一条有真实运行反馈或复验；单一一体化AM4不受第二链门压回G3。恢复修补仍须证明本人结构变化，不能用日常维护代替。

### G5全部硬门

1. **量级与独立性**：闭合一组AM4，另有第二独立AM3或等价高难复验；同一总改革包及其阶段不得拆票。等价复验须在实质不同压力或场景再次证明核心设计能力，不只是同一结构继续存在。
2. **本人归责**：本人实质承担问题定义、方案选择与跨系统整合；主要被动批准成熟臣僚方案原则上封G4。
3. **运行**：核心结构真实运行，至少一条经跨阶段、跨压力或退出后接收复验；颁令设官不足。
4. **下沿**：同构重大结构失灵覆盖主要阶段原则上封G4；局部反证压档内位置，不把架构宽度直接当作免除下沿门。
5. **量级验证**：长期接收或当时国家基本运行的直接中心性证据至少一项闭合；后世影响只验证量级和机制生命力，不直接换分。

**HIGH**为跨多个核心系统的运行范式重写、个人归责极强且复验充分；**MID**为明确AM4加独立AM3或多核心共同改写，但前制、臣下信用或结构下沿显著；**LOW**为刚过量级及第二核心复验门，归责、稳定或适配限制明显。档内定位不能替代硬门。

## 5. 高档复核与发布

G4/G5定向检查前制与臣下信用、最高层瓶颈、接口冲突、信息堵塞、故障不修、非常运行及反转。G5还须说明重写了何种国家运行逻辑、去除最著名制度后的剩余量级、切分技术信用后的本人贡献，并与同量级证据横校。上述量级、剩余证据或本人信用答不稳，原则上回G4。

公众印象或档位分布只触发构念复核，检查量级误判、拆链及信用归属；不按名气或比例配额改档。非知名人物若有直接AM4证据同样适用。

适用人物以最小充分证据裁档，发布来源、正反证、归责、量级依据及限制；E0或影响结论的未决证据缺口不得宣称正式验收。E1/E2用共同合同的置信度、输出模式和外推限制表达，不机械补G3。最新明确重裁覆盖旧档，旧过程不混入当前依据；池外裁决单独保留，不扩大规范池。

## 6. 跨轴边界

| 接口 | 区分 |
|---|---|
| 第二项A1/A2/A3 | 制度贡献、当时净收益、后世影响分别结算；C4消费本人结构选择过程，不能互换档分。 |
| C1 / C2 | 方向与风险选择 / 认知更新；C4只消费相应制度接口变化。 |
| C3 / M4 | 个人识别配置授权 / 集团合作信用；C4消费岗位规则与集团纳入国家机器的制度化接口。 |
| M5 | 既定结构内拆任务、配资源、督办换人归M5；长期权责、组织与固定信息接口重构归C4。临时编组须制度化后才准入。 |
| M1 / M2 / C5 | 军事外交专业判断 / 权力伦理不换C4；只有独立闭合的长期治理结构命题可辅助引用。 |

同一材料跨轴须各自证明独立命题并记录去重边界；C4不进入五项总榜，不设画像总分或轴内排名。
