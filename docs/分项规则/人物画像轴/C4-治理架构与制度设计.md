# C4 治理架构与制度设计能力评估合同

> `DRAFT-G1 / GOVERNANCE-ARCHITECTURE-AND-INSTITUTIONAL-DESIGN`

本轴评价本人能否识别治理目标与结构问题，设计、选择或重组相互协调的制度、组织、信息和责任接口，使国家机器按预期方式运行。

本轴评价的是**治理系统设计能力**，不是制度净收益、制度史影响力、政策数量或道德价值。

## 1. 适用性与评价对象

仅在本人实际拥有下列至少一种真实选择机会时适用：

* 建立或重构中央、地方、财政、选官、司法、监察、户籍、军政等治理接口；
* 在多个既有方案之间作具有结构后果的选择；
* 对继承制度进行重大组合、改造、扩展或重新定型；
* 面对制度运行故障时有权调整其结构。

单纯继承、照常执行、名义批准、礼仪性颁布或无实际制度选择权，不足以形成高信息量父情境。

极短实际权力窗口且没有发生真实治理架构选择时可判 `NOT_APPLICABLE`，不得换算为零分。

## 2. 核心问题

每个G1父情境至少回答：

1. 本人面对的治理目标或结构问题是什么？
2. 当时已有何种制度基础和现实约束？
3. 有哪些真实可行方案？
4. 本人实际提出、选择、组合、否决或重塑了什么？
5. 该方案内部的权责、信息、资源和执行接口如何连接？
6. 是否真正建立并进入运行，而非停留在方案或诏令？
7. 运行结果是否验证其预期机制？
8. 出现故障、副作用或环境变化后，本人是否调整设计？
9. 哪部分应归本人，哪部分来自前任、臣下、时代积累或继任者？

## 3. 主判维度

G1不拆固定子分，但裁档时必须同时观察以下五个方面：

### A. 问题识别

能否抓住真正的治理瓶颈，而非只处理表面症状。

### B. 目标—机制匹配

设计出的制度是否能够服务本人实际想实现的治理目标。

目标本身是否仁慈、扩张、集权或高成本，不由本轴评价。

一个高压甚至有害的制度，如果确实被本人有意识设计并高效实现其目标，仍可构成高G1证据；其社会成本、权力伦理和净损害由其他轴结算。

### C. 系统协调

多个制度、组织、信息和责任接口之间是否具有一致逻辑，能否形成系统而非互相冲突的政策堆积。

### D. 现实适配与可运行性

是否考虑既有官僚、财政、地方结构、人口信息、技术和执行能力，最终形成真实运行接口。

### E. 运行后修订

制度出现摩擦、漏洞或环境变化后，能否理解机制故障并作结构性修订。

此处只消费“修改制度设计”的能力；本人是否更新总体认知仍归C2。

## 4. 不得直接替代G1的事实

以下事实均不能单独换档：

* 后世沿用几百年；
* 制度被称为“创举”“祖制”；
* 制度节点或政策数量很多；
* 国家最终富强或疆域扩大；
* 制度最终带来高净收益；
* 本人批准臣下设计的成熟方案；
* 前代已经形成的国家机器被本人继承；
* 单次极具创造性的制度选择；
* 单纯把中央控制做得更强。

后世耐久只能验证机制确实具有生命力；不能倒推本人必然具有高等级系统设计能力。

## 5. 归责门

本人G1信用依次区分：

* **原创设计**：本人直接提出关键结构或明确塑造主要机制；
* **重大重构**：继承既有制度，但本人改变关键接口、权责或系统关系；
* **方案选择与整合**：本人没有原创全部内容，但在多个方案中作关键判断，并将若干机制组合成新的治理结构；
* **批准与沿袭**：主要方案来自成熟前制或臣下，本人仅批准、扩展或常规维护。

后两类可以形成能力证据，但不能因制度本身历史影响巨大而自动达到G5。

## 6. 正负证据

### 强正证

* 在不同治理领域反复识别结构问题并建立有效新接口；
* 多个机制围绕同一治理逻辑形成协调系统；
* 在既有国家机器上完成高难重构而没有造成主要接口失灵；
* 运行出现问题后能针对机制原因进行有效修改；
* 设计能够跨阶段、跨地区或跨责任中心稳定运行；
* 在约束很强的情况下仍找到低摩擦、可执行的制度方案。

### 强负证

* 设计目标与实际机制长期错配；
* 大量制度停留在纸面或必须依赖非常手段才能运行；
* 不同政策互相冲突，导致系统性行政紊乱；
* 明确收到机制失灵反馈后仍按同一设计反复加码；
* 过度集中、接口缺失或责任不清直接产生持续性组织瓶颈；
* 改制频繁反复，无法形成稳定的运行结构。

制度造成重大社会损害本身不自动构成G1负证；只有当损害同时证明**设计无法实现本人自己的治理目标、机制内部失配或本人无法处理已知故障**时，才进入本轴。

## 7. G0—G5轴内门槛

| 档位     | G1语义                                                                                  |
| ------ | ------------------------------------------------------------------------------------- |
| **G5** | 在多个独立高难治理领域反复表现出历史罕见的系统设计能力；能识别结构问题、构造协调机制、推动真实运行并处理主要制度故障。至少存在跨领域或跨阶段复验，不能只靠一项历史级创制。 |
| **G4** | 明显具备强治理架构能力，至少有多个重要机制实现目标—结构—运行闭环；但原创归责、跨领域迁移、系统协调、运行修订或生涯下沿尚不足以达到历史罕见。               |
| **G3** | 能作出若干有效制度选择或重构，主要治理设计通常可用；但更多依赖既有框架、臣下方案或局部修补，尚未形成稳定强长板。                              |
| **G2** | 有真实设计尝试和少量有效接口，但机制适配、内部一致性或持续运行经常受限，需要大量补救。                                           |
| **G1** | 主要治理设计反复与现实条件错配，制度频繁失灵、反转或制造新的结构性障碍；少量成功不足以改变主模式。                                     |
| **G0** | 在主要适用阶段呈现罕见而稳定的治理架构失能：制度设计大规模自相冲突、无法运行或持续推动已明确失败的系统结构。                                |

## 8. 与其他轴及五项评分的边界

* **与第二项A**：第二项A评价制度实际净建设、方向和耐久；G1评价本人如何设计治理系统。一个制度可以“净负但设计能力强”，也可以“净正但本人设计信用低”。
* **与C1**：C1决定“国家该做什么、风险是否值得”；G1决定“治理系统如何被设计来实现目标”。
* **与C2**：C2评价认知更新；G1只消费由反馈引发的制度结构修订。
* **与C3**：C3评价选谁、放哪里、给多少权限；G1评价岗位、组织和制度接口本身如何设计。
* **与G2**：G1设计机器；G2驾驭已经存在的机器。
* **与C5**：制度是否残酷、是否侵犯比例边界归C5，不因规范性负面自动降低G1。
* **与净收益**：民生、财政、安全和长期社会后果不得反向替代G1。

同一制度节点可同时作为第二项A结果证据和G1过程证据，但必须写明不同消费命题，不复制第二项档位或分值。

## 9. 最低证据与高档复核

G4/G5至少需要：

* 两个以上独立高诊断力父情境；
* 至少一个父情境能闭合本人设计归责；
* 至少一个父情境包含真实运行后的反馈或复验；
* 主动检查重大制度失败、反转和时代/前任继承基盘；
* 不得仅凭制度节点数量、S资格或后世影响升档。

证据厚度、置信度、LOW/MID/HIGH及正式发布字段继承人物画像共同合同。
