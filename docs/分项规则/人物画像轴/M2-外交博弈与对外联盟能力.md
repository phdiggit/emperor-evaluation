# 人物画像分项规则：M2 外交博弈与对外联盟能力

M2与M1分开。计入：

- 对对手、盟友和中立方利益及底线的识别；
- 联盟构建、分化对手、谈判授权与条件交换；
- 战争与谈判之间的转换、有限目标和退出安排；
- 条约、受降、互市、和亲、使节与承诺的实际履行；
- 外交反复、误判、孤立、失信或被动接受不利条件后的纠正。

第三项只复验外交结果，不以总分、和平、岁币、领土或国力差换能力。守约伦理归C5，承诺与重复博弈效力归M2；条约等关键词只作候选，不优于战争谈判转换、归附或均势机制。

### 关系性质、身份切点与发布状态

`对方有独立拒绝权`不是M2充分条件。每条父链先以被评价者自身统治共同体为参照，记录`political_membership_at_cycle_start`、`membership_relative_to_evaluated_ruler`与`relationship_phase`：外部政权/外部自主行为者可进M2；本朝宗室、藩镇、创业联盟、内部叛乱、已内附集团与郡县化领土转M4或其他适用轴。双重身份必须按父链实际交换内容切分，不能同链双计。

对象身份字段与能力主路由字段分离：`AXIS_OUT_WITH_REASON`/`BACKGROUND_VALIDATION`只说明该事实不由M2计分或暂不构成M2闭合链，不得反向把对象身份写成`INTERNAL_TO_EVALUATED_RULER`。外部对象即使主构念转M1/C1/M4，仍保留周期起点的外部身份；跨越受降、郡县化或内部整合时必须写`relationship_phase`与`identity_transition_point`。同一父链混合外部压力和内部集团时，按实际消费部分标明边界，不用单一轴外状态替代对象身份判断。

外部对象转入本政权时，M2只消费转入前的条件、反馈、承诺与执行；授官、封爵、编旗、置州、给地、常设监督和长期政治参与转M4。外部政权被吞并后，内部领土治理、采办、地方反乱和镇压不延长原M2父链；只有关系重新翻转为事实独立政治中心并形成新的条件交换，才另起M2父链。机器记录须在`identity_transition_point`标明切点。

受降、归附或入附后发生的事实，只有在验证身份转变前已经形成的安全保证、撤军、释放、岁币、边界、质子或退出安排时，才可作为该M2父链的`TERMINAL_EXECUTION`/`TERMINAL_BREACH`；不得用后续多年国内整合抬高MI3/MI4。对手要求、条件和反馈须为`VERIFIED_EXTERNAL`；内部伪造、误传或未经核验的试探不作为外部对手反馈。

证据投影固定为：`E1 / LOW / EPISODE_TAG / EVIDENCE_LIMITED`、`E2 / MEDIUM / BOUNDED_PROFILE / EVIDENCE_LIMITED`、`E3 / HIGH / FULL_GRADE / FINAL`。未闭合关键计分链进入工作状态`UNRESOLVED_EVIDENCE_GAP`；正式阅读表若保留整改前数字，只能标为历史显示点，不得解释为当前实裁或当前雷达值。

### 正负名望对称复核

正负名望只触发复核，不定方向、强度或档位。正面人物照查失信、误判、条件失衡、退出失败与臣使代劳；负面人物照留止损、履约、修复与退出成果。

同一预算复核真实拒绝权、本人判断授权、条件交换、对方反馈、执行和全生涯反例。命中名望、事件或强度异常须逐人语义复核，可保留档、改依据或改档，不为升降对称制造裁决。

### 高压亲临外交

高压包括强敌行动、盟友可拒绝/转向、安全结构即时破裂或多方须当场作可执行承诺；按本人即时风险和失败反事实判强度，不要求军事劣势，也不从终局规模倒推。

皇帝亲临不是独立加分项。只有以下条件同时成立，亲临才加强本人归责并提高该父链的诊断强度：

- 对手、盟友或中立方保有真实的拒绝、退出、转向或提高要价能力；
- 皇帝本人面对并处理至少一项实质分歧、条件交换或承诺设计，而非只主持礼仪；
- 现场选择得到对方反馈，并进入封授、撤军、互市、编制、给地、履约或其他可核执行；
- 后续结果用于验证承诺是否成立，但不把领土、战争胜利或名望重复换算为M2能力。

多方协调、即时承诺、跨期执行及拒绝风险闭合的亲临链可为`MI4_CROSS_PHASE_SYSTEMIC`；仅到场、表态或概括结果按实证取`MI1—MI3`。同类亲临须分别说明压力结构，不机械等档。

`G4-HIGH`通常须两条独立高诊断强循环，或一条上述`MI4`亲临链加另一对象/阶段/机制的独立复验，且通过同构念反证与材料密度门；表示关键场景触及历史级、全生涯尚不够`G5`，单次会盟或成果名望不准入。

### 和亲结果门与因果门

和亲、联姻等词只触发全池扫描，先确认确指婚姻；“修和亲”可仅指友好。

婚姻安排只有同时通过下列两门，才可成为M2计分材料：

- `RESULT_GATE`：相对于婚前基线，出现可核的安全改善或外交形式变化，如停战、撤军、可执行的军援或中立、缓冲建立、稳定互使、政治承认或关系转附；
- `CAUSAL_GATE`：材料能够把上述变化与婚姻条件、对方反馈和后续履约连起来，而不是仅在时间上同时发生，也不是由战争胜利、臣服或其他政策独立造成。

仅婚姻仪式、侵扰/单向贡献未变、无新承诺、未履约、拒婚未成、外生中断或后效不明，均为`BACKGROUND_VALIDATION`，不因未成功自动成负链。

婚姻只是更大链工具时，其他谈判/履约等独立机制可继续计分，但须标`marriage_policy_review.disposition = BACKGROUND_COMPONENT_PARENT_RETAINS_OTHER_MECHANISM`并剥离婚姻贡献；通过双门才标`SCORING_EFFECT_VERIFIED`。

以逆风、止损或纠错支持强度/档位，须同链判来源：`INHERITED`继承、`EXTERNAL`外生、`SELF_CAUSED`自致、`MIXED`混合。自致不获逆风加权，危机与纠错同链合判；混合只计可分外生部分。不用逆风语义可省字段，用作依据而缺来源不通过。

方向与强度正交：单次归责闭合的失信、误判或关系损伤保留`NEGATIVE / MI1_CASE / SCORING_PARENT`，通常影响`position`，不为计分抬MI。塑造有限、材料稀疏、臣下主导、无逆风复验或未闭谈判列`LIMITATION / MI1_CASE / BACKGROUND_VALIDATION`。MI门见下表；档位按全生涯主模式，位置再比对象、条件、归责、持续、纠错与反证，不作MI加减。

M2使用下列强度硬门：

- `MI1`：一个外部对象上的单次条件、拒绝、承认、违约或结果性个案；只有汇总结论而无直接过程时最多到此，并必须标记证据受限；
- `MI2`：同一对象上闭合条件提出、对方反馈、本人选择及执行、纠正或终局；
- `MI3`：同一外交机制跨年、跨阶段或在独立对象上复验，且每个被合并部分都能定位条件、反馈和执行；把多个族群、战事、臣将成果或短期归附装入一个父链不构成复验；
- `MI4`：跨主要阶段和不同压力结构仍稳定成立，并含反例后的恢复、退出或再次兑现。

归责与稳定性另判：`MI3/MI4`可共同归责或负向，但须明列本人批准、拒绝、改约、纠正或持续授权；任用多臣将不等于本人系统强链。档位写可独立阅读的全生涯模式，不加减父链数/MI。

“军事外交”仅供外部对照临时映射，须同时展示M1/M2原值，不设正式合成轴或掩盖两轴差异。
