# 人物画像分项规则：M2 外交博弈与对外联盟能力

> `FORMAL-V1.3`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么

M2评价本人识别对手、盟友和中立方的利益与底线，构建联盟、分化对手、谈判交换，以及执行和修正承诺的能力。战争与谈判的转换、有限目标、退出安排、受降、互市、和亲和使节活动均可取证。

和平、岁币、领土、国力差和外交总结果只用于复验，不直接换档。守约伦理归C5，承诺在反复交往中是否有效归M2；条约等关键词不比实际谈判、归附或均势安排更有分量。

## 2. 先判断内外关系及身份变化

每个外交周期以被评价者自身统治共同体为参照，记录`political_membership_at_cycle_start`、`membership_relative_to_evaluated_ruler`、`relationship_phase`。外部政权或外部自主行为者可进M2；本朝宗室、藩镇、创业联盟、内部叛乱、已内附集团和郡县化领土转M4或其他适用轴。“对方有独立拒绝权”本身不够。

身份与计分归属分开记录。`AXIS_OUT_WITH_REASON`、`BACKGROUND_VALIDATION`只说明不由M2计分或证据未完整，不能据此改写为`INTERNAL_TO_EVALUATED_RULER`。外部对象即使主要归M1/C1/M4，仍保留周期起点身份；双重身份和内外混合事件按实际交换内容划界，不同轴不重复计同一部分。

身份转变须用`identity_transition_point`标明：

- 转入本政权前的条件、反馈、承诺和执行归M2；转入后的授官、封爵、编旗、置州、给地、监督和长期政治参与归M4。
- 受降或入附后的事实，只有用于验证转变前已约定的安全保证、撤军、释放、岁币、边界、质子或退出安排，才记为原周期的`TERMINAL_EXECUTION`/`TERMINAL_BREACH`。
- 吞并后的领土治理、采办、地方反乱和镇压不延长原外交周期。对方重新成为事实独立政治中心且发生新的条件交换，才另起周期。多年国内整合不能抬高MI3/MI4。

对方要求、条件和反馈须为`VERIFIED_EXTERNAL`；内部伪造、误传或未核实试探不能当作外部反馈。

## 3. 证据强度与定档

先找本人批准、拒绝、改约、纠正或持续授权，再判断周期完整性。方向、归责和稳定性分别判断；共同归责或负向证据也可达到MI3/MI4。

| 强度 | 必要证据 |
|---|---|
| `MI1` | 一个外部对象上的单次条件、拒绝、承认、违约或结果性个案；只有汇总结论而无直接过程时最多到此，并标证据受限 |
| `MI2` | 同一对象上的条件提出、对方反馈、本人选择，以及执行、纠正或终局 |
| `MI3` | 同一机制跨年、跨阶段或在独立对象上复验，各部分均能定位条件、反馈和执行；多个族群、战事、臣将成果或短期归附的堆叠不算复验 |
| `MI4` | 跨主要阶段和不同压力结构仍稳定成立，并有反例后的恢复、退出或再次兑现 |

档位按全生涯主要模式判断，档内比较对象、条件、本人归责、持续性、纠错和反证，不按父链数或MI加减。任用多臣将不等于本人具备系统能力。

单次归责明确的失信、误判或关系损伤保留`NEGATIVE / MI1_CASE / SCORING_PARENT`，通常影响档内，不为计分抬高MI。塑造有限、材料稀疏、臣下主导、无逆风复验或谈判过程不完整，记`LIMITATION / MI1_CASE / BACKGROUND_VALIDATION`。

若以逆风、止损或纠错支持强度/档位，须在同链注明困境来源：`INHERITED`继承、`EXTERNAL`外生、`SELF_CAUSED`自致、`MIXED`混合。自致危机与纠错合判，不加逆风权重；混合只计可分的外生部分。不使用逆风论据时可省该字段。

### 材料有限时的定档边界

已有可评价的外部选择，即使只有一次承认、拒绝、条件接受或失效，也可用MI1给有界档位；分别说明外部身份、本人或共同授权、对方要求/回应、已执行部分和未证范围。MI2以上仍按上表要求。

有限档位只评价已证选择：局部成功不自动成为强长板，单次失败不自动成为长期失能。材料少不构成G0/G1/G2负证或G3中性依据；缺高压复验限制外推，不按对象、朝贡数量或继承和平定档。保留证据等级、置信度、档内位置和具体限制。

### 终局未显示能力

完成全生涯相关事件、直接选择、间接授权/批准/反馈和关系性质核对后，仍无可计外交能力证据，才用`assessment_basis=NO_DEMONSTRATED_CAPABILITY`：发布E（`G0-MID`，投影7），不作无档结案或默认G3。即位前、称帝前、从属期和退位后均按当时真实行为与权限检查。

此类表示“现有材料未显示外交能力”，须与已证明反复失能的G0分开，不宣称历史上没有外交行为或潜在能力为零。记录直接与间接归责核对、轴外排除理由、有效来源和结论；已有可计能力证据者不能使用。程序不得凭空父链或低置信度自动分配E，旧轴外/背景证据保留，不伪造负链。

固定输出`E1 / LOW / EPISODE_TAG / EVIDENCE_LIMITED`及`adjudication_state=FORMAL_CURRENT`；阅读页保留“未显示外交能力”和范围限制。新增合格证据后可局部改判。

## 4. 两类特殊外交证据

### 高压亲临外交

高压包括强敌行动、盟友可拒绝或转向、安全结构即时破裂、多方须现场作出可执行承诺。按本人当时风险和失败后果判断，不要求军事劣势，也不从终局规模倒推。

亲临只有同时满足下列条件，才加强本人归责及证据强度：

1. 对方有真实拒绝、退出、转向或提高要价的能力；
2. 本人处理实质分歧、交换条件或设计承诺，而非只主持礼仪；
3. 选择得到对方反馈，并进入封授、撤军、互市、编制、给地、履约等可核执行；
4. 后续结果用于验证承诺是否成立，领土、战胜或名望不重复换成能力。

多方协调、即时承诺、跨期执行及拒绝风险都有证据时，可为`MI4_CROSS_PHASE_SYSTEMIC`；仅到场、表态或概括结果按实证取MI1—MI3。同类亲临分别说明压力结构。

`G4-HIGH`通常须两条独立、能充分证明能力的强周期，或一条上述MI4亲临链加另一对象/阶段/机制的独立复验，并通过同类能力反证与材料密度审查；单次会盟或成果名望不足。这表示关键场景触及历史级，全生涯尚未达到G5。

### 和亲结果门与因果门

和亲、联姻等词触发全池扫描，但先确认是否确指婚姻；“修和亲”也可能只是友好。婚姻须同时通过：

- `RESULT_GATE`：比婚前出现可核的安全改善或外交形式变化，如停战、撤军、可执行军援或中立、缓冲建立、稳定互使、政治承认、关系转附。
- `CAUSAL_GATE`：变化能与婚姻条件、对方反馈和后续履约相连，而非仅时间相邻，或由战胜、臣服、其他政策独立造成。

仅有仪式，或侵扰/单向贡献未变、无新承诺、未履约、拒婚、外生中断、后效不明，均记`BACKGROUND_VALIDATION`，失败本身不自动成负链。

双门通过记`SCORING_EFFECT_VERIFIED`；婚姻只是大周期中的背景而其他谈判/履约机制可独立计分时，记`marriage_policy_review.disposition = BACKGROUND_COMPONENT_PARENT_RETAINS_OTHER_MECHANISM`并剥离婚姻贡献，不能把婚姻背景改名计分。

## 5. 复核与发布

正负名望仅触发同等范围的复核，不预定方向或档位。正面人物查失信、误判、条件失衡、退出失败和臣使代劳；负面人物也保留止损、履约、修复和退出成果。遇名望、事件或强度异常，逐人核对拒绝权、本人选择、交换、反馈、执行及全生涯反例，可保留档、改依据或改档，不为对称制造升降。

证据投影固定为：

| 证据 | 置信度 | 输出模式 | 状态 |
|---|---|---|---|
| E1 | LOW | EPISODE_TAG | EVIDENCE_LIMITED |
| E2 | MEDIUM | BOUNDED_PROFILE | EVIDENCE_LIMITED |
| E3 | HIGH | FULL_GRADE | FINAL |

关键计分链未完成时用工作状态`UNRESOLVED_EVIDENCE_GAP`。阅读表如保留整改前数字，须标为历史显示点，不能作当前实裁或雷达值。

“军事外交”只可用于外部对照的临时映射，同时展示M1/M2原值，不设正式合成轴。
