# 人物画像分项规则：M2 外交博弈与对外联盟能力

M2与M1分开。计入：

- 对对手、盟友和中立方利益及底线的识别；
- 联盟构建、分化对手、谈判授权与条件交换；
- 战争与谈判之间的转换、有限目标和退出安排；
- 条约、受降、互市、和亲、使节与承诺的实际履行；
- 外交反复、误判、孤立、失信或被动接受不利条件后的纠正。

外交结果规模由第三项相关事实复验，但不得把第三项总分、长期和平、岁币、领土变化或国力差直接换算为能力。守约伦理主要归C5；M2只看守约是否构成可信承诺、重复博弈和外交工具有效性。显式出现“条约、使者、盟约”等词只形成机械候选，不代表比通过战争—谈判转换、归附安排或多方均势体现的外交能力更强。

### 正负名望对称复核

外交名望、盛世叙事、万国来朝、强国版图等正面印象，以及屈辱、卖国、投降、亡国、昏庸等负面标签，都只能触发候选复核，不能承担方向、强度或档位。正面名望人物必须照常检查失信、误判、条件失衡、退出失败和臣使代劳；负面名望人物也必须照常保留有效止损、承诺兑现、关系修复和可执行退出，不得用终局成败覆盖过程能力。

复核必须回到同一组问题：外部对象是否有真实拒绝权，皇帝本人作了什么判断或授权，条件如何交换，对方如何反馈，安排是否执行，以及后续反例是否改变全生涯模式。正负名望召回采用同一有界预算；命中名望词、著名事件或机械强度异常后必须逐人语义复核，允许结论为保留档位、只重写依据或实质调档。审计不得为了形成“有升有降”的表面对称而制造改档。

### 高压亲临外交

M2中的高压不限于已经处在军事劣势。外部强敌正在行动、潜在盟友仍有拒绝或转向空间、区域安全结构存在即时破裂风险、多个参与方需要当场作出相互约束的可执行承诺，均可构成高压。压力强度看的是皇帝在对方仍有选择时承担的即时决策风险与失败反事实，不以最终成果大小倒推。

皇帝亲临不是独立加分项。只有以下条件同时成立，亲临才加强本人归责并提高该父链的诊断强度：

- 对手、盟友或中立方保有真实的拒绝、退出、转向或提高要价能力；
- 皇帝本人面对并处理至少一项实质分歧、条件交换或承诺设计，而非只主持礼仪；
- 现场选择得到对方反馈，并进入封授、撤军、互市、编制、给地、履约或其他可核执行；
- 后续结果用于验证承诺是否成立，但不把领土、战争胜利或名望重复换算为M2能力。

满足多方协调、即时承诺、跨阶段执行和拒绝风险的亲临完整链，可以裁为`MI4_CROSS_PHASE_SYSTEMIC`；若只有到场、表态或结果概括，仍只能按实际闭合程度裁`MI1—MI3`。不同事件可以同属“亲临高压博弈”，但压力结构必须分别说明：例如临兵对峙与联盟结构濒临破裂具有可比的本人决断含金量，却不得因此机械等档。

`G4-HIGH`通常要求两条独立高诊断性强循环，或一条上述`MI4`高压亲临完整链再加另一对象、阶段或机制的独立复验，并通过同构念反证与材料密度复核。它表示关键场景已经触及历史级表现而全生涯稳定性尚不足`G5`；单次会盟、外交名望、成果规模或后续军事胜利均不能单独满足此门。

### 和亲结果门与因果门

“和亲、联姻、婚盟、政治婚姻、公主、求婚、请婚、纳币、送女、迎亲”等只触发全池候选扫描。扫描命中后，必须先判断该词是否真的指婚姻；史书中的“修和亲”等也可能只表示恢复友好往来，不得望文生义。

婚姻安排只有同时通过下列两门，才可成为M2计分材料：

- `RESULT_GATE`：相对于婚前基线，出现可核的安全改善或外交形式变化，如停战、撤军、可执行的军援或中立、缓冲建立、稳定互使、政治承认或关系转附；
- `CAUSAL_GATE`：材料能够把上述变化与婚姻条件、对方反馈和后续履约连起来，而不是仅在时间上同时发生，也不是由战争胜利、臣服或其他政策独立造成。

下列情况固定为`BACKGROUND_VALIDATION`：只有成婚、送女、迎亲或纳币事实；婚后仍按原强度受侵；仍按原结构连续单向贡献而未换得新的安全或对等承诺；对方没有履约或关系形式没有变化；婚议被拒、未成、外生中断；后效材料缺失。背景不生成正向父链，也不因“没有成功”自动生成负向父链。

若婚姻只是一条更大父链中的附带工具，而该链另有独立闭合的谈判、军援、停战、承认、违约识别或退出程序，父链可以按其他机制继续计分；但必须记录`marriage_policy_review.disposition = BACKGROUND_COMPONENT_PARENT_RETAINS_OTHER_MECHANISM`，并从强度和档位依据中剥离婚姻贡献。只有通过两门者才可标记`SCORING_EFFECT_VERIFIED`。

M2使用“重大逆风、坏牌、止损或纠错”作为强度或档位依据前，必须在同一父链记录逆风来源：`INHERITED`表示继承前任留下的困局，`EXTERNAL`表示由外部行为者或本人无法控制的突发变化造成，`SELF_CAUSED`表示主要由本人此前的误判、升级或失信造成，`MIXED`表示外生压力与本人行为共同造成。`SELF_CAUSED`不得获得逆风加权；本人先制造危机再止损，只能在原父链内联合裁为纠错，不能拆出独立正链。`MIXED`只按可分离的外生部分判断强度。父链未出现上述语义时可以不设该字段，但任何以逆风为档位依据的父链缺少来源判定均不得通过M2语义门。

M2的材料方向与材料强度必须正交记录。单次、局部但本人归责闭合的失信、误判、接待失败、条件设计缺陷或关系损伤，应保留为`NEGATIVE / MI1_CASE / SCORING_PARENT`，通常只影响同档`position`；不得为了让负证“能够计分”而机械抬成`MI2_LIFECYCLE`。反之，“主动塑造有限”“材料稀疏”“臣子主导”“缺少逆风复验”以及尚未闭合的谈判尝试都只是证据或能力上限，必须标为`LIMITATION / MI1_CASE / BACKGROUND_VALIDATION`，不得冒充负向父链。`MI2`至少要求动作—对象反馈—本人纠正、拒绝纠正或可验证终局的生命周期闭合；`MI3/MI4`还须证明跨年、跨对象或跨阶段的稳定模式。正负材料的最高MI强度不直接换算档位，也不得做数字相减；档位先判断全生涯主模式，`position`再比较独立对象、条件质量、本人归责、执行持续性、纠错和同构念反证。

M2使用下列强度硬门：

- `MI1`：一个外部对象上的单次条件、拒绝、承认、违约或结果性个案；只有汇总结论而无直接过程时最多到此，并必须标记证据受限；
- `MI2`：同一对象上闭合条件提出、对方反馈、本人选择及执行、纠正或终局；
- `MI3`：同一外交机制跨年、跨阶段或在独立对象上复验，且每个被合并部分都能定位条件、反馈和执行；把多个族群、战事、臣将成果或短期归附装入一个父链不构成复验；
- `MI4`：跨主要阶段和不同压力结构仍稳定成立，并含反例后的恢复、退出或再次兑现。

本人归责与效果稳定性另行判断。`MI3/MI4`可以是共同归责或负向模式，但裁档必须明确皇帝本人究竟批准、拒绝、改约、纠正或持续授权了什么；“某朝廷先后任用多名臣将”不足以把臣下成果合并为皇帝的系统高强度父链。档位依据禁止用父链条数或MI标签相加减，必须写成可单独阅读的全生涯模式。

视频式“军事外交”只可在外部对照报告中由M1与M2生成临时映射，不是正式画像维度。映射必须同时展示M1、M2原值，不得用一个合成值掩盖赵恒式“统帅偏弱、谈判与安全安排较强”或铁木真式“统帅历史级、外交仍需独立裁决”的非对称结构。
