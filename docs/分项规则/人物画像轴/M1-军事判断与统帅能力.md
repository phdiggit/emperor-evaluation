# 人物画像分项规则：M1 军事判断与统帅能力

> `FORMAL-V1.4`；共同证据、档位与上位边界见[画像总合同](../../项目总纲/皇帝人物画像评估体系合同.md)；共同数据与发布见[共同数据与发布合同](00-共同数据与发布合同.md)。

## 1. 评什么，使用哪些事实

M1评价本人怎样选择战争方向、指挥和统筹作战，以及如何应对失败。以[战役登记](../../公共成果/军事/01-战役登记.json)的完整战役周期为事实依据；[武将人才登记](../../公共成果/军事/02-武将人才等级.json)只帮助定位战役、本人角色与来源。人物级武将等级、稳定性标签和压缩结论不参与定档、校准或公开裁决理由。

本人有实际统兵、战争方向决定、战区统筹或可归责军事授权机会，即适用M1；完成规定检索后须给档，确无这些机会才可记`NOT_APPLICABLE`。全生涯中为他人效力、创业从属、藩王/将领、即位前或退位后的军事行为，均按当时权限和实际角色判断。名义最高授权本身不构成能力正证。

| 子面 | 内容 |
|---|---|
| M1.1 | 战争目标、方向选择与军事战略 |
| M1.2 | 战区、战役和多军种统筹 |
| M1.3 | 临阵判断、战术解题与逆境反转 |
| M1.4 | 失败识别、责任、止损和重组 |
| M1.5 | 个人武勇与前线承担 |

M1.5只作有史源支持的低权重侧写或标签，不替代统帅能力；没有勇武材料不限制最高档位。

按以下顺序取证：

1. 依次用稳定`profile_ref/person_ref`、`name_aliases`、`historical-entity-identities.yml`唯一别名连接人物。跨朝称号和同名须结合朝代、ID及来源角色消歧，无法唯一连接时保留缺口。
2. 从人物索引定位逐战役经历，用战役登记的父级字段核对难度、原始角色、过程和成果。已有明确依据的字段直接复用，不重复制作史料卡。
3. 仅在角色、本人决定、难度、过程、失败反馈缺失或登记实质冲突时，沿`source_refs`回读本地史料；仍不足再作有界补证。人物适用但登记未命中时，定点补查本人经历。

## 2. 分清材料覆盖和能力可证范围

当前正式池已完成全生涯逐战役登记。`evidence_scope.material_coverage_status = FULL_LIFETIME_REGISTERED`声明来源覆盖，不由代表情境数量、索引命中、亲征次数或档位推算。代表情境只是阅读索引。

| 层次 | 正式表达与含义 |
|---|---|
| 材料覆盖 | `evidence_scope.material_coverage_status`及中文说明：生涯战役是否已登记 |
| 本人能力证据 | `axis_evidence_level`及`evidence_scope.ability_evidence_label`：能证明哪些角色、机制和独立情境；E1/E2不表示漏登记，E3不表示能力高 |
| 能力结论 | 角色投影、输出模式、置信度、档位及限制：结论能否推广到不同对象、阶段和压力条件 |

已完成登记和裁决的记录用`score_status = FINAL`；`EPISODE_TAG`、`BOUNDED_PROFILE`只说明能力可证范围。只有具体未登记战役、缺失史源或无法回查的本人行为，才构成材料覆盖缺口；没有亲征、败后恢复机会或足够可归责情境，不等于生涯未查全。

公开阅读先讲表现及定档依据，再连接战役、本人行动和武将档案。覆盖声明和技术归责留在正式记录与评价方法中，不逐人重复；E级不得标为“材料覆盖”。

## 3. 先证明本人角色，再使用任务难度

`D3/D4`描述任务压力。只有本人承担了相应角色，才可用于证明对应能力；下属的临阵表现不能转授给皇帝。

原始`role`、`commander_in_chief`、`principal_commander`、`not_in_command_chain`是输入。结合行动、`consumption_mode`、具体决定和反馈，判定`m1_role_class`，同时保留原字段。字段与事实冲突时记`ROLE_SEMANTIC_CONFLICT`并回查证据。

| `m1_role_class` | 定义 | 可以直接证明 | 不能直接证明 |
|---|---|---|---|
| `DIRECT_COMMAND` | 本人直接承担战役或战区作战指挥，对兵力运用、战役节奏、机动、接战或临阵处置具有可归责控制 | M1.1、M1.2、M1.3；存在本人败绩—反馈—调整链时可证M1.4 | — |
| `OPERATIONAL_COORDINATION` | 本人不直接承担临阵战术指挥，但持续负责战区、多军、后勤/兵力配置、阶段衔接及反馈后的重组 | M1.1、M1.2；本人直接完成止损、换将、资源重配或路线重组时可证M1.4 | 不得凭下属临阵表现证明M1.3 |
| `STRATEGIC_DIRECTION` | 本人主要提供战争目标、主攻方向、路线、资源规模、责任中心配置、节奏或退出条件；临阵执行由他人承担 | 闭合具体目标/路线/资源/责任中心时可证M1.1；跨阶段持续接收反馈并调整多军协同时可有限支持M1.2 | 不得凭战果证明M1.3；普通一次下令不能证明M1.2 |
| `NOMINAL_AUTHORIZATION` | 只有“命某将征某地”、常规批准、名义最高责任或事后追认，缺少可归责军事设计与反馈链 | 原则上不构成能力正证 | 不能证明M1.1/M1.2/M1.3；若后续补出具体错误设计或反馈责任，应按实际事实重投影，不以本标签直接判负 |
| `ROLE_UNRESOLVED` | 现有字段与叙述冲突，或不足判断本人究竟承担何种军事角色 | 仅作缺口标记 | 不得拿任务难度抬档 |

`DIRECT_COMMAND`要求本人直接控制战役操作，不要求亲自冲阵；人在军中也不自动算直接指挥。

角色分布按独立`campaign_group/capability_episode`去重。同一周期中的角色变化分阶段保留，不重复计数；同一战争拆卡、同一终局的多表和一个`MI2_LIFECYCLE`内的多个高压阶段都不增加独立周期。角色数量用于解释经验厚度和迁移，不设数值权重。

## 4. 怎样比较强弱

- **成果和难度组合看。**优先读取武将汇总中已明确归属本人的`campaign_tier/combat_difficulty`，再按角色核对。多个独立`S/S-/A × D2/D3/D4`组合可支持经验厚度，但直接指挥、共同主将、战后接续、统筹和战略方向并不等强。
- **结果用于复验。**逐人反查军事正式结算中的安全起终变化及本人改善、控制成果及其价值和交班成熟度、军事体系承压表现、同周期投入损失与回报。关于多方向成果、维持、恢复或高成本受挫的判断，须指向同值周期。总分和名次仅用于异常筛查。
- **资源决定比较起点。**核对本人可调用的国力、军制、后勤、人才、控制区和对手压力。优势不加分，反而提高合理期待；优势下反复配置失衡、错误点将、重大低效投入或败后未恢复，负证更强。资源劣势也不免除明确误判，大规模动员本身不证明统筹能力。成功与失败使用同一归责尺度。
- **评价本人过程。**国力、名将、扩张和历史影响不能替代能力。扩张只有在本人主帅或战略主导已有证据时才说明难度与范围；创新须有本人选择、运用、解题和跨情境复验，先驱或强势形象不加分。
- **纯战略角色单列成果尺度。**普通维持、正确任将、常规胜利或未受检验的克制，只支持有限G3内判断。本人持续设计并按反馈纠偏，跨对象、阶段实现国家级存续、统一或重建，才可能走下节G4例外路径。

正向阶段占比须带分母，称`observed_positive_share`，不称历史胜率；只有对象、粒度、结果口径和归责可比时才比较。

## G4/G5角色组合门

除总合同的厚度、稳定性和跨情境要求外，还须满足：

| 路径 | 必要条件 |
|---|---|
| G4直接统帅 | 至少两个独立强军事周期；一个为`DIRECT_COMMAND`，另一个为直接指挥或高质量`OPERATIONAL_COORDINATION` |
| G4最高统帅例外 | 可无直接指挥，但至少两个独立高压周期均有强M1.1和M1.2；本人完成目标/路线设计、责任中心与资源配置、反馈纠偏或重组，并经跨对象或阶段复验。最高G4，`limitations`须写`M1.3_DIRECT_COMMAND_NOT_ESTABLISHED`或同义限制 |
| G5直接统帅锚 | 至少一个历史级`DIRECT_COMMAND`，直接证明高压战役/战区中的战略、统筹和临阵解题 |
| G5独立复验锚 | 再有一个独立历史级或近历史级周期，可为直接指挥或高强度统筹。战略方向只有在国家级目标—路线—资源—责任中心—反馈纠偏完整且达到历史级强度时才可充当第二锚，不能称作第二个前线样本 |

普通任将、一次授权、团队总成果不能支持G4例外；`NOMINAL_AUTHORIZATION`不能充当高档锚。单个强周期不足G4。G5还须通过下述失败复核。

历史级直接统帅锚与历史级战略锚可支持G5-LOW，须说明角色差别；顶级直接统帅锚加大量优秀后方统筹，若缺第二个独立历史级或近历史级复验，原则上止于G4-HIGH。

### 重大军事失败门

读取战役登记的本人负向结果、`failure_impact_tier`、过程和归责。本人结果优先于父群总成果；混合周期不能整段转成纯负结果，难度D不换算严重性。未单列负档时保留未分档并审查实际损害，不补造负档。指挥结果责任不等于明确误判；反馈后重复同错须另有行为证据。

| 独立失败后果 | 裁决作用 |
|---|---|
| C、B | 通常限制档内；不按次数累加为A或S级，不因一般攻势未突破自动封顶 |
| 单次A | 审查重大损失、反馈与恢复；不足单独否决G5 |
| 多个独立A及以上 | 明确反馈后仍重复同一军事失误机制，并持续破坏主要任务、未完成有效纠偏时，阻断G5；事件数量本身不是充分条件 |
| S−、S、S+或已明确的同等严重实际后果 | 本人军事决定造成主要作战体系或关键方向能力严重破坏，且止损、重组后仍未恢复可行军事任务能力时，可由单次事件阻断G5；必须写出破坏与未恢复的过程，不以国家败局代替 |
| 混合周期 | 正果、失败及不可逆损失共同保留；负向阶段归并进完整周期，具体失能仍按前两项阻断条件判断 |

同一失败跨父群、人物阶段和武将记录合并，保留别名；同战前败后胜不算两次独立复验。分别判断作战能力恢复、原方向态势恢复和原战略目标实现。恢复能力不抹去不可逆损失，未实现原目标也不等于持续失能；恢复后保留G5时，严重残余损失仍限制档内。无败绩、无后续机会或若干大胜均不能机械抵消失败。

G5、G4-HIGH及明确以本门阻断G5的记录须保存`m1_stability_review`：逐失败记独立周期及别名、来源、本人后果档与口径、归责、反馈、恢复层次、残余损失和裁决，总体说明是否改变全生涯模式。校验只核对去重、口径和裁决一致，不自动判史实或按次数定档。

### 同轴交叉复核

1. **强证低档：**高峰或多个高难战役与档位明显不符时，核对本人角色、独立周期、失败反馈、残余损失及后续选择。平民伤害、强迁、成本或后期崩解，须另证目标、指挥、止损/重组失能才进入M1。阶段失败、保留正果的混合周期或已纠错通常只限档内；改变全生涯判断须达到总合同§4.2的模式改变型反证要求。
2. **高档等强：**与同档同位置人物比较本人过程、成果、压力、独立周期、跨期表现、归责和反证，并通过上表角色条件。总体档不取战略和现场能力中较高的一项。

校准覆盖稳定历史级统帅、高峰伴重大反证、国家成果高于本人能力、名望低估本人能力四类，不以外部视频分数为目标。

## 裁决理由与发布约束

- 保存`m1_role_projection`、`m1_role_distribution`；分布至少列四类已判角色的独立周期refs、其中D3/D4周期refs及未决冲突。`role_attribution`先写角色边界再写能力，多种角色分别说明。
- `phase_profile`、`typical_pattern`、`position_basis`提到高难情境时须附角色分布，不能将全部D3/D4周期称为直接统帅样本。没有M1.3证据须明示。
- 已登记的“战役成果等级/难度组合”“战役群名称/本人角色”按原值投影，JSON保留原文和数组；无事实则留空。公众理由展示战役事实和本人能力边界，不展示人物级武将等级、等级状态或无档案代码。
- G3及以下不得用“历史级能力”等总体评价，只可说明未达到的边界；G4可写强长板、跨情境高水平和历史级单点锚，不能把单点写成全生涯G5。只有G5总体档可直接称为历史级长板。
