# 人物画像分项规则：M1 军事判断与统帅能力

M1直接复用[战役登记](../公共成果/军事/01-战役登记.json)和[武将人才等级](../公共成果/军事/02-武将人才等级.json)中已闭合的本人能力事件、角色、难度、正向结果、可归责败绩、因果过错与证据下限。无需重新采集同一战役，禁止由第三项总分倒推个人能力。

上述两份公共成果是M1的规范主输入，不是检索线索。实施时必须直接读取已登记的战役难度、成果等级、武将角色、皇帝角色、本人能力事件、战役过程、失败归责、`military_grade`、能力事件厚度和稳定性门：

1. 先按稳定人物ID和别名把武将人才等级的人物汇总连接至正式皇帝池；
2. 以武将人才等级的已消费战役经历作为人物级索引，以战役登记的父级战役字段复验难度、角色、过程和成果；
3. 已闭合字段直接继承，不重新拆成逐条史料迁移任务，不为同一战役重复制作来源反查、语义卡或分批人工裁决；
4. 只有登记缺少亲征/指挥角色、本人决定、战役难度、关键过程、失败反馈，或两份登记发生实质冲突时，才沿现有`source_refs`回读本地史料；现有史料仍不足时才新增有界补证；
5. 先裁M1适用性：本人拥有实际统兵、战争方向决定、战区统筹或可归责军事授权机会者适用，完成规定检索后必须给档；确无任何此类机会者才可标记`NOT_APPLICABLE`。登记未命中但人物适用时，必须定点补查本人军事经历，不因皇帝名望、国家战果或名将成果补写本人能力。

人物连接不得只做皇帝展示名与武将`person`的字面相等比较。必须依次使用既有稳定`profile_ref/person_ref`、武将`name_aliases`和`historical-entity-identities.yml`中的唯一人物别名；跨朝共享的庙号、谥号或称号不得脱离朝代与稳定ID单独作为连接键。同名多人必须以既有稳定profile、朝代和来源角色消歧，无法唯一连接时保留缺口，不得自动任选一条。

内部固定展示五个侧面：

| 子面 | 内容 |
|---|---|
| M1.1 | 战争目标、方向选择与军事战略 |
| M1.2 | 战区、战役和多军种统筹 |
| M1.3 | 临阵判断、战术解题与逆境反转 |
| M1.4 | 失败识别、责任、止损和重组 |
| M1.5 | 个人武勇与前线承担 |

M1.5只作低权重能力侧写或标签。亲射、冲阵、单骑、负伤和个人格斗只有在史源闭合时记录；勇武不能替代战略与统帅，缺少个人武勇材料也不限制M1上限。

M1的总体档位不是“战略统筹”和“现场统帅”取高者。正式结果必须同时展示`military_talent_anchor`：直接连接武将人才登记中的`military_grade`、`grade_status`和`stability_status`；未形成正式人物汇总时标记`NO_FORMAL_PROFILE`。该锚只说明现场、战役和直接统帅能力的已闭合下限，不直接换算M1，但用于阻止国家成果、正确任将和最高权力授权越过本人统帅能力边界。M1仍发布一个总体档位，但阅读表必须让战略主导型与现场统帅型的证据差异可见。

凡已连接正式武将档案，M1逐人结算依据必须从武将人才等级阅读表同值投影“战役成果等级/难度组合”和“战役群名称/武将角色”两栏，并在JSON保留原栏文本与逐项数组；不得以M1摘要改写、删减或重新生成这两栏。无正式档案者明确显示`NO_FORMAL_PROFILE`，不得临时拼造等价栏。

校准规则：

- `military_grade`是人物级压缩索引和校准输入，不得单字段映射最终M1；必须同时读取其已汇总的能力事件厚度、独立战役类型、可归责失败、因果过错、生涯稳定性和登记缺口；
- 第三项只用于复验军事行动是否形成安全结果、成本和长期代价；高净收益不自动等于高统帅能力，低净收益也不能抹除已经闭合的能力；
- 第三项正式结算必须作为M1战略成果的逐人反查入口，但不得直接换算档位：A读取任内安全态势起终变化与本人改善归责，B读取实际控制成果、战略价值和交班成熟度，C读取军事体系在压力下的兑现，D读取同一父周期的投入、损失与安全回报。M1声称“多方向成果”“战略维持”“恢复”或“高成本受挫”时，必须能指向上述同值父周期；A净退、B成果低或未成熟、C高低回报混合、D长期负值均不得被国家名望或将领胜绩覆盖。第三项总分和名次只作异常筛查，不是M1分数输入。
- 国力、名将成果、扩张规模和历史影响不得替代本人能力。扩张规模只有在本人实际主帅或主导战略闭合时，才作为已经解决问题的难度与范围；
- “开疆先驱”“民族强势”等形象不加分；真正的军事创新必须有本人选择、实际运用、问题解决与跨情境复验。
- 战役厚度按独立`campaign_group/capability_episode`和完整生命周期判断；同一战争拆出的父卡、阶段卡、第三项定位ref或同一终局的多张表不得相加冒充多场独立战役。正向阶段占比只能写成带分母的`observed_positive_share`，不得称为历史胜率；只有对象、粒度、结果口径和归责可比时才允许比较占比。
- 难度优先读取武将汇总和第一项C已经闭合到本人的`campaign_tier/combat_difficulty`。父战役、同阵营将领或国家整体承受的难度不得自动转授给仅作战略授权的人物。
- “成果等级/难度”必须作为组合读取，是M1与武将档位倒挂复核的主要触发器。多个独立`S/S-/A × D2/D3/D4`本人主帅或主将结果被压在G3及以下时必须逐人说明；但组合不直接换算M1，仍须结合武将角色、`consumption_mode`、共同归责、负向组合、失败反馈与恢复。完整主帅终局、共同主将、战后接续和纯战略授权即使显示相同`S-/D3`也不等强。
- 纯战略或授权型必须单列成果尺度：普通维持、正确任将、一次常规胜利或未受检验的克制只能支持有限的G3内判断；跨对象、跨阶段且由本人持续纠偏的国家级存续、统一或重建才可能支持G3上沿；耶律大石西迁重建一类跨区域历史级巨型序列可进入G4，但仍须显式保留现场统帅、难度和失败反馈边界。
- **资源优势下失常门**：M1必须同时判断本人可调用的国力、成熟军制、财政后勤、人才池、既有控制区与相对对手压力。强国、强军或明显资源优势不是能力加分；它们提高基线期待。在较好初始条件下仍反复错误点将、配置战区失衡、以主力级投入换取低收益、遭受重大败绩且反馈后没有同方向恢复，负证强度高于资源受限者的同等表面结果。不得把大规模动员本身写成统筹能力，也不得把成功时的将领成果上收给皇帝、失败时又只归责将领。资源劣势只能解释任务难度，不能自动洗掉明确的本人误判。

M1另设两道与武将人才等级对照的硬门：

1. **反向差距门**：M1低于本人武将人才等级的相邻兼容区间时，必须列出稳定父战役、本人责任、同轴失败类型、反馈到达和后续选择。`war_conduct`、平民伤害、屠杀、强迁、一般战争成本或国家后来崩解属于结果或伦理负面，不得改写军事能力情境的正负方向；只有它们同时闭合为战争目标、指挥判断、止损或重组失能时，才能按对应M1子面另行消费。同一父战役内的负向记录先合并再判断强度，不得把人物表、战役表和成本表的同一失败重复计数。一次`C`级阶段失败、一次仍保留实质正果的`A`级混合情境，或一次收到反馈后已经有效纠正的失误，通常只限制档内位置；若要改变全生涯主模式，仍须满足4.2节的`PATTERN_CHANGING_COUNTEREVIDENCE`门。
2. **正向等强门**：M1高于本人武将人才等级的相邻兼容区间时，允许以本人主导的战争方向、战区统筹或授权纠偏上调，但必须与至少一名同档同`position`、具有实际统帅战绩的人物作等强比较，并保存锚点`ruler_id`、成果层级、对手与压力、独立情境或跨阶段复验、本人归责和主要反证。`G5`必须同时闭合历史级战略分布和历史级现场/战役统帅锚；武将登记仅为`top`、存在重复重大失败、没有正式人物汇总，或主要依靠国家成果与授权链者，均不得仅靠战略等强比较进入`G5`。`G4`必须至少闭合跨独立情境的强战略—统帅模式；`EPISODE_TAG`、单一生命周期或`SINGLE_CONTEXT_ONLY`不得发布`G4/G5`。纯战略或授权型历史级巨型序列最高发布`G4`，并显式标记现场统帅边界。仅有正确任将、一次普通胜利、团队长期获胜、国家扩张结果或概括性的“多方向较强”，最高只能支持G3。嬴政统一六国一类跨对象、跨阶段的巨型序列可形成战略长板，但在本人临阵、失败反馈和跨阶段统帅材料不足时不得进入G4。

两道门只检验差距是否可解释，不要求M1复制武将人才等级。每个越出相邻兼容区间的对象都必须输出`talent_grade_comparison`、`difference_direction`、`same_grade_position_anchor`和`difference_justification`；缺任一字段不得通过M1横向校准门。

李世民、铁木真、刘彻、耶律阿保机为首轮必审校准组：合同必须能解释历史级稳定统帅、历史级高峰伴重大反证、国家扩张声望高于本人能力、以及大众印象低估本人多战役能力四种不同画像。不得以四人的视频分数为目标值。
