# 人物画像分项规则：M1 军事判断与统帅能力

M1直接消费[战役登记](../../公共成果/军事/01-战役登记.json)和[武将人才等级](../../公共成果/军事/02-武将人才等级.json)的本人能力、角色、难度、成果、败绩归责与证据下限，不重复采集或由第三项总分反推能力。

两登记为规范输入，按以下顺序消费难度、成果等级、角色、过程、失败归责、`military_grade`、厚度与稳定性：

1. 先按稳定人物ID和别名把武将人才等级的人物汇总连接至正式皇帝池；
2. 以武将人才等级的已消费战役经历作为人物级索引，以战役登记的父级战役字段复验难度、原始角色、过程和成果；
3. 已闭合字段直接继承，不重新拆成逐条史料迁移任务，不为同一战役重复制作来源反查、语义卡或分批人工裁决；
4. 只有登记缺少亲征/指挥角色、本人决定、战役难度、关键过程、失败反馈，或两份登记发生实质冲突时，才沿现有`source_refs`回读本地史料；现有史料仍不足时才新增有界补证；
5. 先裁M1适用性：本人拥有实际统兵、战争方向决定、战区统筹或可归责军事授权机会者适用，完成规定检索后必须给档；确无任何此类机会者才可标记`NOT_APPLICABLE`。登记未命中但人物适用时，必须定点补查本人军事经历，不因皇帝名望、国家战果或名将成果补写本人能力。

M1消费人物全生涯中已经闭合的可归责军事能力事件，不以规范池`actual_power_window`、即位、称帝、建国或最高权力身份作为事件截止线。为他人效力、创业从属、藩王/将领或退位后阶段的军事行为，只要本人实际承担战争判断、统兵、战区统筹、资源/责任配置或反馈后调整，即按当时真实角色进入M1；权限有限只影响归责、角色分类和外推范围。反之，窗口内仅有名义最高授权也不得自动形成能力正证。

依次按稳定`profile_ref/person_ref`、`name_aliases`、`historical-entity-identities.yml`唯一别名连接，不只比展示名。跨朝称号须结合朝代与ID；同名以profile、朝代、来源角色消歧，不能唯一连接则留缺口。

内部固定展示五个侧面：

| 子面 | 内容 |
|---|---|
| M1.1 | 战争目标、方向选择与军事战略 |
| M1.2 | 战区、战役和多军种统筹 |
| M1.3 | 临阵判断、战术解题与逆境反转 |
| M1.4 | 失败识别、责任、止损和重组 |
| M1.5 | 个人武勇与前线承担 |

M1.5仅作低权重侧写/标签，勇武须有史源，不替代战略统帅；无勇武材料不封顶。

## 角色证明门

**战役难度属于任务，不自动属于人物。** `D3/D4`只能说明该任务承受了高压力；只有本人实际承担相应军事角色，任务压力才能转换成对应的M1能力证据。后方统筹参与`D4`战争，不等于本人拥有一个`D4`直接作战指挥样本；名将完成高难临阵解题，也不得因皇帝下令出战而转授给皇帝。

战役登记、武将人才等级中的原始`role`、`commander_in_chief`、`principal_commander`、`not_in_command_chain`等字段只作为输入，不直接等同M1能力结论。M1必须结合原始角色、行动描述、`consumption_mode`、本人具体决定和反馈链，生成轴内标准角色`m1_role_class`；原字段与轴内投影同时保留。原字段与事实描述冲突时标`ROLE_SEMANTIC_CONFLICT`，回到现有证据做有界复核，不机械相信字段名，也不因人物名望选择更高角色。

| `m1_role_class` | 定义 | 可以直接证明 | 不能直接证明 |
|---|---|---|---|
| `DIRECT_COMMAND` | 本人直接承担战役或战区作战指挥，对兵力运用、战役节奏、机动、接战或临阵处置具有可归责控制 | M1.1、M1.2、M1.3；存在本人败绩—反馈—调整链时可证M1.4 | — |
| `OPERATIONAL_COORDINATION` | 本人不直接承担临阵战术指挥，但持续负责战区、多军、后勤/兵力配置、阶段衔接及反馈后的重组 | M1.1、M1.2；本人直接完成止损、换将、资源重配或路线重组时可证M1.4 | 不得凭下属临阵表现证明M1.3 |
| `STRATEGIC_DIRECTION` | 本人主要提供战争目标、主攻方向、路线、资源规模、责任中心配置、节奏或退出条件；临阵执行由他人承担 | 闭合具体目标/路线/资源/责任中心时可证M1.1；跨阶段持续接收反馈并调整多军协同时可有限支持M1.2 | 不得凭战果证明M1.3；普通一次下令不能证明M1.2 |
| `NOMINAL_AUTHORIZATION` | 只有“命某将征某地”、常规批准、名义最高责任或事后追认，缺少可归责军事设计与反馈链 | 原则上不构成能力正证 | 不能证明M1.1/M1.2/M1.3；若后续补出具体错误设计或反馈责任，应按实际事实重投影，不以本标签直接判负 |
| `ROLE_UNRESOLVED` | 现有字段与叙述冲突，或不足判断本人究竟承担何种军事角色 | 仅作缺口标记 | 不得拿任务难度抬档 |

`DIRECT_COMMAND`不要求人物亲自冲阵、持械或身处最前线；“是否冒矢石”属于M1.5。只要史源能够闭合本人对战役操作层的直接指挥，就可以投影为`DIRECT_COMMAND`。反之，人在军中也不自动等于直接作战指挥。

M1正式结算必须新增`m1_role_projection`与`m1_role_distribution`。角色分布按独立`campaign_group/capability_episode`去重，不按父卡或表格条数计数，至少列出四类角色对应的独立周期refs、其中`D3/D4`高压周期refs以及未决冲突。角色数量只用于解释厚度和迁移，不设数值权重，不按“前线=1、后方=0.7”之类公式换档。

裁决理由若提及高难情境，必须同时给角色分布。允许写“本人军政生涯涉及7个D3/D4压力周期，其中2个为直接作战指挥、4个为战区/多军统筹、1个为战略方向”；禁止把不同角色合并写成“7个高难统帅样本/7个高难直接统帅情境”。同一独立周期内角色发生升级或变化时，以阶段记录保留，不重复计为多个周期。

总体档不取战略/现场两者最高。须展示`military_talent_anchor`，连接`military_grade`、`grade_status`、`stability_status`，无正式档案标`NO_FORMAL_PROFILE`。锚是直接统帅的证据下限，不换算M1；阅读页须显示战略与现场证据差异，不以国家成果或授权越过本人能力。

有正式武将档案者，同值投影“战役成果等级/难度组合”“战役群名称/武将角色”，JSON保留原文及数组，不以M1摘要改写、删减或重建。无档案显示`NO_FORMAL_PROFILE`，不拼造等价栏。

校准规则：

- `military_grade`是人物级压缩索引和校准输入，不得单字段映射最终M1；必须同时读取其已汇总的能力事件厚度、独立战役类型、可归责失败、因果过错、生涯稳定性和登记缺口；
- 第三项只用于复验军事行动是否形成安全结果、成本和长期代价；高净收益不自动等于高统帅能力，低净收益也不能抹除已经闭合的能力；
- 第三项正式结算必须作为M1战略成果的逐人反查入口，但不得直接换算档位：A读取任内安全态势起终变化与本人改善归责，B读取实际控制成果、战略价值和交班成熟度，C读取军事体系在压力下的兑现，D读取同一父周期的投入、损失与安全回报。M1声称“多方向成果”“战略维持”“恢复”或“高成本受挫”时，必须能指向上述同值父周期；A净退、B成果低或未成熟、C高低回报混合、D长期负值均不得被国家名望或将领胜绩覆盖。第三项总分和名次只作异常筛查，不是M1分数输入。
- 国力、名将成果、扩张规模和历史影响不得替代本人能力。扩张规模只有在本人实际主帅或主导战略闭合时，才作为已经解决问题的难度与范围；
- “开疆先驱”“民族强势”等形象不加分；真正的军事创新必须有本人选择、实际运用、问题解决与跨情境复验。
- 战役厚度按独立`campaign_group/capability_episode`和完整生命周期判断；同一战争拆出的父卡、阶段卡、第三项定位ref或同一终局的多张表不得相加冒充多场独立战役。正向阶段占比只能写成带分母的`observed_positive_share`，不得称为历史胜率；只有对象、粒度、结果口径和归责可比时才允许比较占比。
- 难度优先读取武将汇总和第一项C已经闭合到本人的`campaign_tier/combat_difficulty`。父战役、同阵营将领或国家整体承受的难度不得自动转授；必须经过`m1_role_class`证明门后，才能进入对应M1子面。
- “成果等级/难度”必须作为组合读取，是M1与武将档位倒挂复核的主要触发器。多个独立`S/S-/A × D2/D3/D4`结果只有在本人角色分别闭合后才能讨论M1厚度；组合不直接换算M1，仍须结合`m1_role_class`、`consumption_mode`、共同归责、负向组合、失败反馈与恢复。完整直接指挥终局、共同主将、战后接续、战区统筹和战略方向即使显示相同`S-/D3`也不等强。
- 纯战略型必须单列成果尺度：普通维持、正确任将、一次常规胜利或未受检验的克制只能支持有限的G3内判断；跨对象、跨阶段且由本人持续设计并根据反馈纠偏的国家级存续、统一或重建，可走下述G4“最高统帅例外路径”，但必须明确M1.3缺口。单纯`NOMINAL_AUTHORIZATION`不得作为G4/G5锚。
- **资源优势下失常门**：M1必须同时判断本人可调用的国力、成熟军制、财政后勤、人才池、既有控制区与相对对手压力。强国、强军或明显资源优势不是能力加分；它们提高基线期待。在较好初始条件下仍反复错误点将、配置战区失衡、以主力级投入换取低收益、遭受重大败绩且反馈后没有同方向恢复，负证强度高于资源受限者的同等表面结果。不得把大规模动员本身写成统筹能力，也不得把成功时的将领成果上收给皇帝、失败时又只归责将领。资源劣势只能解释任务难度，不能自动洗掉明确的本人误判。

## G4/G5角色组合门

G4与G5除满足画像总合同的厚度、稳定性和跨情境要求外，还必须满足下列角色组合门：

1. **G4直接统帅路径**：至少两个彼此独立的强军事周期；其中至少一个必须闭合`DIRECT_COMMAND`，第二个可以是另一直接指挥周期，也可以是高质量`OPERATIONAL_COORDINATION`。只拥有一个强周期、同一战争拆卡或单个MI2生命周期，不足G4。
2. **G4最高统帅例外路径**：可以缺少`DIRECT_COMMAND`，但必须至少两个独立高压周期同时闭合强M1.1与M1.2，且本人真实完成目标/路线设计、责任中心和资源配置、反馈后的纠偏或重组，结果能够跨对象或阶段复验。该路径最高G4，并须在`limitations`明确`M1.3_DIRECT_COMMAND_NOT_ESTABLISHED`或同义边界；普通任将、一次正确授权、团队总果或概括“多方向胜利”不得进入该路径。
3. **G5直接统帅锚**：必须至少存在一个历史级`DIRECT_COMMAND`锚，能够直接证明本人在高压战役/战区中的战略、统筹和临阵解题；没有直接作战指挥历史级锚，不得进入G5。
4. **G5独立复验锚**：在直接统帅锚之外，至少再有一个独立的历史级或近历史级军事能力复验。第二锚可以是另一`DIRECT_COMMAND`，也可以是高强度`OPERATIONAL_COORDINATION`；只有当`STRATEGIC_DIRECTION`闭合国家级目标—路线—资源—责任中心—反馈纠偏完整链且达到历史级强度时，才可作为第二锚，但必须明确它不能替代第二个前线/直接指挥样本。`NOMINAL_AUTHORIZATION`绝不能作为第二锚。
5. **稳定性门**：G5必须把全生涯重大败绩、本人归责、反馈是否到达、止损/重组以及同方向恢复一并纳入；一个历史级高光不能覆盖反复重败或反馈后持续失能。

因此，“历史级直接统帅锚 + 历史级战略设计锚”可以构成G5-LOW的合法组合，但档内理由必须明确二者角色不同；不得写成“两个历史级前线样本”。反之，“一个顶级直接统帅锚 + 大量优秀后方统筹”若第二个独立历史级/近历史级复验未闭合，原则上停留G4-HIGH。

M1另设两道与武将人才等级对照的硬门：

1. **反向差距门**：M1低于武将等级相邻兼容区间，须列稳定战役、本人责任、同轴失败、反馈及后续选择。`war_conduct`、平民伤害、强迁、成本或后期崩解须另证目标、指挥、止损/重组失能才入M1。同一失败跨表先归并。一次`C`级阶段失败、保留正果的`A`级混合或已纠错，通常只限位置；改全生涯模式须达总合同§4.2的`PATTERN_CHANGING_COUNTEREVIDENCE`。
2. **正向等强门**：M1高于相邻区间，须本人战略/统筹/纠偏，并与至少一名同档同`position`实战统帅等强比较，保存`ruler_id`、成果、压力、独立/跨期情境、归责及反证。`G5`同时执行上述直接统帅锚、独立复验锚和稳定性门；武将仅`top`、重复重败、无档案或主要靠国家授权均不能仅靠战略比较入G5。`G4`须通过直接统帅路径或最高统帅例外路径；`EPISODE_TAG`、单链或`SINGLE_CONTEXT_ONLY`不入G4/G5。普通任将/胜利、团队总果或概括多方向最高G3。

越出相邻区间须有`talent_grade_comparison`、`difference_direction`、`same_grade_position_anchor`、`difference_justification`，缺一不通过；两门检验差距解释，不要求复制武将档。

## 裁决理由与发布约束

- `role_attribution`必须先写角色边界，再写能力结论；若同一人物兼有直接指挥、战区统筹与战略方向，应分别消费。
- `phase_profile`、`typical_pattern`、`position_basis`若使用“D3/D4压力”“高难战争”等表述，必须附角色分布，不能只报情境数量。
- G3及以下的正向结论不得使用“历史级能力”“历史罕见能力下沿”“历史级统帅下沿”等越档措辞；若需要提及，只能用于说明“未达到历史级”的边界。G4可以描述“强长板”“跨情境高水平”及具体历史级单点锚，但不得把单点锚写成全生涯G5语义。只有G5总体档可以直接称为历史级长板。
- 一个`MI2_LIFECYCLE`即使内部包含多个D3/D4阶段，也仍是一个独立周期；理由不得因组件数、父卡数或战果数写成“多次独立复验”。
- 输出须能让读者看见：哪些能力来自本人直接作战指挥，哪些只来自战区/多军统筹，哪些只是战略设计；若没有M1.3证据，应明示，不以国家战果填补。

横向校准覆盖：稳定历史级统帅、高峰伴重大反证、国家成果高于本人能力、名望低估本人能力；不以视频分数为目标。
