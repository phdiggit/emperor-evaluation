# 第五项B人事与权力管理：用人与授权材料合同

## 1. 合同角色

本文件是第五项B“人事与权力管理”50分中的用人与授权材料子合同，不独立形成得分、档位或动态映射。第五项B最终还必须合并外戚、宦官、宗室、权臣和军头等权力关系管理事实，统一按[第五项总合同](00-规则与计分合同.md)定档。

本合同面向全部统治者，只评价本人可归责的人事行为。它不建立完整臣子档案、完整人才团队或跨时代人才总排名。

## 2. 可计分行为链

每条材料必须闭合：

`本人识别或接触 → 具体岗位与责任 → 授权或约束边界 → 实际反馈 → 本人维持、修正、撤换或保护`

允许以下四类行为：

| 类型 | 评价内容 |
|---|---|
| 识别与岗位匹配 | 是否根据可观察能力和任务需要选择合适对象，而非事后借成果反推识才。 |
| 授权与边界 | 是否给予完成职责所需权限，同时保留必要责任、复核和退出边界。 |
| 监督、纠偏与撤换 | 获得有效反馈后能否留任、调整、收权、撤换、惩处或补救。 |
| 容人保护与反徇私 | 是否保护专业履职和合理异议，并防止私人关系压过公共责任。 |

单纯授官、沿用前任人员、列出名臣、人物声望、官职数量和团队规模不构成材料。受任者后来取得的制度、治理、军事或文明成果只验证人岗配置是否有效，不按成果量级、持续期或历史影响换分。

## 3. 归责与去重

- 必须存在统治者本人设立、任命、授权、维持、纠正或保护行为。前任、父祖、下属或受任者自行建立的团队不得递归归给统治者。
- 同一对象的连续任用、升降和纠偏优先合并为一条责任链；只有岗位、权限或独立反馈完全不同才允许分开。
- 同一创业团队成果已在第一项B结算时，本项只能消费统治者本人不同构念的人事行为，不再消费成果规模和组织化结果。
- 官僚体系整体质量归第二项B1，制度化监督和信息通道归第二项B2，交班时权力结构归第二项D3。
- 军事、治理、文明成果和公共损害分别归对应结果项；本项只判断人事行为是否合理、可纠正和可持续。

## 4. 材料预算

第五项B每名统治者最多消费四条核心行为链，且不得挤占第五项总合同规定的全项七条上限。候选选择顺序为：

1. 国家核心责任或高风险权力关系；
2. 能证明跨阶段稳定模式的连续链；
3. 可能改变正负方向或当前档位的强反证；
4. 普通、重复和同质材料只补来源，不继续计入。

候选冻结必须在数值判断前完成，不按最终正负方向挑样本。至少检查一条正向入口和一条负向入口；史料缺失不得解释为没有失误。

## 5. 人才材料边界

本项不要求公共人才档位。若仓库已有武将、治理、谋略、外交或专业人才画像，可以作为“该对象具备完成责任的可观察能力”旁证，但不得直接把`ordinary / usable / important / top / historic`映射为皇帝分数。

发现人才只有在能够证明统治者在首次实质使用前完成识别、验证或突破明显接近障碍时，才提高识别行为的证据强度。使用后的巨大政绩不得倒推发现能力。建立团队只看本人是否形成互补、可替补和可纠偏的责任结构，不汇总成员人才等级。

## 6. 正负判断

正向主要看岗位适配、授权清楚、反馈有效、纠偏及时、容人和反徇私是否形成可重复模式。负向主要看明知不适任仍重用、授权失控、责任冲突、私人关系污染、压制专业反馈、纵容重大损害以及纠正后复发。

结果大小不直接决定材料强度。核心国家职责只能提高该行为对统治者模式的代表性；不能把受任者的全国性成果原样复制为“卓越用人分”。

## 7. 输出要求

每条接受材料至少保存：

- `behavior_chain_ref`
- `ruler_ref`
- `person_or_group_ref`
- `responsibility_scope`
- `ruler_action`
- `feedback_observation`
- `correction_or_continuation`
- `primary_score_owner`
- `excluded_result_axes`
- `source_refs`

材料输出只进入第五项B人物行为包，由第五项总合同统一定档。未完成全名册同预算校准前，不生成正式50分得分或排名。
