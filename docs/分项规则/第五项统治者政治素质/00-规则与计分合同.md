# 第五项统治者政治素质规则与计分合同

> 状态：`formal_settlement_published / negative_tail_replayed / database_write_closed`。A、B、C分轴及第五项-18—120分汇总已经完成201人全名册和G-1历史级负向尾部正式回放。后续修订必须重跑本合同的全池覆盖、横向一致性、双跑确定性和正式导出门禁，不得直接手改个人分数或排名。

## 1. 评价对象与结构

第五项评价统治者本人跨情境、可重复的政治行为与稳定素质，不评价国家和社会已经取得的业务成果，最高120分、最低-18分：

| 分项 | 名称 | 分值 |
|---|---|---:|
| A | 履职与认知稳定性 | 35 |
| B | 人事与权力管理 | 50 |
| C | 政治克制与品格 | 35 |
| **合计范围** |  | **-18—120** |

第五项面向全部评价对象，不因是否为奠基人而改变准入。创业者在第一项已经取得的团队成果不妨碍其参加第五项，但同一团队成果不得再次换分。

本合同统一规定A、B、C三轴的材料准入、归责、聚类、正负合成、行为预算、档位和输出。旧I5B规则、人物包和实现只保留为事实线索、来源lineage与影子材料工具，不构成独立合同，不得继承旧五规则数值、人才档位、团队分、结果幅度乘数或旧排名。

## 2. 固定材料池与全池工作顺序

第五项先消费第一至第四项已经形成的canonical或accepted材料、公共成果登记和可追溯旧I5B线索，不从少数名人样本或开放人物搜索开始。处理顺序固定为：

1. 对全名册建立唯一、稳定的`ruler_id / task_code`矩阵；
2. 对前四项和旧I5B材料机械全池筛查，A、B、C广召回，不预设每人候选条数；
3. 标记来源分项、本人选择、归责强度、行为、反馈、继续或纠正、方向、同链键、只有结果噪声、跨项重复风险和证据状态；
4. 排除无法形成本人行为命题的纯结果，把可由本人授权、维持、纠正或放任闭合的材料恢复为行为链；
5. 按同一人物或权力关系、同一政策或战役、同一因果链聚合；
6. 对每个命中链完成正负双向语义复核，再确定是否进入核心链、佐证、例外或补证队列；
7. 只有完成全池聚类和复核后，才应用最多七条的最终行为预算。

不得把`NO_OBSERVED_CANDIDATE`、`SUPPORTING_CONTEXT_ONLY`或`UNRESOLVED_EVIDENCE_GAP`写成零分。定向补证只闭合已经发现的本人责任、行为、反馈或例外；全池仍无候选者才进入统一的新发现队列，且不得给名人更宽的检索预算。

默认史料预算为本人本纪、实录或同等连续主干，加不超过两组可能改变档位的专题史源。已有证据足以稳定档位时停止扩展，不建立完整皇帝事件全集、臣子全集或人才知识图谱。

### 2.1 三层检索、客观皇帝基线与豁免

每个轴必须按固定顺序完成三层正反复核：

1. 本地通读总结；
2. 本地缓存史料、前四项正式结算、公共成果、授权周期及既有第五项召回或补证产物；
3. 前两层仍缺少可能改变方向或强度的关键闭环时，联网检索并回到可定位的正史、实录、政书、诏令奏议或可靠学术来源。

只有三层检索均已按需走完、主要阶段和正反入口均已检查，仍未形成中等以上偏离客观皇帝正常履职区间的合格人物特质时，才可裁为`VERIFIED_NORMAL_BASELINE`，固定映射为G3-LOW。它是检索闭合后的中性裁决，不是缺材料、未发现负面、零分或正向美德加分；必须在逐人理由中写明复核范围和检索轨迹。

`UNRESOLVED_EVIDENCE_GAP`表示检索链仍未闭合，不能换成基线。傀儡、无实权或实际掌权窗口极短、无法形成稳定统治素质观察者，使用`EXEMPT_NO_BACKFILL`单列，不伪造特质、不以基线填补，也不参加第五项排名。短在位但具有足够实际权力和可观察行为者仍按普通人物完成三轴复核。

人物百科、完整生平汇总和公共人物页必须同时承担“行为链入口”和“基础画像”两种作用。机械命中不能闭合核心链时，仍须按以下状态保留，不得在消费统计中消失：

- `BEHAVIOR_CHAIN_LOCATOR`：已经指出可能闭合的本人行为、反馈或持续性位置；
- `BASELINE_PROFILE_SUPPORT`：不足以单独计分，但能描述本轴的基本正负画像、阶段变化或反向复核方向；
- `PENDING_CONTEXT_OR_SOURCE`：语义可能有关，尚缺上下文、本人归责或可靠来源；
- `RESULT_ONLY_OR_OTHER_SUBJECT`：只有结果、他人行为或错期内容，明确排除。

人物页已有本轴命中而未形成核心链时，轴级缺口必须记为`MATERIAL_GAP_WITH_PROFILE_CUES`或相应部分观察，不能写成“无材料”或“未发现相关画像”。基础画像不直接换分；它只决定补证入口、反向检索和名望反差审计是否已覆盖人物的基本面。

## 3. 最小充分统治行为链

唯一核心裁决单位是`ruler_behavior_chain`：

`情境与压力 → 本人实际权力与可选空间 → 本人行为或可归责维持/放任 → 可检验的直接结果或后果 → 若后续反馈实际发生，再记录本人继续、修正、撤权或复发`

一条核心链至少必须闭合：

- 发生在本人实际掌权窗口；
- 存在本人可以采取的现实替代方案；
- 能识别本人行动、授权、否决、维持、纠正或明确放任；
- 有足以判断行为是否合理的直接结果、后果或同期检验；
- 后续反馈实际发生时，能说明本人继续、修正、撤权、补救或复发；事件已直接交付终局时，不得为了形式闭环强造中途反馈；
- 已声明成果、损害和跨期后果的主计分项目。

只有结果而没有本人选择的材料不得成为核心链，但结果可以检验已经明确的本人行为或授权。`未观察到继续或纠正`必须原样记录，不得改写成`从未纠正`，也不得把未发生中途反馈视为授权链缺口。

同一行为链内保留`repeat_count`、持续期、地域或群体范围、公共责任层级、后果强度和纠错状态。重复出现可以证明稳定模式或复发，但不得按事件条数等权相加。异文、多源转述和同一结果的不同切片只提高证据置信度，不增加行为数量。

## 4. 皇帝归责与授权推定

重大国家行动在本人实际掌权窗口内原则上进入皇帝授权复核。第五项不因史料只记执行者而自动抹去最高权力责任，也不把所有臣下行为机械归给皇帝。

| 归责状态 | 适用条件 | 第五项处理 |
|---|---|---|
| `DIRECT_EXPLICIT` | 明载本人命令、任命、批准、否决、亲征、撤换、保护或惩处 | 可直接建立本人行为命题 |
| `STATE_ACTION_PRESUMED` | 国家级行动发生在本人实际掌权期，按当时权力结构通常不能绕开最高授权，且没有相反证据 | 进入本人责任复核；必须同时检查例外 |
| `JOINT_OR_SHARED` | 摄政、共治、军政集团或多人共同决定，无法全部归于一人 | 只消费可分离的本人部分；否则降为佐证 |
| `SUBORDINATE_AUTONOMY` | 明载擅自行动、矫诏、抗命、自行投降、开门、弃城或独立叛乱 | 不把初始行为归给皇帝；只审查其事前配置与事后处置 |
| `INHERITED_PREDECESSOR_CHAIN` | 任命、授权或权力结构由前任建立，本人只被动接收 | 不递归归责；本人后续确认、维持、调整或撤换可另成链 |
| `PUPPET_OR_NO_REAL_POWER` | 有证据证明本人被架空、受控制或不掌握相关决定权 | 撤销相应本人推定，转向实际掌权者或记证据缺口 |

第三项战役登记中的`ruler_role_status=unresolved`只表示不能据此推定皇帝亲自指挥，不否定登记内已经明载的亲征、命将、换将或征讨诏令。第五项可以消费这些授权行为，但不得复制战役胜负、控制规模或军事净收益。

归责强度与方向、行为合理性分开记录。名义上的最高责任不能自动形成负向；实际成功也不能自动证明授权合理。

## 5. 与其他项目的边界

- 制度、行政、民生、军事、文明成果归前四项；第五项只消费本人行为方式。
- 第一项B消费创业团队独立成果和组织化结果；第五项B只消费本人识别、配置、授权、纠偏、容人及权力关系管理行为。
- 第二项B1消费官僚体系整体质量，第二项B2消费日常反馈机制是否运行，第二项D3消费交班结构结果；第五项只消费本人面对人事、反馈和权力关系时的行为模式。
- 第三项消费军事安全、控制与成本收益；第五项B只消费选将、授权边界、临阵换将、失败纠正和军头权力关系管理，不消费战场军纪表现。
- 第四项消费教育文化、知识生态和文明整合结果；第五项C只消费本人在文化强制、迫害、保护和宽容中的最高权力伦理。
- 具名重大决策产生的创业、治理、军事或文明结果分别归第一至第四项；第五项A只看跨多个普通或持续治理情境的认知和履职模式，不另设决策分。
- 跨期社会、军事或文明损害的规模与持续性归对应结果项；第五项C只评价本人行为性质和稳定模式，不另设历史负债扣分。

同一史实可以为不同项目提供证据，但第五项必须写明新增消费的本人行为命题。成果规模、持续期、战略价值、社会净收益、文明影响或历史负债不能再次换分。

## 6. A履职与认知稳定性（35）

### 6.1 评价问题

A评价统治者是否能够持续履行最高政治职责、理解政策与现实约束、学习必要知识，并在事实反证出现后更新判断。A的核心是功能和认知可靠性，不是勤奋形象、聪明名声或单次决策成败。

### 6.2 正向触发

- 在多个阶段持续处理核心政务，并能区分轻重缓急；
- 主动理解陌生、复杂或专业问题，而不是完全依赖近臣代断；
- 面对可验证反证修正事实判断、政策理解或工作方法；
- 能识别自身能力、健康和信息边界，进行可监督、可撤回的职务安排；
- 在压力、个人偏好或短期诱惑下仍保持基本履职和认知纪律。

奏章数量、批阅时长、诏令数量、早起晚睡和个人博学只作入口，不能直接换分。单次纳谏、一次认错或一次危机止损通常只证明局部能力。

### 6.3 负向触发

- 长期不履行核心职责、沉迷或把国家职能交给不可监督的私人圈层；
- 在已有明确反证后仍反复坚持同一事实错误；
- 对基本政策机制和现实约束持续表现出严重误解；
- 明知自身失能却拒绝建立可运行的替代履职安排；
- 纠正后迅速复发，形成跨场景的认知或纪律失常模式。

疾病、年龄和客观信息不足本身不作道德扣分；只有在仍有现实替代方案时，本人的安排、拒绝安排或持续错误才进入A。

### 6.4 轴边界

制度化反馈入口是否存在归第二项B2；本人是否听懂、更新并形成跨情境认知模式归A。具体用谁、如何授权和撤换归B。使用强制权力是否守住伦理底线归C。一次重大历史节点若不能复验稳定模式，只按其具体结果归第一至第四项，不在第五项单独计分。

## 7. B人事与权力管理（50）

### 7.1 评价问题

B评价本人能否识别人、配置责任、设定授权边界、监督纠偏，并管理外戚、宦官、宗室、权臣、军头和私人关系等可能侵蚀公共权力的力量。B不只评价任命，也不建立完整臣子名单或人才排名。

### 7.2 五类触发

| 类型 | 评价内容 |
|---|---|
| 识别与岗位匹配 | 是否根据当时可观察能力和任务需要选择合适对象，而非事后借成果反推识才 |
| 授权与责任边界 | 是否给予完成职责所需权限，同时保留复核、问责、收权和退出边界 |
| 监督、纠偏与撤换 | 后续反馈实际出现时，能否留任、调整、收权、撤换、惩处或补救；未发生后续反馈不构成独立缺项 |
| 容人保护与反徇私 | 是否保护专业履职和合理异议，防止亲属、宠信和私人恩怨压过公共责任 |
| 权力集团管理 | 是否配置、制衡和处置外戚、宦官、宗室、权臣、军头及共治集团 |

继承与交班材料只有在能够分离出本人的储位安排、顾命配置、军权约束或权力集团处置时进入B；王朝是否顺利延续的结果仍归第二项D3。

### 7.3 准入与排除

单纯授官、沿用前任人员、列出名臣、人物声望、官职数量、团队规模和受任者结果不构成核心链。受任者成果只验证岗位和授权是否有效，不按制度、治理、军事或文明成果量级、持续期或历史影响换分。

公共人物画像只可证明受任者在当时具有怎样的可观察能力，不得把`ordinary / usable / important / top / historic`映射为皇帝分数。人才发现只有在首次实质使用前存在识别、验证或突破明显接近障碍的证据时，才增强识别链；巨大后续政绩不得倒推发现能力。

同一对象的连续任用、升降、失控与纠偏优先合并为一条链。岗位、权限、反馈和责任完全不同，且各自有独立因果闭环时才允许拆分。

### 7.4 正负判断

正向看岗位适配、授权清楚、可归责交付、容人、反徇私和权力制衡是否形成高于基线的模式；后续反馈实际出现时，再看反馈处理与纠偏。负向看明知不适任仍重用、授权失控、责任冲突、私人关系污染、压制专业反馈、纵容重大损害，以及获得反证后不纠正或纠正后复发。

结果大小不直接决定行为强度。核心国家职责只能提高行为对统治者模式的代表性，不能把全国性成果原样复制为卓越用人分。

B4军事指挥授权须进一步区分“授权事实”和“授权强度”。具体任务、人选匹配、真实独立权限与可归责结果闭合授权事实；强度则综合任务难度、敌我压力、成果规模与质量、受任者独立完成程度、跨任务类型的稳定性以及错误授权反例。战役难度、成果规模与质量必须复用第三项正式结算、战役底账或既有公共成果中的已登记事实，不得在第五项临时重评、另造等级或重算战果。数量不能单独决定强度，同样数量的低难任务不得与少数决定政权存亡或完成大规模统一的高难交付等量齐观。第三项的战果分数不得搬入B4，皇帝本人亲征或战略指挥也不得借受任者战果给B4加分；这里只用既定结果的规模和难度检验“把何种任务交给何人并给予何种权限”的质量。

### 7.5 领域合成不得丢失极性

B可以先按文官行政、军事授权、法律监督、权力关系等适用领域裁决，但领域状态必须分别保存：最强正向、最强负向、重复或持续性、压力情境、反馈与纠正、证据充分度和适用性。不得在轴级合成前把以下不同语义压成同一个`MEDIUM`：

- 多次高于基线但尚未达到强档的正向；
- 正负实质并存的混合领域；
- 明确低于基线但尚未形成严重失控的负向；
- 仅有普通履职、结果线索或极性未闭合的领域。

若保留领域档标签，至少应区分`STRONG_POSITIVE`、`MEDIUM_POSITIVE`、`MIXED_BALANCED`、`MEDIUM_NEGATIVE`、`STRONG_NEGATIVE`、`NEUTRAL_BASELINE`和`UNRESOLVED`。观察到一至四个`NEUTRAL_BASELINE`或`UNRESOLVED`领域都不能机械抬档；多个独立正向领域则必须能够增强轴级模式，不能与单领域普通表现得到完全相同的合成结果。领域缺失、领域不适用和领域表现弱必须分开。

## 8. C政治克制与品格（35）

### 8.1 评价问题

C评价统治者在拥有强制权力、现实诱因或明显优势时，是否对功臣、异见者、百姓、政治对手和弱势者守信、克制并遵守基本程序底线。C评价强制权力伦理，不评价一般性温和名声或私人生活道德。

对皇室公共资源、强制供给和最高权力特权的使用不属于私人生活道德。只有形成可验证的持续选择，且相对同时代合格统治者的正常区间显著节制或显著滥用时，才可作为C的权力克制或失范链；一般生活习惯、一次性节省或单纯褒贬标签不准入。

### 8.2 正向触发

- 有现实报复、清洗、毁约或扩大惩罚的诱因时仍选择有限处置；
- 保护无辜者、合理异议者或依法履职者免受私人报复；
- 对政治对手、降者、功臣或政治合作对象遵守已作承诺；
- 在拥有绝对优势时仍保留申辩、复核、区分责任或减轻株连；
- 发现冤错、滥权或过度惩罚后实施可验证的纠正和补救。

普通未作恶、缺少迫害记载、例行赦免和无现实诱因的宽容不自动形成正向核心链。

### 8.3 负向触发

- 构陷、滥杀、酷刑、株连、任意剥夺或以私人好恶替代责任判断；
- 对投降、议和、归附、功臣或政治合作对象故意毁约；
- 系统性迫害异见者、学者、群体或无辜相关者；
- 明知执行者扩大伤害仍授权、维持、包庇或拒绝纠正；
- 同类侵害跨阶段复发并成为稳定统治工具。

社会损害规模和跨期后果仍归对应结果项；C只消费最高权力的选择性质、重复性、范围、可逆性和纠错状态。

### 8.4 时代校准

时代情境只校准当时是否存在现实替代方案、采取克制的难度和行为的常见程度，不能替暴行免责。不得因某种滥杀、株连、酷刑或群体迫害在当时常见，就将已经存在可行替代方案的主动选择改判为中性。

### 8.5 战场军纪排除

第五项不评价战场军纪和征服过程中的军队行为。屠城、坑杀或杀降、劫掠、焚烧、侵暴、强迫民丁，以及禁止或制止上述行为、保护战场降俘或约束部队等正负材料，均不得进入A、B、C核心链、佐证、档位锚点或硬负向门禁；本人亲征、明确命令、授权、知情、追认、惩处或纠正不改变这一排除。

相关事实可由第三项军事成本以及第二、四项相应社会或文明结果消费。第五项仍可评价选将、授权边界、军头权力关系，以及脱离战场军纪问题后能够独立闭合的政治承诺、政治清洗、司法处置和强制权力伦理，但不得借这些入口把已排除的战场军纪正负材料重新计入。

## 9. 十领域画像、聚类与七条解释预算

轴级裁决固定消费十个领域画像：A1核心履职可靠性与自身边界、A2信息反馈与认知更新；B1文官与行政人才授权、B2法务监察与专业监督、B3关键权力关系管理、B4军事指挥授权；C1惩罚、株连与强制比例、C2异议者、无辜者与履职者保护、C3守信、合作对象与反报复、C4公共资源与最高权力特权克制。B领域内的主题只用于召回、定位和去重，不是六个或更多等权子分，也不要求逐主题齐全。

所有已闭合且互不重复的行为链先在所属领域内合成人物特质画像，再由领域画像合成轴级档位。每名统治者最终最多展示七条不重叠代表性核心行为链，正负方向共同占用展示预算，B最多展示四条。七条是最终解释与审计预算，不是召回、回源或计分证据截断线；未展示的同链事实仍可作为重复性、持续性、范围、反证和纠错状态进入领域画像，但不得作为额外独立链累计。

处理顺序固定为：

1. 全池召回，不限每人条数；
2. 同因果链聚类，并保留重复次数、持续性、范围、后果和纠错状态；
3. A、B、C分别完成正负双向复核；
4. 在不知道最终分数的条件下，完成十领域画像和轴级正负合成；
5. 轴级档位冻结后，按公共责任、模式代表性、独立反馈、反证强度和证据质量选择最多七条代表链，用于解释已经形成的档位。

B最多展示四条。A或C只要存在合格核心链，就各至少展示一个代表槽位；没有合格链时不得为了形式平衡补齐。剩余槽位按解释轴级模式或硬负向门禁的重要程度分配，不按材料数量、人物名望或预期得分分配。七条选择结果不得反向改变已经完成的领域强度和轴级档位。

同一链涉及多轴时只保留一个`primary_axis`。其他轴只能登记`supporting_axes`和辅助命题，不得拆成多条重复得分。主轴按行为的核心评价对象确定：功能与认知可靠性归A，人事与权力关系归B，强制权力伦理归C。

## 10. 正负合成与硬负向门禁

每轴先分别判断正向模式、负向模式和纠错状态，再形成一个轴级档位。不得按正负材料条数相减，也不得以多数低强度正向抵消少数高强度反证。

方向和强度必须相对该情境下合格统治者的客观职责基线与正常行为区间判断，不得只与该统治者自己的早期、峰值或其他阶段相比。高于合理基线为正向，低于合理基线为负向，仍在正常区间内则为中性背景，不得为了凑链强行定向。时代情境只校准当时可行替代、行动难度和正常区间，不替失能或强制侵害免责。

同一统治者从个人峰值回落，但回落后仍高于客观基线，应记录为正向强度下降或满档反证，不得翻写成负向。处于正常职责和合理行为区间内的事实只作中性背景；只有持续性、范围、公共责任、程序、现实替代、后果和反馈后选择等因素使其显著偏离基线时，才形成相应方向和强度。

每条进入合成的行为链必须显式记录：`objective_baseline`、`baseline_deviation`（`POSITIVE`/`NEGATIVE`/`NEUTRAL`/`UNRESOLVED`）、`magnitude`、阶段变化、可行替代、持续性、范围、后果和纠错状态。相对自身的阶段变化只用于描述轨迹和限制档位，不能代替客观基线判断。

纵向归并完成后、七条选择之前，必须执行同领域跨人物横向一致性复核：使用同一客观基线、方向定义和强度标尺比较已经裁决的同类事实链。若较弱事实被判得显著更高、较强事实被判得显著更低，或正负方向出现无法由归责、替代、持续性、范围、后果和纠错解释的倒挂，则相关裁决全部退回逐条复核；横向一致性未闭合前，不得进入轴级档位合成。该复核只校验统一标准，不以人物名望、个人峰值或既有排名作为参照。

轴级合成依次回答：

1. 正向是否跨独立情境或阶段重复；
2. 负向是孤立失误、阶段性短板，还是稳定主模式；
3. 本人收到何种反馈，是否及时纠正、补救或复发；
4. 高责任、高压力场景是否推翻普通场景表现；
5. 是否触发以下上限门禁。

| 门禁 | 条件 | 轴级上限 |
|---|---|---:|
| `H1_MAJOR_UNCORRECTED` | 一次高责任重大反证，反馈明确且仍未纠正，但尚未成为跨场景主模式 | G3-HIGH |
| `H2_REPEATED_OR_SYSTEMIC` | 同类重大反证跨阶段复发，或形成系统性安排，且本人直接授权、维持或包庇 | G2-HIGH |
| `H3_DOMINANT_DESTRUCTIVE_PATTERN` | 严重失能、权力失控或强制侵害成为主要统治模式，且没有实质纠正 | G1-HIGH；符合G0定义时进入G0 |
| `H4_HISTORICAL_DESTRUCTIVE_PATTERN` | 同轴HISTORICAL纯负向成为跨阶段主模式，或多个独立STRONG纯负向共同达到跨时代罕见破坏性，且本人直接维持、反馈后继续、没有实质纠正 | G-1；完整生命周期为`MIXED_NEGATIVE`或归责不足时最高G0 |

门禁按轴适用，不把C轴暴行自动扣到A/B，也不以A/B的正向表现解除C轴门禁。确有及时、有效且持续的纠正时，可降低反证层级，但既成严重行为不得从记录中删除。

### 10.1 混合生命周期

同一因果链先后出现正负阶段时，不得拆成两条相互抵销，也不得把`MIXED`当作正向、负向之外的第三种可直接计分方向。链内必须保留各阶段的客观基线偏离、持续期、反馈和纠正状态，再按主导性统一标记：

- `MIXED_POSITIVE`：负向阶段是局部或已被及时、有效、持续纠正，完整生命周期仍显著高于客观基线；
- `MIXED_NEGATIVE`：正向阶段只是局部缓解、迟来修复或未能阻止主要负向模式，完整生命周期仍显著低于客观基线；
- `MIXED_BALANCED`：正负阶段均有实质承载，现有证据不足以确定主导方向。

原始材料只写`MIXED`时，必须在轴级合成前完成上述主导性裁决；未完成则只输出`PARTIAL_DIRECTIONAL_OBSERVATION`。纠正行为可以降低负向强度或门禁，但不得机械删除纠正前已经形成的持续伤害；早期正向也不得与晚期严重失能按条数或幅度简单相减。

## 11. 档位与计分

三轴统一采用G-1至G5档和LOW/MID/HIGH。G-1不是“材料比G0更多”，而是历史级纯负向已经超过非负下限的专门尾部：

| 档位 | 共同含义 |
|---:|---|
| G-1 | 历史级纯负向构成跨阶段主导模式，反馈后仍持续，且没有足以改变主模式的纠正；只评价本轴本人行为，不读取国家结果规模。 |
| G0 | 反向行为构成稳定主模式，或关键基本能力严重缺失。 |
| G1 | 偶有正向行为，但不稳定、强依赖个案或被主要反证压倒。 |
| G2 | 明确低于合格基线：虽有局部能力或正向反证，但明显短板、阶段断裂或重大反证仍占较大权重。 |
| G3 | 合格基线至稳定正向。G3-LOW是经过完整正反复核的正常履职基线；MID、HIGH依次要求更稳定、更广或更强的正向模式。 |
| G4 | 跨阶段、跨压力情境持续表现优秀，并能处理重要反证。 |
| G5 | 达到历史高位，在强压力和多类情境下仍稳定，且没有主导性结构短板。 |

| 档位 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| G-1 | -15% | -10% | -5% |
| G0 | 0% | 5% | 10% |
| G1 | 15% | 20% | 25% |
| G2 | 30% | 37% | 44% |
| G3 | 50% | 57% | 64% |
| G4 | 70% | 77% | 84% |
| G5 | 90% | 95% | 100% |

`分项得分 = 分项权重 × 得分率`，保留一位小数。

正式消费器按以下语义骨架合成，不作领域分值相加：

| 同轴主导画像 | 默认落点 | 调整条件 |
|---|---|---|
| HISTORICAL纯负向且构成跨阶段主模式 | G-1；完整生命周期为`MIXED_NEGATIVE`、存在实质纠正或本人归责不足时进入G0至G1 | 只由本人行为链的持续性、适用范围、反馈后继续和跨时代横向校准触发；国家崩溃、伤亡或结果规模不得反推 |
| STRONG纯负向 | G1；存在同等强正向阶段或跨领域实质反证时可到G2 | 重复、系统性、终局失能和未纠正向LOW移动；阶段受限或有效纠正向HIGH移动 |
| STRONG的`MIXED_NEGATIVE` | G2 | 正向阶段是真实但非主导反证；只有另有纯STRONG负向或触发H2/H3时才进入G1 |
| MEDIUM负向 | G2 | 与STRONG以上正向并存时按主导性进入G2-HIGH至G3-HIGH，不作算术抵销 |
| VERIFIED_NORMAL_BASELINE | G3-LOW | 必须完成主要阶段和正反复核；普通未命中不适用 |
| MEDIUM正向 | G3-MID至G3-HIGH | 跨阶段、范围和反证处理决定档内位置 |
| STRONG正向 | G4 | 有重大未纠正反证时应用H1/H2，而不是按弱负面条数降档 |
| HISTORICAL正向 | G5；缺少同轴独立支持时暂落G4-HIGH | 必须通过跨时代同领域校准，历史级不限单人 |

`MIXED_POSITIVE`按正向主模式处理，但相反阶段限制档内位置或触发门禁；`MIXED_NEGATIVE`按负向主模式处理，真实正向阶段使其与同强度纯负向拉开一档，但不能使其回到合格基线；`MIXED_BALANCED`通常落在G2-HIGH至G3-LOW，只有完成主导性裁决后才能离开该区间。LOW、MID、HIGH由持续性、压力、适用范围、反馈后选择和反证处理共同确定，不由观察领域数或材料条数机械决定。

单一情境且缺少反向复核时只形成`PARTIAL_DIRECTIONAL_OBSERVATION`，不因方向正负而直接落入低档。一个经过完整正反复核、覆盖主要阶段的领域画像可以独立承载轴级档位，不按其聚类后只剩一条记录而降格。`VERIFIED_NORMAL_BASELINE`固定进入G3-LOW；进入G4必须有STRONG以上代表性正向领域并通过跨阶段或跨压力复验；进入G5必须有HISTORICAL正向领域、同轴其他适用领域或独立情境支持，并通过跨时代锚点比较，且没有H1以上门禁。

“一条跨阶段连续链”是独立于“两条情境”的完整准入路径。已经闭合主要在位期、持续性、压力、反馈和反向复核的高强纵向链，不得因聚类后只剩一个`behavior_chain_ref`而退回单次强链上限。

轴级合成不得将十领域等权相加，也不得用正负条数、主题数量或材料数量决定档位。固定顺序为：先找同轴最强正向、最强负向及其主导性；再审查重复、持续、压力、范围、反馈和纠错；最后应用硬负向门禁。弱正向不能稀释强负向，弱负向也不能把历史级正向直接打回低档。混合画像按完整生命周期的主导方向进入合成，反方向部分保留为档内位置或上限约束。

三轴消费器必须显式实现以下高档路径，不能只在合同中保留档名：

| 轴 | G4最低可执行路径 | G5最低可执行路径 |
|---|---|---|
| A | 高强纵向正向履职或认知更新模式，另经独立压力或反证情境复验，主要阶段稳定且无H2以上门禁 | 在G4基础上通过跨时代同领域锚点，强压力与多类认知/履职情境仍处历史高位，且无H1以上门禁或关键功能短板 |
| B | 一个代表性领域达到STRONG，并以任务匹配、真实权限和可归责交付完成授权单元；另有适用领域正向支持或同领域跨阶段复验。后续反馈仅在实际发生时计入，不要求皇帝二次介入；领域缺失不得冒充领域弱项 | 至少一个领域达到HISTORICAL，另有两个适用领域达到STRONG或形成等价的跨阶段、跨权力类型历史高位组合；不得由单一人才、单一战役或单一制度结果支撑，且无H1以上门禁 |
| C | 至少两个独立克制或保护主题，其中包含跨阶段或高压力检验；重大反证已实质纠正或不占主导，且无H2以上门禁 | 在G4基础上通过跨时代同领域锚点，多类强制权力情境仍保持历史高位，且无H1以上门禁或主导性伦理短板 |

上述是可达性下限，不是按链数自动晋档。消费器必须保留相应字段并提供G4、G5分支；当前数据没有人物满足时可以实证为零，但不得结构上不可达。

表现档位与证据充分度、置信度必须分开。上述证据门槛只限制过度外推，不能把材料较少机械换算为较低表现，也不能使只有正向观察的人物仅因证据较少而排在已有明确负向反证的人物之下。材料只能确定方向或上限、尚不能确定轴级主模式时，应输出`PARTIAL_DIRECTIONAL_OBSERVATION`或`UNRESOLVED_EVIDENCE_GAP`并另记已观察方向，不得强行落入G-1—G5。已经闭合阶段变化、重复表现和反向复核的纵向行为链按其实际语义判断证据承载，不因文件或聚类后只剩一条记录而降格为单次孤证。

G0必须由可归责的稳定反向模式或关键基本能力严重缺失证明，不得由材料少、没有正向候选或结果失败反推。G-1还必须通过`H4_HISTORICAL_DESTRUCTIVE_PATTERN`，并与同轴HISTORICAL/STRONG负向人物逐一横向比较；G0人物不得仅因专门补证发现更多材料就自动降入G-1。证据不足输出`UNRESOLVED_EVIDENCE_GAP`，不得以零分替代。

短任不自动阻断G-1，也不自动减轻负向强度。若人物在完整实际权力窗口内连续面对多个关键节点、反复作出同方向高责任选择，并在明确反馈后继续，短时间内仍可形成稳定主模式；反之，长任和史料丰富只增加可观察机会，不得自动把同性质行为判得比短任者更重。杨广、胡亥等同属多轴严重负面者必须逐轴比较本人选择、反馈后继续、可行替代与纠正，国家资源毁损规模和C1/C2/C3档差不得搬入第五项拉开差距。胡亥清洗大臣及诸公子、杀六公子并迫将闾兄弟自杀，宗室与群臣因此震恐，必须补入C1负向审查；但其对象范围和持续规模不足以达到朱元璋蓝玉案一万五千余人株连的C1历史级锚。胡亥复作阿房并追加五万材士、郡县转输的C4可判强负向，但不足以达到杨广多年多工程、巡游与反馈后继续加码的C4历史级锚。

人物只有在A、B、C三轴分别形成可判档结论后，才允许合成第五项120分正式总分。`VERIFIED_NORMAL_BASELINE`是完成第2.1节检索后的可判档G3-LOW，不属于缺轴；普通`BASELINE_PROFILE_SUPPORT`、未经三层闭合的`NO_SALIENT_DEVIATION_AFTER_FULL_REVIEW`、`PARTIAL_DIRECTIONAL_OBSERVATION`和`UNRESOLVED_EVIDENCE_GAP`仍不计分。任一轴未形成档位时，人物级输出必须保留已判轴档和缺口，但`fifth_item_total_score`为`null`，不得按已有轴归一化、均值填补、同朝代插补或将缺轴记零；合同允许的`EXEMPT_NO_BACKFILL`人物则单列且不参加排名。

### 11.1 缺材料轴的计分处理

证据状态与计分状态严格分离：

| 轴级状态 | 允许输出 | 计分处理 |
|---|---|---|
| `GRADE_CANDIDATE` | 轴级档位、档内位置、证据充分度和置信度 | 通过正式门禁后换算轴分 |
| `VERIFIED_NORMAL_BASELINE` | G3-LOW、三层检索轨迹、基线复核范围和证据充分度 | 视为可判档结论；通过正式门禁后换算正式轴分 |
| `PARTIAL_DIRECTIONAL_OBSERVATION` | 已观察方向、当前上限、缺少的反向复核或独立情境 | `axis_score=null` |
| `UNRESOLVED_EVIDENCE_GAP` | 已完成的检索范围和仍缺材料类型 | `axis_score=null` |
| `EXEMPT_NO_BACKFILL` | 无实权、傀儡或实权极短的依据 | 不生成轴分和总分，不参加排名 |

缺材料不是表现处于平均水平，也不是表现较差。任何缺轴均不得使用以下替代办法：

- 记零、记中档或记基础分；
- 按已有轴重标为120分；
- 用同朝代、同类型统治者、人物名望或前四项得分插补；
- 用材料数量、传记篇幅或未发现负面推定正常表现。

人物只有三轴均为`GRADE_CANDIDATE`或`VERIFIED_NORMAL_BASELINE`并分别通过轴级冻结门，才具有第五项总分和排名资格。其余人物可以公开已判轴结果与缺口，但第五项总分、项目总分和排名资格均保持`null`或`INELIGIBLE_EVIDENCE_GAP`；`EXEMPT_NO_BACKFILL`按豁免规则单列。这是一项证据资格限制，不是对人物的负面评价。

### 11.2 分轴名望画像反差门

名望画像只承担异常发现，不是史实证据、行为链或分数先验。画像必须限定到A、B或C的具体评价问题；泛泛的明君、昏君、贤德、暴君或中兴之主名号不得参与比较。

每轮轴级冻结前，使用正负对称、跨时代的分轴锚点检查全部已判档人物，并将结果归入：

- `ALIGNED`：方向和强度大体一致；
- `EXPLAINED_AXIS_SCOPE`：表面反差可以由本轴边界、跨项去重或混合生命周期解释；
- `MATERIAL_GAP`：画像提示可能漏链，但当前材料不足，不直接改档；
- `DIRECTION_CONTRAST`：已判方向与分轴画像明显相反；
- `UNRESOLVED_STRENGTH_TENSION`：方向一致但强弱显著反常，且不能由归责、替代、持续性、范围、后果或纠错解释。

`DIRECTION_CONTRAST`和`UNRESOLVED_STRENGTH_TENSION`必须退回材料、聚类、强度与映射四层复核；未解决前不得冻结该轴。`MATERIAL_GAP`不降低现有表现档位，但对应人物仍维持部分观察或证据缺口。画像审查不得直接新增事实、提高档位或把缺口改成中性。

### 11.3 档位分布健康门

档位健康审查不预设钟形分布、固定比例或各档名额，也不因分布不好看而移动人物。它只检查量尺是否可执行、正负是否对称、材料覆盖是否被误写成表现差异。

正式冻结前至少通过：

1. **结构可达性**：A、B、C的G-1—G5及LOW/MID/HIGH均存在明确、可执行的证据组合路径；不得出现合同有档、消费器无路径；
2. **单调性**：同领域中持续性、压力、范围、后果和纠错更强的正向模式不得反而更低，重复或系统性负向不得反而更高；
3. **正负对称**：相同证据充分度下，正向与负向形成档位的准入门槛对称；不得把单个负向直接落档而把同强度正向长期留在部分观察；
4. **高低锚点实现**：已闭合的强正向、强负向跨时代锚点应能实际进入相应高低尾部；若已知强锚点仍全部挤在G1/G2，视为映射压缩而非历史分布结论；
5. **覆盖敏感性**：剔除低置信、单领域或材料特别密集群体后，分布形状不得发生无法由史实解释的剧烈变化；
6. **跨项形状复核**：可与前四项相关子项比较量尺形状，只作异常提示，不作能力等值换算或分位数对齐。

任一档在结构上不可达、三轴同时异常集中于低档、或高档尾部只能靠个别偶然样本出现时，档位分布健康门不通过。此时应先修正材料准入、领域聚合或档位映射，再重跑影子结果；不得用强制配额、曲线调分或降低历史高位标准制造健康分布。

## 13. 正式结算门禁

1. 全名册`ruler_id / task_code`唯一且覆盖完整；
2. 所有机械候选均已进入核心链、佐证、例外、排除或有界补证状态；

6. `UNRESOLVED_EVIDENCE_GAP`与未观察候选没有被写成零分；
7. 以已验收事实链为基座的确定性合并、组合—档位偏序、双跑哈希、JSON/Markdown导出和全榜异常审查全部通过；
