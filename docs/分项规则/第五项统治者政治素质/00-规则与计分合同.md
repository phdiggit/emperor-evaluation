# 第五项统治者政治素质规则与计分合同

## 1. 评价对象与结构

第五项评价统治者本人跨情境、可重复的政治行为与稳定素质，不评价国家和社会已经取得的业务成果，满分120分：

| 分项 | 名称 | 分值 |
|---|---|---:|
| A | 履职与认知稳定性 | 35 |
| B | 人事与权力管理 | 50 |
| C | 政治克制与品格 | 35 |
| **合计** |  | **120** |

第五项面向全部评价对象，不因是否为奠基人而改变准入。创业者在第一项已经取得的团队成果不妨碍其参加第五项，但同一团队成果不得再次换分。

## 2. 最小充分统治行为包

每名统治者只建立一份`ruler_behavior_pack`，三轴合计最多消费七条不重叠核心行为链。行为链必须闭合：

`情境与压力 → 本人可选空间 → 本人行为 → 直接反馈 → 是否维持、修正或复发`

候选按公共责任、持续性、可归责性和对本人稳定模式的代表性选择，不按正负方向和最终分数挑样本。每轴必须完成正负双向检索；没有发现门槛事实不等于史实确认不存在。

默认史料预算为本人本纪、实录或同等连续主干，加不超过两组可能改变档位的专题史源。前三项已有材料和公共登记优先复用；已有证据足以稳定档位时停止扩展，不建立完整皇帝事件全集、臣子全集或人才知识图谱。

## 3. 与其他项目的边界

- 制度、行政、民生、军事、文明成果归前四项；第五项只消费本人行为方式。
- 第一项B消费创业团队独立成果和组织化结果；第五项B只消费本人识别、配置、授权、纠偏、容人及权力关系管理行为。
- 第二项B1消费官僚体系整体质量，第二项B2消费日常反馈纠错机制，第二项D3消费交班结构；第五项不得用这些结果反推本人素质分。
- 第六项消费少数重大节点决策；第五项A只看多个普通或持续治理情境中的认知和履职模式。
- 同一社会损害和跨期负债的规模归结果项或第七项；第五项C只评价本人行为的守信、克制和程序性质。

## 4. 三个分项

### 4.1 A履职与认知稳定性

评价持续治理投入、基本工作纪律、自我约束、政策理解、学习能力以及面对反证时是否更新判断。

奏章、诏令、批阅时长、政策数量和作息强度不能直接换分。单次纳谏、一次认错或一次危机止损只能成为弱证；高档必须存在多个独立情境或跨阶段持续表现。沉迷、长期失能、拒绝基本履职、反复无视已知事实和同类错误复发进入负向。

### 4.2 B人事与权力管理

评价本人可归责的识别、岗位匹配、授权边界、监督撤换、容人保护、抵制徇私，以及对外戚、宦官、宗室、权臣和军头的配置、制衡与处置。

受任者成果只用于验证岗位和授权是否有效，不按制度、治理、军事或文明成果量级加分。不得用名臣数量、人才等级总和、团队规模或完整臣子档案换分。详细材料路由见[B人事与权力管理中的用人与授权材料合同](B用人与授权.md)。

### 4.3 C政治克制与品格

评价本人在使用最高权力时对功臣、异见者、百姓和政治对手是否守信、克制并遵守基本程序底线。

正向必须是在存在现实诱因或权力优势时仍表现出克制、守信、有限惩罚或程序约束；普通未作恶不自动加分。构陷、滥杀、毁约、株连、任意剥夺和对无辜者的系统性伤害进入负向，但其社会损害规模和跨期负债不在本项重复扣除。

## 5. 档位与计分

三轴统一采用0—5档和LOW/MID/HIGH：

| 档位 | 共同含义 |
|---:|---|
| G0 | 反向行为构成稳定主模式，或关键基本能力严重缺失。 |
| G1 | 偶有正向行为，但不稳定、强依赖个案或被主要反证压倒。 |
| G2 | 具备有限可重复能力，同时存在明显短板、阶段断裂或重大反证。 |
| G3 | 主要阶段表现稳定，正向模式成立，负向不占主导。 |
| G4 | 跨阶段、跨压力情境持续表现优秀，并能处理重要反证。 |
| G5 | 达到历史高位，在强压力和多类情境下仍稳定，且没有主导性结构短板。 |

| 档位 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| G0 | 0% | 5% | 10% |
| G1 | 15% | 20% | 25% |
| G2 | 30% | 37% | 44% |
| G3 | 50% | 57% | 64% |
| G4 | 70% | 77% | 84% |
| G5 | 90% | 95% | 100% |

`分项得分 = 分项权重 × 得分率`，保留一位小数。材料只够证明单次行为时原则上不得超过G2；只有一个情境且缺少负向复核时不得超过G1。证据不足输出`UNRESOLVED_EVIDENCE_GAP`，不得以零分替代。

## 6. 工作量门禁

- 三轴合计最多七条核心行为链；同一因果链只消费一次。
- A、C各原则上最多两个正向和两个负向候选进入最终裁决；B最多四条核心行为链。
- 同一人物、同一权力关系或同一处置的连续材料先聚合，再判断持续、修正与复发。
- 达到最低充分证据且新增材料不可能改变档位时停止，不因史料丰富继续扩展。

正式120分结算必须在全名册使用同一行为预算、同一正负检索门禁并完成跨时代锚点校准后开启。
