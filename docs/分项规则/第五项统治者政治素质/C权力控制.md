# 第五项C 权力控制计分规则

本文规定第五项C“权力控制”的材料计分公式、材料信号映射、因子档位和 rule 边界。四个 `rule_code` 固定为：

```text
central_military_power_control
regional_clan_power_control
inner_favorite_power_control
institutional_constraint_correction
```

本项评价皇帝对关键权力结构的控制、分配、约束、监督和纠偏能力。核心不是“权力越集中越好”，而是权力是否处在可治理、可约束、可纠错的范围内；既包括防止权臣、军头、地方、宗亲、外戚、近幸和宦官坐大，也包括建立或维护制度性监督与纠偏通道。

## 机器消费摘要

抓包端只需要识别候选事实，不直接判定因子档位或正式入分。推荐把候选事实抽成以下稳定字段：

```json
{
  "power_control_profile": {
    "power_holder": "权力承载对象",
    "power_base": "central | military | regional | clan | inner_favorite | institution",
    "power_channel": "权力来源或运行通道",
    "control_action": "控制、分配、约束、监督或纠偏动作",
    "control_result": "结果、反馈或失控后果",
    "risk_type": "checked | balanced | constrained | corrected | overconcentrated | usurped | militarized | fragmented | informalized | supervision_failed",
    "same_event_chain": true
  }
}
```

候选路由先按“权力风险来源”分流：

| `rule_code` | 快速路由口径 |
| --- | --- |
| `central_military_power_control` | 中枢最高决策链、相权、辅政、权臣、军权、禁军、将帅、边军等核心军政权力。 |
| `regional_clan_power_control` | 地方、封国、藩镇、宗室、外戚、边疆地方势力等外围或半独立权力集团。 |
| `inner_favorite_power_control` | 宦官、近幸、宠臣、后妃、内侍、私人亲信等宫廷或身边非正式权力通道。 |
| `institutional_constraint_correction` | 监察、谏议、法司、审计、考课、复核、申诉、问责、程序制衡等制度化监督纠偏机制。 |

factorization prompt 只注入当前 rule 的因子表和短边界：

- 三个对象域 rule 共用 `power_scale_factor`、`control_outcome_factor`、`risk_context_factor` 和证据修正因子。
- `institutional_constraint_correction` 单独使用 `mechanism_strength_factor`、`correction_effect_factor`、`institutional_scope_factor` 和证据修正因子。
- 不向 prompt 注入跨项或跨 rule 的排他性标签；每个 rule 只按自身适用说明判断。
- 同一材料满足多个 rule 时分别保留候选并窄验；不得因另一个权力风险来源也成立而排除当前 rule。

## 一、材料信号尺度

单条材料先计算 `raw_material_score`，再进入材料层封顶：

```text
material_score = clamp(raw_material_score, -4.0, +4.0)
```

单条材料有效区间为 `[-4.0, +4.0]`。

材料强度解释：

| abs(material_score) | 解释 |
| ---: | --- |
| `0.3 - 0.8` | 弱证、边界证、辅助性材料。 |
| `0.8 - 1.6` | 常规有效材料。 |
| `1.6 - 2.8` | 强材料。 |
| `2.8 - 4.0` | 极强材料。 |

负向材料的高档位权重高于正向材料；严重权力失控、制度性监督失灵、军政集团坐大或非正式权力通道失控，通常比单次成功收权或个案纠偏破坏性更大。

同一 `claim_id + object_id + side` 下拆出的多个 role binding，默认只保留一条最能代表本 rule 的 `score` 材料；其余材料若有上下文价值，记为 `supporting_only`。

## 二、证据修正因子

三项证据修正因子适用于所有材料公式：

```text
evidence_factor =
  attribution_factor
  * source_factor
  * context_factor
```

计算时对合乘结果封顶：

```text
evidence_factor = clamp(evidence_factor, 0.45, 1.25)
```

### `attribution_factor`

| 值 | 口径 |
| ---: | --- |
| `0.8` | 间接归因；通过臣僚执行、既有制度惯性或后见整理才能归因于皇帝。 |
| `1.0` | 皇帝决策链清楚；材料可见皇帝调整、任免、收权、授权、制衡、监督或纠偏动作。 |
| `1.1` | 皇帝亲自判断清楚，且存在逆阻力、危局、既得利益阻碍或关键权力取舍压力。 |

### `source_factor`

| 值 | 口径 |
| ---: | --- |
| `0.75` | 史源链较弱、事实链压缩、片段性强，或需要较多旁证才能支撑。 |
| `1.0` | 标准史源，事实链清楚。 |
| `1.1` | 标准史源且关键事实链完整、对象、权力来源、动作和后果均明确。 |

### `context_factor`

| 值 | 口径 |
| ---: | --- |
| `0.7` | 已满足本 rule 的适用条件，但事实链较弱或上下文不完整。 |
| `1.0` | 本 rule 语境成立，事实和对象关系清楚。 |
| `1.1` | 本 rule 语境强，材料直接展示权力控制、约束、监督或纠偏机制。 |

## 三、对象域 rule 通用公式

以下三个 rule 使用同一材料公式：

```text
central_military_power_control
regional_clan_power_control
inner_favorite_power_control
```

```text
raw_material_score =
  direction_sign
  * power_scale_factor
  * control_outcome_factor
  * risk_context_factor
  * evidence_factor
```

`direction_sign`：正向材料为 `+1`，负向材料为 `-1`。

### `power_scale_factor`

| 值 | 口径 |
| ---: | --- |
| `0.7` | 局部、临时、低层级权力安排，影响范围有限。 |
| `1.0` | 真实权力安排，涉及明确职权、兵权、地方权、亲近圈层权力或行政资源。 |
| `1.25` | 中枢、军政、地方、宗亲外戚或宫廷通道中的关键权力位置。 |
| `1.45` | 国家级、长期性、结构性或足以影响政权稳定的关键权力结构。 |

### `control_outcome_factor`

正向材料：

| 值 | 口径 |
| ---: | --- |
| `0.6` | 有收束、限制、安排或制衡动作，但效果弱、短期或缺少结果反馈。 |
| `1.0` | 权力配置、制衡、收束或处置有效，相关权力风险得到控制。 |
| `1.25` | 在高风险对象或高压力场景下完成有效控制、分权、收束或稳定交接。 |
| `1.45` | 对关键权力结构形成长期、稳定、可复用的控制效果，明显避免权力坐大或失控。 |

负向材料：

| 值 | 口径 |
| ---: | --- |
| `0.8` | 控制不足、约束偏弱或权力安排有隐患，但损害有限。 |
| `1.2` | 权力坐大、干政、擅权、军权失衡、地方失控或非正式通道污染政务，造成明确损害。 |
| `1.6` | 关键权力集团长期失控，造成重大军政失败、政局震荡、人才结构损害或治理秩序受损。 |
| `2.1` | 权力失控达到结构性、连续性或政权安全级别，造成大规模内乱、割据、夺权、清洗、制度瘫痪或继承危机。 |

### `risk_context_factor`

| 值 | 口径 |
| ---: | --- |
| `0.85` | 常规低压场景，权力风险较低。 |
| `1.0` | 常规政治压力或一般风险场景。 |
| `1.15` | 战争、继承、开国、改制、权臣坐大、军头坐大、地方割据、宗亲外戚干政等高风险场景。 |
| `1.3` | 政权转折、内战边缘、重大叛乱、皇位继承危局、军政核心失衡等极高风险场景。 |

## 四、`central_military_power_control` 中枢与军权控制

适用：中枢最高决策、相权、辅政、权臣、机要决策链、禁军、兵权、将帅、边军和重大军政权力是否处在可控范围内。

计分承载对象：权臣、宰辅、辅政者、将帅、禁军系统、军政机构、兵权安排或相关权力集团。

正向材料包括：

- 分散、制衡、收束相权、辅政权、权臣权力或机要决策链。
- 合理配置军权、将帅、禁军、边军和战时授权，并能在战后或危机后收束。
- 防止权臣、军头、辅政集团、禁军或边将坐大。
- 在危局中既能使用关键人物和军政权力，又能保持最终控制。

负向材料包括：

- 相权、辅政、权臣、军头、禁军或边将坐大并实质干政、擅权或威胁皇权。
- 兵权配置失衡、将帅尾大不掉、禁军失控、军政集团夺权或胁迫中枢。
- 中枢决策链被权臣、军头或辅政集团长期把持。
- 因猜忌、过度收权或反复撤权导致军政权力无法正常运行，造成明确治理损害。

边界：

- 若材料核心是任用某人是否合适，归 `appointment_delegation`；只有材料重心是权力结构是否可控时，归本 rule。
- 若材料核心是地方割据、封国或藩镇坐大，归 `regional_clan_power_control`。
- 若材料核心是宦官、近幸、后妃、宠臣等宫廷非正式权力通道，归 `inner_favorite_power_control`。
- 若材料核心是监察、复核、谏议、法司、审计或问责机制，归 `institutional_constraint_correction`。

## 五、`regional_clan_power_control` 地方、封国、宗室外戚控制

适用：地方长官、诸侯王、藩王、藩镇、边疆地方势力、宗室、外戚等外围权力集团是否处在可控范围内。

计分承载对象：地方权力集团、封国、藩镇、宗室、外戚、边疆军政集团、地方长官或相关制度安排。

正向材料包括：

- 削藩、抑制藩镇、限制地方军政财权坐大，或防止地方割据。
- 合理处理宗室、封国、诸侯王、藩王或外戚的权力边界。
- 调整地方军政财政权力结构，使地方权力可监督、可调动、可收束。
- 在保持地方治理能力的同时避免地方或宗亲外戚形成独立权力中心。

负向材料包括：

- 地方、封国、藩镇、边疆军政集团坐大，形成割据、叛乱、尾大不掉或中央无法有效控制。
- 宗室、诸侯、藩王、外戚干政、夺权、威胁继承或污染国家权力结构。
- 对地方或宗亲外戚权力处置失当，造成大规模内乱、继承危机、行政崩坏或长期制度风险。
- 因过度猜忌、粗暴收权或处置失衡，直接激化地方、宗亲或外戚权力危机。

边界：

- 外戚、宗室若主要以亲近身份干政但未形成外围权力集团，归 `inner_favorite_power_control`。
- 地方将领若主要风险是兵权配置和军头坐大，归 `central_military_power_control`；若主要风险是地方割据或藩镇化，归本 rule。
- 单个地方官任用是否得当，归 `appointment_delegation`；地方权力结构是否失控，归本 rule。

## 六、`inner_favorite_power_control` 近幸、宦官、宫廷圈层控制

适用：宦官、近幸、宠臣、后妃、内侍、乳母、女宠、私人亲信等宫廷或身边非正式权力通道是否干政、乱政或污染正式权力。

计分承载对象：宦官、近幸、宠臣、后妃、内侍、私人亲信、宫廷圈层或其非正式权力通道。

正向材料包括：

- 限制宦官、近幸、宠臣、后妃、内侍等非正式通道干政。
- 防止私宠、内廷、宫廷圈层绕过正式官僚、军政或法司系统。
- 及时纠正近幸、宦官、后妃、宠臣擅权、传旨、卖官、干预司法或干预任用。
- 保持内廷服务、机要传达和正式政务权力之间的边界。

负向材料包括：

- 宦官、近幸、宠臣、后妃、内侍等长期干政、卖官、乱政、干预任用或司法。
- 皇帝放任私人亲信、宫廷圈层或非正式通道越过制度程序行使实际权力。
- 近幸、宦官或后妃权力造成重大政治迫害、任用污染、军政失误、继承危机或制度失灵。
- 皇帝以私宠、私怒、私信替代正式权力程序，并造成明确治理损害。

边界：

- 若宦官或近幸已成为中枢制度性权臣，材料重心仍按风险来源判断：强调非正式宫廷通道，归本 rule；强调中枢权力结构失衡，归 `central_military_power_control`。
- 单纯宠爱、赏赐、生活奢侈，不构成权力控制材料；只有进入政务、军务、司法、任用、财政或继承权力链条时才计分。
- 亲族外戚形成外围集团或继承威胁，归 `regional_clan_power_control`。

## 七、`institutional_constraint_correction` 制度性约束、监督与纠偏

适用：监察、谏议、法司、审计、考课、复核、申诉、问责、程序制衡等制度机制是否能够发现、约束和纠正权力滥用。

计分承载对象：制度机制、监督渠道、纠偏程序、监察法司系统、谏议系统、考课审计系统、申诉复核机制或具体制度安排。

```text
raw_material_score =
  direction_sign
  * mechanism_strength_factor
  * correction_effect_factor
  * institutional_scope_factor
  * evidence_factor
```

`direction_sign`：正向材料为 `+1`，负向材料为 `-1`。

### `mechanism_strength_factor`

| 值 | 口径 |
| ---: | --- |
| `0.7` | 临时、个案、低稳定性的监督或纠偏安排。 |
| `1.0` | 有明确制度、官署、程序或稳定渠道。 |
| `1.25` | 多机构、多程序或跨层级监督制衡机制成立。 |
| `1.45` | 长期、结构性、可复用的制度约束和纠偏体系。 |

### `correction_effect_factor`

正向材料：

| 值 | 口径 |
| ---: | --- |
| `0.6` | 制度安排存在，但效果弱、执行不明或只见名义设置。 |
| `1.0` | 监督、复核、问责或纠偏有效，能处理具体权力滥用。 |
| `1.25` | 机制能持续发现并纠正滥权、冤案、欺罔、腐败、擅权或任用污染。 |
| `1.45` | 机制形成稳定反馈闭环，显著降低系统性滥权、偏听、私怒或制度失灵风险。 |

负向材料：

| 值 | 口径 |
| ---: | --- |
| `0.8` | 监督纠偏渠道存在但弱化、虚置或偶发失灵。 |
| `1.25` | 皇帝压制、绕过或破坏监督纠偏机制，导致明确权力滥用或冤错。 |
| `1.7` | 监察、谏议、法司、复核或问责系统长期失灵，造成重大治理损害。 |
| `2.2` | 制度性纠偏被系统性摧毁，形成恐惧、欺罔、滥权、冤案、腐败或政治清洗的连续性结构。 |

### `institutional_scope_factor`

| 值 | 口径 |
| ---: | --- |
| `0.8` | 个案纠偏或单一部门内部监督。 |
| `1.0` | 覆盖一个重要政务领域、司法领域、监察领域或任用领域。 |
| `1.2` | 覆盖中枢、地方、军政、司法、监察、财政或任用等多领域制度链。 |
| `1.35` | 国家级制度安排，长期影响权力运行、监督反馈和纠偏能力。 |

边界：

- 只处置一个权臣、军头、地方官、外戚或宦官，不自动构成本 rule；必须体现制度性监督、复核、问责、申诉、监察、法司或程序制衡。
- 皇帝单次纳谏、听取建议，若重心是认知与纠错态度，归 I5E；若形成制度化监督或程序性纠偏，归本 rule。
- 个案冤案平反若只体现政治品格或仁恕，归 I5D；若体现复核制度、司法纠偏或监督机制，归本 rule。

## 八、rule 聚合

每个 rule 分别聚合正向信号和负向信号，保留原始信号，不在本层做最终分数映射。

同一对象、同一权力通道或同一制度机制在同一 side 下多条材料采用衰减聚合：

```text
object_side_score =
  strongest_material
  + 0.35 * sum(other_materials)

object_side_score = clamp(
  object_side_score,
  -1.5 * abs(strongest_material),
  +1.5 * abs(strongest_material)
)
```

rule 内正向和负向分开聚合：

```text
positive_signal = sqrt(sum(positive_object_side_score^2))
negative_signal = sqrt(sum(abs(negative_object_side_score)^2))
```

`positive_signal` 与 `negative_signal` 均作为原始信号输出。最终第五项C分数应在一批目标完成后，再按动态区间映射和总分权重公式处理。

## 九、跨项复用边界

本章只用于人工审核和跨项候选复用，不得作为 candidate 或 factorization prompt 的排他性门禁。每个 rule 按自身适用说明独立判断；满足当前 rule 的材料必须保留和计分，可同时复用为其他 rule 或 item 的候选。

- 与 I5B：I5B 评价任人、授权、团队、容才和反亲私；I5C 评价权力结构是否可控、可约束、可纠偏。同一事实满足两边 rule 时可同时进入并分别窄验，不以跨项重叠为由预先排除。
- 与 I5D：I5D 评价政治品格、待功臣、猜忌滥杀、仁暴取向等价值面；I5C 只在这些行为影响权力结构控制、制度监督或纠偏机制时入分。
- 与 I5E：I5E 评价认知、纳谏、学习、纠错能力；I5C 只评价制度化监督、复核、问责和权力纠偏机制。
- 与 I6：I6 评价关键决策质量；I5C 评价决策背后的权力控制结构。单次迁都、战争、改革是否正确，归 I6；其是否重塑或破坏权力控制结构，归 I5C。
- 与 I3：I3 评价军事边疆结果；I5C 只评价军权、边将、边疆军政集团或地方军政权力是否可控。
- 与 I7：I7 评价历史负债、制度遗留和长期代价；I5C 只评价权力控制机制本身及其直接失控后果。

同一材料只按最主要风险来源进入一个 I5C rule；不得因为同一人物兼具权臣、将帅、外戚、宗室、地方势力等多重身份而在多个 I5C rule 重复入分。
