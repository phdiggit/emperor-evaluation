# 第四项文明与国家整合收益规则与计分合同

## 1. 评价对象与结构

第四项评价统治窗口内国家共同体整合、教育与人才流动、知识生产和文化生态的显著可归责净变化。它是有符号文明附加项，不进入共同正收益分母；明确进步加分、明确倒退减分，固定扫描空集为0：

| 分项 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

正负两端的总区分跨度为135分，与原第四项权重相同；不得把范围扩成`-135—+135`而使实际区分力度翻倍。第四项与第一项的差别在于：第一项只对满足奠基准入者形成正向条件附加，第四项对全体使用同一固定触发池，既可正向也可负向，未触发者为0。

长期影响不再单列D项。后世延续只能验证A、B、C既有结果的耐久性和档内位置，不得把同一成果再加一次“文明遗产分”。

## 2. 与第一至第三项的边界

- 军事占领、实际控制、安全边界和控制规模归第三项；第四项A只看群体参与、共同体认同、相互接纳和社会整合。
- 设官置县、法律行政适用、财政穿透和国家机器运行归第二项；这些事实只有形成独立社会整合后果时才能作为A的辅助证据。
- 选官制度的创设、修订和国家机器运行归第二项A，当期官僚质量归第二项B1；第四项B只看教育供给、知识传递、受教育机会和跨身份流动。
- 日常政治信息通道和纳谏机制归第二项B2；第四项C看整体知识生产、学术空间和文化公共品，不以一次纳谏或单个人才处置代替文化生态。
- 同一成果规模、持续期和历史影响只能在一个主项目计分。第四项可以引用前三项事实复验因果，不复制前三项分值。

## 3. 固定材料池与最小充分结算单位

第四项不为每名皇帝重建一套完整文明史。正式结算使用两层单位：

1. `dynasty_curve_segment`：按政权和连续历史阶段建立A、B、C三条共享曲线，记录阶段起点、继承基线、方向、水平、转折、主要正负因素、史源覆盖和交班锚；
2. `ruler_window_adjudication`：把皇帝实际掌权窗口投影到曲线，只登记本人造成、授权、持续维持或明确放任的显著推动、破坏和偏离。

候选材料只从第5节固定指标族触发。每个政权或连续阶段先完成一次共享扫描，按稳定`task_code`冻结曲线候选，再投影人物；不得先按人物名望分别搜索“文化贡献”或“历史评价”。人物定向补证只能闭合已触发转折的本人责任、实际结果、反证或持续性，不得借补证插入新的无触发器成果。每条冻结候选最多执行一轮定向补证；一轮可以核对多个权威来源，但必须共享同一闭合问题和预先登记的检索边界。

共享扫描对同一政权内所有统治者使用相同的指标族、史源门槛和补证预算。早期史料稀疏、短在位者和非名人不得适用更低证明标准，名人也不得获得更宽检索范围。

共享曲线只是同一时代的结果基线，不自动把前任功劳归给后任。前任交班与后任接班的相邻窗口原则上不得无材料跳档；需要跳档时必须存在可定位的重大转折和本人归责。

曲线按实际主政而非名义在位投影。摄政、亲政、复位和非连续主政窗口分别登记；间隔期成果不得吞入本人窗口。相邻窗口的前任交班锚和后任接班锚必须一致。

每名皇帝每轴最多消费两个个人增量，三轴合计最多六个，正负方向共同占用预算。超过预算的同方向材料只补充持续性和来源，不继续累加；只有可能改变档位、方向或去重判断时才重新进入裁决。

材料不得直接按篇数或事件条数换分。进入人物裁决前，必须先归并为`civilization_increment_package`：同一行动—机制—结果链的不同记载只增强事实置信度；同一机制在不同地域、群体、时间或制度场景中独立实现，才可增强结果覆盖、耐久性或档内位置。规模、强度或社会后果一眼可见不同的事项不得因题材相同而赋予同级权重，正向与负向均适用。

## 4. 时代校准与归责坐标

第四项同时受人口规模、书写与传播技术、城市化、财政能力、政权形态和史料保存影响。不得比较学校、著作、士人或典籍的裸数量，也不得设置统一“古代折扣”、朝代配额或目标排名。

每条共享曲线必须先固定五个坐标：

1. `inherited_baseline`：本人实际主政开始时继承的A、B、C水平与主要负债；
2. `contemporary_feasible_frontier`：同一技术、人口和政权条件下现实可达到的前沿，只用于判断难度与覆盖，不直接送分；
3. `exposure_and_pressure`：当期实际面对的群体整合、教育扩张、知识生态破坏或维护压力；
4. `background_trend`：人口增长、纸张印刷扩散、城市化、前代积累等非本人自然趋势；
5. `attributable_change`：剥离自然趋势和他人独立行动后，本人造成、授权、受压维持或明确放任的净变化。

归责以`attributable_change`为主。档位首先取决于相对继承基线、且在当时可行条件下由本人造成的文明进步或倒退幅度；绝对覆盖、相关人口占比、持续性和公共可及性决定档内位置及高档上限。所有覆盖指标都必须按当时技术和社会条件解释，不用后世绝对规模压低早期成果。技术扩散和人口增长形成的自然红利只进入共享基线；本人是否把可用条件转成更广覆盖，才进入个人裁决。

高位守成只有同时存在可识别的现实退化压力、本人维持行动和交班结果时，才可作为正向增量。没有压力和本人行动的自然延续只记`BASELINE_CONTINUATION_ONLY`，不得冒充高档守成奖励。固定指标族完成正反入口扫描后，若没有发现达到门槛的本人转折，记`NO_ELIGIBLE_CIVILIZATION_INCREMENT`；它不等于史实上证明“毫无作为”，只表示本附加项未触发，该轴调整为0。`BASELINE_CONTINUATION_ONLY`同样调整为0。两者不得按负向裁决，也不得用其余已触发轴、时代均值或人物名望填充。

长期耐久统一观察本人窗口结束后30年，并额外核对两个直接后继交接锚；超过30年只有现有canonical证据已证明同一机制连续传导时才可延伸，不为延长影响开展开放宽搜。后继者独立决策形成的新结果必须切断。

## 5. 三轴固定指标族

### 5.1 A国家共同体与社会整合

评价不同区域、族群、身份和文化群体是否形成可持续的共同体参与、认同和相互接纳。

计入群体进入公共政治与社会秩序、跨群体合作、法律与身份地位趋于稳定、冲突和排斥下降，以及强制同化、身份压迫、系统性隔离造成的反向结果。国号、疆域、设治、迁徙或服饰命令本身不自动定向，必须看实际社会后果。

A轴只从以下指标族触发：群体公共参与、跨群体合作与通婚交往、身份和法律地位的社会后果、区域与群体冲突变化、排斥隔离及强制同化的实际后果。现代民族国家观念、后世国族叙事和疆域大小不得反向代替当时结果。

### 5.2 B教育可及与人才流动

评价学校和教育供给、知识传播、学习机会、跨地域跨身份流动及其对文明再生产的实际影响。

科举、察举、学校和教材等制度名称只作入口；必须至少闭合一次招生、培养、传播、流动或社会开放结果。当期官员办事能力、名臣数量和官职规模不得在本项换分。

B轴只从以下指标族触发：教育供给覆盖、学习与传播成本、地域或身份准入、实际培养结果、跨地域跨身份流动，以及教育机会的收缩和排除。B评价知识如何到达人、人才如何流动，不评价知识本身产出了多少。

B轴覆盖必须同时报告两个分母：一是相对当时教育供给与人才流动领域的实际覆盖，二是原先受地域、身份、族群、性别或经济门槛排除者中新增可及群体的扩张。早期条件下数百人的稳定新增供给可能构成显著进步；后期仅有更大的裸人数而未扩大相对覆盖或准入，不自动获得更高档位。只有制度名称、名义开放或招生计划而没有实际招生、培养、传播或流动结果时，不得进入高档。

### 5.3 C知识生产与文化生态

评价学术空间、知识生产、典籍整理传播、专业知识、文化公共品和思想文化生态的净变化。

皇帝个人文艺爱好、宫廷收藏和一次性文化活动只有形成公共产出或生态变化时才计入。思想宽松与控制均按知识生产、传播成本、人才安全和长期生态的实际结果判断。

C轴只从以下指标族触发：新知识与学术产出、典籍整理保存及公共传播、专业知识发展、公共文化品、学术安全与思想生态，以及禁毁、压制和人才损失。C评价生产和生态；同一传播事实已经在B消费可及性时，C只能消费独立的知识产出或生态变化。

C轴的典籍与知识工程按“生产—保存—可访问—扩散或采用”链条裁决。编纂规模和保存价值可以构成独立正收益，但若成果长期局限于宫禁、极少数近臣或不可稳定使用的孤本，公共可及与同时代扩散不得推定为高位；后世偶然保存也不能倒推当期已经形成广泛公共品。禁毁、系统压制、人才安全恶化等硬负向后果必须作为上限门禁单列，不得被若干低强度正向事项以条数抵消。

典籍编纂与传播必须使用时代相对尺，不得以同一裸发行量跨时代比较：

| 传播条件 | 可计进步的时代相对门槛 | 主要上限 |
|---|---|---|
| 手抄与早期官学时代 | 形成稳定定本、组织抄传、进入官学或跨区域专业采用，已经可能是显著扩张；不能因绝对受众较少而一律降档 | 只有编成、进呈或宫廷自用，没有实际抄传与采用，不得推定公共传播 |
| 雕版初兴时代 | 首次形成可复制的大部头文本、完成区域或跨区域刊刻链、显著降低复制成本，可构成高幅度进步 | 单次刻成但版片、文本和使用链未闭合，不得按后世通行度倒推 |
| 成熟雕版与商业出版时代 | 必须在既有印刷基线上证明新增版本、发行范围、读者群或专业采用；“奉敕编成”本身不足以进入高档 | 宫禁、秘阁或极少数近臣可见的巨型工程，规模可以计生产保存，但传播与公共性受硬上限 |
| 多语、跨区域或跨文明传播 | 完成翻译、术语转换、双语机构、异域文本引入或跨区域知识采用，可按当时转换难度加权 | 只有使者携书、个人接触或未完成译本，不得推定知识已进入使用网络 |

内容方向同样按当时可行边界判断：相对既有知识结构扩大知识类型、跨文化转译、保存濒失文本、降低检索或学习成本，记正向；把单一正统通过禁毁、排除、刑罚背诵或人才迫害替代原有多元空间，记混合或负向。后世看来仍有局限，不抹消其相对过去的真实进步；但时代局限也不得被包装成超出实际可及范围的普遍开放。

## 6. 影响包、相对进步与增强规则

每个`civilization_increment_package`的核心字段为`package_code`、`axis`、`direction`、`episode_refs`、`inherited_baseline`、`attributable_change`、`relative_change_level`、`field_coverage`、`attribution_strength`、`counterevidence`、`hard_negative_gate`、`source_coverage`和`disposition`。其余字段按是否可能改变裁决条件触发，不为填满Schema重建完整社会史：

- 裸规模、技术条件或自然趋势可能误导相对进步判断时，才强制闭合`contemporary_feasible_frontier`和`background_trend`；
- B轴必须闭合`access_expansion`的两个分母；A轴用相关群体覆盖代替，C轴用生产—保存—可访问—扩散或采用链代替；
- 受压守成、拟进入CIV3以上或结果可逆时，才强制闭合`durability_and_handoff`；即时发生且不可逆的硬负向可直接记录不可逆结果；
- 拟进入CIV4或主张同类事实增强时，才强制闭合`cross_scene_replication`；否则不得为了证明“没有跨场景”继续开放检索。

`relative_change_level`只表达相对继承基线的本人可归责变化，不把材料数量当变化幅度：

| 层级 | 含义 |
|---:|---|
| R0 | 未闭合本人可归责变化，只能作背景、线索或置信度支持。 |
| R1 | 局部、短期或低强度变化，实际结果可见但范围有限。 |
| R2 | 形成清晰、可验证的扩张、修复或收缩，改变了部分主要场景。 |
| R3 | 相对继承基线发生重大跃迁或倒退，改变主要领域并完成结果闭环。 |
| R4 | 形成新范式或系统性破坏，跨场景实现并产生稳定交班或长期断裂。 |

档位主要由正负影响包的`relative_change_level`、净方向和硬负向门禁决定；LOW/MID/HIGH主要由当时条件下的领域覆盖、新增可及群体、持续期、交班、跨场景复验和反证决定。处于同时代前沿只能说明实现难度，不能替代实际结果；实际结果广但主要来自背景趋势，也不能替代本人归责。

同类事实按以下规则消费：

- 同一事件、同一对象和同一结果链的异文、转述或多源记载只增强`source_coverage`与置信度，不增强影响层级；
- 同一机制在不同时间、地域、群体或制度场景独立发生，且各自闭合结果时，可增强`field_coverage`、`cross_scene_replication`、耐久性及档内位置；
- 若后续事实只证明前一结果继续存在，归入耐久与交班，不新建第二个增量；
- 若同类事实的覆盖、强制程度、可逆性或社会后果不同，必须分别确定影响层级，不能因标签相同折叠成等权材料；
- 正负材料先各自形成影响包，再做净裁决；硬负向先执行上限门禁，不允许按“正一条、负一条”机械相抵。

## 7. 档位与计分

三轴统一采用`CIV0—CIV4`影响幅度和LOW/MID/HIGH档内位置。方向与幅度分开记录：正向取正号，负向取负号；`CIV0`只表示同轴内已观察正负结果大致抵消，不等于没有材料。

| 幅度 | 共同含义 | LOW | MID | HIGH |
|---:|---|---:|---:|---:|
| CIV0 | 已观察结果净抵消 | 0 | 0 | 0 |
| CIV1 | 局部、短期或低强度可归责变化 | 3.0 | 4.5 | 6.0 |
| CIV2 | 清晰且可验证的有限扩张、修复、收缩或破坏 | 7.5 | 9.5 | 11.5 |
| CIV3 | 改变主要领域并形成稳定结果的重大跃迁或倒退 | 13.5 | 16.0 | 18.0 |
| CIV4 | 跨场景新范式或系统性破坏，并形成稳定交班或长期断裂 | 19.0 | 21.0 | 22.5 |

表内为绝对值。单轴调整为`方向符号 × 档位点值`，三轴相加形成`CIV4`总调整，范围`-67.5—+67.5`，最终保留一位小数。

同轴最多两个影响包。先把每个包的R1—R4映射为1—4：正负方向分别以最强包确定主体，同方向第二个独立包最多增加0.5，只能增强覆盖或档内位置，不能把两个R2升级成CIV3。正负并存时分别形成有界强度`P`、`N`，取净值`V=P-N`；`V=0`记CIV0，否则方向取其符号，幅度取`min(4, max(1, floor(abs(V))))`。混合包内部若正负两侧都达到独立显著程度，必须分别登记`positive_component_level`与`negative_component_level`，不得只用一个“正向主导”或“负向主导”标签吞掉另一侧。

LOW/MID/HIGH主要由同时代条件下的实际覆盖、新增可及群体、持续性、交班、跨场景复验和同级独立增强确定。R3以上必须闭合持续性；CIV4-HIGH必须闭合跨场景和广泛覆盖。硬负向仍执行正向上限门禁，若低强度正向事项无法改变硬负向幅度，不得按条数抵消。

固定扫描无合格影响包时输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT`并调整0；这只是附加项空集，不证明完整历史能力为零。存在合格包但净抵消时输出`OBSERVED_OFFSETTING_OR_BALANCED_EFFECTS`并调整0。已触发事项若方向、结果或本人归责无法闭合，则输出`UNRESOLVED_EVIDENCE_GAP`并阻断第四项调整与综合分，不能用0替代未知。

每份结果必须同时发布`triggered_axis_count`、逐轴方向、幅度、档内位置、`disposition`和`source_coverage`。不得把单个已触发轴放大到总范围，不得按朝代、名望或其他人物均值插补。

## 8. 史料覆盖与审计字段

史料保存度与业务档位分开记录。每条曲线和人物裁决必须给出`source_coverage`：

- `ADEQUATE`：正向、负向和交班锚足以稳定方向与档位；
- `PARTIAL_BUT_SUFFICIENT`：材料不完整，但最小充分命题、反证和归责已闭合；
- `INSUFFICIENT`：无法区分无变化、未记载和史料散佚，输出`UNRESOLVED_EVIDENCE_GAP`。

不得以现存文献篇数、著作数量或研究热度作为得分变量。早期材料达到最小充分闭合后，不因材料少自动降档；后期材料丰富也不因材料多自动升档。

`dynasty_curve_segment`至少记录`task_code`、`polity_phase`、`axis`、`start_anchor`、`end_anchor`、`inherited_baseline`、`contemporary_feasible_frontier`、`exposure_and_pressure`、`background_trend`、`trigger_family`、`direction`、`durability_window`和`source_coverage`。

`ruler_window_adjudication`至少记录`actual_rule_window`、`curve_refs`、`increment_package_refs`、`personal_action`、`responsibility`、`attributable_change`、`baseline_continuation`、`positive_counterevidence`、`negative_counterevidence`、`cross_item_exclusions`、`search_boundary`、`handoff_anchor`和`disposition`。

## 9. 覆盖、校准与停止规则

- 每个政权优先完成三条共享曲线，再结算人物；不得逐人重复检索相同朝代背景。
- 每轴至少核对一个正向入口和一个负向入口；没有达到门槛的事实可以不计分，但必须记录检索边界并输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT`，不得升级为无限补证任务。
- 已有曲线、本人增量、反证和相邻交班锚足以稳定档位时停止扩展。
- 普通史料增加不能继续堆分；只有可能改变当前档位或归责的材料才补检索。
- 全名册校准必须按时代、史料覆盖度、在位长短和政权形态检查空集率、证据缺口率和档位分布；时代差异只触发语义复核，不自动调整分数。
- 若高档主要由技术年代或现存材料数量解释，或早期人物系统性集中于证据缺口，正式结算继续关闭，先修共享曲线与史源覆盖，不得追加时代系数修饰结果。

本合同确定当前业务结构、证据所得分汇总方式和结算门禁。全名册影子校准通过前不得写正式分数；影子校准通过后仍须由canonical人物裁决生成正式分数，临时分析文件不得直接迁移为正式结果。排名和跨项总榜继续服从总规则与跨项接受门禁。
