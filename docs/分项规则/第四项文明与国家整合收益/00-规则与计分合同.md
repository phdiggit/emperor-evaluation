# 第四项文明与国家整合收益规则与计分合同

## 1. 定位与分值

第四项评价统治窗口内**国家共同体整合、教育与人才流动、知识生产与文化生态的显著可归责净变化**。它是有符号附加项，不进入共同正收益分母；明确进步加分，明确倒退减分，无合格增量为0。

| 分项 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

长期影响不单列。后世延续只验证既有结果的耐久性，不重复形成“文明遗产分”。

## 2. 与其他项目的边界

- 军事占领、安全边界和控制规模归第三项；A只看群体参与、认同、接纳及排斥的社会结果。
- 设官置县、法律行政、财政穿透和国家机器归第二项；只有形成独立社会整合结果时才能辅助A。
- 选官制度本体归第二项A，当期官僚质量归第二项B1；B只消费真实教育供给、学习机会和跨地域跨身份流动。
- 日常纳谏、监察、纠错归第二项B2；C看整体知识生产、传播和文化生态。
- 同一成果的规模、持续期和历史影响只能由一个主项目计分。第四项可以引用前三项事实复验因果，不复制分值。

## 3. 结算单位与固定扫描

正式结算使用两层单位：

1. `dynasty_curve_segment`：按政权和连续阶段建立A、B、C共享曲线，记录继承基线、方向、主要转折和交班锚；
2. `ruler_window_adjudication`：把实际主政窗口投影到曲线，只登记本人造成、授权、持续维持或明确放任的显著增量。

候选材料只从第5节固定指标族触发。先做政权共享扫描，再投影人物；不得按人物名望分别搜索“文化贡献”。人物定向补证只用于闭合已触发事项的归责、结果、反证和持续性，每个事项最多一轮。

共享扫描对同一政权使用相同指标族和证明标准。摄政、亲政、复位和非连续主政窗口分别结算；相邻统治者的交班锚必须一致。

每人每轴最多消费两个影响包，三轴合计最多六个。超过预算的同方向材料只增强覆盖、持续性和置信度，不继续累加。

### 3.1 零值反漏检门

任何轴在输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT`前，必须再做一次**固定高信号反漏检**，仅检查下列结构性触发器，不开放人物名望宽搜：

- **A**：大规模群体纳入或排斥、身份地位重构、强迁、强制同化、群体性毁灭或长期隔离；
- **B**：大规模兴废学校、教育网络扩张或撤销、真实改变准入的考试与培养改革、跨身份/族群招生、重要专业教育新入口；
- **C**：文字创制或重大改革、大型翻译/典籍/刊刻工程、被国家采用的重大科学知识产品，以及禁书、毁书、文字狱、系统性学术或宗教迫害。

发现高信号触发器后必须转入一次定向补证，不能继续记“未触发”。全0人物必须记录`zero_scan_checked=true`。

## 4. 时代校准与本人归责

档位只看**相对继承基线的本人可归责变化**，不比较学校、著作、士人、典籍的裸数量，也不设置朝代系数。

每条曲线至少固定：

- `inherited_baseline`：接掌时的A/B/C水平与主要负债；
- `contemporary_feasible_frontier`：当时现实可达到的前沿，只校准难度与覆盖；
- `background_trend`：人口、纸张印刷、城市化、前代积累等自然趋势；
- `attributable_change`：剥离背景趋势和他人独立行动后的本人变化。

技术扩散和人口增长只进入背景基线。早期绝对规模较小，不自动压低档位；后期绝对规模更大，也不自动升档。

高位守成只有存在现实退化压力、本人明确维持行动和稳定交班时才形成正向增量。自然延续为0。

长期耐久统一观察本人窗口结束后30年，并额外核对两个直接后继交接锚；后继者独立决策形成的新结果必须切断。

## 5. 三轴固定指标族

### 5.1 A 国家共同体与社会整合

评价不同区域、族群、身份和文化群体是否形成可持续的共同体参与、认同和相互接纳。

只从以下指标族触发：群体公共参与、跨群体合作与交往、身份和法律地位的社会后果、区域与群体冲突变化、排斥隔离及强制同化的实际后果。

国号、疆域、设治、迁徙或服饰命令本身不自动定向，必须看真实社会后果。现代民族国家观念和后世国族叙事不得反向代替当时结果。

#### A轴覆盖、复杂度与生命周期

- 固定扫描必须同时覆盖内地身份关系、旧政权及区域人口、边疆群体；正负入口采用相同标准。每轴两个包是最终消费预算，不是两个族群或两个候选事项的检索上限。不得先选两个包，再以其内容代表整个人物窗口。
- 相对规模看实际受影响人口占相关群体、区域及当时主要整合领域的比重；无法给出可靠人口比例时，明确已证对象与未知范围，不编造数字。首领或个别任官者的结果不得外推为全体人口结果。
- 群体复杂度看已跨越的地域、语言文化、生活方式、既有组织与身份边界，以及各自的实际参与结果；不按现代民族名单计数，不设置族群系数或难度加分。
- 整合深度区分临时容纳、稳定安置与交往、持续公共参与、身份与相互接纳的结构变化。大规模与高复杂度只有通过已实现的结果才能影响R级；一个主要群体或区域的稳定结构变化可以达到R3，不因只有一个影响包机械封顶R2。R4仍须跨场景复验，不能由多个R2堆成。
- 基线从本人行动之前取，不能从本人强迁、身份降格之后重新起算。完整追踪迁出、迁入、身份处置、再安置及修复；同链救济不自动成为独立正向包。安置方式改变也不自动等于全部接纳成果归零。
- 既有等级、首领统属、军役或不同参与方式不自动构成N1；必须证明相对基线新增、本人可归责且已实现的独立损害。反之，亲政后的明确强化、放任及真实强制损害不得借时代背景豁免。正负两侧均不得把普通限制当作整数层级。
- 交班按同一政权和具体群体结果核验，分清摄政与亲政；并行政权、同一时代的人物不得串为继承链。后继独立新增成果不回填，后继独立破坏也不自动抹去本人已交出的成果。
- 宗室或政治家族的亲属连坐、身份没入、被迫殉死仍属于身份群体结果；必须剥离直接参与夺权者本人、战斗伤亡和已在其他计分轴消费的同一损害。画像轴可提供候选线索，不能直接搬用画像档位。

### 5.2 B 教育可及与人才流动

评价学校和教育供给、知识传递、学习机会、跨地域跨身份流动及其对文明再生产的实际影响。

科举、察举、学校、教材等制度名称只作入口；必须至少闭合一次真实招生、培养、学习、传播、流动或社会开放结果。当期官员办事能力和名臣数量不计。

B轴必须同时看两个尺度：

1. **相对时代基线的结构变化**：早期从“几乎没有稳定国家教育供给”到建立持续运作的中央或地方教育层级，即使绝对人数只有数百或数千，也可能构成R3；
2. **实际覆盖与新增可及群体**：地域、身份、族群和经济门槛决定LOW/MID/HIGH及高档上限。

因此，单一学校或单一教育层级**不得仅凭人数规模**进入R3；但若它相对继承基线建立了此前不存在或极弱的稳定教育结构，并显著改变当时主要教育供给格局，可以进入R3。覆盖仍集中于首都或上层身份时，优先压LOW/MID/HIGH，而不是机械把幅度降到R2。

后期已有成熟教育网络时，仅扩大裸人数而未扩大相对覆盖或准入，不自动升档。

### 5.3 C 知识生产与文化生态

评价学术空间、知识生产、典籍整理传播、专业知识、文化公共品和思想文化生态的净变化。

典籍与知识工程按“生产—保存—可访问—扩散或采用”裁决。宫廷收藏、奉敕编成和皇帝个人爱好只有形成公共产出或生态变化才计分。

文字创制、跨文化翻译、科学知识产品、稳定定本和显著降低传播成本可以形成正向；禁毁、系统压制、人才迫害和表达安全恶化形成负向。成熟出版时代的大型宫廷孤本不得因体量巨大自动升档。

## 6. 影响包与相对变化层级

进入人物裁决前，材料必须归并为`civilization_increment_package`。同一行动—机制—结果链的多条记载只增强置信度；不同地域、群体、时间或制度场景中独立闭合的结果，才增强覆盖和档内位置。

| 层级 | 含义 |
|---:|---|
| R0 | 本人归责或实际结果未闭合，只能作背景线索 |
| R1 | 局部、短期或低强度变化 |
| R2 | 清晰可验证的有限扩张、修复、收缩或破坏 |
| R3 | 改变主要领域并形成稳定结果的重大跃迁或倒退 |
| R4 | 跨场景形成新范式或系统性破坏，并稳定交班或造成长期断裂 |

**R3门槛**：必须改变主要领域，且闭合持续性；不能只凭裸规模、史料条数或名望进入R3。对早期教育等基线极低领域，单一中央或地方教育层级若本身建立了此前不存在的稳定结构，可以构成R3；其覆盖局限主要压档内带位。

**R4门槛**：必须闭合跨场景复验；单个大型项目有多个产出，不等于自动形成跨场景新范式。

## 7. 档位、净算与硬负向

三轴统一使用`CIV0—CIV4`和LOW/MID/HIGH。正式输出只允许这套标签，不再混用旧G档名称。

| 幅度 | 含义 | LOW | MID | HIGH |
|---:|---|---:|---:|---:|
| CIV0 | 已观察结果净抵消 | 0 | 0 | 0 |
| CIV1 | 局部、短期或低强度变化 | 3.0 | 4.5 | 6.0 |
| CIV2 | 清晰有限的扩张、修复、收缩或破坏 | 7.5 | 9.5 | 11.5 |
| CIV3 | 改变主要领域并形成稳定结果 | 13.5 | 16.0 | 18.0 |
| CIV4 | 跨场景新范式或系统性破坏 | 19.0 | 21.0 | 22.5 |

LOW/MID/HIGH由相对覆盖、持续性、交班、跨场景复验和反证决定。HIGH必须同时有较强覆盖与持续性；CIV4-HIGH还必须有明确跨场景复验。史料条数不得决定带位。

### 7.1 普通净算

正负方向分别取最强影响包为主体；同方向第二个**独立**影响包最多增加0.5，且方向强度封顶4：

`P = min(4, strongest_positive + reinforcement)`

`N = min(4, strongest_negative + reinforcement)`

`V = P - N`

- `V=0`：CIV0；
- `V≠0`：方向取符号，幅度取`min(4, max(1, floor(abs(V))))`。

两个R2不能叠成CIV3；第二包主要用于带位和覆盖，不用于机械堆档。

【CIV4保级】R4表示已经跨场景形成新范式或系统性破坏，属于序数顶档而非与R1等距的算术4分。若最强一侧为R4、反向最高仅R1且无R2以上硬负向，则最终仍为CIV4；R1只压档内带位，存在R1时CIV4不得取HIGH。反向达到R2后恢复普通净算与硬负向门禁。该规则正负对称。

mixed package中的组件只有在各自满足独立影响包的最小闭合条件时才进入P/N；普通反证、覆盖限制、实施成本和未形成独立结果的副作用只影响带位与置信度，不得再作为一个整数层级参与相减。

### 7.2 硬负向门禁

下列**R2以上且本人归责闭合**的结果可激活`hard_negative_gate`：

- A：大规模排斥、强制同化、身份压迫、群体性毁灭或不可逆共同体破坏；
- B：大范围教育网络撤销、身份性准入封锁、强制固化学习/职业身份；
- C：系统性禁毁、文字狱、学术/宗教迫害、人才与文本不可逆损失。

设最强硬负向层级为`H=2/3/4`：

1. 只有同一损害链上的真实修复或逆转可以降低/解除门禁；无关正向成果不能解除；
2. 若`N>P`，最终负向幅度不得低于`H-1`（最低CIV1）；
3. 若`P=N`，可以CIV0，但必须保留硬负向记录；
4. 若`P>N`，正向上限依次为：`H2→CIV3`、`H3→CIV2`、`H4→CIV1`，且带位不得取HIGH。

硬负向解决的是“重大不可逆损失被若干普通正面事项洗掉”的问题，不替代正常正负同账。

## 8. 史料与归责门禁

每条曲线和人物裁决必须标记`source_coverage`：

- `ADEQUATE`：正向、负向、归责和交班锚足以稳定档位；
- `PARTIAL_BUT_SUFFICIENT`：材料不完整，但最小充分命题已闭合；
- `INSUFFICIENT`：无法稳定方向或归责。

以下情况不得正式计分：

- `attribution_strength`仍为`POLITY_OR_RULER_PENDING`、空值或等价未决状态；
- `source_coverage`语义仍是“仅足以证明无增量”却被拿来支持正负分；
- 已触发重大事项，但方向、结果或本人责任无法闭合。

上述情况统一输出`UNRESOLVED_EVIDENCE_GAP`并阻断第四项正式调整，不得以0代替未知。

扩搜后的材料资格裁决：须记录实际检索范围、所见史源、仍未闭合的命题及排除后继/摄政误归等理由。若扩搜仍不能证成该材料的结果或本人归责，撤销其计分资格，标记`scoring_eligibility=REVOKED`，保留原材料代码和来源追溯；该记录即使保留在影响包集合中也不再属于接受计分包，不进入P/N、补强或硬负向门。不得仅因来源字段为空自动撤销，也不得把未进行扩搜的待审材料标成已撤销。

轴上已无合格材料时，可输出`NO_ELIGIBLE_INCREMENT_AFTER_EVIDENCE_REVIEW`和0，表示当前证据集无可结算增量，不是已证明历史上没有影响，亦不是CIV0正负抵消。尚未处置的重大候选仍使用`UNRESOLVED_EVIDENCE_GAP`阻断；资格裁决不能代替全池反漏检、共享曲线和交班校准。

每份结果至少发布：`triggered_axis_count`、逐轴方向、幅度、档内位置、`disposition`、`source_coverage`；全0人物另记录`zero_scan_checked=true`。

## 9. 覆盖、校准与停止规则

- 每个政权优先完成三条共享曲线，再结算人物；不得逐人重复搜索相同朝代背景。
- 每轴至少核对一个正向入口和一个负向入口；全0前执行第3.1节反漏检门。
- 已有曲线、本人增量、反证和交班锚足以稳定档位时停止扩展。
- 普通史料增加不能继续堆分；只有可能改变档位、方向或归责的材料才补检索。
- 全名册校准检查时代、史料覆盖、在位长短和政权形态；时代差异只触发语义复核，不设置自动时代系数。
- 若高档主要由技术年代或现存材料数量解释，或某时期异常集中为0，先修共享曲线与材料覆盖，不直接调分。

本合同确定第四项当前业务结构、证据汇总方式和结算门禁。正式分必须由canonical人物裁决生成；临时分析文件不得直接迁移为正式结果。

A轴的只读核对入口为`python v4.py fourth-item-a-verify`。`python v4.py fourth-item-a-views --write`仅从正式JSON更新A轴阅读版与第四项总榜；不选择影响包、不裁定R级或带位、不写正式分。正负组件、引用归属、净算、硬门、排名及阅读版同值通过，不等于共享曲线与交班已获全池语义验收。分值变动后用既有`composite-ranking --write`同步综合榜。
