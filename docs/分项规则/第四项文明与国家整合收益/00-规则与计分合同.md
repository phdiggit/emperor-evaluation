# 第四项文明与国家整合收益规则与计分合同

## 1. 定位与分值

评本人窗口内共同体、教育流动与知识生态的显著可归责净变化；有符号附加、不入共同正向分母，无合格增量为0。

| 分项 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

后世延续只验耐久，不另设遗产分。

## 2. 与其他项目的边界

| 事实 | 归属 |
|---|---|
| 军事占领、安全边界、控制规模 | 第三项；第四项A只计群体参与、认同、接纳或排斥结果 |
| 设官置县、法律行政、财政穿透、选官制度、当期官僚质量 | 第二项；另有独立社会整合或教育可及、流动结果，才计第四项A/B |
| 家庭生计、经济财政、恢复成本；死亡、抓捕、酷刑、人身财产及司法安全 | 第二项C1/C2/C4及C3；第四项A只计额外身份降格、共同体/家庭离散、群体参与和结构整合后果 |
| 政治反馈、日常异议表达和异议者安全 | 第二项B2；第四项C须另证知识载体、学校教学、文本传播或专业知识生产结果 |

同一成果的规模、持续期与历史影响只由一个主项目计分。可以共用事实复验因果，不能因对象是文士、工匠，就把死亡、抓捕、一般表达安全受损或仕进封锁再计为知识损害。

## 3. 结算单位与固定扫描

先按政权和连续阶段建立三轴共享曲线`dynasty_curve_segment`，记录继承基线、方向、转折与交班；再以`ruler_window_adjudication`评价本人造成、授权、持续维持或明确放任的显著变化。

同政权使用相同指标和证明标准，按§5扫描，不按名望搜贡献。摄政、亲政、复位及不连续窗口分别结算，相邻交班锚一致。每人每轴最多两个影响包，三轴最多六个；更多同方向材料只增强覆盖和置信，不累加。

### 3.1 零值反漏检门

输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT`前，按以下固定高信号复查：

- **A**：大规模群体纳入或排斥、身份地位重构、强迁、强制同化、群体性毁灭或长期隔离；
- **B**：大规模兴废学校、教育网络扩张或撤销、真实改变准入的考试与培养改革、跨身份/族群招生、重要专业教育新入口；
- **C**：文字创制或重大改革、大型翻译/典籍/刊刻工程、被国家采用的重大科学知识产品，以及禁书、毁书、文字狱、系统性学术或宗教迫害。

发现高信号触发器后必须转入一次定向补证，不能继续记“未触发”。全0人物必须记录`zero_scan_checked=true`。

## 4. 时代校准与本人归责

档位只看**相对继承基线的本人可归责变化**，不比较学校、著作、士人、典籍的裸数量，也不设置朝代系数。

每条曲线至少固定：

- `inherited_baseline`：接掌时的A/B/C水平与主要负债；
- `contemporary_feasible_frontier`：当时现实可达到的前沿，只校准难度与覆盖；
- `background_trend`：人口、纸张印刷、城市化、前代积累等自然趋势；
- `attributable_change`：剥离背景趋势和他人独立行动后的本人变化。

技术人口趋势入基线，绝对规模不直接定档。

高位守成只有存在现实退化压力、本人明确维持行动和稳定交班时才形成正向增量。自然延续为0。

长期耐久统一观察本人窗口结束后30年，并额外核对两个直接后继交接锚；后继者独立决策形成的新结果必须切断。

## 5. 三轴固定指标族

### 5.1 A 国家共同体与社会整合

评价不同区域、族群、身份和文化群体是否形成可持续的共同体参与、认同和相互接纳。

只从以下指标族触发：群体公共参与、跨群体合作与交往、身份和法律地位的社会后果、区域与群体冲突变化、排斥隔离及强制同化的实际后果。

国号、疆域、设治、迁徙或服饰命令须证社会后果；后世民族叙事不代当时结果。

#### A轴覆盖、复杂度与生命周期

候选须覆盖内地身份、旧政权区域和边疆群体的正反入口，两包预算不截断扫描。覆盖按已证群体、地域和整合领域说明，未知留空，不编比例或由首领推全体；复杂度看实际跨越的地域、文化、生活、组织和身份边界，不按民族数加分。

深度从容纳、安置交往到公共参与、结构接纳；主要群体的稳定结构变化可R3，R4须跨场景，不能堆R2。基线取行动前，强迁、降格和修复合看，同链救济只减原损害；方式改变也不否定全部接纳。

交班按同政权、同群体及摄政/亲政划分，并行政权不串链，后继独立行为不回填本人结果。既有等级或军役不自动N1，须有本人新增独立损害；强化、放任伤害不因时代免责，普通限制不计整数层级。

#### 个案处置与群体后果准入

亲属株连、没入、殉死及赦免释放，先排除直接夺权者、战损和已在其他项计入的损害；画像只提供候选。须满足下列至少一项才形成A轴独立增量：

- 本人扩大身份性处罚规则或适用范围；
- 反复按身份实施群体排斥；
- 单次处置已造成有群体意义的参与受损、降格、强迁或结构破坏。

不能因一家或数家受罚、跨年执行、死亡不可逆而自动准入，也不能累加案件家庭数或以受罚家庭自身作分母证明群体毁灭。明确的局部群体后果可计，不要求全民变化；沿用旧制不免责。

正向同样须证明身份规则、群体参与或接纳改善，单家保全、赦免、放良不自动成包。准入后再定R级与§7.2硬负向，不能凭死亡、族诛或没入字样直接触发。

### 5.2 B 教育可及与人才流动

评价学校和教育供给、知识传递、学习机会、跨地域跨身份流动及其对文明再生产的实际影响。

科举、察举、学校、教材等制度名称只作入口；必须至少闭合一次真实招生、培养、学习、传播、流动或社会开放结果。当期官员办事能力和名臣数量不计。

B同时看相对基线的结构变化与实际新增覆盖。早期建立此前缺失或薄弱、能持续运行并改变主要供给的教育层级，可达到R3，不能单凭人数或一所学校判定。地域、身份、族群和经济门槛决定档内位置及高档上限；仅首都或上层覆盖主要限制位置，不机械降R2。成熟网络中只增人数而未扩相对覆盖或准入，不自动升档。

### 5.3 C 知识生产与文化生态

C评知识生产、整理保存、传播采用、专业知识、公共文化成果及创作生态的净变化。按“生产—保存—可访问—扩散/采用”追踪，须有超个人娱乐的公共结果，不要求服务行政，也不按宫廷内外或现代大众传播划界。

收藏、敕编、才艺、优待艺人、爱好和后世名望本身不足。校勘、翻译、文字创制、科学产品、稳定定本或降低传播成本可作正证；禁毁、系统压制、人才迫害和表达安全恶化，须按§2证明独立知识后果才计负。礼乐须区分可复用文本、乐律、传习与内部表演，文风转向和停娱裁乐也须证实际保存、传承、传播或创作空间变化。

分清主政前、主政和失权后，后世保存评论只验证当期已发生结果；同一娱乐链不拆成多条补强，大型宫廷孤本不因体量升档。未证公共结果先补证，仍不足撤资格并留史源缺口，不能降R1/LOW绕过准入，也不据此断言无历史影响。

## 6. 影响包与相对变化层级

同一行动—机制—结果合`civilization_increment_package`，多记载增置信；独立场景结果增覆盖与位置。

| 层级 | 含义 |
|---:|---|
| R0 | 本人归责或实际结果未闭合，只能作背景线索 |
| R1 | 局部、短期或低强度变化 |
| R2 | 清晰可验证的有限扩张、修复、收缩或破坏 |
| R3 | 改变主要领域并形成稳定结果的重大跃迁或倒退 |
| R4 | 跨场景形成新范式或系统性破坏，并稳定交班或造成长期断裂 |

R3须主要领域稳定变化，规模/条数/名望不准入；低基线教育路径见§5.2。

**R4门槛**：必须闭合跨场景复验；单个大型项目有多个产出，不等于自动形成跨场景新范式。

## 7. 档位、净算与硬负向

三轴统一使用`CIV0—CIV4`和LOW/MID/HIGH。正式输出只允许这套标签，不再混用旧G档名称。

| 幅度 | 含义 | LOW | MID | HIGH |
|---:|---|---:|---:|---:|
| CIV0 | 已观察结果净抵消 | 0 | 0 | 0 |
| CIV1 | 局部、短期或低强度变化 | 3.0 | 4.5 | 6.0 |
| CIV2 | 清晰有限的扩张、修复、收缩或破坏 | 7.5 | 9.5 | 11.5 |
| CIV3 | 改变主要领域并形成稳定结果 | 13.5 | 16.0 | 18.0 |
| CIV4 | 跨场景新范式或系统性破坏 | 19.0 | 21.0 | 22.5 |

LOW/MID/HIGH由相对覆盖、持续性、交班、跨场景复验和反证决定。HIGH必须同时有较强覆盖与持续性；CIV4-HIGH还必须有明确跨场景复验。史料条数不得决定带位。

### 7.1 普通净算

正负方向分别取最强影响包为主体；同方向第二个**独立**影响包最多增加0.5，且方向强度封顶4：

`P = min(4, strongest_positive + reinforcement)`

`N = min(4, strongest_negative + reinforcement)`

`V = P - N`

- `V=0`：CIV0；
- `V≠0`：方向取符号，幅度取`min(4, max(1, floor(abs(V))))`。

两个R2不能叠成CIV3；第二包主要用于带位和覆盖，不用于机械堆档。

【CIV4保级】一侧R4、反向最高R1且无R2以上硬负向，仍CIV4，R1限位置且不得HIGH；反向≥R2恢复普通净算及硬门。正负对称。

混合组件各自闭合独立包才进P/N；普通反证、成本或覆盖限制只影响位置/置信，不整数相减。

### 7.2 硬负向门禁

下列**R2以上且本人归责闭合**的结果可激活`hard_negative_gate`：

- A：大规模排斥、强制同化、身份压迫、群体性毁灭或不可逆共同体破坏；
- B：大范围教育网络撤销、身份性准入封锁、强制固化学习/职业身份；
- C：系统性禁毁、文字狱、学术/宗教迫害、人才与文本不可逆损失。

设最强硬负向层级为`H=2/3/4`：

1. 只有同一损害链上的真实修复或逆转可以降低/解除门禁；无关正向成果不能解除；
2. 若`N>P`，最终负向幅度不得低于`H-1`（最低CIV1）；
3. 若`P=N`，可以CIV0，但必须保留硬负向记录；
4. 若`P>N`，正向上限依次为：`H2→CIV3`、`H3→CIV2`、`H4→CIV1`，且带位不得取HIGH。

## 8. 史料与归责门禁

每条曲线和人物裁决必须标记`source_coverage`：

- `ADEQUATE`：正向、负向、归责和交班锚足以稳定档位；
- `PARTIAL_BUT_SUFFICIENT`：材料不完整，但最小充分命题已闭合；
- `INSUFFICIENT`：无法稳定方向或归责。

以下情况不得正式计分：

- `attribution_strength`仍为`POLITY_OR_RULER_PENDING`、空值或等价未决状态；
- `source_coverage`语义仍是“仅足以证明无增量”却被拿来支持正负分；
- 已触发重大事项，但方向、结果或本人责任无法闭合。

上述情况统一输出`UNRESOLVED_EVIDENCE_GAP`并阻断第四项正式调整，不得以0代替未知。

扩搜后仍不证结果/归责，记`scoring_eligibility=REVOKED`并保存范围、史源、缺口及排除理由；不入P/N、补强或硬门。空来源不自动撤，未扩搜不称已撤。

已证事实不符本轴准入边界的，亦记`REVOKED`并保留史源与排除理由；此为规则排除，不冒称扩搜失败或史实不存在。

全轴无合格材料可记`NO_ELIGIBLE_INCREMENT_AFTER_EVIDENCE_REVIEW`及0，区别于无历史影响或CIV0抵消；重大候选未处置仍`UNRESOLVED_EVIDENCE_GAP`阻断，不豁免共享曲线和反漏检。

每份结果至少发布：`triggered_axis_count`、逐轴方向、幅度、档内位置、`disposition`、`source_coverage`；全0人物另记录`zero_scan_checked=true`。

## 9. 覆盖、校准与停止规则

每政权先建三条曲线，每轴至少查一个正向和一个负向入口，全0前做§3.1复查；不逐人重复搜索朝代背景。触发事项只作一轮归责、结果、反证和持续性补证，足以稳定档位即停止，只有可能改变方向、档位或归责的新材料才继续查。

全名册比较时代、史料覆盖、在位长短和政权形态。高档若主要由技术年代或材料量解释，或某时期异常集中为0，先查曲线与覆盖，不自动调分或乘时代系数。正式分只取canonical人物裁决，临时分析不直接转正式。

## 正式公开裁决投影

三轴结果及已接纳证据包保存`public_adjudication_summary`、`public_evidence_items`、`public_boundary`和中文幅度标签，直接说明变化、破坏、本人责任、基线、反证与跨项边界，不把CIV、DA、方向、位置代码或审计词留给阅读层翻译。

来源区分古籍转录、研究、史实摘要、项目判断和相关背景，逐条绑定原引用；保留可定位链接，无网址只留文献线索，不猜网址、不将转述冒充原文。各分轴另维护：

| 对象 | 正式字段与要求 |
|---|---|
| A轴及影响包 | `public_reading`保存正文、责任、比较起点、幅度依据、覆盖、持续性和引用；方向读实际正负组件，不靠旧标签推断 |
| C轴 | `public_reading`保存当前位置理由、零值原因、主政窗口及复核依据 |
| C材料 | `public_c_result_reading.result/responsibility/scope`写独立知识结果、本人及执行者职责、跨项边界；区分授权、资源支持、采用、亲作和下属专业工作。`sources`绑定原`source_refs`，字段内引用同值 |
| C撤资格材料 | `public_exclusion_reading.story/reason`保留事实与排除理由，统一显示“不单独计分，保留相关事实”；不用旧正负标签或被否定断言，不参与合成 |

零值分别说明无独立结果/未接纳独立材料、证据未达准入或复核后不计分、已观察正负相抵，保留个人证据边界。准入有疑点时沿当前来源复核，必要时局部改判并同步合成、交班和实际下游；投影本身不改评分。

计算说明只读合格组件、独立补强、净差、CIV4保级、硬负向和换分；撤资格材料不提供强度。跨项名称按具体项目解释，不混淆同名字母。正文、来源与计算各入口共用，阅读层只排版，不补写、删改或重新解释历史。

- `python v4.py third-fourth-item-public --write`保留A正文、刷新投影；A计算只读现行组件、净算与换分，B/C沿正式结果及证据包确定性转述。
- `third-fourth-item-public-verify`查全池覆盖、公开禁词、投影同值、A逐条来源与正式窗口及评分字段签名不变；转述和未知词处理见[共同公开生成约束](../第三项军事与边疆净收益/00-合并计分与军事扣减合同.md#正式公开裁决投影)。
- `fourth-item-a-verify`只读查三轴净算、硬门和审计引用；`fourth-item-a-views --write`只更新阅读页及榜，不重裁证据包、R或位置。语义完成以正式入口/共享审计为准，改分后用`composite-ranking --write`同步。
