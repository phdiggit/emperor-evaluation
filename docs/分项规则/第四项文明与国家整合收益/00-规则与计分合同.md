# 第四项文明与国家整合收益规则与计分合同

## 1. 定位与分值

第四项评价统治窗口内**国家共同体整合、教育与人才流动、知识生产与文化生态的显著可归责净变化**。它是有符号附加项，不进入共同正收益分母；明确进步加分，明确倒退减分，无合格增量为0。

| 分项 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

长期影响不单列。后世延续只验证既有结果的耐久性，不重复形成“文明遗产分”。

## 2. 与其他项目的边界

- 军事占领、安全边界和控制规模归第三项；A只看群体参与、认同、接纳及排斥的社会结果。
- 设官置县、法律行政、财政穿透和国家机器归第二项；只有形成独立社会整合结果时才能辅助A。
- 选官制度本体归第二项A，当期官僚质量归第二项B1；B只消费真实教育供给、学习机会和跨地域跨身份流动。
- 日常纳谏、监察、纠错归第二项B2；C看整体知识生产、传播和文化生态。
- 同一成果的规模、持续期和历史影响只能由一个主项目计分。第四项可以引用前三项事实复验因果，不复制分值。

## 3. 结算单位与固定扫描

正式结算使用两层单位：

1. `dynasty_curve_segment`：按政权和连续阶段建立A、B、C共享曲线，记录继承基线、方向、主要转折和交班锚；
2. `ruler_window_adjudication`：把实际主政窗口投影到曲线，只登记本人造成、授权、持续维持或明确放任的显著增量。

候选材料只从第5节固定指标族触发。先做政权共享扫描，再投影人物；不得按人物名望分别搜索“文化贡献”。人物定向补证只用于闭合已触发事项的归责、结果、反证和持续性，每个事项最多一轮。

共享扫描对同一政权使用相同指标族和证明标准。摄政、亲政、复位和非连续主政窗口分别结算；相邻统治者的交班锚必须一致。

每人每轴最多消费两个影响包，三轴合计最多六个。超过预算的同方向材料只增强覆盖、持续性和置信度，不继续累加。

### 3.1 零值反漏检门

任何轴在输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT`前，必须再做一次**固定高信号反漏检**，仅检查下列结构性触发器，不开放人物名望宽搜：

- **A**：大规模群体纳入或排斥、身份地位重构、强迁、强制同化、群体性毁灭或长期隔离；
- **B**：大规模兴废学校、教育网络扩张或撤销、真实改变准入的考试与培养改革、跨身份/族群招生、重要专业教育新入口；
- **C**：文字创制或重大改革、大型翻译/典籍/刊刻工程、被国家采用的重大科学知识产品，以及禁书、毁书、文字狱、系统性学术或宗教迫害。

发现高信号触发器后必须转入一次定向补证，不能继续记“未触发”。全0人物必须记录`zero_scan_checked=true`。

## 4. 时代校准与本人归责

档位只看**相对继承基线的本人可归责变化**，不比较学校、著作、士人、典籍的裸数量，也不设置朝代系数。

每条曲线至少固定：

- `inherited_baseline`：接掌时的A/B/C水平与主要负债；
- `contemporary_feasible_frontier`：当时现实可达到的前沿，只校准难度与覆盖；
- `background_trend`：人口、纸张印刷、城市化、前代积累等自然趋势；
- `attributable_change`：剥离背景趋势和他人独立行动后的本人变化。

高位守成只有同时存在现实退化压力、本人维持行动和稳定交班结果时才可计分；自然延续记`BASELINE_CONTINUATION_ONLY=0`。

长期耐久统一观察本人窗口结束后30年，并核对两个直接后继交接锚；继任者的新决策必须切断。

## 5. 三轴固定指标族

### 5.1 A 国家共同体与社会整合

看不同区域、族群、身份和文化群体是否形成更稳定的公共参与、相互接纳和共同社会秩序。

计入：群体公共参与、跨群体合作与交往、身份和法律地位的社会后果、群体冲突变化、排斥隔离及强制同化的实际后果。

不以疆域扩大、设治、国号、迁徙命令或后世民族国家叙事直接定向。

### 5.2 B 教育可及与人才流动

看知识如何到达人、人才如何跨地域和身份流动。

计入：教育供给覆盖、学习传播成本、地域/身份准入、实际招生培养、跨地域跨身份流动，以及教育机会收缩和排除。

科举、学校、教材等制度名称只作入口；必须至少闭合一次真实招生、培养、传播、流动或开放结果。选官制度本体和官僚质量不在本轴计分。

B必须同时说明：①相对当时教育领域的实际覆盖；②原先被地域、身份、族群、性别或经济门槛排除者中新增可及群体。只有名义开放而无实际运行，不得进入高档。

### 5.3 C 知识生产与文化生态

看新知识、典籍保存传播、专业知识、公共文化品、学术安全和思想文化生态的净变化。

典籍与知识工程按“生产—保存—可访问—扩散或采用”裁决。宫廷收藏、奉敕编成和皇帝个人爱好只有形成公共产出或生态变化才计分。

文字创制、跨文化翻译、科学知识产品、稳定定本和显著降低传播成本可以形成正向；禁毁、系统压制、人才迫害和表达安全恶化形成负向。成熟出版时代的大型宫廷孤本不得因体量巨大自动升档。

## 6. 影响包与相对变化层级

进入人物裁决前，材料必须归并为`civilization_increment_package`。同一行动—机制—结果链的多条记载只增强置信度；不同地域、群体、时间或制度场景中独立闭合的结果，才增强覆盖和档内位置。

每个影响包至少记录：`package_code`、`axis`、`direction`、`inherited_baseline`、`attributable_change`、`relative_change_level`、`field_coverage`、`attribution_strength`、`counterevidence`、`hard_negative_gate`、`source_coverage`、`disposition`。

| 层级 | 含义 |
|---:|---|
| R0 | 本人归责或结果未闭合，只作背景/线索 |
| R1 | 局部、短期或低强度变化 |
| R2 | 清晰可验证的有限扩张、修复、收缩或破坏 |
| R3 | 改变主要领域并形成稳定结果的重大跃迁或倒退 |
| R4 | 跨场景形成新范式或系统性破坏，并稳定交班或造成长期断裂 |

**R3门槛**：必须改变主要领域，且闭合持续性；单一局部群体、单一学校或单一普通工程原则上不得仅凭规模进入R3。

**R4门槛**：必须闭合跨场景复验；单个大型项目有多个产出，不等于自动形成跨场景新范式。

## 7. 档位、净算与硬负向

三轴统一使用`CIV0—CIV4`和LOW/MID/HIGH。正式输出只允许这套标签，不再混用旧G档名称。

| 幅度 | 共同含义 | LOW | MID | HIGH |
|---:|---|---:|---:|---:|
| CIV0 | 已观察结果净抵消 | 0 | 0 | 0 |
| CIV1 | 局部、短期或低强度变化 | 3.0 | 4.5 | 6.0 |
| CIV2 | 清晰有限的扩张、修复、收缩或破坏 | 7.5 | 9.5 | 11.5 |
| CIV3 | 改变主要领域并形成稳定结果 | 13.5 | 16.0 | 18.0 |
| CIV4 | 跨场景新范式或系统性破坏 | 19.0 | 21.0 | 22.5 |

LOW/MID/HIGH由相对覆盖、持续性、交班、跨场景复验和反证决定。HIGH必须同时有较强覆盖与持续性；CIV4-HIGH还必须有明确跨场景复验。史料条数不得决定带位。

### 7.1 普通净算

正负方向分别取最强影响包为主体；同方向第二个**独立**影响包最多增加0.5，且方向强度封顶4：

`P = min(4, strongest_positive + reinforcement)`

`N = min(4, strongest_negative + reinforcement)`

其中`reinforcement`只能取0或0.5。令`V=P-N`：

- `V=0`：CIV0；
- `V≠0`：方向取符号，幅度取`min(4, max(1, floor(abs(V))))`。

两个R2不能叠成CIV3；第二包主要用于带位和覆盖，不用于机械堆档。

### 7.2 硬负向门禁

下列**R2以上且本人归责闭合**的结果可激活`hard_negative_gate`：

- A：大规模排斥、强制同化、身份压迫、群体性毁灭或不可逆共同体破坏；
- B：大范围教育网络撤销、身份性准入封锁、强制固化学习/职业身份；
- C：系统性禁毁、文字狱、学术/宗教迫害、人才与文本不可逆损失。

设最强硬负向层级为`H=2/3/4`：

1. 只有同一损害链上的真实修复或逆转可以降低/解除门禁；无关正向成果不能解除；
2. 若`N>P`，最终负向幅度不得低于`H-1`（最低CIV1）；
3. 若`P=N`，可以CIV0，但必须保留硬负向记录；
4. 若`P>N`，正向上限依次为：`H2→CIV3`、`H3→CIV2`、`H4→CIV1`，且带位不得取HIGH。

硬负向解决的是“重大不可逆损失被若干普通正面事项洗掉”的问题，不替代正常正负同账。

## 8. 史料与归责门禁

只有以下两类`source_coverage`可以形成正式分：

- `ADEQUATE`；
- `PARTIAL_BUT_SUFFICIENT`。

`INSUFFICIENT`或其他仅证明时代/政权背景、未证明本人事项的状态不得正式计分。

任何R1以上影响包都必须闭合到具体统治者责任。`PENDING`、`POLITY_OR_RULER_PENDING`、仅有政权层面归责、方向不明或结果未闭合的材料只能记R0；若该事项可能改变轴向结果，则输出`UNRESOLVED_EVIDENCE_GAP`，阻断第四项调整，不能用0代替未知。

固定扫描无合格影响包且通过零值反漏检门，输出`NO_ELIGIBLE_CIVILIZATION_INCREMENT=0`；有合格包但净抵消，输出`OBSERVED_OFFSETTING_OR_BALANCED_EFFECTS=0`。

## 9. 覆盖、校准与停止

- 每个政权优先完成三条共享曲线，再结算人物。
- 每轴至少核对一个正向入口和一个负向入口；拟判0时额外执行第3.1节零值反漏检。
- 已有本人增量、反证、归责和相邻交班锚足以稳定档位时停止扩展。
- 普通史料增加不能堆分；只有可能改变方向、幅度、带位或归责的材料才继续补证。
- 全名册校准检查时代、史料覆盖、在位长短、政权形态、全0率和高档率；发现某一时代或政权异常集中于全0或高档时，先查材料覆盖与R档门槛，不加时代修正系数。

本合同是第四项唯一有效计分口径。正式结果必须同时发布逐轴方向、CIV幅度、LOW/MID/HIGH、`disposition`、`source_coverage`、`triggered_axis_count`和`zero_scan_checked`；canonical人物裁决通过门禁后方可进入综合分。
