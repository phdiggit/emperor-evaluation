# 分项规则

## 本目录负责什么

本目录只放七大项和各子项目的业务归项规则。目录层级只到七大项；子项目用 Markdown 文件表示。

## 本目录不负责什么

本目录不承载通用证据规则、JSONL/SQLite 字段规范、Markdown 展示规范、GitHub 协作说明或 registry。

## 与相邻目录的边界

- 总规则与最高层口径，进入 `项目总纲/`。
- 证据强度、负证触发和对象锚点，进入 `证据规则/`。
- 字段和生成库规则，进入 `数据结构与生成库/`。
- 展示与协作规则，进入 `展示与协作/`。

## 后续新增文件限制

每个子项目最多一个分项规则文档。第五项B不例外。不得为复杂子项新增多个分项规则文档。分项规则文档应引用总则、证据规则、数据结构与生成库、展示与协作，而不是复制通用内容。
