# 第二项政权交接稳定（D1/D3）规则与结算合同

D1评退出后的行政连续，D3评中央权力安全承接。两轴按0—5档合成交接质量20分，各自内部指数仅供方向卡，不进入总分。对象覆盖当前正式名单，姓名与ID唯一。

## D1继任行政连续性

### 一、对象、窗口与去重

从实际最高治理权终止起通常观察三年，评官署、人员、命令文书、法律、财政及军政传导是否继续运行，不评正当性、廉洁或政策质量。

储位、遗诏、政变先归D3；与新政策、灾战、财政积弊、专权腐败或异议压制有关的事实，只有证实窗口内行政断裂才进入D1主档或位置。窗外只作H5耐久旁证，不能倒计后世成果。

### 二、H档边界与证据门

| 档位 | 行政连续性边界 | 内部指数区间（30刻度） |
| --- | --- | ---: |
| H0 | 主要官署、命令链和基本行政实际停止；不得仅因皇帝被杀、被废、亡国、政变或继承战争判定。 | 0—2.9 |
| H1 | 仅残存、零散或短暂的旧行政资产，未形成可持续的核心链。被征服后若旧官僚或地方资产仍被新中枢直接接收，须先复核H1/H2。 | 3—11.9 |
| H2 | 关键领域须依赖紧急接管、显著换血或结构重建后才恢复运行；“有明显换人”本身不足。 | 12—16.4 |
| H3 | 可识别的前任旧人员、旧官署、旧命令或文书链在退出后实际继续运行；同一机器持续工作而仅有控制集团更替或政策恶化，优先判本档。 | 16.5—20.9 |
| H4 | 至少两个相互独立的核心行政领域在退出后实际连续交付，或一条同时覆盖中枢决策、执行人员与结果的广域连续链；同一中枢链、同一事项的中央—地方传递或同一人的多重头衔不得拆成两领域。第二领域必须在窗口内以具体旧人员、官署、命令或交付闭合。 | 21—25.4 |
| H5 | 先完整满足H4，并仅可由高压多域门（至少三个独立领域在真实压力下持续交付且无结构重建）或耐久资产门（定向留下、连续任用、未重建替换、后续仍验证高价值）进入。 | 25.5—30 |

H4第二领域若在三年内失控、重建或退出中央控制，不能靠第一领域保档。H5不能由旧臣数量、制度规模、幼主、顺利即位或长期治理直接推出，须满足表中的高压或耐久条件。

### 三、正式卡与校验

JSON保存`D1_level`、`direction_index`、`index_interval`；与Markdown的档、位、指数、排序和依据同值。

## D3政权交接稳定

D3只评实际失权时的中央权力承接，不评日常稳定、个人驾驭能力、继任行政表现或长期治理。摄政、太后、禅让及太上皇均按实际失权而非名义退位开窗，继任者是否入正式池不影响前任评价。

### 一、最小结算单元

每人一个`handover_event`，不设三锚或多轴状态。至少保存：

| 字段 | 内容 |
|---|---|
| `power_end` | 实际失权时间与方式 |
| `prearrangement_evidence`、`actual_successor` | 可执行生前安排与实际承接者；无安排记无或null，不猜意图 |
| `D3_grade`、`direction_index`、`immediate_result_facts` | 唯一主档、15刻度内部指数及承接/争位/接管/分裂/无继承事实；合成只读主档数字 |
| `terminal_source_ref`、`terminal_evidence` | 直接定位正史、编年史或本纪的卷次、年份/稳定锚，保存原文或忠实摘述，不能只引总结卡 |
| `evidence_grade`、`reason`、`confidence` | 证据等级、理由与置信度 |

完整终局窗口可共同支持安排与即时结果，不要求每字段另拆链接。

### 二、证据窗口

先读权力终止至继位的通鉴/正史本纪连续原文，缺储位、托孤或力量安排再按实际继任者回查任内相关段落；总结卡只作定位。

从最后有效安排观察至继任中央正常运行，再观察一年，只计前任储位、辅政、宗室、军权等配置延续的风险。一年内启动的同链冲突可追至结束，继任者新造或后来不连续冲突不倒灌。完整原文窗口无显著冲突才可记`WINDOW_COMPLETE_NO_CONTEST`，摘要缺载不证明稳定。

### 三、六档

| 档位 | 交接结果边界 | 内部指数区间（15刻度） |
| --- | --- | ---: |
| D3-0 交接断裂 | 本政权没有形成有效继承，中央灭亡或权力延续完全中断。旧中央崩溃后仅有傀儡、残余或地方中心并存、但无一方完成有效中央继承的，仍属本档；如同一王朝在一年观察期内快速重建可运行中央，则按实际重建质量改判。 | 0—2.85 |
| D3-1 分裂争位 | 同一政权出现两个以上现实争夺中央承继权的实际中枢、继承战争或大范围军政分裂。 | 3—5.85 |
| D3-2 暴力接管 | 弑杀、伪诏、宫廷武装政变、逼宫或废立以暴力或强制手段重新决定继承者或实际最高权力，但一个中央较快接续。交接期杀戮或清洗本身不足；既定继承者始终在位而其周边集团发生清洗或未遂夺权，原则上不入本档。 | 6—8.85 |
| D3-3 脆弱完成 | 承接完成，但一年内确实出现源于前任交接结构的现实权威威胁、明显竞争、安排失效或权力悬置，尚未发展为暴力接管。 | 9—11.85 |
| D3-4 安全交接 | 顺利承接，且一年内未出现现实的继承或控制权威胁；幼主、摄政、顾命、强臣、军头等结构风险只压低档内位置，不能自动降档。 | 12—14.10 |
| D3-5 高质量交接 | 事前安排明确，关键力量共同接受，交接过程与即时结果均有直接材料，中央安全平稳接续；不要求另有现实风险事件验证。 | 14.25—15 |

主档按实际交接结果；安排、中央军政、宗室外戚、权臣和军头材料用于有据的档内细分，不拆分项或因缺某类材料机械扣分。幼主、摄政、禅让、非嫡长本身不降档，亡国也不因有名义继任者就算中央连续。

### 四、档内指数与证据等级

指数只在本档区间表达安排、共识、连续与风险，最多两位小数，不强制0.15步长、不按篇数累加。证据等级控制可接受性及最高档准入，不自动抬位置：

| 等级 | 条件 |
|---|---|
| `E3_DIRECT_FULL` | 安排、过程、即时结果均有直接材料 |
| `E2_DIRECT_OUTCOME` | 失权、实际继承和即时结果明确，结构细节不全 |
| `E1_CONTINUITY_INFERENCE` | 只能确认前后统治者及中央延续方式 |
| `E0_UNRESOLVED` | 实际权力转换或有效中央继承仍有关键争议 |

D3-5须安全结果、明确安排、关键力量共识及E3，不要求另遇风险事件；被安排稳住的幼主、战时、异地死亡等风险只可辅助档内，不另奖励。完整窗口的简短明确记载也可支持E2，篇幅短不等于弱。E0须补证，不能接受方向卡。

### 五、边界与去重

D1观察行政续行，日常效率归B1，社会恢复归C4，个人能力另归画像。D3只计交接安全；同一政变内战可作战争、治安或能力证据，但不在D3重复计伤亡、军事收益或个人能力。

### 六、方向卡接受门禁

全池逐人须有唯一主档、15刻度指数、实际继任者、证据等级及至少一条可读史料或受约束推断理由，E0须为零。抽查高、中、低档及摄政、政变、战时交班、亡国类型，并通过JSON、链接、UTF-8无BOM、差异及生成幂等检查。

## 七、与D1合成交接质量20分

两轴只按0—5档数字等权合成：

`raw = 2 × (D1_level + D3_level)`

低侧为0/1/2/3/4/5时，上限依次4/8/12/16/20/20分：

`handoff_20 = min(raw, low_side_cap[min(D1_level,D3_level)])`

正式入口：[交接质量结算](../../../评分结算/净收益/第二项治国净收益/政权交接稳定/03-交接质量20分正式结算.md)。

## 八、公开正文与逐条史源

正式JSON逐人维护`public_story`、`public_adjudication_summary`、`public_window`、`public_responsibility`、`public_boundary`和`public_evidence_items`。写明失权、承接者或接管方及具体人员、官署、命令/继承事件，不用分类、材料数量、模板或旧改判过程代替事实。D1长期旁证与三年内运行分清，D3只解释当前结果。

逐条材料保存稳定ID、中文标题、角色、完整正文、采用范围、证据性质及`source_refs`。来源保留本地文件、史书/记录名、卷次/行号、逐字摘录和已有链接，区分原文、摘要、推断、判断及背景，不以结算表代史源。定位同值不代替实际支持关系审查。

`second-item-d1-d3-public --write`只校验字段、刷新元数据并逐字同步两张Markdown，不自动生成、删改或截短正文；缺字段、未知代码、残句或无来源材料拒绝通过。阅读层显示同一正文、映射、公式与来源，不补历史或重释责任。公开维护不改档、内部指数或20分，改分另按评分合同执行。
