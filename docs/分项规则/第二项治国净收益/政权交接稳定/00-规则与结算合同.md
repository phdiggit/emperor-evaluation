# 第二项D3政权交接稳定规则与结算合同

本合同用于秦至唐95名评价对象的D3政权交接稳定结算，满分15分。D3只回答：本人离世、退位、被废或实际失权时，中央权力能否安全延续。它不是统治期政治稳定、官僚质量、制度韧性或继任者长期表现的缩写。

## 一、最小结算单元

每人只建立一个`handover_event`，不设三锚或多轴状态。当前正式JSON至少保存：

- `power_end`：实际权力终止时间和方式；
- `prearrangement_evidence`与`actual_successor`：生前可执行安排及实际承接者；没有安排时明确记无或`null`，不为凑字段推定本人意图；
- `D3_grade`、`D3_score_points`与`immediate_result_facts`：用唯一主档、15分分数和直接事实记录正常承接、脆弱承接、暴力接管、并立分裂或无继承；
- `terminal_source_ref`与`terminal_evidence`：前者必须直接定位正史、编年史或本纪原文的卷次、年份或稳定锚点，后者保存可读原文或忠实摘述；不得只填写总结卡；
- `evidence_grade`、`reason`和`confidence`。安排与即时结果的详细来源可以在同一完整终局窗口内闭合，不要求为每个字段机械拆成不同链接。

摄政、太后和实际掌权者按实际权力终止点结算。继承者是否进入95人名册不影响前任D3。统一创业难度、继任者长期治理和后世王朝寿命均不进入。

## 二、证据窗口

每人必须读取一次《资治通鉴》或正史本纪的原文终局窗口，不能直接用总结卡算分。先读死亡、失权至继位完成的连续段；若该段没有交代储位形成、托孤或关键力量安排，再按实际继承者姓名及“太子、废立、遗诏、顾命、辅政”等词在本人任内定向回查关键节点。只展开命中的段落，不重读整卷或整个任期。

交接窗口从实际权力终止前最后一项仍有效的继承安排开始，到继任中央完成首次正常权力运行为止。默认检查交接后一年；一年内已经启动的继承冲突可以追踪到收束。更晚发生、且未从交接窗口连续发展的政变、内战或政策失败不得倒灌。

现有通鉴总结卡只作定位线索，不能决定证据等级，也不能作为“未见冲突”的依据。只有完整读取原文窗口后，才可用`WINDOW_COMPLETE_NO_CONTEST`表示未见这类高显著性冲突；不得把总结卡缺载当成稳定证据。

## 三、六档

| 档位 | 交接结果边界 | 分数区间 |
| --- | --- | ---: |
| D3-0 交接断裂 | 本政权没有形成有效继承，中央灭亡或权力延续完全中断 | 0—2.85 |
| D3-1 分裂争位 | 出现两个以上实际中枢、继承战争或大范围军政分裂 | 3—5.85 |
| D3-2 暴力接管 | 弑杀、伪诏、宫廷武装政变、逼宫或废立决定交接，但一个中央较快接续 | 6—8.85 |
| D3-3 脆弱完成 | 继位完成且无继承战争，但依赖幼主摄政、单一权臣、外戚或军头，或存在明确即时竞争风险 | 9—11.85 |
| D3-4 安全交接 | 法定或实际继承者获中枢接受，中央军政和政令连续，没有实际争位与武装断裂 | 12—14.10 |
| D3-5 高质量交接 | 事前安排明确，关键力量共同接受，且经实际风险检验仍平稳接续 | 14.25—15 |

主档只由实际交接结果决定。继承安排、中央军政、宗室外戚权臣和军头材料只决定档内位置，不拆成独立分项，也不因缺少某一类材料机械扣分。

## 四、档内分与证据等级

各档先取区间中位，并以0.15分为最小步长作档内微调。明确有效的继承安排、关键力量共同接受、军政与政令连续可分别支持小幅上移；不够跨档的储位反复、单一集团依赖、即时竞争风险或安排缺失可分别支持小幅下移。每次移动都必须在`reason`或`immediate_result_facts`中有可读事实，不按材料篇数累计，也不得跨越本档上下界。证据等级只控制正式化和最高档准入，不因E3比E2材料更完整而自动加分。

D3-5除事前安排和共同接受外，必须存在已经发生的现实风险环境，例如战败或敌军压境、远离首都或军中死亡、幼主与多名顾命力量并存、储位重建、宫廷隐患或军中骚动，并由完整终局窗口证明该风险没有转化为争位和军政断裂。“可能有人反对”“继承本来有风险”或普通病逝本身不算实际风险检验。当前D3-5内部只作0.15级小差距，不另设大额风险奖励。

证据等级：

- `E3_DIRECT_FULL`：安排、交接过程和即时结果均有直接材料；
- `E2_DIRECT_OUTCOME`：权力终止、实际继承和即时结果明确，结构细节不全；
- `E1_CONTINUITY_INFERENCE`：只能确认前后统治者与中央延续方式；
- `E0_UNRESOLVED`：实际掌权转换或是否形成中央继承仍有关键争议。

E1不得进入D3-5；D3-5必须为E3。E0不得正式算分，须定向补证。材料简短不等于低等级：完整本纪或编年窗口中的“帝崩、太子即位”可以直接证明权力终止和法定继承，若窗口完整且无争位记载，可达到E2。

## 五、边界与去重

- 日常行政效率归B，制度脱离本人继续运行归D1，社会承压余量归D2。
- 皇帝平时控制权臣、外戚或宗室的个人能力归第五项；D3只读取这些力量在交接时是否造成断裂风险。
- 同一政变或内战可以被战争、治安或人物能力项目引用；D3只消费它对中央交接安全的结果，不重复计算伤亡、军事收益或个人能力。
- 幼主、摄政、禅让和非嫡长继承均不自动降档；只有实际依赖、竞争和断裂进入裁决。
- 亡国不因继任者名义存在而自动算完成交接；须确认本政权中央确有连续运行。

## 六、正式化门禁

正式结果必须覆盖95人且姓名、ID唯一；每人有唯一主档、15分分数、实际继承者、证据等级、至少一条可读史料或受约束推断理由。E0必须为零；高、中、低档和摄政、政变、战时交班、亡国样本均须抽查。JSON、链接、UTF-8无BOM、`git diff --check`和生成器幂等性必须通过。
