# 第二项政权交接稳定（D1/D3）规则与结算合同

本合同覆盖当前正式评价对象全集；人数、姓名和`ruler_id`以正式D1、D3结算名单为准，并由名单唯一性校验，不在合同中硬编码人数。D1与D3分别保留内部指数用于档内排序，但该指数不是第二项分值；现行正式总分只读取内部档位并等权合成20分交接质量。

## D1继任行政连续性

### 一、对象、窗口与去重

D1只看本人实际最高治理权终止后通常三年内，既有官署、关键人员、命令与文书、法律适用、财政征发、军政及中央—地方传导是否继续实际运行；不评价政治正当性、廉洁性、政策质量、专权、拒谏或权臣俘获。名义禅位、太上皇、摄政退出等以实际最高治理权终止点开窗。

储位、遗诏、顾命名单、政变、争位、弑君、逼宫、废立、宫禁和军权安全本身只归D3；只有它们造成官署停摆、核心人员大换血、命令链改造或地方执行失效时才投影D1。继任者的新政策、政策反转、财政积弊、灾害、战争和社会问题也不直接证明连续或断裂，必须闭合到观察窗内的实际行政后果。窗口外材料仅可作为H5耐久旁证，且必须同时证明前任定向留下、继任者连续任用、中间未重建替换、后来仍显示该人员或行政资产的持续价值；远期成果本身不得倒算D1。

### 二、H档边界与证据门

| 档位 | 行政连续性边界 | 内部指数区间（30刻度） |
| --- | --- | ---: |
| H0 | 主要官署、命令链和基本行政实际停止；不得仅因皇帝被杀、被废、亡国、政变或继承战争判定。 | 0—2.9 |
| H1 | 仅残存、零散或短暂的旧行政资产，未形成可持续的核心链。被征服后若旧官僚或地方资产仍被新中枢直接接收，须先复核H1/H2。 | 3—11.9 |
| H2 | 关键领域须依赖紧急接管、显著换血或结构重建后才恢复运行；“有明显换人”本身不足。 | 12—16.4 |
| H3 | 可识别的前任旧人员、旧官署、旧命令或文书链在退出后实际继续运行；同一机器持续工作而仅有控制集团更替或政策恶化，优先判本档。 | 16.5—20.9 |
| H4 | 至少两个相互独立的核心行政领域在退出后实际连续交付，或一条同时覆盖中枢决策、执行人员与结果的广域连续链；同一中枢链、同一事项的中央—地方传递或同一人的多重头衔不得拆成两领域。第二领域必须在窗口内以具体旧人员、官署、命令或交付闭合。 | 21—25.4 |
| H5 | 先完整满足H4，并仅可由高压多域门（至少三个独立领域在真实压力下持续交付且无结构重建）或耐久资产门（定向留下、连续任用、未重建替换、后续仍验证高价值）进入。 | 25.5—30 |

H4的第二领域如在三年窗口内迅速失控、重建或退出中央控制，不得只凭第一领域保留H4。H5不得由旧臣数量、制度规模、幼主、顺利即位或一般长期治理直接推出。D3型事实不得作为D1档内负向；B1/B2型专权、腐败、异议压制等事实，也只有闭合为实际行政断裂时方可进入D1主档或位置。

### 三、正式卡与校验

正式D1 JSON必须动态声明与`records`相等的覆盖数，并重算`grade_distribution`、排名、`handoff_level`、`direction_index`和`index_interval`；姓名与ID唯一。每位H3至少有一条可识别的旧人员、旧官署、旧命令或文书链继续运行证据；每位H4必须保存双独立领域或广域连续链；每位H5必须保存所走窄门及其证据。Markdown必须与JSON的档位、位置、指数、排名和结算依据同步。

## D3政权交接稳定

D3只回答：本人离世、退位、被废或实际失权时，中央权力能否安全延续。它不是统治期政治稳定、官僚质量、制度韧性或继任者长期表现的缩写。

## 一、最小结算单元

每人只建立一个`handover_event`，不设三锚或多轴状态。当前正式JSON至少保存：

- `power_end`：实际权力终止时间和方式；
- `prearrangement_evidence`与`actual_successor`：生前可执行安排及实际承接者；没有安排时明确记无或`null`，不为凑字段推定本人意图；
- `D3_grade`、`direction_index`与`immediate_result_facts`：用唯一主档、15刻度内部指数和直接事实记录正常承接、脆弱承接、暴力接管、并立分裂或无继承；第二项正式合成只读取`D3_grade`的档位数字；
- `terminal_source_ref`与`terminal_evidence`：前者必须直接定位正史、编年史或本纪原文的卷次、年份或稳定锚点，后者保存可读原文或忠实摘述；不得只填写总结卡；
- `evidence_grade`、`reason`和`confidence`。安排与即时结果的详细来源可以在同一完整终局窗口内闭合，不要求为每个字段机械拆成不同链接。

摄政、太后和实际掌权者按实际权力终止点结算。继承者是否进入当前正式评价对象全集不影响前任D3。统一创业难度、继任者长期治理和后世王朝寿命均不进入。

## 二、证据窗口

每人必须读取一次《资治通鉴》或正史本纪的原文终局窗口，不能直接用总结卡算分。先读死亡、失权至继位完成的连续段；若该段没有交代储位形成、托孤或关键力量安排，再按实际继承者姓名及“太子、废立、遗诏、顾命、辅政”等词在本人任内定向回查关键节点。只展开命中的段落，不重读整卷或整个任期。

交接窗口分为承接阶段与稳定观察期。承接阶段从实际权力终止前最后一项仍有效的继承安排开始，到继任者取得中央最高权力并开始正常运行；首次正常权力运行只结束承接阶段。其后继续观察一年：只计入与前任留下的储位、辅政、宗室、军权、禁军、外戚或权臣配置存在直接连续关系的交接风险。继任者上台后自行制造的新冲突，不因发生在一年内而倒灌前任；一年内已经启动且明显源自交接结构的冲突，可以追踪到其直接收束。更晚发生、且未从交接窗口连续发展的政变、内战或政策失败不得倒灌。

现有通鉴总结卡只作定位线索，不能决定证据等级，也不能作为“未见冲突”的依据。只有完整读取原文窗口后，才可用`WINDOW_COMPLETE_NO_CONTEST`表示未见这类高显著性冲突；不得把总结卡缺载当成稳定证据。

## 三、六档

| 档位 | 交接结果边界 | 内部指数区间（15刻度） |
| --- | --- | ---: |
| D3-0 交接断裂 | 本政权没有形成有效继承，中央灭亡或权力延续完全中断。旧中央崩溃后仅有傀儡、残余或地方中心并存、但无一方完成有效中央继承的，仍属本档；如同一王朝在一年观察期内快速重建可运行中央，则按实际重建质量改判。 | 0—2.85 |
| D3-1 分裂争位 | 同一政权出现两个以上现实争夺中央承继权的实际中枢、继承战争或大范围军政分裂。 | 3—5.85 |
| D3-2 暴力接管 | 弑杀、伪诏、宫廷武装政变、逼宫或废立以暴力或强制手段重新决定继承者或实际最高权力，但一个中央较快接续。交接期杀戮或清洗本身不足；既定继承者始终在位而其周边集团发生清洗或未遂夺权，原则上不入本档。 | 6—8.85 |
| D3-3 脆弱完成 | 承接完成，但一年内确实出现源于前任交接结构的现实权威威胁、明显竞争、安排失效或权力悬置，尚未发展为暴力接管。 | 9—11.85 |
| D3-4 安全交接 | 顺利承接，且一年内未出现现实的继承或控制权威胁；幼主、摄政、顾命、强臣、军头等结构风险只压低档内位置，不能自动降档。 | 12—14.10 |
| D3-5 高质量交接 | 事前安排明确，关键力量共同接受，且经现实风险检验仍平稳接续；已被安排稳住的幼主、多顾命、战时或异地死亡等风险可构成正向检验。 | 14.25—15 |

主档只由实际交接结果决定。继承安排、中央军政、宗室外戚权臣和军头材料只决定档内位置，不拆成独立分项，也不因缺少某一类材料机械扣分。

## 四、档内指数与证据等级

15刻度内部指数只在已经裁定的主档区间内表达相对位置。明确有效的继承安排、关键力量共同接受、军政与政令连续可以支持档内上移；不够跨档的储位反复、单一集团依赖、即时竞争风险或安排缺失可以支持档内下移。每次移动都必须在`reason`或`immediate_result_facts`中有可读事实，不按材料篇数累计，也不得跨越本档上下界。既有159人来自多批次正式接入，内部指数统一保留至最多两位小数，不再强制历史批次全部回写为0.15步长；该指数不进入20分交接质量或387分总榜。证据等级只控制方向卡可接受性和最高档准入，不因E3比E2材料更完整而自动上移。

D3-0至D3-4主要按实际结果划档；D3-5是高质量过程档，除安全结果外还必须有明确安排、关键力量共同接受及现实风险检验。现实风险环境例如战败或敌军压境、远离首都或军中死亡、幼主与多名顾命力量并存、储位重建、宫廷隐患或军中骚动，并须由完整终局窗口证明其没有转化为争位和军政断裂。“可能有人反对”“继承本来有风险”或普通病逝本身不算实际风险检验。当前D3-5内部只作0.15级小差距，不另设大额风险奖励。

证据等级：

- `E3_DIRECT_FULL`：安排、交接过程和即时结果均有直接材料；
- `E2_DIRECT_OUTCOME`：权力终止、实际继承和即时结果明确，结构细节不全；
- `E1_CONTINUITY_INFERENCE`：只能确认前后统治者与中央延续方式；
- `E0_UNRESOLVED`：实际掌权转换或是否形成中央继承仍有关键争议。

E1不得进入D3-5；D3-5必须为E3。E0不得生成可接受方向卡，须定向补证。材料简短不等于低等级：完整本纪或编年窗口中的“帝崩、太子即位”可以直接证明权力终止和法定继承，若窗口完整且无争位记载，可达到E2。

## 五、边界与去重

- 日常行政效率归B1；D1只看本人退出后通常不超过三年的继任行政连续性；社会恢复归C4。D3默认一年窗口只消费中央权力由谁取得、是否发生争位、暴力接管或军政分裂，不因继任行政机器后来连续或断裂重复加减分。
- 皇帝平时控制权臣、外戚或宗室的个人能力归第五项；D3只读取这些力量在交接时是否造成断裂风险。
- 同一政变或内战可以被战争、治安或人物能力项目引用；D3只消费它对中央交接安全的结果，不重复计算伤亡、军事收益或个人能力。
- 幼主、摄政、禅让和非嫡长继承均不自动降档；只有实际依赖、竞争和断裂进入裁决。禅让、太上皇、摄政退出等均以实际最高权力终止点而非名义退位日结算。
- 亡国不因继任者名义存在而自动算完成交接；须确认本政权中央确有连续运行。

## 六、方向卡接受门禁

方向卡必须覆盖当前正式评价对象全集且姓名、ID唯一；每人有唯一主档、15刻度内部指数、实际继承者、证据等级、至少一条可读史料或受约束推断理由。E0必须为零；高、中、低档和摄政、政变、战时交班、亡国样本均须抽查。JSON、链接、UTF-8无BOM、`git diff --check`和生成器幂等性必须通过。

## 七、与D1合成交接质量20分

D1与D3只按内部六档数字`0—5`等权合成，不消费两张方向卡的内部指数：

`raw = 2 × (D1_level + D3_level)`

较弱一侧执行低侧封顶：最低档为0/1/2/3/4/5时，上限依次为4/8/12/16/20/20分。最终公式为：

`handoff_20 = min(raw, low_side_cap[min(D1_level,D3_level)])`

这样，行政机器连续但最高权力交接断裂，或权力继承安全但行政机器严重断裂，都不能被另一侧高档完全冲销。正式入口为[`03-交接质量20分正式结算.md`](../../../评分结算/第二项治国净收益/政权交接稳定/03-交接质量20分正式结算.md)。
