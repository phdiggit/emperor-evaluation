# 第二项制度行政四项规则与计分合同

> A/B1/B2/D1统一规范：机制链裁主档，再定position；数量、名望与指数不反推主档。

## 一、总流程与正式换算

### 1.1 每张方向卡只执行六步

1. 确认材料是否直接回答本项问题，否则只作核验或背景。
2. 将同一制度从建立到运行、失灵和修复的过程合并，分清本人责任和正负结果。
3. 按本项标准定主档。
4. 检查足以改变结论的重要反例。
5. 扣除达到本档所需的最低配置，用剩余正负材料确定档内位置。
6. 只有可能改变档位的具体证据缺口才阻止定档，一般不足写入置信度和限制。

### 1.2 四项唯一问题

| 方向卡 | 唯一问题 | 内部指数刻度 |
|---|---|---:|
| A | 本人对关键制度的建设、修复和可运行化贡献有多大？ | 100 |
| B1 | 本人统治下官僚组织和行政执行总体是否可靠？ | 100 |
| B2 | 真实信息、异议、监督和纠错能否实际运行？ | 80 |
| D1 | 本人退出后的有限窗口内，既有行政机器是否继续实际运转？ | 30 |

四项内部指数只用于本卡档内排序和正式换算，不得直接相加。

治理手段正式合计：

`governance_method_165 = round1(0.8 × [max(A_index,B1_index) + 0.5 × min(A_index,B1_index)]) + round1(45/80 × B2_index)`

A/B1互补块与B2换算块分别四舍五入到一位小数后再相加。D1不进入165分治理手段层；D1与D3按内部档位等权合成交接质量20分，并受较弱一侧封顶。

## 二、共同证据规则

### 2.1 最小结算单元：机制链

每次评价围绕一个完整的制度运行过程：

**原有问题 → 本人举措与责任 → 实际运行 → 成效或失灵 → 纠正与延续**。

同一过程在同一项只计一次，多条引文不等于多项成果。跨项使用须分别说明直接计分事实和核验用途；A/B1合成折扣不能代替去重。

| 项目 | 直接计分命题 | 不得替代的邻项事实 |
|---|---|---|
| A | 本人改变了什么制度结构及其净价值 | 实际运行只证明落地，日常执行良好不另造建设贡献 |
| B1 | 选任、分工、协调、事务传导、替补和执行是否可靠 | 建制不代运行；反馈压制或社会受害不代组织失灵 |
| B2 | 真实信息、异议、申诉和监督是否进入决策并形成纠错或权力约束 | 一般上报、考课和办案不自动成为反馈机制 |
| C3 | 居民实际遭遇的侵害风险、基层秩序和司法保护状态 | 建制、官员表现和纳谏不代社会结果；状态裁决见财政民生合同 |

### 2.2 材料角色

| 角色 | 处理 |
|---|---|
| `score_evidence` | 直接回答本项问题，进入主档与position裁决 |
| `cross_item_verification` | 只验证机制是否真实运行，不新增本项计分链 |
| `context_only` | 背景或邻项结果，不参与本项裁决 |

民生、法律、军事结果只复验本项机制，不重复计结果。

### 2.3 皇帝归责与跨代边界

- 只归责皇帝实际授权、采纳、维持、纠正或破坏的部分，不把臣僚全部成果倒算给皇帝。
- 前代奠基、本朝重组、本人运行、后世修订分别归责；后世长期沿用不得反写为本人任内运行良好。
- A消费后世接收只为制度骨架资格与谱系归责；D1只看本人退出后的有限行政连续窗口。
- 沿用官名、任用前朝人员、一般“承前制”或政权未立即灭亡，均不能单独证明制度连续或长期影响。

### 2.4 M档：机制覆盖与闭合

M只描述本人任内的实际覆盖、持续和闭合，不描述价值或后世影响。

| M档 | 边界 |
|---|---|
| M0 | 未运行、纸面命令、单点线索、未闭合事件，或只作接收/背景证据 |
| M2 | 至少闭合一个实际运行的有限制度接口、反馈—处置链、单地区交付链或明确阶段生命周期 |
| M3 | 全国、多责任系统，或多年形成稳定激励/失灵 |

A/B1/B2无M1：未闭环M0，有限闭环M2；M3须单机制自身系统、持续或广域，不堆M2。

### 2.5 方向与结果

每条直接计分机制只保留：

- `direction`：正向 / 正向主导 / 正负相近 / 负向主导 / 负向；
- `result_closure`：未闭合 / 已观察 / 持续或系统 / 被逆转；
- `terminality`：无 / 制度断裂 / 国家机器崩解；
- A另用`reception_scope=R0—R4`判断后世接收；D1直接计分材料固定R0。

方向系数固定：

`positive=+1`，`mixed_positive=+0.5`，`mixed/neutral=0`，`mixed_negative=-0.5`，`negative=-1`。

同谱系功能阶段先合正负生命周期，再取一个M和方向；同尺度持续纠正计完整净结果。

## 三、A专项：制度谱系、S节点与C_A

### 3.1 固定执行顺序

`先分领域 → 再并制度谱系 → 再找改变谱系基线的重大节点 → 最后归责皇帝`

换名、补条、恢复和局部修订不重复计核心制度贡献；新增重大节点须核对全池同谱系。

节点先确定领域、谱系、角色（`institution_domain`、`institution_lineage`、`major_node_role`）、方向及R/M/S，人物才能引用计分；未裁记`NODE_GATE_PENDING`。

### 3.2 制度领域

`institution_domain`固定为：

中央组织；中央—地方层级；法律与司法；国家行政标准与文书；国家教育与官学；选官与官僚人事；监察反馈；户籍田制与国家资源行政；军政身份与行政动员；身份秩序与人身制度。

领域只用于归类和查漏，不直接计分。

### 3.3 重大节点角色

| `major_node_role` | 核心边界 | A中处理 |
|---|---|---|
| `FOUNDATIONAL_CREATION` | 建立此前不存在的国家级核心接口 | 正向且过R3门后，可记S |
| `MAJOR_RESTRUCTURE` | 改变既有谱系核心规则 | 正向且过R3门后，可记S |
| `MAJOR_RECONSTRUCTION` | 真实断裂后恢复旧基线 | 不记S，可支持G3，完成时`C_A=2` |
| `CANONICALIZATION` | 权威整理/成熟定型，但未改核心基线 | 不记S，可支持G3，完成时`C_A=2` |
| `MAJOR_CIVILIZATIONAL_CORRECTION` | 废除已运行的严重文明倒退制度，恢复长期基线 | 不记S，可支持G3，完成时`C_A=2` |
| `LOCAL_OR_SECONDARY_CONSTRUCTION` | 完成真实接口，但只覆盖局部/次级功能 | 不记S，通常支持G2，`C_A=1` |
| `PAPER_OR_INCOMPLETE_CONSTRUCTION` | 有创设意图但未证明机构、程序或结果运行 | 不记S，只支持G1，通常`C_A=0.5` |
| `TRANSITIONAL_RESTORATION` / `MAINTENANCE_REVISION` | 过渡恢复、换名、补条、普通维护 | 不抬主档，只作运行/背景 |

未过耐久门记`STRUCTURAL_NON_DURABLE`/`DURABILITY_EVIDENCE_PENDING`；完成建设可`C_A=2`，不独支G4。

### 3.4 正向S门禁

只有`FOUNDATIONAL_CREATION`或`MAJOR_RESTRUCTURE`且`normative_direction=positive`，同时满足以下条件，才计正向S：

1. 改变全国或中央—地方核心行政接口；
2. 形成可复制的组织、法律、选官教育、监察反馈、地方层级、户籍田制、资源行政等核心规则；
3. 本人任内至少达到M2运行；
4. 核心规则达到R3：跨多个皇帝、阶段或政权仍实际采用，且保留的是原节点改变的核心接口；
5. 建制证据与耐久证据分开：建制材料证明本人任内接口与M2/M3运行，固定R0；耐久材料只证明后继接收，固定M0、R3/R4；两组材料ID不得互相自证。

R1/R2、短期沿用、相似名称或同朝继任者继续使用，不足以计S。

### 3.5 S+、S++、S-

- 普通正向骨架：`S_plus_regular += 1`。
- 若核心规则跨多个王朝断裂仍长期保持为可识别的文明基础接口：记`S_plus_plus += 1`；S++与普通S+互斥。
- `mixed`结构节点：正向接口只有能独立运行、独立接收并单独过门时，才可拆出S；否则不计S，只保留非S重大建设与内生负向M。
- `negative`结构节点：若其核心规则以制度化伤害、特权、掠夺、任意惩罚或破坏国家接口为主，且通过通常结构/耐久门，可记普通`S-`。
- 严重文明倒退例外`SEVERE_CIVILIZATIONAL_REVERSAL`：最高权力把已长期退出国家规范的杀害、身体侵害或人格降格重新制度化，形成可重复适用且已有执行的正式规则，可记`S-`，权重按§3.6。一次暴行、临时命令、未执行倡议或一般严刑不得使用。

负向节点只归责创设者、重启者，或把既有负面机制正式化、常态化、显著扩张者；后继者一般沿袭不重复记S-。

### 3.6 A汇总字段

`S_total = S_plus_regular + S_plus_plus`

`S_depth_units = S_plus_regular + 2 × S_plus_plus`

`S_minus`：普通S−固定取1，不设S−−或权重2；严重性不单独提高负向权重。

`S_net = S_total - S_minus`

`C_A ∈ {0, 0.5, 1, 2}`：无合格建设取0，未完成尝试取0.5，完成局部/次级建设取1，独立非S重大建设、重建、定型或文明纠偏取2，角色边界见§3.3。多条次级链不得叠加成2；人物已有S时，2必须来自不同谱系。

### 3.7 A净账V2与主档

每个正式制度生命周期先算任内运行，再加耐久溢价。混合结果按正反两侧已证明的最高层级，裁为`positive=1`、`mixed_positive=0.5`、`balanced=0`、`mixed_negative=-0.5`或`negative=-1`，不能用mixed掩盖未决方向。

`M_base`固定为`M0=0、M2=1、M3=2`。逐节点：

`base_signed = M_base × direction_factor`

耐久溢价固定为：`NON_S=0、S+=+1、S++=+2、S−=-1`。因此：

`A_net_units = Σ(base_signed + durability_bonus)`

`S_net`仅诊断。R3/R4只证耐久，S另须相对前态独立重大、实际有效的核心重构；同谱系不设配额。

| 档 | 唯一边界 |
|---|---|
| G0 | `A_net_units <= 0` |
| G1 | `A_net_units = 0.5`；纯M0不加分 |
| G2 | `1 <= A_net_units < 2` |
| G3 | `A_net_units >= 2`但未过G4/G5；非S路线至少一条positive M3或两条独立positive M2 |
| G4 | 至少一条通过R3和谱系边际贡献门的正向S，且`A_net_units >= 2` |
| G5 | `A_net_units >= 6`，且满足：①至少3条独立正向S、覆盖至少2领域；或②至少2条独立S++重定两个核心接口 |

`S_net<0`阻G4/G5，不自动保/封G2；非R3、mixed或谱系拆分不堆S。统一本身不计A，只计已运行行政接口。

### 3.8 建设贡献独立评价与正负对冲说明

制度建设不因邻项低分压档，只扣A自身损害；跨项投影分别证独立后果。

`P_gross`为正节点和，`N_gross`为负节点绝对和，`A_net_units=P_gross-N_gross`；`polarization_ratio`只说明负正比，不托底档位/位置/指数。主档§3.7、位置§3.9；固定正向时增损害不得涨分。

跨≥2档先`extreme_delta_reopen=true`，复核覆盖、归并、S、生命周期、归责去重后正式，结论写人物裁决。

### 3.9 A的position

A按净余与独立结构定位置：G0 upper/middle/lower约0/-1/≤-2；G2约1/1.25/接近2；G3最低2；G4五位置约2/2.5/3/4/≥5；G5约6/7/8/9/≥10。

数值仅区间锚，不机械锁位；G4-upper另比独立接口、边际贡献、净负担与证据成熟度。

### 3.10 A正式阅读正文与逐节点投影

A保存`public_story`、`public_adjudication_summary`、`public_boundary`和`public_institution_nodes`。节点按`institution_node_id`对应`important_institutions`及三类M profile的ID并集，不按同名合并；写具体改变、本人动作、运行、后续采用及来源。无额外边界可为空，无节点不补占位材料。

公开方向和权重沿正式记录，正负分别与`P_gross`、`N_gross`同值；`public_evidence_items`逐字投影节点正文。`second-item-a-public --write`同步投影与Markdown，`second-item-a-verify`查身份、方向、权重、来源及同值。共同正文和史源要求见§9.3。

## 四、B1：官僚治理与行政执行

B1评官僚组织能否稳定交付；官名、人数、名望或盛世不能代替机制证据，跨项用途按§2.1。

### 4.1 机制链与M级

同一事件、机制阶段和责任中心合为一链，M级按§2.4裁定。

profile保存`b1_role=core/central/distributed/support/context`及权重：

- 有效M2的`abs(signed_weight)=1`，M3为2；除下述mixed例外，证据只支持1时须重裁M2，不设0.5或1.5隐藏权重。
- §4.5完整生命周期的`mixed_negative M3`可用`mixed_weight_mode=directional_half`取-1，其他mixed M3仍为2。
- 只有`absorbed/context/balanced`且`position_weight_override=0`可取零。

| 角色 | 边界与用途 |
|---|---|
| `B1-core` | 选任、考课、奖惩、替补、正式命令链、中央—地方传导，以及对这些接口的俘获 |
| `B1-central` | `B1-core`的中枢子型；看责任分工、正常事务进入、部门协调、奏行下达、替补与执行；遮蔽事实、报忧受罚及突破阻隔归B2 |
| `B1-distributed` | 至少3名独立责任官，跨地区或岗位闭合任职结果及中央识别后的迁升、再配置或淘汰 |
| `B1-support` | 赈灾、仓储、一般司法、流民安置、水利、漕运、税粮物流等支撑交付 |
| `verification/context` | 只有制度设置、单纯结果、史赞或邻项事实，未闭合B1组织机制；不直接计M |

central M2须闭合“事务进入—责任处理/协调—正式决定/人员动作—执行结果”；M3另证持续传递与组织交付，官员久任不够。同名臣的人事链与中枢链不得重复计分；作G4主链仍须§4.3跨层传导。

distributed M3用于G3强验证或G4第二验证；有独立中央选任、考课、奖惩机制串联，才可转为core M3。support多层重复运行可达M3，但只作独立第二验证或多链辅助，不能单独支持G3/G4。

### 4.2 B1主档

| 档 | 唯一边界 |
|---|---|
| G0 | 多个核心功能面达到`N3-terminal`，广域行政链整体失效 |
| G1 | `N3-cross`或多条`N3-domain`支配主要阶段、压倒独立正向行政主链，使失能成为总体主导；或terminal仍有足够行政残存 |
| G2 | 有真实选任或行政交付，但覆盖、持续、替补不足；或可用与俘获并存 |
| G3 | 主要阶段总体可用；至少一条代表性core M3；或一条完整central/distributed M3强验证；或至少2条独立M2/M3与结果复验共同闭合 |
| G4 | 达到G3后，通过合格主M3与独立第二验证；同尺度负链未击穿主要阶段可靠性 |
| G5 | 达到G4后，再有一项未被G4重复消费的比较域罕见可靠性证明 |

亡国、战败或宏观盛衰不代机制；小政权广域按主要统治区与责任层级。

G3保存`g3_gate_route=CORE_M3 / CENTRAL_OR_DISTRIBUTED_M3 / MULTI_CHAIN`及`g3_gate_profile_ids`；多链可用M2/M3，验证器不得缩减合格路线。

### 4.3 G4与G5门禁

G4须同时满足：

1. 一条`B1-core M3`证明部署经过实际执行和跨层级传递，产生可观察结果。
2. 另一条独立的M2/M3，证明选任替补、考课问责或不同领域的实际交付；不要求它也是core。
3. 主要阶段总体可用，没有仍独立计权的`major-stage/broad N3-cross`，也没有同尺度负M3破坏主要运行机制。

`mixed_positive M3`的负面阶段若直接打坏同一核心机制，不能独自承担G4主证；生命周期合并按§4.5。

单个`N3-domain`不自动封顶G3。要据此否定G4，须说明哪条必要机制受到何种组织损害；未达到这一程度的负面材料仍计入净余量。正面条件缺失与已证负面事实分开处理。

G5先满足G4，再增加以下一种验证：

1. 第三条功能、因果均独立的M3，使另一个核心官僚功能可靠运行；同一过程深化或support结果不算。
2. 同一体系跨明显阶段、长期人员替补或强臣退出后，仍有实际交付。
3. 战争、灾荒、继承或高强度财政行政压力下，执行未中断，或有独立的备用、恢复及替补能力。

已用于G4的材料不再用于G5，D1/D3交班事实也不作B1升档依据。`major-stage/broad N3-cross`或terminal原则上阻止G5，只有本人窗口内完成恢复并已去重才重审。

门槛依据保存为：G3用`g3_core_profile_id`，无core M3时至少列2个`g3_m2_profile_ids`；G4用`g4_core_profile_id + g4_secondary_profile_id`；G5另列`g5_extra_basis_id`。引用须为去重后仍计权的正向M2/M3；core引用必须确为`b1_role=core`，不得以重复占位或改名满足门槛。

### 4.4 Severity与范围

| Severity | 边界 |
|---|---|
| `N3-domain` | 一个B1核心功能系统失灵 |
| `N3-cross` | 至少两个独立B1核心功能面相互强化失灵 |
| `N3-terminal` | 多功能、广域行政链整体失效 |

cross须证明至少两个真实组织功能受损；异议被逐、罗织刑讯造成的程序破坏、受害和恐惧，不能换名拆成多个功能，剥离B2事实后仍须证明任职、职责、替补或执行损害。正向复验也须去重。

独立负M3必须同时保存表中`severity`及`severity_scope=localized/major-stage/broad`，缺一阻止写入。cross的后两种范围原则上阻G4，localized仅在击穿主链时阻档。broad不等于terminal，后者须多个正式接口广域、常态失效。政策失败、战败或民生损害本身不生成负M3；mixed按§4.5处理。

G0须至少两个核心功能terminal，或一条多功能广域terminal，并按阶段代表性裁定；至少一条有效负M3满足`b1_role=core、severity=N3-terminal、severity_scope=broad`。G1须有行政残存的terminal、主要阶段/广域cross，或两条独立主要阶段/广域domain。仅M0/context、单localized/domain或无有效链均不支持G0/G1；删除、降级负链后须重验主档。

### 4.5 B1/B2、归责与材料边界

跨项用途按§2.1；同源不同事实可分别使用，同一次封还、纳谏、拒谏或改命不能在B1/B2双计。

B1归责使用`direct_control`、`active_delegation`、`passive_inheritance`或`externalized_power`。摄政期同一事实只归一个直接责任中心；名义君主不能继承摄政主链，长期外置百司处理权也不能取得central M3。

“授权—俘获—本人窗口内清算并完成替补恢复”合为一个mixed生命周期：不另标俘获Severity、不二次修正、不把俘获另计cross负链，也不以清算增加G5压力信用。只有未恢复或已扩散到独立责任中心，才保留独立负链。

计分材料登记“人物:B1”角色，新增材料补证原链。建制、纸面考课、后世接收和继任者撤项默认作context，未查到长期结果不算负证。

## 五、B2：反馈纠错与权力约束

B2只看真实信息能否上达、异议者能否安全履职、监督能否约束高官/最高权力，以及错误是否得到实际纠正。

一般司法办案与正常事务上报不直接计B2；须证明申诉、复核、异议或监督实际纠错，或其通道被压制、取消。严刑、冤狱和政治清洗本身不足以证明反馈失灵，须闭合反馈角色、受阻接口或因反馈受罚的关系。司法组织执行归B1，居民实际受害及救济归C3；同次复核的纠错事实与受保护结果分别按§2.1处理。

| 档 | 唯一边界 |
|---|---|
| G0 | 报忧、监督或异议渠道被系统惩罚和封闭，国家机器严重失知或崩坏 |
| G1 | 只有形式渠道/未闭合陈述，或拒谏、报复、构罪与纠偏复发在主要阶段占主导 |
| G2 | 至少一条真实反馈—处置—纠偏链闭合，但重复性、持续性或独立性未证明；或正负重要阶段并存 |
| G3 | 反馈和监督在主要阶段实际运行，错误能够纠正，反对者通常可安全履职 |
| G4 | 多种独立渠道反复约束高官和最高权力，且基层/外朝信息能跨层级上达 |
| G5 | 达到G4后，多渠道纠错在广度、重复性、阶段覆盖和实际结果上形成比较域罕见水平 |

三类角色分别记录：`information_ingress`是信息上达，`sovereign_self_correction`是君主改策，`external_constraint`是外部角色、机构或程序实际改变最高权力偏好。前两者不能代替外部约束。

单次采纳、赦免进言者或因谏改令通常最多G2；故事数量不直接拼G3，但三个不同领域的纠错事件可入G3。G4至少两种独立渠道反复有效，其中至少一条外部约束、一条基层或外朝信息越过常规阻隔上达，并完成同尺度负例检索。G5再证多渠道、重复性及主要阶段覆盖达到比较域罕见水平，同链多次展示不重复计数。

### 5.1 B2公开裁决正式投影

`public_adjudication_summary`与`public_evidence_items`写明意见、提出者、本人处置、结果和限制，条目保留稳定ID、标题、方向、标签、正文、边界及史源。按正式机制身份对应，不按人物、朝代或关键词猜合并。

只有整组无有效评价阶段才标背景；部分不另计，不能说整条机制不计。仅证设置或一般行政结果的材料不改写成已纠错，缺证不写成负面事实。

`second-item-b2-public --write`保留正文、刷新结构，`second-item-b2-verify`查覆盖、身份、方向、阶段及来源；共同要求见§9.3。

## 六、D1：继任行政连续性

D1评价退出后的行政续行，对象、窗口、H0—H5及证据条件统一见[政权交接合同](../政权交接稳定/00-规则与结算合同.md#d1继任行政连续性)，不在本合同另设档表。

方向卡用`handoff_level=H0—H5`，只支持同号G档；直接计分材料`reception_scope=R0`，长期接收不反写即时交班。档内位置及内部指数按下节，正式20分合成按交接合同。

## 七、position与方向指数

### 7.1 五级position

| position | 净余量边界 | 档内锚点q |
|---|---:|---:|
| lower | `< -1` | 0.1 |
| lower-middle | `[-1,0)` | 0.3 |
| middle | `[0,1)` | 0.5 |
| middle-upper | `[1,2)` | 0.7 |
| upper | `>= 2` | 0.9 |

A的position按§3.9；G0零机制例外固定middle。

B1/B2使用：

`净余量 = Σ(M权重 × 方向系数) - 本档门槛占用`

B1的M权重为`M0=0，M2=1，M3=2`，再乘方向系数；`position_weight_override=0`、`absorbed_same_lifecycle`、`context_only`链不进入净余量，不使用`position_depth_bonus`或人物手工position例外。

B1仅对去重后仍独立的负M3追加Severity修正：`N3-domain=0`、`N3-cross=-0.5`、`N3-terminal=-1.0`。

门槛占用：

| 项目 | G0 | G1 | G2 | G3 | G4 | G5 |
|---|---:|---:|---:|---:|---:|---:|
| B1 | 0 | 0.5 | 1 | 2 | 3 | 4 |
| B2 | 0 | 0.5 | 1 | 1.5 | 2 | 2 |

G1的0.5只是档内完成度占用，不代表存在M1。

D1主档由H决定，position只消费继任窗口内去重后的正负M配置。

### 7.2 方向指数

统一归一化区间：

| 档 | 占比区间 | A/B1（100） | B2（80） | D1（30） |
|---|---:|---:|---:|---:|
| G0 | 0%—19.9% | 0—19.9 | 0—15.9 | 0—5.9 |
| G1 | 20%—39.9% | 20—39.9 | 16—31.9 | 6—11.9 |
| G2 | 40%—54.9% | 40—54.9 | 32—43.9 | 12—16.4 |
| G3 | 55%—69.9% | 55—69.9 | 44—55.9 | 16.5—20.9 |

| G5 | 85%—100% | 85—100 | 68—80 | 25.5—30 |

`direction_index = L + q × (U-L)`

### 7.3 跨档一致性审计

低档在同尺度正反证、独立性和完整性上全面强于高档时，须说明高档独有的准入事实，否则重裁；数量和M总量只筛异常。同类core与Severity配置若无真实核心机制、范围或独立复验差别，只在position区分，不因文字写法跨档。

## 八、缺证、反例与检索停止

### 8.1 反例原则

领域内M3负向先限该领域，跨核心领域或足以证明整体失效才封顶子项。M0不参与冲销，多个M2不能靠数量抵消未纠正的M3。负证用于三个以上子项时，逐项说明作用，否则只作跨项核验。

### 8.2 检索停止

查代表正向、同尺度反例、显著漏项和D1窗口；满足任一条件即停止同质搜索：

- 主要阶段/范围已覆盖，新材料不会改变主档、S数或同尺度反例；
- 系统性或终局负向已证，只剩同类小案；
- 正反两侧已足以稳定主档；
- 定向检索完成，未发现可改档合格材料。

新系统漏项先全池筛查再审命中，不能只补点名人物。早期B1须查循吏、能吏及臣传等价功能词，负证对应责任年份；时代只改变检索用词，不降低归责或准入标准。

### 8.3 缺证状态

缺料不等零或负；仅具体“补何事实将改哪档”记`CALIBRATION_BLOCKED`。

A零机制`OBSERVED_NO_ELIGIBLE_MECHANISM`须公共登记、至少两类独立固定史源、A定向与必要接收检索均完成，且无不可得来源/未裁候选；否则`UNOBSERVED_BLOCKED`。

B1、B2、D1不适用零机制例外。

## 九、输出与接受门禁

### 9.1 每卡最小输出

- 人物、朝代、子项、主档、position、方向指数；
- A：`S_plus_regular/S_plus_plus/S_total/S_minus/S_net/S_depth_units/C_A`、逐节点V2净值、`A_net_units/P_gross/N_gross`、正负对冲说明与极端跳档复核字段、主档门槛链；
- B1/B2：正负M配置、门槛占用、最终净余量；
- B1另输出机制链角色、归责类型；负M3存在时输出Severity及`localized/major-stage/broad`范围；G4/G5写明门槛链与独立复验；
- D1：H值、同号G档、继任窗口内的实际连续/断裂结果；
- 一句主导正向、主导负向或“无同尺度反例”；
- 覆盖状态、置信度、具体改档缺口；
- 所有直接计分材料ID必须可回源。

B1另保存`public_story`、`public_responsibility`、`public_adjudication_summary`，分别写经历、本人责任时期、定档理由和限制。`public_evidence_items`逐字投影材料正文并保留材料/profile标识；`public_index_calculation`只按当前权重、Severity修正、固定占用及区间公式生成。共同要求见§9.3。

A若使用`OBSERVED_NO_ELIGIBLE_MECHANISM`，输出负向检索审计ID、已读固定页和题级状态，不虚构直接计分材料。

### 9.2 方向卡接受门禁

正式接受前核对：

1. 当前比较域每人都有A/B1/B2/D1卡，身份唯一，直接计分材料已登记且可追溯。
2. 同一机制已合并去重，跨项用途和本人责任清楚；B1的角色、摄政阶段、负面影响范围及独立验证符合第四节。
3. A按制度生命周期执行V2净账、边际贡献及正负S的对称要求。建设贡献独立判断，正负抵消后不额外托底；程序只验算，不从姓名或旧值推定结论。
4. D1按H值定主档，长期制度影响不代替即时交班；足以改变档位的证据问题已有处理结论。
5. JSON可解析、UTF-8无BOM，人数与当前比较域一致，165分治理手段可重复计算。正式结果使用治理手段165分或交接质量20分，不把方向卡内部指数当作独立分值。

### 9.3 共同公开正文与史源要求

正文按当前裁决与有效史源直接撰写，不从材料数量、权重、通用模板或关键词生成。卡片名称、事实、责任时期和采用范围须一致；缺必要正文或来源时停止，不自动补写。

来源对应原材料路径、材料ID、标题、定位、链接及引文，JSON引用落实到具体材料或人物节点，不补造来源。外部链接只查格式，不声称已联网验证。各页面使用同一完整解释，先讲人物和依据，再展开计算与原始引文；阅读层不改写事实、删除限制。公开维护不改档位、位置、权重或分数。

## 十、正式晋升异常门禁（G6）

新批次晋升前固定裁决作联动回放，只查偏差，不设朝代配额或目标榜形：

1. 民生财政C1/C2曲线：与当前比较域对照，查异常平坦、整批同向偏高/低、两轴严重背离却无机制解释。
2. 公共制度节点：查总量、人均、同谱系拆分和S节点。异常集中或密度突变时，核对是否将材料行、配套、维护恢复或人物组合误拆成公共节点。
3. 晋升后总榜：重算全榜，检查头部人数、全距、四分位距和窄区间聚集；异常只触发证据、公式和去重复核。

保留输入哈希、比较域人数、本批覆盖、三类分布摘要、异常解释、需回查人物及`PASS/BLOCKED`。结构检查不代替语义裁决。
