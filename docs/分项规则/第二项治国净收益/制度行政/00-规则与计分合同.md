# 第二项制度行政四项规则与计分合同

> 状态：本合同统一约束A、B1、B2、D1方向卡裁决及正式换算。规则以机制链为最小单元；主档先裁、position后定；材料条数、人物名望和公式均不得反推主档。

## 一、总流程与正式换算

### 1.1 每张方向卡只执行六步

1. **定项**：材料是否直接回答本卡问题；否则降为跨项核验或背景。
2. **归责去重**：按完整机制链合并同质材料，确认皇帝责任、方向与生命周期。
3. **定主档**：只按本合同对应的G0—G5档表裁定，不按材料数量或指数公式生成主档。
4. **查反例**：只检查足以改变主导结论的同尺度反例；小案不得累计调档。
5. **定position**：扣除本档最低充分配置后，以独立净余量映射五级位置。
6. **判收口**：只有“补成某事实会改变某档”的具体缺口才阻断；一般材料不足只降低置信度。

### 1.2 四项唯一问题

| 方向卡 | 唯一问题 | 内部指数刻度 |
|---|---|---:|
| A | 本人对关键制度的建设、修复和可运行化贡献有多大？ | 100 |
| B1 | 本人统治下官僚组织和行政执行总体是否可靠？ | 100 |
| B2 | 真实信息、异议、监督和纠错能否实际运行？ | 80 |
| D1 | 本人退出后的有限窗口内，既有行政机器是否继续实际运转？ | 30 |

四项内部指数只用于本卡档内排序和正式换算，不得直接相加。

治理手段正式合计：

`governance_method_165 = round1(0.8 × [max(A_index,B1_index) + 0.5 × min(A_index,B1_index)]) + round1(45/80 × B2_index)`

A/B1互补块与B2换算块分别四舍五入到一位小数后再相加。D1不进入165分治理手段层；D1与D3按内部档位等权合成交接质量20分，并受较弱一侧封顶。

## 二、共同证据规则

### 2.1 最小结算单元：机制链

最小单元不是官名、诏令、人物或史料篇章，而是：

`问题基线 → 举措 → 皇帝归责 → 实际运行 → 结果/失灵 → 纠正 → 延续/接收`

同一机制在同一子项只计一次。多个引文、同质命令、同一制度的不同展示节点不得按条数累加。同一机制可投影多个子项，但每个投影都必须说明它直接回答了该项什么问题。

### 2.2 材料角色

| 角色 | 处理 |
|---|---|
| `score_evidence` | 直接回答本项问题，进入主档与position裁决 |
| `cross_item_verification` | 只验证机制是否真实运行，不新增本项计分链 |
| `context_only` | 背景或邻项结果，不参与本项裁决 |

财政民生、法律、军事等结果只有在能证明本项制度、执行或反馈机制时才可复验；其本身不得在制度行政重复计分。

### 2.3 皇帝归责与跨代边界

- 只归责皇帝实际授权、采纳、维持、纠正或破坏的部分，不把臣僚全部成果倒算给皇帝。
- 前代奠基、本朝重组、本人运行、后世修订分别归责；后世长期沿用不得反写为本人任内运行良好。
- A消费后世接收只为制度骨架资格与谱系归责；D1只看本人退出后的有限行政连续窗口。
- 沿用官名、任用前朝人员、一般“承前制”或政权未立即灭亡，均不能单独证明制度连续或长期影响。

### 2.4 M档：机制覆盖与闭合

M只描述本人任内的实际覆盖、持续和闭合，不描述价值或后世影响。

| M档 | 边界 |
|---|---|
| M0 | 未运行、纸面命令、单点线索、未闭合事件，或只作接收/背景证据 |
| M2 | 至少闭合一个实际运行的有限制度接口、反馈—处置链、单地区交付链或明确阶段生命周期 |
| M3 | 全国、多责任系统，或多年形成稳定激励/失灵 |

A/B1/B2中`M1`非法：未形成最低闭环归M0；形成有限闭环直接归M2。M3必须由单条机制自身达到系统性、持续性或广域闭合，不得由多条M2或材料数量凑成。

### 2.5 方向与结果

每条直接计分机制只保留：

- `direction`：正向 / 正向主导 / 正负相近 / 负向主导 / 负向；
- `result_closure`：未闭合 / 已观察 / 持续或系统 / 被逆转；
- `terminality`：无 / 制度断裂 / 国家机器崩解；
- A另用`reception_scope=R0—R4`判断后世接收；D1直接计分材料固定R0。

方向系数固定：

`positive=+1`，`mixed_positive=+0.5`，`mixed/neutral=0`，`mixed_negative=-0.5`，`negative=-1`。

同一谱系、功能和阶段的正负事实必须先合成一个生命周期，再取一个M与一个方向；不得正负双计。重大负向若已被同尺度、持续纠正真正逆转，按完整生命周期裁定。

## 三、A专项：制度谱系、S节点与C_A

### 3.1 固定执行顺序

`先分领域 → 再并制度谱系 → 再找改变谱系基线的重大节点 → 最后归责皇帝`

同一谱系的换名、补条、恢复颁行、局部修订和一般维护不得重复领取国家骨架。新发现合格重大节点时，应对当前正式比较域做同谱系横向筛查。

节点登记层统一裁定：`institution_domain`、`institution_lineage`、`major_node_role`、方向、R值、M值及S资格。人物结算层只消费已统一裁定节点；节点未裁定时输出`NODE_GATE_PENDING`。

### 3.2 制度领域

`institution_domain`固定为：

中央组织；中央—地方层级；法律与司法；国家行政标准与文书；国家教育与官学；选官与官僚人事；监察反馈；户籍田制与国家资源行政；军政身份与行政动员；身份秩序与人身制度。

领域只用于归类和查漏，不直接计分。

### 3.3 重大节点角色

| `major_node_role` | 核心边界 | A中处理 |
|---|---|---|
| `FOUNDATIONAL_CREATION` | 建立此前不存在的国家级核心接口 | 正向且过R3门后，可记S |
| `MAJOR_RESTRUCTURE` | 改变既有谱系核心规则 | 正向且过R3门后，可记S |
| `MAJOR_RECONSTRUCTION` | 真实断裂后恢复旧基线 | 不记S，可支持G3，完成时`C_A=2` |
| `CANONICALIZATION` | 权威整理/成熟定型，但未改核心基线 | 不记S，可支持G3，完成时`C_A=2` |
| `MAJOR_CIVILIZATIONAL_CORRECTION` | 废除已运行的严重文明倒退制度，恢复长期基线 | 不记S，可支持G3，完成时`C_A=2` |
| `LOCAL_OR_SECONDARY_CONSTRUCTION` | 完成真实接口，但只覆盖局部/次级功能 | 不记S，通常支持G2，`C_A=1` |
| `PAPER_OR_INCOMPLETE_CONSTRUCTION` | 有创设意图但未证明机构、程序或结果运行 | 不记S，只支持G1，通常`C_A=0.5` |
| `TRANSITIONAL_RESTORATION` / `MAINTENANCE_REVISION` | 过渡恢复、换名、补条、普通维护 | 不抬主档，只作运行/背景 |

未通过长期门禁的结构性候选标记`STRUCTURAL_NON_DURABLE`或`DURABILITY_EVIDENCE_PENDING`：仍计建设贡献，完成时可取`C_A=2`，但不得单独支持G4。

### 3.4 正向S门禁

只有`FOUNDATIONAL_CREATION`或`MAJOR_RESTRUCTURE`且`normative_direction=positive`，同时满足以下条件，才计正向S：

1. 改变全国或中央—地方核心行政接口；
2. 形成可复制的组织、法律、选官教育、监察反馈、地方层级、户籍田制、资源行政等核心规则；
3. 本人任内至少达到M2运行；
4. 核心规则达到R3：跨多个皇帝、阶段或政权仍实际采用，且保留的是原节点改变的核心接口；
5. 建制证据与耐久证据分开：建制材料证明本人任内接口与M2/M3运行，固定R0；耐久材料只证明后继接收，固定M0、R3/R4；两组材料ID不得互相自证。

R1/R2、短期沿用、相似名称或同朝继任者继续使用，不足以计S。

### 3.5 S+、S++、S-

- 普通正向骨架：`S_plus_regular += 1`。
- 若核心规则跨多个王朝断裂仍长期保持为可识别的文明基础接口：记`S_plus_plus += 1`；S++与普通S+互斥。
- `mixed`结构节点：正向接口只有能独立运行、独立接收并单独过门时，才可拆出S；否则不计S，只保留非S重大建设与内生负向M。
- `negative`结构节点：若其核心规则以制度化伤害、特权、掠夺、任意惩罚或破坏国家接口为主，且通过通常结构/耐久门，可记普通`S-`。
- 严重文明倒退例外`SEVERE_CIVILIZATIONAL_REVERSAL`：最高权力把已长期退出国家规范的杀害、身体侵害或人格降格重新制度化，形成可重复适用且已有执行的正式规则，可记严重`S-`，权重2。一次暴行、临时命令、未执行倡议或一般严刑不得使用。

负向节点只归责创设者、重启者，或把既有负面机制正式化、常态化、显著扩张者；后继者一般沿袭不重复记S-。

### 3.6 A汇总字段

`S_total = S_plus_regular + S_plus_plus`

`S_depth_units = S_plus_regular + 2 × S_plus_plus`

`S_minus`：普通S−固定取1。本版不设S−−或权重2；性质极恶劣但直接制度覆盖有限的宫妃殉葬也按普通S−计。

`S_net = S_total - S_minus`

`C_A ∈ {0, 0.5, 1, 2}`：

- 0：无合格建设；
- 0.5：未完成尝试；
- 1：完成的局部/次级建设；
- 2：独立的非S重大建设、重建、定型或重大文明纠偏。

多条次级链不得叠加成`C_A=2`。人物已有S时，`C_A=2`必须来自与S不同谱系的独立非S重大建设。

### 3.7 A净账V2与主档

A先对每个canonical生命周期计算本人任内运行值，再追加耐久溢价。`mixed`必须按同一生命周期两侧最高闭合层级裁成`positive=1`、`mixed_positive=0.5`、`balanced=0`、`mixed_negative=-0.5`或`negative=-1`；不得用`mixed`表示短命、复杂或未判完。

`M_base`固定为`M0=0、M2=1、M3=2`。逐节点：

`base_signed = M_base × direction_factor`

耐久溢价固定为：`NON_S=0、S+=+1、S++=+2、S−=-1`。因此：

`A_net_units = Σ(base_signed + durability_bonus)`

`S_net`只保留为耐久结构诊断，不直接代入净账。R3/R4只证明耐久资格；S还必须另过谱系边际贡献门，证明相对前态发生独立、重大且实际运行有效的核心制度重构。同一谱系不设S配额，也不得由R3/R4自动生成S。

| 档 | 唯一边界 |
|---|---|
| G0 | `A_net_units <= 0` |
| G1 | `A_net_units = 0.5`；纯M0不加分 |
| G2 | `1 <= A_net_units < 2` |
| G3 | `A_net_units >= 2`但未过G4/G5；非S路线至少一条positive M3或两条独立positive M2 |
| G4 | 至少一条通过R3和谱系边际贡献门的正向S，且`A_net_units >= 2` |
| G5 | `A_net_units >= 6`，且满足：①至少3条独立正向S、覆盖至少2领域；或②至少2条独立S++重定两个核心接口 |

`S_net<0`阻断G4/G5，但不再自动封顶或保底G2。多个未过R3门、mixed节点或同一谱系拆分不得靠数量替代S。统一战争、疆域取得和消灭割据本身不计A；只计统一后实际建立并运行的行政接口。

### 3.8 建设贡献独立评价与正负对冲说明

保留任内运行与建设—接收两条路径。真实、独立的制度建设贡献不因B1行政执行、B2反馈纠错或财政民生表现较差而直接压档；只有属于A自身的制度损害才进入A负账。同一事件的不同投影必须分别说明独立后果，不得把邻项已消费的同一后果重复扣入A。

`P_gross`为去重后正向节点值之和，`N_gross`为负向节点值绝对值之和，`A_net_units = P_gross - N_gross`。高强度正负对冲保留为裁决说明，`polarization_ratio`仅描述负正比；正负规模及其比例不托底主档、档内位置或内部指数。主档执行3.7，档内位置执行3.9。固定正向贡献时，增加制度损害不得使主档或内部指数上升。

任一修订导致主档跨越至少2档时，先置`extreme_delta_reopen=true`，完成材料覆盖、机制合并、S资格、生命周期、归责及跨项去重复核后才可转为正式；复核结论写入人物裁决，不以结构校验代替。

### 3.9 A的position

A以完整净余和独立结构质量定position，不再使用旧`2×S_net + S_plus_plus + C_A/2`结构厚度。数值锚点：G0的upper/middle/lower约为0/-1/≤-2；G2的lower/middle/upper约为1/1.25/接近2；G3以2为最低净值；G4的lower/lower-middle/middle/middle-upper/upper约为2/2.5/3/4/≥5；G5约为6/7/8/9/≥10。

数值只给区间锚点，不机械锁position。尤其G4-upper还必须横向比较独立核心接口数量、节点边际贡献、净负担与证据成熟度；当前以赵匡胤为上沿结构锚点，李世民作为“净值达到6但结构不足upper”的反例。

## 四、B1：官僚治理与行政执行

B1唯一问题：**本人统治下，官僚组织能否把最高权力的政策与国家任务稳定转化为可观察的行政交付；选任、考课、奖惩、替补和中央—地方传导总体是否可靠？**

B1不评价制度原创性，不因官名、机构数量、个别名臣、统治名望或宏观盛世本身加档。财政民生、司法、军事等结果只有在能直接复验官僚运行或执行机制时才进入B1；制度建制、后世延续、单纯政策结果、反馈纠错本身否则仅作A/B2/D1或跨项核验。

### 4.1 机制链与M级

同事件、同机制、同阶段、同责任中心先合并为一个生命周期，再裁一次方向与M：`M0`为纸面设置、单点线索或未闭合；`M2`为至少一条真实但有限的运行闭环；`M3`为单条机制自身达到多年稳定、广域或多责任系统闭合。B1不使用M1，多条M2不得相加成M3。

正式profile必须写入`b1_role=core/central/distributed/support/context`。有效`M2`的`abs(signed_weight)`固定为1，有效`M3`固定为2；但同一完整生命周期已合并“授权/俘获→清算→替补恢复”且裁为`mixed_negative`时，只有明确标记`mixed_weight_mode=directional_half`的M3才按方向系数保留`-1`，并且不得再附加独立Severity修正。其他mixed M3仍为2。只有`absorbed/context/balanced`且显式`position_weight_override=0`的profile可以为零。不得以历史兼容或人物横校保留0.5、1.5等隐藏权重；若现有材料只支持1单位且并非上述完整mixed生命周期，必须先重裁为M2。

| 角色 | 边界与用途 |
|---|---|
| `B1-core` | 选任、考课、奖惩、替补、正式命令链、中央—地方传导，以及对这些接口的俘获 |
| `B1-central` | `B1-core`的中枢子型；看责任分工、信息进入、部门协调、奏行下达、替补与执行 |
| `B1-distributed` | 至少3名独立责任官，跨地区或岗位闭合任职结果及中央识别后的迁升、再配置或淘汰 |
| `B1-support` | 赈灾、仓储、一般司法、流民安置、水利、漕运、税粮物流等支撑交付 |
| `verification/context` | 只有制度设置、单纯结果、史赞或邻项事实，未闭合B1组织机制；不直接计M |

`B1-central M2`至少闭合一次“事务/信息进入 → 明确责任中心处理或协调 → 正式决定/人员动作 → 执行或组织结果”。`B1-central M3`还须证明真实路由持续或重复运行，并有积务处理、跨部门决遣、号令落地或替补后不中断等组织结果；官名、久任、“总百司”“参机务”本身不够，同一名臣的人事链与中枢链不得换标题重复计分。central M3不自动成为G4主链，仍须闭合4.3的跨层或多责任传导。

`B1-distributed M3`默认只承担G3强验证或G4第二验证；只有样本由同一套反复运行的中央选任—考课—奖惩机制串联，且共同机制有独立运行证据，才升级为`distributed→core M3`。`B1-support`在闭合多层责任、重复运行与结果时可裁M3，但不能单独承担G4主链。

### 4.2 B1主档

| 档 | 唯一边界 |
|---|---|
| G0 | 多个核心功能面达到`N3-terminal`，广域行政链整体失效 |
| G1 | `N3-cross`或多条`N3-domain`支配主要阶段、压倒独立正向行政主链，使失能成为总体主导；或terminal仍有足够行政残存 |
| G2 | 有真实选任或行政交付，但覆盖、持续、替补不足；或可用与俘获并存 |
| G3 | 主要阶段总体可用；至少一条代表性core M3；或一条完整central/distributed M3强验证；或至少2条独立M2/M3与结果复验共同闭合 |
| G4 | 达到G3后，通过合格主M3与独立第二验证；同尺度负链未击穿主要阶段可靠性 |
| G5 | 达到G4后，再有一项未被G4重复消费的比较域罕见可靠性证明 |

亡国、战败、财政耗竭、民生惨状、首都陷落和宏观盛衰均不能代替B1机制门禁。小政权的广域按其主要有效统治区与责任层级判断。

G3多链路线中的单链可以是M2或M3；M3不得仅因高于M2而被排除。support M3可以作为多链组合中的一条，但单条support M3不能独担G3，也不能承担G4主core。正式JSON分别登记`g3_gate_route=CORE_M3 / CENTRAL_OR_DISTRIBUTED_M3 / MULTI_CHAIN`及`g3_gate_profile_ids`，validator不得另行缩窄合同路线。

### 4.3 G4与G5门禁

G4必须同时满足：

1. 一条合格`B1-core M3`闭合“部署 → 执行主体 → 跨层或多责任层级传导 → 可观察结果”；
2. 另一条因果独立的选任/替补、考课/问责或不同领域实际交付M2/M3；第二验证不要求第二条core；
3. 主要阶段总体可用，不存在仍独立计权的`major-stage/broad N3-cross`，且同尺度负M3未击穿主链；若本人窗口内已经完成恢复，必须先把“授权/俘获 → 清算 → 替补恢复”合并为一个mixed生命周期，不能一边保留独立cross、一边放行G4。

`mixed_positive M3`若负段直接击中同一核心机制，不能单独承担G4主链。废止绕过统一条件的人物特例。

G5只能在G4配置之外新增下列一项：

1. 第三条功能与因果均独立的M3系统链；该链还须形成另一核心官僚功能面的系统性可靠运行，不能仅以同阶段多领域交付、support结果或同一生命周期的深化材料凑足；
2. 同一官僚体系跨明显阶段、长期替补或强臣退出后仍维持可观察交付；
3. 战争、灾荒、继承转换或高强度财政行政压力下，原执行链不中断，或完成独立冗余、恢复与替补。

G4已经消费的链、压力或结果不得在G5重复使用；“体系很深”“名臣很多”“长期治绩好”不是独立路径，旧“深度型G5”废止。继承安排、交班、摄政归政和继任者承接等D1/D3事实不得用于B1升档或G5复验。

存在`major-stage/broad N3-cross`或`N3-terminal`者原则上不得进入G5；只有先证明该负链已在本人责任窗口内完成独立恢复、且恢复生命周期没有被G4或G5其他路径重复消费时，才可重新审查。G5第三M3路线必须在正式记录中明确写入`g5_extra_basis_id`，不得只以正文声称“第三链”或“跨阶段”代替机器门禁。

正式记录的G3须写入`g3_core_profile_id`，或在无core M3时写入至少2个去重后的`g3_m2_profile_ids`；G4须写入`g4_core_profile_id + g4_secondary_profile_id`；G5须再写入`g5_extra_basis_id`。被引用profile必须是去重后仍计权的正向M2/M3，且各门禁引用不得指向同一生命周期。`g3_core_profile_id`和`g4_core_profile_id`必须指向`b1_role=core`；`central/distributed/support`不得仅因被门禁字段引用而反向取得core身份，`support`只能承担独立第二验证或多链辅助路线。

### 4.4 Severity与范围

| Severity | 边界 |
|---|---|
| `N3-domain` | 一个B1核心功能系统失灵 |
| `N3-cross` | 至少两个独立B1核心功能面相互强化失灵 |
| `N3-terminal` | 多功能、广域行政链整体失效 |

同一批“因异议被逐”的事实不能换名为“人事稳定 + 官僚安全”制造cross；剥离B2的拒谏、惩谏切片后，必须写明第二个真实B1组织功能面。`N3-cross`继续标记`localized`、`major-stage`或`broad`；major-stage/broad原则阻G4，localized只有击穿主链时阻档。broad cross不自动等于terminal，只有多条正式接口普遍不能传递信息、替补问责、执行命令或维持广域常态处理时才裁terminal。

除完整`mixed_negative`生命周期外，所有有效负M3必须同时输出`severity=N3-domain/N3-cross/N3-terminal`与`severity_scope=localized/major-stage/broad`；任一缺失均阻止正式写入。mixed生命周期不得把其俘获段另标独立Severity。Severity只按已闭合的B1组织功能面裁决，政策残酷、财政损失、司法结果、战争失败或民生损害本身不得直接生成B1负M3。

G0须由直接材料闭合至少两个核心功能面的terminal失效，或一条明确覆盖多功能并造成广域行政崩解的terminal机制；仍须结合阶段与时间占比裁主档。

低档同样实行必要条件门禁：G0必须至少引用一条`b1_role=core、severity=N3-terminal、severity_scope=broad`的有效负M3；G1必须至少存在一条仍有行政残存的terminal、一条覆盖主要阶段或广域的`N3-cross`，或至少两条生命周期独立且覆盖主要阶段/广域的`N3-domain`。正负均无有效M链、只有context/M0、只有一条localized/domain负链者均不得保留G0/G1；删除或降级负链后必须重新执行主档门禁，禁止沿用旧grade。

### 4.5 B1/B2、归责与材料边界

- B1消费机器如何分工、任免、替补、传递和执行；B2消费异议能否上达、皇帝是否受约束并实际改意。同一来源可共享，不同事实切片可分别使用；同一次封还、纳谏、拒谏或改命不得双计。
- B1归责固定为`direct_control`、`active_delegation`、`passive_inheritance`或`externalized_power`。正式摄政期同一事实只归一个直接责任中心；名义君主不得消费摄政者的主链，本人长期外置百司处理权也不得反向取得central M3。
- “主动授权 → 俘获 → 本人窗口内清算并完成替补恢复”合并为一个mixed生命周期；不得把俘获二次裁cross，也不得把清算重复作为G5压力加分。未完成恢复或已扩散至独立责任中心时，才保留独立负链。
- 直接计分材料必须登记“人物:B1”角色。制度建制、纸面考课、后世接收和继任者撤项默认只作context；“没有查到长期结果”不是负证。同一生命周期的正负事实合成一个M与方向，新增材料只补厚原链，不另造重复链。

## 五、B2：反馈纠错与权力约束

B2只看真实信息能否上达、异议者能否安全履职、监督能否约束高官/最高权力，以及错误是否得到实际纠正。

| 档 | 唯一边界 |
|---|---|
| G0 | 报忧、监督或异议渠道被系统惩罚和封闭，国家机器严重失知或崩坏 |
| G1 | 只有形式渠道/未闭合陈述，或拒谏、报复、构罪与纠偏复发在主要阶段占主导 |
| G2 | 至少一条真实反馈—处置—纠偏链闭合，但重复性、持续性或独立性未证明；或正负重要阶段并存 |
| G3 | 反馈和监督在主要阶段实际运行，错误能够纠正，反对者通常可安全履职 |
| G4 | 多种独立渠道反复约束高官和最高权力，且基层/外朝信息能跨层级上达 |
| G5 | 达到G4后，多渠道纠错在广度、重复性、阶段覆盖和实际结果上形成比较域罕见水平 |

必须区分三种机制角色：

- `information_ingress`：信息能到达最高权力；
- `sovereign_self_correction`：君主主动或事后改策；
- `external_constraint`：外部角色、机构或程序实际改变最高权力偏好。

前两者不能冒充第三类。单次采纳、赦免进言者或因谏改令通常最多支持G2；多个孤立“纳谏故事”不能按数量拼成G3，但三个不同领域的纠错事件可入G3。

G4最低充分覆盖：至少2种独立反馈/监督渠道反复产生实际结果，其中至少1条是`external_constraint`，至少1条证明基层或外朝信息能越过常规阻隔上达；并完成同尺度负例检索。

G5必须在G4基础上证明多渠道、重复纠错和主要阶段覆盖达到比较域罕见水平；同一谏诤链的多次展示不得重复计数。

## 六、D1：继任行政连续性

D1只判断本人退出后的有限窗口内，既有行政机器是否继续实际运行。`handoff_level=H0—H5`，H值只支持同号G档。

| H值 / 主档 | 唯一边界 |
|---|---|
| H0 / G0 | 国家机器、主要官署或行政命令链整体崩解，无法维持基本行政 |
| H1 / G1 | 主要行政链严重断裂，清洗、争权、割裂或失控成为继任初期主导 |
| H2 / G2 | 部分连续，但关键领域依赖紧急接管、显著换血或大规模重建才恢复 |
| H3 / G3 | 中央行政、命令传递和关键人员在继任初期基本连续，严重断裂非主导 |
| H4 / G4 | 多个核心行政领域连续运行并产生可见交付，局部调整未击穿主要行政链 |
| H5 / G5 | 达到H4后，连续广度、交付深度或所留人员/行政资产的持续价值达到比较域罕见水平 |

D1取证规则：

1. 核心窗口从本人失去实际最高权力前已经影响交班的任末阶段开始，止于继任政权形成自身稳定行政模式或首次结构性重组；通常不超过继任后三年。
2. 储位、政变、宫禁、军权和继承名分本身归D3；只有它们实际打断官署、人员、命令、法律适用、财政征发或中央—地方传导时才进入D1。
3. 指定旧臣或口头“承前”不能单独证明连续；必须有继任初期实际履职、命令交付或行政结果。
4. 同一人员班底或同一行政机制在窗口内合成一条链，不按人数、官名或任务结果拆分。
5. H4至少需要两个独立核心行政领域连续，或一条同时覆盖中枢决策、执行人员和结果的广域连续链。
6. H5必须在核心窗口内闭合罕见连续性；窗口外证据只能在“前任已定向留下—继任者连续任用—中间未重建替换—后来证明该资产仍有价值”四项同时满足时，作为耐久性旁证，不能消费后继任务收益。
7. 亡国、征服或改朝换代不自动等于H0；按原官署、人员和命令链的实际连续程度裁H0—H2。
8. D1直接计分材料固定`reception_scope=R0`；A的长期接收不得反写D1。

## 七、position与方向指数

### 7.1 五级position

| position | 净余量边界 | 档内锚点q |
|---|---:|---:|
| lower | `< -1` | 0.1 |
| lower-middle | `[-1,0)` | 0.3 |
| middle | `[0,1)` | 0.5 |
| middle-upper | `[1,2)` | 0.7 |
| upper | `>= 2` | 0.9 |

A使用3.8的`A_position_residual`直接映射。G0零机制例外固定为middle。

B1/B2使用：

`净余量 = Σ(M权重 × 方向系数) - 本档门槛占用`

其中B1统一固定：`M0=0，M2=1，M3=2`；再乘方向系数。`position_weight_override=0`、`absorbed_same_lifecycle`、`context_only`链不进入净余量。B1不得再使用`position_depth_bonus`或人物手工position例外。

B1只对生命周期去重后仍独立存在的负M3追加Severity修正：`N3-domain=0`、`N3-cross=-0.5`、`N3-terminal=-1.0`。已经合成mixed生命周期的负向不得二次修正。

门槛占用：

| 项目 | G0 | G1 | G2 | G3 | G4 | G5 |
|---|---:|---:|---:|---:|---:|---:|
| B1 | 0 | 0.5 | 1 | 2 | 3 | 4 |
| B2 | 0 | 0.5 | 1 | 1.5 | 2 | 2 |

G1的0.5只是档内完成度占用，不代表存在M1。

D1主档由H决定，position只消费继任窗口内去重后的正负M配置。

### 7.2 方向指数

统一归一化区间：

| 档 | 占比区间 | A/B1（100） | B2（80） | D1（30） |
|---|---:|---:|---:|---:|
| G0 | 0%—19.9% | 0—19.9 | 0—15.9 | 0—5.9 |
| G1 | 20%—39.9% | 20—39.9 | 16—31.9 | 6—11.9 |
| G2 | 40%—54.9% | 40—54.9 | 32—43.9 | 12—16.4 |
| G3 | 55%—69.9% | 55—69.9 | 44—55.9 | 16.5—20.9 |
| G4 | 70%—84.9% | 70—84.9 | 56—67.9 | 21—25.4 |
| G5 | 85%—100% | 85—100 | 68—80 | 25.5—30 |

已裁档内部指数：

`direction_index = L + q × (U-L)`

保留一位小数。position只能在同项目、同主档内比较；G4-upper永远低于G5-lower。

### 7.3 跨档一致性审计

每项都要检查：若低档人物在同尺度正向M、负向M、机制独立性和结果闭合上严格支配高档人物，高档必须给出本项档表内可复制的唯一门禁事实；否则重裁材料角色、方向、M、生命周期或双方主档。材料数量和M总量只能筛查异常，不能自动生成档位。

B1同构人物若呈现近似的“同级正向core + 同级Severity负链”，不得仅因史料表述形式不同而拉开整档。跨档必须写明真实门禁差异，例如core M3有无、负链是localized还是major-stage/broad，或独立第二链是否闭合；否则优先在同档position体现厚度差。

## 八、缺证、反例与检索停止

### 8.1 反例原则

- 一个领域的M3负向首先限制该领域；只有跨多个核心领域或证明本项整体失效时，才封顶整个子项。
- M0不参与正负冲销；有限M2不能靠数量冲销未纠正的M3负向。
- 同一负向材料投影三个以上子项时，必须逐项写清作用路径，否则改为跨项核验。

### 8.2 检索停止

每人每项只需检查：代表性正向机制、同尺度负向反例、可能改档的显著漏项，以及D1继任窗口。满足任一条件即可停止搜集同质材料：

- 已覆盖主要阶段/范围，新增材料不会改变主档、S数或同尺度反例；
- 负向已系统或终局闭合，只剩同质小案；
- 正反两侧足以稳定主档；
- 已完成定向检索，未发现可改档的合格材料。

发现一种可能造成系统偏差的新漏项类型时，对当前正式比较域做统一机械筛查，只对命中者语义复核，不得只补被点名人物。

B1早期材料固定补查循吏、良吏、能吏传及关键臣僚本传中的功能等价词；同时对负证锁定责任年份，防止把前任、继任或摄政窗口事实倒投本人。时代差异只改变召回方式，不降低归责、闭环和主档门禁。

### 8.3 缺证状态

材料缺失不等于零分、负面或低档。只有明确指出“缺什么事实、补成什么结果会改变哪一档”时，才标记`CALIBRATION_BLOCKED`。

A允许严格的零机制例外`OBSERVED_NO_ELIGIBLE_MECHANISM`：必须完成公共登记复核、至少两类独立史源的固定版本读取、A专项定向检索、必要的后续接收检索，且不存在来源不可得或未裁候选。只做部分搜索、摘要检索或来源不可得时，仍为`UNOBSERVED_BLOCKED`。

B1、B2、D1不适用零机制例外。

## 九、输出与接受门禁

### 9.1 每卡最小输出

- 人物、朝代、子项、主档、position、方向指数；
- A：`S_plus_regular/S_plus_plus/S_total/S_minus/S_net/S_depth_units/C_A`、逐节点V2净值、`A_net_units/P_gross/N_gross`、正负对冲说明与极端跳档复核字段、主档门槛链；
- B1/B2：正负M配置、门槛占用、最终净余量；
- B1另输出机制链角色、归责类型；负M3存在时输出Severity及`localized/major-stage/broad`范围；G4/G5写明门槛链与独立复验；
- D1：H值、同号G档、继任窗口内的实际连续/断裂结果；
- 一句主导正向、主导负向或“无同尺度反例”；
- 覆盖状态、置信度、具体改档缺口；
- 所有直接计分材料ID必须可回源。

A若使用`OBSERVED_NO_ELIGIBLE_MECHANISM`，输出负向检索审计ID、已读固定页和题级状态，不虚构直接计分材料。

### 9.2 方向卡接受门禁

正式接受前必须满足：

1. 当前正式比较域中每人都有A/B1/B2/D1卡，人物与朝代标识唯一；
2. 每条直接计分材料已进入公共登记并可回源；
3. 同一机制已去重，跨项计分与核验角色明确；
4. B1的`grade_basis`只描述direct配置已经闭合的功能面；摄政窗口、distributed角色、B1/B2事实切片、D1/D3排除、Severity范围和完整生命周期均已复核；
5. A按canonical生命周期去重并执行V2净账、谱系边际贡献门和正负S耐久对称门；建设贡献独立评价，正负对冲不另行托底。A的正式人物裁决保存在正式JSON，校验器只作确定性算术与硬门复核，不从姓名或旧`C_A/S_net`反推历史判断；
6. D1只由H裁主档，A长期接收不得反写即时交班；
7. 所有具体改档缺口已补证、驳回或证明不改档；
8. JSON可解析、UTF-8无BOM，方向卡总数与正式比较域人数匹配，165分治理手段可重复计算；
9. 正式结果层只消费165分治理手段或20分交接质量；方向卡指数不得冒充独立分项分值。

## 十、正式晋升异常门禁（G6）

新增人物/朝代批次晋升正式值前，必须在不改动卡片裁决的前提下做一次联动重算。G6只负责发现系统偏差，不设朝代配额，也不得为了榜单形状反推档位。

必须检查三类异常：

1. **C1/C2民生财政曲线**：与当前正式比较域横向对照；异常平坦、整批同向偏高/偏低、同一人物两轴严重背离且无机制解释时回查。
2. **公共制度节点密度**：统计总节点、人均节点、同谱系拆分和S节点；异常集中或密度突变时先查是否把材料行、配套措施、维护恢复或人物级组合误拆为公共节点。
3. **晋升后总榜分布**：重算完整总榜，检查头部人数、全距、四分位距和窄区间聚集；异常只触发证据/公式/去重复核，不设目标名次。

G6输出至少包含：输入哈希、比较域人数、本批覆盖、三类分布摘要、异常解释、需回查人物、最终`PASS/BLOCKED`。

> 测试通过只证明结构和计算可重复，不代替历史语义合理性审查。
