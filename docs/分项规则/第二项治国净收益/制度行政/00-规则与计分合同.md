# 第二项制度行政四项规则与计分合同

> 状态：秦至清159人已完成A、B1、B2、D1方向卡裁决。治理手段165分与交接质量20分由方向卡统一换算；数据库写入与跨七大项综合排名保持关闭。

## 一、执行摘要

每张卡只执行六步，完成后不需要回看合同其他章节：

1. **定项**：材料是否直接回答本卡问题；否则标记为跨项核验或排除。
2. **归责去重**：合并同一机制链，确认皇帝责任、方向和作用阶段。
3. **定主档**：只按本项唯一档表裁定`G0—G5`，不由材料条数或公式生成主档。
4. **查反例**：只检查足以改变主导结论的同尺度反例；小案不累计调档。
5. **定档内位置**：比较本档最低充分M配置与人物的独立增量、反例，直接得到五级位置。
6. **判收口**：只有具体、可能改档的材料缺口才阻断；一般材料不足只降低置信度。

四项只回答四个问题：

| 方向卡 | 唯一问题 | 内部指数刻度 |
|---|---|---:|
| A | 本人对关键制度的建设、修复和可运行化贡献有多大？ | 100 |
| B1 | 本人统治下官僚组织和行政执行总体是否可靠？ | 100 |
| B2 | 真实信息、异议、监督和纠错能否实际运行？ | 80 |
| D1 | 本人退出后的有限窗口内，既有行政机器是否继续实际运转，还是发生显著断裂？ | 30 |

四张方向卡的内部指数只作材料裁决、档内排序和正式换算输入，彼此不得直接相加，也不是第二项子项分值。旧260分聚合已经退出当前结果层；需要复核旧结构时使用Git历史，不从旧聚合读取当前值。

当前第二项的治理手段正式合计为：

`governance_method_165 = round1(0.8 × [max(A_index,B1_index) + 0.5 × min(A_index,B1_index)]) + round1(45/80 × B2_index)`

正式输出先把A/B1互补块与B2换算块分别四舍五入到一位小数，再相加形成165分合计；因此机器公式写作`round1(A/B1块)+round1(B2块)`，不得改为只在最终总和处一次舍入。

D1不在治理手段层重复计分，而与D3按内部档位等权合成20分交接质量，并受较弱一侧封顶。治理手段165分正式入口为[`04-治理手段165分正式结算.md`](../../../评分结算/第二项治国净收益/制度行政/04-治理手段165分正式结算.md)。

## 二、边界与材料角色

### 2.1 最小结算单元

最小结算单元是一个能够独立回答治理问题的机制链，而不是官名、诏令、人物或史料篇章：

`问题基线 → 举措 → 皇帝归责 → 实际运行 → 结果或失灵 → 纠正 → 延续或接收`

同一机制在同一子项只计一次；多个引文、同质命令和同一制度的不同展示节点不得按条数累加。同一机制可以投影多个子项，但每个投影必须分别说明它直接回答了该项的什么问题。

### 2.2 三种材料角色

| 角色 | 处理 |
|---|---|
| `score_evidence` | 直接回答本项问题，进入本项M配置与档位裁决 |
| `cross_item_verification` | 只验证机制是否真实运行，不新增本项M链 |
| `context_only` | 只有背景或邻项结果，不参与本项裁决 |

财政民生、法律和国防军事结果只有在能够证明制度适用、行政执行或反馈机制时才可复验本项；财政净收益、人口变化、战争胜负和领土得失本身不得在制度行政重复计分。

D3评价储位、政变、宫禁和军权交接；D1只在这些事件实际打断法律适用、官署运行、行政命令或人员接续时消费其制度后果。

### 2.3 归责与跨代贡献

- 只归责皇帝实际授权、采纳、维持、纠正或破坏的部分，不把臣僚全部成果倒算给皇帝。
- 前代奠基、本朝重组、本人运行和后世修订分别归责；后世长期沿用不得反写为本人任内运行良好。
- A统一结算本人制度建设及其长期基线门禁；后世接收只用于A的R门禁和制度归责，不再进入D1。D1只结算本人退出后有限窗口内的行政连续性。
- 沿用官名、任用前朝人员、一般性“承前制”或王朝没有立即灭亡，不能单独证明制度连续或长期影响。

## 三、证据强度与节点值

### 3.1 机制覆盖M档

M档只描述本人任内的实际覆盖和持续，不描述价值、个案严重性或后世影响：

| M档 | 边界 |
|---|---|
| M0 | 未运行、纯结构、纸面命令、单点线索、未闭合事件，或只作为后世接收/主档上下文证据；不计position |
| M2 | 最低有效机制：至少闭合一个实际运行的有限制度接口、完整反馈—处置链、单地区交付链或明确阶段生命周期 |
| M3 | 全国、多责任系统，或多年形成稳定激励 |

`M1`不是A/B1/B2的有效档位：单次、单点、短期或单一责任通道若未形成上述最低闭环，归M0上下文；若已经闭合实际接口、执行/处置和有限结果，直接归M2。不得用0.5半档回避语义裁决。M档按完整机制链裁定，不按引文数量裁定。“颁行”“设官”“施行多年”只证明启动、范围或持续，不自动证明有效结果。负向M3同样必须证明相应范围的实际失灵，不能由一件严重个案推成全国状态。D1仍按继任窗口合同独立处理，不用本款反向改写既有H裁决。

### 3.2 计分所需的四个属性

每个直接计分节点只保留四个连续计分属性：

| 属性 | 取值 | 含义 |
|---|---|---|
| `direction` | 正向、正向主导、正负相近、负向主导、负向 | 机制净方向 |
| `result_closure` | 未闭合、已观察、持续或系统、被逆转 | 实际结果闭合程度 |
| `terminality` | 无、制度断裂、国家机器崩解 | 未被同尺度修复的终局损害 |
| `reception_scope` | R0—R4 | 后来实际接收范围；只用于A的骨架资格门禁和制度归责，D1固定为R0 |

R值边界：R0无接收证据；R1名义或局部沿用；R2继任者实际采用但范围有限；R3跨多代或阶段保留核心；R4跨朝代、政权或法域形成长期范式。

单个不可逆严重个案必须进入反例审查，但不设置额外C轴，也不得借严重性提高M范围。

制度建设必须先做跨人物、跨朝代的谱系去重，不能从“某皇帝颁过一套全国制度”直接推成一个新骨架。每个建设节点只增加三个离散登记字段，不另造连续加权轴：

- `institution_domain`：制度所属核心领域；
- `institution_lineage`：同一问题、核心接口和主要规则连续演化形成的制度谱系；
- `major_node_role`：该节点在谱系中的贡献角色。

结构重要性、耐久性与净收益方向必须分开裁定。每个建设节点另登记`normative_direction=positive / mixed / negative`和`intrinsic_design_effect`：前两者回答“是否改变并延续国家基线”，后两者回答“该核心规则本身带来什么治理净效应”。动作大、执行强、存在久或被后世沿用，均不能自动推成正向贡献。

- `positive`：核心规则的可观察治理作用净正向；通过长期基线门禁后，普通节点记入`S_plus_regular`。若核心规则还跨越多个王朝断裂、长期保持可识别的文明基础接口，改记入`S_plus_plus`；两者互斥，`S++`不得同时进入普通S+，也不得仅凭R4、持续年数或后世同领域存在自动取得。
- `mixed`：正向能力与制度内生损害不可忽略。只有正向接口能够脱离负向部分独立运行、独立接收并单独通过门禁时，该正向接口才可另立普通`S+`或`S++`；否则节点不计`S_total`，只按非S重大建设消费正向部分，并保留已闭合的负向M。
- `negative`：核心规则以制度化伤害、特权、掠夺、任意惩罚或破坏既有国家接口为主。节点可以是结构重大且耐久的`S-`，计入`S_minus`而不计`S_total`，不直接支持G4/G5，其已闭合损害保留为负向M。

负向节点只归责于创设者、重启已退出恶制者，或把既有负面机制正式化、常态化、显著扩张者。后继者仅沿袭、一般执行或未改变核心规则时，不新增负向节点，也不因沿用自动增加`S_minus`或负向M；其材料只用于原节点的R值与接收门禁。个人偶发暴虐、一次法外处分和一般严刑同样不得冒充制度创设。

负向节点通常仍须满足结构重大和长期基线门禁；另设一个严格的`SEVERE_CIVILIZATIONAL_REVERSAL`例外：最高权力把已经长期退出国家规范的杀害、身体侵害或人格降格重新制度化，形成可重复适用的正式规则，并已有实际执行。该例外即使对象范围有限，也可记一条严重`S-`，在`S_minus`中取权重2；范围仍按事实登记M0/M2，不得因恶劣程度虚增为全国性M3。一次暴行、临时命令、未执行倡议或一般严刑不得使用此例外。

对上述倒退的正式废除，若已经实际终止该规则并恢复此前文明基线，登记为`MAJOR_CIVILIZATIONAL_CORRECTION`。它是重大正向制度纠偏，但属于恢复而非新建国家骨架：不计`S+`，可以进入`C_A`并支持G3，单独不得支持G4/G5。

方向只裁制度设计内生并已观察的作用。一般行政执行失能归B1，信息与异议封闭归B2，财政民生结果归相邻分项；除非材料同时证明这些后果由该制度核心规则稳定产生，否则只作跨项核验，不在A重复扣分。

中央集权型中枢重组须使用同一方向标尺：若制度通过缩短命令链、强化保密或提高最高权力直达能力而提速，同时又以内生方式削弱外朝复核、权力监督或错误纠偏，则整体裁为`mixed`；运行闭合、持续时间长或被后世接收，只能提高结构重要性与耐久证据，不能把净方向洗成`positive`。明初废丞相后六部直达与清代军机处均按此规则处理：前者的中枢提速与最高权力负荷、协调和制衡损失不可分，后者的机务整合、保密和传递效率与绕开外朝复核、强化君主独断不可分；在没有可独立运行且独立接收的正向接口时，二者均为重大`mixed`非S节点。

固定执行顺序为：`先分领域 → 再并制度谱系 → 再找改变谱系基线的重大节点 → 最后归责皇帝`。同一谱系的换名、补条、恢复颁行、局部修订和一般维护不得重复领取国家骨架。

A强制分成两层执行，人物会话不得同时自由解释整套合同：

1. **节点登记层**统一裁定领域、谱系、角色、方向、R值、M值及`S+`或`S-`资格；相同节点只裁一次。人物会话只提交候选事实、生命周期和反例，不自行把材料直接变成S或主档。
2. **人物结算层**只消费已经裁定的节点；A分别汇总`S_plus_regular/S_plus_plus/S_total/S_minus/S_net/S_depth_units/C_A`和正负M配置，B1、B2、D1汇总各自正负M配置，再按第四章短表定档。节点尚未统一裁定时输出`NODE_GATE_PENDING`。

`FOUNDATIONAL_CREATION`和`MAJOR_RESTRUCTURE`只表示结构性候选，不自动计入`S_total`。一个候选还必须通过长期基线门禁，才成为A的正向国家骨架节点。其余角色仍可作为重要建设事实，但不新增`S+`或`S++`：

| `major_node_role` | 边界 | A中的处理 |
|---|---|---|
| `FOUNDATIONAL_CREATION` | 建立此前不存在的国家级制度接口，并完成实际颁行 | 正向节点通过长期基线门禁后按深度互斥计入`S_plus_regular`或`S_plus_plus` |
| `MAJOR_RESTRUCTURE` | 对既有谱系作结构性重组，使制度改按新的核心规则运行 | 正向节点通过长期基线门禁后按深度互斥计入`S_plus_regular`或`S_plus_plus` |
| `MAJOR_RECONSTRUCTION` | 在真实断裂、废弛后恢复国家接口，但主要制度结构仍承接旧基线 | 不新增S；影响建设完成度和档内位置 |
| `CANONICALIZATION` | 将既有体系作权威解释、系统整理或成熟定型，显著提高统一适用但未改变核心基线 | 不新增S；影响建设深度和档内位置 |
| `MAJOR_CIVILIZATIONAL_CORRECTION` | 正式废除已经实际运行的严重文明倒退制度，恢复长期文明基线 | 不新增S；可以支持G3并进入C_A，单独不得支持G4/G5 |
| `LOCAL_OR_SECONDARY_CONSTRUCTION` | 已完成颁行或建立真实接口，但只覆盖局部对象、单一层级或次级功能，尚未改变国家核心制度基线 | 不新增S；单项支持G2并取`C_A=1`，多个独立次级接口可以按G3组合门槛复裁，但不得把`C_A`叠加为2 |
| `PAPER_OR_INCOMPLETE_CONSTRUCTION` | 只闭合诏令、方案或设置意图，尚未证明机构、人员、程序或结果实际运行 | 不新增S；只支持G1，完成度通常取`C_A=0.5` |
| `TRANSITIONAL_RESTORATION` | 过渡性恢复、重新颁行或为下一阶段改革提供接口 | 不新增S；作为运行或背景证据 |
| `MAINTENANCE_REVISION` | 换名、补条、局部修订、常规维护或普通扩展 | 不新增S |

结构性候选须同时满足：

1. 改变全国或中央—地方核心行政接口，而非一次任命、一次工程、一般政策整顿或局部良好结果；
2. 形成可复制的组织、法律、选官教育、监察反馈、地方层级、户籍田制或国家资源行政规则；
3. 本人任内至少有M2建设或运行，不能只凭后世回顾反投本人完成度。

正向结构性候选只有再满足以下长期基线门禁，才计入`S_total`：

1. 核心规则达到R3：跨多个皇帝、阶段或政权仍实际采用，且采用的是原节点改变的核心接口；
2. 只有继任者继续使用、短期过渡、局部沿用或相似名称，均只到R2，不足以计S；
3. 后世政治格局改变不自动否定接收，但必须证明变化后的制度仍保留原核心接口；若后续改革替换了核心规则，只把前项记为阶段性重大改革；
4. 公共登记中的R3/R4标签不能自证。逐字证据必须直接覆盖后续时点、实际采用和被保留的核心规则；创设当时的运行结果不能充当接收证据；
5. 一份概括性接收材料只有分别覆盖两个独立接口时，才能同时为两个节点过门禁。教育延续不能自动证明察举延续，察举延续也不能自动证明太学—考试入仕延续。
6. 建制与耐久必须分角色、分材料ID闭合：建制材料固定为`direction=positive、reception_scope=R0`，直接证明本人任内接口及M2/M3运行；耐久材料固定为`direction=positive_reception、reception_scope=R3/R4、strength=M0`，只证明后继实际接收。两组ID必须互斥，创设材料、同一段总评或同一记录不得同时自证建制与耐久。

未通过长期基线门禁的`FOUNDATIONAL_CREATION`或`MAJOR_RESTRUCTURE`标记为`STRUCTURAL_NON_DURABLE`或`DURABILITY_EVIDENCE_PENDING`。它仍是A的建设贡献，但不计`S_total`，不得单独支持G4。

先按领域和谱系归并，再判断重大节点。同一问题、同一实施链或互为前提的配套措施，即使有多个制度名称，也只算一个节点；只有能够独立运行、独立接收且改变不同国家接口时才能拆分。同一谱系可以跨时代出现多个重大节点，但后一个节点必须证明它改变了前一个节点留下的制度基线，而不能只证明更成熟、更完备或重新颁行。一条概括材料只有逐字证据确实覆盖多个独立接口时才可关联多个节点。

新增朝代或史料更丰富的批次若出现人均重大节点数、同档S节点数显著高于既有比较域，必须先触发覆盖密度复裁：检查是否把材料行、配套措施、维护恢复或人物级`C_A`组合误拆为公共节点。密度异常只是一项阻断信号，不设朝代配额；逐条通过独立运行、独立接收和制度基线变化门禁的节点不得因时代较晚而机械删除。

`institution_domain`固定为：中央组织、中央—地方层级、法律与司法、国家行政标准与文书、国家教育与官学、选官与官僚人事、监察反馈、户籍田制与国家资源行政、军政身份与行政动员、身份秩序与人身制度。最后一类只容纳直接规定人格身份、身体或生命处置的正式制度，不把一般刑罚、宫廷个案或道德评价装入。领域只用于先行归类和横向查漏，不直接计分；谱系和重大节点不能由人物名望、后世评价或材料条数生成。新发现一个合格重大节点时，必须对同一谱系覆盖的159人做同类筛查。

法律谱系的校准例：开皇律对统一法制、刑罚结构和复核接口作实质重组，且其核心成为武德、贞观修律的直接基线，通过R3门禁后计S；武德律主要承接开皇律并承担过渡恢复，不新增S；贞观律对刑罚与适用作大规模实质改革，且成为永徽律疏的法典基线，通过R3门禁后计S；永徽律疏虽有权威解释、统一适用和长期影响，不应被降为普通修补，但在证明其另改核心法律基线以前登记为`CANONICALIZATION`，不与开皇、贞观重复计S。

教育与选官的校准例：汉武帝置五经博士、博士弟子并以考试补官，是国家教育—考试入仕谱系的`FOUNDATIONAL_CREATION`候选；郡国岁举孝廉则是另一条能够独立运行的常制荐举入口，二者不得因同见于一组材料而机械合并，也必须各自取得R3接收证据。光武帝在废弛后重建太学属于教育谱系的`MAJOR_RECONSTRUCTION`，建设贡献应保留，但不得另算一次太学首创骨架。后世一般复置太学、扩招生员或修校舍同理不新增S。

### 3.3 统一M配置与档内公式

A/B1/B2只消费去重后的完整机制链，不再把M换算为P/N/K，固定`M0=0、M2=1、M3=2`；M1在这三项中非法。方向系数固定为`positive/positive_correction=+1`、`mixed_positive=+0.5`、`mixed/neutral=0`、`mixed_negative=-0.5`、`negative=-1`。M值已经包含范围、持续和结果闭合，不再叠加`result_factor`或终局罚分。`reception_scope`也不连续加分：A只用R3判S门禁，D1材料固定R0并按继任窗口合同独立裁定。上述M值是机制强度原值；A的position为保持国家骨架、重大非S建设与一般运行链的层级差异，只把独立M有符号原值的四分之一计入档内厚度，B1/B2仍使用M原值。

同一谱系、功能和阶段的正负事实必须先合成一条生命周期链，再取一个M值和一个方向；不得同时列为独立M+、M-。`mixed`只列入`M±链`，不在正负栏双计；`mixed_positive`和`mixed_negative`分别按半个同档M计入。M3必须由单条机制自身达到系统性、持续性或广域闭合，不得由材料条数或多条M2凑成。A按下表消费建设角色：

| 建设结论 | 主档消费 | 档内消费 |
|---|---|---|
| 通过R3门禁且方向为`positive`的结构性节点 | 按深度互斥记为普通`S+`或`S++`，`S_total += 1`，可以支持G4/G5 | 本人任内运行M并回该建设链，不另设O加分 |
| 方向为`mixed`的结构性节点 | 正向接口未独立拆分并过门禁时不计S；可以支持G3 | 正向完成度进入C_A，内生损害保留为同链负向M |
| 方向为`negative`且通过通常门禁 | 记为普通`S-`，`S_minus += 1`；不计正向S，并抵扣正向骨架主档资格 | 已闭合内生损害保留为负向M |
| 通过`SEVERE_CIVILIZATIONAL_REVERSAL`门禁 | 记为严重`S-`，`S_minus += 2`；对象范围不随权重扩大 | 已闭合内生损害保留为负向M，不因权重2重复登记 |
| `STRUCTURAL_NON_DURABLE`或`DURABILITY_EVIDENCE_PENDING` | 不计S；可以支持G3 | 完成时取`C_A=2`，不按节点堆叠 |
| `MAJOR_RECONSTRUCTION`、`CANONICALIZATION`或`MAJOR_CIVILIZATIONAL_CORRECTION` | 不计S；完成度足够时可以支持G3 | 完成时取`C_A=2`；与上一类共用上限 |
| `TRANSITIONAL_RESTORATION`或`MAINTENANCE_REVISION` | 不单独抬主档 | 只作运行、背景或去重材料 |

令`S_plus_regular`统计普通S+，令`S_plus_plus`统计S++，两者互斥；令`S_total = S_plus_regular + S_plus_plus`统计去重正向骨架节点总数，令`S_depth_units = S_plus_regular + 2 × S_plus_plus`表示文明深度单位。令`S_minus`统计去重负向节点的惩罚权重，普通`S-`取1、严重文明倒退`S-`取2；令`S_net = S_total - S_minus`。`S_net`裁A的主档上限，`S++`相对普通S+多出的文明深度同时参与G5深度门和position厚度。正式JSON和Markdown不得继续输出含混的`S_plus`、`S_depth_bonus`或`S_count`兼容字段。

`C_A∈{0,0.5,1,2}`：`0`为无合格建设，`0.5`为未完成尝试，`1`为已完成的局部或次级建设，`2`仅用于独立的非S重大建设、重建、定型或重大文明纠偏。多条次级M链只调整档内位置，不叠加成`C_A=2`；人物已有`S+`时，`C_A=2`还必须来自与该S不同谱系的独立非S重大建设。A由`S_net+C_A+正负M配置`定主档，并按下述结构厚度公式定position；B1、B2由本域正负M配置定档与位置；D1先由H定主档，再由窗口内正负M配置定位置。证据不足直接阻断，不再用K平滑历史指数。

A的position统一使用结构厚度，不再为G4-upper或任何单一position另设人物门禁：

| A厚度因素 | position厚度 |
|---|---:|
| 普通S+ | `2` |
| S++ | `3`，即普通S+的`2`加文明深度`1` |
| 普通S- | `-2`；严重S-按`S_minus`权重成比例扣除 |
| C_A | `C_A / 2`，即`0/0.25/0.5/1` |
| 与S、C_A支撑链独立的M | `Σ(M原值×方向系数) / 4` |

令`A_structural_thickness = 2 × S_net + S_plus_plus + C_A / 2`。A主档厚度消费固定为`G0=0、G1=0.25、G2=0.5、G3=1、G4=2、G5=6`；G5的三条普通S路径与两条S++路径都恰好消费6。令`A_position_residual = A_structural_thickness - 主档厚度消费 + independent_M_signed / 4`。S、S-节点自己的M以及支撑C_A的最强非S正向建设链已由结构厚度表达，不再进入`independent_M_signed`；其余独立正向、混合与负向生命周期按有符号M进入。这样额外普通S+、S++文明深度和C_A=2都会直接增加档内厚度，而单条独立M3只增加`0.5`，不能压过结构性建设。

四张方向卡统一使用同一组六档占比边界，但按各自内部刻度生成方向指数。A和B1使用100刻度，B2使用80刻度，D1使用30刻度；这些刻度不是独立权重，不得彼此直接相加。所有方向指数保留一位小数，归一化占比按本卡刻度计算：

| 档 | 归一化占比区间 | A指数（100刻度） | B1指数（100刻度） | B2指数（80刻度） | D1指数（30刻度） |
|---|---:|---:|---:|---:|---:|
| G0 | 0%—19.9% | 0—19.9 | 0—19.9 | 0—15.9 | 0—5.9 |
| G1 | 20%—39.9% | 20—39.9 | 20—39.9 | 16—31.9 | 6—11.9 |
| G2 | 40%—54.9% | 40—54.9 | 40—54.9 | 32—43.9 | 12—16.4 |
| G3 | 55%—69.9% | 55—69.9 | 55—69.9 | 44—55.9 | 16.5—20.9 |

`position`表示相对本档最低充分配置的同档净余量，只允许在同一项目、同一主档内比较：

| position | 唯一边界 | 档内锚点`q` |
|---|---|---:|
| lower | 刚过门槛且有显著负向M或完成缺口 | `0.1` |
| lower-middle | 刚完整达到本档最低M配置，无独立强增量 | `0.3` |
| middle | 最低配置外另有一项独立M2增量，或正负合成后为本档典型状态 | `0.5` |
| middle-upper | 另有独立M2/M3增量，负向M不接近降档 | `0.7` |
| upper | 统一净余量大于等于`2` | `0.9` |

不得按人物数量、名次、分位数或材料条数分配position。A只执行上一段统一结构厚度公式：S与C_A支撑链不重复计M，额外S、S++深度、C_A完成度及其余独立正负M全部进入同一个净余量；负向已经进入`S_net`或独立M净值，不再设置upper门、负向封顶或人物特设修正。B1、B2先扣本档最低充分配置，再比较有符号净余量。同一谱系、功能、阶段或结果的多条材料只算一条。

A完成上述门槛消费后，也按下述同一组净余量区间映射position；G0零机制例外仍固定为middle。A、B1、B2不得各自另设未写入合同的降级修正。

B1、B2的档内门槛占用值如下；它只用于计算已裁主档内的净余量，不能反推或改变主档：

| 项目 | G0 | G1 | G2 | G3 | G4 | G5 |
|---|---:|---:|---:|---:|---:|---:|
| B1 | 0 | 0.5 | 1 | 2 | 3 | 3 |
| B2 | 0 | 0.5 | 1 | 1.5 | 2 | 2 |

B1、B2以`Σ(M权重×方向系数)-门槛占用`得净余量：小于`-1`为lower，`[-1,0)`为lower-middle，`[0,1)`为middle，`[1,2)`为middle-upper，大于等于`2`为upper。G1的`0.5`只是“单点或不完整主档”相对完整机制的完成度占用，不对应、也不得伪造一条M1材料。负向已经进入有符号净余量，不再额外降级。输出必须同时列出门槛占用、正向、混合、负向、M0上下文和最终余量；跨档余量不得横向排序。

令已裁档内部指数下界为`L`、上界为`U`，最终`direction_index=L+q×(U-L)`，保留一位小数。跨档位不得用position比较，G4-upper仍低于G5-lower。

“跨档位不得用position比较”只禁止把五级位置当作跨档排名工具，不豁免主档的一致性审计。每项必须对当前全体人物建立跨档去重M配置支配矩阵：若低档人物在同尺度正向M、负向M、机制独立性和结果闭合上严格支配高档人物，高档必须给出本项档表内可复制的唯一门禁事实（如主要阶段覆盖、跨层级传导、最高权力约束或D1的H语义）；不能给出时，必须重裁材料角色、方向、M、生命周期或双方主档。材料条数与有符号M总量只负责筛查候选，不自动生成跨档结论。

没有合格M链时默认标记`UNOBSERVED_BLOCKED`。只有A可以使用一个严格受限的例外：若统一负向检索门禁已经证明当前比较域内`OBSERVED_NO_ELIGIBLE_MECHANISM`，即没有发现达到A门槛的建设，也没有发现足以形成负向节点的同谱系系统破坏，则进入G0-middle；这不是把“未找到”当成历史零。该状态必须同时满足：

1. 当前公共登记和本人全部既有A角色已逐条复核；
2. 至少实际读取一份固定版本的本纪、帝纪或本人主传，以及一份来源谱系独立的纪传、制度志、政书或《资治通鉴》相关在位窗口；
3. A的制度接口变化、本人归责、任内实际运行、同谱系失败或反转四类问题均已执行定向检索；涉及S候选时还须检索后续实际接收；
4. 每次读取保存固定版本、页哈希和题级状态，不得用索引页、搜索摘要或同一页面的URL变体充当独立来源；
5. 不存在`SOURCE_UNAVAILABLE`、未裁决候选或只因材料错挂而形成的空卡。

只完成部分页面、只得到`SEARCHED_NOT_FOUND`、来源不可得或没有执行本项专项检索时，仍是`UNOBSERVED_BLOCKED`。B1、B2和D1不适用零机制例外，因为行政运行、反馈和交班的沉默不能证明其不存在。

## 四、唯一主档表

### 4.1 A：制度建设与可运行化

A以关键国家制度对文明基线的净建设、重组和修复为主，不评价王朝总体治理状态。先按正向建设M配置确定候选档，再用`S_net`裁主档上限，最后按独立M余量定五级位置。`S_net < 0`时最高G2，`S_net = 0`时最高G3，`S_net > 0`才有G4/G5资格；净门禁只压上限，不会仅凭一个负向节点自动把人物判成G0。

| 档 | 唯一边界 |
|---|---|
| G0 | 经统一负向检索门禁确认没有达到A门槛的可识别制度建设；或既有关键制度被系统破坏、弃置或互相冲突。前一种必须登记为`OBSERVED_NO_ELIGIBLE_MECHANISM`，不能由普通材料缺失推定 |
| G1 | 主要只有纸面创设、临时措施或未完成的制度尝试 |
| G2 | 至少一项制度完成实质建设，但只改变局部接口、覆盖有限或完成度不足；正向建设虽更强但`S_net < 0`时也不得高于本档 |
| G3 | 至少一项结构性改革、重大重建、重大文明纠偏或权威化定型完成，但尚未证明成为长期国家基线；或多个次级制度形成可识别建设组合；`S_net = 0`时不得高于本档 |
| G4 | 至少一项通过R3门禁的正向国家骨架节点完成建设，且`S_net >= 1`；多个未过门禁或混合节点不得靠数量替代，重大负向骨架不得只留在档内而不影响主档资格 |
| G5 | 净正向制度建设达到本比较域罕见水平：或多个独立国家核心接口同时形成广而深的正向骨架组合，或少数正向基础架构制度重定国家组织基线并形成长期范式 |

G5按统一门槛执行，不作人物特设：满足以下任一条件即可进入G5；否则至多进入G4。其一，至少三条相互独立的正向S节点、覆盖至少两个制度领域，且`S_net >= 3`；其二，至少两条相互独立的`S++`共同重定两个不同的国家核心接口，且`S_net >= 2`、`S_depth_units >= 4`。第二种只适用于少数跨多个王朝断裂仍保留核心规则的基础架构型组合，不能用同一谱系拆分、普通R4、同一概括接收材料、混合节点或一般配套措施凑数。存在`S-`时必须先做净骨架门禁，不能以正向节点数量绕过抵扣。

制度颁行后立即撤销、从未建立执行接口或多个骨架均停留纸面，说明建设本身未完成，可以影响主档。制度已经建成后的财政恶化、战争失败、官僚失能或反馈失灵，只有在证明该制度自身严重失效、被反转或名存实亡时才进入A档内负向；其他问题进入B1、B2或相邻分项。

统一战争、疆域取得和消灭割据本身不计A，也不能作为额外家族或M档加成；只计统一后实际建立的行政接口。新取得疆域只能证明适用范围，不能代替设官、颁行、运行和接收证据。

### 4.2 B1：官僚治理与行政执行

B1评价选任、考课、奖惩、替补、中央—地方传导和政策交付的实际状态，不评价制度设计名望或个别名臣数量。

| 档 | 唯一边界 |
|---|---|
| G0 | 选任、信息、奖惩和执行链被全面俘获，行政结果大范围崩坏 |
| G1 | 官僚失能、腐败、避责或临时迫胁在主要阶段占主导 |
| G2 | 已有真实选任或行政交付，但覆盖、持续或替补能力不足；或可用与俘获并存 |
| G3 | 选任、考课和执行在主要阶段总体可用，严重失灵不是主导状态 |
| G4 | 官僚体系在主要阶段广域可用，中央—地方能够稳定传导，显著失能并非主导 |
| G5 | 达到G4后，官僚机器在覆盖广度、持续运行、专业替补和政策交付中形成了本比较域罕见的可靠性组合，且不存在占主要阶段的长期系统性俘获 |

一次工程、一个能臣或一轮整顿不能按节点数量抬档；必须证明官僚体系或行政交付本身。

G5所列“覆盖广度、持续运行、专业替补、政策交付”是四个可观察的可靠性侧面，不是四项必须全部齐备的合取条件，也不把“专业替补”设为任何人物进入G5的单独硬门。达到G4后，还须满足以下任一路径：一是至少三条相互独立的系统运行链，覆盖至少两个行政领域；二是至少两条独立系统链，并由跨阶段反复、重大压力下不中断或长期代表性结果证明其持续可靠；三是稳定选任/替补链与独立政策交付链共同闭合。专业替补、稳定考课、危机下不中断交付、不同政策领域反复成功，都是可替代的可靠性证明。若现有史料难以直接观察替补，只降低该侧面的可证性，不据此自动降为G4；同一总评拆出的多个标题、一个能臣和一项工程不得凑足路径。

成熟王朝的官署齐全、例行奏报、考课命令和档案丰富度，只能证明行政接口存在或信息较易观察，不自动证明交付质量高于早期王朝。B1必须核对“部署—执行主体—跨层传导—可观察结果”是否闭合；只有设官、下令、议政、要求考察或列出制度职掌而没有后续执行结果的，至多作M0背景或有限M2，不得直接写成M3系统交付。

同一段通读总评或同一材料不得仅因标题改写而拆成河工、赈济、考课、专业替补等多条独立M3。材料标题、机制角色和引文必须语义相符；引文没有出现选任替补、跨层执行或结果时，不得以分析者命名补足。G4至少需要一条广域中央—地方交付链，并由另一条独立的选任替补、考课问责或不同领域交付链交叉验证；G5还必须在此基础上证明跨时段持续和比较域罕见可靠性，不能由一段宏观总评或成熟官僚制的常规运行推成。

G4与G5只区分一个核心问题：G4看广域可靠，G5看这种可靠性在159人横向比较中是否形成罕见的广度、持续性和专业交付组合。G5不要求把多阶段、多区域和重大任务逐格全部闭合，也不要求两条同类型中央—地方链；关键人事更替、重大治理压力或高难度任务只是强验证路径，不是统一必选题。进入G5必须已有一条主要阶段总体运行材料、完成同尺度负例检索且不存在占主要阶段的长期系统性俘获，并满足以下任一路径：其一，至少三个独立核心行政接口跨三个领域，其中至少两个达到持续或系统运行，并包含中央—地方交付或专业替补；其二，专业选任替补与代表性中央—地方交付在同一长期生命周期内反复生效，形成比较域罕见的深度。第二条路径只承认同一生命周期的语义深度，不把总链、摘要与实例重复计为多条M。上述材料包是最低充分覆盖门，不按接口数、材料条数或M总量自动生成档位。

### 4.3 B2：反馈纠错与权力约束

B2评价真实信息能否上达、异议者能否安全履职、监督能否约束高官和最高权力，以及错误是否得到实际纠正。

| 档 | 唯一边界 |
|---|---|
| G0 | 报忧、监督或异议渠道被系统惩罚和封闭，国家机器严重失知或崩坏 |
| G1 | 只有形式渠道或未闭合陈述；或拒谏、报复、构罪与纠偏复发在主要阶段占主导 |
| G2 | 至少一条真实反馈—处置—纠偏链已经闭合，但重复性、持续性或独立性尚未证明；或正负重要阶段并存 |
| G3 | 反馈和监督在主要阶段实际运行，错误能够被纠正，反对者通常可安全履职 |
| G4 | 多种独立渠道在主要阶段反复约束高官和最高权力，信息能够跨层级传递；可以存在显著失灵，但报复、封闭或同类纠偏复发不占主要阶段主导 |
| G5 | 达到G4后，多种渠道对最高权力和高官的纠错在广度、重复性、阶段覆盖和实际结果上形成了本比较域罕见的制度化水平 |

设置谏官、下诏求言或皇帝自述不等于机制运行；至少要有实际反馈、处置或纠偏结果。单个异议者遭不可逆打击必须复查，但只有其击中核心反馈通道或形成稳定激励时才改变主档。

单次采纳、单次赦免进言者或单次因谏改令，只能证明该事件内存在一条有限反馈—处置链，通常至多支持G2。无论搜集到多少彼此孤立的“纳谏故事”，都不能仅按数量拼成G3；进入G3必须证明同一反馈接口跨分离事件重复生效，或多个独立角色在主要阶段持续安全表达并产生纠正。杨广等任何皇帝都可能出现一次采纳，故“至少采纳过一次”不是人物区分门槛。

必须区分三种角色：`information_ingress`只证明信息到达最高权力，`sovereign_self_correction`只证明君主主动或事后改策，`external_constraint`才证明外部角色、机构或程序能够改变最高权力偏好。前两者可以构成B2的有限正向事实，但不能冒充对最高权力的独立约束；G4所需“直接约束最高权力”必须由第三类闭合。

材料标题、机制名和逐字证据必须同义闭合。一般政务总评、财政民生摘要、机构设置句或相邻事项结果不得改写成材料没有直接记载的“反复纠偏”“异议安全”或“最高权力约束”。同一材料可以展示多个相邻事实，但只有分别闭合独立入口、实际运行和纠正结果时才能拆为多条渠道；同一引文或同一摘要换标题重复登记，不得形成渠道数量或M强度。

相邻分项的一次战争止损、财政采纳、继承咨询或一般政策改令，只有在材料同时证明真实异议入口、信息上达或表达安全时才可作为B2闭合链；不得仅凭相邻事项结果进入G2。法律材料同理：法条、刑罚宽严或一般司法结果不直接进入B2，只有复核纠错、申诉上达、监察问责或最高权力受程序约束的运行事实可以投影。

G4不要求统治期内从未发生重大错误，也不要求同一具体政策永不反复。最低充分覆盖为：至少两种相互独立的反馈或监督渠道反复产生实际结果，其中至少一条直接约束最高权力偏好，至少一条证明基层或外朝信息能够越过常规阻隔上达；同时完成同尺度负例检索。单一领域存在未完全修复的显著失灵时，先压档内位置；只有其扩展为主要阶段的报复激励、信息封闭或跨渠道俘获，才阻断G4。G5要求在G4基础上形成横向罕见的多渠道、重复纠错和主要阶段覆盖；危机或强烈个人偏好下仍多次生效可以强力支持G5，但不是统一必选题。一般纳谏数量、同一谏诤链的多次展示或君主自我评价仍不得堆成G5。

### 4.4 D1：继任行政连续性

D1只判断一个问题：本人退出后的有限窗口内，既有行政机器是否继续实际运转，还是发生显著断裂。机器字段统一使用`handoff_level=H0—H5`，每个H值只支持同号G档，不再设置制度影响I轴。

| H值 / 主档 | 唯一边界 |
|---|---|
| H0 / G0 | 国家机器、主要官署或行政命令链整体崩解，继任初期无法维持基本行政 |
| H1 / G1 | 主要行政链严重断裂，清洗、争权、割裂或失控成为继任初期主导状态 |
| H2 / G2 | 部分行政连续，但关键领域依赖紧急接管、显著换血或大规模重建才恢复 |
| H3 / G3 | 中央行政、命令传递和关键人员在继任初期基本连续运行，严重断裂并非主导 |
| H4 / G4 | 多个核心行政领域连续运行，并在继任初期产生可见交付；局部调整没有击穿主要行政链 |
| H5 / G5 | 达到H4后，行政机器在连续广度、交付深度或所留人员与行政资产的持续价值上达到本比较域罕见水平 |

D1按以下规则取证和结算：

1. 核心窗口从本人失去实际最高权力前已经影响交班的任末阶段开始，止于继任政权形成自身稳定行政模式或完成首次结构性重组；通常不超过继任后三年。核心窗口内的实际运行或断裂决定H0—H4。窗口外若仍是同一人员或同一行政链、期间没有被继任者重建替换，可以作为`cross_window_continuity_verification`复验交班质量，但不得产生P，也不得把继任者长期任用、独立决策或任务收益倒归前任；后世制度沿用、修订和跨朝影响仍只归A。
2. 即位名分、遗诏、储位、顾命名单、宫禁控制、政变和军权归属本身归D3；只有材料继续证明官署、人员、命令、法律适用、财政征发或中央—地方传导在继任初期实际运行或断裂时，才可投影D1。
3. 指定旧臣或继任者口头宣布承前均不能单独证明连续。正向材料至少要闭合到继任初期的实际履职、命令交付或行政结果；负向材料至少要闭合到主要行政链受损，不能仅凭死亡方式、继位争议或后世结局倒推。
4. D1直接计分材料的`reception_scope`一律为R0；A中的建设、耐久门禁和后世接收材料不得作为D1直接计分或档内加分。确需证明前置机制或人员归责时，只可作`cross_item_verification`。
5. 同一人员班底或同一行政机制在窗口内的连续运行合成一条机制链，不按人数、官名、战功或多个结果拆分累加。军事、财政、法律结果只证明该行政链经受实际任务检验，不重复结算相邻分项收益。
6. H4至少需要两个相互独立的核心行政领域实际连续，或一条同时覆盖中枢决策、执行人员和结果的广域连续链。H5在H4基础上按159人横向比较裁定，可以由核心窗口内罕见的多领域连续、连续交付深度或关键人员与行政资产的持续价值支持；重大压力、关键人员变化或高难度任务是强验证而非必选条件。若核心窗口已经独立闭合H4，窗口外证据只有同时满足“前任已定向留下该人员或行政资产、继任者连续任用且中间未重建替换、后来在高难任务中证明该资产仍有实际价值、只消费耐久性而不消费任务收益”四项，才可作为H5的稀有耐久性门禁。材料条数不自动生成高档。
7. 亡国、征服或改朝换代本身不自动生成H0。若继任政权在核心窗口内实际沿用原地方牧守、官署人员或既有命令链，并据此维持基本行政，应按实际连续程度在H1—H2区分：只有短暂军事动员、受降任命或个别旧臣被吸收，尚不足以证明基本行政连续；旧班底或官署部分运行但关键领域依赖外部紧急接管、显著换血或首次结构性重组，属于H2。只有原国家机器和基本行政均整体停止、短暂挣扎未形成可持续交付时，才进入H0。
8. H5的罕见性必须在本人退出后的核心继任窗口内闭合：至少由多个核心行政领域连续运行并产生高难度、跨层级或多环节的可见交付证明。更远期的人才表现、后世军功、长期制度沿用、R值或持续年限只能作旁证，不能把核心窗口内仅达到H4的材料抬为H5。
9. 公共`material_id`是稳定标识，不承载当前H值。历史ID中的`-H0`至`-H5`后缀只视为创建时标签；现行H一律读取`adjudicated_handoff_level`及D1方向卡的`handoff_level`。仅因重裁H不得改ID或建立平行别名。

D1内部指数区间统一使用3.4表；公式只在已由H裁定的同号G档内定位。

## 五、反例、缺证与检索停止

### 5.1 反例只比较同尺度机制

- 一个领域的M3负向首先限制该领域；只有跨多个核心领域或证明本项整体失效时，才能封顶整个子项。
- M0上下文不参与正负冲销；一条有限M2也不能仅凭数量冲销未纠正的M3负向或压过覆盖主要阶段的正向主链。
- 重大负向已被同尺度、持续纠正实际逆转时，按完整生命周期裁定；表态、短期撤回或换名不算修复。
- 同一负向材料直接投影三个以上子项时，必须逐项说明作用路径；否则改为跨项核验。

### 5.2 统一检索机会

每人每项只检查：代表性正向机制、同尺度负向反例、可能改档的显著制度漏项，以及D1直接交班窗口。新发现一种可能造成系统偏差的漏项类型时，对159人做统一机械筛查，只对命中者语义复核；不得只给被点名人物补证。

达到以下任一状态即停止继续搜集同质材料：

- 已有机制覆盖主要阶段或范围，新增材料不会改变主档、通过长期门禁的骨架节点数S或同尺度反例；
- 负向已达到系统或终局闭合，只剩同质小案；
- 正反两侧足以稳定主档，剩余缺口不会改变档位；
- 已完成定向检索但未发现能够改档的合格材料。

### 5.3 缺证处理

- 材料缺失不等于零分、负面或低档。
- 本人直接材料不足时，可依次使用同阶段共享制度状态、前后任连续性和其他公共底账对行政机器的复验；不得连续两跳推断唯一高档。
- 只有已经指出“缺哪一项事实、补成何种结果会改变哪一档”的具体缺口才标记`CALIBRATION_BLOCKED`。
- 史家概括、现代名望和网页摘要只用于发现异常与定位史源，不直接产生方向档或内部指数。

## 六、输出与方向卡接受门禁

### 6.1 每卡最小输出

每张卡只要求：

- 人物、朝代、子项、主档、档内位置、影子点分；
- A输出`S_plus_regular/S_plus_plus/S_total/S_minus/S_net/S_depth_units/C_A`及正负M配置，`S+`与`S++`必须独立计算和展示，`S++`节点必须逐条给出跨王朝核心规则接收依据；其他项输出正负M配置；同时输出主档门槛链、档外增量链、结构性反例、五级position依据和直接计分材料ID；A若使用`OBSERVED_NO_ELIGIBLE_MECHANISM`，改为输出负向检索审计ID、已读固定页及题级状态，不虚构直接计分材料ID；
- 一句主导正向、主导负向或“无同尺度反例”；
- 覆盖状态、置信度和具体改档缺口；
- D1另输出H值及其同号支持档，并逐条说明继任窗口内的实际运行或断裂结果。

材料详情每条独占一行，行首只放公共材料ID；史源正文与回源状态只认`docs/公共成果/制度行政/`公共登记。

### 6.2 收口门禁

方向卡接受前必须同时满足：

1. 159人各有A、B1、B2、D1四卡，人物与朝代标识唯一；
2. 每条直接计分材料均已进入公共登记并可回源；
3. 同一机制已去重，跨项直接计分与核验角色明确；
4. 主档由本合同唯一档表生成；A按谱系去重`S+`和`S-`并执行`S_net`门禁，四项均由去重M配置直接生成五级position，不再读取P/N/K；
5. D1只由H裁定，长期制度影响仅进入A，没有用长期影响反写即时交班；
6. 所有具体改档缺口已补证、驳回或证明不改档；
7. JSON可解析、UTF-8无BOM、636卡总数和165分治理手段聚合均可重复；
8. 正式结果层分值只能由165分治理手段或20分交接质量统一换算；方向卡不得冒充独立分项分值。

### 6.3 G6：逐朝晋升分布异常门禁

新增朝代批次从影子值晋升正式值前，必须在不改动卡片裁决的前提下完成一次联动重算，并同时检查以下三类分布。G6是异常复核门禁，不是朝代配额：异常可以由史实结构解释，但必须留下逐项解释和受影响人物；不得为了让曲线或名次“好看”而反推档位、补节点或删去已通过事实门禁的记录。

1. **C1/C2民生财政曲线**：把本批人物的C1状态曲线、C2财政治理曲线与当前全部正式比较域横向对照，同时按本朝分裂程度、战争压力、统治期长短、南北政权差异和恢复阶段解释极值、单调跳变、异常同档或两轴长期背离。出现本批过度平坦、无史实依据的整批同向偏高/偏低，或同一人物C1/C2严重背离而没有机制解释时，阻断晋升并回查材料角色、状态锚与归责；不得因朝代整体印象机械统一降档。
2. **公共登记重大制度节点数量**：统计本批总节点数、人均节点数、各人物节点数、同谱系拆分数和S节点数，并与既有比较域及相邻朝代的覆盖密度对照。零节点、单人异常集中或人均密度显著偏离都必须解释；若源于把材料行、配套措施、维护恢复或人物级组合拆成公共节点，必须先去重。确有独立运行、独立接收和制度基线变化的节点，不因密度异常机械删除。
3. **晋升后总榜名次分布**：使用拟晋升值重算完整总榜，报告本批进入头部区间的人数、无头部人物的情况、全距、四分位距，以及任一窄名次窗口内的最大聚集人数。大量进入头部、一个头部也没有、或集中占据某个窄区间均触发语义复核；复核只检查共同的证据富集、统一偏移、公式或去重错误，不设必须占据多少名次的目标。

G6输出必须包含输入哈希、比较域人数、本批人物与卡片覆盖、C1/C2曲线摘要、公共节点计数、拟晋升总榜分布、异常解释、需回查人物和最终`PASS / BLOCKED`。只有G6通过且6.2的来源、材料角色、档位、生命周期和缺证门禁也全部通过，才允许接受方向卡并刷新正式结果层。
