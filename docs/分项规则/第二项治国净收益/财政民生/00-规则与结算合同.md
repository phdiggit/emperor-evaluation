# 第二项C1/C2与D2财政民生规则与结算合同

本合同用于皇帝第二项C1、C2和D2结算。秦至唐95人C1已经完成正式文档结算；C2、D2、数据库写入和第二项综合排名仍关闭。

## 一、评分边界

- C1民生福祉与社会繁荣（70分）：普通民众在整个统治期的温饱、家庭供给、赋役承受、生产生活、人口再生产和社会安定。
- C2经济活力与财政健康（40分）：生产、流通、货币、税制、财政收支和长期承受力。国库充盈不等于民富，极端汲取不得抬档。
- D2社会韧性（20分）：交班时民间余量、恢复机制、社会失稳基础及财政压力转嫁后的继续运行能力。

战争胜负、安全收益和投入是否值得归第三项；本合同只消费百姓和财政实际承受的后果。统一、创业和兼并战争按既有合同排除。

同一事实可以被不同评分项引用，但每项只回答自己的问题，同一种收益或损害在同一分项内只能结算一次。

## 二、正式输入与证据优先级

只接受：

1. 政书底账中已经裁决的正式节点；
2. 通鉴财政民生接入裁决及原通读卡定位；
3. 战争成本底账中最终`war_event_id`对应的`READY_COST`父事件；
4. 为补齐状态锚所作的有约束推断。

`HOLD`、拒绝节点、未执行政策、单帝专题排除材料和未完成父级去重的战争记录不得进入结算。

证据优先级为：

1. 同时代或近时代、明确覆盖天下或主要统治区的宏观状态叙述；
2. 跨年份连续的粮价、人口、生产、赋役、流亡、市场和社会运行结果；
3. 能与其他结果互证的区域或单轴材料；
4. 直接政策、工程和战争后果；
5. 继承状态、治理时间、治理方向和安全环境组成的受约束推断。

政策颁布、仓库数字、户籍数字或事件数量都不能单独替代宏观状态。材料稀疏降低置信度，不自动降低状态档或稳定性。

## 三、状态证据与直接贡献

### 3.1 状态证据

状态材料按用途分为：

| 类型 | 用途 |
|---|---|
| `STATE_ANCHOR` | 范围、时期和实际结果足以直接锚定`S0/S_avg/S_end` |
| `STATE_SUPPORT` | 单轴、宽时段或次一级范围，只用于加强或限制主锚 |
| `LOCAL_ONLY` | 只描述局部地区或群体，不外推全国状态 |
| `CONTRIBUTION_ONLY` | 证明措施或局部公共结果，不替代总体状态 |
| `CONTEXT_ONLY` | 只说明天灾、战争环境、前朝遗产、意见或未执行计划 |

宏观状态优先于由零散政策数量合成的推断。跨任期材料按时间拆分，前任`S_end`直接成为后任`S0`，不再追溯分摊给更早或更晚的皇帝。

### 3.2 直接贡献强度

政策、工程和财政措施不能按“每条材料同档”处理。每项独立结果至少保存：覆盖人口、地理范围、持续时间、收益或损害深度、实现阶段、责任和置信度。

正负结果统一采用`PI0—PI6`、`NI0—NI6`：

| 档 | 一般边界 |
|---:|---|
| 0 | 只有主张、风险或方向，实际结果未知 |
| 1 | 单点、短时、轻微结果 |
| 2 | 已有明确家庭、生产或财政结果，但覆盖有限 |
| 3 | 区域性或持续性结果，足以改变一个状态子轴 |
| 4 | 跨区域、多年或深度损害/收益，明显影响阶段状态 |
| 5 | 广域、长期、结构性结果，影响主要统治区 |
| 6 | 全国性、跨代或系统性结果，改变整体状态轨迹 |

只有已经实现且未被宏观状态吸收的结果才能进入档内余额。政策方向、诏令数量和史料篇幅不增加强度。

## 四、工程消耗

工程同时记录公共收益和施工成本，两者分别裁决，不能互相冲销。长期公共收益不能删除当期死亡、徭役和财政损失；当期损害也不能否认后来确实实现的结构收益。

| CI | 工程消耗边界 |
|---:|---|
| `CI0` | 日常维护，未见额外征发或损害 |
| `CI1` | 单点、小规模修缮，只有有限劳苦 |
| `CI2` | 显著单项工程，有明确人力物资支出但未形成区域压力 |
| `CI3` | 大型、跨州郡或跨农时工程，已有生产或生计损失 |
| `CI4` | 十万级或全国性超大型工程，显著影响人员、财政或生产 |
| `CI5` | 百万级、多年或多个大型工程并发，严重改变阶段状态 |
| `CI6` | 灾难性汲取，百万级或同等动员伴随大规模死亡、逃亡和生产破坏 |

每月役丁、累计人次和独立人数必须分开。只记修缮、壮丽或大作而没有规模和后果时，只能取最低可证明档。

## 五、战争成本接入

战争成本沿用战争卡已经裁决的`P/S/M/A→WC0—WC7`，财政民生链不得重估或相加`ΣWC`。只有最终父事件的实际后果可以消费；人员、军费、粮运、物耗和附带损害不得拆卡重复累计。

战争成本在C1有三级用途：

1. 只有WC档位、动员或支出压力而没有实际民生后果时，只触发复核；
2. 后果足以改变主要统治区或主要持续阶段时，直接进入`S0/S_avg/S_end`；
3. 后果不足以改写全国`S_avg`，但证明某个区域或短时阶段实际低于`S_avg`时，进入稳定性K。

第三级是战争成本除复核门之外的正式用途。例如全国`S_avg=C1-4`，边疆战争已经造成人口被杀掳、牲畜损失和生产中断，但不足改变全国主态，可以据此降低K；若这些后果只说明为什么不能进入C1-5，则已被`S_avg`吸收，不再影响K。

WC数值、战争次数和战争胜负本身都不能机械改变C1。同一战争后果一旦用于状态锚或K，不再作为独立负面贡献重复扣分。

## 六、天灾、外部冲击与责任

天灾发生本身不记皇帝负面贡献。只评价：

- 是否存在可行预防却拒绝执行；
- 是否及时赈济、减免、调粮和安置；
- 是否以加征、强役、封锁或行政失灵放大损害；
- 灾后是否恢复生产、人口和社会运行。

灾害造成的实际状态可以作为时代状态证据，但自然原因不转化为皇帝直接负贡献；有效赈济和恢复可以计正面结果。战争、前朝结构和既有财政条件同样先记录外部起点，再判断本人的响应、放大和恢复责任。

## 七、C1三锚与六档

每位皇帝必须保存：

- `S0`：即位或实际掌权起点；
- `S_avg`：任内平均或持续时间最长的主要状态；
- `S_end`：离任或实际交班状态；
- `main_band`：以`S_avg`为核心形成的唯一主档；
- `confidence`与材料局限。

### 7.1 C1状态六档

| 档位 | 状态边界 |
|---:|---|
| `C1-1`崩溃 | 大范围饥饿死亡、人口逃散、生产停顿或社会运行断裂成为主要状态 |
| `C1-2`广泛困顿 | 基本生产仍在，但多数家庭长期难以稳定维生，重役、破产或流亡广泛存在 |
| `C1-3`基本维持 | 战乱或危机后已经恢复基本生产和社会运行，多数人可勉强维生，但余量和抗冲击能力有限 |
| `C1-4`普遍温饱 | 主要统治区多数家庭能够稳定温饱，生产、人口和社会生活长期正常运行 |
| `C1-5`富庶 | 在普遍温饱之上，民间财富、家庭余量、生产流通和生活安全形成多维、长期高位 |
| `C1-6`极盛 | 秦至唐范围内罕见的全国性峰值，需多维直接宏观材料证明，不能由一般盛世评价推定 |

恢复生产通常只能证明C1-3；C1-4必须证明普遍温饱，C1-5必须有比低粮价或户口增长更高一级的民间富足材料。缺少升级材料时取较低档，不能用一条负面事实人为设置更高档的否决门。

### 7.2 缺证推断

锚点不能空置。缺少直接宏观材料时，依次使用：

1. 前任`S_end`的连续继承；
2. 任内已有多路实际结果；
3. 有效治理时间和结果出现时间；
4. 工程、战争和财政后果；
5. 治理方向及同政权前后状态约束。

上升证据不足取较低档；下降可以由明确、持续的实际后果推断。推断必须给出唯一档、置信度和依据，不用事件数量代替状态。

## 八、持续性与稳定性

持续性与稳定性不是等权并列项：持续性先决定升档成果兑现多久，稳定性再判断`S_avg`是否被实际跌破。

### 8.1 升档持续性

凡`S_end>S0`或任内出现高于起点的阶段，必须把每次相邻升档逐级保存：

- `from_band/to_band`；
- `first_supported_entry`；
- `minimum_sustained_years`；
- `reign_share_lower_bound`；
- `continuity_basis`；
- `duration_class`。

| 持续档 | 边界 |
|---:|---|
| `END_ONLY` | 只证明交班时达到，持续下界为0 |
| `SHORT` | 不足有效治理窗口四分之一 |
| `SUBSTANTIAL` | 四分之一以上、不足二分之一 |
| `MAJORITY` | 至少覆盖有效治理窗口一半 |

缺精确年份时取可证下界，不从任期长度或`S_avg`反推伪精确年份。相邻升档价值逐级保存，越高档跨越门槛越难；低位重建不能因起点低被封死上限。

### 8.2 相对`S_avg`的稳定性K

K只回答：任内主要持续状态`S_avg`形成后，是否出现实际低于该档的阶段。

| K | 相对于`S_avg`的边界 |
|---:|---|
| `K4`保持 | 没有证据证明任何有效阶段低于`S_avg`；负面材料只构成本档或限制更高档 |
| `K3`轻度波动 | 局部或短时阶段低于`S_avg`，但主态未变，后续同档状态、恢复或影响受限有证 |
| `K2`显著波动 | 低于`S_avg`的状态成为不可忽略的阶段，`S_avg`仍是主要状态但并非稳定保持 |
| `K1`接近失守 | 较大时段或主要区域低于`S_avg`，但尚不足把`S_avg`本身改判为更低档 |
| `K0`末期逆转 | `S_end<S_avg`且交班低位是实际逆转或系统崩溃，不是窄时点缺证 |

裁决顺序固定为：

```text
先定S_avg
→ 将负面事实转换为对应时空阶段的状态
→ 比较该阶段与S_avg
→ 只按低于S_avg的程度和持续范围确定K
```

以下事实不得降低K：

- `S0`较低或重建尚未完成；
- `S0`高于`S_avg`，但下降已经由三锚轨迹消费；
- 只能解释为何没有进入更高档的材料；
- 本档本来就包含的困顿、脆弱或结构裂缝；
- 材料稀疏、恢复未证、负面材料较多；
- 灾害次数、战争次数、WC数值或诏令数量。

低档平盘者可以是K4，表示其低档状态没有再次被跌破；K4不抬高状态分，也不把稳定的C1-1/C1-2奖励成高档。`S_end<S_avg`造成的K0只标记轨迹逆转，连续计分不得对同一末期损害重复扣分。

### 8.3 C1连续分数候选公式

`S_avg`基础分为：C1-1=5、C1-2=18、C1-3=21、C1-4=43、C1-5=61、C1-6=70。C1-3只表示生产恢复和社会基本运行，守成难度很低；C1-4“普遍温饱”仍有22分的明显跃升，但不再以27分悬崖制造相邻排名断层，C1-5以上再评价富庶和顶峰。生成器必须验证，从C1-1短期重建到C1-2的样本仍高于无升档、无下滑的C1-3平盘样本。

相邻升档价值依次为：1→2=8、2→3=10、3→4=12、4→5=14、5→6=16。升档越高，准入材料越严格，成立后的边际价值也越高；生成器必须验证同持续性下`2→4→5`严格高于`3→4→5`。

持续系数：`END_ONLY=0.15`；其余为`min(1, 0.20 + 1.30 × reign_share_lower_bound)`。逐级升档只有在目标档不高于`S_end`时才进入`trajectory_gain`；已经被交班状态跌破的临时高档只由`S_avg`基础分消费，不再重复领取重建奖励。

若阶段结果与交班锚共同确认同档，允许用有约束的历史推断夹定持续下界，不要求任期每年都有独立宏观总评。仅有单点材料且交班锚也只是“无反证”时，仍不得静默外推全任。

交班时仍保留的升档兑现值乘1.9后加入`S_avg`基础分，正面部分先截到70分；提高轨迹权重用于抵消C1-4基础分下调，避免只把原断层转移到高分区，同时继续承认长期低位重建。不按低起点另设上限。生成器必须验证，C1-1→C1-3的长期稳定重建严格高于无升档、无下滑的C1-4守成。封顶必须发生在下滑和K扣分之前，避免溢出的升档奖励吞掉稳定性损失。

`S0>S_avg`时，先计算逐级档值之和的50%，再乘下降归责系数。归责只设三类：`DIRECT=1.0`、`MIXED=0.5`、`EXTERNAL_DOMINANT=0`。必须逐人保存归责理由；自然灾害、外来冲击主导且响应未放大损害时，不把状态落差转成皇帝负贡献。

K按`S_avg`消费档内稳定性：K4/K3/K2/K1分别扣0/1/3/6分；K0按`S_avg`跌到`S_end`所跨的完整逐级档值再乘下降归责系数。于是末期逆转越深、责任越直接，扣分越大；低档本身不会因为材料较多被重复扣低。

```text
score = clamp(
  min(70, state_base + 1.9 × trajectory_gain)
  - 0.50 × starting_decline_path_value × starting_attribution
  - K_penalty,
  0, 70
)
```

秦至唐95人三路输入共形成644个人物—事件簇。正式化前逐簇检查其在三锚、升档持续性、限制升档或K中的消费位置，未发现独立于这些状态结果的C1余额，因此本轮直接贡献余额正式结算为0。这不是默认忽略政策和工程：高强度工程、战争后果和赈济结果均须在相应状态或K理由中明示；以后新增材料只有证明独立结果且通过同样去重，才可重开余额。

## 九、去重与直接余额

同一事件簇按以下顺序消费：

1. 先进入阶段状态；
2. 不足改变`S_avg`但形成相对低位阶段时进入K；
3. 仍有未被宏观状态解释的独立结果时，才进入直接贡献余额。

结果不能同时在状态、K和直接余额中重复扣加。战争收益不能冲销已经发生的人员和民生损害；财政收入不能冲销压力向民间的转嫁。

C1连续分数已经完成正式文档结算，但仍不写数据库或第二项总排名。正式化门禁包括：排除14名方向校准样本后对其余81人的非定向结构审计、644个人物—事件簇的直接余额去重，以及高、中、低档和反常样本复核。

## 十、C2经济财政定档与连续分数

C2仍使用`S0/S_avg/S_end`，但不继承C1档位。生产、市场货币、常规财政与长期可持续性是四个判断面；单有国库、户籍、低粮价或一项制度不得独立上高档。

| 档位 | 精确边界 |
| --- | --- |
| C2-1 失灵崩解 | 生产、交易或常规财政已广泛失灵，币制、税基、仓储或征收体系至少两面出现系统性断裂。 |
| C2-2 汲取脆弱 | 国家仍能取得收入或维持局部生产，但主要依赖加派、贬币、强制转输等透支方式；市场、民间生产余量或财政储备明显不足。 |
| C2-3 基本运行 | 常规生产、交易和税收能够继续，或从战乱低谷恢复至可运行；积累、跨区调度和抗冲击余量仍有限。 |
| C2-4 健康稳定 | 广域生产、市场货币和常规财政总体稳定，正常支出不以持续透支民间为前提，并有可验证的储备、调度或恢复能力。 |
| C2-5 富实强健 | 至少三面长期处于高位，公私积累或生产流通相互印证，经历冲击仍能维持；存在重大区域失衡或持续额外汲取即不得入档。 |
| C2-6 结构顶峰 | 四面均有独立广域强材料，长期高位且公共财政、民间经济和市场繁荣不相背离。秦至唐只允许极少峰值阶段进入，不因盛世标签授予。 |

三锚缺证时按以下顺序补齐：相邻交接锚点；同一任期的广域结果；生产、币制、税制和仓储的相互制约；已有战争、工程的实际经济后果；最后才用政权连续性。推断可以降档；升至C2-5至少需要两类独立宏观结果，升至C2-6必须满足本档全部条件。

C2以`S_avg`为状态底分，并另计真实升档、起点回落和相对`S_avg`的稳定性。正式参数为：

| 项目 | C2-1 | C2-2 | C2-3 | C2-4 | C2-5 | C2-6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 状态底分 | 2 | 8 | 17 | 27 | 34 | 40 |

相邻升档价值依次为`4/5/6/7/8`分；持续系数沿用第八节的事实口径，升档奖励为`1.25 × 各级已实现升档价值之和`。只有目标档不高于`S_end`的升档计入奖励，短期峰值只留在`S_avg`。正向部分先封顶40分。

若`S_avg<S0`，按相邻路径价值的`0.5 × 责任系数`扣分；责任系数仍为直接1、混合0.5、外部主导0。稳定性以C2自身`S_avg`为参照：`K4/K3/K2/K1`分别扣`0/0.5/1.5/3`分；`K0`按`S_avg→S_end`相邻路径价值乘责任系数扣分。战争和工程只有已证生产、交易、财政或储备后果才能进入该处，单纯成本档不直接扣C2。

因此C2最终分为：

`clamp(min(40, 状态底分 + 1.25 × 保留升档价值) - 起点回落扣分 - K扣分, 0, 40)`。

## 十一、D2交班韧性定档与分数

D2不再计算任内平均，也不奖励从低位上升本身；只回答交班时社会能否继续承压、恢复和运行。C1、C2的`S_end`是约束输入，不是按比例重复折算。

| 档位 | 精确边界 |
| --- | --- |
| D2-1 韧性崩解 | 交班时广泛流亡、相食、叛乱基础、财政或救济失灵已经使社会继续运行能力断裂。 |
| D2-2 严重裂损 | 大范围民间余量耗尽或财政压力下沉，恢复渠道很弱；政权仍存在不等于社会具有恢复能力。 |
| D2-3 脆弱可续 | 基本生产和社会组织尚能继续，但家庭、仓储、财政或救济中至少一面余量偏低，遇新冲击容易再度恶化。 |
| D2-4 可恢复交班 | 民间与财政基础均未出现主导性断裂，救济、仓储、调运或复业机制至少一项可运行，继任者可在既有基础上继续治理。 |
| D2-5 强韧交班 | 家庭余量、公共储备与恢复机制多面相互支持，并有吸收较大冲击后仍恢复或保持的结果。 |
| D2-6 极强缓冲 | 多次重大冲击下仍证明广域恢复和制度传导，交班时公私余量均强；仅凭长期安定或库藏充盈不得进入。 |

裁决顺序为：先看交班前直接社会结果；再看运行中的赈济、仓储、复业和跨区调度；再用C1、C2终点检查家庭与财政是否存在硬约束。无直接韧性材料时，必须精确定档：以两个终点和相邻阶段连续性作推断，并标记`TERMINAL_CONSTRAINED_INFERENCE`。缺乏独立恢复结果时，D2不得高于`min(C1_end+1, C2_end+1)`；若其中一面低两档以上，除非有直接缓冲证据，D2不得高于较低面一档。

D2各档分数区间为`0—3.9/4—7.9/8—11.9/12—15.9/16—18.9/19—20`。档内位置从0.50起算：交班广域直证`+0.15`，任内实际吸收重大冲击并恢复`+0.15`，仅靠连续性推断`-0.15`，次要维度存在接近降档的裂缝`-0.15`；位置限制在`0.15—0.85`。这些因素只决定档内位置，不得跨档。

同一损害在C1/C2已作为平均状态或K消费后，D2只消费它在交班时是否仍留下恢复能力裂缝，不重复扣事件本身；同一赈灾措施在C1/C2已解释结果后，D2只消费交班时仍在运行的缓冲机制，不重复奖励政策动作。

## 十二、输出与验证

每位皇帝至少输出：

- 三锚、主档、置信度和可审计理由；
- 直接史料原文或有约束推断线索；
- 每一级升档持续性；
- `stability_reference_band=S_avg`、K值及低于`S_avg`的事实；
- 战争成本在复核、状态或K中的唯一消费位置；
- 材料局限和去重说明。

正式生成物必须满足：95人唯一覆盖、链接和JSON有效、UTF-8无BOM、`git diff --check`通过、生成器重复运行结果一致。未通过门禁时只能称候选定档，不能写正式分数或排名。
