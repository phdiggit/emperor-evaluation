# 第二项C1/C2/C3/C4治理结果规则与结算合同

本合同用于皇帝第二项治理结果层C1、C2、C3、C4正式结算。C1/C2/C3只计绝对主态，C4独占可归责恢复、稳定承压、可归责恶化与破坏性放大，旧D2退出独立计分；治理结果层上限220分，并与治理手段165分、交接质量20分共同形成405分可排序上限。评价范围与人数只读取`config/project.yml`登记的正式机器入口及其当前正式池，不在合同中硬编码。现有共同语料按同一门禁整改；材料沉默、缺少新增字段或私人巨富现象本身都不得自动改分。数据库写入仍关闭。

## 一、评分边界

- C1民生福祉绝对状态（80分）：普通家庭在整个统治期实际获得的温饱、物质余量、赋役承受和人口再生产。
- C2经济活力与财政健康绝对状态（35分）：生产、流通、货币、税制、常规财政、储备和长期承受力。国库充盈不等于民富，极端汲取不得抬档。
- C3社会安全绝对状态（60分）：人身财产安全、基层秩序、司法救济和社会可预期性。
- C4社会恢复、承压与可归责恶化（最高45分，最低-45分）：正向结算本人可归责的净恢复、稳定兑现与实际压力吸收；负向结算本人造成或显著放大的状态恶化、破坏性动员与失败后继续加码。绝对高位或低位本身不重复得分。

战争胜负、安全收益和投入是否值得归第三项；本合同只消费百姓和财政承担的资源成本及其实际后果。第三项取得的安全收益不能冲销第二项的财政民役成本；统一、创业和兼并战争是否排除，仍按各项既有适用范围处理。

同一事实可以被不同评分项引用，但每项只回答自己的问题，同一种收益或损害在同一分项内只能结算一次。C1/C2/C3的主态分回答“任内主要状态有多好”，C4负向分回答“本人使可比起点恶化了多少、又在多大程度上主动制造或放大了该恶化”；两者不是同一量，但同一后果不得再拆成事件数量累扣。

## 二、正式输入与证据优先级

只接受：

1. 政书底账中已经裁决的正式节点；
2. 通鉴财政民生接入裁决及原通读卡定位；
3. 战争成本底账中最终`war_event_id`对应的`READY_COST`父事件；
4. 为补齐状态锚所作的有约束推断。

`HOLD`、拒绝节点、未执行政策、单帝专题排除材料和未完成父级去重的战争记录不得进入结算。

证据优先级为：

1. 史家、政书或第三方叙述中，明确覆盖天下或主要统治区的宏观状态及其转折；
2. 跨年份连续的粮价、生产、赋役、流亡、市场、家庭生计和社会运行结果；
3. 能与其他结果互证的区域或单轴材料；
4. 臣子奏议、诏令自述、直接政策、工程和战争后果；
5. 继承状态、治理时间、治理方向和安全环境组成的受约束推断。

这里的优先级是证明力而不是篇数权重。同一宏观总评可以闭合多个实际结果轴；臣子奏议主要用于定位问题、政策背景和可能的结构裂缝，除非另有第三方叙述或已实现后果互证，不得把奏议中的典型户、修辞数量或劝谏逻辑直接当作全国状态。是否存在敢于直谏的臣子、奏议是否保存，不得使任何皇帝自动获益或受损。

既有朝代政书宏观卡是当前证明力最高、比较口径最统一的材料，但不是封闭语料边界。人物缺少合格宏观锚、现有推断链不能闭合唯一档或高档门禁需要补强时，允许联网检索正史、实录、编年史、政书、诏令奏议原文以及有明确史料依据的现代专业研究。搜索结果页、百科、普通网页总结和模型概述只能作定位线索，必须回到可核验原文、版本或研究结论后才能进入裁决。

联网补证按“缺口优先、朝代成组、最小充分停止”执行：优先处理`NO_MACRO_ANCHOR`和链式推断风险人物；同一批次兼看其前任、后任及同朝可比人物，避免只为某一高分候选选择性加料；一旦材料已经足以闭合人物窗口、结果方向、唯一状态档和不确定性，即停止扩搜，不要求重建逐年社会经济史。没有找到宏观总评不得封死档位，仍可依第7.2节用多路实际结果和王朝曲线作受约束推断。

政策颁布、仓库数字、户籍数字或事件数量都不能单独替代宏观状态。材料稀疏降低置信度，不自动降低状态档或稳定性；同样，负面记载稀少不证明徭役轻、分配好或没有结构压力。

### 2.1 跨时期统一状态口径与规模转译

C1、C2、C3档位不按年代先后递增门槛。跨时期扩展继续使用三锚、状态证据门和王朝曲线，不另建时代修正系数；恢复幅度和K统一进入C4。

人口、户口、田亩、税收、库藏、贸易和货币等规模总量不得跨时期直接比较，也不得因后期统计更细、辖境更大或货币化程度更高而自动升档。优先转译为普通家庭或人均实际负担、覆盖人口与地域、生产和市场安全、公共收入相对于常规责任的充足度、真实储备及公私余量；缺少可比数量时，可以使用范围与时期明确的定性宏观结果和多轴互证，不要求补造现代统计，也不因无法量化而自动降档。

最高档的“罕见”以当前统一评价全集为比较范围；扩展评价人口时必须同步复核既有最高档边界和相邻高位人物，但不得为了给新增时期预留位置而反向压低既有真实状态。

## 三、状态证据与直接贡献

### 3.1 状态证据

状态材料按用途分为：

| 类型 | 用途 |
|---|---|
| `STATE_ANCHOR` | 范围、时期和实际结果足以直接锚定`S0/S_avg/S_end` |
| `STATE_SUPPORT` | 单轴、宽时段或次一级范围，只用于加强或限制主锚 |
| `LOCAL_ONLY` | 只描述局部地区或群体，不外推全国状态 |
| `CONTRIBUTION_ONLY` | 证明措施或局部公共结果，不替代总体状态 |
| `CONTEXT_ONLY` | 只说明天灾、战争环境、前朝遗产、意见或未执行计划 |

宏观状态优先于由零散政策数量合成的推断。跨任期材料优先按可定位阶段拆分；无法逐年拆分但明确描述连续数任之间形成的长期状态时，可以同时约束该时期的王朝曲线，不得仅因某一任缺少窄时点材料而制造无实际转折依据的降档再升档。该材料只证明状态延续，不把后任的新增治理功劳追授前任，也不使每位皇帝重复领取同一贡献。

### 3.2 逐条证据语义与可证明范围

逐条材料固定按以下顺序裁决：

```text
identity_window_gate
→ macro_anchor_specificity
→ proof_scope_constraints
→ attribution
→ 状态、K或直接余额的唯一消费位置
```

`identity_window_gate`只允许`ELIGIBLE / BACKGROUND_ONLY / REJECT`。异政权、异人物或超出本人窗口的材料不得成为本人直接状态证据；前任、后任和泛朝代结构只可作起点或背景。

跨越前后任的综合叙述必须拆分本人窗口与继任窗口的可证明范围：继任期才完成的耗尽、恢复或崩解不得倒算给前任。正史、政书对转折起点存在冲突时，须保留`CROSS_BOUNDARY_SOURCE_CONFLICT`并只消费各说共同支持的最小结论；不得选择其中更有利或更不利的一说直接定档。

`macro_anchor_specificity`固定为：

| 值 | 边界 |
|---|---|
| `NOT_APPLICABLE_AFTER_IDENTITY_GATE` | 材料已被判为异人物、异窗口或仅背景，停止在身份门，不参与本人宏观性和分数判断 |
| `NO_MACRO_ANCHOR` | 当前人物—赛道没有通过身份窗口门且达到宏观门槛的材料 |
| `LABEL_ONLY` | 只有“大治、富实、民安”等标签，未闭合范围或可观察结果轴 |
| `NON_MACRO_RESULT` | 政策、诏令、制度、局部事件、单项数字或私人个案，没有描述宏观状态 |
| `SCOPED_MACRO_SUMMARY` | 本人窗口和适用范围可闭合，至少有一个可观察宏观结果轴 |
| `BOUNDED_MULTI_AXIS_MACRO` | 本人窗口、主要范围和适用边界明确，并闭合至少三个相互独立的结果轴 |

材料使用`direct_anchor_evidence`或`direct_evidence`容器不等于已经成为直接宏观锚。人物—赛道必须另存`best_macro_anchor_class`；只有`ELIGIBLE`的`SCOPED_MACRO_SUMMARY`或`BOUNDED_MULTI_AXIS_MACRO`可以生成该值。没有合格宏观锚时可以按7.2作受约束推断，但不得继续标为`DIRECT_MACRO_ANCHOR`；`LABEL_ONLY`只能作方向线索，不能独立支持高档、持续性或多轴结论。

户口、著籍、垦田和田亩数字另受`REGISTRATION_VISIBILITY`限制：

`登记户口或田亩 = 真实人口或土地 × 政权控制覆盖 × 清查登记强度 × 申报服从度 × 档案与统计口径`

清查、检括、按比、进户、土地制度、辖境或统计口径变化前后，不直接作跨期、跨朝数值比较。户口与田亩的绝对量或增减不得独立证明人口增长、生活改善、农业增产或农户收入；它们可以证明财政登记面、行政控制覆盖或赋役可见度，也可以与粮价、丰歉、复业、储备、流亡、饥疫和实际负担等独立结果互证。战争期户口骤降是死亡、流亡、失控、逃籍和档案崩解的混合结果，可以证明国家社会基础断裂，不等同精确人口死亡率。

赋役、土地兼并和贫富分化采用结果门，不新增独立加扣分轴：

- 史料未提徭役，不得推定轻役，也不得按时代常态统一推定重役；材料沉默只降低置信度，不得成为相对于有直谏记载皇帝的比较优势。
- 减役、免役诏令和法定役额只证明政策；谏疏对劳役、兼并或贫富的概括先标`REMONSTRANCE_WARNING`，其典型户模型和修辞数量不能直接升级为`REALIZED_LABOR_BURDEN`或`REALIZED_DISTRIBUTIONAL_HARM`。
- 已经出现误农、卖产、鬻子、失地、流亡、死亡、生产破坏或广域家庭余量下降时，按实际时空范围进入状态或K。
- 私人巨富、豪奢、个别豪强或财富集中本身属于`ELITE_WEALTH_ONLY`，既不证明普通百姓富足，也不证明普遍贫困，不进入C1/C2。
- 土地兼并或贫富分化只有已经传导为普通家庭失地和生计恶化、税负向编户转嫁、民间生产受损、财政税基空洞或交班社会裂缝时，才按`REALIZED_DISTRIBUTIONAL_HARM`消费。
- 同一负担或分配后果已经由`S_avg/S_end`或K吸收后，不再进入直接余额重复扣分。

这套限制只约束材料能证明到哪里，不要求为正式池补建逐年役期、完整土地关系、私人财富谱系或考古—墓志社会史。现有共同语料不足时保留`UNOBSERVED`，只有可能改变档位且当前推断无法闭合的个案才允许最小定向补证。

### 3.3 直接贡献强度

政策、工程和财政措施不能按“每条材料同档”处理。每项独立结果至少保存：覆盖人口、地理范围、持续时间、收益或损害深度、实现阶段、责任和置信度。

正负结果统一采用`PI0—PI6`、`NI0—NI6`：

| 档 | 一般边界 |
|---:|---|
| 0 | 只有主张、风险或方向，实际结果未知 |
| 1 | 单点、短时、轻微结果 |
| 2 | 已有明确家庭、生产或财政结果，但覆盖有限 |
| 3 | 区域性或持续性结果，足以改变一个状态子轴 |
| 4 | 跨区域、多年或深度损害/收益，明显影响阶段状态 |
| 5 | 广域、长期、结构性结果，影响主要统治区 |
| 6 | 全国性、跨代或系统性结果，改变整体状态轨迹 |

`PI/NI`只作为判断结果能否改变raw三锚或K的证据强度标签，固定保存`scoring_role=DIAGNOSTIC_ONLY`。C1不设档内直接贡献余额，政策方向、诏令数量、史料篇幅和新增材料均不得在固定主档分之外加减分；独立动态结果按边界进入C4或其他对应分项。

## 四、工程与其他非战争汲取

本合同不要求为正式池穷举宫室、陵寝、道路、水利、封禅等工程，也不要求估算缺失的工程量。工程同时记录公共收益和施工成本，两者分别裁决，不能互相冲销；但只有第三方宏观叙述或可观察结果证明其已经改变主要区域的财政、生产、家庭生计、死亡流亡或阶段状态时，才进入raw `S_main/S_end`或K。臣子奏议中的劳役警告、工程名目和动员数字可触发复核，不能单独代替宏观后果。对C4破坏性放大门，已确认由本人选择实施的大型营造本身即有可预见的财政、材料、运输与役工成本；没有另存一条“征发”原句不等于成本为零，但仍须按工程规模、重复性、是否停止和公共用途裁定DA，不能按工程名称计数。

多个已知大型工程、战争和其他汲取可以组成同一阶段的负荷背景，用来检查既定档位是否自洽；不得按项目数量机械累加，也不得因为其他皇帝的工程没有同等暴露就对记载丰富者作额外惩罚。公共收益和损害已经被宏观状态吸收后，不再进入直接余额重复结算。

当直接宏观材料不足时，允许建立人物窗口及朝代阶段的“成本画像”，但只作状态推断的约束项，不把成本低直接等同于民间富庶。成本画像至少分开记录：既有战争父事件的实际财政民生负荷、集中营造与公共工程、皇族宗室及外戚的制度性汲取、国家可见的财政组织与救济能力。每路使用`HIGH / MATERIAL / LOW / UNOBSERVED`四态；`UNOBSERVED`不得解释为`LOW`，工程名目、战争次数、宗室人数和史料篇幅不得机械相加。

成本画像按“公共成果先行、可能改档才补证”执行：战争路直接读取已经闭合的公共成本登记，不重做战史；营造和宗室汲取先查共同政书、本纪、编年和现有治理底账，只在其可能改变档位时作最小联网定位。工程必须同时区分征发成本与实现后的公共收益；皇族、宗室或外戚富贵只有形成制度性供给、赋役转嫁、财政挤压或普通家庭实际损害时才进入画像，私人巨富和一般优厚待遇本身不计。

## 五、战争成本接入

战争成本沿用战争卡已经裁决的`P/S/M/A→WC0—WC7`，财政民生链不得重估或相加`ΣWC`。只有最终父事件的实际后果可以消费；人员、军费、粮运、物耗和附带损害不得拆卡重复累计。

战争成本归责不以“另有史料直书征兵、征粮或徭役”为准入门。正式战争父链已经闭合本人发起、授权、再授权或维持的非必要进攻、扩张、惩罚性远征时，维持军队、军粮、转输和装备的通常可预见成本即进入C4的破坏性放大复核；可以依据正式父链已有的动员层级、持续期和重复性判断相对强度，但不得虚构精确人数、钱粮或民役数量。这类成本只进入DA，不凭推断直接改写C1/C2/C3绝对状态，也不重复计入恶化档差。

逐条战争父链必须先作选择性质裁决：

- `UNAVOIDABLE_DEFENSIVE_ENGAGEMENT`：敌军已经侵入、直接压迫国家或主要统治区，且大规模接战属于当时无法合理回避的防御需要；必要动员基线不作战争成本归责。若在必要防御之外存在错误部署、无效重复动员、拒绝和议、过度追击或风险反馈后继续扩大，超出部分仍复核。
- `DISCRETIONARY_OFFENSIVE_OR_EXPANSION`：本人主动选择进攻、扩张、惩罚性远征或在已有退出条件下继续战争；通常可预见的财政民役成本应归责，不要求另有征发原句。一次有限行动通常从DA1复核，重复远征、失败后再授权或长期维持进入DA2以上复核。
- `MIXED_SECURITY_AND_EXPANSION`：既有真实安全压力，又包含可选择的前推、扩大战果或延长战争；只豁免必要防御基线，对可选择增量作共享或分段归责，不得把整条链一概写成防御豁免。

战果高、战争最终值得或第三项D档高，均不自动加重或免除本项成本；唯一可以整段不作通常战争成本归责的，是已经闭合的必要防御接战。材料没有记载动员峰值只限制强度上推，不能把已经闭合的主动战争成本改写成`DA0`。

战争成本在C1有三级用途：

1. 只有WC档位、动员或支出压力而没有实际民生后果时，只触发复核；
2. 后果足以改变主要统治区或主要持续阶段时，直接进入`S0/S_avg/S_end`；
3. 后果不足以改写全国`S_avg`，但证明某个区域或短时阶段实际低于`S_avg`时，进入稳定性K。

第三级是战争成本除复核门之外的正式用途。例如全国`S_avg=C1-4`，边疆战争已经造成人口被杀掳、牲畜损失和生产中断，但不足改变全国主态，可以据此降低K；若这些后果只说明为什么不能进入C1-5，则已被`S_avg`吸收，不再影响K。

WC数值、战争次数和战争胜负本身都不能机械改变C1。同一战争后果一旦用于状态锚或K，不再作为独立负面贡献重复扣分。

第三项军事成本达到C6/C7且C1同时为raw/formal高档或K4时，必须触发跨项强制复核；所有`raw_state_band / formal_band / raw_peak_band`任一达到C1-5/6的人物，不限成本档，均进入高档军事成本复核队列。复核读取第三项主要战争父链，区分必要防御与可选择进攻/扩张，对C4以上成本定向检查兵役、军粮、转输、征发、逃役、弃业、流亡、卖产、死亡、家庭劳力及继任初承接状态。军事成本档本身绝不改C1/K；只有已实现家庭结果才能进入raw阶段、`S_end`或K。高成本而未找到同尺度后果时，必须标记负证覆盖与史料密度不足并降低置信度，不得以材料沉默自动给K4。仅有奏疏警告通常只触发复核；压低高档终点或判K0/K1原则上需要第三方实际结果、跨阶段互证或继任初承接证据。

## 六、天灾、外部冲击与责任

天灾发生本身不记皇帝负面贡献。只评价：

- 是否存在可行预防却拒绝执行；
- 是否及时赈济、减免、调粮和安置；
- 是否以加征、强役、封锁或行政失灵放大损害；
- 灾后是否恢复生产、人口和社会运行。

灾害造成的实际状态可以作为时代状态证据，但自然原因不转化为皇帝直接负贡献；有效赈济和恢复可以计正面结果。战争、前朝结构和既有财政条件同样先记录外部起点，再判断本人的响应、放大和恢复责任。

C4负向归责固定为`FULL / MATERIAL / NONE`三档：

- `FULL`：本人直接发起或反复维持主要致损行动，已有实际后果和反馈，仍继续、扩大或拒绝可行纠偏；按1.0计入相应轴的恶化档差。
- `MATERIAL`：前代结构、天灾、外敌或其他权力主体是重要共同原因，但本人选择明确放大损害或阻断恢复；按0.5计入。
- `NONE`：损害主要在本人实际权力窗口前形成，或主要由不可控制外因造成，未闭合本人显著放大；不计负向档差。

归责不明时取较低档并保留理由，不得用亡国、灾害、战败或末档本身反推`FULL`。反过来，成熟高位承接者在多年内反复发动超常工程、战争和汲取，已有广域民生财政后果且在劝止、失败或组织失灵后继续加码，可以闭合`FULL`；工程名目和军队人数仍只作动员规模佐证，必须与实际死亡、破产、生产中断、财政耗竭、流亡或秩序崩溃互证。

## 七、C1三锚与六档

每位皇帝必须保存两层状态：

- `raw_state_band`：普通家庭绝对生活状态，是三锚、K、交班和C4的唯一状态口径；
- `complexity_class`：`LOW / MEDIUM / HIGH`，按实际控制人口、地域跨度、多经济区或多核心、族群与制度异质性、行政链长度、边疆及运输协调综合裁定，不按名义国号或面积单判；
- `formal_band`：复杂度认证后的C1正式计分档，兼容字段`main_band`必须与它同值；
- `complexity_basis`：复杂度档及是否折算的可审计依据；
- `S0 / S_avg / S_end / raw_peak_band`：全部保存raw绝对状态；`S_avg`的业务语义是`S_main`，不是逐年数学平均；
- `formal_peak_band`：仅供展示，不得进入K、交班或C4；
- `confidence`与材料局限。

高复杂度政权的raw档可以原档计分；低复杂度政权进入高档时原则上`raw=C1-5 → formal≤C1-4`、`raw=C1-6 → formal≤C1-5`；中复杂度是否折算须按证据覆盖与实际治理范围逐人裁决。`formal=C1-6`只允许“raw极盛 + HIGH复杂度”。复杂度回答“高位在多难治理的盘面上实现并维持”，C4回答动态恢复与稳定性，两者不重复。

### 7.1 C1状态六档

| 档位 | 状态边界 |
|---:|---|
| `C1-1`崩溃 | 大范围家庭衣食断裂、饥饿死亡、卖产鬻子或逃散成为主要状态，家庭形成与劳动力再生产显著失守 |
| `C1-2`广泛困顿 | 多数家庭长期难以稳定维生，净税役负担、破产、流亡或家庭劳动力损失广泛存在 |
| `C1-3`基本维持 | 多数家庭可维持基本衣食和家庭劳动力，但可保留资产、物质余量及对额外税役的承受力有限 |
| `C1-4`普遍温饱 | 主要统治区多数家庭稳定温饱，基本生活资料可得，净税役未普遍压穿家庭维生，家庭形成与再生产总体可维持 |
| `C1-5`富庶 | 普遍温饱之上存在广域、跨阶段的家庭粮储、衣食余量、可保留资产或民间财富，并至少另有一类纯C1结果轴互证 |
| `C1-6`极盛 | 三类纯C1结果轴均达到罕见的广域、长期强宏观门，且家庭余量轴有直接强锚；不得由一般盛世标签或纯推断取得 |

C1只允许三类结果轴：`HOUSEHOLD_SUBSISTENCE_SURPLUS`（家庭衣食、粮储、生活资料、可保留资产与物质余量）、`NET_TAX_LABOR_BURDEN`（税赋、徭役、兵役落到家庭后的净承受结果）、`HOUSEHOLD_FORMATION_REPRODUCTION`（婚育、家庭劳动力维持、家庭形成与人口再生产结果）。生产、市场、财政材料只有明确传导到家庭消费、储蓄或净余量后才可进入第一轴；治安与人身财产安全完全归C3；动态抗冲击完全归C4。“谷贱、农人少利”原则上是市场健康与交换条件阻断点，只有继续闭合负债、卖产、衣食不足或流亡等家庭后果时才回流C1。

每条可观察结果必须保存`result_axis_owner`；人物级保存`lane_axis_coverage`。`BOUNDED_MULTI_AXIS_MACRO`只是通用材料等级，不自动满足C1多轴门；综合总评必须能拆出不同的纯C1实际结果语义，单一“富庶、大治、民安”标签不得技术拆轴。C1-5必须有直接、广域的`HOUSEHOLD_SUBSISTENCE_SURPLUS`核心锚，并至少再闭合另一纯C1轴或明确跨阶段持续；没有该强锚时受约束推断最高C1-4。C1-6必须三轴全部过强宏观门。晚于峰值的转折进入K或终点，不回溯抹除已实现峰值；峰值同时保存`raw_peak_band`与只供展示的`formal_peak_band`。

C1-6始终可达，不要求当前正式池必须有人占档。新增高档材料必须同步检查相邻统治期及最接近高档人物的同尺度反证，防止选择性深挖；不要求为全池追加同等篇数。

### 7.2 缺证推断

锚点不能空置。缺少直接宏观材料时，依次使用：

1. 前任`S_end`的连续继承；
2. 任内已有多路实际结果；
3. 有效治理时间和结果出现时间；
4. 工程、战争和财政后果；
5. 治理方向及同政权前后状态约束。

上升证据不足取较低档；下降可以由明确、持续的实际后果推断。这里的“证据不足”是指既有材料、最小联网补证和可用推断仍不能闭合目标档，不是“当前宏观卡没有原句”。推断必须给出唯一档、置信度和依据，不用事件数量代替状态。

每个推断锚必须保存`inference_source_anchor`、`inference_hops`和`inference_basis`。前任`S_end`可以一跳成为后任`S0`；如果前任`S_end`本身主要由连续性推断形成，后任只能把它作为低置信起点约束，不得再把它作为后任`S_avg`、`S_end`、升档持续性或高档准入的唯一依据。连续两任都缺直接或多路结果时，必须标记`CHAINED_INFERENCE_BLOCKED`并停在最后一个有独立事实支持的档位，不得沿王朝标签传播高位或低位。

连续性推断只补状态闭合，不生成额外史实。它可以帮助确定C1-1—C1-4的唯一档，但不能单独支持C1-5/6，也不能单独证明任内升档已经持续到某个精确年份。

成本画像、王朝连续曲线和“未见反证”只能限制推断、检验持续性，不能替代家庭余量强锚。`COST_PROFILE_CONSTRAINED_HIGH_INFERENCE`不得在缺少直接家庭余量强锚时取得C1-5；只有政策方向、生产市场、户籍田亩、国库或材料沉默时，最高为C1-4。C1-6不开放纯推断。

### 7.3 王朝曲线与横向复核

个人三锚和主档先按本人材料独立裁决；正式池全部得到唯一档后，必须再作一次宏观曲线复核，而不是用王朝印象先行分档：

1. 真正交接边默认强制`前任raw S_end = 后任raw S0`。只有交接短窗中已有实现后果的饥荒、流亡、死亡或生活断裂，突发入侵/核心区失陷/控制骤变，实际控制范围重构、分裂或迁都，及其他有直接结果证据的急剧外生冲击才可不等；单纯灾害标签不足。例外必须保存`handoff_break_type / break_window / realized_result / evidence`，缺一即校验失败。
2. 若前后强宏观锚均处于同一高位或低位，中间短任或材料稀疏者不得仅因缺少窄时点总评而无事实地降档再回升。跨数任的第三方长期总评可以约束这段曲线，但不生成个人贡献奖励。
3. 后任即位后立刻可见的大规模财政、战争或赈济能力，可以反证其继承的国家资源下限；它只作连续性校验，不能单独证明普通家庭富足，也不能把后任成就倒算给前任。
4. C1横向比较只使用三类纯家庭结果轴；生产流通、财政可持续性和治安分别留在C2/C3，抗冲击留在C4。户籍覆盖、税收汲取能力和工程动员能力不能直接等同民生更好。
5. 曲线复核发现冲突时，优先重读已有共同语料和证据角色；仍不能闭合时，按缺口人物和相邻统治期成组开展最小联网补证，不启动逐年、全工程或全社会史扫描，也不以“现有池没有宏观总评”直接维持旧档。

曲线复核的结果必须保存`dynasty_curve_review`或等价审计记录，说明连续性、实际转折、跨任期锚和未解决不确定性。它可以纠正无依据的状态跳变，不得为了让曲线平滑而抹去已证实的真实崩溃、恢复或区域分化。

短任、摄政和复辟另执行以下结构门：

- 中间统治者即使因共同母池或实权时长规则不评分，也不得跨越；在独立`handoff_bridges`中保存`bridge_ruler / bridge_S0 / bridge_S_end / exclusion_reason`，桥接不新增评分对象。
- 被废、失权、复辟或二次在位者保存`reign_windows[]`，每窗至少含`window_S0 / window_S_end / start / end / handoff_from / handoff_to`，逐条实际交班边仍执行连续硬门。
- 摄政、共治、太后临朝等重叠实权者共享客观状态时间线，但分别保存`overlap_power_window / shared_state_anchor / overlap_with`；R9只约束真正交接边，不把重叠窗口退出伪造为继位。

## 八、持续性与稳定性

持续性与稳定性不是等权并列项：持续性只判断升档结果被观察到何种程度并是否保留到交班，稳定性再判断`S_avg/S_main`是否被实际跌破。两者都不要求重建逐年民生曲线。

### 8.1 升档持续性

凡`S_end>S0`或任内出现高于起点的阶段，必须把每次相邻升档逐级保存：

- `from_band/to_band`；
- `first_supported_observation`；
- `terminal_confirmation`；
- `persistence_basis`；
- `persistence_class`。

| 持续档 | 只要求的可观察事实 | 系数 |
|---:|---|---:|
| `END_ONLY` | 只在交班锚确认达到；不推定此前持续 | 0.15 |
| `SINGLE_PHASE_CONFIRMED` | 至少一个可定位的任内阶段直接或多路结果确认达到，且没有把单点外推为全任 | 0.40 |
| `REPEATED_PHASES_CONFIRMED` | 两个时间上可区分的阶段，或一项明确表示“累年、屡年、久行”的宏观叙述，与交班方向相容 | 0.70 |
| `MULTI_STAGE_AND_TERMINAL_CONFIRMED` | 至少三个可区分阶段，或覆盖前后阶段的明确长期叙述，并由交班锚确认成果仍在 | 1.00 |

这些系数是“可观察持续性兑现权重”，不是任期占比。不得输出`reign_share_lower_bound`、`minimum_sustained_years`或0.37、0.52之类占比小数；即使史料恰有年份，也只用于证明阶段先后和去重，不要求补齐中间年份。相同史实的重复记载不增加阶段数，同一结果轴的材料篇数不线性加权；最多使用三个代表性观察闭合最高档。

正式闭合不要求主动扫描考古报告、墓志、地方材料全集或重建逐年社会经济序列。此类材料若已有且能改变档位可以使用，但不得成为正式池统一结算的必备门槛。相邻升档价值逐级保存，越高档准入材料越严格；低位重建不能因起点低被封死上限。

### 8.2 相对`S_avg/S_main`的稳定性K

K只回答：在已确定`S_avg/S_main`后，是否有实际低于该档的可定位阶段。K不要求证明其余每一年均保持主档，也不因史料空白自动扣分。

| K | 相对于`S_avg`的边界 |
|---:|---|
| `K4`保持 | 没有有效阶段跌破raw `S_main`；负面材料只构成本档或限制更高档 |
| `K3`轻度波动 | 仅一个局部、短时或轻度低谷，影响受限且有恢复或范围边界 |
| `K2`显著波动 | 一个实质性低谷命中主要区域、持续较久、跌幅较深之一，或多个仍属局部/短时的低谷；主态代表性未受挑战 |
| `K1`接近失守 | 低位成为次级主态竞争者，原则上须在范围、持续/重复、跌幅深度三项中至少两项为强；仅两个阶段或一个主要区域不足 |
| `K0`末期逆转 | raw `S_end < raw S_main`且交班低位是实际逆转，不是窄时点缺证 |

裁决顺序固定为：

```text
先定S_avg
→ 将负面事实转换为对应时空阶段的状态
→ 比较该阶段与raw S_main
→ 只按低于S_avg的程度和持续范围确定K
```

每个进入K比较的低谷保存`stage_band / depth_from_raw_main / scope_class / duration_class / repeat_group / recovery_confirmed / evidence_strength / counts_toward_k / exclusion_reason`。`duration_class`相对于本人有效统治窗口裁定；灾害/战争次数、同一危机的重复记载不得充当repeat。新增或因主档变化触发的K1必须同步生成有效stage并即时过门，不允许先写K1后补理由。

以下事实不得降低K：

- `S0`较低或重建尚未完成；
- `S0`高于`S_avg`，但下降档差已经转交C4负向分支消费；
- 只能解释为何没有进入更高档的材料；
- 本档本来就包含的困顿、脆弱或结构裂缝；
- 材料稀疏、恢复未证、负面材料较多；
- 灾害次数、战争次数、WC数值或诏令数量。

低档平盘者可以是K4，表示其低档状态没有再次被跌破；这不改变C1绝对状态分。K只作为C4稳定兑现与压力吸收的输入，C1不再因K加减分。

### 8.3 C1绝对状态正式公式

正式固定映射为：C1-1=5.7、C1-2=17.1、C1-3=32.0、C1-4=54.9、C1-5=74.3、C1-6=80.0。分数只由复杂度认证后的`formal_band`决定，兼容字段`main_band`必须与之同值；C1-5进入90%以上区间，C1-6保留为罕见的结构顶峰。

持续性材料只决定主档升档能否成立、`persistence_class`和置信度，不形成材料密度倍率。相同主档必须同分，材料数量、观察阶段数、臣子敢谏程度和归责叙述不得另造数值差。

raw `S0`、`S_main/S_avg`、`S_end`、`raw_peak_band`、交班和K只供曲线解释与C4输入，不得读取复杂度折算后的formal档，也不得改变C1固定分。恢复、回落和长期稳定只在C4结算一次；因此C1公式为`score = fixed_base(formal_band)`。

人物身份门禁与事件簇统计属于结算审计输出，不写入合同固定人数。合格材料只在raw三锚、升档确认、限制升档或K中消费；C1永久不设直接贡献余额。高强度工程、战争后果和赈济结果仍须在相应状态或K理由中明示，但新增材料不得“重开余额”。

## 九、去重与唯一消费

同一事件簇按以下顺序消费：

1. 先进入阶段状态；
2. 不足改变`S_avg`但形成相对低位阶段时进入K；
3. 仍有未被宏观状态解释的独立动态结果时，按边界进入C4或其他分项，C1不另设余额。

结果不能同时在状态、K、C4或其他分项中重复扣加。战争收益不能冲销已经发生的人员和民生损害；财政收入不能冲销压力向民间的转嫁。

C1按统一raw绝对状态与formal复杂度认证双层口径维护：持续性只作证据门，同formal档同分，恢复与K全部转交C4。正式化门禁包括正式入口唯一覆盖、formal主档同分、人物身份与结果唯一消费、高中低档和反常样本复核，以及不同起点/终点轨迹的中立性诊断。

## 十、C2经济财政定档与连续分数

C2仍使用`S0/S_avg/S_end`，但不继承C1档位。生产、市场货币、常规财政与长期可持续性是四个判断面；单有国库、户籍、低粮价或一项制度不得独立上高档。

| 档位 | 精确边界 |
| --- | --- |
| C2-1 失灵崩解 | 生产、交易或常规财政已广泛失灵，币制、税基、仓储或征收体系至少两面出现系统性断裂。 |
| C2-2 汲取脆弱 | 国家仍能取得收入或维持局部生产，但主要依赖加派、贬币、强制转输等透支方式；市场、民间生产余量或财政储备明显不足。 |
| C2-3 基本运行 | 常规生产、交易和税收能够继续，或从战乱低谷恢复至可运行；积累、跨区调度和抗冲击余量仍有限。 |
| C2-4 健康稳定 | 广域生产、市场货币和常规财政总体稳定，正常支出不以持续透支民间为前提，并有可验证的储备、调度或恢复能力。 |
| C2-5 富实强健 | 至少三面长期处于高位，公私积累或生产流通相互印证，经历冲击仍能维持；存在重大区域失衡或持续额外汲取即不得入档。 |
| C2-6 结构顶峰 | 四面均有独立广域强材料，长期高位且公共财政、民间经济和市场繁荣不相背离。当前统一评价全集中只允许极少峰值阶段进入，不因盛世标签授予。 |

C2表中的“长期”只需由明确的长期叙述或彼此可区分的阶段结果证明，不要求逐年序列、固定年份密度或覆盖任期一定比例。

三锚缺证时按以下顺序补齐：相邻交接锚点；同一任期的广域结果；生产、币制、税制和仓储的相互制约；已有战争、工程的实际经济后果；最后才用政权连续性。C2沿用第七节的`inference_source_anchor / inference_hops / CHAINED_INFERENCE_BLOCKED`规则，不得把已由连续性推断形成的前任终点继续传播为后任任内高位。

推断可以降档；纯连续性推断最高只能支持C2-4。升至C2-5至少需要两个彼此独立的广域结果轴，且必须同时覆盖民间生产或市场与公共财政或储备；“独立”指结果轴相互独立，不机械要求来自两部史书。一条范围、时期和结果轴都明确的第三方多轴综合总评可以同时闭合公私两面，但不得把只有“富庶”“殷富”等标签的同一句话技术拆成多轴。升至C2-6必须满足本档全部条件并有多来源直接结果。国库充盈、户籍增长、低粮价或税收增长任一单轴都不得替代公私两面。

C2以全任主态为唯一计分输入。正式参数为：

| 项目 | C2-1 | C2-2 | C2-3 | C2-4 | C2-5 | C2-6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 绝对状态分 | 1.8 | 7.0 | 14.9 | 23.6 | 29.8 | 35.0 |

持续性材料只决定主档能否成立、`persistence_class`和置信度，不形成材料密度倍率。相同主档必须同分。`S0`、`S_end`和K只进入曲线解释及C4，战争和工程也只有在闭合生产、交易、财政或储备后果时才能影响主档。C2公式为`score = fixed_base(main_band)`。

## 十一、C3社会安全定档与分数

C3只回答普通人的人身财产安全、基层秩序、司法救济和社会可预期性。统一战争和对外安全收益不计入；粮价、仓储、财政充盈和单纯政权存续不能替代C3结果。采用政权共享曲线与本人窗口转折点共同裁定`S0/S_main/S_end`，前任交班与继任接班原则上不得无证跳档。

| 档位 | 精确边界 | 固定分 |
| --- | --- | ---: |
| C3-1 | 广域暴力、法外侵害或基层秩序崩解成为常态，普通人缺乏最低安全预期 | 5 |
| C3-2 | 基本秩序仍在但人身财产、司法或基层控制至少两面持续脆弱 | 16 |
| C3-3 | 主要统治区维持可运行秩序，重大侵害或司法任意仍限制更高档 | 28 |
| C3-4 | 广域人身财产安全、基层秩序和司法救济总体稳定，局部或阶段性裂缝不占主导 | 40 |
| C3-5 | 多轴长期高位且经历现实冲击仍能维持安全与救济，系统性高压或广域法外侵害不存在 | 52 |

## 十二、旧D2迁移边界

旧D2已退出独立计分。其交班窗口材料不按旧20分比例搬入C4，只用于确定C4终局低侧门、验证冲击吸收是否真实发生，并为前任终点—继任起点连续性提供约束。旧D2高档、长期安定、库藏充盈或C1/C2高终点都不能直接生成C4正分；无独立恢复结果时最多支持终局约束推断。

## 十三、C4社会恢复、承压与可归责恶化正式合同

C4为最高45分、最低-45分的目标层子项，统一消费C1民生、C2财政经济、C3社会安全三条状态曲线中的动态结果，不把旧D2分数按比例搬入。C1/C2/C3继续回答绝对状态；C4回答本人使既有状态恢复或恶化了多少、实际压力下能否吸收恢复，以及是否主动制造或显著放大压力。绝对终点高位不直接取得正分，绝对终点低位也不直接生成负分；正负都必须经过动态档差和本人归责门。

### 13.1 边界复核结论与当前状态

原`轨迹结果20＋稳定积累15＋终局余量10`公式已退出可接受候选。全池复核确认维持路线会再次消费主态/终点，形成确定性重复；旧公式及其历史分布只保留为材料审查和问题诊断，不得进入正式回放。

C1与C2不是按史料来源分家，而是按结果角色分家。共用史书本身不构成重复，但同一句笼统的“富实”、同一仓廪段或同一恢复叙述未经子句拆分而同时抬高两项，就构成重复。结构回放采用以下唯一归属：

| 结果轴 | 唯一回答的问题 | 不再消费 |
| --- | --- | --- |
| C1民生福祉 | 普通家庭实际获得的温饱、物质余量、赋役承受与人口再生产 | 生产财政系统本身、治安秩序、恢复幅度、K分 |
| C2经济财政 | 生产、流通、货币、常规公共财政、储备与调度系统的绝对健康度 | 仅有家给人足、仅有治安、恢复幅度、K分 |
| C3社会安全 | 人身财产安全、基层秩序、司法救济与受冲击后的社会可预期性 | 粮价、仓储或财政充盈本身 |
| C4恢复韧性 | 可归责净恢复、长期稳定兑现和实际压力吸收 | C1/C2/C3绝对主态、绝对终点高位 |

同一来源可以支持多个轴，但必须拆成不同子句或不同实现结果；同一结果token只能有一个计分归属。以仓储为例：日常储备和跨区调度能力归C2，实际平粜赈济改善家庭食物安全才归C1，冲击中真实调出并补回储备的动态结果才归C4。C1旧合同中“社会安定、生活安全”作为高档独立结果轴的表述已经移交C3。

### 13.2 路线与动态结果门

C4不把人物先验分成恢复型和守成型。路线的最小单元是轴或阶段：继承低位、外生冲击且响应—结果闭合者走恢复路线；没有合格重大冲击者走维持路线；本人造成或显著放大状态下坠者走恶化路线；同一人可以同时包含恢复、维持和下坠阶段。没有重大冲击既不奖励也不惩罚，已知冲击没有闭合结果时不得改称维持。本人先制造低谷再回到破坏前基线只算止损，不取得正恢复信用；短期下坠已经完全修复且没有独立长期损害时，只降低稳定承压，不再另扣终局恶化。

恢复结果必须同时满足同一对象、同一地域尺度、本人时间窗口和因果归责。跨数任的王朝恢复趋势只作背景；不能闭合本人增量时，不得在C1、C2各领一次恢复信用，也不得直接转成C4正分。前任交班与继任接班原则上同档；补终局材料优先查本纪或帝纪的即位初年承接状态，再查食货志、会要和通考。只允许继任即位短窗中明确描述承接状态的材料回填前任，继任后来创造的改善不得倒算；重叠摄政、并立和权责不清的交接不得机械回填。

发生统一战争、控制范围扩张或统计口径显著变化时，S0不得机械取即位日。用于全国或全政权横向比较的起点，应取“本人取得实际最高权力”和“第一处可与终点同范围比较的稳定控制时点”两者中较晚者；该时点仍保留的战争耗损属于继承或统一遗留基线，除非已有证据证明低位主要由本人在此前权责窗口新增造成。反向也不得把前代已经完成的休养恢复抹去：成熟承接者的S0必须高于尚未完成统一的乱世基线。不同轴可以因对象和可比范围不同使用不同起点时刻，但直接交接边不得无证跳档。当前校准锚为李渊C1/C2/C3=`1/1/1`，李世民=`2/3/2`，刘恒=`3/4/4`，刘询=`3/4/4`；李渊—李世民的C3交接保持`2→2`，其余成熟承接者相对相应乱世轴均至少高一档。

政权初期曲线另执行四项门禁：第一，称帝年数不等于实际治理窗口，只有已经取得实际最高治理权的称帝前阶段可以纳入；第二，短任本身不设机械档位上限，但两档以上跃升须有本人窗口内的广域结果，措施、政权存在或继任后的繁荣均不得替代；第三，继任即位短窗只能验证承接状态，且不得把继任改善抬入前任终点；第四，初期人物进入C4T-4以上，必须闭合本人退出窗口的家庭或民间余量、公共财政或储备余量与实际恢复机制，不能仅凭政权继续运行推断。全48条政权初期曲线按此门完成横向校准。

### 13.3 纯动态公式敏感性与材料可得性结论

`25＋15＋5`敏感性只用于验证边界方向，现已退出可接受公式候选：

| 组成 | 分值 | 业务含义 |
| --- | ---: | --- |
| 闭合净恢复 | 25 | 只消费同尺度、可归责的正档差；本人致损后回基线不计正恢复 |
| 稳定与压力吸收 | 15 | K由C4独占；C1/C2/C3不再加减K分，低状态稳定严格封顶 |
| 独立运行机制 | 5 | 试验项；因材料可得性不足和时代/名次偏差而退役，不再作为普遍独立得分 |

三轴诊断权重暂沿用C1 50%、C2 20%、C3 30%。净恢复25分由旧材料中已经闭合的恢复差单独映射，不含绝对维持等级。K0/K1/K2/K3/K4在稳定与压力吸收部分暂映射为`0/3/7/12/15`分；轴主态一至二档时最多3分，防止把稳定困顿包装成韧性。`S_end`只负责封顶或阻断，不提供正分。

旧阈值及其历史分布只作诊断，不证明当前档界正确。公式语义和量纲改变后，必须先接受结构角色，再依据当前全池校准；纯动态边界应区分“目标状态高”与“把低位真正拉回并稳定住”。

材料可得性压力测试进一步证明，机制不能作为全池普遍计分项：若按材料有无给分，会重新制造时代文书优势并把既有关注度写回分数。关键词仅用于发现，不能证明机制分成立；缺少候选必须记为未观察，不能计零分。

正式接受正负对称的两部分业务结构：正向结算“可归责净恢复”与“稳定兑现/压力吸收”，按27/18分分配；负向结算“可归责净恶化”与“破坏性制造/放大”，同样按27/18分封顶。赈济、复业、调拨、补库等运行机制，以及工程、战争、额外汲取和拒绝纠偏，只作为因果链、归责与强度门禁，不按名目数量另取固定分；没有重大冲击者不要求虚构机制材料。

两部分已完成`30/15`、`27/18`、`24/21`原始敏感性。三组均未产生唐以后均值优势，但都使原始前20完全由有恢复档差者占据，其中八人终局仅一至三档、八人只有单轴恢复。原因不只在权重：旧恢复函数含“只要恢复即从三档路线起跳”的激活奖励，且新结构尚未应用终局低侧封顶，故三组原始结果均不接受。

第三轮进一步修正等距跨档和过早封顶。恢复量仍按C1 50%、C2 20%、C3 30%加权，但先逐轴识别从`S0`到任内实际达到的最高`S_avg/S_main/S_end`，再按所跨档界累计难度：`1→2=0.6`、`2→3=0.8`、`3→4=1.0`、`4→5=1.3`、`5→6=1.6`。各轴档界难度乘轴权重后求和，恢复分为`min(27, difficulty_weighted_recovery_credit × 10)`；因此进入高档比低位复原获得更多建设信用，也不再让约1.9个等距档差直接贴近27分封顶。任内达到高点后回落不在恢复分中悄悄抹除，而由稳定承压、DA和交班下沿封顶分别处理，确保建设成果与未能守住成果可同时展示但不重复计分。稳定承压分继续由边界清洁K指数按18分线性映射，低状态稳定仍在源指数内封顶。正向终局只施加低侧封顶：C4T-1至C4T-6依次封到7.9、15.9、24.9、34.9、40.9、45分，不因高终点本身加分。原正向总分档界为8/16/25/35/41分；六档还须同时满足C4T-6、多次重大冲击和广域多轴恢复。负向分支加入后，零分以下另按第13.4节输出负向档，不与原正向六档共用门槛。

难度加权回放中，完颜雍三轴`3→4/3→4/2→4`得到难度信用1.24、恢复分12.4；刘秀三轴`1→4/1→4/1→4`得到2.40、恢复分24.0；李世民两条`2→5`主建设链并含C2 `3→4`，得到2.68、恢复分26.8。三者不再因线性档差封顶挤在25.7—27分之间。刘恒跨入五档的终局建设得到难度信用1.54、恢复分15.4；刘询为1.35、13.5。稳定承压、交班封顶与DA随后独立合成，故恢复分高不等于最终C4一定更高。

### 13.4 负向动态公式与破坏性放大门

逐轴先计算经归责折算的终点恶化：

`axis_deterioration = max(0, S0 - S_end) × attribution_factor`

三轴合成为：

`weighted_attributable_deterioration = 0.5×C1 + 0.2×C2 + 0.3×C3`

负向档差分为：

`deterioration_penalty = min(1, weighted_attributable_deterioration / 2.0) × 27`

破坏性制造/放大另按0—18分裁决，只回答本人是否把原本可维持或可控制的压力主动变成更大、更久、更广的实际损害，不重复回答状态下降了几档：

| 档 | 扣分 | 门槛 |
|---:|---:|---|
| `DA0` | 0 | 未闭合本人可选择的致损行为；已见战争均为必要防御基线，或仅有继承低位、不可控外因且未见本人放大。材料不足本身不能证明DA0。 |
| `DA1` | 4.5 | 单一阶段或有限范围的错误选择造成已实现损害；或一次本人主动选择的非必要战争/大型工程形成通常可预见成本，后续停止、纠正或未继续扩张。 |
| `DA2` | 9.0 | 本人反复维持一条主要致损路线，收到风险或失败反馈后纠偏不足；包括重复远征、再授权、长期前推或同一路线营造，形成重大但仍有明显共同原因的损害。 |
| `DA3` | 13.5 | 多阶段或多通道持续加码，战争、营造、币制或其他汲取的跨区域成本相互叠加，并在反馈后继续，成为系统恶化的重要主因。 |
| `DA4` | 18.0 | 罕见的系统性自造或放大崩溃：承接可运行或高位盘面，长期同时发动多条超常汲取、工程或战争动员，广域死亡、破产、生产财政断裂与秩序崩溃互证，且多次失败、劝止或组织失灵后仍继续。 |

`DA1`不是“在位即有成本”的默认起步档。全任期几乎必有征发、工程、战争或治理摩擦，但只有闭合到本人错误选择、普通家庭/生产财政/社会安全的已实现后果，并且能从C1/C2/C3已经消费的绝对状态中拆出残余放大时才扣DA。反过来，状态没有跨档也不自动等于`DA0`：有限阶段的强迁、伤亡、错误工程、财政转嫁或知情不作为只要闭合本人选择与实现损害，仍可进入`DA1`；重复维持、收到反馈后继续和跨通道扩张再分别进入`DA2`、`DA3`。每人都必须留下逐人裁决，`DA0`必须写明未闭合的是本人选择、实际后果还是残余去重门，不能以材料沉默代替复核。

工程量、军队人数、战争次数和亡国本身不能直接决定`DA`。C1/C2/C3与恶化档差仍只读取已经闭合的普通家庭、生产流通、公共财政和社会安全实际后果；DA另读取本人在这些后果反馈后的继续或纠正，以及主动战争和大型营造的通常可预见资源成本。第三项的成本档、战果价值、Q值、分数和军事评价均不得搬入；第三项父链只提供战争对象、选择性质、动员相对规模、持续与重复入口。不得因为没有独立征发原句把主动战争判成无成本，也不得因为第三项成本档高就跳过选择性质裁决。

正向贡献先经过终局低侧门：

`positive_score_retained = min(recovery_score + stability_absorption_score, terminal_cap)`

正负合并公式为：

`C4_raw = positive_score_retained - deterioration_penalty - destructive_amplification_penalty`

最终限制为`[-45, 45]`。阅读视图的算式必须显示`positive_score_retained - deterioration - DA`，不能在已经触发终局封顶时仍把封顶前的净恢复与K直接相加，也不能在负向分支把仅作诊断的K误写成实际正分。同一轴的同一阶段不得同时领取恢复和恶化；本人致损后仅回到破坏前基线不得领取恢复。存在可归责恶化时，已经由该恶化阶段生成的“低档稳定”不得再取得正稳定分；其他独立阶段或未恶化轴的稳定承压只有在证据能拆分时才可保留。负向档暂定为：`C4N-1`为`(-8,0)`、`C4N-2`为`[-16,-8]`、`C4N-3`为`[-25,-16)`、`C4N-4`为`[-35,-25)`、`C4N-5`为`[-41,-35)`、`C4N-6`为`[-45,-41)`；全样本回放后只允许校准档界，不得改写逐人事实与归责来迁就分布。

杨广—胡亥是负向尺度锚：杨广三轴均为四档起点、一档终点，且多年工程、巡游、战争与额外汲取共同闭合全国性持续损害，在失败和反馈后仍加码，候选为`FULL + DA4`；胡亥接手时C1/C3已为二档、C2已为一档，秦末反抗基础已经形成，本人恢复阿房、追加转输并拒绝减役纠偏，属于对既有崩坏结构的重大加速，候选为`FULL + DA2`。两人的主要区分必须来自C1/C2/C3各自起点—终点档差及其归责，而不是第三项军事成本或第五项政治素质的跨项补罚；C4只是三条状态轨迹的统一动态结算位置，不改变差异的事实来源。正式定分仍须与当前全池同门复核，但不得再因胡亥绝对主态更低而机械判其新增破坏大于杨广。
