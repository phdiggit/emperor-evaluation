# 第二项 C1/C2/C3/C4 治理结果规则与结算合同

C1—C3评任内绝对主态，C4评恢复、归责恶化及主动成本；治理结果上限202。

现行正式规则为[主态低谷与净恢复机制](02-主态低谷与净恢复机制.md)。当前规范评价池统一采用V4，池外既有记录不进入当前综合榜。

## 一、分项边界

- **C1 民生福祉绝对状态（80分）**：普通家庭实际获得的温饱、物质余量、赋役承受和人口再生产。
- **C2 经济活力与财政健康绝对状态（35分）**：民间生产、市场货币、常规财政税基与静态储备余量的绝对健康度。
- **C3 社会安全绝对状态（60分）**：人身财产安全、基层秩序、司法救济和社会可预期性。
- **C4 社会恢复与可归责恶化（-40至27分）**：本人可归责的净恢复，以及本人造成或显著放大的恶化与破坏性动员。

战争胜负、安全收益和战争是否值得归第三项；本合同只消费已经发生的家庭、经济财政和社会安全后果。第三项收益不能冲销第二项已经发生的成本。

C1—C4按实际状态同表计分，不设时代、治理复杂度或小政权折扣。

同一史料可以支持多个分项，但必须对应不同结果语义；同一结果不得在同一分项重复结算。

## 二、证据与可证明范围

### 2.1 正式证据

依次采用：覆盖主要统治区的正史、政书、实录和编年史宏观结果；跨阶段连续结果；可互证的区域或单轴材料；奏议、诏令、政策、工程与战争后果；有史料基础的专业研究；受约束推断。搜索页、百科、普通网页和模型概述只作线索。

材料少或任期短只限制观察和置信度，不自动降档、扣分或封顶；负面记载少也不证明状态好。只评已发生结果，不计“再执政几年可能改善”的潜力。个案须证明范围及主要阶段代表性才能支持主态，否则另按低谷L的准入和去重规则判断。

### 2.2 身份与时间窗口

先确定本人实际最高治理权窗口，再判材料对象、结果轴和证明范围。跨人物、政权、任期的叙述分开，不计继任者结果；统一、分裂、迁都或范围重构时，三锚须保持对象可比。

### 2.3 跨时期尺度

人口、田亩、税收、储备、贸易和货币裸数量不跨时代直接比较，须转为覆盖、生产交易、家庭负担、常规收支和真实余量。清查、登记、辖境或统计口径变化，不能单独证明人口增长、增产或生活改善。

### 2.4 政策与结果

政策名称、诏令和设计不能代替已发生的家庭、生产交易、财政或安全结果。私人巨富不代表全民状态；兼并分化须证失地、生计、负担转嫁、生产或税基损害。

诏令、奏议、策问与史书论赞先区分发声者、修辞和事实。自谦、自警、罪己、愿望、预警和纯褒德不能独立证明状态、低谷或档位上限；未见富庶不等于已证困顿。只要本人窗口、对象、地区/阶段和已发生结果明确，皇帝、臣下或史家的记述均可采用。

宏观总结只能支持原文明确的结果，不能由泛称安乐补齐各维度，或拆成独立互证。剔除修辞后用有效材料重核主态、三锚、低谷和恢复；高档证据不足与已证低态分开处理。

## 三、工程、战争与外部冲击

工程公共成果与征发成本分别举证，不互相冲销；已发生的家庭、经济财政或安全后果才改变C1—C3。本人可选择的大型营造，其可预见财政、材料、运输和役工成本进入C4审查，不按工程数量累计。

战争成本复用已裁决的正式父事件，不重新估算、拆卡累加。C4按选择区分：

| 类型 | 责任边界 |
|---|---|
| `UNAVOIDABLE_DEFENSIVE_ENGAGEMENT` | 必要防御基线不作破坏性成本归责；超出基线的错误部署、拒绝退出、过度追击或重复动员仍可归责 |
| `DISCRETIONARY_OFFENSIVE_OR_EXPANSION` | 主动进攻、扩张、惩罚远征或已有退出条件仍继续战争，审查通常可预见成本 |
| `MIXED_SECURITY_AND_EXPANSION` | 豁免必要防御部分，可选择增量分段归责 |

战争档位、次数、胜负不直接改变C1—C3。岁币、赔款、贡物等财政转移归C2，按实际支付、持续性和财政承载审查；只有改变常规收支、税基或储备才改状态，不按名义金额降档，也不由第三项安全收益抵销或转为军事成本。另有家庭、生产或非军事公共用途受损时，按C1/C4去重规则处理。

天灾、外敌和前朝遗产造成的实际状态仍计C1—C3，本人延误、放大、纠偏或恢复的责任另由C4判断。负向归责如下；不明时取较低档：

| 责任 | 条件 | 系数 |
|---|---|---:|
| `FULL` | 本人发起或反复维持主要致损行为，反馈后仍继续或扩大 | 1.0 |
| `MATERIAL` | 外因重要，但本人明确放大损害或阻断恢复 | 0.5 |
| `NONE` | 不可控外因或窗口前因素为主，未证本人显著放大 | 0 |

## 四、共同三锚、交班与L

### 4.1 三锚

C1—C3各保存接手`S0`、任内主态`S_avg`（业务名`S_main`）、交班`S_end`，必要时另记`peak_band`。主态是主要局面，不是数学平均；峰值只有在时间、范围、支配性或重复上具有代表性才可作主态。

### 4.2 交班连续性

原则上`S_end = 后任S0`；只有短窗内已发生灾乱、失陷或控制重构才可跳档。短任、复辟、摄政、共治和分裂均按实际权力窗口处理，不为平滑曲线跨过真实阶段。

### 4.3 缺证推断

缺宏观直接材料时，依次查前任`S_end`、本人多路实际结果、同政权前后状态、工程战争财政的已实现后果；治理方向只作限制。连续性只补缺，不能造繁荣或崩溃；前任推断高锚不能独立支持后任高位，连续两任缺独立结果即停止传播。

### 4.4 任内低谷L

低谷准入、分档、缺证边界、恢复期与唯一公式见[主态低谷机制§2](02-主态低谷与净恢复机制.md#2-全任低谷l)。历史稳定诊断不进入本项计分；仅保留独立画像所需的最小引用。

## 五、C1 民生福祉

### 5.1 状态口径

C1按家庭绝对状态；`raw_state_band`、`formal_band`、`main_band`同值供三锚、L审查与C4读取。

### 5.2 纯C1结果轴

C1只使用三类结果：

1. `HOUSEHOLD_SUBSISTENCE_SURPLUS`：家庭衣食、粮储、生活资料、可保留资产和物质余量；
2. `NET_TAX_LABOR_BURDEN`：税赋、徭役、兵役落到家庭后的净承受结果；
3. `HOUSEHOLD_FORMATION_REPRODUCTION`：婚育、家庭劳动力维持、家庭形成与人口再生产。

生产、市场和财政材料只有明确传导到家庭消费、储蓄或净余量后才能进入C1；治安归C3；动态抗冲击归C4。

### 5.3 C1六档

| 档位 | 边界 |
|---:|---|
| `C1-1` 崩溃 | 大范围家庭衣食断裂、饥饿死亡、卖产鬻子或逃散成为主要状态 |
| `C1-2` 广泛困顿 | 多数家庭长期难以稳定维生，净税役、破产、流亡或家庭劳动力损失广泛存在 |
| `C1-3` 基本维持 | 多数家庭可维持基本衣食，但资产余量和额外负担承受力有限 |
| `C1-4` 普遍温饱 | 主要统治区多数家庭稳定温饱，净税役未普遍压穿维生，家庭再生产总体可维持 |
| `C1-5` 富庶 | 普遍温饱之上存在广域、跨阶段的家庭粮储、衣食余量、可保留资产或民间财富，并至少有另一纯C1轴互证 |
| `C1-6` 极盛 | 三类纯C1轴均达到罕见的广域、长期强宏观门，且家庭余量有直接强锚 |

C1-5必须有直接、广域的家庭余量核心锚；没有该强锚时受约束推断最高C1-4。C1-6不开放纯推断。

### 5.4 C1固定分

|---|---:|---:|---:|---:|---:|---:|
| 分数 | 5.7 | 17.1 | 32.0 | 54.9 | 74.3 | 80.0 |


## 六、C2 经济活力与财政健康

### 6.1 两柱四面

C2由两根主柱组成：

**A. 民间经济系统**

- `P_PRODUCTION`：农业、手工业及其他生产活动的广域运行、产出和生产性积累；
- `M_MARKET_MONEY`：市场、商业、货币、信用、价格与跨区流通的实际运行。

**B. 公共财政系统**

- `F_FISCAL_BASE`：常规税基、常规收入与常规支出的匹配程度，是否依赖持续额外汲取；
- `R_RESERVE_BUFFER`：国库、仓储、边储、可支配余额及静态调度余量。

国库充盈不等于民间经济健康；商业繁荣也不能遮蔽财政失衡。

### 6.2 C2唯一归属

以下内容不得直接抬高C2：

- “家给人足、百姓安土、衣食丰足”等家庭生活结果 → C1；
- 治安、司法救济、人身财产安全 → C3；
- 经历灾害/战争后仍能维持、恢复、补库 → C4；
- 税制、币制、仓储制度如何设计 → 治理手段项；只有实现后的税基、交易、财政或储备结果进入C2。

低粮价、户籍增长、税收增长、府库充盈任一单项都不能独立证明C2高档。

### 6.3 两柱合成

两柱均强才可能到C2-5/6，均至少健康才可到C2-4。一柱只有基本运行或结构脆弱，原则上最高C2-3，强柱只能有限补偿。缺证先降低置信度并触发推断，不能据此判另一柱差；四面不作平均或按命中数量计分。

### 6.4 C2六档

| 档位 | 边界 |
|---:|---|
| `C2-1` 失灵崩解 | 民间经济或公共财政至少一柱广泛失灵，且总体经济财政系统出现多面系统性断裂 |
| `C2-2` 汲取脆弱 | 系统仍能运行，但至少一柱长期明显脆弱；市场、生产、税基或储备已出现持续透支或失衡 |
| `C2-3` 基本运行 | 两柱基本可运行，或一柱较强而另一柱只有基本运行；能维持常规生产、交易和财政，但结构余量有限 |
| `C2-4` 健康稳定 | 两柱均至少健康：民间生产与市场总体稳定，常规财政不依赖持续超常汲取，并有可验证的静态储备或财政余量 |
| `C2-5` 富实强健 | 两柱均有本人窗口的广域强结果，民间经济与公共财政同时高位，且不存在足以构成结构性弱柱的持续反证 |
| `C2-6` 结构顶峰 | P/M/F/R四面均有直接、广域、长期强材料，两柱均达到罕见高位，且公私系统没有实质性背离 |

C2-2不要求一定存在加派、贬币或强制转输；这些只是脆弱的证据之一。外生战争或灾荒造成的财政脆弱同样按绝对状态定档，责任另由C4处理。

### 6.5 C2系统推断

C2-3/4可由一柱强直接证据、另一柱若干实际结果、相邻连续性及反证共同支持。只能证明运行而不能证明健康时，优先C2-3；纯连续性不制造繁荣，也不跨任连续传播高位。C2-5两柱均须有本人窗口直接结果，C2-6不开放纯推断。

专业经济史用于解释收支、税基、货币市场和财政挤压，不直接给人物定档。

### 6.6 C2主态与峰值

`S0/S_main/S_end`与必要`peak_band`按§4.1；短时繁荣或材料集中不代全任主态。

### 6.7 C2固定分

|---|---:|---:|---:|---:|---:|---:|
| 分数 | 1.8 | 7.0 | 14.9 | 23.6 | 29.8 | 35.0 |

```text

```

K、持续性、材料数量和历史名望不形成档内加减分。

## 七、C3 社会安全

C3评居民实际人身财产风险、基层秩序、司法救济和安全预期，不能用外部安全、粮价储备、政权存续、法律设立或官员称职代替。司法救济须证免受任意侵害或受害后得到保护；个案不外推普通社会主态，广域判断须有对象、范围和阶段代表性。

与A/B1/B2共用事实时，按[制度行政合同§2.1](../制度行政/00-规则与计分合同.md#21-最小结算单元机制链)分别证明制度、组织、反馈和居民结果；同一伤害改称行政或反馈失灵，不增加计分资格。

| 档位 | 边界 | 分数 |
|---|---|---:|
| `C3-1` | 广域暴力、法外侵害或基层秩序崩解成为常态，普通人缺乏最低安全预期 | 5 |
| `C3-2` | 基本秩序仍在，但人身财产、司法或基层控制至少两面持续脆弱 | 16 |
| `C3-3` | 主要统治区维持可运行秩序，重大侵害或司法任意仍限制更高档 | 28 |
| `C3-4` | 广域人身财产安全、基层秩序和司法救济总体稳定，局部或阶段性裂缝不占主导 | 40 |
| `C3-5` | 多轴长期高位，系统性高压或广域法外侵害不存在 | 52 |
| `C3-6` | 多阶段、多区域和多轴均达到罕见结构顶峰 | 60 |

C3先按`S_main`固定映射，再按L有限修正；恢复和可归责恶化统一交C4。

## 八、C4 社会恢复与可归责恶化

### 8.1 唯一职责

C4评价本人带来的净恢复、恶化和主动额外成本，不重复奖励C1—C3的主态或高终点。同一事实可分别证明绝对状态与`S0→S_end`责任，但同轴同阶段不能同时计恢复和恶化。

### 8.2 正向：净恢复

三轴恢复权重为C1 50%、C2 20%、C3 30%。

逐轴从可比恢复基线到`S_end`累计实际保留的向上档界难度；S_end不高于基线时为0，峰值已丧失的档界不计：

```text
1→2 = 0.6
2→3 = 0.8
3→4 = 1.0
4→5 = 1.3
5→6 = 1.6
```

```text
axis_credit = attribution × 基线至S_end之间保留的向上档界难度之和
difficulty_weighted_recovery_credit = 0.5×C1_credit + 0.2×C2_credit + 0.3×C3_credit
recovery_score = round_half_up_1(min(27, difficulty_weighted_recovery_credit × 10))
```

自造低谷后恢复到破坏前基线只算止损；外生冲击不删除实际状态。同轴同档界只按交班保留增量计一次。

### 8.2.1 恢复归责

恢复归责：`FULL`本人唯一/主导最高权力100%，`SHARED`实质共治且不可拆50%，`NONE`他人主导0；先乘系数再套终局上限。

### 8.2.2 正式统治前自造低起点

正式窗口前已由本人在同区直接造成重大破坏，恢复从介入前可比状态算；直接重大致损门已成立而前置状态不明时，以S0作计算代理并取`SHARED`50%；须标基线推断。普通统一、乱世参与或史料稀疏不触发。基线推断与实质共治取同一系数中较低者，不重复相乘。各轴基线与归责可以不同。

`closed_recovery_axes`只列准入轴；非空时按公式重算的`recovery_score`须大于0。终局档由实际交班重新推导：`terminal_quality = 0.5×C1_end + 0.2×C2_end + 0.3×C3_end`，四舍五入取整后受`min(C1_end,C2_end,C3_end)+1`封顶，并限制在`C4T-1`至`C4T-6`；不能沿用主态、峰值或旧判词。

正向结果受终局低侧封顶：

| 终局层级 | 正向上限 |
|---:|---:|
| C4T-1 | 7.9 |
| C4T-2 | 15.9 |
| C4T-3 | 24.9 |
| C4T-4 | 27.0 |
| C4T-5 | 27.0 |
| C4T-6 | 27.0 |

```text
positive_score_retained = min(recovery_score, terminal_cap)
```

### 8.3 负向：可归责恶化

逐轴只比较接手与交班；任内峰值回落不得再作为第二个恶化起点：

```text
axis_deterioration = max(0, S0 - S_end) × attribution_factor
```

三轴合成：

```text
weighted_attributable_deterioration
= 0.5×C1 + 0.2×C2 + 0.3×C3
```

```text
deterioration_penalty
= min(1, weighted_attributable_deterioration / 2.0) × 13
```

不得用亡国、灾害或末档本身反推本人全责。

### 8.4 破坏性制造/放大 DA

DA准入与档表见[分账合同](01-主动民力成本与军事分账合同.md#da-cost)。

### 8.5 C4合成

```text
C4_raw
= positive_score_retained
- deterioration_penalty
- destructive_amplification_penalty
```

最终限制为`[-40, 27]`。

有符号净分，`main_band=C4`为组件标识，`terminal_band=C4T-*`表终局质量，不再用旧分数段定档。

同轴同阶段不同时领恢复与恶化；客观状态和归责下降可分别消费，DA只计主态、L及恶化之外的剩余成本。

## 九、唯一消费与维护原则

C1—C3按主态固定分和L有限修正，不设档内贡献加减；C4按恢复、责任、恶化、额外成本净算，DA只计尚未被主态、L或恶化计入的部分。

逐人正式裁决为权威结果。史料或规则变化时修改受影响人物及必要的直接交班邻接；程序只做确定性计分、校验、排序、索引和汇总，不推导历史裁决。

## 公开文案

正式记录直接维护`public_story`、`public_adjudication_summary`、`public_loss_label`、`public_boundary`和`public_evidence_items`，保留事实、数量、否定、责任及未决限制，不混入修订过程或旧稿对比。L1须区分已证有限损害与程度范围不足的最低已证，不能统一写成轻微。公开字段不参与评分。

每条依据用`evidence_mode`、`public_scope`和`source_binding_kind`说明证据性质、范围与用途：

| 绑定方式 | 要求 |
|---|---|
| `CLAIM_SUPPORT` | 已逐条核实支持关系；`source_refs`非空，保留书名、定位、原字段路径、逐字摘录和已有链接 |
| `MATERIAL_COLLECTION` | 尚未逐条核实；`source_refs`为空，材料去重放在人物轴的`public_related_source_refs`，由`public_source_note`说明是相关材料汇集 |

不能把整组材料重复绑定每条事实、将摘要冒充原文或将档位判断说成史料结论。跨期、失权后及未采用材料只作背景/排除说明；新事实和改判仍须核实支持关系。引用须定位同一人物的有效记录，不猜出处；新增摘录在上游`public_source_documents`维护。

条目只有独有边界才填`public_boundary`，否则为`null`；共同边界只写一次。定位、摘录与同值检查不代替引文支持关系的语义审查。

`public_calculation`由正式数值确定性生成，说明最低状态分、L修正、三轴恢复、责任系数、终点上限、恶化与额外成本；池外旧口径明确标记。C4的`public_reading_sections`依次写恢复幅度、基线与交班、本人作用、恶化责任、额外代价和净调整，`public_story`为同值串联。三轴路径写字母档、状态名及升降档数；无恢复区分未跨档、未保留或责任未确认。受损前基线、共治分工和池外原机制采用点，不得写成接手、独立主导或交班状态。

`second-item-c-public --write`先校验整批公开字段与来源，再同步计算、元数据和四张Markdown；保留手工正文及来源绑定，非公开评分字段不变。不加`--write`时只查同值。人物页、对照、专页和Markdown共用上游文字，阅读层只排版、折叠、链接及明确枚举映射，不改句子或重建计算。`reader/second-item-c.html`覆盖全部正式C记录，不等于综合榜入榜范围。
