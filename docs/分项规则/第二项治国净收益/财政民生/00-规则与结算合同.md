# 第二项 C1/C2/C3/C4 治理结果规则与结算合同

本合同仅规定第二项治理结果层的正式裁决逻辑。C1/C2/C3评价任内绝对主态，C4独占恢复、稳定承压、可归责恶化与破坏性放大。治理结果层上限220分。

## 一、分项边界

- **C1 民生福祉绝对状态（80分）**：普通家庭实际获得的温饱、物质余量、赋役承受和人口再生产。
- **C2 经济活力与财政健康绝对状态（35分）**：民间生产、市场货币、常规财政税基与静态储备余量的绝对健康度。
- **C3 社会安全绝对状态（60分）**：人身财产安全、基层秩序、司法救济和社会可预期性。
- **C4 社会恢复、承压与可归责恶化（-45至45分）**：本人可归责的净恢复、稳定兑现、实际压力吸收，以及本人造成或显著放大的恶化与破坏性动员。

战争胜负、安全收益和战争是否值得归第三项；本合同只消费已经发生的家庭、经济财政和社会安全后果。第三项收益不能冲销第二项已经发生的成本。

同一史料可以支持多个分项，但必须对应不同结果语义；同一结果不得在同一分项重复结算。

## 二、证据与可证明范围

### 2.1 正式证据

优先使用：

1. 正史、政书、实录、编年史中覆盖主要统治区的宏观结果；
2. 跨阶段连续的生产、市场、财政、赋役、家庭生计和社会运行结果；
3. 可与其他结果互证的区域或单轴材料；
4. 奏议、诏令、政策、工程和战争后果；
5. 有明确史料基础的专业研究；
6. 最后才使用受约束推断。

搜索结果页、百科、普通网页总结和模型概述只能作定位线索，不能直接进入裁决。

材料稀疏只降低置信度，不自动降档；负面记载稀少也不自动证明状态良好。

### 2.2 身份与时间窗口

每条材料先判断：

```text
本人/本人实际权力窗口
→ 适用范围与结果轴
→ 是否足以进入状态裁决
```

异人物、异政权、身后继任期材料不得成为本人直接状态证据。跨前后任综合叙述必须拆分本人窗口与继任窗口；继任后来形成的改善或崩坏不得倒算前任。

称帝年不必等于治理窗口起点。称帝前已经取得实际最高治理权并持续控制可比区域的阶段可以纳入；统一战争、分裂、迁都或控制范围重构时，三锚应尽量保持比较对象一致。

### 2.3 跨时期尺度

C1/C2/C3不设置时代修正系数。人口、户口、田亩、税收、库藏、贸易和货币总量不得跨时期直接比较；应转译为覆盖范围、实际生产与交易状态、普通家庭负担、公共收入相对常规责任的充足度、真实储备和公私余量。

户口、田亩变化受清查、登记、辖境和统计口径影响，不得单独证明人口增长、农业增产或生活改善。

### 2.4 政策与结果

政策、制度、诏令、工程名目本身不等于结果。只有已经闭合到生产、交易、财政、家庭生活或社会安全的实现后果，才进入C1/C2/C3；政策设计能力本身归相应治理手段项。

私人巨富、豪奢或个别豪强既不证明全民富足，也不证明全民贫困。土地兼并、贫富分化只有传导为家庭失地、生计恶化、税负转嫁、生产损害或财政税基空洞时才进入结果层。

## 三、工程、战争与外部冲击

### 3.1 工程与其他汲取

工程同时区分公共结果和征发成本，不互相冲销。只有已实现的生产、财政、家庭或社会后果才能改变C1/C2/C3状态。

大型营造本身具有可预见的财政、材料、运输和役工成本；若属于本人可选择行为，可进入C4破坏性放大审查，但不得按工程数量机械累加。

### 3.2 战争成本

战争成本读取已经裁决的正式战争父事件，不重新估算或拆卡重复累计。

战争选择分三类：

- `UNAVOIDABLE_DEFENSIVE_ENGAGEMENT`：必要防御基线不作破坏性战争成本归责；超出必要防御的错误部署、拒绝退出、过度追击或重复动员仍可归责。
- `DISCRETIONARY_OFFENSIVE_OR_EXPANSION`：主动进攻、扩张、惩罚性远征或已有退出条件下继续战争，其通常可预见成本进入C4审查。
- `MIXED_SECURITY_AND_EXPANSION`：只豁免必要防御部分，对可选择增量分段归责。

战争档位、次数、胜负和战果价值本身不能机械改变C1/C2/C3。只有已实现的家庭、生产、交易、财政或社会安全后果可以改变绝对状态。

### 3.3 天灾与外生压力

天灾、外敌和前朝遗产本身不构成本人负贡献，但其造成的实际状态可以成为绝对状态证据。本人是否延误、放大、纠偏或恢复，统一由C4归责。

C4负向归责固定为：

- `FULL`：本人直接发起或反复维持主要致损行为，已有反馈仍继续或扩大；归责系数1.0。
- `MATERIAL`：外因重要，但本人明确放大损害或阻断恢复；归责系数0.5。
- `NONE`：主要由不可控外因或本人权力窗口前形成，未闭合本人显著放大；不计负向档差。

归责不明时取较低档。

## 四、共同三锚、交班与K

### 4.1 三锚

C1/C2/C3均保存：

- `S0`：本人实际治理窗口起点；
- `S_avg`：业务语义为`S_main`，即现有材料下最能代表任内主要局面的状态，不是数学平均；
- `S_end`：退出实际最高权力时的交班状态；
- 必要时保存`peak_band`。

短时高峰即使证据很强，也不能自动成为`S_main`；只有在时间、覆盖范围、结构支配性或多阶段重复上足以代表主要局面时才可成为主态。

### 4.2 交班连续性

真正交接边原则上满足前任`S_end = 后任S0`。只有交接短窗内出现已经实现的饥荒、流亡、死亡、重大入侵、核心区失陷、控制范围重构等事实，才允许跳档。

中间短任、复辟、摄政、共治或分裂政权必须按实际权力窗口处理，不得为了曲线平滑跨越真实统治阶段。

### 4.3 缺证推断

缺少直接宏观材料时依次使用：

1. 前任`S_end`；
2. 本人窗口内多路实际结果；
3. 同政权前后阶段的系统状态；
4. 工程、战争和财政的已实现后果；
5. 治理方向只作限制项。

连续性只能补缺，不能制造繁荣或崩溃。前任锚本身主要由连续性推断形成时，不得继续作为下一任任内高位的唯一依据。连续两任均缺独立结果时停止链式传播。

### 4.4 稳定指数K

K只回答：已确定`S_main`后，是否存在实际低于主态的有效阶段。K不改变C1/C2/C3分，只交C4消费。

| K | 边界 |
|---:|---|
| `K4` | 没有有效阶段跌破主态 |
| `K3` | 一个局部、短时或轻度低谷，影响受限 |
| `K2` | 一个实质性低谷，或多个仍属局部/短时的低谷；主态仍明显占优 |
| `K1` | 低位成为次级主态竞争者；范围、持续/重复、跌幅深度三项中至少两项为强 |
| `K0` | `S_end < S_main`且构成实际末期逆转或系统下坠 |

同一连续危机不得按年份拆成多个低谷；`S0`低位及其恢复过程不得降低K；仅两个阶段或一个主要区域不足以判K1。

## 五、C1 民生福祉

### 5.1 状态口径与复杂度

C1保存两层状态：

- `raw_state_band`：普通家庭绝对生活状态，是三锚、K、交班和C4的唯一状态口径；
- `formal_band`：复杂度认证后的正式计分档，`main_band`与其一致。

复杂度按实际控制人口、地域跨度、多经济区或多核心、族群与制度异质性、行政链长度、边疆及运输协调综合裁定：

- 高复杂度政权raw档可原档计分；
- 低复杂度政权原则上`raw C1-5 → formal≤C1-4`、`raw C1-6 → formal≤C1-5`；
- `formal C1-6`只允许`raw C1-6 + HIGH复杂度`。

### 5.2 纯C1结果轴

C1只使用三类结果：

1. `HOUSEHOLD_SUBSISTENCE_SURPLUS`：家庭衣食、粮储、生活资料、可保留资产和物质余量；
2. `NET_TAX_LABOR_BURDEN`：税赋、徭役、兵役落到家庭后的净承受结果；
3. `HOUSEHOLD_FORMATION_REPRODUCTION`：婚育、家庭劳动力维持、家庭形成与人口再生产。

生产、市场和财政材料只有明确传导到家庭消费、储蓄或净余量后才能进入C1；治安归C3；动态抗冲击归C4。

### 5.3 C1六档

| 档位 | 边界 |
|---:|---|
| `C1-1` 崩溃 | 大范围家庭衣食断裂、饥饿死亡、卖产鬻子或逃散成为主要状态 |
| `C1-2` 广泛困顿 | 多数家庭长期难以稳定维生，净税役、破产、流亡或家庭劳动力损失广泛存在 |
| `C1-3` 基本维持 | 多数家庭可维持基本衣食，但资产余量和额外负担承受力有限 |
| `C1-4` 普遍温饱 | 主要统治区多数家庭稳定温饱，净税役未普遍压穿维生，家庭再生产总体可维持 |
| `C1-5` 富庶 | 普遍温饱之上存在广域、跨阶段的家庭粮储、衣食余量、可保留资产或民间财富，并至少有另一纯C1轴互证 |
| `C1-6` 极盛 | 三类纯C1轴均达到罕见的广域、长期强宏观门，且家庭余量有直接强锚 |

C1-5必须有直接、广域的家庭余量核心锚；没有该强锚时受约束推断最高C1-4。C1-6不开放纯推断。

### 5.4 C1固定分

| 档位 | C1-1 | C1-2 | C1-3 | C1-4 | C1-5 | C1-6 |
|---|---:|---:|---:|---:|---:|---:|
| 分数 | 5.7 | 17.1 | 32.0 | 54.9 | 74.3 | 80.0 |

```text
score = fixed_base(formal_band)
```

材料数量、持续阶段数、K、历史名望和归责叙述均不得形成档内加减分。

## 六、C2 经济活力与财政健康

### 6.1 两柱四面

C2由两根主柱组成：

**A. 民间经济系统**

- `P_PRODUCTION`：农业、手工业及其他生产活动的广域运行、产出和生产性积累；
- `M_MARKET_MONEY`：市场、商业、货币、信用、价格与跨区流通的实际运行。

**B. 公共财政系统**

- `F_FISCAL_BASE`：常规税基、常规收入与常规支出的匹配程度，是否依赖持续额外汲取；
- `R_RESERVE_BUFFER`：国库、仓储、边储、可支配余额及静态调度余量。

国库充盈不等于民间经济健康；商业繁荣也不能遮蔽财政失衡。

### 6.2 C2唯一归属

以下内容不得直接抬高C2：

- “家给人足、百姓安土、衣食丰足”等家庭生活结果 → C1；
- 治安、司法救济、人身财产安全 → C3；
- 经历灾害/战争后仍能维持、恢复、补库 → C4；
- 税制、币制、仓储制度如何设计 → 治理手段项；只有实现后的税基、交易、财政或储备结果进入C2。

低粮价、户籍增长、税收增长、府库充盈任一单项都不能独立证明C2高档。

### 6.3 两柱合成

C2采用**瓶颈优先、强柱有限补偿**：

1. 两柱都强，才可能进入C2-5/6；
2. 两柱都至少健康，才可进入C2-4；
3. 一柱只有基本运行或出现结构性脆弱时，另一柱再强也原则上最高C2-3；
4. 不能因为一柱缺证直接判另一柱差；缺证首先降低置信度并触发系统推断。

四面不做机械平均，也不按“命中几项”计数。

### 6.4 C2六档

| 档位 | 边界 |
|---:|---|
| `C2-1` 失灵崩解 | 民间经济或公共财政至少一柱广泛失灵，且总体经济财政系统出现多面系统性断裂 |
| `C2-2` 汲取脆弱 | 系统仍能运行，但至少一柱长期明显脆弱；市场、生产、税基或储备已出现持续透支或失衡 |
| `C2-3` 基本运行 | 两柱基本可运行，或一柱较强而另一柱只有基本运行；能维持常规生产、交易和财政，但结构余量有限 |
| `C2-4` 健康稳定 | 两柱均至少健康：民间生产与市场总体稳定，常规财政不依赖持续超常汲取，并有可验证的静态储备或财政余量 |
| `C2-5` 富实强健 | 两柱均有本人窗口的广域强结果，民间经济与公共财政同时高位，且不存在足以构成结构性弱柱的持续反证 |
| `C2-6` 结构顶峰 | P/M/F/R四面均有直接、广域、长期强材料，两柱均达到罕见高位，且公私系统没有实质性背离 |

C2-2不要求一定存在加派、贬币或强制转输；这些只是脆弱的证据之一。外生战争或灾荒造成的财政脆弱同样按绝对状态定档，责任另由C4处理。

### 6.5 C2系统推断

C2允许比C1更强的受约束系统推断：

- C2-3/4可以由一根主柱的强直接证据、另一柱的若干实际结果、相邻时期连续性和反证共同闭合；
- 纯连续性不能制造任内繁荣，且不能连续跨任传播高位；
- 只能证明“系统仍可运行”而不能证明健康时，优先C2-3；
- C2-5必须两柱都有本人窗口的直接结果，不能主要靠连续性；
- C2-6不开放纯推断。

专业经济史可正式用于解释财政收支、税基、货币流通、市场整合、商业网络、长期亏空、军费挤压等系统问题，但专业研究只解释系统状态，不直接给人物档位。

### 6.6 C2主态与峰值

C2继续使用`S0/S_main/S_end`和必要时`peak_band`。短时繁荣或财政峰值不足代表全任主态时，只保存为峰值；不能因某一阶段材料特别丰富而把它判成全任主要状态。

### 6.7 C2固定分

| 档位 | C2-1 | C2-2 | C2-3 | C2-4 | C2-5 | C2-6 |
|---|---:|---:|---:|---:|---:|---:|
| 分数 | 1.8 | 7.0 | 14.9 | 23.6 | 29.8 | 35.0 |

```text
score = fixed_base(main_band)
```

K、持续性、材料数量和历史名望不形成档内加减分。

## 七、C3 社会安全

C3只回答普通人的人身财产安全、基层秩序、司法救济和社会可预期性。统一战争和对外安全收益不计入；粮价、仓储、财政充盈和单纯政权存续不能替代C3结果。

| 档位 | 边界 | 分数 |
|---|---|---:|
| `C3-1` | 广域暴力、法外侵害或基层秩序崩解成为常态，普通人缺乏最低安全预期 | 5 |
| `C3-2` | 基本秩序仍在，但人身财产、司法或基层控制至少两面持续脆弱 | 16 |
| `C3-3` | 主要统治区维持可运行秩序，重大侵害或司法任意仍限制更高档 | 28 |
| `C3-4` | 广域人身财产安全、基层秩序和司法救济总体稳定，局部或阶段性裂缝不占主导 | 40 |
| `C3-5` | 多轴长期高位，系统性高压或广域法外侵害不存在 | 52 |
| `C3-6` | 多阶段、多区域和多轴均达到罕见结构顶峰 | 60 |

C3只按`S_main`固定映射计分；恢复、压力吸收和K统一交C4。

## 八、C4 恢复、承压与可归责恶化

### 8.1 唯一职责

C4只回答动态变化和本人归责：

- 从既有低位真正恢复了多少；
- 已实现高位能否在现实压力下稳定兑现；
- 本人使既有状态恶化了多少；
- 本人是否主动制造或放大了损害。

C1/C2/C3绝对主态和高终点本身不在C4重复得分。

### 8.2 正向：净恢复 + 稳定承压

三轴恢复权重：

- C1：50%
- C2：20%
- C3：30%

逐轴从`S0`到本人窗口内实际达到的最高有效状态累计跨档难度：

```text
1→2 = 0.6
2→3 = 0.8
3→4 = 1.0
4→5 = 1.3
5→6 = 1.6
```

```text
recovery_score = min(27, difficulty_weighted_recovery_credit × 10)
```

本人先制造低谷再回到破坏前基线只算止损，不取得正恢复信用。

`closed_recovery_axes`只登记实际通过恢复准入的轴；只要该字段非空，`recovery_score`就必须按上述档界公式重算且大于0，不得把恢复信用挪入稳定分以维持正向总分。`terminal_band`必须由实际交班向量重新推导，不能继承旧主态、峰值或旧自然语言裁决。具体计算为`terminal_quality = 0.5×C1_end + 0.2×C2_end + 0.3×C3_end`，常规层级按四舍五入取整，同时受低侧瓶颈`min(C1_end,C2_end,C3_end)+1`封顶；最终限制在`C4T-1`至`C4T-6`。

稳定承压分由三轴边界清洁的K状态按18分上限合成；低状态稳定不得包装成高韧性。

正向结果受终局低侧封顶：

| 终局层级 | 正向上限 |
|---:|---:|
| C4T-1 | 7.9 |
| C4T-2 | 15.9 |
| C4T-3 | 24.9 |
| C4T-4 | 34.9 |
| C4T-5 | 40.9 |
| C4T-6 | 45.0 |

```text
positive_score_retained = min(recovery_score + stability_absorption_score, terminal_cap)
```

### 8.3 负向：可归责恶化

逐轴只比较接手与交班；任内峰值回落已经由K、稳定分、rollback和保留度消费，不得再作为第二个恶化起点：

```text
axis_deterioration = max(0, S0 - S_end) × attribution_factor
```

三轴合成：

```text
weighted_attributable_deterioration
= 0.5×C1 + 0.2×C2 + 0.3×C3
```

```text
deterioration_penalty
= min(1, weighted_attributable_deterioration / 2.0) × 27
```

不得用亡国、灾害或末档本身反推本人全责。

### 8.4 破坏性制造/放大 DA

DA只回答本人可选择行为实际制造或放大的额外成本有多高，不重复回答状态下降了几档。DA首先判断未被轨迹变量吸收的残余成本量级，而不是先数行为是否反复、是否收到反馈后仍继续或是否跨越多个通道。反复、反馈后继续和跨通道只提高累计成本或归责确定性，不是DA1—DA3的升档必要条件；一次行为只要成本量级足够高，也可直接进入DA2或DA3。

| 档 | 扣分 | 门槛 |
|---:|---:|---|
| `DA0` | 0 | 无可归责的实质额外成本，或只有必要防御、普通治理基线；未闭合到本人可选择增量的压力不得转入DA |
| `DA1` | 4.5 | 明确但总体有限的额外成本；大型工程或战争虽有可见负担，但规模、死亡、财政抽取或家庭传导仍受限 |
| `DA2` | 9.0 | 显著国家级或主要区域级额外成本；一次超大型动员、战争或工程即可成立，也可由多次中等成本累计形成 |
| `DA3` | 13.5 | 极高国家级成本；一次灾难性选择即可成立，或由多轮国家级动员、多通道巨额成本累计形成；不要求必须已经造成系统状态崩坏 |
| `DA4` | 18.0 | 罕见的近系统性自造或放大灾难；成本本身达到灾难性国家或政权级量级，并与本人可选择行为及多轴广域崩坏高度闭合 |

DA证据必须闭合本人选择、实际成本载体、影响范围和残余后果。工程量、军队人数、战争次数、动员名义、政策数量和亡国本身不能直接决定DA；必要防御和普通治理不因规模较大自动转为DA。反过来，量级已经闭合的一次性灾难选择，也不得因“不够反复”被压低。

DA2升DA3必须额外闭合国家主力级毁损、极重资源或财政占用、广域生产与家庭传导，或等价的严重残余成本；“多年、多方向、远距离、几十万动员”等规模词本身只足以支持DA2。高基准全窗A4以上稳定可作为“只有规模词、没有残余成本”的DA3反证；低基准可能存在地板效应，不得机械免责。

同一后果若已通过C1/C2/C3交班回落、K或C4可归责恶化完整计入，DA只结算尚未被这些轨迹变量吸收的剩余主动成本，不得再次完整扣减。

### 8.5 C4合成

```text
C4_raw
= positive_score_retained
- deterioration_penalty
- destructive_amplification_penalty
```

最终限制为`[-45, 45]`。

同一轴同一阶段不得同时领取恢复和恶化；同一已实现后果不得同时进入绝对状态、恶化档差和DA重复计算。

## 九、唯一消费与维护原则

- C1/C2/C3先确定绝对阶段状态和主态；K只描述相对主态的低谷；动态恢复、压力吸收和本人归责统一进入C4。
- C1/C2/C3均为固定档分，不设档内直接贡献余额。
- 正式结算文件中的逐人裁决是权威结果。史料或规则变化时，原则上只修改受影响人物及必要的直接交班邻接。
- 程序只负责固定分映射、格式校验、排序、索引和汇总，不重新推导历史裁决。
