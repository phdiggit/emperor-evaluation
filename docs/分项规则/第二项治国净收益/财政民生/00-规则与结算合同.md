# 第二项C1/C2与D2财政民生规则与结算合同

本合同用于皇帝第二项C1、C2和D2结算。秦至唐95人C1、C2、D2已有正式文档结果；当前修订已完成C1轨迹中立化、稀疏观察持续性及高档直接证据门，并进一步固化逐条宏观锚、登记可见度、谏疏和分配后果边界。现有共同语料按同一门禁整改；材料沉默、缺少新增字段或私人巨富现象本身都不得自动改分。数据库写入和第二项综合排名仍关闭。

## 一、评分边界

- C1民生福祉与社会繁荣（70分）：普通民众在整个统治期的温饱、家庭供给、赋役承受、生产生活、人口再生产和社会安定。
- C2经济活力与财政健康（40分）：生产、流通、货币、税制、财政收支和长期承受力。国库充盈不等于民富，极端汲取不得抬档。
- D2社会韧性（20分）：交班时民间余量、恢复机制、社会失稳基础及财政压力转嫁后的继续运行能力。

战争胜负、安全收益和投入是否值得归第三项；本合同只消费百姓和财政实际承受的后果。统一、创业和兼并战争按既有合同排除。

同一事实可以被不同评分项引用，但每项只回答自己的问题，同一种收益或损害在同一分项内只能结算一次。

## 二、正式输入与证据优先级

只接受：

1. 政书底账中已经裁决的正式节点；
2. 通鉴财政民生接入裁决及原通读卡定位；
3. 战争成本底账中最终`war_event_id`对应的`READY_COST`父事件；
4. 为补齐状态锚所作的有约束推断。

`HOLD`、拒绝节点、未执行政策、单帝专题排除材料和未完成父级去重的战争记录不得进入结算。

证据优先级为：

1. 史家、政书或第三方叙述中，明确覆盖天下或主要统治区的宏观状态及其转折；
2. 跨年份连续的粮价、生产、赋役、流亡、市场、家庭生计和社会运行结果；
3. 能与其他结果互证的区域或单轴材料；
4. 臣子奏议、诏令自述、直接政策、工程和战争后果；
5. 继承状态、治理时间、治理方向和安全环境组成的受约束推断。

这里的优先级是证明力而不是篇数权重。同一宏观总评可以闭合多个实际结果轴；臣子奏议主要用于定位问题、政策背景和可能的结构裂缝，除非另有第三方叙述或已实现后果互证，不得把奏议中的典型户、修辞数量或劝谏逻辑直接当作全国状态。是否存在敢于直谏的臣子、奏议是否保存，不得使任何皇帝自动获益或受损。

既有朝代政书宏观卡是当前证明力最高、比较口径最统一的材料，但不是封闭语料边界。人物缺少合格宏观锚、现有推断链不能闭合唯一档或高档门禁需要补强时，允许联网检索正史、实录、编年史、政书、诏令奏议原文以及有明确史料依据的现代专业研究。搜索结果页、百科、普通网页总结和模型概述只能作定位线索，必须回到可核验原文、版本或研究结论后才能进入裁决。

联网补证按“缺口优先、朝代成组、最小充分停止”执行：优先处理`NO_MACRO_ANCHOR`和链式推断风险人物；同一批次兼看其前任、后任及同朝可比人物，避免只为某一高分候选选择性加料；一旦材料已经足以闭合人物窗口、结果方向、唯一状态档和不确定性，即停止扩搜，不要求重建逐年社会经济史。没有找到宏观总评不得封死档位，仍可依第7.2节用多路实际结果和王朝曲线作受约束推断。

政策颁布、仓库数字、户籍数字或事件数量都不能单独替代宏观状态。材料稀疏降低置信度，不自动降低状态档或稳定性；同样，负面记载稀少不证明徭役轻、分配好或没有结构压力。

## 三、状态证据与直接贡献

### 3.1 状态证据

状态材料按用途分为：

| 类型 | 用途 |
|---|---|
| `STATE_ANCHOR` | 范围、时期和实际结果足以直接锚定`S0/S_avg/S_end` |
| `STATE_SUPPORT` | 单轴、宽时段或次一级范围，只用于加强或限制主锚 |
| `LOCAL_ONLY` | 只描述局部地区或群体，不外推全国状态 |
| `CONTRIBUTION_ONLY` | 证明措施或局部公共结果，不替代总体状态 |
| `CONTEXT_ONLY` | 只说明天灾、战争环境、前朝遗产、意见或未执行计划 |

宏观状态优先于由零散政策数量合成的推断。跨任期材料优先按可定位阶段拆分；无法逐年拆分但明确描述连续数任之间形成的长期状态时，可以同时约束该时期的王朝曲线，不得仅因某一任缺少窄时点材料而制造无实际转折依据的降档再升档。该材料只证明状态延续，不把后任的新增治理功劳追授前任，也不使每位皇帝重复领取同一贡献。

### 3.2 逐条证据语义与可证明范围

逐条材料固定按以下顺序裁决：

```text
identity_window_gate
→ macro_anchor_specificity
→ proof_scope_constraints
→ attribution
→ 状态、K或直接余额的唯一消费位置
```

`identity_window_gate`只允许`ELIGIBLE / BACKGROUND_ONLY / REJECT`。异政权、异人物或超出本人窗口的材料不得成为本人直接状态证据；前任、后任和泛朝代结构只可作起点或背景。

跨越前后任的综合叙述必须拆分本人窗口与继任窗口的可证明范围：继任期才完成的耗尽、恢复或崩解不得倒算给前任。正史、政书对转折起点存在冲突时，须保留`CROSS_BOUNDARY_SOURCE_CONFLICT`并只消费各说共同支持的最小结论；不得选择其中更有利或更不利的一说直接定档。

`macro_anchor_specificity`固定为：

| 值 | 边界 |
|---|---|
| `NOT_APPLICABLE_AFTER_IDENTITY_GATE` | 材料已被判为异人物、异窗口或仅背景，停止在身份门，不参与本人宏观性和分数判断 |
| `NO_MACRO_ANCHOR` | 当前人物—赛道没有通过身份窗口门且达到宏观门槛的材料 |
| `LABEL_ONLY` | 只有“大治、富实、民安”等标签，未闭合范围或可观察结果轴 |
| `NON_MACRO_RESULT` | 政策、诏令、制度、局部事件、单项数字或私人个案，没有描述宏观状态 |
| `SCOPED_MACRO_SUMMARY` | 本人窗口和适用范围可闭合，至少有一个可观察宏观结果轴 |
| `BOUNDED_MULTI_AXIS_MACRO` | 本人窗口、主要范围和适用边界明确，并闭合至少三个相互独立的结果轴 |

材料使用`direct_anchor_evidence`或`direct_evidence`容器不等于已经成为直接宏观锚。人物—赛道必须另存`best_macro_anchor_class`；只有`ELIGIBLE`的`SCOPED_MACRO_SUMMARY`或`BOUNDED_MULTI_AXIS_MACRO`可以生成该值。没有合格宏观锚时可以按7.2作受约束推断，但不得继续标为`DIRECT_MACRO_ANCHOR`；`LABEL_ONLY`只能作方向线索，不能独立支持高档、持续性或多轴结论。

户口、著籍、垦田和田亩数字另受`REGISTRATION_VISIBILITY`限制：

`登记户口或田亩 = 真实人口或土地 × 政权控制覆盖 × 清查登记强度 × 申报服从度 × 档案与统计口径`

清查、检括、按比、进户、土地制度、辖境或统计口径变化前后，不直接作跨期、跨朝数值比较。户口与田亩的绝对量或增减不得独立证明人口增长、生活改善、农业增产或农户收入；它们可以证明财政登记面、行政控制覆盖或赋役可见度，也可以与粮价、丰歉、复业、储备、流亡、饥疫和实际负担等独立结果互证。战争期户口骤降是死亡、流亡、失控、逃籍和档案崩解的混合结果，可以证明国家社会基础断裂，不等同精确人口死亡率。

赋役、土地兼并和贫富分化采用结果门，不新增独立加扣分轴：

- 史料未提徭役，不得推定轻役，也不得按时代常态统一推定重役；材料沉默只降低置信度，不得成为相对于有直谏记载皇帝的比较优势。
- 减役、免役诏令和法定役额只证明政策；谏疏对劳役、兼并或贫富的概括先标`REMONSTRANCE_WARNING`，其典型户模型和修辞数量不能直接升级为`REALIZED_LABOR_BURDEN`或`REALIZED_DISTRIBUTIONAL_HARM`。
- 已经出现误农、卖产、鬻子、失地、流亡、死亡、生产破坏或广域家庭余量下降时，按实际时空范围进入状态或K。
- 私人巨富、豪奢、个别豪强或财富集中本身属于`ELITE_WEALTH_ONLY`，既不证明普通百姓富足，也不证明普遍贫困，不进入C1/C2。
- 土地兼并或贫富分化只有已经传导为普通家庭失地和生计恶化、税负向编户转嫁、民间生产受损、财政税基空洞或交班社会裂缝时，才按`REALIZED_DISTRIBUTIONAL_HARM`消费。
- 同一负担或分配后果已经由`S_avg/S_end`或K吸收后，不再进入直接余额重复扣分。

这套限制只约束材料能证明到哪里，不要求为95人补建逐年役期、完整土地关系、私人财富谱系或考古—墓志社会史。现有共同语料不足时保留`UNOBSERVED`，只有可能改变档位且当前推断无法闭合的个案才允许最小定向补证。

### 3.3 直接贡献强度

政策、工程和财政措施不能按“每条材料同档”处理。每项独立结果至少保存：覆盖人口、地理范围、持续时间、收益或损害深度、实现阶段、责任和置信度。

正负结果统一采用`PI0—PI6`、`NI0—NI6`：

| 档 | 一般边界 |
|---:|---|
| 0 | 只有主张、风险或方向，实际结果未知 |
| 1 | 单点、短时、轻微结果 |
| 2 | 已有明确家庭、生产或财政结果，但覆盖有限 |
| 3 | 区域性或持续性结果，足以改变一个状态子轴 |
| 4 | 跨区域、多年或深度损害/收益，明显影响阶段状态 |
| 5 | 广域、长期、结构性结果，影响主要统治区 |
| 6 | 全国性、跨代或系统性结果，改变整体状态轨迹 |

只有已经实现且未被宏观状态吸收的结果才能进入档内余额。政策方向、诏令数量和史料篇幅不增加强度。

## 四、工程与其他非战争汲取

本合同不要求为95人穷举宫室、陵寝、道路、水利、封禅等工程，也不要求估算缺失的工程量。工程同时记录公共收益和施工成本，两者分别裁决，不能互相冲销；但只有第三方宏观叙述或可观察结果证明其已经改变主要区域的财政、生产、家庭生计、死亡流亡或阶段状态时，才进入`S_avg/S_end`或K。臣子奏议中的劳役警告、工程名目和动员数字可触发复核，不能单独代替宏观后果。

多个已知大型工程、战争和其他汲取可以组成同一阶段的负荷背景，用来检查既定档位是否自洽；不得按项目数量机械累加，也不得因为其他皇帝的工程没有同等暴露就对记载丰富者作额外惩罚。公共收益和损害已经被宏观状态吸收后，不再进入直接余额重复结算。

当直接宏观材料不足时，允许建立人物窗口及朝代阶段的“成本画像”，但只作状态推断的约束项，不把成本低直接等同于民间富庶。成本画像至少分开记录：既有战争父事件的实际财政民生负荷、集中营造与公共工程、皇族宗室及外戚的制度性汲取、国家可见的财政组织与救济能力。每路使用`HIGH / MATERIAL / LOW / UNOBSERVED`四态；`UNOBSERVED`不得解释为`LOW`，工程名目、战争次数、宗室人数和史料篇幅不得机械相加。

成本画像按“公共成果先行、可能改档才补证”执行：战争路直接读取已经闭合的公共成本登记，不重做战史；营造和宗室汲取先查共同政书、本纪、编年和现有治理底账，只在其可能改变档位时作最小联网定位。工程必须同时区分征发成本与实现后的公共收益；皇族、宗室或外戚富贵只有形成制度性供给、赋役转嫁、财政挤压或普通家庭实际损害时才进入画像，私人巨富和一般优厚待遇本身不计。

## 五、战争成本接入

战争成本沿用战争卡已经裁决的`P/S/M/A→WC0—WC7`，财政民生链不得重估或相加`ΣWC`。只有最终父事件的实际后果可以消费；人员、军费、粮运、物耗和附带损害不得拆卡重复累计。

战争成本在C1有三级用途：

1. 只有WC档位、动员或支出压力而没有实际民生后果时，只触发复核；
2. 后果足以改变主要统治区或主要持续阶段时，直接进入`S0/S_avg/S_end`；
3. 后果不足以改写全国`S_avg`，但证明某个区域或短时阶段实际低于`S_avg`时，进入稳定性K。

第三级是战争成本除复核门之外的正式用途。例如全国`S_avg=C1-4`，边疆战争已经造成人口被杀掳、牲畜损失和生产中断，但不足改变全国主态，可以据此降低K；若这些后果只说明为什么不能进入C1-5，则已被`S_avg`吸收，不再影响K。

WC数值、战争次数和战争胜负本身都不能机械改变C1。同一战争后果一旦用于状态锚或K，不再作为独立负面贡献重复扣分。

## 六、天灾、外部冲击与责任

天灾发生本身不记皇帝负面贡献。只评价：

- 是否存在可行预防却拒绝执行；
- 是否及时赈济、减免、调粮和安置；
- 是否以加征、强役、封锁或行政失灵放大损害；
- 灾后是否恢复生产、人口和社会运行。

灾害造成的实际状态可以作为时代状态证据，但自然原因不转化为皇帝直接负贡献；有效赈济和恢复可以计正面结果。战争、前朝结构和既有财政条件同样先记录外部起点，再判断本人的响应、放大和恢复责任。

## 七、C1三锚与六档

每位皇帝必须保存：

- `S0`：即位或实际掌权起点；
- `S_avg`：为兼容既有数据保留的技术字段，业务语义是`S_main`，即现有材料下最有证据支持、最能代表任内主要局面的状态；不是逐年状态的数学平均，也不要求证明覆盖任期一半；
- `S_end`：离任或实际交班状态；
- `main_band`：以`S_avg/S_main`为核心形成的唯一主档；
- `confidence`与材料局限。

### 7.1 C1状态六档

| 档位 | 状态边界 |
|---:|---|
| `C1-1`崩溃 | 大范围饥饿死亡、人口逃散、生产停顿或社会运行断裂成为主要状态 |
| `C1-2`广泛困顿 | 基本生产仍在，但多数家庭长期难以稳定维生，重役、破产或流亡广泛存在 |
| `C1-3`基本维持 | 战乱或危机后已经恢复基本生产和社会运行，多数人可勉强维生，但余量和抗冲击能力有限 |
| `C1-4`普遍温饱 | 主要统治区多数家庭能够稳定温饱，生产、人口和社会生活长期正常运行 |
| `C1-5`富庶 | 在普遍温饱之上，民间财富、家庭余量、生产流通和生活安全形成多维、长期高位 |
| `C1-6`极盛 | 秦至唐范围内罕见的全国性长期峰值，需多维直接宏观材料证明，不能由一般盛世评价推定 |

恢复生产通常只能证明C1-3；C1-4必须证明普遍温饱，C1-5必须有比低粮价或户口增长更高一级的民间富足材料。C1-5至少需要两类相互独立的广域实际结果轴，其中一类必须直接涉及家庭余量、民间财富或生活安全；一条范围与时期明确的第三方综合总评可以同时闭合多个结果轴，不要求为每个轴另找一部史书。C1-6必须是`BOUNDED_MULTI_AXIS_MACRO`：既有共同语料中的上下文明确覆盖本人窗口、天下或主要统治区和长期阶段，同时至少闭合家庭或民间财富、生产或市场、生活安全等三个结果轴；同一综合总评可以闭合多个实际结果轴，不因集中在一条政书总评中被机械拆除或要求另找一部史书，但低粮价、户口或国库等单轴材料不能拼成C1-6。还须检查同窗口、同尺度的宏观反证；晚于该峰值的转折另进K或终点，不回溯抹除已经实现的峰值阶段。

C1-6始终可达，不要求当前结算批次必须有人占档。C1-6可以使用既有共同语料或按本合同联网补证取得的合格材料；若新增材料只覆盖单个人物，必须同时检查相邻统治期和当前最接近的高档人物是否存在同尺度反证或明显漏检，但不要求为95人同步追加同等篇数。不得因选择性搜索造成只有被深挖者能够进入高档，也不得因其他人物材料较少而拒绝已经闭合的真实峰值。若C1-6只在可定位峰值阶段成立而不是`S_main`或`S_end`，保存`peak_band=C1-6`和对应非保留升档，不领取状态底分或交班保留奖励。

### 7.2 缺证推断

锚点不能空置。缺少直接宏观材料时，依次使用：

1. 前任`S_end`的连续继承；
2. 任内已有多路实际结果；
3. 有效治理时间和结果出现时间；
4. 工程、战争和财政后果；
5. 治理方向及同政权前后状态约束。

上升证据不足取较低档；下降可以由明确、持续的实际后果推断。这里的“证据不足”是指既有材料、最小联网补证和可用推断仍不能闭合目标档，不是“当前宏观卡没有原句”。推断必须给出唯一档、置信度和依据，不用事件数量代替状态。

每个推断锚必须保存`inference_source_anchor`、`inference_hops`和`inference_basis`。前任`S_end`可以一跳成为后任`S0`；如果前任`S_end`本身主要由连续性推断形成，后任只能把它作为低置信起点约束，不得再把它作为后任`S_avg`、`S_end`、升档持续性或高档准入的唯一依据。连续两任都缺直接或多路结果时，必须标记`CHAINED_INFERENCE_BLOCKED`并停在最后一个有独立事实支持的档位，不得沿王朝标签传播高位或低位。

连续性推断只补状态闭合，不生成额外史实。它可以帮助确定C1-1—C1-4的唯一档，但不能单独支持C1-5/6，也不能单独证明任内升档已经持续到某个精确年份。

C1-5可以由“本人窗口的广域正面结果＋王朝连续曲线＋成本画像”共同闭合，但不得由“没有发现战争、工程或民怨”反向推出。除相邻高位或长期恢复背景外，本人窗口至少要有一项可定位的广域实际结果，并与另一项独立结果轴或跨阶段观察互证；战争、集中营造和制度性宗室汲取三路经过最小充分检查后不得存在足以否定富庶主态的已实现负荷。此路线标记为`COST_PROFILE_CONSTRAINED_HIGH_INFERENCE`并降低置信度；若只有政策方向、户籍田亩、国库或“未见负面”，最高仍为C1-4。C1-6继续只接受第7.1节的直接多轴宏观材料，不开放成本画像推定。

### 7.3 王朝曲线与横向复核

个人三锚和主档先按本人材料独立裁决；95人全部得到唯一档后，必须再作一次宏观曲线复核，而不是用王朝印象先行分档：

1. 连续两任的`前任S_end→后任S0`原则上连续；若发生战争、灾荒、政权控制或统计口径突变，才允许跳变并记录原因。
2. 若前后强宏观锚均处于同一高位或低位，中间短任或材料稀疏者不得仅因缺少窄时点总评而无事实地降档再回升。跨数任的第三方长期总评可以约束这段曲线，但不生成个人贡献奖励。
3. 后任即位后立刻可见的大规模财政、战争或赈济能力，可以反证其继承的国家资源下限；它只作连续性校验，不能单独证明普通家庭富足，也不能把后任成就倒算给前任。
4. 横向比较以普通家庭生计、生产流通、抗冲击和实际财政可持续性为共同轴；户籍覆盖、税收汲取能力和工程动员能力不能直接等同民生更好。
5. 曲线复核发现冲突时，优先重读已有共同语料和证据角色；仍不能闭合时，按缺口人物和相邻统治期成组开展最小联网补证，不启动逐年、全工程或全社会史扫描，也不以“现有池没有宏观总评”直接维持旧档。

曲线复核的结果必须保存`dynasty_curve_review`或等价审计记录，说明连续性、实际转折、跨任期锚和未解决不确定性。它可以纠正无依据的状态跳变，不得为了让曲线平滑而抹去已证实的真实崩溃、恢复或区域分化。

## 八、持续性与稳定性

持续性与稳定性不是等权并列项：持续性只判断升档结果被观察到何种程度并是否保留到交班，稳定性再判断`S_avg/S_main`是否被实际跌破。两者都不要求重建逐年民生曲线。

### 8.1 升档持续性

凡`S_end>S0`或任内出现高于起点的阶段，必须把每次相邻升档逐级保存：

- `from_band/to_band`；
- `first_supported_observation`；
- `terminal_confirmation`；
- `persistence_basis`；
- `persistence_class`。

| 持续档 | 只要求的可观察事实 | 系数 |
|---:|---|---:|
| `END_ONLY` | 只在交班锚确认达到；不推定此前持续 | 0.15 |
| `SINGLE_PHASE_CONFIRMED` | 至少一个可定位的任内阶段直接或多路结果确认达到，且没有把单点外推为全任 | 0.40 |
| `REPEATED_PHASES_CONFIRMED` | 两个时间上可区分的阶段，或一项明确表示“累年、屡年、久行”的宏观叙述，与交班方向相容 | 0.70 |
| `MULTI_STAGE_AND_TERMINAL_CONFIRMED` | 至少三个可区分阶段，或覆盖前后阶段的明确长期叙述，并由交班锚确认成果仍在 | 1.00 |

这些系数是“可观察持续性兑现权重”，不是任期占比。不得输出`reign_share_lower_bound`、`minimum_sustained_years`或0.37、0.52之类占比小数；即使史料恰有年份，也只用于证明阶段先后和去重，不要求补齐中间年份。相同史实的重复记载不增加阶段数，同一结果轴的材料篇数不线性加权；最多使用三个代表性观察闭合最高档。

正式闭合不要求主动扫描考古报告、墓志、地方材料全集或重建逐年社会经济序列。此类材料若已有且能改变档位可以使用，但不得成为95人统一结算的必备门槛。相邻升档价值逐级保存，越高档准入材料越严格；低位重建不能因起点低被封死上限。

### 8.2 相对`S_avg/S_main`的稳定性K

K只回答：在已确定`S_avg/S_main`后，是否有实际低于该档的可定位阶段。K不要求证明其余每一年均保持主档，也不因史料空白自动扣分。

| K | 相对于`S_avg`的边界 |
|---:|---|
| `K4`保持 | 没有证据证明任何有效阶段低于`S_avg`；负面材料只构成本档或限制更高档 |
| `K3`轻度波动 | 局部或短时阶段低于`S_avg`，但主态未变，后续同档状态、恢复或影响受限有证 |
| `K2`显著波动 | 至少一个可定位阶段出现低于`S_avg`的实际状态，不能只由单点事故或材料篇数推定 |
| `K1`接近失守 | 多个可区分阶段或主要区域出现低于`S_avg`的实际状态，但交班锚尚不足以把主档改判为更低档 |
| `K0`末期逆转 | `S_end<S_avg`且交班低位是实际逆转或系统崩溃，不是窄时点缺证 |

裁决顺序固定为：

```text
先定S_avg
→ 将负面事实转换为对应时空阶段的状态
→ 比较该阶段与S_avg
→ 只按低于S_avg的程度和持续范围确定K
```

以下事实不得降低K：

- `S0`较低或重建尚未完成；
- `S0`高于`S_avg`，但下降已经由三锚轨迹消费；
- 只能解释为何没有进入更高档的材料；
- 本档本来就包含的困顿、脆弱或结构裂缝；
- 材料稀疏、恢复未证、负面材料较多；
- 灾害次数、战争次数、WC数值或诏令数量。

低档平盘者可以是K4，表示其低档状态没有再次被跌破；K4不抬高状态分，也不把稳定的C1-1/C1-2奖励成高档。`S_end<S_avg`造成的K0只标记轨迹逆转，连续计分不得对同一末期损害重复扣分。

### 8.3 C1连续分数正式公式

`S_avg`基础分改为：C1-1=5、C1-2=15、C1-3=28、C1-4=48、C1-5=65、C1-6=70。C1-5由此正式进入90%得分区间，C1-6保留为接近满分的罕见极盛。C1-4与C1-5的基础差为17分：既保留“普遍温饱”与“长期多轴富庶”的实质门槛，又避免把已经达到普遍温饱且交班进入C1-5者仅因全任主档仍为C1-4而重复拉开过大差距。C1-4无论恢复跨度多大，正向小计仍不得越过62.9，不能越过C1-5门禁。

持续性材料只决定一段升档能否成立、`persistence_class`和置信度，不再乘`0.15/0.40/0.70/1.00`形成分数倍率。旧倍率把政书丰富者和阶段可细分者系统性抬高，同一`S0/S_avg/S_end/K`曾产生最高18.4分差，违反跨朝可比性。当前公式明确要求：相同`S0/S_avg/S_end/K`必须同分，材料数量、观察阶段数、臣子敢谏程度和归责叙述不得在四元组之外另造数值差。

恢复贡献保留为次级信用，但只按已裁定的起点与交班档计算：`20% × max(0, state_base(S_end)-state_base(S0))`。它不要求逐年覆盖，不随材料篇数增加；终点未高于起点时为0。恢复信用与`S_avg`基础分相加后，按主档封顶：C1-1=9.9、C1-2=21.9、C1-3=39.9、C1-4=62.9、C1-5=69.9、C1-6=70。达到下一档仍必须先通过下一档宏观状态门。

`S0>S_avg`不再另设起始下降归责扣分。`S_avg`已经消费任内主要低位，K又消费波动与末期逆转，继续按归责系数扣一次会重复结算同一状态。归责仍保留在历史解释、响应评价和其他分项中，但不破坏C1同状态四元组同分。

K按`S_avg`消费档内稳定性：K4/K3/K2/K1分别扣0/1/3/6分；K0每跨一个`S_avg→S_end`完整档固定扣6分。K0只结算实际终点逆转的深度，不再因归责系数造成相同S与K不同分。不同起点或不同终点之间仍不设置“重建必须高于守成”或相反方向的强制排序。

```text
score = clamp(
  min(main_band_positive_cap,
      state_base(S_avg) + 0.20 × max(0, state_base(S_end)-state_base(S0)))
  - K_penalty,
  0, 70
)
```

秦至唐95人三路输入共形成644个人物—事件簇。人物身份门禁保留566簇，拒绝78个明显串入异人物、异政权或身后继任期的旧簇；身份待复核为0。合格簇检查其在三锚、升档确认、限制升档或K中的消费位置，未发现独立于这些状态结果的C1余额，因此当前直接贡献余额为0。这不是默认忽略政策和工程：高强度工程、战争后果和赈济结果均须在相应状态或K理由中明示；以后新增材料只有证明独立结果且通过同样去重，才可重开余额。

## 九、去重与直接余额

同一事件簇按以下顺序消费：

1. 先进入阶段状态；
2. 不足改变`S_avg`但形成相对低位阶段时进入K；
3. 仍有未被宏观状态解释的独立结果时，才进入直接贡献余额。

结果不能同时在状态、K和直接余额中重复扣加。战争收益不能冲销已经发生的人员和民生损害；财政收入不能冲销压力向民间的转嫁。

C1已使用确定性状态轨迹公式完成95人重建：持续性等级只作证据门，不再乘材料密度倍率；同一`S0/S_avg/S_end/K`同分；C1-5进入90%区间。当前C1及130分汇总为正式文档输出，数据库写入和第二项总排名继续关闭。正式化门禁包括：95人唯一覆盖、四元组同分、644簇人物身份与直接余额去重、高中低档和反常样本复核，以及不同起点/终点轨迹的中立性诊断。

## 十、C2经济财政定档与连续分数

C2仍使用`S0/S_avg/S_end`，但不继承C1档位。生产、市场货币、常规财政与长期可持续性是四个判断面；单有国库、户籍、低粮价或一项制度不得独立上高档。

| 档位 | 精确边界 |
| --- | --- |
| C2-1 失灵崩解 | 生产、交易或常规财政已广泛失灵，币制、税基、仓储或征收体系至少两面出现系统性断裂。 |
| C2-2 汲取脆弱 | 国家仍能取得收入或维持局部生产，但主要依赖加派、贬币、强制转输等透支方式；市场、民间生产余量或财政储备明显不足。 |
| C2-3 基本运行 | 常规生产、交易和税收能够继续，或从战乱低谷恢复至可运行；积累、跨区调度和抗冲击余量仍有限。 |
| C2-4 健康稳定 | 广域生产、市场货币和常规财政总体稳定，正常支出不以持续透支民间为前提，并有可验证的储备、调度或恢复能力。 |
| C2-5 富实强健 | 至少三面长期处于高位，公私积累或生产流通相互印证，经历冲击仍能维持；存在重大区域失衡或持续额外汲取即不得入档。 |
| C2-6 结构顶峰 | 四面均有独立广域强材料，长期高位且公共财政、民间经济和市场繁荣不相背离。秦至唐只允许极少峰值阶段进入，不因盛世标签授予。 |

C2表中的“长期”只需由明确的长期叙述或彼此可区分的阶段结果证明，不要求逐年序列、固定年份密度或覆盖任期一定比例。

三锚缺证时按以下顺序补齐：相邻交接锚点；同一任期的广域结果；生产、币制、税制和仓储的相互制约；已有战争、工程的实际经济后果；最后才用政权连续性。C2沿用第七节的`inference_source_anchor / inference_hops / CHAINED_INFERENCE_BLOCKED`规则，不得把已由连续性推断形成的前任终点继续传播为后任任内高位。

推断可以降档；纯连续性推断最高只能支持C2-4。升至C2-5至少需要两个彼此独立的广域结果轴，且必须同时覆盖民间生产或市场与公共财政或储备；“独立”指结果轴相互独立，不机械要求来自两部史书。一条范围、时期和结果轴都明确的第三方多轴综合总评可以同时闭合公私两面，但不得把只有“富庶”“殷富”等标签的同一句话技术拆成多轴。升至C2-6必须满足本档全部条件并有多来源直接结果。国库充盈、户籍增长、低粮价或税收增长任一单轴都不得替代公私两面。

C2以`S_avg`为状态底分，并另计真实升档、起点回落和相对`S_avg`的稳定性。正式参数为：

| 项目 | C2-1 | C2-2 | C2-3 | C2-4 | C2-5 | C2-6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 状态底分 | 2 | 8 | 17 | 27 | 34 | 40 |

持续性材料只决定升档能否成立、`persistence_class`和置信度，不再以`0.15/0.40/0.70/1.00`倍率进入分数。C2与C1遵守同一材料中立性：相同`S0/S_avg/S_end/K`必须同分，观察阶段数、史料篇数和政书详略不得在四元组之外制造差距。

恢复贡献只按已经裁定的起点与交班档计算：`20% × max(0, state_base(S_end)-state_base(S0))`。它是次级信用，不要求逐年覆盖，不随材料数量增加。C2仍以实际主状态为第一语义，各主档正向封顶依次为C2-1=7.9、C2-2=16.9、C2-3=26.9、C2-4=33.9、C2-5=39.9、C2-6=40；恢复信用可逼近但不得进入下一状态档的基础分区间。

`S_avg<S0`不再另设起点回落归责扣分；主状态已经消费任内下降，继续按责任系数扣分会重复结算。稳定性以C2自身`S_avg`为参照：`K4/K3/K2/K1`分别扣`0/0.5/1.5/3`分；`K0`每跨一个`S_avg→S_end`完整档固定扣3分。归责继续保留在解释中，但不得使相同四元组产生不同分数。战争和工程只有已证生产、交易、财政或储备后果才能进入状态或K，单纯成本档不直接扣C2。

因此C2最终分为：

`clamp(min(主档正向封顶, 状态底分 + 0.20 × max(0, state_base(S_end)-state_base(S0))) - K扣分, 0, 40)`。

## 十一、D2交班韧性定档与分数

D2不再计算任内平均，也不奖励从低位上升本身；只回答交班时社会能否继续承压、恢复和运行。C1、C2的`S_end`是约束输入，不是按比例重复折算。

| 档位 | 精确边界 |
| --- | --- |
| D2-1 韧性崩解 | 交班时广泛流亡、相食、叛乱基础、财政或救济失灵已经使社会继续运行能力断裂。 |
| D2-2 严重裂损 | 大范围民间余量耗尽或财政压力下沉，恢复渠道很弱；政权仍存在不等于社会具有恢复能力。 |
| D2-3 脆弱可续 | 基本生产和社会组织尚能继续，但家庭、仓储、财政或救济中至少一面余量偏低，遇新冲击容易再度恶化。 |
| D2-4 可恢复交班 | 民间与财政基础均未出现主导性断裂，救济、仓储、调运或复业机制至少一项可运行，继任者可在既有基础上继续治理。 |
| D2-5 强韧交班 | 家庭余量、公共储备与恢复机制多面相互支持，并有吸收较大冲击后仍恢复或保持的结果。 |
| D2-6 极强缓冲 | 多次重大冲击下仍证明广域恢复和制度传导，交班时公私余量均强；仅凭长期安定或库藏充盈不得进入。 |

裁决顺序为：先看交班前直接社会结果；再看运行中的赈济、仓储、复业和跨区调度；再用C1、C2终点检查家庭与财政是否存在硬约束。无直接韧性材料时，必须精确定档：以两个终点和相邻阶段连续性作推断，并标记`TERMINAL_CONSTRAINED_INFERENCE`。缺乏独立恢复结果时，D2不得高于`min(C1_end+1, C2_end+1)`；若其中一面低两档以上，除非有直接缓冲证据，D2不得高于较低面一档。

`TERMINAL_CONSTRAINED_INFERENCE`最高只能进入D2-4。D2-5必须至少有一条直接证明交班窗口内家庭余量、公共储备或恢复机制实际吸收冲击并继续运行的广域结果，并有另一独立结果面互证；一条范围、时期和结果轴都明确的第三方综合总评可以同时闭合多个结果面，不因集中在同一条政书或编年总评中而机械要求另一部史书。D2-6必须有多次重大冲击下广域恢复和制度传导的直接结果。长期安定、库藏充盈、C1/C2高终点或前任高位都不能单独推入D2-5/6。

D2各档分数区间为`0—3.9/4—7.9/8—11.9/12—15.9/16—18.9/19—20`。档内位置从0.50起算：每一项已经实现且独立的家庭余量、公共储备、救济传导、跨区调运或冲击后恢复保护面可上移0.15；每一项接近降档的家庭耗竭、财政失灵、救济中断或恢复渠道裂缝可下移0.15。多轴系统崩解已直接闭合本档极端下沿时可取0.15；位置限制在`0.15—0.85`，按档位区间线性换算并保留一位小数。证据等级、材料篇数和`DIRECT_TERMINAL_STATE`/`TERMINAL_CONSTRAINED_INFERENCE`模式本身不加减分，只决定可进入的最高档、置信度和是否允许正式结算。这些因素只决定档内位置，不得跨档。

同一损害在C1/C2已作为平均状态或K消费后，D2只消费它在交班时是否仍留下恢复能力裂缝，不重复扣事件本身；同一赈灾措施在C1/C2已解释结果后，D2只消费交班时仍在运行的缓冲机制，不重复奖励政策动作。

## 十二、输出与验证

每位皇帝至少输出：

- 三锚、主档、置信度和可审计理由；
- 直接史料原文或有约束推断线索；
- 逐条材料的`identity_window_gate`、`macro_anchor_specificity`与必要的`proof_scope_constraints`，以及人物—赛道`best_macro_anchor_class`；
- 每一级升档的`persistence_class`及不超过三个代表性观察；不得输出或要求任期占比、逐年序列；
- 推断锚的`inference_source_anchor`、`inference_hops`与链式推断门禁状态；
- `stability_reference_band=S_avg`、K值及低于`S_avg`的事实；
- 战争成本在复核、状态或K中的唯一消费位置；
- 材料局限和去重说明。

正式生成物必须满足：95人唯一覆盖、链接和JSON有效、UTF-8无BOM、`git diff --check`通过、生成器重复运行结果一致。未通过门禁时只能称候选定档，不能写正式分数或排名。
