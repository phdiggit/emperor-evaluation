# 第二项C1/C2与D2财政民生规则与结算合同

本合同用于秦至唐皇帝的第二项C1、C2和D2正式结算。它只消费已经验收的财政民生政书基础、通鉴接入裁决和`READY_COST`战争成本；不开放第二项A、B、D1、D3、正式数据库写入或全项目排名。

## 一、问题边界

- C1民生福祉与社会繁荣（70分）：任内普通民众实际生活、赋役承受、生产恢复、人口再生产和社会安定的平均状态及变化。
- C2经济活力与财政健康（40分）：任内生产流通、货币市场、财政收支和长期承受力；极端汲取形成的账面收入不能抬档。
- D2社会韧性（20分）：实际交班时社会承压、灾后恢复、流民民变基础和财政压力转嫁后的继续运行能力。

同一事实可以回答三个不同问题，但同一种损害或收益只结算一次。C1不重复计算C2已经结算的财政账面变化；D2不重算任内平均，只读取交班状态。战争的胜负、安全收益和投入是否值得归第三项；本合同只消费百姓和财政实际承受的成本。

## 二、状态与贡献账

每位皇帝至少保存：

- `S0`：即位或实际掌权起点；
- `S_avg`：按持续时间观察的任内平均或主要持续状态；
- `S_end`：离任或实际交班状态；
- `trajectory_type`：`LOW_BASE_REBUILD`低位重建、`HIGH_BASE_STEWARDSHIP`高位守成、`RISE_THEN_FALL`高开低走、`SHORT_PEAK`短期高峰、`LATE_COLLAPSE`末期崩溃、`SPARSE_INFERENCE`稀疏推断或其他明确类型。

事实层五轴映射如下：

| 评分项 | 主要状态输入 | 只作校验或次要修正 |
|---|---|---|
| C1 | `S-pop`、`S-life`、`S-production`、社会安定结果 | `S-resilience`的任内实际救济结果 |
| C2 | `S-fiscal-market`、生产流通结构、税制与财政承受力 | 人口登记只校验税基，不直接代表繁荣 |
| D2 | `S-resilience`、`S-end`民间承压、流民民变基础、压力转嫁 | 任内平均和单项财政数字不得替代交班状态 |

状态账先回答“实际过得怎样”，贡献账再回答“可归责改变了多少”。政策节点只解释或修正状态轨迹；已经用于解释宏观转移的政策不得再全额叠加。未知轴以相邻阶段、同一政权连续状态、已证政策运行和外部冲击作有约束推断，并保存置信度；不得用事件数量补空。

## 三、六档边界

三个分项共用`0—5`六档语义，按各自满分映射不同区间。档位先由状态和轨迹裁决，分数再在档内连续落点。

| 档 | C1民生状态 | C2经济财政状态 | D2交班社会韧性 | 得分率区间 |
|---:|---|---|---|---:|
| 5 | 长期广泛繁荣，民生、生产和人口多轴高位，或极低起点后形成可持续高位 | 生产流通与财政同时健康，税负可承受且结构可持续 | 交班时社会余量充足、恢复机制成熟、无重大裂缝 | 90%—100% |
| 4 | 多数任期稳健，改善广泛且可持续；局部损害未改变主趋势 | 经济财政总体稳健，存在明确结构收益，汲取或波动可控 | 承压能力较强，已有问题不构成系统性失稳基础 | 75%—89% |
| 3 | 中等或混合状态；有实质改善，也有持续负担或区域性恶化 | 收支与生产流通可运行，但结构性弱点、反复或高成本明显 | 尚能继续运行，但社会矛盾、流民、灾害或转嫁压力已经显著 | 60%—74% |
| 2 | 平均处于恢复或脆弱状态；改善有限，负担与损害压低主趋势 | 财政经济勉强运行，市场、税基或储备有持续脆弱性 | 韧性偏弱，交班时已有广泛承压或较强失稳基础 | 45%—59% |
| 1 | 普遍困苦或长期下行，局部正面不足以改变生活恶化 | 汲取、币制、生产或财政失衡占主导，但尚未全面崩溃 | 交班时社会接近失稳，恢复能力弱且矛盾广泛 | 30%—44% |
| 0 | 饥死、逃亡、破产、暴乱与生产崩溃形成系统灾难 | 财政、货币、生产和市场多轴系统崩溃 | 交班时已经大规模崩溃、政权失去社会承载或民变全面爆发 | 0%—29% |

对应分值区间：C1为`0—20.9 / 21—30.9 / 31.5—41.9 / 42—52.4 / 52.5—62.9 / 63—70`；C2为`0—11.9 / 12—17.9 / 18—23.9 / 24—29.9 / 30—35.9 / 36—40`；D2为`0—5.9 / 6—8.9 / 9—11.9 / 12—14.9 / 15—17.9 / 18—20`。边界小数保留一位，档内位置不得跨档。

## 四、轨迹裁决

1. **低位重建**：不得把自然恢复全部算给皇帝；但有持续政策、执行和公共结果支持时，改善增量可以把同等平均状态的样本推到更高档内位置，必要时提高一档。
2. **高位守成**：高起点不自动归功，但长期维持高位、成功吸收冲击且没有透支交班余量，本身是可归责治理成果；不得因增量小被压到中档。
3. **高开低走**：C1/C2按持续时间形成`S_avg`，早期高位不能被删除；D2只看末期，若交班已崩溃则降至0档或1档。
4. **短期高峰**：单年低粮价、仓储或政策密集期不能代表任内平均；高峰未持续时只提高档内位置。
5. **末期崩溃**：人口、生产、市场、财政或社会秩序多轴崩溃时，C1/C2最高分别为1档；D2原则上为0档。早期高位仅影响C项档内位置，不抬高D2。
6. **短任与稀疏材料**：必须给出有约束推断。优先读取继承状态、任内已证冲击、明确政策、战争成本和交班状态；置信度为`LOW`时不得进入5档，只有一两项正面政策且无宏观状态支持时不得超过3档。

## 五、责任与外部冲击

- 自然灾害只进入观察起点；预防、救济、放大、转嫁、拒救和恢复结果才进入皇帝责任。
- 既有结构与前任遗留先进入`S0`。继承高位不是个人新增贡献，继承崩溃也不是个人负债；任内维护、修复或继续耗损另判。
- 战争成本按`war_event_id/settlement_group`去重，只消费`READY_COST`。不得相加WC档位，也不得用军事收益冲销已发生的人命、征发和生产损害。
- 创业、统一、兼并战争成本与经济回报全部排除；统一后的复员、返籍、复业和独立赈济可以作为新结果。
- 皇帝直接发起、批准、明知不纠或决定性停止使用强归责；臣子执行和地方失效分别保留，不把全部宏观结果独占给皇帝。

## 六、事件簇与冲突裁决

同一制度、工程、战争或灾害生命周期共享`settlement_group`。征丁、粮运、失农时、破产、逃亡和财政支出可以分别保存，但合并为一个净后果，不逐项全额扣分。纠偏不删除已发生损害。

状态证据与直接贡献冲突时按以下顺序处理：

1. 先排查命令未执行、风险被当成结果、局部外推全国、同簇重复和来源覆盖不对称；
2. 政策偏正而状态下降时，保留政策贡献，但总体档服从实际状态，并记录传导失败或外部冲击；
3. 政策偏负而状态上升时，保留独立损害，但不得宣布总体恶化；检查增长残差和其他正面机制；
4. 无法消解时，以状态定档、以贡献限制档内位置，并把置信度降为`MEDIUM/LOW`。

## 七、档内连续分数

每条正式记录保存`grade`和`within_grade_position`（`0.00—1.00`）。后者由以下三项人工裁决后确定，不由节点数计算：

- C1/C2：任内持续时间与覆盖面50%，相对起点和合理反事实的变化25%，可归责直接修正25%；
- D2：交班绝对承压状态60%，恢复机制与财政压力转嫁25%，已形成的流民民变基础15%。

分数为`档位下界 + 档内位置 × (档位上界 - 档位下界)`，四舍五入到一位小数；5档位置`1.00`可取满分。同档皇帝可因持续时间、覆盖面、起点变化、责任和交班裂缝不同而得分不同。

`within_grade_position`是裁决结果而非独立事实；JSON必须同时保存状态锚点、轨迹类型、证据节点、推断线索、置信度和一句可审计理由，禁止只留小数。

## 八、跨项防重复

- 人命、温饱、赋役、破产和生产损害主要归C1；同一链在C2只消费其对财政结构、市场流通或长期税基的不同结果。
- 财政收入若来自过度汲取，C2记结构负面，C1只记民户实际承受；不得把同一征收额两边各全额扣分。
- 灾害响应的任内实际生存与复业结果归C1/C2；交班时仍有多少恢复余量归D2。
- 战争成本以一个聚合结论修正状态轨迹，不按每场WC相加；第三项D继续独立回答投入是否值得。

## 九、正式输出与门禁

正式JSON是机器读取入口，Markdown是确定性阅读视图。两者必须覆盖同一95人、按三项合计降序、同分并列名次，并保存C1/C2/D2档位、分数、`S0/S_avg/S_end`、轨迹、置信度、证据引用和理由。

发布前必须验证：95人无重无漏；分数在档内；排名与并列规则正确；所有相对链接存在；JSON可解析；UTF-8无BOM；生成器连续两次运行零差异；`git diff --check`通过。`formal_score_write=false`与`database_write=false`保持不变。
