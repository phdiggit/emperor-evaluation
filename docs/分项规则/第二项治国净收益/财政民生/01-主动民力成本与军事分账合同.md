# 主动民力成本与军事分账合同

本文件是DA准入、军事与民力分账、唯一消费及DA档表的主题合同，承接[财政民生规则](00-规则与结算合同.md)原§8.4。判断DA须读完整主题正文；核对后果是否已消费时，按具体对象补读原合同§4.4、§5—§7或§8.3，计算C4净分另读§8.5。军事C档及其扣分不由本合同定义。

<a id="da-cost"></a>

### 8.4 破坏性制造/放大 DA

DA只结算本人可选择行为制造或放大、且尚未被C1—C3主态、K折损或C4可归责恶化吸收的主动成本。先剔除必要防御、必要平乱、普通维护、正常陵寝、灾后修复和最低限度国家重建的基线成本，再排除已计后果，按剩余成本的整体严重程度定档。重叠部分不再计入；剩余部分仍达到哪档就定哪档，不能证明独立剩余成本时不计DA，不按重叠事件数量机械减档。

每人按本人责任窗口内去重后的整体成本只定一个DA档、扣一次对应分值；多次战争或营造可以共同证明成本程度，不逐事件赋分相加，也不按事件数量升档。实际动员、役工、军粮、转输和财政抽取可证明客观负担，民困、耗竭和役夫死亡等后果用于判断严重程度；纯军队伤亡、工程名目、改名或概括性规模词不能单独定档，史料简略也不等于没有成本。

**军事成本与民力负担分账**：第一、第三项完整记录本方客观军事投入和毁损；必要防御同样有成本。军人伤亡、军资毁损、军粮实付、军事运输投入及再动员不得仅因本人主动选择而再次折成DA。DA另行判断本人可选择增量对普通家庭劳动力、生产机会、民间财产及非军事公共用途的挤占，或直接平民伤害。可以共用父事件和史料，但必须写出不同的成本对象与传导机制；“主动战争”“已有反馈仍继续”只证明选择归责，不是第二份损害。

**史料可见性保底**：独立民力负担不等于必须另有民困记载。本人窗口内已经实施、超出必要安全基线、相对本政权承载具有实质规模的主动动员，可以通过兵源征集、家庭离业、军需征取等机制受约束推断额外民力负担；对同等动员采用同一门槛，不能有民困记载才扣、失载便不扣。记录须区分`DIRECT`（直接结果）、`INFERRED`（民力传导推断）和`NONE`（无剩余准入成本），分别列出已证行为、推断对象与范围、已由其他项消费的部分及剩余部分。仅由出兵规模、次数、距离、军资金额或战损推断的，统一按DA1保守下限；这不是认定实际负担轻微，也不得凭这些军事指标把推断升为高档。DA2及以上须有民力承载本身的独立范围、强度或持续证据；不要求特定人数、金额或夸张灾难词，有明确役期、征发比例、民间财产损害或广域实际负担的同样可以闭合。

**保底仍服从唯一消费**：逐条核对C1—C3主态、K和C4恶化究竟已消费哪一窗口、群体和后果。明确已经消费同一动员的家庭役负、失农、财产损耗等完整已证后果，且没有其他剩余对象时，不再用“还有主动投入”保留DA1；反之，低档、K折损或恶化扣分本身不证明任何一条成本已被吸收。起点低位及恢复过程依法未计入K的，不可伪称已由K消费。必要防御不能仅因战败变成DA；防御中的独立超额征敛、可避免的役工虐待等仍须单独审查。第一项排除出第三项的统一父链同样执行本规则，不因第三项不适用而把其军费搬入DA。

“国家级”“全国性”均指所评政权的实际治理范围，结合其人口、财政与承载能力判断负担，不设统一疆域、人口或动员人数门槛，也不对小政权打折。成本规模、持续时间和影响范围用于整体判断，不拆成加分项。

| 档 | 扣分 | 整体成本边界 |
|---:|---:|---|
| `DA0` | 0 | 无可归责的实质额外成本，或只有必要防御、普通治理基线；未闭合到本人可选择增量的压力不得转入DA |
| `DA1` | 4.5 | 已证剩余负担总体有限；或主动动员的额外民力传导已满足受约束推断门，按保守下限入档，实际强度尚未直接闭合 |
| `DA2` | 9.0 | 对国家或主要区域形成显著额外负担，已有实质资源占用或民生传导，但尚未达到极重程度 |
| `DA3` | 13.5 | 极重资源或财政占用，或严重生产、家庭损害；一次灾难性选择也可成立，不要求系统状态已经崩坏 |
| `DA4` | 18.0 | 严重全国性或多通道成本，明显挤压正常财政民生，但国家承载体系仍能维持 |
| `DA5` | 22.5 | 接近全国总动员或长期系统汲取，正常财政民生运行已被显著破坏 |
| `DA6` | 27.0 | 罕见灾难级；本人主动成本体系本身成为政权级系统崩坏或近崩坏的直接主要驱动之一 |

裁决依据须说明本人选择、实际成本及其未被其他扣分吸收的部分，并据此匹配上述边界。高状态不能自动抵销主动成本，低状态或亡国也不能反推高DA。
