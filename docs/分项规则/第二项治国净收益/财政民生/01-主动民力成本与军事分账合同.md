# 主动民力成本与军事分账合同

DA规范。已消费后果按[财政民生合同](00-规则与结算合同.md)§4.4、§5—§7、§8.3核对，C4合成见§8.5。

<a id="da-cost"></a>

### 8.4 破坏性制造/放大 DA

**先确定独立剩余成本。**DA只计本人可选择行为造成的额外民力负担，先扣必要防御/平乱、普通维护、正常陵寝、灾后修复和最低重建，再剔除C1—C3主态、L及C4恶化已计后果。按窗口、群体和后果逐条去重，无剩余不扣，也不保底DA1；不能仅凭已有低档或L认定损害已被计入。

军人伤亡、军资军粮、军运和再动员归第一/第三项，主动选择也不再折DA。DA须另证家庭劳力、生产机会、民间财产、非军事公共用途挤占或平民伤害；可共用史源，不能共用同一损害。第一项统一链同样分账，不能把第三项排除的军费搬来。

**再判断证据与程度。**责任窗口整体定一档、扣一次，战争/营造次数仅辅助判断，不叠扣或按重叠事件数减档。动员役工证明负担，民困、耗竭、役夫死亡等证明程度；工程名称、纯军损或规模概括不足，失载也不证明无成本。

已实施、超必要安全基线且相对政权承载有实质规模的动员，可推断家庭离业等负担，不强求另一条民困原文。记`DIRECT`、`INFERRED`或`NONE`，说明已证行为、对象范围、已计与剩余部分。仅据军事规模、次数、距离、金额或战损推断时限DA1下限，不表示实际轻微；DA2以上须民力自身范围、强度或持续证据，如役期、征发比例、财产损害，不设特定数字或灾难词门槛。

恢复期和低起点仍按L实际已计后果核对，不因恢复身份豁免，也不把整条恢复链视为已扣。防御战败不转DA，独立超额征敛、可避免虐役另审。国家尺度按本政权范围、人口及财政承载判断，不设统一疆域/人数门槛或小政权折扣。

| 档 | 扣分 | 整体成本边界 |
|---:|---:|---|
| `DA0` | 0 | 无可归责的实质额外成本，或只有必要防御、普通治理基线；未闭合到本人可选择增量的压力不得转入DA |
| `DA1` | 4.5 | 已证剩余负担总体有限；或主动动员的额外民力传导已满足受约束推断门，按保守下限入档，实际强度尚未直接闭合 |
| `DA2` | 9.0 | 对国家或主要区域形成显著额外负担，已有实质资源占用或民生传导，但尚未达到极重程度 |
| `DA3` | 13.5 | 极重资源或财政占用，或严重生产、家庭损害；一次灾难性选择也可成立，不要求系统状态已经崩坏 |
| `DA4` | 18.0 | 严重全国性或多通道成本，明显挤压正常财政民生，但国家承载体系仍能维持 |
| `DA5` | 22.5 | 接近全国总动员或长期系统汲取，正常财政民生运行已被显著破坏 |
| `DA6` | 27.0 | 罕见灾难级；本人主动成本体系本身成为政权级系统崩坏或近崩坏的直接主要驱动之一 |

依据写本人选择、实付成本与未消费部分；高状态不抵成本，低状态/亡国不反推高DA。
