# 主动民力成本与军事分账合同

<a id="da-cost"></a>

P总价、已计抵扣及过渡状态规范。恢复与恶化基础定义见[财政民生合同](00-规则与结算合同.md)§8。

## 一、直接损害总价P

P为责任窗口内已准入的直接民力损害集合总价。对象包括家庭劳力、生产机会、民间财产、非军事公共用途挤占及平民生命、人身损害。先排必要防御与平乱、普通维护、正常陵寝、灾后修复及最低重建，再对超必要部分判断；不先减去C1—C3或E已记金额。已计部分统一由后述抵扣处理。

每组结果必须明确实施行为、受害对象、实际后果、本人责任窗口与史源定位。监督责任须连接具体行动或制度授权、实际控制和作用链；仅名义在位、任官或一般宠信不充分。事后纠正限制持续时间与范围，不抹去已发生的伤害。少数人或政治人物受害不因身份排除，但处决、拘捕本身不足证明超必要；须区分必要制伏、真实威胁及过度处分，未闭合者留作未决事件。

军人伤亡、军资军粮、军运和再动员仍归第一或第三项；第一项统一链同样分账。第四项已计身份、奴属及国家整合结构后果，不再以同一结构转属收P；另有直接生命、身体、家庭财产或生计损害时，须单独闭合后果再准入。不能把其他项目排除的军事投入移来计价。

证据分DIRECT、INFERRED、NONE。已实施、超必要安全基线且相对政权承载有实质规模的动员，可以有界推断家庭离业等负担，不强求另一条民困原文；须说明已证行为、对象、传导链及限制。仅据军事规模、次数、距离、金额或战损推断时，只能取4.5保守下限；9以上须民力自身范围、强度或持续证据。没有准入证据不等于零损害，不能用粗计价补造事实。

责任窗口整体定一档、只扣一次，不按事件数相加；不同后果合看，重复史料不加价。尺度依据本政权范围、人口及财政承载，不设统一死亡人数门槛、小政权折扣，也不以亡国或低状态反推价格。

| P档 | 分值 | 整体已纳集合边界 |
|---|---:|---|
| P0 | 0 | 已核集合无可归责实质额外直接损害；不能代替未知或未审 |
| P1 | 4.5 | 有界个人、家庭直接损害或有限额外负担；符合有界推断门的保守下限 |
| P2 | 9 | 显著群体侵害、持续拘系或实质额外资源负担，整体达到显著程度 |
| P3 | 13.5 | 重大区域严重生命、生计或家庭损害，或极重额外资源占用 |
| P4 | 18 | 多区域或多通道严重直接损害 |
| P5 | 22.5 | 长期系统重损，正常财政民生运行被显著破坏 |
| P6 | 27 | 极重集合，直接损害支配主要生活领域；不能仅靠亡国或状态低档成立 |

P依当前证据独立定档，取值限于上表；旧DA的档名和分值均不作为P的定档依据或下限。

## 二、主态及L抵扣

逐轴确认已纳损害参与压低当前实际主态或L，并给出有材料约束的粗粒度会计参照。仅阻断潜在高态而未形成实际扣分的影响、未准入事件及战争灾荒等其他后果，不予回补。参照用于计算已计损害，无需证明历史上曾达到该状态，也不改变实际状态或产生恢复功劳。

每轴合并主态及L影响后计算一次：

```text
C_axis = state_score(参照主态, 参照L) − state_score(实际主态, 实际L)
C_state_L = Σ C_axis
```

参照档须在现合同1—6档、L枚举内；C_axis非负，且不能超过该轴实际分与合法最大参照分之差。不同轴须对应不同后果，不能拿同一家庭资源损失同时按民生和财政再退一次；主态及L也不得分别计算后重复相加。真实S0、S_main、S_end及L保持原裁决；原裁决确有错误时另作源裁决修订。

## 三、E分账与R边界

先按现行实际S0、S_end及归责系数计算E_before，再逐轴裁定本次P已纳损害所对应的实际下降档界k。0≤k≤max(0,S0−S_end)，须有同组后果依据；不能按P价格换算k。原归责系数不变，其他原因导致的下降保留。

```text
d_axis = max(0, S0_axis − S_end_axis)
E_remaining = round_half_up_1(13 × min(1, Σ(weight_axis × attribution_axis × (d_axis − k_axis)) / 2))
C_E = E_before − E_remaining
```

权重仍为C1 0.5、C2 0.2、C3 0.3。先合成、封顶13再舍入，不将各轴回补分别计算后相加。C_E是派生展示值，不再进入采用E_remaining的公式。E内部跨轴仍须区分后果；主态/L与E两个记账位置的重复扣分分别回补，同一位置只处理一次。

R继续按现行实际可比基线、交班保留增量、恢复归责及终局上限计算。前窗同区直接重大致损成立后采用介入前基线；前置状态不明才适用现合同50%代理，不重复叠乘共享归责。不能因任内有P一律取消R，也不能从抵扣参照生成R。

## 四、唯一合成与范围

```text
C4 = R − E_remaining − P + C_state_L
   = R − E_before − P + C_state_L + C_E
```

两式择一计算，禁止重复加入C_E。取消C4单项[-40,27]截断。旧DA不再另扣；相对旧制变化以新旧实际C4相减为准。旧C4未经截断时才可简写为old_DA−P+C_state_L+C_E，不把这一历史数据条件设为新制度普遍恒等式。

C1—C3加合法抵扣最多175，R最多27，E_remaining与P非负，故C块最多202、第二项最多387、第二三项共同分母637不变。保留P≤27时，C4下界仍为−40；第二项下界仍为−27.5：C1—C3最低合计12.5，C4不低于−40，其他组件非负。C4本身可超过27，展示不得用27将去重回补截掉。

## 五、适用状态与唯一输入

正式版本为C4-CIVILIAN-HARM-V2，唯一人工输入位于C4正式人物记录的civilian_harm_adjudication。ADOPTED采用本合同；BASELINE_RETAINED、UNRESOLVED、NOT_READY及OUTSIDE_POOL保留本页旧制公式，新P必须为null，不得退款或宣称新制已完成。规范池就绪状态仍由canonical-ruler-pool决定，未就绪及池外不参加综合排名。

已纳集合与未决事件分开。部分事件未决不撤销已闭合集合，未决事件不进入已纳价格及其范围。每人以稳定group_id标识已裁整体集合，保留对象、实际后果、责任窗口、史源及归责/去重理由；必要时分列独立后果ID。同一集合跨轴须明确各账位消费的不同后果，不以拆分ID制造独立性。状态参照、E剥离及恢复边界均须有当前理由。原文和引用只指向正式记录、有效证据来源或史源，不依赖临时试算与历史报告。

记录跨项交班时，`cross_item_handoffs`须指向当前邻项人物及具体结果（存在结果ID时），双方以同一`binding_id`保存各自独占后果、对方后果及分账理由。撤销第四项额外价格须保留其事实、当前不准入理由和去向，不能只删一边。制度条文、程序变化或身份规则已在其他项计价时，另收P须有实际直接伤害及本人责任，不能仅将规则损害改称人身损害。双向引用校验只验证定位和说明一致，不代替历史独立性判断。

旧DA字段及06主动民力成本去重审计对ADOPTED只承担原证据追溯，不再参与计分；不得把旧DA改名冒充新P。civilian_harm_calculation为从当前人工输入派生的计算明细，不是第二份裁决输入。展示须区分恢复、损害总价、剩余恶化与回补，并透传保留旧制状态。

审慎情景保留P和已裁会计参照：若情景实际状态分已达到/超过参照，该轴抵扣为0；E剥离不得超过情景实际下降。不得把参照继续随情景上推、生成新R或保留已不存在的退款。实际主裁变化须复核人工参照；情景裁剪不反向改写正式主裁。

## 六、保留旧制对象的DA规则

以下只用于未采用新制或池外保留对象。旧制C4=clip(R−E−DA,−40,27)，正向恢复与恶化仍按主合同。新P为null与旧DA为0不同，不以保留数值推定新制语义完成。

**先确定独立剩余成本。**DA只计本人可选择行为造成的额外民力负担，先扣必要防御/平乱、普通维护、正常陵寝、灾后修复和最低重建，再剔除C1—C3主态、L及C4恶化已计后果。按窗口、群体和后果逐条去重，无剩余不扣，也不保底DA1；不能仅凭已有低档或L认定损害已被计入。

军人伤亡、军资军粮、军运和再动员归第一/第三项，主动选择也不再折DA。DA须另证家庭劳力、生产机会、民间财产、非军事公共用途挤占或平民伤害；可共用史源，不能共用同一损害。第一项统一链同样分账，不能把第三项排除的军费搬来。

**再判断证据与程度。**责任窗口整体定一档、扣一次，战争/营造次数仅辅助判断，不叠扣或按重叠事件数减档。动员役工证明负担，民困、耗竭、役夫死亡等证明程度；工程名称、纯军损或规模概括不足，失载也不证明无成本。

已实施、超必要安全基线且相对政权承载有实质规模的动员，可推断家庭离业等负担，不强求另一条民困原文。记`DIRECT`、`INFERRED`或`NONE`，说明已证行为、对象范围、已计与剩余部分。仅据军事规模、次数、距离、金额或战损推断时限DA1下限，不表示实际轻微；DA2以上须民力自身范围、强度或持续证据，如役期、征发比例、财产损害，不设特定数字或灾难词门槛。

恢复期和低起点仍按L实际已计后果核对，不因恢复身份豁免，也不把整条恢复链视为已扣。防御战败不转DA，独立超额征敛、可避免虐役另审。国家尺度按本政权范围、人口及财政承载判断，不设统一疆域/人数门槛或小政权折扣。

| 档 | 扣分 | 整体成本边界 |
|---:|---:|---|
| `DA0` | 0 | 无可归责的实质额外成本，或只有必要防御、普通治理基线；未闭合到本人可选择增量的压力不得转入DA |
| `DA1` | 4.5 | 已证剩余负担总体有限；或主动动员的额外民力传导已满足受约束推断门，按保守下限入档，实际强度尚未直接闭合 |
| `DA2` | 9.0 | 对国家或主要区域形成显著额外负担，已有实质资源占用或民生传导，但尚未达到极重程度 |
| `DA3` | 13.5 | 极重资源或财政占用，或严重生产、家庭损害；一次灾难性选择也可成立，不要求系统状态已经崩坏 |
| `DA4` | 18.0 | 严重全国性或多通道成本，明显挤压正常财政民生，但国家承载体系仍能维持 |
| `DA5` | 22.5 | 接近全国总动员或长期系统汲取，正常财政民生运行已被显著破坏 |
| `DA6` | 27.0 | 罕见灾难级；本人主动成本体系本身成为政权级系统崩坏或近崩坏的直接主要驱动之一 |

依据写本人选择、实付成本与未消费部分；高状态不抵成本，低状态/亡国不反推高DA。
