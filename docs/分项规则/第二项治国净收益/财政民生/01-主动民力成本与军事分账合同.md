# 主动民力成本与军事分账合同

DA规范。已消费后果按[财政民生合同](00-规则与结算合同.md)§4.4、§5—§7、§8.3核对，C4合成见§8.5。

### 8.4 破坏性制造/放大 DA

DA计本人可选择行为的剩余主动成本：先扣除必要防御/平乱、普通维护、正常陵寝、灾后修复和最低重建基线，再剔除C1—C3主态、L或C4恶化已消费后果。按剩余严重度定档，无独立剩余不扣，不按重叠事件数减档。

责任窗口内整体只定一档、扣一次，多次战争/营造可共同证明程度但不按次数加分。动员与役工等证负担，民困、耗竭、役夫死亡证程度；纯军损、工程名目、改名或规模概括不足定档，失载不等于无成本。

军人伤亡、军资军粮、军运与再动员归第一/第三项，必要防御亦计，不因主动选择再折DA。DA另证家庭劳力、生产机会、民间财产、非军事公共用途挤占或平民伤害。可共用父事件史源，但对象与传导须独立；主动或知情继续只证归责。

窗口内已实施、超必要安全基线且相对政权承载有实质规模的动员，可受约束推断家庭离业等额外负担，不强求另有民困原文。标`DIRECT`、`INFERRED`或`NONE`，列已证行为、推断对象范围、已消费及剩余。纯由军事规模/次数/距离/金额/战损推断统一DA1下限，不代表实际轻微；DA2以上须民力本身范围、强度或持续证据，役期、征发比例、财产损害等均可，不设特定数额或灾难词门。

逐条核对消费窗口、群体与后果：完整消费且无剩余不保底DA1，低档或已有L/恶化本身不证明已吸收。低起点及恢复阶段须按当前L实际消费结果核对，不因恢复身份一律豁免，也不把整条恢复链视为已消费。防御战败不转DA，但独立超额征敛、可避免虐役另审。第一项统一父链同样分账，不将被第三项排除的军费搬入DA。

国家尺度按所评政权的范围、人口、财政承载判，不设统一疆域/人数门槛或小政权折扣；规模、时长、范围只作整体判断。

| 档 | 扣分 | 整体成本边界 |
|---:|---:|---|
| `DA0` | 0 | 无可归责的实质额外成本，或只有必要防御、普通治理基线；未闭合到本人可选择增量的压力不得转入DA |
| `DA1` | 4.5 | 已证剩余负担总体有限；或主动动员的额外民力传导已满足受约束推断门，按保守下限入档，实际强度尚未直接闭合 |
| `DA2` | 9.0 | 对国家或主要区域形成显著额外负担，已有实质资源占用或民生传导，但尚未达到极重程度 |
| `DA3` | 13.5 | 极重资源或财政占用，或严重生产、家庭损害；一次灾难性选择也可成立，不要求系统状态已经崩坏 |
| `DA4` | 18.0 | 严重全国性或多通道成本，明显挤压正常财政民生，但国家承载体系仍能维持 |
| `DA5` | 22.5 | 接近全国总动员或长期系统汲取，正常财政民生运行已被显著破坏 |
| `DA6` | 27.0 | 罕见灾难级；本人主动成本体系本身成为政权级系统崩坏或近崩坏的直接主要驱动之一 |

依据写本人选择、实付成本与未消费部分；高状态不抵成本，低状态/亡国不反推高DA。
