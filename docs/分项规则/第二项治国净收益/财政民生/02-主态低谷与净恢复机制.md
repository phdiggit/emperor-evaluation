# 主态低谷与净恢复机制

规则版本：`GOVERNANCE-STATE-RECOVERY-V4`。适用当前规范评价池，入口与启用状态由`config/project.yml`声明。池外保留既有记录且不进入当前综合榜；不得混用机制版本。结构检查不代替语义裁决。

## 1. 对象与主态

C1家庭80、C2经济财政35、C3社会安全60，对象、六档及固定分沿用[主合同](00-规则与结算合同.md)。C4范围仍为[-40,27]，共同分母637与综合公式不变，小政权不折扣。

每轴保存可比治理对象的接手`S0`、任内主态`S_main`与交班`S_end`。主态评主要受治群体、主要治理阶段的实际状态，不是先汇总全任损害后的折中档；不能以最强史评、短暂峰值或材料沉默替代。低位实际占主导时重裁主态；高低竞争且无法证明高态占优时，取有证据支持的较低主态。材料稀少本身不降档。

## 2. 全任低谷L

L只计本人实际治理窗口内、本轴对象已经遭遇、且较主态更差的独立后果。先剔除已使主态降低的部分；仅用来否定更高档的反证不自动算已计，须结合主态正证判断。

每轴写清主态已计什么、L另计哪个阶段和后果。同源不同结果可分计，不能只填去重模板。全任每轴一档，不按年份或事件叠扣，也不强求人口比例、时长或低谷六档。

| L | 必要边界 | 主态分扣减率 |
|---|---|---:|
| L0 | 定向审查未另证独立有效低谷；不表示全任完美 | 0 |
| L1 | 已证损害，仅能证明有界局部、短时或有限后果；更高档的程度范围未闭合 | 3% |
| L2 | 重要地区或群体的明显损害，或有依据的反复影响；未达L3 | 7% |
| L3 | 严重本轴后果已证，并满足广泛覆盖或重要地区、群体长期反复受害；主态仍独立成立 | 12% |

严重度须由家庭失保、经济财政失常、人身财产伤害或基层司法失效等实际结果证明，政策、灾害、战争名称和预警不够。短而广泛严重可L3，长期小范围不因此到L3；多档符合取已证最高档。

恢复期、衰败期同样审实际体验：掌权后有效低态可计L，接手瞬间不单独扣，“正在恢复”不证明损害。外生性只影响归责，末期低态不自动固定扣档，失权后新增损害不倒灌；跨任、共享、范围变化按主合同保证三锚可比。

损害已证但程度范围不足，取L1并注明“最低已证”，不能说已证轻微。无有效低谷可L0，但不能补足高主态证据。对象、人物、窗口或足以改变裁决的关键矛盾未决时，不标相应裁决完成；正常证据限制与语义闭合的区分见[不确定性合同§2.1](../../../证据规则/裁决不确定性与敏感性合同.md#21-受约束推断与语义闭合)。

```text
C_axis = round_half_up_1(max(F_axis(1), F_axis(S_main) × (1 - rate(L))))
```

只舍入最终轴分，最低档分托底，主态已计困顿不重扣。修正不代表人口年平均，也不要求落在两个实际阶段分数之间。历史稳定诊断仅保留画像追溯所需引用，不计分，不从L换算画像或稳定分。

## 3. 净恢复、归责及去重

恢复只计可比基线至交班仍保留的向上档界，按[主合同§8.2—§8.3](00-规则与结算合同.md#82-正向净恢复)结算。不得以峰值代替交班；自造低起点、前置状态不明代理、共享归责及终局上限沿用对应条款。

C4恶化逐轴比较S0与S_end，保留已裁责任系数；责任不得由末档、亡国或灾害反推。端点改变须复算恢复、恶化与直接交班邻接。净恢复零分不抹去C1—C3长期主态。

状态修正与归责恶化分别消费绝对体验与本人净损害；同一事件须区分窗口、群体和后果，不能因标签不同重复记同一对象。[DA分账合同](01-主动民力成本与军事分账合同.md)只计独立剩余。不得把取消旧折损释放的分差搬到DA，也不得仅因L较低认定原有后果尚未消费。

## 4. 裁决与验收

逐人源为`config/second-item/governance-state-recovery-adjudications.json`；离线纯计算、校验及声明的组件写入为`src/emperor_v4/evaluation/governance_state_recovery.py`。

每轴保存三锚、主态依据、L及具体结果依据、强维度、全任恢复期审查声明、具体去重判断和史源指针。L3强维度必须包含严重度及范围或持续性，后者须符合§2对象边界；历史诊断与模板不能生成新档。恢复保存逐轴基线、终点、归责及可复算结果。覆盖与规范池动态核对，不固化人数。

全池裁决完成后统一启用；局部改判同步受影响的C1—C4、第二项总表、综合榜及画像引用。验证映射、舍入、上下限、单调性、覆盖、引用及同值；不固化人物分数或分布，不作跨轴哈希同步。
