# 主态低谷与净恢复机制

规则版本：`GOVERNANCE-STATE-RECOVERY-V3`。适用当前规范评价池，入口与启用状态由`config/project.yml`声明。池外保留既有记录且不进入当前综合榜；不得混用机制版本。结构检查不代替语义裁决。

## 1. 对象与主态

C1家庭80、C2经济财政35、C3社会安全60，对象、六档及固定分沿用[主合同](00-规则与结算合同.md)。C4范围仍为[-40,27]，共同分母637与综合公式不变，小政权不折扣。

每轴保存可比治理对象的接手`S0`、任内主态`S_main`与交班`S_end`。主态须代表主要受治群体，不能以最强史评、短暂峰值或材料沉默替代。低位实际占主导时重裁主态；高低竞争且无法证明高态占优时，取有证据支持的较低主态。材料稀少本身不降档。

## 2. 全任低谷L

先确认本人实际治理窗口、本轴对象及已实现的较主态更差结果，再剔除主态已消费的同一后果。全任每轴只裁一档，不逐年、逐事件叠扣，不强制填写人口比例、阶段时长或低谷六档。

| L | 必要边界 | 本轴满分扣减率 |
|---|---|---:|
| L0 | 定向审查未另证独立有效低谷；不表示全任完美 | 0 |
| L1 | 已证损害，仅能证明有界局部、短时或有限后果；更高档的程度范围未闭合 | 3% |
| L2 | 重要地区或群体的明显损害，或有依据的反复影响；未达L3 | 7% |
| L3 | 广泛覆盖、长期/反复、严重后果三项至少两项有实证，且主态仍独立成立 | 12% |

严重后果须为家庭失保、经济财政失常、人身财产伤害或基层司法失效等本轴结果，不是政策、灾害、战争名称。短而广泛严重的灾难可到L3；长期小范围事件不因“长期”自动到L3。多档重叠取证据支持的最高档。

继承低起点不一律豁免：本人掌权后已形成有效恢复阶段的低态纳入L，接手瞬间截面不单独扣。外生性只影响责任，不删除实际状态。末期较低不自动触发固定扣档；失去实际治理权后的新增损害不倒灌。跨任、共享及范围重构按主合同三锚可比性处理。

已证损害但程度范围不足，取L1并注明“最低已证”，不得写成“已证损害轻微”。只有预警、政策/战争名或历史诊断标签，不满足L1准入，须沿引用回源。无有效低谷证据可取L0，但不能据此补足高主态正证。人物、窗口、对象或关键矛盾未决时不得标完成。

```text
C_axis = round_half_up_1(max(F_axis(1), F_axis(S_main) - M_axis × rate(L)))
M_axis = {C1:80, C2:35, C3:60}
```

只舍入最终轴分，不先舍入扣减。最低档分为下限，最低主态已消费的困顿不重复扣。此为主态主导的有限评价修正，不解释成人口年平均，不要求修正分落在两个实际阶段分数之间。历史稳定诊断只保留独立画像引用所需的最小lineage，不再计分，也不从L机械换算画像档位或稳定分。

## 3. 净恢复、归责及去重

恢复只计可比基线至交班仍保留的向上档界，按[主合同§8.2—§8.3](00-规则与结算合同.md#82-正向净恢复)结算。不得以峰值代替交班；自造低起点、前置状态不明代理、共享归责及终局上限沿用对应条款。

C4恶化逐轴比较S0与S_end，保留已裁责任系数；责任不得由末档、亡国或灾害反推。端点改变须复算恢复、恶化与直接交班邻接。净恢复零分不抹去C1—C3长期主态。

状态修正与归责恶化分别消费绝对体验与本人净损害；同一事件须区分窗口、群体和后果，不能因标签不同重复记同一对象。[DA分账合同](01-主动民力成本与军事分账合同.md)只计独立剩余。不得把取消旧折损释放的分差搬到DA，也不得仅因L较低认定原有后果尚未消费。

## 4. 裁决与验收

逐人源为`config/second-item/governance-state-recovery-adjudications.json`；离线纯计算、校验及声明的组件写入为`src/emperor_v4/evaluation/governance_state_recovery.py`。

每轴保存三锚、主态依据、L及具体结果依据、强维度、全任恢复期审查声明、去重判断和史源指针。L3须至少两个强维度；历史诊断与模板不能生成新档。恢复保存逐轴基线、终点、归责及可复算结果。覆盖与规范池动态核对，不固化人数。

全池裁决完成后统一启用，同步C1—C4、第二项总表、综合榜及受影响画像引用。验证映射、舍入、上下限、单调性、覆盖、引用及上下游同值；不把人物分数或档位分布写入测试，不做跨轴哈希同步。
