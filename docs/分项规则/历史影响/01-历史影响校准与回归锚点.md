# 历史影响校准与回归锚点

> [历史影响总则](../../项目总纲/历史影响评价总则.md)的人工校准附件，适用`FORMAL-V1.10`。本文件列检查问题与对照对象，不另存人物档位答案。

## 1. 使用边界

人物当前结论读取正式JSON，按总则和事实判断；样本只帮助比较，不能成为人物特例、自动测试的固定答案，或保住旧档的理由。事实改变时先改正式记录，再确认样本是否仍适合；历史由Git保存。

## 2. 范围尺度引用

主体核心和大型政治空间可参考既有`major_region`、`macroregion`、全国核心统一尺度及`external_equivalent_block`，外围空间参考[统一空间锚点表](../第三项军事与边疆净收益/国防安全/01-B1统一空间锚点表.md)。只比较实际改写空间的量级，不继承控制权重、覆盖率、分数或阈值。

先对同主体、战争链和控制关系去重；全国领域性变化不能与领土面积相加。

## 3. 范围合同回归样本

范围规则变化后，用下列对象检查是否误把国名、方向数、面积或战争触达当作秩序改写。当前档位以正式记录为准。

| 对照对象 | 检查问题 |
|---|---|
| 嬴政、朱元璋 | 巨大核心统一与全国组织重组是否按实际量级评价，既不因“一个单元”压低，也不因统一自动给高档？ |
| 李世民、铁木真 | 多个外围政治空间、服从关系和军政节点是否真实重组，是否混入羁縻名义面积或短暂触达？ |
| 玄烨 | 多空间采用的秩序层是否明确、互不重复？ |
| 弘历 | 西北空间的主体终结、常设治理与全国领域变化是否被机械相加？ |
| 黄巢 | 是否把行军、战区、劫掠和短占范围当作已改写空间？ |
| 李隆基 | 是否只计失权前实际核心控制和中枢断裂，而非整个安史战区？ |

## 4. 个人因果高档回归门

个人因果回归不靠“谁和谁必须同档”，而是检查相同结构问题是否得到同一回答：

| 结构类型 | 重点边界 | 必须回答的问题 |
|---|---|---|
| 成熟政权高密度改革 | S- / S | 删除本人后，改革大方向是否仍较可能发生？差异只是速度、力度和组合，还是至少一条国家级关键链很可能不能形成或制度化？ |
| 创建或重建型人物 | S / S+ | 删除本人后，是少数关键结构缺失，还是支撑核心足迹的主要路径大部消失或国家基本路径根本换轨？ |
| 强国家机器上的战争/统一完成者 | S- / S | 既有国力、军队和人才保留后，替代者是否仍较可能取得功能等价结果？本人改变的是结果存在本身，还是完成时间、代价和具体边界？ |
| 危机逆转或亡国放大型人物 | S / S+ | 危机本身是否由前制和外力主导？删除本人后，危机结局是否仍高度收敛，还是本人选择真正关闭或开启了国家级替代路径？ |

## 5. V1.10现行适用规则

版本升级不自动重裁。个人因果理由若只靠改革数量、勤政、执行强或后世沿用，未说明最近可行替代，才进入专项复核；范围理由若依赖数方向、数国名、面积直加或秩序层相加，则重开范围审查。

`scope_assessment.method`记录最近实际完成的范围复核版本，不能随总合同升级冒称已完成人工复核；`contract_version`表示适用合同。影响性质复核不等于同时完成四维、总档或个人因果重裁。
