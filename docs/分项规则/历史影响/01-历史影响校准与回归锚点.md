# 历史影响校准与回归锚点

> 本文是[历史影响评价总则](../../项目总纲/历史影响评价总则.md)的校准附件，服务于 `FORMAL-V1.10`。这里只保存会随正式裁决与合同演进而变化的回归样本、尺度引用和重点复核集合；一般档位规则只在总则定义。

## 1. 使用边界

- 本附件用于**回归测试与横向校准**，不构成人物特例，也不是独立裁判真源。
- 人物当前档只能由总则的一般规则和正式事实推出；不得因为某人被列为锚点，就为了守住旧档反向修改一般规则。
- 正式事实变化时先更新该人物正式记录，再复核其是否仍适合作为回归样本。历史版本由 Git 保存，不在本附件维护阶段报告。
- 本附件中的人物档位是当前校准快照；总则中的规则优先级高于任何单个人物锚点。

## 2. 范围尺度引用

历史影响只借既有正式空间体系做**尺寸横校**，不继承其他项目的分数、控制信用或数值阈值。

- 既有空间体系中的 `major_region`、`macroregion`、全国核心统一尺度与 `external_equivalent_block` 可作为主体核心与大型政治空间的尺寸参照。
- 现行[统一空间锚点表](../第三项军事与边疆净收益/国防安全/01-B1统一空间锚点表.md)可作为外围政治空间的横向尺寸参照。
- 历史影响只问“实际被改写的政治空间大致属于什么量级”；不得把既有权重、覆盖率、控制分或阈值直接换算为历史影响档位。
- 同一主体、同一战争链、同一控制关系先去重，再做当量比较；全国领域性变化不得与领土空间机械相加。

## 3. 范围合同回归样本

下列样本用于范围规则变更后的人工回归。它们检验规则是否出现“数方向、数国名、面积直加、把战争触达当改写”等漂移，不承担定义档位的职责。

| 样本 | 当前范围 | 回归功能 |
|---|---|---|
| 嬴政 | S- | 单一超级核心空间大部 + 全国国家组织重组；检验“一个巨大空间”不会因只算一个单元而被压低，也不会仅因全国统一自动进S |
| 朱元璋 | S- | 巨大核心统一 + 全国组织重塑、外围较弱；与嬴政共同压实S-核心尺度 |
| 李世民 | S+ | 主体核心继续统一 + 多个主要外围政治主体、服从关系和军政节点真实重组；检验最高档不是羁縻面积换算 |
| 铁木真 | S+ | 草原核心重组 + 多个超大型外围政治空间真实改变；检验域外等价与最高覆盖形状 |
| 玄烨（康熙帝） | S | 多个中大型空间但改写层次不同；检验多空间合并必须先限缩实际秩序层并去重 |
| 弘历（乾隆帝） | A+ | 一个超大型西北政治空间发生主体终结与常设治理，同时另有全国领域变化；检验空间与领域覆盖不能机械相加 |
| 黄巢 | A+ | 负向样本：军队经过、战区、劫掠与短期占领不得按地图覆盖折算空间当量 |
| 李隆基（唐玄宗） | S- | 负向样本：不消费安史战区面积，只消费本人失权前已经发生的核心控制与最高中枢真实断裂 |

## 4. 个人因果高档回归门

个人因果回归不靠“谁和谁必须同档”，而是检查相同结构问题是否得到同一回答：

| 结构类型 | 重点边界 | 必须回答的问题 |
|---|---|---|
| 成熟政权高密度改革 | S- / S | 删除本人后，改革大方向是否仍较可能发生？差异只是速度、力度和组合，还是至少一条国家级关键链很可能不能形成或制度化？ |
| 创建或重建型人物 | S / S+ | 删除本人后，是少数关键结构缺失，还是支撑核心足迹的主要路径大部消失或国家基本路径根本换轨？ |
| 强国家机器上的战争/统一完成者 | S- / S | 既有国力、军队和人才保留后，替代者是否仍较可能取得功能等价结果？本人改变的是结果存在本身，还是完成时间、代价和具体边界？ |
| 危机逆转或亡国放大型人物 | S / S+ | 危机本身是否由前制和外力主导？删除本人后，危机结局是否仍高度收敛，还是本人选择真正关闭或开启了国家级替代路径？ |

## 5. V1.10现行适用规则

- V1.9收紧个人因果高档语义，并把人物回归表、尺度引用和重点复核集合移出总则；V1.10补入影响性质的独立正负后效边界，不因版本号变化自动重裁四维或总档。
- 现有个人因果裁决只有在其理由实质依赖“改革很多”“勤政”“执行强”“后世长期沿用”而没有闭合最近可行反事实时，才进入专项复核。
- 现有范围裁决继续有效；仅当理由实际依赖数方向、数国名、面积直加或不同秩序层机械相加时重开。
- `scope_assessment.method`仍表示该人物最近一次完成的范围专项复核方法版本，不得仅因总合同升级就批量伪装成已经完成V1.9人工复核。
- 正式JSON的 `contract_version` 升级表示当前裁决受V1.10治理；本轮影响性质全池复核不冒称同时完成了四维、总档或个人因果的重新裁决。
