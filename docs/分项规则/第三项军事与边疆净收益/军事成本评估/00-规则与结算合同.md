# 军事成本评估合同

## 1. 范围与归责

本合同只裁决第三项军事成本 C0—C7、档内位置和证据状态。安全结果、D 档及总分换算由各自合同规定。

只评价本人实际主政窗口内已经发生的本方军事投入和毁损：军事人员死亡、被俘和失联，兵团与指挥组织毁损，征兵、驻屯、调军、军用劳役，军马、舰船、军械、军粮、工程和运输损耗，以及灾后补充、重建和持续战争承载。已经执行的造船、备马、筑塞、屯粮与转运，即使最终未出征也计入；未执行的计划不计。

敌军、叛军、平民和无法拆分的军民混合死亡不计入本方军事损害；财政恶化、生产破坏、失地、失都、亡国和安全恶化本身不能替代成本证据。民生后果只能在证明军用征发规模时辅助说明军事承载。

第一项已经消费的创业、复国、统一或政权取得父链，成果与成本整链退出第三项，记 `NOT_APPLICABLE`，不得写成 C0。第三项 C 能力层消费的任务可退出 D 局部视图，但其本人窗口内实际军事成本仍进入第三项全局成本；两种范围不得混用。

归责决定成本属于哪个主体、哪个窗口，不改变已发生损害的物理或组织严重度，也不直接决定档内位置。交接与重叠主政阶段沿用正式窗口，同一阶段不得重复归入两个主体。

## 2. 档位

| 档位 | 必须闭合的成本结构 |
|---|---|
| C0 | 本项范围内没有实质可归责军事投入或毁损。 |
| C1 | 局部、短期、常规投入，无显著军资或兵团毁损。 |
| C2 | 有限方向投入，或轻度、容易恢复的人员、军资或编组损害，无长期高强度反复。 |
| C3 | 明显方向级投入，或有限行动形成可见累计承载；尚未形成显著兵团毁损、重大战争准备或国家级长期承载。 |
| C4 | 大规模或持续显著的区域、国家行动，具有实质意义的兵团毁损，或已执行的显著战争准备、后勤工程；仍未达到 C5。 |
| C5 | 主要野战力量或核心兵团重大但非灾难性毁损；或连续战争时期长期反复高强度投入形成国家尺度承载；或尚未恢复、共享军力与后勤重建链的相邻成本累计达到同等结构。国家核心军事组织和作战能力总体仍保持连续。 |
| C6 | 国家主力、核心战区军力、核心军种或军事指挥组织发生灾难性连续性断裂；或国家不可替代的核心作战能力灾难性耗损，实际中断、显著失能，或被迫大规模补充、重建、替代。 |
| C7 | C6 级断裂后，经重大补充、重建或替代，再发生新的 C6 级断裂；或多个核心系统、主要战区反复发生同级终止，使国家主要军事能力反复系统性失效与重建。 |

C6 的组织与核心能力是两条独立通道。军马、舰船或运输资产损失很多，仍须证明其国家核心角色、灾难程度与能力后果；一次亡国或一次体系终止本身不够 C7。强国能迅速恢复，不减免此前已经发生的核心连续性断裂；后来能出兵也不能反推此前必有断裂。

## 3. 聚合与比较

先切分窗口和去重，辨明受损对象及其军力角色，再核对绝对规模、相对损失、组织连续性与重建事实。最高已闭合单次或单链结构确定下限，累计只有真正达到更高档结构时才能抬档。

两个 C4 不自动成为 C5，两个 C5 不自动成为 C6，C6 加后续重大损失不自动成为 C7。同一事实被拆成几场战斗不能改变档位。

跨事件累计须有时间及恢复连续性：前次恢复尚未完成，或同属连续战争、共享主力、战区、后勤与再动员体系。相隔多年、已恢复常态且无持续承载关系的事件，按恢复重置处理，只能辅助档内比较，不能按全任期总和拼档。

本土重要区域的长期战争、灾后再动员与多方向承载可以强化成本，但不能代替高档核心门。小国数千人也可能是国家主力，大国数万人也可能只是一路军；同时比较绝对规模与相对重要性，不能仅凭人数或国力定档。

## 4. 位置、状态与正式记录

- `LOW`：刚闭合本档结构，规模或累计强化有限。
- `MID`：结构清楚，并有一项明显强化。
- `HIGH`：结构极强、多项同向强化，但仍缺更高档必要门。
- C7 另允许 `HIGHEST`，须以反复国家级军事断裂及其绝对规模闭合，不能凭人物名望。

位置比较人员与资产损失、动员与后勤规模、军力重要性、持续年限、战区覆盖和重建规模，责任强弱不作为位置加减器。

证据状态为 `CONFIRMED`（关键结构闭合）、`LOWER_BOUND`（至少达到本档）、`PROVISIONAL`（窗口、角色、分母或归责仍有关键缺口）及 `NOT_APPLICABLE`（不属于本项消费范围）。失载不等于零，也不自动降低严重度。

人物成本在现行正式结算记录中局部修订，保留逐链事实与史源引用；全局恢复视图沿用现行配置。阅读依据必须与当前档位、位置和状态一致，不保留旧裁决作并列答案。程序只校验和确定性换算，不依据旧 F、M、A 标签数量自动重裁。
