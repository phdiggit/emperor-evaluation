# 国防安全：规则与结算合同

本合同评价皇帝接手怎样的安全局面、交班时留下怎样的防御体系与边疆控制，以及其中有多少属于本人贡献。每位皇帝只形成一条当前记录；战争和地区是证据单元，不逐件累加分数。

阅读顺序：先看第一节确定评价范围，再按第二节计算A、第三节计算B；遇到摄政、复出、任期空档或统一战争，查第四节。第五节集中列出证据、输出与校验要求。

## 一、评价什么，按什么顺序裁决

### 1.1 五个轴，各回答一个问题

| 轴 | 核心问题 | 计分方式 |
|---|---|---|
| A1 战略威胁 | 主要威胁的能力和国家战略主动如何变化？ | 接班、交班两个0—5档状态，各轴满分60 |
| A2 防御体系 | 防线、门户、纵深、补给和缓冲能否有效协同？ | 同上；A1+A2合计A120 |
| B1 控制规模 | 本任净增多少边疆空间，交班留下多大规模？ | 接班与交班空间值合成一个0—5档结果 |
| B2 战略价值 | 本人控制成果对战略格局有多重要？ | 一个0—5档结果 |
| B4 交班成熟度 | 本人控制成果能否常态运行和移交？ | 一个0—5档结果；与B1、B2合成B80 |

A轴不另设“任内长期状态”第三锚点，也不维护平行SS/CS状态体系。B1的两个空间快照是计算输入，不是两份得分。各方向材料须先合成皇帝级总体判断，不得分别定档后相加或平均。

普通治安、未达战略门槛的内乱不进入本层。统一战争的客观状态、本人信用及跨项排除分别处理，见4.4。

### 1.2 裁决顺序

1. **确认主体和时段**：核实本人是受益方、受损方还是仅同时在场；事件绑定只提供候选，不能证明收益方向。不明者记入`ambiguous_event_refs`。
2. **确定两个快照**：按接班与离世、退位时的实际状态，分别裁决A1、A2和B1空间；不因前任责任改写接班事实，不读继任者表现。
3. **派生变化并归责**：A终点高于、等于、低于起点分别为`IMPROVED／STABLE／WORSENED`；本人信用另行裁决。B1按固定公式计算。
4. **审查任内损害**：登记重大逆转和未恢复失控；本人制造危机后恢复原状，不等于净建设。
5. **裁决B2、B4**：先确认本人控制成果包及贡献类型，再判战略价值和交班成熟度。
6. **执行终局门与去重**：按1.3及第四节处理，再生成分数。必要输入或归责无法闭合时保留`UNKNOWN`及理由，不补成中档。

### 1.3 亡国终局与宫廷政变

**终局门须同时满足**：本人交班时中央政权已无可实际移交的国防统治能力、政权随即终结，且A1终点、A2终点、B1交班空间均为0。此时B1、B2、B4统一记`0档LOW`。任内阶段性扩张仍保留在战争、成本和能力底账，不再作为已留下的国防成果。

宫廷政变、弑君、废立或近卫兵变，不因君主死亡、退位、宫城失控或政权改名自动降低A轴，也不自动触发终局门。只有本人窗口内已出现以下军事后果，才按实际后果计入：

- 全国或主要区域军事指挥瓦解，大规模内战已经形成；
- 核心国土、重要边疆失守，或主力军队分裂、毁损、失控；
- 外敌取得重大突破，或中央作为国家军事组织已面临现实存续危机。

须写明军事事实与发生时间；达到准入门槛也不等于一律判0。本人离世或退位后才发生的崩溃不得倒灌前任，此前已发生的损害也不得以“宫廷事件”为由豁免。相隔独立军事阶段时分别建状态桥，不强制共享同一快照。

## 二、A轴：先定状态，再计本人贡献

### 2.1 A1：战略威胁状态

| 档位 | 状态边界 |
|---|---|
| 0 | 首都、核心统治区正受国家级军事威胁，或国家军事组织的存续已受现实威胁，整体安全秩序接近崩解；单纯宫城失控、弑君或皇位易手不满足本档。 |
| 1 | 至少一个主要威胁具有制造国家级危机的现实能力，国家被迫长期高强度防御。 |
| 2 | 主要方向明显处于被动，入侵、割据或颠覆威胁反复发生，但尚未形成即时存亡危机。 |
| 3 | 主要威胁与国家相互制衡，攻守均有能力，任何一方均未取得稳定主动。 |
| 4 | 主要威胁总体受控，国家掌握战略主动，但仍有一个明显未决强敌或方向。 |
| 5 | 主要威胁已被结构性压低，国家居整体安全秩序主导；彻底解决一个足以支配全国安全格局的存亡级威胁即可满足，不要求多个方向同时取胜。 |

A1只看威胁能力和整体安全，不看占地规模。反复击退敌军但起终档不变，客观变化仍为`STABLE`；是否取得保全或独立建设信用，另按2.4—2.5判定。

只有交班时仍达到本轴威胁门槛的对象才列为`unresolved_threats`，并反映在终点档位。仅仅尚存的强邻、独立政权或次要争夺，放入`handover_security_context`，不能一面称其为未解决的主要威胁，一面判最高状态。

### 2.2 A2：战略边界状态

| 档位 | 状态边界 |
|---|---|
| 0 | 缺乏有效战略边界，首都或核心区长期直接暴露于主要威胁。 |
| 1 | 主要防线或缓冲体系已经破裂，只能依靠核心区附近的应急防御。 |
| 2 | 若干关隘、城镇、边镇或属部能够防守，但彼此孤立、易被绕过，尚未形成主要方向体系。 |
| 3 | 一个决定性主要方向已经形成可运作的防线、纵深、交通、补给或缓冲协同，整体仍有显著缺口。 |
| 4 | 与国家主要威胁相对应的边界体系总体有效，关键门户和纵深能够协同，仅存一个明显未决缺口或若干次要缺口。 |
| 5 | 与全国安全格局相称的战略边界体系已经成形，核心区具有稳定纵深，国家掌握整体防御主动且无显著结构缺口。 |

A2判断与本国现实主要威胁相对应的体系是否有效、完整。一个决定全国存亡的方向得到根本解决，也可达到高档；小政权不因规模小而封顶，大政权不因疆域广而得高档。占地、建城数量、单场胜利、少战或A1威胁下降，均不能代替直接体系证据。

交班时若仍有主要通道持续争夺、主要防线缺口或`BCN2`以上结构性失控，原则上最高A2-4；偏远控制点退出、次要方向争夺或强邻尚存，本身不构成显著结构缺口。A2-5必须直接证明体系覆盖当时主要威胁方向。

### 2.3 计分公式与归责

```text
轨迹值T = clamp(0, 100, 12×终点档 + 10×可归责档差 + 专项信用 − 负向调整)
每轴分数 = 0.6×T
A120 = A1分数 + A2分数
专项信用 = max(档内建设, 封顶建设, 同档保全)
负向调整 = max(重大逆转扣分, 档内恶化扣分)
```

`clamp`表示把结果限制在0—100之间。公式分开承认交班状态和本人增量：终点每档12点，正向改善每档最多10点。高档不自动证明本人贡献更多或维持更难。

| 本人归责 | 无 | 有限 | 共同 | 主要 | 主导 |
|---|---:|---:|---:|---:|---:|
| 每档正向改善信用 | 0 | 0.25 | 0.5 | 0.75 | 1 |

正向可归责档差为逐档信用之和；负向档差按本人实际责任裁决。前任、摄政、将领独立决策、外生崩解或第一项已消费成果，不得冒充本人信用。归责不改写客观起终档；状态序号之差不是可直接使用的正式分数。

例如，完全本人归责的1→5为100轨迹点；无专项的5→5为60点，4→4为48点。跨档同时改变终点状态锚和本人档差，不能只拿每档10点与档内建设基础点比较。

### 2.4 建设：跨档、档内与封顶

| 路径 | 适用条件 | 信用 |
|---|---|---|
| 跨档改善 | 终点高于起点 | 按2.3逐档归责；不再领取档内建设信用 |
| 档内建设 | A1或A2起终同为1—4档 | 显著10／重大20 × 本人归责 |
| 封顶建设 | 终点5档，包括跨档升至5档 | 同样为显著10／重大20 × 本人归责；仅计未被跨档消费的独立增量 |

| 建设等级 | 必须证明的结构变化 | 档内／封顶枚举 |
|---|---|---|
| 显著，基础10 | 一个主要方向的威胁能力或防御结构发生可移交的实质改善 | `SIGNIFICANT／DEEPENED` |
| 重大，基础20 | 系统级联合军事威胁被拆除，或关键防御网络完成结构性重建 | `DECISIVE／CEILING_ADVANCED` |

同等成果、同等归责采用同一尺度；5档、广阔疆域或新战略空间不另加倍率。本人归责仍取0.25／0.5／0.75／1；无独立增量记`NONE=0`。终点5档必须检查封顶路径，不能只筛5→5。

建设准入须同时闭合：

- **结构**：A1证明主要威胁再战或支配能力下降；A2证明防线、门户、纵深、补给由缺口转为有效协同。更多战果、据点、领土、一般修缮或一次敌退不能代证。
- **本人贡献**：写明接班结构、交班变化、本人行动、归责系数、等级理由、准入父链和可定位来源；名义在位、接受既成战果或继承存量不足以准入。
- **净增与去重**：不以本人造成危机后的低谷作起点；同一后果不跨轴、跨项重复。5档只走封顶建设，不另领档内建设；各方向综合裁决一次，不按链数累计。

整体未跨档，不妨碍独立结构增量获分；增加建设信用也不撤销其他方向的负向责任。多次主政须先按4.2闭合逐窗归责，不能直接套同档公式。

### 2.5 保全：现实压力下有效守住

| 同档交付 | 无信用 | 经受检验`TESTED` | 严重`SEVERE` | 历史级`HISTORIC` |
|---|---:|---:|---:|---:|
| 1→1、2→2、3→3：低位抗压 | 0 | 3 | 6 | 10 |
| 4→4、5→5：高位守成 | 0 | 10 | 15 | 25 |

保全须同时具备：非本人制造的现实外部战略压力；具名受控威胁、防线、门户或军事组织；本人可识别的决策、部署或供给且至少主要归责0.75；交班仍持续有效；成果未被其他轴或项目消费。少战、敌方自行撤退、没有亡国或继承高位均不自动加分。0→0及跨档变化不走保全。

压力按[公共O档合同](../../../证据规则/军事对手战争机器O档合同.md)读取本窗口实际投入，不套敌国巅峰：

| 保全等级 | 低位压力门槛 | 高位压力门槛 |
|---|---|---|
| 经受检验 | 至少O4 | 明确战略压力检验 |
| 严重 | 至少O5或持续O4等效压力 | 显著强度、持续性或多方向风险 |
| 历史级 | O6或持续多方向O5等效压力 | O5/O6现实压力，或可证明的长期近似压力，并有罕见完整交付 |

等效压力须证明组织、投送、再动员及受压对象的连续性，不按事件数相加。O档只给审查资格，不自动决定奖励；保全不完整或本人贡献不足须降级或归零。

高位较高奖励承认重要体系的实际保全，不表示高位天然更难。低位保全最高10点，不超过下一档无专项基线；这一限制不适用于已证明的结构建设。同一防守链不得在A1、A2重复获奖，也不得靠降低奖励等级规避去重；建设与保全始终取高。

### 2.6 退步、主类型与显示

| 负向项目 | 扣分档 |
|---|---|
| 重大逆转 | `NONE=0／MATERIAL=10／SEVERE=20` |
| 档内实质恶化 | 0／5／10 |

两者取高。终点降档已完整表达的同一损害不再扣；交班降档、政权终结或重大失控未恢复时，不能用该阶段较早的守住事实领取保全。

每轴主类型按以下顺序确定，主类型只解释路径，不隐藏伴随加减：

1. 客观跨档，先判改善或恶化。
2. 同档，取实际最高正向专项；平分依次为封顶建设、档内建设、保全。
3. 无正向专项，依次为重大逆转、档内恶化、平稳交付；保全及平稳交付仍区分高低位。

同档1—5档逐轴写明“已计信用／其他路径消费／无净结构改善／本人归责未成立／证据不足”及事实理由。零专项不能留空代替审查；证据不足仅表示当前不授分，不等于历史上没有建设。

轨迹显示档：90—100历史顶级、75—不足90优秀、60—不足75良好、45—不足60一般、30—不足45较差、0—不足30极差。显示档不反向决定裁决。全池量程审计要求各轴有达到95%的结果；不足须复查尺度与证据，不得指定人物凑满分。

## 三、B轴：控制规模、价值与成熟度

### 3.1 B1：先建空间快照，再按公式落档

```text
受控空间当量 = 跨朝固定空间权重 × 实际覆盖比例
原始净变化 = 交班空间 − 接班空间
B1加权控制值 = 0.6×原始净变化 + 0.4×交班空间
             = 交班空间 − 0.6×接班空间
```

| 档位 | 状态边界 |
|---|---|
| `B1-0` | 加权控制值小于或等于0；发生足以抵消交班绝对规模修正的严重净退控。 |
| `B1-1` | 加权控制值大于0但不足0.75，只有小规模守成、轻微增益，或较大交班存量被明显退控抵消。 |
| `B1-2` | 加权控制值达到0.75但不足1.5，形成中等规模守成或有限净增。 |
| `B1-3` | 加权控制值达到1.5但不足3.0，形成较大规模守成、显著净增，或二者兼有。 |
| `B1-4` | 加权控制值达到3.0但不足6.0，形成大规模净扩张并留下广域控制。 |
| `B1-5` | 加权控制值达到6.0以上，在跨朝共同尺度上形成历史顶级的超大扩张与交班控制组合。 |

B1同时承认本人净变化及交班绝对规模。继承区域必须进入接班值：其中60%在公式中扣除，剩余40%承认交班维持规模的难度，不冒充净扩张。统一对象及稳定核心领土在两个快照中均不计入边疆区域表。B1之外不得再加“净变化加档”或“归责降档”；B1-5须证明加权值至少6.0，仅凭高位守成不能达到最高档。

空间当量是归一化单位，不宣称精确古代平方公里。区域权重、ID、重叠排除与旧ID映射只读[B1统一空间锚点表](01-B1统一空间锚点表.md)及`config/third-item/third-item-b1-region-anchors.json`。部分控制只改覆盖比例，不改区域权重；新增空间须先扩充规范附件并横向校准，不能逐人临时造锚或按现代国土面积换算。

**是否计入控制**：

| 可以计入 | 不足以计入 |
|---|---|
| 直接郡县、都护府或常设军政体系 | 普通友好、一次称臣入贡 |
| 锚点时仍有可执行册立、征调、驻援、问罪或官爵任免关系的属国、藩国、羁縻政权 | 仅受册封却不能约束、短期占领、锚点前已失效的安排 |

灭亡当地政权只证明旧主权消失，仍须证明本国统治或实质宗主权已接替。控制形式只决定是否达到实际受控门槛，不另打折；锚点时有效但脆弱的控制按真实范围计B1，稳固性由B4评价。击破、掳掠、迫贡或旧政权仍存，不能自动取得全覆盖。

**覆盖比例与缺证处理**：

| 可限定的实际范围 | 保守阶梯 |
|---|---:|
| 孤立据点或明确小支点 | 至多0.25 |
| 约半个主要走廊或网络 | 0.50 |
| 大部有效，仍有明显缺口 | 0.75 |
| 整体有效 | 1.00 |

没有精确面积不等于`UNKNOWN`。能限定范围即作有界推断，犹疑取低值；`reason`须注明“有界推断”、事实范围、所取阶梯、为何不取更高值并挂证据。相邻同政权已审交班快照可复用，任内无足以改变覆盖阶梯的事实可维持原值。不得从胜负档、事件数、威胁下降或后继表现反推比例。

本地材料仍不能限定对象或锚点时，须先联网查正史、实录、《资治通鉴》、政书及权威历史地理资料；普通网页只作定位线索，尽量回到可定位史源。将范围、存续与制度关系写入证据和理由。冲突列明并取低值；只有检索失败且不能形成合理区间时才暂记`UNKNOWN`，登记已查线索与失败原因。

每人须逐区域列控制方式、当量、证据及排除项，大区名不能替代具体对象。区域内部得失先净额裁决，不累计单次事件档。

### 3.2 B2、B4先过本人贡献门

对两轴使用的同一控制成果包确定一种贡献类型，再分别定档：

| 归责类型 | 必要边界 | B2/B4最高档 |
|---|---|---:|
| `NEW_RECOVERED_REBUILT` | 本人新建、收复或完成足以改变控制结构的重建 | 5 |
| `SAVED_UNDER_MAJOR_PRESSURE` | 继承控制已面临现实主要失控风险，本人通过可识别行动将其保全或恢复稳定 | 4 |
| `ROUTINE_MAINTENANCE` | 本人有实际维护行为，但未经历主要失控风险，也未形成结构性增量 | 2 |
| `INHERITED_ONLY` | 只有继承存量，缺少本人可识别的控制成果 | 0 |

上限只约束本人贡献，不改国家事实，也不保证取得该档。小规模新建仍按实际价值低判；不能用次要新建节点给全部继承存量解锁高上限。两轴只消费真正满足该类型的成果包。

摄政、前任、边将、地方行动者或外部崩解形成的控制，按实际任期边界进入B1；名义在位、事后接收不能自动变成本人B2、B4。仅能证明本人继续供给、任命接替者或维持既成体系时，最多常规维护；本人以可识别改策、任命、部署或制度收束保全现实主要失控风险，才可认定重大压力下保全。

无计分成果及创业整链排除均归`INHERITED_ONLY`，原因另由路由字段说明。证据账形式和路由状态不是贡献类型。混合成果只将实际支撑本人得分的包列入`primary_control_package_refs`；两轴任一非0，此列表必须非空。被排除的他人成果仍可留在B1、A客观端点与原始证据中。

### 3.3 B2：控制成果的战略价值

| 档位 | 必要边界 |
|---|---|
| `B2-0` | 无实际控制成果，或成果缺乏可识别战略价值。 |
| `B2-1` | 价值有限、易替代，只改善单点态势。 |
| `B2-2` | 对局部交通、防御、资源或贸易具有明确作用。 |
| `B2-3` | 对一个主要区域的门户、走廊、缓冲、补给或强敌压制具有重要作用。 |
| `B2-4` | 对一个主要战略方向具有关键作用，显著改变攻防条件。 |
| `B2-5` | 对国家存续、核心区安全或整体战略格局具有决定性价值。 |

按本人新建、收复、结构重建或现实失控压力下保全的成果组合之最高价值及兑现程度综合定档，不按点数累计；一个决定性节点即可达到最高档。继承控制正常存在已由B1处理，只有本人可识别维护、稳固或保全才开启B2。

### 3.4 B4：全部主要成果的交班成熟度

| 档位 | 必要边界 |
|---|---|
| `B4-0` | 主要控制成果在交班前已经丧失，或始终只有名义控制。 |
| `B4-1` | 主要成果仍处战时占领、围困或随时可能失控状态。 |
| `B4-2` | 主要成果取得不久且结构未完备，仍明显依赖临时重兵、个人威望或异常资源投入；“新近”本身不构成本档。 |
| `B4-3` | 已有常态运行成果，但全部主要控制净成果中仍有脆弱包，或本人任内另一主要方向发生未恢复的结构性退控，交班时仍有显著缺口或较高维持压力。 |
| `B4-4` | 本人全部主要控制净成果在交班时已完成制度、驻防、指挥、补给或地方安排等必要闭合，能够转入常态运行；本人任内没有尚未恢复的主要方向结构性退控，只允许次要或非决定性缺口。 |
| `B4-5` | 本人全部主要控制净成果均已完成制度、驻防、指挥、补给和地方安排等必要闭合，可以正常移交，不依赖异常资源或个人临时维持，且不存在显著结构缺口。 |

B4每人只判一次，以B2的可归责成果为正向主干，同时检查**全部主要控制净成果**及`major_in_reign_reversal_refs`：

- 本人造成或放大的另一主要方向结构性退控，交班前未恢复时，B4最高3档。不得挑最成熟一包，也不得以损害“不属于该成果包”排除。
- 短期战败、外生压力或无关控制成果的A1威胁，不自动触发此上限。
- 只读本人任内至离世、退位；继任者很快失地不能反推前任不成熟。
- 取得时间、存续年限及任内压力检验只影响证据置信度，不设机械年限上限。新近成果只要在交班前完成必要结构闭合，也可达4或5档。
- 纯战略削弱而无实际控制取得或保全，不能以A贡献补B4。归责不足以判断时记`UNKNOWN`；已确认纯继承、无本人控制成果时记`INHERITED_ONLY`、0档。

### 3.5 档内位置与B80合成

| 单锚档 | LOW | MID | HIGH |
|---|---:|---:|---:|
| 0 | 0 | 15 | 29 |
| 1 | 30 | 37 | 44 |
| 2 | 45 | 52 | 59 |
| 3 | 60 | 67 | 74 |
| 4 | 75 | 82 | 89 |
| 5 | 90 | 95 | 100 |

`LOW`为刚满足且有明显限制，`MID`为典型满足，`HIGH`为充分满足且接近下一档、但仍缺下一档硬边界；最高档完整满足时取`HIGH=100`。只用这三级位置，不自由填写另一归一值。

```text
B80 = 80×(0.55×B1率 + 0.45×B2率)×(0.70 + 0.30×B4率)
```

公式中的率按0—1使用。JSON内B1、B2、B4的`axis_points`仍按0—100得分率的25%、30%、25%保存，供逐轴审计与材料阅读；当前总榜只读取上述非线性B80，不将三列相加，也不允许人工另填B总分。

## 四、任期边界、证据合并与跨项去重

### 4.1 连续交班和空档期

同政权直接连续交接，且无摄政重叠、政权重建或事实断裂时，前任终点与后任起点是同一客观事实：A1、A2档位及B1空间快照必须相等。B1净增量档和分数不得复制给后任。双方已裁决而不相等即校验失败；变化只能归后任窗口，或以事实证明交接中存在独立变化并建状态桥。

没有直接战争事件不等于0，可用共享交班事实、任内非战争安全事实及前后已闭合状态证明端点。并行摄政、实际权力重叠、跨政权易代或时间空档禁止自动复用，须另裁决。

名册有空档时必须审查桥接：无跨档、跨值事实则保持前一已闭合状态，不能因中间统治者未入名册而凭空升降；有变化须挂事实引用，材料不足记`UNKNOWN`。桥至少保存：左右人物、空档范围、A1/A2桥、B1控制快照、状态、变化引用及理由。

### 4.2 多次主政与重叠主体

同一人有不连续实际主政窗口，须保存`active_rule_windows`及逐窗A状态、B1快照：

| 项目 | 读取方式 |
|---|---|
| A客观终点基础 | 最后一次实际交班状态 |
| A本人变化信用 | 只累计各本人窗口内的正负变化 |
| B1本人净变化 | 各窗口“终点－起点”之和 |
| B1交班规模 | 最后一次交班快照，仍按60%净变化＋40%交班空间合成 |
| B2、B4 | 只读本人窗口中新建、恢复或重大压力下保全的成果 |

间隔期他人形成的变化只作下一窗口继承存量，不得从最早起点与最晚终点相减后全归本人；最终仍存在的间隔期成果可进B1交班存量，不能自动开启本人B2、B4。

名义君主、摄政、退位后掌权者或复出者分别建档时，必须执行`overlapping_subject_window_review`。同父链可切时间阶段，但同阶段A本人信用、B1净增、B2及B4贡献只能归一个实际主政主体；客观国家状态可在交接锚重复。D或公共父链已有更细切片时，AB须复用，不能将完整终局重复归给多人。

### 4.3 父链、阶段与重大逆转

同威胁主体的连续战争合为威胁链；同地区的取得、维持、复失合为控制包。主要程度按威胁、规模与价值判，不按方向、标题或事件数量判。

B项须先应用与C、D相同的父级战争收束：同战略目标、连续动员和结果闭合只留一个规范父周期。成员战役卡可作内部证据，不能重复支持B1/B2/B4；事件数、控制变化、控制包及重大逆转引用均从收束后周期生成。

父链的唯一`machine_settlement`所有者只防事件成本收益重计，不吞任期边界事实。跨任期父链在前任已发生的入侵、失地、道路中断、体系建设或威胁存量须另列`boundary_stage_refs`并进入其终点；主体不同、即位前或退位后的候选列`boundary_stage_excluded_refs`并说明。已裁决者须闭合`boundary_stage_review_status=REVIEWED`。

`major_in_reign_reversal_refs`只收显著改变任内安全、边界或控制状态的真实逆转，不收普通战败、短期波动。起终同档不豁免任内重大损害。

### 4.4 统一战争：状态照读，重复贡献排除

统一和创业兼并不得将胜方战役数量、歼敌、攻城及统一核心控制量经任期端点再次累计。B1只计统一核心之外的边疆空间，不把统一对象改名为额外控制包。

A1、A2始终读取可独立评价政权形成后的客观安全轨迹：

- 创业者交班时实际存在的主导秩序、纵深与边疆体系，不因第一项已有创业分而整轴清零。
- 起点取政权形成时的真实非统一安全状态，不能因草创、流动军团或统一核心尚未成形便定0档；终点只读当时仍存在的状态，不累计统一战役节点。
- 同一战争在败方任内实际终结其政权，败方仍按1.3读终局。胜方不重复得分，不等于败方不读亡国后果。

**收益—成本对称排除**：第一项已整链消费、第三项D亦连反转与成本一并排除的父链，不得继续生成第三项A本人正向信用或B1/B2/B4控制收益；A客观端点及非成本状态锚仍保留。确有独立边防收益时，须先拆出边界、授权、结果可独立闭合的第三项父链，并同步接入成本，才可恢复相应信用；不得只拆收益而继续排除成本。

### 4.5 与其他底账的分工

| 底账或项目 | 负责内容 |
|---|---|
| 01战役 | 战争边界、难度、胜负与指挥事实；本层不重评人才等级 |
| 02国防安全事件账 | SB/SN/BCP/BCN事实；不能直接推人物分数 |
| 03财政民生 | 人员、生产、动员、军资及财政民生损害 |
| 第三项C | 军事体系运行表现 |
| 第三项D | 全部军事成本收益，包括取得、维持边疆控制的成本 |
| 第四项A | 政治认同、人口融入、精英参与与共同体；控制本身不能转为文明整合 |

BCP/BCN是父战役在“主体—任期阶段”中的实际控制变化，分别记正向取得、恢复、保持及负向丧失、撤离、被夺回；均为0—5绝对档，同一变化按父周期终局净结果计一次。它们不能相加为B轴或替代空间快照；具体档位、缺证与字段见[战争成本安全收益与战争回报档位](../../../证据规则/战争成本安全收益与战争回报档位.md)。

同战争的不同、不可替代后果可依总则2.6分别进入对应构念，但须各自证明；同一后果不得改换表述重复计分，B控制成果不能直接搬成A建设信用。

## 五、正式输出与校验

### 5.1 阅读视图应能独立说明裁决

共同战争、时间线与总体格局在`A_axis_common_context`写一次。A1专属理由须回答主要威胁、压力变化及档位；A2专属理由须回答具体防线、门户、纵深、补给或缓冲、遗留缺口及档位。两轴理由均非空且不能完全相同；作用域分别为`STRATEGIC_THREAT_CONTROL_STATE`和`STRATEGIC_BOUNDARY_SECURITY_SYSTEM`。

仅写“消费现行语义标签”“按人物窗口裁决”，或在同一段后追加两轴名称，不构成事实依据。已有明确逐档裁决可由其来源闭合，不因冗余摘要重复判缺；文本相似度只作筛查，不作硬阈值。未就绪者不能因旧分非空恢复入榜，也不能机械扩写占位文字通过校验。

[A轴叙事裁决](../../../../config/third-item/third-item-a-axis-narrative-adjudications.json)保存共同背景及专属理由，同步器只按人物ID并入正式快照，不从档位或B1空间账自动生成历史结论。

阅读视图须显示：A起终档、本人改善、实际专项、负向扣分和轴分；B的规模、战略价值、成熟度及归责。主类型不能遮蔽伴随扣分。

### 5.2 最小记录，按用途分组

每人只保留一条当前记录。下表按语义列字段，层级以当前正式JSON为准。

| 内容 | 必须保存的字段 |
|---|---|
| 身份与就绪 | `ruler_id`、`reign_range`、`subject_binding_review_status`、`ambiguous_event_refs`、`coverage_status`、`score_ready` |
| A1、A2各自状态 | 各轴`start`、`end`、`transition`、`transition_attribution`、`base_trajectory_value`、`trajectory_value`、`axis_points` |
| A信用与解释 | 各轴`ceiling_progress`、`ceiling_bonus`及当前A120归责、专项和扣分裁决；同档零专项也须有事实理由 |
| B结果 | B1/B2/B4各自`grade`、`score_rate`、`axis_points`，以及A120、B80和AB合成结果；保留`AB_score_points`审计字段 |
| B1空间 | `b1_region_control`（接班、交班的区域→当量）、`b1_control_equivalents`（start/end/net_change/weighted_value）、`b1_region_adjudications`（对象、权重、覆盖、方式、快照、证据、排除） |
| 本人贡献与终局 | `control_contribution_type`、`control_contribution_grade_cap`、`terminal_polity_collapse`、`primary_threat_refs`、`primary_control_package_refs`、`major_in_reign_reversal_refs` |
| 证据与阶段 | `evidence_event_refs`、`parent_cycle_refs`、`defense_event_count`、`parent_cycle_merge_adjudications`、`boundary_stage_refs`、`boundary_stage_excluded_refs`、`boundary_stage_review_status` |

多窗口或空档另保留第四节要求。空档桥字段为`left_ruler、right_ruler、gap_range、A1_bridge、A2_bridge、B1_control_snapshot、bridge_status、change_refs、rationale`；A的`NO_CROSS_GRADE_CHANGE`要求左右档相等，B1的`NO_CROSS_VALUE_CHANGE`要求快照值相等。

同档1—5档无保全记`maintenance_difficulty=NONE`；跨档及0→0记`NOT_APPLICABLE`。B1只保存空间变化，不另存状态转变归责。

### 5.3 硬校验与保存边界

- B1档位必须与固定加权公式一致；B2、B4不得超过贡献类型上限。`control_contribution_grade_cap`只能从四种类型派生，不能为空或取自B1档。
- `REAL_REGION_LEDGER`、`NO_SCORING_CONTROL_RESULT`、`FOUNDING_CONTROL_EXCLUDED_NO_SEPARATE_RESULT`等证据形式或路由状态不得充当贡献类型。只有父周期列表、模板理由或客观国家状态，不能支持非0的B2/B4。
- 原始WAR卡和阶段证据放`evidence_event_refs`，规范周期放`parent_cycle_refs`；`defense_event_count`只等于后者唯一周期数。原始卡数量不作B项样本厚度，`parent_cycle_merge_adjudications`须与同主体C项一致。
- 直接交班、空档桥、多窗口、主体重叠、统一链排除和A轴事实理由均须通过对应校验；明确占位理由须在第三项重建或综合榜写入前阻断。
- 五个原子轴均须允许事实直接到达0—5档；个别对象的贡献上限、证据门槛或样本厚度不能变成全局永久封顶。生成器测试须分别覆盖五轴六档输入输出，不能以合计分或某个人已到5档替代。
- 低事件暴露不自动压低A客观状态，也不证明救危、重建或成熟控制。没有主要压力及结构增量时，本人维护最多按`ROUTINE_MAINTENANCE`处理。

正式仓库仅维护当前JSON入口与同值Markdown，历史由Git追溯；数据库写入关闭。历史档位与归责须逐人逐轴据事实裁决，生成器只做确定性同步、计算与硬约束校验。
