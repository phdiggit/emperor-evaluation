# B1统一空间锚点表

> [机器锚点](../../../../config/third-item/third-item-b1-region-anchors.json)与本附件定义空间、重叠、覆盖、继承及就绪门；公式与其余轴见[主合同](00-规则与结算合同.md)。人物不得另造权重。

## 一、用途

统一用区域权重×覆盖率建立接班、交班快照，不混用新增量与继承存量。

空间权重只用于B1，不代替A1/A2、B2或B4。

## 二、唯一计算口径

```text
区域控制当量 = spatial_weight × coverage_factor
start_total = Σ 接班时所有合格边疆区域控制当量
end_total   = Σ 交班时所有合格边疆区域控制当量
weighted_control_value = end_total − 0.6 × start_total
```

覆盖率只允许：

| 覆盖率 | 含义 |
|---:|---|
| 0 | 无可执行实际控制 |
| 0.25 | 孤立支点或小型控制网络 |
| 0.50 | 约半个主要走廊/网络 |
| 0.75 | 大部有效但仍有明显缺口 |
| 1.00 | 标准区域整体有效 |

B1档位继续沿用既有边界：`≤0`为0档；`(0,0.75)`为1档；`[0.75,1.5)`为2档；`[1.5,3)`为3档；`[3,6)`为4档；`≥6`为5档。

## 四、重叠与复合锚

1. 北方草原整体锚与其覆盖的漠北、漠南、匈奴属部不得重复；漠北与漠南只有在事实空间清楚分离时才能并计。
2. 使用西域整体`2.0`时，不再加龟兹、高昌、哈密内部节点。
3. 使用北中国复合控制带`1.8`时，不再加其覆盖范围内的山东河北或燕云。
4. 使用辽东—松外东北复合锚`1.0`时，不再加辽东`0.5`和松外`0.5`。
5. 青藏高原整体锚覆盖同一青海空间时，不再叠加吐谷浑—青海锚。
6. 河西陇右、河西宁夏鄂尔多斯、关中陇右存在交叠；必须按实际边界拆分或选择一个不重复口径。
7. 岭南与交趾—安南发生同空间重叠时不得双计。
8. 朝鲜半岛整体网络与汉郡小锚不得对同一时期同一空间重复。

机器配置中的`mutual_exclusion_sets`为正式约束。

## 五、核心排除与跨项去重

- 稳定核心不入B1，目录有锚不自动属于边疆。
- 第一项已消费统一新增不再计B1；闭合后的边疆可作第三项start存量。
- 拆独立边防收益须同时闭合边界、归责、结果与成本。
- 本土海岸/卫所不因倭患海战入B1，仅离岸、边疆或对外控制准入。

## 六、连续交接硬约束

连续皇帝交接时：

```text
前任逐区域end = 后任逐区域start
前任end_total = 后任start_total
```

存在摄政重叠、空档期或政权重建时必须另建状态桥。不得因后一任材料较少，就把继承边疆存量清零。

## 七、旧数据迁移门

`legacy_must_rebuild`列出的聚合包和临时空间对象不能继续使用；`legacy_aliases`可无歧义对应的按别名转换，其余重建，不保留临时权重。明朝东南本土沿海旧对象退出B1，确有台湾、澎湖等离岸/边疆控制时改用标准锚。

旧`MESOPOTAMIA_CAUCASUS_NETWORK`统一对应`MESOPOTAMIA_AZERBAIJAN_SOUTH_CAUCASUS`。旧ID清单及映射以[机器锚点](../../../../config/third-item/third-item-b1-region-anchors.json)为准。

## 八、score_ready门禁

B1重新标记`score_ready=true`前必须同时满足：

1. 每个计入区域都引用本表`region_id`；
2. `start_total/end_total`等于逐区域当量之和；
3. 每个当量等于`spatial_weight × coverage_factor`；
4. 连续交班快照闭合或有状态桥；
5. 有实际B1候选区域时，`b1_region_adjudications`不得为空；
6. `formal_B1_rate`只能由区域账机械生成，不允许独立override；
7. 任何`legacy_must_rebuild`对象尚未迁移时，B1不得就绪。

## 九、扩充与校准

新增空间先扩充统一目录并横向校准，再结算人物；不能在人物JSON中临时造锚。全部现行锚已列第三节，具体采用与覆盖率保存在正式区域账。
