# B1统一空间锚点表

> 本文件是第三项“国防安全”B1边疆加权控制值的规范附件。机器唯一锚点入口为
> `config/third-item/third-item-b1-region-anchors.json`。
>
> **规范优先级**：仅对B1空间锚、重叠排除、继承快照和`score_ready`门禁，若与`00-规则与结算合同.md`第六节旧的临时区域表或既有人物数据冲突，以本附件及机器配置为准；B1公式、档位边界及A1/A2、B2、B4规则仍以00合同为准。
>
> 本轮只建立统一空间标尺与重审门禁，不直接改写既有201人B1分数。现有B1在全量重审完成前视为待复核数据。

## 一、为什么重建

现有B1底账已经确认存在多种互不兼容口径：有的完整登记继承边疆存量，有的只登记本人新取得区域；有的按固定区域权重乘覆盖率，有的直接把`0.25/0.50/0.75/1.00`当绝对控制当量；还有人物的逐区域账与正式`formal_B1_rate`互相冲突。

因此B1必须先统一空间单位，再逐人重建起终快照。A1/A2、B2、B4不因本文件自动失效。

## 二、唯一计算口径

```text
区域控制当量 = spatial_weight × coverage_factor
start_total = Σ 接班时所有合格边疆区域控制当量
end_total   = Σ 交班时所有合格边疆区域控制当量
weighted_control_value = end_total − 0.6 × start_total
```

覆盖率只允许：

| 覆盖率 | 含义 |
|---:|---|
| 0 | 无可执行实际控制 |
| 0.25 | 孤立支点或小型控制网络 |
| 0.50 | 约半个主要走廊/网络 |
| 0.75 | 大部有效但仍有明显缺口 |
| 1.00 | 标准区域整体有效 |

B1档位继续沿用既有边界：`≤0`为0档；`(0,0.75)`为1档；`[0.75,1.5)`为2档；`[1.5,3)`为3档；`[3,6)`为4档；`≥6`为5档。

## 四、重叠与复合锚

1. 北方草原整体锚与其覆盖的漠北、漠南、匈奴属部不得重复；漠北与漠南只有在事实空间清楚分离时才能并计。
2. 使用西域整体`2.0`时，不再加龟兹、高昌、哈密内部节点。
3. 使用北中国复合控制带`1.8`时，不再加其覆盖范围内的山东河北或燕云。
4. 使用辽东—松外东北复合锚`1.0`时，不再加辽东`0.5`和松外`0.5`。
5. 青藏高原整体锚覆盖同一青海空间时，不再叠加吐谷浑—青海锚。
6. 河西陇右、河西宁夏鄂尔多斯、关中陇右存在交叠；必须按实际边界拆分或选择一个不重复口径。
7. 岭南与交趾—安南发生同空间重叠时不得双计。
8. 朝鲜半岛整体网络与汉郡小锚不得对同一时期同一空间重复。

机器配置中的`mutual_exclusion_sets`为正式约束。

## 五、核心排除与跨项去重

- 稳定核心领土不进入B1。一个锚点存在，不代表任何政权都能把该区域计为边疆。
- 第一项已经消费的统一核心新增，不进入第三项B1净增。
- 但第一项闭合后实际存在的边疆控制可以成为第三项`start`存量；不能因为“不是本人新取得”就从接班快照删除。
- 同一历史过程若要从第一项拆出独立边防收益，必须同时闭合独立边界、本人归责、结果和相应成本，保持收益—成本对称。
- 普通本土海岸、沿海卫所和国内海防节点不因发生倭患或海战自动成为B1控制空间；离岸、边疆或对外实际控制空间才进入B1。

## 六、连续交接硬约束

连续皇帝交接时：

```text
前任逐区域end = 后任逐区域start
前任end_total = 后任start_total
```

存在摄政重叠、空档期或政权重建时必须另建状态桥。不得因后一任材料较少，就把继承边疆存量清零。

## 七、旧数据迁移门

以下旧对象不能直接沿用，必须重建：

- `AGGREGATE_REVIEWED`
- `NORTH_SONG_REIGN_CONTROL_PACKAGE`
- `TANG_NORTHERN_REMAINDER`
- `MING_NORTHERN_MAIN_FRONTIER`
- `MING_NORTHEAST_LIAODONG`
- `MING_SOUTHWEST_FRONTIER`
- `MING_SOUTHEAST_COAST`

其中明朝东南沿海旧对象原则上退出B1；若存在台湾、澎湖或其他离岸/边疆实际控制，则改用对应标准锚重新结算。

已有旧ID若能无歧义映射，统一按机器配置`legacy_aliases`迁移；不能无歧义映射的一律重建，不允许保留人物级临时权重。

## 八、score_ready门禁

B1重新标记`score_ready=true`前必须同时满足：

1. 每个计入区域都引用本表`region_id`；
2. `start_total/end_total`等于逐区域当量之和；
3. 每个当量等于`spatial_weight × coverage_factor`；
4. 连续交班快照闭合或有状态桥；
5. 有实际B1候选区域时，`b1_region_adjudications`不得为空；
6. `formal_B1_rate`只能由区域账机械生成，不允许独立override；
7. 任何`legacy_must_rebuild`对象尚未迁移时，B1不得就绪。

## 九、本轮新增校准锚

本轮只新增四个此前缺失、但全时代重审必需的锚：

- 青藏高原主要控制体系`1.5`：以西域整体`2.0`为上锚、吐谷浑—青海`1.0`为下锚；
- 辽东—松外东北复合带`1.0`：由两个`0.5`既有锚机械合成；
- 交趾—安南北部`0.8`：与岭南完整控制同量级，但只用于超出稳定华南核心的对外控制；
- 哈密—伊州门户`0.2`：与高昌—西州小型门户同级。

后续若遇到本表仍无法覆盖的历史空间，必须先扩充本表并横校，再结算人物，禁止在人物JSON内临时造锚。
