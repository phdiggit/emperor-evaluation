# 第三项D军事成本收益比规则与结算合同

本项以40分评价皇帝完整统治期内的军事投资是否值得。先按独立战略行动周期配对己方军事成本、战役结果与安全控制收益，再合并为皇帝军事投资组合；不按战斗次数平均，也不把档位序号相加。

共享计分材料从[`《资治通鉴》战争计分材料审计索引`](../../../共享史料/唐以前编年/00-战争卡审计索引.md)按`WAR-*`键回源；机器计分唯一读取入口为[`D秦至唐皇帝正式结算.json`](../../../评分结算/第三项军事与边疆净收益/军事成本收益比/01-皇帝D项正式结算.json)。

## 1. 事件范围

- `D_STANDARD`：对外战争、战略级内战，以及已经并入战争父卡完整行动周期的实际边防与驻军投入。独立`DEF-*`工程卡当前只服务国防状态与控制轴；未完成全体皇帝主体绑定和周期去重前，不得选择性混入D项。
- `D_INTERNAL_COST_ONLY`：未达到国防安全门槛、但实际消耗国家军事资源的地方镇压或兵变处置。
- 创业统一、兼并战争固定排除；宫禁政变、个人刺杀和未形成国家军事行动的政治暴力固定排除。
- 同一战略目标、连续动员与结果闭合链只结算一次；重新决策、重新动员、目标转换或前一周期已闭合时才拆分。

统一战争只服从战役底账的最终逐卡路由，不得按标题或整个战争群重新推断。跨皇帝周期只结算本人任内决策、投入和阶段结果。

## 2. 成本和收益

成本端分为两层：直接军事成本消费己方军事人员损耗P、军事动员M和军资资产A；战争外部成本消费能够归责于本人战争决策的S、平民P、民役和财政透支后果。敌方人员损失不是己方成本。

S的实际民生财政结果仍由第二项C完整结算；D读取同一事实只回答“军事收益是否值得付出该代价”。主动战争、本人诱发内乱的S从严；外来或继承性威胁造成的S先做责任切分，必要防御不得机械全责。WC只作为P/S/M/A综合严重度和复核门禁，不能与SB、BC或WR做序数加减，也不能在D内与四轴重复累计。

收益端消费战役实际结果、已经实现的WR、战略安全SB/SN和边疆控制BCP/BCN。杀敌、缴获、名义臣服或后任取得的成果，未转化为本周期实际结果时不得计入。

`BCP/BCN`仅记录父战役在“评价主体—任期阶段”视图内的实际净控制变化：`BCP`为取得、恢复或保持的边疆控制增益，`BCN`为丧失、撤离或被敌方夺回的边疆控制减益。二者均为`0—5`绝对档，具体边界、`UNKNOWN`条件和去重方式以[`战争成本安全收益与战争回报档位`](../../../证据规则/战争成本安全收益与战争回报档位.md)为准。战斗胜负、杀敌、缴获或名义关系不自动产生非零BCP/BCN；同一控制变化不得在父子卡、正负档或跨皇帝阶段重复消费。

事件分为`HIGH_RETURN、PROPORTIONATE、LOW_RETURN、NEGATIVE_RETURN、UNKNOWN`。同一事件涉及多个政权或跨越统治转换时，必须建立“事件—评价主体—任期阶段”视图；事件公共行只作事实汇总，不能直接代替各主体的P/M/A、SB/SN、BCP/BCN和回报方向。人工覆盖必须同步给出主体成本、收益档和理由，不得只改`return_class`，更不得把收益未知的事件强制改成高收益。禁止把攻方成本配给守方，也禁止把继任者阶段结果倒灌前任。防御战争的必要成本从宽，但可避免的后勤崩溃、重复失败和本人政策诱发的内乱不得转化为正收益。

## 3. 皇帝组合档

| 档位 | 组合边界 | 40分区间 |
|---|---|---:|
| D-U | 无实质军事投资周期，成本收益能力未受检验；仅给中性占位，不解释为能力档。 | 20.0 |
| D0 | 军事投资是全国性崩溃或覆亡的主导原因，国家级反复透支且几乎无补偿收益。亡国不自动归零。 | 0.0—7.9 |
| D1 | 高成本低收益或负收益长期占主导，反复大军覆没、无功重征或安全控制倒退。 | 8.0—15.9 |
| D2 | 总体明显失衡，存在国家级负收益周期或多项持续低收益，但仍有可确认成果。 | 16.0—21.9 |
| D3 | 成本收益混合且大体可解释，有明显浪费、保持不足或一次较重负收益。 | 22.0—29.9 |
| D4 | 主要投入取得相称或较高回报，成果能够保持，无反复国家级浪费和战略透支。 | 30.0—35.9 |
| D5 | 经真实高难度压力与多项重大投入检验，取得历史顶级且长期保持的回报，无国家级负收益周期；最多容纳不改变整体的局部失利。 | 36.0—40.0 |

一项国家级负收益不得被许多低成本小胜平均稀释；多项重大高收益可以证明稳定效率，但同一父树阶段不得重复。主动或自我诱发战争出现一次可归责S5以上，或反复出现S4以上，原则上不得进入D4、D5；解除存亡级威胁时须另审必要性。D0必须另做覆亡因果裁决。D5必须同时具备历史顶级回报、多项实质投资检验、总体明显占优、成果保持和无国家级战略透支；不能仅以低暴露无败绩进入最高档。

### 3.1 机器定档顺序

先定义：`正向数 = HIGH_RETURN + PROPORTIONATE`，`负向数 = LOW_RETURN + NEGATIVE_RETURN`；P、M、A或归责后S任一成本档，或SB、SN、BCP、BCN任一收益绝对档达到3，视为实质周期；`HIGH_RETURN`且收益绝对档达到4，视为重大高收益，达到5视为顶尖高收益；`NEGATIVE_RETURN`且M/A任一达到4或收益绝对档达到4，视为国家级负收益。顶尖与重大高收益均按独立父级周期计数，同一战争群阶段不得重复。

机器按下列顺序命中首个适用档位：无实质周期置D-U并固定20分；国家级负收益达到3项且按每项额外加一份严重性权重后负向不低于正向，或达到2项且负向数不低于正向数，或达到1项且无正向周期，置D1；其余含国家级负收益者置D2；无国家级负收益但至少2项负收益且负向数不低于正向数者置D2。D5沿用既有组合门槛并落实“历史顶级回报”语义：至少1项顶尖高收益、2项重大高收益和3项高收益，无国家级负收益，负收益不超过1项、低收益不超过3项。D4须正向数至少比负向数多2项、占全部正负向周期至少三分之二，并且至少有2项实质周期；还须至少有1项高收益，若没有高收益，则须由至少4项全部相称、没有低收益或负收益的实质周期证明长期稳定效率；可容纳至多1项非国家级负收益，但此时正向数须至少净多3项，且至少有2项重大高收益形成强反证。其余置D3。正负打平、仅微弱占优、正向比例不足、没有高收益又夹有低收益，或只有一次未经充分组合检验的回报，均不足以进入D4。

D4、D5另过S门禁：主动或自我诱发的S5，至少2项主动或自我诱发的S4以上，或主动/自我诱发与共同归责的S4以上合计达到2项，降至D3。存在未闭合的实质`UNKNOWN`周期时，D5封顶D4。D0不由数量条件自动产生，须另作“军事投资是否为全国崩溃或覆亡主导原因”的因果裁决。

D4或D5若仅有2—3项实质周期，须通过ABC—D一致性门禁：A/B安全控制合计至少80/160，且C军事体系至少30/50；任一不足则封顶D3。该门禁只验证少量D样本是否得到独立结果与体系证据支撑，不把ABC分数重复计入D，也不限制“ABC高而D低”的有效但昂贵组合。

### 3.2 档内分公式

档内分只表达同档支撑强弱，不改变档位边界。设可用行动周期总数为`T`（包括可用的`UNKNOWN`），四类周期数分别为`H`（高收益）、`R`（相称回报）、`L`（低收益）、`N`（负收益）：

```text
Q = 2H + R - L - 2N
u = clamp(0.5 + Q / (4T), 0, 1)       （T > 0）
u = 0.25                               （T = 0）
档内分 = round(档位下限 + (档位上限 - 档位下限) × u, 1)
```

D4须再校正检验广度与正向占优程度。设实质周期数为`E`，重大高收益数为`G`，正向、负向周期数分别为`F`、`U`：

```text
b = min(1, (E + 2G) / 8)
d = F / max(1, F + U)
u = 0.5u + 0.3b + 0.2d
若 G = 0，则 u = min(u, 0.8)
c(E) = min(1, 0.70 + 0.05E)
u = u × c(E)
```

校正后再代入档内分公式。D4的实质周期折减只限制档内排序，不改变D4准入；`E=2/3/4/5`时分别乘以`0.80/0.85/0.90/0.95`，`E≥6`不折减。该折减保持质量差异，不再以硬封顶把同一检验广度但表现不同的组合压成同分；少量全正向样本仍不能与经更多独立周期检验者并列本档顶部。D-U固定20分，不使用档内公式；只有1项实质周期时按该周期类别分别将D3的`u`封顶为高收益0.65、相称0.50、低收益0.30、负收益0.10、未知0.25，避免一次事件占满中档上沿。正式结果同步标记`UNDER_TESTED`、`LIMITED_EXPOSURE`或`SUFFICIENT_EXPOSURE`，使缺乏检验与已观察表现可区分。明确的D0因果裁决或其他经规则记录的人工覆盖值直接替代机器档位与档内分，并必须在正式结果中保存理由。

## 4. 当前事实链

战役底账决定准入、事件主键和结果；国防安全底账提供SB/SN与BCP/BCN；财政民生战争成本账提供P/M/A。BCP/BCN与SB/SN、WR共同说明收益方向，但不把各档位作加法；返还、成果保持与实际控制必须在同一主体—阶段视图中核对。独立`DEF-*`卡不在当前D项正式结果中选择性取样；以后若接入，必须先完成全量主体绑定、跨卡去重和同一公式复算。正式结算保存皇帝档位、40分、全部计分周期和证据缺口；事件级全量配对及重建程序保留在`tmp/**`，不另造战争事实。
