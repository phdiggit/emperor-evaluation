# 第三项D：军事投入—战略安全净变化结算合同

## 1. 当前状态与评价问题

本合同是第三项D当前唯一正式合同，取代旧九轴逐父周期Q求和方案。D评价：统治者面对军事目标或安全挑战，投入了多少可控军事资源，以怎样的作战过程，最终使本方安全态势发生了什么变化。

- 正式主对象是战略链，不是单场战斗、单卷卡片或周期票数量。
- 对外战略链与达到系统门的异常内部战略链共同衡量安全态势变化，E与EN同权。
- 成本用于相近成果组合的横向比较；高成本可以降档或封顶，但不得由亡国、失地或敌方伤亡倒灌。
- 普通平乱只作辅助背景，数量不加分也不扣分。
- 不再计算旧Q，也不恢复P/S/M/A与SB/SN/BCP/BCN/WR逐票求和。

## 2. 战略链、窗口与跨项去重

同一对手、目标和连续授权下的多阶段行动合为一条战略链；重新授权、目标改变、前链闭合后复发或起点威胁显著改变时拆链。阶段票只作证据，不重复消费终点。

第一项已经消费的创业、统一、兼并及政权取得父链整链退出D，成果与成本一并退出。第三项C独占消费的完整任务同理退出D局部评分。若只去重新增疆土或政权取得收益，而同一新授权战争仍改变即位后的外部安全态势，则保留该安全变化、失败阶段和可归责成本。所有退出对象只能位于`cross_item_excluded_chains`，不得进入D主评价数组。

上述退出只定义`D_local_cost_profile`，不得把消费者去重后的C0解释成全第三项低成本。第三项总分另生成`global_cost_credit_profile`：第一项创业统一整链仍完全排除；第三项C独占消费、但发生于本人正式统治窗口的任务成本恢复进全局视图，只折算A正向成果信用与B80，不恢复D成果分、D负分，也不折损C50。全局系数和三项明确恢复裁决统一读取[`config/third-item-cost-credit-factors.json`](../../../../config/third-item-cost-credit-factors.json)。

不连续实际主政窗口与重叠评价主体必须沿用A/B、C相同的阶段边界。D只计算本人实际主政阶段发生的安全结果和可归责成本；同一父链跨越权力交接时按时间阶段分别挂接，但同一阶段的成果与成本只能归入一个主体。收益侧若在A正向信用、B2或B4消费了某一阶段，该阶段的军事成本必须同步进入该主体的全局成果信用成本视图；不得因D局部消费者去重、父链终局归属或人物窗口切换而形成“收益进入、成本漏接”。正式记录必须输出`active_rule_windows`、`overlapping_subject_window_review`及跨窗阶段引用。

## 3. 开战前有效对手挑战O档

只设`effective_opponent_challenge_grade`，只看本方决定响应前，对手当时实际能对本方形成的威胁；不读母体历史峰值、远征难度、本方投入或战后结果。

| 档 | 定义 |
|---|---|
| O1 | 地方武装或局部压力，不能持续组织跨区域战争。 |
| O2 | 能稳定袭扰边境或争夺有限区域，但不能持续压迫主要方向。 |
| O3 | 能持续压迫一个主要战略方向。 |
| O4 | 能同时压迫多个重要方向，或直接威胁核心区域。 |
| O5 | 能迫使本方核心防务体系或全国主力作系统响应。 |
| O6 | 开战前已能持续压迫本方政权军事生存。 |
| NOT_APPLICABLE / NOT_CLOSED | 无单一外部对手，或现有材料不足。 |

## 4. 链级安全结果E/EN

周期级SB/SN、BCP/BCN和WR只作为`stage_security_evidence`。链级裁决比较响应前起点与最后一次有效授权收束后的终点，必须同时保存阶段最好成果、最坏负阶段、终点控制、耐久性和反转轨迹。

| 档 | 链终点相对起点的净变化 |
|---|---|
| E0 | 威胁持续且无净改善，或主动行动未改变本方原有安全态势。 |
| E1 | 止损、击退或恢复原线，但未形成显著结构改善。 |
| E2 | 稳定或恢复一个区域性方向。 |
| E3_MAJOR_STAGE | 显著削弱主要对手或取得重大阶段成果，但战略目标未闭合。 |
| E3_REGIONAL_TERMINAL | 区域对手终结，或重要单一区域方向永久稳定。 |
| E4_MAJOR_STRATEGIC | 终结主要外部威胁，形成耐久跨区域控制，或长期重构一个主要国防方向。 |
| E5A | 开战前具全国防务压迫能力的外部体系实际终结或不可逆降级。 |
| E5B | 由本轮军事行动因果促成跨多个重要方向的长期战略体系重构。 |
| EN1 | 局部方向净恶化。 |
| EN2 | 一个或多个主要方向发生耐久恶化。 |
| EN3 | 全国或多数核心防务体系崩溃，中央或政权军事生存终止。 |
| NOT_CLOSED | 终点材料不足；不得当作E0、失败或低成本。 |

E5A与E5B为两条独立通道。E4可由对手终结、耐久控制或主要方向系统重构三条通道进入。被动接收、普通归附、谈判或制度化不得凭高BCP机械进入E5。先得后失按终点只消费一次，阶段成果仍保留在trajectory中。

## 5. 可归责军事成本C档

成本只计本方军队动员、人员与兵团毁损、军事资产、灾后再动员、长期反复投入及统治者本人责任。敌军、叛军、平民和无法拆出的军民合账不进入军事人员损害。将领独立违令不自动变成本人重大责任。

成本聚合依次看：单链最高闭合结构、全期累计毁损、全期动员与反复、同链或连续链灾后再动员、统治者本人责任。链数和事件数只展示，不能拼接成不存在的因果链。

| 档 | 结构门 |
|---|---|
| C0 | D范围内无实际可消费军事投入或损害。 |
| C1 | 单次、小规模、短期，无显著兵团毁损。 |
| C2 | 一条或少量有限投入，无F2+及长期高强度反复。 |
| C3 | 一条10—30万级投入，或若干有限链形成可见累计承载。 |
| C4 | 严重但分母未闭合的万级损失/F3候选，或多条十万级以上投入形成显著累计承载。 |
| C5 | 闭合F3主力级毁损、同一长期链灾后重大再动员，或多项独立F2+与全国性承压。 |
| C6 | 闭合F4大军团/国家主力灾难，或多个独立F3重大毁损。 |
| C7 | 全池最高结构：多个独立全国级灾难、F4后持续全国再动员，或同等级累计承载。 |

F4不是同质布尔值，必须同时保存投入分母、绝对损失、损失比例、兵团角色和灾后再动员。`NOT_RECORDED`降低置信度或形成LOWER_BOUND/PROVISIONAL，不代表低成本。

## 6. 人物D0—D5映射

先把独立外部/系统内部链的E与EN组成同权的有符号安全组合，再应用成本。不同对象的正负结果并列，同一对象的阶段正负不得重复。

| 档 | 人物级统一安全组合 |
|---|---|
| D0 | EN2/EN3或连续失败强支配，缺少足以抵消的独立净改善。 |
| D1 | 接近无净改善，或有限正向与重大负向大体抵消。 |
| D2 | 形成有限区域净改善，但仍受EN2或高成本明显压制。 |
| D3 | 形成明确主要方向净改善；稳定E3组合，或E4与负链并存后仍为正。 |
| D4 | 形成强主要战略净改善；E4组合无强支配EN，或E5与EN2并存仍明显为正。 |
| D5 | 形成变革性净改善；可由闭合E5进入，也可由多个独立耐久E4进入，且无支配整体的EN2/EN3并通过成本门。 |

C6/C7原则上封顶D4；C5需要证明成果显著支配成本。高成本允许降档。D5不设E5单链硬门，但多个E4必须来自独立对象或方向，不能拆票凑数。档内LOW/MID/HIGH按成果终结程度、覆盖范围、耐久性、负链和成本排序。

人物D档与档内位置按下表映射为40分制正式点值。点值只消费当前战略链D档，不读取旧Q、旧周期均值或周期数量；同档低、中、高位分别拉开，档间保留清晰间隔。

| D档 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| D0 | 0 | 3 | 6 |
| D1 | 10 | 12 | 14 |
| D2 | 18 | 20 | 22 |
| D3 | 24 | 26 | 28 |
| D4 | 30 | 32 | 34 |
| D5 | 36 | 38 | 40 |

全任期闭合且无D实质链者记D-N；D-N为不适用，合并第三项时记0分，但不得解释为低成本、失败或最低D档。D项正式JSON同时保存档位、档内位置与点值，第三项汇总只能读取这一当前映射。

## 7. 证据、普通平乱与输出顺序

每条链必须有固定docs或公共03来源；链终点、阶段反转、动员、人员毁损和责任分别追溯。普通平乱执行史实沉默推定：已载官军讨伐并载破、平、擒首、散、复城/州，且无反复失败正面证据时，默认本次成功并恢复原控制；这只能证明普通平乱成功，不能产生重大成果或低成本。

人物叙述顺序固定为：外部战略链成果与代价 → 异常内部链 → 普通平乱摘要。
