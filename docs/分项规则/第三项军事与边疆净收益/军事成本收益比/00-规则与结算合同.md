# 第三项D：军事投入—战略安全净变化结算合同

## 1. 当前状态与评价问题

D评价本人军事投入与安全结果的组合，保留40分审计点值；普通成本独立裁决，与ML一起由合并合同扣分，D点值不另加到总分。

战略链是基本单位，对外链与达到系统性条件的异常内部链使用同一E/EN尺度；普通平乱只作背景，不按战事或材料数量加减。旧Q及P/S/M/A、SB/SN/BCP/BCN/WR逐票求和不再使用。

正式JSON保存经史源审查的链归并、对手、安全、成本、责任和档位位置，局部修改，不从公共登记或旧Q自动推导。验证器查结构、唯一性、证据去重、映射与阅读同值；仅`--write`跨组件重建，日常D校验不读AB/C配置。

## 2. 战略链、窗口与跨项去重

同对手、目标及连续授权的阶段合链；新授权、目标改变、闭合后复发或起点威胁显变才拆，终点不重复消费。

第一项已消费整链及第三项C独占任务退出D局部，置`cross_item_excluded_chains`。仅扣新增疆土/政权收益、仍有新授权安全变化者，保留其安全、失败和成本。

`D_local_cost_profile`不代表全项成本；`global_cost_credit_profile`恢复本人窗口内C独占任务成本，仍排除第一项整链。[factor与扣分表](../../../../config/third-item/third-item-cost-credit-factors.json)唯一。

窗口与AB/C一致，同阶段成果成本只归一主体；A/B2/B4消费阶段必须接入该主体全局成本，不因局部去重或终局归属漏接。保存`active_rule_windows`、`overlapping_subject_window_review`及跨窗引用。并行共享权力按国防合同的单一记账主体规则处理；共享背景不折减客观军损严重度，但同一阶段的军损、军资和再动员不得在另一主体D中再次消费。

## 3. 开战前有效对手挑战O档

`effective_opponent_challenge_grade`读取[公共O档合同](../../../证据规则/军事对手战争机器O档合同.md)及机器实例，使用`O1`—`O6`、`NOT_APPLICABLE`或`NOT_CLOSED`。D只判断本方响应前、当前竞争窗口的有效压力；母体峰值、远征难度、本方投入或战后结果不能替代。

O5同级竞争、O6持续战略优势的条件均按公共合同执行，多方向或重要区域压力本身不足O6。后期增强不倒灌前期，多条低档周期不相加升档；旧`O*_...`扩展名仅作遗留显示，不保留第二套定义。

## 4. 链级安全结果E/EN

SB/SN、BCP/BCN、WR只作`stage_security_evidence`。比较响应前起点与最后有效授权终点，保存峰值、最坏阶段、终点控制、耐久与反转。

| 档 | 链终点相对起点的净变化 |
|---|---|
| E0 | 威胁持续且无净改善，或主动行动未改变本方原有安全态势。 |
| E1 | 止损、击退或恢复原线，但未形成显著结构改善。 |
| E2 | 稳定或恢复一个区域性方向。 |
| E3_MAJOR_STAGE | 显著削弱主要对手或取得重大阶段成果，但战略目标未闭合。 |
| E3_REGIONAL_TERMINAL | 区域对手终结，或重要单一区域方向永久稳定。 |
| E4_MAJOR_STRATEGIC | 终结主要军事威胁，形成耐久跨区域控制，或长期重构一个主要国防方向。 |
| E5A | 开战前具全国防务压迫能力的军事体系实际终结或不可逆降级。 |
| E5B | 由本轮军事行动因果促成跨多个重要方向的长期战略体系重构。 |
| EN1 | 局部方向净恶化。 |
| EN2 | 一个或多个主要方向发生耐久恶化。 |
| EN3 | 全国或多数核心防务体系崩溃，中央或政权军事生存终止。 |
| NOT_CLOSED | 终点材料不足；不得当作E0、失败或低成本。 |

E5A/E5B独立，E4可由对手终结、耐久控制或主要方向重构准入；高BCP不自动给E5。先得后失按终点一次计，阶段保留trajectory。

内部链须有核心失控、全国主力响应或独立军政中心，规模只决定准入。原威胁体系实质削弱或终结，即使只恢复原疆域也可E3—E5；仅平本轮、转移威胁或改名不足。终点看本人窗口的控制、指挥及再战能力，不由身后少乱反推。E不直接换分：A1采用净安全，B2/B4另审控制，仍核对自致与去重。

宫廷事件按[国防合同](../国防安全/00-规则与结算合同.md)切片；弑废、夺宫须另证本人窗口国家级军事后果才入E/EN，不倒灌后续内战。实际军损另审，不因隔离而豁免或推定。

## 5. 成本合同引用

成本C档和证据状态见[军事成本合同](../../../证据规则/军事成本评估合同.md)，总扣分及ML的完整准入见[合并合同](../00-合并计分与军事扣减合同.md#third-ml)。亡国、失地、敌损或民生损害不直接生成ML；D排除也不能代替第一项成本裁决。

## 6. 人物D0—D5映射

先把独立外部/系统内部链的E与EN组成同权的有符号安全组合，再应用成本。不同对象的正负结果并列，同一对象的阶段正负不得重复。

| 档 | 人物级统一安全组合 |
|---|---|
| D0 | EN2/EN3或连续失败强支配，缺少足以抵消的独立净改善。 |
| D1 | 接近无净改善，或有限正向与重大负向大体抵消。 |
| D2 | 形成有限区域净改善，但仍受EN2或高成本明显压制。 |
| D3 | 形成明确主要方向净改善；稳定E3组合，或E4与负链并存后仍为正。 |
| D4 | 形成强主要战略净改善；E4组合无强支配EN，或E5与EN2并存仍明显为正。 |
| D5 | 形成变革性净改善；可由闭合E5进入，也可由多个独立耐久E4进入，且无支配整体的EN2/EN3并通过成本门。 |

C6/C7原则上封顶D4；C5需要证明成果显著支配成本。高成本允许降档。D5不设E5单链硬门，但多个E4必须来自独立对象或方向，不能拆票凑数。档内LOW/MID/HIGH按成果终结程度、覆盖范围、耐久性、负链和成本排序。

人物D档与位置按下表映射40分审计点值，不读旧Q或周期均值/数量。

| D档 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| D0 | 0 | 3 | 6 |
| D1 | 10 | 12 | 14 |
| D2 | 18 | 20 | 22 |
| D3 | 24 | 26 | 28 |
| D4 | 30 | 32 | 34 |
| D5 | 36 | 38 | 40 |

全任期闭合且无D实质链者记D-N；D-N为不适用，合并第三项时记0分，但不得解释为低成本、失败或最低D档。D项正式JSON同时保存档位、档内位置与点值，第三项汇总只能读取这一当前映射。

## 7. 证据、普通平乱与输出顺序

各链以docs或公共03来源定位终点、反转、投入、损失与归责。普通平乱已载讨伐及破/平/擒/散/复城且无反复失败证据，可推定本次成功恢复原控；不推重大成果或低成本。

人物叙述顺序固定为：外部战略链成果与代价 → 异常内部链 → 普通平乱摘要。

## 8. 当前正式输入与运行边界

正式结算保存逐链事实、来源和裁决，不读临时影子文件、不写数据库。总分按[合并合同](../00-合并计分与军事扣减合同.md#third-total)计算。
