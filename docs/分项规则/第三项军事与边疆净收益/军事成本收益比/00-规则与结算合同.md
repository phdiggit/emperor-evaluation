# 第三项D军事成本收益比规则与结算合同

本项以40分评价皇帝完整统治期内的军事投入是否值得。正式计分单元是“评价主体—任期窗口—去重父战役周期”，不是单场战斗、单卷卡片或战术阶段。机器必须先完成父级去重和父级成本收益轴收束，再由轴直接生成回报档位；禁止先写回报类别再反推轴。

史料阶段卡遵守[`战争成本、安全收益与战争回报档位`](../../../证据规则/战争成本安全收益与战争回报档位.md)。正式结果唯一读取入口为[`皇帝D项正式结算.json`](../../../评分结算/第三项军事与边疆净收益/军事成本收益比/01-皇帝D项正式结算.json)。

## 1. 准入与平乱

- `D_EXTERNAL_OR_FRONTIER`：对外战争、边防行动、驻防维持及其完整结果链。
- `D_INTERNAL_STRATEGIC`：争夺国家或主要区域控制、形成持续军政对抗的战略级内战。双方军民损失均属本国成本；内部府库、旧地和人口转手不记新增`WR`，只有超出战前状态的实际安全、控制或资源改善才记正收益。
- `D_INTERNAL_RESTORATION`：地方叛乱、兵变、盗乱和局部镇压。实际成本必须计入；恢复事前控制和秩序只算止损，回报最高`PROPORTIONATE_RETURN`。
- 创业、统一和兼并战争固定排除；宫禁政变、个人刺杀、未形成国家军事行动的政治暴力固定排除。

平乱是否计入只看是否已经形成国家军事投入和可归责结果，不看事件名称。不得以`MUTINY/REBELLION`等字符串代替语义路由。

本项不建立历代起义、叛乱或工程的全量目录。事件存在本身不是计分单元：没有形成国家军事行动的逐帅、骚动和政治冲突不进入D；普通城建、道路、迁徙与宫室工程也不因发生在战争前后自动进入D。同一战略周期内的平乱、工程和后勤阶段只把已经发生的成本上传父级，不另增周期数。

所有人物共用同一准入合同。叛乱、起义和兵变不再用成本收益轴或`I`反推规模，而由全榜逐人审计确认：实际规模或地理覆盖达到当时制度下的区域级以上、镇压跨年或旷日持久、动用重兵/多路军/皇帝亲征、镇压方明显损兵折将，任一成立即可准入；非宫廷事件若攻陷监督多州郡或战略区的区域级军政中枢，也可直接准入。准入后若终局确已恢复事前秩序，走`D_INTERNAL_RESTORATION`且不得获得扩张型高收益；若周期终局仍是军政节点失控、主力叛逃、讨伐失败或区域控制未恢复，则走`D_INTERNAL_STRATEGIC`并保留实际负收益，禁止把“发生过镇压”伪装成成功恢复。普通地方骚乱、短促局地兵变和纯宫廷政变跳过。州、郡名称不得跨时代机械等量，必须结合当时行政层级、实际幅员、人口兵力、战略区和中枢后果判断。没有检索到合格事件只写“当前未发现”，不得写成历史上不存在。

生成器可以用已经登记的内部语义与高强度国家投入轴建立“必须人工处置”的召回门禁，但该门禁只负责发现遗漏，不能自动证明事件达到大型叛乱准入标准，也不能决定回报档。每个命中项必须落入准入、同父周期合并、明确非内部叛乱排除三种处置之一；历史规模明确但公共轴暂未达到自动召回阈值的事件仍须人工上调准入。

非内乱军事任务使用独立的重大任务门槛：正式大战役合同达到A级以上，或已闭合事实出现至少一项4档战略后果，或军事工程至少有两项独立3档成本，才进入实质父级周期。创业统一父链仍统一排除。由此，准入结论独立于后续回报档和Q值，不能再用待评分结果决定样本。

内乱起因不设独立计分路由。史文明载本人政策、征发、用人或处置与内乱形成直接因果时，该因果只用于判断是否把前置军事投入与平乱阶段合并为同一父周期，并据实归入`P/S/M/A、SN/BCN`；没有直接因果证据时不得推定、不得合并。这样避免因史料详略不同而使“自致”成为跨朝代不稳定的人工惩罚标签。

## 2. 父战役周期与去重

公共战役登记的 `canonical campaign family` 与本项父战役周期不是同一对象。公共层只完成历史军事事件身份、战争树父子关系、跨书跨卷重复观察与共享 lineage 的去重；本项必须在公共层之后，按“评价主体—任期窗口—连续决策动员链”生成 `canonical ruler-window investment cycle`。同一公共战争链跨皇帝时按本人窗口切开；同一皇帝的D周期不得重复消费同一公共父级。正式D生成器只能通过公共登记统一加载器取得战役事实，不得直接读取编年裁决卡作为计分输入。

公共层可以保存内战、叛乱、兵变、国家军事投入与是否恢复事前控制等中性事实，但不得提前决定本项准入、`D_INTERNAL_RESTORATION` 路由或回报上限。平乱规则仍在本合同后置执行，以免D的评分语义污染第一项C、军事人才等其他公共成果消费者。

### 2.1 合并边界

满足以下四项时合并为一个父战役周期：

1. 服务同一战略目标或同一威胁、控制对象；
2. 决策和动员连续，未发生可辨的新授权与重新集结；
3. 前一阶段结果尚未闭合，后一阶段是在追击、解围、恢复、议和、驻守或结果确认；
4. 成本、收益或控制证据存在父子卡、跨卷或回溯重叠。

出现新战略目标、新授权、新一轮独立动员，或前一周期已经形成可保持的终局后再度开战，才拆成新周期。跨皇帝事件按本人任期阶段切开；后任成果不得倒灌前任。

每项人工合并必须保存`canonical_parent_cycle_ref、member_cycle_refs、decision_window、mobilization_window、terminal_result_refs、reason`。生成器先把全部成员映射到唯一父级ID，再检查同一皇帝的父级ID唯一；重复即拒绝生成。原始卡、卷、战术阶段和来源锚点只作证据清单，不得进入周期数量。

父周期数量还须进行跨人物密度审计。当前以长期高频对外作战且已完成逐周期复核的李世民`T=11`、李治`T=9`作为经验警戒锚，不是人数上限或评分标准：任一人物达到`T≥9`都必须重新检查同一战争、同一方向的连续动员、跨卷追击、解围、驻守和终局确认是否仍被拆票。长在位、多方向独立战争、大型内乱或反复发生的新授权可以合理高于锚点，但必须能逐项说明为何属于新的战略投资；不能只以卡片已有不同ID证明应当拆分。

### 2.2 去重后的成本轴

父级`P/S/M/A`按完整连续动员链的实际最高负担定档，不相加阶段档位。卡片拆得更细不能增加成本票数；同一父级内出现多轮补兵、转输或重新征发时，必须把累计事实写进阶段轴或人工父级轴，再取修订后的最高档。

- `P`：按同一人员群体的最终状态去重；死亡、未归、伤俘和流亡只按最严重状态计一次，再重算父级死亡当量。
- `S`：按受损区域和生产、交通、财政、行政系统去重；同一地区的失陷、收复和再次受扰保留过程，但实际破坏只按完整影响范围定一次。
- `M`：同一批军队、民夫、运输和驻屯不得按战斗数重复；新一轮补兵、转输或重复国家动员属于父级累计事实，按完整持续机制重新定档。
- `A`：同一批粮械、舟马、堡寨和府库损失不得重复；缴获不能冲减己方已经支付的资产成本。

单阶段直接沿用阶段轴；多阶段由生成器取去重后的成本峰值并标记`PARENT_PEAK_COST_ROLLUP`。若重复投入可能使完整周期跨档，人工`parent_cost_axes`必须先覆盖阶段轴并写明累计事实和来源；禁止把若干低档机械相加，也禁止以“只取最大值”为由漏掉已证实的累计升级。

### 2.3 去重后的收益轴

父级`SB/SN、BCP/BCN、WR`表达周期起点到终点的实际净状态，不表达阶段峰值。

- 同一威胁对象先增强后削弱、或先削弱后复发，只保留完整父级中影响更强的净方向；不同威胁对象可同时保留正负轴，但必须分别列出对象和锚点。
- 同一城地、通道或防线先失后复、先得后失，只按终局实际控制判`BCP`或`BCN`；同一控制对象不得同时进入正负轴。
- `WR`只保留周期终点仍已实现、可控制的资源与资产；已经消耗、丧失、返还或仅名义取得的部分删除。
- 阶段最大`SB`与最大`SN`、最大`BCP`与最大`BCN`不得并列复制成父级轴。默认收束分别比较安全正负方向、控制正负方向的最高实际影响，只保留较强方向；正负同档时转为`UNKNOWN`，必须用`parent_benefit_axes`说明起点、终点、被净掉的阶段和仍存对象。`WR`取父级内已经实现且终局仍可控制的最高档；回溯小败或卡片文件顺序不得覆盖完整战争终局。

人工裁决只能覆盖父级轴及其事实理由，禁止只覆盖`return_class`。父级轴不闭合时回报类别必须为`UNKNOWN`。

第一项统一链排除必须以明确的父周期集合或显式起止窗口为边界。公共战役阶段遗留的`is_founding_process`只能在`FOUNDING_FLAG_ONLY`模式下单独构成排除依据；已经声明显式窗口时，窗口外周期不得仅凭该标签继续排除。跨出窗口的父周期必须按本人窗口切片或保留到第三项审计，防止后统一时期的叛乱、边防失败和军役负债被创业标签吞没。

## 3. 由轴直接生成回报档位

机器只读取父级`P/S/M/A/WC、SB/SN、BCP/BCN、WR`和内部战争路由。没有`G`、综合收益轴或轴序数加总。

先按下列顺序判断：

1. 关键成本、终局安全、控制或资源轴仍可能跨档且为`UNKNOWN`：`UNKNOWN`。
2. `D_INTERNAL_RESTORATION`只恢复事前状态：`PROPORTIONATE_RETURN`；未恢复且成本明显：`LOW_RETURN`或`NEGATIVE_RETURN`。明载的前置政策因果已经进入同一父周期成本与负收益轴，不再另加类别上限。
3. 任一`SN/BCN`达到4，或达到3且没有更高的已实现`SB/BCP/WR`抵补：`NEGATIVE_RETURN`。没有任何正收益时，只有不可逆损失轴`P/A`、可归责`S`或`SN/BCN`达到4才为`NEGATIVE_RETURN`；未达到则为`LOW_RETURN`，避免把未证明毁损的高投入工程与大军覆没等权。
4. 把可归责成本`P/S/M/A`从高到低取前三项形成成本强度剖面；`S`不归评价主体时按0处理。再把`SN/BCN`并入并从高到低取前三项，形成成本负收益剖面`C=(c1,c2,c3)`。把`SB/BCP/WR`从高到低排列，形成收益强度剖面`B=(b1,b2,b3)`。
5. 已实现正收益存在但`B<C`（按第一处不同值比较）时为`LOW_RETURN`；`B=C`时为`PROPORTIONATE_RETURN`。该比较保留多轴成本强度，禁止再用一个最高成本轴遮蔽其余同级成本。
6. `b1≥3`且`B>C`，成果已经保持且不受内部恢复上限约束时为`HIGH_RETURN`。若`b1<3`，即使`B>C`也只到`PROPORTIONATE_RETURN`。

暴露强度`I`只作描述，不参与准入。设成本负收益剖面前三项为`c1≥c2≥c3`，最高正收益轴为`b1`：

```text
I = max(2×c1, c1+c2+c3, 2×b1)
```

输出逐周期保存`material_exposure_index`，用于比较已准入周期的成本收益强度；任何`I`值都不能自动把叛乱或工程送入样本。内部战争的本国系统损害天然可归评价主体，必须把`S`纳入成本剖面；对外战争的`S`仍须有主体归责证据。

单次均未达到重大阈值、但共享同一方向、连续国家动员和共同长期终局的反复边患、海防或治安投入，必须先合并为唯一累计父周期，再由人工明确标记`material_cumulative_admitted=true`方可进入D。该通道只承认多年累计形成的实质战略负担，不按卡数、事件数或同年零散冲突自动准入；必须列出成员、连续投资关系和父级净轴。它既防止把长期低效负债逐卡过滤掉，也不得把普通骚扰堆成国家级失败。

高收益内部档位也直接读取轴：

| 高收益档 | 轴条件 | Q权重 |
|---|---|---:|
| 普通高收益 | `SB3、BCP3、WR3`至少一项成立，且没有4—5档正收益轴 | +3 |
| 重大高收益 | `SB4、BCP4、WR4`至少一项成立，且没有5档正收益轴 | +6 |
| 顶尖高收益 | `SB5、BCP5、WR5`至少一项成立 | +10 |

其他档位权重为：国家级负收益-8、普通负收益-3、低收益-1、相称收益+1。没有证明人员、资产或战略能力发生4档以上不可逆毁损的高投入未遂项目，原则上归低收益，不得仅因“有成本而无当期收益”自动归普通负收益；主力覆没、重大人员/资产毁损或同等级安全退化才进入普通负收益。国家级负收益要求`NEGATIVE_RETURN`且满足`P5、S5、A5、SN5、BCN5`任一条件，或有同等强度的国家存亡/体系崩溃父级裁决；单纯`M4`重动员不再自动视为国家级负收益。不得用普通小胜稀释国家级负收益。

## 4. 皇帝组合档

`Q`是全部已知实质父级周期的互斥权重之和，只作可加总的审计量。展示数量也必须互斥：普通、重大、顶尖高收益各周期只能进入一列。`J=重大高收益数+2×顶尖高收益数`。周期数量本身不奖励，`UNKNOWN`不按0或负收益计入，但仍占据已经发生的实质投资暴露分母，不能因后效失载而提高效率。

皇帝组合定档使用风险调整后的归一化效率：

```text
T = 全部实质父级周期数（含UNKNOWN）
K = 已闭合实质父级周期数
N = Q/T + J/T - 2×(低收益数+负收益数)/T - 2×国家级负收益数/T
```

`Q/T`避免厚样本因少数高收益机械抵消大量低效周期，也避免未知后效的高成本投入从分母消失；`J/T`保留重大、顶尖成果密度；普通负面周期占比取双倍惩罚，使少数重大胜绩不能遮蔽占多数的低收益或负收益周期；国家级负收益再承担独立双倍惩罚。各项都以同一`T`归一，不叠加人物特例或离散的正负结构`if/else`。

| 档位 | 组合边界 | 40分区间 |
|---|---|---:|
| D-N | 全任期审计已经闭合，未发现达到D实质准入门槛的军事投入周期。 | 0分；只表示未取得D正收益，A/B/C仍可进入阶段总榜。 |
| D-U | 存在潜在实质周期、回报轴或材料缺口尚未闭合，当前无法判定实际D收益。 | 不计分 |
| D0 | 军事投入是全国性崩溃或覆亡的主导原因。 | 0.0—7.9 |
| D1 | `N < -4.0`，保留给持续严重亏损组合。 | 8.0—15.9 |
| D2 | `-4.0 ≤ N < 0.0`，净效率仍为负但未达到严重亏损。 | 16.0—21.9 |
| D3 | `0.0 ≤ N < 1.2`，风险调整后至少不为负。 | 22.0—29.9 |
| D4 | `1.2 ≤ N < 3.0`，且`K≥5`。 | 30.0—35.9 |
| D5 | `N ≥ 3.0`，且`K≥8`。 | 36.0—40.0 |

实质回报闭合率低于三分之二最高D3；存在实质`UNKNOWN`但闭合率不低于三分之二时最高D4。D0须有单独因果裁决，亡国不自动归零。A/B和C只作交叉审计，不补偿或惩罚D。

各档按`N`在本档区间线性映射档内分；D1下界锚为`N=-11.0`，D5满分上界为`N=4.0`。D3只有`K≥3`时才可取得完整档内位置；`K<3`时位置上限为`K/3`，防止单个正向周期直接占据D3上沿，但不改变已经成立的D3档。若高效率组合因闭合样本数或`UNKNOWN`被压到较低档，档内位置还须连续受证据支持率限制：缺D4样本时上限为`K/5`，缺D5样本时上限为`K/8`，存在实质`UNKNOWN`时再取与闭合率`K/T`的较小值。证据不足不能反而自动取得封顶档的最高分。输出同时保留Q、J、均值、决定性密度、负面占比、国家级负收益占比和证据档内位置上限及原因，供重算与解释。

`K≤1`标记`UNDER_TESTED`，`K=2—4`标记`LIMITED_EXPOSURE`，`K≥5`标记`SUFFICIENT_EXPOSURE`。只有在全任期材料审计闭合、没有潜在实质周期、没有未解决成本收益轴或大型事件缺口时，才能从D-U转为D-N；D-N不赠送中性分，按实际取得D正分为0进入第三项总榜。仍有潜在周期、回报轴或材料缺口者保持D-U且不进入总分排名。

## 5. 正式输出门禁

正式JSON必须逐周期保存父级ID、成员卡、路由、父级成本轴、父级收益轴、轴裁决来源、回报档位和Q贡献，并满足：

- 每位对象的父级ID唯一；成员卡不得跨父级重复消费；
- 同一收益或控制对象不得同时进入父级正负轴；
- `return_class`必须由当前父级轴确定性生成，禁止单字段人工覆盖；
- 五类回报计数之和严格等于实质父级周期数；
- Q必须等于逐周期`q_contribution`之和；
- 平乱路由不得依赖事件ID字符串；
- 无变化重跑结果与哈希一致。

本目录只保存当前合同和当前正式结果，不写数据库，不保留旧门槛、旧类别或兼容分支。
