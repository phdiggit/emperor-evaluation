# 皇帝任期军事体系结算规则

每人一条C记录，满分50；C1定基础，C2/C3只作上限，不另加分。

共享战争材料从[`《资治通鉴》战争计分材料审计索引`](../../../史料通读产物/唐以前编年/00-战争卡审计索引.md)按`WAR-*`键回源；机器计分唯一读取[正式C结算JSON](../../../评分结算/净收益/第三项军事与边疆净收益/军事体系有效性/01-皇帝C项正式结算.json)，Markdown只作人工阅读视图。

## 一、三轴结构

| 轴 | 字段 | 核心问题 |
|---|---|---|
| C1 实战兑现度 | `combat_delivery_grade` | 面对实际战争任务，军队能否完成任务 |
| C2 持续作战能力 | `operational_sustainability_cap` | 动员、补充、后勤和恢复能否持续支撑作战 |
| C3 体系可靠性 | `system_reliability_cap` | 战力能否跨将领、跨战场重复运行 |

三轴均按0—5档由事实直接裁定：

| 档 | C1 实战兑现 | C2 持续作战 | C3 体系可靠性 |
|---:|---|---|---|
| 0 | 核心任务整体失去作战能力 | 动员、补充或后勤体系崩溃 | 国家级军令和组织长期、全面崩溃且任内未恢复 |
| 1 | 普通任务也反复失败 | 只能维持极短期、临时性行动 | 中央级组织长期严重失灵或崩溃未恢复 |
| 2 | 胜负混杂且总体偏弱 | 能有限作战，但保障经常限制主要行动 | 反复重大组织失误，明显依赖单一将领、集团或临时拼凑 |
| 3 | 普通和中等任务总体可兑现 | 通常能支撑普通战争，大规模或长期行动仍有明显缺口 | 通常有效，但跨将领、跨方向复制有限 |
| 4 | 主要或高难任务多数兑现，仅有少数重大失败 | 能稳定支撑多路、大规模或较长期战争，但仍有显著保障缺口 | 多名将领、多方向可稳定运行，但仍有显著组织缺口 |
| 5 | 多个O4—O6对手体系下长期保持历史顶级兑现，且完整战略链上无重大体系失败 | 多个独立方向、至少两个O4—O6对手体系下长期保持历史顶级保障且无战役群级保障崩溃 | 历史顶级跨将领、跨战场复制，并满足第三节的将领成果资格 |

C评任内军事体系，以实战为主；安全归A、控制归B、成本归D、军制制度史归第二项。名将个人能力不能代替体系可靠性。无实战时按第三节检查继承能力。

C1结合对手、交战过程、战果战损和续战能力判断。目标未成不等于全役战败，也不能靠改写目标改变同一作战过程的档位；斩获比例、政治或领土结果均不是单一判据。敌方造成明确损害且长期无有效拒止/止损，属于被动失守；撤收、坚壁、撤民、外交或反击有效控损时不机械判负，失载留未知。

## 二、证据准入与跨项边界

### 1. 以完整战略链判断

同一主要方向或压力对象、连续国家授权和共同终局合为一条战略链；目标重置、对手体系实变、停战后重新授权、攻防转换或内部叛乱主体不同则拆链。地方转战、增援、追击、预备动员及直接后效保留为成员证据，不按年度、卡片、父周期或链数加减能力。

按本人实际权力窗口取证，同年交班细分月日，不借继任结果。防务、屯戍、行政须在战争压力下证明交付、持续或复制，才算实战任务；普通刺杀、盗劫和司法捕治，未证军队、军事节点或组织性武装任务受压，只作背景。军官身份不代替所部作战，规模小也不排除真实军事任务。

### 2. 创业战争与本项任务分开

实战主要取对外战争，统一战争与内部平乱有限参照，不按类别机械打折。第一项整链的成果与成本退出第三项A/B/D；只有已形成可评价政权或实际主政窗口内的战争，才可列`capability_only_parent_refs`支持三轴，不进当前任务、结果剖面或D成本。更早私人/联盟军团只归第一项。

能力专用链适用相同O档、方向和体系要求，可支持1—4档及五档候选；任一轴正式取5，仍须本项准入的对外战争重大体系胜绩独立复验该轴，否则最高4档。不能只靠创业、统一或内部平乱取得五档。

### 3. 重大体系失败

重大失败须有以下之一：主力毁灭、整组行动因保障/军令崩溃、主要方向因组织失灵连续失效。普通伤亡、民损、战术波动、成本档或目标未成但主力可续战，均不自动满足。

完整战略链保留阶段败绩，恢复须对应同一任务和压力对象，不能用另一方向胜利抵销；已证主力毁灭或整组崩溃不因后来获胜注销。C1取5时，当前链及能力专用链均不得有重大体系失败。

同一失败可分别证明三轴问题，但总档只按第四节的短板及资格上限结算一次，不再扣代价。成本仅旁证C2保障，重大胜负须引用完整父周期及采用范围。

## 三、未知、无实战与样本门禁

事实检索限公共战役登记和底账战役通读数据，不要求联网。两处均无本人有效窗口战争事实，按“现有材料未见战争任务周期”结束补查；可列注明依据和范围的非计分参考档，不能补造战争、战果或成本。已有战争但部分过程失载，仍按实际事实评价。

**继承体系评价**须先核查本人窗口确无交战、进逼、被动失守或异常内部军事任务。失载、任务归第一项或已发生军事崩溃，都不算无实战。继承评价须同时具备：

1. 紧接任初的同一国家军事体系有实战基线；
2. 任内指挥骨干、军队组织、动员补充及保障有正面延续证据；
3. 逐轴检查裁撤、叛离、指挥失灵和保障衰退等反证。

不能跨政权重建或已证断裂承接，也不按年份衰减。前任总档、名将名望、一次动员或史料沉默均不足。三轴分别按基线与延续证据判断，不复制前任或默认中档。

记录`system_observation_status=INHERITED_UNTESTED`，在`inherited_system_assessment`保存本人及基线窗口、来源、逐轴延续、反证和依据。评价的是保有能力，前任战果不进入本人的任何任务链、胜绩资格、结果质量或A/B/D。

无任内实战验证时`gate_cap=3`，只限总档，不回写三轴，也不是默认给3。无本人战果可算时`q=0.5`作中性位置，仍取`p=max(a,q)`，不另设显式位置升降。必要轴缺证则`UNKNOWN`、分值为空且不可计分，不用C-N或0代替；补出本人实战后按正常规则重裁。

样本数量只限制证据上限，不替代事实裁决：

- C1、C3只有1条当前体系压力战略链时原则上最高3档，至少2条才可支持4档；父周期成员数不改变该上限；
- 任一轴取5，必须至少有3条跨期高难度战略链；高难度必须引用[`公共O档合同`](../../../证据规则/军事对手战争机器O档合同.md)的`opponent_system_ref`且`organization_grade`为O4—O6；
- C1-5至少闭合两个不同O4—O6对手体系；
- C2-5必须覆盖多个独立战略方向、至少两个不同O4—O6对手体系，并证明各方向长期保障有效；
- C3-5必须闭合至少两名`top/historic`武将分别在本人有效窗口取得A级及以上的本人正向显著成果；按公共登记枚举采用`A、S-、S、S+`。统治者本人不充作自己的部将，不借入前任、继任者或敌方将领成果。

任一轴拟取5时输出`c5_axis_gate`并列明相应对手、方向、父任务或武将成果；未通过者只封顶该轴4档。

## 四、总体档与计分

```text
axis_floor_grade = min(C1, C2, C3)
raw_grade = axis_floor_grade
final_grade = min(raw_grade, gate_cap)
```

`axis_floor_grade`为三轴短板，当前等于`raw_grade`，不能用平均替代。`gate_cap`只限制总档，不重裁三轴；`C_overall_grade`必须等于`final_grade`。必要轴为`UNKNOWN`时，`axis_floor_grade`、`raw_grade`、`final_grade`和得分均保持`UNKNOWN`；C2/C3只能验证或限制C1，不能抬高它。

总体档得分率区间：`C0=0%—29%、C1=30%—44%、C2=45%—59%、C3=60%—74%、C4=75%—89%、C5=90%—100%`。

重大胜绩资格如下，能力专用链可参加但不恢复A/B/D信用：

- C4至少1项高难任务中的重大体系胜绩；若有F项重大体系失败，胜绩还须至少F项。
- C5至少3项重大胜绩、重大体系失败为0，并通过三轴五档要求。

`raw_grade<4`时不再压档，胜绩上限为5；`raw_grade=4`时，C4资格不通过则上限3，通过则5；`raw_grade=5`时，C5不通过至多4，C4也不通过则3。

`gate_cap=min(major_victory_gate_cap, other_caps)`；继承体系未经任内实战检验时`other_caps=3`，无其他上限取5。

设`g=final_grade`，`s=(C1-g)+(C2-g)+(C3-g)`；当`g<5`时：

```text
a = clamp(0, 1, s / [2 × (5-g)])
q = 当前战略链结果质量位置：高收益=1、相称收益=0.55、低收益=0.2、负收益=0
q按已知结果数最多4项逐步从0.5收敛到实际质量，任务数本身不增加q
p = max(a, q)
存在显式同档裁决时：p = max(a, 显式同档位置)
显式同档位置：LOW=0.25、MID=0.50、HIGH=0.75
得分率 = 区间下界 + (区间上界 - 区间下界) × p
C项得分 = 50 × 得分率 / 100
```

三轴均为5且资格通过时，`final_grade=5`、C=50。三轴高于最终档的差额只提高档内位置，不越区间，也不回写三轴；位置不能按战绩、任务、年份或卡片数量决定。

## 五、战略链、父周期与结果剖面

| 字段组 | 保存什么、怎样使用 |
|---|---|
| `strategy_chains`、`strategy_chain_refs` | 当前完整战略链及本人窗口、压力对象、边界、终局、结果类别和来源；用于三轴、胜负资格和结果质量 |
| `capability_only_strategy_chains`、`capability_only_parent_refs` | 仅复用第一项能力证据，与当前任务、结果剖面、A/B/D及成本分开 |
| `independent_task_groups`、`current_parent_cycle_refs`、`current_item_task_refs` | 父周期来源及D逐链镜像的兼容引用；`strategy_chain_parent_cycle_evidence`保存链内成员，不再独立计任务或胜负 |
| `strategy_chain_outcome_profile` | 当前链各一次：高收益、相称收益、低收益、负收益或`UNKNOWN`，用于q；单链回报未知不改写已证三轴，也不等于中性或失败 |
| `task_outcome_profile` | 覆盖当前父任务；其中`d_security_result_profile`按`(ruler_id, chain_id)`镜像D逐链结果，只补证据状态，不用D档替换C回报 |
| `major_system_success_chain_refs`、`major_system_failure_chain_refs` | 按战略链去重，一链最多各有一次成功和失败存在性；对应`major_system_success_refs`、`major_system_failure_refs`保留父任务来源 |

公共C主体阶段绑定只证明来源与归责，不证明容器就是独立周期。合并须有同一压力对象、连续动员和共同终局；边界不明标待审。合并后按完整周期重判`return_class`，同步剖面和位置，不平均成员胜负，也不只取起点败绩或终点胜绩。不同窗口、压力对象或已结束后重启的任务，不因同年同地同对手合并。

不连续主政，或皇帝与摄政、太上皇分别建档时，保存`active_rule_windows`，按`phase_id`或`(parent_ref, ruler_id, consumption_scope)`分阶段。并行共享权力须保存与A/B/D同值的`overlapping_subject_window_review`；各主体只用归属于自己的任务、胜负、体系反证和成本。

生成器校验三轴0—5可保存、四个总档字段可追溯且不回写三轴、链ID唯一、当前与能力专用链分离、父成员去重、胜负属于有效窗口及五档资格可回源。

## 六、最小输出

C3正文具名将领及五档资格人物须显式连接当前军事人才档案，展示人才档位和本任显著成果采用范围；同名待核、未关联、未绑定本任成果、人才档位不足分别说明。个人生涯等级、链接或人数不直接换算C3。

正式`public_reading`保存经历、窗口、本人责任、三轴各自依据、逐条材料与来源及限制。区分评价判断、史实摘要和史料原文，材料汇集不冒称逐条支持；三轴不共用一段总评，整改过程不代历史依据。

`public_reading.contract_review`须覆盖当前及能力专用链：每链列本人窗口、父周期/阶段、公共O档及依据、绑定状态、完整回报、重大胜负及三轴作用。未核准对手只列候选；旧名与公共登记冲突并列，缺失不当低档、无失败或已验证。

逐轴说明本档要求、具体支持、相邻两档分界、反证和未解释处；满足必要条件不等于已证明档位。继承评价另列基线、延续与反证。错归或不准入任务退出计分后重算；缺证或冲突不能用原分自证，也不自动降档，必要轴仍无法成立则UNKNOWN、分值为空并退出综合排名。

计算解释只读现行规则与字段，展示总档、资格上限、位置及舍入。各阅读入口直接显示同一上游正文，不删统计、改判词或补历史关系；资格上限不回写三轴。

最小字段：

`ruler_id、reign_range、combat_delivery_grade、operational_sustainability_cap、system_reliability_cap、axis_floor_grade、raw_grade、gate_cap、final_grade、C_overall_grade、C_score_rate、C_score_points、C_score_support_surplus、C_score_band_position、C_score_position_method、C_score_within_band_adjudication、strategy_chain_refs、strategy_chains、strategy_chain_outcome_profile、capability_only_strategy_chain_refs、capability_only_strategy_chains、observed_parent_cycle_count、independent_task_count、independent_task_groups、current_parent_cycle_refs、current_item_task_refs、capability_only_parent_refs、task_outcome_profile、major_system_failure_chain_refs、major_system_success_chain_refs、major_system_failure_refs、major_system_success_refs、major_victory_gate、major_victory_gate_chain_view、c5_axis_gate、parent_cycle_merge_adjudications、active_rule_windows、settled_event_refs、non_war_evidence_refs、coverage_status、unresolved_gaps、score_ready`。

顶层`canonical_status=FORMAL_CURRENT`；`database_write=false`不影响其正式真源地位。
