# 皇帝任期军事体系结算规则

C项满分50分，以C1实战兑现为主评，保障、组织及恢复作为事实共同判断档位；不独立评C2/C3，不取短板、平均或加权。安全归A、控制归B、成本归D，军制制度史归第二项，同一成果或损害不重复结算。

## 一、整体档位

|档|完整任期的军事体系表现|
|---:|---|
|0|核心任务整体失去作战能力，有主军、防御、供应或军令过程证明|
|1|主要任务反复不能兑现，已有成功不足证明可靠执行|
|2|能完成实质区域或重要任务，但主要任务总体偏弱|
|3|通常任务有可靠执行依据，高难复验或主要压力覆盖仍有明显边界|
|4|高难主要任务有充分实战交付及有分量的独立复验，整体仍支持主要任务可靠兑现|
|5|面对多个O4—O6体系，跨期、不同主要任务持续顶级兑现，并有本项对外战争重大胜绩复验|

按本人实际权力窗口识别主要任务，不按终局成败挑选。正反证、实际对手、交付与败果程度、保障军令及对应恢复共同决定档位；必要条件通过不等于档位成立。未知不作失败，有限成功不保底三档，不按胜败条数、战争年数、兵数、成本或名望定档。

一般未克、任务失败、主军重损或覆没、跨任务保障军令失灵须分别说明。已证重大失败不得只塞进档内位置；后续恢复只解释同任务、同压力对象，不能注销既有失败或由另一方向胜利替代。多个主要方向持续失能不支持顶级判断；单次受挫也不自动封顶。损失仅解释军事后果，不重复扣D成本。

## 二、任务、压力与高难交付

完整战略链为基本观察单位，保留准备、接战、调整、追击、撤退与收束。围绕同一主要对象、连续动员和共同终局的阶段合并；任务结束后重新发动或压力、目标实质变化可独立。不能按卡片、父周期或阶段数凑复验，也不因同年、同地、同对手机械合并。

创业、统一战争在已经形成可评价政权或实际主政后，可作为能力专用观察；更早私人或联盟军团不采用。能力专用观察不恢复本项A/B/D收益、成本或当前回报，不能独自取得五档。本项当前战争与能力专用链分别保存。

O档只认[公共O档合同](../../../证据规则/军事对手战争机器O档合同.md)登记的本人及实际投入窗口，不借母体、他任、历史巅峰、独立盟军或胜败结果推档。缺证保留未知；分主体、分阶段的投入不取最高O覆盖全链。

高难重大交付须同时满足：

1. **实际困难**：本人窗口有O4—O6压力，或关键阶段有D3—D4实证难度。D按[公共难度定义](../../../证据规则/公共成果登记与人物画像规则.md#5-作战难度成本和不利事实)裁决；D3须证明至少两项重大约束相互强化，D4须有极端不利条件及可追踪的判断、组织过程。本人准备解决的困难仍采用；他人已解决、接手前已消失的困难不冒领。前败、成本、敌兵数、地形名称或解法数量不单独抬D。
2. **重大军事交付**：本国军事体系通过实际作战重创主要作战集团、突破主要防御，或挫败主要攻势；政治受降、守住一处节点、领土接收、外交或首领死亡不能单独证明。

关键阶段先确定承担的任务与起止，再说明约束及其相互作用、本方行动、主要军事结果和完整链反证。个人、盟军、敌方或后任的高D不整包移给皇帝；同一阶段不新增独立复验。强内战同样可以成立，普通平乱和局部小胜不机械补高难。

四档的独立复验须有实际军事分量，不要求两个不同国家。五档须有至少三项跨期高难主要任务、至少两个不同O4—O6体系及本项对外战争重大交付；D路径不替代五档O门。本人、受命国家军、地方军与盟军作用分别归责；保障与组织事实共同限制整体，不能由名将名单或人数授档。

## 三、缺证、继承与归责

只用公共战役登记及现有通读底账；两处均无有效窗口战争事实时结束补查，不补造战争。缺代表性正反证则`UNKNOWN`、分值为空，不以0或默认中档替代；未登记失败不等于已审零败。

继承保有能力须同时有紧接任初的同一体系实战基线、本人军队组织与动员保障的正面延续、裁撤叛离和指挥衰退反证核查，并确认本人窗口无交战、进逼、被动失守或异常内部军事任务。不能跨政权断裂承接，不能复制前任战果。记录`INHERITED_UNTESTED`，按证据定档，最高3档；档内位置也须有本人延续与限制依据。

不连续主政按实际阶段保存；皇帝、摄政或太上皇分档时，沿规范池共享权力窗口及显式归责，并与A/B/D一致。错归或不准入材料退出本人采用范围，保留退出理由；不把未知或他人战果用于保分。

## 四、确定性计分

先裁整体档，再裁显式位置；位置共同说明正证强度、主要压力覆盖、反证及未解释处，不能反向决定档位。

|档|得分率区间|
|---:|---|
|0|0%—29%|
|1|30%—44%|
|2|45%—59%|
|3|60%—74%|
|4|75%—89%|
|5|90%—100%|

`p = LOW:0.25 / MID:0.50 / HIGH:0.75`

`得分率 = 区间下界 + (区间上界－区间下界) × p`

`C分 = 50 × 得分率 / 100`，Decimal四舍五入至一位。五档也按位置计分，不自动满分；回报剖面保留为事实，不再参与位置公式。

## 五、正式记录与验证

`combat_delivery_grade`保存C1主评，`final_grade`保存同值总档；`joint_assessment`保存正反证、整体与位置理由、采用链、实际O窗口、高难阶段、独立复验及缺证限制。当前与能力专用链、父阶段、共享窗口、重大胜负及来源继续分别追溯；重大胜负为事实，不按数量自动授档。不得保留旧C2/C3档、三轴短板、资格封顶或能力余量公式。

权威写回源、正式JSON及人工正文由`config/project.yml`登记。公开正文须直接保存于正式记录，区分评价、史实摘要和原文；各阅读入口只投影相同正文，不猜配对手、窗口、战果或将领归属。具体证据不依赖临时试算、阶段报告或历史快照。

验证核对规范池、本人窗口、引用及去重、采用链、未知状态、联合档与分数、源/JSON/Markdown及实际下游同值、输出确定性。结构通过不代替语义裁决；保留未审链和证据边界，不宣称穷尽史料。
