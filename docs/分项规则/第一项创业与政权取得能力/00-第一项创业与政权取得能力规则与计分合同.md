# 第一项创业与政权取得能力——规则与计分合同

> 状态：当前执行合同。A、B1、B2、C1、C2均已完成全量裁决并锁定执行口径。本合同替代旧“创业战略A1/A2”、旧B“团队关键成果组合”和旧C“累计创业战果+旧前线峰值映射”结构。

## 1. 项目定位

第一项只考察：

> **一个政权的创建、复国或统一主链中，评价对象实际贡献了多少，以及其在怎样的起点、竞争环境和执行条件下完成这些贡献。**

第一项属于条件附加项，只适用于对建国、复国或尚未闭合的统一主链存在实际可归责贡献者。成熟帝国时期的边疆经营、外部扩张、国防战争原则上进入第三项。

### 1.1 主链窗口

第一项窗口从本人首次进入本次建国/复国/统一/政权取得主链并产生可归责贡献开始，到：

- 本人的相关贡献终止；或
- 该政权核心建国/统一主链闭合。

称帝、称王、称汗、受禅本身不自动截断第一项。

主链闭合后的成熟国家扩张、国防安全、边疆经营进入第三项，不得重复结算。

> **A看做成多少；B1看在什么条件下、以什么速度做成；B2看怎么组织做成；C看本人军事能力。**

同一历史事实可以作为不同能力维度的证据，但同一“客观成果规模”只能在A结算一次。

## 3. A：统一主链客观贡献（100）

### 3.1 评价对象

A只评价在建国、复国、统一主链中最终留下的稳定控制成果。

不进入A：

- 起点高低；
- 对手强弱；
- 统一速度；
- 战略判断优劣；
- 团队强弱；
- 本人军事能力；
- 纯粹的称帝、受禅、宫廷夺权或形式建国。

这些分别由B1、B2、C承接。

### 3.2 固定空间尺度

为避免跨时代人口、财赋、战略价值画像失真，A使用稳定空间控制单位：

```text
macroregion = 100
major_region = 60
全国核心统一尺度 = 1000
```

区域内部允许使用0.05、0.10、0.25、0.50、0.75等稳定覆盖比例。

### 3.3 有效控制信用

```text
有效控制信用 U
= 新增稳定空间控制
+ 50% × 恢复稳定空间控制
```

恢复型政权有客观贡献，但恢复既有国家控制不与从无到有的新建控制等价，因此按50%折算。

### 3.4 A映射

```text
项目A池
= 100 × (min(1000, U) / 1000) ^ 0.65
```

统一使用`ROUND_HALF_UP`保留1位。

0.65次方用于在保留规模递减收益的同时，避免小型区域项目在平方根曲线下被过度抬高。

### 3.5 baseline

只有在进入本条连续创业/统一责任链之前已经稳定拥有、继承或被正式交付的控制，才作为baseline扣除。

不得把本人在同一创业链前段已经亲手取得的成果，因为后来受封、称王、称帝而重新切成外生起点。

典型：

- 嬴政继承秦国既有国家控制：baseline；
- 杨坚接管北周成熟国家机器：baseline；
- 刘邦从沛县起兵后取得的关中、巴蜀等：仍属于同一创业链本人贡献，不因受封汉王而倒切。

### 3.6 耐久与终点

A不以历史峰值结算。

本人退出创业链前已经彻底丧失、且未被后继项目有效继承的成果，不计最终A。

因此：

- 一度取得但旋即失去的控制不得保留；
- 失败创业终点可以为A=0；
- 苻坚不能以376年北方统一峰值锁定A，而应考虑383—385年本人在位期间的实际崩解。

### 3.7 共同创业与跨代接力

同一连续建国/统一项目只生成一次非线性A项目池。

```text
先算项目总有效控制信用
→ 生成一次项目A池
→ 再按个人客观控制信用零和分账
```

不得把同一项目拆成多人后，各自重新运行0.65次方公式。

适用包括：

- 李渊 / 李世民；
- 宇文泰 / 宇文邕；
- 司马昭 / 司马炎；
- 李克用 / 李存勖 / 李嗣源；
- 铁木真 / 窝阔台 / 蒙哥 / 忽必烈；
- 努尔哈赤 / 皇太极 / 多尔衮 / 福临 / 玄烨。

普通下属执行不自动从最高创业责任中心的A中扣除；只有同属第一项评价对象、且确有独立可归责项目成果者才进入零和分账。

### 3.8 域外项目

现有中国区域目录无法覆盖的项目，可以建立`external_equivalent_block`，按与中国固定空间单位等价的稳定控制规模裁决，不要求扩张为全球州县数据库。

## 4. B1：创业难度与战略效率（50）

```text
B1 = 起点难度15 + 对手难度15 + 完成效率20
```

B1不再读取旧A1/A2中的精确资源百分比、Shannon entropy、战略责任系数或旧`550.25`控制锚。

### 4.1 起点难度（15）

起点只看：

> **本人首次进入本次建国/复国/统一/政权取得主链并开始承担可归责贡献时，能够直接调用多少实际军政资源。**

不看贫寒出身本身，也不把后来亲手形成的集团倒灌为先天资源。

| R档 | 定义 | 分值 |
|---|---|---:|
| R0 | 无有效独立资源 | 15 |
| R1 | 极小个人集团 | 13 |
| R2 | 地方据点或小型成建制部众 | 11 |
| R3 | 成熟区域军政机器 | 8 |
| R4 | 强藩、大型方面军或大区域机器 | 5 |
| R5 | 全国主要竞争机器 | 2 |
| R6 | 接近统一的成熟国家机器 | 0 |

继承、摄政、辅政、禅代人物必须把当时已经可以调用的成熟国家机器计入起点，不能因为个人早年出身普通而领取低起点分。

### 4.2 对手难度（15）

O档评价的是：

> **对手在与本人实际竞争阶段，相对于己方形成了多强的主链压迫。**

不是对手自身“是不是大国”。

只取最强两个独立战争机器：

```text
对手分
= 第一强O档全值
+ 第二强O档 × 50%
```

| O档 | 定义 | 分值 |
|---|---|---:|
| O6 | 压制级竞争极：明显占据战略优势，能直接逼迫己方生存、核心根据地或统一主链发生重大现实危机 | 10 |
| O5 | 同级竞争极：双方处于大体同一竞争层级，均有真实机会赢下主链 | 8 |
| O4 | 成熟军政机器：有稳定区域、财政兵员和持续作战能力，但与己方已有明显层级差 | 6 |
| O3 | 成建制区域对手 | 4 |
| O2 | 局部武装或残余政权 | 2 |
| O1 | 零散地方力量或短时抵抗 | 1 |

典型锚：

- 项羽之于刘邦：O6；
- 唐初东突厥之于李唐：O6；
- 窦建德、王世充之于唐：O5；
- 袁绍之于曹操：O5；
- 秦统一总攻期的楚、赵：成熟国家机器，但秦已明显高一层，原则上O4。

执行边界：

1. 看交手当时状态，不看历史巅峰；
2. 大国若已明显衰败，只能按实际竞争能力定档；
3. 小型政权不能仅因己方更弱就自动升O6；
4. 同一国家机器的主战、复起、追击、残余终局只消费一次；
5. 内部储位、禅代、宫廷反对集团原则上不按独立O战争机器计；
6. 具备独立军政体系、可以脱离中央持续作战的外镇或区域集团，可以按实际层级进入O。

### 4.3 完成效率（20）

#### 4.3.1 核心闭合点 `T_core`

统一效率不以“最后一个残余何时被消灭”为终点。

`T_core`是最早同时满足以下条件的时点：

1. 已取得并最终保持/传承的成果达到该阶段最终有效成果约90%；
2. 已不存在仍能争夺本条主链的O5/O6独立战争机器；
3. 若仍有O4，其不得继续控制使“核心统一”明显不能成立的关键中心；
4. 剩余不超过约10%的成果只属于边缘尾项、局部残余或不具逆转统一格局能力的收尾。

因此：

- 唐以624年前后核心闭合作为效率终点；628梁师都是尾项；
- 刘邦必须到前202项羽终局，因为项羽直到最后仍是O6；
- 刘秀不能在公孙述仍控制巴蜀核心时，仅凭面积超过90%提前闭合。

`T_core`后的尾项仍进入A，不继续拉长本阶段B1效率工期。

若后来出现重大反复，使有效成果跌回90%以下，或O5/O6竞争极复起，则原`T_core`失效。

#### 4.3.2 多阶段路线

如果前一独立目标已经达到`T_core`，随后明确转向新的独立目标，不能从第一次起兵一直计到最后一次扩张。

每阶段单独计算：

```text
个人最终效率分
= Σ（阶段效率分 × 阶段A有效控制信用）
  / Σ阶段A有效控制信用
```

铁木真等长期、多目标项目必须按此拆分。

#### 4.3.3 同代共同创业

同代共同创业且贡献窗口高度重合时，若个人成果节点尚未完全拆清，则共同使用项目规模与项目`T_core`。

不得因为A零和分账较少，就把其中一人的“期望工期”机械缩短并判得更慢。

#### 4.3.4 期望工期与分档

```text
期望完成年
= 4 + 8 × sqrt(效率阶段有效控制信用 / 1000)

速度比
= 实际阶段年数 / 期望完成年
```

| 速度比 | 效率分 |
|---:|---:|
| ≤0.75 | 20 |
| ≤1.00 | 18 |
| ≤1.25 | 16 |
| ≤1.50 | 14 |
| ≤2.00 | 11 |
| ≤2.50 | 8 |
| ≤3.00 | 5 |
| ≤4.00 | 2 |
| >4.00 | 0 |

该公式使全国级项目的期望工期为12年；U=100约6.5年，U=50约5.8年。

#### 4.3.5 A=0

A终点有效控制信用为0时：

```text
效率分 = 0
```

B1不奖励快速夺权、快速称帝或短期占领后最终全部丧失。

但真实的起点难度和外部独立战争机器压力仍然正常计分。

### 4.4 B1与A的非重复

允许出现：

> **A很低，但B1很高。**

例如一个人物只建立小型区域政权，但确实从低起点、面对强敌并迅速完成该有限目标，其B1可以高。

如果因为项目小又在B1额外压分，就会把“规模”在A和B1重复结算。

## 5. B2：创业组织与政治整合（30）

B2不再评价“团队替本人做了多少绝对成果”，而评价：

> **本人是否把创业团队组织成可多中心并行、覆盖关键专业、能以较低本人干预完成高难任务，并能将异质集团稳定转化为共同执行体系的组织。**

```text
B2
= 并行执行能力10
+ 团队能力覆盖与组织杠杆10
+ 异质整合能力10
```

每轴L0—L5，对应0、2、4、6、8、10分。

### 5.1 并行执行能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 主要靠本人逐项处理 |
| L1 | 2 | 有助手，但不能独立闭合关键方向 |
| L2 | 4 | 至少一个稳定独立责任中心 |
| L3 | 6 | 两个稳定责任中心，或主要国家功能可以并行 |
| L4 | 8 | 至少三个稳定责任中心，可跨战区/功能同时推进 |
| L5 | 10 | 多中心运行体系化，多个关键方向可长期同时推进，本人无需逐项现场控制 |

名将数量、官位数量和团队人数没有直接计分入口。

### 5.2 团队能力覆盖与组织杠杆

判断团队是否存在足够多的高级专业责任中心，使本人能够把高难创业任务交出去，并以较低本人时间、现场控制和资源消耗得到高质量结果。

关键专业领域包括：

- 战略谋划；
- 前线统帅；
- 后勤、财政与兵员；
- 行政与新区域接收；
- 外交、联盟与情报；
- 制度设计与国家组织。

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 缺少能独立承担关键任务的高级责任中心 |
| L1 | 2 | 只有单一助手或一般执行者 |
| L2 | 4 | 有一个高质量专业中心，但覆盖窄 |
| L3 | 6 | 至少两个重要领域有高级独立责任中心 |
| L4 | 8 | 多个高级领域形成稳定覆盖，可独立完成高难任务，本人主要承担最高层决策 |
| L5 | 10 | 多个关键领域均有高等级责任中心，并在高难竞争中反复以较低本人干预兑现关键结果 |

团队稳定、高效、低成本完成高难任务本身是正向证据。

死亡、退出、换将不是高档成立前置条件；实际发生的责任链断裂、关键集团失控或高额协调损失才作为负证。

### 5.3 异质整合能力

| 级别 | 分值 | 成立边界 |
|---:|---:|---|
| L0 | 0 | 核心集团即严重排斥或分裂，无法形成共同执行 |
| L1 | 2 | 只能维持单一核心集团，外来力量多为短期依附 |
| L2 | 4 | 成功吸收一类外来或旧政权力量，但职责有限 |
| L3 | 6 | 多地域/旧集团可以共同工作，但仍明显分层或高度独立 |
| L4 | 8 | 多个异质集团能稳定承担核心军政职责 |
| L5 | 10 | 跨地域、族群、旧政权与降附机器被体系化重组，并持续为同一创业目标独立兑现成果 |

仅列出不同族群、降将、士族或旧臣名单不能证明高整合；必须存在稳定共同执行结果。

### 5.4 证据与去重

旧B的团队成果证据可以继续作为B2责任中心证据，但旧“团队关键成果组合30分”彻底废止，不再作为独立计分轴。

同一事实可以分别证明：

- A的客观成果；
- B1的竞争环境；
- B2的独立执行结构；
- C的本人军事能力；

但各轴读取的事实含义必须不同，不得把同一战果规模重复加分。

### 5.5 继承成熟机器

继承成熟团队不自动扣分：

> 如果本人确实能在创业窗口内调用既有责任中心独立完成高难任务，这属于真实组织能力。

但继承本身也没有分值。成熟国家“人才很多”不能直接映射L5。

连续多代创业时：

- 前代已经搭好的组织结构可以证明后继“会用”；
- 不能每一代都把同一成熟机器重新当作本人“重新搭建”的满档证据；
- 后继高档必须有本人窗口内的新增、重组、再授权或高难调度表现。

### 5.6 多人共同创业

B2不是A式零和分账。

同一团队可以分别成为多个共同创业者的能力证据，但必须按各自实际控制和责任关系裁决：

- 李渊可以评价其对李世民、李靖等责任中心的组织使用；
- 李世民只能评价本人秦王府、行台及直接责任链；
- 不得把李渊中央直接控制的整套唐创业机器自动复制给李世民。

### 5.7 主链窗口

B2严格服从第一项主链窗口。

主链闭合后的成熟帝国治理、远征、边疆组织和后续人才表现不得倒灌第一项B2。

## 6. C：本人军事能力

当前结构：

- C1：本人军事统帅能力，40分，已锁定；
- C2：本人前线指挥能力，20分，已锁定。

C只消费本人可归责的军事能力证据。部将取得的战果可以进入A，也可以作为B2团队证据，但不得转写为君主个人C能力。

### 6.1 C1定位

C1评价：

> **评价对象本人在第一项创业、建国、复国、统一或政权取得主链中的军事统帅能力。**

C1不是“打了多少仗”的战果累计项。

- A已经结算客观成果规模；
- C1只把战役结果、难度和责任链作为能力已经兑现的证据；
- 战役数量本身不产生线性加分。

### 6.2 C1数据源

优先级：

1. 公共战役登记中的人物实际结果、角色、战役档和难度；
2. 已经完成的人物战争路由与归责；
3. 公共武将人才等级作为全生涯横向校验；
4. 若人物登记存在明显断链，可回到已通读史料补人物责任。

公共武将人才档不得直接换算C1分数，因为它覆盖全生涯，而第一项只读本项目窗口。

### 6.3 C1可进入的军事责任

可进入：

- 本人为实际主帅；
- 本人承担可验证的独立主将方向；
- 本人虽然不在前线，但存在可追踪的**具体战争统筹**。

“具体战争统筹”必须能够闭合到战争本身，例如明确体现：

- 主攻目标与先后顺序；
- 进军路线或多路配置；
- 兵力、后勤或战区资源配置；
- 接战/撤退时机；
- 指挥链重组；
- 战役阶段目标控制；

并且能够与实际战争结果建立因果链。

不进入：

- 普通遣将；
- 单纯选将、任命或批准；
- 最高层政治口号或宽泛战略意图；
- 事后奖惩；
- 下属独立完成的战术判断和前线难度；
- 仅作为普通参战者但没有独立指挥责任的阶段。

### 6.4 C1主链窗口

不是“第一项时期发生的所有战争”都进入C1。

必须同时满足：

1. 战争属于本人第一项创业/统一/政权取得主链；
2. 本人存在可归责军事责任。

因此：

- 赵匡胤作为后周将领时期的淮南战绩不直接进入北宋创业C1；
- 耶律阿保机916年核心建国闭合后的灭渤海转第三项；
- 皇太极的朝鲜战争不因时间重合自动进入清朝中国统一主链；
- 铁木真、窝阔台的中西亚战争不进入元统一中国主链；
- 杨坚同期对突厥战争不进入其灭陈统一C1；
- 淝水之战发生在苻坚北方统一主链闭合后，不反向污染第一项C1。

### 6.5 C1档位

| 档位 | 核心含义 | 分值 |
|---|---|---:|
| C1-0 | 无可用本人军事统帅责任证据 | 0 |
| C1-1-LOW / MID / HIGH | 基础统帅 | 4 / 7 / 10 |
| C1-2-LOW / MID / HIGH | 重要统帅 | 12 / 15 / 18 |
| C1-3-LOW / MID / HIGH | 优秀统帅 | 20 / 23 / 26 |
| C1-4-LOW / MID / HIGH | 顶级统帅 | 28 / 31 / 34 |
| C1-5-LOW / MID / HIGH | 历史级统帅 | 36 / 38 / 40 |

档位判断不采用战果指数累加公式。

### 6.6 正向能力锚与复验

每人优先读取至多三个彼此独立的最高正向统帅锚，重点检查：

- 战役结果档；
- 实际难度D；
- 本人角色；
- 是否由本人作出关键军事判断；
- 是否在不同对手、战区或战争形态下得到复验。

十个普通B级胜仗不能靠数量堆成历史级。

一个著名S级胜仗也不能在没有复验时自动达到C1-5。

### 6.7 负向能力证据

第一项主链内的可归责失败、混合结果和错误判断必须进入C1。

作用方式：

- 重大败绩限制高档上限；
- 同类错误反复出现进一步压档；
- 正负同等级长期并存时，下调稳定性判断。

不作为能力败责：

- 已裁为外部灾害；
- 上级强令；
- 史源冲突；
- 不能证明本人指挥责任的结果。

C1不采用固定“败一次扣X分”公式。

### 6.8 纯后方战争统筹上限

如果一个人的全部合格C1证据均为后方具体战争统筹，没有本人实际战区或前线指挥：

> **C1最高不超过C1-2-HIGH，即18分。**

理由：

- C1承认战争组织和军事判断；
- 但缺少真实战场反馈下的统帅复验，不能进入“优秀统帅”及以上。

锚点：

- 司马炎：灭吴S级全国战争统筹 → 18；
- 李渊：晋阳南下与关中A级总体统筹 → 12；
- 玄烨：三藩—台湾再统一存在国家级战争统筹，但不继承图海、赖塔、施琅前线难度 → 12；
- 嬴政：现有证据主要是最高层用将与政治决策，没有闭合具体战争统筹 → 0；
- 杨坚：对突厥统筹不属于灭陈统一主链；灭陈链又没有闭合本人具体军事统帅责任 → 0。

### 6.9 数据缺口

不得把“公共人物登记缺失”自动等价为“本人C1=0”。

若父战役、通读史料或其他已验收材料明确显示本人存在军事责任，应补人物链后裁决。

典型：

- 李雄旧C归0属于人物登记断链；补出破孙阜、郫城诱伏、断成都运道和取成都后，C1重裁为26。

只有在复核后仍无可用本人军事责任，才能结算C1=0。

### 6.10 C2定位

C2评价：

> **评价对象本人亲临第一项主链战区后，实际控制作战并在真实战场压力下兑现指挥能力的水平。**

C2只评价直接前线兑现，不评价：

- 后方战争统筹；
- 用人；
- 团队成果；
- 个人勇武。

### 6.11 C2入场门槛

必须同时满足：

1. 战争属于本人第一项创业/统一/政权取得主链；
2. 本人亲临相关战区；
3. 本人对具体接战、攻守、进退、部署或临场指挥承担实际责任；
4. 人物结果可以在战役登记或已验收史料中闭合。

不进入：

- 普通遣将；
- 单纯批准、选将和政治决策；
- 仅随军或名义亲征；
- 下属独立完成的临场判断；
- 主链闭合后的第三项战争。

### 6.12 C2计分

```text
C2
= 前线峰值 P（0—12）
+ 前线复验 R（0—8）
- 重大可归责负证 N（0—4）
```

最终限制在0—20。

#### P：前线峰值

| P | 典型能力锚 |
|---:|---|
| 0 | 无合格本人前线锚 |
| 3 | C/B级、D0—D1有限前线责任，或C/D2下限 |
| 5 | B/D2或A/D0—D1 |
| 7 | B/D3或A/D2 |
| 9 | A/D3或S-/D2 |
| 11 | A/D4、S-/D3或S/D2 |
| 12 | S-/D4、S/D3及以上极高前线锚 |

结果档和难度必须同时读取；国家终局本身不会自动抬高P。

#### R：前线复验

| R | 复验要求 |
|---:|---|
| 0 | 只有一个可用前线锚 |
| 2 | 一个独立B/D2以上复验 |
| 4 | 第二个A/D2以上，或两个稳定中档复验 |
| 5—6 | 第二个高质量A/D3、S-/D2以上锚，并有其他稳定复验 |
| 7—8 | 多个独立A/D3以上高质量锚，跨战区、对手或战争形态持续成立 |

同一父战役吸收阶段不得拆成多个复验。

#### N：重大可归责负证

| N | 负证结构 |
|---:|---|
| 0 | 无明显可归责重大前线失败 |
| 1 | 单个较轻失败或单个mixed结果 |
| 2 | 一次A级重大失败，或两次普通失败 |
| 3 | 一次重大失败叠加其他失败，或三次以上普通失败 |
| 4 | S级灾难性失败、明确重大指挥过失，或多次重大失败形成稳定性问题 |

以下不进入N：

- 外部灾害；
- 上级强令；
- 史源冲突；
- 已判定非本人责任；
- 与军事能力无关的伦理、屠杀或战争行为负面。

### 6.13 C2结果档

| 档位 | 分数 | 含义 |
|---|---:|---|
| C2-5 | 17—20 | 历史级前线指挥 |
| C2-4 | 13—16 | 顶级前线指挥 |
| C2-3 | 9—12 | 优秀前线指挥 |
| C2-2 | 5—8 | 重要前线指挥 |
| C2-1 | 1—4 | 有限前线能力 |
| C2-0 | 0 | 无合格本人前线证据，或有限正向被重大负证完全抵消 |

C2=0必须在逐人依据中区分：

- 没有本人前线责任；
- 战绩属于窗口外；
- 下属作战不能转写；
- 有有限正向但被重大负证抵消。

不得把这些原因统一写成“没有军事能力”。

### 6.14 C1与C2边界

- C1评价“会不会统军、组织战争、作军事判断”；
- C2评价“本人真正进入战区后，现场指挥兑现到了什么水平”。

同一战役可以同时证明C1与C2，但读取含义不同：

- C1读取综合统帅能力；
- C2只读取本人直接前线指挥。

后方具体战争统筹只能进入C1，不能凭此补C2。

因此：

- 司马炎、李渊、玄烨可以有C1统筹分而C2为0；
- 赵匡胤后周时期的前线履历不能倒灌北宋创业C2；
- 嬴政的最高层用将不能代替王翦、王贲的前线指挥；
- 刘崇可以因本人上过前线而有P，但若重大败绩完全抵消，最终C2仍可为0。

## 7. 第一项与第三项边界

第一项按“建国/统一主链是否闭合”截断，不按称帝、称汗截断。

主链闭合后：

- 成熟帝国扩张；
- 边疆经营；
- 国防安全；
- 外部征服；
- 常态化军事制度运行；

原则上转入第三项。

同一成果不得在第一项和第三项重复结算。

## 8. 当前已锁定的审计要求

1. 先定规则，再跑全量数据，再看分布；
2. 去光环：不得因“大一统”“雄主”“开国皇帝”名望抬档；
3. 共享成果零和分账；
4. 继承基线必须扣除；
5. 失败终点不能保留峰值；
6. O档必须基于实际竞争关系；
7. B1效率必须使用`T_core`，不得被边缘尾项拖累；
8. A=0与第一项不适用是两个不同概念；
9. 正式结算只保存最终口径与逐人依据，不保存试错过程；
10. A、B1规则变动后必须全量重算，不允许人物级手填终分覆盖公式。
