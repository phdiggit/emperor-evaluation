# 第一项B政治整合能力规则与计分合同

## 一、评价对象与边界

第一项B只评价本名册所属王朝或独立政权的奠基人，满分60分。普通继承、守成扩张或仅取得个人皇权者输出`NOT_APPLICABLE_NON_FOUNDER`，不得以零分参加排序。

B评价奠基人之外的开国团队对创业项目作出的实际贡献，以及该团队是否形成可并行、可续接、可整合的组织。成功创业所需职能最终必然由奠基人或属下承担；只列人名、官位、集团或岗位不成立。

- A评价创业路线、总体难度、效率和稳固；
- B评价非本人团队完成了哪些开国成果、承担了多少创业工作；
- C评价奠基人本人在创业战争中的军事作用；
- 第五项B评价一般性的识人、授权和驾驭素质，不回流第一项。

## 二、最小工作单元

B1的裁决单位是非本人团队实际闭合的、不重叠的成果群，不是人物或被拆开的职能。它评价团队成果的绝对质量，不计算团队占整个项目的份额；因此奠基人本人C高不会机械压低B1。

B2的裁决单位是组织属性。人物与成果责任链只作为证据索引，不参与加总。不得以人物名气、官位、全生涯人才等级、战役字母档、贡献链条数或简单列名直接换分。

## 三、B1团队关键成果组合（30）

```text
单项价值 = 成果量级 × 团队贡献信用 × 完成度
B1 = min(30, 最强成果全值 + 次强不重叠成果 × 0.5)
```

成果量级依次为`SUPPORTING=4`、`IMPORTANT=8`、`MAJOR=13`、`DECISIVE=17`、`FOUNDATION_PILLAR=20`；团队贡献信用为`SUPPORT=0.65`、`JOINT=0.85`、`PRIMARY=1.0`；完成度为`PARTIAL=0.5`、`SUBSTANTIAL=0.8`、`COMPLETE=1.0`。

- 本人亲自决策或督战、团队仅执行，不得把完整结果归给团队；
- 团队独立闭合一个战区、后方动员体系、政治接收或外交重组，可以形成一个成果群；
- 同一结果由多人共同完成仍只形成一个成果群；祖先、阶段与终局不得重复消费；
- 一人跨军事、后勤、财政等领域形成两个真实且不重叠的成果，可以进入两个计分位，不会因名字少而折扣；
- 最多消费两个成果群，第三个以后不再增加B1，防止通过细拆链条堆分；
- 证据不足时保持成果量级下限，不以“某朝名臣很多”推定高成果。
- 进入两个计分位的成果必须具有公共战役登记引用或固定史料逐字锚；只有背景说明价值、尚未补锚的成果可以保留在非计分证据中。

军事成果按人物实际责任和结果边界读取公共战役登记；治理、财政、外交与接收成果只按创业窗口内已经兑现的结果裁决。

## 四、B2创业团队组织化能力（30）

B2由三个组织轴组成，每轴0至5级，依次为0、2、4、6、8、10分：

| 组织轴 | 判断对象 | 5级成立边界 |
|---|---|---|
| `parallel_execution` | 团队能否脱离奠基人逐项现场控制，同时闭合独立方向或国家功能。 | 存在多个稳定责任中心，可跨战区、军政或后勤方向并行闭合结果；三个稳定中心以后不再按人数加分。 |
| `continuity_resilience` | 关键成员退出、阵亡、失势或轮换后，创业主链能否由既有梯队接续。 | 已形成多层梯队或制度化接续，单一关键人物退出不会中断主要方向。 |
| `heterogeneous_integration` | 不同地域、族群、旧政权、降附与继承机器能否成为共同执行体系。 | 能持续吸纳多个异质集团并令其为同一创业目标兑现成果，而非短期挂名或旋即分裂。 |

中间档按“无可用证据—单点依附—基本成立—稳定成立—强组织化—体系化”逐级裁决。三轴只看已发生的组织结果：没有人员损失不能据此直接证明替补能力，列出多个集团名称也不能直接证明整合成功。

刘邦团队可以用韩信闭合的战略征服和萧何闭合的后方国家机器形成两个支柱成果；李世民本人承担多数主战场结果，但房杜谋划、行台后勤或诸将独立闭合的真实成果仍按自身绝对价值进入B1，不因本人C高而折损。

## 五、去重与失败边界

- 同一结果只能在两个成果位中消费一次，不得按战略、军事、行政等近义名称重复拆分。
- 名字数量、责任链条数和前三/前四人物名单没有计分入口；增列同一结果的参与者必须产生零分变化。
- 团队责任链发生失败时降低该成果完成度或量级；若失败暴露单点依赖、接续失败或集团分裂，可以同时限制对应组织轴，但必须分别说明事实含义。
- 已在A作为路线误判、效率或稳固损失结算的后果，以及已在C结算的奠基人本人军事胜败，不在B重复扣分。
- 继承的人才和国家机器不因“不是亲手培养”折扣；只按创业窗口内是否实际承担并完成任务计分。

## 六、当前输入与输出

当前裁决输入为[`config/first-item/first-item-b-team-contribution-adjudications.json`](../../../../config/first-item/first-item-b-team-contribution-adjudications.json)，秦至清名册由总名册与第一项A奠基人元数据确定，并读取最新战役登记与军事人才登记的指纹、人物身份和人才档作缺漏/越界复核。全生涯人才档不得直接替代创业窗口贡献档。生成命令：

```text
python v4.py first-item-b-registry
```

输出位于[`评分结算/第一项创业与政权取得能力/政治整合能力/`](../../../评分结算/第一项创业与政权取得能力/政治整合能力/)，是B项当前唯一有效结果。不写数据库或全榜排名。
