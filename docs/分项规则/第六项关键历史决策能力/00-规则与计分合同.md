# 第六项关键历史决策能力规则与计分合同

## 1. 评价对象与结构

第六项评价重大历史节点上的事前判断质量，以及危机或路线失效后的风险识别、修正和止损，满分90分：

| 分项 | 名称 | 分值 |
|---|---|---:|
| A | 重大选择与长期方向 | 50 |
| B | 危机处置与风险止损 | 40 |
| **合计** |  | **90** |

本项不按决策产生的制度、民生、军事、疆域或文明成果规模评分。结果只用于验证当时判断是否兑现、风险是否真实以及后来是否出现可归责的新信息。

## 2. 固定候选池、决策弧与预算

唯一计分单位是`decision_arc`：

`重大节点 → 当时信息 → 可选方案 → 本人选择 → 新信息与反馈 → 维持、修正或止损`

每名统治者最多消费三条不重叠重大决策弧。候选必须先按事前国家风险、不可逆性、选择空间和本人最高决策责任排序，再裁决方向；不得先看结果好坏后挑选有利样本。

候选池只从第一至第五项已经接受的canonical父链、正式结算材料和公共登记机械派生，不开展独立的全生涯宽搜。只有同时满足下列条件的父链才进入候选池：

1. 存在可定位的决策时点或短窗口，而不是多年结果的概括；
2. 本人承担最高决定、批准、否决、坚持或可归责放任责任；
3. 当时至少存在两个现实可行方案，且不是后见之明虚构的选项；
4. 可以识别当时已知信息、可预见风险以及后续反馈；
5. 可以区分初始选择和收到新信息后的维持、修正或止损。

机械派生完成后，按稳定`task_code`冻结全名册候选队列，再做证据闭合和前三条选择。定向补证只能填补冻结候选的当时信息、备选方案、本人责任或反馈缺口，不得借补证发现并插入新的有利候选。确有遗漏必须先重跑同一派生规则，并使全名册候选队列同步更新。

每名统治者适用相同的候选数量、补证轮次和史源门槛；不得因知名度、史料便利或既有印象扩大名人检索范围。第一至第五项材料未完整覆盖时，只能记为`UPSTREAM_COVERAGE_INCOMPLETE`，不得据此认定没有重大决策弧。

## 3. 与其他项目的边界

- 第一项A2已经计分的具名创业决策直接排除，不得在第六项换名重算。
- 制度、行政、民生和交班结果归第二项，军事安全、控制和成本收益归第三项，文明结果归第四项。
- 第五项A评价跨情境认知与履职模式；第六项只评价少数重大节点。
- 第二项B2评价日常反馈纠错机制；第六项B只评价异常危机或重大路线失效后的离散止损决定。
- 已形成的跨期灾难性历史负债归第七项；第六项只能评价当时判断和后续更新，不再按负债规模扣分。

同一决策弧原则上只能进入A或B。初始重大选择归A；在新信息出现或路线恶化后作出的独立修正归B。若选择与止损无法分割，则按整个决策弧的核心问题选择一个主轴，不得拆成两条加分。

## 4. 两个分项

### 4.1 A重大选择与长期方向

评价重大节点上的时机、方向、主次、人事、国家利益和长期结构判断。

裁决至少回答：当时已知什么、有哪些现实可选方案、本人为何选择该方案、主要风险是否可预见、选择是否与当时信息相称。后来成功不能自动证明当时判断正确，后来失败也不能自动证明当时判断错误；偶然性、执行偏差和后继者新决策必须剥离。

### 4.2 B危机处置与风险止损

评价异常危机、重大失败或路线失效后，能否及时识别风险、更新判断、改变承诺、收缩暴露并阻止损失扩大。

只有在新信息或重大负反馈出现后仍存在现实选择空间时才适用。日常政策调整、例行监督和没有实际风险暴露的“从谏”不进入。拒绝承认现实、持续加码、错失明确止损窗口或纠正后迅速复发进入负向。

## 5. 档位、空集与计分

两轴统一采用0—5档和LOW/MID/HIGH：

| 档位 | 共同含义 |
|---:|---|
| G0 | 在重大节点作出严重失当选择，或在明确风险下持续扩大损失。 |
| G1 | 判断或止损能力很弱，主要依赖偶然、他人强制或事后被动接受。 |
| G2 | 有一次有限正确判断或修正，但证据、难度、独立性或稳定性不足。 |
| G3 | 在主要重大节点形成稳定合格判断，能够处理现实反馈。 |
| G4 | 在高风险和复杂约束下多次作出高质量选择或有效止损。 |
| G5 | 达到跨时代高位，在最高风险、强不确定性和重大反对下仍持续正确，并经反事实复核成立。 |

| 档位 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| G0 | 0% | 5% | 10% |
| G1 | 15% | 20% | 25% |
| G2 | 30% | 37% | 44% |
| G3 | 50% | 57% | 64% |
| G4 | 70% | 77% | 84% |
| G5 | 90% | 95% | 100% |

`分项得分 = 分项权重 × 得分率`，保留一位小数。单条决策弧即使极强，也只能证明相应能力的上界候选；没有第二条独立复验时原则上不得超过G3-HIGH。证据不足输出`UNRESOLVED_EVIDENCE_GAP`，不得以结果印象补档。

完整扫描第一至第五项固定输入后，若某轴确无合格重大决策弧，输出`CONFIRMED_NO_ELIGIBLE_MAJOR_ARC`。它表示该轴没有适用对象，不是G0，也不是史料不足；该轴不生成能力分，只在影子校准中单独统计空集比例，不得进入总分或排名。若空集主要集中于短在位者、早期史料稀疏者或非名人，说明第六项作为独立90分项不可比，必须缩减权重或并入第五项，不得以开放检索填满候选。

`UNRESOLVED_EVIDENCE_GAP`和`UPSTREAM_COVERAGE_INCOMPLETE`均不得写0分、总分或排名。

## 6. 停止与审计

- 三条预算按事前重要性冻结；正负两侧均须完成候选检查。
- 同一决策的近义表述、上位战略与下位执行不得拆分。
- 已有三条决策弧、反证和备选方案足以稳定档位时停止扩展。
- 输出必须列出被第一项A2排除的决策、前三项主计分归属和本项未消费的结果轴。
- 每条入选弧必须记录`task_code`、`canonical_parent_ref`、`source_items`、`decision_window`、`responsibility`、`available_information`、`realistic_options`、`foreseeable_risks`、`feedback`、`update_action`、`primary_axis`和`excluded_result_claims`。
- 同一史料可以支持多个项目，但第六项必须写明新增消费的是哪条事前判断或反馈更新命题；只有结果叙述而没有新增决策命题时不得计分。
- 候选队列冻结前不得回源补证；队列冻结后不得进行无触发器的开放发现。

正式90分结算在全名册完成同一候选预算、事前重要性排序和跨时代锚点校准前保持关闭。
