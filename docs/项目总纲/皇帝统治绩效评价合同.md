# 皇帝统治绩效评价合同

> 本合同受[皇帝综合评价体系合同](皇帝综合评价体系合同.md)约束，定义统治绩效四项边界及综合公式。奠基贡献与能力、治理手段、军事体系有效性均属绩效构成，不替代独立人物画像；历史影响另行评价。

候选包括皇帝（含追封）、实权摄政太后和天王。正式准入须实际独立最高决策权≥3年，且有可统一结算史料；第二项待结算者可入池，但不进综合分/排名。逐人窗口与就绪状态见[对象规范](正式评价对象范围.md)。

|---|---|---:|---|

| 第二项 | 治国净收益 | 最高387，最低-27.5 | 共同治理项，含本项负向尾部 |
| 第三项 | 军事与边疆净收益 | 最高250，最低-80 | 共同军事项，含本项负向尾部 |

| **第二、三项共同上限 `M`** |  | **637** | 所有人使用同一正向上限分母 |

第二、三项共同计分，各自保留负尾；第一项补偿创业贡献及机会成本，第四项固定材料无增量为0。不得另设决策、负债、名望或伟业加减；共同正向上限变动时M与第一项附加同比更新。

## 2. 总原则

### 2.1 务实评价与统一尺度

按实证行为、成果、成本和后果判断，不凭名望补分；开国、守成、亡国与摄政使用同一尺度。

### 2.2 结果、过程、制度与运行分离

制度创设、行政执行、民生、军事、文明和个人素质分别举证，能力不代结果。

### 2.3 净收益与跨期后果

跨期持续性、严重性、结构锁定和修复负担只校准原项目结果，不另设历史负债。

### 2.4 生产力增长与文明进步

按当时生产力、社会成本、民间弹性、人才流动、反馈和文明进步判断方向。国家控制、汲取、库藏或登记规模不自动为正，高压强化须审净后果。

### 2.5 本人窗口与后世影响分离

归责本人实际行动及授权结果；交班看离世、退位或失权时留下什么，后世承继只验耐久，不用王朝寿命替代，也不回填后继者独立变化。

### 2.6 事实去重与机制辐射

同一原因可产生不同结果，但同一结果只计一次。每项分别证明对象、窗口、实际结果与归责，不能用机制存在代替结果，也不能靠改名、换轴或多源转述重复计分。

跨轴相关、同时高低或总分离群，只触发证据、归责、公式和去重检查，不证明重复计分；不能为贴合名望、缩小分差或配平分布调分。具体边界见§3。

军损认定按[共同合同](../证据规则/军事成本评估合同.md)，各项独立换分；第三项排除不等于第一项成本为0。S1是扣成本后的0—240净分。

### 2.7 史料依据、最小充分证据与置信度

采用最小充分证据。置信度看来源可靠性、命题直接性、时空代表性、归责和同尺度反证，不按条数、篇幅、书目数量或总评措辞判断，也不乘分。

可定位宏观总评若匹配本人窗口、对象和范围，直接回答本项结果且无同等级矛盾，可独立作主锚；多源互证是增强项，不是统一硬门。不能外推原文范围或把一句总评拆成多个强锚。某一命题已证可靠时，整体材料稀疏不自动降档、降置信或打开相邻档区间。

合法替代解释、未决缺口和数值情景按[不确定性与敏感性合同](../证据规则/裁决不确定性与敏感性合同.md)处理；权重情景不代替证据解释，未量化不等于无不确定性。考古、民间杂记尚未系统整合，结论限于现有证据范围。

## 3. 重复结算边界

| 易冲突项目 | 主要边界 |
|---|---|
| 第一项创业 vs 第二项制度 | 第一项看取得政权过程；第二项看正式统治期的制度建设与运行。 |
| 第一项创业战争 vs 第三项军事 | 第一项独占创业、统一和政权取得战争的成果与成本；第三项A/B/D只读第一项闭合后的独立军事链。创业战争若发生在可评价政权或实际主政窗口内，可仅作为第三项C的能力佐证。 |
| 第二项制度持续性 vs 第四项文明遗产 | 第二项只看国家机器在交班与后世是否继续运行、被继承或被修正；文化、教育、思想和共同体遗产归第四项。 |
| 第二项行政治理 vs 第二项政权交接 | 行政治理看日常国家机器；政权交接只看交班安全与断裂风险。 |
| 第二项民生经济 vs 第二项社会恢复 | 民生经济看统治期绝对结果；社会恢复只看本人窗口内已实现的净恢复。 |
| 第二项民生经济 vs 第三项军事成本 | 第三项完整计入主动进攻和被动防御的客观军事成本；第二项DA按分账合同只计独立剩余民力负担。可共用动员事实推断家庭传导，不重复折算军资、军粮和军事运输。 |
| 第三项军事边疆 vs 第四项文明整合 | 第三项看安全与实际控制；第四项看认同、吸纳和共同体建设。 |
| 第四项教育人才 vs 第二项制度行政 | 第二项看国家机器；第四项看教育、选才和人才流动的文明再生产。 |
| 跨期后果 vs 当期结果 | 跨期持续性、结构锁定和修复负担只校准第二至第四项对应结果的强度与耐久性，不另设负债扣分。 |

第一项不适用不同于0，原分不直接加共同项。

## 4. 第一项：政权奠基与统一贡献及能力（240）

### 4.1 评价内容

评价建国、复国或未闭合统一进程中的本人贡献、组织与军事能力。

### 4.2 边界

适用创建、复国、共同奠基、未闭统一链后继贡献及实际独立建政后失败者；纯继承、成熟扩张或王朝内部皇权转移不适用。共同成果先按阶段、区域、节点或`shared_result_group`分账。

### 4.3 分值构成

| 子项 | 名称 | 满分 |
|---|---|---:|
| A | 统一主链客观贡献 | 120 |
| B1 | 创业难度与战略效率 | 50 |
| B2 | 创业组织与政治整合 | 30 |
| C | 本人军事统帅与战争解题能力 | 40 |
| **合计** |  | **240** |

四轴毛分扣军事成本后得到正式净分：

`S1 = max(0, A + B1 + B2 + C - 军事成本扣分)`

各子项0.1分，无名望、正统或政权类型奖励。

### 4.4 分项入口

[第一项合同](../分项规则/第一项政权奠基与统一贡献及能力/00-规则与计分合同.md)定义稳定控制、起点/对手/效率、组织和本人军事能力；[成本计分](../分项规则/第一项政权奠基与统一贡献及能力/07-军事成本计分合同.md)定义扣分；[正式结算](../评分结算/净收益/第一项政权奠基与统一贡献及能力/01-第一项政权奠基与统一贡献及能力正式结算.md)保存当前结果。

### 4.5 综合分计入公式

综合榜使用以下量：

- `S_common=S2+S3`；`M=637`为两项正向上限之和。
- `S1`为第一项扣军事成本后的正式净分，`r=S1/240`。
- `CIV4`为第四项`-67.5—+67.5`调整。

符合奠基准入者的第一项条件附加分为：

`F = 0.20 × M × r^1.25`

不适用第一项者`F=0`，不加入共同分母。

`T = S_common + F + CIV4`

基准排序唯一，以下只作离散敏感性分析，固定裁决、对象池及指数1.25：

| 参数 | 取值 |
|---|---|
| 第一项附加系数 | 0.18 / 0.20 / 0.22 |
| CIV4倍率 | 0.8 / 1 / 1.2 |
| 共同项倾斜d | -0.2 / 0 / 0.2 |

S2/S3分别乘`(1+d)×k`/`(1-d)×k`，`k=637/[387×(1+d)+250×(1-d)]`。展示9种纯附加和全部27种范围，机器保留单因素、参数及逐景名次，精度并列同基准。这不是史料不确定性、置信区间或连续界；重叠范围不表示同档，不改正式权重。

F最高127.4，CIV4总跨度135，不按个别人补回去重分。[唯一综合榜](../评分结算/净收益/00-统治绩效综合评分榜.md)只读`COMPOSITE_READY`，分别显示共同项、S1、F、CIV4及T。

治理覆盖规模和结构复杂度按`config/common/composite-governance-context.json`并列展示，只作背景，不调整状态、置信度、控制规模或能力分。现有各项已部分反映规模与压力，复杂度又可能由治理问题造成，统一加权容易重复奖励或二次折扣。只有出现跨时代可比、不重复且参数敏感性低的独立机制，才重新讨论计分。

## 5. 第二项：治国净收益（387）

### 5.1 评价内容

评正式治理与交班的制度、行政、民生、财政和社会结果。

### 5.2 边界

与创业、军事、文明和人格的分工按§3。

### 5.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| 治理手段AB块 | A制度建设与B1行政执行互补合成 | 120 |
| 治理手段B2 | 反馈纠错与权力约束 | 45 |
| C1 | 民生福祉绝对状态 | 80 |
| C2 | 经济活力与财政健康绝对状态 | 35 |
| C3 | 社会安全绝对状态 | 60 |
| C4 | 社会恢复与可归责恶化 | 最高27，最低-40 |
| 交接质量D块 | D1行政连续性与D3权力交接等权合成 | 20 |
| **可排序合计上限** |  | **387** |

`第二项 = 治理手段165 + 治理结果(-27.5—202) + 交接质量20`，范围`-27.5—387`。方向卡指数不是独立分值；换算见[制度行政合同](../分项规则/第二项治国净收益/制度行政/00-规则与计分合同.md)，D1/D3等权及低侧封顶见[交接合同](../分项规则/第二项治国净收益/政权交接稳定/00-规则与结算合同.md)。

### 5.4 分项简述

- A评制度建设与接收；B1评行政可靠性；B2评反馈纠错和权力约束，具体档界见制度行政合同。
- C1家庭、C2经济财政、C3社会安全按主态固定分及L有限修正；C4评归责恢复/恶化，见[财政民生合同](../分项规则/第二项治国净收益/财政民生/00-规则与结算合同.md)。小政权不折扣。
- DA只计去重后的主动民力负担，准入、推断、档表见[分账合同](../分项规则/第二项治国净收益/财政民生/01-主动民力成本与军事分账合同.md)。
- D1评退出后行政连续，D3评实际权力交接安全，见交接合同。

## 6. 第三项：军事与边疆净收益（250）

### 6.1 评价内容

评正式统治期的战略安全、边疆控制、军事体系及军事成本收益。

### 6.2 边界

第一项已消费军事链排除；民生与文明后果归第二/第四项。

### 6.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 战略威胁状态与本人可归责变化 | 60 |
| A2 | 安全边界状态与本人可归责变化 | 60 |
| B1/B2/B4 | 控制规模与战略价值，经交班成熟度修正 | 80 |
| C | 军事体系有效性 | 50 |
| D | 军事成本固定扣分 | 不独立加分 |
| **合计** |  | **250** |

A按起终状态与归责，B按规模价值成熟，C按体系表现，D供全局固定成本；普通成本与ML取高。执行[国防合同](../分项规则/第三项军事与边疆净收益/国防安全/00-规则与结算合同.md)及[合并扣减合同](../分项规则/第三项军事与边疆净收益/00-合并计分与军事扣减合同.md)，最终总分四舍五入：

```text
第三项 = A120 + B80 + C50 - max(cost_debit, |military_net_loss_penalty|)
```

### 6.4 分项简述

A1威胁、A2边界；B1实际空间、B2战略价值、B4交班成熟；C军事体系的兑现、持续与可靠，无实战窗口按[C合同第三节](../分项规则/第三项军事与边疆净收益/军事体系有效性/00-规则与计分合同.md#三未知无实战与样本门禁)核验继承能力，不因未受检验归零；D成本。各轴不以名望、战争数量或他项成果替代事实。

## 7. 第四项：文明与国家整合收益（-67.5—+67.5有符号附加项）

### 7.1 评价内容

### 7.2 边界

国家机器、军事控制各归第二/第三项；个人才艺或内部娱乐须另证公共结果才准入，不要求服务行政，不重复计遗产。

### 7.4 分项入口
