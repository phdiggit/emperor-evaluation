# 皇帝人物画像评估体系合同

> `FORMAL-V3.0 / NINE-AXES-FORMALLY-SETTLED`。九轴中八轴评价能力，C5评价权力运用风格与克制。

## 1. 目标与上位边界

画像回答：**这个人在真实经历中，哪些能力强、哪些能力弱，怎样使用权力？** 看反复表现和阶段变化，不算一个笼统的总分。

共同边界见[综合评价体系合同](皇帝综合评价体系合同.md)。

### 1.1 与其他体系及归档证据的关系

可以复用其他评价中的事实、史源和本人责任，但要重新回答本轴的问题，不能照搬得分。外部排名只提供核查线索。

已退役第五项只可作为[归档事实与史源](../../archive/README.md)使用，不是当前评价项目，也不用于换算画像档位。

### 1.2 评价对象与就绪状态

人物名单与身份读[规范人物池](../../config/common/canonical-ruler-pool.json)，以`ruler_id`连接。画像可以独立发布，不必等待统治绩效达到`COMPOSITE_READY`。

| 状态 | 含义与发布方式 |
|---|---|
| `PROFILE_READY` | 九轴均已判断是否适用，适用轴完成本轴要求并发布；不适用轴留空。 |
| `AXIS_READY` | 某一轴已完成适用性与裁决，可单独发布。 |
| `EVIDENCE_LIMITED` | 已完成声明范围内的检索，材料只能支持有限判断；给档并说明置信度和限制。 |
| `UNRESOLVED_EVIDENCE_GAP` | 关键事实或冲突未判清，仍在工作中，不进入正式雷达。 |
| `NOT_APPLICABLE` | 人物确实没有本轴所评价的适用机会，不给分，也不算零分。 |

适用轴达到最低证据要求后，给出G档、档内位置和数值，不因缺料默认普通档。单轴允许“证据不足、无档结案”的，计入完成覆盖，但档位、分数和雷达留空；它与不适用或能力低下不同。

## 2. 共同证据合同

### 2.1 最小充分人物行为单元

一项证据至少说清：当时是什么情境、本人有哪些选择、实际做了什么、产生什么结果，以及依据在哪里。注明本人权限、团队作用、反馈、反证和未决问题。

事件使用稳定`profile_episode_id`；同一问题的连续经历可归成“父链”，使用`parent_id`或`parent_ref`，不要混用两类ID。记录主评价轴、允许辅助的轴及去重理由。已经核实的公共事实和归责直接复用，但成果大小不能代替本人能力证据。

#### 跨轴落实深度与受阻重组证据门

需要执行结果来证明能力时，区分命令、局部执行、持续运行和失败后恢复；旧记录可在`basis`中说明相同意思。

| 状态 | 含义 | 证据作用 |
|---|---|---|
| `ORDER_ONLY` | 只有诏令、授权或目标宣示，未见实际运行 | 只能证明意图或一次选择，不能单独支持持续能力 |
| `PARTIAL_DELIVERY` | 已有局部执行，但范围、持续性或关键环节未闭合 | 可验证有限兑现，必须保留外推限制 |
| `SUSTAINED_DELIVERY` | 跨时间或跨层级持续运行并产生可归责交付 | 可以增强本轴生命周期强度，不另计组织能力分 |
| `RECONFIGURED_AFTER_FAILURE` | 阻力或失败到达后重新配置责任、资源或路径并恢复交付 | 在原主轴证明恢复；若另有独立多中心组织命题，可按M5边界复用过程，不重复消费原命题 |

说明执行依靠既有组织、臣下、本人反复补救，还是稳定分工。执行事实先用于原能力轴；只有另能证明独立组织能力时才用于M5。长期制度设计归C4，不因“执行得好”再加一份C4。

### 2.2 能力事件准入与生涯阶段

画像看全生涯中与本轴有关、且本人确有选择和责任的经历，不按即位、称帝、亲政或退位时间截断。从属和有限授权阶段也可以使用，但只能评价本人实际控制的部分。

`actual_power_window`是其他体系使用的身份信息，画像不要求携带、同步或展示，也不能据它筛掉证据、定档或判断覆盖。各轴同样不能另设时间窗口决定事件去留。

阶段只解释当时角色、权限与机会，不预定正负。使用以下代码，不要求每人凑齐所有阶段：

| 阶段代码 | 含义 | 主要边界 |
|---|---|---|
| `FOUNDING_SUBORDINATE` | 开国或争位中处于他人最高权力之下 | 只计本人真实控制的府署、战区、属官和承诺；国家级联盟、册封和资源分配不得自动归本人 |
| `FOUNDING_PRIMARY` | 本人已是开国最高责任中心 | 可评价跨区域联盟、国家资源配置和政权级承诺 |
| `SOVEREIGN_CONSOLIDATION` | 取得最高权力后的中枢重组期 | 重点观察旧敌吸纳、利益重配、制度接管和权力边界 |
| `MATURE_RULE` | 主要统治与压力复验期 | 重点观察能力能否跨对象、跨事件持续成立 |
| `LATE_SUCCESSION` | 晚期、储位、退出与交接期 | 重点观察联盟信用、纠错、功臣退出和主模式是否反转 |

没有机会不算失败；一个狭窄场景也不能代表全部能力。从属阶段的成功要说明能否推广到其后主政。

### 2.3 方向中立检索与生涯覆盖

先看材料属于哪种能力，再判断正负和本人责任。尽量观察不同阶段、对象及收到反馈后的选择，缺资料就说明限制，不猜正面或负面。各轴自行说明什么情境最有判断力，不统一要求高压经历。

`material_intensity`表示经历的持续性、作用范围和是否形成稳定机制，不是分数：

| 强度 | 含义 | 在全生涯裁决中的作用 |
|---|---|---|
| `MI1_CASE` | 单一对象、单次命令或窄场景个案 | 证明能力或行为曾出现，可限制档内位置；通常不能单独定义长期典型模式 |
| `MI2_LIFECYCLE` | 对同一问题闭合“选择—反馈—维持/纠正—结果”的完整生命周期，或同一机制有实质复验 | 可以建立阶段性模式，但仍须说明能否迁移到其他对象或压力 |
| `MI3_SUSTAINED_SYSTEMIC` | 跨多年、跨对象持续运行的制度、程序、授权结构或稳定行为模式，并实际约束或放大本人权力 | 高于普通个案；应作为全生涯典型模式的主要锚点，多个`MI1_CASE`不得靠数量机械抵消 |
| `MI4_CROSS_PHASE_SYSTEMIC` | 制度性或稳定机制跨主要阶段、不同压力和不同对象持续成立，且有反例与恢复复验 | 可支撑历史级或强长板/短板比较，但仍须满足本人归责和轴内语义 |

先比较持续程度和覆盖，再定档。一件极端事件通常仍是MI1；有完整过程或独立重复才到MI2，严重伤害本身不能抬高持续性。个案可以揭示重大短板，但要推翻MI3/MI4的总体判断，须证明它改变了同一核心行为模式（`PATTERN_CHANGING_COUNTEREVIDENCE`）。

材料强度、本人贡献、效果稳定性和过程充分度分别记录。臣下主导不使整段经历变弱，但会限制归给本人的能力；只有结果汇总、看不到选择和执行过程的，最高MI1并说明限制。

### 2.4 归责与成果边界

权力、国力和臣下成果都不能直接当作本人能力。共同决策、团队行动和接续成果按实际角色分清；分不清时限制判断，不把全部成果归给统治者。

负面事实同样核对本人责任、是否收到反馈、当时是否有可行替代选择，不凭失败或名望直接定罪、免责。

### 2.5 跨轴去重

每个事件设一个主评价轴。只有另能证明不同能力或行为时，才辅助其他轴，并记录`secondary_projection_reason`。

战略优先级归C1，认知更新归C2，个人用人归C3，集团合作归M4；军事归M1，外交归M2，制度设计归C4，组织执行归M5，强制权力及公共特权归C5。民生、财政或其他成果只能验证相应能力，不能直接换分。

外交的特殊准入见[M2高压亲临规则](../分项规则/人物画像轴/M2-外交博弈与对外联盟能力.md#高压亲临外交)和[和亲规则](../分项规则/人物画像轴/M2-外交博弈与对外联盟能力.md#和亲结果门与因果门)。

### 2.6 轴内证据等级、适用性与置信度

每轴独立判断证据等级`axis_evidence_level`，不能因某个人整体材料多，就认为九轴都证据充分。

| 等级 | 含义 | 对适用人物的发布要求 |
|---|---|---|
| `E0` | 关键本人行为链仍未定位，或最低证据范围尚未完成 | 工作中，不得验收；继续补证 |
| `E1` | 只有一个或少量闭合情境，或材料偏于单一机制、阶段或对象 | 给低置信度档位，明确推断边界 |
| `E2` | 有多个独立情境，或一条足以展示变化的完整生命周期 | 给中置信度档位，列未覆盖范围 |
| `E3` | 主要命题已有代表性情境，归责、反例和限制已完成必要检查 | 可给高置信度档位；不预设档位高低 |

独立情境须在对象、任务、阶段或压力上实质不同。同一政策、战役或人物的重复记载先合并。

#### 材料范围与单向证据风险

不设九轴通用的材料数量要求。G4/G5、证据明显偏向一面或范围过窄时，才定向复核，说明实际检索范围、缺口以及补到什么可能改变结论。

复核可记`COVERAGE_CLOSED`、`COUNTEREVIDENCE_FOUND`、`MATERIAL_DENSITY_LIMITED`。最后一种只限制置信度和结论范围，不自动改档，也不要求补写完整生涯史。

| 输出模式 | 允许内容 | 档位要求 |
|---|---|---|
| `UNRESOLVED` | 尚未完成的缺口与检索范围 | 仅工作中使用，不得视为轴完成 |
| `EPISODE_TAG` | 单一具体事件、有限外推、阶段和限制 | 适用人物仍发布低置信度G档和数值 |
| `BOUNDED_PROFILE` | 已观察机制、适用阶段、变化范围和缺口 | 适用人物仍发布中置信度G档和数值 |
| `FULL_GRADE` | 全生涯模式、阶段画像、档位和限制 | 发布高置信度G档和数值 |

高置信度FULL_GRADE须有本人行为、归责和来源，说明典型表现、短板及证据范围，且无影响档位的未决冲突；不要求穷尽生涯或所有反例。单轴特有的高档条件不能扩成全池通读义务。

### 2.7 机械筛选与语义裁决隔离

程序可以按人物和轴连接材料、找重复或提醒缺口，不能凭关键词、条数、篇幅、分项排名或名望定档。

按[全池工作流](../分项规则/人物画像轴/01-画像全池工作流合同.md)建立稳定任务ID、整理可用材料，再判断适用性和本人表现。正式记录只留实际采用的依据、范围及限制；探索候选放工作矩阵，不阻止其他已完成记录发布。跨轴冲突和材料偏窄按触发条件复核，不每次全部重查。

## 3. 八个能力轴、一个行为风格轴与辅助标签

现行能力轴包含M5组织驾驭与执行编排；九轴正式入口由项目配置登记，其他项目同名代码不受影响。

- **八个能力轴**：M1、M2、M4、M5、C1、C2、C3、C4，分别评价军事、外交、内部联盟、组织编排、战略、学习纠错、识才授权和制度设计能力。
- **一个行为风格轴**：C5评价权力运用风格与克制，不归入能力轴。

九轴均保留各自独立裁决与雷达值；[九轴结算汇总](../评分结算/人物画像/九轴结算汇总.md)并列展示，不把C5解释为能力高低。

正式展示和发布顺序固定为`M1、M2、M4、M5、C1、C2、C3、C4、C5`。文档或生成物中的历史文件编号只用于定位文件，不定义轴顺序。M3已退役并[归档](../../archive/README.md)，不再发布档位或雷达值，其代码不重新分配。

| 代码 | 维度 | 核心问题 | 主要既有入口 |
|---|---|---|---|
| M1 | 军事判断与统帅能力 | 本人在战争选择、战区统筹、临阵解题和失败处置上达到什么能力层级？ | 战役登记、武将人才等级及既有军事裁决 |

| M4 | 内部政治联盟与集团整合 | 能否在实际权限内吸收统治共同体内部的异质集团、配置利益与地位、维持政治信用并处理联盟退出？ | 全生涯重大集团关系、团队与社会整合行为链 |
| M5 | 组织驾驭与执行编排 | 能否拆解复杂任务、配置多责任中心并协调监督、替补恢复，使组织持续自主执行？ | C3、C4、B1正式事实与独立组织过程史料 |

### 3.2 辅助特质与欲望自控

勤政、韧性、欲望自控和爱好用`trait_code`标签，只记录有充分证据的显著特点，不给G档或百分值，也不为没材料的人填“普通”。

标签保存方向`POSITIVE / NEGATIVE / MIXED`、强度`NOTICEABLE / STRONG / EXTREME`、阶段、行为与反证、置信度和史源。

私人爱好通常中性。只有长期挤占核心职责、异常耗费公共资源、扭曲重大判断，或收到伤害反馈后仍持续沉迷，才作负向标签。强正向须证明有充分特权与诱因时，仍跨阶段主动克制、不转嫁成本且确有成效；一般俭朴或一次拒贡不够。

真实学习成果可辅助C2；强制征发和公共特权归C5。生活自律与权力失范可以并存，不能互相抵消。

## 4. 档位、百分制与置信度

### 4.1 六档主尺度

先按实际表现定G档，再查表得到数值。证据等级决定置信度和说明范围，不直接决定能力高低。

| 档位 | 语义 | 核心门槛 | 百分区间 |
|---|---|---|---:|
| G5 | 历史级长板 | 在本轴主要机制和主要适用阶段呈现历史罕见的典型表现；困难情境、普通情境、失误与恢复共同构成后仍保持上沿 | 90—98 |
| G4 | 强长板 | 全生涯典型表现明显高于合格统治者，但覆盖、稳定性、可迁移性或下沿尚未达到历史罕见模式 | 75—89 |
| G3 | 合格或中性 | 多数诊断情境可用，存在清晰长短项但不形成稳定强长板或强短板 | 55—74 |
| G2 | 明显短板 | 多数诊断情境显示受限、失衡或依赖外部补救，仍有可用机制或阶段 | 35—54 |
| G1 | 强短板 | 主要机制或多数适用阶段反复失效，偶有成功不足以改变典型模式 | 15—34 |
| G0 | 历史级负面 | 本轴主要机制和适用阶段呈现罕见、稳定且难以恢复的失能模式 | 0—14 |

LOW/MID/HIGH看典型表现、短板、失误后恢复及阶段一致性，不按材料数量提高位置。98是一般可达上限，100是理论上限，不给样本第一名自动满分。

九轴统一使用下列确定性投影，不允许各轴为相同G档和档内位置另设百分值：

| 档位 | LOW | MID | HIGH |
|---|---:|---:|---:|
| G0 | 2 | 7 | 12 |
| G1 | 18 | 25 | 31 |
| G2 | 38 | 45 | 51 |
| G3 | 58 | 65 | 71 |
| G4 | 77 | 82 | 87 |
| G5 | 91 | 94 | 97 |

百分值只按表投影，不反推G档或按事件数/分项分数微调。

M2另有经终局核对的“未显示外交能力”证据类别，使用E投影并保留独立的认定依据；不等同本表已证实历史级失能的语义，具体准入及发布限制见[M2合同](../分项规则/人物画像轴/M2-外交博弈与对外联盟能力.md#终局未显示能力)。

理由说明本人怎样选择、表现是否稳定、能否应对不同情境及主要限制，不从正负条数或最高MI直接推档。

### 4.2 全生涯模式裁决与异常情境

同一问题的连续经历合成一次判断，成功、失误、反馈和恢复一起看，不拆成互相封顶的正负记录。

总体定档要回答：主要能力通常表现怎样，在哪些阶段稳定或反转；最差表现是偶发还是常见；最好表现能否在不同情境重现；未观察部分是否可能改变结论。不把“找到一个强反例”写成自动封顶算法。

`G4-HIGH`（85—89）通常需要两个独立的强表现过程，或MI4的亲临完整经历加独立复验；关键情境可接近历史级，但全生涯的主要机制、阶段或短板仍未到G5。

- `G5-LOW`（90—92）：总体达到历史罕见水平，但范围、稳定性、短板或推广性仍有限制。
- `G5-MID`（93—95）：主要能力与适用阶段普遍很强，失误后的恢复与总体能力相符。
- `G5-HIGH`（96—98）：覆盖广，典型表现与较差表现都很强，长期稳定，未决范围很小；不要求零错误。

阶段变化明显时，同时给阶段和总体判断。某一阶段G5不自动等于全生涯G5，总体G4也不抹去阶段长处。

### 4.3 置信度与下限

适用轴发布档位、位置、百分值、证据范围与置信度，并解释典型表现、短板和阶段变化。字段使用`axis_grade`、`position`、`score_100`、`output_mode`、`confidence`和`score_status`；具体职责见[共同数据合同](../分项规则/人物画像轴/00-共同数据与发布合同.md)。

`confidence`为HIGH/MEDIUM/LOW；`score_status`为FINAL/EVIDENCE_LIMITED。UNRESOLVED只用于未完成的工作记录。EPISODE_TAG或BOUNDED_PROFILE仍给人工判断的单点档及限制，不因缺少另一方向证据就默认G3。

### 4.4 同链语义冲突复核

不同体系分数或名次不同，不必复核。只有**同一人、同一阶段、同一事实，评价的也是同一问题，却作出相反判断**，且无法用责任、阶段或新证据解释时，才复核。

| 结果代码 | 含义 |
|---|---|
| `NO_TRIGGER` | 只有分数或名次不同。 |
| `CONSTRUCT_SEPARATED` | 实际评价的是不同问题，如能力与结果。 |
| `ATTRIBUTION_SEPARATED` | 本人、团队或前后任的责任范围不同。 |
| `PHASE_SEPARATED` | 使用的时期不同。 |
| `EVIDENCE_DELTA_EXPLAINED` | 画像使用了另一体系没有采用的新证据。 |
| `SAME_CHAIN_REVIEW_REQUIRED` | 确有同一问题的相反裁决，须核查事实与归责。 |
| `EVIDENCE_CONFLICT_UNRESOLVED` | 复核后仍有冲突，该轴不能标FINAL。 |

不为让不同体系分数靠拢而调档。
