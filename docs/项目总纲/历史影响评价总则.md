# 历史影响评价总则

> `FORMAL-V1.2`。历史影响、人物画像、净收益是三套并列评价体系。本合同受[皇帝综合评价体系合同](皇帝综合评价体系合同.md)约束。历史影响不属于净收益四项或九轴画像，不进入净收益总分、九轴雷达或综合榜破平。

## 1. 评价对象与问题

评价具体人物实际改变了多大历史空间、留下多深多久的结构后效，其中多少依赖本人，以及是否形成被后世实际使用的政治范式。影响量级不等于功绩、能力、善恶或知名度。

| 体系 | 回答的问题 |
|---|---|
| 净收益 | 实际留下多少净收益或净损害？ |
| 人物画像 | 能力结构、行为风格与治理画像如何？其中八轴评能力，C5为独立行为风格轴。 |
| 历史影响 | 实际改变了多少历史；删除本人后，哪些核心路径会以不同方式、强度或时间发生？ |

正式主池读取规范人物池的`INCLUDED`对象，以稳定`ruler_id`连接事实。附件中已存在的池外特殊历史对象单列补充样本，不计入主池人数、分布或覆盖率，不因此修改其他体系准入。后续新增主池对象先走规范池准入。帝号、性别、摄政或实际奠基者身份不直接决定档位。

## 2. 最近可行反事实与归责

从本人首次足以独立改变路径的关键行动窗口起删除本人，而非一律从即位开始。规范池窗口用于身份对齐；反事实删除点须由具体主链说明，即位前独立作用、断续掌权、共享与失权阶段分别处理。

保留删除点前已经存在的国力、疆域、财政、军队、制度、技术、社会结构、其他人物与时代趋势；不顺带删除家族、集团或前代平台。只有明确因果才能改变其后状态。默认替代者是当时政治条件下可合理占据相近位置的普通人，不使用完美明君、已知天才或刻意安排的失败者。具名候选的权限、既有表现和可行方案用于约束反事实；同类高能力者能否复制仅作稳健性检验，不替换默认基线。

只消费直接变化、有明确链条的二级变化及少量已形成结构锁定的长期后果。因果链越长，推断越谨慎。趋势降低不可替代性，但不能抹去时点、方式与制度组合差异；延迟只有足以改变战争、继承或结构路径时才构成实质影响。

比较对象是政治功能、组织方式、空间格局与时间路径，不要求替代者复制相同姓氏、国号、亲属或事件名称。“没有本人就没有同名政权”不构成高因果证据；尚未找到替代者也不等于证明不存在。每人说明删除所对应的事件/窗口及保留条件；缺少精确日期可用可定位事件，不制造伪精确年份。

归责优先核对：他人曾失败且损失已发生，本人作出非显然选择后同一瓶颈被解决；本人阻止现实危险路线；本人长期控制关键决策接口；臣下独立完成；仅名义批准。亲临不是必需条件，用人授权也不自动继承臣下全部信用。最高权力者只领取专业文明成果的入口、资源与组织信用，内容原创另归专业作者。

## 3. 四维定性标尺

每人保留1—3条宏观主链，再分别裁四维。战役、制度和外交事件并入相应主链，不按数量累加。四维均使用`S+、S、S-、A+、A、B、C`；除范围只发主档外，其余维度可附上沿/下沿说明。不设分数、权重或平均值。

四维与公众总档的每一档都须有现实可满足的条件。最高档表达已可观察的极高量级，不预留“比所有已知人物更高”的虚顶；空档不等于不可达，也不要求每档必须有人。

基建工程不单独构成历史影响主链。只有国家结构或宏观历史转型已独立成立时，工程才作其过程证据；不得凭规模、存续或后世使用独立抬深度，也不得将工程改称“体系”绕过此门。全池同样适用，不设人物特例，不据此扩建工程清单。

| 档位 | 影响范围 | 深度与持续 | 个人因果 | 范式与示范 |
|---|---|---|---|---|
| S+ | 主体核心与多个主要外围政治空间共同发生极大规模重组，代表本评价对象中可由史实证明的最高覆盖量级 | 多域国家/文明底层结构跨多轮改朝换代持续锁定 | 删除本人，核心足迹大部消失或根本换轨，现实替代者难在相近窗口复制 | 系统政治模板跨朝、跨环境，被多代最高权力反复实际使用 |
| S | 全国国家整体转型并伴随重要外部空间变化，或多个大型政治空间广泛重组；强于单一全国/区域变化，但整体覆盖组合尚未达到S+ | 多个基本接口形成跨朝或超长寿命政治结构的长期组合 | 国家级核心链明显依赖本人，但重要部分仍有独立结构、团队或替代支撑 | 多朝或多个独立最高权力反复接收，并影响实际政治论证或行为 |
| S- | 中国核心政治空间或同量级政治空间大部实质变化；也可由跨多个大型区域国家的实际重组达到同量级，但未过S的整体门 | 多条结构或一条外溢多领域的核心路径跨多代约束后继 | 关键转折归责高，但相当部分仍可由现有结构、团队实现 | 多次独立最高权力接收，跨代清楚，主题或用途较窄 |
| A+ | 多个大区域或全国重要领域出现实质变化；中枢调整须另证其广域权责或执行影响 | 重要结构跨多个统治周期，或单一领域深远遗产 | 本人选择、维持或授权重要，趋势与团队共享显著 | 一个高质量最高权力接收闭环，并有重复使用或辅助接收 |
| A | 大型王朝关键中枢或重要部分、主要区域国家、多个重要区域的实质变化 | 一代至数十年的结构后效，后继较易逆转或重组 | 本人确有作用，主要方案、执行和结构动力高度共享 | 一个可信的朝廷实际使用案例，或较薄的政治引用 |
| B | 重要区域、制度领域或精英政治圈层变化 | 短期偏转，退出后较快回归，仍有过渡余波 | 主要批准、承接或名义领导，换人后大体仍发生 | 主要是名望、史学文学形象，尚无稳定接收闭环 |
| C | 局部地区、单一集团或短窄领域 | 核心形态随本人或短命政权消失，稳定结构后效不足 | 本人可分离作用很弱 | 未建立有效传播闭环 |

**范围**看实际改变量，不看继承疆域、峰值地图、远征最远点或帝号。全国实施单项政策通常只到A+；核心大部未重组，多个外围变化也不能自动升S-。范围高低与影响正负无关；臣下共享信用另在个人因果处理。

范围复核分别列出**基线、实际变化、未发生的扩大解释**。实际变化须指向控制与服从关系、政治主体存灭、国家基本组织或对外秩序中的具体约束。军事到达、交战、使节往来和共同名义不等于所涉全域都被重组；臣下完成的真实变化仍计范围，其个人信用另分账。一次远征造成的实际破坏可以计入，但不连同未改变的整个文明空间计入。

仅因更换者位居全国中枢、涉及帝位或任免最高官员，不自动成为全国范围；须指出实际改变的责任关系、制度对象或政治空间。中枢人员与亲属组合变化而未另证广域变化者，按已观察的中枢/精英政治范围裁判。

直接改变国家关键中枢或继承接口可形成A；普通个别任免、集团内部变化不自动达到A。无广域执行证据时，不从中枢地位再推成A+。

高范围必须比较**改变覆盖面与改变程度的整体形状**，不数国名、方向或大陆。核心承接而外围有限改组通常为A+；达到S-须证明合并后的实际改变量确与全国核心尺度可比，不能仅因跨域获得例外。S+是历史实例能够达到的最高量级，不要求改变全球或超越已知最强对象。各档均须有现实可满足的条件；空档只表示当前样本尚未命中，不得另设永远高于实际案例的门槛，也不按人数或名望填档。范围只发布主档，边界理由写入事实说明，不使用孤立的“上沿/下沿”标签。

第一项A控制信用、第三项控制账可定位统一链、外围增量与继承基线，但二者不相加、不换范围档。第一项包含个人分账，第三项区分起点、净变化、交班存量与跨项扣除，均不得与历史影响覆盖面混用。范围不是只计净扩张：失控、崩解和制度重组仍须独立核对，不能用净减或统治短暂自动抹除。

**深度**看退出后可识别结构如何约束后继，不按在位年数、善后耗时、物质遗产寿命或王朝总寿命换档。单一领域原则上不独撑S-以上，除非外溢多个国家基本接口；S+同时要求多域底层化与超长持续。前制与共享设计不反向压低已真实形成的深度。短命政权可以留下长期骨架；长任期也可能退出即回摆。

跨过一次交班不单独证明A+，A+也不要求跨朝；单一领域的长期承接与用于总档的共同足迹分开判断。S的超长寿命结构组合须分别定位多个基本接口的承接，不能由一个机构长寿外推整组；同朝承接不自动排除S，跨朝出现同名机构也不自动达到S。

长制度谱系只计本人新增、重构或恢复且被后继实际接收的部分；法典、官制等文本相承不等于整套制度归于本次修订者。后继独立改造须标明，不把整条传统的寿命逐人重复分配。

**个人因果**只裁归责纯度，不因作用局部、持续短或没有独立建国而代扣。创建、挽救、破坏均可高度个人化，但不可替代性不能凭空制造影响规模。

创建、维持与破坏使用同一持续性标准：指出本人退出后仍在运行的结构、承接者及独立重建的截断点。后继同姓、沿用国号或国祚延长不单独抬深度；灾难影响也不因新王朝出现而自动消失。工程及其他未准入材料不加入深度候选；合格主链的持续差异与用于基础档的共同足迹分别说明，不把“不能拼总档”误写为长期事实不存在。

**范式**须闭合“可识别政治内容→稳定载体→后世最高权力实际接收”。A+须有明确接收，S-以上须多次独立接收；名声、治世称号、史家评价及单纯制度承接不足。正反模板同权，祖宗之法须剥离制度延续，只计政治规则的实际援用；不得回填深度。

区分已定位接收、只有形象传播与尚未定位接收；未定位不等于历史上不存在。高档须列接收者、载体及实际用途；同一接收者的多次引用不拆成多个独立接收者。已有结构继续运行属于深度，以该结构或人物名义论证、限制或改变后继选择才属于范式。

## 4. 总档裁判与公众标签

先用范围与深度裁内部基础量级，再作个人因果分账和有限范式修正，最后映射公众标签。下列规则是语义裁判边界，不授权程序按四维自动裁档。

**主链共现是前提：**广度与纵深必须来自同一条或紧密相连的核心足迹；不能将广而短的事件与局部而长的遗产拼档。个人因果抬升也必须作用于该核心足迹。范式可独立修正，但仍受主维度上限约束。

| 内部基础带 | 范围—深度组合 |
|---|---|
| S+ | 范围S+且深度至少S；或深度S+且范围至少S- |
| S | 范围至少S且深度至少S-；或范围至少S-且深度至少S，且未达上一档 |
| S- | 典型S-/S-；S/A+、A+/S等失衡高位组合须结合共现审查 |
| A+ | 典型A+/A+、A+/S-、S-/A、A/S- |
| A | 典型A/A、A/A+、A+/A、S-/B |
| B | 典型B/B、B/A、B/A+、A/B、A+/B、S-/C |
| C | 范围与深度均局部、短暂 |

表中未列的组合回到共同足迹裁判，不插值、不取字母平均。亡国型S-/A+若长期新秩序主要由独立胜者建立，先按A+基础审查，不拼成S-。

逐人保存已裁基础档、实际支撑该档的主链和因果/范式修正理由；若偏离典型组合，须写明共现差异，不从最终总档倒推基础档。程序只能检查这些字段与已裁标签，不替代人工判断。

范围S-/深度A+一般先按A+基础审查；若要取更高基础，必须另证同一核心足迹的广度与长期结构同时达到该语义，不得靠原有范围标签或个人因果倒推。范围改判后复核基础、共现与公众总档，其余三维只因本维新证据改判，不作补偿调整。

- **个人因果修正：**S+可上调一档；S只确认上沿，不自动跨档；S-/A+原则维持；A对高于A的基础原则降一档，A及以下不机械再降；B/C原则至少降一档。
- **范式修正：**S+/S在基础至少A时可升一档；因果已抬至硬上限不得重复抬升。S-主要将基础A推到A+，或确认更高基础上沿。A+只补回一次因果折扣或确认边界，不独立突破主维度；A/B/C不抬档。
- **内部总档上限：**S+须基础至少S；基础仅S时因果原则须S+，基础已S+时因果至少S-。S要求两个主维度至少S-，基础S-上升须因果S+。S-原则要求两主维度至少A+，基础A+上升须因果S+。深度B最高A+，深度C最高A；范围A最高A+，范围B及以下原则不得进A+。

S+还必须具有长期结构主链、可约束的重大反事实分叉，完成趋势与共享信用分账，并提出最强可替代/高估反论证。范式不得替代基础或归责，低置信度不发布S+；不设人数配额。

| 内部裁判带 | 当前公众总档 | 公众语义 |
|---|---|---|
| S+ | S+ | 文明／国家主路径重塑 |
| S | S | 超重大历史影响 |
| S- | A | 重大长期历史影响 |
| A+ | B | 重大历史影响 |
| A | C | 显著历史影响 |
| B | D | 有限但真实影响 |
| C | E | 弱历史影响 |

标签迁移只作用于总档，四维字母不变。旧H档不属于现行输出。总档不得反向改写四维；异常先查范围/深度串项，再查共现、个人因果与范式。

## 5. 连续链、存亡与共享边界

- **前驱—完成者：**分别识别政治主体创建、空间增量、国家形态与稳定结构。后继只验证前驱留下的结构，不反投后继统一、疆域、文明产出与王朝寿命。正式受禅、改号不重复生成已被前驱控制的空间。
- **同朝连续高档：**同一链有三名以上内部A+或两名以上内部S-时，复核阶段终点、长期遗产、反事实分叉是否各自独立，并跨同量级王朝比较。密度只触发复核，不设配额；独立跃迁可以并存高档。
- **亡国—救亡：**事件规模、本人选择、外敌与前制、胜者新秩序分开。末帝不自动承担全部崩解，接盘者也不因坏起点免除主动放大责任。救亡范围与因果可以高，危机安排退出即换轨则深度仍低。后继新国家的全部寿命不得归给终结旧中央者。
- **共享与失权：**摄政、共治、名义君主分别保存实际接口与独立行动。被控制、幽禁或退位失权期间的危机不因后来复权而回填；仍实际掌权的退位者继续按真实作用评价。后任、外部征服者及自主军头的新选择设置截断点。
- **区域、恢复与灾难：**区域或跨文明主体同门槛，不因非大一统而降格。复国、新主体、长期外交秩序可形成深度，但必须识别本人结构。征服峰值、失败创业、全国叛乱不能替代长期锁定；正向遗产与灾难后果并存，不机械抵消。
- **双方与后续回应：**双边地缘安排可各有真实足迹，但共享因果不得让双方同时独占。改革回应、后继救亡、宗族谱系或专业作品的后效，须有明确连续因果；仅仅发生在某人之后不算其遗产。

## 6. 证据、置信度与发布

证据分别闭合真实事实、持续/扩散、反事实约束。优先复用现有正式事实及有效史源，不继承其他体系的档位、分数或排名。反事实没有直接史料，须用现实候选、前制推进、同时代趋同、成熟方案与后继表现约束。

置信度评价当前量级判断的稳定性，采用HIGH、MEDIUM、LOW，不转成概率。原“中高”统一以MEDIUM表达，不增设模糊第四档。HIGH须说明现实替代分支为何不改变核心量级判断；事实清楚不等于反事实确定。来源承接与底层史料重审分别声明，不以结构校验代替语义裁决。

每人保存身份与池关系、关键行动窗口说明、公众总档、内部裁判带、四维及边界说明、影响性质、置信度、1—3条主链、反事实、因果边界、范式与当前理由、来源。影响性质单列正向、负向或混合，不与量级相抵；当前裁决所需依据留在记录，历史版本与批次过程由Git保存。

主链只连接实际使用的采纳段落或已核对史料；仅能定位人物的正式入口作为相关检索入口另列，不假称主链证据。不可恢复的会话引文不得留作有效定位，须保留来源限度；重新发现影响结论的事实冲突才重开裁决。
