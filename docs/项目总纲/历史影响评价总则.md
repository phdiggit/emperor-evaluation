# 历史影响评价总则

> `FORMAL-V1.10`。共同边界见[综合评价体系合同](皇帝综合评价体系合同.md)，尺度参照和复核样本见[校准与回归锚点](../分项规则/历史影响/01-历史影响校准与回归锚点.md)。

## 1. 评价对象与问题

历史影响评价**一个人实际改变了多少历史**，不评价他有多好、多能干或多有名。

分别判断四件事：

| 维度 | 问什么 |
|---|---|
| 影响范围 | 实际改变了哪些地区、政权或国家运行方式，涉及多大范围？ |
| 深度与持续 | 本人退出后，改变还能持续多久，对后人约束多深？ |
| 个人因果 | 如果换一个现实可行的人，结果会有多大不同？ |
| 范式与示范 | 后世统治者是否真正把这个人或其治世用于政治选择、教育或鉴戒？ |

四维独立判断，不互相补分。主池使用规范人物池中的`INCLUDED`对象，以`ruler_id`连接；已有池外样本单列，不计主池统计。新增主池人物先按规范池准入，身份和帝号不决定档位。

## 2. 最近可行反事实与归责

从本人首次能够独立改变局势的行动开始，设想由当时有可能处于相近位置的普通人接替。保留此前已有的国家、家族、团队、制度、资源和时代趋势；不用完美明君或特意挑选的失败者作比较。

说明替换发生在哪个事件或阶段、保留哪些条件，再判断方向、时点和结果会怎样变化。比较实际政治功能，不要求出现相同国号、人名或制度名称。找不到替代者，不等于证明无人能替代。

只计有证据支持的直接变化、因果明确的后续变化和已形成稳定结构的长期后果。推断越远，理由应越充分；单纯慢一点，只有足以改变战争、继承或后续发展时才算实质差异。

本人、前任、臣下和继任者的作用分别说明。授权与组织可以构成贡献，但不把臣下全部成果归给最高统治者；专业内容的原创归实际作者。

## 3. 四维定性标尺

每人选1—3条最能解释其历史影响的主要过程，下文称“主链”。战役、制度和外交事件归入相应过程，不靠事件数量累加。

四维使用`S+、S、S-、A+、A、B、C`。范围只发主档，其余维度可说明处于档内上沿或下沿。最高档须现实可达，但不规定每档必须有人。

范围与深度按下表判断；个人因果和范式的档位分别见3.3、3.4节。

| 档位 | 影响范围 | 深度与持续 |
|---|---|---|
| S+ | 主体国家的核心地区与多个主要外围政治区域共同发生极大改变，或其他组合达到同等范围；属于实际史例能够证明的最高覆盖量级 | 多个领域的国家或文明基本结构，经多次改朝换代仍在约束后人 |
| S | 国家整体发生重大改变并影响重要外部区域，或多个大型政治区域合计范围明显超过S-，但未到S+ | 多个国家基本功能共同形成跨朝或超长时间延续的政治结构 |
| S- | 改变中国核心政治区域的大部，或一个超大型、多个大型政治区域达到相当范围，但未到S | 多项结构，或一项影响多个领域的核心改变，持续影响多代继任者 |
| A+ | 一个超大区域、多个大区域或全国重要领域发生实质变化；达到核心大部的相当范围则按S-审查，中枢变化须证明广泛实际影响 | 重要结构延续多个统治周期，或在单一领域留下深远遗产 |
| A | 大型王朝关键中枢或重要部分、主要区域国家、多个重要区域出现实质变化 | 一代至数十年的结构后效，后继较易逆转或重组 |
| B | 重要区域、制度领域或精英政治圈层发生变化 | 短期偏转，退出后较快回归，仍有过渡余波 |
| C | 局部地区、单一集团或短窄领域发生变化 | 核心形态随本人或短命政权消失，稳定结构后效不足 |

### 3.1 影响范围：先过有效影响门槛，再看覆盖量级

先确认发生了实际改变，再比较覆盖范围。有效改变包括政权的建立或终结、归属与服从关系变化、国家组织变化，以及实际限制了对外行动的秩序变化。军队到过、名义册封或短暂臣服，而退出后原秩序基本不变，不算有效改写。

按实际改变的部分计入：直接吞并可能改变当地治理，间接统治可能只改变对外关系；消灭政权即使没有接管土地，也改变了其存亡。实控方式不直接换分。

每项说明“原来怎样、实际改变什么、哪些范围不能算”。排除峰值地图、名义臣属和后继独立扩张。破坏、失控和收缩同样可以形成影响；正负性质及本人贡献另行判断。

#### 3.1.1 政治空间当量桥接

不同年代的地区与国家大小不同，须按既有[空间参照](../分项规则/历史影响/01-历史影响校准与回归锚点.md)比较实际覆盖，不能数国名、行政区或地图面积直接换档。

- 同一政治秩序或同一战争结果先合并去重；独立政权及不同区域秩序可分别识别。
- 只改变外部服从关系，就只计算这层变化，不假定内部治理也被重写；不设统一折扣。
- 全国某一领域的政策变化不能当作另一个政治空间，与领土变化直接相加。

S-须达到中国核心政治空间大部或相当的有效覆盖；S须在此之上有实质性的独立大型空间覆盖，或合计量级明显更大；S+须达到主体核心与多个主要外围共同改变的最高覆盖量级，或其他组合的同等量级。一个超大型空间和多个大型空间按同一尺度比较。

全国单项政策通常只到A+。改变国家关键中枢或继承安排可以达到A；要到A+以上，另证其广泛影响。普通任免不因发生在中枢就算全国变化。

#### 3.1.2 校准与回归外置

人物样本、尺度参照和当前复核名单放在[校准附件](../分项规则/历史影响/01-历史影响校准与回归锚点.md)。它们用来检查规则是否前后一致，不是人物特例，也不以某人现档倒推规则。

### 3.2 深度与持续：看退出后的结构约束

看本人退出后，哪些制度或政治结构仍在影响后人、由谁承接、何时被独立重建取代。不用在位年数、王朝寿命、工程留存或沿用同名机构直接换档。

只计本人新增、重构或恢复且被后继实际采用的部分。短命政权也可能留下长期结构；建设与破坏使用同一持续性标准。

单一领域原则上不能独撑S-以上，除非影响多个国家基本功能。S要求多个基本功能长期共同延续；S+还须有跨多轮改朝换代的多领域深层影响。跨一次交班不足以证明A+，但A+不要求跨朝，同朝的长期延续也不排除S。

### 3.3 个人因果：裁删除本人后的路径差

针对已经确认的主要改变，依次问：换人后，大方向是否仍会发生？能否在相近时期形成？政治功能与结果是否大致相同？这与影响范围和持续时间分别判断。

| 档位 | 删除本人后的核心反事实 | 边界语义 |
|---|---|---|
| S+ | 主要国家级改变大部不会发生，或国家发展根本转向；现实替代者在相近时期难以形成相近的政治功能和结果 | 创建、重建或决定性逆转，不能只凭做事多 |
| S | 至少一项关键的国家级改变很可能无法在相近时期形成或成为制度，也缺少能达到相近结果的现实替代方案 | 决定关键发展，不只是加快、加强 |
| S- | 大方向仍较可能发生，但关键组合、时点、力度或具体制度形态显著不同 | 对发展方式有很强影响 |
| A+ | 大方向及主要问题仍会被处理，换人主要是变慢、变弱或局部换方案 | 重要推动者 |
| A | 本人有可辨认作用，但主要方案、执行和推动力量由多人或既有条件共同提供 | 共同主导 |
| B | 主要批准、承接或名义领导，换人后关键作用大体仍会实现 | 本人新增作用较弱 |
| C | 难以辨认出足以改变主要发展的本人独立作用 | 本人独立作用很弱 |

改革者与创建者使用同一标准。成熟国家原有的制度、资源、人才和在行方案必须保留在比较中；改革很多、执行很强或后果巨大，本身都不能证明不可替代。

若换人后主要只是慢一点、弱一点或组合不同，原则上按S-及以下判断。S须证明至少一条国家级关键发展在相近时期很可能无法形成；S+须证明主要国家级发展大部不会出现或发生根本转向。

高档记录在`causal_review`中说明保留条件、最强现实替代方案，以及该方案为何仍达不到相近结果。不能只用“本人坚定推动”作理由。

### 3.4 范式与示范：看人物化接收，不看制度自然延续

范式必须说明：后人借鉴的是谁或哪种治国实践，通过什么载体，怎样用于最高层的实际政治或帝王教育。正面示范和反面鉴戒同样有效；一般名望、文学形象和制度自然延续不足。

可以用“去掉人名”检查：如果后世行为仍能完全由现有制度、礼仪或流程解释，通常只计深度；如果人物或治世本身是政治论证、教育或选择的重要依据，才计范式。

| 档位 | 所需接收证据 |
|---|---|
| A | 一次可信的最高权力实际使用或帝王教育。 |
| A+ | 一次高质量接收，并有重复使用、第二个独立教育场景或同等辅助证据。 |
| S- | 多次独立最高权力接收，跨代清楚。 |
| S | 多朝或多个独立最高权力反复用于实际政治论证或行为。 |
| S+ | 系统性内容、稳定专门载体或同等传播方式；跨朝、跨政治环境的多代独立接收；用于多个治理问题，且有多次可定位的实际使用。 |
| B | 主要是名望或史学文学形象，尚未证明稳定的实际接收。 |
| C | 尚未建立有效传播与接收证据。 |

同一教材、同一统治者或同一接收时期的多个故事不拆成独立接收。制度延续和人物借鉴要分别有证据，不能凭“后世仍在使用”重复提高两个维度。

记录区分`LOCATED_RECEPTION`（已定位接收）、`IMAGE_ONLY`（只有形象或名望）与`NOT_LOCATED`（尚未定位）。未找到不等于不存在；高档须列出接收者、载体和用途。

## 4. 总档裁判与公众标签

顺序是：**范围与深度确定基础档 → 按本人贡献调整 → 范式有限修正 → 映射公众标签**。由人作判断，程序不根据四维自动定档。

范围和深度必须来自同一过程或紧密相连的主要改变，不能把“广而短”和“局部而长”拼成高档。本人贡献的加档也须针对这些主要改变。

| 内部基础带 | 范围—深度组合（按无序对解释，交换范围与深度不改变结果） |
|---|---|
| S+ | 一项S+且另一项至少S- |
| S | 一项至少S且另一项至少S-，且未达S+ |
| S- | 典型S-/S-；S/A+、A+/S等组合须结合共现审查 |
| A+ | 典型A+/A+；A+/S-、S-/A+；A/S-、S-/A |
| A | 典型A/A；A/A+、A+/A；B/S-、S-/B |
| B | 典型B/B；A/B、B/A；A+/B、B/A+；C/S-、S-/C |
| C | 范围与深度均局部、短暂 |

未列组合按同一标准判断，不取字母平均；高于典型组合时，说明实际覆盖与长期影响为何共同达到该档。亡国型S-/A+若长期新秩序主要由胜者建立，先按A+基础审查。

| 环节 | 规则 |
|---|---|
| 个人因果 | S+可上调一档；S只确认上沿，不自动跨档；S-/A+原则维持；A对高于A的基础原则降一档，A及以下不机械再降；B/C原则至少降一档 |
| 范式 | S+/S在基础至少A时可升一档；因果已抬至硬上限不得重复抬升；S-主要将基础A推到A+，或确认更高基础上沿；A+只补回一次因果折扣或确认边界；A/B/C不抬档 |
| 总档上限 | S+须基础至少S；基础仅S时因果原则须S+，基础已S+时因果至少S-。S要求两个主维度至少S-，基础S-上升须因果S+。S-原则要求两主维度至少A+，基础A+上升须因果S+ |

范围与深度同权。改判其中一维后复核基础档与总档，其余维度只因本维证据变化而调整。

S+还须有长期结构影响、可论证的重大历史分岔，并认真比较趋势、团队贡献及最强替代解释；低置信度不发布S+，不设人数配额。

| 内部裁判带 | 当前公众总档 | 公众语义 |
|---|---|---|
| S+ | S+ | 最高量级历史影响 |
| S | S | 超重大历史影响 |
| S- | A | 重大长期历史影响 |
| A+ | B | 重大历史影响 |
| A | C | 显著历史影响 |
| B | D | 有限但真实影响 |
| C | E | 弱历史影响 |

映射只改变公众总档，四维字母不变；旧H档不再输出。记录保存基础档、主要依据及实际修正理由，不能从最后标签倒推过程。

### 4.1 影响性质

性质与量级分开。比较本人造成的主要正负后果，说明独立反向结果及其归属；通常战争代价、未完成目标或后人的新选择，不自动把人物判为混合。反面鉴戒不把原损害变成正向成果。

| 性质 | 裁判边界 |
|---|---|
| 正向为主 | 可归责的建设、整合、恢复或稳定后效占主导；未证另一条相当的独立负向后果。 |
| 混合偏正 | 正向后效占主导，同时存在可定位、不可由主链吸收的负向结果。 |
| 高度混合 | 独立正负后果均重大，或同一宏观转轨同时形成两面重大结果，不能将一面降为普通过程代价。 |
| 负向为主 | 可归责的破坏、失序或长期不利路径占主导；局部建设、物理遗存及后继独立修复不足以改变方向。 |

性质判断写入`impact_nature_basis`，说明主导后果、反向结果与本人责任，不从名望或总档推断。

## 5. 疑难边界与防重复规则

- 工程本身不单独构成主要历史影响；它可作为已成立的国家结构变化或宏观转型的证据，不能凭规模和寿命独立抬档。
- 前驱、完成者和继任者各计自己造成的改变；后继采用可以验证前人遗产，后继新增成果不能倒算给前人。
- 同一过程出现三名以上内部A+或两名以上内部S-时，复核各人的独立变化、遗产和个人作用；这是检查信号，不是名额限制。
- 亡国、救亡及共治按实际作用分责。失权期间的他人决策不回填给本人，外部征服者或后继的独立重建也另行处理。
- 区域、跨文明、恢复和灾难使用相同标准。双边安排可以影响双方，但双方不能各自独占全部因果；发生在某人之后，不等于由其造成。

## 6. 证据、置信度与发布

证据要分别支持发生了什么、改变怎样延续，以及为何认为换人会不同。反事实用现实候选、已有方案、同期相似发展及后继表现约束，不冒充直接史实。

置信度使用HIGH、MEDIUM、LOW，表示当前判断的稳定性，不是概率；原“中高”归MEDIUM。HIGH还须解释主要替代方案为何不改变量级判断。

每人保留身份和实际行动窗口、四维与总档、影响性质、置信度、1—3条主链、反事实、责任边界及来源。只连接实际采用的材料；相关检索入口另列，不能冒充直接证据。无法恢复的引文说明限度，影响结论的事实冲突才重新裁决。

公众正文直接保存在正式记录：总档理由用`public_total_basis`，性质理由用`impact_nature_basis`，各维理由用`public_basis`，必要限制用`public_boundary`。先用普通中文解释结论，再供读者查看计算标签和详细来源；页面只负责展示，不重新拼写判断。

正式JSON及生成命令见`config/project.yml:historical_impact_assessment`，Markdown为同值生成物。主池与补充样本分列，同档按时代或朝代阅读；至少显示总档、性质、范围与深度、主要历史改变。校准名单放附件，历史过程由Git保留。
