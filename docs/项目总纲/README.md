# 项目总纲

## 本目录负责什么

本目录只放全项目执行总闸门、最高层执行口径和总规则。它回答“全项目如何被约束”和“下位规则冲突时如何处理”。

## 本目录不负责什么

本目录不放数据字段规范、分项细则、展示规范、registry、批次文件生命周期细则或可重建导出说明。

## 与相邻目录的边界

- 证据如何裁量，进入 `证据规则/`。
- JSONL、SQLite、配置和批次文件生命周期，进入 `数据结构与生成库/`。
- 子项业务归项，进入 `分项规则/`。
- Markdown 展示、GitHub 发布和 scripts 协作，进入 `展示与协作/`。

## 当前索引

- [`总规则.md`](总规则.md)

`docs/皇帝综合评价体系评分标准.md` 仍保留在 `docs/` 根目录，是最高层评分标准。

## 后续新增文件限制

新增文件必须是全项目总闸门或最高层执行口径；不得把具体数据、证据、展示或分项规则放回本目录。
