# 中国古代皇帝综合评价体系

> 本文档是当前有效评分标准，不记录历史修订过程。  
> 适用对象：中国古代政权的皇帝（包括被追封的）、摄政太后、天王；剔除在位时间不足一年的、无实权的对象；评价其在实际统治周期内对国家、社会、文明造成的净影响。

---

## 0. 总分、公式与口径

### 0.1 计分公式

最终得分：

> **正收益总分 − 历史负债**

正收益由前六大项构成。历史负债为第七项，只扣分，不加分。

### 0.2 正收益分值结构

| 大项 | 名称 | 分值 |
|---|---:|---:|
| 第一项 | 创业与政权取得能力 | 260 |
| 第二项 | 治国净收益 | 465 |
| 第三项 | 军事与边疆净收益 | 250 |
| 第四项 | 文明与国家整合收益 | 180 |
| 第五项 | 统治者政治素质 | 170 |
| 第六项 | 关键历史决策能力 | 175 |
| **正收益合计** |  | **1500** |
| 第七项 | 历史负债 | **0—300扣分** |

### 0.3 总分口径

当前六个正向大项合计为：

> 260 + 465 + 250 + 180 + 170 + 175 = 1500

本版按 **正收益总盘1500分** 执行；第二项D3以15分独立评价实际交接结果，第六项以175分评价关键决策能力。不新增第八项，也不设置“历史地位 / 综合影响 / 特殊伟业”等二次结算项目。

## 1. 总原则

### 1.1 务实评价与统一标准

只看实际行为、实际成果、实际代价，以及实际留下的制度、社会、边疆、文明后果。不得因名气、后世宣传、王朝滤镜、“千古一帝”或雄主光环补分。

执行 **同名替换检验**：遮去人物姓名后若会判低，不得因其统一功业、军功、制度创设或历史名气而判高。同一标准适用于所有皇帝。

### 1.2 结果、过程、制度、运行分离

一个成果只能主要结算一次。创业、制度、行政、民生、军事边疆、文明整合、个人素质、关键决策和历史负债必须按项目边界切分，不得互相回填。

制度创设不等于制度运行，行政执行不等于民生收益，国富/库富/账面富不等于民富，交接实际成功不自动等于制度韧性强。

### 1.3 净收益与负债分离

前六项评价正向净收益；第七项处理前六项未完全覆盖的跨期性、结构性、灾难性历史窟窿。前六项已吸收的普通代价，不在第七项机械重复扣分。

### 1.3.1 生产力增长与文明进步根本标准

制度、政策和治理成果的正负判断，最终以是否推动历史条件下的生产力增长与文明进步为根本标准。国家控制力、财政汲取力、行政穿透力、国库充盈或账面人口田亩增长，不自动等于正向制度收益。

正向制度应能降低社会成本、保护民间弹性、稳定法制秩序、扩大人才流动、改善反馈纠错、促进经济恢复与文明进步；负向制度包括主要通过抽血汲取、高压清查、告发连坐、身份固化、反馈堵塞、特务化控制、过度集权或制度错配来增强国家机器的安排。

执行时应特别区分：

- **国家能力增强** 与 **社会净收益增强**。前者只有服务于后者时才按正向计。
- **国富/库富/账面富** 与 **民富/生产力增长**。前者不能直接替代后者。
- **制度动作规模** 与 **制度净质量**。动作越大不自动越高，若主要压缩社会弹性，应转为负向或降温。

### 1.4 档位压缩与从严落点

优秀以上正式只保留三档：历史极限、历史顶级、优秀。历史极限是该小项天花板，不是“非常优秀”的同义词，原则上单项不超过1—3人。

| 等级 | 得分率 | 说明 |
|---|---:|---|
| 历史极限 | 96%—100% | 几乎不可超越的历史天花板，原则上极少数人；达到完整边界者可以满分。 |
| 历史顶级 | 90%—95% | 明确进入该小项历史第一梯队，但仍低于极限。 |
| 优秀 | 80%—89% | 高质量正收益，明显强于多数皇帝，但不进入历史第一梯队。 |
| 良好 | 70%—79% | 有稳定正收益，但未达到名君级表现。 |
| 合格 | 60%—69% | 基本完成该项职责，有功但不突出。 |
| 一般 | 50%—59% | 功过有限，或表现平庸。 |
| 较差 | 40%—49% | 明显低于合格线，存在较大短板。 |
| 很差 | 30%—39% | 严重失职或明显负收益。 |
| 极差 | 30%以下 | 接近灾难性表现，通常会连带历史负债。 |

档内可微调为高段、正常、低段，但“历史顶级上段”“优秀上段”不再作为正式档位。

### 1.5 交班状态、后代发挥与长期影响归因分离

判断可持续性时，重点看皇帝离世或实际交班时留下的制度、社会与政权质量。王朝最终寿命、后代是否败家、很久以后发生的偶然变化不能直接算给前任；但可在不替代本项证据的前提下，作为反推交班结构强弱的旁证。

涉及长期影响的子项，统一执行“创设—继承验证—后世放大切分”原则：本人当期直接创设、定型或强力推行者为主分；后世长期继承、制度化、经典化、共同体化只能作为生命力验证；后世成熟、高峰、扩展和王朝整体光环不得回填给本人。

## 3. 第一项：创业与政权取得能力（260）

### 3.1 核心问题

> 天下是怎么得到的？

评价皇帝取得政权的能力，包括战略设计、政治整合、军事夺取与创业难度。

### 3.2 总边界

本项只评价王朝奠基人在取得天下、建立政权或完成复国过程中的表现。普通继承、守成、在既成王朝内取得个人皇权，以及登基后才形成主要扩张成绩者不纳入第一项；其分数状态为“不适用”，不得按零分处理或参加本项排序。

王朝创建者、复国重建者、正式建国前已有决定性独立贡献的共同奠基者，以及虽失败但实际建立独立政权的创业者可以纳入。实际控制、正式建国与统一分属数代时，只评价各人在奠基链中不可替代的本人贡献。

计入：

- 起兵、夺权、统一、篡位中的实际奠基能力
- 创业集团组织
- 创业战争指挥
- 夺权战略路线
- 创业环境难度

不计入：

- 登基后的制度建设，归第二项A
- 登基后的行政治理，归第二项B
- 登基后的对外战争和边疆经营，归第三项
- 长期文明整合，归第四项
- 个人性格素质，归第五项

### 3.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 创业战略能力（含创业难度） | 100 |
| B | 政治整合能力 | 60 |
| C | 军事夺取能力 | 100 |
| **合计** |  | **260** |

### A 创业战略能力（100）

#### A1 创业战略增益与难度兑现（60）

评价：奠基项目拿着怎样的起点资源，面对怎样的对手和局势，实际把创业局面推进了多少、完成了多少。

计入：

- 本人创业起点占同期开局全部主要势力有效战略资源的份额
- 窗口内全部主要对手在各次主要对抗中的相对资源压力；不得只取最强对手
- 奠基项目实际创造而非继承的战略增量
- 经时代区域价值校准的王朝级新增净控制量
- 主要对手压力和天下格局复杂度
- 奠基项目的创业目标完成度

不计入：

- 继承、辅政、摄政、政变或禅代时已经有效控制的国家机器
- 个人战役路线覆盖、战区统筹和具体战争指挥，归C项
- 登基后国家战略，归第六项或第三项

边界：

> 战略增益与目标完成度必须同时成立；难度只能提高已经兑现成果的含金量，不能脱离完成度单独得分。原D创业难度已并入A1，不再单列。

#### A2 创业路线效率与稳固（40）

评价：与王朝级新增净控制规模相比，创业路线是否足够迅速、少反复、能闭合，并形成早期可维持的政权结果。

计入：

- 由王朝级新增净控制规模统一推导的期望闭合时间
- 高价值核心的价值加权取得时间与创业目标全部闭合时间
- 创业期控制留存和失控恢复
- 本人责任范围内的终点目标闭合率
- 建国后五至十年或本人去世前的战略性稳定
- 本人具名的非战役正向战略锚点，包括根据地、政治时机、合法性、总体夺权路径和重大纠偏
- 已确认归于本人的重大路线误判；事后恢复不能抹除原判断责任

不计入：

- 具体战役中的本人军事贡献与结果，归C1
- 本人前线指挥能力，归C2
- 非本人团队在联盟构建中的实际成果，归B
- 建国后的具体制度、行政和民生得失，归第二项

边界：

> A2以具名非战役正向战略锚点和具名误判为个人判断主轴，再读取路线最终造成的时间、控制和稳定后果；无误判事件即零负担，不设置奠基覆盖率封顶。具体战役路线和军事统筹归C，不得充当A的正向锚点。早期观察窗只判断创业结果能否站住，不评价具体治理政策。玄武门之变不属于唐创业统一过程且未造成区域控制不稳，不进入第一大项。

A1、A2详细公式、起点资源边界和共同奠基者归责见[`分项规则/第一项创业与政权取得能力/战略决策能力/00-规则与计分合同.md`](../分项规则/第一项创业与政权取得能力/战略决策能力/00-规则与计分合同.md)。

### B 政治整合能力（60）

#### B1 非本人团队关键成果贡献（30）

评价：创业窗口内，奠基人之外的成员实际完成了多少重要且不重复的开国成果。成果可以来自战略、战争、联盟、后勤、行政或区域接收；同一成员可以凭多个真实成果累计，一人多职不按人数折扣。

#### B2 开国人才贡献质量（30）

评价：创业窗口内由实际成果证明的团队顶端人才质量。跨多个领域形成支柱成果的一人可以高于多名普通成员，不按人数和岗位数量计分。

开国人才团队统一在B评价，但不建立全生涯抽象人才等级，不按五职能占位或人头评分。B1按成果量级、团队贡献信用和完成度结算，B2按创业窗口内个人实际贡献组合结算；奠基人参与同一结果不反向抹去成员贡献，用人与授权的一般性个人素质仍归第五项B。详细规则见[`分项规则/第一项创业与政权取得能力/政治整合能力/00-规则与计分合同.md`](../分项规则/第一项创业与政权取得能力/政治整合能力/00-规则与计分合同.md)。

### C 军事夺取能力（100）

C项只评价本人在取得天下、建立政权或取得最高权力的创业战争中实际发挥了多少军事作用。名将、联盟或开国人才团队的招揽、授权、组织和协同统一归B，不因他人战果给本人增加C分。

| 小项 | 名称 | 分值 | 核心问题 |
|---|---|---:|---|
| C1 | 本人创业战争贡献与成果 | 70 | 本人对创业战役结果实际贡献了多少？ |
| C2 | 本人前线指挥能力 | 30 | 本人亲自承担并解决了什么层级、什么难度的军事问题？ |

C1看本人已经兑现的作战设计、战区统筹、独立方向或前线指挥成果；C2只看本人作为前线核心统帅的实际解题能力。普通授权、名义领导、制度性默认责任和他人独立完成的战果均不进入C。个人勇武、亲征风险和战场威望只可作为C2同档旁证，不单独设分。

普通继承、宫廷权力转移、未发生正规军事争夺的政治事件不伪装成战役。取得权力后的边疆经营、国家安全和常备军事体系归第三项；创业路线选择归A，政治联盟与开国人才团队归B。

详细准入、六档边界、档内计分、去重和输出合同见[`分项规则/第一项创业与政权取得能力/军事夺取能力/00-规则与计分合同.md`](../分项规则/第一项创业与政权取得能力/军事夺取能力/00-规则与计分合同.md)。

## 4. 第二项：治国净收益（465）

### 4.1 核心问题

> 国家治理得怎么样？

评价皇帝在正式统治期间对制度、行政、民生经济和交班状态造成的净收益。

### 4.2 总边界

计入：

- 登基后的制度创设、修复、运行
- 行政体系运转
- 民生经济结果
- 离世或交班时的制度、社会、政权质量

不计入：

- 夺权过程，归第一项
- 对外军事安全收益，归第三项
- 文明认同与文化影响，归第四项
- 皇帝个人素质本身，归第五项
- 关键节点判断能力本身，归第六项
- 长期灾难性历史窟窿，归第七项

### 4.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 制度建设 | 140 |
| B | 行政治理 | 160 |
| C | 民生经济 | 110 |
| D | 可持续性 | 55 |
| **合计** |  | **465** |

---

### A 制度建设（140）

评价皇帝对国家制度体系的建设、修复、运行与制度史影响。

| 小项 | 名称 | 分值 |
|---|---|---:|
| A1 | 制度创设与修复 | 50 |
| A2 | 制度运行质量 | 50 |
| A3 | 制度历史影响力 | 40 |

#### A1 制度创设与修复（50）

评价：皇帝是否创设、重构、修复或成熟化了关键国家制度，并且这些制度在历史条件下是否有利于生产力增长与文明进步。

计入：

- 中央制度、地方制度、财政制度、选官制度、法制体系、军政关系制度、国家治理框架重建
- 能降低治理成本、稳定社会预期、保护民间弹性、扩大人才流动、改善反馈纠错、促进经济恢复和文明进步的制度建设

不计入：

- 制度实际运行效果，归A2
- 行政日常效率，归B项
- 教育人才的文明层面影响，归第四项B
- 单纯开疆或军事控制，归第三项
- 国库充盈、账面户口/田亩暴增、国家汲取能力增强本身；若主要体现抽血、高压清查、告发连坐、身份固化或压缩民间弹性，应作为负向制度审查

边界：

> A1问“有没有建设制度、修复制度、重构制度，以及这些制度净方向是否有利于生产力增长和文明进步”。

#### A2 制度运行质量（50）

评价：皇帝统治期内制度是否运行顺畅、稳定、有效。

计入：

- 制度执行稳定度
- 制度与行政实践的匹配度
- 皇帝是否尊重并维护制度
- 制度能否降低治理成本
- 制度运行中的纠偏能力

不计入：

- 制度原创性，归A1
- 制度后世影响，归A3
- 官僚个体质量，归B1
- 政权交接稳定，归D3

边界：

> A2问“制度当时跑得好不好”，不是问“制度是否伟大”。

#### A3 制度历史影响力（40）

评价：皇帝留下的国家机器制度是否改变后世制度史。

计入：

- 后世长期继承的国家机器制度
- 对帝国政治结构的深层塑造
- 被后世反复模仿、修正、沿用的制度框架
- 对中央—地方、君主—官僚、财政—军事关系的长期影响

不计入：

- 离世时制度是否能立刻稳定运行，归D1
- 文明、文化、思想层面的遗产，归第四项D
- 教育社会化与人才流动，归第四项B
- 单纯行政效率，归B项

边界：

> A3只看“国家机器制度史影响”，不再使用“制度遗产与可持续性”的混合口径。

### B 行政治理（160）

评价皇帝在统治期内组织国家机器、管理官僚、纠错监督、推动执行的能力和效果。

| 小项 | 名称 | 分值 |
|---|---|---:|
| B1 | 吏治水平 | 60 |
| B2 | 纠错与监督能力 | 50 |
| B3 | 行政执行力 | 50 |

> 注：原标准曾写“中央效率、地方治理、官僚体系质量、社会秩序”四项各40分；现有标尺库已重组为B1吏治、B2纠错监督、B3行政执行力。为保证标准与标尺一致，本版采用三项结构。

#### B1 吏治水平（60）

评价：官僚体系是否清明、稳定、专业、可用。

计入：

- 官员选拔质量
- 官僚廉洁度
- 官僚专业能力
- 官场风气
- 中央与地方官僚体系的整体质量
- 地方治理中的官吏表现

不计入：

- 制度本身创设，归A1
- 制度史影响，归A3
- 皇帝个人用人性格，归第五项B
- 社会秩序的最终民生结果，归C或D2

边界：

> B1看“官僚队伍质量”，不是单纯看皇帝勤不勤政。

#### B2 纠错与监督能力（50）

评价：国家机器运行中是否能发现问题、纠正偏差、约束官僚和政策错误。

计入：

- 谏议机制
- 监察机制
- 政策反馈
- 对冤案、弊政、财政失控、地方失序的纠偏
- 皇帝对反对意见的容纳和处理

不计入：

- 一次关键危机止损，归第六项B
- 政治品格中的待异见态度，归第五项D
- 制度原创性，归A1

边界：

> B2看日常治理系统能否纠错；第六项B看关键节点能否止损。

#### B3 行政执行力（50）

评价：政策能否从中央意志转化为实际治理结果。

计入：

- 中央命令贯彻
- 地方执行穿透力
- 政策推进速度
- 动员能力
- 复杂政务处理能力
- 国家机器响应能力

不计入：

- 军事动员效果，主要归第三项C/D
- 创业战争组织，归第一项C
- 单纯高压控制造成的负面后果，需在C、D或第七项扣除

边界：

> B3不是“越高压越高分”，必须看执行带来的净治理收益。

### C 民生经济（110）

评价皇帝统治期间百姓生活、社会繁荣、经济活力和财政健康的净结果。

| 小项 | 名称 | 分值 |
|---|---|---:|
| C1 | 民生福祉与社会繁荣 | 70 |
| C2 | 经济活力与财政健康 | 40 |

> 注：原标准强调“百姓生活改善”为核心指标，且“不看单纯国库”。本版将该注解并入C1与C2：财政健康可以加分，但不能压倒民生福祉。

#### C1 民生福祉与社会繁荣（70）

评价：普通百姓生活是否改善，社会是否繁荣安定。

计入：

- 生活水平
- 社会安定
- 赋役承受感
- 战乱恢复
- 民间生产状态
- 人口恢复与增长
- 社会活力
- 灾荒、流民、破产、逃亡情况

不计入：

- 单纯国库充盈
- 单纯皇室奢侈或城市表面繁荣
- 开疆战争带来的国家声望
- 后世文化繁荣，归第四项

边界：

#### C2 经济活力与财政健康（40）

评价：国家经济结构、财政状态、生产流通是否健康。

计入：

- 财政收支健康
- 税制合理性
- 市场、农业、手工业、商业活力
- 国家储备
- 经济恢复能力
- 长期财政可承受性

不计入：

- 通过极端压榨形成的短期财政充盈
- 因军事扩张获得的短期战利品
- 单纯账面国库数字
- 军事投入是否值得，归第三项D

边界：

> C2看经济和财政健康，不是看皇帝会不会敛财。

### D 可持续性（55）

评价皇帝离世或实际交班时，其治理成果是否具备长期生命力。

特别说明：

- 不看后代发挥
- 不看王朝最终寿命
- 不看后世是否败家
- 只看交班时留下的制度、社会与政权质量

| 小项 | 名称 | 分值 |
|---|---|---:|
| D1 | 交班制度韧性 | 20 |
| D2 | 社会韧性 | 20 |
| D3 | 政权交接稳定 | 15 |

#### D1 交班制度韧性（20）

评价：皇帝离世时，制度是否能脱离本人继续稳定运行。

计入：

- 制度是否过度依赖皇帝个人能力
- 制度是否具备自我修复能力
- 制度运行是否已常态化
- 继任者是否有可承接的制度框架
- 交班时制度是否存在结构性裂缝

不计入：

- 制度对后世几百年的历史影响，归A3
- 行政运行质量，归A2/B项
- 后代个人能力造成的成败

边界：

> D1看“交班时能不能继续跑”，A3看“制度史上有没有深远影响”。

#### D2 社会韧性（20）

评价：皇帝离世时，社会是否具备长期稳定运行能力。

计入：

- 社会矛盾强度
- 阶层关系
- 财政压力向民间转嫁程度
- 民间承受能力
- 社会共识
- 灾后恢复能力
- 是否存在大规模不满、逃亡、流民、民变基础

不计入：

- 统治期平均民生表现，归C1
- 单纯财政账面健康，归C2
- 继任者新政策造成的社会变化

边界：

> C项看“统治期过得怎么样”；D2看“交班时社会还扛不扛得住”。

#### D3 政权交接稳定（15）

评价：皇帝离世或实际交班时，中央政权是否能安全完成权力延续。

计入：

- 继承安排清晰度
- 中央军政大权是否稳固
- 宗室、外戚、权臣、军头是否可能造成断裂
- 中枢是否存在立即分裂风险
- 是否存在军阀化、藩镇化倾向

不计入：

- 日常行政效率，归B3
- 官僚体系质量，归B1
- 皇帝控制权臣的个人能力，归第五项C
- 后代长期治理成败

边界：

> D3只看交接安全，不再泛泛评价“政权稳定”。

## 5. 第三项：军事与边疆净收益（250）

### 5.1 核心问题

> 国家安全提升多少？

评价皇帝统治期间对国家安全、边疆控制、军事体系和军事成本控制造成的净收益。

### 5.2 总边界

计入：

- 消除外部或内部战略威胁
- 建立安全边界
- 扩展或稳定边疆控制
- 军事体系实际战斗力
- 军事投入与国家承受能力之间的比例

不计入：

- 创业战争，归第一项
- 民生承受的最终生活结果，归第二项C
- 边疆地区文明认同和文化吸纳，归第四项A
- 战争造成的长期灾难性窟窿，归第七项

### A 战略安全收益（80）

评价皇帝是否显著改善国家所处的安全环境。

| 小项 | 名称 | 分值 |
|---|---|---:|
| A1 | 消除战略威胁 | 40 |
| A2 | 建立安全边界 | 40 |

#### A1 消除战略威胁（40）

评价：比较皇帝即位与交班时的战略威胁受控状态。

计入：

- 消灭强敌
- 平定长期内乱
- 解除北方、南方、西域、海疆等方向的重大威胁
- 降低国家被入侵、分裂、颠覆的风险

不计入：

- 单纯战役胜利但未改变安全格局
- 创业统一战争，归第一项
- 战争造成的民生损耗，归第二项C或第三项D

边界：

> A1看战略威胁受控状态及其变化，不看地盘是否扩大；地盘问题主要归B项。

A1分别登记起点和终点两个状态锚点，净变化由两锚点得出；终点已达最高状态者可按严格的封顶推进证据继续区分，详细档位、归责和转换规则由国防安全底账规定。

#### A2 建立安全边界（40）

评价：比较皇帝即位与交班时的战略边界安全状态。

计入：

- 战略缓冲区
- 关隘、防线、边镇体系
- 边疆防御纵深
- 交通线和补给线安全
- 长期安全格局改善

不计入：

- 单纯疆域面积扩大，归B1
- 新边疆的文明整合，归第四项A
- 军事制度建设，归C项

边界：

> A2看“边界是否更安全”，不是看“版图是否更好看”。

A2分别登记起点和终点两个状态锚点，净变化由两锚点得出；终点已达最高状态者可按严格的封顶推进证据继续区分，详细档位、归责和转换规则由国防安全底账规定。

### B 边疆控制净收益（80）

评价开疆、固疆、收复、羁縻、设治等行为对国家安全和控制能力带来的净收益。

| 小项 | 名称 | 分值 |
|---|---|---:|
| B1 | 控制规模 | 25 |
| B2 | 战略价值 | 30 |
| B4 | 交班成熟度 | 25 |

> 注：原名为“开疆净收益”。本版扩展为“边疆控制净收益”，以避免只奖励扩张，也能评价收复、固疆、有效设治和边疆稳定。

> 原B3“控制效率”取消；取得和维持边疆控制的成本收益统一归D。B4编号保留，以维持既有语义和底账引用稳定。

#### B1 控制规模（25）

评价：比较皇帝即位与交班时的实际边疆控制规模状态。

计入：

- 新增有效控制区域
- 收复失地
- 把松散控制转化为稳定控制
- 将边疆纳入常态治理范围
- 具有可执行宗主权的属国、藩国或羁縻体系

不计入：

- 纸面宣称但不能有效控制的土地
- 短期掠夺性占领
- 普通友好、一次称臣或仅有名义册封的政权
- 单纯文明影响扩散，归第四项

边界：

> B1看控制规模，不等于地图涂色。

B1按任内边疆控制净变化与交班绝对规模合成一个结果档：`B1加权控制值=60%×（交班空间－接班空间）+40%×交班空间`。接班、交班的实际受控空间仍分别登记，但不各自落状态档或生成双锚轨迹。直接统治、都护羁縻和具可执行宗主权的属国均可计入，控制成熟度不在本轴重复折减。空间基准跨朝固定，不能把大小悬殊的地区都按“一个区域”计数。详细口径由国防安全底账规定。

B1以净变化为主、交班绝对规模为难度修正；大规模守成可取得中档，但不能仅凭继承存量进入最高档。详细档位与档内位置由国防安全底账规定。

#### B2 战略价值（30）

评价：边疆控制是否具有重要安全、交通、资源或地缘价值。

计入：

- 关键走廊
- 关隘门户
- 战略缓冲
- 资源产地
- 贸易通道
- 对强敌的压制作用

不计入：

- 面积大但战略价值低的区域自动高分
- 文明象征意义，归第四项D

边界：

> B2看“值不值得控制”，不是看“面积大不大”。

#### B4 交班成熟度（25）

评价：皇帝离世或退位时，任内形成或有效稳固的边疆控制是否已转化为能够常态运行的控制体系。

计入：

- 控制持续时间及驻军、行政、交通、补给和地方合作状态
- 交班时是否仍依赖个人威望、临时重兵或异常资源投入
- 本人全部主要控制净成果，以及本人任内造成或放大的主要方向结构性退控是否已在交班前恢复

不计入：

- 交班后的失地、叛乱、继任者决策和外部格局变化
- 仅削弱对手但未形成实际控制的战略安全贡献
- 当地文明认同，归第四项A；中央权力交接，归第二项D3

边界：

> B4每位皇帝只评一次，只看本人交班时的控制成熟度；具体档位、证据合并和封顶规则由国防安全底账规定。

B4不得只挑选本人最成熟的一项正向成果；同任期另一主要方向由本人造成或放大的结构性退控也必须进入交班审查。继任者后续失地、扩张和政策变化仍不反推前任，交班时已有可执行驻军、行政和补给者按当时状态裁决。

### C 军事体系有效性（50）

评价皇帝统治期内军事体系的实际运行效果。

本项只形成一个50分总体分：先由C1、C2、C3确定总体档，再在该档区间内计分。C2、C3不另行加分。

#### C1 实战兑现度

评价：军事体系面对不同难度对手时，能否实际完成作战任务并持续取得有效战果。

计入：胜负、任务完成、攻防转换、不同对手与战场难度、连续实战表现。

不计入：战果造成的战略安全和边疆控制收益，分别归A、B；创业战争中的个人统兵能力归第一项C。

#### C2 持续作战能力

评价：既有实战表现是否获得稳定动员、兵源补充、粮饷运输、军需后勤和败后恢复的支持。

本维度不独立加分，只能因支撑不足封顶或降低C1基础档。对百姓和财政造成的最终负担归第二项C，投入是否值得归第三项D。

#### C3 体系可靠性

评价：实战能力是否来自可重复运行的国家军事体系，而非单一名将、临时拼凑或偶然胜利。

计入：军令统一、将帅体系、中央与地方军事关系、跨将领和跨战场复制能力、将帅更替后的运行情况。

不计入：军制的纯制度史影响，若主要影响国家机器制度史，归第二项A3。

结算规则：

- `C总体档 = min(C1基础档, C2封顶档, C3封顶档)`；任一必要门禁未知时保持未知。
- C2、C3只能验证或压低C1，不能把低劣实战表现抬高。
- 总体档先确定得分率区间：`C0=0%—29%、C1=30%—44%、C2=45%—59%、C3=60%—74%、C4=75%—89%、C5=90%—100%`。
- 同档内按三轴相对最低轴的剩余支撑线性落点：设`g=min(C1,C2,C3)`，`s=(C1-g)+(C2-g)+(C3-g)`；当`g<5`时，`得分率=区间下界+(区间上界-区间下界)×s/[2×(5-g)]`，C项得分为`50×得分率/100`；三轴均为5时得50分。
- 该档内公式只区分同档强弱，不能突破总体档上界；同一总体档不再机械同分。
- 最高档必须同时有高难度实战兑现、持续作战能力和不依赖单一名将的体系证据；可有局部失利，但不得发生战役群级崩溃或体系级失败。
- 单场胜败不直接形成总体档；必须按皇帝统治期合并主要战争系列和重大体系失败。

> C项问“国家军事体系实际能不能打、能不能持续、能不能重复运行”，只给一个总体结果分。

### D 军事成本收益比（40）

评价军事行动和边疆经营是否在国家承受能力内取得足够且已经兑现的收益。D不按战斗次数计分，而按独立战略行动周期形成事件结算，再按皇帝完整统治期合并军事投资组合。

计入：

- 是否穷兵黩武
- 是否战略透支
- 是否财政透支
- 是否兵役、徭役过重
- 取得和维持边疆控制所需的战争、驻军、后勤及行政投入是否与收益相称
- 战争收益是否配得上代价
- 战争是否导致国家安全反而下降
- 已实际发生投入但取消、撤回或未形成收益的军事动员
- 未达到国防安全门槛、但已实际消耗国家军事资源的地方镇压或兵变处置

不计入：

- 百姓生活的最终恶化结果，归第二项C1
- 财政健康的总体结果，归第二项C2
- 长期不可逆历史窟窿，归第七项
- 创业、统一和兼并战争
- 宫禁政变、个人刺杀及未演变为国家军事行动的政治暴力

边界：

> 第三项D统一看全部军事投入是否值得，不再另设边疆控制成本轴；第二项C看百姓和经济实际承受结果；第七项看是否留下跨期灾难。

无实质军事投资者按中性未检验处理；少量样本的高档须经A/B结果与C体系证据交叉验证。具体门槛只写入D项规则合同，不在总则重复展开。

结算口径：

- 成本端综合军事投入与可归责的战争外部成本；具体消费字段、归责和门禁规则以军事成本收益底账的《规则与结算合同》为准。
- 结果端消费战役目标与实际结果，收益端消费战略安全和边疆控制净变化；杀敌、缴获或名义臣服未转化为实际结果时不自动构成收益。
- 一个完整战略目标、动员周期和结果闭合链结算一次；换帅、分路、跨年或单场胜败不自动拆分，重新决策、重新动员、目标转换或前一周期已经闭合时才另立周期。
- 皇帝级结算不得按事件数简单平均或把档位序号加减；必须综合主导性高成本行动、反复无收益模式、必要防御、长期驻防及成果保持情况。

## 6. 第四项：文明与国家整合收益（180）

### 6.1 核心问题

> 给文明留下什么？

评价皇帝对国家认同、文明整合、教育人才、思想文化和长期文明遗产造成的净收益。

### 6.2 总边界

计入：

- 国家共同体建设
- 多族群、多区域、多文化整合
- 教育与选才机制对文明再生产的贡献
- 思想文化生态
- 长期文明层面影响

不计入：

- 单纯制度创设，归第二项A
- 单纯行政效率，归第二项B
- 单纯开疆和边疆控制，归第三项
- 单纯个人文艺爱好
- 现代价值观直接投射

特别说明：

> 不以现代价值观直接评分。以历史条件下净收益评分。

### 6.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 国家认同与文明整合 | 60 |
| B | 教育与人才机制 | 45 |
| C | 思想与文化生态 | 35 |
| D | 长期文明遗产 | 40 |
| **合计** |  | **180** |

---

### A 国家认同与文明整合（60）

评价皇帝是否增强国家共同体、政治认同与文明整合。

计入：

- 共同体建设
- 国家认同
- 民族整合
- 区域整合
- 新纳入地区的人心吸纳
- 中央政权合法性向基层和边疆扩展

不计入：

- 单纯军事占领，归第三项B
- 单纯安全边界，归第三项A
- 单纯户籍、郡县、行政设置，归第二项A或第三项B

边界：

> 第三项问“地盘安不安全、控不控制得住”；第四项A问“人心和认同有没有整合进国家共同体”。

---

### B 教育与人才机制（45）

评价皇帝是否推动教育、选官与人才流动机制，增强文明再生产能力。

计入：

- 教育体系
- 学校与经学、学术培养
- 选官机制对人才流动的影响
- 阶层流动通道
- 文官群体生成
- 人才标准的制度化和社会化

不计入：

- 选官制度作为国家机器制度本身的创设，归第二项A1
- 官僚队伍当期行政质量，归第二项B1
- 行政执行效率，归第二项B3

边界：

> 第二项看“国家机器是否好用”；第四项B看“文明是否能持续生产人才”。

---

### C 思想与文化生态（35）

评价皇帝统治下学术环境、文化活力和知识生产的净状况。

计入：

- 学术环境
- 文化活力
- 知识生产
- 典籍整理
- 文化宽容度
- 思想统一与思想活力之间的平衡

不计入：

- 现代自由主义标准的直接套用
- 单纯皇帝个人文学成就
- 单纯宣传工程
- 与治理无关的宫廷娱乐

特别说明：

> 不以现代价值观直接评分。思想控制未必一概低分，文化宽松也未必一概高分，关键看历史条件下对国家和文明的净收益。

---

### D 长期文明遗产（40）

评价皇帝对中国文明长期结构留下的影响。

计入：

- 长期文明影响
- 制度文化遗产中的文明层面
- 价值观、国家观、族群观、天下观的长期影响
- 教育文化模式的长期塑造
- 文明整合范式

不计入：

- 国家机器制度史影响，归第二项A3
- 单纯疆域控制，归第三项B
- 单纯短期文化繁荣，归C项

边界：

> 第四项D看“文明层面的长期遗产”，不重复第二项A3的国家机器制度史。

## 7. 第五项：统治者政治素质（170）

### 7.1 核心问题

> 这个人本身是否是优秀统治者？

评价皇帝作为政治人物的素质，而不是直接重复前四项成果。

### 7.2 总边界

计入：

- 自律勤政
- 用人与授权
- 权力控制
- 政治品格
- 认知与学习能力

不计入：

- 具体制度成果，归第二项A
- 具体行政成果，归第二项B
- 具体军事成果，归第三项
- 具体文明成果，归第四项

边界：

> 第五项评“人怎么样”；前四项评“国家实际得到什么”。

### 7.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 自律与勤政 | 30 |
| B | 用人与授权 | 45 |
| C | 权力控制能力 | 40 |
| D | 政治品格 | 25 |
| E | 认知与学习能力 | 30 |
| **合计** |  | **170** |

### A 自律与勤政（30）

评价：皇帝是否能长期保持治理投入、自我约束和基本工作能力。

计入：勤政、节制、稳定办公、持续处理政务、避免沉溺享乐。

不计入：治理结果本身，结果归第二项至第四项。

### B 用人与授权（45）

评价：皇帝是否能识人、任人、授权、容人。

计入：发现人才、信任人才、合理授权、建立团队、避免任人唯亲或滥杀能臣。

不计入：官僚体系整体质量，归第二项B1；创业联盟整合，归第一项B。

五个分项的权重、材料因子、结算预算、检索停止条件、人物画像边界、重复结算规则及运行时限，统一见 `docs/分项规则/第五项统治者政治素质/B用人与授权.md`。

### C 权力控制能力（40）

评价：皇帝是否能控制外戚、宦官、宗室、权臣、军头和继承风险。

计入：

- 外戚控制
- 宦官控制
- 宗室控制
- 权臣控制
- 军权控制
- 继承风险控制

不计入：政权交接当天的结构稳定，归第二项D3；由权力失控造成的重大长期灾难，归第七项。

### D 政治品格（25）

评价：皇帝对功臣、异见者、百姓和政治对手的基本政治伦理。

计入：

- 待功臣
- 待异见
- 待百姓
- 信义
- 克制
- 是否滥杀、酷虐、猜忌成性

不计入：单纯现代道德评判；必须看其行为对政治秩序和国家净收益的影响。

### E 认知与学习能力（30）

评价：皇帝是否具备战略思维、学习能力和纠错能力。

计入：

- 战略思维
- 学习能力
- 政策理解能力
- 纠错能力
- 接受现实反馈

不计入：关键节点的具体决策成败，归第六项。

## 8. 第六项：关键历史决策能力（175）

### 8.1 核心问题

> 关键时刻会不会做决定？

评价皇帝在重大历史节点上的判断、止损与长期战略眼光。

### 8.2 总边界

计入：

- 战争、改革、迁都、废立、继承、外交等重大节点判断
- 危机处理和止损
- 长期方向选择

不计入：

- 具体制度建设成果，归第二项A
- 具体军事收益，归第三项
- 个人认知素质的一般表现，归第五项E
- 长期灾难性后果本身，归第七项

边界：

> 第六项评“关键选择能力”；具体成果和后果仍回到对应项目结算。

### 8.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 重大节点判断 | 60 |
| B | 风险控制与止损 | 50 |
| C | 长期战略眼光 | 65 |
| **合计** |  | **175** |

### A 重大节点判断（60）

评价：面对战争、改革、迁都、废立、继承、外交等重大节点时，是否判断正确。

计入：

- 时机判断
- 方向判断
- 主次判断
- 关键人事判断
- 国家利益判断

不计入：执行过程中的行政效率，归第二项B；战争具体指挥，归第一项C或第三项C。

### B 风险控制与止损（50）

评价：局势恶化时是否能控制风险、修正错误、及时止损。

计入：

- 危机处理
- 错误修正
- 战略收缩
- 防止局面扩大化
- 政策回调

不计入：日常纠错监督机制，归第二项B2。

### C 长期战略眼光（65）

评价：皇帝是否能判断未来方向，避免留下重大隐患。

计入：

- 长期国家方向
- 制度与边疆长期风险
- 继承和权力结构远期影响
- 是否识别结构性隐患

不计入：长期隐患最终造成的灾难性扣分，归第七项。

## 9. 第七项：历史负债（0—300扣分项）

### 9.1 核心问题

> 给国家留下了多大的历史窟窿？

本项不加分，只扣分。

最终总分：

> **正收益 − 历史负债**

### 9.2 总边界

计入：

- 前六项不能完全覆盖的长期结构性负债
- 对国家、社会、文明造成跨期损害的重大错误
- 由皇帝主动决策或长期失控造成的灾难性后果

不计入：

- 已经在前六项净收益中充分扣除的普通代价
- 正常执政失误
- 完全由后代独立造成的灾难
- 与皇帝决策无明显因果关系的偶然事件

特别说明：

> 第七项不是“所有缺点再扣一遍”，而是处理历史窟窿。前六项已经扣过的成本，不得机械重复扣分。

---

### G0 轻微负债（0—20）

正常执政失误。

适用情形：

- 局部政策失当
- 小规模损失
- 后续容易修复
- 不伤国家主体

---

### G1 明显负债（20—60）

造成损失，但国家主体无伤。

适用情形：

- 明显错误政策
- 局部社会、财政或军事损失
- 需要后继者一定程度修复
- 但不改变国势基本面

---

### G2 严重负债（60—120）

国力明显受损，需后继者长期修复。

适用情形：

- 大规模财政、民生、军事透支
- 重要制度或边疆结构受损
- 社会矛盾明显激化
- 国家恢复成本很高

---

### G3 灾难级负债（120—200）

国势逆转，由盛转衰。

适用情形：

- 重大决策导致国家趋势反转
- 王朝由强转弱
- 中央权威、财政、军事或社会结构遭到重创

区间参考：

- 李隆基

---

### G4 毁国级负债（200—280）

直接导致王朝崩溃，或基本不可逆崩溃。

适用情形：

- 政权主体崩坏
- 国家进入不可逆分裂或崩溃
- 后继者几乎无力修复

区间参考：

- 司马衷

---

### G5 天花板级负债（280—300）

接手顶级国力盘，短期内因主动决策造成王朝覆灭。

适用情形：

- 起点极高
- 主动决策极坏
- 后果极快显现
- 王朝主体直接覆灭或接近覆灭

典型标尺：

- 杨广

## 11. 标准使用流程

### 第一步：确认统治阶段

区分：

- 创业夺权阶段
- 正式统治阶段
- 交班阶段
- 后世影响阶段

### 第二步：按项目归口

同一事实先判断应主要归入哪一项。

例如：

- 创业战争胜利：第一项
- 登基后边疆战争收益：第三项
- 战争造成民生透支：第二项C或第三项D
- 战争留下长期崩溃隐患：第七项

### 第三步：先算正收益，再算历史负债

前六项每项内部都按净收益评分。

第七项只处理额外历史窟窿。

### 第四步：选择评分路径并从严落点

先判断小项属于哪类：

- 精细量化项：先核对量化账本、净值、系数和负面项，再按量化结果落点；档位用于解释和审计，不反向压缩量化断层。
- 非精细量化项：继续按 V3.2 新档位体系先定档，再在档位区间内给分。
- 半量化或派生画像项：能由账本控制的部分按账本处理，仍需史实画像判断的部分按档位处理。

按 V3.2 新档位体系定档时：

- 96%—100% 为历史极限，完整达到该项最高边界者可以满分；
- 90%—95% 才是历史顶级；
- 80%—89% 为优秀；
- 不再使用“历史顶级上段”“优秀上段”作为正式档位。

同档内有明显黑点者，应向下压分。没有黑点的标尺人物和有黑点的人物不得机械同分。

### 第五步：复核重复结算

打分后必须检查：

- 是否同一成果重复加分
- 是否同一代价重复扣分
- 是否把后代发挥算给前任
- 是否把个人素质替代实际成果
- 是否把文明影响和制度影响混算
