# 中国古代皇帝综合评价体系评分总则

> 本文档是当前有效的评分总则，只规定评价内容、项目边界、简要口径和分值构成。各项详细执行细则以对应分项规则为准，不在总则重复。

适用对象为中国古代政权的皇帝（包括被追封者）、实际摄政太后和天王。原则上剔除实际统治不足一年或没有实权的对象。评价窗口只覆盖本人实际掌权时期。

## 2. 总原则

### 2.1 务实评价与统一尺度

只看实际行为、实际成果、实际代价，以及本人留下的制度、社会、边疆和文明后果。不得因名气、王朝滤镜、后世宣传或传统名望补分。

同一事实在遮去人物姓名后应得到相同判断。开国者、守成者、亡国者和摄政者均受同一事实标准约束。

### 2.2 结果、过程、制度与运行分离

创业、制度、行政、民生、军事边疆、文明整合、个人素质、关键决策和历史负债分别评价。制度创设不等于制度运行，行政执行不等于民生收益，国家汲取能力不等于社会净收益，个人素质也不能替代实际成果。

### 2.3 净收益与历史负债分离

前六项内部评价各自范围内的净收益。第七项只处理尚未被前六项充分覆盖的长期历史窟窿，不把普通代价或同一失败重复扣除。

### 2.4 生产力增长与文明进步

制度、政策和治理成果的方向判断，以其在当时历史条件下是否促进生产力增长、降低社会成本、保护民间弹性、改善人才流动、增强反馈纠错并推动文明进步为根本标准。

国家控制力、行政穿透力、财政汲取力、国库充盈或账面人口田亩增长本身不自动构成正收益。主要依靠高压清查、告发连坐、身份固化、反馈堵塞、过度集权或制度错配强化国家机器的安排，应审查其社会净后果。

### 2.5 本人窗口与后世影响分离

只把本人实际创设、授权、执行或明确造成的结果归于本人。继任者的新决策、后代发挥和偶然变化不得回填；后世长期继承只能作为制度或文明生命力的旁证。

交班评价看本人离世、退位或失去实权时留下的状态，不以王朝最终寿命替代。

### 2.6 事实去重

同一成果和同一代价原则上只在最符合其核心含义的项目结算一次。分项之间可以共享事实来源，但不得共享同一计分结果。

## 3. 重复结算边界

| 易冲突项目 | 主要边界 |
|---|---|
| 第一项创业 vs 第二项制度 | 第一项看取得政权过程；第二项看正式统治期的制度建设与运行。 |
| 第一项创业战争 vs 第三项军事 | 第一项消费本人创业、统一和政权取得链；第三项消费取得统治权后的国家安全、边疆与军事体系。 |
| 第二项制度历史影响 vs 第二项交班韧性 | 制度历史影响看后世制度史；交班韧性看本人交班时制度能否继续运行。 |
| 第二项行政治理 vs 第二项政权交接 | 行政治理看日常国家机器；政权交接只看交班安全与断裂风险。 |
| 第二项民生经济 vs 第二项社会韧性 | 民生经济看统治期结果；社会韧性看交班时社会承压余量。 |
| 第二项民生经济 vs 第三项军事成本 | 第二项看百姓和经济实际承受结果；第三项看可归责军事投入是否换来相称安全成果。 |
| 第三项军事边疆 vs 第四项文明整合 | 第三项看安全与实际控制；第四项看认同、吸纳和共同体建设。 |
| 第二项制度影响 vs 第四项文明遗产 | 第二项限国家机器制度史；第四项限文明、文化和认同遗产。 |
| 第四项教育人才 vs 第二项制度行政 | 第二项看国家机器；第四项看教育、选才和人才流动的文明再生产。 |
| 第五项政治素质 vs 前四项成果 | 第五项评价统治者本人；前四项评价国家和社会实际得到的结果。 |
| 第六项关键决策 vs 具体成果 | 第六项评价关键节点判断；决策产生的制度、民生、军事或文明结果仍归对应项目。 |
| 第七项历史负债 vs 前六项净收益 | 第七项只处理前六项未充分覆盖的跨期结构性灾难。 |

第一项只对符合奠基准入的对象适用。“不适用”不是零分，也不得与适用对象混作同一分母的裸分比较。

## 4. 第一项：创业与政权取得能力（260）

### 4.1 评价内容

> 天下是怎么得到的？

评价奠基人在取得政权、建立独立国家、完成复国或统一过程中的战略设计、政治整合和本人军事贡献。

### 4.2 边界

计入：

- 起兵、夺权、建国、复国和统一过程
- 创业目标、起点条件和主要对手压力
- 创业路线与政治时机
- 创业团队组织和政治整合
- 本人在创业战争中的实际军事贡献

不计入：

- 普通继承和既成王朝内的个人皇权转移
- 正式统治期的制度与行政治理，归第二项
- 取得统治权后的国家安全和边疆经营，归第三项
- 长期文明整合，归第四项
- 一般政治素质，归第五项

王朝创建者、复国重建者、正式建国前具有决定性独立贡献的共同奠基者，以及实际建立独立政权但最终失败的创业者可以纳入。多人共同完成奠基时，只评价各自不可替代的本人贡献。

### 4.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 创业战略增益与难度兑现 | 60 |
| A2 | 创业路线效率与稳固 | 40 |
| B1 | 非本人团队关键成果组合 | 30 |
| B2 | 创业团队组织化能力 | 30 |
| C1 | 本人创业战争贡献与成果 | 50 |
| C2 | 本人前线指挥能力 | 50 |
| **合计** |  | **260** |

### 4.4 分项简述

- **A1 创业战略增益与难度兑现**：看本人面对怎样的起点、对手和局势，实际完成了多少创业目标。难度只能说明已兑现成果的含金量，不能脱离完成度单独形成成绩；战争净控制规模归A2，具体军事指挥归C。
- **A2 创业路线效率与稳固**：看创业目标取得是否迅速、少反复、能闭合，并形成可维持的早期政权结果。具体战役贡献归C，团队独立成果归B，正式建国后的治理得失归第二项。
- **B1 非本人团队关键成果组合**：看奠基人之外的团队实际闭合了什么关键成果，不以人才名单、官职数量或抽象声望替代成果。
- **B2 创业团队组织化能力**：看团队能否并行执行、连续替补并整合不同来源的人才和力量。一般用人与授权素质归第五项。
- **C1 本人创业战争贡献与成果**：看本人对创业战争结果实际贡献了多少。普通授权、名义领导和他人独立战果不归本人。
- **C2 本人前线指挥能力**：看本人亲自承担并解决了什么层级和难度的军事问题。个人勇武、亲征风险和战场声望不能脱离实际结果单独评价。

## 5. 第二项：治国净收益（465）

### 5.1 评价内容

> 国家治理得怎么样？

评价正式统治期内的制度、行政、民生经济，以及交班时的制度、社会和政权质量。

### 5.2 边界

计入：

- 正式统治期的制度创设、修复和运行
- 行政体系、官僚质量、监督纠错和政策执行
- 百姓生活、社会繁荣、经济活力和财政健康
- 离世、退位或失去实权时的制度、社会与政权状态

不计入：

- 夺权与创业过程，归第一项
- 对外军事安全和边疆控制，归第三项
- 文明认同、教育文化和文明遗产，归第四项
- 统治者个人素质，归第五项
- 关键节点判断能力，归第六项
- 跨期灾难性历史窟窿，归第七项

### 5.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 制度创设与修复 | 50 |
| A2 | 制度运行质量 | 50 |
| A3 | 制度历史影响力 | 40 |
| B1 | 吏治水平 | 60 |
| B2 | 纠错与监督能力 | 50 |
| B3 | 行政执行力 | 50 |
| C1 | 民生福祉与社会繁荣 | 70 |
| C2 | 经济活力与财政健康 | 40 |
| D1 | 交班制度韧性 | 20 |
| D2 | 社会韧性 | 20 |
| D3 | 政权交接稳定 | 15 |
| **合计** |  | **465** |

### 5.4 分项简述

- **A1 制度创设与修复**：看是否创设、重构、修复或成熟化关键国家制度，以及这些制度是否有利于降低治理成本、保护社会弹性并促进生产力和文明进步。制度当期运行归A2。
- **A2 制度运行质量**：看制度在本人统治期内是否稳定、顺畅、有效，并能适应实际治理。制度原创性归A1，后世制度史影响归A3。
- **A3 制度历史影响力**：看国家机器制度是否被后世长期继承、模仿或修正，并深刻影响政治结构。交班时能否继续运行归D1，文明文化遗产归第四项。
- **B1 吏治水平**：看官僚体系是否清明、稳定、专业、廉洁且可用。统治者个人识人用人素质归第五项B。
- **B2 纠错与监督能力**：看日常治理系统能否发现问题、约束官僚、吸收反馈并修正政策。单次重大危机止损归第六项B。
- **B3 行政执行力**：看中央政策能否转化为实际治理结果。高压控制本身不是正收益，其民生和长期后果分别归对应项目。
- **C1 民生福祉与社会繁荣**：看普通百姓生活、社会安定、赋役承受、战乱恢复、流民灾荒和民间生产的实际状况。国家强盛感和国库数字不能替代民生。
- **C2 经济活力与财政健康**：看生产流通、市场、农业、手工业、税制、财政和储备是否健康。极端压榨形成的短期充盈不构成健康财政。
- **D1 交班制度韧性**：看交班时制度能否脱离本人继续运行。制度对后世的长期影响归A3。
- **D2 社会韧性**：看交班时社会矛盾、民间承受能力和灾后恢复余量。统治期平均民生表现归C1。
- **D3 政权交接稳定**：看交班时继承安排、中枢、军权、宗室、外戚、权臣和军头是否造成即时断裂风险。后代长期治理成败不反推本人。

## 6. 第三项：军事与边疆净收益（250）

### 6.1 评价内容

> 国家安全提升多少？

评价正式统治期内的战略安全、边疆控制、军事体系和军事投入成本收益。

### 6.2 边界

计入：

- 消除或压低外部和重大内部战略威胁
- 建立、恢复和稳固安全边界
- 扩展、恢复或成熟化实际边疆控制
- 国家军事体系的实战、持续运行与可靠性
- 可归责军事投入与已兑现安全成果是否相称

不计入：

- 创业、统一和政权取得战争，归第一项
- 百姓生活和经济财政的最终承受结果，归第二项C
- 边疆地区的文明认同和文化吸纳，归第四项A
- 跨期不可逆的灾难性历史窟窿，归第七项

### 6.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 消除战略威胁 | 40 |
| A2 | 建立安全边界 | 40 |
| B1 | 控制规模 | 25 |
| B2 | 战略价值 | 30 |
| B4 | 交班成熟度 | 25 |
| C | 军事体系有效性 | 50 |
| D | 军事成本收益比 | 40 |
| **合计** |  | **250** |

### 6.4 分项简述

- **A1 消除战略威胁**：比较本人接掌与交班时的战略威胁状态，看重大外敌、长期内乱和颠覆风险是否实际下降。单场胜利未改变安全格局时不构成战略收益；地盘变化归B。
- **A2 建立安全边界**：看缓冲区、关隘、防线、边镇、交通和补给安全是否形成更有利的长期边界。单纯疆域扩大归B1，军事制度归C。
- **B1 控制规模**：看实际有效控制、收复、设治、羁縻和可执行宗主权的规模。纸面宣称、短期掠夺占领、普通友好和一次名义称臣不计。
- **B2 战略价值**：看控制对象是否具有关键走廊、门户、缓冲、资源、贸易或压制强敌的实际价值。面积本身不替代战略价值。
- **B4 交班成熟度**：看交班时主要边疆成果是否具备稳定驻军、行政、交通、补给和地方合作，是否仍依赖个人威望、临时重兵或异常投入。交班后的新变化不反推本人。
- **C 军事体系有效性**：综合看实战兑现、持续作战和体系可靠性。战略安全与控制收益分别归A、B；创业战争中的本人军事能力归第一项C；投入是否值得归本项D。
- **D 军事成本收益比**：看军事行动和边疆经营投入了多少可控军事资源，经历怎样的作战过程，最终取得什么安全结果。普通平乱只作辅助背景，异常规模、异常成本、重大失败或系统威胁才进入主要评价。敌军、叛军和平民损失不得当作本方军事成本；第一项和第三项C已完整消费的战争链不得重复结算。

## 7. 第四项：文明与国家整合收益（180）

### 7.1 评价内容

> 给文明留下什么？

评价国家共同体、文明整合、教育人才、思想文化生态和长期文明遗产。

### 7.2 边界

计入：

- 国家认同、区域和族群共同体建设
- 教育、选才与人才流动对文明再生产的贡献
- 学术环境、文化活力和知识生产
- 文明、文化、价值观和共同体层面的长期影响

不计入：

- 单纯国家机器制度创设和行政效率，归第二项
- 单纯军事占领、边疆安全和实际控制，归第三项
- 皇帝个人文艺爱好和与治理无关的宫廷娱乐
- 现代价值观的直接投射

### 7.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 国家认同与文明整合 | 60 |
| B | 教育与人才机制 | 45 |
| C | 思想与文化生态 | 35 |
| D | 长期文明遗产 | 40 |
| **合计** |  | **180** |

### 7.4 分项简述

- **A 国家认同与文明整合**：看新旧区域、族群和文化是否真正进入国家共同体。单纯军事占领和行政设治分别归第三项与第二项。
- **B 教育与人才机制**：看教育、学校、学术培养、选才和阶层流动是否增强文明再生产。选官制度作为国家机器的创设归第二项A1，当期官僚质量归第二项B1。
- **C 思想与文化生态**：看学术环境、文化活力、知识生产、典籍整理和思想生态的历史条件下净收益。思想控制和文化宽松均须看实际后果。
- **D 长期文明遗产**：看本人对文明认同、教育文化模式、价值观和共同体范式的长期影响。国家机器制度史影响归第二项A3。

## 8. 第五项：统治者政治素质（170）

### 8.1 评价内容

> 这个人本身是否是优秀统治者？

评价统治者作为政治人物的自律、用人、权力控制、政治品格和认知学习能力。

### 8.2 边界

计入：

- 持续治理投入与自我约束
- 识人、任人、授权和容人
- 对外戚、宦官、宗室、权臣、军头和继承风险的控制
- 对功臣、异见者、百姓和政治对手的政治伦理
- 战略思维、学习、政策理解和接受反馈能力

不计入：

- 具体制度、行政、民生、军事和文明成果，归前四项
- 关键历史节点的具体决策成败，归第六项
- 同一行为已经形成的跨期灾难性后果，归第七项

### 8.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 自律与勤政 | 30 |
| B | 用人与授权 | 45 |
| C | 权力控制能力 | 40 |
| D | 政治品格 | 25 |
| E | 认知与学习能力 | 30 |
| **合计** |  | **170** |

### 8.4 分项简述

- **A 自律与勤政**：看能否长期保持治理投入、自我约束和基本工作能力。勤政不能替代治理结果。
- **B 用人与授权**：看能否识人、任人、授权、容人并形成有效团队。官僚体系整体质量归第二项B1，创业团队整合归第一项B。
- **C 权力控制能力**：看能否控制外戚、宦官、宗室、权臣、军头和继承风险。交班时的实际结构稳定归第二项D3。
- **D 政治品格**：看待功臣、异见者、百姓和政治对手的信义、克制及政治伦理，重点评价其对政治秩序和国家净收益的影响。
- **E 认知与学习能力**：看战略思维、学习、政策理解、纠错和接受现实反馈的能力。关键节点的具体决策归第六项。

---

## 9. 第六项：关键历史决策能力（175）

### 9.1 评价内容

> 关键时刻会不会做决定？

评价重大历史节点上的判断、风险控制、止损和长期方向选择。

### 9.2 边界

计入：

- 战争、改革、迁都、废立、继承、外交等重大节点判断
- 危机处理、错误修正和战略止损
- 对国家长期方向和结构性风险的识别

不计入：

- 决策形成的具体制度、民生、军事和文明成果，归对应项目
- 一般性认知与学习素质，归第五项E
- 最终形成的跨期灾难性历史负债，归第七项

### 9.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 重大节点判断 | 60 |
| B | 风险控制与止损 | 50 |
| C | 长期战略眼光 | 65 |
| **合计** |  | **175** |

### 9.4 分项简述

- **A 重大节点判断**：看重大节点上的时机、方向、主次、人事和国家利益判断。行政执行和战争指挥归对应项目。
- **B 风险控制与止损**：看局势恶化时能否修正错误、控制风险、适时收缩并防止损失扩大。日常监督纠错机制归第二项B2。
- **C 长期战略眼光**：看能否判断长期国家方向，识别制度、边疆、继承和权力结构的远期隐患。隐患最终形成的历史窟窿归第七项。

## 10. 第七项：历史负债（0—300扣分项）

### 10.1 评价内容

> 给国家留下了多大的历史窟窿？

本项只评价前六项未充分覆盖的长期、结构性和灾难性历史负债，不提供正向分值。

### 10.2 边界

计入：

- 对国家、社会或文明造成跨期损害的重大错误
- 由统治者主动决策、持续放任或可归责失控造成的结构性窟窿
- 需要后继者长期修复，或已经造成国势逆转、政权崩溃的历史负担

不计入：

- 已在前六项充分吸收的普通代价
- 一般执政失误和短期可恢复损失
- 完全由后代独立决策造成的灾难
- 与本人决策缺乏明确因果关系的偶然事件

历史负债不是“所有缺点再扣一遍”。同一损害已在前六项完整处理时，不得在本项机械重复。
