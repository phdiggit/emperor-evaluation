# 中国古代皇帝综合评价体系评分总则

> 总则定义对象、项目边界与综合公式；分项执行细则见对应合同。

候选含皇帝（含追封）、实权摄政太后与天王；正式池须实际独立最高决策权≥3年且有可统一结算史料。第二项待结算可先入池，不计综合分/排名；窗口按实际权力，逐人范围及就绪见[对象规范](正式评价对象范围.md)。

## 2. 总原则

### 2.1 务实评价与统一尺度

以实证行为、成果、成本及后果评价，名望不补分。

遮去姓名应同判，开国、守成、亡国与摄政同尺度。

### 2.2 结果、过程、制度与运行分离

制度创设、行政执行、民生、军事、文明与个人素质分别举证；汲取不等净收益，能力不代结果。

### 2.3 净收益与跨期后果

跨期持续、严重性及修复负担只校准原结果，不另设历史负债。

### 2.4 生产力增长与文明进步

方向按当时生产力、社会成本、民间弹性、人才流动、反馈及文明进步判。

国家控制、汲取、库藏或登记规模不自动正向，高压强化须审社会净后果。

### 2.5 本人窗口与后世影响分离

归本人实际行动及授权结果；后继独立变化不回填，后世承继只验耐久。

交班评价看本人离世、退位或失去实权时留下的状态，不以王朝最终寿命替代。

### 2.6 事实去重

同事件可证不同独立后果，同后果不因多源/多表述重复计分。

创业统一整链归第一项；已形成可评价政权/主政窗口内可辅第三项C能力，不恢复A/B/D成果成本。

军损认定见[共同合同](../证据规则/军事成本评估合同.md)；各项独立换分，第三项排除不等第一项成本0。正式S1是扣成本后的0—240净分。

### 2.7 史料依据与研究边界

各项评分尽量以可追溯史料为依据，但受材料与研究范围限制，不保证史料强度和互证程度充分或一致；考古发现、民间杂记尚未纳入系统性整合研究，结论仅适用于现有证据范围。

## 3. 重复结算边界

| 易冲突项目 | 主要边界 |
|---|---|
| 第一项创业 vs 第二项制度 | 第一项看取得政权过程；第二项看正式统治期的制度建设与运行。 |
| 第一项创业战争 vs 第三项军事 | 第一项独占创业、统一和政权取得战争的成果与成本；第三项A/B/D只读第一项闭合后的独立军事链。创业战争若发生在可评价政权或实际主政窗口内，可仅作为第三项C的能力佐证。 |
| 第一项创业团队 vs 第五项用人 | 第一项消费创业窗口内非本人团队的独立成果和组织化结果；第五项只看本人可归责的识别、岗位匹配、授权、纠偏、容人和反徇私行为，不再次消费创业成果量级或团队人才存量。 |
| 第二项制度持续性 vs 第四项文明遗产 | 第二项只看国家机器在交班与后世是否继续运行、被继承或被修正；文化、教育、思想和共同体遗产归第四项。 |
| 第二项行政治理 vs 第二项政权交接 | 行政治理看日常国家机器；政权交接只看交班安全与断裂风险。 |
| 第二项民生经济 vs 第二项社会恢复 | 民生经济看统治期绝对结果；社会恢复只看本人窗口内已实现的净恢复。 |
| 第二项民生经济 vs 第三项军事成本 | 第三项完整计入主动进攻和被动防御的客观军事成本；第二项DA只计独立且未被C1—C3、K或C4恶化吸收的主动民力负担。可共用动员事实推断家庭传导，但不得重复折算军资、军粮和军事运输投入。 |
| 第三项军事边疆 vs 第四项文明整合 | 第三项看安全与实际控制；第四项看认同、吸纳和共同体建设。 |
| 第二项制度影响 vs 第四项文明遗产 | 第二项限国家机器制度史；第四项限文明、文化和认同遗产。 |
| 第四项教育人才 vs 第二项制度行政 | 第二项看国家机器；第四项看教育、选才和人才流动的文明再生产。 |
| 第二项反馈纠错 vs 第五项用人认知 | 第二项看日常信息、监督和纠错机制是否运行；第五项只看本人跨情境表现出的容人、理解和更新行为，制度化反馈入口不得在第五项再次得分。 |
| 第五项政治素质 vs 前四项成果 | 第五项评价统治者本人；前四项评价国家和社会实际得到的结果。 |
| 关键决策 vs 第一至第五项 | 创业决策质量归第一项A；治理、军事和文明决策按实际结果归第二至第四项；本人跨情境判断与更新模式归第五项A，不另设决策分。 |
| 跨期后果 vs 当期结果 | 跨期持续性、结构锁定和修复负担只校准第二至第四项对应结果的强度与耐久性，不另设负债扣分。 |

第一项不适用不同于0，原分不直接加共同项。

## 4. 第一项：政权奠基与统一贡献及能力（240）

### 4.1 评价内容

> 在建国、复国或尚未闭合的统一进程中，本人作出了什么贡献，体现了怎样的组织与军事能力？

### 4.2 边界

适用创建、复国、共同奠基、未闭统一链后继贡献及实际独立建政后失败者；纯继承、成熟扩张或王朝内部皇权转移不适用。共同成果先按阶段、区域、节点或`shared_result_group`分账。

### 4.3 分值构成

| 子项 | 名称 | 满分 |
|---|---|---:|
| A | 统一主链客观贡献 | 120 |
| B1 | 创业难度与战略效率 | 50 |
| B2 | 创业组织与政治整合 | 30 |
| C | 本人军事统帅与战争解题能力 | 40 |
| **合计** |  | **240** |

四轴毛分扣军事成本后得到正式净分：

`S1 = max(0, A + B1 + B2 + C - 军事成本扣分)`

各子项0.1分，无名望、正统或政权类型奖励。

### 4.4 分项简述

A评稳定控制，B1评起点/对手/效率，B2评组织，C评本人军事统帅与战争解题。具体准入与去重统一见下列合同。

[第一项合同](../分项规则/第一项政权奠基与统一贡献及能力/00-规则与计分合同.md)；[成本计分](../分项规则/第一项政权奠基与统一贡献及能力/07-军事成本计分合同.md)；[正式结算](../评分结算/第一项政权奠基与统一贡献及能力/01-第一项政权奠基与统一贡献及能力正式结算.md)。

### 4.5 综合分计入公式

综合榜使用以下量：

- `S_common=S2+S3`；`M=637`为两项正向上限之和。
- `S1`为第一项扣军事成本后的正式净分，`r=S1/240`。
- `CIV4`为第四项`-67.5—+67.5`调整。

符合奠基准入者的第一项条件附加分为：

`F = 0.20 × M × r^1.25`

不适用第一项者`F=0`，不加入共同分母。

`T = S_common + F + CIV4`

基准排序唯一。敏感性固定裁决、池与指数1.25：附加系数0.18/0.20/0.22，CIV4倍率0.8/1/1.2，共同倾斜d=-0.2/0/0.2，S2/S3分别乘`(1+d)×k`/`(1-d)×k`，`k=637/[387×(1+d)+250×(1-d)]`。展示9种纯附加、全部27种范围；机器保留单因素、参数与逐景名次，精度并列同基准。仅离散敏感性，不改正式权重，不含史料不确定性、不是置信区间/连续界，范围重叠不等同档。

F最高127.4，CIV4总跨度135，不按个别人补回去重分。展示共同项、S1、F、CIV4与T；[唯一统治成效综合评分榜](../评分结算/00-皇帝统治成效综合评分榜.md)只读`COMPOSITE_READY`。

## 5. 第二项：治国净收益（387）

### 5.1 评价内容

> 国家治理得怎么样？

评正式治理与交班的制度、行政、民生、财政与社会结果。

### 5.2 边界

与创业、军事、文明和人格的分工按§3。

### 5.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| 治理手段AB块 | A制度建设与B1行政执行互补合成 | 120 |
| 治理手段B2 | 反馈纠错与权力约束 | 45 |
| C1 | 民生福祉绝对状态 | 80 |
| C2 | 经济活力与财政健康绝对状态 | 35 |
| C3 | 社会安全绝对状态 | 60 |
| C4 | 社会恢复与可归责恶化 | 最高27，最低-40 |
| 交接质量D块 | D1行政连续性与D3权力交接等权合成 | 20 |
| **可排序合计上限** |  | **387** |

`第二项 = 治理手段165 + 治理结果(-27.5—202) + 交接质量20`，范围`-27.5—387`。方向卡指数不是独立分值；换算见[制度行政合同](../分项规则/第二项治国净收益/制度行政/00-规则与计分合同.md)，D1/D3等权及低侧封顶见[交接合同](../分项规则/第二项治国净收益/政权交接稳定/00-规则与结算合同.md)。

### 5.4 分项简述

- A评制度建设与接收；B1评行政可靠性；B2评反馈纠错和权力约束，具体档界见制度行政合同。
- C1家庭、C2经济财政、C3社会安全按主态固定分及L有限修正；C4评归责恢复/恶化，见[财政民生合同](../分项规则/第二项治国净收益/财政民生/00-规则与结算合同.md)。小政权不折扣。
- DA只计去重后的主动民力负担，准入、推断、档表见[分账合同](../分项规则/第二项治国净收益/财政民生/01-主动民力成本与军事分账合同.md)。
- D1评退出后行政连续，D3评实际权力交接安全，见交接合同。

## 6. 第三项：军事与边疆净收益（250）

### 6.1 评价内容

> 国家安全提升多少？

评价正式统治期内的战略安全、边疆控制、军事体系和军事投入成本收益。

### 6.2 边界

第一项已消费军事链排除；民生与文明后果归第二/第四项。

### 6.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 战略威胁状态与本人可归责变化 | 60 |
| A2 | 安全边界状态与本人可归责变化 | 60 |
| B1/B2/B4 | 控制规模与战略价值，经交班成熟度修正 | 80 |
| C | 军事体系有效性 | 50 |
| D | 军事成本固定扣分 | 不独立加分 |
| **合计** |  | **250** |

A按起终状态与归责，B按规模价值成熟，C按体系表现，D供全局固定成本；普通成本与ML取高。执行[国防合同](../分项规则/第三项军事与边疆净收益/国防安全/00-规则与结算合同.md)及[合并扣减合同](../分项规则/第三项军事与边疆净收益/00-合并计分与军事扣减合同.md)，最终总分四舍五入：

```text
第三项 = A120 + B80 + C50 - max(cost_debit, |military_net_loss_penalty|)
```

### 6.4 分项简述

A1威胁、A2边界；B1实际空间、B2战略价值、B4交班成熟；C军事体系的兑现、持续与可靠，无实战窗口按[C合同第三节](../分项规则/第三项军事与边疆净收益/军事体系有效性/00-规则与计分合同.md#三未知无实战与样本门禁)核验继承能力，不因未受检验归零；D成本。各轴不以名望、战争数量或他项成果替代事实。

## 7. 第四项：文明与国家整合收益（-67.5—+67.5有符号附加项）

### 7.1 评价内容

> 给文明留下什么？

按政权共享曲线固定继承与背景，再判本人社会整合、教育流动及知识生态净变化；不比裸数量或设时代折扣，后世只验耐久。

### 7.2 边界

国家机器、军事控制各归第二/第三项；个人才艺或内部娱乐须另证公共结果才准入，不要求服务行政，不重复计遗产。

### 7.3 分值构成

| 项目 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

### 7.4 分项简述

A共同体参与接纳；B教育可及流动；C知识、保存传播与生态。各须本人窗口可归责公共结果，规模、名称、场所与后世名望不代证。

后世只验原轴可信度/位置，不另设第四项D；国家制度史仍归第二项A。

详细执行见[第四项文明与国家整合收益规则与计分合同](../分项规则/第四项文明与国家整合收益/00-规则与计分合同.md)。

## 8. 第五项：统治者政治素质（不计分）

第五项保留独立评价与既有材料，不计分，不进入综合总榜，也不参与第一项附加分的共同上限计算。既有数值结算仅作留存资料，不构成当前计分依据。

### 8.1 评价内容

> 这个人本身是否是优秀统治者？

评履职认知、人事权力管理及强制伦理。

### 8.2 边界

只评跨情境本人模式，不重复消费前四项成果。

### 8.3 评价构成

本项不设计分权重或合计分，由履职与认知稳定性、人事与权力管理、政治克制与品格三个方面作独立评价。

### 8.4 分项简述

A履职认知，B识人授权与集团管理，C权力克制；行为事实不按名臣数、政绩规模或名望替代。

每人最小行为包，最多展示七条代表链，不截断完整证据；未完成双向复核不把缺料作中性。

材料与评价口径见[第五项统治者政治素质规则与计分合同](../分项规则/第五项统治者政治素质/00-规则与计分合同.md)。
