# 中国古代皇帝综合评价体系评分总则

> 本文档是当前有效的评分总则，只规定评价内容、项目边界、简要口径和分值构成。各项详细执行细则以对应分项规则为准，不在总则重复。

候选对象为中国古代政权的皇帝（包括被追封者）、实际摄政太后和天王。正式评价池进一步执行可行性准入：本人必须拥有至少3年的实际、独立最高决策权，并具有足以支持统一尺度结算的本地通读产物与史料；无实权、仅有有限本人选择或实际最高权力不足3年者不进入当前正式池。第二项无正式分但材料充分者可以先纳入池内，标为待结算；补齐前不得计算综合分或进入总排名。评价窗口只覆盖本人实际掌权时期。逐人准入、排除理由与结算就绪状态见[正式评价对象范围](正式评价对象范围.md)。

## 2. 总原则

### 2.1 务实评价与统一尺度

只看实际行为、实际成果、实际代价，以及本人留下的制度、社会、边疆和文明后果。不得因名气、王朝滤镜、后世宣传或传统名望补分。

同一事实在遮去人物姓名后应得到相同判断。开国者、守成者、亡国者和摄政者均受同一事实标准约束。

### 2.2 结果、过程、制度与运行分离

创业、制度、行政、民生、军事边疆、文明整合和个人素质分别评价。制度创设不等于制度运行，行政执行不等于民生收益，国家汲取能力不等于社会净收益，个人素质也不能替代实际成果。

### 2.3 净收益与跨期后果

前四项内部评价各自范围内的净收益，其中第一项通过条件附加公式进入综合分。跨期后果不是独立评分对象：制度、社会、军事、边疆和文明后果的持续性、严重度与修复负担，分别用于校准第二至第四项相应结果；不得从原结果中抽出后再设“历史负债”重复扣分。

### 2.4 生产力增长与文明进步

制度、政策和治理成果的方向判断，以其在当时历史条件下是否促进生产力增长、降低社会成本、保护民间弹性、改善人才流动、增强反馈纠错并推动文明进步为根本标准。

国家控制力、行政穿透力、财政汲取力、国库充盈或账面人口田亩增长本身不自动构成正收益。主要依靠高压清查、告发连坐、身份固化、反馈堵塞、过度集权或制度错配强化国家机器的安排，应审查其社会净后果。

### 2.5 本人窗口与后世影响分离

只把本人实际创设、授权、执行或明确造成的结果归于本人。继任者的新决策、后代发挥和偶然变化不得回填；后世长期继承只能作为制度或文明生命力的旁证。

交班评价看本人离世、退位或失去实权时留下的状态，不以王朝最终寿命替代。

### 2.6 事实去重

同一事件若产生性质不同、彼此不可替代的独立后果，可以分别进入不同评价构念；同一后果不得仅因存在多种表述、证据或因果链条而重复计分。

第一项已消费的创业、统一战争，其安全收益、控制成果和军事成本不得再进入第三项A、B、D；若战争发生在本人已形成可评价政权或实际主政窗口内，可以作为第三项C的军事体系能力佐证，但只能影响C的能力判断，不恢复第三项成果或成本信用。

第一、第三项的军事成本认定统一使用[军事成本评估合同](../证据规则/军事成本评估合同.md)，各项独立规定消费范围与扣分映射。第一项父链在第三项不适用，不等于其成本为零。第一项成本扣分映射、全池逐人裁决及去重已闭合，正式S1为五轴合计扣除军事成本后的净分，最低为0、最高240；综合折算公式不变。

| 第一项创业团队 vs 第五项用人 | 第一项消费创业窗口内非本人团队的独立成果和组织化结果；第五项只看本人可归责的识别、岗位匹配、授权、纠偏、容人和反徇私行为，不再次消费创业成果量级或团队人才存量。 |
| 第二项制度持续性 vs 第四项文明遗产 | 第二项只看国家机器在交班与后世是否继续运行、被继承或被修正；文化、教育、思想和共同体遗产归第四项。 |
| 第二项行政治理 vs 第二项政权交接 | 行政治理看日常国家机器；政权交接只看交班安全与断裂风险。 |
| 第二项民生经济 vs 第二项社会恢复 | 民生经济看统治期绝对结果；社会恢复只看本人窗口内已实现的净恢复。 |
| 第二项民生经济 vs 第三项军事成本 | 第二项看百姓和经济实际承受结果；第三项看可归责军事投入是否换来相称安全成果。 |

| 第二项制度影响 vs 第四项文明遗产 | 第二项限国家机器制度史；第四项限文明、文化和认同遗产。 |
| 第四项教育人才 vs 第二项制度行政 | 第二项看国家机器；第四项看教育、选才和人才流动的文明再生产。 |
| 第二项反馈纠错 vs 第五项用人认知 | 第二项看日常信息、监督和纠错机制是否运行；第五项只看本人跨情境表现出的容人、理解和更新行为，制度化反馈入口不得在第五项再次得分。 |
| 第五项政治素质 vs 前四项成果 | 第五项评价统治者本人；前四项评价国家和社会实际得到的结果。 |
| 关键决策 vs 第一至第五项 | 创业决策质量归第一项A；治理、军事和文明决策按实际结果归第二至第四项；本人跨情境判断与更新模式归第五项A，不另设决策分。 |
| 跨期后果 vs 当期结果 | 跨期持续性、结构锁定和修复负担只校准第二至第四项对应结果的强度与耐久性，不另设负债扣分。 |

第一项只对符合奠基准入的对象适用。“不适用”不是零分，也不得与适用对象混作同一分母的裸分比较。第一项原始分只用于计算奠基人条件附加分，不与共同项或第四项有符号调整直接相加。

## 4. 第一项：政权奠基与统一贡献及能力（240）

### 4.1 评价内容

> 在建国、复国或尚未闭合的统一进程中，本人作出了什么贡献，体现了怎样的组织与军事能力？

评价奠基人在取得政权、建立独立国家、完成复国或统一过程中的战略设计、政治整合和本人军事贡献。

本项不评价一般性的最高权力取得能力；既成王朝内部单纯的个人皇权转移不适用，不表示其夺权能力低下。

### 4.2 边界

计入：

- 起兵、夺权、建国、复国和统一过程
- 创业目标、起点条件和主要对手压力
- 创业路线与政治时机
- 创业团队组织和政治整合
- 本人在创业战争中的实际军事贡献

不计入：

- 普通继承和既成王朝内的个人皇权转移
- 正式统治期的制度与行政治理，归第二项
- 取得统治权后的国家安全和边疆经营，归第三项
- 长期文明整合，归第四项
- 一般政治素质，归第五项

第一项适用于王朝创建者、复国重建者、正式建国前共同奠基者，以及对尚未闭合的本王朝建国/统一主链产生实质新增或恢复成果的后继统一贡献者；实际建立独立政权但最终失败的创业者也可以纳入。普通继承、守成扩张、以及同一王朝内仅取得个人最高权力而没有新增或恢复建国/统一主链成果者不适用。多人共同完成奠基时，客观成果必须先按阶段、区域、成果节点或不可再拆的`shared_result_group`分账。

### 4.3 分值构成

| 子项 | 名称 | 满分 |
|---|---|---:|
| A | 统一主链客观贡献 | 100 |
| B1 | 创业难度与战略效率 | 50 |
| B2 | 创业组织与政治整合 | 30 |
| C1 | 本人军事统帅能力 | 40 |
| C2 | 本人前线指挥能力 | 20 |
| **合计** |  | **240** |

五个子项直接相加：

`S1 = A + B1 + B2 + C1 + C2`

各子项按0.1分结算；总分为其直接加总，不再使用旧A1/A2、B、C三轴结构或A130/B40/C70重加权。聚合不设置大一统、正统王朝、历史名望或政权类型奖励，也不新增补偿项。

### 4.4 分项简述

- **A 统一主链客观贡献**：只结算建国、复国或统一主链最终留下的稳定控制成果；起点、对手、速度、团队和本人军事能力不进入A。共同创业和跨代接力先形成一次项目A池，再按个人客观控制信用零和分账。
- **B1 创业难度与战略效率**：由起点难度、对手难度和完成效率构成；难度不能脱离已完成主链成果单独给分，A为零时B1为零。
- **B2 创业组织与政治整合**：结算并行执行、团队能力覆盖与组织杠杆、异质集团整合；成熟国家机器的继承不自动转换为组织能力。
- **C1 本人军事统帅能力**：结算本人在第一项主链战争中的组织、统帅和军事判断能力；名义领导、普通授权及他人独立战果不归本人。
- **C2 本人前线指挥能力**：只结算本人亲临主链战区后的前线指挥兑现；个人勇武、亲征风险和战场声望不能脱离实际结果单独评价。

第一项具体映射、门槛、共同创业分账、证据去重和与第三项的边界，以[第一项规则与计分合同](../分项规则/第一项政权奠基与统一贡献及能力/00-规则与计分合同.md)为准；正式结果以[第一项正式结算](../评分结算/第一项政权奠基与统一贡献及能力/01-第一项政权奠基与统一贡献及能力正式结算.md)为准。

### 4.5 综合分计入公式

第一项保留240分正式结算，用于比较符合奠基准入的对象；综合榜不直接累加该总分。设：

- `S_common`为第二、三项实际得分之和；
- `M`为第二、三项当前有效满分之和，即637；
- `S1`为第一项按A100、B1 50、B2 30、C1 40、C2 20直接加总的正式得分，`r = S1 / 240`；
- `CIV4`为第四项有符号文明调整，范围为`-67.5—+67.5`。

符合奠基准入者的第一项条件附加分为：

`F = 0.15 × M × r^1.25`

不符合奠基准入者不适用第一项，取`F = 0`，不得把“不适用”换算为第一项零分后加入共同分母。最终综合分统一为：

`T = S_common + F + CIV4`

总榜保留唯一基准排序，同时列示共同项合计、两个附加项和权重情景名次范围；第一项原分与第二、三项分数保留在分项明细中。敏感性诊断固定正式裁决、入榜池和指数1.25：第一项附加系数取0.12、0.15、0.18，第四项正负调整同步乘0.8、1、1.2；共同项倾斜参数`d`取-0.2、0、0.2，第二、三项分别乘`(1+d)×k`、`(1-d)×k`，其中`k=637/[387×(1+d)+250×(1-d)]`，保持共同正向上限637。总榜分别显示共同项不变时的9种附加项组合范围、全部27种组合范围；机器结果另保留单因素范围、情景参数及逐情景名次。情景采用与基准相同的总分精度及并列规则，不改写正式权重或分项结算。范围仅表示所列离散情景的最好至最差名次，不是置信区间或连续参数的严格界限，不包含史料与裁决不确定性；区间重叠不直接判同档。

该公式使第一项满分者最多取得共同正向上限15%的附加分，即当前最多95.55分，同时保持共同项每一分对奠基人与非奠基人的边际价值一致。该尺度统一体现创业贡献及治国机会成本，不按个别人物的跨项去重减分补回，也不改变第一项准入、原始结算或战争成果与成本去重边界。指数保持1.25。第四项正负两端的总区分跨度仍为原135分，不因改为有符号附加项而把权重翻倍。正式发布时应同时展示共同项得分、第一项正式分、第一项条件附加分、第四项有符号调整和最终综合分。当前唯一正式合成结果见[皇帝功业与治理净收益榜](../评分结算/00-皇帝功业与治理净收益榜.md)，只读取`COMPOSITE_READY`对象。

## 5. 第二项：治国净收益（387）

### 5.1 评价内容

> 国家治理得怎么样？

评价正式统治期内的制度、行政、民生经济，以及交班时的制度、社会和政权质量。

### 5.2 边界

计入：

- 正式统治期的制度创设、修复和运行
- 行政体系、官僚质量、监督纠错和政策执行
- 百姓生活、社会繁荣、经济活力和财政健康
- 离世、退位或失去实权时的制度、社会与政权状态

不计入：

- 夺权与创业过程，归第一项
- 对外军事安全和边疆控制，归第三项
- 文明认同、教育文化和文明遗产，归第四项
- 统治者个人素质，归第五项
- 已由第一、三、四、五项消费的创业、军事、文明或个人素质命题

### 5.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| 治理手段AB块 | A制度建设与B1行政执行互补合成 | 120 |
| 治理手段B2 | 反馈纠错与权力约束 | 45 |
| C1 | 民生福祉绝对状态 | 80 |
| C2 | 经济活力与财政健康绝对状态 | 35 |
| C3 | 社会安全绝对状态 | 60 |
| C4 | 社会恢复与可归责恶化 | 最高27，最低-40 |
| 交接质量D块 | D1行政连续性与D3权力交接等权合成 | 20 |
| **可排序合计上限** |  | **387** |

A、B1、B2、D1、D3方向卡继续保留作材料裁决与解释入口，其内部指数不是第二项分值，不得简单相加。治理手段以A/B1/B2内部指数换算为165分：`round1(0.8 × [max(A_index,B1_index) + 0.5 × min(A_index,B1_index)]) + round1(45/80 × B2_index)`；治理结果固定为`C1 80 + C2 35 + C3 60 + C4(-40—27)`，范围为-27.5至202；交接质量只读取D1与D3内部档位，等权合成并执行较弱一侧封顶，上限20。第二项总分为`治理手段165 + 治理结果 + 交接质量20`，范围最低-27.5、最高387。

### 5.4 分项简述

财政民生C1—C4对小政权不设置折扣机制，不因疆域、人口或政权体量较小而折减得分。

- **A 制度建设与实际运行**：合并原A1、A2，看关键国家制度是否被创设、重构、修复或成熟化，并采用任内运行与建设—接收两条入档路径。本人完成重大实质建设、实际颁行且制度后来明确接收时，即使B1/B2行政和反馈表现较差，A仍可取得中高档；只有制度名称、官署设置、静态条文或后人完全重建时不得进入高档。财政民生和军事结果只复验制度是否适用，不在A重复结算结果分。
- **B1 官僚治理与行政执行**：合并原B1、B3，看官僚激励、选任考课、专业性、廉洁度和组织可靠性是否足以把中央政策转化为实际治理结果。不要求重建全国官员总体样本；以具有代表性的运行链、系统性激励和中央—地方执行结果判断，少数名臣、酷吏或官名数量不得代替体系质量。统治者个人识人用人素质归第五项B。
- **B2 反馈纠错与权力约束**：在原B2基础上提高权重，看真实信息能否上达，臣下能否提出反对，监督能否约束官僚和最高权力，政策错误能否被实际修正。存在监察官署、偶次纳谏或一次危机止损本身不证明系统有效；只有单次采纳或零散纠偏、尚不能证明重复运行时停在G1，不得为了说明低档而反推不存在的拒谏负证。报忧获罪、拒谏杀谏、朝令夕改和纠偏后复发必须按范围与持续性进入判断。G4允许存在局部或阶段性失灵，关键是多种独立渠道在主要阶段反复生效，且报复、封闭或同类复发不占主导；重大危机和最高权力强烈偏好下仍能持续校正才进入G5。单次重大危机止损只有在同时暴露日常反馈机制时才作为本项材料，不因事件重大而另加决策分。
- **C1 民生福祉绝对状态**：看普通家庭实际获得的温饱、物质余量、赋役承受与人口再生产。先按全任绝对主态计分，再按K主态完整度折损；恢复幅度转交C4，治安与财政能力分别归C3、C2，国家强盛感和国库数字不能替代民生。
- **C2 经济活力与财政健康绝对状态**：看生产、流通、货币、常规公共财政、储备与调度系统是否健康，并检查公共财政是否以透支民间为代价。先按全任绝对主态计分，再按K主态完整度折损；恢复幅度转交C4。
- **C3 社会安全绝对状态**：看普通人的人身财产安全、基层秩序、司法救济和社会可预期性。先按全任绝对主态计分，再按K主态完整度折损；粮价、仓储、财政充盈与单纯政权存续不得替代社会安全结果。
- **C4 社会恢复与可归责恶化**：结算本人可归责的净恢复、状态恶化与主动成本；本人制造低谷后回到原基线只算止损。DA先排除必要治理基线和已由C1—C3主态、K或C4恶化吸收的成本，再按本人责任窗口内剩余主动成本的整体严重程度定一个档，不逐事件加扣。已确认本人主动征发大军且超出必要防御、平乱基线的，即使未记民力财政损害，也至少按DA1保底，不因史料沉默裁为DA0；更高档按整体成本判断，保底仍须去重且不另行叠加扣分。DA0—DA6依次扣0、4.5、9、13.5、18、22.5、27分；档位边界见财政民生合同§8.4，以所评政权实际承载能力判断，不对小政权打折。C4为保留恢复分减可归责恶化扣分、再减DA扣分，最终限制为-40至27，第二项可排序上限为387。
- **D1 继任行政连续性**：只看本人退出后的有限窗口内，既有官署、关键人员、命令、法律适用、财政征发和中央—地方传导是否继续实际运行。储位、遗诏、顾命名单、政变、宫禁和军权安全本身归D3，只有它们实际打断或维持行政机器时才投影D1。长期制度沿用、后世修订和跨朝影响统一归A；D1不再设置制度影响轴，也不消费A的耐久门禁。
- **D3 政权交接稳定**：看交班时继承安排、中枢、军权、宗室、外戚、权臣和军头是否造成即时断裂风险。后代长期治理成败不反推本人。

## 6. 第三项：军事与边疆净收益（250）

### 6.1 评价内容

> 国家安全提升多少？

评价正式统治期内的战略安全、边疆控制、军事体系和军事投入成本收益。

### 6.2 边界

计入：

- 消除或压低外部和重大内部战略威胁
- 建立、恢复和稳固安全边界
- 扩展、恢复或成熟化实际边疆控制
- 国家军事体系的实战、持续运行与可靠性
- 可归责军事投入与已兑现安全成果是否相称

不计入：

- 创业、统一和政权取得战争，归第一项
- 百姓生活和经济财政的最终承受结果，归第二项C
- 边疆地区的文明认同和文化吸纳，归第四项A
- 百姓、经济、文明等跨期后果，分别归第二项或第四项；军事安全与控制尾部仍在本项相应轴校准

### 6.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 战略威胁状态与本人可归责变化 | 60 |
| A2 | 安全边界状态与本人可归责变化 | 60 |
| B1/B2/B4 | 控制规模与战略价值，经交班成熟度修正 | 80 |
| C | 军事体系有效性 | 50 |
| D | 军事成本固定扣分 | 不独立加分 |
| **合计** |  | **250** |

A1、A2各先形成客观终点；本人改善逐档按`0／0.25／0.5／0.75／1.0`归责，高位守成按`0／10／15／25`、低位抗压保全按`0／3／6／10`加点，两者均须通过公共O档压力与本人保全归责门。A1、A2同档1—4档及终点5档的独立建设均按显著10／重大20乘本人归责记信用，封顶路径不另加倍率；跨档已消费的成果不得重复。正向专项取高、不叠加，每轴按实际计分路径写入唯一主类型。B80按`(55%×B1规模率＋45%×B2价值率)×(70%＋30%×B4成熟率)`形成成果信用。D按现有全局成本档与档内位置读取`factor`，并固定换算为`cost_debit=80×(1-factor)`。ML与普通成本只取较高扣分，不叠加。最终只在总分层四舍五入：

```text
第三项 = A120 + B80 + C50 - max(cost_debit, |military_net_loss_penalty|)
```

### 6.4 分项简述

- **A1 消除战略威胁**：比较本人接掌与交班时的战略威胁状态，看重大外敌、长期内乱和颠覆风险是否实际下降。起终同为1—4档而系统级威胁已结构性改善时，按`10×本人归责信用`记一次档内信用，与守成加分取高；不按链数累计，不重复跨档、控制或制度成果。单场胜利未改变安全格局时不构成战略收益；地盘变化归B。
- **A2 建立安全边界**：看缓冲区、关隘、防线、边镇、交通和补给安全是否形成更有利的长期边界。单纯疆域扩大归B1，军事制度归C。
- **B1 控制规模**：看实际有效控制、收复、设治、羁縻和可执行宗主权的规模。纸面宣称、短期掠夺占领、普通友好和一次名义称臣不计。
- **B2 战略价值**：看控制对象是否具有关键走廊、门户、缓冲、资源、贸易或压制强敌的实际价值。面积本身不替代战略价值。
- **B4 交班成熟度**：看交班时主要边疆成果是否具备稳定驻军、行政、交通、补给和地方合作，是否仍依赖个人威望、临时重兵或异常投入。交班后的新变化不反推本人。
- **C 军事体系有效性**：综合看实战兑现、持续作战和体系可靠性。战略安全与控制收益分别归A、B；创业战争中的本人军事能力归第一项C；投入是否值得归本项D。
- **D 军事成本固定扣分**：现有成本档和档内位置不变，`factor`只用于按80分基准换算固定扣分。ML是总军事扣分的严重度下限，与普通成本取高、不叠加。第一项创业统一整链成本继续排除；敌军、叛军和平民损失不得当作本方军事成本。

## 7. 第四项：文明与国家整合收益（-67.5—+67.5有符号附加项）

### 7.1 评价内容

> 给文明留下什么？

评价国家共同体的社会整合、教育与人才流动、知识生产和文化生态。各轴以政权阶段共享曲线固定继承基线、同时代可行前沿和非本人自然趋势，再裁决本人实际主政窗口的可归责净变化；不比较跨时代裸数量，也不设置统一时代折扣。长期影响只验证各轴结果的耐久性，不再单列一个“遗产”项目重复加分。

### 7.2 边界

计入：

- 国家认同、区域和群体之间的共同体参与与相互接纳
- 教育供给、受教育可及性、知识传递与人才流动
- 学术环境、文化活力和知识生产
- 上述结果在本人窗口以后是否具有可验证的延续、扩散或再生产能力

不计入：

- 单纯国家机器制度创设和行政效率，归第二项
- 单纯军事占领、边疆安全和实际控制，归第三项
- 选官制度创设本身和当期官僚质量，归第二项A、B1
- 同一认同、教育或文化成果的长期沿用，不另设遗产分重复奖励
- 皇帝个人文艺爱好和与治理无关的宫廷娱乐
- 现代价值观的直接投射

### 7.3 分值构成

| 项目 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

### 7.4 分项简述

- **A 国家共同体与社会整合**：看新旧区域、族群和文化群体是否形成可持续的共同体参与、认同和相互接纳。疆域扩大、军事占领、设官置县和财政行政穿透本身不构成本项收益。
- **B 教育可及与人才流动**：看教育供给、知识传递、受教育机会和跨身份人才流动是否增强文明再生产。选官制度的国家机器建设归第二项A，当期官僚质量归第二项B1；第四项只消费其教育、流动和社会开放后果。
- **C 知识生产与文化生态**：看学术空间、知识生产、典籍与文化公共品、思想和文化生态的历史条件下净收益。一次纳谏、皇帝个人文艺爱好或单个人才处置不能代替整体生态。

每一轴分别检验本人窗口内的实际结果及其耐久性。后世延续只能提高该轴结果的可信度和档内位置，不再形成独立的第四项D分数；国家机器制度史影响仍归第二项A。

详细执行见[第四项文明与国家整合收益规则与计分合同](../分项规则/第四项文明与国家整合收益/00-规则与计分合同.md)。

## 8. 第五项：统治者政治素质（不计分）

第五项保留独立评价与既有材料，不计分，不进入综合总榜，也不参与第一项附加分的共同上限计算。既有数值结算仅作留存资料，不构成当前计分依据。

### 8.1 评价内容

> 这个人本身是否是优秀统治者？

评价统治者作为政治人物的履职与认知稳定性、人事与权力管理能力，以及使用权力时的克制与政治品格。

### 8.2 边界

计入：

- 持续治理投入、自我约束、政策理解和认知更新
- 识别、岗位匹配、授权、纠偏、容人和反徇私行为
- 在位期间对外戚、宦官、宗室、权臣和军头等权力关系的管理
- 对功臣、异见者、百姓和政治对手的克制、程序底线和政治伦理

不计入：

- 具体制度、行政、民生、军事和文明成果，归前四项
- 创业团队独立成果、团队人才存量和官僚体系整体质量，归第一项B或第二项B1
- 日常制度化反馈入口与交班时的实际结构稳定，归第二项B2、D3
- 关键决策产生的具体制度、行政、民生、军事和文明结果，归前四项
- 同一行为已经形成的社会、军事或文明后果规模，归对应结果项

### 8.3 评价构成

本项不设计分权重或合计分，由履职与认知稳定性、人事与权力管理、政治克制与品格三个方面作独立评价。

### 8.4 分项简述

- **A 履职与认知稳定性**：看能否长期保持必要治理投入、工作纪律、自我约束、政策理解和面对反证时的认知更新。奏章、诏令或政策数量不直接换分，单次纳谏、一次危机止损和关键决策最终成败也不能替代跨情境表现。
- **B 人事与权力管理**：面向所有皇帝，评价本人可归责的识别、岗位匹配、授权边界、监督纠偏、容人保护、抵制徇私，以及对外戚、宦官、宗室、权臣和军头的配置、制衡与处置。受任者成果只验证行为是否有效，不按成果量级换分；团队人才存量、名臣数量和完整人才档案不作为必要输入。日常制度监督归第二项B2，交班结果归第二项D3。
- **C 政治克制与品格**：看对功臣、异见者、百姓和政治对手是否守信、克制并遵守基本程序底线。同一行为造成的社会或文明损害规模归对应结果项，本项只评价本人使用权力的行为性质。

第五项每人只建立一份最小充分统治行为包，三轴合计最多消费七条不重叠核心行为链。没有完整人物全集不构成缺陷；但未完成正负双向检索时不得把材料缺失当作中性结论。

材料与评价口径见[第五项统治者政治素质规则与计分合同](../分项规则/第五项统治者政治素质/00-规则与计分合同.md)。
