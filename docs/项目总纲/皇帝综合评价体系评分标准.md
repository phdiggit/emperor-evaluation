# 中国古代皇帝综合评价体系评分总则

> 本文档是当前有效的评分总则，只规定评价内容、项目边界、简要口径和分值构成。各项详细执行细则以对应分项规则为准，不在总则重复。

适用对象为中国古代政权的皇帝（包括被追封者）、实际摄政太后和天王。原则上剔除实际统治不足一年或没有实权的对象。评价窗口只覆盖本人实际掌权时期。

## 2. 总原则

### 2.1 务实评价与统一尺度

只看实际行为、实际成果、实际代价，以及本人留下的制度、社会、边疆和文明后果。不得因名气、王朝滤镜、后世宣传或传统名望补分。

同一事实在遮去人物姓名后应得到相同判断。开国者、守成者、亡国者和摄政者均受同一事实标准约束。

### 2.2 结果、过程、制度与运行分离

创业、制度、行政、民生、军事边疆、文明整合、个人素质、关键决策和历史负债分别评价。制度创设不等于制度运行，行政执行不等于民生收益，国家汲取能力不等于社会净收益，个人素质也不能替代实际成果。

### 2.3 净收益与历史负债分离

第一至第六项内部评价各自范围内的净收益，其中第一项通过条件附加公式进入综合分。第七项只处理尚未被前六项充分覆盖的长期历史窟窿，不把普通代价或同一失败重复扣除。

### 2.4 生产力增长与文明进步

制度、政策和治理成果的方向判断，以其在当时历史条件下是否促进生产力增长、降低社会成本、保护民间弹性、改善人才流动、增强反馈纠错并推动文明进步为根本标准。

国家控制力、行政穿透力、财政汲取力、国库充盈或账面人口田亩增长本身不自动构成正收益。主要依靠高压清查、告发连坐、身份固化、反馈堵塞、过度集权或制度错配强化国家机器的安排，应审查其社会净后果。

### 2.5 本人窗口与后世影响分离

只把本人实际创设、授权、执行或明确造成的结果归于本人。继任者的新决策、后代发挥和偶然变化不得回填；后世长期继承只能作为制度或文明生命力的旁证。

交班评价看本人离世、退位或失去实权时留下的状态，不以王朝最终寿命替代。

### 2.6 事实去重

同一成果和同一代价原则上只在最符合其核心含义的项目结算一次。分项之间可以共享事实来源，但不得共享同一计分结果。

第一至第三项已经形成当前正式结算，第四至第六项尚未结算。处理跨项重合时，由未结算项适配已结算项：第一至第三项已经消费的创业成果、治理结果和军事边疆净收益，不得为了给第四至第六项腾出空间而反向改写。相同史实可以作为不同构念的辅助证据，但成果规模、持续期、战略价值、社会净收益或损害强度只能由一个主项目计分；第四至第六项若不能从这些既有结果中分离出独立评价对象，则该事实在未结算项中不再得分。

| 第一项创业团队 vs 第五项用人 | 第一项消费创业窗口内非本人团队的独立成果和组织化结果；第五项只看本人可归责的识别、岗位匹配、授权、纠偏、容人和反徇私行为，不再次消费创业成果量级或团队人才存量。 |
| 第一项创业决策 vs 第六项重大选择 | 第一项A2已经计分的具名创业决策不再进入第六项；第六项只消费其他统治窗口内尚未结算的重大节点。 |
| 第二项制度持续性 vs 第四项文明遗产 | 第二项只看国家机器在交班与后世是否继续运行、被继承或被修正；文化、教育、思想和共同体遗产归第四项。 |
| 第二项行政治理 vs 第二项政权交接 | 行政治理看日常国家机器；政权交接只看交班安全与断裂风险。 |

| 第三项军事边疆 vs 第四项文明整合 | 第三项看安全与实际控制；第四项看认同、吸纳和共同体建设。 |
| 第二项制度影响 vs 第四项文明遗产 | 第二项限国家机器制度史；第四项限文明、文化和认同遗产。 |
| 第四项教育人才 vs 第二项制度行政 | 第二项看国家机器；第四项看教育、选才和人才流动的文明再生产。 |
| 第二项反馈纠错 vs 第五项用人认知 | 第二项看日常信息、监督和纠错机制是否运行；第五项只看本人跨情境表现出的容人、理解和更新行为，制度化反馈入口不得在第五项再次得分。 |
| 第二项反馈纠错 vs 第六项危机止损 | 第二项看日常机制；第六项只看异常危机或重大路线失效后的离散止损决定。 |
| 第五项政治素质 vs 前四项成果 | 第五项评价统治者本人；前四项评价国家和社会实际得到的结果。 |
| 第六项关键决策 vs 具体成果 | 第六项评价关键节点判断；决策产生的制度、民生、军事或文明结果仍归对应项目。 |
| 第七项历史负债 vs 前六项净收益 | 第七项只处理前六项未充分覆盖的跨期结构性灾难。 |

第一项只对符合奠基准入的对象适用。“不适用”不是零分，也不得与适用对象混作同一分母的裸分比较。第一项原始分只用于计算奠基人条件附加分，不与共同项或第四项有符号调整直接相加。

## 4. 第一项：创业与政权取得能力（240）

### 4.1 评价内容

> 天下是怎么得到的？

评价奠基人在取得政权、建立独立国家、完成复国或统一过程中的战略设计、政治整合和本人军事贡献。

### 4.2 边界

计入：

- 起兵、夺权、建国、复国和统一过程
- 创业目标、起点条件和主要对手压力
- 创业路线与政治时机
- 创业团队组织和政治整合
- 本人在创业战争中的实际军事贡献

不计入：

- 普通继承和既成王朝内的个人皇权转移
- 正式统治期的制度与行政治理，归第二项
- 取得统治权后的国家安全和边疆经营，归第三项
- 长期文明整合，归第四项
- 一般政治素质，归第五项

王朝创建者、复国重建者、正式建国前具有决定性独立贡献的共同奠基者，以及实际建立独立政权但最终失败的创业者可以纳入。多人共同完成奠基时，只评价各自不可替代的本人贡献。

### 4.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 创业战略增益与难度兑现 | 60 |
| A2 | 创业路线效率与稳固 | 40 |
| B1 | 非本人团队关键成果组合 | 30 |
| B2 | 创业团队组织化能力 | 30 |
| C1 | 本人创业战争贡献与成果 | 50 |
| C2 | 本人前线指挥能力 | 30 |
| **合计** |  | **240** |

### 4.4 分项简述

- **A1 创业战略增益与难度兑现**：看本人面对怎样的起点、对手和局势，实际完成了多少创业目标。难度只能说明已兑现成果的含金量，不能脱离完成度单独形成成绩；战争净控制规模归A2，具体军事指挥归C。
- **A2 创业路线效率与稳固**：看创业目标取得是否迅速、少反复、能闭合，并形成可维持的早期政权结果。具体战役贡献归C，团队独立成果归B，正式建国后的治理得失归第二项。
- **B1 非本人团队关键成果组合**：看奠基人之外的团队实际闭合了什么关键成果，不以人才名单、官职数量或抽象声望替代成果。
- **B2 创业团队组织化能力**：看团队能否并行执行、连续替补并整合不同来源的人才和力量。一般用人与授权素质归第五项。
- **C1 本人创业战争贡献与成果**：看本人对创业战争结果实际贡献了多少。普通授权、名义领导和他人独立战果不归本人。
- **C2 本人前线指挥能力**：看本人亲自承担并解决了什么层级和难度的军事问题。个人勇武、亲征风险和战场声望不能脱离实际结果单独评价。

### 4.5 综合分计入公式

第一项保留240分原始结算，用于比较符合奠基准入的对象；综合榜不直接累加该原始分。设：

- `S_common`为第二、三、五、六项实际得分之和；
- `M`为第二、三、五、六项当前有效满分之和；
- `S1`为第一项原始得分，`r = S1 / 240`；
- `CIV4`为第四项有符号文明调整，范围为`-67.5—+67.5`；
- `D7`为第七项历史负债扣分。

符合奠基准入者的第一项条件附加分为：

`F = 0.10 × M × r^1.25`

不符合奠基准入者不适用第一项，取`F = 0`，不得把“不适用”换算为第一项零分后加入共同分母。最终综合分统一为：

`T = S_common + F + CIV4 - D7`

该公式使第一项满分者最多取得共同正收益上限10%的附加分，同时保持共同项每一分对奠基人与非奠基人的边际价值一致。第四项正负两端的总区分跨度仍为原135分，不因改为有符号附加项而把权重翻倍。正式发布时应同时展示共同项得分、第一项原始分、第一项条件附加分、第四项有符号调整、第七项扣分和最终综合分。

## 5. 第二项：治国净收益（405）

### 5.1 评价内容

> 国家治理得怎么样？

评价正式统治期内的制度、行政、民生经济，以及交班时的制度、社会和政权质量。

### 5.2 边界

计入：

- 正式统治期的制度创设、修复和运行
- 行政体系、官僚质量、监督纠错和政策执行
- 百姓生活、社会繁荣、经济活力和财政健康
- 离世、退位或失去实权时的制度、社会与政权状态

不计入：

- 夺权与创业过程，归第一项
- 对外军事安全和边疆控制，归第三项
- 文明认同、教育文化和文明遗产，归第四项
- 统治者个人素质，归第五项
- 关键节点判断能力，归第六项
- 跨期灾难性历史窟窿，归第七项

### 5.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| 治理手段AB块 | A制度建设与B1行政执行互补合成 | 120 |
| 治理手段B2 | 反馈纠错与权力约束 | 45 |
| C1 | 民生福祉绝对状态 | 80 |
| C2 | 经济活力与财政健康绝对状态 | 35 |
| C3 | 社会安全绝对状态 | 60 |
| C4 | 社会恢复与承压韧性 | 45 |
| 交接质量D块 | D1行政连续性与D3权力交接等权合成 | 20 |
| **可排序合计上限** |  | **405** |

A、B1、B2、D1、D3方向卡继续保留作材料裁决与解释入口，其内部指数不是第二项分值，不得简单相加。治理手段以A/B1/B2内部指数换算为165分：`round1(0.8 × [max(A_index,B1_index) + 0.5 × min(A_index,B1_index)]) + round1(45/80 × B2_index)`；治理结果固定为`C1 80 + C2 35 + C3 60 + C4 45`，上限220；交接质量只读取D1与D3内部档位，等权合成并执行较弱一侧封顶，上限20。第二项总分为`治理手段165 + 治理结果220 + 交接质量20`，上限405。当前159人正式入口为[`01-第二项治国净收益405分正式结算.md`](../评分结算/第二项治国净收益/01-第二项治国净收益405分正式结算.md)。

### 5.4 分项简述

- **A 制度建设与实际运行**：合并原A1、A2，看关键国家制度是否被创设、重构、修复或成熟化，并采用任内运行与建设—接收两条入档路径。本人完成重大实质建设、实际颁行且制度后来明确接收时，即使B1/B2行政和反馈表现较差，A仍可取得中高档；只有制度名称、官署设置、静态条文或后人完全重建时不得进入高档。财政民生和军事结果只复验制度是否适用，不在A重复结算结果分。
- **B1 官僚治理与行政执行**：合并原B1、B3，看官僚激励、选任考课、专业性、廉洁度和组织可靠性是否足以把中央政策转化为实际治理结果。不要求重建全国官员总体样本；以具有代表性的运行链、系统性激励和中央—地方执行结果判断，少数名臣、酷吏或官名数量不得代替体系质量。统治者个人识人用人素质归第五项B。
- **B2 反馈纠错与权力约束**：在原B2基础上提高权重，看真实信息能否上达，臣下能否提出反对，监督能否约束官僚和最高权力，政策错误能否被实际修正。存在监察官署、偶次纳谏或一次危机止损本身不证明系统有效；只有单次采纳或零散纠偏、尚不能证明重复运行时停在G1，不得为了说明低档而反推不存在的拒谏负证。报忧获罪、拒谏杀谏、朝令夕改和纠偏后复发必须按范围与持续性进入判断。G4允许存在局部或阶段性失灵，关键是多种独立渠道在主要阶段反复生效，且报复、封闭或同类复发不占主导；重大危机和最高权力强烈偏好下仍能持续校正才进入G5。单次重大危机止损仍归第六项B，只在其同时暴露日常反馈机制时作为本项材料。
- **C1 民生福祉绝对状态**：看普通家庭实际获得的温饱、物质余量、赋役承受与人口再生产。只按全任绝对主态计分；恢复幅度、K稳定性、治安与财政能力分别转交C4、C3、C2，国家强盛感和国库数字不能替代民生。
- **C2 经济活力与财政健康绝对状态**：看生产、流通、货币、常规公共财政、储备与调度系统是否健康，并检查公共财政是否以透支民间为代价。只按全任绝对主态计分；恢复幅度和K稳定性转交C4。
- **C3 社会安全绝对状态**：看普通人的人身财产安全、基层秩序、司法救济和社会可预期性。粮价、仓储、财政充盈与单纯政权存续不得替代社会安全结果。
- **C4 社会恢复与承压韧性**：只结算本人可归责的净恢复和稳定兑现、压力吸收。本人制造低谷后回到原基线只算止损；没有重大冲击不加分也不扣分；C1/C2/C3的绝对主态与高终点不在C4重复得分，终局状态只作低侧封顶。
- **D1 继任行政连续性**：只看本人退出后的有限窗口内，既有官署、关键人员、命令、法律适用、财政征发和中央—地方传导是否继续实际运行。储位、遗诏、顾命名单、政变、宫禁和军权安全本身归D3，只有它们实际打断或维持行政机器时才投影D1。长期制度沿用、后世修订和跨朝影响统一归A；D1不再设置制度影响轴，也不消费A的耐久门禁。
- **D3 政权交接稳定**：看交班时继承安排、中枢、军权、宗室、外戚、权臣和军头是否造成即时断裂风险。后代长期治理成败不反推本人。

## 6. 第三项：军事与边疆净收益（250）

### 6.1 评价内容

> 国家安全提升多少？

评价正式统治期内的战略安全、边疆控制、军事体系和军事投入成本收益。

### 6.2 边界

计入：

- 消除或压低外部和重大内部战略威胁
- 建立、恢复和稳固安全边界
- 扩展、恢复或成熟化实际边疆控制
- 国家军事体系的实战、持续运行与可靠性
- 可归责军事投入与已兑现安全成果是否相称

不计入：

- 创业、统一和政权取得战争，归第一项
- 百姓生活和经济财政的最终承受结果，归第二项C
- 边疆地区的文明认同和文化吸纳，归第四项A
- 跨期不可逆的灾难性历史窟窿，归第七项

### 6.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A1 | 战略威胁状态与本人可归责变化 | 60 |
| A2 | 安全边界状态与本人可归责变化 | 60 |
| B1/B2/B4 | 控制规模与战略价值，经交班成熟度修正 | 80 |
| C | 军事体系有效性 | 50 |
| D | 军事成本成果信用修正 | 不独立加分 |
| **合计** |  | **250** |

A1、A2各先形成客观终点与负债锚，再分离本人可归责的正向改善、结构推进或高压守成信用。B80按`(55%×B1规模率＋45%×B2价值率)×(70%＋30%×B4成熟率)`形成成果信用。D不再另加40分，而以全局成本档和档内位置折算A正向成果信用与B80；A客观终点、负向责任和C50能力不折损。最终只在总分层四舍五入：

```text
第三项 = A非成本锚 + 成本系数 × (A正向成果信用 + B80) + C50
```

### 6.4 分项简述

- **A1 消除战略威胁**：比较本人接掌与交班时的战略威胁状态，看重大外敌、长期内乱和颠覆风险是否实际下降。单场胜利未改变安全格局时不构成战略收益；地盘变化归B。
- **A2 建立安全边界**：看缓冲区、关隘、防线、边镇、交通和补给安全是否形成更有利的长期边界。单纯疆域扩大归B1，军事制度归C。
- **B1 控制规模**：看实际有效控制、收复、设治、羁縻和可执行宗主权的规模。纸面宣称、短期掠夺占领、普通友好和一次名义称臣不计。
- **B2 战略价值**：看控制对象是否具有关键走廊、门户、缓冲、资源、贸易或压制强敌的实际价值。面积本身不替代战略价值。
- **B4 交班成熟度**：看交班时主要边疆成果是否具备稳定驻军、行政、交通、补给和地方合作，是否仍依赖个人威望、临时重兵或异常投入。交班后的新变化不反推本人。
- **C 军事体系有效性**：综合看实战兑现、持续作战和体系可靠性。战略安全与控制收益分别归A、B；创业战争中的本人军事能力归第一项C；投入是否值得归本项D。
- **D 军事成本成果信用修正**：看军事行动和边疆经营投入了多少本方直接军事资源，以及这些投入换来的A/B正向成果应兑现多少信用。D局部成本档继续服务战略链内部去重；全局成本视图另纳入因第三项C能力消费者而退出D评分的本人正式统治期任务成本，但只用于成果信用折算，不恢复D成果分或负分。第一项创业统一整链成本继续排除；敌军、叛军和平民损失不得当作本方军事成本，第二项财政民生后果和第七项跨期结构透支也不进入本修正。

## 7. 第四项：文明与国家整合收益（-67.5—+67.5有符号附加项）

### 7.1 评价内容

> 给文明留下什么？

评价国家共同体的社会整合、教育与人才流动、知识生产和文化生态。各轴以政权阶段共享曲线固定继承基线、同时代可行前沿和非本人自然趋势，再裁决本人实际主政窗口的可归责净变化；不比较跨时代裸数量，也不设置统一时代折扣。长期影响只验证各轴结果的耐久性，不再单列一个“遗产”项目重复加分。

### 7.2 边界

计入：

- 国家认同、区域和群体之间的共同体参与与相互接纳
- 教育供给、受教育可及性、知识传递与人才流动
- 学术环境、文化活力和知识生产
- 上述结果在本人窗口以后是否具有可验证的延续、扩散或再生产能力

不计入：

- 单纯国家机器制度创设和行政效率，归第二项
- 单纯军事占领、边疆安全和实际控制，归第三项
- 选官制度创设本身和当期官僚质量，归第二项A、B1
- 同一认同、教育或文化成果的长期沿用，不另设遗产分重复奖励
- 皇帝个人文艺爱好和与治理无关的宫廷娱乐
- 现代价值观的直接投射

### 7.3 分值构成

| 项目 | 名称 | 调整范围 |
|---|---|---:|
| A | 国家共同体与社会整合 | -22.5—+22.5 |
| B | 教育可及与人才流动 | -22.5—+22.5 |
| C | 知识生产与文化生态 | -22.5—+22.5 |
| **合计** |  | **-67.5—+67.5** |

### 7.4 分项简述

- **A 国家共同体与社会整合**：看新旧区域、族群和文化群体是否形成可持续的共同体参与、认同和相互接纳。疆域扩大、军事占领、设官置县和财政行政穿透本身不构成本项收益。
- **B 教育可及与人才流动**：看教育供给、知识传递、受教育机会和跨身份人才流动是否增强文明再生产。选官制度的国家机器建设归第二项A，当期官僚质量归第二项B1；第四项只消费其教育、流动和社会开放后果。
- **C 知识生产与文化生态**：看学术空间、知识生产、典籍与文化公共品、思想和文化生态的历史条件下净收益。一次纳谏、皇帝个人文艺爱好或单个人才处置不能代替整体生态。

每一轴分别检验本人窗口内的实际结果及其耐久性。后世延续只能提高该轴结果的可信度和档内位置，不再形成独立的第四项D分数；国家机器制度史影响仍归第二项A。

详细执行见[第四项文明与国家整合收益规则与计分合同](../分项规则/第四项文明与国家整合收益/00-规则与计分合同.md)。

## 8. 第五项：统治者政治素质（120）

### 8.1 评价内容

> 这个人本身是否是优秀统治者？

评价统治者作为政治人物的履职与认知稳定性、人事与权力管理能力，以及使用权力时的克制与政治品格。

### 8.2 边界

计入：

- 持续治理投入、自我约束、政策理解和认知更新
- 识别、岗位匹配、授权、纠偏、容人和反徇私行为
- 在位期间对外戚、宦官、宗室、权臣和军头等权力关系的管理
- 对功臣、异见者、百姓和政治对手的克制、程序底线和政治伦理

不计入：

- 具体制度、行政、民生、军事和文明成果，归前四项
- 创业团队独立成果、团队人才存量和官僚体系整体质量，归第一项B或第二项B1
- 日常制度化反馈入口与交班时的实际结构稳定，归第二项B2、D3
- 关键历史节点的具体决策成败，归第六项
- 同一行为已经形成的跨期灾难性后果，归第七项

### 8.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 履职与认知稳定性 | 35 |
| B | 人事与权力管理 | 50 |
| C | 政治克制与品格 | 35 |
| **合计** |  | **120** |

### 8.4 分项简述

- **A 履职与认知稳定性**：看能否长期保持必要治理投入、工作纪律、自我约束、政策理解和面对反证时的认知更新。奏章、诏令或政策数量不直接换分，单次纳谏、一次危机止损和关键决策最终成败也不能替代跨情境表现。
- **B 人事与权力管理**：面向所有皇帝，评价本人可归责的识别、岗位匹配、授权边界、监督纠偏、容人保护、抵制徇私，以及对外戚、宦官、宗室、权臣和军头的配置、制衡与处置。受任者成果只验证行为是否有效，不按成果量级换分；团队人才存量、名臣数量和完整人才档案不作为必要输入。日常制度监督归第二项B2，交班结果归第二项D3。
- **C 政治克制与品格**：看对功臣、异见者、百姓和政治对手是否守信、克制并遵守基本程序底线。同一社会损害和跨期负债的规模分别归结果项和第七项，本项只评价本人使用权力的行为性质。

第五项每人只建立一份最小充分统治行为包，三轴合计最多消费七条不重叠核心行为链。没有完整人物全集不构成缺陷；但未完成正负双向检索时不得把材料缺失当作零分。

详细执行见[第五项统治者政治素质规则与计分合同](../分项规则/第五项统治者政治素质/00-规则与计分合同.md)。

## 9. 第六项：关键历史决策能力（90）

### 9.1 评价内容

> 关键时刻会不会做决定？

评价尚未被第一项创业决策消费的重大历史节点选择，以及异常危机中的风险识别、修正和止损。候选只从第一至第五项已接受父链机械派生，评价依据以决策当时可得信息、可选方案和后续更新过程为主，不以结果规模回填决策分，也不另做全生涯宽搜。

### 9.2 边界

计入：

- 战争、改革、迁都、废立、继承、外交等重大节点的选择与长期方向判断
- 危机处理、错误修正和战略止损
- 在后果充分显现前对结构性风险或机会的识别和前置安排

不计入：

- 决策形成的具体制度、民生、军事和文明成果，归对应项目
- 第一项A2已经计分的具名创业决策
- 一般性履职与认知素质，归第五项A
- 最终形成的跨期灾难性历史负债，归第七项

### 9.3 分值构成

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 重大选择与长期方向 | 50 |
| B | 危机处置与风险止损 | 40 |
| **合计** |  | **90** |

### 9.4 分项简述

- **A 重大选择与长期方向**：看离散高风险节点上，在当时信息和可选方案下，对时机、方向、主次、人事、国家利益和长期结构的判断质量。制度、民生、军事和文明成果规模不在本项再次换分；第一项A2已消费的创业决策直接排除。
- **B 危机处置与风险止损**：看异常危机或重大路线失效后，能否及时识别风险、更新判断、改变承诺、收缩暴露并停止损失扩大。日常监督纠错机制归第二项B2，军事成本和最终损失规模归第三项D或其他结果项。

第六项按少数不重叠重大决策弧结算，每人最多消费三条按事前重要性选出的决策弧，不以决策、诏令或事件数量累加。同一决策产生的业务结果只能归第一至第四项；第六项只消费决策时点的判断质量和更新过程。长期方向不再单设C轴，避免以制度寿命、疆域、文明遗产或后世负债反向重复计分。

详细执行见[第六项关键历史决策能力规则与计分合同](../分项规则/第六项关键历史决策能力/00-规则与计分合同.md)。

## 10. 第七项：历史负债（0—300扣分项）

### 10.1 评价内容

> 给国家留下了多大的历史窟窿？

本项只评价从前六项负向父链触发、但尚未被充分覆盖的长期、结构性和灾难性历史负债，不提供正向分值，也不开放搜索人物全部历史错误。

### 10.2 边界

计入：

- 对国家、社会或文明造成跨期损害的重大错误
- 由统治者主动决策、持续放任或可归责失控造成的结构性窟窿
- 需要后继者长期修复，或已经造成国势逆转、政权崩溃的历史负担

不计入：

- 已在前六项充分吸收的普通代价
- 一般执政失误和短期可恢复损失
- 完全由后代独立决策造成的灾难
- 与本人决策缺乏明确因果关系的偶然事件

历史负债不是“所有缺点再扣一遍”。同一损害已在前六项完整处理时，不得在本项机械重复。

详细执行见[第七项历史负债规则与计分合同](../分项规则/第七项历史负债/00-规则与计分合同.md)。
