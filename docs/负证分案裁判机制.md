# 负证分案裁判机制

本机制用于第五项B《用人与授权》的高风险负证裁判。它不生成评分，不替代人工裁判，只约束证据卡的候选强度和分案记录。

## 为什么增加本机制

- 防止“杀功臣、处置能臣、死后信任逆转”被机械高估。
- 防止史料真实但归因错误。
- 防止第五项B与第五项C、第五项D、第五项E、第二项B2、第二项B3混项。

## 分案流程

1. 先判断当事人是否确有谋反、违法、失职或明确政权安全风险。
2. 再判断是否有疑忌、罗织、逼反、扩大化。
3. 再判断是否有追悔、平反、复碑、恢复评价。
4. 再判断是生前伤害还是死后信任逆转。
5. 再判断是单案处置还是系统性清洗。
6. 最后才给候选强度。

## 典型规则

- 确有谋反链条：默认不得高于弱负。
- 未坐实但有强嫌疑：默认不得高于中负。
- 死后信任逆转：默认弱负。
- 有追悔、恢复评价：必须降权或标待人工裁判。
- 系统牵连扩大、死徙以千数、群臣不敢正言等可支持强负候选。
- 极负必须人工裁判，Codex 不得直接写入。

## 李世民问题作为规则案例

- 侯君集：谋反链条明确，最多弱负候选。
- 张亮：有强嫌疑但反形未具且太宗追悔，可中负候选。
- 魏征身后：死后信任逆转且可能有恢复评价，默认弱负候选，需补对照材料。

上述案例只作为分案规则示例；本任务不处理 task005b3 分支，不新增李世民证据卡。
