# 第五项B自动结算规则

本规则用于把第五项B的证据组结论映射为自动结算草案。它只处理规则敏感点、带位方向和人工复核触发条件，不输出分数、排名或总榜。

## 一、适用范围

本规则适用于第五项B《用人与授权》的成熟试点阶段，尤其是已经完成以下步骤的材料：

1. 原子证据卡已回源。
2. 证据组已完成相邻项剥离。
3. 净证据池已生成。
4. 对象锚点已作为轻量标签进入证据卡或证据组。

## 二、自动结算的输出

自动结算层只输出三类内容：

1. `band_direction`：自动带位方向。
2. `confidence`：规则命中的置信层级。
3. `rule_sensitive_points`：命中的规则敏感点。

自动结算替代人物级/证据簇级人工裁判的常规流程；不替代的是规则级复核与最终正式定档确认。

## 三、规则敏感点

### 1. 中负边界不阻断极正上探

当正向证据已形成多维高位强正，而负向材料只是带有 `mitigation_flag`、`upper_bound_flag` 或明显边界属性的中负时，默认不阻断极正上探。

默认处理：

- 保留中负边界；
- 降低置信度；
- 继续保留极正候选标记；
- 不把边界负证机械抬成强负拦截。

### 2. 单一维度强正不能直接上探极正

当正向证据主要集中在创业期军政授权、单一人才类型或单一对象池时，强正封顶，不得直接推到极正。

默认处理：

- 维持强正；
- 若缺少长期中枢治理、文臣生态、反馈入口或异质人才整合等新维度，则不入极正；
- 只有在多维覆盖成立时才考虑上探。

### 3. 强负核心压制强正

当强负核心直接命中表达安全、谏臣保护、人才安全感或反馈入口，而正向又已成立时，自动结论应保留强正基础，但不得上探极正。

默认处理：

- 保留强正底盘；
- 标记“强正受压制”；
- 触发高档位上探拦截；
- 进入规则级复核。

### 4. 相邻项剥离后的强负默认中负剩余

当负向材料原本来自系统性牵连、司法残酷、政权安全或政治残酷性，而相邻项已被剥离后，只剩本项剩余影响时，默认按中负处理。

默认处理：

- 除非存在直接寒蝉硬证，否则不自动保留强负；
- 若出现“群臣莫敢正言”“表达安全破坏”等硬证，再考虑升级为强负核心；
- 不能把相邻项结果直接回填为本项强负。

## 四、带位方向约定

带位方向只表达自动结算结论，不代表最终定档。

常见方向包括：

- `高位强正，上探极正候选`
- `强正受压制，不上探极正`
- `高位强正，极正候选受中负边界提示`
- `中正受中负压制`
- `中正受强负压制`

## 五、规则级复核

规则级复核只问四件事：

1. 规则是否命中。
2. 规则是否被误触发。
3. 边界负证是否被抬高过头。
4. 是否存在仍需回到人物级人工裁判的异常情况。

如果上述问题都能由规则层解释清楚，就不再回到逐人逐卡裁判。

## 六、与导出文件的关系

自动结算规则对应两个导出文件：

- `exports/markdown_views/第五项B自动结算规则敏感点清单.md`
- `exports/markdown_views/第五项B三人自动结算草案.md`

前者列规则，后者列自动结算结果。
