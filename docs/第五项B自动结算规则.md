# 第五项B自动结算规则

本规则用于把第五项B的证据组结论映射为自动结算草案。它只处理规则敏感点、带位方向和人工复核触发条件，不输出分数、排名或总榜。

## 一、适用范围

本规则适用于第五项B《用人与授权》的成熟试点阶段，尤其是已经完成以下步骤的材料：

1. 原子证据卡已回源。
2. 证据组已完成相邻项剥离。
3. 净证据池已生成。
4. 对象锚点已作为轻量标签进入证据卡或证据组。

## 二、自动结算的输出

自动结算层只输出三类内容：

1. `band_direction`：自动带位方向。
2. `confidence`：规则命中的置信层级。
3. `rule_sensitive_points`：命中的规则敏感点。

自动结算替代人物级/证据簇级人工裁判的常规流程；不替代的是规则级复核与最终正式定档确认。

自动结算结果与规则/算法审查必须分层处理：

- `auto_band_direction`、evidence profile、规则敏感点和 warning 均为复核材料，不等于 V3.2 九档正式档位。
- 当前自动结算层不直接给人物正式分，不生成排名、阶段总榜或总榜。
- 人工复核只检查规则是否误触发、算法是否解释得通、数据是否回源完整、相邻项剥离是否正确。
- 异常结果应回到数据、规则或算法层修复，不做单人人物 override，也不把人工备注写成正式分数或正式档位。

## 三、规则敏感点

### 1. 边界负证分两类

#### A. 弱负上调为中负的边界负证

这一类只做轻量边界提示，不阻断极正或高位上探。

默认处理：

- 只降低置信度；
- 不作为强负核心；
- 典型形态是带 `mitigation_flag` / `upper_bound_flag` 的轻边界中负。

#### B. 中负上调为强负的边界负证

这一类阻断极正或高位上探，进入强负核心或强负拦截候选。

默认处理：

- 必须说明为何突破中负封顶；
- 仍不得机械扩大到极负，除非另有极负硬证；
- 只对直接命中表达安全、人才安全或授权可信度破坏的材料生效。

### 2. 单一维度强正三核心可上探极正

单一维度强正默认强正封顶。

默认处理：

- 若同一维度内至少存在三个强正核心，且均为第五项B直接证据，则允许上探极正候选；
- 若不足三个强正核心，则不得上探极正；
- 三个强正核心不得由战功、政绩、边疆收益、治世光环回填生成。

### 3. 相邻项强负剥离后的 B 项剩余

#### 3.1 相邻项主导的识别

以下因素优先切出第五项B：

- 谋反、宗室威胁、政权安全、储位/藩王安全 → 第五项C；
- 司法残酷、株连、刑罚严酷、酷烈处置 → 第五项D；
- 行政威慑、官僚执行、基层控制、法令贯彻 → 第二项B3 或相关行政项；
- 认知/谶纬/灾异判断、皇帝反省判断 → 第五项E 或第二项B2 等对应项；
- 军事战果、边疆收益、战役胜负 → 第一项/第三项。

#### 3.2 第五项B剩余的识别

剥离后，只有以下内容保留在第五项B：

- 是否直接破坏人才安全感；
- 是否让臣僚不敢表达；
- 是否损害容谏入口；
- 是否造成群臣寒蝉、人才退缩、谏臣安全破坏；
- 是否破坏授权可信度或功臣/能臣安全预期。

#### 3.3 默认强度

相邻项主导的大案，剥离后第五项B默认只留中负剩余；
若只体现事件严重、死徙多、牵连广，但没有直接表达寒蝉/人才安全硬证，不得保留强负；
若出现“群臣莫敢正言”、明确表达寒蝉、人才退缩、谏臣/能臣安全受损等硬证，才保留强负核心；
若只有轻微外溢或象征性影响，则可降为边界负证或备注。

#### 3.4 一句话固定

大案本身严重 ≠ 第五项B强负；
大案导致人才生态/表达安全直接受损 = 第五项B强负。

### 4. 强负核心压制强正

#### 4.1 强正底盘定义

强正底盘指：

 - 皇帝在识人、拔擢、授权、专任、容谏入口、人才生态等第五项B直接维度上，已有稳定强正证据组；
 - 该强正不能由战功、政绩、边疆收益、治世光环直接回填；
 - 可以是多维强正，也可以是满足三个强正核心的单一维度强正。

#### 4.2 强负核心定义

强负核心必须直接命中第五项B核心，不是所有负证都算。包括：

 - 谏臣因直言遭重罚；
 - 表达入口被破坏；
 - 群臣莫敢正言；
 - 人才安全感受到直接冲击；
 - 功臣/核心人才因非充分责任被严重处置并形成寒蝉；
 - 授权可信度因皇帝处置方式受到结构性破坏。

不包括：

 - 单个边界负证；
 - 有谋反/政权安全主因且已切第五项C的案件；
 - 已被封顶为中负的身后信用反转；
 - 主要属于司法残酷或政权安全的材料；
 - 只有象征性或轻度外溢的材料。

#### 4.3 正负结算方式

强正成立 + 强负核心成立：

- 不机械抵消；
- 保留“强正基础”；
- 自动标记“强正受压制”；
- 阻断极正上探；
- 若强负核心为多条或结构性寒蝉，可进一步压低到中正受强负压制。

#### 4.4 一句话固定

会用人不等于人才生态无硬伤；
强负核心直接命中表达安全/人才安全时，强正底盘保留，但极正上探被阻断。

## 四、带位方向约定

带位方向只表达自动结算结论，不代表最终定档。

常见方向包括：

- `高位强正，上探极正候选`
- `强正封顶，不上探极正`
- `强正受压制，不上探极正`
- `中正受中负压制`
- `中正受强负压制`

## 五、规则级复核

规则级复核只问四件事：

1. 规则是否命中。
2. 规则是否被误触发。
3. 边界负证是否被抬高过头。
4. 是否存在仍需回到人物级个案复核的异常情况。

如果上述问题都能由规则层解释清楚，就不再回到逐人逐卡裁判。

## 六、与导出文件的关系

自动结算规则对应两个导出文件：

- `exports/markdown_views/第五项B自动结算规则敏感点清单.md`
- `exports/markdown_views/第五项B三人自动结算草案.md`

前者列规则，后者列自动结算结果。
