# G2.6G 物化阻断与 v2.4 身份契约

状态：`failed_closed_before_candidate_score`

## 结论

G2.6G 按隔离协议冻结了全新输入、Boundary Review、Historical Gold 和 Rule Gold，但首次 Episode Graph 物化未生成候选文件，因而不得报告 recall、precision 或 RuleEvidenceUnit 指标。PostgreSQL G3 继续阻断。

输入为杨坚、赵匡胤的 32 个只读 V3 claim，共 66 条 Assertion 与 66 个 SourcePassage。Boundary reviewer 在不读取 Gold 的条件下提出 32 个 Episode group、20 条 Relation 和 103 个完整 pair disposition；Historical Gold 独立冻结 38 个 Episode、27 条 Relation；Rule Gold 独立冻结 15 个规则证据单元。

## 阻断原因

v2.3 只要求多 passage 合并时提供 reviewer-level `atomic_event_key`。它没有要求每个已经拆开的单 passage group 都有独立原子键。

首次物化发现 6 对不同原子事件具有完全相同的 evaluation context、participant roles、action、责任域、时间和地点。它们因此生成相同 semantic fingerprint 与 Episode ID，使 `outcome_of` 或 `causal_followup` Relation 退化为自环。

该问题发生在 candidate graph 成功创建之前。Gold 冻结后不得回填这 12 个 group 的 key，因此本批只能失败关闭，不能修补后继续作为 blind 证据。

## v2.4 修复

`episode-boundary-review-v2.4` 规定：

1. 每个 EpisodeBoundaryGroup 必须声明非空 `atomic_event_key`；
2. 确定性单 Proposition 快通道使用 proposition semantic hash 生成该键；
3. reviewer key 进入 semantic fingerprint，local episode code 与 Gold code 仍不进入；
4. 不同 group 若仍生成重复 Episode ID，materialization 在 Relation 构造前直接失败；
5. v2.3 缺键结果不得进入 v2.4 cache。

G2.6G 从此只作身份碰撞回归集。必须在另一批全新输入上验证 v2.4，才可能形成正式 Graph Blind 指标。
