## Schema Live Apply 边界

生产 schema live apply 只表示 schema-only baseline 已被允许并可验证，不表示 production migration 完成。执行前必须有显式人工批准；批准文本仍由工具检查为 `批准所有权限`。该路径允许读取 DSN、连接数据库和执行 schema SQL，但不得读取生产 seed/data manifest，不得写 target business table，不得发布评分、排名或榜单。

机器检查锚点：

```text
schema live apply execution pr
allows dsn read
allows db connect
allows sql execution
allows public schema write
does not execute seed/data apply
does not mark production migration complete
future target importer gate required
must not fake success
```
