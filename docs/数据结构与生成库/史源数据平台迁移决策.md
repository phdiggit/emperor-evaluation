## PostgreSQL Contract 的保留原因

`db/postgres/001_init.sql` 仍可作为未来设计讨论的 schema contract。它记录源文档、段落、候选匹配、证据链、任务、outbox 和导入审计等结构设想，但当前仓库没有对应的 active runtime 或 importer。

保留 schema contract 不等于：

- 批准 PostgreSQL 成为唯一写源；
- 批准 source/passages 或 evidence/cluster/anchor/relationship 业务表写入；
- 批准 production runtime；
- 批准最终总榜、阶段总榜、跨子项 leaderboard 或新排名发布。
