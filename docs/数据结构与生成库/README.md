# 数据结构与生成库

## 本目录负责什么

本目录负责 JSONL 过渡主表字段、query/search 字段、稳定 ID、SQLite 本地生成库、史源上下文机制、离线史料包过渡契约、对象化证据输入契约、规则承载对象关系模型、retrieval_v2 clean 抓包流程、史源数据平台迁移决策、史源数据平台实现设计和批次文件生命周期等数据结构与生成库规则。

## 本目录不负责什么

本目录不定义评分语义，不替代证据裁判，不规定 Markdown 展示形态，也不承载单个分项的业务归项规则。

## 与相邻目录的边界

- 证据强度、负证触发和对象锚点，进入 `证据规则/`。
- 子项计入/不计入和相邻项切分，进入 `分项规则/`。
- 人工阅读导出与 scripts 协作，进入 `展示与协作/`。
- registry 机器登记，进入 `文档与脚本登记/`。
