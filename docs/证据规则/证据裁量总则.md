# V4 证据裁量总则

> 状态：`review_ready`

## 1. 证据角色

- `primary_source`：原始或准原始史源；
- `authoritative_edition`：可定位的权威整理版本；
- `scholarly_secondary_source`：用于解释、校勘、身份或史学争议；
- `discovery_only`：百科、索引、一般文章、搜索摘要。

只有前两类默认可承载正式事件事实；学术二手来源可支持解释和冲突处理，不替代原始事件证据。

## 2. 最小可用证据

正式 Assertion 必须具备：

- 明确 SourceDocument；
- 可定位 SourcePassage；
- 原文；
- 足够上下文；
- 内容 hash；
- 来源和抓取 provenance；
- 对应抽取字段。

缺一项时只能进入候选或补查队列。

## 3. 直接性

证据裁量至少考虑：

- 史源距离事件的时间与制度距离；
- 叙述者身份；
- 是否一手记录；
- 是否后世编纂；
- 是否存在明确来源链；
- 是否为论赞、传闻、奏报或正式记录。

来源等级不直接变成固定分数；它决定证据用途、冲突处理和可接受性。

## 4. 归因

归因至少分：

- 皇帝直接决策；
- 皇帝批准/采纳；
- 臣僚主导、皇帝间接责任；
- 制度惯性；
- 结果相关但因果不明；
- 不能归因。

规则判断必须引用归因证据，不得把“发生在某朝”自动算给皇帝。

## 5. 史家评价

史家评价可用于：

- 人物或政策的历史共识；
- 因果解释；
- 评价争议；
- 发现补查方向。

但史家评价不自动替代具体 action、responsibility 和 outcome 事实。

## 6. 多源一致

多来源一致可以增强证据充分性，但不得按来源数量重复计分。同源转抄、同一底本、现代页面复制必须识别为非独立来源。

## 7. 冲突

冲突处理顺序：

1. 确认是否同一事件；
2. 区分原书、版本和转抄关系；
3. 对比时间、人物、动作和结果字段；
4. 查找校勘或学术解释；
5. 保留各自 Assertion；
6. 给出当前接受、并列或阻断结论。

模型不得通过摘要把冲突平均化。

## 8. 负证触发

以下情况必须主动查负证：

- 极强正向或负向判断；
- 名人光环明显；
- 单一来源给出完整因果链；
- 结果与传统叙述差异大；
- 可能存在诬告、政治清洗或后世神化；
- 任用结果只展示成功，不展示代价；
- 失败可能由外部因素而非用人本身造成。

## 9. 不得入证

- 无 locator 的摘抄；
- 搜索结果摘要；
- 模型生成引文；
- 无法区分原书与承载站的页面；
- 断章取义；
- 只有现代作者结论、无事实依据的评论；
- 仅因 V3 已经使用而未重新核验的材料。

## 10. 接受状态

- `candidate`
- `needs_source_review`
- `needs_context`
- `accepted`
- `accepted_with_limitations`
- `rejected`
- `retired`

限制条件必须结构化，不能只写在自由文本备注里。

## 11. 可追溯性

正式 Judgment 的每个核心因子必须能回到：

```text
factor
→ episode field
→ assertion
→ source passage
→ source document
```

任何断链都阻断正式发布。
