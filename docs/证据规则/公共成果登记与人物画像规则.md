# 公共成果登记与人物画像规则

> 状态：当前 shadow 公共规则。适用于所有评分项；分项文档只能引用和投影，不得复制一套战役、治理、人才或政治风险事实。

## 一、公共对象

史料先形成中性的 `HistoricalEpisode`，再按独立结果归并为 `HistoricalOutcomeCluster`。人物画像从公共成果和风险事件重建。评分项只能后置判断适用性、方向和数值，不得建立评分专属事实副本。

固定数据顺序为：中性材料 → 无皇帝窗口的战役、治理与谋略成果总登记 → 皇帝窗口绑定 → 规则材料映射 → 计分。成果总登记不得包含 `ruler_window_status`、当前皇帝结算范围或人才计分信用；窗口无法判断只阻断该皇帝投影，不能删除成果。皇帝作为事件参与者的亲征、授权或治理责任属于成果事实，不等于把成果绑定进某位皇帝的评分窗口。

同一事实和同一独立结果只保存一次；跨书材料用于补足责任、规模、结果、持续性和冲突，不按来源数重复登记。Google、网页摘要和模型常识只作发现线索。

## 二、战役登记

### 1. 战役群优先

一个统一战略目标、主要对手或区域竞争链形成一个父级战役群。具体交战、围城、追击、受降、撤军和补给损耗作为子事件保留逐字史源与单战结果，默认不另算独立成果。

总登记把完整战略链记为 `campaign_group`；人物在其中独立统帅不同战区、对手或战略阶段并形成独立终局时，另登记 `campaign_subresult` 并引用父级。后置投影才决定皇帝结算消费父级、人物人才消费哪些本人独立成果；不得为防止皇帝重复计分而删除韩信平魏、破赵、平齐这类独立指挥成果，也不得让同一评分消费者同时结算父子两级。

划分顺序：

1. 有明确主要对手时，按对手和同一战略目标合并；
2. 无单一对手时，按区域与功能阶段合并；
3. 同一区域的取得、保持、反复和丧失优先合并；
4. 只有产生独立终局、开启新战略阶段或合并会掩盖重大责任时才另立战役群。

父级保存整体 `battle_result` 与 `objective_completion`；子事件可有不同胜败。整体未达最高目标但取得重大阶段成果时登记为 `mixed / partial`，不能只保留胜利或只保留失败。

### 2. 人物指挥身份与皇帝关系分轴

军事参与者按其对当前注册战役群的最高实际指挥责任只取一档：`主帅`统摄战役群全局、节度多路军并承担最高军事责任；`主将`独立指挥一支主力或一个主要方向，并直接承担主要阶段结果；`从攻`有可核实作战贡献但没有主力独立指挥权。不另设 `副将`：史书称某人为主帅之副，只证明其受总帅节制；若仍独立指挥主力方向，登记为 `主将`，否则登记为 `从攻`。官名只是线索，最终以节度关系、独立统军权、实际行动和结果责任判断。同一人在子事件中表现突出，不自动改变其在父级战役群中的最高身份；若一个方向形成可独立验收的终局，应另立人物子成果后再判断其在该子成果中的身份。

征吐谷浑战役群中，《旧唐书》明确记载李靖为西海道行军大总管，侯君集与任城王道宗“并为之副”；随后李靖分军，侯君集、道宗共同统领南路深入。故父级登记李靖为节度诸军的 `主帅`，侯君集以主力南路独立指挥权登记为 `主将`；“为之副”保留在责任依据中，不再映射为单独角色。

皇帝未进入军事指挥链时登记为 `不在军事指挥链`，不能为了容纳皇帝身份虚构“从攻”。皇帝对一个父级战役群只登记一个皇权关系：

| 代码 | 含义 |
| --- | --- |
| `obstructed` | 皇帝阻止、掣肘或撤销既定军事行动，并有明确责任证据 |
| `acquiesced` | 皇帝知情默许，但没有建立明确主动授权或统筹 |
| `authorized` | 皇帝批准目标、任命统帅或正式授权出兵，但未进入战区统筹 |
| `temporary_theater_control` | 皇帝临时到达战区压阵、督战、收束或处置危机，主战由他人完成 |
| `sustained_theater_control` | 皇帝长期坐镇主战区并持续统筹多路军、节奏和资源 |
| `personal_command` | 皇帝亲征并直接承担前线核心统帅责任 |

皇权关系互斥，并按最终达到的最高实际参与覆盖低档：`personal_command > sustained_theater_control > temporary_theater_control > authorized > acquiesced > obstructed`。已经亲征就不再同时登记授权，长期统筹不再同时登记临时坐镇；过程中的低档关系只保留在子事件事实，不进入父级角色。若皇帝最终有效阻止、撤销或掣肘该战役且没有转为更高参与，才登记 `obstructed`。必须保存最高角色的行动和逐字依据。武将身份回答“谁实际指挥”，皇权关系回答“皇帝如何控制、支持或阻碍”，两者不得互相替代。

例如赵构对岳飞军事行动的阻挠，应登记赵构的 `obstructed + not_in_command_chain` 皇权责任，并保留岳飞自己的实际指挥身份；不能把赵构写成从攻，也不能因皇帝没有亲征而把阻挠责任排除在战役登记之外。

### 3. 过程负面

战役最终结果和过程逆境分开保存。公共登记使用中性档位，不直接保存分项分数：

| 档位 | 含义 |
| --- | --- |
| `none` | 无明显过程负面 |
| `limited` | 小挫、不克非核心目标或轻微损耗，未改变主目标 |
| `material` | 重要目标未达、重要部队或机动力明显受损，成果仍可保留 |
| `severe_repaired` | 主力重创或门户失控，但在同一战役群内修复并取得正向终局 |
| `near_collapse_repaired` | 几近战略失败，虽后来赢回但修复成本极高 |
| `terminal_failure` | 核心目标彻底失败且未在同线修复，形成独立终局 |

每项同时保存固定负面指数 `0 / 0.20 / 0.40 / 0.60 / 0.70 / 1.00`，与上述档位一一对应，供后置投影读取；公共成果登记不直接计算分项得分。敌方主力损失支持正向战果，我方人员、战马、舟船、器械和补给损失进入过程负面，二者不能机械相抵。正常动员、追击、敌军来援、战役困难或未追求决定性终局不属于过程负面；`none` 只写“无达到过程负面门槛的事实”，不得罗列每场战争都有的普通成本。

过程负面属于战役群，责任属于人物，必须分开登记。非 `none` 项逐条保存责任人、责任类型和逐字依据：`primary` 为本人决策或直接指挥导致，`shared` 为共同决策或系统责任，`subordinate_execution` 为部将执行导致，`disobedience` 为部将违令导致，`mitigated` 为存在明确减责事实，`not_responsible` 为证据明确排除该人责任，`external_unattributed` 为天气、疾病或敌方行动等不归责本方人物。不得因为某人是主帅就默认把战役链全部负面归给他。

贞观十九年征高句丽应登记为一个父级远征战役群：盖牟城、辽东城、白岩城、驻跸山、安市城等为子事件；整体为 `mixed / partial`，安市为失败子事件，拔城和驻跸山胜利保留正向事实，撤军及机动力损耗进入 `material` 过程负面。不得只登记安市，也不得把各城重复算成多个完整远征成果。

### 4. 战略结果等级与作战难度

字母等级只表示已经兑现的战略结果，不表示战斗打得多难。每项仍必须列明土地轴、对手在当时竞争体系中的位置、交战状态和结果轴；对手位置使用 `弱小力量 / 区域主要对手 / 第一梯队竞争极 / 主导竞争极 / 一般外部国家 / 外部霸权`，不得再用含义游移的“国家级”或“帝国主力”。

| 战略结果类 | 战役等级 | 成立边界 |
| --- | --- | --- |
| `local_tactical` | `C` | 局部战术或低权重辅助结果 |
| `important_objective` | `B` | 重要清障、防御或单项目标，没有形成主要战略终局 |
| `major_stage_or_crisis` | `A` | 主要区域、门户、主力集团或重大阶段目标；重大失败或国家危机也按其实际影响登记 |
| `independent_direction` | `S-` | 独立强区域终局、核心根据地或长期战略方向成立 |
| `single_pole_or_state_terminal` | `S` | 终结一个第一梯队竞争极、决定单一国家存亡或整场战争 |
| `composite_poles_terminal` | `S+` | 同一战役群一次终结两个以上第一梯队竞争极 |
| `unification_terminal` | `S+` | 终结主导竞争极并直接完成从同等小型起点开始的国内统一链 |
| `external_hegemony_terminal` | `S+` | 击溃外部霸权的统治结构，并持久逆转本国所处安全秩序 |

`S+` 只允许后三条硬路径，不得用“艰苦”“名将大胜”或普通灭国代替。虎牢同时终结王世充、窦建德，走复合竞争极终局；垓下终结项羽主导竞争极并完成汉初统一链，走统一终局；灭东突厥只有在汗国统治结构崩解并逆转唐初安全秩序时才走外部霸权终局。白登面对外部霸权但结果失败，不能因对手强而升为 `S+`。

作战难度另记 `D0–D3`：`D0` 为残余或显著优势下的低难度行动，`D1` 为常态可战对手，`D2` 为强主力、坚城、复杂地形或显著后勤困难，`D3` 为极端兵力态势、霸权压迫、连续击败本方主力或近乎崩溃后逆转。难度必须有当时交战事实支持，不能只凭对手历史声望；它不得改变字母等级。刘黑闼可以因连续击败唐军主力登记为 `A / D3`，而不虚增其战略结果。

等级依据固定逐项写 `土地轴`、`对手轴` 和 `结果轴`；难度依据另写，不机械取平均。当前仅互校汉初刘邦创业统一链与唐初李渊—李世民创业统一链，且不混入匈奴、突厥、高句丽等对外战争；互校只防止同类战略结果系统性错档，不要求两边战役数量或档位集合相同。

## 三、治理成果登记

按以下顺序判定，任一步不成立即停止，不得靠后文补猜：

1. **结果门**：是否已有制度生效、持续程序、跨个案公共效果、明确先例或可验收公共产品；只有动作、意图或建议则拒绝。
2. **独立门**：能否独立运行、归责和验收；同一改革的法令、组织、执行与初期效果通常合并一项。
3. **事实门**：逐字史源能否同时支持结果、规模和人物责任；缺一项就拒绝或降为中性 Episode。
4. **登记门**：先写不绑定皇帝的 `governance_result`，再由窗口绑定决定是否进入某皇帝投影。

| 事实类型 | 处理 |
| --- | --- |
| 已生效并持续改变税负、服役、任期、司法等权利义务 | 登记；制度约束本身即结果 |
| 已运行制度、跨个案公共效果、完成并投入使用的公共产品 | 登记 |
| 迁都、设官、建机构、任命、结约、颁令，但没有生效或公共结果 | 只留 Episode |
| 奏疏、谏言、批评，没有独立实施或结果史源 | 只供相应规则消费，不登记成果 |
| 单案改判、一次礼遇、个人赏罚、官职、参会、一般言行 | 不登记成果 |
| 政变、清洗、权力争夺仅改变最高权力归属 | 不登记治理成果；按需进入谋略事实或政治风险 |

特殊类型只按下表处理：

| 类型 | 登记规则 |
| --- | --- |
| 粮价、人口、生产、治安等宏观结果 | 登记 `macro_public_result`；原文明示承接总体治理用 `source_attributed`，仅同时期关系用 `limited`，不得伪归因于单项政策 |
| 一代正史、跨代通史或同量级大型典籍 | 完成并投入国家使用即为 `national_cultural_corpus`；普通单朝实录通常仅 `important` |
| 文明奠基作品 | 仅本人独著、主编或最终定稿，且作品开创范式并长期作为基础文本，才可标 `era_shaping / foundational` |
| 专业目标伴随跨领域代价 | 保留专业结果，代价另行登记；不得在成果簿内机械抵消 |

人物责任只取一档：`exclusive`=独立建立且无同级共同主导者；`lead`=主导方案或持续执行；`governance_participant`=有逐字证据的实质参与；`authorized`=只批准或维持授权。授权、任职和参会不能推定实施责任。所有人物的外窗口成果仍供全生涯画像使用，但不得计入错误的皇帝窗口。

## 四、谋略成果登记

谋略成果与战役、治理并列，只登记本人提出或主导、已被采纳并形成独立可核实战略结果的非指挥成果。它只供人物画像消费，不进入皇帝治理投影，也不把谋士伪装成主帅。未实施建议、一般献策、只有手段成功而无独立战略结果、纯夺权或宫廷清洗均不登记；玄武门谋划和云梦骗捕韩信不得仅凭行动成功转成正向成果。

谋略规模沿用公共结果的 `local / important / regional / national / era_shaping`，但含义限于战略影响范围。成员仍按 `exclusive / lead / governance_participant / authorized` 记录实际责任；同一战争或危机中的多个步骤只有能独立归责、独立产生结果时才可拆分。

## 五、人才等级

人才等级是跨皇帝复用的全生涯能力轴，政治风险与其正交。实绩限定上限，权威评价用于校准归属、时代位置、置信度和相邻档，不以官职、声望或单次高光定档。军事与治理分别定档，不得让治理成果猜测对应哪个战役字母档。

人物画像登记不得以团队建设材料预算为名单边界。凡在战役、治理、谋略或政治风险登记中具有可归责记录的人物都进入总人物表；正向八人、负向三人及支持材料的选择只作为后置投影。未完成全生涯本传和政治风险复核的人物仍须展示，但只能标记为“现有登记支持的档位下限”，不得伪装成冻结终值或“无风险”。

军事、治理、谋略和文化学术分别独立定档，总档取已经成立的最高领域档位；其他领域只展示能力广度，不能互相凑数量门槛。两个领域分别独立达到 `top` 时，可以走配置中明确的全能型 `historic` 路径；除此之外不得跨领域相加。最高档并列时全部列为主领域。

### 1. 军事人才门槛

先过滤责任，再看主锚，最后看复验。人才档只计算本人作为主帅或主将取得的独立正向战役群；从攻事实仍进入人物履历，但不能分享主帅、主将的战略终局信用。同一战役群不因多场交战重复计算。

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无达到 `C` 级的本人已实现指挥成果；材料不足不能推定普通 |
| `usable` | 至少一个本人主帅或主将的 `C` 级以上已实现成果 |
| `important` | 至少一个本人主帅或主将的 `A` 级战役群；没有 `A` 时，至少两个独立 `B` 级主力指挥成果 |
| `top` | 有一个本人主帅或主将的 `S-` 级以上主锚，并由稳定兑现、另一项 `A` 级以上成果或重要军事方法完成复验；决定性 `S+` 自带复验 |
| `historic` | 在 `top` 之上满足“巅峰双成果”或“持续战略统帅”任一路径，见下文 |

为避免穷举排列组合，只给 `A` 以上主力指挥成果计算战略权重：`A=1、S-=2、S=3、S+=4`，`B/C` 不计战略权重。`historic` 只有两种语义路径：

1. **巅峰双成果**：至少两项独立成果，满足“一个决定性 `S+` 加另一个 `A` 以上”，或“两项均为决定性 `S` 以上”。
2. **持续战略统帅**：至少三项独立 `A` 以上成果，其中至少一项 `S` 以上，战略权重合计不少于 `7`。

该权重只压缩组合表达，不改变战役本身等级，也不进入分项计分。它使 `S + S- + S-`、`S + S + A` 等等价组合自动落在同一路径，而 `S + S- + A`、三个 `S-` 等未达到门槛的组合自然排除。`S+` 不是 `S` 的显示别名：它可以单项建立 `top`，但升 `historic` 仍需独立复验。

### 2. 治理人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人主导或独占的已实现治理成果；材料不足不能推定普通 |
| `usable` | 至少一个范围有限但已实施并形成可观察结果的本人治理成果 |
| `important` | 至少一个 `important` 级以上、由本人主导或独占的治理成果 |
| `top` | 至少一个 `national` 级主导或独占成果，并另有稳定运行、第二个 `regional` 级以上成果或重要方法之一 |
| `historic` | 两个独立 `national` 级以上成果加第三个 `regional` 级以上成果，并满足一个独占或两个主导；或一个本人主导、跨阶段运行的奠基性 `national` 级制度，加另一个 `national` 级成果或两个 `regional` 级成果 |

### 3. 谋略人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人主导、已实施并形成独立战略结果的谋略成果 |
| `usable` | 至少一个范围有限但已实现的本人谋略成果 |
| `important` | 至少一个 `regional` 级以上主导或独占谋略成果 |
| `top` | 至少两个独立 `national` 级主导或独占谋略成果 |
| `historic` | 至少三个独立 `national` 级主导或独占谋略成果 |

文化学术与跨领域路径继续按执行配置单独判断，不借用战役字母档。执行门槛以 `config/talent-grade-v11-domain-equivalent-historic.yml` 为准。同一战役、治理或谋略责任链只计一次；专业目标失败和同领域灾难性失败进入能力一致性复核，其他领域代价不能抹去已经成立的专业事实。

## 六、政治风险

政治风险只认本人直接实施、命令、持续放任或以实际责任造成的公共损害。私德、结局、普通战败、被诬告、官位、亲属身份和史料详略不成立风险；功绩和人才等级也不能抵消风险。

风险与人物全生涯事件相连，但每个皇帝只消费本窗口内已经实施或暴露的风险。未过公共损害门槛记 `below_floor`，材料不足记 `insufficient_evidence`，均不得伪装成无风险。严重度、历史影响范围、责任、实现状态和检索完备性全部由唯一执行合同 `config/political-risk.yml` 判定；子流程不得自行类比定档。

公共层只保留三条硬边界：单次故意或无正当依据直接致人死亡不得低于 `material`；多次直接致死、严重身体伤害或群体伤害不得低于 `major`；史料详略、名声、官位和人才等级不得改变风险档位。历史影响范围与严重度分开登记。

普通战役失败不自动成为政治风险。只有擅自出兵、违令冒进、弃军弃城、杀降毁约、纵兵劫掠、持续损兵或其他明确可归责公共损害，才进入风险审查。

## 七、跨项引用

第一项可引用战役群、皇帝关系、人物指挥身份、规模和过程逆境；第二、三项可引用治理成果、军事安全和公共代价；谋略登记只供人物画像及明确允许的规则引用；第五项可引用人才等级、政治风险和授权责任。任何分项只能声明 eligibility、方向、材料预算和数值映射，不能修改公共事实、人物全生涯档位或风险事件。
