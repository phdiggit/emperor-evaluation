# 公共成果登记与人物画像规则

> 状态：当前 shadow 公共规则。适用于所有评分项；分项文档只能引用和投影，不得复制一套战役、治理、人才或政治风险事实。

## 一、公共对象

史料先形成中性的 `HistoricalEpisode`，再按独立结果归并为 `HistoricalOutcomeCluster`。人物画像从公共成果和风险事件重建。评分项只能后置判断适用性、方向和数值，不得建立评分专属事实副本。

固定数据顺序为：中性材料 → 无皇帝窗口的战役与治理成果总登记 → 皇帝窗口绑定 → 规则材料映射 → 计分。成果总登记不得包含 `ruler_window_status`、当前皇帝结算范围或人才计分信用；窗口无法判断只阻断该皇帝投影，不能删除成果。皇帝作为事件参与者的亲征、授权或治理责任属于成果事实，不等于把成果绑定进某位皇帝的评分窗口。

同一事实和同一独立结果只保存一次；跨书材料用于补足责任、规模、结果、持续性和冲突，不按来源数重复登记。Google、网页摘要和模型常识只作发现线索。

## 二、战役登记

### 1. 战役群优先

一个统一战略目标、主要对手或区域竞争链形成一个父级战役群。具体交战、围城、追击、受降、撤军和补给损耗作为子事件保留逐字史源与单战结果，默认不另算独立成果。

总登记把完整战略链记为 `campaign_group`；人物在其中独立统帅不同战区、对手或战略阶段并形成独立终局时，另登记 `campaign_subresult` 并引用父级。后置投影才决定皇帝结算消费父级、人物人才消费哪些本人独立成果；不得为防止皇帝重复计分而删除韩信平魏、破赵、平齐这类独立指挥成果，也不得让同一评分消费者同时结算父子两级。

划分顺序：

1. 有明确主要对手时，按对手和同一战略目标合并；
2. 无单一对手时，按区域与功能阶段合并；
3. 同一区域的取得、保持、反复和丧失优先合并；
4. 只有产生独立终局、开启新战略阶段或合并会掩盖重大责任时才另立战役群。

父级保存整体 `battle_result` 与 `objective_completion`；子事件可有不同胜败。整体未达最高目标但取得重大阶段成果时登记为 `mixed / partial`，不能只保留胜利或只保留失败。

### 2. 人物指挥身份与皇帝关系分轴

军事参与者按实际指挥链登记：`主帅`、`主将`、`副将`、`从攻`。皇帝未进入军事指挥链时登记为 `不在军事指挥链`，不能为了容纳皇帝身份虚构“从攻”。皇帝对一个父级战役群只登记一个皇权关系：

| 代码 | 含义 |
| --- | --- |
| `obstructed` | 皇帝阻止、掣肘或撤销既定军事行动，并有明确责任证据 |
| `acquiesced` | 皇帝知情默许，但没有建立明确主动授权或统筹 |
| `authorized` | 皇帝批准目标、任命统帅或正式授权出兵，但未进入战区统筹 |
| `temporary_theater_control` | 皇帝临时到达战区压阵、督战、收束或处置危机，主战由他人完成 |
| `sustained_theater_control` | 皇帝长期坐镇主战区并持续统筹多路军、节奏和资源 |
| `personal_command` | 皇帝亲征并直接承担前线核心统帅责任 |

皇权关系互斥，并按最终达到的最高实际参与覆盖低档：`personal_command > sustained_theater_control > temporary_theater_control > authorized > acquiesced > obstructed`。已经亲征就不再同时登记授权，长期统筹不再同时登记临时坐镇；过程中的低档关系只保留在子事件事实，不进入父级角色。若皇帝最终有效阻止、撤销或掣肘该战役且没有转为更高参与，才登记 `obstructed`。必须保存最高角色的行动和逐字依据。武将身份回答“谁实际指挥”，皇权关系回答“皇帝如何控制、支持或阻碍”，两者不得互相替代。

例如赵构对岳飞军事行动的阻挠，应登记赵构的 `obstructed + not_in_command_chain` 皇权责任，并保留岳飞自己的实际指挥身份；不能把赵构写成从攻，也不能因皇帝没有亲征而把阻挠责任排除在战役登记之外。

### 3. 过程负面

战役最终结果和过程逆境分开保存。公共登记使用中性档位，不直接保存分项分数：

| 档位 | 含义 |
| --- | --- |
| `none` | 无明显过程负面 |
| `limited` | 小挫、不克非核心目标或轻微损耗，未改变主目标 |
| `material` | 重要目标未达、重要部队或机动力明显受损，成果仍可保留 |
| `severe_repaired` | 主力重创或门户失控，但在同一战役群内修复并取得正向终局 |
| `near_collapse_repaired` | 几近战略失败，虽后来赢回但修复成本极高 |
| `terminal_failure` | 核心目标彻底失败且未在同线修复，形成独立终局 |

每项同时保存固定负面指数 `0 / 0.20 / 0.40 / 0.60 / 0.70 / 1.00`，与上述档位一一对应，供后置投影读取；公共成果登记不直接计算分项得分。敌方主力损失支持正向战果，我方人员、战马、舟船、器械和补给损失进入过程负面，二者不能机械相抵。正常动员、追击、敌军来援、战役困难或未追求决定性终局不属于过程负面；`none` 只写“无达到过程负面门槛的事实”，不得罗列每场战争都有的普通成本。

过程负面属于战役群，责任属于人物，必须分开登记。非 `none` 项逐条保存责任人、责任类型和逐字依据：`primary` 为本人决策或直接指挥导致，`shared` 为共同决策或系统责任，`subordinate_execution` 为部将执行导致，`disobedience` 为部将违令导致，`mitigated` 为存在明确减责事实，`not_responsible` 为证据明确排除该人责任，`external_unattributed` 为天气、疾病或敌方行动等不归责本方人物。不得因为某人是主帅就默认把战役链全部负面归给他。

贞观十九年征高句丽应登记为一个父级远征战役群：盖牟城、辽东城、白岩城、驻跸山、安市城等为子事件；整体为 `mixed / partial`，安市为失败子事件，拔城和驻跸山胜利保留正向事实，撤军及机动力损耗进入 `material` 过程负面。不得只登记安市，也不得把各城重复算成多个完整远征成果。

### 4. 土地轴与对手轴

战役规模必须同时说明：

- 土地轴：局部据点、重要区域、战略门户、核心根据地、都城或国家存亡区；
- 对手轴分成两个必填字段：战略权重为残余或弱小力量、区域主要对手、全国级竞争者、帝国主力；交战状态另记强盛、可战、衰弱、残余或不明。不得用“强敌”一词同时替代两者；
- 结果轴：局部战术结果、重要目标、战区控制、整场战争、国家存亡、统一或灭国。

战役群使用独立等级，不再以“国家级、战区级”直接充当军事人才定级依据：

| 战役等级 | 土地轴、对手轴与结果边界 |
| --- | --- |
| `S+` | 极限复合终局；同时重塑多个核心方向或时代秩序，普通灭国或名将大胜不能进入 |
| `S` | 全国性决定战役群；决定统一、国家存亡、主要竞争政权或整场战争结局 |
| `S-` | 准全国或强区域终局；消灭强区域竞争者、决定核心根据地或重大长期战略方向 |
| `A` | 重要区域或战略门户；决定主要区域、门户、主力集团或重大阶段目标 |
| `B` | 一般区域、重要清障或重要防御结果，但没有形成主要战略终局 |
| `C` | 局部据点、短期战术或低权重辅助结果 |

等级依据必须用规范字段逐项列出 `土地轴`、`对手权重/状态` 和 `结果轴`，不能只写一段概括，也不能机械取三轴平均；最终档位不得高于结果实际兑现能够支持的上限。名称宏大、对手名义上建国或史料记载详细都不能自动升档。旧版权重和 C1 分数不进入公共登记。

当前只对汉初刘邦创业统一链与唐初李渊—李世民创业统一链做横向校准：两者内部可独立登记的决定性会战与主要方向应形成大体相近的 `S`、`S-`、`A` 分布，相似三轴若相差超过一档必须说明。校准只含两条统一链内部的内战、兼并与割据平定，不含匈奴、突厥、高句丽等对外战争；其他政权暂不进入互校组，仍按自身三轴定级。

## 三、治理成果登记

治理成果只收已经实施并形成制度、持续程序、跨个案公共效果或明确先例的独立结果。单案改判、一次礼遇、个人赏罚、一般言行、官职、参会和未实施建议只保留 Episode 或规则证据。

奏疏、谏言和批评首先只证明“臣下提出该主张”，不能单独证明所指现象、规模或公共后果已经发生；必须有独立实施记录、结果记载或可核实的交叉史源才可登记治理成果。未过该门槛的材料继续供 I5A 欲望与自我约束、纳谏等相应规则消费，不得为进入成果簿而把谏言改写成既成事实。

粮价、人口、生产、治安等跨区域直接结果即使尚不能拆清具体政策责任，也不得静默删除；应登记为 `macro_public_result`。史源上下文明示该结果承接于某一总体治理时，登记 `source_attributed` 并按原文归责；只有同时期关系而没有因果承接时，才登记 `limited`。两者都不得把每项宏观变化伪写成某一条单项政策的效果，也不能与已经明确责任链的制度成果混算；属于哪个皇帝窗口由后置绑定决定。

同一改革的法令、组织、执行和初期结果若属于同一责任链，只登记一个成果簇；只有可以独立运行、独立归责并产生独立公共结果的模块才拆分。治理专业成效与社会净收益分开：专业目标实现可以保留，但跨领域代价必须另行登记并在相应分项结算。

完成并投入国家使用的一代正史、跨代通史或同量级大型文化典籍，原则上属于 `national_cultural_corpus`，不得仅因官修、集体协作而压成普通重要事项。例行修成单朝皇帝实录通常只属 `important`，除非多个朝代或完整国家史体系的规模、使用和长期影响另有直接史源。只有作品本身开创文明范式、长期成为跨时代基础文本，且本人实际独著、主编或最终定稿时，才可用 `civilization_foundational_corpus / era_shaping / foundational`；《史记》的首创性体现在这一附加门槛，不意味着《汉书》《隋书》《资治通鉴》等完成的大型史书与普通文书工程同档。成果规模与个人责任分别判断：授权、总裁、主修、分卷撰修和挂名参与不得共享同一贡献档。

所有独立治理成果先统一登记为 `governance_result`，不区分“皇帝成果”与“人物外窗口成果”。后置窗口绑定再决定哪些进入当前皇帝治理投影，人物画像仍可消费其完整生涯成果。不得因为永徽成果不归李世民计分，就删除长孙无忌在永徽时期主持的独立制度成果；也不得反过来把臣子外窗口成果计入当前皇帝。

治理成员按实际责任只取一档：`exclusive` 表示该成果由本人独立建立且没有同级共同主导者；`lead` 表示本人主导方案或持续执行；`governance_participant` 表示有可核实的实质参与但不构成主导；`authorized` 表示仅批准、维持或提供授权而没有主导实施。授权不能代替实施责任，参会、在职和一般赞同不能推定参与。每项治理成果必须保存影响规模、规模依据和成员责任的逐字史源；无法确定责任档位时不得猜测。

## 四、人才等级

人才等级是跨皇帝复用的全生涯能力轴，政治风险与其正交。实绩限定上限，权威评价用于校准归属、时代位置、置信度和相邻档，不以官职、声望或单次高光定档。军事与治理分别定档，不得让治理成果猜测对应哪个战役字母档。

### 1. 军事人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无达到 `C` 级的本人已实现指挥成果；材料不足不能推定普通 |
| `usable` | 至少一个本人副将以上的 `C` 级成果，或多个可核实从攻成果形成稳定专长 |
| `important` | 至少一个本人主帅或主将的 `A` 级战役群，或两个独立 `B` 级战役群 |
| `top` | 一个本人主帅或主将的 `S+` 级战役群可直接成立；否则至少一个 `S-` 级以上战役群，并另有稳定兑现、第二个 `A` 级以上成果或重要方法之一 |
| `historic` | 满足下列任一路径：一个 `S+` 加另一个独立 `A` 级以上；两个决定性 `S` 级以上；一个 `S` 加两个独立 `S-` 级以上；或两个 `S` 级以上加另一个独立 `A` 级以上 |

`historic` 所计战役均须为本人主帅或主将。`S+ + A` 路径中的 `S+` 必须具有决定性；两个决定性 `S` 级以上路径不再要求第三场。`S+` 不是 `S` 的显示别名：它可单项建立 `top`，并降低 `historic` 对重复 `S` 级成果的数量要求。

### 2. 治理人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人主导或独占的已实现治理成果；材料不足不能推定普通 |
| `usable` | 至少一个范围有限但已实施并形成可观察结果的本人治理成果 |
| `important` | 至少一个 `important` 级以上、由本人主导或独占的治理成果 |
| `top` | 至少一个 `national` 级主导或独占成果，并另有稳定运行、第二个 `regional` 级以上成果或重要方法之一 |
| `historic` | 两个独立 `national` 级以上成果加第三个 `regional` 级以上成果，并满足一个独占或两个主导；或一个本人主导、跨阶段运行的奠基性 `national` 级制度，加另一个 `national` 级成果或两个 `regional` 级成果 |

文化学术与跨领域路径继续按执行配置单独判断，不借用战役字母档。执行门槛以 `config/talent-grade-v11-domain-equivalent-historic.yml` 为准。同一战役群或治理责任链只计一次；专业目标失败和同领域灾难性失败进入能力一致性复核，其他领域代价不能抹去已经成立的专业事实。

## 五、政治风险

政治风险只认本人直接实施、命令、持续放任或以实际责任造成的公共损害。私德、结局、普通战败、被诬告、官位、亲属身份和史料详略不成立风险；功绩和人才等级也不能抵消风险。

风险与人物全生涯事件相连，但每个皇帝只消费本窗口内已经实施或暴露的风险。未过公共损害门槛记 `below_floor`，材料不足记 `insufficient_evidence`，均不得伪装成无风险。严重度、历史影响范围、责任、实现状态和检索完备性全部由唯一执行合同 `config/political-risk.yml` 判定；子流程不得自行类比定档。

公共层只保留三条硬边界：单次故意或无正当依据直接致人死亡不得低于 `material`；多次直接致死、严重身体伤害或群体伤害不得低于 `major`；史料详略、名声、官位和人才等级不得改变风险档位。历史影响范围与严重度分开登记。

普通战役失败不自动成为政治风险。只有擅自出兵、违令冒进、弃军弃城、杀降毁约、纵兵劫掠、持续损兵或其他明确可归责公共损害，才进入风险审查。

## 六、跨项引用

第一项可引用战役群、皇帝关系、人物指挥身份、规模和过程逆境；第二、三项可引用治理成果、军事安全和公共代价；第五项可引用人才等级、政治风险和授权责任。任何分项只能声明 eligibility、方向、材料预算和数值映射，不能修改公共事实、人物全生涯档位或风险事件。
