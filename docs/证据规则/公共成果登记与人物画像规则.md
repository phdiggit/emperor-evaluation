# 公共成果登记与人物画像规则

> 公共成果先裁事实，人才与皇帝评价再按各自范围采用。

## 一、公共对象与处理顺序

先登记事件，按独立结果合并，再供人才和皇帝评价使用。同一事实只保存一次，多种史源补充责任、范围及分歧；网页、游戏和模型只帮助定位。人才评价覆盖全生涯，皇帝评价按本项时期与准入规则取用，均不得为预想档位增删或改写公共事实。

记录按朝代分片，由统一加载器读取。人物及成果ID全局唯一，同人的异名和跨朝经历合并；manifest只描述分片及校验信息，不是完整业务记录。

## 二、战役公共登记

### 1. 准入与去向

战事满足以下至少一项，才登记为公共战役成果：

1. 产生明确的领土、政权存亡、主力损害或国家安全结果。
2. 有足以改变人物军事能力判断的独立指挥成果。
3. 有会影响皇帝评价的亲征、具体战争统筹或重大决策责任。
4. 有需要评价的重大成本、失败或长期安全后果。

普通小战和没有独立结果的追击、围困、受降只保留为事件。宫廷夺权通常归交接、谋略或风险，发展为有独立方向或区域控制的持续正规作战后才建战役。

最终去向为`CAMPAIGN_GROUP`（战役成果）、`REDIRECT_NON_BATTLE_OUTCOME`（其他成果）或`BELOW_PUBLIC_OUTCOME_THRESHOLD`（普通事件）。结果、档位和本人责任未判清的，不用于人才定档。引用使用稳定`war_event_id`及对应史源，名称和名气不决定等级。

### 2. 战争树、拆合与去重

公共战争按事实组织；D项成本收益周期另按责任人、时期和连续投入划分，不重复使用结果。

公共战争最多分三级，不必凑齐：

| 层级 | 用途 |
|---|---|
| `war_terminal` | 长期战争或统一战争的总体背景，不直接计成果。 |
| `campaign_group` | 围绕同一主要对手、战略目标、战区及连续指挥补给形成的战役群，是基本成果单位。 |
| `person_command_result` | 一个人独立承担某方向、阶段或主力并取得可辨认结果，用于本人责任和人才评价。 |

是否拆分，看动员、目标、战区和最终结果能否独立，不只看时长或地域。一个总体记录包含多个独立结果时，标`SPLIT_CAMPAIGN_PORTFOLIO`后分别评价；没有独立结果的阶段并入上级，标`MERGED_INTO_PARENT`并保留原引用。

皇帝采用互不重叠的战役群；人才优先采用本人结果，未单列时裁其在战役群中的实际贡献。整体与阶段不双计，父群难度、成本和他人贡献不整包归个人。失而复得保留过程，按实际净结果判断。

### 3. 战略结果三轴

字母档只证兑现战略结果；土地、对手与结果分别闭合，不重复抬高或把难度名望换档。

土地轴按战役当时的功能性战略重量裁定，不按“州、郡、道、县、城”的名称、数量或名义面积跨时代换算：

| 土地轴 | 功能边界 |
| --- | --- |
| `local_point` | 普通据点或离散目标，无独立军政财政功能 |
| `strategic_gateway` | 控制进退、补给或跨区交通的关隘、渡口、粮道、河谷等节点 |
| `important_region` | 具有显著人口、赋税、兵源、军备或交通价值的成片主要区域 |
| `core_heartland` | 可持续征兵、征税、供粮、驻军和组织指挥的核心腹地或完整强区域基地 |
| `capital_or_state_survival` | 中央军政中枢或得失直接影响政权存续的核心战区 |

土地至少证人口税源、军备、交通、持续控制或战略功能之一；短占名义归附不外推，小国全土不自动核心腹地/S-。

对手轴必须先区分政治体系，再判断战前强度：

- 国内竞争用`minor / regional_major / first_tier_pole / dominant_pole`，地方乱不凭兵数占都升极。
- 独立外交战争政权为`external_state`，另标`opponent_condition=strong / viable / weakened / residual / unclear`。
- `external_hegemony`须战前持续压核心、全国安全围其调整、可威胁存亡三证，按当期可变，不是国号标签。

结果轴至少记录 `battle_result`、`objective_completion`、控制保留和敌军效果。战略目标可以是攻城略地、政权终结、解围保全，也可以是削弱或摧毁敌方有生力量。`opponent_force_effect` 固定为：

| 敌军效果 | 边界 |
| --- | --- |
| `none` | 无可验收军力损害 |
| `limited_attrition` | 一般消耗或局部斩获 |
| `major_degradation` | 重创成建制主力，但对手仍能维持同一战争 |
| `main_force_destroyed` | 当前战略方向主力失去继续作战能力 |
| `military_system_collapsed` | 对手整体军事组织无法继续运转 |

土地、主力、政权是同果观察，不加成果数。未克按已兑现阶段定档并记`objective_shortfall`；`major_degradation`通常最高A，主力毁灭升档另证方向与对手分量，体系崩溃仍过终局门。

负档按实损及`result_direction=negative`，不从假想胜档减一；胜败双方不必等档。

### 4. 战略结果类与字母档

| 战略结果类 | 等级 | 成立边界 |
| --- | --- | --- |
| `local_tactical` | `C` | 局部战术或低权重辅助结果 |
| `important_objective` | `B` | 重要清障、防御或单项目标，未形成主要战略终局 |
| `major_stage_or_crisis` | `A` | 主要区域、门户、主力集团或重大阶段结果；重大负向结果亦按实际影响登记 |
| `independent_direction` | `S-` | 强区域终局、核心根据地或长期独立战略方向成立 |
| `single_pole_decisive_defeat` | `S` | 决定性摧毁第一梯队竞争极的核心主力，但政权未在本役终结 |
| `external_hegemony_decisive_defeat` | `S` | 决定性摧毁外部霸权的王庭、核心主力或同等军事中心，但统治结构或安全秩序逆转尚未闭合 |
| `single_pole_or_state_terminal` | `S` | 终结第一梯队单一竞争极，或完成具有全国分量的外部国家终局 |
| `composite_poles_terminal` | `S+` | 同一战役群一次终结两个以上第一梯队竞争极 |
| `unification_terminal` | `S+` | 从有限根据地推进到核心区域统一，或在统一总链中终结多个第一梯队竞争极 |
| `external_hegemony_terminal` | `S+` | 击溃外部霸权统治结构，并持久逆转评价主体所处安全秩序 |

S+限表中三路。`single_pole_decisive_defeat`须`first_tier_pole / dominant_pole + victory / complete + main_force_destroyed`；外霸决定败须三项战前门＋核心主力毁灭，terminal另证统治崩解与持久逆转。选择external_hegemony均保存完整战前评估。

成熟国家平乱通常C/B，跨区长乱或大危机A；事实分裂、长期核心控制及独立方向才S-。对等政权终结归统一/兼并，不借平乱获S/S+。

组合只查切分、重复终局、首次净控及对手误档，不另算总分或压低本人实担难度。

### 5. 作战难度、成本和不利事实

难度按本人承担问题时的资源、情报、距离、地形、后勤和对手状态裁定，不由胜负或损耗倒推：

| 难度 | 边界 |
| --- | --- |
| `D0` | 未形成有效军事对抗，或主要接收已崩解残余 |
| `D1` | 本方综合优势足以稳定覆盖常规风险；胜得快本身不是依据 |
| `D2` | 存在强主力、坚城、复杂地形、远距离或显著后勤中的一项重大难点，但本方总体态势仍覆盖主要风险 |
| `D3` | 两项以上重大约束相互强化，需要一线统帅质量才能稳定完成；执行干净、伤亡低也不降档 |
| `D4` | 明确极端劣势、孤军、断粮、被围、战线濒临崩溃或连续败退后的临阵逆转，并有可追踪的判断与组织事实 |

D不因名气、灭国或远征升档，也不由父群直接复制给个人。

本人通过侦察、削弱、分化、联盟或择机解决的约束，仍计入原军事问题；他人准备或接手前已消失的约束不得冒领。外生衰败和真实力量变化须独立举证，与本人解题分开。

不利事实必须互斥归入四类：

| 类型 | 后置用途 |
| --- | --- |
| `difficulty_context` | 敌强、复杂地形、天气、坚城、补给环境或接手前败局；只支持难度 |
| `operational_cost` | 伤亡、战马舟船器械和补给损耗；进入成本收益 |
| `objective_shortfall` | 目标未完成或成果未保持；处理成果保留，不自动生成个人负向 |
| `attributable_failure` | 有逐字证据的错误决策、错误指挥、违令或执行失误；可进入人物或皇帝负向 |

同事实不以成果短缺、成本和个人失败重复扣。`attributable_failure`须责任人、类型、影响、史源；敌强、受伤、接手败局或未归责失败不代过错，后续复发不倒改已成当次目标。

### 6. 组织身份、实际贡献与统治者控制

组织职务与实际贡献分别记录。`role_code`表示总指挥、主要指挥、参与者或不在指挥链；指挥关系未明记`command_unresolved`。S-/S/S+、重大失败及足以改变人物主档的战事，须核清完整指挥关系。

`campaign_command_topology`描述统一指挥、联合指挥、分区行动或对抗等组织关系，不直接分配功劳。本人贡献用两组字段说明：

- `capability_mode`：整体指挥、独立方向、战争统筹、战术执行、授权或名义身份。
- `decisive_relation`：创造结果、接续扭转、共同决定、收尾、阶段执行或无贡献。

接手后扭转局势，可以完整评价本人解决的问题；接手时敌方主力已被打垮，则按实际收尾贡献处理。职务高低不决定比例。

统治者作用区分`authorization_only`、`operational_direction`、`frontline_command`。前线指挥须亲临且实际承担最高指挥；单纯授权不产生军事人才信用。战争统筹不要求亲临，但须证明**面对什么约束、本人作了什么安排、安排已被采用、怎样影响了作战**。目标先后、路线时机、兵力协同、后勤或纠偏都可以，任将、批准出兵和下属获胜本身不够。

统筹使用`consumption_mode=operational_result / capability_mode=operational_design`；`operational_role_review`保存约束、操作、实施、结果、本人范围及来源，合格状态为`QUALIFIED`。正向说明本人造成的`major_result`，负向说明已证失败及本人后果档；未证明操作或结果时只保留史料，不计能力成果。

已有直接史源但人物与结果尚未连接时，用`personal_action_attributions`补录本人行动、角色、实施、结果、责任限制和引用；只补事实，不新增战争、独立成果或猜档。非战争政治取得、名义统属或时间不清的事实，存入`person_military_scope_notes`，保留来源与范围，不作正向军事成果。

仅补闭既有本人结果与原史源连接时，可建`record_level=person_command_result_registration / settlement_scope=PERSON_RESULT_ONLY`节点，保留稳定PCR、本人字段及直接源卡，固定`public_outcome_registered=false`。节点只作维护与引用入口，不新增独立战争、公共成果、军事成本或独立厚度；来源定位不代表完成语义裁决，未决角色及范围仍写入本人记录。

## 三、治理与谋略成果

### 1. 治理成果

治理成果须有已发生的结果，并能说明原来怎样、采取了什么措施、运行效果、代价或持续性，以及本人责任。先登记公共事实，再按皇帝的实际时期归责；只有意图或动作的，保留为事件。

事实角色使用 `baseline / measure / operation / result / cost / continuity / responsibility`。运行状态使用 `implemented / operated / completed / failed / unclear`；价值方向使用 `positive / negative / mixed / unclear / not_established`，不得把 `mixed` 写成运行状态。

按民生生产、文明制度、安全、文化教育分别记录变化、方向、强度及`fact_ref`。强度为`limited / significant / structural / era_shaping / not_established`；规模变大或征收更多不自动算进步，利弊并存记mixed，证据不清记unclear。

按实际结果去重，不按政策名称计数；scale只表示覆盖范围。个人须有设计、执行或纠偏证据，不因在位或任职就分得成果；跨代事项分别说明各阶段责任。

每个治理`fact_ref`明确登记、合并或不采用（`register / merge / reject`）；读过一部政书不代表查遍整个朝代。

### 2. 谋略成果

谋略须由本人提出或主导，已被采用并产生独立战略结果。未实行的建议、纯夺权清洗或只有手段成功不算。谋略成果按相应画像规则使用，不改记为治理成果或主帅战绩。

## 四、人物画像与人才等级

每人使用唯一`person_ref/profile_ref`，保存全生涯总档和领域档。各领域独立裁定，总档取最高，未配置跨域路径不拼凑。实际成果限制上限，外部评价只用于时代、置信度及相邻档校准，政治风险另列。

记录全部合格独立成果、贡献、难度、反证和来源，不能只留够门槛的样本；生涯覆盖未全时只发证据下限。重建不得因战役分区替换删掉canonical人物，或按当前朝代集合重造身份。既有人物缺失/身份漂移须先解决公共身份迁移，否则拒绝覆盖登记。

### 1. 军事人才消费

#### 本人结果、角色与独立性

[武将等级](../公共成果/军事/02-武将人才等级.json)只读[战役登记](../公共成果/军事/01-战役登记.json)中已裁的本人结果，新增朝代沿用同一schema。按`config/military/military-capability-episodes.json`合并能力情境，每情境只取最高结果；同对手但目标、战区、问题独立时可分。

正锚须有`decisive_creator / decisive_successor / co_decisive`实际作用，收尾和阶段执行只计本人完成部分。统筹先过第二节第6小节的操作、实施及结果门槛；两个独立合格A级统筹可走important路径，高档按下表设计路线，保存`operational_grade_review`中的约束解题、实施结果、独立性、可靠性、史源及至少两个相邻档比较，不以前线峰值替代设计能力。

#### 失败与可靠性

先核正向资格，再独立裁可靠性；前线和统筹分别统计、同情境去重，合计只用于展示定位。前线正向厚度用本人独立`A/D2+`，重大败果用`adverse_result_review.effect_tier>=A`及实际控制、结果责任，不因D低或mixed标签排除。统筹不设前线D门，按合格操作、本人A级以上正果/败果及控制范围审查，不能用统筹数量替代前线厚度，也不能用前线胜绩抵消统筹重复失能。

国家损害不整包归个人，具体过错与结果责任分开。elite以上重大失败须查结果与致败责任；实际主帅经检索仍无免责证据，记`COMMANDER_RESPONSIBILITY_AFTER_UNRESOLVED_SEARCH`。只有明确强令、灾害或无控制才记`NO_FAULT_* / NOT_RESPONSIBLE`，不计能力败责，但已证军事损害仍留净值。过错另记`attributable_failure`，不重复扣。

下列前线组合触发复核，不自动降档：

- 正向不超过三项，且有一项重大主帅败责或两项重大不利；
- 正向至少四项，重大败责至少两项且达到正向一半。

复核写明目标约束、判断部署、反馈纠偏、实际恢复、不可逆损失及是否改变生涯主要模式。重复主/共责可阻稳定路径，但不删已成峰值；早期强峰也不抵消晚期持续失能。至少五项正向、含两个`S/D3+`高峰且重大败责不超过一项，可支持复验充分的解释，不自动免责。政治、民生和一般作战成本不作军事能力败责。

统筹的目标、配置或反馈错误若反复导致运行失效，也可影响档位，不因未上前线或D为空排除；调整须留`operational_stability_review`的过程、反馈、残余损失及裁决。操作尚未证明时保留事实和限制，不以缺证判无能；必要时发“现有史料审慎档位区间”，上端须有补足操作、实施及结果作用的明确条件，不再当确定档使用。

#### 能力档位

| 档位 | 能力边界 |
| --- | --- |
| `ordinary` | `career_coverage_review.status=COMPLETE`并闭全生涯覆盖后仍无本人已实现的 C 级军事贡献；缺证只能以`evidence_lower_bound`发布未定档材料下限，不作无能力结论 |
| `usable` | 至少一项本人已实现的 C 或 B 级贡献 |
| `capable` | 至少一项 A，或两个独立 B 级能力情境 |
| `important` | 至少一项 `A/D2+`，或两个独立 A 级能力情境 |
| `elite` | 强将级：决定性`S-/D2+`前线峰值、两项独立`A/D3+`或三项独立`A/D2+`之一；设计路径为一项本人S级以上已实施战争设计，加另一独立A级本人设计或`A/D2+`前线复验。两条须分别闭本人作用，不把同一终局拆成复验 |
| `top` | 全国一线：`S+/D3+`本人决定性成果；`S/D3+`加另一独立`A/D2+`；`S-/D3+`加另一独立`S-/D2+`或至少两项独立`A/D2+`；已有`S/D2+`前线峰值时，可加独立S级本人设计及另一`A/D2+`前线复验；持续路径为至少四项独立`A/D2+`，含`A/D3+`或`S-/D2+`。设计路径为两个独立S级以上本人战争设计终局，加第三独立A级本人设计或`A/D2+`前线复验，并闭高档设计审查。统筹不继承难度，单项纯统筹、单个`S-/D3`或四项同质`A/D2`不直通top |
| `historic` | 先满足top；前线事实门三路：①`S+/D3+`加独立`S-/D3+`，且至少三个独立`A/D2+`；②两个独立`S/D3+`或`S/D4+S-/D3+`，另有独立`A/D2+`；③有`S/D2+`峰值，且至少四个独立`A/D2+`、其中至少两个`A/D3+`，或另有两项独立`A/D3+`。以上均须再闭时代终局/极难组合/持续大统帅的实际对象、本人作用和跨情境意义，并通过可靠性裁决；事实门不等于自动历史级，纯统筹不单独建立historic |

`positive_evidence_paths`只展开已裁正向资格，不自动定档或加人名例外。事实不符门槛时，先查拆合、归责、证据和范围，再局部裁决；脚本不能靠少数门槛样本重建全生涯档位。

#### 混合结果与去重

同情境正果和败果分别按下节取一份代表，但只算一次独立复验。父卡、本人结果和过错中的同一失败合并，用`source_alias_refs`留旧引用。`capability_episode_anchors/count`仅表示已证正向厚度，负向与未决另列。

`mixed_review`须同时有本人可验收军事正果和实际败果：攻取、破敌、解围或守住独立目标可作正果；仅撤退脱险、保存余军、未兑现建议、勇敢或未全军覆灭不够。战死、一般成本、屠杀、强迁、政治让步不自动成军事败果；仅大目标未成或控制未保、但无已证本人军事损害时，保留局部正果及`objective_shortfall`，不生成混合扣减。

胜负史源冲突或本人角色未明，不算已裁混合结果或确定净值。败后止损、整军及另周期恢复用于能力和稳定性，不改原败果。

`mixed_result_review`保存`positive_result`、`adverse_result`、`retention`、`personal_scope`、`source_refs`及恰好两个`components`，分别注明positive/negative、本人`effect_tier`、依据和史源。正向另写本人阶段难度与贡献，战前条件未证则D为空，不能继承混合总档难度或作D2锚；负向用`adverse_result_review`保存本人后果档、控制范围、结果责任系数、致败责任及来源。

正负分开采用，负向不因同一正果或mixed标签半扣；合写、分写须同值且稳定性计数一致。失去控制后保留已发生军事解题，不再当长期终局。程序只查字段、方向和同值，史实与档位仍靠局部裁决。

#### 成果净值

基础值：`C=0.15、B=0.4、A=1、S-=2.2、S=3.6、S+=4.5`；难度乘数：`D0=0.55、D1=0.75、D2=1、D3=1.25、D4=1.55`；贡献系数：决定性创造/接续逆转为1，共同决定0.85，收尾0.5，阶段执行0.35。

| 单项值 | 前线 | 战争统筹 |
|---|---|---|
| 正向 | 基础值×本人难度乘数×贡献系数 | 基础值×0.4 |
| 负向 | -0.8×本人实际后果基础值×已裁结果责任系数 | 前线负向公式×0.4 |

统筹不继承前线难度，负向均不乘难度。本人败果按以下尺度裁定；可沿用已裁本人纯负档，不能用混合总档、父战役档、D档或胜方成果代替，缺失时须补裁。

| 后果档 | 本人控制范围内的损害 |
|---|---|
| C | 局部战术损害 |
| B | 据点或有限方面受挫 |
| A | 主要方向或军团严重损失 |
| S- | 战区主力/控制系统重大崩溃 |
| S | 国家军事核心或长期战略体系摧毁 |
| S+ | 更广且独立闭合的体系级后果 |

责任系数按本人结果的实际控制判定，不因其只是父群的一部分再作阶段折价，也不因致败过错未知自动降低。能力免责与实际损害的区别按“失败与可靠性”执行。

正向每个能力情境取单项值最高的代表，前线与统筹共用一个降序队列`v1…vn`，同情境只取一份。前四项权重`wi=1、0.8、0.6、0.4`，第五项起取0.2，尾部总值不超过首项未递减值：

`P=Σ(i=1…min(n,4)) wi×vi + min(0.2×Σ(i=5…n) vi, v1)`；无正果时`P=0`。

前线、统筹分解仅拆分同一队列的实际贡献，不另轨起算；尾部触顶时同比例缩减。每个不利情境取扣减最大的一份代表，去重后直接累加，不作递减：`N=P+不利扣减和`。正负采用按“混合结果与去重”执行，不另加名气、常胜、方法、平方或恢复奖励。

数值用十进制累积，最终保留两位小数，半位取偶；净值从未舍入总量计算，分解项各自舍入，舍入误差不回计净值。

净值只在同档、角色、实际机会和证据覆盖相近时辅助比较，不能反推可靠性或人才档位，也不作跨档总排名。展示分别说明正果、损害、可靠性与材料边界，按档位降序、同档净值降序排列，同值再按朝代、姓名、稳定ID排序。

维护以当前本人结果及有效史源为输入，身份迁移保留稳定ID和引用别名。净值、统计、阅读视图确定性刷新，以`military-talent-verify`校验；刷新不发现人物、不裁档、不恢复退役身份生成流程。

### 2. 治理与谋略人才

治理人才只取positive且本人设计/交付；本人在位天然全国权限结果列`talent_grade_exclusions: ruler_own_reign_governance`，mixed/negative/unclear不折半正项。

治理档位：`usable` 至少一项已实现正向成果；`important` 至少一项 `significant`；`top` 至少一项 `structural`，并有稳定运行、另一项 `significant` 或重要治理方法复验；`historic` 要求一项 `era_shaping` 加独立 `significant`，或两项 `structural` 且合计至少三项 `significant`。

谋略档位：`usable` 至少一项有限但已实现的独立谋略；`important` 至少一项 `regional`；`top` 至少两项独立 `national`；`historic` 至少三项独立 `national`。文化学术和跨领域人物档位不在当前保留的确定性重建入口内；既有正式评分直接读取已验收结算，不再消费旧 shadow 校准。

## 五、政治风险与跨项引用

政治风险须有本人行动、命令或持续放任造成的公共损害，按实际掌权时期评价；私德、结局、身份和材料数量不是依据，功绩也不抵销风险。

普通败战不自动构成政治风险。违令、弃军、杀降毁约等须有本人责任和史源，再按相应分项处理。

各分项只决定材料能否采用、如何归责和计分，不改写公共事实、全生涯人才档位或风险事件。
