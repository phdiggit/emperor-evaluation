# 公共成果登记与人物画像规则

> 保留公共成果与人才登记的事实判据；旧shadow流程不再运行，批次与迁移历史由Git保存。

## 一、公共对象与处理顺序

中性`HistoricalEpisode`按独立结果归并`HistoricalOutcomeCluster`；全生涯人才画像复用公共事实，评分后置判窗口、方向和数值，不复制/反写事实。

中性材料→公共成果→全生涯人才→皇帝窗口与风险→分项消费。先登记合格成果再定人才，不按预期档删补战绩。

同事实/结果只存一次，多源补边界、责任及冲突，不增数量；网页、游戏或模型只定位。

按朝代分片，manifest含数量与内容/字节指纹，统一加载器合并；不将manifest当业务JSON或绕过登记读卡。`HOUT-*`、`PROFILE-*`、`person_ref`全局唯一，跨朝唯一主分区，异名跨期合一人。

## 二、战役公共登记

### 1. 准入与去向

战事先保存为中性事件，只有满足下列至少一项才晋升公共战役成果：

1. 产生可验收的显著领土、政权存亡、主力损害或国家安全结果；
2. 形成能够改变人物军事能力判断的独立指挥成果；
3. 存在会影响皇帝评分的亲征、具体作战统筹或重大决策责任；
4. 形成重大成本、失败或长期安全后果，需要后置规则消费。

普通地方乱、小战、无独立终局的追围降留事件层；宫廷夺权转交接/谋略/风险，发展为持续正规作战且有区域控制/独立方向才建战役。

候选最终只能有一个去向：`CAMPAIGN_GROUP`、`REDIRECT_NON_BATTLE_OUTCOME` 或 `BELOW_PUBLIC_OUTCOME_THRESHOLD`。未完成边界、档位或人物裁决的记录不得进入人才消费。

引用最终`war_event_id`及目标、结果、归责来源lineage；标题、档标签、数字和名气只触发复核。

### 2. 战争树、拆合与去重

公共层与评分层使用两级父对象，禁止混为一层：

- 公共`canonical campaign family`管事件身份、父子树、多源归并与lineage，不绑皇帝窗口。
- D的`canonical ruler-window investment cycle`按主体、窗口、连续动员决策收束成本结果；跨帝切窗，同人不重消费公共父级。

公共层只存中性事实，不预裁D准入、`D_INTERNAL_RESTORATION`或上限；消费者按本项合同判断。

战争树最多三级，不为形式完整强行补层：

1. `war_terminal`：长期战争或统一战争的上下文容器，不直接计入皇帝成果或人才等级；
2. `campaign_group`：围绕同一主要对手、独立战略目标、战区和连续指挥后勤链形成的可消费基本成果；
3. `person_command_result`：人物在父群内独立承担方向、阶段或主力并形成可单独验收结果时建立，只供人物责任和人才消费。

按独立动员、目标、战区与收束拆战争组合，时长地域仅线索；连续进攻的围追降不拆终局。

多独立收束的父候选标不可消费`SPLIT_CAMPAIGN_PORTFOLIO`，分裁子群；共享对手目标战区后勤且无独立终局者`MERGED_INTO_PARENT`并保全lineage。

帝王成果只取不重叠`campaign_group`；人才优先`person_command_result`，无子结果才取父群本人贡献。同情境不双取祖孙，不复制父成本/难度/他人份额。

失复过程保留，组合取主体实际净结果；同因果链的主力、政权、残部不拆终局。

### 3. 战略结果三轴

字母档只证兑现战略结果；土地、对手与结果分别闭合，不重复抬高或把难度名望换档。

土地轴按战役当时的功能性战略重量裁定，不按“州、郡、道、县、城”的名称、数量或名义面积跨时代换算：

| 土地轴 | 功能边界 |
| --- | --- |
| `local_point` | 普通据点或离散目标，无独立军政财政功能 |
| `strategic_gateway` | 控制进退、补给或跨区交通的关隘、渡口、粮道、河谷等节点 |
| `important_region` | 具有显著人口、赋税、兵源、军备或交通价值的成片主要区域 |
| `core_heartland` | 可持续征兵、征税、供粮、驻军和组织指挥的核心腹地或完整强区域基地 |
| `capital_or_state_survival` | 中央军政中枢或得失直接影响政权存续的核心战区 |

土地至少证人口税源、军备、交通、持续控制或战略功能之一；短占名义归附不外推，小国全土不自动核心腹地/S-。

对手轴必须先区分政治体系，再判断战前强度：

- 国内竞争用`minor / regional_major / first_tier_pole / dominant_pole`，地方乱不凭兵数占都升极。
- 独立外交战争政权为`external_state`，另标`opponent_condition=strong / viable / weakened / residual / unclear`。
- `external_hegemony`须战前持续压核心、全国安全围其调整、可威胁存亡三证，按当期可变，不是国号标签。

结果轴至少记录 `battle_result`、`objective_completion`、控制保留和敌军效果。战略目标可以是攻城略地、政权终结、解围保全，也可以是削弱或摧毁敌方有生力量。`opponent_force_effect` 固定为：

| 敌军效果 | 边界 |
| --- | --- |
| `none` | 无可验收军力损害 |
| `limited_attrition` | 一般消耗或局部斩获 |
| `major_degradation` | 重创成建制主力，但对手仍能维持同一战争 |
| `main_force_destroyed` | 当前战略方向主力失去继续作战能力 |
| `military_system_collapsed` | 对手整体军事组织无法继续运转 |

土地、主力、政权是同果观察，不加成果数。未克按已兑现阶段定档并记`objective_shortfall`；`major_degradation`通常最高A，主力毁灭升档另证方向与对手分量，体系崩溃仍过终局门。

负档按实损及`result_direction=negative`，不从假想胜档减一；胜败双方不必等档。

### 4. 战略结果类与字母档

| 战略结果类 | 等级 | 成立边界 |
| --- | --- | --- |
| `local_tactical` | `C` | 局部战术或低权重辅助结果 |
| `important_objective` | `B` | 重要清障、防御或单项目标，未形成主要战略终局 |
| `major_stage_or_crisis` | `A` | 主要区域、门户、主力集团或重大阶段结果；重大负向结果亦按实际影响登记 |
| `independent_direction` | `S-` | 强区域终局、核心根据地或长期独立战略方向成立 |
| `single_pole_decisive_defeat` | `S` | 决定性摧毁第一梯队竞争极的核心主力，但政权未在本役终结 |
| `external_hegemony_decisive_defeat` | `S` | 决定性摧毁外部霸权的王庭、核心主力或同等军事中心，但统治结构或安全秩序逆转尚未闭合 |
| `single_pole_or_state_terminal` | `S` | 终结第一梯队单一竞争极，或完成具有全国分量的外部国家终局 |
| `composite_poles_terminal` | `S+` | 同一战役群一次终结两个以上第一梯队竞争极 |
| `unification_terminal` | `S+` | 从有限根据地推进到核心区域统一，或在统一总链中终结多个第一梯队竞争极 |
| `external_hegemony_terminal` | `S+` | 击溃外部霸权统治结构，并持久逆转评价主体所处安全秩序 |

S+限表中三路。`single_pole_decisive_defeat`须`first_tier_pole / dominant_pole + victory / complete + main_force_destroyed`；外霸决定败须三项战前门＋核心主力毁灭，terminal另证统治崩解与持久逆转。选择external_hegemony均保存完整战前评估。

成熟国家平乱通常C/B，跨区长乱或大危机A；事实分裂、长期核心控制及独立方向才S-。对等政权终结归统一/兼并，不借平乱获S/S+。

组合只查切分、重复终局、首次净控及对手误档，不另算总分或压低本人实担难度。

### 5. 作战难度、成本和不利事实

作战难度回答“以当时资源、情报、距离、地形、后勤和对手状态，这个军事问题本身有多难”，不回答最后打得是否轻松：

| 难度 | 边界 |
| --- | --- |
| `D0` | 未形成有效军事对抗，或主要接收已崩解残余 |
| `D1` | 本方综合优势足以稳定覆盖常规风险；胜得快本身不是依据 |
| `D2` | 存在强主力、坚城、复杂地形、远距离或显著后勤中的一项重大难点，但本方总体态势仍覆盖主要风险 |
| `D3` | 两项以上重大约束相互强化，需要一线统帅质量才能稳定完成；执行干净、伤亡低也不降档 |
| `D4` | 明确极端劣势、孤军、断粮、被围、战线濒临崩溃或连续败退后的临阵逆转，并有可追踪的判断与组织事实 |

D按战前条件，名气、灭国远征不升档；个人只取实担问题，不复制父群全部D3/D4。

不利事实必须互斥归入四类：

| 类型 | 后置用途 |
| --- | --- |
| `difficulty_context` | 敌强、复杂地形、天气、坚城、补给环境或接手前败局；只支持难度 |
| `operational_cost` | 伤亡、战马舟船器械和补给损耗；进入成本收益 |
| `objective_shortfall` | 目标未完成或成果未保持；处理成果保留，不自动生成个人负向 |
| `attributable_failure` | 有逐字证据的错误决策、错误指挥、违令或执行失误；可进入人物或皇帝负向 |

同事实不以成果短缺、成本和个人失败重复扣。`attributable_failure`须责任人、类型、影响、史源；敌强、受伤、接手败局或未归责失败不代过错，后续复发不倒改已成当次目标。

### 6. 组织身份、实际贡献与统治者控制

`role_code=commander_in_chief / principal_commander / participant / not_in_command_chain`仅表组织，未闭帅记`command_unresolved`。低档只闭明载人物；S-/S/S+、重大失败或可改人才主锚须追全指挥链。

`campaign_command_topology` 只描述 `single_integrated_command / joint_integrated_command / federated_directions / opposed_commands / distributed_response / command_unresolved`，不直接分配信用。

人物能力贡献由两轴决定：

- `capability_mode = integrated_command / independent_direction / operational_design / tactical_execution / authorization_only / nominal_only`；
- `decisive_relation = decisive_creator / decisive_successor / co_decisive / terminal_finisher / stage_executor / none`。

能力信用须本人控制与结果。接续扭转可`decisive_successor`全取所解难题，前任留负；接手已毁主力仅收尾为`terminal_finisher`，身份不决定比例。

统治者控制分`authorization_only / operational_direction / frontline_command`。低档默认制度授权不生人才信用；具体路线、多路、目标或持续统筹及战果才`operational_direction`，人物记`consumption_mode=operational_result / capability_mode=operational_design`。前线须亲临且实际最高指挥，皇帝窗口后置。

## 三、治理与谋略成果

### 1. 治理成果

治理须结果已见、可独立运行归责验收、史源闭合基线措施运行代价/持续、方向可判；先无窗公共结果再绑帝窗。只有动作意图留事件层。

事实角色使用 `baseline / measure / operation / result / cost / continuity / responsibility`。运行状态使用 `implemented / operated / completed / failed / unclear`；价值方向使用 `positive / negative / mixed / unclear / not_established`，不得把 `mixed` 写成运行状态。

写基线—变化—结果，按民生生产、文明制度、安全、文化教育四面给方向、强度及`fact_ref`；强度`limited / significant / structural / era_shaping / not_established`。规模/汲取不自动进步，利弊mixed、缺证unclear。

同结果链去重，不按政策名；scale只表覆盖。个人须实证设计、交付或纠偏，不因在位任职入成员；跨代生命周期逐窗口另证责任。

每个治理`fact_ref`恰有`register / merge / reject`处置；政书扫描不等全朝穷尽。

### 2. 谋略成果

谋略须本人提出/主导、采用并有独立战略结果，排除未行献策、纯夺权/清洗及仅手段成功。只供允许的画像/规则，不入治理投影或伪装主帅。

## 四、人物画像与人才等级

每个`person_ref`唯一`profile_ref`、全生涯总档及领域档；实绩限上限，外评只校时代/置信/邻档，风险独立。

保存全部合格独立成果、贡献、难度、反证和lineage，不只门槛样本；生涯未全只发证据下限。领域分裁，总档取最高，未配置跨域路径不凑数。

人才登记重建不得因战役分区替换而删除既有 canonical 人物，或用当前观察到的朝代集合重新生成 `person_ref/profile_ref`。出现既有人物缺失或身份漂移时必须先闭合公共人物身份迁移，生成器拒绝覆盖当前登记。

### 1. 军事人才消费

军事人才读已闭公共人物结果；[战役登记](../公共成果/军事/01-战役登记.json)供[武将等级](../公共成果/军事/02-武将人才等级.json)，朝代扩展同schema，不用旧档覆盖新事实。

同能力情境取一个最高结果；连续解题按`config/military/military-capability-episodes.json`归并。同对手但目标、战区、问题独立可分。

正锚须`decisive_creator / decisive_successor / co_decisive`实际能力，收尾/阶段只取实做；`operational_design`可统筹复验，不继承前线难度/终局。

败绩验本人稳定性，过错另记`attributable_failure`不双扣。elite以上重败须查结果与致败责任；检索后实际主帅仍无免责证，记`COMMANDER_RESPONSIBILITY_AFTER_UNRESOLVED_SEARCH`，只有明确强令、灾害或无控制才`NO_FAULT_* / NOT_RESPONSIBLE`。重复主/共责可阻稳定路径，不抹单项峰值。

高档先算正向能力上限，再过稳定性下限。重大情境只统计本人实际闭合的独立 `A/D2+` 结果：正向不超过三项时，一项重大主帅败责或两项重大不利即可下压一档；正向达到四项后，至少两项重大败责且败责达到正向的一半，或重大不利已接近正向数量，才下压一档；正向至少五项、含两个 `S/D3+` 高峰且重大败责不超过一项者，不因少数败绩下压。战争发动、杀俘、纵掠等非指挥负面不得进入军事人才稳定性 Gate。

| 档位 | 能力边界 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人已实现的 C 级军事贡献 |
| `usable` | 至少一项本人已实现的 C 或 B 级贡献 |
| `capable` | 至少一项 A，或两个独立 B 级能力情境 |
| `important` | 至少一项 `A/D2+`，或两个独立 A 级能力情境 |
| `elite` | 强将级：形成决定性 `S-/D2+` 峰值、两项独立 `A/D3+` 攻坚，或三项独立 `A/D2+` 可靠方面表现之一；战争统筹必须有独立前线复验 |
| `top` | 全国一线：`S+/D3+` 本人决定性成果可直接成立；`S/D3+` 必须另有一项独立 `A/D2+`；`S-/D3+` 必须另有一项 `S-/D2+` 或至少两项独立 `A/D2+`；本人已有 `S/D2+` 前线峰值时，也可由独立 `S` 级战争统筹成果和另一项 `A/D2+` 前线成果共同复验；持续履历路径要求至少四项独立 `A/D2+`，且其中至少一项达到 `A/D3+` 或 `S-/D2+`。战争统筹不继承前线难度，且不能单独建立 top。单个可持续 `S-/D3` 或四项同质 `A/D2` 不再直通 top |
| `historic` | 必须先满足 top，并形成时代罕见的终局峰值、极难攻坚组合或持续大统帅履历；除 `S+` 终局双锚、双 `S` 极端攻坚和持续大统帅路径外，独立 `S/D4 + S-/D3+` 极难双峰还须另一项 `A/D2+` 前线复验方可成立。至少要求 S/S+ 高峰、独立高难战略复验和足够的跨情境厚度，不能由单次高光、纯数量或纯统筹成立 |

elite/top/historic仅峰值、攻坚、持续统帅三路，机器确定性展开；不符先审事实，不加人名特例。净值只校同档。

净值每个能力情境只取一个结果。基础值：`C=0.15、B=0.4、A=1、S-=2.2、S=3.6、S+=6`；难度乘数：`D0=0.55、D1=0.75、D2=1、D3=1.25、D4=1.55`；决定性创造和接续逆转系数 1，共同决定 0.85，收尾 0.5，阶段执行 0.35，战争统筹 0.4 且不继承前线难度。前线正向成果按 `1、0.65、0.35、0.2、0.1、0.05……` 递减，统筹成果按 `1、0.6、0.35、0.2、0.1、0.05……` 递减，负向乘 `-0.8`、混合乘 `-0.4`。不另加名气、常胜、方法、平方或单项稳定奖励。

### 2. 治理与谋略人才

治理人才只取positive且本人设计/交付；本人在位天然全国权限结果列`talent_grade_exclusions: ruler_own_reign_governance`，mixed/negative/unclear不折半正项。

治理档位：`usable` 至少一项已实现正向成果；`important` 至少一项 `significant`；`top` 至少一项 `structural`，并有稳定运行、另一项 `significant` 或重要治理方法复验；`historic` 要求一项 `era_shaping` 加独立 `significant`，或两项 `structural` 且合计至少三项 `significant`。

## 五、政治风险与跨项引用

风险须本人行动、命令、持续放任的公共损害，按皇帝当窗消费；私德、结局、身份、料量不构成，功绩不抵风险。

普通败战不自动风险；违令、弃军、杀降毁约等须归责史源并按分项裁决，不维护独立shadow风险配置。

消费者只定eligibility、方向、预算与换分，不修改公共事实、全生涯人才档或风险事件。
