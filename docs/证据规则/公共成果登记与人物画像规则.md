# 公共成果登记与人物画像规则

> 状态：当前 shadow 公共规则。适用于所有评分项；分项文档只能引用和投影，不得复制一套战役、治理、人才或政治风险事实。

## 一、公共对象

史料先形成中性的 `HistoricalEpisode`，再按独立结果归并为 `HistoricalOutcomeCluster`。人物全生涯画像从无窗口公共成果和本传扫描重建，与成果总登记并列为共享公共对象。评分项只能后置判断适用性、方向和数值，不得建立评分专属事实副本。

固定数据顺序为：中性材料 → 无皇帝窗口的战役、治理与谋略成果总登记 → 共享人物全生涯画像总登记 → 皇帝窗口绑定与窗口政治风险 → 规则材料映射 → 计分。必须先按统一成果门槛登记全部合格战役，再让人物画像消费登记结果；不得先看人物已达到哪个人才档位，再以“够档”为由停止战役登记或省略其余合格战役。成果总登记不得包含 `ruler_window_status`、当前皇帝结算范围或人才计分信用；共享人物画像不得包含某位皇帝的团队预算、入选状态或窗口风险结论。窗口无法判断只阻断该皇帝投影，不能删除成果或重算人物全生涯档位。皇帝作为事件参与者的亲征、授权或治理责任属于成果事实，不等于把成果绑定进某位皇帝的评分窗口。

同一事实和同一独立结果只保存一次；跨书材料用于补足责任、规模、结果、持续性和冲突，不按来源数重复登记。Google、网页摘要和模型常识只作发现线索。

公共成果和人物画像按朝代 token 分区保存，分别使用 `eval/historical_outcome_registry/<DYNASTY>/current.*` 与 `eval/historical_person_profiles/<DYNASTY>/current.*`；顶层 `current.*` 只是由全部朝代分区确定性、无损合并出的全局只读视图。`HOUT-*`、`PROFILE-*` 和 `person_ref` 仍须全局唯一。跨朝代成果必须显式指定唯一主分区，其他朝代只引用同一登记号，不得复制事实；分区不能无损合并或出现重复主对象时发布失败。

## 二、战役登记

战役审阅固定按以下顺序执行，不得跳步：

1. 先把史实保存在中性事件层；
2. 判断是否存在明确后置评分或人才画像用途，决定是否晋升战役群；
3. 判断属于统一、平叛、对外战争还是安全危机，不以名称代替事实性质；
4. 按独立战略目标建立战争树并执行祖先—后代防重；
5. 分开登记实际指挥者、当时统治者控制方式和受评人物窗口归属；
6. 登记战前背景和失败利害，再分别判断战略结果等级、作战难度、战争成本和可归责失败。

任何一步未通过都停在对应层级；不得先定高档、先分配人物信用，再反向拼接战役群。

### 1. 战争树与战役群

战役登记采用最多三级的战争树，但不得为了形式完整强行补层：

1. `war_terminal`：只在一场取得天下、统一或长期战争确实包含两个以上独立战略方向时建立，保存整场战争的总体终局、总时段和跨方向关系。它是上下文根节点，不直接进入第一项 C1、C2、C3 或人才等级结算。
2. `campaign_group`：围绕一个主要对手、战区或战略目标形成的独立战役群，是皇帝 C1 和军事人才等级共同使用的基本成果单位。
3. `person_command_result`：人物在战役群内独立统帅一支主力、一个方向或一个阶段，并形成可独立验收结果时建立；必须引用所属 `campaign_group`，只供该人物责任和人才画像使用，不作为与战役群并列的皇帝成果。

只有一个独立战略方向时直接登记 `campaign_group`，不得套一个内容相同的 `war_terminal`。具体交战、围城、追击、受降、撤军和补给损耗作为中性子事件保存，默认不另立成果。

总登记和所有后置消费者必须执行祖先—后代防重：

- C1 只消费互不重叠的 `campaign_group`，不消费 `war_terminal` 或 `person_command_result`；
- 人才等级优先消费本人 `person_command_result`；没有人物子成果时才消费本人在 `campaign_group` 中的主帅或主将信用；
- 同一人物在同一战争树中不得同时消费祖先与后代节点；
- `war_terminal` 的总体终局不得因某个阶段曾由皇帝亲征，就回流成皇帝对全部子战区的本人前线指挥成果；
- 人物子成果不得继承父级的皇帝控制方式、战争成本、目标未完成、可归责失败或其他人物责任。

人物画像必须另存“完整定级依据”：列出该人物在公共成果总登记中全部具备人才定级资格的独立成果、责任角色、实际结果、当前成果等级和史源 lineage。该清单不得只保留当前人才规则命中的最少成果；以后人才阈值变化时应从完整清单重算，不得重新扫描本传或反向补猜成果。普通小战、无独立成果的具体交战和 `participant` 从攻经历不进入该清单。

划分顺序：

1. 有明确主要对手时，按对手和同一战略目标合并；
2. 无单一对手时，按区域与功能阶段合并；
3. 同一区域的取得、保持、反复和丧失优先合并；
4. 只有产生独立终局、开启新战略阶段或合并会掩盖重大责任时才另立战役群。

父级保存整体 `battle_result` 与 `objective_completion`；子事件可有不同胜败。整体未达最高目标但取得重大阶段成果时登记为 `mixed / partial`，不能只保留胜利或只保留失败。

### 2. 全类别召回与横向校准边界

战役候选必须从皇帝窗口内的连续编年主干和本纪按同一口径召回，不得只按当前人物绑定或既有评分项目筛选。每个窗口至少逐类检查：

1. 创业统一、割据清除与政权兼并；
2. 已建立统治后的叛乱、内战与地方武装反抗；
3. 对外战争与边疆攻防；
4. 入侵、围城及重大安全危机的防御处置。

类别只用于检查漏召回和解释成果性质，不是数量配额。某类没有正式成果可以成立，但必须列出固定史源覆盖范围、候选及其拒绝理由；不得以“未绑定当前皇帝或人才”“现有材料包未专门搜索该类”为零登记依据。

平叛事实默认停留在中性 `HistoricalEpisode`，不是见到“反”“讨”“平”就建立公共战役群。只有至少命中以下一项，才允许晋升 `campaign_group`：

1. 叛乱已成为跨区域、长期或威胁首都、核心疆域及政权存续的内部战略威胁，其平定结果可被第三项 A1 消费；
2. 某人物独立统帅主要方向并形成足以改变其军事人才等级的代表性实绩；
3. 皇帝亲自指挥、详细制定作战计划，或存在足以影响评分的明确决策责任；
4. 形成显著战争成本、重大失败或长期未能消除的安全后果，需要第三项 D 或负向责任消费。

普通州县骚乱、短期地方反抗以及由地方官军迅速处置且没有上述后置用途的事项，只保存中性事件和处置结论，不建立战役群。总登记是最小充分评分基础，不承担完整战争目录职责。

横向校准只在“不同政权从相近起点最终完成国内统一”这种总成果相似的场景使用：校准的是整条统一链的总成果体量，防止一方按大战役群登记、另一方把同一统一成果拆成大量子战役而重复放大。各政权的具体战役数量、路径和单项档位不要求相同。

平叛和对外战争不具有上述总成果等价关系。其发生频率、对手强度、持续时间、疆域收益和实际结果可以显著不均，必须按史实逐项登记；不得为了看起来平衡而补齐数量、合并强弱结果、压平档位或校准累计体量。此类成果只能在独立性、等级阈值和责任口径上使用同一把尺，不能预设相似总分。

### 3. 人物指挥身份与统治者控制分轴

军事参与者按其对当前注册战役群的最高实际指挥责任只取一档：`主帅`统摄战役群全局、节度多路军并承担最高军事责任；`主将`独立指挥一支主力或一个主要方向，并直接承担主要阶段结果；`从攻`有可核实作战贡献但没有主力独立指挥权。不另设 `副将`：史书称某人为主帅之副，只证明其受总帅节制；若仍独立指挥主力方向，登记为 `主将`，否则登记为 `从攻`。官名只是线索，最终以节度关系、独立统军权、实际行动和结果责任判断。同一人在子事件中表现突出，不自动改变其在父级战役群中的最高身份；若一个方向形成可独立验收的终局，应另立人物子成果后再判断其在该子成果中的身份。

征吐谷浑战役群中，《旧唐书》明确记载李靖为西海道行军大总管，侯君集与任城王道宗“并为之副”；随后李靖分军，侯君集、道宗共同统领南路深入。故父级登记李靖为节度诸军的 `主帅`，侯君集以主力南路独立指挥权登记为 `主将`；“为之副”保留在责任依据中，不再映射为单独角色。

历史上的在位统治者未进入军事指挥链时登记为 `不在军事指挥链`，不能为了容纳其身份虚构“从攻”。正向控制方式只保留三档：

| 代码 | 含义 |
| --- | --- |
| `authorization_only` | 批准、任命或下令出兵，但没有详细作战设计、持续战区统筹或前线最高指挥 |
| `operational_direction` | 详细制定分路、路线、阶段目标或作战节奏，或者实际统筹战区，但没有亲自承担前线最高统帅责任 |
| `frontline_command` | 亲临前线并直接承担该完整战役群的最高军事指挥责任 |

`authorization_mode = explicit / tacit` 区分正式授权与默许；`control_extent = partial / sustained` 区分临时压阵与持续坐镇。二者只补充事实，不另设角色。阻止、掣肘或撤销军事行动使用独立的 `obstruction_status` 和责任事实，不与正向控制方式排成一个高低梯子。

控制方式必须按当前 `campaign_group` 的完整范围判断，不得取其中某一阶段达到的最高参与方式覆盖整组。本人只在局部亲征而其他独立方向由名将完成时，不能把父级或战争终局标成完整 `frontline_command`。详细制定分路、路线和每路任务具有独立含金量，应登记为 `operational_direction`；普通遣将不得据此升级。

公共总登记中的统治者控制关系只属于事件发生时实际在位的统治者。目标人物在登基前作为亲王、储君、藩王或创业首领统军时，只登记其实际军事身份；不得倒写成皇帝亲征。该人物与其以后皇帝身份的 C1 归责由窗口绑定另存 `c1_inclusion_index = 0 / 0.50 / 0.75 / 1.00`、实际覆盖范围和逐字依据。

武将身份回答“谁实际指挥”，统治者控制方式回答“当时在位者如何授权、设计或控制战争”，C1 计入指数回答“当前受评人物对该战役群有多少本人军事归属”。三者不得互相替代。

例如赵构对岳飞军事行动的阻挠，应登记赵构的 `not_in_command_chain`、独立阻挠责任及其结果，并保留岳飞自己的实际指挥身份；不能把赵构写成从攻，也不能因皇帝没有亲征而把阻挠责任排除在战役登记之外。

### 4. 难度、成本、目标保留与可归责负面

原统一 `process_adversity / process_adversity_index` 同时混入敌情、正常成本、目标未完成和人物失误，容易把敌军强、本人中箭或接手前败局机械扣给受评人物，停止作为评分输入。战役中的不利事实必须逐条归入四个互斥方向：

| 方向 | 含义 | 后置用途 |
| --- | --- | --- |
| `difficulty_context` | 敌军强盛、前任败局、复杂地形、天气、坚城或补给环境 | 只支持作战难度，不扣人物 |
| `operational_cost` | 本方伤亡、战马舟船器械和补给损耗 | 进入军事成本收益；本人受伤另可支持亲征风险 |
| `objective_shortfall` | 核心或阶段目标未完成、成果未保持 | 由成果保留系数 `M` 处理，不重复建立人物负向 |
| `attributable_failure` | 有逐字证据的错误决策、错误指挥、违令或执行失误 | 唯一允许进入人物或皇帝负向指数的类型 |

`attributable_failure` 必须保存具体事件、责任人、责任类型、结果影响和逐字依据。责任类型仍使用 `primary / shared / subordinate_execution / disobedience / mitigated / not_responsible`；外部原因和无法归责事实不得伪装成固定人物负向。

只有 `attributable_failure` 可以使用严重度指数 `0.20 / 0.40 / 0.60 / 0.70 / 1.00`。指数表示该责任人造成的实际失败程度，不表示战役有多难或付出过普通战争成本。本人中箭、敌军清野、接掌前本方败退、敌方攻占地区但没有本人失误证据，均不得产生人物负向指数。

同一不利事实不得同时通过成果保留系数、战争成本和人物失败指数重复扣除。父级的成本或失败也不得自动继承给人物子成果；人物子成果只保存本人责任范围内的事实。

战役结果只对照该战役群在当时可证的作战目标和收束状态，不用后来发生的新战争倒推降级。主力被击溃、敌方首领逃亡且目标区域恢复控制时，本次战役可记 `victory / complete`；其后重新起兵属于后续独立事件或成果稳定性问题。只有当本次目标本来就是彻底消灭该势力、或战役收束时核心目标仍未完成，才记 `partial`。后续复起可以令 `stable_delivery=false`，但不得把已经完成的本次胜利改成 `mixed / partial`。

贞观十九年征高句丽应登记为一个父级远征战役群：盖牟城、辽东城、白岩城、驻跸山、安市城等为子事件；整体为 `mixed / partial`，安市目标未完成，拔城和驻跸山胜利保留正向事实，撤军及机动力损耗进入战争成本。不得只登记安市，也不得把各城重复算成多个完整远征成果。

### 5. 战略结果等级与作战难度

字母等级只表示已经兑现的战略结果，不表示战斗打得多难，也不表示战前失败风险。每项仍必须列明土地轴、对手在当时竞争体系中的位置、交战状态和结果轴；对手位置使用 `弱小力量 / 区域主要对手 / 第一梯队竞争极 / 主导竞争极 / 一般外部国家 / 外部霸权`，不得再用含义游移的“国家级”或“帝国主力”。

战前背景另存 `prewar_context`，只写开战前已经成立的政权态势、敌我位置和该方向在整体战争中的作用；失败后果另存 `failure_stakes`，并用 `strategic_stakes` 标为 `bounded / major / critical / existential`。四档依次表示失败可局部吸收、会造成重大区域或阶段损失、会动摇核心根据地或统一关键方向、会直接威胁国家存续。背景和失败利害必须由本战役簇固定史源支持，可以供 C1 战役重要性和任用责任重要度复用，但不得反向抬高已经兑现的字母等级。

| 战略结果类 | 战役等级 | 成立边界 |
| --- | --- | --- |
| `local_tactical` | `C` | 局部战术或低权重辅助结果 |
| `important_objective` | `B` | 重要清障、防御或单项目标，没有形成主要战略终局 |
| `major_stage_or_crisis` | `A` | 主要区域、门户、主力集团或重大阶段目标；重大失败或国家危机也按其实际影响登记 |
| `independent_direction` | `S-` | 独立强区域终局、核心根据地或长期战略方向成立 |
| `single_pole_or_state_terminal` | `S` | 终结一个第一梯队竞争极、决定单一国家存亡或整场战争 |
| `composite_poles_terminal` | `S+` | 同一战役群一次终结两个以上第一梯队竞争极 |
| `unification_terminal` | `S+` | 终结主导竞争极并直接完成从同等小型起点开始的国内统一链 |
| `external_hegemony_terminal` | `S+` | 击溃外部霸权的统治结构，并持久逆转本国所处安全秩序 |

`S+` 只允许后三条硬路径，不得用“艰苦”“名将大胜”或普通灭国代替。虎牢同时终结王世充、窦建德，走复合竞争极终局；垓下终结项羽主导竞争极并完成汉初统一链，走统一终局；灭东突厥只有在汗国统治结构崩解并逆转唐初安全秩序时才走外部霸权终局。`external_hegemony` 必须按战役发生时相对于本国的安全秩序判断：对手须能持续压迫本国核心疆域、迫使全国安全秩序围绕其调整，并具备直接威胁国家存亡的体量；大军规模、广阔疆域或只在另一地区称雄，均不能单独把一般外部国家升为外部霸权。汉初匈奴、唐初东突厥、宋辽可进入该门槛审查；显庆二年西突厥虽仍强盛且拥兵十万，但现有事实不足以证明其相对唐朝仍具这一国家存亡级压迫，只按强盛外部国家终局登记为 `S`。白登面对外部霸权但结果失败，不能因对手强而升为 `S+`。

已建立统一国家后的平叛，结果等级默认低于统一战争和对等政权战争：地方性成果通常不建立战役群；达到登记门槛者通常为 `C / B`，跨区域长期内乱或解除重大政权危机可为 `A`。只有叛军已造成事实分裂、长期控制核心区域并成为独立战略方向，平定结果才可到 `S-`；正式“叛乱”名义、皇帝动用全国资源或作战困难本身都不能升档。真正终结对等竞争政权并完成创业统一的事件应归入统一或政权兼并链，不以“平叛”名义取得 `S / S+`。

作战难度另记 `D0–D3`：`D0` 为残余或显著优势下的低难度行动，`D1` 为常态可战对手，`D2` 为强主力、坚城、复杂地形或显著后勤困难，`D3` 为极端兵力态势、霸权压迫、连续击败本方主力或近乎崩溃后逆转。难度必须有当时交战事实支持，不能只凭对手历史声望；它不得改变字母等级。刘黑闼可以因连续击败唐军主力登记为 `A / D3`，而不虚增其战略结果。

等级依据固定逐项写 `土地轴`、`对手轴` 和 `结果轴`；背景、失败利害和难度依据分别另写，不机械取平均。当前仅对汉初刘邦创业统一链与唐初李渊—李世民创业统一链执行总成果体量互校，且不混入统一完成后的平叛、匈奴、突厥、高句丽等其他战争。互校只防止相似统一总成果因拆分粒度不同而系统性多算或少算，不要求两边战役数量、路径或单项档位集合相同，也不得扩张成平叛和对外战争的累计体量校准。

## 三、治理成果登记

按以下顺序判定，任一步不成立即停止，不得靠后文补猜：

1. **结果门**：是否已有制度生效、持续程序、跨个案公共效果、明确先例或可验收公共产品；只有动作、意图或建议则拒绝。
2. **独立门**：能否独立运行、归责和验收；同一改革的法令、组织、执行与初期效果通常合并一项。
3. **证据链门**：固定史源是否合计支持历史基线、举措、实际运行、公共结果、代价或反复、持续性和人物责任。单条引文不必同时具备全部角色；政书、本纪与列传中的中性事实按稳定 `fact_ref` 连接，缺口明确保留，禁止让模型补猜。
4. **价值门**：把“已经实施或运行”与“价值方向”分开判断。国家汲取、控制、疆域、机构或账面规模增长本身不自动算正面，必须相对于当时既有状态判断四轴的实际改善或倒退。
5. **登记门**：先写不绑定皇帝的 `governance_result`，再由窗口绑定决定是否进入某皇帝投影。

中性抽取先标事实角色：`baseline / measure / operation / result / cost / continuity / responsibility`，并只标可能相关的价值轴，不在抽取阶段预判正负。无人物的粮价、人口、生产、治安等宏观结果必须保留；人物责任可以稍后由本纪或列传接入，不能因当页没有 actor 丢弃。

每项治理成果必须同时保存运行状态与 `value_judgment`。判断基线是举措实施前的同一社会状态，不是现代制度理想，也不以数百年后的远期后果替代当时可验证结果。四轴固定为：

1. **生产力与民生**：生产、交换、财政可持续性、人口恢复、生活负担；
2. **文明与制度进步**：权利义务、法治、行政能力、人才流动、反馈纠错；
3. **国家与民众安全**：治安、边疆、外部压力、灾害与生存风险；皇权或皇室自身安全不计；
4. **文化教育与思想活力**：教育和知识生产、传播、表达空间、思想禁锢与精神压力。

每轴分别记录方向、进步强度和逐条 `fact_ref` 依据。方向使用 `positive / negative / mixed / unclear / not_established`；强度使用 `limited / significant / structural / era_shaping / not_established`。总体净方向必须由四轴证据综合得出。降低社会成本、保护生产恢复和发展弹性、形成稳定法治、扩大人才流动、建立反馈纠错及产生可验证民生改善，支持正面判断；加重汲取、身份固化、告密连坐、反馈封闭、秘密控制、制度错配、思想禁锢或精神恐惧，支持负面判断。利弊同时成立时登记 `mixed`，证据不足时登记 `unclear`，不得以“制度完成”“国力增强”替代价值判断。

`scale` 只回答影响覆盖到局部、区域还是全国，不回答进步有多大，也不直接决定人才档位。全国性低增益制度不能因覆盖广自动升档；范围较小但形成可复用结构改善的成果，也不能被规模字段压低其进步强度。

朝代政书 current 是共享事实源，不是某一皇帝的私有材料。凡纪年与当前皇帝窗口相交、或明确点名当前皇帝及其臣子的已验收治理事实，都必须在本次成果工作清单中逐条形成“登记、并入既有成果或拒绝”的处置；不得因为该材料已被另一皇帝使用、当前 source pack 尚为空，或名称看似相似而跳过。共享材料只抽取一次，但每个皇帝窗口都要独立完成成果处置和绑定。

治理成果按同一历史结果链去重，不按政策名称去重。不同皇帝先后实施名称或形式相似的政策，只要生效时点、适用范围、执行链或公共结果不同，就分别登记；同一改革的法令、组织、执行和初期效果才合并。临时占领秩序与后来全国正式法典也不得仅因都属“约法”或“律令”而机械合并、等同定级。

| 事实类型 | 处理 |
| --- | --- |
| 已生效并持续改变税负、服役、任期、司法等权利义务 | 登记；制度约束本身即结果 |
| 已运行制度、跨个案公共效果、完成并投入使用的公共产品 | 登记 |
| 迁都、设官、建机构、任命、结约、颁令，但没有生效或公共结果 | 只留 Episode |
| 奏疏、谏言、批评，没有独立实施或结果史源 | 只供相应规则消费，不登记成果 |
| 单案改判、一次礼遇、个人赏罚、官职、参会、一般言行 | 不登记成果 |
| 政变、清洗、权力争夺仅改变最高权力归属 | 不登记治理成果；按需进入谋略事实或政治风险 |

特殊类型只按下表处理：

| 类型 | 登记规则 |
| --- | --- |
| 粮价、人口、生产、治安等宏观结果 | 登记 `macro_public_result`；原文明示承接总体治理用 `source_attributed`，仅同时期关系用 `limited`，不得伪归因于单项政策 |
| 一代正史、跨代通史或同量级大型典籍 | 完成并投入国家使用即为 `national_cultural_corpus`；普通单朝实录通常仅 `important` |
| 文明奠基作品 | 仅本人独著、主编或最终定稿，且作品开创范式并长期作为基础文本，才可标 `era_shaping / foundational` |
| 专业目标伴随跨领域代价 | 保留专业结果，代价另行登记；不得在成果簿内机械抵消 |

人物责任只取一档：`exclusive`=独立建立且无同级共同主导者；`lead`=主导方案或持续执行；`governance_participant`=有逐字证据的实质参与；`authorized`=只批准或维持授权。另以 `contribution_types` 记录其实际贡献是政策设计、制度设计、实施主导、运行交付、纠偏监督还是学术创作，并用责任事实的 `fact_ref` 支撑。授权、任职和参会不能推定实施责任；文化轴受益也不能把一般行政组织者自动定为文化人才，文化档只消费本人学术创作或最终定稿责任。

## 四、谋略成果登记

谋略成果与战役、治理并列，只登记本人提出或主导、已被采纳并形成独立可核实战略结果的非指挥成果。它只供人物画像消费，不进入皇帝治理投影，也不把谋士伪装成主帅。未实施建议、一般献策、只有手段成功而无独立战略结果、纯夺权或宫廷清洗均不登记；玄武门谋划和云梦骗捕韩信不得仅凭行动成功转成正向成果。

谋略规模沿用公共结果的 `local / important / regional / national / era_shaping`，但含义限于战略影响范围。成员仍按 `exclusive / lead / governance_participant / authorized` 记录实际责任；同一战争或危机中的多个步骤只有能独立归责、独立产生结果时才可拆分。

## 五、人才等级

人才等级是跨皇帝复用的全生涯能力轴，政治风险与其正交。共享人物画像按朝代分区保存并确定性合并为唯一全局视图，在任何皇帝窗口绑定前由全部公共成果统一计算；同一 `person_ref` 只能对应一个 `profile_ref`、一个全生涯总档和一组分领域档位。实绩限定上限，权威评价用于校准归属、时代位置、置信度和相邻档，不以官职、声望或单次高光定档。军事与治理分别定档，不得让治理成果猜测对应哪个战役字母档。

人物画像登记不得以团队建设材料预算为名单边界。凡在战役、治理、谋略中具有可归责记录，或进入跨窗口任用候选闭包的人物都进入总人物表；正向八人、负向三人及支持材料的选择只作为后置投影。未完成全生涯本传的人物仍须展示，但只能标记为“现有登记支持的档位下限”，不得伪装成冻结终值。政治风险事件可在公共事实层留存，但“是否在某皇帝窗口暴露、由该皇帝承担何种团队风险”只能写入窗口投影，不得反向改变共享画像。

皇帝本人在自己的在位窗口内形成的治理成果仍属于其完整生涯事实和公共成果责任链，但不得用于抬高该皇帝本人的治理人才档位；画像必须把这些成果列入 `talent_grade_exclusions`，理由固定为 `ruler_own_reign_governance`。这是为了区分“作为统治者取得公共治理结果”与“可被其他皇帝任用的人才能力”，避免皇帝因天然拥有全国治理权限而人均高档。登基前、退位后或作为臣子独立承担的治理成果仍按普通人物规则审查。

治理人才的正向档位只消费 `value_judgment.overall_direction = positive` 的治理成果。`mixed / negative / unclear` 仍须保留在完整人物画像及责任链中，用于显示能力边界、代价和负向责任，但不得抬高正向治理人才等级；不能以“局部专业目标完成”覆盖整体价值方向。军事成果仍按战役专业结果与跨领域代价分账，不受本条改变。

军事、治理、谋略和文化学术分别独立定档，总档取已经成立的最高领域档位；其他领域只展示能力广度，不能互相凑数量门槛。两个领域分别独立达到 `top` 时，可以走配置中明确的全能型 `historic` 路径；除此之外不得跨领域相加。最高档并列时全部列为主领域。

### 1. 军事人才门槛

先过滤责任，再看主锚，最后看复验。人才档只计算本人作为主帅或主将取得的独立正向战役群；从攻事实仍进入人物履历，但不能分享主帅、主将的战略终局信用。同一战役群不因多场交战重复计算。

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无达到 `C` 级的本人已实现指挥成果；材料不足不能推定普通 |
| `usable` | 至少一个本人主帅或主将的 `C` 级以上已实现成果 |
| `important` | 至少一个本人主帅或主将的 `A` 级战役群；没有 `A` 时，至少两个独立 `B` 级主力指挥成果 |
| `top` | 有一个本人主帅或主将的 `S-` 级以上主锚，并由稳定兑现、另一项 `A` 级以上成果或重要军事方法完成复验；决定性 `S+` 自带复验 |
| `historic` | 在 `top` 之上满足“巅峰双成果”或“持续战略统帅”任一路径，见下文 |

为避免穷举排列组合，只给 `A` 以上主力指挥成果计算战略权重：`A=1、S-=2、S=3、S+=4`，`B/C` 不计战略权重。`historic` 只有两种语义路径：

1. **巅峰双成果**：至少两项独立成果，满足“一个决定性 `S+` 加另一个 `A` 以上”，或“两项均为决定性 `S` 以上”。
2. **持续战略统帅**：至少三项独立 `A` 以上成果，其中至少一项 `S` 以上，战略权重合计不少于 `7`。

该权重只压缩组合表达，不改变战役本身等级，也不进入分项计分。它使 `S + S- + S-`、`S + S + A` 等等价组合自动落在同一路径，而 `S + S- + A`、三个 `S-` 等未达到门槛的组合自然排除。`S+` 不是 `S` 的显示别名：它可以单项建立 `top`，但升 `historic` 仍需独立复验。

### 2. 治理人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人主导或独占的已实现治理成果；材料不足不能推定普通 |
| `usable` | 至少一个本人主导或独占、已实施且形成可观察正向结果的治理成果 |
| `important` | 至少一个达到 `significant` 进步强度的本人主导或独占成果 |
| `top` | 至少一个 `structural` 进步成果，并有稳定运行、另一项 `significant` 以上独立成果或重要治理方法之一 |
| `historic` | 一个 `era_shaping` 进步成果加另一项独立 `significant` 以上成果；或至少两个 `structural` 进步成果且合计至少三项 `significant` 以上独立成果 |

这里的进步强度来自四轴及总体判断，不由 `scale` 换算。人物只有在责任事实证明其承担政策或制度设计、实施主导、运行交付或纠偏监督时，才消费该成果；只授权者不分享治理人才信用。

### 3. 谋略人才门槛

| 档位 | 门槛 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人主导、已实施并形成独立战略结果的谋略成果 |
| `usable` | 至少一个范围有限但已实现的本人谋略成果 |
| `important` | 至少一个 `regional` 级以上主导或独占谋略成果 |
| `top` | 至少两个独立 `national` 级主导或独占谋略成果 |
| `historic` | 至少三个独立 `national` 级主导或独占谋略成果 |

文化学术与跨领域路径继续按执行配置单独判断，不借用战役字母档。执行门槛以 `config/talent-grade-v11-domain-equivalent-historic.yml` 为准。同一战役、治理或谋略责任链只计一次；专业目标失败和同领域灾难性失败进入能力一致性复核，其他领域代价不能抹去已经成立的专业事实。

## 六、政治风险

政治风险只认本人直接实施、命令、持续放任或以实际责任造成的公共损害。私德、结局、普通战败、被诬告、官位、亲属身份和史料详略不成立风险；功绩和人才等级也不能抵消风险。

风险与人物全生涯事件相连，但每个皇帝只消费本窗口内已经实施或暴露的风险。未过公共损害门槛记 `below_floor`，材料不足记 `insufficient_evidence`，均不得伪装成无风险。严重度、历史影响范围、责任、实现状态和检索完备性全部由唯一执行合同 `config/political-risk.yml` 判定；子流程不得自行类比定档。

公共层只保留三条硬边界：单次故意或无正当依据直接致人死亡不得低于 `material`；多次直接致死、严重身体伤害或群体伤害不得低于 `major`；史料详略、名声、官位和人才等级不得改变风险档位。历史影响范围与严重度分开登记。

普通战役失败不自动成为政治风险。只有擅自出兵、违令冒进、弃军弃城、杀降毁约、纵兵劫掠、持续损兵或其他明确可归责公共损害，才进入风险审查。

## 七、跨项引用

第一项可引用战役群、皇帝关系、人物指挥身份、规模和过程逆境；第二、三项可引用治理成果、军事安全和公共代价；谋略登记只供人物画像及明确允许的规则引用；第五项可引用人才等级、政治风险和授权责任。任何分项只能声明 eligibility、方向、材料预算和数值映射，不能修改公共事实、人物全生涯档位或风险事件。
