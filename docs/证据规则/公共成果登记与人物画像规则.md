# 公共成果登记与人物画像规则

> 状态：当前 shadow 公共合同。它只保存可跨朝代复用的判据；已完成样本、批次状态、迁移过程和阶段性横向排序留在 canonical 数据与 Git 历史中，不写回合同。

## 一、公共对象与处理顺序

史料先形成中性的 `HistoricalEpisode`，再按可独立验收的结果归并为 `HistoricalOutcomeCluster`。人物全生涯画像由无窗口公共成果和本传事实重建；评分项只能后置判断适用性、方向和数值，不能复制一套事实或反写公共结果。

固定顺序为：中性材料 → 战役、治理与谋略公共成果 → 人物全生涯画像 → 皇帝窗口绑定与窗口政治风险 → 规则材料映射 → 计分。必须先完整登记符合门槛的成果，再计算人才档位；不得先看人物是否“够档”，再决定补录或删除战绩。

同一事实和同一独立结果只保存一次。跨书材料只补足边界、结果、责任、持续性和冲突，不按来源数重复登记。Google、网页摘要、游戏数值和模型常识只作发现或异常提示，不能代替固定史源裁决。

公共成果与人物画像按朝代 token 分区；顶层 `current.*` 只是各分区的确定性无损合并。`HOUT-*`、`PROFILE-*`、`person_ref` 全局唯一。跨朝成果指定唯一主分区，其他分区只能引用；同一人物的异名、即位前后身份和跨朝代活动必须归并到同一 `person_ref`。

## 二、战役公共登记

### 1. 准入与去向

战事先保存为中性事件，只有满足下列至少一项才晋升公共战役成果：

1. 产生可验收的显著领土、政权存亡、主力损害或国家安全结果；
2. 形成能够改变人物军事能力判断的独立指挥成果；
3. 存在会影响皇帝评分的亲征、具体作战统筹或重大决策责任；
4. 形成重大成本、失败或长期安全后果，需要后置规则消费。

地方短期骚乱、普通州县叛乱、小规模交战和无独立结果的追击、围城、受降默认停在事件层。宫廷政变、刺杀、禁军夺权、诛杀权臣和一般军中哗变转入政权交接、谋略或政治风险；只有发展为正规军持续交战并形成区域控制或独立战略方向后，才从该阶段建立战役成果。

候选最终只能有一个去向：`CAMPAIGN_GROUP`、`REDIRECT_NON_BATTLE_OUTCOME` 或 `BELOW_PUBLIC_OUTCOME_THRESHOLD`。未完成边界、档位或人物裁决的记录不得进入人才消费。

正式成果必须引用战役底账最终 `war_event_id`，并保存足以复核目标、结果、责任和来源的 lineage。标题、SB/SN/WC、灭国字样、伤亡数和史学名气只能触发复核，不能换算档位。

### 2. 战争树、拆合与去重

战争树最多三级，不为形式完整强行补层：

1. `war_terminal`：长期战争或统一战争的上下文容器，不直接计入皇帝成果或人才等级；
2. `campaign_group`：围绕同一主要对手、独立战略目标、战区和连续指挥后勤链形成的可消费基本成果；
3. `person_command_result`：人物在父群内独立承担方向、阶段或主力并形成可单独验收结果时建立，只供人物责任和人才消费。

大型战争按交战各方的持续动员能力、独立目标、战区与收束状态拆分。时间长、地域广只是线索；更换统帅后仍能重建军队并继续不同战略目标，通常说明这是战争组合而非单一战役群。连续进攻中的交战、围城、追击和受降不得拆成多个终局。

父候选覆盖多个独立动员或战略收束时，记为不可消费的 `SPLIT_CAMPAIGN_PORTFOLIO`，子群分别裁定。两项候选共享对手、目标、战区和连续指挥后勤链，且前项没有独立终局时，以 `MERGED_INTO_PARENT` 合并，并完整保留被吸收 lineage。

所有消费者执行祖先—后代防重：皇帝战役成果只消费互不重叠的 `campaign_group`；人才优先消费本人 `person_command_result`，没有人物子结果时才消费其在父群中已闭合的实际贡献；同一人物在同一能力情境不得同时消费祖先和后代。父级成本、失败、难度和他人贡献不得自动复制给人物子结果。

同一区域的失陷、收复、再失陷和最终收复分别保存事实，但组合校验只计算评价主体的实际净结果。主力受创、政权终结和残部平定若属于同一因果链，不得包装为多个终局。

### 3. 战略结果三轴

战役字母档只表示已经兑现的战略结果，不表示过程难度、战前失败风险、史书篇幅或人物名望。每项必须分别闭合土地轴、对手轴和结果轴，不能把同一证据在三轴重复抬高。

土地轴按战役当时的功能性战略重量裁定，不按“州、郡、道、县、城”的名称、数量或名义面积跨时代换算：

| 土地轴 | 功能边界 |
| --- | --- |
| `local_point` | 普通据点或离散目标，无独立军政财政功能 |
| `strategic_gateway` | 控制进退、补给或跨区交通的关隘、渡口、粮道、河谷等节点 |
| `important_region` | 具有显著人口、赋税、兵源、军备或交通价值的成片主要区域 |
| `core_heartland` | 可持续征兵、征税、供粮、驻军和组织指挥的核心腹地或完整强区域基地 |
| `capital_or_state_survival` | 中央军政中枢或得失直接影响政权存续的核心战区 |

土地依据至少说明人口财赋、兵源军备、交通门户、连续控制或战略方向中的一项功能。短期破城、离散据点和名义归附不得超过实际可控功能。一个小政权的全部领土可以证明其终结，却不能因为“这是对方全部”自动成为核心腹地或 `S-`。

对手轴必须先区分政治体系，再判断战前强度：

- `minor / regional_major / first_tier_pole / dominant_pole` 仅用于同一统一、内战或国内竞争体系；地方叛乱不得因动员规模或一时占都自动写成竞争极。
- 有独立战争、议和和外交决策链的政权记 `external_state`；强弱另以 `opponent_condition=strong / viable / weakened / residual / unclear` 表示，不能把外国降写为国内区域势力。
- `external_hegemony` 不是永久国号标签。它要求本役战前同时存在：持续压迫评价主体核心疆域、迫使全国安全秩序围绕其调整、具备直接威胁国家存亡的能力。三项都须有事件期证据，同一政权可随时期升降。

结果轴至少记录 `battle_result`、`objective_completion`、控制保留和敌军效果。战略目标可以是攻城略地、政权终结、解围保全，也可以是削弱或摧毁敌方有生力量。`opponent_force_effect` 固定为：

| 敌军效果 | 边界 |
| --- | --- |
| `none` | 无可验收军力损害 |
| `limited_attrition` | 一般消耗或局部斩获 |
| `major_degradation` | 重创成建制主力，但对手仍能维持同一战争 |
| `main_force_destroyed` | 当前战略方向主力失去继续作战能力 |
| `military_system_collapsed` | 对手整体军事组织无法继续运转 |

土地、主力损害和政权终结是同一结果的不同观察轴，不能相加成多个成果。大胜而未克不按反事实胜利档机械减一：按实际已兑现的重大阶段成果定档，未完成目标进入 `objective_shortfall`。`major_degradation` 通常最多支持实际 A 级阶段成果；`main_force_destroyed` 只有在独立方向和对手分量同时成立时才支持更高档；`military_system_collapsed` 仍须满足相应终局硬路径。

战败也不按“应有胜利档减一级”。负向档按实际损失直接裁定，并以 `result_direction=negative` 分离：有限远征未克可以很低，主力覆灭、核心区或首都失守、政权终结按其真实影响登记。胜方正向档与败方负向档不要求相等。

### 4. 战略结果类与字母档

| 战略结果类 | 等级 | 成立边界 |
| --- | --- | --- |
| `local_tactical` | `C` | 局部战术或低权重辅助结果 |
| `important_objective` | `B` | 重要清障、防御或单项目标，未形成主要战略终局 |
| `major_stage_or_crisis` | `A` | 主要区域、门户、主力集团或重大阶段结果；重大负向结果亦按实际影响登记 |
| `independent_direction` | `S-` | 强区域终局、核心根据地或长期独立战略方向成立 |
| `single_pole_decisive_defeat` | `S` | 决定性摧毁第一梯队竞争极的核心主力，但政权未在本役终结 |
| `external_hegemony_decisive_defeat` | `S` | 决定性摧毁外部霸权的王庭、核心主力或同等军事中心，但统治结构或安全秩序逆转尚未闭合 |
| `single_pole_or_state_terminal` | `S` | 终结第一梯队单一竞争极，或完成具有全国分量的外部国家终局 |
| `composite_poles_terminal` | `S+` | 同一战役群一次终结两个以上第一梯队竞争极 |
| `unification_terminal` | `S+` | 从有限根据地推进到核心区域统一，或在统一总链中终结多个第一梯队竞争极 |
| `external_hegemony_terminal` | `S+` | 击溃外部霸权统治结构，并持久逆转评价主体所处安全秩序 |

`S+` 只允许表中三条硬路径。普通灭国、艰苦作战、名将大胜、广阔疆域或大军数量都不能替代。`single_pole_decisive_defeat` 要求 `first_tier_pole / dominant_pole + victory / complete + main_force_destroyed`；`external_hegemony_decisive_defeat` 要求战前霸权三项成立且至少摧毁核心主力；`external_hegemony_terminal` 还必须另行证明统治结构崩解和安全秩序持久逆转。选择 `external_hegemony` 时，无论最终档位高低都必须保存完整战前评估。

已建立统一国家后的平叛通常只到 `C/B`，跨区域长期内乱或解除重大政权危机可到 `A`。只有叛军已造成事实分裂、长期控制核心区域并形成可持续独立战略方向，才可到 `S-`。真正终结对等竞争政权并完成创业统一的事项归统一或兼并链，不借“平叛”名义取得 `S/S+`。

组合层只作异常筛查，不另造总分公式。统一链和大型战争应检查首次净控制、独立对手、国家安全秩序变化与重复终局；若普通战争累计结果异常接近一条完整开国统一链，必须复核是否切得过碎、重复计算收复、把人物阶段成果升成公共终局，或错误抬高对手位置。组合校验不得反向压低人物确实承担的高难度。

### 5. 作战难度、成本和不利事实

作战难度回答“以当时资源、情报、距离、地形、后勤和对手状态，这个军事问题本身有多难”，不回答最后打得是否轻松：

| 难度 | 边界 |
| --- | --- |
| `D0` | 未形成有效军事对抗，或主要接收已崩解残余 |
| `D1` | 本方综合优势足以稳定覆盖常规风险；胜得快本身不是依据 |
| `D2` | 存在强主力、坚城、复杂地形、远距离或显著后勤中的一项重大难点，但本方总体态势仍覆盖主要风险 |
| `D3` | 两项以上重大约束相互强化，需要一线统帅质量才能稳定完成；执行干净、伤亡低也不降档 |
| `D4` | 明确极端劣势、孤军、断粮、被围、战线濒临崩溃或连续败退后的临阵逆转，并有可追踪的判断与组织事实 |

难度必须按战前可见条件裁定；著名战役、名将身份、灭国或远征不自动升档。父级难度描述整个战役群；人物只消费本人实际承担的问题，共同统帅和方向主将不得各自复制父级全部 D3/D4。

不利事实必须互斥归入四类：

| 类型 | 后置用途 |
| --- | --- |
| `difficulty_context` | 敌强、复杂地形、天气、坚城、补给环境或接手前败局；只支持难度 |
| `operational_cost` | 伤亡、战马舟船器械和补给损耗；进入成本收益 |
| `objective_shortfall` | 目标未完成或成果未保持；处理成果保留，不自动生成个人负向 |
| `attributable_failure` | 有逐字证据的错误决策、错误指挥、违令或执行失误；可进入人物或皇帝负向 |

同一事实不能同时通过成果保留、战争成本和人物失败重复扣除。`attributable_failure` 必须保存责任人、责任类型、实际影响和史源；敌军强、本人受伤、接手前败局和无法归责的战败不得伪装成人物失误。后续复发可以影响成果持续性，但不能倒写已经完成的当次目标。

### 6. 组织身份、实际贡献与统治者控制

`role_code` 只保存历史组织关系：`commander_in_chief / principal_commander / participant / not_in_command_chain`。官名、爵位和“副”字只作线索；无法闭合实质主帅时记 `command_unresolved`。低档战役只闭合史料明确人物；`S-/S/S+`、重大失败和可能改变人才主锚者必须追索完整指挥链。

`campaign_command_topology` 只描述 `single_integrated_command / joint_integrated_command / federated_directions / opposed_commands / distributed_response / command_unresolved`，不直接分配信用。

人物能力贡献由两轴决定：

- `capability_mode = integrated_command / independent_direction / operational_design / tactical_execution / authorization_only / nominal_only`；
- `decisive_relation = decisive_creator / decisive_successor / co_decisive / terminal_finisher / stage_executor / none`。

只有史料闭合到本人实际控制和实际结果时才形成能力信用。主帅、主将、从攻和皇帝身份本身不决定消费比例。前任没有正向成果、后任接手并扭转终局时，后任可记 `decisive_successor` 完整消费本人解决的结果和难度，前任保存负向事实；前任已摧毁主力而后任只收尾时，后任记 `terminal_finisher`。人物结果不得继承同僚、官职或父群中本人未完成的部分。

统治者控制只记 `authorization_only / operational_direction / frontline_command`。普通低档战事在唯一在位者明确而无具体指挥事实时可记制度性默认授权，但不产生军事人才信用。`operational_direction` 要求逐字锚闭合到本人设计的详细路线、分路、阶段目标或持续战区统筹，并已有相应战果，人物层写为 `consumption_mode = operational_result / capability_mode = operational_design`；只见任命、出师命令或朝廷名义不得升级。`frontline_command` 要求亲临并承担实际最高指挥。皇帝窗口归属另行计算，不反写公共事实。

## 三、治理与谋略成果

### 1. 治理成果

治理成果依次通过五道门：已有可观察结果；能够独立运行、归责和验收；固定史源支持基线、措施、运行、结果、代价或持续性；价值方向能够相对举措前状态判断；先登记无窗口公共结果，再做皇帝窗口绑定。只有动作、意图、任命、颁令或建议而无运行和公共结果时，停在事件层。

事实角色使用 `baseline / measure / operation / result / cost / continuity / responsibility`。运行状态使用 `implemented / operated / completed / failed / unclear`；价值方向使用 `positive / negative / mixed / unclear / not_established`，不得把 `mixed` 写成运行状态。

价值判断固定写“举措前基线—实施变化—实际结果”，并按四轴分别给出方向、强度和 `fact_ref`：生产力与民生、文明与制度进步、国家与民众安全、文化教育与思想活力。强度使用 `limited / significant / structural / era_shaping / not_established`。疆域、机构、汲取能力或账面规模增长本身不自动等于进步；利弊同时成立记 `mixed`，证据不足记 `unclear`。

治理成果按同一历史结果链去重，不按政策名称去重。`scale` 只表示覆盖范围，不换算进步强度。人物只有在史源证明其承担政策或制度设计、实施主导、运行交付或纠偏监督时才消费；在位、授权、任职和参会不推定成果成员。跨朝沿革可保存完整生命周期，但每个皇帝窗口必须另有逐字责任事实。

朝代政书中性材料属于共享事实源。每个已验收治理 `fact_ref` 必须恰好得到 `register / merge / reject` 处置；皇帝会话只增量补本纪、列传事实、责任和窗口绑定，不能把“政书已扫描”误写为全朝治理成果已经穷尽。

### 2. 谋略成果

谋略只登记本人提出或主导、已被采纳并形成独立可核实战略结果的非指挥成果。未实施建议、一般献策、只有手段成功而无独立战略结果、纯夺权或宫廷清洗均不登记。谋略只供人物画像及明确允许的规则消费，不进入皇帝治理投影，也不把谋士伪装成主帅。

## 四、人物画像与人才等级

人才等级是跨皇帝复用的全生涯能力轴，政治风险与其正交。每个 `person_ref` 只能有一个 `profile_ref`、一个全生涯总档和一组分领域档位。实绩限定上限，权威评价和外部参考系只校准时代位置、置信度与相邻档，不得覆盖公共成果。

人物画像保存全部具备定级资格的独立成果、实际贡献、结果、难度、负面和 lineage，不能只保留当前门槛命中的最少样本。材料未覆盖完整生涯时只能标示当前证据支持的下限，不伪装成冻结终值。军事、治理、谋略和文化学术分别定档，总档取已成立的最高领域；除配置明确的跨领域路径外，不得跨域凑数。

### 1. 军事人才消费

军事人才只消费公共战役登记中已经闭合的人物实际能力结果。秦至唐当前 canonical 输入为 `docs/公共成果/军事/01-战役登记.json`，输出为 `docs/公共成果/军事/02-武将人才等级.json`；扩展到唐以后时按同一 schema 追加朝代分区并确定性合并，不复制旧档位或以旧人物画像覆盖新战役登记。

同一能力情境只取一项最高人物结果计算门槛和净值；跨多个公共结果但实为同一次连续解题的情境，由 `config/military-capability-episodes.json` 显式合并。对手相同不自动合并，目标、战区或所解决问题不同仍可保持独立。

正向主锚要求本人为 `decisive_creator / decisive_successor / co_decisive`，且不是纯授权、挂名或未落实建议。`terminal_finisher / stage_executor` 只消费实际完成部分，不构造父级战略峰值。`operational_design` 可作为统筹复验，但不得继承前线难度或冒充本人前线终局。

负面结果独立保存，不把正向成果机械降档。指挥败绩按本人实际范围检验稳定性；逐字闭合的错误决策、违令或执行失误另记 `attributable_failure`，同一事实不得双扣。对 `elite` 及以上候选，重大败绩必须同时闭合结果责任和致败责任：先定向检索；检索后仍不能证明免责而本人确为实际主帅时，按 `COMMANDER_RESPONSIBILITY_AFTER_UNRESOLVED_SEARCH` 计主帅结果责任，不再保留过错未知。只有史料明确闭合强制命令、外部灾害或本人未实际控制，才使用 `NO_FAULT_* / NOT_RESPONSIBLE` 免责。反复重大主责或共同败责可阻断依赖稳定性、重复攻坚或持续厚度的高档路径，但不能反写已经成立的单项能力峰值。

高档先算正向能力上限，再过稳定性下限。重大情境只统计本人实际闭合的独立 `A/D2+` 结果：正向不超过三项时，一项重大主帅败责或两项重大不利即可下压一档；正向达到四项后，至少两项重大败责且败责达到正向的一半，或重大不利已接近正向数量，才下压一档；正向至少五项、含两个 `S/D3+` 高峰且重大败责不超过一项者，不因少数败绩下压。战争发动、杀俘、纵掠等非指挥负面不得进入军事人才稳定性 Gate。

| 档位 | 能力边界 |
| --- | --- |
| `ordinary` | 完整覆盖后仍无本人已实现的 C 级军事贡献 |
| `usable` | 至少一项本人已实现的 C 或 B 级贡献 |
| `capable` | 至少一项 A，或两个独立 B 级能力情境 |
| `important` | 至少一项 `A/D2+`，或两个独立 A 级能力情境 |
| `elite` | 强将级：形成决定性 `S-/D2+` 峰值、两项独立 `A/D3+` 攻坚，或三项独立 `A/D2+` 可靠方面表现之一；战争统筹必须有独立前线复验 |
| `top` | 全国一线：`S+/D3+` 本人决定性成果可直接成立；`S/D3+` 必须另有一项独立 `A/D2+`；`S-/D3+` 必须另有一项 `S-/D2+` 或至少两项独立 `A/D2+`；本人已有 `S/D2+` 前线峰值时，也可由独立 `S` 级战争统筹成果和另一项 `A/D2+` 前线成果共同复验；持续履历路径要求至少四项独立 `A/D2+`，且其中至少一项达到 `A/D3+` 或 `S-/D2+`。战争统筹不继承前线难度，且不能单独建立 top。单个可持续 `S-/D3` 或四项同质 `A/D2` 不再直通 top |
| `historic` | 必须先满足 top，并形成时代罕见的终局峰值、极难攻坚组合或持续大统帅履历；除 `S+` 终局双锚、双 `S` 极端攻坚和持续大统帅路径外，独立 `S/D4 + S-/D3+` 极难双峰还须另一项 `A/D2+` 前线复验方可成立。至少要求 S/S+ 高峰、独立高难战略复验和足够的跨情境厚度，不能由单次高光、纯数量或纯统筹成立 |

`elite / top / historic` 只允许“峰值、攻坚、持续大统帅”三类通用能力解释。具体机器门槛必须是这三类的确定性展开；新样本不匹配时先复核战役切分、结果档、问题难度和贡献，不得增加人名或单战特判。档位由门槛决定，净战略值只作同档横向校准。

净值每个能力情境只取一个结果。基础值：`C=0.15、B=0.4、A=1、S-=2.2、S=3.6、S+=6`；难度乘数：`D0=0.55、D1=0.75、D2=1、D3=1.25、D4=1.55`；决定性创造和接续逆转系数 1，共同决定 0.85，收尾 0.5，阶段执行 0.35，战争统筹 0.4 且不继承前线难度。前线正向成果按 `1、0.65、0.35、0.2、0.1、0.05……` 递减，统筹成果按 `1、0.6、0.35、0.2、0.1、0.05……` 递减，负向乘 `-0.8`、混合乘 `-0.4`。不另加名气、常胜、方法、平方或单项稳定奖励。

### 2. 治理与谋略人才

治理人才只消费总体方向为 `positive`、本人承担设计或交付责任的独立成果；统治者本人在自己在位窗口内依靠天然全国权限取得的治理成果，列入 `talent_grade_exclusions: ruler_own_reign_governance`，不抬高其作为可任用人才的治理档位。`mixed / negative / unclear` 保留为能力边界，不折算半项正向信用。

治理档位：`usable` 至少一项已实现正向成果；`important` 至少一项 `significant`；`top` 至少一项 `structural`，并有稳定运行、另一项 `significant` 或重要治理方法复验；`historic` 要求一项 `era_shaping` 加独立 `significant`，或两项 `structural` 且合计至少三项 `significant`。

谋略档位：`usable` 至少一项有限但已实现的独立谋略；`important` 至少一项 `regional`；`top` 至少两项独立 `national`；`historic` 至少三项独立 `national`。文化学术和跨领域路径按 `config/talent-grade-v11-domain-equivalent-historic.yml` 判断，不借用战役字母档。

## 五、政治风险与跨项引用

政治风险只认本人直接实施、命令、持续放任或以实际责任造成的公共损害。私德、结局、普通战败、被诬告、官位、亲属身份和史料详略不成立风险；功绩和人才等级也不能抵消风险。事件可保存在全生涯事实层，但每位皇帝只消费本窗口内已经实施或暴露的风险。

普通战败不自动成为政治风险。只有擅自出兵、违令冒进、弃军弃城、杀降毁约、纵兵劫掠、持续损兵或其他明确可归责公共损害，才进入 `config/political-risk.yml` 审查。

第一项可引用战役群、统治者控制、人物实际贡献、战略结果、难度与成本；其他分项按各自合同引用公共成果、人才等级和政治风险。任何消费者只能声明 eligibility、方向、材料预算和数值映射，不能修改公共事实、人物全生涯档位或风险事件。
