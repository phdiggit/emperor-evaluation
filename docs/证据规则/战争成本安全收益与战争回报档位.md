# 战争成本、安全收益与战争回报档位

## 一、用途

本文件用于读懂和追溯保留的旧战役卡，**不用于重算现行正式分数**。当前军事成本和第三项换分以[军事成本合同](军事成本评估合同.md)及[第三项合同](../分项规则/第三项军事与边疆净收益/README.md)为准；旧网页采集和D净Q流程已退役。

一场战争分开记录四类事实：

| 账户 | 记录什么 |
|---|---|
| `WC0—WC7` | 已经付出的人员、生产、动员、运输和军资财政成本。 |
| `SB0—SB5 / SN0—SN5` | 已经形成的安全改善或恶化。 |
| `WR0—WR5` | 当期实际取得且可使用的物资、军事资产和财政资源。 |
| `BCP0—BCP5 / BCN0—BCN5` | 实际取得、守住、恢复或失去的地区、通道、防线和节点。 |

各档位不相加，也不互相抵销。只记本主体、本阶段的事实；胜利不能代替成本证据，土地控制不再作为物资回报重复记录。创业过程另填启动账，独立税役或恢复政策另存史源。

皇帝、储君的人员损失仍按P，宫室资产按A，不设身份倍率；高档仍须有公共体系实际变化。

### 事件准入边界

从实际起兵、调军、据城、攻宫或武装伤害的阶段开始记录。未实行的谋反、刺杀计划，单纯储位争夺、审讯、处刑、籍没和没有实际武装行动的宫廷政变，只作政治背景；不能把诱因或事后处刑算成战争损失。

### 建国启动账

开国、复国、割据政权建立或新政权取得稳定统治基础过程中的战役，在每个适用的主体阶段卡填写：

```text
is_founding_process：true
founding_stage：REGIME_EMERGENCE／TERRITORIAL_EXPANSION／REGIME_CONSOLIDATION
startup_significance：本阶段实际取得、失去或未能取得的建国基础
```

三个阶段依次表示形成可持续的政治中枢、扩展地盘资源和通道、巩固控制。没有史源支持时，`is_founding_process=false`，阶段记`NOT_APPLICABLE`；启动账不替代各轴事实。

## 二、战争成本档位 `WC`

### 1. 判档顺序

成本采用四轴独立判定：

1. **人员损害轴 `P`**：死亡、未归、被俘被掳、流亡和明确伤残。
2. **地区—生产体系轴 `S`**：战争对城市、农业、交通、税源、行政和军政控制的实际破坏。
3. **动员—服役—运输轴 `M`**：已经发生的征兵、民夫、转输、驻屯、役期和重复动员负担。
4. **军资—财政资产轴 `A`**：史料可识别的战马、牲畜、舟船、军械、粮秣、堡垒、府库等物质或财政资产投入、损失。

四轴独判，不另加距离、时长或胜负轴：

```text
base_WC = max(P, S, M, A)

若 P = S = base_WC 且 base_WC >= 1：
    WC = min(base_WC + 1, 7)
否则：
    WC = base_WC
```

只有P与S并列最高、且各有独立事实时，才在最高值上再升一档。不能从人员伤亡推造地区破坏；M和A不参与抬档。

敌我口径必须分开：

- 本方军民、受保护者的损失及军资征发，计入WC。
- 敌方战斗力下降用于判断SB，缴获用于判断WR，不能增加本方成本。
- 对敌方平民或投降者的侵害作为战争行为与人道负面事实保留，不算本国实付成本。
- 同一政权内战按各主体、各阶段记录，用`campaign_group`合并去重。

距离、道路、水运和气候只触发后勤核查，不单独计分。本土受战程度直接进入S轴，不再另设空间修正项。

### 2. 四轴互斥递进档位

#### 2.1 人员损害轴 `P0—P7`

先把同一评价主体承担的人员损害折算为“死亡当量”：

```text
P_equivalent = 可证死亡
             + 未归、失联、结局不明者 × 1/2
             + 被俘、被掳、流亡、明确受伤或伤残者 × 1/5
```

“未归”须是战后结局不明，不含暂时掉队或尚未记载归队。查明结局后替换1/2暂算；军民原数分存，同人只按最终可证的最重状态计一次。

| P档 | 死亡当量 | 人员负面程度 |
|---|---:|---|
| `P0` | 可判定没有人员损害 | 明确未交战、不战而降、纯部署，或材料足够详尽且可确认本方无人受害。 |
| `P1` | 1—99 | 小规模人员损害。 |
| `P2` | 100—999 | 百人级人员损害。 |
| `P3` | 1,000—9,999 | 千人级人员损害。 |
| `P4` | 10,000—99,999 | 万人至近十万人级人员损害。 |
| `P5` | 100,000—299,999 | 十万至近三十万人级人员损害。 |
| `P6` | 300,000—999,999 | 三十万至近百万人级人员损害。 |
| `P7` | ≥1,000,000 | 百万人级人员损害。 |

非零当量不足1记P1。仅疲惫饥寒而无伤亡或未归，记M；后来证实伤亡再记P。比例须有对应群体基数，混合损害按死亡、未归、伤俘和流亡拆算。

旧P估档依次保存：

1. `P_observed`：直接人数、比例和可靠下界。
2. 推定区间：依据受损群体、上下文兵员、同类编制/有数样本及战型环境，两端均有理由；敌兵、距离、时长或胜负单项不直接换数。
3. 中心与档位：分开死亡及1/2、1/5群体，取几何中值映射P1—P7；0端改最小非零当量，记`P_scoring=Px估`、取点依据及置信度。

估档参与旧WC及P/S升档，置信度不折档；新证据替换估计，不叠加。不得用模型常识或他战单个数字作参数；只有确认无接战伤害或详载无人受害才P0，失载不证明低损。

旧D的P尾部映射（仅供历史反查）：

```text
P_penalty(P) = 4×P + 4×max(P-4, 0)
P0—P7罚分 = [0, 4, 8, 12, 16, 24, 32, 40]
```

旧P5—P7须`P_observed`、`equivalent_range`、`center`、`P_scoring`、取点、来源、置信及映射一致；仅旧档记`FORMAL_GRADE_ONLY`，不据此发布现行军事结果。

单一后出文献巨数须死亡语义、共同体、父窗和去重明确才用`PREMODERN_SINGLE_GIANT_COUNT_MAGNITUDE_BAND`：报告数仅上锚，无独立枚举时下界最多半量级，中心取几何值、置信≤`MEDIUM`。小额不重叠直接死亡可列部分下限，不为精确合计而加巨数。

#### 2.2 地区—生产体系轴 `S0—S7`

地区—生产体系轴按实际失控和破坏范围定位：

| 系统档 | 典型事实 |
|---|---|
| `S0` | 未见本方统治区、生产、交通、财政或行政体系受到实际破坏。 |
| `S1` | 单一节点短时受扰，行政和生产连续。 |
| `S2` | 一般州县或一段边区局部破坏、阻运或短期失控。 |
| `S3` | 一个重要区域或若干州县持续争夺，但主要行政网络仍在运行。 |
| `S4` | 一个核心区域的生产、交通或行政体系受到大规模战争破坏；或一个完整边远行政—战略区域成片、持续失控。 |
| `S5` | 多个核心区域或首都圈广泛危机；或整个大型边疆的州郡、屯田、军镇和交通体系成片丧失。 |
| `S6` | 大型国家或相当人口地域尺度上的主要军政、财政和生产体系严重瘫痪，主力与首都控制同时发生系统性崩溃。 |
| `S7` | 大型国家或相当人口地域尺度上的行政、财政、生产和跨区交通体系全面瓦解。 |

核心区域须有对应人口、生产、税源、交通或军政功能，不能由地名、城数或宫门遇险直接判断体系损害。

旧S不填`UNKNOWN`：境外且未损本方功能记S0，境内按实际范围与持续性判断。高档证据不足只限制上界，不借名气、兵力或P档推定。

S证据固定分为三种状态：

- `DIRECT`：明载本方空间功能后果，按范围/持续定档。
- `INFERRED_BOUNDED`：受扰空间与反复争夺、道路军镇失效、长期复叛等症状共同成立；不要求现代术语。存`S_lower、S_upper、S_scoring、affected_area_refs、functional_symptoms、duration_basis、inference_basis、confidence`，取证据最支持档，不永取下限。
- `S0_CONFIRMED`：明确本方体系外或短点接触且功能连续，须肯定`S0_basis`，缺载/缺字段不代证。

烈度和兵数不能单独证明S；若同时有受扰空间、功能症状与持续证据，须审查有界推断，不能自动归0。

#### 2.3 动员—服役—运输轴 `M0—M5`

M计已发生国家/民间负担；表内人数指新增临时动员，常备军另看役期、兵种、运输、粮源、民夫与困乏。

| M档 | 典型边界 |
|---|---|
| `M0` | 未见新增动员、服役或运输负担。 |
| `M1` | 小规模、短期、局地行动；调发和补给有限。 |
| `M2` | 万人以上、不足十万人的短期动员，或较小兵力的较长服役、明确地方转输；尚未形成跨区持续重负。 |
| `M3` | 单一战略方向的十万级动员；或不足十万人但已有跨区水陆转运、较长驻屯、反复征发、大批民夫以及显著疲惫、怨苦、误农等事实。尚未形成全国性普遍征发。 |
| `M4` | 一次国家级大动员：全国征发、多个主要区域或多路大军共同承担兵役与跨区转输；数十万级实际投入可作为强证据，但短期集结人数本身不能单独定档。 |
| `M5` | 超常国家汲取：数十万以上实际征发，并叠加多年持续、反复补充、全国或多核心区域转输、长期驻屯、大型筑防、大规模军民移殖等至少一项强持续机制；或者多轮国家级动员在同一战争父链中反复发生，已明显超过一次全国大征发。 |

单次巨军无持续机制最高M4；兵数稍低但多年反复征发已超常汲取可M5。距离气候只触发核查，不凭路线抬M。

#### 2.4 军资—财政资产轴 `A0—A5`

旧A评净资产负担，先分：

- `gross_commitment`：已经投入或占用的资产总量；
- `reusable_input`：周期终点仍由本方控制、可继续使用的舟船、战马、军械、堡寨等资产；
- `consumed_asset`：已经实际消耗的粮秣、军资和财政支出；
- `lost_or_destroyed_asset`：战毁、遗弃、被夺或永久失去的资产。

组件合一个`A_scoring`，gross不直接复制成消耗/毁失。可复用资产只计占用、建运及机会成本；同规模永久毁失应更重。组件可UNKNOWN，但据已证投入损失有界定档，不按关键词充毁失。

| A档 | 典型边界 |
|---|---|
| `A0` | 未见可证资产投入或损失；未知不计分。 |
| `A1` | 少量军资、粮秣、畜力、船械、赏赐或局部设施投入、损失。 |
| `A2` | 一支部队或一处重要工程的可观资产投入、损失，已明显占用一个方向的军资。 |
| `A3` | 大批战马、舟师、军械、粮运或成体系军镇工程，显著造成战略方向上的消耗或重建负担。 |
| `A4` | 一个国家级府库、舰队、监牧、运输、防御或军械资产系统发生大规模投入、毁失；或多个战略方向的军资发生系统性消耗。 |
| `A5` | 多个国家级资产系统长期同时投入或毁失；或者单项形成超巨型实体网络及其持续供应，例如万里级防线兼道路、亭障、仓储和运输设施。须有具体资产、设施或财政支出事实，不能只由战争规模推定。 |

A只评可识别资产净负担，须区分可复用、正常消耗和永久毁失。人命归P，兵数、编制、役期与军民迁徙归M；土地控制归BCP/BCN，土地上的生产、交通、财政或行政损害归S。它们不自动再算A，也不能按出兵人数推口粮装备；A5仍须表中的具体资产系统或实体网络。另有财政、生产、漕运或行政危机，须以独立事实计S。

### 2.5 实际主体与双向事实

攻守双方分别记录各自的投入和损失，附上方向与史源；不能把胜方投入、败方损失、敌军死亡和第三方伤害混为一笔。同一主体的同一死亡不重复计数。

S5须有多个核心地区或首都圈持续受损，造成广泛功能危机。地点多、计划破坏、君主死亡或小国灭亡本身不够；小国的实际毁损通常按S4—S5审查，S6—S7仍须有相应人口、区域和生产破坏证据。胜方所得另记SB、BCP或WR。

### 3. WC统一禁则

只按P/S/M/A实际后果定档，远征、时长、胜败、名气或篇幅不另加分。伤亡失载按§2.1估计，不能从“战败”“退兵”直接补人数或给P0。M5/A5可支持WC5，但不代表体系瘫痪，二者相加也不升WC6；升档只按P/S公式。

## 三、安全收益与安全损失档位 `SB/SN`

SB记录本主体已经实现的安全改善，说明威胁、影响地区、持续情况和是否复发；自然变化和未来预测不计入。

| 档位 | 安全收益程度 | 典型边界 |
|---|---|---|
| `SB0` | 无改善或恶化 | 威胁未减、迅速恢复，或安全状态反而恶化。 |
| `SB1` | 一次缓解 | 解围或击退一次进攻，敌方再犯能力基本不变。 |
| `SB2` | 局部阶段改善 | 一个局部区域、门户或交通线暂时安全，主要威胁仍在。 |
| `SB3` | 重大削弱 | 主要对手的进攻能力遭到重大、持续削弱，但该威胁主体或其继承结构仍能继续构成高强度威胁。 |
| `SB4` | 一项主要威胁结构性终结 | 一个长期反复造成重大风险的威胁主体、割据体系或入侵结构不再具备同类再犯能力；或者一个主要战略方向长期转为低威胁。 |
| `SB5` | 整体安全秩序重塑 | 跨多个重要主体、区域或战略方向形成长期主导秩序，使国家由被动应对转为稳定支配安全格局。 |

SB看实际后效，不由诏令、胜负词、机构或外敌身份升档。SB4不要求灭国、纳地或羁縻，这些形式也不保证SB4；须证原威胁结构终结。SB4/5另核当时组织、控制、恢复能力与压力，远征困难不代威胁强度。

后来独立新威胁不抹去旧收益，只有原集团、继承结构或同一复叛机制恢复才构成反证。材料窗口不足留“待后续”，不以预测代结果；恢复原有安全与控制也算成果，具体见下节。

### 内部平乱、解围守成与收复失地

平乱、防御、收复按实际成果判断，不因没有扩张归零，成本另记。内部安全采用以下尺度：

- 短时兵变、局部袭扰或单一据点威胁解除，未形成持续区域威胁，记SB1。
- 普通地方/区域叛乱被平定、集团失去作战能力，通常SB2；跨重要州郡、长期或组织强大的叛乱持续受重创，仍有同源威胁，审SB3。
- SB4须长期、跨区、可再生的主要威胁结构被拆除，同时证明原强度与终局持久性。SB5须多个主要方向或全国威胁秩序重塑，普通一次平乱不足。

已载叛乱、出兵，合理后续时期无失控、再战或同源复发，可低置信推定本轮成功，至少按SB2审查；成功明载优先。沉默不能证明原威胁强大，也不因此直接改成0或UNKNOWN，后有反证修正同一过程。

同源复发须有首领、组织、据点、指挥或继承连续性，同类但独立的新乱不倒算前次失败。相同范围、组织与结果同判；短文按可辨事实审SB2/BCP1—3，不统一最低、不补规模，长文也不自动升档。

控制另按第四节空间尺度：未证叛军长期占完整州县、仅恢复正常军事行政通行，通常BCP1；收复按实际区域定档。发生现实进攻且守住控制时，`HOLD`可为BCP1—BCP4；只有部署或从未受挑战仍BCP0。

同一控制对象终点已恢复，记BCP，不同时保留阶段BCN；终点未恢复则保留BCN。阶段人员、生产、动员和资产损害仍记P/S/M/A。同一安全变化不同时记SB和SN，不同对象/阶段方向相反时分别留依据再评整体回报。

| 档位 | 安全损失程度 | 典型边界 |
|---|---|---|
| `SN0` | 无可确认恶化 | 威胁未增加，或仅有未实现风险。 |
| `SN1` | 一次局部受扰 | 单次失利、边地或交通线短时暴露，主要防御仍在。 |
| `SN2` | 局部方向退化 | 一处门户、局部区域或稳定交通线的安全明显变差，威胁尚未扩展。 |
| `SN3` | 主要威胁显著增强 | 对手获得持续进攻条件，或一条重要战略方向长期处于高风险。 |
| `SN4` | 重要安全结构失效 | 一个主要边疆、核心区域或反复威胁结构持续失守，国家须长期被动应对。 |
| `SN5` | 整体安全秩序崩解 | 多个战略方向同时失稳，国家原有安全格局被长期颠覆。 |

材料只足以确认短期战果、而不足以判断其后效时，安全轴写 `UNKNOWN`，并在 `carry_out` 标明需要后卷核验的事实。

## 四、边疆控制变化档位 `BCP/BCN`

BCP/BCN分别记录实际控制的取得、守住、恢复或丧失，按主体和阶段独立判定。面积、册封、短暂入城和战斗胜负不代控制结果，攻守双方不共享档位。

| 档位 | `BCP`正向控制变化 | `BCN`负向控制变化 |
|---|---|---|
| `0` | 无可确认的正向控制变化。 | 无可确认的负向控制变化。 |
| `1` | 取得、守住或恢复单一低价值节点、局部据点，或使受扰地区恢复正常军事—行政通行；对主要方向无实质改变。 | 丧失或暂弃单一低价值节点、局部据点，且主防线与主要方向未受实质影响。 |
| `2` | 实际守住、恢复或取得一处关键城塞、关隘、通道或有限区域，足以改善一个局部方向。 | 失去一处关键城塞、关隘、通道或有限区域，造成局部方向明显退缩，但主要边界体系仍可运行。 |
| `3` | 守住、恢复、形成或显著扩展一个重要战略区域、主通道或防线段的实际控制，明显改善可防御空间。 | 一个重要战略区域、主通道或防线段持续退控，主要方向的防御纵深或机动空间明显缩减。 |
| `4` | 一个主要战略方向或大型边疆区域被稳定守住、恢复或转入控制，显著改变全国边疆控制格局。 | 一个主要战略方向或大型边疆区域持续丧失控制，显著破坏全国边疆控制格局。 |
| `5` | 多个主要方向或国家级战略空间被长期恢复或重塑，形成历史级控制成果。 | 多个主要方向或国家级战略空间的控制体系崩解，形成历史级退控。 |

### 1. 判定与收束

1. 控制变化必须已在本主体、本阶段发生。名义授予、请降承诺、一次进驻或后来才取得的成果不算。
2. 同一对象先失后复或先得后弃，保留过程，只按阶段结束时的净结果记BCP或BCN。
3. 非零档须说明控制对象、实际归属、持续情况和来源。胜负、歼敌与缴获本身不等于控制变化；已知没有变化记0。
4. 尚未结束或无法判明归属和保持情况，`control_effect_status`及BCP/BCN记UNKNOWN，不按地名、兵力或声望补档。
5. 同一事件可以产生资源、安全和控制等不同后果，但须各有事实，不将四类档位相加。

### 2. 最小记录

记录控制状态、对象、变化方式、结果、持续情况、来源和BCP/BCN，对应`control_effect_status、control_objects、control_change_mode、control_outcome、continuity_status、source_refs、BCP、BCN`。变化方式用`GAIN、RECOVER、HOLD、LOSS、WITHDRAWAL、NONE、UNKNOWN`；持续状态用`HELD、LOST、REVERSED、UNRESOLVED`。实际守住或收复可以是正向成果，创业阶段也照实记录。

## 五、战争回报档位 `WR`

WR只看当期已经取得且可用的资源。供军、运输和财政使用都算实际使用，不必先用于赈民，但不能因此宣称直接民生收益。

| 档位 | 已实现回报 | 典型边界 |
|---|---|---|
| `WR0` | 无回报 | 无可见所得，所得旋即丧失，或只有名义称臣、空头许诺。 |
| `WR1` | 有限 | 少量可用军资、粮秣、牲畜、船械或财政物资，难以显著抵补本次成本。 |
| `WR2` | 实质 | 可观粮草、牲畜、装备、府库或其他可支配资产，能部分抵补战争和后续防务。 |
| `WR3` | 重大 | 大批军用资产或多类重要财政军事资源已经实际取得，足以明显改善一个主要方向的军事财政条件。 |
| `WR4` | 国家级 | 巨量且已进入本方支配的军资、牲畜、粮储、府库或可兑现财政资源，能显著增强国家能力，但尚未重构全国资源基础。 |
| `WR5` | 国家资源结构重塑 | 新取得并持续整合的税源、兵源、生产、交通和战略资源中的多个轴同时发生结构性跃升。相关空间控制必须另记BCP；WR只记录已经实现的资源流和国家能力增长。一次性缴获、人口数字或若干相邻节点不能单独达到WR5。 |

资源来源分`ENDOGENOUS_ASSET_FORMATION`（本方新建）、`EXTERNAL_ASSET_TRANSFER`（体系外转入）、`INTERNAL_REALLOCATION`（体系内调配）。本方新建时A记消耗损失，WR记新增产出，不把同一成品同时写成毁失和所得。

内部府库、土地、人口转手通常WR0，仅有独立新资源、实际可用且未重复时例外。人口本身不是资产，只计带来的实际军资、税源、兵源或能力，土地控制另记BCP/BCN。

承诺、使用前丧失/返还或不能支配部分不计，正常供军消耗不撤销已实现回报。同批资源只在取得阶段记一次，后续说明留存、使用和损失；单项缴获最高WR4，WR5须表中多个资源系统的结构性提升。

### 1. 物资失载时的简化推定

物资没有详细记载时，不能因灭国或歼军就给高WR，也不能直接给0。使用以下状态：

- `EXPLICIT_REALIZED`：明确记载本方取得、接收、支配或实际使用的资源；按已识别资源对象直接定档。
- `SIMPLIFIED_INFERRED`：资源清单或数量失载，但敌方资产基盘、资产转移方式及本方留存状态均能有界判断；按下述三因子给出粗区间。
- `CONFIRMED_NONE`：明确无所得，或资产被毁、随敌逃散、返还、无法支配、在使用前旋即丧失；必须保存肯定性依据。
- `UNKNOWN`：资产基盘、转移方式或留存状态至少一项无法有界判断。史料沉默本身只能进入`SIMPLIFIED_INFERRED`或`UNKNOWN`，不能进入`CONFIRMED_NONE`。

`SIMPLIFIED_INFERRED`只使用三个输入：

1. `asset_base_grade`：终局前对方实际供养的军队、骑畜、舟师、军械、营地、府库、财政和运输资产，可列`lower—upper`。人口、疆域、城数仅辅助证明基盘，不直接定WR；国体或军队规模既不自动封顶WR2，也不保证高档。
2. `transfer_mode`：只能从固定枚举选择：
   - `NONE_OR_DESTROYED`：没有转入本方或主要资产已毁，带宽`0—0`；
   - `ROUT_WITH_ASSETS_ESCAPED`：敌军溃逃且主要资产去向不明，带宽`0—1`；
   - `PARTIAL_FIELD_CAPTURE`：取得部分战场军资或局部资产，带宽`0—2`；
   - `CAMP_OR_MAJOR_FORCE_CAPTURE`：夺取主要营地、主力资产或接受一支重要军队，带宽`1—3`；
   - `COMPLETE_FORCE_OR_CENTRAL_TRANSFER`：完整军队、王庭、都城府库或政权中枢被本方接收，带宽`2—4`；
   - `STATE_RESOURCE_SYSTEM_INTEGRATION`：税源、兵源、生产、交通等多个国家资源系统已经转入并持续运行，带宽`3—5`。
3. `realization_retention`：只能为`RETAINED_USABLE、PARTIAL_OR_UNCERTAIN、LOST_RETURNED_UNUSABLE`。正常供军消耗仍属已实现；部分流失或私人侵占只降低下界，不能证明国家取得为0；明确毁失、返还或不可用才归零。

区间算法固定为：先取对应`transfer_mode`的带宽；`WR_upper=min(带宽上界, asset_base_upper)`；`WR_lower=min(max(带宽下界, asset_base_lower-2), WR_upper)`；若留存为`PARTIAL_OR_UNCERTAIN`，再将下界降低1但不低于0；若为`LOST_RETURNED_UNUSABLE`，上下界均为0。计分点固定取区间的下中位数`floor((WR_lower+WR_upper)/2)`，不得针对不同人物选择性取上沿或下沿。粗推定保留低于明载资源的置信度，不得反向冒充具体缴获事实。

明确记载只覆盖已识别的资源。若另估计未记载部分，须用`residual_resource_object_ref`和`excluded_explicit_resource_object_refs`区分对象、排除重复。内部调配不推定正WR；另有体系外新资源时，只按明载事实记录。

## 六、阶段回报档位 `phase_return_class`

`phase_return_class`是对本主体、本阶段的概括，须有行动、结果和史源依据。它不把各轴数字相加，不替代各轴，也不进入已退役的D净Q计算。

| 档位 | 含义 | 适用情形 |
|---|---|---|
| `HIGH_RETURN` | 高回报 | 本阶段形成显著、可确认的安全改善、资源取得或控制成果，且阶段成本没有压倒这些实际成果。 |
| `PROPORTIONATE_RETURN` | 相称回报 | 已实现的安全、资源或控制所得与本阶段成本大体相称；成果可能局部、短期，但已经发生。 |
| `LOW_RETURN` | 低回报 | 已实现收益有限、短暂或未稳住，明显低于本阶段可见成本，但尚未形成更强的终局负向状态。 |
| `NEGATIVE_RETURN` | 负回报 | 本阶段成本及实际安全恶化、退控或资源损失明显超过已经实现的正收益。 |
| `UNKNOWN` | 尚不可判定 | 原文或相邻卷窗口不足，无法确认本阶段成本、结果或后效；需在 `carry_out` 写明待核事实。 |

阶段有可见战果而后续是否保持尚未知时，不因一时胜负直接写 `HIGH_RETURN`；按已证成果写 `PROPORTIONATE_RETURN`、`LOW_RETURN` 或 `UNKNOWN`，并留下后卷核验点。后续阶段的成果或损失不得倒灌到本阶段。

## 七、各轴事实关系与去重

同一损益只记一次：敌方作战能力下降支持SB，可用缴获支持WR，本方实付损害支持WC，控制得失支持BCP/BCN。不同事实可来自同一对象，例如筑城支出记A，实际守住城防记BCP；但同一支出不计两项成本，同一控制变化不同时记正负。

账户之间不相加、不抵销：胜利、缴获和安全收益不降低WC，SB不算财政收入，局部胜利不自动消除SN，土地、臣服和人口不直接成为WR。主体、阶段及实际后果分别留证。

### 跨卷连续性

同一战争过程跨卷或跨年时，沿用`campaign_group`，本卷记录实际发生的阶段，并交代前后衔接：

- `carry_in`：本卷承接的前卷阶段、已知状态与来源卡；
- `carry_out`：本卷不能判明、必须由后卷核验的结果；
- `cross_volume_followups`：本卷复核发现的所有未闭合事项。

后卷可以补证此前行动的实际后效，但后来的新行动和新成果仍属于后来阶段。

## 八、裁决卡填写与校准例

每个主体阶段裁决卡写明：

- `P/S/M/A/WC`及每轴来源锚点；`P`为推定档时，填写观察值、区间、中心、依据、上限理由和置信度；
- `SB/SN`、`WR`、`BCP/BCN`及各自的实际对象、方向、持续或失效状态；
- `phase_return_class`及本阶段行动—结果—锚点链；
- 适用时的建国启动账；
- `carry_in`、`carry_out`与跨卷待核事项。

旧量纲案例与修改历史见Git；人物事实以原卡和正式裁决为准。
