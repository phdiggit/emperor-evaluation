# 战争成本、安全收益与战争回报档位

## 一、用途

本文是编年体史料通读中“战役裁决卡”的事实定档合同。网页端按“战役 × 实际战争主体 × 实际阶段”填写卡片；本地工具再据卡片的来源、阶段与连续性做后续汇总。

每场战争分开记四类互不替代的事实：

- **战争成本 `WC0—WC7`**：已经发生的人员、生产、动员、运输和军资财政代价。
- **安全收益／损失 `SB0—SB5` / `SN0—SN5`**：战争实际形成的安全改善或恶化。
- **战争回报 `WR0—WR5`**：当期已经取得并可使用的物资、军用资产与财政资源；土地和控制权只进`BCP/BCN`，不得在WR重复登记。
- **边疆控制变化 `BCP0—BCP5` / `BCN0—BCN5`**：本评价主体在本周期内实际取得或失去的边疆、战略区域、通道、防线与节点控制；`BCP`为正向变化，`BCN`为负向变化。

各轴不互相替代，证据层也不把档位序号直接相加；第三项D只在父周期完成去重与终局收束后，按其规则合同的统一公式组合父级轴。胜利不自动降低成本，失败也不能凭空推定伤亡。统一战争、政权创业战争仍照此记录事实；裁决卡另填“建国启动账”，说明本阶段对新政权形成、扩展或稳定统治基础的实际作用。

评价以国家和人民的安全、生命、生产与公共资源为中心，皇帝、储君和皇权本身没有额外倍率：其人员伤亡按P的一般人口径，宫门宫室的物质损失按A取证；只有国家行政、供应、交通、生产或军队体系实际受损、改善时，才进入S或SB高档。

裁决卡只写本主体在本阶段实际承担的成本、取得或失去的安全、资源与控制结果。专项税、普遍征调制度、停造减役、战后赈济复业等独立政策，作为非战役事实保留原文锚点。

### 事件准入边界

本账只接收已经形成对外战争、边防行动、内战、武装叛乱、军事政变或实际武装袭击的事件。下列材料可以保留为政治秩序、皇位继承或宫廷安全旁证，但不得仅因其“危及皇位”而进入 `WC/SB/WR`：

- 尚未发动即被告发的谋反计划、刺杀计划和宫廷阴谋；
- 单纯的储位争夺、废立、审讯、处刑、籍没和流徙；
- 未调动军队、未发生战斗、未争夺城池或军政节点的宫廷政变风险。

若事件已经杀官起兵、据城设防、调动军队、攻入宫禁、造成武装死伤或扩展为区域内战，则从实际武装阶段进入本账；此前的政治诱因仍单列，不把事后处刑人数伪装成战争人员损失。事件是否“严重”与是否属于战争账户是两个问题。

### 建国启动账

开国、复国、割据政权建立或新政权取得稳定统治基础过程中的战役，在每个适用的主体阶段卡填写：

```text
is_founding_process：true
founding_stage：REGIME_EMERGENCE／TERRITORIAL_EXPANSION／REGIME_CONSOLIDATION
startup_significance：本阶段实际取得、失去或未能取得的建国基础
```

`REGIME_EMERGENCE` 记录政权首次形成可持续军政中心，`TERRITORIAL_EXPANSION` 记录扩大可治理的核心地盘、资源或通道，`REGIME_CONSOLIDATION` 记录击退决定性竞争者、建立稳定治所或控制体系。只要原文不能支持建国进程，就填 `is_founding_process=false` 与 `NOT_APPLICABLE`。建国启动账保留同一阶段的成本和收益事实，不以“开国”标签替代 `P/S/M/A/WC`、`SB/SN`、`WR` 或 `BCP/BCN`。

## 二、战争成本档位 `WC`

### 1. 判档顺序

成本采用四轴独立判定：

1. **人员损害轴 `P`**：死亡、未归、被俘被掳、流亡和明确伤残。
2. **地区—生产体系轴 `S`**：战争对城市、农业、交通、税源、行政和军政控制的实际破坏。
3. **动员—服役—运输轴 `M`**：已经发生的征兵、民夫、转输、驻屯、役期和重复动员负担。
4. **军资—财政资产轴 `A`**：史料可识别的战马、牲畜、舟船、军械、粮秣、堡垒、府库等物质或财政资产投入、损失。

四轴先各自定档，不把距离、持续时间或胜败另设为第五个加分轴。基础档与最终档按下式计算：

```text
base_WC = max(P, S, M, A)

若 P = S = base_WC 且 base_WC >= 1：
    WC = min(base_WC + 1, 7)
否则：
    WC = base_WC
```

只有 `P`、`S` 同时位于基础最高档才抬一档。`M`、`A` 可以独立决定基础档，但无论彼此并列还是与主轴并列，均不触发抬档。例如：`P3/S1/M3/A3 → WC3`，`P3/S3/M1/A1 → WC4`，`P5/S5 → WC6`。P、S必须有独立事实支撑：不能只因死亡很多便反推生产体系必然崩溃，再把同一事实重复抬档。

一次造成百万人死亡，即使持续时间短，也高于多年无死亡、无生产破坏的驻防；反过来，核心区大规模内战即使死亡数字残缺，也不能因“未满万人”降成普通远征。

敌我口径必须分开：

- 己方军队死亡、己方或己方负有统治保护责任的民众死亡，以及本国承担的征发、运输和军资损失，进入 `WC`。
- 敌方战斗人员被斩杀、投降或主力瓦解，是威胁能力下降的证据，主要支持 `SB`；缴获其军资支持 `WR`，不得再反向抬高己方 `WC`。
- 对敌方平民的屠杀、掠夺、毁耕、强迁以及坑杀降众，属于被评价方造成的战争行为与人道负面，必须保留事实并进入相应的平民保护、战争行为或民生负面判断；但不得伪装成“本国已经支付的财政军事成本”。
- 内战双方均属同一政权人口和生产体系时，双方军民损失都应按各自实际阶段记录，并标记同一`campaign_group`，供后续去重，不能按每场战斗重复累计。

距离、道路、水运和气候只触发后勤核查，不单独计分。本土受战程度直接进入S轴，不再另设空间修正项。

### 2. 四轴互斥递进档位

#### 2.1 人员损害轴 `P0—P7`

先把同一评价主体承担的人员损害折算为“死亡当量”：

```text
P_equivalent = 可证死亡
             + 未归、失联、结局不明者 × 1/2
             + 被俘、被掳、流亡、明确受伤或伤残者 × 1/5
```

“未归”指战后没有返回、但死亡、被俘、逃散构成不明的人；不能把行军暂时掉队或本卷尚未写到归队者算作未归。后续若查明其死亡、被俘或流亡，应用新口径替换原来的 `1/2` 暂算，不得累加。军人和平民分别保留原数，折算只用于定档。同一人兼具受伤、被俘、流亡等多种状态时只按最严重且最终可证状态计算一次。

| P档 | 死亡当量 | 人员负面程度 |
|---|---:|---|
| `P0` | 可判定没有人员损害 | 明确未交战、不战而降、纯部署，或材料足够详尽且可确认本方无人受害。 |
| `P1` | 1—99 | 小规模人员损害。 |
| `P2` | 100—999 | 百人级人员损害。 |
| `P3` | 1,000—9,999 | 千人级人员损害。 |
| `P4` | 10,000—99,999 | 万人至近十万人级人员损害。 |
| `P5` | 100,000—299,999 | 十万至近三十万人级人员损害。 |
| `P6` | 300,000—999,999 | 三十万至近百万人级人员损害。 |
| `P7` | ≥1,000,000 | 百万人级人员损害。 |

非零折算值不足1时向上记`P1`；因此，若全部属于单一非死亡类别，约五百名被俘、被掳、流亡或明确受伤才达到 `P2`，约二百名未归达到 `P2`。死亡始终是最高权重。仅有疲惫、怨苦、饥寒、冻馁而没有明确受伤、死亡或未归结果，不进入P折算，转入 `M`；若后来形成明确伤亡，再据结果进入P。

比例必须有基数。“死十之六七”“过半不返”先确定损失率，再推定该群体规模；“万余人受害”须按可辨的死亡、未归、伤俘和流亡构成折算，不能全部按死亡计算。

史书未载完整人数时仍须给出可消费的P档，不得长期保留 `P?` 或以 `P1下限`代替估计：

1. 先记 `P_observed`：只包含史书直接支持的人数、比例、个体死亡和最低下限。
2. 再估计死亡当量区间。依次使用同一事件的受损群体、前后文兵力或人口、同朝同类编制、相近战型有数样本；同时结合接战范围、持续时间、胜败方式、围歼溃散、致死环境、补兵遗属及平民暴露。敌军兵数、距离、时长或“败”“破”等单项不能直接换算伤亡。
3. 区间下限和上限都须有理由，并区分死亡与按 `1/2`、`1/5`折算的人群。采用区间几何中值映射 `P1—P7`；若区间包含0，先以可证或推定的最小非零当量代替0。结果记为 `P_scoring=Px估`并写置信度。
4. `P_scoring`进入 `WC`，也可触发P/S同档抬升；置信度只说明估计可靠性，不降低档位。后续获得更强证据时重估并替换，不能叠加新旧估计。

推断必须同时写清：`推定人数区间`、`中心当量`、`P_scoring`、`推定依据`、`上限理由`和`置信度`。允许分析者作有约束的历史推断，但模型回答、常识印象和其他战争的单个数字不能直接作为参数。明确没有武装接触、不战而降，或叙事足够详尽且可确认本方无人受害，才记 `P0`；材料越简略，史书沉默越不能证明低损失。

第三项D组合P轴时使用唯一尾部映射：

```text
P_penalty(P) = 4×P + 4×max(P-4, 0)
P0—P7罚分 = [0, 4, 8, 12, 16, 24, 32, 40]
```

该映射不改变本节死亡当量档位，只改变D的组合惩罚：P0—P4沿用每档4分，保持既有低中档锚点；P5以上每升一档边际惩罚改为8分，以拉开十万级以上人员灾难的尾部，同时不另设“灾难覆没”加罚门，也不采用更激进的P6/P7超线性表。原因是当前历史池仍有部分P5以上记录只有旧正式档、没有完成死亡当量回源；在这些记录闭合前，不应让未审旧档获得更强的额外放大。

因此P5—P7进入正式D前，必须保存可审计的本方死亡当量证据：`P_observed`、`equivalent_range`、`center`、`P_scoring`、取点政策、来源引用和置信度，且区间到P档映射一致。只有档值、没有死亡当量或区间的旧记录固定标为`FORMAL_GRADE_ONLY`：允许进入内存影子敏感性，必须列入待审清单，但不得据此直接发布正式D、第三项汇总或排名。

前现代文献以单一后出编年或汇总性语句记载百万人级死亡大数时，不得把该数字伪装成现代精确统计。只有死亡动词、受害共同体、父周期窗口和与其他人数的去重关系均明确，才可使用`PREMODERN_SINGLE_GIANT_COUNT_MAGNITUDE_BAND`：报告数只作量级上锚；在没有独立枚举复核时，下界最多按其半量级保守开放，中心仍用几何中值，置信度不得高于`MEDIUM`。同一父周期另有语义不重叠的小规模直接死亡，可以记录为显式部分下限，但若不改变P档，不得为了制造精确总数机械加到巨量追述上。

#### 2.2 地区—生产体系轴 `S0—S7`

地区—生产体系轴按实际失控和破坏范围定位：

| 系统档 | 典型事实 |
|---|---|
| `S0` | 未见本方统治区、生产、交通、财政或行政体系受到实际破坏。 |
| `S1` | 单一节点短时受扰，行政和生产连续。 |
| `S2` | 一般州县或一段边区局部破坏、阻运或短期失控。 |
| `S3` | 一个重要区域或若干州县持续争夺，但主要行政网络仍在运行。 |
| `S4` | 一个核心区域的生产、交通或行政体系受到大规模战争破坏；或一个完整边远行政—战略区域成片、持续失控。 |
| `S5` | 多个核心区域或首都圈广泛危机；或整个大型边疆的州郡、屯田、军镇和交通体系成片丧失。 |
| `S6` | 大型国家或相当人口地域尺度上的主要军政、财政和生产体系严重瘫痪，主力与首都控制同时发生系统性崩溃。 |
| `S7` | 大型国家或相当人口地域尺度上的行政、财政、生产和跨区交通体系全面瓦解。 |

S轴只守三条：核心地位须由人口、生产、税源、交通或军政作用证明；城数和地名本身不计档；皇帝本人、行宫或宫门遇险不代表国家与人民体系受损，仍看中央行政、供应、生产、交通和军队体系是否实际失效。

S轴不得写`UNKNOWN`。每场已准入战争都有可定位的地点和本方统治空间：发生在本方统治区外且未破坏本方生产、交通、财政或行政体系时记`S0`；发生在本方统治区内时，按上表所列实际受扰范围和持续程度定档。史料没有记载更高破坏只能限制上档，不能使S失载，也不能凭战争名气、敌军规模或人员伤亡反推S。

S证据固定分为三种状态：

- `DIRECT`：史文明载焚掠、围城、破城、失地、阻运、停屯、逃散、行政失效、军镇或补给体系受损等本方空间后果；按可证范围与持续性直接定档。
- `INFERRED_BOUNDED`：史料未使用现代系统分类措辞，但已同时给出可定位的本方受扰空间，以及攻守州县、反复争夺、守将战死、道路或军镇失效、长期复叛、跨区重兵恢复控制等功能性症状。此时症状本身就是桥梁事实，不得再要求史书逐字写“生产、交通、财政或行政受损”；须保存`S_lower、S_upper、S_scoring、affected_area_refs、functional_symptoms、duration_basis、inference_basis、confidence`，并在区间内选择证据最支持的档，禁止永远取下限。
- `S0_CONFIRMED`：能够说明行动发生在本方体系之外，或本方仅有短时单点接触且行政、生产、交通和军政功能保持连续。必须保存肯定性的`S0_basis`；“未载损害”“缺少四字段”“没有精确伤亡”或单纯未检索到现代措辞，均不能单独构成`S0_basis`。

战争烈度、敌军规模、己方伤亡或动员规模单独存在时仍不能反推S；但它们与明确的本方受扰空间、功能性症状和持续性共同出现时，必须进入`INFERRED_BOUNDED`审查，不能被生成器短路为0。

#### 2.3 动员—服役—运输轴 `M0—M5`

M只计算已经发生的国家与民间负担，不把“出兵人数”直接当作等量民生损失。下表人数默认指新增临时动员；常备军短期出战仍须结合兵种、役期、水陆运输、民夫、粮源、重复动员和实际困乏判断。

| M档 | 典型边界 |
|---|---|
| `M0` | 未见新增动员、服役或运输负担。 |
| `M1` | 小规模、短期、局地行动；调发和补给有限。 |
| `M2` | 万人以上、不足十万人的短期动员，或较小兵力的较长服役、明确地方转输；尚未形成跨区持续重负。 |
| `M3` | 单一战略方向的十万级动员；或不足十万人但已有跨区水陆转运、较长驻屯、反复征发、大批民夫以及显著疲惫、怨苦、误农等事实。尚未形成全国性普遍征发。 |
| `M4` | 一次国家级大动员：全国征发、多个主要区域或多路大军共同承担兵役与跨区转输；数十万级实际投入可作为强证据，但短期集结人数本身不能单独定档。 |
| `M5` | 超常国家汲取：数十万以上实际征发，并叠加多年持续、反复补充、全国或多核心区域转输、长期驻屯、大型筑防、大规模军民移殖等至少一项强持续机制；或者多轮国家级动员在同一战争父链中反复发生，已明显超过一次全国大征发。 |

`M5`不是“大军=M5”。单次百万号称、一次性数十万集结或一场短期大会战，若缺少长期服役、反复补充、广域转输、筑防或移殖等已经发生的持续机制，仍至多为`M4`。反之，兵数略低于数十万但多年反复征发、驻屯和转输已经形成超常国家汲取，也可以进入`M5`。远征距离、越碛、气候恶劣只是核查条件；轻骑闪击、就地取给、以缴获续战可能成本很低。没有实际动员和后勤结果，不能凭路线遥远抬M。

#### 2.4 军资—财政资产轴 `A0—A5`

`A`进入第三项D净Q时表示本方已经承担的**净资产负担**，不是投入名义总额，也不是把可复用投入与永久毁失视为同一种代价。阶段卡和父周期必须先分别记录：

- `gross_commitment`：已经投入或占用的资产总量；
- `reusable_input`：周期终点仍由本方控制、可继续使用的舟船、战马、军械、堡寨等资产；
- `consumed_asset`：已经实际消耗的粮秣、军资和财政支出；
- `lost_or_destroyed_asset`：战毁、遗弃、被夺或永久失去的资产。

最终`A_scoring`根据上述组件形成一个净资产负担档，再进入Q一次。`gross_commitment`只负责约束投入规模，不能直接复制为`consumed_asset`或`lost_or_destroyed_asset`；可复用资产仍有占用、建造、运输和机会成本，但不得按永久毁失的全额代价裁定。正常消耗和永久毁失均为实际成本，后者在相同投入规模下必须体现更高的残余负担，不得与仍可复用的同规模投入机械同档。组件事实不足时允许组件为`UNKNOWN`，但须依据已证最低投入和损失给出有边界的`A_scoring`及置信度，不能用关键词把整个gross档复制为毁失档。

| A档 | 典型边界 |
|---|---|
| `A0` | 未见可证资产投入或损失；未知不计分。 |
| `A1` | 少量军资、粮秣、畜力、船械、赏赐或局部设施投入、损失。 |
| `A2` | 一支部队或一处重要工程的可观资产投入、损失，已明显占用一个方向的军资。 |
| `A3` | 大批战马、舟师、军械、粮运或成体系军镇工程，显著造成战略方向上的消耗或重建负担。 |
| `A4` | 一个国家级府库、舰队、监牧、运输、防御或军械资产系统发生大规模投入、毁失；或多个战略方向的军资发生系统性消耗。 |
| `A5` | 多个国家级资产系统长期同时投入或毁失；或者单项形成超巨型实体网络及其持续供应，例如万里级防线兼道路、亭障、仓储和运输设施。须有具体资产、设施或财政支出事实，不能只由战争规模推定。 |

人命不得并入军资折算；战马、牛羊、舟船和军械的数量只能在A轴比较。兵数、军队建制、服役年限和军民迁徙分别归M，土地控制变化归`BCP/BCN`，土地上的生产、交通、财政或行政体系实际受损才进S，二者都不能自动再算A；普通口粮装备也不能从出兵人数反推。`A5`尤其不能由“全国动员”“几十万军队”或“远征多年”推出，必须直接看到多个国家级资产系统，或超巨型实体网络及其持续供应。形成财政、生产、漕运或行政系统危机时，另以独立事实进入S轴。A档比较的是完成组件拆分后的净资产负担：同为大规模投入时，资产仍可复用、正常消耗与成体系永久毁失必须在判档理由中明确区分。

### 2.5 实际主体与双向事实

每张裁决卡必须先写明承担成本的实际战争主体。胜方出兵成本、败方国土人口损失、敌军死亡和第三方损害属于不同账面，不能揉成一个“战争总成本”。

- 同一战争出现攻守双方时，分别输出双方各自的 `P/S/M/A/WC` 主体阶段卡；不得只写胜方低成本而漏掉败方首都、州郡和人口体系损失。
- 双方视图不是把同一死亡重复写入同一主体的成本。每张卡的主体、方向与原文锚点必须可辨。
- 胜方攻取敌方五十城但本方无显著损失，可以是胜方 `WC1—WC3`；同一事实对败方若造成完整区域持续失控，可以是败方 `S4/WC4`。两者不矛盾。

多个核心地名被刺杀、纵火、短时袭击或未遂阴谋触及，不等于 `S5`。`S5`要求多个核心区域或首都圈实际发生大规模、持续性的战争破坏，并造成中央财政、漕运、生产或行政的广泛危机；被及时阻止的拟议焚城、屠城和破坏计划只记风险及止损，不按假想后果抬档。

政权尺度同样必须校准：小型割据政权灭亡、君主死亡、都城易手或行政名号消失，不自动进入 `S6—S7`。应按实际人口、区域、生产体系和强迁破坏判定，通常落在 `S4—S5`；胜方实际形成的安全改善、控制变化和资源取得分别由`SB、BCP、WR`说明。

### 3. WC统一禁则

1. 距离、持续时间、胜败、名气和篇幅不得轴外加档；只把已经发生的后果放入P/S/M/A。
2. 人命只进P，畜力和器械只进A；不得互相折算。
3. “败”“退兵”不能直接换算伤亡人数；人数失载须按2.1节形成推定区间和P档，明确无武装损害才记`P0`。
4. 推定P参与计算，证据不足只降低置信度；M5、A5只表示超常动员汲取或超巨型资产代价，不等同于国家体系已经瘫痪，体系危机仍须由S轴事实支持。
5. M、A可以独立把基础成本定到WC5，但没有抬档资格；`M5+A5`仍为`WC5`，不得升为WC6。只有P、S同时位于基础最高档才按公式抬档。

## 三、安全收益与安全损失档位 `SB/SN`

安全收益是**可归因于评价主体、已经形成的新安全状态所承载的未来避损价值**，不是外部局势自然变化或对未来的空泛预测。需记录威胁对象、受益区域、持续时间、是否复发及置信度。

| 档位 | 安全收益程度 | 典型边界 |
|---|---|---|
| `SB0` | 无改善或恶化 | 威胁未减、迅速恢复，或安全状态反而恶化。 |
| `SB1` | 一次缓解 | 解围或击退一次进攻，敌方再犯能力基本不变。 |
| `SB2` | 局部阶段改善 | 一个局部区域、门户或交通线暂时安全，主要威胁仍在。 |
| `SB3` | 重大削弱 | 主要对手的进攻能力遭到重大、持续削弱，但该威胁主体或其继承结构仍能继续构成高强度威胁。 |
| `SB4` | 一项主要威胁结构性终结 | 一个长期反复造成重大风险的威胁主体、割据体系或入侵结构不再具备同类再犯能力；或者一个主要战略方向长期转为低威胁。 |
| `SB5` | 整体安全秩序重塑 | 跨多个重要主体、区域或战略方向形成长期主导秩序，使国家由被动应对转为稳定支配安全格局。 |

判定只守五条：

1. 看实际后效，不看诏令、胜负词或机构名称；材料窗口不足则记`待后续`。
2. `SB4`既不要求灭国、纳地或羁縻，也不会因这些形式自动成立；只看原威胁结构是否真正终结。
3. 后来出现另一个独立威胁，不抹掉前一威胁已经解除的收益；只有原集团、继承结构或同一复叛机制恢复，才构成降档反证。
4. 内部平乱、解围守成与收复失地按下节单独赋轴；恢复既有安全和控制也是已经实现的军事收益，不得因没有扩张而清零，但普通一次平乱不能仅凭“不复发”升到`SB4`。
5. 同一安全事实只在实际形成它的主体阶段卡记录一次；WC、WR、BCP/BCN另账，互不冲销。

`SB4/5`另设威胁对象相对强度硬门禁。裁决必须把对手在本周期内的兵力、组织、控制范围、再生能力和对评价政权造成的战略压力，与评价政权当时的规模和承受能力相比较。对等或主要外部政权、长期入侵体系、足以与中央持续对抗的强军政割据，或者七国之乱这类全国级内部威胁，才可能进入`SB4/5`；普通地方叛乱、盗乱、短时兵变和一般区域武装，即使被彻底剿灭且后续不再记载，也通常只能形成`SB2`，有跨区强组织事实时才进入`SB3`。外敌身份本身不自动加档，但主要外部政权的独立资源、纵深和再战能力可以构成高档相对强度；远征距离、深入敌境和合围难度属于`P/S/M/A`成本证据，不得重复换算为`SB`。

### 内部平乱、解围守成与收复失地

内部平乱、击退入侵、解除围困、守住防线和收复失地都可能形成正向`SB/BCP`。第一层只判断实际威胁是否被削弱、实际控制是否被保住或恢复；本周期为恢复战前状态还是超出战前状态，只影响收益强度，不得把已经发生的安全和控制收益机械清零。成本仍按`P/S/M/A`完整记录，收益能否覆盖成本只在第三项D父周期的加权Q中判断。

内部平乱的安全轴按实际威胁强度和终局结果定档：

- `SB1`：局部武装袭扰、短时兵变或单一据点威胁被解除，原集团没有形成持续区域威胁。
- `SB2`：已经发生的普通地方或区域武装叛乱被平定，活动集团失去继续作战能力；这是有真实接战、调兵处置而没有更强结构性证据时的通常档。
- `SB3`：跨多个重要州郡、持续较久或已经形成强军政组织的重大叛乱、割据军或入侵力量受到持续性重大削弱，但同源威胁结构仍可能存在。
- `SB4`：长期、跨区、可再生的主要威胁结构被拆除，须同时证明威胁强度和终局持久性；“后来未再记载”只能支持持久性，不能单独证明强度。
- `SB5`：多个主要方向或全国性武装威胁秩序被长期重塑，不能由一次普通平乱取得。

结果判定采用统一编年沉默规则：史书已经记载武装叛乱和实际出兵处置，后续合理观察窗口没有记载继续失控、久攻不克、重大败绩、同源复发或另行再次发兵时，默认本轮处置成功，普通事件至少按`SB2`审查；若原文明确“平、定、尽歼、降、散”等，按明文确证。沉默推定的置信度低于明文，但不因此把轴改成0或`UNKNOWN`；一旦后卷出现反证，按同一结果链回写终局档。

“同类事件连续发生”不等于“同一威胁未被平定”。只有首领、组织、部众、据点、指挥链或明确继承关系连续，才能认定同源复叛；不同州郡的独立集团相继起事，且每批均有破、平、降、散或沉默推定终局时，应分别确认各批成功，再在共同父周期按全部受影响区域汇总`SB/BCP`。不得因父周期内出现多批同类叛乱，就把已经平定的前批倒改为未平或把多州恢复压成单点收益。

跨时代裁决使用同一影响尺度，不以叙事篇幅代替事实强度。早期材料仅以“某獠反、遣军讨之”简载时，只要已达到军事行动准入且沉默推定成立，仍按实际可辨的威胁和控制范围审查`SB2/BCP1—3`，不得惯例性敷衍为`SB2/BCP1`；但简载不能凭空证明万人规模、跨区组织或主要城州失复，证据不足只降低`confidence`并限制高档上界。后期实录、战报记载较详，也不得因人物、兵数和过程细节更多而抬档；只有威胁组织、受影响空间、控制对象或终点状态确实更强，才能得到更高`SB/BCP`。同等范围、组织和终局事实在不同时代必须得到同档。

控制轴与安全轴分别赋值：

- 叛军只造成焚掠、阻断或行政受扰，未证明长期占据完整州县，而平乱恢复正常军事—行政通行时，通常记`BCP1`。
- 收复一个关键城塞、关隘或有限区域记`BCP2`；恢复一个重要战略区域、多州郡或主要防线段记`BCP3`；恢复一个大型边疆或主要战略方向记`BCP4`；恢复多个主要方向或国家级战略空间才可到`BCP5`。
- 实际进攻已经发生而本方守住节点、防线或区域，`HOLD`按同一空间尺度记`BCP1—BCP4`；只有部署而没有实际争夺，或控制从未受到现实挑战时，仍为`BCP0`。
- 同一控制对象在父周期终点已经恢复时记正向BCP，不再同时保留该对象阶段性的BCN；战争期间已经造成的人员、地区生产、动员和资产损害由`P/S/M/A`保留。若终点仍未恢复，则按实际状态保留`BCN`。

同一平乱事实可以同时支持SB和BCP：前者回答正在发生的军事威胁是否被解除，后者回答实际控制是否被保住或恢复。两轴都必须如实赋值；相关收益如何组合由第三项D统一权重处理，不在证据层指定主轴或删除旁轴。

安全损失 `SN` 记录本阶段已经形成的反向安全结果。`SN` 与 `SB` 各自对应独立事实；同一安全变化不能同时写成正、负收益。阶段同时存在不同方向的改善和恶化时，分别说明对象与锚点，再由 `phase_return_class` 判断该阶段整体结果。

| 档位 | 安全损失程度 | 典型边界 |
|---|---|---|
| `SN0` | 无可确认恶化 | 威胁未增加，或仅有未实现风险。 |
| `SN1` | 一次局部受扰 | 单次失利、边地或交通线短时暴露，主要防御仍在。 |
| `SN2` | 局部方向退化 | 一处门户、局部区域或稳定交通线的安全明显变差，威胁尚未扩展。 |
| `SN3` | 主要威胁显著增强 | 对手获得持续进攻条件，或一条重要战略方向长期处于高风险。 |
| `SN4` | 重要安全结构失效 | 一个主要边疆、核心区域或反复威胁结构持续失守，国家须长期被动应对。 |
| `SN5` | 整体安全秩序崩解 | 多个战略方向同时失稳，国家原有安全格局被长期颠覆。 |

材料只足以确认短期战果、而不足以判断其后效时，安全轴写 `UNKNOWN`，并在 `carry_out` 标明需要后卷核验的事实。

## 四、边疆控制变化档位 `BCP/BCN`

`BCP`（Border Control Positive）与`BCN`（Border Control Negative）记录的是实际控制的取得、保持、恢复或丧失结果，不是疆域面积、名义册封、短暂入城或一场战斗的胜负。每张裁决卡均按“实际战争主体—实际阶段”分别判定；同一战争的攻守双方可以方向相反，不能共享一方的档位。

| 档位 | `BCP`正向控制变化 | `BCN`负向控制变化 |
|---|---|---|
| `0` | 无可确认的正向控制变化。 | 无可确认的负向控制变化。 |
| `1` | 取得、守住或恢复单一低价值节点、局部据点，或使受扰地区恢复正常军事—行政通行；对主要方向无实质改变。 | 丧失或暂弃单一低价值节点、局部据点，且主防线与主要方向未受实质影响。 |
| `2` | 实际守住、恢复或取得一处关键城塞、关隘、通道或有限区域，足以改善一个局部方向。 | 失去一处关键城塞、关隘、通道或有限区域，造成局部方向明显退缩，但主要边界体系仍可运行。 |
| `3` | 守住、恢复、形成或显著扩展一个重要战略区域、主通道或防线段的实际控制，明显改善可防御空间。 | 一个重要战略区域、主通道或防线段持续退控，主要方向的防御纵深或机动空间明显缩减。 |
| `4` | 一个主要战略方向或大型边疆区域被稳定守住、恢复或转入控制，显著改变全国边疆控制格局。 | 一个主要战略方向或大型边疆区域持续丧失控制，显著破坏全国边疆控制格局。 |
| `5` | 多个主要方向或国家级战略空间被长期恢复或重塑，形成历史级控制成果。 | 多个主要方向或国家级战略空间的控制体系崩解，形成历史级退控。 |

### 1. 判定与收束

1. 控制必须在本实际主体的本阶段内已经取得、守住、恢复或确认丧失；名义授予、请降、朝贡承诺、一次性进驻、后续阶段才取得的成果均不成立。
2. 同一城地或控制空间在一个实际阶段内先失后复、先得后弃时，只按该阶段终局的净控制结果记录；过程保留为证据，不得同时把同一变化计作`BCP`和`BCN`。
3. 战斗胜负、歼敌和缴获本身不构成控制变化；只有能够指出控制对象、实际归属、持续或失效状态及来源锚点时，才可定非零档。已知没有控制变化应记`BCP0/BCN0`，不得写成`UNKNOWN`。
4. 本周期尚未闭合、史料不能判明实际归属或后续保持情况时，`control_effect_status=UNKNOWN`，`BCP/BCN`保持`UNKNOWN`；不得以地名、兵力或名望补档。
5. 控制变化可以同时提供WR、SB/SN的事实线索，但四类字段不作序数相加；资源、威胁和控制须分别说明其独立结果，避免同一城地、同一损益重复制造收益。

### 2. 最小记录

主体—实际阶段裁决卡至少保存`control_effect_status、control_objects、control_change_mode、control_outcome、continuity_status、source_refs、BCP、BCN`。`control_change_mode`只可为`GAIN、RECOVER、HOLD、LOSS、WITHDRAWAL、NONE、UNKNOWN`；`continuity_status`说明`HELD、LOST、REVERSED、UNRESOLVED`。`RECOVER`和受到实际进攻后的`HOLD`均可形成正向BCP，不得因终点回到战前控制线而自动记0。统一与创业兼并链照实填写控制变化，并在建国启动账说明其建国阶段意义。

## 五、战争回报档位 `WR`

战争回报只记**已实现、可识别、可控制的所得**。战利品未赈济百姓，不计直接民生增益；但粮草、战马、牛羊、武器、船只和财政物资可成为下一次战争的启动资产，减少未来重新向民间征发的需要。

| 档位 | 已实现回报 | 典型边界 |
|---|---|---|
| `WR0` | 无回报 | 无可见所得，所得旋即丧失，或只有名义称臣、空头许诺。 |
| `WR1` | 有限 | 少量可用军资、粮秣、牲畜、船械或财政物资，难以显著抵补本次成本。 |
| `WR2` | 实质 | 可观粮草、牲畜、装备、府库或其他可支配资产，能部分抵补战争和后续防务。 |
| `WR3` | 重大 | 大批军用资产或多类重要财政军事资源已经实际取得，足以明显改善一个主要方向的军事财政条件。 |
| `WR4` | 国家级 | 巨量且已进入本方支配的军资、牲畜、粮储、府库或可兑现财政资源，能显著增强国家能力，但尚未重构全国资源基础。 |
| `WR5` | 国家资源结构重塑 | 新取得并持续整合的税源、兵源、生产、交通和战略资源中的多个轴同时发生结构性跃升。相关空间控制必须另记BCP；WR只记录已经实现的资源流和国家能力增长。一次性缴获、人口数字或若干相邻节点不能单独达到WR5。 |

WR必须先区分资源形成方式，再判断实现与留存：

- `ENDOGENOUS_ASSET_FORMATION`：本方投入工料、财政和劳动后新形成的舟船、军械、堡寨设备等可用军用资产。它不是所有权转移；只有已经形成且进入本方支配的产出才计WR，计划量、开工量和未完成工程不计。相同资产的投入端与产出端必须去重：A只计已经消耗、毁失或形成机会成本的投入，WR只计新增且可用的产出，不得把成品同时记为A损失和WR收益。
- `EXTERNAL_ASSET_TRANSFER`：缴获、交付、贡赋或其他从体系外进入本方支配的既有资产。其WR按实际所有权或支配权转移、可用性和留存判断；失载时才使用下文的敌方资产基盘与转移方式推定。
- `INTERNAL_REALLOCATION`：同一国家系统内府库、军资和人口在内战或平乱中的转手。通常不增加国家净资源，除非能够证明形成了不与成本重复的新资产，否则为WR0。

判定只守五条：

1. 人口不是战利资产；只记录随附军资、牲畜以及实际形成的税源、兵源和治理能力。
2. 名义称臣和未实际交付的许诺不算回报；已经取得并用于供军、运输、补充畜力或财政支出的资源属于已实现回报，后来正常消耗不撤销WR。取得后在使用前旋即丧失、返还或无法支配的部分不计。
3. 土地、城池、通道和行政控制只进BCP/BCN。内战中原属同一国家系统的府库、土地和人口在内部主体间转手，通常不构成国家净WR；只有能够指出从体系外转入或由本方投入新形成、已经进入评价主体支配、实际可用且没有在同一父周期内重复登记的具体资源，才按净取得量定档。
4. 单项缴获最高`WR4`；`WR5`必须使税源、兵源、生产、交通等多个国家资源轴发生结构性跃升。
5. 同一批资源只在实际取得它的主体阶段卡记录一次；后续阶段仅说明仍在控制、耗尽或丧失的事实。

### 1. 物资失载时的简化推定

史书不一定逐项记录击溃主力、夺取营地或覆灭政权后的粮草、牲畜、军械、舟船、府库和运输资产。此时既不得因“灭国、歼军”自动给高WR，也不得因缴获清单失载自动记WR0。WR证据状态固定为：

- `EXPLICIT_REALIZED`：明确记载本方取得、接收、支配或实际使用的资源；按已识别资源对象直接定档。
- `SIMPLIFIED_INFERRED`：资源清单或数量失载，但敌方资产基盘、资产转移方式及本方留存状态均能有界判断；按下述三因子给出粗区间。
- `CONFIRMED_NONE`：明确无所得，或资产被毁、随敌逃散、返还、无法支配、在使用前旋即丧失；必须保存肯定性依据。
- `UNKNOWN`：资产基盘、转移方式或留存状态至少一项无法有界判断。史料沉默本身只能进入`SIMPLIFIED_INFERRED`或`UNKNOWN`，不能进入`CONFIRMED_NONE`。

`SIMPLIFIED_INFERRED`只使用三个输入：

1. `asset_base_grade`：敌方在本周期终局前实际能够供养和维持的军队、骑畜、舟师、军械、营地、王庭府库、财政与运输体系的资产基盘，允许给`lower—upper`区间。人口、疆域和城数不能直接当WR，但可以和常备军、城防、营地、国家组织能力共同证明资产基盘。小国不自动封顶WR2，大国或数十万军也不自动给高档；看实际可供养的资产系统。
2. `transfer_mode`：只能从固定枚举选择：
   - `NONE_OR_DESTROYED`：没有转入本方或主要资产已毁，带宽`0—0`；
   - `ROUT_WITH_ASSETS_ESCAPED`：敌军溃逃且主要资产去向不明，带宽`0—1`；
   - `PARTIAL_FIELD_CAPTURE`：取得部分战场军资或局部资产，带宽`0—2`；
   - `CAMP_OR_MAJOR_FORCE_CAPTURE`：夺取主要营地、主力资产或接受一支重要军队，带宽`1—3`；
   - `COMPLETE_FORCE_OR_CENTRAL_TRANSFER`：完整军队、王庭、都城府库或政权中枢被本方接收，带宽`2—4`；
   - `STATE_RESOURCE_SYSTEM_INTEGRATION`：税源、兵源、生产、交通等多个国家资源系统已经转入并持续运行，带宽`3—5`。
3. `realization_retention`：只能为`RETAINED_USABLE、PARTIAL_OR_UNCERTAIN、LOST_RETURNED_UNUSABLE`。正常供军消耗仍属已实现；部分流失或私人侵占只降低下界，不能证明国家取得为0；明确毁失、返还或不可用才归零。

区间算法固定为：先取对应`transfer_mode`的带宽；`WR_upper=min(带宽上界, asset_base_upper)`；`WR_lower=min(max(带宽下界, asset_base_lower-2), WR_upper)`；若留存为`PARTIAL_OR_UNCERTAIN`，再将下界降低1但不低于0；若为`LOST_RETURNED_UNUSABLE`，上下界均为0。计分点固定取区间的下中位数`floor((WR_lower+WR_upper)/2)`，不得针对不同人物选择性取上沿或下沿。粗推定保留低于明载资源的置信度，不得反向冒充具体缴获事实。

显式资源只覆盖已经识别的具体对象。若显式事实只是部分下限，仍可对不重叠的残余资产池作简化推定，但必须保存`residual_resource_object_ref`并列出`excluded_explicit_resource_object_refs`，保证同一资源不被显式档与推定档重复消费。内部平乱、内战和兵变中原属同一国家系统的人口、土地、府库和军资转手，禁止使用简化推定生成正WR；只有能够指明从体系外新进入本国、实际可用的独立资源对象时才按显式事实登记。

## 六、阶段回报档位 `phase_return_class`

`phase_return_class` 是对一个主体在一个实际阶段的描述性事实判断。它综合本阶段已经发生的成本、安全、资源和控制结果，但不把 `WC`、`SB/SN`、`WR`、`BCP/BCN` 的数字相加，也不替代这些字段。它不得进入第三项D的父周期合并、净Q或组合档计算；每张裁决卡仍须写明支撑本档的行动、结果与原文锚点。

| 档位 | 含义 | 适用情形 |
|---|---|---|
| `HIGH_RETURN` | 高回报 | 本阶段形成显著、可确认的安全改善、资源取得或控制成果，且阶段成本没有压倒这些实际成果。 |
| `PROPORTIONATE_RETURN` | 相称回报 | 已实现的安全、资源或控制所得与本阶段成本大体相称；成果可能局部、短期，但已经发生。 |
| `LOW_RETURN` | 低回报 | 已实现收益有限、短暂或未稳住，明显低于本阶段可见成本，但尚未形成更强的终局负向状态。 |
| `NEGATIVE_RETURN` | 负回报 | 本阶段成本及实际安全恶化、退控或资源损失明显超过已经实现的正收益。 |
| `UNKNOWN` | 尚不可判定 | 原文或相邻卷窗口不足，无法确认本阶段成本、结果或后效；需在 `carry_out` 写明待核事实。 |

阶段有可见战果而后续是否保持尚未知时，不因一时胜负直接写 `HIGH_RETURN`；按已证成果写 `PROPORTIONATE_RETURN`、`LOW_RETURN` 或 `UNKNOWN`，并留下后卷核验点。后续阶段的成果或损失不得倒灌到本阶段。

## 七、各轴事实关系与去重

| 账户 | 回答的问题 | 不得替代 |
|---|---|---|
| `WC` | 这场战争已经付出了什么？ | 不因胜利、缴获或长期安全而降档。 |
| `SB` | 此后少承受了什么安全风险？ | 不当作已经入库的财政收入。 |
| `SN` | 此后增加了什么安全风险？ | 不因一次局部胜利自动消失。 |
| `WR` | 当期实际拿到了什么可用资源？ | 不把土地、控制、名义臣服或人口本身虚构成财富。 |
| `BCP/BCN` | 实际控制空间怎样改变？ | 不把战斗胜负或资源所得直接等同为控制变化。 |

同一损益只记录一次：敌军作战能力被摧毁主要支持 `SB`；缴获其马匹、粮草和府库支持 `WR`；己方死亡、转运和民众破坏支持 `WC`；实际取得或丧失的边疆控制空间支持`BCP/BCN`。同一对象可提供不同类别的事实依据，例如筑城支出进A、城防实际保持支持BCP，但不得把同一支出重复写成两项成本，也不得把同一控制变化同时写为正、负变化。

### 跨卷连续性

同一战略战争跨卷、跨年或拆成多个阶段卡时，沿用同一`campaign_group`。每卷只写本卷已发生的实际阶段，并用下列字段把尚未闭合的事实交给相邻卷复核：

- `carry_in`：本卷承接的前卷阶段、已知状态与来源卡；
- `carry_out`：本卷不能判明、必须由后卷核验的结果；
- `cross_volume_followups`：本卷复核发现的所有未闭合事项。

后卷出现撤军、议和、复叛、设治失效、威胁复发或控制保持时，按原文补足该后卷的实际阶段；不把后卷结果倒灌为前卷已经取得的成果。

## 八、裁决卡填写与校准例

每个主体阶段裁决卡写明：

- `P/S/M/A/WC`及每轴来源锚点；`P`为推定档时，填写观察值、区间、中心、依据、上限理由和置信度；
- `SB/SN`、`WR`、`BCP/BCN`及各自的实际对象、方向、持续或失效状态；
- `phase_return_class`及本阶段行动—结果—锚点链；
- 适用时的建国启动账；
- `carry_in`、`carry_out`与跨卷待核事项。

用于检验量纲的例子：

- 秦北击匈奴—河南地—长城防线链：人员数失载，裁决时须依据三十万军长期驻外、谪戍、驻屯及同类长期边役样本推定P，不得保留`P?`；M5、A5仍只按超常动员和万余里长城—道路—亭障网络确定，不能反推P或S。
- 贞观灭东突厥：`P1估/S0/M2/A0 → WC2；SB5 / WR4`。多路实际接战但过程迅速、未见唐军败退、围困、补兵或重大伤亡后效，推定为百人以下；不能因史书未记己方伤亡而定P0，也不能因出兵规模直接抬高P。东突厥牙帐和漠南主威胁体系瓦解，颉利被擒，十余部内附并形成十州、两都督府和“天可汗”主导秩序。
- 贞观征高句丽：`P3/S0/M3/A3 → WC3；SB3 / WR3`。唐方战死近二千，属于 `P3`；战争发生在境外，未见唐本土生产行政体系受战，属于 `S0`；二千余里远征本身不计分，十万级动员、土工与转运支持 `M3`，已载战马等重大损失支持 `A3`。P、S没有同档，不能抬为 `WC4`。唐军在驻跸山击溃十五万援军，全役斩四万余，并夺取大量马牛军械、十城及人口，使高句丽国家级野战与持续进攻能力受到重大削弱；但安市、平壤未下，辽州、岩州旋罢，高句丽仍能守城、侵新罗并抵抗后续唐军，尚非结构性解决，不能定 `SB4`。
- 贞观吐谷浑远征：`P3估/S0/M3/A0 → WC3；SB4 / WR3`。薛氏先锋随骑死十之六七，契苾何力以数百骑解围，结合成建制先锋与六道连续作战，推定唐方死亡当量为一千至三千；六道总兵力不能直接当作随骑基数，且无全军同率损失，故不上P4。六道远征和显著补给困乏支持M3；伏允时期威胁结构终结，二十余万牲畜形成重大军用回报。
- 汉文帝前166年匈奴入侵：`P3估/S3/M3/A2 → WC4`。十四万骑深入塞内月余，杀北地都尉并“虏人民畜产甚多”，受损主体覆盖边军和平民，中心当量应为千人级；但被掳只按`1/5`折算，现有材料不足以支持万级当量P4。P与S同为3，抬为WC4。
- 汉文帝前158年匈奴入侵：`P3估/S3/M2/A1 → WC4`。两路六万骑同时进入上郡、云中并“所杀略甚众”，跨两郡军民损害支持千人级中心当量；无大规模主力决战或万级死亡证据，不上P4。P与S同为3，抬为WC4。
- 东汉交趾六十五城叛乱：东汉方成本可定 `WC4`。不是因为“六十五”这个数字本身，而是九真、日南、合浦响应，连续城邑脱离控制，交趾刺史与诸太守仅能自守，证明完整边远行政—战略区域持续失效；这与普通远征的资源消耗不是同一强度。
- 七国之乱：`WC5 / SB4 / WR0`。核心地区大规模内战远重于普通远征；平乱结构性改变诸侯军事威胁，但既有国家系统内的府库、土地与人口转手不是新增资源。若另有可证的域外资源或新形成的净可用资产，才据具体对象另定WR。
- 八王之乱—永嘉战争群：`P6/S7/M4/A4 → WC7；SB0 / WR0`。长期全国性内战与人口生产、行政财政全面瓦解不能拆成若干普通战役稀释；P6须由同一战争群可去重的人员证据独立支持，不能从S7反推。

这些例子只固定量纲；实际裁决时仍须依据完整材料、事件边界和置信度复核。
