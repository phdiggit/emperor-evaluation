# 编年体史料通读工作流

## 输入

每卷只读以下内容：

```text
docs/原始史料/<史书>/卷NNN.md
```

原文开头的 `source_unit_id`、`source_url`、`revision_ref`、`raw_sha256`、段落数和首尾锚点一并写入总结。方括号中的 `SRC-...-Pxxxx` 是原文段落锚点。

## 怎么总结

从卷首读到卷尾，按时间顺序组织原文事实。

1. 先列出全卷连续时序导航。
2. 战争、围城、攻守、叛乱、受降、撤军、征兵、援军、边防和武装政变，按连续战事展开。保留原文明确的兵力、死伤、俘掳、征发、民夫、粮运、军资、城池、焚掠、迁徙、生产影响和控制权变化。
3. 赋役、钱粮、仓储、赈济、工程、灾害、人口迁徙和政治秩序，按原文事实记入对应章节。
4. 每个实质事件列出相关原文锚点；兵力、过程和结果分散在不同段时，把这些锚点一起列出。关键事实附同一锚点内的连续原文短引。
5. 只写本卷原文事实。跨卷未结束的事件写入“后卷边界”。

## 输出

每卷写一份：

```text
volume-NNN.source-summary.md
```

使用以下格式：

```markdown

- 后卷边界：……
```
