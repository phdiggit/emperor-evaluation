# 编年体史料通读工作流 V2

适用环境：ChatGPT 网页端项目。每次只处理一卷；先从首锚点线性读到末锚点，再交付本卷产物。

本工作流不再要求把战役事实压缩进通读总结。非战役事实照常总结；每个战役改写为可被本地确定性工具消费的“战役裁决卡”。

## 参考合同

- 《战争成本安全收益与战争回报档位》：确定 `P/S/M/A/WC`、`SB/SN`、`WR`、`BCP/BCN`、建国启动账、`UNKNOWN` 与阶段回报档位的口径。

## 输出一：非战役通读总结

文件名：`volume-NNN.source-summary.md`。

只总结不进入战役裁决卡的原文事实，按时序写入：财政民生、工程灾害、政治秩序、外交、人口与其他社会变化。每项附原文锚点和必要的连续短引。

```markdown
# 《<史书>》卷<卷号>非战役通读总结

- source_unit_id：……
- revision_ref：……
- raw_sha256：……
- 通读范围：<首锚点> 至 <末锚点>

## 一、财政、民生、工程与灾害

- ……；原文定位：`SRC-...-Pxxxx`“……”。

## 二、政治秩序、外交与人口变化

- ……；原文定位：`SRC-...-Pxxxx`“……”。

## 三、跨卷连续性

- 向前／向后：……
```

## 输出二：战役裁决卡

文件名：`volume-NNN.battle-adjudications.json`。

对本卷每个战役输出一张裁决卡。卡以“战役 × 评价主体 × 实际阶段”为单位；同一战役存在攻守双方或连续阶段时，分别输出多个 `subject_phase_cards`。

```json
{
  "schema_version": "chronicle-battle-adjudication-v2",
  "source_volume": "<史书>/卷NNN",
  "source_identity": {
    "source_unit_id": "...",
    "revision_ref": "...",
    "raw_sha256": "..."
  },
  "cards": [
    {
      "battle_label": "本卷原文所见战役名称或简要标识",
      "source_anchor_refs": ["SRC-...-Pxxxx"],
      "source_quotes": ["原文短引"],
      "subject_phase_cards": [
        {
          "evaluation_subject_phase": "政权／部队 × 实际阶段",
          "subject_role": "ATTACKER／DEFENDER／...",
          "actual_process": "本阶段实际行动与结果",
          "cost_axes": {
            "P": "P0—P7 或 Px估",
            "S": "S0—S7",
            "M": "M0—M5 或 UNKNOWN",
            "A": "A0—A5 或 UNKNOWN",
            "WC": "WC0—WC7"
          },
          "P_inference": {
            "range": "...",
            "center": 0,
            "basis": "...",
            "upper_bound_reason": "...",
            "confidence": "high／medium／low"
          },
          "strategic_security": "SB0—SB5／SN0—SN5／UNKNOWN",
          "material_return": "WR0—WR5／UNKNOWN",
          "border_control": {
            "BCP": "BCP0—BCP5 或 UNKNOWN",
            "BCN": "BCN0—BCN5 或 UNKNOWN",
            "control_effect_status": "..."
          },
          "phase_return_class": "HIGH_RETURN／PROPORTIONATE_RETURN／LOW_RETURN／NEGATIVE_RETURN／UNKNOWN",
          "founding_startup_ledger": {
            "is_founding_process": false,
            "founding_stage": "NOT_APPLICABLE",
            "startup_significance": "..."
          },
          "carry_in": "本卷承接的前卷阶段，或无",
          "carry_out": "需由后卷继续核验的事实，或无"
        }
      ],
      "non_battle_disposition": null
    }
  ],
  "review": {
    "raw_battle_anchor_inventory": [
      {"source_anchor_ref": "SRC-...-Pxxxx", "disposition": "ADJUDICATED／NOT_A_BATTLE"}
    ],
    "new_battle_candidates": [],
    "cross_volume_followups": []
  }
}
```

`P_inference` 仅在 `P` 为估计档时填写；直接见于原文的人数照实写入 `P`。开国、复国或新政权取得稳定统治基础过程中的战役，填写 `founding_startup_ledger`，并写明该阶段怎样启动、扩展或稳固建国进程；其余卡填 `NOT_APPLICABLE`。无法由本卷原文确认的轴写 `UNKNOWN`。

## 本卷复核

完成初稿后，再从首锚点线性复读到末锚点，并把复核结果写入同一 JSON 的顶层 `review`：

```json
{
  "raw_battle_anchor_inventory": [
    {"source_anchor_ref": "SRC-...-Pxxxx", "disposition": "ADJUDICATED／NOT_A_BATTLE"}
  ],
  "new_battle_candidates": [
    {"source_anchor_ref": "SRC-...-Pxxxx", "actual_fact": "..."}
  ],
  "cross_volume_followups": ["..."]
}
```

复核时从首锚点到末锚点建立 `raw_battle_anchor_inventory`，逐项确认每段武装行动均已生成裁决卡或标为 `NOT_A_BATTLE` 并说明原因。原文中尚未形成裁决卡的武装行动列入 `new_battle_candidates`，并保留原文锚点与实际事实。
