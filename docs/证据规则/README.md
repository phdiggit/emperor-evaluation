# 证据规则

## 本目录负责什么

本目录负责史料如何进入证据链、证据如何入分前裁量、负证如何触发、对象锚点如何校准，以及跨项目可复用的证据强度和裁判边界。

## 本目录不负责什么

本目录不保存 JSONL 字段事实、不承载 SQLite 生成库说明、不写 Markdown 展示格式，也不为单个复杂子项增开多份分项规则文档。

## 与相邻目录的边界

- 字段、配置、稳定 ID 和批次生命周期，进入 `数据结构与生成库/`。
- 子项专用计入边界、相邻项切分和专用触发点，进入 `分项规则/`。
- 人工阅读导出和 GitHub 协作，进入 `展示与协作/`。

## 职责重叠收束

本轮收束后的证据链主入口为“检索与回源”“裁量总则”“证据簇公式”“负证触发”四层；`评分因子赋值Skill治理.md` 只规定辅助规程启用门槛，不新增证据链层级：

1. `史料检索与回源工作流.md` 到原子证据卡为止，只处理线索、回源、上下文和 source passage 关系，不定档、不定分。
2. `证据裁量总则.md` 从原子证据卡开始，处理候选强度、五轴、对象锚点、证据组和人工裁判门槛，不替代分项标尺。
3. `证据簇计算公式.md` 从已回源对象材料开始，处理规则级证据簇的聚合公式，不直接生成最终档位或排名；I5B 另用规则承载对象影子层审计对象归属。
4. `负证触发式裁判通用规则.md` 只提供高风险负证的触发模块；单个子项的专用计入边界仍进入 `分项规则/`。

## 后续新增文件限制

新增文件必须是跨项目、跨分项可复用的证据规则。若内容只服务某一子项，应进入 `分项规则/` 且遵守“每个子项目最多一个分项规则文档”。
