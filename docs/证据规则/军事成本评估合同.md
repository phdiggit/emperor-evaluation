# 军事成本评估合同

第一项、第三项共用本合同，统一认定军事成本档位、档内位置和证据状态。**先划责任范围，再定档位，最后判断位置；扣多少分由各项自己的规则决定。**

## 1. 先确定哪些成本归本人

只计本人责任窗口内，已经发生的本方军事投入和损失。

| 计入 | 不计入或不能替代成本证据 |
|---|---|
| 军人死亡、伤残、被俘、失联，以及军队和指挥组织毁损 | 敌军、叛军、盟军、平民及无法拆分的军民混合损失 |
| 征兵、驻屯、调军、军用劳役、运输、灾后补充与重建 | 尚未执行的计划 |
| 军马、舰船、军械、军粮、工程的实际投入和损耗；已做准备即使未出征也计 | 失地、失都、亡国、财政恶化和生产破坏本身；民生事实只能辅助证明军用征发负担 |

第一项按本人实际参与的创业、复国、统一阶段划窗，不以称帝时间倒切；第三项按实际主政窗口。跨人物的同一战争，须拆清阶段、控制和授权责任，不复制整条战争成本，也不按成果分账比例机械分摊。共同责任拆不清时保留缺口。

**归责决定成本归谁，不改变损失严重度，也不直接升降档内位置。**胜负、恢复快慢和继承成熟军队，都不自动增减已经发生的成本。

## 2. 档位总览

按已经证明的最高结构定档；多个低档事件不自动相加成高档。

| 档位 | 判定标准 |
|---|---|
| C0 | 已核实没有实质军事投入或毁损。失载、被其他项排除都不等于C0。 |
| C1 | 局部、短期、常规投入，无显著军资或兵团毁损。 |
| C2 | 有限方向投入，或轻度且容易恢复的人员、军资、编组损害；没有长期高强度反复。 |
| C3 | 明显方向级投入或可见累计负担，但未形成显著兵团毁损、重大战争准备或国家级长期承载。 |
| C4 | 大规模或持续显著的区域、国家行动；有实质兵团毁损，或已执行显著战争准备、后勤工程。尚未达到C5。 |
| C5 | 主要野战力量、重要兵团或军事资产严重毁损；或长期反复高强度战争形成国家尺度负担。尚未达到C6。 |
| C6 | **极端人员损耗，或国家核心军事能力严重毁损。**满足任一路径即可。 |
| C7 | **C6灾难之后，发生反复灾难，或持续投入仍走向军事耗竭。**满足任一路径即可。 |

## 3. C6：两条路径，满足一条即可

### 人员路径：可靠损失下界达到十万人

同一行动或连续损耗链中，本方军人**死亡＋已证永久丧失服役能力的伤残**，去重后至少十万人，即可进入C6。十万是本合同的规范门槛，不是史学定律，也不自动决定高位。

本路径不要求全国停战或军制重建。大国仍能征兵、后来获胜，不抵销已经证明的人员损失。须交代受损军队规模、损失比例和全政权军力背景；全国军额不详可记缺口，但若对象或分母不明导致十万下界不成立，就不能确认本路径。

### 核心能力路径：核心功能实际中断或必须重大替代

不设死亡人数门槛，但须同时证明三件事：

1. **核心角色**：受损的是整个政权实际可调用的核心野战力量、不可替代军种或中枢军事指挥体系。用部署、功能、可替代性说明，不能只称“国家级远征军”。
2. **实际后果**：国家尺度持续作战能力中断、显著失能，或必须重大重建、替代才能恢复该核心功能。成建制被俘、永久失去调用权可以构成组织损失；一般换将、改隶或同一政权完整接收不等于能力消失。
3. **灾后核对**：说明剩余主力、后续行动、受限功能和替代过程。一支方面军惨败后由既有体系常规补员、轮换，并不足以证明本路径。

核心军种失能不要求其他军种全部停摆；军马、舰船等损失须按其核心作用和实际后果判断，不折成人数。两条路径证明同一损失时只认一个C6。

## 4. C7：反复灾难，或持续耗竭

两条路径都要求**先有独立C6灾难，再有实际重大补充和新的损耗**。不能在亡国时只认出一次C6，再把此前普通战争倒作灾后过程。

| 路径 | 必须证明的过程 |
|---|---|
| 反复灾难 | 首次C6 → 重大补建或替代并投入 → 再次独立C6 → 国家级持续非常补充、消耗或反复失能。 |
| 持续耗竭 | 首次C6 → 持续重大补充并投入 → 新的严重人员、军资或组织损耗 → 广泛军事功能仍无法维持或恢复。 |

**重大补充**须有实际征补、装备、运输、编组或跨区调集主要力量并投入作战的事实，超出常规轮换。不要求逐名追踪士卒或逐支对应新旧番号，单有再次出征命令不够。

**持续耗竭**还须满足：

- 首灾和后续负担共享战争承载或军力补给关系。新损耗不能重复计算首灾，也不能拿一般开支、计划、失地或敌损替代。
- 国家军事动员、补给、指挥、核心作战组织中，**至少两个相互关联的功能广泛失效**。须有补充受阻、军资耗失、主军反复瓦解、中枢无法有效调集等具体事实。
- 实际补充仍不能维持或恢复国家尺度持续作战。剩余部队、局部反攻不自动否定耗竭；替代力量已稳定承担核心任务、恢复常态，则是反证。

**耗竭路径不要求先恢复成功，也不要求后续每一阶段各达C6。**但单一战区长期受压、一次军种替代、一般财政困难或亡国本身，都不足以入档。

一次损失再大，先按C6的规模和位置判断；一轮终局不能拆成几次灾难。C7不要求亡国，两条路径也不重复计档。最高案例用于检验规则可达性，不按名望或档位人数配额定档。

## 5. 人数、累计与反证怎么处理

| 问题 | 统一口径 |
|---|---|
| 哪些算死亡？ | 战死及军事行动中的饥疫、溺死、冻死等实际死亡。同一人不按多种死因重复计。被俘后已证遭杀害者计死亡。 |
| 哪些不能直接折算？ | 普通受伤、被俘、失踪、溃散、逃亡、倒戈、被接收及暂时不能作战，不能直接当死亡或永久伤残。 |
| “伤亡”“死俘”“杀获”怎么办？ | 拆出已证死亡或永久伤残下界。动员数、未归差额、D项人员当量、旧P/F标签及任意系数都不能替代。 |
| 只有定性记载怎么办？ | 对象、规模和语义明确时，可判断量级下界，但不编造精确比例。十七万军“死亡殆尽”足以支持超过十万；十万军“死亡殆尽”则不能保证达到十万。“全军败没”须另分死亡、被俘和溃散。 |
| 区间与未知数怎么办？ | 用可靠下界，不取上界或几何中点跨门槛。“确切人数未知”和“准入下界未证”分别记录；失载不等于零，也不自动降低严重度。 |
| 哪些战事可以累计？ | 前次恢复未完成，或同属连续战争、共享主力、战区、后勤与再动员体系。已恢复常态且无持续承载关系的独立事件，只辅助档内比较，不按全任期拼档。 |
| 后来还能打仗说明什么？ | 是核心能力是否失能、是否持续耗竭的核查证据，不否定已证死亡。大量归队、获释或复役则可反驳原死亡、永久伤残估计。继续出兵也不能反推此前必有重建。 |

创业政权按当时整个军政共同体的军事机器判断核心角色，不因私人部众比例高就视为国家级灾难；十万人门槛不缩小。共同创业时，其他创业者控制的军队仍属比较分母，不得把本人一路军假定为全国全部主力；保留参照不等于重复归责。

## 6. 档内位置与证据状态

先满足档位，再比较人员与资产损失、军队重要性、动员后勤、持续时间、战区覆盖和重建负担。任期长、败战多或责任重，都不能单独抬位置。

| 位置 | 标准 |
|---|---|
| LOW | 刚达到本档，规模或累计强化有限。 |
| MID | 结构清楚，有一项明显强化。 |
| HIGH | 结构极强，多项同向强化，但未满足更高档门槛。 |
| HIGHEST（仅C7） | 已达到C7，实际损失、国家级持续补充消耗、军事失能广度与深度综合处于极端上沿。 |

C6人员损失刚过十万且无其他强化，一般从LOW比较；可靠损失达二十万级，是HIGH的强证据。十万至二十万之间不线性换位置，须结合比例、军队构成、同链军资与补充负担；核心路径按失能程度和替代难度比较。同档不表示死亡人数相等，两条路径可相互佐证，但不自动升C7。

| 状态 | 含义 |
|---|---|
| CONFIRMED | 关键结构已经证明。 |
| LOWER_BOUND | 至少达到本档，仍有覆盖或上限缺口；必须已有一条准入路径成立。 |
| PROVISIONAL | 窗口、角色、分母或归责仍有关键缺口。 |
| NOT_APPLICABLE | 不属于指定项目的消费范围，不是C0，也不代表其他项目已经结算。 |

## 7. 正式记录与跨项消费

高档裁决在既有依据中写清：**路径、损失下界与分母、核心角色及后果、灾后过程与反证、累计边界、位置理由、证据缺口和史源。**人员路径可注明核心后果非准入条件；C7按第4节写明所用过程。

人物裁决在所属项目正式记录中局部修改，保留逐链事实与史源引用。确认改判后同步JSON、同值阅读页和下游榜单，不保留旧裁决并列答案。合同修订、旧档位和旧F/M/A标签都不自动触发重裁；程序只做校验与确定性换算，不另建一套评分或固定人物答案。

| 消费范围 | 边界 |
|---|---|
| [第一项](../分项规则/第一项政权奠基与统一贡献及能力/00-规则与计分合同.md) | 创业、复国、统一及政权取得父链的成果与成本整链归第一项，退出第三项。第一项待裁不能用第三项的NOT_APPLICABLE代替，也不能把成本塞回第三项。 |
| [第三项](../分项规则/第三项军事与边疆净收益/README.md) | 本人主政窗口内的适用成本。C能力层消费的任务可退出D局部视图，但其军事成本仍进入第三项全局；第一项已消费成本不因C能力佐证而回流。全局恢复视图沿用现行配置。 |
| 第二、第四项 | 分别承接独立的民生、财政、社会和文明后果，另证窗口与实际结果；平民损害不转为军事损失，同一后果不跨项重复扣分。 |

各项的成本扣分尺度、生效条件、ML、E/EN和D档，由各项规则独立规定，本合同不改变换分公式。
