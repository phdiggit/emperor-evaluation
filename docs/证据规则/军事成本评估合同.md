# 军事成本评估合同

## 1. 范围与归责

本合同是第一项与第三项共用的军事成本认定合同，统一裁决 C0—C7、档内位置、证据状态、本人归责及阶段归并。相同主体、窗口和成本事实不因消费项目变化而改变成本档位；各项不得另设一套成本认定尺度。第一项的成本扣分映射及下限、第三项的固定扣分与军事净毁损ML、安全结果E/EN及D档均由各自合同规定，不属于本公共合同。

只评价本人可归责责任窗口内已经发生的本方军事投入和毁损：军事人员死亡、被俘和失联，兵团与指挥组织毁损，征兵、驻屯、调军、军用劳役，军马、舰船、军械、军粮、工程和运输损耗，以及灾后补充、重建和持续战争承载。第一项沿用本人实际参与的创业、复国、统一主链责任窗口，不能以称帝或成熟政权形成时间倒切；第三项沿用本人实际主政窗口。已经执行的造船、备马、筑塞、屯粮与转运，即使最终未出征也计入；未执行的计划不计。

敌军、叛军、平民和无法拆分的军民混合死亡不计入本方军事损害；财政恶化、生产破坏、失地、失都、亡国和安全恶化本身不能替代成本证据。民生后果只能在证明军用征发规模时辅助说明军事承载。

第一项消费的创业、复国、统一或政权取得父链，其成本照常按本合同裁决并归第一项消费，成果与成本整链退出第三项。第三项消费范围记 `NOT_APPLICABLE`，不得写成 C0，也不得将这一排除状态当作第一项成本裁决。第三项 C 能力层消费的任务可退出 D 局部视图，但属于第三项本人窗口内的实际军事成本仍进入第三项全局成本；第一项父链的成本不因第三项C能力佐证而恢复进入第三项。

归责决定成本属于哪个主体、哪个窗口，不改变已发生损害的物理或组织严重度，也不直接决定档内位置。交接与重叠主政阶段沿用正式窗口，同一阶段不得重复归入两个主体。

同一父链跨人物或跨项时，先明确阶段、实际控制及授权责任，再分别裁决各主体的成本；不得把整条父链成本复制给每个人，也不得按第一项A的成果分账比例机械分摊成本。共同责任无法拆清时保留证据缺口，不以全额重复归责代替裁决。作战失败或最终失去成果不自动证明高成本；战争胜利、快速完成或后来恢复也不抹除实际已发生的投入和毁损。

## 2. 档位

| 档位 | 必须闭合的成本结构 |
|---|---|
| C0 | 已核对的责任窗口及消费范围内没有实质可归责军事投入或毁损；不得由失载或其他项排除状态推定。 |
| C1 | 局部、短期、常规投入，无显著军资或兵团毁损。 |
| C2 | 有限方向投入，或轻度、容易恢复的人员、军资或编组损害，无长期高强度反复。 |
| C3 | 明显方向级投入，或有限行动形成可见累计承载；尚未形成显著兵团毁损、重大战争准备或国家级长期承载。 |
| C4 | 大规模或持续显著的区域、国家行动，具有实质意义的兵团毁损，或已执行的显著战争准备、后勤工程；仍未达到 C5。 |
| C5 | 主要野战力量或核心兵团重大但非灾难性毁损；或连续战争时期长期反复高强度投入形成国家尺度承载；或尚未恢复、共享军力与后勤重建链的相邻成本累计达到同等结构。国家核心军事组织和作战能力总体仍保持连续。 |
| C6 | 整个政权的核心军事力量发生极高耗损，主力、不可替代军种或中枢指挥体系伤筋动骨，导致国家尺度持续作战能力实际中断、显著失能，或必须进行重大重建、替代才能恢复。一路重要方面军的惨败、撤退和补员本身不满足本档。 |
| C7 | 已闭合C6的国家核心能力，经重大重建、替代后再次发生同级毁损，或多个不可替代核心系统反复终止，使政权主要军事机器接近崩坏。须证明国家尺度反复失能，不能由数支方面军先后失败、普通调兵或单次终局推定。 |

C6 的组织与核心能力是两条独立通道。军马、舰船或运输资产损失很多，仍须证明其国家核心角色、灾难程度与能力后果；一次亡国或一次体系终止本身不够 C7。强国能迅速恢复，不减免此前已经发生的核心连续性断裂；后来能出兵也不能反推此前必有断裂。

## 3. 聚合与比较

先切分窗口和去重，辨明受损对象及其军力角色，再核对绝对规模、相对损失、组织连续性与重建事实。最高已闭合单次或单链结构确定下限，累计只有真正达到更高档结构时才能抬档。

两个 C4 不自动成为 C5，两个 C5 不自动成为 C6，C6 加后续重大损失不自动成为 C7。同一事实被拆成几场战斗不能改变档位。

跨事件累计须有时间及恢复连续性：前次恢复尚未完成，或同属连续战争、共享主力、战区、后勤与再动员体系。相隔多年、已恢复常态且无持续承载关系的事件，按恢复重置处理，只能辅助档内比较，不能按全任期总和拼档。

本土重要区域的长期战争、灾后再动员与多方向承载可以强化成本，但不能代替高档核心门。小国数千人也可能是国家主力，大国数万人也可能只是一路军；同时比较绝对规模与相对重要性，不能仅凭人数或国力定档。

创业阶段尚未形成成熟国家时，以上“国家主力”“国家尺度”“核心系统”按本人所属创业政权或实际军政共同体的整体军事机器核对。少量私人部众的损失不能仅因相对比例高就推定为国家级灾难，仍须满足绝对规模、核心角色与组织后果的共同要求；继承成熟机器也不自动减免成本。

共同创业按实际军队和阶段分配成本，但严重度的比较分母仍为当时整个政权或军政共同体的军事机器。不得将其他共同创业者统率的主力从比较分母中删除，再把本人分到的一路军视为独立国家的全部核心；保留其他军队作能力参照，不等于重复扣除其成本。

C6、C7必须同时核对灾后实际军事进程。持续有效的主力组织、多线作战、重大进攻和快速统一，是核心能力是否曾经失能的反证；须以具体损失、能力限制及实际重建说明两者如何相容。后来恢复不抹除已证毁损，但“恢复快不减成本”不能替代对本档准入的证明。普通战役间的调兵、补员、追击与继续围城，不直接视为国家核心重建。

档内比较也不得绕过上述尺度。C6高位须比中位呈现更强的国家核心耗损及实际后果，不能仅以任期长、多方向出兵或相隔多年的败损清单抬高；绝对人数很大仍须核对本方分母，军民混合和盟军损失不得合算。既有裁决仅作横向核验，不能替代这些共同要求。

## 4. 位置、状态与正式记录

- `LOW`：刚闭合本档结构，规模或累计强化有限。
- `MID`：结构清楚，并有一项明显强化。
- `HIGH`：结构极强、多项同向强化，但仍缺更高档必要门。
- C7 另允许 `HIGHEST`，须以反复国家级军事断裂及其绝对规模闭合，不能凭人物名望。

位置比较人员与资产损失、动员与后勤规模、军力重要性、持续年限、战区覆盖和重建规模，责任强弱不作为位置加减器。

证据状态为 `CONFIRMED`（关键结构闭合）、`LOWER_BOUND`（至少达到本档）、`PROVISIONAL`（窗口、角色、分母或归责仍有关键缺口）及 `NOT_APPLICABLE`（不属于指定消费项目范围）。前两种不代表另一项目已完成成本结算；第一项待裁决不能用第三项的 `NOT_APPLICABLE` 代替。失载不等于零，也不自动降低严重度。

人物成本在所属项目正式结算记录中局部修订，保留逐链事实与史源引用；第三项全局恢复视图沿用现行配置。阅读依据必须与当前档位、位置和状态一致，不保留旧裁决作并列答案。程序只校验和确定性换算，不依据旧 F、M、A 标签数量自动重裁。
