# 军事对手战争机器O档合同

O1—O6是“主体—实际竞争窗口—对手战争机器”的关系档，不是国家、族群或名望的永久标签。

[机器合同](../../config/military/opponent-system-contract.json)唯一登记O档；各项只定义消费方式，不另造语义、顺序或映射。

## 一、六档共同边界

| O档 | 战争机器边界 |
|---|---|
| `O1` | 零散地方力量、残余据点或低于主要方向的短时武装。 |
| `O2` | 大型流动军、松散联盟或短期割据，可形成局部大会战，但缺乏稳定国家机器。 |
| `O3` | 具有统一指挥并能持续负责主要方向，但国家纵深、财政兵员或再生能力不完整。 |
| `O4` | 具有稳定区域、行政征补、财政兵员和持续独立作战能力，但相对评价主体仍有明显层级差或不足以争夺时代主导权。 |
| `O5` | 双方处于大体同一竞争层级，对手具有成熟中枢、跨区域主力和持续再动员能力，真实具备赢下主要战略竞争的机会。 |
| `O6` | 对手在实际竞争窗口明显占据战略优势，能持续逼迫评价主体的生存、核心根据地或主要战略目标发生重大现实危机。 |

O1—O4区分已兑现的机器成熟度，O5—O6还须同级竞争或持续压制在当前窗口成立；国号、疆域、兵数、潜力或本方弱小不代证。

O6的生存、核心根据地、主要战略目标为择一条件，不要求濒临亡国、最终灭国或压倒对方全国核心体系。

## 二、实际窗口门

1. 看实际交手阶段，不看对手历史巅峰或后来发展。
2. 母体国家达到高档，不表示偏师、孤军、边镇守军、复起残部或短期联盟自动继承同档；只按本窗口实际投入的统一指挥、投送、补给和再动员能力裁决。
3. 大国已经明显衰败时按实际能力降档；小政权不能仅因评价主体更弱而自动升为`O6`。
4. 多阶段只有在属于同一持续压力链、对同一主要战略对象形成连续作用时才合并；事件数量和多个低档对象不得机械相加升档。
5. 独立盟军、外援或借用军政机器改变竞争结构时，按产生当前结果阶段的实际双方结构定档；不得同时消费外援介入前的高压力和介入后的高效率。

窗口包括与任务直接相连的战前侦察、削弱、分化、联盟经营及择机过程，不以正式交战日截断。对手强度先按该过程中的组织、资源、持续投入与战略压力判断，再解释这些条件如何被改变；战事顺利、低损、速胜或对手最终崩溃不能反推其原先低档。本人有效准备造成的削弱须保留其能力归属，不把成功解题后的有利态势当作原题简单。对手在任务前已有衰败、分裂或实际投入受限的，须有独立事实，并区分本人行动、其他主体与外生条件；材料未逐项记载财政、后继兵或全国主力，不单独构成降档依据。

## 三、体系边界与去重

同机器主战、复起、追击及残余只建一个`opponent_system_ref`，阶段另记。独立征补和持续作战的区域体系可另建；宫廷集团、禅代或一次兵变不独立成体系，除非已形成区域中枢与财政征补。

统一链实例归公共登记`unification_campaign_portfolios[].opponent_systems`；其他正式实例归机器合同`supplemental_opponent_systems`。人物窗口、权重及分值留分项，不回写公共事实。

## 四、最小证据

最少保存`opponent_system_ref`、名称、`organization_grade`、依据、`source_campaign_refs`；依据说明窗口内指挥、根据地、财政兵员、投送补给、再动员和现实压力。个别项缺失不自动降档，抽象称号不代关键事实。

须证本人窗口确遇该体系及本阶段投入，不借用其他时期或母体档。

同一机器在不同主体或实际投入阶段的判断保存在该实例的`window_assessments`，不另建多个机器身份。每条窗口判断保存`subject_ruler_id`、`actual_competition_window`、`source_chain_refs`、`organization_grade`、具体依据及逐字`source_passages`；消费者必须匹配本人及实际任务后使用。实例原有总体登记不能替代窗口判断，窗口兵力也不得借用母体全部战争资源；同一机器的多个窗口仍只算一个对手体系。新增窗口史实不自动改写各项已结算的能力档与分值。

实例位于公共统一登记时，窗口补证可按同一`opponent_system_ref`保存在共同机器合同的`window_assessment_extensions`，不得在补充实例中复制一个同名机器。窗口记录只精化实际交手对象与投入，不把母体总体登记和局部方面军当作两个独立强敌重复出票。

## 五、分项消费边界

- 第一项消费O档计算创业或统一贡献窗口的对手压力；具体席位权重、相对资源合成和本项分值由第一项合同定义。
- 第三项C只把`O4—O6`作为高难度任务证据门，不从O档直接生成C分。
- 第三项AB只把O档作为高位守成和低位抗压的压力门；仍须分别通过非自致压力、本人归责、具名保全对象、同档交班和去重门。

O只证机器与压力，不单独证明胜利、成果、归责或成本收益。

## 六、变更门

改共同语义、顺序或实例须复核第一项压力、第三项C难度和AB承压门；只改分项权重/准入则改相应`consumer_contracts`与分项合同，不复制共同定义。
