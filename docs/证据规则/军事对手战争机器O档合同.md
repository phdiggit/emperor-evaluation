# 军事对手战争机器O档合同

本合同统一定义跨评分项复用的军事对手战争机器强度`O1—O6`。O档是“评价主体—实际竞争窗口—对手战争机器”的关系档，不属于第一项或第三项私有规则，也不是对国家、族群、军队或历史声望的永久标签。

机器唯一合同入口为[`config/military/opponent-system-contract.json`](../../config/military/opponent-system-contract.json)。第一项只定义如何把O档换算为创业对手压力；第三项只定义如何把O档用于军事体系高难度门和国防守成、抗压压力门。任何分项不得另写一套O档语义、顺序或阈值映射。

## 一、六档共同边界

| O档 | 战争机器边界 |
|---|---|
| `O1` | 零散地方力量、残余据点或低于主要方向的短时武装。 |
| `O2` | 大型流动军、松散联盟或短期割据，可形成局部大会战，但缺乏稳定国家机器。 |
| `O3` | 具有统一指挥并能持续负责主要方向，但国家纵深、财政兵员或再生能力不完整。 |
| `O4` | 具有稳定区域、行政征补、财政兵员和持续独立作战能力，但相对评价主体仍有明显层级差或不足以争夺时代主导权。 |
| `O5` | 双方处于大体同一竞争层级，对手具有成熟中枢、跨区域主力和持续再动员能力，真实具备赢下主要战略竞争的机会。 |
| `O6` | 对手在实际竞争窗口明显占据战略优势，能持续逼迫评价主体的生存、核心根据地或主要战略目标发生重大现实危机。 |

O档同时读取对手自身已经兑现的组织能力和相对评价主体形成的现实压力。`O1—O4`主要区分战争机器成熟度，`O5—O6`进一步要求同级竞争或持续压制已经在当前窗口成为事实；不能只凭国号、疆域、一次大军、潜在资源或评价主体较弱抬档。

## 二、实际窗口门

1. 看实际交手阶段，不看对手历史巅峰或后来发展。
2. 母体国家达到高档，不表示偏师、孤军、边镇守军、复起残部或短期联盟自动继承同档；只按本窗口实际投入的统一指挥、投送、补给和再动员能力裁决。
3. 大国已经明显衰败时按实际能力降档；小政权不能仅因评价主体更弱而自动升为`O6`。
4. 多阶段只有在属于同一持续压力链、对同一主要战略对象形成连续作用时才合并；事件数量和多个低档对象不得机械相加升档。
5. 独立盟军、外援或借用军政机器改变竞争结构时，按产生当前结果阶段的实际双方结构定档；不得同时消费外援介入前的高压力和介入后的高效率。

## 三、体系边界与去重

同一国家机器的主战、复起、追击和残余终局原则上只建立一个`opponent_system_ref`；阶段变化作为该体系的窗口事实，不重复制造多个对手。具备独立军政体系、能够脱离中央持续作战的外镇或区域集团，可以按实际层级独立建档。内部储位、禅代、宫廷反对集团和一次性兵变原则上不作为独立O体系；已经形成独立区域中枢、财政征补和持续战争能力者除外。

统一链对手实例由公共战役登记的`unification_campaign_portfolios[].opponent_systems`拥有；不属于统一链但被正式评分消费的补充实例由机器合同的`supplemental_opponent_systems`拥有。人物消费窗口、计分权重和分项结果仍保存在各分项输入中，不回写公共对手事实。

## 四、最小证据

每个对手体系至少保存稳定`opponent_system_ref`、对手名称、`organization_grade`、裁决依据和可回源`source_campaign_refs`。裁决依据必须说明实际窗口内的指挥统一度、区域或根据地、财政兵员、投送补给、失败后再动员能力，以及相对评价主体形成的现实压力；缺一项不必自动降档，但不得用抽象称号替代全部关键事实。

跨项消费时还必须证明当前人物窗口实际遇到该体系。仅能证明对手在其他时期达到某档，或只有母体国家档而不能证明本阶段投入，不得作为本窗口O档证据。

## 五、分项消费边界

- 第一项消费O档计算创业或统一贡献窗口的对手压力；具体席位权重、相对资源合成和本项分值由第一项合同定义。
- 第三项C只把`O4—O6`作为高难度任务证据门，不从O档直接生成C分。
- 第三项AB只把O档作为高位守成和低位抗压的压力门；仍须分别通过非自致压力、本人归责、具名保全对象、同档交班和去重门。

O档只证明对手战争机器和现实压力强度，不证明本方获胜、成果成熟、人物归责或成本收益。任何消费者都不得从O档单独推出高分。

## 六、变更门

修改六档语义、顺序或公共实例时，必须同时检查第一项对手压力、第三项C高难度门、第三项AB守成与抗压门。分项若只需调整自身权重或准入档，可修改机器合同中的对应`consumer_contracts`及该分项合同，但不得复制或改写六档定义。
