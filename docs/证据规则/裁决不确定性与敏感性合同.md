# 裁决不确定性与敏感性合同

## 1. 对象与边界

本合同处理统治绩效中现有证据允许的不同解释。分析只读正式输入，不改对象、权重、裁决真源、就绪状态、人物画像或历史影响；治理规模仍按各分项规则处理。

| 分析 | 改变什么 | 不能声称什么 |
|---|---|---|
| 权重敏感性 | 固定裁决，改变规范参数 | 不代表史料解释的不确定性 |
| 证据解释情景 | 固定规则，改变有证据支持且依赖完整的裁决 | 不代表概率、统计置信水平或连续误差界 |
| 未决缺口与条件候选 | 说明还缺哪些事实、满足条件后可能落在哪档 | 不等于已采信替代裁决 |

材料数量和置信度不乘分，不自动降档、封顶或生成区间；裁决分不是概率期望。`PROVISIONAL`、`LOWER_BOUND`和覆盖标签分别保留原义，不合成统一置信等级。

成本下界也不是总分下界：固定其他条件时，较低成本对应较高净分；收益、责任和其他成本尚未量化时，连综合分上界也不能据此确定。

## 2. 证据审查

每项争议核对对象、本人窗口、来源、实际结果、时空代表性、归责、反证及去重。宏观总评只支持原文明确的结果，不因简短排除，也不外推未记载的年份、地域和群体。

同源转述不增加独立史源；同源不同结果可互证维度，但不称来源独立。书名、条数、政策名目和名望不能代替高档条件。正反材料使用同一窗口与代表性要求，资料多不等于损害重，失载不等于无损害。

已确认的误读、越窗、错误归责、准入或重复计分问题，须修正正式裁决并同步下游，不能继续包装为合理分歧。

### 2.1 受约束推断与语义闭合

受约束推断以可定位的实际结果为基础，说明对象、阶段、代表性、推断路径及主要反证；不以材料沉默、治理意愿或政策名称补造结果。它可在分项允许范围内支持档位与交班，不要求逐年、逐地或临近交班的独立直接记录；分项规定的高档强锚、归责及去重门槛不因此放松。

语义闭合是现有材料与合同精度内已形成有依据、可解释且依赖完整的裁决，不等于唯一历史真值、无剩余疑问或高置信度。主态须有代表性理由，低谷须与主态分账，交班与恢复须满足对象可比、衔接及归责条件；这些判断均可使用合同允许的推断。一个采用解释成立并处理了有源竞争解释，或多个完整配对均成立且分歧边界清楚，均可闭合；后者按§3—4保留合法分歧。

只有足以改变裁决的关键事实或依赖未决，才阻断相应裁决或情景准入，例如对象/窗口错配、关键相反结果未处理、主态与低谷重复、共享交班矛盾、恢复增量或责任无有效依据。缺少精确比例、逐年记录、另一独立书证或任末直接实测本身属于正常证据限制，记录范围与置信度后不单独阻断。不得以“还可以补证”无限重开；也不得将已证实的错误降格为一般限制。

“未发现有源替代”可以关闭本次替代端点搜索，但不单独证明当前正式裁决成立；关键缺口可以明确保留并结束本轮核查，不把这种处置称为该裁决已语义闭合。有限档位条件计算、清单覆盖和结构校验均不代替以上判断。语义闭合与正式写回、发布及名次稳健性分别声明。

## 3. 解释的三种处置

| 状态 | 处理 |
|---|---|
| `SUPPORTED_INTERPRETATION` | 同一合同下有来源支持的完整替代解释；写清分歧、支持与限制、裁决及全部依赖 |
| `REJECTED_DIAGNOSTIC` | 违反证据或合同的假设，可演示影响但须说明排除理由，不进入允许范围 |
| `UNRESOLVED_EVIDENCE_GAP` | 对象、窗口、代表性或依赖未明，不填写猜测的已采信分数；有明确条件的候选按下节单列，发布就绪另按分项规则 |

没有找到替代解释、或仅有同值解释，不证明唯一历史真值或高置信度。

## 4. 情景计算

### 有限档位复核候选

逐人列当前档、具体待审档、支持条件、排除其他档的理由及交班/归责/去重依赖。不统一上下浮动一两档；跨度超过两档须专门解释，但不截断真实证据范围。

`grade_review`中的`CONDITIONAL_REVIEW_ONLY`不是`SUPPORTED_INTERPRETATION`，也不限定未来新史料。可按现行公式列固定其他明确输入后的条件分差，须声明固定条件，不生成候选名次，不将其他争议极值独立叠加。成本或基准档变化后重审候选。

### 现有史料审慎总分区间

每位`COMPOSITE_READY`对象从当前正式档出发，只纳入现有史料可定位且未被规则排除的异档条件，另记排除档及联动来源。条件端点不等于已采信裁决或未来史料的绝对界；没有有源异档时可列单点，只表示本轮语料未发现具体替代。

| 争议输入 | 权威来源及使用限制 |
|---|---|
| 军事成本 | `config/common/prudent-military-cost-grade-reviews.json`；绑定当前档、位置、状态、复核上端和触发事实 |
| 第三项D阶段结果低于HIGH标签 | `config/common/prudent-strategic-stage-grade-reviews.json`；核对父链、D档和史源。标签不自动改D，无完整有源替代D档不填分差 |
| 治理主态低于HIGH | `config/second-item/c1-c2-c3-low-confidence-terminal-adjudications.json`；用终裁端点，HIGH及HIGH_扩展标签不属此门。单点只用正式采用点，配对端点不能拆主档和L自由组合；分片采用点与终裁一致 |
| 共享交班、C4恢复及其他具名争议 | `config/common/prudent-governance-grade-scenarios.json`；按完整联合情景计算 |

总分按四项正式结果、合法端点及现行公式重算，普通成本与ML只取高一次。独立命题的极值可合成审慎外包区间，但须明说端点未必同时可达。这里的高置信度只指已登记史料经门槛、来源和联动核查，不是概率或不可突破的历史误差界。来源、规则、基准或依赖改变即须重审，程序覆盖不代替史源验收。

### 已成立的合法情景

只有证据和全部依赖均成立的替代裁决，才进入已成立情景的分数与名次范围；不能与待审候选混称。每景记录改变的原始字段、基准、依据、受影响对象及去重边界，分数和名次由公式生成，不手填目标值。

主态、低谷、端点、归责和成本须联动：改主态重审L是否重复，改起终点联动恢复、恶化及直接交班邻接，改军费联动普通成本、ML和第一/第三项分账。依赖未明时停止数值输出，不能默认相关字段不变。

局部情景固定其他人的正式裁决，也可联合改变相关人物，再按当前精度和竞争排名重排整个`COMPOSITE_READY`池。互斥解释不相加，共享史源、交班或同一损害不独立抽样，不据不完整依赖构造概率排名。

## 5. 输出与维护

### 保守排名排除检验

合同极限及名次外界只作内部诊断，不在公开页面显示为分数波动，也不由范围重叠生成邻位标签。公开显示当前正式分、名次、现有史料审慎区间；依赖完整的替代裁决才显示已成立情景名次。

没有完整情景，不等于所有人的分数都未定。以当前裁决为基准，只放宽已登记改分项、跨人依赖、成本下界/暂定限制，其余固定。C1—C3缺证推断仍守财政民生合同§4.3及高档要求，停止推断不自动降档或允许跳档。

内部可用合同绝对限额构造保守外包范围，但它不是史料支持端点、合法情景或概率，也不回写评分。普通成本和ML取高一次；下界成本不低于已证下界，暂定成本保守包含更低值。主态、端点、恢复、恶化和交班涉及的对象逐项列入，未知范围或新问题未映射即停止。

有逐档排除证据时可收窄外界，保存来源、当前基准及固定维度的独立依据。若争议仅在D3而D1已独立成立，可固定D1，将未排除D3代入交接公式和低侧封顶；基准改变或另有未联合审查的交接争议即停止。未排除不等于可达；若排除了当前采用档，先改正式裁决。

对人物i的总分外包范围[L_i,U_i]，竞争排名必在[1+数量(L_j>U_i), 1+数量(U_j>L_i)]以内，j不含本人，并列使用严格大于。范围须覆盖最终舍入分。两端均为现名次，只证明已登记范围、固定其余裁决条件下名次不变；两端不同表示仍需收窄，不证明不稳定。另以其他人基准分算本人局部范围，分清自身争议和竞争者影响。

外包范围可含无法联合成立的组合，只能令排除证明更保守，不能声称端点可达、生成合法情景或借此降分，更不能外推永久稳定。

### 分数与名次状态

分数证据是否完整、名次是否稳健分开说明：

- 本人全部合法情景均不改名次：声明“本人裁决变化不影响当前名次”，其他人仍固定。
- 全池完整合法联动均不改名次：声明“全池合法联动范围内名次稳定”。
- 合法情景确有名次变化：报告已证变化。
- 只查了部分情景或还有未量化缺口：稳健性未判定。

完整范围须由`coverage_closures`显式枚举全部有限合法情景，保存对象、情景ID、覆盖/依赖依据、来源和全池基准分。每景必须联合成立，不能拼互斥极值，也不能只用两个端点同名次推断中间。全池声明覆盖全部入榜对象，不静默固定未经审核的竞争者；程序只查引用、遗漏、缺口及基准漂移，不判史源语义。

JSON、Markdown和人物页共用公开状态与解释，列基准、替代解释、准入性质、公式分差、局部名次和未量化缺口。无完整范围声明不自动标分数已闭合，已列情景也不冒称全历史误差或全池稳健范围。

基准失配须报错；证据、合同或裁决变化后重审。只留当前有效解释与阅读视图，历史使用Git，不另存阶段状态镜像。
