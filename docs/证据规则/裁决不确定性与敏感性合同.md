# 裁决不确定性与敏感性合同

## 1. 对象与边界

本合同处理统治绩效中现存证据允许的不同解释，不改变评价对象、正式权重、正式裁决真源或人物画像、历史影响。治理规模按各分项原合同处理；史料数量和置信度标签不乘分，不据此自动降档、封顶或生成数值区间。规则下的裁决分不称为概率期望值。

权重敏感性、证据解释敏感性和未解决证据缺口分别表达。前者改变规范参数，后者固定规则并改变有证据支持的裁决；二者均不自动具有概率、置信水平或连续上下界的含义。

组件的证据下界不自动成为综合分下界：仅固定其他成果与公式时，更高成本只会降低或不改变净分；成本下界对应的是该成本维度上的条件性较高净分。收益、责任及其他成本也未量化时，不得据此声称已得到综合分上界。`PROVISIONAL`、`LOWER_BOUND`和来源覆盖标签原样保留各自含义，不合成为统一置信等级。

## 2. 证据审查

每个争议命题核对对象、本人窗口、来源谱系、实际结果、时空代表性、归责、反证与跨项消费。宏观总评可以证明其明确指向的结果，不因篇幅短一律排除，也不得把一句总评扩展为未记载的连续年份、全部地域或所有群体。

同源转述不增加独立史源数；同一史源中不同结果维度可以互证构念，但不据此宣称来源独立。不同书名、材料条数、政策名目和名望不能替代分项高档门。反面材料适用相同的窗口与代表性要求；资料丰富不等于损害更重，失载不等于没有损害。

确认原裁决违反准入、误读、越窗、错误归责或重复消费时，修正正式裁决并同步实际受影响下游，不能把已排除的错误继续包装为合理分歧。

## 3. 解释的三种处置

- `SUPPORTED_INTERPRETATION`：在同一现行合同下，有可定位证据支持的另一完整解释。必须说明与基准分歧的命题、支持与限制、对应裁决以及依赖闭合。
- `REJECTED_DIAGNOSTIC`：可以演示影响，但已违反证据或合同的假设；须说明排除原因，不进入证据允许范围。
- `UNRESOLVED_EVIDENCE_GAP`：关键对象、窗口、代表性或依赖尚不能闭合。不填写猜测的**已采信替代分数**；有具体门槛与依赖的条件档位可按下述审慎区间单独计价，并明确仍缺什么。正式发布就绪是否受影响另按对应分项合同判断。

没有找到合法替代解释，不等于已证明唯一历史真值。基准加单个同值解释形成的零跨度，也不称作高置信度。

## 4. 情景计算

### 有限档位复核候选

逐人列当前采用档及已登记争议的具体复核候选，不以“未知”代替档位分析。候选须说明为何仍需审、其余档为何不纳入及共享交班、归责、去重依赖；不得按全池统一上下浮动一档或两档。超过两档是要求专门解释的复核线，不是截断真实证据的硬上限。

`grade_review`中的`CONDITIONAL_REVIEW_ONLY`只表示当前命题的有限待审候选，不是已经满足全部准入的`SUPPORTED_INTERPRETATION`，不证明未来新史料只能落在这些档。可以列固定其他明确输入时的条件分差，但必须使用现行公式、声明固定条件、不生成候选名次、不与其他争议极值独立叠加。军事净毁损始终与普通成本取高；成本或当前档变化须重审原候选。

### 现有史料审慎总分区间

按用户选定的非统计口径，为每名`COMPOSITE_READY`对象列一条总分审慎区间。逐人从正式当前档出发，只纳入现有史料可具体定位、且未被合同门排除的上档或下档复核条件；另记已排除的更高档与联动来源。缺少最终准入证据仍可列**条件候选**，但不得把候选端点称作已采信裁决或未来新史料的绝对界。当前语料未留下具体有源异档者可以列单点，含义仅限本轮史料审查。

军事成本复核源为`config/common/prudent-military-cost-grade-reviews.json`；逐人绑定现行档、位置、证据状态、复核上端与触发事实。第三项D内部链阶段结果轴中的低于HIGH标签另由`config/common/prudent-strategic-stage-grade-reviews.json`逐阶段核对父链、当前D档与史源；阶段标签不自动改变D档，没有完整有源替代D档时不手填分差。治理主态中低于HIGH的记录以`config/second-item/c1-c2-c3-low-confidence-terminal-adjudications.json`的终裁端点为准；HIGH及HIGH_扩展标签不属此门。单点只消费正式采用点；区间列出合法端点及消费方式，声明配对或只取显式端点时不得拆分主档和L自由组合。分片正式采用点必须与终裁相同。共享交班、C4恢复及其他具名争议由`config/common/prudent-governance-grade-scenarios.json`按完整联合情景计算。总分由正式四项和合法端点按现行公式重算，不手填希望得到的总分。不同独立命题的极值合并形成审慎外包区间，端点可以不同时可达；需在输出中显式说明。普通成本与ML只取高一次。

这里的“高置信度”指现有已登记史料下经逐人门槛、来源和联动核查的审慎覆盖，**不是**已校准概率或全历史不可突破的误差界。来源、合同、正式裁决或依赖改变即失效并须重审；程序的174人覆盖及基准检查不代替史源语义验收。

未列有源异档的对象在上述现有史料审慎口径下采用正式当前档，不据此声称全历史零误差。原始证据缺口仍可保留事实描述；只有证据和全部依赖闭合的替代裁决才进入**已成立合法情景**的分数、排名范围，不能与审慎候选区间混称。

每个数值情景列出被改变的原始裁决字段、当前基准条件、依据、完整受影响对象及去重边界；分值必须由现行确定性公式计算，禁止直接填写希望得到的总分或名次。仅声明LOW/MEDIUM/HIGH、任意上下浮动一档或期望名次，不构成合法情景。

主态、低谷、端点、归责与成本并非独立旋钮。改变主态须重审原低谷是否已被消费；改变起终点须联动恢复、恶化和直接交班邻接；改变军事成本须联动普通成本、ML准入和第一项/第三项分账。未闭合的联动阻止数值输出，不默认其他字段不变。

局部情景固定其他人的正式裁决；允许同一情景联合改变多个相关对象，统一重排完整`COMPOSITE_READY`池，使用现行精度及竞争排名。互斥解释不能机械相加，共享史源、交班锚或同一损害不能独立抽样。未逐一闭合依赖，不构造全池概率排名。

## 5. 输出与维护

### 保守排名排除检验

合同极限及由其计算的名次外界只保留为内部诊断，不在总榜或人物阅读页显示为分数波动范围，也不据范围重叠生成“本人边界涉及邻位”等公开标签。公开列当前正式分、名次及上述现有史料审慎总分区间；只有依赖闭合的替代裁决才列**已成立情景名次**。审慎区间用具名档位候选及条件分差，明确未达正式采信门；既不默认全合同域均可能，也不统一套用上下浮动一档。

C1/C2/C3缺证推断继续遵守财政民生合同§4.3及各轴高档门：接班锚可以补缺，连续性传播和高档准入仍受原条件约束；停止推定不等于自动降档或允许任意跳档。本文不放宽分项评分规则。

没有完整史料情景时，不把所有人物标为分数未闭合。按当前正式裁决为基准，仅放宽已登记的未决改分项、明确的跨人依赖，以及正式成本的下界/暂定限制；未受这些问题影响的分项固定为当前裁决。固定不等于历史事实已被穷尽证明。

可以用现行合同的绝对限额构造覆盖上述变化的**保守外包范围**，作为排名排除证明，不称史料支持的上界/下界、不写回评分、不认作合法情景、不推断概率。普通军事成本与ML共同取高，最大扣减只用一次；下界成本不允许低于已证下界，暂定成本保守包含更低成本。主态、端点、恢复、恶化和共享交班消费者必须逐问题显式列入，不能静默固定相关人物。未知范围或新未决问题没有映射时停止生成。

回源能逐档排除结果时，可以收窄此外包范围，须保存逐档排除事实、来源、当前分项基准及未受影响维度的独立依据。交接性质仅涉及D3而D1依据独立成立时，固定已核D1，将未排除D3档位代入交接公式及低侧封顶；基准改变或另有未联合复核的交接争议时停止生成。未排除不等于已证可达，不以此替代完整合法情景；若排除了当前采用档位，应先修正正式裁决。

对人物i的总分外包范围[L_i,U_i]，竞争排名必在[1+数量(L_j>U_i), 1+数量(U_j>L_i)]以内，j不含本人，并列使用严格大于。上下界计算须包住最终舍入后的分数。两端均为现名次，则在已登记范围及固定其余裁决的条件下，名次得到证明；两端不同只能说明需进一步收窄，不能称已证明不稳定。另用其他人的基准分计算本人局部范围，区分自身争议和竞争者影响。

外包范围可以包含不能联合成立的组合，这只会使证明更保守；不得用这种组合生成可采信情景、宣称其端点可达或借此下调正式分数。内部记录证明范围，不能把“已登记争议不影响名次”扩张为所有未来史料下永久稳定。

分数闭合与名次稳健性分开输出。未决证据不自动表示名次不稳定：完整本人合法情景均不改变名次时，声明“本人裁决变化不影响当前名次”，仍固定其他人；全池竞争者的完整合法联动情景均不改变名次时，声明“全池合法联动范围内名次稳定”。存在合法情景改变名次可直接报告已证变化；仅有部分情景同名次，或有未量化缺口时，稳健性为未判定，不称稳定也不称不稳定。

完整范围采用`coverage_closures`中的显式有限情景枚举声明，保存覆盖对象、全部合法情景ID、覆盖依据、依赖依据、来源和全池基准总分。每个情景是一个联合成立的完整裁决，不把互斥或相关分项极值拼成不可能组合，不由两个端点同名次推出中间情景同名次。全池联动声明必须覆盖全部入榜对象，不静默固定未审核的竞争者。覆盖完整性是须回源的语义裁决，程序检查引用、遗漏、未决缺口和基准漂移，不能代替史源验收。

总榜JSON、Markdown及人物阅读页直接消费相同的公开状态和说明；没有完整范围声明者不得自动标为分数已闭合。标签只作说明，不改变正式分数、名次、就绪状态或引入置信度乘数。

输出基准、解释、准入性质、公式算得分差及局部情景名次，并显式列出没有量化的缺口。允许范围只涵盖已列出的合法情景，不称统计置信区间、全历史误差范围或全池稳健排名区间。

分析只读正式输入，不回写正式评分。相关证据、合同或裁决改变后须复核解释；基准条件失配必须报错，不能悄悄沿用。只保留当前仍有效的证据解释与生成阅读视图，历史过程使用Git，不另存阶段复审状态镜像。
