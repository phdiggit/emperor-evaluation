# 中国古代皇帝综合评价体系 V3.2（评分标准当前版）

> 本文档是当前有效评分标准，不记录历史修订过程。  
> 适用对象：中国古代皇帝横向比较；评价皇帝在其统治周期内对国家、社会、文明造成的净影响。

---

## 0. 总分、公式与口径

### 0.1 计分公式

最终得分：

> **正收益总分 − 历史负债**

正收益由前六大项构成。历史负债为第七项，只扣分，不加分。

### 0.2 正收益分值结构

| 大项 | 名称 | 分值 |
|---|---:|---:|
| 第一项 | 创业与政权取得能力 | 260 |
| 第二项 | 治国净收益 | 460 |
| 第三项 | 军事与边疆净收益 | 250 |
| 第四项 | 文明与国家整合收益 | 180 |
| 第五项 | 统治者政治素质 | 170 |
| 第六项 | 关键历史决策能力 | 180 |
| **正收益合计** |  | **1500** |
| 第七项 | 历史负债 | **0—300扣分** |

### 0.3 总分口径

当前六个正向大项合计为：

> 260 + 460 + 250 + 180 + 170 + 180 = 1500

本版按 **正收益总盘1500分** 执行；原 60 分缺口整体补入第六项《关键历史决策能力》，不新增第八项，也不设置“历史地位 / 综合影响 / 特殊伟业”等二次结算项目。

## 1. 总原则

### 1.1 务实评价与统一标准

只看实际行为、实际成果、实际代价，以及实际留下的制度、社会、边疆、文明后果。不得因名气、后世宣传、王朝滤镜、“千古一帝”或雄主光环补分。

执行 **同名替换检验**：遮去人物姓名后若会判低，不得因其统一功业、军功、制度创设或历史名气而判高。同一标准适用于所有皇帝。

### 1.2 结果、过程、制度、运行分离

一个成果只能主要结算一次。创业、制度、行政、民生、军事边疆、文明整合、个人素质、关键决策和历史负债必须按项目边界切分，不得互相回填。

制度创设不等于制度运行，行政执行不等于民生收益，国富/库富/账面富不等于民富，交接实际成功不自动等于制度韧性强。

### 1.3 净收益与负债分离

前六项评价正向净收益；第七项处理前六项未完全覆盖的跨期性、结构性、灾难性历史窟窿。前六项已吸收的普通代价，不在第七项机械重复扣分。

### 1.3.1 生产力增长与文明进步根本标准

制度、政策和治理成果的正负判断，最终以是否推动历史条件下的生产力增长与文明进步为根本标准。国家控制力、财政汲取力、行政穿透力、国库充盈或账面人口田亩增长，不自动等于正向制度收益。

正向制度应能降低社会成本、保护民间弹性、稳定法制秩序、扩大人才流动、改善反馈纠错、促进经济恢复与文明进步；负向制度包括主要通过抽血汲取、高压清查、告发连坐、身份固化、反馈堵塞、特务化控制、过度集权或制度错配来增强国家机器的安排。

执行时应特别区分：

- **国家能力增强** 与 **社会净收益增强**。前者只有服务于后者时才按正向计。
- **国富/库富/账面富** 与 **民富/生产力增长**。前者不能直接替代后者。
- **制度动作规模** 与 **制度净质量**。动作越大不自动越高，若主要压缩社会弹性，应转为负向或降温。

### 1.4 档位压缩与从严落点

优秀以上正式只保留三档：历史极限、历史顶级、优秀。历史极限是该小项天花板，不是“非常优秀”的同义词，原则上单项不超过1—3人。

| 等级 | 得分率 | 说明 |
|---|---:|---|
| 历史极限 | 96%—98% | 几乎不可超越的历史天花板，原则上极少数人。 |
| 历史顶级 | 90%—95% | 明确进入该小项历史第一梯队，但仍低于极限。 |
| 优秀 | 80%—89% | 高质量正收益，明显强于多数皇帝，但不进入历史第一梯队。 |
| 良好 | 70%—79% | 有稳定正收益，但未达到名君级表现。 |
| 合格 | 60%—69% | 基本完成该项职责，有功但不突出。 |
| 一般 | 50%—59% | 功过有限，或表现平庸。 |
| 较差 | 40%—49% | 明显低于合格线，存在较大短板。 |
| 很差 | 30%—39% | 严重失职或明显负收益。 |
| 极差 | 30%以下 | 接近灾难性表现，通常会连带历史负债。 |

档内可微调为高段、正常、低段，但“历史顶级上段”“优秀上段”不再作为正式档位。

### 1.5 量化、锚点池与证据卡

| 类型 | 适用条件 | 控分方式 |
|---|---|---|
| 精细量化项 | 已有可复核账本、公式、净值或系数 | 量化结果主导，标尺用于解释与审计 |
| 非精细量化项 | 主要依赖史实画像和横向比较 | 先建锚点池，先定档，再在档内定分 |
| 半量化项 | 有局部账本但仍需画像判断 | 量化部分控底，画像部分定档校验 |

非精细量化项和半量化项应先建立代表性锚点池，再分档、定标尺、定分。锚点池需覆盖高位、中位、低位和失败样本。

证据使用顺序固定为：

> **史料证据卡 → 人物标签/能力画像 → 正反两向检索 → 新史料修正标签 → 负证拦截/切分 → 定档/定分**

证据卡必须有明确史料或研究来源定位；定性判断不得伪装成证据卡。标签记录极性和强度：正/负/双刃/中性，强度1—4；强度只辅助裁判，不机械折算分数。

所有子项定档前，都必须进行轻量负证扫描：正面证据密集者必须查本项负证、时间线逆转和上限限制；负面证据密集者也必须查本项正证和例外。凡拟进入**优秀及以上**者，必须形成显式拦截记录。

规则和算法进入正式版本后，人工只审规则、算法、参数、锚点、数据质量约束、回归报告和影响报告，不审具体人物个案。人物级异常只能回到证据、规则或算法修复，不能通过人工最终档位、人工最终分数或单人 override 修正。

### 1.6 交班状态、后代发挥与长期影响归因分离

判断可持续性时，重点看皇帝离世或实际交班时留下的制度、社会与政权质量。王朝最终寿命、后代是否败家、很久以后发生的偶然变化不能直接算给前任；但可在不替代本项证据的前提下，作为反推交班结构强弱的旁证。

涉及长期影响的子项，统一执行“创设—继承验证—后世放大切分”原则：本人当期直接创设、定型或强力推行者为主分；后世长期继承、制度化、经典化、共同体化只能作为生命力验证；后世成熟、高峰、扩展和王朝整体光环不得回填给本人。


### 1.7 新版流程硬规则（当前有效）

1. 子项纯度校验：每个子项只计本子项直接相关证据；统一、开国、中兴、盛世、亡国等总标签只作检索提示，不得替代本项证据。
2. 同名替换检验：遮去人物姓名后若会判低，不得因人物名气、王朝滤镜、统一功业、军功或制度光环判高。
3. 高位硬证门槛：历史极限、历史顶级必须有本子项直接硬证；证据不足可空出高位或降为观察，不为填档硬塞人。
4. 负证拦截与归因切分：所有子项定档前均需扫描本项直接负证；拟进入优秀及以上者，必须完成“正向硬证、反向硬证、时间线逆转、相邻项切分”四栏拦截；长期影响项同时检查本人创设、后世继承验证和后世放大回填。
5. 缺证不悬空：查标签，正向封顶优秀中段，反向下探较差中段，无标签合格中档；标签不得替代硬证进入历史顶级以上。
6. 线索回源：现代文章、用户提示和研究综述只能作线索；能回到原典/准原典者可转硬证，不能回源者只作参考。

### 1.7.1 子项负证拦截表

负证拦截不是独立加分项，而是证据卡流程的定档前检查。其目的不是“为扣分而扣分”，而是防止强正证人物因单线材料越评越高。

| 栏目 | 必答问题 | 裁判作用 |
|---|---|---|
| 正向硬证 | 本子项直接正证是什么？ | 支撑入档，但不能用总标签替代。 |
| 反向硬证 | 本子项有没有直接负证？ | 发现强负证时必须压档、降温或重定锚点。 |
| 时间线逆转 | 早期建设是否被中晚期收缩、废止、反噬抵消？ | 防止只吃前期建设、不吃后期破坏。 |
| 相邻项切分 | 证据应归本项、转相邻项，还是第七项？ | 防止功劳/负债外包或重复结算。 |

执行门槛：

- 所有人物、所有子项：至少在裁判语中体现轻量负证扫描。
- 拟进入优秀及以上：必须有显式拦截记录。
- 拟进入历史顶级/历史极限：必须有本项正反两向硬证核验；未核验者只能列观察位。
- 定分后若发现本项强负证，必须回修证据卡、锚点池和正式评分记录。

## 3. 第一项：创业与政权取得能力（260）

### 3.1 核心问题

> 天下是怎么得到的？

评价皇帝取得政权的能力，包括战略设计、政治整合、军事夺取与创业难度。

### 3.2 总边界

本项只评价取得天下或取得最高权力过程中的表现。

计入：

- 起兵、夺权、统一、篡位、继承危机处理中的实际能力
- 创业集团组织
- 创业战争指挥
- 夺权战略路线
- 创业环境难度

不计入：

- 登基后的制度建设，归第二项A
- 登基后的行政治理，归第二项B
- 登基后的对外战争和边疆经营，归第三项
- 长期文明整合，归第四项
- 个人性格素质，归第五项

### 3.3 分项结构

| 项目 | 名称 | 分值 |
|---|---|---:|
| A | 战略决策能力 | 80 |
| B | 政治整合能力 | 60 |
| C | 军事夺取能力 | 100 |
| D | 创业难度 | 20 |
| **合计** |  | **260** |

> 注：原标准中有“战略路线设计80、政治整合60、战争组织与领导70、个人统兵实绩30、创业难度20”。现有标尺库实际将战争组织、战场统率、亲征勇武合并为C项100分。为保证标准与标尺一致，本版采用A80+B60+C100+D20结构。

### A 战略决策能力（80）

#### A1 战略方向判断（40）

评价：是否能判断天下大势，选择正确的夺权方向。

计入：

- 对主要敌我力量的判断
- 对政治合法性来源的判断
- 对主攻方向、根据地、盟友、时机的判断
- 是否能避开明显错误路线

不计入：

- 战略路线执行效果，归A2
- 具体战争指挥，归C项
- 登基后国家战略，归第六项或第三项

边界：

> A1问“路选得对不对”；A2问“路走得成不成”。

#### A2 战略落实能力（40）

评价：是否能把战略判断转化为稳定推进的夺权行动。

计入：

- 战略计划的阶段推进
- 根据局势变化调整路线
- 战略资源配置
- 战略目标与政治、军事行动之间的匹配度

不计入：

- 单场战役指挥，归C1
- 集团联盟驾驭，归B2
- 登基后制度落实，归第二项A/B

边界：

> A2不是单纯“会打仗”，而是夺权路线的整体执行能力。

### B 政治整合能力（60）

#### B1 联盟构建能力（30）

评价：创业阶段能否吸纳、组织、团结足够多的政治力量。

计入：

- 联合地方势力、豪强、旧贵族、新军功集团
- 吸引人才和军事集团
- 建立政治合法性叙事
- 争取关键支持者

不计入：

- 对已构建联盟的长期驾驭，归B2
- 登基后官僚体系建设，归第二项B
- 用人与授权的个人素质，归第五项B

边界：

> B1问“能不能把人聚起来”。

#### B2 联盟驾驭能力（30）

评价：创业阶段能否控制、协调、平衡已经形成的联盟和集团。

计入：

- 处理功臣、宗室、军头、地方集团关系
- 防止联盟瓦解
- 在夺权过程中维持共同目标
- 对关键人物的驾驭与制衡

不计入：

- 登基后清洗功臣或政治品格，归第五项D或第七项
- 正式官僚制度运行，归第二项B

边界：

> B2问“聚起来以后能不能驾驭”。

### C 军事夺取能力（100）

#### C0. 当前统一口径：基础账本 + 统帅指数 + 勇武分项 + 统筹复核

C项当前采用统一公式版，不再使用旧的“C2/C3派生画像凭综合判断”口径。

| 小项 | 名称 | 分值 | 当前控分方式 |
|---|---|---:|---|
| C1 | 战役贡献与指挥归属 | 50 | 精细量化项；按C1净重要性最高锚点线性映射。 |
| C2 | 前线统帅指挥指数 | 30 | 半量化项；只看计入指数1.00战役群的T4统帅指数，并扣1.00独立负向。 |
| C3 | 亲征风险与个人勇武 | 20 | 半量化项；亲征基础8分 + 个人勇武与战场威望V 12分。 |
| C4 | C项统筹复核 | 0 | 不给分，只查重复、错位和回流。 |

##### 当前统一公式

```txt
C1 = 50 × 本人C1净重要性 ÷ 当前最高C1净重要性
当前最高C1净重要性 = 铁木真66.23

T4正向 = 计入指数1.00正向战役群中，单项统帅强度最高的前4项之和
单项统帅强度 = 层级权重W × 成果保留系数M
T负向 = 计入指数1.00独立负向战役群之和
C2净统帅指数 = max(0, T4正向 - T负向)
C2 = 30 × 本人C2净统帅指数 ÷ 当前最高C2净统帅指数
当前最高C2净统帅指数 = 铁木真36.4

C3 = 8 × T4正向 ÷ 当前最高T4正向 + V
当前最高T4正向 = 铁木真36.4
V = 个人勇武与战场威望分，0—12
```

说明：精细量化项的最高锚点满额属于量化归一化满额，不等于定性意义上的“绝对完美”。C项内部若出现新人物超过当前最高锚点，应同步重算归一化基准。

#### C1. 战役贡献与指挥归属（50）

##### 评价问题

本人在取得天下或取得最高权力过程中，亲征、坐镇主战区或亲临战区指挥过哪些真正重要的主链战役？这些战役对开国、统一、灭国、政权创建、旧帝国崩解有多大意义？

##### 计入

- 创业阶段本人亲征、主导、坐镇主战区或高度直接控制的战役群；
- 直接服务于取得天下、取得最高权力或完成政权创建的主链战役；
- 战役群层级、本人计入指数、成果保留系数、独立负向与C1锚点系数；
- 与本人军事归属明确相关的正向或负向战役群。

##### 不计入

- 普通后方授权、名义统帅、普通遣将；
- 名将独立完成而本人无高度直接控制的战果；
- 登基后边疆经营、防御扩张或常备军事体系建设；
- 单纯个人勇武，归C3；
- 取得权力后的国家安全收益，归第三项。

##### 执行公式

```txt
C1正向重要性 = 层级权重W × 计入指数I × 成果保留系数M × C1锚点系数A
C1负向重要性 = 层级权重W × 计入指数I × 负面指数N × C1锚点系数A
C1净重要性 = Σ正向重要性 - Σ负向重要性
C1 = 50 × 本人C1净重要性 ÷ 66.23
```

层级权重：`S+ = 12，S = 10，S- = 8，A = 5，B = 3，C = 1`。

计入指数：`1.00 / 0.75 / 0.50 / 0.00`。

C1锚点系数：`1.50 / 1.00 / 0.90 / 0.80 / 0.65 / 0.50`。

C1是精细量化项，分数由净重要性线性映射控制；档位只用于解释梯队和审计异常，不得用固定档位区间压缩C1净重要性的真实差距。

#### C2. 前线统帅指挥指数（30）

##### 评价问题

本人在创业战争中作为前线核心统帅，直接统率部队、稳定军心、临场调整、逆境组织和控制战场的能力如何？

##### 计入

- C1中计入指数为`1.00`的正向战役群；
- 本人亲征主导、前线核心统帅、当面控制战局的战役群；
- 体现统军、临场、军心、逆境组织能力的高强度战役群；
- 计入指数为`1.00`的独立负向战役群，用于扣除亲征主导失败。

##### 不计入

- `0.75`、`0.50`样本，因为它们不是完整前线核心统帅样本；
- C1锚点系数，因为C2评价统帅能力，不评价政权/统一层级；
- 纯粹个人冲锋勇武，归C3；
- 普通名将代打、后方授权、名义统帅。

##### 执行公式

```txt
T4正向 = 计入指数1.00正向战役群中，W × M最高的前4项之和
T负向 = 计入指数1.00独立负向战役群的W × N之和
C2净统帅指数 = max(0, T4正向 - T负向)
C2 = 30 × C2净统帅指数 ÷ 36.4
```

取最高4项，是为了同时避免“单一高光战役顶满”和“材料细碎者刷分”。单一极高光战役可以抬高C2，但不能自动等同于多条高层级主链持续亲征样本。

#### C3. 亲征风险与个人勇武（20）

##### 评价问题

创业阶段本人是否亲自统兵、亲临前线、承担直接战场风险，并具备可确认的个人勇武、战场威望或士气带动能力？

##### 计入

- 亲自统兵、亲临关键战场、承担战场风险；
- 个人冲阵、突围、近战、受伤、临阵鼓舞、敢死突击等可确认事迹；
- 直接构成夺权资本的前期军功、战场威名和个人勇武形象；
- 从C1中`1.00`正向样本派生出的亲征风险基础。

##### 不计入

- 幕后战略规划，归A项或C1；
- 前线统帅组织能力，归C2；
- 名将代打战果；
- 后世演义、神化传说或不可确认的勇武形象。

##### 执行公式

```txt
C3 = 亲征风险基础分 + 个人勇武与战场威望分V
亲征风险基础分 = 8 × T4正向 ÷ 36.4
V = 0—12
```

V值参考：

| V区间 | 判定 |
|---:|---|
| 0—2 | 基本只有统帅亲临，缺少明确个人勇武材料。 |
| 3—5 | 有遇险、受伤、亲临危境材料，但个人搏战/冲阵不突出。 |
| 6—8 | 有明确冲阵、突围、亲自搏战、冒险救援、战场激励。 |
| 9—10 | 多次明确个人勇武，并形成稳定战场威望。 |
| 11—12 | 极罕见；个人勇武本身成为夺权资本和军事威望核心标签。 |

C3不再作为“小号C2”。亲征风险基础只占8分，个人勇武与战场威望占12分，是C3最有独立价值的部分。

#### C4. C项统筹复核（不计分）

C4只做一致性检查，不另给分，不反向改写C1战役定级。

检查问题：

- C1、C2、C3是否使用同一套战役事实；
- 是否把名将代打、后方授权、普通遣将重新回流到本人；
- 是否把个人勇武重复奖励为战争指挥；
- 是否把C1层级较低的战役因亲征而反向拔高；
- 是否因为总排名直觉反向修改战役层级或计入指数。

### D 创业难度（20）

#### D1 创业难度与超额完成度（20）

评价：取得政权的起点、对手、环境与完成度。

计入：

- 起点高低
- 对手强弱
- 天下局势复杂度
- 资源匮乏程度
- 是否完成超出起点的成果

不计入：

- 创业成功后的治理成果
- 后世王朝影响
- 单纯“出身低”但实际对手弱、环境顺的加分

边界：

> D项是难度修正项，不是结果重复加分项。难度高但表现差，不能高分；难度低但完成度高，也不应无限拉低。

### A 制度建设（140）

评价皇帝对国家制度体系的建设、修复、运行与制度史影响。

| 小项 | 名称 | 分值 |
|---|---|---:|
| A1 | 制度创设与修复 | 50 |
| A2 | 制度运行质量 | 50 |
| A3 | 制度历史影响力 | 40 |

#### A1 制度创设与修复（50）

评价：皇帝是否创设、重构、修复或成熟化了关键国家制度，并且这些制度在历史条件下是否有利于生产力增长与文明进步。

计入：

- 中央制度、地方制度、财政制度、选官制度、法制体系、军政关系制度、国家治理框架重建
- 能降低治理成本、稳定社会预期、保护民间弹性、扩大人才流动、改善反馈纠错、促进经济恢复和文明进步的制度建设

不计入：

- 制度实际运行效果，归A2
- 行政日常效率，归B项
- 教育人才的文明层面影响，归第四项B
- 单纯开疆或军事控制，归第三项
- 国库充盈、账面户口/田亩暴增、国家汲取能力增强本身；若主要体现抽血、高压清查、告发连坐、身份固化或压缩民间弹性，应作为负向制度审查

边界：

> A1问“有没有建设制度、修复制度、重构制度，以及这些制度净方向是否有利于生产力增长和文明进步”。

#### A2 制度运行质量（50）

评价：皇帝统治期内制度是否运行顺畅、稳定、有效。

计入：

- 制度执行稳定度
- 制度与行政实践的匹配度
- 皇帝是否尊重并维护制度
- 制度能否降低治理成本
- 制度运行中的纠偏能力

不计入：

- 制度原创性，归A1
- 制度后世影响，归A3
- 官僚个体质量，归B1
- 政权交接稳定，归D3

边界：

> A2问“制度当时跑得好不好”，不是问“制度是否伟大”。

#### A3 制度历史影响力（40）

评价：皇帝留下的国家机器制度是否改变后世制度史。

计入：

- 后世长期继承的国家机器制度
- 对帝国政治结构的深层塑造
- 被后世反复模仿、修正、沿用的制度框架
- 对中央—地方、君主—官僚、财政—军事关系的长期影响

不计入：

- 离世时制度是否能立刻稳定运行，归D1
- 文明、文化、思想层面的遗产，归第四项D
- 教育社会化与人才流动，归第四项B
- 单纯行政效率，归B项

边界：

> A3只看“国家机器制度史影响”，不再使用“制度遗产与可持续性”的混合口径。

### B 行政治理（160）

#### B1 吏治水平（60）

计入：

- 官僚专业能力

- 中央与地方官僚体系的整体质量

- 复杂政务处理能力
- 国家机器响应能力

不计入：

### A 战略安全收益（80）

#### A1 消除战略威胁（40）

- 长期安全格局改善

不计入：

- 单纯疆域面积扩大，归B1
- 新边疆的文明整合，归第四项A
- 军事制度建设，归C项

边界：

> A2看“边界是否更安全”，不是看“版图是否更好看”。

### B 边疆控制净收益（80）

评价开疆、固疆、收复、羁縻、设治等行为对国家安全和控制能力带来的净收益。

| 小项 | 名称 | 分值 |
|---|---|---:|
| B1 | 控制规模 | 20 |
| B2 | 战略价值 | 25 |
| B3 | 控制效率 | 20 |
| B4 | 稳固程度 | 15 |

> 注：原名为“开疆净收益”。本版扩展为“边疆控制净收益”，以避免只奖励扩张，也能评价收复、固疆、有效设治和边疆稳定。

#### B1 控制规模（20）

评价：新增、恢复或有效稳固的边疆控制规模。

计入：

- 新增有效控制区域
- 收复失地
- 把松散控制转化为稳定控制
- 将边疆纳入常态治理范围

不计入：

- 纸面宣称但不能有效控制的土地
- 短期掠夺性占领
- 单纯文明影响扩散，归第四项

边界：

> B1看控制规模，不等于地图涂色。

#### B2 战略价值（25）

评价：边疆控制是否具有重要安全、交通、资源或地缘价值。

计入：

- 关键走廊
- 关隘门户
- 战略缓冲
- 资源产地
- 贸易通道
- 对强敌的压制作用

不计入：

- 面积大但战略价值低的区域自动高分
- 文明象征意义，归第四项D

边界：

> B2看“值不值得控制”，不是看“面积大不大”。

#### B3 控制效率（20）

评价：国家以多大成本实现边疆控制。

计入：

- 行政设治成本
- 驻军成本
- 后勤成本
- 当地治理合作度
- 控制方式是否适配现实条件

不计入：

- 总体军事成本收益比，归D项
- 民生最终承压结果，归第二项C

边界：

> B3看边疆控制本身是否高效；D项看整个军事战略是否透支国家。

#### B4 稳固程度（15）

评价：边疆控制是否能在皇帝离世后保持稳定。

计入：

- 驻军与行政稳定
- 当地政治结构是否可控
- 交通补给是否可维持
- 是否反复丢失、叛乱或失控

不计入：

- 当地人心认同，归第四项A
- 中央政权交接稳定，归第二项D3

边界：

> B4看控制是否稳固，不看文明认同是否完成。

### C 军事体系有效性（50）

评价皇帝统治期内军事体系的实际运行效果。

本项不强制再拆固定分值，但评分时应综合以下维度：

#### C1 军制与组织

计入：军制结构、军队编制、将帅体系、中央与地方军事关系。

不计入：纯制度史影响，若主要影响国家机器制度史，归第二项A3。

#### C2 兵源与动员

计入：兵源稳定性、动员能力、军队补充机制、军民关系。

不计入：对百姓生活造成的最终负担，归第二项C。

#### C3 后勤与财政支撑

计入：粮饷、运输、军需、长期作战支撑能力。

不计入：军事战略总体是否值得，归第三项D。

#### C4 战斗力与持续性

计入：军队实际战斗力、连续作战能力、战后恢复能力、体系是否依赖个别名将。

不计入：创业战争中的个人统兵能力，归第一项C。

边界：

> C项采取结果导向，不只看军制创新，也看指挥、兵源、后勤、战斗力和持续性。

### D 军事成本收益比（40）

评价军事行动和边疆经营是否在国家承受能力内取得足够收益。

计入：

- 是否穷兵黩武
- 是否战略透支
- 是否财政透支
- 是否兵役、徭役过重
- 战争收益是否配得上代价
- 战争是否导致国家安全反而下降

不计入：

- 百姓生活的最终恶化结果，归第二项C1
- 财政健康的总体结果，归第二项C2
- 长期不可逆历史窟窿，归第七项

边界：

> 第三项D看“军事投入是否值得”；第二项C看“百姓和经济实际承受结果”；第七项看“是否留下跨期灾难”。

## 9. 第七项：历史负债（0—300扣分项）

### 9.1 核心问题

> 给国家留下了多大的历史窟窿？

本项不加分，只扣分。

最终总分：

> **正收益 − 历史负债**

### 9.2 总边界

计入：

- 前六项不能完全覆盖的长期结构性负债
- 对国家、社会、文明造成跨期损害的重大错误
- 由皇帝主动决策或长期失控造成的灾难性后果

不计入：

- 已经在前六项净收益中充分扣除的普通代价
- 正常执政失误
- 完全由后代独立造成的灾难
- 与皇帝决策无明显因果关系的偶然事件

特别说明：

> 第七项不是“所有缺点再扣一遍”，而是处理历史窟窿。前六项已经扣过的成本，不得机械重复扣分。

---

### G0 轻微负债（0—20）

正常执政失误。

适用情形：

- 局部政策失当
- 小规模损失
- 后续容易修复
- 不伤国家主体

---

### G1 明显负债（20—60）

造成损失，但国家主体无伤。

适用情形：

- 明显错误政策
- 局部社会、财政或军事损失
- 需要后继者一定程度修复
- 但不改变国势基本面

---

### G2 严重负债（60—120）

国力明显受损，需后继者长期修复。

适用情形：

- 大规模财政、民生、军事透支
- 重要制度或边疆结构受损
- 社会矛盾明显激化
- 国家恢复成本很高

---

### G3 灾难级负债（120—200）

国势逆转，由盛转衰。

适用情形：

- 重大决策导致国家趋势反转
- 王朝由强转弱
- 中央权威、财政、军事或社会结构遭到重创

区间参考：

- 李隆基

---

### G4 毁国级负债（200—280）

直接导致王朝崩溃，或基本不可逆崩溃。

适用情形：

- 政权主体崩坏
- 国家进入不可逆分裂或崩溃
- 后继者几乎无力修复

区间参考：

- 司马衷

---

### G5 天花板级负债（280—300）

接手顶级国力盘，短期内因主动决策造成王朝覆灭。

适用情形：

- 起点极高
- 主动决策极坏
- 后果极快显现
- 王朝主体直接覆灭或接近覆灭

典型标尺：

- 杨广

## 11. 标准使用流程

### 第一步：确认统治阶段

区分：

- 创业夺权阶段
- 正式统治阶段
- 交班阶段
- 后世影响阶段

### 第二步：按项目归口

同一事实先判断应主要归入哪一项。

例如：

- 创业战争胜利：第一项
- 登基后边疆战争收益：第三项
- 战争造成民生透支：第二项C或第三项D
- 战争留下长期崩溃隐患：第七项

### 第三步：先算正收益，再算历史负债

前六项每项内部都按净收益评分。

第七项只处理额外历史窟窿。

### 第四步：选择评分路径并从严落点

先判断小项属于哪类：

- 精细量化项：先核对量化账本、净值、系数和负面项，再按量化结果落点；档位用于解释和审计，不反向压缩量化断层。
- 非精细量化项：继续按 V3.2 新档位体系先定档，再在档位区间内给分。
- 半量化或派生画像项：能由账本控制的部分按账本处理，仍需史实画像判断的部分按档位处理。

按 V3.2 新档位体系定档时：

- 96%—98% 才是历史极限；
- 90%—95% 才是历史顶级；
- 80%—89% 为优秀；
- 不再使用“历史顶级上段”“优秀上段”作为正式档位。

同档内有明显黑点者，应向下压分。没有黑点的标尺人物和有黑点的人物不得机械同分。

### 第五步：复核重复结算

打分后必须检查：

- 是否同一成果重复加分
- 是否同一代价重复扣分
- 是否把后代发挥算给前任
- 是否把个人素质替代实际成果
- 是否把文明影响和制度影响混算
