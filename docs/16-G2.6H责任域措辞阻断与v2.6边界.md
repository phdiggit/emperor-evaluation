## 阻断原因

v2.5 原子结构签名要求 responsibility domain 精确字符串一致。9 个 group 因史料措辞不同而被误判，例如：

- `温之战` / `温地战事`；
- `伐赤眉` / `赤眉讨伐`；
- `回溪之战` / `回溪战事`；
- `河南尹` / `河南尹、被阳侯`；
- `汝南太守` / `扬州牧、汝南太守`。

这些差异不能证明跨原子事件。每个 group 已有独立原子键，具体 merge 是否正确应由 blind Gold 指标裁定，不应被展示字符串先验阻断。

## v2.6 规则

原子 core 的硬一致字段保留：

- action；
- responsibility family；
- focal role；
- normalized time 与 dynasty/era。

responsibility domain、原文地名和官名组合不再要求精确字符串相等。它们仍进入 Episode semantic payload；不同原子事件由 `atomic_event_key` 区分，错误 merge 由 Gold scorer 计入 precision、wrong merge 和 catastrophic merge。

G2.6H 冻结结果不得按 v2.6 重跑后重新命名为 blind 成绩，只作责任域别名回归集。
