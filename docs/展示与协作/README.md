# 展示与协作

## 本目录负责什么

本目录负责 Markdown 人工阅读展示、GitHub 发布认证、scripts 协作规范等人机协作和展示规则。

## 本目录不负责什么

本目录不定义评分语义、不裁判证据、不登记 JSONL 字段事实，也不存放 registry。

## 与相邻目录的边界

- 证据规则进入 `证据规则/`。
- 数据结构和生成库进入 `数据结构与生成库/`。
- 子项业务归项进入 `分项规则/`。
- docs/scripts 机器登记进入 `文档与脚本登记/`。

## 后续新增文件限制

新增文件必须服务展示、协作或人工复核流程。不得把评分、证据裁判、字段 schema 或分项规则写入本目录。
