# V4 领域模型与不可妥协约束

## 1. 目标

V4 将“历史事件”设为第一事实单元。检索结果、人物、主张、材料、裁判和评分都围绕事件建立，
不得让 claim cache、模型输出或某次评分结果反向充当历史事实。

核心链路：

```text
史源文档 -> 可定位段落 -> 事件 -> 事件参与关系
                         -> 事件主张 -> 证据引用 -> 规则裁判 -> 评分结果
```

该链路表达的是依赖方向，不预设数据库、消息队列、worker 或部署实现。

## 2. 核心对象

### 2.1 SourceDocument

史源的书目、版本和承载信息。承载站与原书身份必须分离；同一原书可以有多个版本或承载。

最低字段：稳定标识、原书名、版本、承载位置、来源等级、内容指纹、获取时间。

### 2.2 SourcePassage

可复核的原文定位单元。必须能回到 SourceDocument，并保存卷次、篇章、纪年、页码或稳定段落定位。
正文修订必须产生新版本，不能覆盖已被证据引用的文本。

### 2.3 Event

在特定时间和语境中发生、可以被多个史源共同描述的历史事实候选。事件不是一句文本，也不是模型摘要。

最低字段：

- 稳定事件标识；
- 事件类型与规范标题；
- 时间范围及其精度；
- 地点或政治空间；
- 当前事实状态；
- 语义版本；
- 与前一版本的 lineage。

事件状态至少区分：候选、已回源、存在冲突、已接受、已否决。只有已接受事件可进入正式裁判。

### 2.4 EventParticipation

连接事件与人物、组织、制度或其他对象，明确角色、行为、归因强度和时间范围。不得只凭人物与事件共现
推导责任，也不得把臣僚行为自动归因给统治者。

### 2.5 EventClaim

关于事件的可检验命题，例如“某人作出任命”“授权持续到某时”“处置造成某后果”。每条主张必须：

- 只表达一个可裁判命题；
- 指向事件与参与关系；
- 记录支持、反驳和不确定性；
- 标明证据版本与语义版本；
- 不直接携带正式分数。

### 2.6 EvidenceCitation

连接 EventClaim 与 SourcePassage，记录引用角色：支持、反驳、背景、旁证、削弱或相邻项剥离。
短摘只是导航，正式复核必须读取可定位段落及必要上下文。

### 2.7 RuleJudgment

在明确规则版本下，对已接受事件及主张作出的可审计裁判。必须记录适用规则、输入事件版本、证据版本、
结论、理由、置信边界和人工复核状态。规则变更不得覆写旧裁判。

### 2.8 ScoreResult

在明确评分版本下，由已通过门禁的 RuleJudgment 推导的结果。评分是派生物，不得反向修改事件、证据或裁判。
当前架构阶段和 shadow 阶段均不得发布正式分数。

## 3. 版本维度

以下版本彼此独立，不得合并为单一“数据版本”：

| 版本 | 负责内容 | 变化示例 |
| --- | --- | --- |
| 语义版本 | 对象、关系和字段含义 | 事件参与角色定义变化 |
| 证据版本 | 史源文本、定位和引用集合 | 新增反证或更换点校本 |
| 规则版本 | 归项、裁量和触发条件 | 负证拦截条件变化 |
| 评分版本 | 权重、映射和聚合 | 档位区间或权重变化 |

任何结果都必须能够固定到这四个版本；重算生成新结果，不覆盖旧结果。

## 4. 不可妥协约束

1. **事件优先**：正式裁判必须从已接受事件开始，不能从人物印象、搜索摘要或旧 claim 开始。
2. **原文可定位**：正式证据必须回到明确史源与可定位段落。
3. **支持与反驳并存**：冲突材料必须保留并显式裁判，不能用最后写入覆盖。
4. **归因显式**：人物、行为、后果和责任链必须分开记录。
5. **相邻项隔离**：同一事件可以影响多项，但每个作用必须独立说明，禁止重复结算。
6. **版本不可覆盖**：已接受证据、裁判和结果只追加新版本，不原地改写历史。
7. **模型非事实源**：模型只可生成候选、草案和 worklist；不得建立事实、裁判或正式评分。
8. **V3 只读隔离**：V3 数据只作对照，不能以迁移、回填或缓存命中绕过 V4 门禁。
9. **shadow 先行**：未通过 shadow 验收，不得替换生产服务或发布正式结果。
10. **可重复与可审计**：任一结果必须能从固定输入和固定版本重复生成，并解释每一步来源。

## 5. 架构阶段明确不决定

当前不决定数据库产品、表名、队列、worker 拆分、并发、超时、部署路径或系统服务。这些属于后续
runtime 设计，必须在领域对象和验收门禁稳定后另行决策。
