# V4 文档导航

`docs/` 保存统治绩效、九轴人物画像、历史影响三套体系的现行规则、证据、公共登记和正式结果。完整退役组件的最后有效版本见[归档](../archive/README.md)，其他历史版本由Git保存。

## 按任务查阅

- 局部评分维护：从 [`config/project.yml`](../config/project.yml) 定位对应正式记录及 `分项规则/` 合同章节。
- 安装、维护命令与验证选择：查[项目入口](../README.md#安装与日常操作)。
- 三体系分工与共同边界：查[综合评价体系合同](项目总纲/皇帝综合评价体系合同.md)。
- 统治绩效总公式或跨项边界：查[统治绩效评价合同](项目总纲/皇帝统治绩效评价合同.md)对应章节。
- 结果查询：从 [`评分结算/`](评分结算/README.md) 进入当前正式结果。
- 证据复核：沿正式记录引用查 `公共成果/`、`治理/` 或 `史料通读产物/`。
- 阅读文案与构建：查[分项编辑与刷新](../reader/README.md#分项编辑与刷新)。其他展示或开发支持只读相关文档与依赖，无需每次通读总纲。

## 目录职责

| 目录 | 内容 |
| --- | --- |
| `项目总纲/` | 三套体系的总合同、专项合同与跨体系边界 |
| `分项规则/` | 各项档位、公式、归责和去重合同 |
| `评分结算/` | 当前唯一正式机器结果与阅读视图 |
| `展示成果/` | 正式结果派生的雷达图、人物卡及文字小样，不作为裁决真源 |
| `证据规则/` | 仍参与评分裁量和公共成果登记的证据边界 |
| `公共成果/` | 仍被各体系引用的军事、制度、法律等公共登记与证据 |
| `治理/` | 第二项仍引用的治理底账 |
| `史料通读产物/` | 正式结算仍引用的固定史料证据 |

旧模型服务、任务状态机、source-cache、数据库和shadow执行流程已退役；当前裁决仍引用的材料继续保留，是否删除按引用与证据用途判断。静态阅读站点的发布流程见阅读层说明。
