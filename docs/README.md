# V4 文档导航

`docs/` 只保存五大项评分仍在使用的规则、证据 lineage、公共登记和当前正式结果。Git 是唯一历史载体。

## 按任务查阅

- 局部评分维护：从 [`config/project.yml`](../config/project.yml) 定位对应正式记录及 `分项规则/` 合同章节。
- 总公式或跨项边界：查 [`评分标准`](项目总纲/皇帝综合评价体系评分标准.md) 对应章节。
- 结果查询：从 [`评分结算/`](评分结算/README.md) 进入当前正式结果。
- 证据复核：沿正式记录引用查 `公共成果/`、`治理/` 或 `史料通读产物/`。
- 文案、展示或开发支持：只读相关文档与依赖。无需每次从总纲开始通读；已读且未变化的资料复用。

## 目录职责

| 目录 | 内容 |
| --- | --- |
| `项目总纲/` | 五项结构、总公式与跨项边界 |
| `分项规则/` | 各项档位、公式、归责和去重合同 |
| `评分结算/` | 当前唯一正式机器结果与阅读视图 |
| `证据规则/` | 仍参与评分裁量和公共成果登记的证据边界 |
| `公共成果/` | 第一、第三项共同消费的军事成果与人才登记 |
| `治理/` | 第二项仍引用的治理底账 |
| `史料通读产物/` | 正式结算仍引用的固定史料证据 |

模型服务、任务状态机、source-cache、数据库、部署、shadow 和会话工作流文档均已退役，不再属于当前文档集。
