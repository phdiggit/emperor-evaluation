# 第五项B_李世民正证回源说明

本任务只处理李世民三条第五项B正证线索：识人拔擢、授权专任、容谏纳言。不处理李世民负证，不处理刘秀、刘庄。

本任务不定档、不定分、不排名。正证强度只表示候选证据强度，不是最终入分强度。

## 已成功回源

- `EVD-I5B-LISHIMIN-POS-SHIREN-FANGDU-001`：据《旧唐书》卷六十六，房玄龄在李世民幕府中先收人物、联结谋臣猛将，可作为识人聚才与多类型人才结构的强正锚点。
- `EVD-I5B-LISHIMIN-POS-SHIREN-WEIZHENG-001`：据《旧唐书》卷七十一，魏征原属建成阵营而太宗仍擢拜谏议大夫，可作为重用旧敌阵营人才的中正锚点。
- `EVD-I5B-LISHIMIN-POS-SHOUQUAN-LIJING-001`：据《旧唐书》卷六十七，李世民以李靖为代州道行军总管，体现对关键军事人才的专任授权。
- `EVD-I5B-LISHIMIN-POS-RONGJIAN-WEIZHENG-001`：据《旧唐书》卷七十一，“太宗與之言，未嘗不欣然納受”，可作为容谏纳言与反馈入口的强正锚点。

## 仍待继续回源

本任务范围内三条李世民正证线索均已找到公开古籍文本并生成锚点证据卡。后续仍可补《资治通鉴》《贞观政要》对照，但不影响本任务闭环。

## 相邻项切分摘要

- 识人拔擢：B项只计发现人才、任用人才、重用旧敌阵营人才和多类型人才结构；不计战功、政绩、盛世光环。
- 授权专任：B项只计授权、专任、权责匹配；战役胜利、版图扩张切第一项/第三项，行政执行效果切第二项B3。
- 容谏纳言：B项只计谏臣表达安全、反馈入口、愿意听取谏臣；政策纠错效果切第二项B2，皇帝认知反省切第五项E。
