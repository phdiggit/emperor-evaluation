# 覆盖度与验收标准

> 状态：`accepted`
> 适用：李世民、刘邦、朱元璋三人 shadow 试点。

## 1. 三类覆盖度

### 1.1 source_coverage

回答：重要史源是否被发现、抓取、定位和缓存？

最小维度：

- 必选史源族是否覆盖；
- 文献抓取成功率；
- 关键章节/本传/本纪/志书覆盖；
- 结果段、失败段和论赞段覆盖；
- 跨朝、跨时期材料是否分段；
- fetch error 和不可访问来源。

### 1.2 episode_recall

回答：已获取史源中的重要事件是否被识别并正确归并？

最小维度：

- gold major episode recall；
- secondary episode recall；
- accepted episode precision；
- 错误合并率；
- 错误拆分率；
- 人物归因错误率；
- 关键结果/失败边界缺失率。

### 1.3 consumption_integrity

回答：已接受事件是否完整进入规则投影、判断和评分？

逐事件检查：

```text
episode
→ participants
→ projection
→ judgment
→ score contribution
→ cluster/result
```

每个阻断必须有具体阶段和 next action。

## 2. Gold manifest

每位试点皇帝建立人工冻结 manifest，至少包括：

- 主要相关人物；
- 重大正向任用授权事件；
- 重大负向或失败事件；
- 容易误合并/误拆分的边界事件；
- 关键史源和 locator；
- 预期适用/不适用规则；
- 明确反例；
- V3 曾发生重复、漏召回、错绑或上下文丢失的案例。

Gold manifest 不是把 V3 结果当真值，而是重新回源后的人工作业基准。

## 3. 初始试点阈值

阈值用于进入下一 Gate，不代表最终生产 SLA。

| 指标 | 阈值 |
| --- | ---: |
| 必选史源族覆盖 | 100% 有结果或可审计不可得结论 |
| major episode recall | ≥ 90% |
| secondary episode recall | ≥ 80% |
| accepted episode precision | ≥ 95% |
| 错误合并率 | ≤ 2% |
| 错误拆分率 | ≤ 2% |
| canonical person 重复 | 0 |
| lineage 完整率 | 100% |
| 已接受 episode 的消费完整率 | 100% |
| 无变化重跑业务写入 | 0 |
| 无变化重跑模型调用 | 0 |
| 新增同义证据导致重复 score | 0 |

任何严重错归因、来源不可追溯或跨皇帝污染可直接阻断，不因总体百分比达标而放行。

## 4. Gate

### G0 范围冻结

- 三人和 `appointment_delegation` 明确；
- gold manifest 有版本；
- 排除项明确；
- V3 对照标记为只读。

### G1 史源

- 每个正式候选有可定位 passage；
- 来源身份、版本、hash 和检索过程完整；
- discovery-only 来源未进入正式证据。

### G2 Assertion 与 Episode

- 断言可核验；
- 同事件跨来源汇聚；
- 冲突、时间不确定和身份不确定未被抹平；
- merge/split 有 lineage。

### G3 规则投影

- 每个 episode 对当前 rule 只有一个活动 projection；
- 不适用理由可审计；
- 相邻项与重复结算检查完成。

### G4 判断与评分

- Judgment 使用有限值并声明规则版本；
- 模型输出未直接成为正式判断；
- ScoreContribution 为确定性结果；
- 每个贡献可追到 episode、assertion 和 passage。

### G5 可重复性与性能

- 无变化重跑零写入、零模型调用；
- 新增同义证据不重判；
- 新事件只处理局部 delta；
- 失败后从失败阶段恢复。

### G6 Shadow comparison

差异分类至少包括：

- 漏召回；
- 误召回；
- 错误合并；
- 错误拆分；
- 人物/皇帝归因错误；
- 证据冲突处理差异；
- 规则边界差异；
- 评分公式差异。

每个严重差异有人工裁定；与 V3 一致不是正确性的唯一标准。

### G7 发布安全

- V4 无 V3 数据库写权限；
- 正式评分和排名关闭；
- 凭据与 runtime 参数不在仓库；
- 回滚和隔离方案经过演练；
- 生产切换另有明确批准。

## 5. 验收结论

- `pass`：全部阻断项关闭；
- `conditional_pass`：只剩明确、可控且不影响下一阶段的限制；
- `fail`：存在不可追溯结论、严重回归、范围漂移或隔离风险。

G0—G5 全部 pass 后才可完成正式 shadow comparison。G6—G7 pass 只表示可以提出切换设计，不等于授权切换。
