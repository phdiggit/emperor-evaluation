# 第五项B《用人与授权》边界说明

第五项B《用人与授权》只评价统治者在人本政治素质层面的：

- 识人与选才
- 授权与职责匹配
- 容人与团队结构
- 任后纠偏与风险控制
- 能臣/功臣处置底线

## 可计入第五项B的证据

- 发现、拔擢、任用人才。
- 是否授权充分，权责是否匹配。
- 是否能容纳不同类型人才、逆耳者、旧臣、降臣、边将、儒生、异质人才。
- 任用错误后是否能纠偏。
- 对功臣、能臣、谏臣的处置是否影响人才安全感。
- 是否因疑忌、谗言、酷吏、近幸、意识形态压制破坏用人生态。

## 不直接计入第五项B的内容

- 政策最终收益，不直接计入B，主要归第二项或第四项。
- 军事战果，不直接计入B，主要归第一项或第三项。
- 权力集中、制度控制本身，不直接计入B，主要归第五项C。
- 统治者道德残酷性本身，不直接计入B，主要归第五项D。
- 认知、学习、纠错能力本身，不直接计入B，主要归第五项E或第二项B2。
- 行政执行成效本身，不直接计入B，主要归第二项B3。

## 相邻项切分示例

- “纳谏后改正政策”：B只计容纳反馈入口，政策纠错效果切第二项B2或第五项E。
- “任用名将取得大战果”：B只计识人授权，战果切第一项/第三项。
- “杯酒释兵权”：B可计功臣处置克制，权力结构收益切第五项C。
- “酷吏制狱”：B计错误授权对象与人才安全破坏，政治品格残酷性切第五项D。
- “以谶决事压制反对者”：B计人才/谏臣受压，认知问题切第五项E。

## 功臣/能臣处置分案规则

不能直接从“被杀、被贬、失势”推出极负。必须先判断：

- 当事人是否确有谋反、叛乱、违法、失职。
- 皇帝是否存在疑忌、听谗、逼反、罗织、扩大化。
- 处置是否单案、株连化、系统清洗。
- 对人才安全感和授权预期的破坏程度。

## 负证分案裁判补充

高风险负证不得只因“被杀、被贬、失势、死后被疑”而机械升格。进入 evidence_cards 时，应先补齐分案字段：

- `case_classification`
- `risk_status`
- `mitigating_factors`
- `aggravating_factors`
- `reversal_or_rehabilitation`
- `adjudication_status`

确有谋反链条的功臣处置，默认不得高于弱负候选；未坐实但有强嫌疑的疑案，默认不得高于中负候选；死后信任逆转若出现公开信用撤销且直接命中谏臣/表达安全预期，默认按中负封顶，不得上探强负。若存在追悔、复碑、平反或恢复评价，应作为减轻与封顶因素处理，而不是把普通单证全部推给人工裁判。只有系统牵连扩大、死徙以千数、群臣不敢正言等直接影响人才生态的材料，才可支持强负候选；极负必须人工裁判，Codex 不得直接写入。
