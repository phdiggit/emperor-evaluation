- 特质：**C4 公共资源与最高权力特权克制｜负向·历史级**。负向依据：连续营建东都、显仁宫、西苑、离宫、运河、御道、长城、巡游船队，并在旧龙舟焚毁后扩大重造。；东京役丁死什四五；造船役夫死什三四；粮运道路死者相枕，耕作、粮价、逃亡与群盗恶化，群臣多次指出百姓疲弊。；反馈后仍有613年十万丁男城大兴、615年数千龙舟扩大重造、616年全国失控期毗陵宫苑和十六离宫，未形成资源收缩。 来源：docs/史料通读产物/唐以前编年/隋/卷183-通读总结.md:15；docs/史料通读产物/唐以前编年/隋/卷180-通读总结.md:141；docs/史料通读产物/唐以前编年/隋/卷180-通读总结.md:147；docs/史料通读产物/唐以前编年/隋/卷180-通读总结.md:153。

### 嬴政

- 档位：G-1-LOW；特质组合：历史级·负向×1；强·负向×1。
- 特质：**C1 惩罚、株连与强制权力克制｜负向·强**。负向依据：嬴政统一后持续维持国内连坐和重刑扩大责任，且没有在长期运行反馈后收缩；排除焚书禁议与战时暴力后，仍构成C1纯负向强。 来源：https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B77。
- 特质：**C4 公共资源与最高权力特权克制｜负向·历史级**。负向依据：嬴政C4仅取非战争的阿房—骊山—宫观网络：七十余万刑徒、跨区运材和八万户迁徙均由本人最高接口发动，且阿房未竟仍未收缩。道路、长城、南北战争与既有C1重刑链全部排除，故为历史级纯负向。 来源：https://zh.wikisource.org/zh-hans/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7007。

### 刘聪

- 档位：G-1-LOW；特质组合：历史级·负向×1；强·混合负向×1。
- 特质：**C1 惩罚、株连与强制权力克制｜负向·历史级**。负向依据：刘聪在己方宫廷和中枢反复以猜忌诛杀宗室、后妃与大臣，持续造成继承和组织失序，构成C1历史级负向。 来源：https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B788；https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B789；https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B790。
- 特质：**C2 异议者、无辜者与依法履职者保护｜混合负向·强**。依据：正向反证或纠偏：后期未恢复早期保护标准，负向反复压过有限正向阶段。 反证/负向依据：主导负向：刘聪早期尚能容纳部分直谏，后期却因逆耳、猜忌反复贬杀或威胁谏臣与大臣。；反馈/后果：早期保护带来持续进言；后期死亡和恐惧使反证接口收缩，中枢错误更难纠正。 来源：https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B789。

### 石虎

- 档位：G-1-LOW；特质组合：历史级·负向×1；强·负向×1。
- 特质：**C1 惩罚、株连与强制权力克制｜负向·强**。负向依据：石虎在己方控制区反复以酷刑、扩大杀戮和高压征发对待臣民与政治对象，死亡逃亡反馈后仍持续，构成C1负向强。 来源：https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B796。
- 特质：**C4 公共资源与最高权力特权克制｜负向·历史级**。负向依据：石虎C4达到历史级不是因知名度：洛阳、长安二宫动作者四十余万，后续华林苑再役十六万并配十万车，苑役暴雨死数万、游猎死万余；342—347跨阶段扩建，韦謏劝停后反而兴缮更繁。规模、持续、反馈后继续三门同时满足，和嬴政、杨广同属历史级硬锚。 来源：https://zh.wikisource.org/zh-hans/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7097。
