# 评分结算

本目录保存统治绩效、人物画像与历史影响三套并列体系的正式结果和同值阅读视图。权威输入按 [`config/project.yml`](../../config/project.yml) 声明读取：第一项使用 Markdown 结算源，其余使用对应正式 JSON；派生视图必须同值。

| 体系目录 | 正式阅读入口 | 内容 |
|---|---|---|
| `净收益/` | [统治绩效综合评分榜](净收益/00-统治绩效综合评分榜.md) · [四项入口](净收益/README.md) | 前四项、综合排名及统治绩效综合分析 |
| `人物画像/` | [九轴结算汇总](人物画像/九轴结算汇总.md) · [正式轴入口](人物画像/00-已结算轴正式入口.md) | 八个能力轴与C5行为风格轴 |
| `历史影响/` | [历史影响正式结算](历史影响/01-历史影响正式结算.md) | 公众总档与四维定性裁决，主池与既有池外样本分列 |

三套结果不互相换分。画像雷达、视频人物卡和文字小样在[展示成果](../展示成果/人物画像/README.md)，不属于裁决真源；综合阅读层在[`reader/`](../../reader/README.md)，退役组件在[`archive/`](../../archive/README.md)。

各项当前验收状态与局部复核边界见对应正式入口及共享审计；结构同值校验不替代语义验收，也不要求每次局部维护重开全池复审。

统治绩效各榜按最终得分降序排列，同分使用竞争排名。分项榜可以保留大于正式评价池的证据全集；当前人数、分项缺口与第一项适用范围统一读取[`正式评价对象范围`](../项目总纲/正式评价对象范围.md)，本页不另存人数副本。综合统计和总排名只消费`COMPOSITE_READY`对象，第一项不适用者取F=0。综合榜由正式命令确定性生成；数据库写入不在执行范围。

历史整改表、裁决前后对照和阶段验收报告只通过Git回溯。当前证据处置账与尚未关闭的语义门继续服务于正式裁决；结构同值通过不替代语义验收。
