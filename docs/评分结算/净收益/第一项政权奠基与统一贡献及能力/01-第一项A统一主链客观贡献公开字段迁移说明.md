# 第一项A公开成果字段迁移说明

## 迁移范围

第一项A仍以[正式结算 Markdown](01-第一项A统一主链客观贡献正式结算.md)保存分值、成果范围和归责结果。本次新增的[公开成果伴随数据](01-第一项A统一主链客观贡献正式公开成果.json)只保存面向普通读者的三段说明：起点与继承背景、本人实际成果范围、公开边界；它不保存或重算A分值。

`reader/build.py`在构建阶段校验伴随数据与正式A人物集合、共同项目集合和成果占比一致，再把公开字段投影到人物详情。浏览器端不再读取A的原始“成果内容”来改写人物叙述。

## 旧 reader 文案与本次处理

旧版`publicOutcomeText()`只对少数固定句子做替换，覆盖后金—清、后周、晋—后唐、后赵、后秦、蒙古—元、北宋、北魏、西晋、西魏—北周、金、汉赵、西夏、辽、前秦等共同项目，以及南宋、东晋、西辽和若干单人创业或恢复案例。那些替换同时承担了起点、阶段归属、最终保有和排除范围的说明，未覆盖的正式A人物仍会把内部结算措辞带到 reader。

迁移后的差异处理如下：

- 共同项目不再用一条项目级句子覆盖所有人物；每人分别写明本人实际范围，另一位或其他阶段只在边界中作为排除说明。
- 恢复型成果改写为“恢复哪些既有区域、最终留下什么”，不把恢复说成全新征服，也不把50%恢复口径写进公开叙述。
- 曹操、刘备、苻坚、姚兴等存在阶段性失守或退出终点的对象，公开字段按正式终点保留结果，不按历史峰值补足。
- 司马懿、司马师、曹丕、王莽等只有中枢接管或改朝而没有新增区域控制的对象，公开字段明确说明这一边界，不把政治作用改写为区域成果。
- 其余正式A人物一并补齐同样的三字段；删除的固定替换不改变正式A、第一项总分、附加F、综合总分或排名。

如旧替换句与上述正式终点、阶段归属或排除范围不一致，以正式A结算及本伴随数据为准；这类差异只属于公开叙述修正，不构成重新裁决。

## 验收锚点

- 伴随数据必须覆盖当前正式A来源的全部人物。
- 共同项目的每位参与者必须使用同一公开项目标签，并有不重复的个人成果范围。
- 公开字段不得出现项目池、控制信用、分账、倒算、回填等内部结算术语。
- reader只消费`reader_public_outcome`投影；正式评分字段保持不变。
