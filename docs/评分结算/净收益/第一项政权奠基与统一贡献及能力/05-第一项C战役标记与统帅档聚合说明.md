## 1. `S-/D3` 是两个独立标签，但必须先辨责任层级

逐人结算中的 `鄱阳湖S/D3`、`洛阳—虎牢S+/D4`、`官渡S/D4` 等写法，都是“**战略结果档 / 作战难度档**”证据锚，不是一个合成等级，也不是武将总档。但它们不能脱离责任层级阅读，更不能默认等于父战役的整场总档。

公共战役登记可以同时保存两层记录：

1. **父战役整体档**：`campaign_tier / combat_difficulty`，回答整场战役或战役群最终形成了多大的结果、整体问题有多难；
2. **人物可归责档**：人物责任记录中的 `result_tier / combat_difficulty`，回答该人物实际承担并闭合的部分形成了多大的结果、本人面对的任务有多难。

第一项C只消费能够闭合到本人的责任证据。因此，人物责任记录已经给出更精确的个人战果／个人任务难度时，逐人C结算应按人物级标签解释；只有责任路线本来就在消费整场战争设计、高层统筹或相应父层结果时，才能按该责任层级解释。不能因为某人参与或批准了一场D4战役，就自动继承整场D4；反过来，也不能因为父战役整体只有D3，就把人物在其中实际承担的D4局部任务强行降成D3。

### 1.1 左侧：当前责任层级的战略结果档

| 档 | 大致含义 |
|---|---|
| C | 局部战术或低权重辅助结果 |
| B | 重要清障、防御或单项目标，尚未形成主要战略终局 |
| A | 主要区域、门户、主力集团或重大阶段结果；重大负向结果亦按实际影响登记 |
| S- | 强区域终局、核心根据地或长期独立战略方向成立 |
| S | 决定性击败第一梯队竞争极、国家级终局或同等量级结果 |
| S+ | 统一终局、多个第一梯队竞争极终局、外部霸权终局等规则限定的最高结果 |

结果档回答“**在当前责任层级上，最终兑现了多大的战略结果**”。如果当前锚是人物级记录，就是本人可归责结果；如果当前锚明确是整场／统筹层级，才读作对应层级的结果。它不评价问题有多难，也不直接等于个人能力。

### 1.2 右侧：当前责任层级的作战难度档

| 档 | 大致含义 |
|---|---|
| D0 | 未形成有效军事对抗，或主要接收已崩解残余 |
| D1 | 本方综合优势足以稳定覆盖常规风险 |
| D2 | 有一项重大难点，但本方总体态势仍覆盖主要风险 |
| D3 | 两项以上重大约束相互强化，需要高质量一线统帅才能稳定完成 |
| D4 | 明确极端劣势、孤军、断粮、被围、战线濒临崩溃或连续败退后的临阵逆转 |

难度档回答“**以当前责任层级实际面对的资源、情报、距离、地形、后勤和对手状态，这个军事问题有多难**”。执行得干净、伤亡低不会自动降低难度。

因此 `S-/D3` 的含义仍是：在D3级高难条件下，兑现了S-级独立战略方向成果；但在逐人C结算里，还必须再确认这对标签属于人物级、整场级还是高层统筹级。结果档高不等于难度一定高，难度高也不保证正向结果。

同一场战争出现“**整场战役难度D3 / 某人物个人任务难度D4**”并不自相矛盾：前者评价整场问题，后者评价该人物实际承担的局部任务。阅读层必须把两者分别标明，不能都写成裸的“难度D#”。

## 2. 战役档不是第一项C的直接计分公式

第一项C不把每场战役的S/A/B、D2/D3/D4转成数字后求和或平均。公共战役登记提供的是证据锚，最终按以下顺序整体裁决：

1. **责任门**：只消费本人真正承担的战略统筹、实际主帅或临阵指挥。普通任将、批准出兵、国家总成果、下属独立判断和名义亲征不自动转给本人；逐人结算中的战役标记也必须按这一责任层级解释。
2. **窗口门**：只消费第一项建国、复国、统一或政权取得主链。主链闭合后的成熟扩张、防务及独立外征不得倒灌抬高本项C。
3. **正向证据结构**：看本人最高峰值、高难成果、是否有独立复验、不同战区和战争形态的跨度，以及统筹或前线能力能否反复成立。
4. **负向证据结构**：本人可归责的重大失败、同错复发和未纠偏可以压档；敌强、天气、外部灾害、史源冲突或下属独立失败本身不构成本人败责。
5. **整体定C档**：C-0无可用本人责任证据；C-1基础统帅；C-2重要统帅；C-3优秀统帅；C-4顶级统帅；C-5历史级统帅，再按LOW/MID/HIGH映射0—40分。

一个高质量闭环但没有独立复验，最高只能到C-3；C-4、C-5必须跨情境稳定成立。因此一场`S/D4`不会自动得到C-5，多场`A/D3`也不能机械相加。

## 3. 父战役档与人物本人档不能混用

公共战役登记同时保存父战役整体结果/难度，以及具体人物在该战役中实际承担部分的结果、难度和责任模式。第一项C只消费能够闭合到本人责任的部分。

例如：
- 下属独立完成D4级临场问题，不能因为君主任命该将领就把D4转写给君主；
- 君主若明确设计全国战争方向、兵力配置和持续调度，可以按`operational_design`等责任路线消费其本人高层统筹结果，但不继承下属前线难度；
- 亲临前线也不自动获得整场父战役全部结果与难度，仍须按本人实际控制和决定闭合；
- 阅读战役档案时，主卡的“整场战役战果／整场战役难度”与责任人物块的“个人战果／个人任务难度”应分别比较，不能用其中一层覆盖另一层。

## 4. 公共武将总档与第一项C不是一套尺度

公共武将人才登记的 `ordinary / usable / capable / important / elite / top / historic` 是**全生涯军事能力聚合档**，会综合多个时期、多个政权窗口、峰值、独立复验、稳定性和重大反证。

第一项C则只看第一项指定主链，而且对象是当前净收益人物。两者可以互相核对证据厚度，但不能机械换算：

- `historic` 不自动等于 C-5；
- `top` 不自动等于 C-4；
- 第一项窗口之外的高峰可以提高全生涯武将档，却不能抬第一项C；
- 第一项C中引用公共人才登记的计数或稳定性信息，只能作交叉复核，正式定档仍须回到本项责任窗口与战役锚。

## 5. 阅读层档案

阅读层另建“战役档案”和“武将档案”，直接读取上述两套公共登记：

- 战役档案主卡展示**整场战役**的过程摘要、战略结果档及理由、作战难度档及理由、已登记军事成本和史源；责任人物块另展示人物可归责结果与任务难度；
- 武将档案展示全生涯总档、代表性能力记录、独立复验、重大反证，并反向链接到对应战役；人物级字段缺失而退回展示父战役档时，必须显式标为“关联整场”，不能冒充“个人”；
- 第一项C阅读层引用战役标记时，应提示观众先核对责任层级，不能把父战役D档与人物任务D档视为重复或冲突；
- 单场战役成本只说明该战役已有成本事实，不能反推第一项或第三项总体军事成本档。

本说明只增加可读性和审计路径，不重新裁决任何既有C结算。
