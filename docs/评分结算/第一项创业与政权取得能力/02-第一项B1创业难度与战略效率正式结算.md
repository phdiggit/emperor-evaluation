## 二、正式计分口径摘要

### 2.1 起点难度：15分

| R档 | 定义 | 分值 |
|---|---|---:|
| R0 | 无有效独立资源 | 15 |
| R1 | 极小个人集团 | 13 |
| R2 | 地方据点或小型成建制部众 | 11 |
| R3 | 成熟区域军政机器 | 8 |
| R4 | 强藩、大型方面军或大区域机器 | 5 |
| R5 | 全国主要竞争机器 | 2 |
| R6 | 接近统一的成熟国家机器 | 0 |

起点按本人**首次进入本次建国/复国/统一/政权取得主链并开始承担可归责贡献时**能够直接调用的实际军政资源裁定。不得用贫寒出身替代统一主链起点，也不得把后续亲手形成的集团倒灌为先天资源。

### 2.2 对手难度：15分

只取贡献窗口内最强两个独立战争机器：第一强全值，第二强按50%计。

| O档 | 定义 | 分值 |
|---|---|---:|
| O6 | 压制级竞争极：能直接逼迫己方生存、核心根据地或统一主链发生重大危机 | 10 |
| O5 | 同级竞争极：双方均有真实机会赢下主链，任一方获胜都能改写统一格局 | 8 |
| O4 | 成熟军政机器：能持续作战并造成重大成本，但与己方已有明显层级差 | 6 |
| O3 | 成建制区域对手 | 4 |
| O2 | 局部武装或残余政权 | 2 |
| O1 | 零散地方力量或短时抵抗 | 1 |

O档看**交手当时相对于己方的实际竞争压迫强度**。国号、历史名望、疆域大小均不能直接映射O档。同一体系不同阶段只消费一次；内部储位、禅代反对集团原则上不按独立O机器计。

### 2.3 完成效率：20分

效率终点使用核心闭合点`T_core`，而非最后一个边缘残余被消灭的时间。最早同时满足以下条件时视为核心闭合：

1. 已取得并最终保持/传承的成果达到该阶段最终有效成果约90%；
2. 已不存在仍能争夺该主链的O5/O6独立战争机器；
3. 剩余O4不得继续占据使核心统一明显不能成立的关键中心；
4. 后续只剩不超过约10%的边缘尾项或不具逆转能力的局部残余。

`T_core`后的尾项仍计A，但不继续拉长效率工期。若成果随后重新跌破90%，或O5/O6竞争极复起，则原`T_core`失效。

多阶段人物在前一阶段已经闭合、随后转入新的独立目标时，分别计算阶段效率，再按阶段A有效控制信用加权。

```text
期望完成年
= 4 + 8 × sqrt(效率阶段有效控制信用 / 1000)

速度比
= 实际阶段年数 / 期望完成年
```

| 速度比 | 效率分 |
|---:|---:|
| ≤0.75 | 20 |
| ≤1.00 | 18 |
| ≤1.25 | 16 |
| ≤1.50 | 14 |
| ≤2.00 | 11 |
| ≤2.50 | 8 |
| ≤3.00 | 5 |
| ≤4.00 | 2 |
| >4.00 | 0 |

A终点有效控制信用为0者，效率项固定0；B1不奖励“快速夺权但没有留下稳定统一成果”。
