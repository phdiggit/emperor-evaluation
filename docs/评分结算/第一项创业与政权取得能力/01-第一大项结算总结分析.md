# 第一大项创业与政权取得能力结算总结分析

## 一、结算范围与结构

第一大项只评价本名册所属王朝或独立政权的奠基人。秦至唐95名对象中38名进入结算，57名普通继承者、守成扩张者或仅取得个人皇权者不适用。

总分260分，由三个互不替代的部分组成：

- A创业战略能力100分：评价起点、对手环境、净控制取得、统一效率、稳固以及本人非战役战略判断；
- B政治整合能力60分：评价非本人开国团队完成的成果和创业窗口内顶端人才贡献质量；
- C军事夺取能力100分：只评价奠基人本人在创业战争中的统筹、实际指挥、胜绩与败责。

他人战果不进入C；奠基人本人亲自承担更多任务，也不再反向压低团队已经形成的B项贡献。具体合同与逐人依据分别见[A规则](../../分项规则/第一项创业与政权取得能力/战略决策能力/00-规则与计分合同.md)、[B规则](../../分项规则/第一项创业与政权取得能力/政治整合能力/00-规则与计分合同.md)和[C规则](../../分项规则/第一项创业与政权取得能力/军事夺取能力/00-规则与计分合同.md)。

## 三、主要结论

### 1. 第一梯队是三种不同的成功结构

刘秀以241.8分居首，优势来自A、B、C均无明显短板：低起点完成大规模复国，方面团队广泛独立交付，本人军事贡献也达到最高组。

李世民以239.7分列第二。A、C分别为96.6和96.5，体现其在唐初统一中的总体战略、战区统筹和前线高难解题；B为46.6，并不是秦王府人才弱，而是B只结算非本人团队。房玄龄、杜如晦、屈突通、尉迟敬德等仍形成高质量贡献，但李世民本人承担了大量不可转移的创业任务。

刘邦以230.9分列第三，并以B满分成为开国团队最高样本。萧何、韩信构成跨领域和战略征服支柱，张良、陈平又提供顶级谋划、外交和破局贡献。其A、C低于刘秀、李世民，主要来自具名战略误判和本人前线表现差异，而不是统一成果不足。

### 2. 刘裕、石勒、曹操等体现强团队与强军事的第二梯队

刘裕同时拥有刘穆之后方中枢和多名方面将领，本人C又达90.8，因此总分223.6。石勒依靠张宾的跨领域支柱和本人军事创业形成209.0。曹操B达57.0，但长期统一效率、赤壁误判及未闭合全国目标压低A、C，最终为203.2。

### 3. 高A、B而低C不等于创业失败

嬴政、杨坚、司马睿、李雄等人的C为0，表示当前合同没有把王翦、杨素、王导等人的独立成果算成奠基人本人军事贡献，并非否认其战略、组织或最终建国成绩。相应成果分别在A和B结算。李渊也呈现类似但不完全相同的结构：A82.6、B54.4而C36.4，说明唐初统一项目及团队很强，但本人实际军事贡献明显低于李世民。

### 4. 结果规模、本人作用和团队质量已经分开

本轮收口后，不再用同一套战役结果同时奖励总体战略、团队和本人指挥：王朝净控制、统一时间与稳固进入A；非本人成员的实际成果和人才贡献进入B；奠基人本人的创业战争作用进入C。三项可以形成不同人物画像，而不是把统一结果重复计算三遍。

## 四、当前状态与限制

- A、B、C均为当前唯一有效结算，旧B试算不再保留。
- 38名奠基者全部有确定结果，未决为0；57名非奠基者保持不适用，不以零分参排。
- C中5名史料链不足对象继续采用明确的0档保守默认；这是当前值，不伪装成已证明无贡献。
- B的人才贡献档只消费创业窗口内已形成的成果，不替代后续全生涯军事、治理、外交或谋略人才评价。
- 当前结果不写正式评分数据库，不形成跨七大项的皇帝总排名。
