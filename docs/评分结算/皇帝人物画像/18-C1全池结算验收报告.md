# C1“战略判断与风险控制”语义整改验收报告

## 结论

C1已在原正式结算基础上重新打开并完成语义整改。184人仍唯一覆盖，全部人物保留人工档位、`position`、雷达值、置信度与限制；`E0=0`、`UNRESOLVED_GAP=0`。本次没有把MI、成果规模、版图或其他分项档位转换为C1能力等级，而是先过本人战略选择、当时信息、可行替代、目标—资源—时序—风险、反馈、后续选择、结果验证与本人归责的构念准入门。

48名原高档及近高档候选全部重新建立人工诊断：正证另记`PS0—PS4`，负证另记`DW0—DW4`。MI继续只表示材料持续性；PS/DW也不是评分数组，不作数字相减。G4主体须PS3，G5须PS4，负证按全生涯分布影响档位与位置，不再以“阻断G5”作机械封顶。

## G5名单与横向锚

最终G5为：李世民、铁木真（HIGH）；刘邦、刘秀、朱元璋、玄烨（MID）；曹操（LOW）。

- `G5-HIGH`锚要求在创业、统一或守成等不同阶段与不同约束下反复兑现PS4，并且下沿仍可解释。李世民的高句丽DW2有撤军止损，严重度低于彭城、白登；铁木真的泛化治理反例因不闭合本人C1选择而退出。
- `G5-MID`锚以刘邦为有强恢复但存在两次DW3下沿的基准。刘秀保留度田DW2与尤来DW1；第三项中`ruler responsibility=NONE_CONFIRMED`的兵损不倒灌。朱元璋和玄烨在剔除跨轴错绑后，正向PS4覆盖仍足，但本人独占归责、自致风险和臣下份额不支持HIGH。
- `G5-LOW`仅保留曹操一人：迎帝、屯田和群雄分化达到PS4，同时宛城DW2与赤壁DW3分别闭合，严重下沿真实存在；LOW不是证据不足的暂存桶。

李世民“先取关中”按新旧唐书与资治通鉴归责差异标为`CONTESTED_OR_SHARED_ATTRIBUTION`，只作`PS1/BACKGROUND_VALIDATION`辅助正证，不写成本人独立制定，也不写成与本人无关，更不作为G5升降关键。

## 错绑证据整改

删除或降为背景的主要错绑包括：

- 玄烨撤藩—反叛的结果倒推，以及储位废复废、压制建言的C2/C3/C5倒灌；
- 朱元璋大狱、重典和报忧成本对C1位置的暗中扣减；
- 铁木真“花剌子模后有限退出”“中原治理承载不足”的无具体选择泛化反例；
- 杨坚把灭陈、长期承平、停赋等结果和长孙晟、高颎的设计直接换成本人PS4，以及无负父链却用继承和杨素监督压位；
- 李世民“长期维持谏议”和泛化晚期承载；先取关中则改为争议共享辅助证，而非独占主锚；
- 刘秀第三项中无本人致败归责的卢芳—匈奴、乌桓、武陵、羌乱等事件；这些逐项作为`DW0/BACKGROUND_VALIDATION`，不沉默倒灌；
- 司马昭的弑君高压、李纯的晚期近幸、朱祁钰储位风险等未闭合战略实际后果的跨轴材料。

刘邦的彭城、白登和曹操的宛城、赤壁已从“正负合成的一条MI4”中拆出独立负向父链。正证与反证分别记录PS/DW，恢复能力可保高档，但不抹去真实下沿。

## 直接过程定位清理

上一版共有1,664条`direct_process_refs`。整改后为1,230条，净清理434条；删除项主要是`POLICY_OR_EDICT`、`OFFICIAL_SUMMARY`、任期日期、`state_roles`、证据限制和宏观状态说明等伪直接来源。当前1,230条均满足以下至少一项：

1. 仓库中真实存在的文件及锚点；
2. 带卷次与原文锚点的史源定位；
3. 能在该父链所引来源中反查的稳定`material_id`。

formal verifier逐父链复查上述规则，当前真实可反查率为`1,230/1,230 = 100%`。MI3/MI4若没有合格直接过程定位将直接验收失败。

## 单父链合法特殊情况

当前高档中仍只有一条统摄父链、但满足“跨领域多阶段且四机制直接闭合”替代门的特殊情况共有6人：朱元璋、赵匡胤、杨行密、石勒、拓跋宏、钱镠。这里的“一条父链”不是一个周期：父链内声称的阶段均有真实`direct_process_refs`，能力剖面不再靠概括文本虚拆周期。其余一条父链而未满足该门者最高发布G3。

## 证据限制

- 低密度、短任和臣下主导人物仍给出正式档位，但限制写入`limitations`，不伪造负证。
- 多数古代事件只能重建可证替代，不外推不存在的现代方案；史源争议采用共享或争议归责。
- 结果只验证选择，国家资源、统一、版图和长期繁荣均不直接加档。
- PS/DW为人工诊断标签，只服务本轮语义审计；不得由程序、MI或档位反向生成。
