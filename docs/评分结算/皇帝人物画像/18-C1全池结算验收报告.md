# C1“战略判断与风险控制”全池结算验收报告

## 1. 验收结论

C1已按固定人物顺序完成人工裁决与结构重校：184人唯一覆盖，全部人物均有人工档位、`position`、雷达值、置信度和限制，`E0=0`，`UNRESOLVED_GAP=0`。结算表与阅读表均按雷达值降序、同值按`ruler_id`升序排列；C1不进入人物画像总分或综合总榜。

本轮没有用父链正负合成、最高MI或五项/M1/M2档位生成C1结论。MI只记录材料持续性；档位另按主要矛盾识别、目标—资源匹配、路径/时序组合、风险隔离与退出四个机制及决策机会厚度裁决。

## 2. 结构性重校

异议触发时，前135人暂定高档42人（G4 36、G5 6），其中27人仅一条父链，且6名G5全部为LOW。冻结后对全部42名初始高档候选逐人建立能力剖面，并在后49人中对新增高档候选同样建档。

- 前135人重校后高档由42人降至27人（G4 22、G5 5）。
- 15人降档：郭威、王建、耶律隆绪、朱棣、赵恒、萧绰、冯太后、刘渊、宇文邕、慕容德、李暠、苻健、马殷、朱祁钰、孟知祥。李昪经横向复核确认禅代、拒绝合取楚地和吴越火灾后克制为三个可区分周期，恢复为`G4-LOW`。
- 原6名`G5-LOW`全部重开：刘邦、刘秀改为`G5-MID`；玄烨、杨坚保留`G5-LOW`但新增核心机制下沿的专门理由；皇太极、石勒改为`G4-HIGH`。另因反证不得机械封顶，朱元璋、曹操进入`G5-LOW`；这四个LOW均有逐人理由，不作为证据不足的暂存桶。
- 全池最终高档33人；每人均通过“至少两个独立重大决策周期，或跨领域多阶段且四机制直接闭合”的G4门。G5另通过多领域、多阶段、不同约束和高难反例门。
- 48份能力剖面覆盖33名当前高档与15名降档对象，显式保存机会厚度、独立周期、难度、兑现、好牌低产、坏牌止损、跨领域与跨阶段稳定，并另存反例和晚期退化复核。

这次调整处理的主要倒挂不是人物名次，而是“材料强度高于能力厚度”的结构倒挂：MI4单链、正证加一条概括反证、长期结果概括均不再自动顶入G4/G5；创业、守成、好牌、坏牌、短任和臣子主导按同一能力门比较。

横向复核还重开了漏判门：李昪和窝阔台分别因三个可区分的军政周期进入`G4-LOW`；萧绰、宇文邕仍为`G3-HIGH`，因为有界回读后可直接归C1的材料仍主要闭合为澶渊一周期、灭齐换路一周期，长期治理、授权或军事执行分别留在C4、C5/M4和M1，不用其他轴成果补足C1决策厚度。

## 5. 玄烨多伦会盟整改

玄烨父链直接引用共用补证卡`C1-CHAIN-KANGXI-DOLON-1688-1697`：1688年喀尔喀危机后先赈抚接纳，1691年本人主持多伦会盟完成政治承认与旗盟安置，再于1696—1697年以军事行动收束噶尔丹威胁。C1只消费主要矛盾识别、政治整合优先、外交—行政—军事排序、缓冲结构与长期风险控制；喀尔喀对象的利益交换、依附和承诺仍由M2主计。

该链与雅克萨战谈、三藩及储位反例共同进入玄烨全生涯剖面。多伦链达到跨阶段MI3，但玄烨的`G5-MID`来自多个独立领域和约束下的能力分布，不由多伦会盟历史意义、最终疆域或单条MI强度直接生成。
