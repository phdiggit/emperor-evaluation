# C1“战略判断与风险控制”稳定单元与高档重裁验收报告

## 结论

C1已在正式结算基础上完成第二轮语义整改。184人唯一覆盖，全部人物保留人工档位、`position`、雷达值、置信度与限制；`E0=0`、`UNRESOLVED_GAP=0`。本轮直接修订结算表与阅读表、四态审计、48人能力剖面、合同、画像manifest与验证器，不以分布目标调档。

原审计中502个`M1_PARENT_PROJECTION #parent_id=MISSING`已全部删除。M1投影改从正式M1的`representative_parent_contexts[].parent_ref`、`diagnostic_context_refs`和`normative_entry_coverage.entries[].stable_parent_refs`取并集，按人物内真实稳定引用去重后逐单元四态处置。验证器现拒绝`MISSING`、空锚、悬空路径和锚值不存在的片段。

相对上一正式版，本轮发生4次降档、1次位置调整：

- 耶律大石：`G4-MID → G3-HIGH`。东征失败—停止东耗—西迁建基是一条恢复生命周期，失败不能充当第二个正向周期；正向只闭合PS2，东征另列DW2。
- 拓跋宏：`G4-LOW → G3-HIGH`。迁洛与配套改革是一条组合周期；扣除冯太后继承基础和财政专业设计后只闭合PS2，南征目标失稳另列DW2。
- 李雄：`G4-LOW → G3-HIGH`。成都建基是一条PS2；轻赋属于第二项，纳谏属于C2/C5，仇池覆败另列DW2。
- 钱镠：`G4-LOW → G3-HIGH`。长期奉正朔、联邻保境是一条PS2生命周期；筑塘兴城缺独立目标—资源—反馈过程，重敛与铅铁钱主路由第二项/M3并列DW0背景。
- 努尔哈赤：`G4-HIGH → G4-MID`。女真整合与蒙古联盟—转明形成PS3；宁远只闭合本人攻城、未克和撤围，战损、可行替代及后续调整不足，裁DW0背景，不因败果倒推负证。

李昪维持`G4-LOW`，但统一为两个独立周期：渐进禅代一项、两次拒绝扩张合并为同一守成克制周期；原“3个周期”表述已删除。

## 来源与限制

正式父链共有1,220条`direct_process_refs`，均通过文件、史源卷次锚或所引来源内稳定ID反查。MI3/MI4仍只表示材料持续性；国家资源、版图、统一结果、臣下独立设计与其他轴档位不转换C1能力。
