# M3 民生财政建设审查清单

> 用途：M3合同、上游同步、正式结算与逐人裁决的持续审查清单。后续同一问题或人物重审时直接覆盖旧结论，只保留最新有效意见；不记录过程流水账。

## 一、合同与规则

### P0｜DA定义表述需要重写

**现状问题**：当前合同把DA1—DA4过多写成“是否反复、反馈后是否继续”的行为形态，容易误导执行者把“单次行为”机械压在DA1。

**应改口径**：DA首先衡量**本人可选择性制造或放大的已实现额外成本量级**；行为是否反复、收到反馈后是否继续、是否跨阶段/跨通道，只用于判断归责强度、成本持续性与是否应进一步升级，不能替代成本量级本身。

建议重写为：
- `DA0`：无可归责额外成本，或仅必要防御/不可控外因；
- `DA1`：有限但明确的额外成本；典型包括一般大型营造、一次性非必要动员等，实际损害范围有限；
- `DA2`：显著额外成本；可由一次高成本行为直接达到，也可由多次中等成本累积达到；
- `DA3`：严重额外成本；一次超大规模行为若已形成广域、重度人员/财政/生产损害即可进入，不要求必须反复；多阶段、多通道持续加码是常见但非必要条件；
- `DA4`：罕见的系统性自造/放大崩溃，要求成本及后果接近全国性或系统性失能。

同时保留：同一后果若已被交班回落、K或可归责恶化充分消费，DA只结算未被吸收的剩余主动成本，禁止重复扣减。

### P1｜M3对“同档内结构建设”可能低估

M3当前第一判断轴高度依赖C1/C2/C3跨档恢复。对于高基准人物，如果重大财政/民生制度建设使系统从“同档下沿、结构失序”提升到“同档上沿、结构健康”，但绝对状态仍不跨档，恢复分可能记为0。

典型测试样本：胤禛。C2承认其清理亏空、耗羡归公、地方公费正规化，但C2仍为4→4，M3因此把财政建设贡献压成0恢复。

**待改方向**：考虑增加严格受限的“高基准同档结构建设”路线，只允许在上游已闭合重大结构性改善、本人贡献明确、且结果达到可验证稳定运行时使用；不得用政策名目、制度数量或历史名望直接制造建设信用。

### P1｜实现表现下限需硬化例外条件

当前“A4交班通常不得低于G3、A5通常不得低于G4”等使用“通常”表述，程序执行容易出现漂移。

建议改成：只有明确命中多轴严重净下降、`SEVERE_DECLINE+`、`DA4`或列明的其他硬例外时，才允许突破实现下限；否则必须保底。
