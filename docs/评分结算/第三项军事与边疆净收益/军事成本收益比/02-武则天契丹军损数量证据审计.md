# 武则天契丹军损数量证据审计

对象：`RULER-TANG-WUZETIAN`，`WZT-KHITAN`，696—700连续战争链。本文保留当前成本裁决所需的证据与排除理由；分值读取[正式D结算](01-皇帝D项正式结算.json)，数量规范见[高档与证据合同§5](../../../证据规则/军事成本高档与证据裁决合同.md#cost-evidence)。

## 数量与受损对象

| 来源 | 已证内容 | 可证明范围 |
|---|---|---|
| [《资治通鉴》卷206，697年三月](https://zh.wikisource.org/zh-hans/資治通鑑/卷206) | 总出征军额记十七万；随后转述王孝杰率精兵前锋、苏宏晖先退、孝杰战死及将士大量死亡 | 总军额与前锋受损范围并未明确等同；不能据此给出十万死亡下界 |
| [《新唐书》卷111，王孝杰传](https://zh.wikisource.org/w/index.php?title=新唐書/卷111&oldid=3517040) | 军额记十八万；前锋先出谷列阵，后军自行撤退而援兵不到，孝杰部溃败 | 后军存在且退出，不能把全军军额直接套作前锋死亡分母；十七万与十八万的异文不用于扩大下界 |
| [《旧唐书》卷93，王孝杰传](https://zh.wikisource.org/zh/舊唐書/卷93) | 总军额十八万；前锋出谷布阵、后军逃退，营中溃乱并有大量战死、践踏死亡 | 死亡类型比“败没”明确，但实际受损编组与十八万总额仍未等同，不能补足死亡分母 |
| [《资治通鉴》卷205，696年八月](https://zh.wikisource.org/zh-hans/資治通鑑/卷205) | 前批唐军弃步兵而以骑兵轻进，伏击中将卒大量死亡、将领被俘；后批受假牒诱骗而败没 | 两次重要编组严重毁损；死亡、被俘、溃散人数未拆清，不与697年按军额相加 |

三部697年叙事均提及张说奏报，不能当作三次独立死亡统计。这里否定的是“十万下界已经证明”，并未证明实际死亡必然少于十万，也未断言“将士”只能指前锋。

## 累计下界核对

| 战事或投入 | 死亡数可证明到哪里 | 能否补足十万下界 |
|---|---|---|
| 696年两次伏击 | 大量死亡及编组毁损明确，人数未知，另有被俘 | 与697年属于可累计连续链，但没有可相加的可靠数值下界 |
| 697年东硖石谷 | 前锋与实际参战部队重损，军额与死亡范围未闭合 | 不能给十万下界；也不能用696年不明人数补差 |
| 697年二十万军与供马 | 再动员、军用实物投入 | 不计死亡，重复征补也不自动证明上一批全死 |
| 684年平李敬业渡溪 | 五千先锋溺死过半，明确二千五百余军人死亡；叛军死亡排除 | 属独立内部战争，不直接并入契丹链 |
| 684—686年北边忻州败战 | 本方死五千余 | 属突厥方向；没有证明与十余年后的契丹链持续共享未恢复军力 |
| 687年爨宝璧远袭 | 一万三千精兵“全军皆没”，死亡、被俘与溃散未拆 | 不能把一万三千全记死亡；与契丹链亦未证连续承载 |
| 689年寅识迦河及696年素罗汗山 | 前者冻饿死亡甚众、后者大败，缺人数 | 严重成本事实可保留；不以定性词给足差额，不跨独立战区拼档 |

以上两项明确数字只提供七千五百余的已量化死亡子集，绝不是全任期实际死亡估计，也不是排除其他已发生死亡。即使暂不考虑跨链条件，当前已证数字加上未知项仍不能推出十万下界；若新增可靠数量材料，应另核归责、去重及连续关系后重审。依据另见[卷203北边与李敬业战事](../../../史料通读产物/唐以前编年/唐/卷203-通读总结.md)、[卷204突厥与吐蕃战事](../../../史料通读产物/唐以前编年/唐/卷204-通读总结.md)。

## 其他准入路径及档内位置

696—697连续链中，重要兵团相继败损，已达到C5兵团严重毁损结构。697年又组织大军、征用京官军马；武懿宗退军时大量弃置军资，后续仍有实际相持、夹击与邀截。连续毁损、再投入和资产损耗共同强化，按当前合同取C5高位。二十万为后续出征军额，不是死亡人数，也不把两轮军额相加为独立人数。

人员路径：前锋与后军实际规模、死亡与其他去向均有关键缺口，可靠十万死亡下界未证。696年的不明基数不能补足697年的不明分母。

核心能力路径：渔阳军震恐不进是方向受限事实；后军撤退不等于被消灭，唐军随后仍相持、夹击，700年又由降将平余党。现有证据未证明整个政权核心军事功能中断，或必须重大替代方能恢复。继续出兵不是抵消已证死亡，而是核对另一条准入路径。

C7：两路径均要求独立C6在先，本链未过此前提；后续夹击和余党平定也不证明灾后补充再次毁损并走向广泛耗竭。不能按败战次数或多个独立战区军额拼档。

证据状态为LOWER_BOUND：C5结构与高位强化成立，但死亡确数、全国军额和部分补充规模仍未知。该状态只指已经证明的C5，不代替更高档准入。

## 消费与关联复核

- D人物安全组合：既有E与EN终点不因死亡数量解释改变；两条EN2仍显著抵消区域正收益，C5高成本下保留D1低位的审计裁决。
- 第三项：普通成本按当前factor映射换分，与ML取高；ML0既有准入结论不因成本降低自动上调。第一项没有消费本链。
- 第二、第四项：平民屠掠、财政和文明后果各有独立对象；本次只修军损分母，不搬移其分数。
- 画像M1、C1：当前依据为强国资源下战略净轨迹退化、反复负回报与判断限制，没有以十万死亡阈值换档；维持现有裁决。
- 保留的编年与公共登记已同步标明数量缺口。旧P轴及死亡当量不用于重建当前D或第三项分数。

## 敏感性试点边界

“受损将士主要指前锋”和“可能覆盖更多参战部队但各部去向未明”均不能闭合十万下界；两种文本范围解释下，已证C5高位结构相同。将全军军额直接用作死亡分母的假设仅可作为被排除假设的影响诊断，不进入证据允许的名次范围。分析固定其他人物及未受影响裁决，不代表完整历史不确定性或置信区间。
