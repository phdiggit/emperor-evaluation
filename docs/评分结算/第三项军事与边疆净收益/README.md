# 军事与边疆正式资料

本目录保存第三项“军事与边疆净收益”的当前正式结算。规则合同统一位于[`docs/分项规则/第三项军事与边疆净收益`](../../分项规则/第三项军事与边疆净收益/README.md)，唐以前共享计分材料位于[`docs/史料通读产物/唐以前编年`](../../史料通读产物/唐以前编年/README.md)，五代十国、北宋与南宋材料分别位于`docs/史料通读产物/五代十国/资治通鉴/`、`docs/史料通读产物/北宋/续资治通鉴/`、`docs/史料通读产物/南宋/`；本目录不复制规则或史料事实。

当前已正式覆盖秦至唐95位、五代十国12位、北宋11位、南宋5位、元朝8位及明朝17位完整主政窗口对象的第三项A/B“国防安全”、C“军事体系有效性”与D“军事成本收益比”。140位已计分，16位经审计确认为D-N=0后以A/B/C实际得分进入总榜，8位因实质缺口保持D-U待定。全部记录均为可复核当前值，可随规则、史料与父级周期裁决更新，不设朝代保值例外。南宋将582个绑定周期先隔离创业链，再把415个准入主体阶段归并为198个D父周期；元朝588个原始周期排除248个第一项取得周期后归并为232个父周期；明朝743个准入周期经父战役去重后归并为670个父周期。公共登记只消费主体阶段的P/S/M/A/WC、SB/SN、BCP/BCN、WR和阶段回报；父卡指标不复制给主体，皇帝与摄政者采用互斥实际主政窗口。
