# 军事与边疆正式资料

本目录保存第三项“军事与边疆净收益”的当前正式结算。规则合同统一位于[`docs/分项规则/第三项军事与边疆净收益`](../../分项规则/第三项军事与边疆净收益/README.md)，唐以前共享计分材料位于[`docs/史料通读产物/唐以前编年`](../../史料通读产物/唐以前编年/README.md)，五代十国与北宋材料分别位于`docs/史料通读产物/五代十国/资治通鉴/`、`docs/史料通读产物/北宋/续资治通鉴/`；本目录不复制规则或史料事实。

当前已正式完成秦至唐95位、五代十国12位及北宋11位完整主政窗口对象的第三项A/B“国防安全”、C“军事体系有效性”与D“军事成本收益比”。全部记录均为可复核当前值，可随规则、史料与父级周期裁决更新，不设朝代保值例外。五代十国以卷263至294的521张战役裁决卡和两条定向终局补充为依据；北宋以卷001至097的716张战役裁决卡、1586个主体阶段为依据。公共登记只消费主体阶段的P/S/M/A/WC、SB/SN、BCP/BCN、WR和阶段回报；父卡指标不复制给主体，皇帝与摄政者采用互斥实际主政窗口。卷095按内禅段落锚切开赵佶、赵桓，靖康覆亡后的地方复国行动不倒灌赵桓。
