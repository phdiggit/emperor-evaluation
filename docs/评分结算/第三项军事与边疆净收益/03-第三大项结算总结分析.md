# 第三大项“军事与边疆净收益”结算总结分析

## 一、结算结论

第三大项已经完成秦至唐中期95位皇帝的正式结算。A战略安全收益80分、B边疆控制净收益80分、C军事体系有效性50分、D军事成本收益比40分均已有独立规则合同和皇帝级正式值，并已确定性合并为250分。

当前得分范围为6.3—246.4，平均116.4，中位数118.7。四分位点为79.2、118.7、157.1，说明结果没有集中挤在中档；安全控制建设、军事体系运行和成本收益失衡都能形成显著区分。

正式机器结果见[`02-第三项正式结算.json`](02-第三项正式结算.json)，按分排序和各轴档位见[`02-第三项正式结算.md`](02-第三项正式结算.md)。

### 1. 北朝呈现最高的群体性军事净收益

北朝总分均值149.4、中位数159.7，均居各多样本阶段首位，优势主要来自A、B、C同步偏高，而非单靠某一位皇帝抬升。北魏六人的连续样本说明，其高位具有跨任期延续性；西魏宇文泰、北周宇文邕也保持较强建设与体系兑现。高纬26.9则证明这一优势并非朝代标签加分，末期安全与体系崩溃仍会被结算到低位。

### 2. 唐的上限最高，但任期差异大于汉

唐的B均值50.9，仅次于北朝，反映大规模边疆控制和战略支点带来的群体优势；李世民246.4又把全样本上限显著推高。但唐代总分中位数只有115.7，低于均值124.2，说明均值受到李世民、李忱等高分样本明显拉升。李治、武则天、李隆基及中晚唐各任期在安全状态、体系可靠性和成本收益上分化较大，因此不能把唐初峰值直接外推为整个唐代的稳定水平。

唐代最低数值是李渊60.8，但这是统一战争隔离造成的特殊可比性边界，不能写成“李渊是唐代军事与边疆表现最差”。唐直到贞观二年灭梁师都才完成统一，李渊退位时创业战争尚未闭合，整个皇帝任期几乎都属于第一项消费的建国统一窗口；在这种边界下，他本来就很难产生可与后世守成皇帝比较的主动对外战役。其建国统一成果全部由第一项消费后，第三项只保留武德朝对东突厥较被动的外部安全状态：A仅1.6分，统一新增控制又不能进入B2、B4，故B只有9.2分；C的30分来自622—626年三组统一战争外的突厥入侵与边防任务，D的20分则是`D-U`未检验中性值。相较之下，李儇虽在A、C、D明显失效，仍因本任期可归责的边疆控制成果在B2、B4取得41.7分，最终65.1，仅比李渊高4.3分。两者的先后反映本项“排除统一收益、只结算非统一国防净结果”的结构，不是总体军事能力或亡国责任排序；若观察唐代已建立政权后的严重失控样本，应重点看李儇、李隆基等，而不是把李渊的数值最低直接作历史评价。

汉代21个样本的均值117.3、中位数117.9较接近，表现为较长时期的中高位连续性。刘询201.1居首，刘肇189.2、刘庄等也有高位支撑；但西汉末、东汉中后期和汉末崩解阶段把整体均值拉低。刘盈按前192年匈奴危机与前188年荥阳军队集结作一次小样本裁决，C项2/2/2、第三项70.9；该值只表示有限运行，不把无战事推定为正常，也不消费刘邦任期的平叛战果。与唐相比，汉的边疆控制规模均值较低，但样本跨度更长、极端高分依赖更弱。

### 3. 分裂时期必须区分控制结果与军事体系

十六国C均值28.8而B均值仅29.9，说明一些政权能够形成有效军队和较好的局部投入回报，却受制于控制范围、边界成熟度和政权持续性。李雄、赫连勃勃、沮渠蒙逊等高分个体不能代表整个阶段；冉闵等极低样本同样表明短期作战能力不能替代稳定安全秩序。

南朝总分均值88.1，主要短板是A、B均值分别只有18.1和23.3，而C均值26.5并未同比例坍塌。其典型结构是军队仍能完成若干任务，但北方战略压力、内部失控或控制范围收缩长期压低净结果。刘裕180.9是显著高峰，却不足以消除刘宋后期、梁末和陈末的低位样本。相对而言，汉末与三国的B均值50.6较高，曹魏多数任期和孙权等样本支撑了较成熟的分区防御体系；刘备短任期及蜀吴末期的较低结果使该组仍保持明显内部差异。

### 4. 秦、隋及单样本政权不宜作朝代能力判断

秦和隋都只有两名样本，且分别由嬴政与胡亥、杨坚与杨广构成近乎相反的极端结算。两组均值约86—90分，实际只是在数学上折中了“高位奠基”和“快速崩溃”，没有一个真实的中间型任期。两朝更有意义的结论不是均值高低，而是军事安全资产能否跨任期保持，以及继任者是否以高成本行动迅速耗尽既有体系。

新朝只有王莽一个样本，其10.7分反映该任期安全、控制和军事体系的全面崩解，不能进一步推导出朝代内部趋势。西魏、成汉等只有单一正式参评主体的政权同理：个体分可以参与皇帝横向比较，但不能被包装成稳定的朝代平均能力。

朝代横向表中的D均值还包含13个`D-U/20`未检验中性值，只可参与当前250分确定性合计，不能据此断言某一朝代的军事成本收益能力高于另一朝代。单样本政权和样本很少的阶段也只适合作个案描述；判断“朝代持续性”应优先看多任期中位数、内部离散和各轴结构，而不是只看最高分或算术平均。

## 五、交叉校准说明

### 1. 高成果不等于高效率

刘彻A/B/C合计155.4，但D仅11.8，最终167.2；宇文泰A/B/C合计157.7，D为19.6，最终177.3。两者证明D项确实能够识别“安全控制和体系成果很高，但投入昂贵或存在重大透支”的组合，而不是重复A、B、C给分。

### 2. 高效率不等于最高净结果

陈蒨D为34.6、拓跋珪D为34.5，但总分分别为160.9和160.4。两人的投入产出效率处于D4上部，却因安全起点终点、控制规模或体系总体结果没有达到最顶层，未被D单轴抬入总榜最前列。李雄D为33.0且总分174.0，体现相同原则。

### 3. 体系强不能掩盖安全失控

部分皇帝C仍处中档或中高档，但A、B很低，说明国家军队在若干任务上仍能运行，不等于整体安全秩序和边疆控制良好。吕光、萧绎、陈顼等样本因此不会只凭局部作战能力取得高总分。

### 4. 被动挨打和体系崩溃能够进入低位

杨广6.3、胡亥9.4、王莽10.7、冉闵13.8位于末端。低分并非由亡国标签自动生成，而是A/B安全控制归零或崩解、C体系失效以及D国家级负收益共同造成。高纬、陈叔宝等虽因D档含义不同略高，也仍被A/B/C多轴失效压在低位。

## 六、结果边界

- 创业、统一和兼并战争继续归第一项，不进入第三项A/B/D；第三项C只读取统一战争排除后的本项体系证据。
- A、B评价实际安全和控制净结果；C评价军事体系能否兑现、持续和重复运行；D评价全部纳入范围的军事投入是否值得。四者可以交叉验证，但不得互相替代。
- D-U固定20分是未检验中性值。正式JSON保留`D_score_status=IMPUTED_NEUTRAL_UNASSESSED`；它参与250分确定性合计，但不参加D项能力排序，也不能写成“成本收益能力中等”。
- 当前文件是Git中的正式当前值，`formal_score_write=false`、`database_write=false`仅表示尚未写入评分数据库或全项目总排名，不表示本项仍是试算草稿。

## 七、总体判断

第三大项已经能够独立覆盖总则所需的四个问题：国家是否变得更安全、边疆控制是否扩大并成熟、军事体系是否真实有效、以及为这些结果付出的代价是否值得。综合结果同时区分建设者与高位守成者、扩张者与修复者、有效但昂贵者、低投入高回报者，以及安全与体系共同崩溃者。

从宏观排序、相邻样本和ABC—D交叉检验看，目前没有发现需要重新划分A/B/C/D权重或第三项250分结构的系统性倒挂。后续工作应直接消费本目录的当前正式JSON，不再依赖`tmp/**`候选投影或运行报告。
