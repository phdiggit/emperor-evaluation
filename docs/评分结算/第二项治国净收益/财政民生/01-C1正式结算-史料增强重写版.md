## 0. 本版逐人条目固定结构

每人统一写明：

1. **正式结算**：`raw_state_band / formal_band / score / S0→S_main→S_end / peak / K`。
2. **治理复杂度**：说明 raw→formal 是否折算；复杂度不改变客观状态时间线。
3. **主态/峰值证据链**：优先保存能直接落到 C1 三轴的史料原文短摘，并明确轴归属。
4. **稳定性 / K 阶段审计**：逐段说明时窗、实际家庭结果、范围、持续、深度、是否计入 K。
5. **军事成本传导复核**：读取第三项军事成本档，但军事档本身不自动扣 C1；只消费已经闭合到家庭端的实际结果。
6. **交班与连续性**：说明 `S_end→下一任S0` 的锚点来源；继任初追述必须明确标注为反向交班证据，不伪装成本人任内当年材料。
7. **排除项与反证**：生产、市场、财政、治安等跨项材料只能作背景或互证，不能独立凑 C1 高档门。
8. **最终裁决**：说明为什么落在当前档/K，而不是相邻档。

# 第一批：高档人物与军事成本交叉复核

## 刘启（西汉景帝）

- **正式结算**：`raw_state_band=C1-5`；`formal_band=C1-5`；固定分 `74.3`；raw 曲线 `C1-5→C1-5→C1-5`；`K=K2`。
- **治理复杂度**：高复杂度大一统盘面，raw 5 通过复杂度认证，formal 不折算。

### 1. 主态结算依据

**核心轴：`HOUSEHOLD_SUBSISTENCE_SURPLUS`**

- 《汉书·食货志》回顾文景承平至武帝初，直接有“**民则人给家足**”。这不是府库、户口或单纯产量，而是普通家庭供给状态，能够作为景帝主态 5 的跨期宏观锚。
- 同段虽又记太仓、府库积储，但这些只属于财政/国家储备背景，不作为 C1-5 独立轴计数。

**连续性约束**

- 景帝 `S0=C1-5` 由文帝交班直接承接。文帝末《资治通鉴》有“**海内安宁，家给人足**”，因此景帝不是从低位重新恢复到 5，而是继承高位后总体维持。
- 武帝初的“人给家足”又从后端反向约束景帝 `S_end=C1-5`；不能因七国之乱本身把终点机械压低。

### 2. 稳定性 / K 阶段审计

#### 阶段 A：前154年七国之乱

- **实际结果**：《史记·吴王濞列传》记吴王在国内下令，年龄从十四岁至少延伸到六十二岁者“**皆发**”，并动员二十余万人。
- **责任边界**：这是吴王刘濞叛乱政权的征发，不是景帝中央直接下令。C1记录的是景帝统治期客观家庭状态，责任归属则在军事/政治责任项另行处理，两者不能混写。
- **家庭传导**：如此宽年龄层征发意味着吴地大量家庭劳力被短期抽离，叠加吴、楚、梁、赵等战区军事扰动，客观上形成一个明显低于全期 5 档常态的区域阶段。
- **范围 / 持续 / 深度**：范围超过单一县郡，但战争约数月；现有证据未闭合多个主要经济区长期出现普遍饥饿、卖产、流亡或家庭结构持续崩坏。
- **计入 K**：`counts_toward_k=true`，作为一个实质性区域低谷。

#### 阶段 B：后元二年歉收

- 《汉书·景帝纪》本人诏书承认“**今岁或不登，民食颇寡**”。这已经落到普通家庭食物可得性，不只是“发生旱灾”或“粮食减产”的生产标签。
- **范围 / 持续**：可定位的年度性低谷；现证不足证明多年持续。
- **计入 K**：`counts_toward_k=true`，与七国之乱属于不同因果链。

**K2 判定**：一个实质战争低谷 + 一个独立家庭食物低谷，明显高于 K3 的单一轻微波动；但尚未达到 K1 所要求的“次级主态竞争者”强度。低态没有同时满足长期持续、多个主要区域反复深跌等至少两项强条件。

### 3. 军事成本传导复核

- 第三项军事成本正式档：**C5**。
- C5 只触发 C1 负向扩搜，**不直接降低主态或 K**。
- 本条真正进入 C1 的战争后果仅是已经闭合的家庭端结果：吴地大年龄跨度征发、多个战区家庭劳力抽离与区域扰动。
- 七国之乱中的军队伤亡数字属于军事成本分母，不能把“死伤很多”直接换算成普通家庭 C1 跌档；除非另有家庭死亡、失业、流亡、卖产、缺食等闭环证据。

### 4. 排除项与反证

- “府库充实”“太仓陈陈相因”不作为 C1-5 独立高档轴。
- 七国之乱的政治严重性、军队伤亡、平乱功绩均不直接改变 C1；只消费家庭端已经实现的状态变化。

### 5. 最终裁决

**维持 `C1-5→5→5 / K2 / 74.3`。** 七国之乱足以否定 K3 式“仅轻波动”，但其持续时间和家庭后果覆盖不足以把景帝长期高位主态或交班终点压到 4，也不足 K1。

## 李世民（唐太宗）

- **正式结算**：`raw_state_band=C1-5`；`formal_band=C1-5`；固定分 `74.3`；raw 曲线 `C1-2→C1-5→C1-5`；`K=K2`。
- **治理复杂度**：高复杂度大一统盘面，raw 5 不折算。

### 1. 主态结算依据

**核心轴：`HOUSEHOLD_SUBSISTENCE_SURPLUS`**

- 《贞观政要·俭约》以二十年为跨度总结“**财帛富饶，无饥寒之弊**”。其中“无饥寒之弊”直接落到普通家庭基本生活与物质余量，不是单纯财政强盛。
- 贞观中期连续丰稔、流散者归乡及低粮价只能作为持续性互证；低价、产量、户口本身不独立承担 C1-5 高档门。

**起点与恢复**

- `S0=C1-2` 反映隋末唐初战乱后的低基线；从 2 向 5 的恢复过程按规则不计 K。
- 主态 5 由恢复完成后的长期家庭物质状态确认，而不是由“贞观之治”名望直接上推。

### 2. 稳定性 / K 阶段审计

#### 阶段 A：贞观二十二年剑南造船役

- **动员机制**：为后续辽东用兵造舟，朝廷令剑南发民造船，地方督迫加剧。
- **家庭资产结果**：《资治通鉴》直接记“**民至卖田宅、鬻子女不能供**”。这同时闭合可保留资产流失与家庭结构受损，属于强 C1 负证。
- **生活资料结果**：同段又记“**谷价踊贵，剑外骚然**”，说明重役与需求压力已经传导到家庭食物可得性和区域生活成本。
- **区域结果**：雅、邛、眉三州随后发生反抗，说明压力并非单一奏疏式风险预警；但反抗本身属于政治/治安后果，不单独计 C1。
- **范围 / 持续 / 深度**：家庭后果深，且不止一户一县；但空间仍主要闭合于剑南造船区，现证不足证明全国主要区域在649年交班前同步跌到 4。
- **计入 K**：`counts_toward_k=true`，作为一个实质区域低谷，强度超过 K3。

**K2 判定**：剑南阶段的卖产、鬻子与粮价上涨足够深，不能只记 K3；但缺少第二条同等级、跨主要区域长期反复的家庭低态，因此不升 K1。

### 3. 军事成本传导复核

- 第三项军事成本正式档：**C4**。
- 主要父链包括东突厥、吐谷浑、高昌、高句丽、薛延陀等。战争规模、军队伤亡、马匹损失、转输量本身只属于第三项军事成本。
- **唯一已充分闭合到 C1 的高强度军事传导链，是贞观二十二年剑南造船役。** 它已经在 K2 中消费，不得再以“征高丽成本高”重复压主态或终点。
- 高句丽亲征等若没有进一步闭合普通家庭卖产、缺食、流亡、死亡或长期劳力损失，只保留为负向复核背景。

### 4. 交班与连续性

- 旧稿将太宗末年多项军旅、营造压力合并外推为全国 `S_end=C1-4`，证据边界过宽。
- 现有强家庭负证只能把剑南识别为区域低谷，不能证明649年全国普遍降档；故 `S_end=C1-5`。
- 李治 `S0` 应与此连续，承接 `C1-5`。

### 5. 排除项与反证

- 不以“米价很低”单独证明 5 档；低价只作物质可得性互证。
- 不把征高丽、修宫室等成本规模直接换算为 C1 负档。
- 不把雅、邛、眉反抗本身重复当作家庭结果；C1 消费的是其前端已经实现的卖产、鬻子、粮价上涨。

### 6. 最终裁决

**维持 `C1-2→5→5 / K2 / 74.3`。** 剑南役证明贞观末并非“无裂缝稳定”，但其空间边界不足以推翻全国交班 5；旧 `S_end=4 / K0` 应维持台账已经作出的修正，不再恢复。

## 刘恒（西汉文帝）

- **正式结算**：`raw_state_band=C1-5`；`formal_band=C1-5`；固定分 `74.3`；raw 曲线 `C1-3→C1-5→C1-5`；`K=K2`。
- **治理复杂度**：高复杂度大一统盘面，raw 5 不折算。

### 1. 主态结算依据

**轴一：`NET_TAX_LABOR_BURDEN`**

- 《史记·律书》直接总结文帝时期“**百姓无内外之繇**”“**得息肩于田亩**”。这不是减税政策名义，而是对百姓实际徭役与劳动恢复状态的结果描述。

**轴二：`HOUSEHOLD_SUBSISTENCE_SURPLUS`**

- 同段紧接“**天下殷富**”，并以极低粟价作物质可得性互证。C1 只把“天下殷富”作为家庭/社会物质状态核心锚；低粮价不是独立高档轴。
- 文帝末《资治通鉴》进一步总结“**家给人足**”，构成交班终点的直接家庭结果锚。

以上已经满足 C1-5 所需的直接家庭余量核心证据，并有另一独立 C1 轴（实际徭役负担）闭合。

### 2. 稳定性 / K 阶段审计

#### 阶段 A：前168年前后《论贵粟疏》所见农户困境

- 晁错明确写到“**卖田宅、鬻子孙以偿责**”，并总结“**农人所以流亡者也**”。这些都是已经实现的家庭资产和家庭结构后果，不只是“建议重农”的政策论证。
- 同篇又直言“**农夫已贫贱矣**”，说明至少存在覆盖不小的农户群体低于全期 5 档主态。
- **证据降权**：该材料是奏疏，带有强化问题以推动政策的修辞目的，因此不能单独推翻《史记》《通鉴》对全任高位和交班高位的宏观总结。
- **范围 / 持续 / 深度**：问题并非单一户例，且家庭损害较深；但当前没有闭合为跨多个阶段、多个主要区域长期反复的次级主态。
- **计入 K**：`counts_toward_k=true`，判一个实质中期低谷。

**K2 判定**：深度高于 K3，但持续性/重复性不足 K1；终点重新回到 5，故绝非 K0。

### 3. 军事成本传导复核

- 第三项军事成本正式档：**C4**。
- 主要压力来自匈奴入侵下的防御动员及济北王叛乱的短时平乱。
- 文帝本人在《史记·律书》相关叙述中明确将“劳民不可烦”与不轻启外战相联系，但这是治理取向；C1 只看最终家庭结果。
- 当前父链没有闭合出比《论贵粟疏》更强的新广域家庭低态：没有足够证据证明这些防御/平乱动员进一步造成主要统治区长期卖产、饥饿、流亡或家庭劳力崩解。
- 因此 **C4 军事成本不追加 C1 扣档，也不另生成 K 阶段**。

### 4. 交班与连续性

- 文帝末“家给人足”直接支持 `S_end=C1-5`。
- 景帝继位 `S0=C1-5` 与之硬连续；无需人为制造交班跌档。

### 5. 排除项与反证

- 不以中央府库、仓储或国家财政宽裕证明 C1-5。
- 不把《论贵粟疏》整体标成“政策警告”而忽略其中卖产、鬻子、流亡等实际结果；也不反过来用一篇奏疏覆盖全任宏观高位。

### 6. 最终裁决

**维持 `C1-3→5→5 / K2 / 74.3`。** 文帝高档证据是本批最完整的纯 C1 双轴之一；中期农户困境足以形成实质裂缝，但不构成次级主态。

## 李隆基（唐玄宗）

- **正式结算**：`raw_state_band=C1-5`；`formal_band=C1-5`；固定分 `74.3`；raw 曲线 `C1-3→C1-5→C1-1`；`peak_band=C1-6`；`K=K0`。
- **治理复杂度**：高复杂度大一统盘面；raw 5/peak 6 均不因复杂度折算。

### 1. 主态与峰值结算依据

**C1-6 核心轴：`HOUSEHOLD_SUBSISTENCE_SURPLUS`**

- 元结《问进士》回顾开元天宝前期，直接称“**人家粮储，皆及数岁**”。这是普通家庭粮食储备的直接高位结果，比户口、税额、市场繁荣或“盛世”名号更符合 C1 高档门。
- 同文还以战后“衣食至难”反衬此前生活资料易得，能够约束峰值确实属于家庭端而非国家财政端。

**互证而非独立轴**

- 《通典·食货七》所见开元时期低米价、低绢价与长期供应充足，只作为物质可得性互证；价格和市场繁荣本身不独立凑 C1-6 三轴。
- “道路列肆”“远行不持寸刃”等分别属于市场/治安背景，全部退出 C1 高档门。

**峰值窗口**

- `peak=C1-6` 只允许落在开元后期至天宝前中期的有界窗口，不能外推覆盖天宝十三载以后。

### 2. 稳定性 / K 阶段审计

#### 阶段 A：天宝十三载以后军役—转输裂缝

- 《通典·食货七》记关辅、河南、京兆被征发者“**去者万不一全**”，又有“**连枷赴役**”。这已经不是单纯军费数字，而是大规模人身役使与家庭劳力抽离。
- 同段进一步记“**驴马车牛，悉被虏夺**”，且“不酬其直”。这直接闭合家庭生产/运输资产被无偿占用，属于 C1 的可保留资产与净负担结果。
- 店肆闭藏属于市场运行结果，主要归 C2；在 C1 中只作为生活资料供给链受扰的辅助背景，不独立计轴。
- **裁决作用**：上述材料足以证明极盛状态在安史之乱爆发前已经开始出现实质裂缝，因此 C1-6 峰值窗口必须在天宝十三载以后截断；但它发生在此前高峰之后，不能反向抹去早期 C1-6。

#### 阶段 B：安史之乱及其终局

- 安史战争造成的广泛饥饿、流亡和社会生活断裂已经由现行正式数据独立闭合 `S_end=C1-1`。
- 因 `S_end < raw S_main`，稳定性直接为 `K0`；无需再用“战争很多”或 C6 成本档重复解释。

### 3. 军事成本传导复核

- 第三项军事成本正式档：**C6**。
- C6 触发强化负向检索，但不自动把主态 5、峰值 6 或 K 下调。
- 本人窗口内已找到清晰的军事成本→家庭结果链：
  1. 大规模征发 → 家庭劳力抽离、去者大量不能全归；
  2. 强制赴役 → 人身役使加剧；
  3. 驴马车牛被夺且无补偿 → 家庭资产与生产能力直接受损；
  4. 店肆闭藏 → 市场供给同步恶化（主要归 C2）。
- 因此军事成本在 C1 中的正确作用是**截断峰值窗口并解释高态晚期裂缝**，而不是凭 C6 标签机械降低此前峰值。

### 4. 排除项与反证

- “海内富实”、人口/户数、太仓积储可作广域背景，但 C1-6 的核心必须由“人家粮储”这类家庭直接结果承担。
- 道路安全完全归 C3；市场繁荣主要归 C2；二者不再技术性凑满 C1-6 多轴门。

### 5. 最终裁决

**维持 `C1-3→5→1 / peak6 / K0 / 74.3`。** 新增军事成本细化不会降低开元—天宝前中期的真实峰值；它只把峰值终点明确截在天宝十三载以前后，避免把高位静态外推到晚期。

## 刘庄（东汉明帝）

- **正式结算**：`raw_state_band=C1-5`；`formal_band=C1-5`；固定分 `74.3`；raw 曲线 `C1-4→C1-5→C1-3`；`K=K0`；`persistence=REPEATED_PHASES_CONFIRMED`。
- **治理复杂度**：高复杂度大一统盘面，raw 5 不折算。

### 1. 主态结算依据

**核心轴：`HOUSEHOLD_SUBSISTENCE_SURPLUS`**

- 《资治通鉴》永平十二年总结“**百姓殷富**”，这是直接家庭/民间物质状态锚。
- 同段“岁比登稔”、低粟价、牛羊被野只作为供给与持续性互证，不分别充当新的 C1 高档轴。

**持续性**

- 《后汉书·明帝纪》永平九年“大有年”、十年继续丰收，可证明高位并非单一年份偶然峰值；但产量材料本身归生产侧，只用于确认“百姓殷富”并非孤证。

### 2. 稳定性 / K 与交班审计

#### 高位阶段

- 永平中期有直接“百姓殷富”锚，并有连续丰稔互证，足以使 `S_main=C1-5`，且 persistence 不是 `END_ONLY`。

#### 末期—交班低态：年代表达必须纠正

- 旧稿容易把“比年牛多疾疫，垦田减少，谷价颇贵，人以流亡”直接写成明帝本人任内材料。**这不严谨。**
- 该句见《后汉书·章帝纪》建初元年（76）诏书，属于继任初对“比年”状态的追述，应当标记为**反向交班锚**，而不是伪装成明帝在位某年的即时记载。
- 同一继任初记录明确承接了牛疫、田地减少、粮价上涨与人口流亡；其中“谷价颇贵、人以流亡”已经落到普通家庭生活与迁徙结果。
- 章帝即位的75年交班年度又见京师及三州大旱、牛疫等冲击。单纯“大旱/牛疫”不自动降 C1，但与76年“谷价颇贵、人以流亡”的已实现结果合读，可以反向确认明帝末—章帝初客观状态已明显低于永平中期 5 档。
- **交班约束**：因此刘庄 `S_end=C1-3` 与刘炟 `S0=C1-3` 连续成立。

**K0 判定**：raw 终点 3 明显低于 raw 主态 5，满足终局逆转定义，故 `K=K0`。

### 3. 军事成本传导复核

- 第三项军事成本正式档：**C4**。
- 主要军事实体包括北匈奴方向、羌事及永平末西域用兵。
- C4 只触发负向复核。现有材料没有闭合出一条比末期牛疫—旱灾—粮价—流亡链更强、且能独立再生成 K 阶段的普通家庭军事传导结果。
- 因此不把军队规模、边疆远征、驻军或财政耗费直接换算为 C1；末期失守已经由真实家庭结果反映在 `S_end=3 / K0`，避免双重扣减。

### 4. 排除项与反证

- 河汴治理、农业产量、户口增长只能作 C2/持续性互证；主 5 仍由“百姓殷富”承担。
- “天下安平”属于 C3/综合背景，不计入 C1 高档轴。
- 76年章帝诏不得在新稿中写成“明帝永平末诏”；必须保留其继任初追述身份。

### 5. 最终裁决

**维持 `C1-4→5→3 / K0 / 74.3`。** 本轮不改档，但修正证据时间归属：明帝末端 3 档由继任初对“比年”家庭状态的反向交班证据闭合，而不是伪造一条明帝本人当年材料。
