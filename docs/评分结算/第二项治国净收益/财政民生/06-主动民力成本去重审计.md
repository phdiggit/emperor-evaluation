# 主动民力成本去重审计

本表支撑当前C4正式逐人裁决。覆盖以当前正式入口实际记录为准；本次逐人核对现有正式证据、军事成本依据与C1—C3消费对象，不宣称穷尽全部历史文献。

## 结算口径

1. 第一、第三项保留客观军事成本；主动进攻与被动防御均计。
2. DA只取独立的主动民力负担。军资、军粮、军事运输和军队毁损不重复折成DA。
3. 独立对象不要求独立一句民困原文。已证主动动员可以推断家庭供役与生产机会负担；纯军事规模推断统一按保守下限，不因失载直接归零。
4. 主态、K或恶化已消费同一窗口和对象时，不再通过换成“主动投入”重扣。反之，低主态或存在K不构成已吸收的证明。
5. 直接证据的高档仍须有独立的剩余程度。工程名目、军事人数和文献数量均不能机械累计。

DA归零表示没有尚待本项另扣的对象，不表示没有军事成本、没有严重民困或本人没有责任。严重损害仍留在实际消费它的状态、K、恶化及军事项目中。
