# 李雄治理结果证据复核

本说明是李雄实际治理窗口内C1—C4及宁州B4的池外历史复核记录，曾用于同步M3引用；不按名望、疆域大小或预期排名反改分数。文中旧审计数值保留为证据背景，不是当前规范池的统一评分输入。

## 证据范围

重新阅读《华阳国志》卷九李雄段、《晋书》卷一百二十一李雄载记，并定位《资治通鉴》卷八十九的治世总评。近同的低赋、富实、闾门不闭记载按同一史源传统使用，不把三个书名算作三个独立时段。重点补查总评附近的财政、军纪、征服区和晚年反证。

- [《华阳国志》卷九（四库本）](https://zh.wikisource.org/wiki/華陽國志_(四庫全書本)/卷09)：治世总评之外，记货贿公行、惩劝不明及攻城以虏获为先；咸和八年至九年宁州段记初平后转凌掠民、建宁民反及牂柯转附晋。
- [《晋书》卷一百二十一](https://zh.wikisource.org/wiki/晉書/卷121)：明确记国用不足、诸将进金银珍宝得官，以及汉中、宁州、仇池诸战争；军事伤亡与军纪问题须按结果对象分别处理。
- [《资治通鉴》卷八十九](https://zh.wikisource.org/wiki/資治通鑑/卷089)：富实、稀役、复除、屡熟属于本人治理正证，不能因史料数量少而抹去。

## 当前裁决

| 组件 | 当前结果 | 复核理由 |

| C1 | 五档，历史低谷诊断，73.2 | 家庭余量与低赋役支持主要蜀地五档；李班在李雄在位时指出贫者无地种植，已涉及家庭生计。采纳不等于已纠正；反证限于贫者群体，未证广域长期跌档或末期逆转，保守裁一个范围有界的历史低谷诊断，置信度中。 |

| C3 | 五档，历史低谷诊断，49.9 | 基层财产安全与司法约束支持主要蜀地高主态；晚年宁州侵掠及叛离构成恢复后一个实质区域低谷，撤销原历史诊断标签。 |

C3终点五档是对主要治理核心的有范围限制的延续判断，不声称新占宁州同步达到五档。晚年区域低谷未证取代全任主要状态，也未证形成全政权末期逆转，因此保留为历史低谷诊断，不把全政权终点直接降档。身后李班、李期内争及李寿时期饥疫不倒算李雄。

C1—C4合计160.5；治理手段99.4、交接8.0，第二项267.9。贫者生计低谷由C1历史低谷诊断记录，不凭同条材料追加DA。

## 土地、宁州与恢复基线裁决

《晋书·卷121·李班载记》把贵者占荒田、贫者无地种植及李雄采纳进言置于李雄在位期，不是继任者结果。“雄纳之”未证明分田执行和家庭生计恢复；缺少确切年、覆盖比例和持续时间，不扩大为多数家庭整体困顿，也不假称已有纠正。

《华阳国志》记333年宁州侵掠、民反及牂柯转晋后，又记李寿平定；334年春分置宁交二州、任霍彪与爨深，李寿三月还、李雄六月卒。因此不能认定交班完全失控，但设置长官也不独证全部主要控制成果常态运行。第三项B4定三档中位67%：涪城常态控制与南中平叛后重整并存；不以核心地区成熟代替南中运行。军事控制恢复不抵销C3居民安全低谷。

《通鉴》卷85记李雄参与集团战争，不能称为无关破坏的纯接盘者；但大范围逃散、城邑空虚在李流时期已出现，不能把李特、李流和晋军损害全部归李雄。本次未闭合可单列的本人直接重大民生致损及可比前置高基线，不触发自造低点扣除或机械减半，恢复实施归责保留FULL。前置状态不明的50%规则须先通过本人直接重大致损门，不能由一般参战自行触发。

当前三轴恢复为1→5、2→3、1→5，档界信用3.7、0.8、3.7，加权3.12，恢复31.2封顶27；C1内部恢复路径同步为五档，不以残留四档路径反改正确主态。

补充史源：[《晋书》卷121李班段](https://zh.wikisource.org/wiki/晉書/卷121#李班)、[《晋书》卷120](https://zh.wikisource.org/wiki/晉書/卷120)、[《通鉴》卷85](https://zh.wikisource.org/wiki/資治通鑑/卷085)、[《通鉴》卷95](https://zh.wikisource.org/wiki/資治通鑑/卷095)。卷120明确成都纵兵大掠者为李特，不能移作李雄入城后的行为。

## 可见性与小政权边界

小政权不折分是当前结果合同的明文规则。真正应控制的是证据外推：主态、末态、低谷修正、恢复和DA分别论证，不能用一句治世总评包办全任、全域、全轴。此次新增的有效反证落在C3；未证明的C1/C2跌档不强行补造。

主动动员有实质民力传导时，即使没有民困专句，也使用与其他人物相同的保守推断门。保底不表示真实损害轻微；更高档须有剩余民力负担本身的程度证据。旧理由“整体治理高位限制DA3”不再使用，高状态不能自动抵销主动成本。

本次扩搜是定向史源验证，不是所有成汉史料的穷尽检索。高位终点的精确年度覆盖仍有限；当前将此限制明确写入裁决及置信度，而不制造缺证惩罚或史料沉默红利。
