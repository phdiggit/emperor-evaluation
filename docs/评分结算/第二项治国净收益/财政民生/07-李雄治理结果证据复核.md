# 李雄治理结果证据复核

本说明支撑当前逐人裁决。范围是李雄实际治理窗口内C1—C4，另按统一口径同步M3；不按名望、疆域大小或预期排名反改分数。

## 证据范围

重新阅读《华阳国志》卷九李雄段、《晋书》卷一百二十一李雄载记，并定位《资治通鉴》卷八十九的治世总评。近同的低赋、富实、闾门不闭记载按同一史源传统使用，不把三个书名算作三个独立时段。重点补查总评附近的财政、军纪、征服区和晚年反证。

- [《华阳国志》卷九（四库本）](https://zh.wikisource.org/wiki/華陽國志_(四庫全書本)/卷09)：治世总评之外，记货贿公行、惩劝不明及攻城以虏获为先；咸和八年至九年宁州段记初平后转凌掠民、建宁民反及牂柯转附晋。
- [《晋书》卷一百二十一](https://zh.wikisource.org/wiki/晉書/卷121)：明确记国用不足、诸将进金银珍宝得官，以及汉中、宁州、仇池诸战争；军事伤亡与军纪问题须按结果对象分别处理。
- [《资治通鉴》卷八十九](https://zh.wikisource.org/wiki/資治通鑑/卷089)：富实、稀役、复除、屡熟属于本人治理正证，不能因史料数量少而抹去。

## 当前裁决

| 组件 | 当前结果 | 复核理由 |
|---|---|---|
| C1 | 五档，K4，74.3 | 家庭余量与低赋役有直接结果；跨年丰收互证持续。宁州反证尚不能外推为四川核心家庭普遍跌档。置信度改为中，不把K4解释为全任无负担。 |
| C2 | 三档，K4，14.9 | 公共财政未闭合健康；国用不足与以财得官进一步支持瓶颈约束。不能仅凭官无秩禄再推全面失灵，也不能把低赋自动当财政健康。 |
| C3 | 五档，K2，49.9 | 基层财产安全与司法约束支持主要蜀地高主态；晚年宁州侵掠及叛离构成恢复后一个实质区域低谷，撤销K4。 |
| C4 | 恢复27.0－恶化0.0－DA1的4.5＝22.5 | 高位恢复仍成立；主动远征仅保留独立家庭供役的推断下限，军队损失不重复转分。宁州侵掠已交C3，不再用它叠加DA。 |

C3终点五档是对主要治理核心的有范围限制的延续判断，不声称新占宁州同步达到五档。晚年区域低谷未证取代全任主要状态，也未证形成全政权末期逆转，因此用K2而非把全政权终点直接降档。身后李班、李期内争及李寿时期饥疫不倒算李雄。

C1—C4合计为161.6。与复核前相比，C3减少2.1，DA按全池统一规则减少扣分4.5，净增加2.4。这两项方向相反，各自依规则结算；不能为了让复核“必须降总分”而保留重复成本。

## 可见性与小政权边界

小政权不折分是当前结果合同的明文规则。真正应控制的是证据外推：主态、末态、K、恢复和DA分别论证，不能用一句治世总评包办全任、全域、全轴。此次新增的有效反证落在C3；未证明的C1/C2跌档不强行补造。

主动动员有实质民力传导时，即使没有民困专句，也使用与其他人物相同的保守推断门。保底不表示真实损害轻微；更高档须有剩余民力负担本身的程度证据。旧理由“整体治理高位限制DA3”不再使用，高状态不能自动抵销主动成本。

本次扩搜是定向史源验证，不是所有成汉史料的穷尽检索。高位终点的精确年度覆盖仍有限；当前将此限制明确写入裁决及置信度，而不制造缺证惩罚或史料沉默红利。
