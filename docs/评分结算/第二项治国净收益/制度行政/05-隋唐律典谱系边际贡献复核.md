# 隋唐律典谱系边际贡献复核

本裁决支撑[制度节点链](../../../公共成果/制度行政/03-重要制度发展节点链.json)与[A正式方向卡](01-A制度建设与实际运行方向卡.json)。按[合同§3](../../../分项规则/第二项治国净收益/制度行政/00-规则与计分合同.md)区分新增核心规则、任内运行与后继接收，不以同谱系节点数量限制S，也不把整套唐律的后世影响分别归给每次编修。

## 当前裁决

| 节点 | 认领的边际贡献 | 裁决与证据边界 |

## 关键原文与限制

- [《五代会要》卷十，天成二年奏敕](../../../公共成果/法律/回源资料/跨朝制度史补充通读/source-texts/五代會要-卷十.txt)：贞观京师五覆奏、外州三覆奏，经建中调整；后唐奏称近年废弛，实际请求京师决前、决日各一覆奏并获准。引用旧法、调整恢复与原制连续稳定运行须区分；据此撤去当前证据未充分支持的最高溢价，不断言贞观制度没有深远影响。
- [《文献通考》卷166，后梁开平四年及后周显德四、五年条](../../../公共成果/法律/回源资料/跨朝制度史补充通读/source-texts/文獻通考%20(四庫全書本)-卷166.txt)：律疏三十卷进入颁行、折狱与通行法源，证明实用接收。该组证据限定于所载时期和解释功能，不补造宋元明清原样适用链，也不将相邻王朝数量机械折算为S++。
- [《隋书》卷25](../../../公共成果/法律/回源资料/历代刑法志通读/source-texts/隋書__卷25.txt)：开皇删减刑条和实际运行补入原建制材料；其同卷所载梁代整理前代注律等事实，亦排除“永徽首创国家法律解释”的说法。
