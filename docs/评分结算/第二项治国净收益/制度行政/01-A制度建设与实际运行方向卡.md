# A制度建设与实际运行方向卡

## 一、方向卡结论

A已完成159人方向卡裁决，最高内部指数为刘彻 98.5，平均45.9，中位数47.5，范围2.0—98.5。

> A使用100刻度内部指数，不是第二项独立分值；正式结果只在治理手段165分中与B1互补合成。

## 二、评价边界

评价国家级制度建设、任内运行及后来对同一核心接口的实际接收；普通行政成绩归B1，长期接收不进入D1。

主档由事实语义与高档门槛决定；材料数量不直接换分。

G5头部横向校准对象为刘彻、杨坚、嬴政、忽必烈：共同要求跨领域制度骨架、任内实际运行和后继接收同时闭合；档内次序再比较骨架深度、重大非骨架建设及独立运行增量，不按材料条数换分。唐代法制链中，开皇律是近端底本，贞观律完成实体规范重构并成为后世唐律核心，永徽律疏完成解释与适用定型。
