# A、B1、B2与C3构念边界复核

本审计支撑当前构念归属裁决；分数、档位与完整史源仍以各轴正式JSON为准。合同唯一规则见[制度行政合同§2.1](../../../分项规则/第二项治国净收益/制度行政/00-规则与计分合同.md#21-最小结算单元机制链)。

## 覆盖与方法

全池筛查覆盖A/B1/B2各185条现存方向卡及C3的195条记录，包含当前规范池全部184人；制度行政未结算的10人只检查既有C3，不补造方向卡。共同材料及B1边界关键词产生122名候选；共同来源不是重复计分的判定依据。另检查A的运行替代建设、B2的普通司法/行政替代反馈、C3的政策与政治个案外推。
构念整改涉及A 3人、B1 49人、B2 11人；其中23处B1主档门禁继续扩搜并已完成下述裁决。C3阶段状态与低谷未改；朱温C5因越窗材料和强度外推另作局部改判。该复核是构念边界验收，不替代全池全部史实重新回源。

制度行政待结算：拓跋弘、李乾顺、李仁孝、李元昊、李安全、李德旺、李德明、李秉常、李谅祚、载湉。

## 主要裁决

- A只计制度结构：完颜亶、完颜璟的妄杀/惩报忧退出A；萧绰的共同议政退出额外建设链。司法改革等原有制度节点保留。
- B1只计组织运行：建制、纳谏、民生安全结果以及没有组织后果的人员受害退出独立链；同一次程序损害与受害恐惧不再凑成cross。
- B2只计真实反馈、纠错与约束：普通刑罚、财政供养和概括行政衰败退出；没有因反馈受罚不等于一概排除，另有具体失真或复核受阻仍可计入。
- C3只计居民安全结果：已有直接结果、阶段及范围限定继续有效。政治个案可以证明该对象受害或局部裂缝，但不能只凭A/B1/B2负链把主态下调。
