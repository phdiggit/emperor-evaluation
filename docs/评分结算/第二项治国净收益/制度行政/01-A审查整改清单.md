## 一、总原则（锁定）

1. A评价制度**净贡献**，不评价动作大小、改革声势、制度数量或抽象创新能力。
2. 正向制度与负向制度同时计算；不得因“建设很多”获得保底高档。
3. 只看实际运行、收益、代价和后果；纸面创设、未运行尝试不产生正收益。
4. 同一制度生命周期先合并正负事实，再形成唯一裁决；不得材料堆分、同机制重复计分。
5. 一个可独立运行、可独立接收的核心制度接口才是一个节点；人物级政策包不得直接成为节点。
6. 不因历史名望或人物姓名设置特例。
7. **锁定裁决：朱元璋“宫妃殉葬成为宫廷继承礼制并延续”固定普通S−、权重1。性质极恶劣，但直接制度覆盖范围有限，不使用S−−/权重2。**

## 二、A新净账与position影子规则（整改主干）

### 2.1 mixed强制裁决

`mixed`只表示**同一生命周期正负实质相抵**，不能表示“复杂”“短命”“证据没判完”。

同一生命周期分别记录：

- `benefit_effect_level`: 0—3
- `harm_effect_level`: 0—3

每侧只取最高闭合层级，不按材料数量累计。

`effect_delta = benefit_effect_level - harm_effect_level`

| delta | direction | factor |
|---:|---|---:|
| ≥ +2 | positive | +1 |
| +1 | mixed_positive | +0.5 |
| 0且双方>0 | mixed / balanced | 0 |
| -1 | mixed_negative | -0.5 |
| ≤ -2 | negative | -1 |
| 双方0 | 不构成A计分节点 | — |

M只管覆盖/运行闭合：`M0=0，M2=1，M3=2`。

`signed_weight = M_base × direction_factor`

撤回、短命优先影响`result_closure / reception_scope / S资格`，不能自动把direction写成mixed；只有撤回本身造成同尺度内生制度损害时才进入harm。

### 2.2 废除无符号C_A计分

建议正式主干：

`nonS_net_weight = Σ(去重后的非S signed_weight)`

`A_net_units = 2 × S_net + S_plus_plus + nonS_net_weight`

解释：

- 普通S+ = +2
- 普通S− = -2
- S++在普通S基础上再+1深度
- 非S按真实signed M直接进入同一本净账
- `C_A`最多保留为`C_A_raw`审计字段，**不再参与grade和position**

### 2.3 主档门

- **G0**：`A_net_units <= 0`，或没有任何真实正净贡献。
- **G1**：`A_net_units = 0.5`；典型为已经实际运行但仅偏正的有限M2。纯M0不加分。
- **G2**：`1 <= A_net_units < 2`。
- **G3**：`A_net_units >= 2`但未通过G4/G5；非S路线至少一条positive M3，或两条独立positive M2。
- **G4**：至少一条合格R3正向S，且**`A_net_units >= 2`**。
- **G5**：原结构门继续保留，同时新增**`A_net_units >= 6`**。即：①至少3条独立正S且覆盖≥2领域；或②至少2条独立S++重定两个核心接口；并且完整净账至少6。

`S_net<0`只表示耐久骨架净负：无条件禁止G4/G5，但**不再自动生成/封顶G2**。低档统一由`A_net_units`决定。

### 2.4 position影子锚点

position不再把非S M统一除以4。当前审查阶段先用净值余量直接裁决：

**G0：**

- upper：0
- middle-upper：-0.5
- middle：-1
- lower-middle：-1.5
- lower：≤-2

**G2：**

- lower：净值刚到1
- middle：约1.25
- middle-upper：约1.5
- upper：接近2但未达G3结构门

**G3：**以2为主档最低净值，按完整净余和独立结构质量分position；不得用C_A厚度。

**G4：**

- lower：2
- lower-middle：约2.5
- middle：约3
- middle-upper：约4
- upper：≥5

**G5：**

- lower：6
- lower-middle：约7
- middle：约8
- middle-upper：约9
- upper：≥10

另外保留`signed S_operation_bonus`做二级校准：S节点M2/M3不能在过S门后完全消失；M3正S应略优于M2正S，M3负S同理反向。
