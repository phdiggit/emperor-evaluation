## 一、总原则（锁定）

- A评价制度净贡献，不评价“动作大小”“改革声势”或抽象创新能力。
- 正向制度与负向制度必须同时计入；不得因为建设厚度高而获得保底高档。
- 只看实际运行、收益、代价和后果；面子工程、纸面创设、未运行改革不得抬档。
- 同一制度生命周期必须先合并正负事实，再形成唯一裁决；不得正负双计、材料条数堆分或同一机制重复计分。
- 本轮不因历史名望或直觉反差对任何人物设特例。
- **锁定裁决：朱元璋“宫妃殉葬成为宫廷继承礼制并延续”固定为普通S−、权重1。性质极恶劣，但影响范围有限，不使用S−−/权重2。**

## 三、P0：规则净值与mixed解决方案

### [ ] A-RULE-000：mixed不再是模糊口袋；用正负effect强制裁决

真正正负实质相抵的balanced mixed仍应计0；问题是当前mixed混入“没判完、短命、结构复杂、正向主导但有代价”等状态。正式数据不允许“净方向未闭合”作为最终标签。

**M与方向分工**：M只管覆盖/持续/闭合；方向比较同一生命周期内A项内生收益与A项内生损害。跨项后果不重复塞A。

同一生命周期分别给`benefit_effect_level`与`harm_effect_level`：

| effect_level | 边界 |
|---:|---|
| 0 | 未观察到该侧实际效果 |
| 1 | 已有实际效果，但较弱/局部/次级 |
| 2 | 明确实质的有限接口效果，约M2尺度 |
| 3 | 系统性、广域、多年或核心接口重大效果，约M3尺度 |

每侧只取最高闭合层级，不按材料条数累计。

`effect_delta = benefit_effect_level - harm_effect_level`

| delta | 最终方向 | factor |
|---:|---|---:|
| ≥+2 | positive | +1 |
| +1 | mixed_positive | +0.5 |
| 0且双方>0 | mixed/balanced | 0 |
| −1 | mixed_negative | −0.5 |
| ≤−2 | negative | −1 |
| 双方0 | 不构成A计分节点 | — |

撤回/短命首先影响`result_closure/reception_scope/S资格`，不能自动变mixed；只有撤回造成同尺度实际制度损害才进harm。

signed M继续简洁计：M0=0、M2=1、M3=2；`signed_weight=M_base×factor`。

### [ ] A-RULE-005：废除无符号C_A计分，统一用A_net_units做净账

**核心公式（建议作为新主干）**

`nonS_net_weight = Σ(去重后的非S signed_weight)`

`A_net_units = 2 × S_net + S_plus_plus + nonS_net_weight`

解释：普通S+/S−各贡献±2；S++因跨朝深度在普通S基础上再+1；非S M2/M3按±0.5/±1/±2实际净值直接进入同一本账。

`C_A`可保留为`C_A_raw`节点完成度审计字段，但**不得再参与主档或position**。

**低档建议门禁**

- G0：`A_net_units <= 0`且未通过更高正向S门；表示无净正贡献或总体偏负。
- G1：`A_net_units = 0.5`，典型为实际运行的mixed_positive M2；不奖励M0。
- G2：`1 <= A_net_units < 2`。
- G3：`A_net_units >= 2`但未通过G4/G5；非S路线需至少一条positive M3，或至少两条独立positive M2真实组合。balanced mixed和同生命周期拆分不得凑档。

这可自然取消赵昀人名例外，也会纠正“正负抵消仍凭动作保G3”。
