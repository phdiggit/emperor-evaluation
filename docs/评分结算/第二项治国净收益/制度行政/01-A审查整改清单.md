## 一、总原则（锁定）

- A评价制度净贡献，不评价“动作大小”“改革声势”或抽象创新能力。
- 正向制度与负向制度必须同时计入；不得因为建设厚度高而获得保底高档。
- 只看实际运行、收益、代价和后果；面子工程、纸面创设、未运行改革不得抬档。
- 同一制度生命周期必须先合并正负事实，再形成唯一裁决；不得正负双计、材料条数堆分或同一机制重复计分。
- 本轮不因历史名望或直觉反差对任何人物设特例。
- **锁定裁决：朱元璋“宫妃殉葬成为宫廷继承礼制并延续”固定为普通S−、权重1。性质极恶劣，但影响范围有限，不使用S−−/权重2。**

## 三、P0：必须先修的规则净值问题

### [ ] A-RULE-000：重构mixed为“收益—代价双边强制裁决”，并取消无符号C_A保底

**核心判断**

`mixed=0`本身不是根本问题。真正的问题是当前`mixed`同时承载了“正负实质相抵”“净方向尚未判断”“短期改革后来被撤回”“结构复杂”等不同语义，然后又被无符号`C_A`抬到G2/G3。

本轮改为：**正式数据里不允许“净方向未闭合”作为最终方向标签。每条生命周期必须按实际收益和实际代价强制裁决。**

**强制裁决算法**

同一制度生命周期分别计算：

- `benefit_level`：该核心制度接口相对问题基线产生的、已观察到的A项内生收益强度；无闭合收益=0，M2级有限收益=1，M3级系统/广域收益=2。
- `harm_level`：该核心制度接口自身带来的、已观察到的A项内生制度损害强度；无闭合损害=0，M2级有限损害=1，M3级系统/广域损害=2。

每一侧只取同一生命周期中**最高闭合强度**，不按材料条数或同质后果累计。跨项财政民生、战争成本、D1交班等不进入这里，只在对应分项结算。

`net_direction = benefit_level - harm_level`

| 净差 | 最终方向 | direction_factor |
|---:|---|---:|
| +2 | positive | +1.0 |
| +1 | mixed_positive | +0.5 |
| 0且双方均>0 | mixed / balanced | 0 |
| -1 | mixed_negative | -0.5 |
| -2 | negative | -1.0 |
| 0且双方均=0 | 不构成A计分节点 | — |

**关键边界**

1. “制度后来被撤回/短命”首先影响`result_closure / reception_scope / S资格`，**不能自动把方向改成mixed**。只有撤回过程本身闭合了同尺度制度损害，才进入`harm_level`。
2. “没有证明净收益”不等于mixed。未证明收益则benefit=0；未证明损害则harm=0；两边都没有则该节点不产生A计分。
3. 真正balanced mixed仍然计0，这是净收益原则的必然结果；但它必须是收益与代价同尺度相抵后算出的0。
4. 所有现有`mixed`、`mixed_balanced`、以“迅速反转/复杂/净方向未闭合”为理由的节点全部重裁。

**C_A同步整改**

当前`C_A`是方向无关的建设完成度奖励，必须退出直接保底逻辑。可保留`C_A_raw`作结构审计，但正式结算改用方向敏感的`C_A_effective`：

- raw=2：positive→2；mixed_positive→1；mixed/mixed_negative/negative→0。
- raw=1：positive→1；mixed_positive→0.5；mixed/mixed_negative/negative→0。
- raw=0.5（M0/未完成尝试）：统一→0，不产生正向主档收益。

对应主档最低配置建议：

- G1：至少一条**实际运行**的mixed_positive M2有限净正向接口；不再奖励纯M0纸面动作。
- G2：至少一条positive M2，或一条mixed_positive M3。
- G3：至少一条positive M3的非S重大建设/重建/定型/文明纠偏；多个独立positive M2形成组合是否可G3，另按覆盖规则审，不允许mixed_positive靠数量堆G3。
- true mixed/balanced不得提供正向主档保底；mixed_negative/negative只产生负向影响。

**已确认需重裁样本**

- 宇文邕：“军士身份与军籍重构”底层材料写`mixed_balanced`，同时又写“净方向未闭合”；应按收益M?/代价M?重新强裁，不能直接凭改革规模拿G3。
- 海山：“武宗改制及迅速反转”当前03定为mixed，但A profile又写positive M3；“迅速反转”本身更接近耐久性失败，不应自动变成负向，需要拆开方向与R值重裁。
