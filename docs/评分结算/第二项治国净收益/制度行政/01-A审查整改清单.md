## 一、总原则（锁定）

1. A评价制度**净贡献**，不评价动作大小、改革声势、制度数量或抽象创新能力。
2. 正向制度与负向制度同时计算；不得因“建设很多”获得保底高档。
3. 只看实际运行、收益、代价和后果；纸面创设、未运行尝试不产生正收益。
4. 同一制度生命周期先合并正负事实，再形成唯一裁决；不得材料堆分、同机制重复计分。
5. 一个可独立运行、可独立接收的核心制度接口才是一个节点；人物级政策包不得直接成为节点。
6. 不因历史名望或人物姓名设置特例。
7. **朱元璋宫妃殉葬固定普通S−、权重1。** 性质极恶劣，但直接制度覆盖范围有限，不使用S−−/权重2。
8. A不做“制度史大全”。能否改变grade/position是继续补搜的唯一理由；粮长、一般条令、普通修订等次级机制原则上不为单个人无限扩搜。

## 三、A净账V2：M运行值 + S耐久溢价

> **本节替代此前 `2×S_net + S_plus_plus + nonS_net_weight` 公式。此前基于V1公式得出的批量影子改档全部撤销锁定，必须按V2重算。**

### 3.1 mixed强制裁决

`mixed`只表示同一生命周期正负实质相抵，不能表示“复杂”“短命”“没判完”。

- `benefit_effect_level`: 0—3
- `harm_effect_level`: 0—3
- 每侧只取最高闭合层级，不按材料数量累计。

`effect_delta = benefit - harm`

| delta | direction | factor |
|---:|---|---:|
| ≥+2 | positive | +1 |
| +1 | mixed_positive | +0.5 |
| 0且双方>0 | mixed/balanced | 0 |
| -1 | mixed_negative | -0.5 |
| ≤-2 | negative | -1 |
| 双方0 | 不构成A计分节点 | — |

M只管本人任内实际运行/覆盖：`M0=0，M2=1，M3=2`。

### 3.2 S是耐久溢价，不再与M重复定额

每个canonical节点先算：

`base_signed = M_base × direction_factor`

再追加耐久溢价：

| S状态 | durability_bonus |
|---|---:|
| NON_S | 0 |
| S+（R3） | +1 |
| S++（R4/跨朝深度） | +2 |
| S−（R3负向骨架） | -1 |

因此典型节点：

- positive M2 S+ = `1+1=2`
- positive M3 S+ = `2+1=3`
- positive M3 S++ = `2+2=4`
- negative M3 NON_S = `-2`
- negative M3 S− = `-2-1=-3`

`A_net_units = Σ(base_signed + durability_bonus)`

**关键含义：**

1. 一条已形成R3耐久骨架的M3正S（+3）应强于一条仅任内成立的负M3（-2）；否则S的长期接收信息等于白记。
2. S++的跨朝/文明深度继续产生额外收益，嬴政这类长期制度影响不会被普通非S负M轻易抹掉。
3. S节点M2/M3差异天然保留，不再需要另设“operation bonus”。
4. `S_net`保留作诊断字段，但**不直接代入总分公式**。
5. 正负S仍完全对称：同样R3门、同样耐久溢价绝对值；宫妃殉葬等普通S−仍为-1耐久溢价，不另造S−−。

### 3.3 主档影子门

- G0：`A_net_units <= 0`；
- G1：`A_net_units = 0.5`；纯M0不加分；
- G2：`1 <= A_net_units < 2`；
- G3：`A_net_units >= 2`，但未过G4/G5；非S路线至少一条positive M3或两条独立positive M2；
- G4：至少一条合格R3正S，且`A_net_units >= 2`；
- G5：原结构门继续保留，同时要求`A_net_units >= 6`。

G5结构门：

1. 至少3条独立正S、覆盖≥2领域；或
2. 至少2条独立S++、重定两个核心接口。

`S_net<0`仍阻断G4/G5，但不再自动“封顶/保底G2”；低档统一看V2净账。

### 3.4 position影子锚点

- G0：upper=0；middle-upper≈-0.5；middle≈-1；lower-middle≈-1.5；lower≤-2。
- G2：lower≈1；middle≈1.25；middle-upper≈1.5；upper接近2。
- G3：以2为最低净值，按完整净余和独立结构质量排position。
- G4：lower≈2；lower-middle≈2.5；middle≈3；middle-upper≈4；upper≥5。
- G5：lower≈6；lower-middle≈7；middle≈8；middle-upper≈9；upper≥10。
