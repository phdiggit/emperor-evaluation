## 一、总原则（锁定）

- A评价制度**净贡献**，不评价动作大小、改革声势或抽象创新能力。
- 正向制度与负向制度必须同时计算；不得因建设厚度高获得保底高档。
- 只看实际运行、收益、代价和后果；纸面创设、未运行尝试不得抬档。
- 同一制度生命周期先合并正负事实，再形成唯一裁决；不得正负双计、材料堆分或同机制重复计分。
- 不因历史名望或人物姓名设置特例。
- **锁定：朱元璋“宫妃殉葬成为宫廷继承礼制并延续”固定普通S−、权重1。性质极恶劣，但影响范围有限，不使用S−−/权重2。**

## 三、P0：规则净值与mixed

### [ ] A-RULE-000：mixed必须由正负effect强制裁决

`mixed`只表示正负实质相抵，不能表示“复杂”“短命”“没判完”。同一生命周期分别记录`benefit_effect_level`与`harm_effect_level`（0—3），每侧只取最高闭合层级，不按材料数累计。

`effect_delta = benefit - harm`：≥+2 positive；+1 mixed_positive；0且双方>0 mixed；−1 mixed_negative；≤−2 negative；双方0不构成A计分节点。

M仍只管覆盖/闭合：M0=0、M2=1、M3=2；`signed_weight=M_base×direction_factor`。

### [ ] A-RULE-002：M0纸面/未完成尝试不得获得正向主档

现G1六人需逐人重裁。已确认：姚苌、元恪只闭合制度命令；刘骜底层材料甚至为negative，均不应因“有尝试”获得正收益。

### [ ] A-RULE-004：major_node_role不再自带G3

`MAJOR_RECONSTRUCTION/CANONICALIZATION/MAJOR_CIVILIZATIONAL_CORRECTION`只描述制度类型，不直接给档。朱祁镇终止殉葬、朱翊钧缩小永远充军等必须按实际覆盖与净结果计。

### [ ] A-RULE-005：废除无符号C_A计分，统一用A_net_units净账

建议主干：

`nonS_net_weight = Σ(去重后的非S signed_weight)`

`A_net_units = 2 × S_net + S_plus_plus + nonS_net_weight`

普通S+/S−各±2；S++再加1深度；非S按实际signed M进入同一本账。`C_A`最多保留为审计字段，不参与grade/position。

低档影子门：G0 `<=0`；G1 `0.5`；G2 `[1,2)`；G3 `>=2`且未过G4/G5，并要求至少一条positive M3或两条独立positive M2。

### [ ] A-RULE-006：position使用完整净余，不再把非S M统一除以4

旧公式严重稀释重大负向。主档确定后，position应使用`A_net_units - 本档最低净值门槛`或等价完整净余。

### [ ] A-RULE-007：取消`S_net<0 → 固定/封顶G2`特殊机制

`S_net<0`代表耐久骨架净负，是强负信号，但不能自动生成一个G2结果。

**新处理**：`S_net<0`禁止G4/G5；所有负S全额进入`A_net_units`；低档由统一净账决定，可落G0/G1/G2，理论上大量独立真实正向非S可把总净值抬到G3；不再用“做过很多建设”保G2。朱元璋作为压力样本，若净值≤0必须允许落G0。

### [ ] A-RULE-008：S节点过门后不得丢失本人任内M2/M3运行强度

曹叡“魏律与律博士法制体系”为M2+S+；李嗣源“三司使统合中央财赋接口”和李适“两税法”为M3+S+。当前一旦计S，M2/M3差异被完全吃掉。

**整改方向**：G4资格仍允许M2+R3的S；但M3应在档内净余体现优势。建议S固定价值负责耐久骨架资格，另设`S_operation_bonus`（M2=0，M3按方向形成正/负余量），具体权重在影子结算校准，不用人物反推。
