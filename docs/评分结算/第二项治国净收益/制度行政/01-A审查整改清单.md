## 一、总原则（锁定）

- A评价制度净贡献，不评价“动作大小”“改革声势”或抽象创新能力。
- 正向制度与负向制度必须同时计入；不得因为建设厚度高而获得保底高档。
- 只看实际运行、收益、代价和后果；面子工程、纸面创设、未运行改革不得抬档。
- 同一制度生命周期必须先合并正负事实，再形成唯一裁决；不得正负双计、材料条数堆分或同一机制重复计分。
- 本轮不因历史名望或直觉反差对任何人物设特例。
- **锁定裁决：朱元璋“宫妃殉葬成为宫廷继承礼制并延续”固定为普通S−、权重1。性质极恶劣，但影响范围有限，不使用S−−/权重2。**

## 三、P0：规则净值与mixed解决方案

### [ ] A-RULE-000：mixed不再是模糊口袋；用“正向effect—负向effect”强制裁决

**结论**

真正“正负实质相抵”的balanced mixed仍应计0，因为A评价净贡献；问题在于当前mixed混入了“证据没判完”“改革短命”“结构复杂”“正向主导但有代价”等不同状态。

正式数据不允许“净方向未闭合”作为最终方向。每条生命周期必须裁成五档之一。

**1. M与方向彻底分工**

- M只描述制度生命周期的覆盖、持续和闭合：M0/M2/M3。
- 方向单独比较同一生命周期内实际观察到的A项内生收益与A项内生制度损害。
- 跨项财政民生、战争、D1交班等后果不重复塞进A方向。

**2. 每一侧建立effect_level（不是新的M档）**

同一生命周期分别给`benefit_effect_level`与`harm_effect_level`：

| effect_level | 边界 |
|---:|---|
| 0 | 未观察到该侧实际效果 |
| 1 | 已有实际效果，但局部、较弱或只构成同一生命周期的次级副作用/收益 |
| 2 | 明确、实质、可闭合的有限接口效果，约为M2尺度 |
| 3 | 系统性、广域、多年或改变核心接口的重大效果，约为M3尺度 |

每一侧只取**最高闭合效果层级**，不按材料条数累计。

`effect_delta = benefit_effect_level - harm_effect_level`

| effect_delta | 最终方向 | factor |
|---:|---|---:|
| ≥ +2 | positive | +1.0 |
| +1 | mixed_positive | +0.5 |
| 0且双方均>0 | mixed / balanced | 0 |
| −1 | mixed_negative | −0.5 |
| ≤ −2 | negative | −1.0 |
| 双方均0 | 不构成A计分节点 | — |

这样可以处理刘欣这类mixed_positive M2：例如正向效果2、负向/不稳定性1，强制落+0.5，而不是把整个M2误写成balanced 0。

**3. 撤回/短命不自动等于mixed**

制度后来被撤回首先影响`result_closure / reception_scope / S资格`。只有撤回本身造成同尺度制度损害，才进入harm_effect。海山“武宗改制及迅速反转”必须按此重裁，不能把“短命”直接当负向。

**4. signed M继续使用现有简洁权重**

- M0 base=0；M2 base=1；M3 base=2。
- `signed_weight = M_base × direction_factor`。
- 因而：M2 mixed_positive=+0.5；M3 mixed_positive=+1；balanced=0；M3 mixed_negative=−1；M3 negative=−2。

### [ ] A-RULE-005：C_A退出直接计分，G0—G3改用去重后的non-S signed净权重+结构门禁

**原因**

当前无符号C_A会把净0的mixed改革抬到G2/G3，本质上重新奖励“建设动作”。C_A可保留为`C_A_raw`审计节点完成度，但不得再直接进入结构厚度或提供主档保底。

**建议统一低档门禁**

先计算所有去重、非S、合法A节点的：

`nonS_net_weight = Σ signed_weight`

再按结构配置定档：

- **G0**：`nonS_net_weight <= 0`，没有可识别净正向制度贡献；负向可通过position继续下压。
- **G1**：`nonS_net_weight = 0.5`，典型为一条实际运行的mixed_positive M2；不再奖励M0纸面动作。
- **G2**：`1 <= nonS_net_weight < 2`，典型为positive M2或mixed_positive M3。
- **G3**：`nonS_net_weight >= 2`，且至少满足其一：①有一条positive M3重大非S节点；②至少两条独立positive M2制度生命周期形成真实组合。不得由同一生命周期拆分、材料条数或balanced mixed凑成。
- `S_net=0`仍最高G3；有正向S则进入G4/G5专门门禁。

这一规则可自然解释赵昀：两条独立positive M2合计净权重2，可按全体统一规则进入G3，不需要姓名特例。

**待校准点**

- 多条mixed_positive M2是否允许累计到G3：暂不允许纯数量直接凑；若无positive M3，组合路线优先要求至少两条**positive M2**。后续用全量影子结算校准。
- G4/G5如何把non-S负向纳入降档门，另见A-RULE-003，不在此提前拍死。
