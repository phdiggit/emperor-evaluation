## 二、逐人结算依据

### 1. 拓跋珪

- **C2结算**：**20/20（C2-5-HIGH）** = P12 + R8 - N0。
- **结算依据**：参合陂S/D3、柴壁A/D3、刘卫辰终局S-/D3及多次A/B级本人前线成果形成历史级厚度。最新人才登记没有可归责前线失败；坑杀降众属于战争行为负面而非指挥能力败责，因此不得人为压1分，P12+R8完整成立。

### 2. 李世民

- **C2结算**：**20/20（C2-5-HIGH）** = P12 + R8 - N0。
- **结算依据**：虎牢S+/D4是当前最高前线峰值，另有柏壁S-/D4、刘黑闼A/D4、薛仁杲S-/D3等彼此独立复验；第一项窗口内无同等级可归责重大失败。

### 3. 努尔哈赤

- **C2结算**：**18/20（C2-5-MID）** = P12 + R6 - N0。
- **结算依据**：萨尔浒S/D4为极限前线锚，灭乌拉A/D3、灭哈达A/D2形成独立复验；第一项窗口没有同等级可归责败绩。

### 4. 朱元璋

- **C2结算**：**18/20（C2-5-MID）** = P12 + R6 - N0。
- **结算依据**：鄱阳湖S/D3为核心前线峰值，和州A/D3、渡江、龙湾等形成多种战争形态复验；北伐后方统筹不进入C2。

### 5. 石勒

- **C2结算**：**18/20（C2-5-MID）** = P12 + R8 - N2。
- **结算依据**：前赵终局S/D4、段氏围攻A/D4、王浚A/D3及多项A/D2形成极高峰值与厚复验。最新人才登记只保留南进江夏一项A级负向，不支持此前N4式重罚；按单个A级重大失败取N2。

### 6. 铁木真

- **C2结算**：**18/20（C2-5-MID）** = P12 + R8 - N2。
- **结算依据**：克烈终局S/D4提供极限峰值，乃蛮等S/D3、S-/D3多次复验；班朱尼前大败和若干围城失败属于第一项主链负证，因此从理论满分下调。

### 7. 刘裕

- **C2结算**：**17/20（C2-5-LOW）** = P11 + R6 - N0。
- **结算依据**：京口起兵—建康连续决战S-/D3，另有卢循方向A/D4及多次A/D3本人前线成果；后秦分路将领D3/D4不能转写给刘裕，因此复验分不取满。

### 8. 宇文泰

- **C2结算**：**17/20（C2-5-LOW）** = P12 + R6 - N1。
- **结算依据**：沙苑S/D4为历史级峰值，窦泰、第一次邙山等A/D3提供高质量复验。最新人才登记中，长期降雨撤军明确不能计个人指挥败责；真正可用负证主要是第二次邙山mixed A/D3，因此按单个混合结果取N1。

### 9. 慕容垂

- **C2结算**：**17/20（C2-5-LOW）** = P11 + R6 - N0。
- **结算依据**：后燕复国主链内，灭西燕S-/D3与灭翟魏A/D3是两个独立高质量前线锚，另有多项B/D2、A/D2复验；前燕时期枋头等只作全生涯校验，不重复进入本次创业链。

### 10. 李存勖

- **C2结算**：**17/20（C2-5-LOW）** = P12 + R8 - N3。
- **结算依据**：直取大梁S/D3及多个A/D3、B/D3前线锚形成历史级厚度；负向包括两次B级明显失败和两次C级未克，其中一次有明确拒绝避战的决策责任。属于多次普通至中等失败，N3更合适，不按灾难性N4处理。

### 11. 吕光

- **C2结算**：**16/20（C2-4-HIGH）** = P11 + R6 - N1。
- **结算依据**：西域远征S-/D3、东归凉州S-/D2、平河西A/D3形成多个高质量前线锚；创业竞争后段有一次mixed A/D3，故轻度限制稳定性。

### 12. 完颜阿骨打

- **C2结算**：**16/20（C2-4-HIGH）** = P11 + R5 - N0。
- **结算依据**：反辽主链中S-/D3选阵追围歼灭是最高锚，另有A/D3与多次A/B级本人亲征；复验厚但极限难度略低于D4组。

### 13. 曹操

- **C2结算**：**16/20（C2-4-HIGH）** = P12 + R8 - N4。
- **结算依据**：官渡S/D4是极高峰值，乌桓S-/D3及多次A/D3形成充分复验；张绣、赤壁及南线多项可归责失败，并存在明确指挥过失，因此只能顶级高位而非历史级。

### 14. 李克用

- **C2结算**：**16/20（C2-4-HIGH）** = P11 + R7 - N2。
- **结算依据**：收复长安S-/D3，并有多次A/D3、A/D2亲自主战；洹水、讨刘仁恭等两次明确失败限制稳定性，但整体前线复验极厚。

### 15. 李嗣源

- **结算依据**：故元城、雨夜取郓州、幽州解围均达到A/D3，另有多次B/D3、B/D2前线复验；虽无S级极限峰值，但本人前线厚度极高且无明显同窗重大败绩。
