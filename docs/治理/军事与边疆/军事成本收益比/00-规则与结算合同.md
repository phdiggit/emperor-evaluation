# 第三项D军事成本收益比规则与结算合同

本项以40分评价皇帝完整统治期内的军事投资是否值得。先按独立战略行动周期配对己方军事成本、战役结果与安全控制收益，再合并为皇帝军事投资组合；不按战斗次数平均，也不把档位序号相加。

## 1. 事件范围

- `D_STANDARD`：对外战争、战略级内战、实际边防与驻军投入。
- `D_INTERNAL_COST_ONLY`：未达到国防安全门槛、但实际消耗国家军事资源的地方镇压或兵变处置。
- 创业统一、兼并战争固定排除；宫禁政变、个人刺杀和未形成国家军事行动的政治暴力固定排除。
- 同一战略目标、连续动员与结果闭合链只结算一次；重新决策、重新动员、目标转换或前一周期已闭合时才拆分。

统一战争只服从战役底账的最终逐卡路由，不得按标题或整个战争群重新推断。跨皇帝周期只结算本人任内决策、投入和阶段结果。

## 2. 成本和收益

成本端消费战争成本账中的己方军事人员损耗P、动员服役M和军资资产A。平民生活与经济网络的最终损害归第二项，不在D重复扣分；敌方人员损失也不是己方成本。

收益端消费战役实际结果、已经实现的WR、战略安全SB/SN和边疆控制BCP/BCN。杀敌、缴获、名义臣服或后任取得的成果，未转化为本周期实际结果时不得计入。

事件分为`HIGH_RETURN、PROPORTIONATE、LOW_RETURN、NEGATIVE_RETURN、UNKNOWN`。同一事件涉及多个政权或跨越统治转换时，必须建立“事件—评价主体—任期阶段”视图，禁止把攻方成本配给守方，也禁止把继任者阶段结果倒灌前任。防御战争的必要成本从宽，但可避免的后勤崩溃、重复失败和本人政策诱发的内乱不得转化为正收益。

## 3. 皇帝组合档

| 档位 | 组合边界 | 40分区间 |
|---|---|---:|
| D0 | 军事投资是全国性崩溃或覆亡的主导原因，国家级反复透支且几乎无补偿收益。亡国不自动归零。 | 0.0—7.9 |
| D1 | 高成本低收益或负收益长期占主导，反复大军覆没、无功重征或安全控制倒退。 | 8.0—15.9 |
| D2 | 总体明显失衡，存在国家级负收益周期或多项持续低收益，但仍有可确认成果。 | 16.0—21.9 |
| D3 | 成本收益混合且大体可解释，有明显浪费、保持不足或一次较重负收益；缺乏实质军事投资检验者也落本档。 | 22.0—29.9 |
| D4 | 主要投入取得相称或较高回报，成果能够保持，无反复国家级浪费和战略透支。 | 30.0—35.9 |
| D5 | 经真实高难度压力与多项重大投入检验，取得历史顶级且长期保持的回报，无国家级负收益周期；最多容纳不改变整体的局部失利。 | 36.0—40.0 |

一项国家级负收益不得被许多低成本小胜平均稀释；多项重大高收益可以证明稳定效率，但同一父树阶段不得重复。D0必须另做覆亡因果裁决，D5必须同时通过高难度、重大收益、成果保持和无战略透支四项门槛。

档内分只表达同档支撑强弱：比较重大高收益、相称回报、低收益、负收益和证据缺口的组合，不改变档位边界。无法闭合的高物质性周期至少封顶D4。
