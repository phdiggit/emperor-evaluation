# 法律治理正式资料

本目录保存秦统一后至清代法律治理的当前可计分底账及其回源材料。

- [`联合统筹/01-秦至清法律治理联合底账.md`](联合统筹/01-秦至清法律治理联合底账.md) 是法律治理唯一计分读取入口，也为治理人才等级判断提供结构化依据。
- `联合统筹/03-跨朝强度与组合校准.md` 保存方向、强度、运行档、独立机制广度和整合度的当前校准规则。
- `朝代底账/` 保存24个朝代或政权的节点原档、人物归责和审计说明，只供联合底账回源，不是并列评分入口。
- `回源资料/` 保存联合底账实际引用的通读总结、固定原文及revision元数据；其中阶段性评分措辞不覆盖联合底账当前值。

后续新增或修订法律治理材料时，先更新对应朝代底账及回源材料，再完成跨朝校准并更新联合底账。评分和人才等级链路始终只读取联合底账。
