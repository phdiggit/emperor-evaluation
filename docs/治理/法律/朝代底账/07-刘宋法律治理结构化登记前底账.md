# 刘宋法律治理结构化登记前底账

用途：本文件保存刘宋法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以420年刘裕代晋至479年萧道成代宋为朝代边界。刘宋没有独立刑法志可供连续复原，现有底账主要来自《通典》对宋代制度与疑难案件的汇录；因此能够闭环的节点照常登记，缺少采纳或运行结果者留在审计层，不用材料稀少冒充“没有治理”。

## 一、刘宋法律治理总判断

刘宋现存材料的重心不是重编完整法典，而是亲属伦理、死刑比例、赦后责任和重囚复核：

> 文帝朝停止强迫子孙具辞指证父祖 → 多名法官围绕亲属连坐、盗墓邻伍、劫犯家属和重囚覆核提出缩责方案 → 部分方案获采纳或形成个案减死 → 孝武帝朝又以尊亲和官长秩序扩大赦后死刑、终身役使及家属责任。

相对于东晋法出多门，刘宋材料显示朝廷仍能形成若干明确裁判规则；但这些规则的文明方向并不统一。亲属伦理有时缩小无辜牵连，有时又被用于扩大死刑或压倒主观动机，必须按实际责任和伤害分别定向。

- 东晋后期已有律令失效、私狱和法外裁量的负向基线；刘宋若形成明确规则边界，即使没有重编新律，也可构成治理增量。
- 同一罪责由死刑改为远徙，按减死判断为正向；远徙是剩余处分，不另判负。只有扩大到原本无责亲属或新增受罚场景时才另作负向判断。
- 未写“从之”、未见判决或未见施行的奏议，不因论证完整进入正式计分。

## 三、法律运行档位在刘宋的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 制度或方案已经提出、议定，未见具体适用 |
| L1 | 至少一次明确改判、处刑、免责或亲属责任结果 |
| L2 | 稳定程序或裁判规则进入重复适用 |
| L3 | 群体、区域或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

现存材料大多是正式议决或单案终局，最高只到L1；没有把若干方向不同的案件拼成制度性L3，也没有用法令颁布本身冒充重复运行。

## 四、方向、归责与去重原则

- 每个READY个案必须同时具备具体事实、具名决策行为和终局结果；仅有建议者的材料不纳入联合底账。
- 亲属相隐不预设为正面：减少强迫作证或无行为连坐时为正向；因礼教扩大死刑、役使或亲属处罚时为负向。
- 皇帝只在明确采纳、下诏或改变终局时获得R档；只写“朝廷”的案件不强行把名义皇帝定为R4。
- 徐羡之减死案只登记刑罚变化，不包装成儿童保护；孔渊之、顾觊之节点则按实际扩大死刑或重罪认定登记。

## 五、刘宋法律治理结构化底账

### 节点原档字段合同

- 综合档位固定写为 `方向强度·运行档·状态`。
- `P/N/M1—3`、`U`、`L0—L4/LX`、`READY/HOLD` 和R档沿用法律领域共同合同。
- `READY` 行只把已有明确R1—R4的人物送入个人计分；R?人物只保留待补。

| 综合档位 | 治理节点 | 皇帝归责档 | 臣子归责档 | 审计说明 |
|---|---|---|---|---|
| `P1·L1·READY` | 景平年间母杀幼子案由死刑改远徙 | 刘义符:+R? | 徐羡之:+R4 | （周氏活埋三岁患病儿，原判弃市；徐羡之建议改徙并获诏从，属于同一罪责减死，不能扩写为儿童保护成果） |
| `P2·L0·READY` | 文帝朝停止强迫子孙具辞指证父祖 | 刘义隆:+R3 | 蔡廓:+R4 | （蔡廓提出只令家人与囚相见，不再要求子孙明言父祖之罪；朝议同意并施行，现存材料未给重复适用结果） |

| `N2·L1·READY` | 剖尸案以礼教重判无害意图妻儿 | 裁断皇帝:-R3 | 顾觊之:-R4；刘勰:+R2 | （妻遵死者遗言剖腹查病，儿年幼未阻止；顾觊之主张分别按不道、不孝重断并获诏从，刘勰曾据动机与认知反对） |

## 六、未纳入联合底账的材料

- 傅隆处理祖母杀儿媳案：限制远徙和家族复仇逻辑，但未见明确采纳，且被害妇女权益与亲属伦理交织，暂只保留审计。
- 何承天反对借叔母身份扩大劫犯从弟补兵：方向明确但终局未载，不再与何叔度节点重复生成HOLD。
- 刘宋沿用、损益晋律的概括：缺少具体编修节点、条文和人物行为，不虚构一项“沿用法典”成果。
- 单纯列名的法司、朝议成员：没有开创、重大设计或改变终局的独立行为，不分配人才归责。
