# 秦统一后法律治理结构化登记前底账

用途：本文件保存秦始皇二十六年统一至秦亡的法律治理登记前结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

秦无独立刑法志，也没有能按统一后皇帝和臣子完整归责的传世秦律。本稿以《史记·秦始皇本纪》为连续主篇，以《汉书·刑法志》和《通典》保存的秦制回顾校准，只登记统一后可以证明的法权结构、实际刑罚运行和人物责任，不冒充秦律全貌。

## 一、秦统一后法律治理总判断

秦统一后的法律治理主线是：

> 结束战国多国法权并立、建立全国统一法令和郡县执行链 → 把统一法权用于知识与政治表达刑事化、刑徒工程和扩大化处分 → 二世、赵高以重法清洗宗室大臣、惩罚进谏并封锁危机信息 → 官吏和将领因无论有功无功皆可能被诛而失去忠诚，刑政反噬国家运行。

其正向增量主要是全国统一法权和跨地域执行标准；商鞅以来已有的连坐、告发、军功和重刑不得再次登记为始皇原创。负向增量在于这些制度被扩大到统一帝国，并出现全国刑徒动员、知识犯罪、群体处死和终末政治清洗。

## 三、运行档位在秦代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 只有制度交付，未见实施 |
| L1 | 明确颁行或至少一次实际执行 |
| L2 | 全国跨郡实施、常规程序化或反复执行 |
| L3 | 群体、区域或系统层面的明确结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有称颂、灾异附会或无法核定的推断 |

刑徒数字可能含行政征发人员，不能把七十余万人全部视为经正常司法定罪者；但刑徒在湘山、长城、南越、阿房、骊山等工程中跨年反复调用，以及秦末继续被当作应急兵源，足以证明惩罚性劳役已经形成系统运行。

## 四、方向、归责与去重原则

- 全国统一法权只结算法律规范和执行链的结构建立，不重复领取统一战争、郡县制、文字或度量衡分数。
- 秦法原有连坐和重刑不归始皇开创；统一后扩大适用范围、增加知识犯罪或形成新的群体结果，才计算其增量责任。
- 皇帝直接采纳、下令处死、维持或拒绝纠偏为R4；李斯提出焚书和具体刑罚方案，承担独立R4设计责任。
- 扶苏、冯去疾、冯劫和李斯后期的未获采纳建议只证明纠偏遭拒，不形成正向公共成果。
- 二世的授权采用责任与赵高的设计、操纵和直接执行责任并列；二世失控不抹去其先前主动采用重法清洗的责任。
- 秦亡是多因素结果，不能把全部亡国责任计入法律；这里只登记刑政对信息上报、官僚信任和将领忠诚已有连续证据的部分。

## 六、不得补成成果的材料

- 刻石关于法律清楚、官吏公正和人民安宁的颂辞；
- 侯生、卢生全部人物评价中不能被制度行为互证的部分；
- 扶苏反对重法、冯去疾等请停工程减戍转等未实施建议；
- 二世赦骊山刑徒授兵：目前不能证明从刑徒状态转入高风险作战对同一人群形成净减害；
- 秦简中无法可靠绑定统一后具体皇帝、年代和重大变革者的静态条文。
