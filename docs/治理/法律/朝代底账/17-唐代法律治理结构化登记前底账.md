# 唐代法律治理结构化登记前底账

用途：本文件保存唐代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、唐代法律治理总判断

唐代法律治理的主线是：

> 隋末法制失序 → 武德恢复统一法典 → 贞观减死、复核和法源重构形成正向主峰 → 永徽完成解释制度化 → 高宗后期运行恶化 → 武周形成告密酷吏体系 → 开元重新清理法源 → 天宝以后替代刑和格敕体系持续失稳。

唐代的主要增量不是发明十二篇、五百条、五刑或死刑复核；这些已有隋及更早基线。可归责的唐代增量主要是：

1. 武德恢复一套可用、统一的成文法体系；
2. 贞观显著缩小死刑和连坐范围，并把复核、狱政和法官问责接入实际运行；
3. 永徽把法律解释统一用于教育、考试和断狱；
4. 武周另建告密、罗织和特别审讯体系，构成结构性倒退；
5. 中晚唐虽反复清理格敕、局部减刑，但未恢复唐初的整体稳定。

## 三、法律运行档位的审计解释

| 档位 | 审计含义 | 典型证据 |
|---|---|---|
| L0 | 制度已经制定、删改、颁行或撤销，但尚无实际适用证据 | 法典颁行、条文删除、诏令交付 |
| L1 | 至少有一次明确适用、改判、释放、处分或执行 | 单案免死、一次录囚、规则实际采用 |
| L2 | 多案援例、常规程序化、跨机关反复执行或形成稳定先例 | 法司据疏断狱、多次复核救生 |
| L3 | 出现全国、区域或系统层面的汇总结果和方向性后果 | 天下死刑数、大规模平反或杀戮、断狱趋平 |
| L4 | 系统结果跨多年、跨区域或跨阶段持续 | 长期酷吏体系、多年法源失稳、广域无重囚 |
| LX | 不能证明法律运行 | 祥瑞、灾异感应和无法核定的颂扬数字 |

全国死刑人数属于L3强指标，但通常只能证明相应口径和年份的司法输出，不能直接推导全国犯罪率或整个统治期平均水平。制度交付与运行结果分开：L0可以进入制度创设评价，不能冒充运行成效。

制度、法典或诏令长期存在本身不构成L4；必须另有正负方向一致的系统结果跨多年、跨区域或跨阶段持续。

## 四、归责与净变化审计原则

- R档只表示人物对节点的责任强度，不改变节点本身的公共价值。
- 主动发起、核心设计、最终决定或长期维持通常为R4；不可替代的领衔设计和关键纠偏为R3；重要支持为R2；普通参修、署名和例行执行为R1；普通沿用为R0。
- 皇帝、方案提出者、组织者和直接执行者可以同时有高责任，但必须说明责任类型，不得平均分摊。
- 同一罪责、同一人群由死刑改为流、徒、杖等较轻刑罚，剩余刑罚只限制正向幅度，不另生负向。
- 只有新增受罚场景、扩大受罚人群、加重同一罪责，或产生新的实际净伤害，才登记负向部分。
- 错误决定已经造成死亡、伤害或系统后果时，另立负向节点；被阻止而未落地的主张不进入公共运行结果，可作为关键决策能力材料另审。
- 已确认节点先独立分账，再按规模、持续时间、伤害或收益强度综合人物净责任；重大伤害后的有限纠偏不得写成正负各半。

## 五、唐代法律治理结构化底账

### 节点原档字段合同

- 综合档位固定写为 `方向强度·运行档·状态`。
- 方向强度：`P3/P2/P1`＝结构性/显著/有限正向；`N3/N2/N1`＝结构性/显著/有限负向；`M3/M2/M1`＝正负并存且规模相应；`U`＝方向未定。
- 运行档：`L0—L4` 沿用法律领域运行档位；档位后的括号只作审计解释，不参与机器读取。
- 状态：`READY`＝该节点可进入计分校准；`HOLD`＝节点成立，但人物归责或因果尚不足，暂不进入个人计分。
- 人物归责固定写为 `姓名:+R档`、`姓名:-R档` 或 `姓名:±R档`；`R?` 表示尚不能定档。
- `READY` 行只把已有明确R1—R4的人物送入个人计分；同一行的R?只保留待补，不阻断已闭合的开创者或重大变革者。
- 同一罪责、同一人群由死刑改为流、徒、杖等较轻刑罚，剩余刑罚只限制正向强度，不另生负向。只有新增场景、扩大人群、加重刑罚或出现新的净伤害，才记负向。
