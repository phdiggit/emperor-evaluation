# 辽代法律治理结构化登记前底账

用途：本文件保存辽代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、辽代法律治理总判断

辽代法律治理的主线是：

> 太祖、太宗按契丹、汉人和渤海人建立多元司法辖区，同时保留族属差序和非常酷刑 → 穆宗以个人意旨反复实施法外酷刑 → 景宗恢复申冤，圣宗把同罪同法、贵戚问罪、复核巡狱和盗罪减死接入实际运行 → 兴宗整理成文法并局部减刑，却以亲疏好恶任意宽免并发生政治大狱 → 道宗统一法努力因条文膨胀而失败，耶律乙辛又俘获告首和专案审讯 → 天祚末平反与报复并行，赏罚失序和酷刑复归。

辽代的正向主峰是圣宗时期从族属差序向同罪同法、复核和限制主人私刑收束；负向主峰是穆宗、乙辛诬狱和天祚末期使皇帝、权臣或近侍意志突破一般法律。

## 三、法律运行档位在辽代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法令或法典已经形成，未见适用 |
| L1 | 至少一次明确适用、改判、释放或处置 |
| L2 | 全国法源、常规复核或跨机关程序进入运行 |
| L3 | 群体、区域、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

圣宗改革包含多轮制度、跨地区巡审、贵戚和部民案件及南京等地“狱空”，定L4；乙辛诬狱从告首、专案审讯延伸至皇后、太子和家属处分，跨阶段持续，定L4。

## 四、方向、归责与去重原则

- 辽初辖区建立和身份差序分别结算，不用正向国家能力抵销同罪异罚。
- 景宗恢复钟院与其一次未经审问杀告发者分账；纠偏渠道不能给实际法外杀人免责。
- 兴宗成文整合、实体减刑、任意宽免和钦哀后政治大狱机制不同，分别登记。
- 道宗统一法从五百余条膨胀至千余条又被撤回，作为一个失败生命周期定mixed，不把立项和失败拆成两份全额计分。
- 政治诬狱只登记构陷、授权、维持和关键纠偏者；普通审讯、行刑和后续沿用者不计。

## 六、未纳入联合底账的材料

- 圣宗每一条盗罪门槛、刺配次数和巡狱个案：由同罪同法与复核主节点吸收，不碎片化重复计分。
- 穆宗“百余人”与一次六十五人中杀四十四人：口径可能重叠，不相加制造精确死亡总数。
- 南北院分治本身：只有造成同罪异罚、特权免刑或救济障碍的部分进入负向。
- 辽亡：不能由法律单因解释；只将末期赏罚、酷刑和继承机制的直接后果纳入节点。
- 皇帝事后悔言、祥瑞灾异和史家道德感应：不作为独立运行成果。
