# 北魏法律治理结构化登记前底账

用途：本文件保存北魏法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以386年拓跋珪称王建国至534年北魏分裂为朝代边界。北魏跨越近一百五十年，法律治理须按“草创简法—成文严制—献文纠偏—孝文重构—特旨侵法—末期失序”分阶段登记，不能把开国、统一和末期的相反结果压成一个平均值。

## 一、北魏法律治理总判断

北魏法律治理反复出现“严刑求治—执行激励反转—再纠偏”的循环：

> 道武帝删战时酷法、约定科令，晚年又转为滥酷 → 太武帝建立成文法、死刑奏报和刑讯限制，同时以过密盗法与告举牧守制造新的失控 → 献文帝缩小门房族诛、限制口传诏令和刑讯 → 孝文帝撤侦伺、修律、限重枷并大量减死，形成朝代正向主峰，但对官员受赃采用极低死刑门槛 → 宣武帝又以特旨诏狱突破常法并处罚持法官 → 孝昌后权臣和临时严制使法律再度失稳。

其历史增量在于把北方战时裁断转为成文、复核和申诉制度，并在孝文帝时期形成可观察的减死与限制侦伺结果；主要倒退则是皇帝和权臣不断用临时严令、特旨和政治需求突破已建成的规则。

## 三、法律运行档位在北魏的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典或命令已经交付，未见适用 |
| L1 | 至少一次明确裁判、减免或责任结果 |
| L2 | 全国法源、常规程序或规则进入反复适用 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

孝文综合改革达到L4，是因为撤侦伺、一般死案减死、京师处决和跨年保全人数形成多年同向证据；其余阶段性制度或系统结果最高定L3，不因朝代持续很久自动抬档。

## 四、方向、归责与去重原则

- 太武成文程序与过密盗法、告举牧守分别登记，因为措施、受影响对象和结果链可分；正向法典不能抵销独立负向政策。
- 盗三匹即死后来恢复旧阈值，只限制负向持续程度；“犯者更众”的实际结果已经发生，不因纠偏而归零。
- 孝文一般死刑减免与极低受赃死刑门槛分别结算。反腐短期见效是运行事实，但不足以把明显失衡的生命代价改判正向。
- 宣武帝特旨案中崔纂、游肇是失败纠偏者；臣子正向归责不稀释皇帝突破常法和处罚持法官的负向责任。

## 六、未纳入联合底账的材料

- 献文时期为求审慎而反复覆鞫：作为纠偏节点的运行成本审计，缺少可独立归责的统一新制度，不另拆负分。
- 宣武、孝明时期其他单案法理争论：没有改变终局或稳定规则者，不因论证精彩登记成果。
- 孙腾主张恢复常律及东魏迁邺后的整肃：发生在北魏分裂后的东魏阶段，留给东魏底账。
- 北魏最终分裂：不把政权结局本身当作法律治理结果，只登记史源明确的法令失序机制。
