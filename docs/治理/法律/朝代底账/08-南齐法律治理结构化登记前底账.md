# 南齐法律治理结构化登记前底账

用途：本文件保存南齐法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以479年萧道成代宋至502年萧衍代齐为朝代边界。现有通读材料没有足以复原南齐完整法律治理的独立刑法志；只确认齐武帝时期一次法典注释汇编，以及宋、齐律在篇目和刑名上大体沿用晋律。材料不足不能改写成“南齐没有法律治理”，也不能把未施行文本算成成果。

## 一、南齐法律治理总判断

当前可闭合的判断只有：

> 宋、齐律大体沿用晋律结构 → 齐武帝命王植之汇集张斐、杜预旧注为一书，共一千五百三十条 → 该书未施行且文本几乎亡佚 → 梁初蔡法度凭家传律学口述其内容，成为梁律的材料来源。

这说明南齐存在法律整理工作，并对梁律形成间接知识传承；但没有颁行、适用或公共结果证据，现阶段不能产生READY评分节点。

## 三、法律运行档位在南齐的使用

| 档位 | 本稿采用边界 |

| L0 | 文本或制度已形成，未见颁行和适用 |
| L1—L4 | 须分别有个案、重复程序、系统结果或跨阶段持续证据 |
| LX | 只有抽象称颂或无法核定的推断 |

王植之汇注明确“事未施行”，故只保留知识保存审计，不纳入联合底账。

## 四、方向、归责与去重原则

- 沿用晋律不登记为创新成果；只有相对前制的重大改变才可能计分。
- 齐武帝承担明确授权责任，王植之承担汇注责任；但未施行节点不进入个人计分。
- 梁初对旧稿的吸收归入梁律生命周期，不回填成南齐运行成果。

## 六、未纳入联合底账的材料

- “宋及南齐律篇目、刑名略同晋氏”：只说明承袭，不足以识别重大变革者或公共结果。
- 南齐末“刑政多僻”“昏虐”等梁朝回顾：缺少本稿范围内可拆分的具体法律机制、人物行为和结果，不直接生成笼统负分。
- 王植之稿在梁代被蔡法度转述并损益：实际成典与颁行责任归梁，不在南齐重复登记。
