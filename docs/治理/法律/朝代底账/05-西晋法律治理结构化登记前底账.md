# 西晋法律治理结构化登记前底账

用途：本文件保存西晋法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以266年司马炎受禅至316年西晋亡为朝代边界。司马昭在曹魏末年主持启动、至司马炎时期完成颁行的修律工程，按跨政权连续生命周期登记于西晋；曹魏已经完成十八篇新律、统一官方解释和设置律博士，构成西晋的直接基线。

## 一、西晋法律治理总判断

西晋法律治理前后反差显著：

> 司马昭启动总修 → 泰始律在司马炎时期完成、讲读、颁行和注释，并公开死罪条目 → 惠帝时期裁判逐渐脱离成文法，法外加重和同事异判持续多年 → 刘颂推动“有正文依正文、正文不及依名例、两者不及不论”的法源边界成为制度。

泰始律的主要增量不是单纯增加篇目，而是把律、令和故事分开，删减部分族诛从坐、禁锢告讦和身份性重罚，并通过全国颁行、官方讲读、注释与公开死罪条目提高可执行性。其后西晋没有维持住这套制度成果：惠帝时期皇帝偏好逐案“曲当”，下级遂以揣测上意替代稳定规则，出现多年连续的法外加重和裁判分裂。

- 曹魏已经完成法典分篇、官方解释和职业教学；西晋不得重复领取这些开创责任。
- “海内同轨，人甚安之”与实际颁行、讲读、注释、公开条目互相印证，可支持系统层面的正向结果，但不足以证明跨多年、跨阶段持续稳定，故不升L4。
- 惠帝时期材料列出元康四年、五年、八年及其后的多起法外加重，并明确总结“刑法不定，狱讼繁滋”“曲议犹不止”“法渐多门，令甚不一”，不是由一个冤案外推全国状态。

## 三、法律运行档位在西晋的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 制度已经正式议定，未见具体适用或结果 |
| L1 | 至少一次明确适用、改判或免除 |
| L2 | 全国法源、常规程序或公开规范进入反复适用 |
| L3 | 群体、区域或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

泰始律定为L3，依据是全国颁行、制度配套与“海内同轨，人甚安之”的系统汇总；惠帝时期失序定为L4，依据是元康年间多个年份、多个机关和多类案件连续出现同向结果，并有明确的总体运行结论。刘颂方案虽被议定为永久制度，但尚缺可核验的适用结果，停在L0。

## 四、方向、归责与去重原则

- 泰始律按一个完整生命周期登记，不把修律、颁行、讲读、注释和公布死罪条目拆成多项重复计分。
- 司马昭承担发动和授权总修的开创责任；司马炎承担完成、奖叙、亲临讲读和全国颁行责任。贾充按主持续修者定档；仅列入十四人名单而无独立行为者不强行分配R档。
- 惠帝时期的负向不是“皇帝有过失、臣子也曾进谏”各打五十大板：综合方向取决于持续运行结果。裴頠、刘颂的反对不能抵销最高统治者未能停止法外加重和多门裁判的责任。
- 刘颂方案只登记法源与裁判权限边界；其此前恢复肉刑主张多年未被采纳，不纳入联合底账。

## 五、西晋法律治理结构化底账

### 节点原档字段合同

- 综合档位固定写为 `方向强度·运行档·状态`。
- `P/N/M1—3`、`U`、`L0—L4/LX`、`READY/HOLD` 和R档沿用法律领域共同合同。
- `READY` 行只把已有明确R1—R4的人物送入个人计分；R?人物只保留待补。

## 六、未纳入联合底账的材料

- 刘颂多次主张恢复肉刑：未获采纳，只有论证和徒刑运行问题描述，不生成改革成果。
- 裴頠反对法外加重：属于对既有负向运行的纠偏主张，“曲议犹不止”，不另造未实现的正向成果。
- 泰始律中礼法身份等级、婚姻和性规范等单条：用于限制法典改革强度，不从同一法典生命周期继续拆分计分。
- 十四名修律参与者中缺少独立行为记载者：保留在史源审计，不因列名自动取得人才计分责任。
