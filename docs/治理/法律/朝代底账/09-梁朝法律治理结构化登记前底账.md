# 梁朝法律治理结构化登记前底账

用途：本文件保存梁朝法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以502年萧衍代齐至557年陈霸先代梁为朝代边界。梁律承接晋、宋、齐法源传统；南齐王植之汇注未施行，不能替梁朝领取成典和运行责任，也不能把梁律沿用的全部旧制都写成梁武帝原创。

## 一、梁朝法律治理总判断

梁朝法律治理呈现清楚的制度与运行分化：

> 梁武帝取得南齐旧律材料并重编二十篇梁律，统一律令解释、刑罚规格和录囚程序 → 天监十一、十四年停止押送部分老幼家属并废黵面 → 皇帝长期宽待朝士、对百姓按法严办，司法专业又被忽视，形成奸吏舞文、同罪异役 → 晚年对贵戚重罪纵容，暴力与窝藏扩散 → 同时又缩小非大逆犯罪的尊亲连坐。

因此，梁朝不能用“崇尚宽仁”概括。法典统一、定期录囚和缩小若干亲属处罚是实际进步；身份特权、司法寻租及贵戚法外则是独立负向运行，后来的局部纠偏不能抵销此前责任。

## 三、法律运行档位在梁朝的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 命令或方案已经形成，未实际执行 |
| L1 | 至少一次明确处刑、免除、停止牵连或身份改变 |
| L2 | 全国法源、定期程序或多项同向规则进入运行 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

梁律与月度录囚进入制度运行，定L2；宽贵严民、奸吏舞文和同罪异役有年度数量及系统描述，定L3，但现有材料不足以把不同阶段拼成L4。江陵棒杀死囚命令未执行，只作决策审计，不虚报公共结果。

## 四、方向、归责与去重原则

- 梁律编纂、颁行、刑罚规格和录囚作为一个法典生命周期登记；其中残酷刑讯和身份特权只限制正向强度，不把同一法典逐条拆分。
- 停押老幼、废黵面和后来缩小尊亲连坐属于实际改变受罚范围的独立纠偏，可分别按连续减害和重大范围变化登记。
- 宽贵严民与贵戚暴力的负向结果按实际运行归责；萧纲提出徒役标准但未获采纳，不能用未成建议抵销皇帝责任。
- 任景慈因在审讯中证实母罪而被流放，是新增作证者处罚场景，不能以“亲属相隐”之名预设为正向。

## 六、未纳入联合底账的材料

- 萧纲提出固定徒犯服役分配标准：梁武帝以难行拒绝，属于未成纠偏，不生成正向成果。
- 梁律每项刑具尺寸、赎罪金额和身份差序：已纳入法典生命周期的强度限制，不逐条拆账。
- 临川王萧宏之后每起王侯暴力：已有系统运行节点，不按案件数重复扣分。
- 梁敬帝时期“刑政适陈”：只是政权交替，缺少独立制度行为和结果，不另行登记。
