# 北周法律治理结构化登记前底账

用途：本文件保存北周法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以557年宇文觉代西魏至581年杨坚代周为朝代边界。二十五篇大律在西魏时期启动、北周保定三年完成，按跨朝连续生命周期登记于实际交付的北周；西魏已经颁行的苏绰五卷简制不重复计分。

## 一、北周法律治理总判断

北周法律治理依次经历：

> 西魏以来的完整编律工程在保定三年完成二十五篇大律，但条流苛密、烦而不要 → 宇文护以宽政取人心却放任子弟僚属弄权，百姓控告无门 → 周武帝诛护后严正用法，并在灭北齐后释放全部杂户为百姓 → 对新占地区又以《刑书要制》设置极低死刑门槛 → 周宣帝在宽法、频赦和极端严刑间反复，以天杖和微罪重罚制造系统恐惧 → 杨坚辅政后删略旧律、恢复宽大并获颁行。

北周的正向主峰是释放世袭杂户身份；负向主峰是宣帝把法律变成随个人政治需要反复摆动的惩罚工具。大律恢复完整法典有制度价值，但相对北齐河清律更繁密，不能当作更高文明阶段。

## 三、法律运行档位在北周的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典或命令已经形成，未见施行 |
| L1 | 至少一次明确处置、释放或身份改变 |
| L2 | 全国法源或颁行规则进入运行 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张或无法核定的推断 |

大律和杨坚新制均明确颁行，定L2；释放杂户产生全国身份改变，定L3；宣帝刑政跨多轮政策和多年运行，定L4。

## 四、方向、归责与去重原则

- 大律从宇文泰、赵肃到拓跋迪跨两朝完成，作为一个生命周期登记；只给开创、领衔和最终采纳者分层归责。
- 宇文护的负向不是“法律宽”本身，而是其亲属僚属不受规则约束、民众无处申诉。
- 周武帝释放杂户与严正用法分开登记：前者消除世袭身份，后者是阶段运行；随后极低死刑门槛不能用“欺诈减少”转成正向。
- 杨坚辅政新制发生在北周国号下，归北周节点；其后开皇律另按隋朝新生命周期结算。

## 六、未纳入联合底账的材料

- 大律中的每一刑等、赎额、皇族隐狱和家属配役：均作为法典生命周期强度限制，不逐条拆分。
- 周武帝“中外肃然”不等于犯罪率或普遍幸福，只支持阶段性规则恢复。
- 周宣帝每次赦令、天杖个案和谏歌者死亡：合并为同一刑政反复机制，不按事件数量重复扣分。
- 北周灭亡：不作为独立法律治理结果。
