# 北齐法律治理结构化登记前底账

用途：本文件保存北齐法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以550年高洋代东魏至577年北周灭齐为朝代边界。东魏武定年间已经恢复相对严明的旧律运行；北齐的比较重点是能否从沿用魏律和“变法从事”转为稳定法典，以及新法典能否约束皇帝、权格和权幸。

## 一、北齐法律治理总判断

北齐呈现极强的法典技术与实际权力分裂：

> 文宣帝初年仍沿魏律且常以变法从事，设棒处死请托使者后接受宋轨意见撤销 → 天保六年后皇帝法外酷杀、供御囚和酷刑逼供形成系统恐怖 → 为防罪犯反告而设的案劾格反向激励抢先诬告，大狱动辄千人并拖延多年 → 武成帝催成十二篇河清律，法令简明且法律讲习提高可知性 → 并行权令、权格和后主权幸又逐步架空律典。

北齐的文明进步主峰是河清律的简明结构、法律讲习和疑罪从轻取向；负向主峰则是最高权力把死囚和刑讯变成任意工具，以及后期以平行法源和权幸操纵轻重。

## 三、法律运行档位在北齐的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典或命令已形成，未见适用 |
| L1 | 至少一次明确撤销、改判或责任结果 |
| L2 | 全国法源、讲习或常规程序进入反复适用 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张或无法核定的推断 |

文宣帝酷暴贯穿天保六年后并同时进入皇帝处刑和官府刑讯，达到L4；权格从高归彦案后延续至后主时期，也达到跨阶段L4。河清律有全国法源和可知性结果，定L3。

## 四、方向、归责与去重原则

- 设棒制度从过重创制到正式撤销作为一个纠偏生命周期登记；没有死亡规模证据，不虚造此前全国伤亡。
- 杨愔等维持部分日常行政不能冲销文宣帝本人法外杀戮和官府酷讯，只按其实际缓冲作用保留正向R档。
- 河清律与并行权令、权格分开：前者提高规则结构和可知性，后者使司法官能按意愿轻重比附。
- 北齐灭亡不计分；后主节点只计算权幸用法打击异己和正式法源被架空。

## 六、未纳入联合底账的材料

- 孝昭帝意图纠正文宣失政：在位短且未形成完成改革，不登记成果。
- 河清律每一刑等、赎额和宗室例外：作为法典生命周期的强度限制，不逐条拆账。
- 文宣帝时期“主昏于上、政清于下”：只证明杨愔等存在局部缓冲，不能反转皇帝节点方向。
- 政权灭亡：不作为独立法律治理负分。
