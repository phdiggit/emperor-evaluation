# 陈朝法律治理结构化登记前底账

用途：本文件保存陈朝法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿以557年陈霸先代梁至589年隋灭陈为朝代边界。陈律大体沿用梁法，梁朝已经具备成文法典、录囚和刑具规范；陈朝只能按乱后恢复、相对梁制的具体增损及实际运行归责，不能把沿用部分重新算作开创。

## 一、陈朝法律治理总判断

陈朝法律治理经历连续反转：

> 陈武帝在梁末丧乱后重新编定律令并建立定期巡狱 → 新律同时恢复父母缘坐、保留严酷测罚和身份差序 → 陈文帝以亲览狱讼打破部分功臣贵戚法外，但执行趋于峻刻 → 陈宣帝由简易宽政滑向法令不立，北伐负担又放大盗乱 → 陈后主时期司法交易、命令失效与法外夷戮合流。

陈朝最大的正向是乱后恢复可运行的成文法与巡狱程序；最大的负向不是法典“条文多”，而是后期司法权商品化、最高权力任意杀戮并使正式赏罚不能贯彻。

## 三、法律运行档位在陈朝的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典或命令已经交付，未见适用 |
| L1 | 至少一次明确裁判、免除或责任结果 |
| L2 | 全国法源、定期程序或规则进入反复适用 |
| L3 | 群体、阶段或系统层面出现方向性汇总结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有理论主张、抽象称颂或无法核定的推断 |

陈初法典和每年三月巡狱达到L2；文帝、宣帝各有阶段性运行汇总，定L3。后主负向贯穿其在位阶段，并同时覆盖司法交易、命令执行和皇帝刑杀，达到严格L4。

## 四、方向、归责与去重原则

- 陈律的乱后恢复与其恢复父母缘坐分别结算：前者改善法源和复核，后者新增无行为亲属责任，不用一个mixed标签掩盖两个可分机制。
- 文帝对贵戚依法和刑政峻刻发生在同一“亲览严明”运行机制中，保留为M档；审计解释两向原因，联合底账不再要求二次阅读后拆分。
- 宣帝后期盗乱不能全部归因于宽刑，史源同时写明连续北伐和民众疲敝；只归其法令不立及未维持司法运行的责任。
- 陈亡不是单独计分结果；后主节点只计算已有直接证据的司法市场化、命令失效和法外夷戮。

## 六、未纳入联合底账的材料

- 陈律沿用梁律的其余篇目、刑等和身份规则：没有相对前制的独立重大改变，不重复登记。
- 宣帝初期“上下便之”：只有阶段感受，且随后法令失效，不另拆一个短期正向节点冲销后果。
- 陈朝灭亡：受战争、财政和政治等多因素影响，不把亡国本身作为法律治理负分。
- 编修名单中未见独立设计行为者：保留史源列名，不平均分配人才责任。
