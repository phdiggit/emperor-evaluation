# 隋代法律治理结构化登记前底账

用途：本文件保存隋代法律治理的登记前综合结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

## 一、隋代法律治理总判断

隋代法律治理的主线是：

> 北周末刑制反复、天杖与微罪重罚 → 开皇初统一南北法制，废除枭首、轘裂、鞭刑和法外刑讯 → 开皇三年再次删繁减死，形成十二篇五百条 → 废除孥戮相坐、建立死刑大理复核与三奏 → 文帝晚年以宫廷杖杀、告密诱捕、律外决杖和深文酷吏持续破坏成法 → 大业律一度减轻二百余条 → 炀帝中后期弃置法典，恢复族诛、轘裂、枭首和不分轻重的盗窃死刑，最终形成全国性司法失序。

隋代的正向主峰是把北周末严酷而反复的刑政改造成全国统一、简要且可申诉复核的法律体系；负向主峰不是法典中仍有流刑、配役等残余刑罚，而是文帝晚年和炀帝中后期主动突破、弃置既定法律，重新扩大死刑、连坐和法外处置。

- 十二篇、五刑和官当等制度已有北齐、北周基线；开皇律的增量是统一、删繁、减酷和程序化，不把继承部分算作隋代原创。

- 大业律的正向交付与炀帝随后弃法分账；后者不能抹掉前者已经发生的减刑，但在人物净责任中占明显主导。

## 三、法律运行档位在隋代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法典或命令已经形成，未见实际适用 |
| L1 | 至少一次明确改判、释放、执行或社会响应 |
| L2 | 全国法源、申诉或复核程序进入常规运行 |
| L3 | 群体、阶段或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

开皇法典、申诉和复核均有全国颁行或常规程序证据，定L2；晚年深文酷法横跨开皇十七年至仁寿并形成系统冤滥，定L4；大业律虽有百姓欢迎，但稳定运行很快被弃置，只定L1。

## 四、方向、归责与去重原则

- 开皇初次定律和三年再次删定分别改变刑罚体系与法典规模，作为两轮重大变革登记；同轮内部条文不再碎分。
- 废除孥戮相坐与死刑复核保护不同人群、机制不同，分别登记。
- 文帝宫廷杖杀、告密极刑和后期深文体系按机制分账，但同一机制下的瓜、榱、马粪等个案不重复扣分。
- 来旷案由死改为流放是同一案件的明确减刑；流刑只是正向幅度的限制，不另生负向采用责任。
- 普通参修、例行法司和沿用者不计；只给最终决定者、核心设计者、关键抗辩者及主动建立或维持酷法者定R档。

## 六、未纳入联合底账的材料

- 官当、八议、赎刑等继承性特权：用于限制开皇法典的进步幅度；没有隋代新增或扩大证据时不另立负向节点。
- 停废律博士与律生：可能减少技术垄断，也可能削弱专业司法，现有运行证据不足，留作审计而不定向。
- 文帝季节禁杀争论、佛道神像恶逆条款和单一法外处死：能够说明运行倾向，但已被晚年深文节点吸收，不按个案数重复扣分。
- “百姓喜于刑宽”只支持大业律至少进入社会运行，不证明全国犯罪率或长期司法改善。
- 隋末国家崩溃不是独立法律治理节点，只作为弃法、滥刑和地方专擅的结果边界。
