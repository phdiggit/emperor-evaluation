# 五代法律治理结构化登记前底账

用途：本文件保存后梁、后唐、后晋、后汉、后周法律治理的连续登记前结论。**正式计分只读取[秦至清法律治理联合底账](../联合统筹/01-秦至清法律治理联合底账.md)；本文件第五节保留节点原档和审计说明，供联合底账回源，不作为并列评分入口。**

本稿合并五个短期政权，是因为现存《旧五代史·刑法志》本身以唐法散失、恢复、编敕累积和后周整合为连续生命周期；第五节仍逐行标明具体政权和人物，不把不同皇帝责任合并计算。

## 一、五代法律治理总判断

五代法律治理的主线是：

> 后梁删定并颁行新法但破坏唐代法书 → 后唐恢复唐法并重建法源，又建立录囚、死刑覆奏、医囚和雪冤激励 → 后晋继续死刑报核和疑案上讞，却另设和奸死刑，地方律外刑仍盛 → 后汉藩镇奏杀缺乏中央事实复核 → 后周撤销和奸死刑、限制连坐籍没，并最终把唐律、五代格敕整合为《大周刑统》。

这一时期的正向主峰不是创造全新法律体系，而是在战乱散失和多头法源下重新恢复可检索、可复核的统一法律；负向主峰是临时重刑和军镇权力把私人意志直接转化为国家刑罚。

## 三、法律运行档位在五代的使用

| 档位 | 本稿采用边界 |
|---|---|
| L0 | 法书或命令已经形成，未见适用 |
| L1 | 至少一次明确适用、释放、处置或改变 |
| L2 | 全国颁行、跨机关程序或多次实际运行 |
| L3 | 政权、区域或系统层面出现方向性结果 |
| L4 | 同方向结果跨多年、跨区域或跨阶段持续 |
| LX | 只有主张或无法核定的推断 |

法书恢复、狱政程序和《大周刑统》均进入颁行或多次运行，定L2；现有材料没有足以证明五代某项正向司法效果稳定跨越多年和区域的L4证据。

## 四、方向、归责与去重原则

- 后唐首创的录囚、覆奏、医囚改革族集中登记；后晋、后周的普通重复申令不再占开创贡献，只有新增报核层级、疑案上讞和律外刑禁止另记重大变革。
- 后晋和奸死刑与后周撤销分别分账；后周纠偏不倒改后晋责任。
- 《大周刑统》只结算法源整合、解释和旧入口退出，不把其吸收的唐律条文重新算作后周原创。
- 后汉军镇专杀的系统问题成立；默认只给刘承祐有限监督责任，不虚构具体授权，也不向匿名藩镇和承办者平均归责。

## 六、未纳入联合底账的材料

- 后唐至后周每一道普通疏狱、暑月放囚和清扫监狱诏：已由改革族吸收，不按重复诏令数量计分。
- “百余日不决”、胥吏追证勒索：用于限制正向运行档，不另拆成大量负向个案。
- 后晋、后周官当赎规则：具有规范化与身份特权双重面向，现有材料不足以判定净变化。
- 法书卷数只证明保存、散失和整理规模，不以卷数多少判断文明进步。
- 《大周刑统》后来被宋承接属于历史影响，不替代本朝实际颁行证据，也不提前结算宋代成果。
