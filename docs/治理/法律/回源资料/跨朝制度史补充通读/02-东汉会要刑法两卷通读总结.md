# 《东汉会要》刑法两卷通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

## 一、材料定位

本次通读《东汉会要》卷三十五、三十六。它以《后汉书》本纪、列传、百官志、礼仪志等材料重组法令、刑制、恤刑、赎罪、狱制和断狱程序，能够补足既有东汉底账的节点链和具名归责。

相对于《晋书·刑法志》的制度骨架及此前已读列传，这两卷的主要增量是：

1. 光武、章帝、和帝朝具体删法、减刑和程序规则；
2. 陈宠、郭躬、张敏、陈忠、刘恺、鲁恭等人的提议—采用关系；
3. “四十一事皆施行”“五十余事定著于令”“亡命无虑万人”“济活甚众”等有边界的运行证据；
4. 没有实施的梁统重法方案、陈宠总删律方案，与实际落地改革的清楚区分。

## 二、主要节点和归责

### 1. 光武恢复轻法与若干明确边界

光武以解除王莽繁密、恢复汉代轻法为总方向，但不能只凭概括语登记一个高强度成果。可以确认的实际规则包括：

- 杀奴婢不得减罪，明确提高奴婢生命的刑法保护；
- 边郡盗谷五十斛即死被废除并与内郡统一，关闭地方酷吏借法杀人的通道；
- 八十以上、十岁以下及妇人从坐者原则上不得拘系；
- 女徒可归家、按月出钱雇人服山作。

这些规则可合并为光武初年缩小身份、地域和从坐差异的正向节点，达到 `P2·L2`。刘秀承担最终采用 `+R4`；未见同等明确的具名设计者。

桓谭提出统一科比、消除同罪异判，未被采纳；梁统多次主张恢复重法，也被搁置。两者都只能进入决策审计，不能作为已实现成果。

### 2. 阻止增科与章帝删酷法

群臣以法轻为由要求增加禁科，杜林反对以小事积成大罪，光武采纳而未增法。此事是阻止倒退的明确决定，但没有产生独立的新制度和运行结果，宜作为光武节点的审计补充，不拆分计分。

章帝即位后，陈宠指出尚书决事仍以酷刑、威吓和文致为常，皇帝采纳后：

- 禁绝钻钻等酷烈刑讯；
- 解除妖恶禁；
- 删除文致请谳五十余事并定著为令；
- 明定榜笞和刑具边界；
- 纠举逼迫无辜自杀的官吏。

这构成“问题诊断—皇帝采用—法令交付—司法风格变化”的连续改革。祥瑞和灾异不作证据；“狱法和平”只能与具体制度和运行材料合用。

- **方向与运行**：`P3·L3`，并与和帝期陈宠复核运行合成跨阶段 `L4` 改革链。
- **归责**：刘炟 `+R4`；陈宠为核心诊断、设计和运行者 `+R4`。

### 3. 郭躬的四十一项从轻规则

郭躬把可从轻的四十一项重文逐条奏请，全部施行著令；章和赦令漏掉赦前犯罪、赦后才捕获的亡命者时，他又推动统一适用，使大量原本将被重判者减死戍边。

- **方向**：明确减刑与统一适用，`P2`。
- **运行**：规则成批适用，并有“亡命无虑万人”的群体范围，取 `L3`。
- **归责**：刘炟最终采用 `+R4`；郭躬是关键设计与纠偏者 `+R4`。
- **边界**：减死以后戍边是同一案件中的剩余生刑，不另造负向责任。

### 4. 轻侮复仇比的扩张和废止

章帝曾因一名受辱父亲之子杀人而减死，后来这个一次性恩典扩成四五百条轻侮比，给执法者任意比附和杀人减罪留下空间。张敏反复指出这一机制并非稳定成科、实际会扩大相杀和法吏操纵，和帝最终采纳并废除。

- **章帝责任**：开放并容许规则扩张，形成 `N2·L3` 的独立负向节点；刘炟 `-R4`。若只登记和帝废止，便会漏掉负向制度的创制责任。
- **和帝纠偏**：关闭开放式杀人减刑例外并恢复规则统一，`P2·L2`；刘肇 `+R4`、张敏 `+R4`。
- **边界**：正向价值来自关闭任意扩张的杀人豁免，而不是“重新判死更文明”。

### 5. 陈宠总删律未成与陈忠实体改革

和帝时陈宠核校发现律令死刑六百一十、耐罪一千六百九十八、赎罪以下二千六百八十一，主张删去超出三千之数的一千九百八十九项，并统一三家律说。方案未及实施即因陈宠免职而中止，不能登记为成果。

陈忠随后据其父思路形成决事比二十三条，并实际施行：

- 废除蚕室刑；
- 解除赃吏子孙三世禁锢；
- 精神失常杀人减重论；
- 母子兄弟代死时赦免被代者等。

刘恺在叔孙光、范邠赃罪案中明确主张“恶恶止其身”，皇帝采纳，直接支撑解除代际禁锢。

- **方向与运行**：`P2·L2`，不是只有文本交付。
- **归责**：陈忠 `+R4`；刘恺对代际禁锢的决定性论证 `+R3`。最终采用者涉及和帝末、邓太后和安帝初的跨节点材料，未完成逐条时序前不能笼统给某一皇帝 `+R4`。

### 6. 应劭在战乱中保存旧章

董卓毁坏典宪后，应劭汇集律本章句、尚书旧事、廷尉板令、决事比、诏书及议驳，删去重复，形成二百五十篇主体及补充议论。献帝认可。

- **方向与运行**：这是战乱中的法源保存和整理，`P2·L0`；不能说已恢复全国统一司法运行。
- **归责**：应劭为编纂主责 `+R4`；刘协只是认可而无持续推动证据，`+R2`。

### 7. 季节断狱制度的变动

章帝把重狱裁断缩到十月，并采陈宠意见维持。此后地方为赶期限，出现“不问曲直便即格杀”和疑罪不能复核。鲁恭反复说明制度的实际副作用，邓太后组织公卿复议，最终恢复冬月详断、立春后不报囚的规则。

这不是单纯历法或灾异问题，而是制度期限影响审判质量：

- 章帝改革有减少冬季行刑期的表面宽刑方向，却造成集中赶判和疑罪复核不足，宜为 `M2·L3`；刘炟、陈宠承担 `±R4`。
- 鲁恭推动恢复充分复核期，邓绥最终采用，宜为 `P2·L2`；鲁恭、邓绥各 `+R4`。
- 旱灾、阴阳解释全部排除，只使用“赶判格杀、疑罪不讞”等运行材料。

## 三、长期恤刑和赎罪材料的边界

两卷记录大量减死、徙边、赎罪、录囚和赦令。不能逐诏计分：

- 死刑减为戍边、徒刑或赎罪，方向上仍是减刑；剩余处分只限制正向强度。
- 皇帝亲录囚徒只有在发现冤狱、成批减害或形成常规程序时才提供运行证据。
- 以钱帛赎罪长期存在明显的财富差异，应在跨朝统一校准中识别初创者和重大扩张者；普通沿用者不登记。
- 灾异后赦免、降雨、祥瑞等不提供因果或运行证明。

## 四、对现有东汉底账的修订结论

1. 新增光武缩小奴婢、边郡和从坐差别的 `P2·L2` 节点；原“恢复听讼并拒绝重法”可并入审计，不再承担全部光武正向结论。
2. 把章帝轻侮复仇比的开放和扩张登记为 `N2·L3`，与和帝废止节点分开。
3. 陈忠节点补入刘恺的代际禁锢纠偏贡献；皇帝归责保持待逐条核对，不强行统一。
4. 新增章帝缩短断狱期的 `M2·L3` 与邓太后、鲁恭恢复复核期的 `P2·L2`。
5. 梁统重法、桓谭统一科比、陈宠总删一千九百八十九事均因未实施而不进入评分入口。
6. 大量赦令和减死诏只为已有恤刑趋势提供运行背景，不按次数制造节点。
