# 《旧唐书》《新唐书·刑法志》双史互证通读总结

> 定位：回源与上下文审计材料，不作为并列评分入口。涉及方向、档位、归责或人才门槛的阶段性表述，均以[秦至清法律治理联合底账](../../联合统筹/01-秦至清法律治理联合底账.md)当前值为准。

> 状态：《旧唐书》卷五十、《新唐书》卷五十六按固定正文全文重读；隋→唐基线、制度文本、实际运行、效果后果和人物参与已合并校准。同一事项只登记一次；正式归责仍须本纪、本传、奏议补强。

## 一、篇章性质、双史分工与中心判断

两篇《刑法志》都不是单纯的法典目录，而是在解释一条完整生命周期：

> 唐初如何继承隋制并从隋末弃法中恢复法律秩序，贞观如何把减刑、复核、狱政和官僚激励结合成实际运行，永徽如何完成法律解释制度化；又如何从高宗后期开始，在格敕增殖、刑讯失控、武周告密、玄宗后期政治大狱和安史以后临时处分中逐步失稳。

两史分工不同：

- 《旧唐书》保存编律人员、条数、刑具、狱政、复核、案件、伤亡和中晚唐格敕整理的细节，是制度与运行主篇；
- 《新唐书》更强调长时段盛衰，补充武德录囚、贞观实际死刑数和狱政条目、高宗以后刑滥、开元前后运行反转，以及代宗至宣宗的统治效果；
- 两史相同叙述只构成一项事实；史家评论不自动等同于实际效果；
- 《新唐书》把宋璟修《开元后格》误系开元二十六年，《旧唐书》所记开元七年与宋璟卒年相合，此处采用《旧唐书》次序。

双史校准后，不能再笼统说“贞观第一、永徽第二”。更准确的分层是：

- **贞观**：制度改革与实际运行共同构成唐代正向主峰；
- **永徽前期**：法律解释和规范体系的制度化高点；
- **高宗朝整体运行**：早期狱囚少、承继贞观，随后已出现深文、笞杖致死和三司刑讯失控，不能整体列为第二治理高峰；
- **开元前中期**：第二个显著运行高点，但后期发生清楚反转；
- **武周**：负向主峰；
- **肃宗以后**：仍有重要纠偏，却多为局部、短期措施，无法恢复唐初稳定法制。

## 二、隋唐直接基线

开皇律已经形成十二篇、五百条和笞、杖、徒、流、死五刑，废除枭首、轘裂等酷刑，存在八议、赎刑、官当、刑讯限制、申诉和死刑三奏。大业律文本也曾从轻。唐朝接手的不是法律空白。

但隋文帝晚年以特旨杀人，炀帝在战争、征发和盗乱中以即时处斩、族诛架空律典。唐初的真实起点因而有两层：

1. **制度基线**：隋已有成熟统一法典；
2. **运行基线**：隋末法律秩序崩溃、法外杀戮扩张。

因此，唐代成果必须分别标注继承、恢复、增量改革和实际运行，不能把沿用隋制的五刑、十二篇、复核制度全算成唐代原创。

## 三、武德：有限改法与秩序恢复

### 1. 立法内容

高祖入长安约法十二条，受禅后命刘文静等以开皇律令为基础，删除大业烦峻之法，制定五十三条格；裴寂、萧瑀等十五人继续编成五百条律，武德七年颁行。

《新唐书》补明，武德律除把五十三条新格纳入外，“余无所改”；流刑距离反而增加，部分居作年限则缩为一年。因此其法典原创增量有限，不能仅凭“颁行天下”列为唐代结构性创新。

### 2. 实际运行

高祖武德四年亲自录囚，考虑战乱中冒法者众，赦免未劫伤事主的盗犯、部分逃亡者，但官吏枉法不在宽免之列。又规定特定月份和断屠日不行刑。

这表明武德的宽简不只停留在颁布文本，至少有一次明确的分类录囚和实际释放；同时它仍以战乱后的临时宽宥为主，尚不足证明长期稳定运行。

### 3. 初判

| 观察面 | 判断 |
|---|---|
| 法典原创 | 有限，大体继承开皇律 |
| 秩序恢复 | 明显，从隋末弃法转回全国统一规范 |
| 运行证据 | 有录囚、分类宽免，但连续性有限 |
| 方向与强度 | `positive / significant`；历史角色为 restoration |

## 四、贞观：制度与运行共同达到主峰

### 1. 绞刑改断趾，再改加役流

戴胄、魏征等认为旧律过重，议将五十条绞刑改为断右趾。适用对象原本应死，改革后“多蒙全活”，所以相对同一场景首先是明确减刑：

- 原基线：绞死；
- 新结果：保全生命、永久残足；
- 方向：`positive`；
- 强度：`significant`；
- 限制：隋已废肉刑，这不是完整文明跃迁。

现有材料没有证明断趾新增适用于原来不判死的人群，不能仅因肉刑重新出现就判 mixed。

太宗随后因不忍残肢要求重议。裴弘献驳律令四十余事，房玄龄等指出另设刖刑会使五刑变六刑，遂改为流三千里、居作二年。这是在保命基础上进一步消除永久身体残害，仍是正向纠偏。登记时可把两步合为“贞观死刑替代连续改革”，内部保存两个阶段，避免重复结算。

### 2. 连坐和死刑范围缩小

房强因弟谋反应连坐处死，太宗录囚时要求区分实际兴兵与恶言犯法。房玄龄等重新调整祖孙、兄弟缘坐：部分死刑降为配没或流放。贞观律相对隋律减少大辟九十二条、流刑降徒七十一条，史称死刑较古制约减一半。

这是全国性、可量化的刑罚结构变化，方向 `positive / structural`。但谋反连坐、配没和身份差等仍存在，不能写成“废除连坐”。

### 3. 律、令、格、式的重构与稳定

贞观律仍为十二篇五百条，继承隋制；真正增量在于：

- 系统降低死、流等刑级；
- 调整政治犯罪责任边界；
- 制定令一千五百余条；
- 将武德以来三千余件敕格删至七百；
- 形成律、令、格、式协同适用；
- 《新唐书》明确记载房玄龄等定制后，终太宗一朝没有随意改变。

因此，贞观的结构性贡献不仅是“修了一部律”，而是减少刑罚、清理临时规则并保持长期稳定运行。

### 4. 刑讯、狱政和囚犯生存条件

双史合读后，贞观运行颗粒度必须包括：

- 枷、杻、钳、锁和笞杖尺寸统一，按罪轻重使用；
- 拷讯最多三次、总数不超过二百，轻罪不得超过本刑数；
- 京师监狱长官五日一虑囚，御史巡狱；
- 夏季供浆饮，每月沐浴，疾病给医药，重病者释械并允许家人照护；
- 流人途中遇病、产乳、丧事等可给假并供程粮；
- 居作者有休假、病假和解除刑具规则；
- 无亲属的死者由官府给棺、标识埋葬，家属可取回；
- 立春至秋分、斋祭、朔望、节气、雨天、夜间和特定月份暂停死刑。

开皇已有刑讯限制，故唐代不是首次创设；但这些条目把复核、卫生、疾病、照护、劳役和尸体处置连成一套可运行的狱政体系，属于 `positive / structural` 的运行制度化。

### 5. 禁止鞭背

太宗看到脏腑近背，认识到轻刑可能意外致死，遂禁止鞭背。它直接改变行刑部位和死亡风险，属于 `positive / significant`，可并入贞观刑讯与狱政组合，不另作重复主成果。

### 6. 张蕴古案、五覆奏与门下复理

张蕴古认为李好德有癫疾、依法不应定罪，权万纪则指控张蕴古存在地方关系和狱中交往。太宗在争议未充分复核时“怒，遽斩蕴古”，随后后悔。因此可以判断死刑决定仓促、复核不足，但不能只凭皇帝后悔便断定张蕴古完全无过。卢祖尚案上下文更少，也只保留程序失当判断，不提前定为冤案。

太宗由此把京师死刑从三覆奏加密为两日五覆奏，地方保持三覆奏，并要求门下对依法当死但情可宥者上奏。《旧唐书》明载“自是全活者甚众”。

因此这条生命周期应完整登记：

> 争议案件仓促处死、复核不足 → 认识死刑不可逆 → 增加复核时间与情理复理 → 实际救活多人。

纠偏成果为 `positive / significant`，但不能因为后来建立复核制度，就把此前仓促处分只写成皇帝自我改正的美德；皇帝窗口中程序失当和纠偏责任均须保留。

### 7. 失入失出的司法激励纠偏

张蕴古被杀后，法官害怕轻纵获罪，宁可深文入罪。刘德威指出，现实执行把失出看得过重、失入反而无责，导致系统性重判。太宗命按律同时追究失入失出，史称断狱渐趋平允。

这是典型的“规则—官僚激励—运行结果”链：

> 轻判风险过高 → 法官普遍趋重 → 问责重新对称 → 审判趋于平允。

方向 `positive / significant`，刘德威承担明确的问题诊断和方案责任。

### 8. 可观察成效

《新唐书》提供的运行结果不能遗漏：

- 贞观四年全国断死罪二十九人；
- 贞观六年太宗暂释三百九十名死囚归家，届期皆返回，最终全赦；
- 贞观律令格式终其一朝保持稳定；
- 五覆奏和门下复理实际“全活者甚众”；
- 失入失出纠偏后断狱趋于平允；
- 流刑调整后，史称犯罪者渐少。

二十九名死刑可以证明该年度正式死刑裁判较少，不能直接外推全国犯罪率；三百九十名死囚归返可以证明史书所记的录囚与赦免事件，不能直接外推全民诚信。两项均不因数字醒目就判假，也不承担超出记载范围的证明任务。与法律稳定、复核救生和法官行为变化合并后，可以支持贞观出现了可观察的运行成效。

### 9. 限制与负向事实

- 八议、请减、赎刑、官当继续制造身份差等，主要继承隋制；若未证明唐代扩大，不作为贞观新增负向；
- 党仁弘因严重违法依法当死，太宗因其旧功减为免官。结合唐律“议功”和群臣意见，只能确认功臣身份改变了刑罚结果；不能仅据皇帝自责判为徇私，方向暂缓；
- 流人被配置边远恶州，死罪者又被迁往西州、流人戍边，具有刑罚减轻与边疆强制利用并存的成本，须按具体适用场景另核；
- 张蕴古、卢祖尚被处死以及复核不足是事实；“冤杀”定性须分别补证，不能由皇帝后悔直接推出。

## 五、永徽及高宗朝：制度高点与运行恶化分叉

### 1. 早期继承贞观运行

高宗初即位遵贞观故事。唐临报告在押仅五十余人、其中二人应死，高宗以囚数少而喜。这是早期刑狱较轻的运行证据，但只是一个时点，不能外推整朝。

### 2. 《律疏》和解释统一

长孙无忌、李勣、于志宁、唐临等编定律令格式，把常务规则分为留司格、全国通行规则分为散颁格；永徽三年起编《律疏》三十卷，四年颁行，断狱自此据疏解释。

相对贞观，它的独立增量是：

- 统一法条解释；
- 给明法考试和司法人员提供固定依据；
- 降低同律异解；
- 把贞观成果转化为可传承的法律知识体系。

应判 `positive / structural`，历史角色是 institutional consolidation，而非新建刑罚体系。

### 3. 对深文文化的识别

永徽五年，高宗询问刑罚是否枉滥，长孙无忌指出：宽平者被称痴人，深文者被称能吏；本应杖者被判徒，可生者被判死。高宗认可这一诊断。

该材料证明，贞观纠正过的司法激励并未永久消失。这里只有问题诊断和皇帝表态，没有明确制度改造及效果，不能登记为已完成正向成果。

### 4. 规范整理与废《法例》

高宗时期多次因官号变化修订格式；赵仁本另撰《法例》三卷，高宗认为会在律、令、格、式之外增加疑义，令其废止。这是控制规范增殖的正向纠偏，可并入解释统一组合。

### 5. 《新唐书》补出的运行反证

《新唐书》明确记载“自永徽以后”刑罚开始泛滥：

- 大狱由刑部、御史台、大理寺三司杂按；
- 法吏以惨酷为能；
- 囚犯不解枷而遭笞棰致死；
- 杖百条目五十九项，有人刑未执行完已经死亡；
- 后来删除其中四十九项仍“无益”，说明文本减条未改变运行。

这组材料推翻的不是《律疏》的制度贡献，而是“永徽法典成熟等于高宗朝刑政治理整体高峰”的推断。高宗朝必须形成两条独立成果链：

1. `positive / structural`：《律疏》及解释统一；
2. `negative / structural candidate`：深文激励、三司酷刑和笞杖致死的实际运行恶化。

《新唐书》带有强烈史家褒贬，具体责任时间还须用本纪、本传细分给高宗、武则天和法司，不能把“自永徽以后”的全部负面平均归给永徽修律人员。

## 六、武周：详密法典与告密酷吏并行

### 1. 格式整理本身

武则天命裴居道、岑长倩、韦方质等编《垂拱格》《式》，大体沿用旧律，只改二十四条。史家称韦方质、王守慎所定格式详密。

这说明武周不是“完全无法”，正式法典仍在整理；也正因为如此，后面的酷吏体系应判为对正式法律的架空，而不是法典缺失。

### 2. 四匦的实际运行

四匦扩大求仕、谏政、申冤和军谋灾异的直接投书入口。投入运行后，立即出现攻击阴私和诽谤朝政，朝廷随后要求投书者由官员识认，并派中书、门下官监督。

现有材料证明入口开放、恶意材料出现和准入收紧，却尚未直接证明某一无辜者仅因四匦材料被定罪。因此：

- 渠道扩展可暂判 `positive / significant`；
- 恶意告讦是明确运行成本；
- mixed 须等待同一入口造成实际伤害的证据；
- 后续国家支持的告密酷吏体系另作独立负向成果。

### 3. 告密、酷吏和罗织体系

徐敬业等起兵后，武则天因恐惧人心动摇而启用酷吏、秘密告发和特别推事院。《旧唐书》保存了可量化的实际后果：

- 万国俊先杀广州流人三百余，再伪造反状；
- 刘光业一路杀九百人，王德寿杀七百人，其他各路少者亦数百；
- 杂犯和多年以前的流人也被牵连；
- 来俊臣等招集数百告事者，编《告密罗织经》，系统制造反状；
- 醋灌鼻、火围瓮、绝粮、粪秽和十号大枷用于逼供；
- 赦书下达时，先杀重囚再宣赦；
- “一人被告，百人满狱”，大量告密查无实据；
- 海内恐惧、道路以目。

这是完整的负向机制和结果链：

> 政权不安全感 → 奖励告密和酷吏 → 特别机关、伪证与刑讯 → 大规模误杀和恐惧 → 正式法司、赦免和正常证据规则被架空。

方向 `negative / structural`，达到 `era_shaping` 候选。《告密罗织经》是机制证据，不另行重复计分。

### 4. 反对、纠错和清算

陈子昂、周矩等提出反对，但奏疏不被采纳，只能记失败纠偏，不能登记成果。陈子昂把旱灾归因冤狱属于当时政治论证，不作为现代意义上的因果证据；其“一人被告、百人满狱”等观察仍可作为运行材料。

徐有功持续与酷吏廷争，史称救活者不可胜数，构成跨案件的 `positive / significant` 司法纠偏。后来：

- 酷吏被诛后刑狱稍息；
- 王及善、姚崇、朱敬则等推动复查；
- 三司重审来俊臣等案件，有冤者雪免；
- 中宗追赠徐有功、授一子官；
- 丘神勣、来俊臣等二十三人被追夺官爵；
- 史称天下称庆。

这些是实际平反和制度清算，能登记为独立正向纠偏，但不能抵销先前死亡和恐惧。

## 七、开元：第二运行高点及其反转

### 1. 规范清理

开元初多次整理律、令、格、式。李林甫等修订时处理七千零二十六条：删除一千三百二十四条，修改二千一百八十条，保留三千五百九十四条，另编事类便于检索并向全国发五十本。

这是一项显著的规范清理和可用性改进，方向 `positive / significant`。但相对贞观从三千余敕删至七百，开元仍反映制敕重新大量累积。

### 2. 前二十年的实际成效

《新唐书》将开元前二十年的低刑狱与整体治理联系起来：良吏进入州县、民生和衣食改善、人少犯法；开元二十五年全国死刑五十八人。《旧唐书》记大理狱出现鹊巢、百官称贺，这是象征叙事，不能独立当统计证据。

低死刑数、较少犯罪的记载与规范清理、地方官运行合并后，可以支持开元前中期为唐代第二个 `positive / structural` 运行高点，但制度原创性低于贞观。

### 3. 李林甫政治大狱和战争财政后果

同一时期随后发生明显反转：

- 李林甫重新发动政治大狱，韦坚、李邕等数十至百人被诬杀；
- 玄宗追求边功，战争失败造成士卒死伤以万计；
- 国用耗乏、转漕烦费、民力疲弊；
- 盗贼兴起，狱讼随之增加。

玄宗后来下诏免除部分徒杖、照顾老人重病和侍丁，但《新唐书》明确说巨盗已起，民众没有实际普遍获得这些恩惠。

因此开元、天宝不能合成一个正向时代标签，而应记录：

> 前期地方治理和法制运行改善 → 低刑狱；后期政治司法、战争财政负担扩大 → 盗讼增加和宽刑措施失效。

## 八、肃宗：严惩脅从者造成可观察的国家后果

收复两京后，数百名陷贼官员待罪。崔器等主张重刑，李岘力争分等，肃宗本人偏好刑名，百官多唯唯署名。最终：

- 达奚珣等十一人被处死，其中有人腰斩；
- 陈希烈等七人赐死；
- 二十一人重杖致死；
- 家属流窜；
- 三司刑狱多年不止。

更关键的是史书保存了实际行为后果：史思明、高秀岩等本已归命，闻处刑后恐惧复叛；萧华后来报告，河北官吏听说脅从者被杀，庆幸自己没有归降，此后无人敢归，战争延续。

这是本轮颗粒度最重要的范例之一：

> 处罚责任区分不足 → 归降预期恶化 → 已降者复叛、未降者不敢投降 → 战争持续。

故该项为 `negative / structural candidate`，不仅是“杀人过多”。王玙推动未结案件一律释放、肃宗临终释放流人，是实际止损；肃宗本人也承认被三司所误，但后悔不能消除既成后果。

## 九、代宗至宣宗：局部纠偏、制度摇摆与规则膨胀

### 1. 代宗：以肃宗为戒的宽刑运行

代宗对河南、河北任伪职者一切不问，释放史朝义部众妻子四百余人，不连坐仆固怀恩家属，限制特旨杖数。《新唐书》称即位五年府县寺狱无重囚。

这些措施直接逆转肃宗“惩脅从—阻归降”基线，构成 `positive / significant` 至结构性候选。不过代宗对食人盗首高玉仍以杖杀，说明宽刑并非无边界。

### 2. 德宗：取消死刑前额外重杖，处理制敕冲突

德宗时取消死囚处决前先重杖的做法，避免人在正式死刑前再受一次无必要酷刑，属 `positive / significant`。同时，至德以来临事制敕互相冲突，朝廷再次要求筛选可长期施行者，说明法源稳定性已下降。

### 3. 宪宗：宽死刑、限审期与个案衡平

宪宗拒绝李吉甫、于頔以重刑立威的建议，元和八年把十恶、杀人等之外的部分死罪改流天德五城，并允许家属随行。方向是明确减刑，适用面较广，可判 `positive / significant`。

《新唐书》作者担心宽刑使人侥幸，但没有给出犯罪实际增加的结果，不能把史家风险判断直接转成负向事实。

元和四年又规定大理、刑部及外州勘报期限，针对羁押拖延建立可执行时限；这是狱政 `positive / significant`。梁悦复仇、康买得救父等案件则显示礼、情、法冲突通过个案减死处理，属于司法衡平案例，不宜拆成全国制度成果。

### 4. 穆宗：审期细化与“参酌院”撤销

牛僧孺按案件规模细分大理、刑部审限，延续解决久系问题。穆宗另设中书舍人参与大案轻重的“参酌院”，崔杞认为其使裁判系于人情、削弱法司，随后撤销。

这条应登记为短暂的制度偏离及及时撤销，不把“增设复核”表面上自动判正向。

### 5. 文宗：禁鞭背执行失败与宦官法外杀戮

太和八年重申轻罪不得鞭背，但京兆尹韦长以治安困难请求恢复，朝廷随即允许。这证明一项正向禁令没有形成稳定运行，不能登记为完成成果。

文宗本人谨慎，但无力制止宦官杀害大臣、夷灭家族，明知冤滥而不能救止。这里的核心不是个人仁心，而是皇帝无法约束法外权力，属于 `negative / structural` 的治理能力失败。

### 6. 武宗、宣宗：盗窃死刑扩大及撤销

武宗把盗赃满千钱者改判死刑，而旧制盗窃原则上无死刑。这对原本不适用死刑的场景新增死亡，属于明确 `negative / significant` 至结构性候选。

宣宗即位后撤销该规则，是可定位的 `positive / significant` 纠偏；但《新唐书》同时评价宣宗好刑名、少仁恩。后者缺少同等具体运行结果，暂作人物画像材料，不另登记公共成果。

### 7. 格敕持续膨胀

中晚唐不断编《格后敕》《刑法格》《刑法统类》。大中时从贞观至当时二百二十四年杂敕仍有六百四十六门、二千一百六十五条。《新唐书》概括其弊：法令频繁变动、繁积到专业者不能遍习，官吏得以上下其手。

这里不能把每次编书都算成果。应登记一个制度生命周期：

> 临事制敕不断累积 → 定期整理暂时降低冲突 → 新敕继续增加 → 法律可知性、稳定性下降并扩大官吏操作空间。

只有能证明具体一次整理实际恢复统一适用时，才另记显著纠偏。

## 十二、颗粒度范例所得

唐代总结表明，一个可登记节点至少应回答：

1. 前制是什么，本朝是在继承、恢复还是新增；
2. 法律文本具体改变了什么；
3. 适用于哪些罪名、人群和司法阶段；
4. 是否真正运行，运行到什么程度；
5. 史书是否记载了人数、频率、持续时间或行为变化；
6. 有无意外效果、执行失败或国家层面的后果；
7. 皇帝、倡议臣子、编修者、执行者、反对者各承担什么责任；
8. 后续是延续、扩大、纠偏、架空还是废止；
9. 同一生命周期如何组合，避免按条文和史书重复计数；
10. 哪些只是史家评论、风险推测或象征叙事，不能当作实际结果。

以此标准看，唐代不能只登记“武德律—贞观律—永徽律疏—开元修格”。真正影响评分的是：贞观制度是否运行并救生、永徽制度成熟后为何仍发生刑滥、武周酷吏造成多少实际伤害、开元低刑狱如何反转、肃宗重刑如何改变归降行为，以及中晚唐为何不断修格仍无法恢复法律稳定。
