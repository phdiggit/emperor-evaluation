# 规则判断结果契约

> 状态：`accepted`
> 契约版本：`rule-judgment-result-v1`

## 1. 边界

Judgment 是对 RuleProjection 的结构化业务裁量。它不是史源，不修改 Episode，也不直接包含最终聚合分。

## 2. 输入引用

```yaml
projection_ref:
input_type:
input_semantic_fingerprint:
rule_code:
rule_version:
judgment_policy_version:
factor_schema_version:
```

## 3. 输出

```yaml
judgment_id:
projection_ref:
applicability:
direction:
factor_values:
evidence_assessment:
attribution:
uncertainties: []
supporting_episode_fields: []
supporting_assertion_refs: []
excluded_assertion_refs: []
review_status:
review_reason:
judgment_version:
provenance:
```

## 4. Applicability

允许值：

- `applicable`
- `supporting_only`
- `not_applicable`
- `blocked_identity`
- `blocked_evidence`
- `blocked_conflict`

不适用不是零分判断；Score 层不得把 blocked 或 not_applicable 当作已判零分。

## 5. Direction

- `positive`
- `negative`
- `mixed`
- `neutral_context`

方向必须由规则语义和事件责任决定，不得只靠关键词。

## 6. Factor values

- 只能使用 RuleDefinition 声明的有限值；
- 每个值必须有 evidence/episode field 支持；
- 缺失关键因子时阻断，不由模型自由补值；
- 人物画像因子必须引用明确 PersonProfileSnapshot 版本；
- 数值计算在 scorer 中完成。

## 7. Evidence assessment

至少包括：

- source sufficiency；
- attribution strength；
- context completeness；
- conflict status；
- negative evidence search status；
- rule boundary check。

## 8. Review status

- `draft`
- `needs_review`
- `accepted`
- `rejected`
- `superseded`

只有 accepted Judgment 可产生 ScoreContribution。

## 9. 模型 provenance

若模型参与，必须记录：

- model family；
- prompt/policy version；
- input/output fingerprint；
- cache hit；
- token/latency；
- validation result；
- 人工或规则接受者。

模型原始文本不是正式字段；只有通过 Schema 和 Gate 的有限值进入 Judgment。

## 10. 幂等与缓存

活动唯一键：

```text
projection_ref + rule_version + judgment_policy_version + factor_schema_version
```

缓存键使用 input semantic fingerprint，不使用 binding ID、文件路径或生成时间。

## 11. Score 接口

ScoreContribution 读取：

- accepted judgment；
- deterministic scoring formula version；
- 必要的权重/衰减配置；
- evaluation context。

Judgment 不允许直接提供最终 score，只提供有限因子和方向。

## 12. 验收

- 一条活动 Projection 最多一个当前 accepted Judgment；
- 值域错误为 0；
- supporting/excluded evidence 可追溯；
- 规则版本和 input fingerprint 100% 存在；
- 相同输入重跑复用 Judgment；
- scorer 可在无模型参与下重复得到相同结果。
