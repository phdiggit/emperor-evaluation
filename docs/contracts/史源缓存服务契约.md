# 史源缓存服务契约

> 状态：`accepted`
> 契约版本：`source-cache-contract-v1`

## 1. 职责

史源缓存服务负责：

- 按明确请求发现和获取候选文献；
- 保存不可变原始内容与检索元数据；
- 生成可定位 passage；
- 去重网络抓取；
- 返回 fetch error 和覆盖审计。

它不负责：

- 建立历史事实；
- 判断 rule；
- 创建 canonical episode；
- 评价人物；
- 评分。

## 2. 请求

```yaml
request_id:
idempotency_key:
subject:
  person_or_ruler_ref:
  canonical_name:
  aliases: []
evaluation_context:
source_hints: []
required_source_families: []
mode: ensure | supplement | refresh
source_policy_version:
requested_at:
```

### mode

- `ensure`：确保已有可用缓存，不重复抓取相同内容；
- `supplement`：寻找未覆盖来源，复用已有页面缓存；
- `refresh`：明确刷新远端内容，必须有原因和请求键。

## 3. 响应

```yaml
request_id:
status:
input_fingerprint:
output_fingerprint:
documents: []
passages: []
coverage:
errors: []
provenance:
```

### document 最小字段

- `document_cache_id`
- `work_identity`
- `edition_identity`
- `title`
- `url`
- `source_role`
- `retrieved_at`
- `content_hash`
- `http_metadata`
- `license_or_access_note`

### passage 最小字段

- `passage_cache_id`
- `document_cache_id`
- `locator`
- `raw_text`
- `context_before`
- `context_after`
- `content_hash`
- `selection_reason`

## 4. 幂等

同一：

```text
subject + source hints + mode + policy version + request key
```

必须复用同一业务任务。文档内容以 hash 去重；相同 URL 内容变化生成新 content version，不覆盖旧内容。

## 5. 来源身份

URL 不是唯一来源身份。服务必须尽量区分：

- 原书；
- 卷/篇；
- 版本；
- 数字承载站；
- locator；
- 抓取时间。

## 6. passage 规则

- passage 必须足以判断人物、行为和上下文；
- 不得只保存搜索摘要；
- 分段不得切断指代链；
- 同一原文不同窗口可以并存，但应记录 overlap；
- passage 接受后不可原位改写。

## 7. 错误

错误类型至少包括：

- `not_found`
- `access_denied`
- `timeout`
- `parse_failed`
- `source_identity_uncertain`
- `content_changed`
- `policy_blocked`

部分来源失败不等于整个请求成功；coverage 必须显示缺失来源族。

## 8. 安全

- 只访问 source policy 允许的来源；
- 凭据和网络 allowlist 不进入业务请求；
- 原始内容与模型处理隔离；
- 任何自动刷新都有速率限制和审计。

## 9. 验收

- 相同 ensure 请求零网络重复抓取；
- supplement 不复制已有文档；
- refresh 生成新版本；
- 100% 文档和 passage 有 content hash；
- fetch error 可重试且不污染已成功缓存；
- 输出不含 rule、judgment 或 score。
