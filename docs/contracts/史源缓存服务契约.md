# 史源缓存服务契约

> 状态：`accepted`
> 契约版本：`source-cache-contract-v2`
> 兼容说明：v1 仅用于读取既有 V3 fixture，不具备 G2.6K0 输入资格。

## 1. 职责

史源缓存服务负责：

- 按明确请求发现和获取候选文献；
- 保存不可变原始内容与检索元数据；
- 生成可定位 passage；
- 去重网络抓取；
- 返回 fetch error 和覆盖审计。

它不负责：

- 建立历史事实；
- 判断 rule；
- 创建 canonical episode；
- 评价人物；
- 评分。

## 2. 请求

```yaml
request_id:
idempotency_key:
subject:
  person_or_ruler_ref:
  canonical_name:
  aliases: []
evaluation_context:
source_hints: []
required_source_families: []
mode: ensure | supplement | refresh
source_policy_version:
requested_at:
```

### mode

- `ensure`：确保已有可用缓存，不重复抓取相同内容；
- `supplement`：寻找未覆盖来源，复用已有页面缓存；
- `refresh`：明确刷新远端内容，必须有原因和请求键。

## 3. 响应

```yaml
request_id:
contract: source-cache-contract-v2
status:
input_fingerprint:
output_fingerprint:
documents: []
passages: []
coverage:
errors: []
provenance:
```

### document 最小字段

- `document_cache_id`
- `work_identity`
- `edition_identity`
- `title`
- `url`
- `source_role`
- `retrieved_at`
- `content_hash`
- `http_metadata`
- `license_or_access_note`

### passage 最小字段

- `passage_id`
- `document_id`
- `locator`
- `raw_text`
- `context_before`
- `context_after`
- `content_hash`
- `selection_reason`
- `content_version`
- `section_id`
- `section_heading`
- `span_start` / `span_end`：文档 content version 内的半开字符区间；长度必须等于 `raw_text` 长度
- `passage_kind`：`atomic`、`context` 或 `navigation_noise`
- `linked_passages[]`：`passage_ref + relation`
- `overlap_group`：窗口重叠时声明；无重叠可为空
- `window_policy_version`

`linked_passages[].relation` 只允许：

- `antecedent`：补足前置主体或指代；
- `continuation`：同一叙事连续段；
- `responsibility`：职责或授权范围；
- `outcome`：结果或反馈段。

链接两端必须属于同一 `document_id + content_version`，不得自链接或引用不存在的 passage。

## 4. 幂等

同一：

```text
subject + source hints + mode + policy version + request key
```

必须复用同一业务任务。文档内容以 hash 去重；相同 URL 内容变化生成新 content version，不覆盖旧内容。

## 5. 来源身份

URL 不是唯一来源身份。服务必须尽量区分：

- 原书；
- 卷/篇；
- 版本；
- 数字承载站；
- locator；
- 抓取时间。

## 6. passage 规则

- 切片先识别 section，再在 section 内按明确 anchor 和版本化窗口策略展开；
- `atomic` passage 必须自身足以核验 identity 与 action；
- `context` passage 只补充指代、职责或结果，不得伪装为可独立进入 Episode core 的证据；
- 页面导航、目录、站点工具条等必须标为 `navigation_noise` 并在正式 evidence 输入前排除；
- 不得只保存搜索摘要；
- 分段不得切断指代链；
- 任命/授权、职责和结果相隔较远时，用显式 linked passage 保留关系，不拼接或改写原文；
- 同一原文不同窗口可以并存，但必须记录 `overlap_group`；
- passage 身份只来自文档、content version、section、span、kind 和窗口策略，不包含模型摘要、Gold code 或数据库自增 ID；
- passage 接受后不可原位改写。

## 7. 错误

错误类型至少包括：

- `not_found`
- `access_denied`
- `timeout`
- `parse_failed`
- `source_identity_uncertain`
- `content_changed`
- `policy_blocked`

部分来源失败不等于整个请求成功；coverage 必须显示缺失来源族。

## 8. 安全

- 只访问 source policy 允许的来源；
- 凭据和网络 allowlist 不进入业务请求；
- 原始内容与模型处理隔离；
- 任何自动刷新都有速率限制和审计。

## 9. 验收

- 相同 ensure 请求零网络重复抓取；
- supplement 不复制已有文档；
- refresh 生成新版本；
- 100% 文档和 passage 有 content hash；
- 100% passage 有 section、span、kind、content version 和窗口策略版本；
- 100% linked passage 可回到同一文档 content version；
- 导航噪声不会进入 Assertion 输入；
- fetch error 可重试且不污染已成功缓存；
- 输出不含 rule、judgment 或 score。
