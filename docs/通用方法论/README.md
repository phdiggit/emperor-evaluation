# 通用方法论

本目录用于承载跨大项、跨子项复用的方法论。这里的内容回答“如何工作”，不替代项目总纲，也不承载单一子项的专用评分口径。

## 职责

- 证据链总流程与文档索引。
- 证据强度与五轴裁量。
- 证据裁量总则。
- 史料检索与回源工作流。
- 检索画像与检索日志字段。
- 数据主表、配置说明、运行库生成与稳定标识规范。
