# 证据强度四级与五轴量化规则（讨论版 v0.1）

## 一、证据强度层级

证据卡继续采用四级强度：

- 1 = 弱正 / 弱负；
- 2 = 中正 / 中负；
- 3 = 强正 / 强负；
- 4 = 极正 / 极负。

四级是“候选证据强度”，不是最终得分，也不是最终档位。

## 二、五轴量化

### 轴一：归项直接度

判断这条史料是否直接证明当前子项。

- 低：只是间接相关，主要应归入其他项目；
- 中：与本项有关，但需要较多解释；
- 高：直接命中本项；
- 极高：直接命中本项核心定义。

### 轴二：行为关键性

判断该行为是否涉及关键人物、关键岗位、关键时刻或关键决策。

- 低：普通任命、普通言行、普通事件；
- 中：涉及较重要人物或岗位；
- 高：涉及核心人物、关键岗位或重大时点；
- 极高：涉及决定性节点或核心制度/团队/战略结构。

### 轴三：持续性 / 结构性

判断证据是单点行为，还是能体现持续模式或系统结构。

- 低：单点、偶发、孤立；
- 中：有一定重复或代表性；
- 高：体现较稳定模式；
- 极高：体现系统性、长期性或制度化结构。

### 轴四：后果外溢度

判断该证据是否造成明显的生态、制度、社会、军事、行政或政治后果。

正证看：

- 是否形成稳定团队；
- 是否形成反馈入口；
- 是否形成授权秩序；
- 是否形成持续治理能力。

负证看：

- 是否造成恐惧；
- 是否造成株连；
- 是否造成清洗；
- 是否造成制度破坏；
- 是否造成长期衰败或大规模伤害。

### 轴五：相邻项剥离后剩余强度

先剥离相邻项，再判断本项剩余证明力。

例如：

- 战役胜利剥离后，任将行为还剩多少用人证明力；
- 政策效果剥离后，纳谏行为还剩多少反馈入口证明力；
- 政治残酷性剥离后，臣僚表达安全还剩多少用人生态证明力；
- 后世盛世光环剥离后，原始行为还剩多少直接证明力。

## 三、四级映射规则

### 弱正 / 弱负

适用情形：

- 方向明确；
- 但只是普通案例；
- 或归项直接度不高；
- 或相邻项剥离后剩余证明力有限；
- 或虽有负面/正面意义，但影响范围较小。

示例：

- 普通任命某官；
- 单次采纳建议；
- 身后追责但未造成现实外溢；
- 确认谋反后的功臣处置对用人生态造成轻微信号损伤。

### 中正 / 中负

适用情形：

- 直接命中本项；
- 涉及关键人物、关键岗位或关键事件；
- 但主要仍是单线材料；
- 尚不足以证明系统性结构。

示例：

- 授权关键将领承担重要军事任务；
- 重用旧敌阵营人才；
- 强嫌疑未坐实的功臣处置争议；
- 一次重大错用将相，但尚未形成系统性问题。

### 强正 / 强负

适用情形：

- 直接命中本项核心；
- 同时体现持续性、结构性或明显生态影响；
- 或单条史料本身包含明确的持续性表述；
- 或负面证据造成明显群体性、制度性、生态性损害。

示例：

- 对谏臣长期欣然纳受，形成稳定反馈入口；
- 多类型人才被持续吸纳、授权；
- 群臣莫敢正言；
- 无明确谋反嫌疑而杀害、逼死核心能臣/谏臣；
- 用人系统被佞臣、近幸、宦官、后宫长期污染。

### 极正 / 极负

适用情形：

- 系统性极强；
- 规模极大；
- 长期影响深远；
- 可作为本项历史级锚点；
- 或造成大规模、长期、不可逆伤害。

极级必须人工裁判。

示例：

- 跨文臣、武将、谏臣、旧敌阵营、财政/边疆等多类型人才形成长期稳定用人系统；
- 大规模株连、系统清洗、死徙以千数，并造成长期人才生态破坏；
- 国家层面长期政策导致民生、户口、财政、社会结构严重崩坏。

## 四、单证与证据组的区别

### 单证

单条原子证据一般不宜轻易给极级。

单证最多常见到强级。

### 证据组

多个中正、强正证据若覆盖多个维度，可在证据组层面上探极正候选。

多个中负、强负证据若显示系统性问题，可在证据组层面上探极负候选。

## 五、触发模块的作用

五轴裁量给出基础强度。

触发模块负责：

- 封顶；
- 降权；
- 上探；
- 标记人工裁判；
- 防止混项。

例如：

- “杀功臣”初看可能强负，但若确认谋反，则在用人项内封顶为弱负；
- “身后追责”若未外溢，通常弱负；
- “大规模株连”可从强负上探极负候选；
- “错用大将”必须切分用人错误与军事失败结果。
