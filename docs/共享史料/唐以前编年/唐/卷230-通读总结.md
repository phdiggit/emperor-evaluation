### WAR-LEAD-230-01 宁陵四十五日守城与李希烈退围

- 当前状态：卷229李希烈陷大梁后的东南推进在宁陵受阻；本卷此围收束，淮西战争整体未终。
- 时间与地域：784年二月，宁陵、白马、石柱、汴水。
- 集结与部署：李希烈五万围宁陵、引水灌城；濮州刺史刘昌仅三千守城。滑州李澄表面仍奉李希烈，暗向朝廷请降；李希烈以养子六百戍白马并召李澄会攻。
- 攻守过程：李澄在石柱制造营惊、烧营而遁，又诱李希烈养子剽掠后收斩，以此解除内部监视。刘昌四十五日不解甲。韩滉遣王栖曜援刘洽，王以数千强弩沿汴水游进，夜入宁陵，次日自城上直射李希烈坐幄。
- 收束：李希烈因宣润弩手到达而惊，解围撤去；宁陵保持。
- C 已实现军事成果：以少数守军坚持至外援入城，解除李希烈五万围攻；但这只是宁陵节点，未消灭李希烈政权。
- D 责任与控制：刘昌负直接守城责任，王栖曜完成水路增援；李澄通过佯动清除李希烈驻军而未立即暴露。韩滉提供强弩援军形成实际公共防务贡献。
- 财政民生后果：两问均未命中，不另建FIN卡。
- 影子定位：`P0/S4/M2/A1→base_WC4→WC4`〔评价主体：唐内战体系。P0：四十五日守城未载人员损害结果，不能从围城推定。S4：宁陵核心江淮通道节点被五万军引水长期围攻。M2：五万围军、三千守军及援军属十万人以下持续动员。A1：围城器械与局部城防资产投入，未载重大损失。最高S4，P不与S同档，不升档；置信度中高〕；SB1〔宁陵解围，但李希烈主力与淮西战争均未消除〕；WR0〔只守住既有城池，无新增或恢复所得；置信度：高〕。
- 父级去重：淮西父链宁陵子卡，只结算本次围城解围，不与大梁卡重复。
- SB/WR依据：`SB1`〔评价主体为唐，威胁对象为李希烈五万围军，受益方向为宁陵与江淮通道；三千守军坚持至援军入城并迫敌撤围，但只解除一城之围，淮西主体和再犯能力未变，不足SB3。本卡为淮西父链宁陵子阶段；置信度高〕；`WR0`〔宁陵是既有城池防守成功，未见缴获、收复失地或新增行政资源；同一防守事实只记SB，不再重复为WR；置信度高〕。
- 证据与不确定性：五万、三千、六百、数千均是兵力或器械规模，不自动作为财政民生负担；`revision_ref=803248`；正文锚点“遂解圍去”。

### WAR-LEAD-230-02 李怀光由逗留通敌至逼驾、东走河中

- 父级收束：`campaign_group=PARENT-HEZHONG-REBELLION-784-785`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-232-01`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件 ID：`EVT-ZZTJ-230-LIHUAIGUANG-REBELLION`。
- 当前状态：卷229解奉天围的主力转为叛军；本卷完成公开决裂并占河中，尚未平定。
- 集结与部署：李怀光控制咸阳联营及朔方诸道兵，李晟、李建徽、杨惠元一度附营。朱泚守长安宫苑。朝廷拟引吐蕃五万，但李怀光拒在敕书署名，吐蕃遂不进。
- 战略争议：朱泚出长安求战时，李晟主张当即决战；李怀光以马未秣、士未饭拒绝，随后以疲弊为由累月不进。其所称吐蕃入城后可能焚掠、五万人按每人百缗赏格需五百万缗及坐观胜负，均是风险预判，不登记为实际成本；拒署的实际结果是外援未进。
- 分军与控制：陆贽据李怀光亲口“许去无妨”为依据，促成李晟移东渭桥；德宗没有及时把李建徽、杨惠元一并抽走。李怀光筑咸阳、移军据城，杀张名振、石演芬，夜袭李建徽与杨惠元军，杨被追杀。
- 逼驾展开：李怀光约韩游瑰、遣赵升鸾内应并拟烧乾陵惊胁乘舆；赵升鸾反向告发。德宗在浑瑊尚未整队时即仓促西出奉天，戴休颜留守。李怀光又遣精骑追驾，孟保等三将借觅粮纵兵剽掠而故意放过，百官得入骆谷。
- 邠州与转进：李怀光令张昕发留兵万余及行营家属，又遣刘礼三千余骑强迁；韩游瑰、高固等借吐蕃逼城，先杀张昕，保住邠宁。李怀光三令所部袭李晟，军士拒从；遂以准许掠夺东方富县换取军众随行，烧营东走，沿途掠泾阳等十二县，军将散亡，最终进入河中。
- B 已证实际成本：张名振、石演芬、杨惠元、张昕等被杀；奉天朝臣将士仓促扈从；追驾军在盩厔实际剽掠；强迁邠州家属虽未成，但刘礼三千余骑已经用于胁迫；李怀光东走实际洗劫泾阳等十二县至鸡犬无遗。
- C 目标完成与保持：李怀光逼德宗离奉天、夺部分联军并占河中，却未能吞并李晟军、带走邠宁留兵家属或取得同州、坊州长期控制；赵贵先、符峤相继降唐。中央罢其兵权，朔方诸军分归本镇。
- D 可归责失误：德宗在陆贽已明确指出“强者恶积、弱者先覆”后仍延迟抽走建徽、惠元，杨惠元被杀，属于已有预警后风险兑现；李怀光对通敌、夺军、逼驾、杀谏者和县域洗劫负直接责任。
- 财政民生后果：军粮积储耗尽、官民被杀与逃徙、追驾剽掠、强迁威胁以及十二县全面洗劫均只在本WAR卡结算；没有记载同一事件造成的返乡复业或被掠物资归还。
- 影子定位：`P0/S5/M3/A4→base_WC5→WC5`〔评价主体：唐内战体系。P2估：多名将领官民被杀、逃徙，人数不详，不擅升P2。S5：咸阳奉天河中及京畿十二县逼驾、军裂和全面洗劫，首都圈军政财政广泛危机。M3：李怀光大军分裂转移并跨京畿河中持续行动。A4：军粮积储耗尽、十二县财产近乎荡尽并失河中城地，国家级区域资产重损。最高S5，P不与S同档，不升档；置信度高〕；SB0〔解围主力转叛并逼驾占河中，安全恶化〕；WR0〔军粮城地与县域财产净损；置信度：高〕。
- 父级去重：`PARENT-LIHUAIGUANG-784-785`首段父卡，只结算公开反叛与东走河中，后续围困另收束。
- SB/WR依据：`SB0`〔评价主体为唐，威胁对象为李怀光叛军，受益方向为奉天、京畿与河中；解围主力转叛、逼驾并掠十二县，安全明确恶化。本卡为784—785父链入口，后续围平不在此反结；置信度高〕；`WR0`〔中央净失军粮、城地及县域财产，河中府库属国内夺取，不创造国家新增财富；置信度高〕。
- 证据与不确定性：李怀光关于吐蕃焚掠和五百万缗的陈述属于风险预判；`revision_ref=803248`；正文锚点“掠涇陽等十二縣，雞犬無遺”。

### WAR-LEAD-230-03 李晟脱离联营、重建粮秣与复京军势

- 父级收束：`campaign_group=PARENT-JINGYUAN-FENGTIAN-783-784`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-231-02`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件 ID：`EVT-ZZTJ-230-LISHENG-RECOVERY-FORCE`。
- 当前状态：李晟由受李怀光压制的偏军转为京畿复京主力；本卷完成整军与战略包围，决战待卷231。
- 集结与部署：李晟先斩不受节制且纵军剽掠的刘德信，合并其军；后从咸阳列阵转移东渭桥。李怀光叛迹明朗后，李晟治城隍、缮甲兵，并建议以赵光铣等各带五百守洋、利、剑三州，保护蜀汉通道。
- 粮道与后勤：东渭桥原有积粟十余万斛，已由度支供应李怀光军而用尽。李晟在孤军、无资粮无外援条件下，以张彧权京兆尹，选四十余人督渭北诸县征集刍粟，不足十日仓储充羡。四月李齐运再任京兆尹，供应军粮与役务。
- 军纪与士气：李晟军不受李怀光军分赃；其百口之家及神策军属虽在长安，仍斩朱泚送家书的间人。军士盛夏仍着裘褐，未授春衣而无叛志。
- 外围整合：韩游瑰守邠宁、戴休颜守奉天、骆元光守昭应、尚可孤守蓝田，皆受李晟节度。李怀光部孟涉、段威勇数千来归，军势增强。
- C 已实现军事成果：保全独立指挥与东渭桥基地，恢复短期粮秣，整合京畿多支守军，使李怀光因部众拒战而不能袭取；尚未收复长安。
- D 责任与限度：李晟军纪、通道预案和后勤组织均有明确决策与实际结果；渭北赋敛则是已执行的民间负担，不因服务复京而免除成本登记。
- 财政民生后果：十余万斛公粮耗尽、渭北诸县被征刍粟、京兆继续供粮役、军士缺春衣均只在本WAR卡结算；军粮恢复不等于民众生产或生活恢复。

### WAR-LEAD-230-04 田绪政变、魏州守城与朱滔军掠境

- 父级收束：`campaign_group=PARENT-ZHUTAO-BEIZHOU-781-784`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-231-01`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件 ID：`EVT-ZZTJ-230-WEIBO-COUP-SIEGE`。
- 当前状态：田悦归唐后被田绪杀害；魏博由内部政变转入抵御朱滔，未收束。
- 前态与兵损：田悦此前屡败，士卒死亡什六七，军中厌战。孔巢父到魏州宣示逆顺，田悦与将士一度接受归唐并撤警备。
- 政变展开：田绪杀侄后惧罪，夜穿后墙杀田悦及其母、妻十余人，又诱杀许士则、蒋济，嫁祸刘忠信与扈崿。扈崿得到约三分之一将士响应；田绪以兵马使二千缗、大将千缗、士卒百缗并“竭公私之货、五日取办”的赏格翻转军心，扈崿被杀。田绪随后又杀薛有伦等二十余人。
- 外军攻守：朱滔遣郑景济五千增援马寔，合计一万二千攻魏州；马寔军王莽河，骑兵与回纥四出剽掠。田绪先短暂向朱滔送款，后采曾穆、卢南史议，归命朝廷并守城待援。
