- 鹿头防线：刘辟筑鹿头关、连八栅，驻万余。高六月击败，刘又在关东万胜堆设栅；高霞寓夺堆、居高俯瞰关城，连续八战皆胜。
- 多路连续战斗：高崇文在德阳、汉州取胜；严秦在绵州石碑谷破万余；高又在玄武破万人。朝廷命所有西川继援兵统一听高崇文处分，形成战区单一指挥。

- 成都追击：高军长驱成都、沿途崩溃不停；九月克城。刘辟、卢文若数十骑向吐蕃逃，高霞寓追至羊灌田；刘投江未死被擒，卢先杀妻子后系石沉水。
- ⑥收束、控制、威胁变化、持续性与跨卷更新：高崇文屯通衢休军，市场不惊，珍宝山积而秋毫无犯；只斩邢泚、沈衍，其余不问。军府大小事务沿用韦皋旧制，一境皆平；六州改隶东川，崇文任西川。高崇文居蜀一年后主动请调边镇，未转成新割据，西川威胁在本卷完成父级收束。
- B 实际战争成本：多地连续交战及执行军法造成死亡；刘辟部署万余守鹿头、两次唐军各破万人级部队，降卒万计；卢文若杀妻子并自沉，刘辟及族党后被诛。数字多为参战规模或降众，不推算总死亡。
- C 已实现结果：刘辟政权消灭，梓州、成都及西川恢复中央控制；市场、财物和行政连续性保持。高崇文一年后主动请离富镇，控制未转为个人割据。
- D 责任与贡献：宪宗授权出兵；杜黄裳负责选将与不设监军的总体设计，高崇文统一前线并执行严军纪，阿跌光颜完成关键断粮。李康失守是否应处死属高崇文的处置责任，不用最终胜利覆盖。
- 财政民生后果：死亡与连续动员为损害；成都市场、公私财物和行政实际保全为正向结果，均在本卡结算。

### WAR-LEAD-237-02 李锜镇海叛乱与浙西收束

- 当前状态：镇海叛乱父级收束卡。
- 时间范围：807年九月至十一月。
- 地理范围：京口、苏常湖杭睦五州、石头城、宣州。
- 主要对手：李锜及挽强、蕃落亲兵。
- 共享事件 ID：`EVT-ZZTJ-237-LIQI-ZHENHAI`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- ①战前状态、起因与可证目标：李锜因卷236盐铁利权、贡奉结权与特种兵扩张而势大；宪宗初政使藩镇多求入朝，李锜也请朝却一再拖延。朝廷目标是使其离镇入朝、恢复五州任命控制；李锜的可证目标是拒召并先取富庶宣州。
- ②决策、授权、反对意见及责任人：李锜称疾再请延期，武元衡指出若任其自定进止便无法号令四海，宪宗据此下诏征召。李锜密令亲兵杀留后、命五州镇将杀刺史，对叛乱负责；朝廷削官属籍并授权王锷统多道进讨。
- ③动员兵力、统帅、分路与部署：李锜预置五名亲信分任苏、常、湖、杭、睦镇将，各带数千兵监视刺史；另遣庚伯良三千治石头城，张子良等三千拟袭宣州。朝廷以王锷统淮南、宣歙、江西、浙东等军，宣武、义宁、武昌及淮南、宣歙军出宣州，江西出信州，浙东出杭州。

## 财政民生旁路扫描




### FIN-LEAD-237-04 《元和国计簿》的财政—军队结构

- 807年全国账面：方镇四十八，州府二百九十五，县一千四百五十三。
- 财政范围：十五道七十一州不申报户口；每年赋税实际依靠浙江东、西、宣歙、淮南、江西、鄂岳、福建、湖南八道四十九州，共一百四十四万户，比天宝税户减少四分之三。
- 军队供养：依赖中央供给的军人八十三万余，比天宝增加三分之一；约二户供养一兵。水旱损失和临时征发尚不在此数。
- 证据性质：李吉甫国家财政簿册的当时汇总，反映中央可控税基与军费结构，不把“不申户口”推成零人口。
- revision：`1964113`；正文锚点“一百四十四萬戸”；“天下兵仰給縣官者八十三萬餘人”。

### FIN-LEAD-237-05 李巽财赋收入增长

- 李巽接掌度支、盐铁转运后，首年征课收入接近刘晏，次年超过，第三年再增加一百八十万缗。

- revision：`1964113`；正文锚点“又一年加一百八十萬緡”。

### FIN-LEAD-237-06 两税省估纠偏与江淮稍息

- 前态：建中定两税时货贵钱轻，后来货轻钱贵，民实际负担已比初定翻倍；留州、送使部分又压低官方估值、按实际市价加征。
- 政策：裴垍任相后奏令天下留州、送使物一律按省估；观察使先税本州自给，不足才可向属州征取。
- 已实现结果：正文明确江淮百姓由此稍得休息。
- revision：`1964113`；正文锚点“由是江、淮之民稍蘇息”。

### FIN-LEAD-237-07 南方旱饥与809年减租赈恤

- 808年宣歙旱饥：卢坦拒绝限低粮价，认为低价会阻商船；结果米斗二百，商旅聚集，民众依靠外粮生存。
- 809年南方旱饥：宪宗遣郑敬等宣慰江淮、二浙、荆湖襄鄂，强调救民不计费用。久旱后又依李绛、白居易建议减租税、放宫人、停进奉、禁掠良人为奴；诏令实施后降雨。
- 灾害与政策分账：旱灾不归责朝廷；商粮到达、赈使出发、蠲税和禁掠是实际纠偏，不把降雨归因政策。
- revision：`1964113`；正文锚点“商旅輻湊，民賴以生”；“蠲租稅，出宮人，絶進奉，禁掠賣”。

### FIN-LEAD-237-08 安国寺圣德碑楼拆除

- 建筑类型：安国寺大修中的拟建圣德碑及已先建成的高大碑楼；不是既有碑改名。
- 资金：吐突承璀称已备一万缗拟酬学士撰文。
- 纠偏执行：李绛反对以寺院壮丽自称圣德；宪宗命拉倒碑楼。承璀请求缓拆，皇帝坚持，实际用一百头牛曳倒。
- B 已证实际成本：碑楼已经施工完成；拆除动用一百牛力。
- 结果：碑文与圣德工程停止，避免后续一万缗酬文支出成为事实，但不把未支付数额登记为已节省入库。
- revision：`1964113`；正文锚点“臣已具錢萬緡”；“凡用百牛曳之，乃倒”。
