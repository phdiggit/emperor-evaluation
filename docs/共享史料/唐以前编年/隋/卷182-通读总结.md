### WAR-LEAD-SUI-GOGURYEO-613 第二次征高丽

- 父级收束：`campaign_group=SUI-GOGURYEO-611-614`；`settlement_role=stage`；`settlement_owner=WAR-PARENT-SUI-GOGURYEO-611-614`；`machine_settlement=no`；`settlement_status=absorbed`。

- 动员与粮城：正月再征天下兵会涿郡，开始募民为骁果，修辽东古城贮粮。朝廷把612年宇文述兵粮不继归咎军吏支料，恢复其官爵，未据前败修正远征目标。
- 展开：四月炀帝渡辽，宇文述、杨义臣向平壤，王仁恭出扶余道，以劲骑一千破新城外高丽数万，高丽退守城内。辽东城方面，隋军飞楼、橦、云梯、地道四面昼夜并进，高丽随方拒守，二十余日不拔，双方死者甚众。
- 攻城升级：隋造土囊百余万口，拟堆成宽三十步、与城齐高的鱼梁大道；又造八轮楼车夹道俯射。器械已造并临近总攻，不是仅有建议。
- 后方断裂：督黎阳运粮的杨玄感故意迟滞漕运，随后起兵。炀帝闻反书且斛斯政投高丽，夜间密令撤军；军资、器械、攻具积如丘山，营垒帐幕均原样遗弃，诸道部伍分散。
- 追击：高丽先疑为诱敌，二日后才以数千人远随；辽水御营渡毕后逼击后军，最后羸弱数千人被杀略。“杀略”含杀与掠，不把全数一律计死亡。
- 财政民生后果：重复征兵、修粮城、百余万土囊和大型楼车均已投入；撤退时大批军用资产实际丧失。围城双方死亡事实成立，但只有隋方最后数千羸弱者可明确纳入本方人员损失。
- **战争成本影子定位（评价主体：隋）**：P3估 / S0 / M4 / A4 → WC4（中高置信度）。P按下列区间正式推定；战区在辽东，未证隋本土生产直接破坏，定S0；再征天下兵定M4，百余万土囊、大型楼车及军资器械尽弃定A4。SB0；WR0。
- P推定：P_observed=最后数千羸弱者被杀略，按死亡至被掳的混合构成折算（完整人数失载）；推定死亡当量区间=600—3,000人，几何中心当量约1,342人，P_scoring=P3估；推定依据=受损群体、接战范围、胜败方式与持续性综合约束；上限理由=不把杀略全数视为死亡；置信度=中高。
- 父级去重：作为611—614三征父级的第二征子卡；不再把土囊、器械遗弃和后军损失拆卡累计。

### WAR-LEAD-SUI-YANGXUANGAN-613 杨玄感内战

- 父级收束：`campaign_group=SUI-REBELLIONS-611-615`；`settlement_role=stage`；`settlement_owner=WAR-PARENT-SUI-REBELLIONS-613-615`；`machine_settlement=no`；`settlement_status=absorbed`。

- 后勤夺取与集结：杨玄感借督黎阳运粮迟滞漕运，闭城搜男夫，以帆布制牟甲，征集少壮运夫五千余、丹阳宣城篙梢三千余，并以“来护儿反”为名召旁郡军。黎阳仓运成为起兵的资源基础。
- 战略选择：李密上策为北趋蓟、扼临渝断炀帝归路，中策为直取长安，下策为攻东都；玄感因百官家属在洛阳、欲示威而取下策。河内已被唐祎告警，临清关有守，玄感改从汲郡南渡河。
- 三路进攻：杨积善三千沿洛水、杨玄挺越邙山、玄感三千余相继西进，初军仅单刀柳楯、无弓甲。达奚善意五千不战而溃，甲仗被夺；裴弘策八千在白司马板至太阳门连续五战皆败，余众多归玄感。
- 围城与扩军：玄感屯上春门，父老献牛酒、子弟日以千数来投，兵至五万余；分五千守慈涧、五千守伊阙、三千围荥阳、五千取虎牢。樊子盖斩裴弘策整肃守军，随方拒守，玄感尽锐攻城不克。
- 援军反攻：卫文升四万自关中救洛，入东都北面；其步骑二万渡瀍水后屡败，死伤太半且尽。玄感众至十万，与文升在邙山一日十余合，杨玄挺中流矢死后攻势始衰。屈突通渡河、宇文述继至，樊子盖又出击，玄感被迫分军东西拒援并连续失利。
- 攻守转换与追击：七月玄感解东都围西走，欲开永丰仓振贫并据关中；在弘农宫因粮城诱惑停攻三日。宇文述、卫文升、来护儿、屈突通追至皇天原，玄感在槃豆列阵五十里、且战且行，一日三败；董杜原再大败，仅十余骑逃入上洛，最终令弟杨积善杀己。
- 外围响应：韩相国在梁郡旬月聚十余万、攻剽郡县，玄感败后瓦解；刘元进等另成江左战线。杨玄感之乱因此不能只按洛阳单点计算，但外围战争另卡保存过程。
- 财政民生后果：黎阳漕运中断、仓储被军用，东都围城和河洛—弘农—潼关通道多军反复争夺。玄感开仓赈民是已执行给付；事后朝廷把受米者全部坑杀，另杀党与三万余、籍没家庭、流徙六千余。这些是镇压后的政治司法和人道损害，不冒充交战死亡，但纳入本事件广义民生后果。
- **战争成本影子定位（评价主体：隋政权体系；内战双方损失在本父卡合并去重）**：P3 / S4 / M3 / A2 → WC4（试算旧档已废止→新档WC4；高置信度）：
  - P3：卫文升步骑二万“死伤太半且尽”中的“死伤”混合且后续基数变化，不能把过半直接折成死亡万人；现有可量化交战人员损失只稳健支持千人级。镇压后杀党与三万余、坑杀受米者、籍没流徙属于事后政治司法及人道损害，不作为战争P。
  - S4：黎阳漕运被截、仓储转为叛军资源，东都持续围城，河洛—弘农—潼关核心交通带有多军反复争夺；这些是核心税粮、首都供应与交通系统的实际战争冲击，独立支持S4。外围响应虽广，不在本卡重复抬至S5。
  - M3：叛军由五千余运夫、三千余篙梢扩至五万、十万，中央先后投入卫文升四万及屈突通、宇文述、来护儿诸军，形成跨区多军围城、救援和追击；未在本卡单独证明全国性多年动员，故M3。
  - A2：黎阳仓粮、达奚善意甲仗被叛军实际夺用，漕运资产转入内战；国内资产转移不是WR新增财富，但仍是政权体系在战争中发生的军储控制损失。未载足以定A3以上的不可恢复毁失。
  - 公式：基础档 `max(P3,S4,M3,A2)=4`；P、S不同为基础最高档，不升档，故WC4。SB1、WR1维持：杨玄感集团被消灭但同类武装迅速扩张；内部城市仓道复控不创造新增财富。置信度：高。
- 父级去重：本卡即杨玄感战争父卡，围城、援军、追击与外围响应不重复结算；三吴、全国乱局独立父卡只记录其自身事实。
- 史源定位：`資治通鑑/卷182@1502778#玄感選運夫少壯者得五千餘人—遂引兵向洛陽`；`#善意渡洛南—皆歸於玄感`；`#玄感收兵得五萬餘人—玄感軍乃稍卻`；`#壬辰玄感解東都圍—玄感大敗獨與十餘騎奔上洛`。

### WAR-LEAD-SUI-SHANDONG-613-614 山东河南群盗与张须陀连续作战

- 威胁面：孟海公据周桥数万；王薄、孟让、郭方预、张金称、郝孝德、格谦、孙宣雅等各有数万至十余万，攻剽山东。北海被攻陷并大掠，地方军多望风败。
- 张须陀反击：须陀在泰山下突击无备的王薄，追至临邑再破；王薄合孙宣雅、郝孝德十余万攻章丘，须陀以步骑二万击溃。裴长才二万突至城下时，须陀先以五骑接战、身中数创，城兵到后再反击。

- 区域扩展：杨玄感败后，刘元进与朱、管合军，据吴郡、置百官；毗陵、东阳、会稽、建安多地执长吏响应。该链已从逃役升级为占城、设治和跨郡战争。
- 官军攻守：吐万绪渡江解丹杨围，进屯曲阿；与刘元进隔栅相持百余日后击溃。朱燮、管崇在毗陵连营百余里，被追至黄山；管崇及将卒被斩，三万余子女被收，随后会稽解围。原文“将卒五个余人”文本疑有脱误，不据此换算。

- 财政民生后果：三吴兵役驱动逃亡；多郡长吏被执、丹杨会稽受围、曲阿百日相持；三万余人口被俘、另三万余降众被坑，构成区域人口与生产秩序重大损害。
