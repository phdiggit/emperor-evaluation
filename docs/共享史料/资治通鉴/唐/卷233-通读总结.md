### WAR-LEAD-233-01 吐蕃陇右入侵、人口强迁与连云失守

- 父级收束：`campaign_group=PARENT-TUBO-LONGYOU-787-791`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-233-01`；`machine_settlement=yes`；`settlement_status=closed`。

- 共享事件 ID：`EVT-ZZTJ-233-LONGYOU-RAIDS`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- 集结与推进：尚结赞率羌、浑连营数十里寇陇州；唐以石季章戍武功、唐良臣戍百里城。吐蕃继掠汧阳、吴山、华亭，后围陇州，被韩清沔、苏太平夜击退。
- 人口处置：吐蕃杀老弱，或断手凿目后遗弃；驱丁壮万余至安化峡西，拟分隶羌、浑。被掳者获准东哭辞乡，赴崖谷死伤千余。
- 华亭、连云：两城再陷，数千城民及邠泾人畜万计被驱至弹筝峡西。连云原为泾州斥候，失守后泾州西门不开，门外即敌境，樵采路绝；收获须列阵护卫，常误农时、仅得空穗，持续缺粮。
- 788年再侵：吐蕃改以扣押唐人妻子、由唐人引导，盛夏出兵三万余，掠泾邠宁庆鄜人畜万计；各州只守城不战。另有奚、室韦因振武斥候疏漏大掠人畜并杀回鹘使者。
- B 已证实际成本：老弱被杀残伤、丁壮万人以上及城民数千被强迁、赴崖谷死伤千余；人畜万计被掠，泾州樵采与农业中断、长期缺粮。
- C 已实现成果与限度：陇州夜袭、丰义和长武等点防守击退部分入侵；华亭连云仍失，不能以局部胜利覆盖持续民损。
- D 责任：吐蕃对杀伤、强迁和破坏生产负直接责任；唐边城体系失去连云斥候后造成长期供应困难，随后刘昌重筑连云才恢复节点。
- 财政民生后果：实际损害明确；本卷后段连云重筑、泾陇屯田数年军食充羡，是已实现恢复，均在本卡结算。
- 影子定位：`P3/S4/M2/A3→base_WC4→WC4`〔评价主体：唐。P3：丁壮万余被强迁按五分之一折算约二千余，另有军民损失未详。S4：陇右军镇、屯田、交通体系连续受攻迁徙。M2：边军接防重筑屯田为区域动员。A3：连云等城防屯田资产重大损失。最高S4，P不并列，不升档；置信度高〕；SB1（连云重筑与屯田恢复形成局部改善，整体边患仍在，置信度高）；WR1（恢复连云等局部节点，未恢复全部失地，置信度中）。
- 父级去重：纳入`PARENT-TUBO-LONGYOU-787-791`；强迁、连云失守与后续重筑只在本父级结算一次。
- SB/WR依据：`SB1`〔评价主体为唐，威胁对象为吐蕃陇右攻势，受益方向为连云与陇右交通；重筑连云、屯田恢复仅带来局部缓解，万级强迁与整体边患仍在，不得因工程完成抬高。本卡纳入陇右父链；置信度高〕；`WR1`〔连云等少量节点恢复实际控制，但未恢复全部失地和完整生产交通体系；强迁人口不作资产；置信度中〕。

- B 已证实际成本：台登谷斩首二千，另有大量投崖溺死；云南此前仍被迫发兵数万，吐蕃又取云南大臣子弟为质。
