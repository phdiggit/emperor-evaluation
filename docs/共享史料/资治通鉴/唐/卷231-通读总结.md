### WAR-LEAD-231-01 贝州野战与朱滔军溃败

- 共享事件 ID：`EVT-ZZTJ-231-BEIZHOU-BATTLE`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- 前态与集结：朱滔围贝州百余日，马寔攻魏州四十余日。王武俊、李抱真距贝州三十里列营；朱滔急召马寔，出战兵三万。
- 战前方案：有人建议前逼营垒、以回纥断粮道，朱滔依德棣转输守营，待敌饥疲再战；马寔也以冒暑困乏请休数日。回纥达干自夸五百破数千，杨布、蔡雄以霸业声望激朱滔立即决战，朱滔采后者。
- 部署与交战：王武俊令赵琳五百骑伏桑林，李抱真列方阵于后，自己以骑居前承受回纥冲击。王军控马让锋，待回纥突过再反击，赵琳由林横击；回纥败退，朱滔骑兵随溃并自践步阵。王、李合兵追至营前。
- 决战成本：朱滔三万人中死万余、逃溃万余，仅数千入营；夜焚营南逃，遗弃所掠资货如山。昏雾使追兵不能继续追击。
- C 已实现成果：解除朱滔对贝魏的主要攻势，迫其退德州、归幽州；王武俊随后让还幽州卢龙节度名义。朱滔本人及幽州根基尚存至次年病死。
- D 可归责失误：朱滔在粮道持久方案与疲军休整建议均在场时，受回纥夸口及霸业激将而仓促出战，立即造成主力溃败；责任链清晰。
- 财政民生双问：实际损害命中——大规模死亡逃散、营地焚毁；正向恢复命中——朱滔遗弃此前掠取的大量资货，但正文只证遗弃，未证归还原主或入公储，故只按掠夺控制终止登记，不折算公共收入。
- 影子定位：`P4/S4/M3/A3→base_WC4→WC5`〔评价主体：唐内战体系。P4：三万出战军死万余；逃万余结局未明不再与死亡重复。S4：贝魏核心区域长期受围及运输军营体系持续受战。M3：多镇数万军长期围救决战。A3：所掠资货山积被遗弃、营垒辎重重大损失。P4与S4同为最高档，公式升档；置信度高〕；SB3（朱滔国家级进攻主力被击溃并解除贝魏攻势，但幽州根基尚存，置信度高）；WR1（大量被掠资货遗弃而脱离叛军控制，但未证官军接收或入公储，低置信度仅记有限返还可能）。
- 父级去重：纳入`PARENT-ZHUTAO-BEIZHOU-783-784`；本卡结算贝州决战局部损失与成果，不与卷230前段围攻重复累计。
- SB/WR依据：`SB3`〔评价主体为唐，威胁对象为朱滔国家级进攻主力，受益方向为贝州、魏州与河北；三万出战军溃散、贝魏攻势解除，但幽州根基与再战能力仍存，符合重大持续改善而非结构性解决。本卡为贝州父级收束；置信度高〕；`WR1`〔史料只明载所掠资货“委弃山积”，可确认脱离叛军控制，却未证唐军实际接收、入公储或持续控制；不能把围攻解除本身重复作WR，故降至低置信度有限回报〕。

### WAR-LEAD-231-02 李晟收复长安、朱泚覆亡

- 集结：李晟约浑瑊、骆元光、尚可孤会城下；尚可孤先于蓝田西斩仇敬忠。李晟移米仓村、亲筑垒，张庭芝、李希傅来攻；华州营兵少受压，李演精兵救援并追入光泰门，两战皆胜。
- 攻城突破：李晟拒绝等待西师，乘敌新败连续出兵；骆元光胜于浐西。官军夜开苑墙二百余步，敌以栅封缺口并刺射。史万顷先拔栅，王佖、李演骑兵继入；诸军分路，与姚令言部十余合。白华门后方数千骑被李晟百余骑回御惊溃。
- 追击与收束：朱泚、姚令言率近万人西逃，张光晟送出城后降；田子奇骑兵追击。浑瑊等同日克咸阳，破敌三千余并分兵截击。朱泚部沿途散亡，至泾州仅百余骑；姚令言被泾卒杀，朱泚至彭原被梁庭芬射坠坑、韩旻等斩首。
- 军纪与安置：李晟驻含元殿，下令五日内不得通家信；李齐运安慰居民。高明曜取贼妓、尚可孤军士取贼马，均被斩。长安公私安堵、秋毫无犯，远坊有人隔夜才知官军入城；钟虡、宗庙宫貌保持。
- B 已证实际成本：连续攻守造成参战者死亡；咸阳叛军三千余被击败，朱泚逃亡部队大量散亡；官军内部两起掠取被军法处死。
- C 已实现成果：宫禁、宗庙、宫阙及坊市完整收复，朱泚政权覆灭，德宗于七月回长安；军事目标、控制结果和持续收益均已兑现。
- D 责任：李晟选择苑北突破并严肃军纪，直接实现降低居民与城市破坏；诸将的实际贡献分别保留。张光晟助朱泚出亡后降，虽对灭贼有力，仍被德宗处死，不能只按末端贡献洗去前期责任。
- 财政民生后果：战斗死亡与叛乱期长期困扰已经发生；官军明令并实际保护居民、坊市、公私财物和宫庙，城市秩序即日保持。两向结果均在本卡结算。
