### WAR-LEAD-235-01 昭义继承、洺州分裂与归附安置

- 父级收束：`campaign_group=PARENT-MINGZHOU-WAR-794-796`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-235-01`；`machine_settlement=yes`；`settlement_status=closed`。

- 共享事件 ID：`EVT-ZZTJ-235-MINGZHOU-WAR`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- **战前状态、起因与目标**：李抱真死后昭义精兵多在山东，李缄秘丧求袭，朝廷目标先是阻止父子世袭并使王延贵接镇；元谊随后要求磁、邢、洺另成一镇，目标转为恢复昭义军令与洺州控制。
- **决策、授权与责任人**：德宗遣第五守进观变并把军务委王延贵；王武俊拒绝资助李缄。元谊拒饶州任命、厚赉精兵，对分裂负责；王虔休决定水攻与冬季渡壕。
- **动员与部署**：马正卿督石定蕃等五千攻洺，石定蕃率二千倒戈；王虔休后亲军围城。元谊最终以洺州兵五千及家属万余奔魏。
- **阶段序列与攻守转换**：临洺先归王虔休；五千进军因二千倒戈退回；王虔休引洺水灌城、破元谊并拔鸡泽；冬乘冰渡壕急攻失败，日暮冰解；翌年元谊诈降诱入二千尽杀；796年放弃洺州奔魏，战争收束。
- **后勤、道路与环境作用**：洺水被直接用作围城水攻；冬季冰合提供渡壕条件，日暮冰解又造成攻军高比例死亡。死亡比例没有本军基数，不换算总人数。
- **收束与后续控制**：德宗赦免奔魏军民并令田绪安抚，洺州分裂结束；归附安置属于国家整合，不把人口作为战利资产。
- 李抱真死后，子李缄秘丧求袭，朝廷以王延贵掌军；李缄交印离镇。元谊要求磁邢洺另镇，厚赏山东精兵，拒绝饶州任命。
- 王虔休引洺水灌城，破元谊军、取鸡泽。冬乘冰渡壕急攻，退军时冰解，士卒死过半。795年元谊诈降，诱二千人入城尽杀。
- 796年元谊、石定蕃带兵五千及家属万余奔魏州；德宗不追罪，令田绪安抚。
- B 已证实际成本：水攻与连续交战；冰解致攻军死过半；二千降入部队被杀；万余家属随军迁徙。
- C 结果：朝廷避免李缄世袭并最终结束洺州分裂，五千军与万余家属获安置；这是国家整合，不能把人数自动折算财政收益。
- 财政民生后果：冰解溺亡、诱降屠杀、水攻与万余家属迁徙为负向；归附安置是已执行的整合结果，不把人口自动折算财政收益。
- 影子定位：`P3/S4/M2/A2→base_WC4→WC4`〔评价主体：唐内战体系。P3：二千入城者被杀；“死者太半”基数不明不另换算。S4：昭义核心军镇长期水攻围城与分裂。M2：多军长期围城但总动员未达十万级重负。A2：城防、粮秣和水攻设施可观损失。最高S4，不升档；置信度高〕；SB2（洺州分裂结束并完成归附安置，但只解决一次军镇继承危机，置信度高）；WR2（洺州控制恢复，军与家属获安置但人口不作战利资产，置信度高）。
- 父级去重：以`PARENT-MINGZHOU-WAR-794-796`结算围城、诱降和归附；“死者太半”不因基数未知与二千死亡机械叠加。
- SB/WR依据：`SB2`〔评价主体为唐，威胁对象为昭义继承分裂与洺州武装，受益方向为洺州—昭义；围城与分裂结束、归附安置完成，但仅解决一次继承危机，未证明藩镇世袭或兵变结构长期削弱，不足SB3。本卡统一结算围城、诱降和安置；置信度高〕；`WR2`〔洺州这一关键军镇恢复实际控制，属于单点实质回报；归附军民及家属是安置责任，不作资产，置信度高〕。
- 证据：`revision_ref=982552`；正文锚点“日暮冰解，士卒死者太半”；“命田緒安撫之”。

### WAR-LEAD-235-02 宣武连续兵变与董晋、韩弘整军

- 父级收束：`campaign_group=PARENT-XUANWU-MUTINIES-792-800`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-235-02`；`machine_settlement=yes`；`settlement_status=closed`。

- 共享事件 ID：`EVT-ZZTJ-235-XUANWU-MUTINIES`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- **战前状态、起因与目标**：刘玄佐把汴兵扩至十万、厚赏养成骄纵；主帅病死和赏给争议反复触发兵变。朝廷目标是让新任主帅入镇并恢复汴州这一漕运军镇秩序。
- **决策、授权与责任人**：霍仙鸣荐刘沐引发军中猜疑；董晋选择只带十余从者入镇、暂留邓惟恭军权并撤公庭武装；陆长源、孟叔度以刻急与低价折布激怒军士；韩弘查明五次首谋后集中处决。
- **动员与部署**：李乃依腹心士卒，邓惟恭与监军反制；董晋不用兵卫快速入汴。刘全谅由宋州引兵径入平定799年兵变；韩弘在牙门陈兵，召刘锷等三百人。
- **阶段序列与攻守转换**：796年军士先逐刘沐、杀仓官及二将，邓惟恭拘李乃；董晋入镇后温和稳军，再捕斩邓党。799年陆长源折价丧服，军士杀陆、孟并食之，刘全谅入城止乱；800年韩弘清除历次首谋，父链最终收束。
- **后勤与军资作用**：兵变直接关联军赏、仓储给纳和丧服布价；刘玄佐以来的厚给构成军队预期。没有大规模战场转输，不能用十万旧编制直接抬M。
- **收束与后续控制**：史文明载韩弘处置后至其二十一年入朝，城中无敢喧乱，支持单一军镇兵变结构的长期压制；事后处刑保留人道责任但不计战场P。
- 796年李万荣病重，军士杀仓官刘叔何并食其肉，又杀伊娄说、张丕；邓惟恭拘李乃。董晋仅带十余人入汴，保留邓军权后撤去公庭武装，军中暂安；后捕斩邓党二百余，邓获免死流放。
- 799年陆长源以严法整军，又把主帅丧服折成低价盐，每人仅盐二三斤；军士杀陆、孟叔度并肢解食之，刘全谅入城平乱。
- 韩弘继任后查明自刘玄佐死以来五次作乱首谋，800年集刘锷等三百人于牙门全部斩杀；其后二十一年城中无敢喧乱。
- B 已证实际成本：两轮实际兵变中多名将吏被杀食，丧服折价侵损军士；邓党二百余、刘锷党三百均属平乱后的处刑，只作政治与人道负面，不进入战争人员损失。
- C 已实现结果：董晋以低刺激接管并暂安，韩弘以大规模处决终止长期兵变；秩序保持与死亡成本分别记录。
- D 责任：陆长源、孟叔度刻急侮军和压低布价是明确触发；兵卒对杀戮负直接责任；韩弘承担三百人处决责任。
- 财政民生后果：武装阶段杀官、食人、军需折价侵损为负向；二百余与三百人均属控制恢复后的处刑，不进入战争人员损失。二十一年无再乱只记安全状态。
- 影子定位：`P1/S4/M2/A2→base_WC4→WC4`〔评价主体：唐。P1：武装阶段数名官吏被杀；事后处刑不计。S4：宣武核心交通军政节点多年连续兵变。M2：多轮军镇动员换帅。A2：牙城、军赏与抢掠形成可观损失。最高S4，不升档；置信度高〕；SB4（五次作乱首谋结构被清除且后二十一年无再乱，达到长期结构性稳定门槛，置信度高）；WR1（军城控制稳定恢复，无新增公共资产，置信度高）。
- 父级去重：作为`PARENT-XUANWU-MUTINIES-792-800`收束卡，合并卷234两轮兵变；事后处刑仅作政治人道负面，不重复进入WC。
- SB/WR依据：`SB4`〔评价主体为唐，威胁对象为宣武反复兵变结构，受益方向为汴州漕运与军镇；五次作乱首谋网络被清除，后二十一年无再乱，单一核心方向由反复高强度危机转为长期低威胁，满足SB4。本卡收束卷234—235父链；置信度高〕；`WR1`〔宣武军城控制稳定恢复，但无新增公共资产或外部资源；国内控制复归只记有限回报，置信度高〕。
- 证据：`revision_ref=982552`；正文锚点“軍士作亂，殺長源、叔度，臠食之”；“悉斬之，血流丹道”。

### WAR-LEAD-235-03 吴少诚扩张与十七道讨伐失败

- 父级收束：`campaign_group=PARENT-WUSHAOCHENG-WAR-797-800`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-235-03`；`machine_settlement=yes`；`settlement_status=closed`。

- 共享事件 ID：`EVT-ZZTJ-235-WUSHAOCHENG-WAR`；财政民生后果以本卡为唯一事实账，不另建FIN卡。
- **战前状态、起因与目标**：吴少诚先擅开刀沟试探中央命令，继而侵霍山、唐州及许州方向。德宗削官爵、命诸道进兵，可证目标是解除吴氏淮西武装并恢复唐、许等地安全。
- **决策、授权与责任人**：前期诸军没有统帅；其后德宗因窦文场推荐，以无军略的韩全义统十七道。刘昌裔主张闭城耗敌并募勇士反击；韦皋提出统一元帅、本人出巴峡或及时赦免止损三案，贾耽主张给吴少诚生路。
- **动员与部署**：于頔、伊慎、王宗、上官涗、韩弘等多镇进击；韩弘选卒三千会攻许下。800年恒冀、易定、陈许、河阳先战不利，随后十七道统一名义上受韩全义节度，但帐中数十监军争论不决。
- **阶段序列与攻守转换**：吴军掠霍山并置兵，后袭唐州、俘陈许三千、昼夜攻许；刘昌裔以千人凿城出击解围。官军一度拔吴房、朗山，却在小殷水自行溃败；800年广利原未交锋即溃，退五楼后再败，继退殷水、陈州；孟元阳等留军反击杀敌二千余，吴军最终还蔡州，朝廷赦免复官。
- **后勤、天气与环境作用**：小殷水溃败使器械资粮全部落吴；韩全义军盛暑久屯沮洳，疫病多发而不抚恤，直接造成离心。十七道名义统一未解决监军争议和指挥分裂。
- **收束与后续控制**：蔡州未下，吴少诚军政结构保存，局部拔县不能转化为稳定控制；朝廷以赦免复官结束本轮，主要威胁延续。
- 797—799年吴少诚开刀沟、掠霍山并杀谢详，侵地二十余里；后袭唐州掠民千余，俘陈许援兵三千，围许州。刘昌裔闭城耗敌，募千人凿城出击保全许州。
- 唐削吴官爵，多镇进攻并取吴房、朗山；但诸军无统帅、各自谋利，在小殷水自行溃败，器械资粮全归吴军。
- 800年韩全义统十七道。盛暑久屯湿地，士卒疫病而不受抚恤；广利原未交锋即溃，后五楼、殷水再败。韩全义诱杀四镇将领，诸军离散；孟元阳等留守者杀敌二千余。
- B 已证实际成本：官民被杀掠，千余百姓被掳、三千援军被俘；小殷水遗失器械资粮；湿地久屯引发疫病；连续溃败与将领处决。
- C 目标失败：十七道未取蔡州，最终朝廷赦吴少诚并复官；局部保许、取二县未转化为平叛收束。
- D 可归责失误：缺统一指挥先致溃败；韩全义无军略且监军数十争论、疫病不抚，造成未战先溃。德宗用宦官关系推荐统帅，责任链明确。
