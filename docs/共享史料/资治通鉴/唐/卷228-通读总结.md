### WAR-LEAD-228-01 李希烈淮西攻势、襄城围困与官军多线反击

- 父级收束：`campaign_group=PARENT-LIXILIE-HUAIXI-782-786`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-232-02`；`machine_settlement=no`；`settlement_status=absorbed`。

- 当前状态：淮西战争父链；唐收复部分州县，但襄城卷末陷落，李希烈威胁持续。
- 时间范围：783年正月—十月。
- 地理范围：汝州、尉氏、郑州、彭婆、郏城、邓州、上津、黄梅、黄州、蔡山、蕲州、安州、襄城、许州、沪涧、东都。
- 主要对手：李希烈及淮宁军。
- **①战前状态、起因与可证目标**：承卷227，李希烈据许、联叛镇并威胁汴渠；本卷以渗透汝州、围郑襄扩大控制。唐方目标是保东都、汝郑、襄城并压制淮西；李希烈目标可证为扩大许蔡、夺交通节点。定位：`#入數百人元平不之覺`；`#帥兵三萬圍襄城`。
- **②决策、授权与责任人**：德宗令哥舒曜统行营反击，曹王皋负责东南舟师方向；卢杞主张遣颜真卿宣慰，举朝及李勉反对，德宗仍授权，颜遂被扣。李勉拟袭空虚许州解襄城，中使责其违诏迫返，统帅撤退又不设斥候。定位：`#詔下舉朝失色`；`#上遣中使責其違詔`。
- **③动员与部署**：李希烈数百内应加数百骑袭汝，三千骡军机动袭周曾，三万围襄城；哥舒曜统凤翔等行营兵万余，李勉拟唐汉臣一万、刘德信三千袭许，李坚四千援东都。预备队和襄城守军数本卷未载。定位：`#李克誠將騾軍三千`；`#唐漢臣將兵萬人`。
- **④阶段序列与攻守转换**：淮西内外夹击取汝、继取尉氏围郑；哥舒曜破郏城前锋并复汝。曹王皋先黄梅取胜，再佯攻蕲州诱敌离蔡山，顺流返攻连拔蔡山、蕲州。周曾三万倒戈计划被骡军先发扑灭。襄城被三万围，大雨迫哥舒曜退守；李勉袭许方案被撤后于沪涧中伏，李坚又被断后；哥舒曜粮尽弃城，襄城陷。定位：`#急攻蔡山拔之`；`#殺傷大半`；`#棄襄城奔洛陽`。
- **⑤后勤与环境的实际作用**：李希烈据邓使南路贡商断绝；大雨使哥舒曜从颍桥退襄城，围城最终粮尽；骡军提供快速突袭能力；唐汉臣、刘德信撤回时无斥候导致伏击。上津替代道路另见FIN。定位：`#南路遂絕`；`#會大雨引歸襄城`；`#無復斥候`。
- **⑥收束与后续控制**：唐复汝、黄、蔡山、蕲等节点，但襄城失守、颜真卿仍扣、淮西主力与东都威胁持续，整体安全实际未改善；卷229以后续接李希烈父链。定位：`#李希烈陷襄城`。
- 战前状态与目标：李希烈已据许州、名义奉诏而实际联合叛镇；目标从扩大许蔡控制发展为威胁东都和襄城。唐目标为保东都、汝郑、襄城并平淮西。
- 初期渗透与攻势：李希烈以数百壮士假应募进入汝州工程，再以数百骑外袭内应夺城；董待名等四出抄掠，取尉氏、围郑州，官军数败，侦骑逼彭婆，东都士民避入山谷。
- 唐军部署与反击：哥舒曜率凤翔、邠宁、泾原、奉天、好畤行营兵一万余，郏城破前锋，二月收复汝州。曹王皋在黄梅破韩霜露、拔黄州，以舟师佯攻蕲州引敌离蔡山，再顺流急返拔蔡山、蕲州。
- 内部分化：周曾等计划率三万回袭李希烈并奉颜真卿，拟以王玢等内应；李希烈以李克诚三千骡军袭杀，计划失败。此后外出掠郑、尉氏部队一度撤回，显示短期牵制收益。
- 襄城阶段：李希烈三万围城。哥舒曜因大雨从颍桥退襄城；其后守粮耗尽。李勉判断许州空虚、拟以唐汉臣一万和刘德信子弟军三千袭许解围，却被中使责令回师，撤回时无斥候，李克诚伏击于沪涧，杀伤大半；李坚四千又被断后不能归。十月哥舒曜弃城奔洛阳，襄城陷。
- A 环境敌情：大雨、坚城围困、敌三万与机动骡军；东都周边交通和人心受威胁。
- B 实际成本：东都士民逃入山谷；南路贡商中断；沪涧官军杀伤大半；张伯仪安州败亡节；襄城守军粮尽。
- C 目标未完成或未保持：汝州、黄蔡蕲方向有局部收复，襄城最终失守，淮西主力未被消灭。颜真卿仍被扣。
- D 可归责失误：汝州募工不察内应是防务疏漏；中央撤销袭许方案后部队狼狈回返且无斥候，直接导致伏击，责任链涉及中使传诏与统帅侦察失当。卢杞以几无依据的“宣慰可服”遣颜真卿，在举朝、李勉均警告下仍执行，形成明确高风险用人决策，实际结果为元老被扣。
- 已实现收益：哥舒曜短期克汝，曹王皋拔黄、蔡山、蕲；未改变总体襄城危机。
- 影子定位：`P3/S4/M3/A2→base_WC4→WC4`〔评价主体：唐内战体系。P3：一万三千军杀伤大半，即使全按伤残五分之一折算亦逾千；死亡伤残构成不明不上推P4。S4：东都屏障、南路贡运与襄城核心交通军政区多军反复争夺。M3：跨多道长期围守与救援、粮道供给。A2：襄城粮尽弃守及局部城防军资损失。最高S4，P3不与S同档，不升档；置信度高〕；`SB0`〔虽收复汝、黄、蔡山、蕲等节点，但襄城终陷、淮西主力与东都威胁仍在，安全状态已有明确恶化事实，置信度：高〕；`WR2`〔实际恢复汝州、黄州、蔡山、蕲州多个节点控制，但襄城丧失且持续性受李希烈主力威胁，降档记实质回报，置信度：中〕。
- SB/WR依据：`SB0`〔评价主体为唐，威胁对象为李希烈淮西主力，受益方向为东都屏障与江淮贡运；局部虽复数州，襄城最终失守且主威胁继续扩张，安全状态明确恶化。本卡只结算本卷阶段并归入李希烈父链；置信度高〕；`WR2`〔汝、黄、蔡山、蕲等节点确已恢复控制，形成多个可识别城州所得；襄城丧失且持续控制受威胁，故压在实质回报，不把降众人口视作资产；置信度中〕。

### FIN-LEAD-228-03 三份军给、间架税与除陌钱

- 独立机制：本卡登记出境军三份给养制度、间架税和除陌钱等普遍财政政策；各战军粮消耗与战损归WAR卡。
- 时间与地点：783年六月，全国财政，重点关中与出境诸军。
- 前态：四军屯魏、十余道军环淮宁；旧制军出本境由度支供给。德宗加出境酒肉而本道仍给军户，使一人兼本人、出境加给、家属供给三份，士卒因此有利可图，诸军刚越界即停。
- 军费结果：月费一百三十余万缗，常赋不能供；这是一项已发生的激励错配和财政成本，不等同普通士卒个人过错。
- 间架税：每屋两架为间，上等每间二千、中一千、下五百；吏入室计数。屋多而无其他资产者可能缴数百缗；隐匿一间杖六十，告者赏五十缗且由被告家支付。
- 除陌钱：公私给付、买卖每缗留五十钱，实物交换折钱计税；隐百钱杖六十、罚二千，告赏十缗。
- 人身、产权与市场影响：官吏入户清点，刑罚和告密奖励造成普遍压力；正文明确远近愁怨，但未载房屋出售、逃亡、税收总额或物价。
- 持续性：八月陆贽建议罢京城及畿县间架杂税以靖人心，德宗未采纳；十月叛军以“不税间架陌钱”号召居民，表明政策成为现实政治怨点。
- 证据：`revision_ref=803246`；正文锚点“一人兼三人之給”（编纂者制度描述）；“吏執筆握算，入人室廬計其數”（编纂者纪事，执行方式）；“愁怨之聲，盈於遠近”（编纂者总结，公共反应）。
