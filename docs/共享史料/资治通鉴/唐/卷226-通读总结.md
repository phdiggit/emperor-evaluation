## 需建详卡的候选

### WAR-LEAD-226-01 吐蕃—南诏三路入蜀与唐军反击

- 父级收束：`campaign_group=CAMPAIGN-TANG-226-01`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-226-01`；`machine_settlement=yes`；`settlement_status=closed`。

- 当前状态：可能形成西川防御战役群；本卷阶段已从入侵收束到恢复维、茂二州，但长期边防效果未知。
- 时间范围：779年十月。
- 地理范围：茂州、扶州、文州、黎州、雅州、江油、白坝、七盘、维州、茂州、大度河外。
- 主要对手：吐蕃、南诏联军。
- 本卷所属阶段：集结—三路入侵—唐军跨道部署—合击—追击—收复。
- 可能父链与子事件：父链为西川安全危机；白坝、七盘、维茂和大度河外为同一反击阶段的子事件，不拆成四项成果。
- **①战前状态、起因与可证目标**：崔宁入朝，留镇诸将不能御；吐蕃、南诏合兵十万，明确宣称取蜀为“东府”，分茂州、扶文、黎雅三路入侵。唐方可证目标是救蜀、阻止其占领并恢复失州；杨炎同时借救援在蜀腹地部署中央亲兵。定位：`#吐蕃與南詔合兵十萬三道入寇`；`#吾欲取蜀以爲東府`。
- **②决策、授权与责任人**：德宗起初催崔宁归镇；杨炎反对，提出留崔宁在朝、调朱泚所领范阳戍兵与禁兵救蜀，德宗批准。李晟、曲环分别统中央与边镇兵，东川、山南将领执行另一合击方向；具体东川、山南统帅本卷未载。定位：`#請留寧發朱泚所領范陽戍兵數千人`；`#上曰善`。
- **③动员与部署**：李晟领禁兵四千；曲环领邠、陇、范阳兵五千；东川军自江油趋白坝，与山南军合击。正文未载预备队、各州守军数及联军三路分别兵数。定位：`#上發禁兵四千人使晟將之`；`#發邠隴范陽兵五千使曲環將之`。
- **④阶段序列与攻守转换**：联军三路突破、连续陷州县，刺史弃城、士民入山；唐改为多道救援，东川与山南先在白坝合击获胜；范阳兵追至七盘再破敌，继而收复维、茂；李晟继续追至大度河外第三次击破。联军由进攻转为退走，唐军由救援转为追击收复。定位：`#虜連陷州縣`；`#自江油趣白壩與山南兵合擊`；`#遂克維茂二州`；`#晟追擊於大度河外`。
- **⑤后勤与环境的实际作用**：联军退却途中因饥、寒和山崖地形大量死亡，说明补给与山地追退直接促成溃败；唐军利用江油—白坝、七盘、大度河方向连续追击。唐军粮源、运输损耗、天气遭遇和军械，本卷未载。定位：`#饑寒隕於崖谷死者八九萬人`。
- **⑥收束与后续控制**：唐实际收复维、茂，入蜀攻势被击退；其他先陷州县的逐一恢复、本方驻军与追击终点本卷未载。异牟寻随后筑苴咩城并继续受吐蕃册封，表明吐蕃—南诏联盟未被结构性拆除，须跨卷续查。定位：`#遂克維茂二州`；`#吐蕃封之爲日東王`。
- 战前国家与战区状态：崔宁入朝，留镇诸将不能御；西川地富但朝廷此前十四年贡赋不入，中央与地方军权关系紧张。
- 敌方状态与目标：正文直接载联军十万、分三路，并宣称“取蜀以为东府”；其兵力为联军总口径，未分列两方。
- 本方初始条件与部署：禁兵四千由李晟统率，邠、陇、范阳兵五千由曲环统率；另有东川军自江油趋白坝与山南兵合击。朱泚所领范阳戍兵、禁军用于救蜀同时带有中央在蜀腹地布置亲兵的政治目标。
- 阶段序列：敌军三路突破州县，刺史弃城、士民入山；唐留崔宁于朝并调兵；东川、山南在白坝合击；范阳兵追至七盘再破；收复维、茂；李晟追至大度河外再破。
- 粮道、地形、气候：敌方在追退中出现饥寒、坠崖谷死亡；正文未说明唐军粮运线路和损耗。山地州县、七盘和大度河外反映追击地形，但不可据名称补猜具体难度。
- A 环境与敌情困难：敌军号十万且三路并进，地方守军先败、州县连续陷落。
- B 实际战争成本：士民“竄匿山谷”，已发生流离和地方控制中断；敌方“饑寒隕於崖谷死者八九萬人”为编纂者直接数量叙述，含饥饿、寒冷、坠谷等复合死亡原因，不能改写为唐军斩杀八九万。
- C 目标未完成或成果未保持：本卷恢复维、茂并击退入侵，其他先陷州县恢复情况、南诏是否退出吐蕃体系均未知；异牟寻随后筑苴咩城并受吐蕃封日东王，说明联盟政治关系未消失。
- D 可归责失误：留镇诸将不能御、刺史弃城是直接事实；具体责任权限与造成损失未充分，暂不定个人责任。杨炎留崔宁方案包含收回蜀地军政权的政治计算，本卷军事结果为成功，不能仅因动机复杂判失误。
- 已实现结果与收益：联军退却，维、茂二州收复，蜀地即时入侵危机缓解；持续时间和边防稳定性未知。
- 军事体系证据：禁兵、边镇兵、东川与山南军形成多路协同；中央借救援向西川腹地置亲兵，显示战争部署与削藩控制重叠。
- 跨领域后果：战争造成州县陷落和士民避难；收复恢复区域安全。南诏筑城迁居是其内部防御与政权中心安排，不作为唐方工程成果。

- 举措前状态：玄宗末版籍失实；安史战争后征科无常准、使司多头自立名目，富户以为官为僧规避，贫户负担更重，吏胥侵蚀，民众频繁输送并逃为浮户，土著“百无四五”。
- 举措：先定州县岁费和上供总额；按现居登记、不分主客；按贫富而非丁中定差；行商在所在州县税三十分之一；夏秋两征；租庸调杂徭并省，统一于度支；两税外加征一钱以枉法论。
- 决策者与责任：杨炎建议，德宗采纳并借赦令执行；黜陟使、观察使、刺史负责定等。
- 已实施结果：正文明确“因赦令行之”，不是仅有倡议；本卷未提供各地征收公平性、逃户回流或长期民生效果。
- 人口财政口径：当年税户3,085,076，籍后人口768,000余，税钱10,898,000余缗，税谷2,157,000余斛。正文“籍後”具体身份口径需后续校勘，不自行解释。
- 正负分账：制度意图包括取消杂征、均衡主客与贫富；实际全国结果尚未知，不能以制度文本直接判民生改善。两税外禁加征是约束，不等于地方从此零加派。
- 证据：`revision_ref=1546182`；正文锚点“二稅外輒率一錢者，以枉法論”（制度文本）；“率皆逃徙為浮戶，其土著百無四五”（编纂者历史背景与实际人口迁徙）。

### FIN-LEAD-226-06 安史跨期破坏与刘晏财政民生体系

- 独立机制：本卡以安史破坏作为历史基线，只结算刘晏物价信息、常平救荒、盐法和分段漕运体系及其兑现结果；战争损害仍归前卷WAR父级。
- 时间与性质：780年七月刘晏死后追叙；覆盖安史乱后至刘晏任末的跨期财政、人口、救荒、盐法、漕运结果。
- 历史基线：安史乱数年间“天下户口什亡八九”，州县多为藩镇控制、贡赋不入，府库枯竭，戎狄岁犯、重兵长期驻防，军费无数。这里的“户口亡”包含死亡、逃散、脱籍等可能，不等同于全国人口死亡八九成。
- 价格与信息：付厚价募快行人员，建立递报物价网络；通过掌握物价、丰歉调节，使正文称天下无甚贵甚贱之忧。
- 救荒与人口：各道知院官按旬月报雨雪丰歉；丰时贵籴、歉时贱粜，提前预计蠲免救助，按期奏行，不待流亡饿殍后才赈。正文归因“民得安其居业，户口蕃息”。
- 数量结果：全国见户由不超过二百万增至三百余万；正文特别称刘晏所统区增长、非所统区不增。财赋岁入由不超过四百万缗至一千余万缗。
- 盐法：只在产盐地设盐官，收盐转卖商人；远地设官盐储备，商绝盐贵则减价卖常平盐。江淮盐利从不超过四十万缗至六百余万缗；正文称国用足而民不困。河东盐利不超过八十万缗且盐价更贵。
- 漕运：按江、汴、河、渭水情分段造船、设仓转运，十船一纲；每年运谷有时百余万斛，正文称无斗升沉覆。扬子十场造船，每艘给千缗，刘晏明确以较高初始支出换坚牢和长期运行。
- 成本与不确定性：盐专卖对不同地区价格、商民负担的细项未知；船场给费被质疑实际成本不到一半，刘晏解释为组织激励，属于本人政策论证。后世五十年、咸通年间削减造船费后船脆、漕废，是编纂者跨期持续性叙述，不归咎本卷当时百姓。
- 责任边界：刘晏的财政运行成效有编纂者明确总结；其被杀源于杨炎复仇构陷，天下称冤。不能把后续罢使造成的组织失灵当作刘晏本人失误。
- 证据：`revision_ref=1546182`；正文锚点“天下戶口什亡八九”（编纂者跨期总结，复合人口损失口径）；“由是民得安其居業，戶口蕃息”（编纂者因果判断与公共结果）；“每歲運谷或至百餘萬斛，無斗升沉覆者”（编纂者数量与运行结果）。
