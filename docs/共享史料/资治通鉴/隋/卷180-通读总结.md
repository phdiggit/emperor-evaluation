## 二、战争、边防与安全详卡

### WAR-LEAD-SUI-HANWANG-604 杨谅十九州内战

- 父级收束：`campaign_group=SUI-LEAD-SUI-HANWANG-604`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-SUI-HANWANG-604`；`machine_settlement=yes`；`settlement_status=closed`。

- 战前军政基础：杨谅总并州，自山以东至沧海、南到黄河的五十二州受其节制，可便宜行事；以防突厥为名大修器械、招亡命，私人近数万。文帝死后征书不合预设密记，杨谅确认宫廷有变并发兵。
- 谏阻与扩散：皇甫诞判断杨谅兵资不足、逆顺不敌，流泪切谏后被囚；岚州陶模拒绝乔钟葵，被兵临仍不屈。最终十九州从乱，已经越过谋议进入实际大规模内战。
- 战略分歧：王頍提出二选一——长驱京师须用关西将领，割据旧齐则用山东人；裴文安主张以弱兵守节点、精锐经蒲津直趋霸上。杨谅同时采用两策，分余公理出太谷趋河阳、綦良出滏口趋黎阳、刘建出井陉略燕赵、乔钟葵出雁门，裴文安等指京师。
- 蒲津突袭与自失战机：数百精骑蒙面伪装宫人，骗过门司进入蒲州，丘和越城逃走；裴文安距蒲津百余里时，杨谅忽令紇单贵断桥守蒲州并召回前锋，失去疾进京师机会。
- 代州守城：李景先斩刘暠；乔钟葵以劲兵三万攻城，李景仅数千、城池不固，边战边筑。李景把战术交给冯孝慈、吕玉、侯莫陈乂，自己稳定军心，屡次击退乔军。
- 杨素渡河：杨素以轻骑五千夜抵黄河，收商船数百、船内铺草消声，衔枚渡河，黎明突击蒲州；紇单贵败逃，王聃以城降。此后杨素统数万任并州道总管、河北安抚大使。
- 内部反正失败：豆卢毓斩留守朱涛、释放皇甫诞并闭城拒杨谅；杨谅回攻，南门稽胡不识而射，西门守兵识王开门，豆卢毓、皇甫诞被杀。
- 河阳—黎阳战线：史祥在河阴诱余公理聚兵守南岸，另以精锐从下游潜渡；余军尚未列阵即败。史祥东进黎阳，綦良部不战溃散。
- 井陉与代州救援：李子雄先在幽州募千余、伏兵擒总管窦抗，再发幽州步骑三万西进，抱犊山破刘建。杨义臣以步骑二万救李景，将数千牛驴藏涧谷、令数百人执鼓；与乔钟葵再战时驱牛驴扬尘齐鼓，敌误认为伏兵，奔溃后被追击大败。
- 高壁决战：赵子开十余万据高壁、列阵五十里。杨素以各二千人牵制晋、绛、吕三州，自率奇兵潜入霍山崖谷，绕至北军背后；为强迫出战，斩原定留营三百人。突袭中鸣鼓纵火，北军自相蹂践，死伤数万。
- 清源终局：杨谅亲率近十万在蒿泽拒杨素，遇雨欲退；王頍主张乘杨素孤军疲弊决战，未被采纳。杨谅退清源后再败，萧摩诃被擒；杨谅退守晋阳、被围后请降，余党平定。王頍自杀。
- 财政民生后果：内战实际杀伤数万，杨素又处死本军三百人；十九州、多条交通和军镇长期动员。战后杨谅部吏民“死徙者二十余万家”，死亡与迁徙合并口径不可拆算，但代表大规模人口与家庭破坏。
- **战争成本影子定位（评价主体：隋中央政权；内战双方损失在本父卡合并去重）**：P4 / S5 / M3 / A1 → WC5（试算旧档已废止→新档WC5；高置信度）：
  - P4：高壁等战斗明确“死伤数万”，另有杨素处死本军三百人，支持万人至十万人以下量级；“死徙二十余万家”混合死亡、迁徙且以户为单位，不能换算人数进入P。
  - S5：十九州卷入，蒲津、河阳、黎阳、井陉、晋阳等多个核心军政交通区域实际发生大规模持续作战，中央通向河北、河东的交通与行政控制形成广泛危机；不是由政治终结或地名数量自动定档。
  - M3：杨谅近十万主力及多路军、中央数万援军在十九州战区跨区展开，渡河、救城、追击均已发生；尚不足以证明全国性多年动员，故不取M4。
  - A1：仅能确认商船数百被中央军征用作渡河工具；原文未载大规模船械、粮储或府库毁失，故资产损失只作轻档。
  - 公式：基础档 `max(P4,S5,M3,A1)=5`；P、S不同为基础最高档，不升档，故WC5。SB3、WR1维持：叛乱集团与晋阳被控制，但未证明宗王威胁结构长期消失；内部复控不创造新增财富。置信度：高。
- 父级去重：本卡是杨谅内战唯一父卡，蒲津、代州、高壁等阶段不另立WC；二十余万家死徙只记录一次，不能把户数换算人口或死亡。
- 史源定位：`資治通鑑/卷180@1502733#漢王諒有寵於高祖—餘黨悉平`；`#諒所部吏民坐諒死徙者二十餘萬家`。
