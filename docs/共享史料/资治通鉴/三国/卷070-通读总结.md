- 时间与地域：本卷所见223年春，江陵、中洲、濡须、橐皋和长江沙洲；围江陵已持续六个月，其起点在前卷，因禁读范围不补猜
- 战前状态：魏军已经包围江陵，吴军援兵曾被夏侯尚击退；曹仁另以步骑数万攻濡须。吴依大江、城池和水军守势，魏军存在跨江、浮桥和单线撤退困难
- 濡须兵力与过程：朱桓分兵后在手及所部仅五千；曹仁大军长途步行、人马疲困，遣曹泰攻城、常雕和王双乘油船袭吴军家属所在中洲，自留万人后援。朱桓示弱诱敌，亲拒曹泰并遣别将救中洲
- 濡须结果：曹泰烧营撤退；吴斩常雕、俘王双，魏临阵被杀及溺死者千余。曹仁未夺濡须
- 江陵难度：朱然城内多人肿病，可战者仅五千；魏筑土山、地道、楼橹，箭如雨下，粮食将尽，江陵令姚泰图谋内应。朱然杀姚泰并趁隙破魏两屯
- 魏军后勤危险：夏侯尚将步骑置于江中沙洲，以浮桥联络；董昭事前明确指出深入、浮桥、单道三重风险及江水将涨。曹丕下令促撤后，吴军从两端压迫，魏军在狭道上“仅而获济”；十余日后江水果然大涨
- 实际成本：江陵守城病患与缺粮、魏军围城六个月、濡须千余死溺均已发生；随后“大疫”促使曹丕召回诸军，“大疫”只用于解释召还，不据以量化或分配到具体军种
