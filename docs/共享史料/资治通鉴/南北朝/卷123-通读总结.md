## 二、战争、边防与安全详卡

### WAR-LEAD-NC-NORTHERN-YAN-END-436-438 北燕东迁与政治终结父卡


- **①战前状态、起因与可证目标**：卷122北燕已被北魏压缩至和龙并请高句丽接应。436年北魏拒绝冯弘送侍子之请，决定出兵；北魏目标是迫燕服从或取和龙，高句丽的实际行动是接走冯弘及其户口，冯弘则求保存政权与人口。
- **②决策、授权、反对意见及责任人**：魏主遣娥清、古弼率精骑一万并会辽西军；高句丽遣葛卢孟光数万随阳伊接应。燕尚书令郭生利用民众畏惧迁徙开门迎魏，魏军疑而不入，郭生遂转攻燕王。古弼酒后拔刀阻止高苟子追击，使撤离队伍脱身，后与娥清同被黜。438年高句丽王决定杀不受约束且求宋接应的冯弘；宋使王白驹等擅自报复，高句丽据此要求宋方处置。
- **③动员兵力、统帅、分路与部署**：魏军精骑一万，另有拓跋婴所统辽西军；高句丽接应军数万。燕撤离时妇女披甲居中、阳伊等精兵在外、葛卢孟光骑兵殿后，队列前后八十余里。宋使所领七千余人在438年另行袭击高句丽将领，属于后续外交武装阶段，不与436年兵数相加。
- **④交战阶段和攻守转换**：
  1. 魏军克白狼城并逼近和龙；高句丽军在临川集结。
  2. 郭生开门未获魏军接应，转而在宫阙内攻冯弘；冯弘引高句丽军自东门入战，郭生中箭死。
  3. 葛卢孟光取燕武库精仗分给部众并大掠城中；冯弘组织全城现有户口东迁、焚宫殿，火延续十日。
  4. 高苟子拟追，古弼强令停止，燕众以长队撤至高句丽控制区。
  5. 高句丽先削夺冯弘侍从、取其太子为质，继而在北丰杀冯弘及子孙十余，北燕政治实体终结。
  6. 宋使七千余人擅击执行杀弘的高句丽将领，杀一人、擒一人；宋为维持远国关系先拘送执行者，后赦免。
- **⑤粮运、道路、地形、天气与军械作用**：和龙东、西城门和宫阙构成内战节点；燕武库精械被高句丽军直接接收，改变撤离部队装备。八十余里队列、妇女披甲和骑兵殿后说明撤离保护序列；粮运、天气和沿途损失未载。
