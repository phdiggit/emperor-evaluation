- 兵力与地形：史载柳仲礼赴援百骑；侯景军伤亡有“斩首数百级”“沉淮水死者千余人”。大雾、夜半迷途、未闭营栅与马陷泥淖均直接进入战斗过程。
- 毛成本：韦粲及其子弟、从弟战死，亲戚死数百人；侯景军数百人被斩、千余人溺死；柳仲礼肩部重伤。

- 责任与证据类型：刘叔胤未按部署截后、柳仲礼负伤后不再求战均为已发生行为；大雾属于战场条件，不作主观过失。郭山石救人、惠氏吮创止血为实际救援。
- 财政民生投影：续接 `FIN-LEAD-162-01`，只结算已载死亡、溺死与重伤。
- 史源定位：`資治通鑑/卷162@803202#春正月丁巳朔—亦推柳仲禮為大都督`。

### WAR-LEAD-162-03 伪和、粮道转移与台城陷落

- 父级收束：`campaign_group=NC-HOUJING-LIANG-548-552`；`settlement_role=stage`；`settlement_owner=WAR-LEAD-164-07`；`machine_settlement=no`；`settlement_status=absorbed`。

- 共享事件ID：`event-zztj-161-houjing-rebellion`
- 战前供给态势：闭城时公卿组织男女负米四十万斛，收府藏钱帛五十万亿聚于德阳堂，但未备薪刍、鱼盐；到二月，台城拆尚书省作薪，撤坐荐喂马，继而以饭喂马，士兵煮铠、熏鼠、捕雀，食马肉杂人肉者发病。侯景军同样饥饿，因援军切断东城粮路，掠无所得；东城存米可支一年。
- 伪和阶段：王伟判断台城难以速拔、援军日增、己军乏食，主张假和以运东城米入石头，借机休士、修甲械 → 梁太子因城困请和，梁武帝先拒称“和不如死”，在太子固请后许可 → 侯景索江右四州与人质，傅岐所陈“借和退援”的判断当时属于谏言和风险预判 → 梁以石城公大款为质，在西华门外盟誓并敕诸军不得进 → 侯景不解长围，持续修铠仗，以缺船、怕南军追击为由追加要求；梁又把会理所部三万人自白下移往江潭苑 → 侯景完成东府米向石头的转运，获知荆州军退、援军不统一后背盟。
- 决战阶段：台城闭城初十余万人、披甲二万余；久围后身肿气急，死者十之八九，乘城者不足四千且羸弱，尸体满路、腐液入沟 → 会理等拟夜渡，但协同部队未按时到，营垒未立即被宋子仙攻击，赵伯超先退，战死及溺死五千 → 侯景决开石阙前水，百道昼夜攻城 → 太阳门守将邵陵世子坚饮酒不恤士卒，董勋、熊昙朗由城西北楼引侯景军登城 → 永安侯确力战不能退敌，台城于三月丁卯陷落。
- 城破与外援解体：侯景以五百甲士见梁武帝，随后撤两宫侍卫，纵兵尽掠乘舆、服御和宫人 → 柳仲礼召诸将而不决战，外围军各散，仲礼等开营投降 → 王琳运二十万石米到姑孰，闻城陷后将米沉江而返 → 侯景焚台内积尸，重病未死者也被聚焚。
- 毛成本：台城军民十之八九病死，守城者由十余万人体系减至不足四千乘城者；东府夜战战及溺死五千；宫中财物与人员被掠；二十万石军粮沉江；积尸与尚存气息的重病者被焚。
- 已实现战果与持续收益：侯景取得台城、梁皇帝和宫禁物资，解除粮荒并击散外援；梁中央军政体系被挟持。其控制范围此后仍受吴兴、宣城、会稽及各藩抵抗，并非立即统有江南。
- 责任与证据类型：王伟关于假和用途的谋划随后通过运米、修械、背盟实际兑现，可与傅岐此前风险预判区分；梁太子允许移兵、柳仲礼与诸将不战、太阳门将领失守均有后续结果。侯景奏列梁政十失属于叛军自辩，不作这些政务事实的独立证明。
- 财政民生投影：续接 `FIN-LEAD-162-03`，共享结算围城饥病、死亡、掠夺、毁用官署、军粮沉江和焚烧病者；运入石头的粮食只构成侯景军供应恢复，不作居民民生收益。

- 江北阶段：秦郡、阳平、盱眙降侯景，阳平改北沧州、秦郡改西兖州；东徐、北青、淮阳等则降东魏或弃城，使侯景与东魏同时切割梁江北 → 董绍先以不足二百且久饥的兵抵广陵，南康王会理虽士马强盛仍交城；董绍先收走广陵文武部曲、铠仗、金帛，令会理单骑还建康 → 北兖州民发兵拒侯景所置刺史，援将羊海转降东魏，东魏据淮阴。
