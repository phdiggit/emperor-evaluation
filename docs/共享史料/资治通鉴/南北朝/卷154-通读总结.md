## 战争事件详卡

### WAR-LEAD-154-01 关陇平乱：渭水诱伏、安定追击与水洛坑降

- 父级收束：`campaign_group=NC-V154-LEAD-154-01`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-154-01`；`machine_settlement=yes`；`settlement_status=closed`。

- **初始编组**：尔朱荣以尔朱天光为主帅、贺拔岳与侯莫陈悦为左右都督。天光离洛阳时仅配军士一千，并发洛阳以西沿路民马供军，先已形成民间军需征取。
- **赤水蜀破路阶段**：赤水蜀断道且拒绝受谕、纳马，天光停潼关；贺拔岳越过主帅犹疑，在渭北击破之，获马二千，选强壮者补军，又税民马，合得万余匹。尔朱荣再因停军责杖天光一百，并增兵二千。
- **岐州与趣栅态势**：丑奴自围岐州，尉迟菩萨、万俟仵率部渡渭取趣栅；贺拔岳以一千骑赴援，见栅已失，故意杀掠吏民诱敌来战。此处杀掠是实际民众伤害，不能写成纯粹战术成功。
- **渭水诱伏**：菩萨以步骑二万至渭北。贺拔岳先以数十、百余骑隔水挑衅，逐渐东引至浅水处；敌误判其逃，弃步兵、以轻骑半渡追击。岳依横冈预设伏兵，返身攻击，命下马者免杀，遂俘三千、尽获马匹，再渡渭降步卒万余并收辎重，生擒菩萨。
- **佯休与分割**：丑奴弃岐州走安定、在平亭设栅。天光到汧渭间牧马，故意宣称暑热停军、秋后再进，并放还敌方侦候。丑奴据此分众耕种，只留元进五千守大栅和许多千人以下小栅。
- **突进安定**：天光黄昏秘密整军，诸军连续夜发，黎明围拔元进大栅；俘虏全放，各小栅闻讯而降。魏军昼夜不停抵安定，侯几长贵献城；丑奴奔高平，贺拔岳轻骑追至平凉，趁敌未列阵时由侯莫陈崇单骑突入擒丑奴，后骑继至使全军崩溃。高平城中又执送萧宝寅投降。
- **初步整合**：泾、豳以西至灵州各部多降，关中大赦；魏处死宝寅、丑奴。降众停止作战并复纳魏治，首先构成人口保全和国家整合成果；原文未载这些降众遭强迁或异常供亿。
- **道洛复起**：万俟道洛率六千入山不降。高平大旱、马乏草，天光退屯五十里外，仅留长孙邪利二百镇原州；道洛联络城民突袭，杀邪利及所部。天光追至牵屯山，敌败入陇，投王庆云；庆云据水洛城称帝。
- **水洛攻守转换**：天光七月入陇，野战射伤道洛并夺东城；敌并守西城，但城中缺水。获知庆云、道洛欲夜突后，天光一面招降并故意退军、允许敌众到涧取水，使其放弃立即逃走，一面令军士造七尺木枪环城布列、要道加密，伏兵其中，并暗缚长梯于城北。
- **夜间决战与追歼**：庆云、道洛夜突，马触枪受伤倒地，伏兵起而擒二人；魏军缘梯入城。南出余众同样被木枪阻截，穷困请降。天光收走兵仗后坑杀降众一万七千，并分其家口。这是已发生的大规模杀降与家庭拆分，不因平乱收益而冲淡。
- **已实现收益**：三秦以及河、渭、瓜、凉、鄯州皆降；秦州、南秦州城民谋杀刺史之变也被讨平。宇文泰行原州事，以恩信安抚凋弊关陇，民间评价称若早遇之便不从乱；具体户口、税收恢复量不载。
- **双账**：魏消灭丑奴、宝寅、庆云、道洛主要政权，重新整合关陇多州；毛成本包括沿路征马、岳为诱敌而杀掠趣栅吏民、旱灾与军马草料困境、邪利二百人被杀，以及一万七千已缴械降众遭坑杀、家口被分。
- **史源定位**：卷154，二月尔朱天光受命至七月水洛城破、宇文泰抚原州段。
- **战争成本影子定位（北魏政权体系内战父级）**：`P4 / S4 / M3 / A3 → WC5`（WC5，高置信度）。P：水洛明确坑杀已降一万七千人，另有原州守军二百被杀，合计已达P4；趣栅杀掠人数不详不再推算。S：关陇多州长期反复、城栅易手并发生大规模平乱，是完整核心战略区域的生产军政系统重大破坏。M：多路军、二万步骑及连续攻城追击为大战区动员。A：沿路征取民马万余、夺辎重并发生城防军资损失，按A3。公式：`base=4`，P、S同为基础最高档，升至WC5；父级去重。

- **皇帝决策**：城阳王徽、李彧等持续劝除荣；孝庄帝因河阴之难与受制状态密谋。匿名书、洛阳流言以及双方互称将受害都是风险线索，不能直接当作荣已反。
- **入洛态势**：尔朱荣率四五千骑从并州来洛，入宫时从人通常不过数十且不持兵。皇帝一度因元天穆仍在并州而延迟，召其入京后又有一次伏兵未及发动。

### WAR-LEAD-154-04 河桥争夺、尔朱诸部反攻与洛阳陷落

- 父级收束：`campaign_group=NC-ERZHU-COUNTERCOUP-530-531`；`settlement_role=terminal`；`settlement_owner=WAR-LEAD-154-04`；`machine_settlement=yes`；`settlement_status=closed`。
- absorbed_stages: WAR-LEAD-154-03

- **河阴集结**：尔朱世隆奉北乡长公主和荣部曲焚西阳门出屯河阴。司马子如劝其不要立即北逃，而以守河桥、反逼京师显示力量；世隆遂攻河桥、擒杀奚毅，占北中城并斩朝廷使者。
- **双方扩军**：朝廷命杨津经略河汾，高乾、高敖曹回河北集众；尔朱拂律归以胡骑一千白服至洛索荣尸。皇帝出库物置西门外，一日募敢死之士万人，但洛阳人不习战，屡战不胜。明确出库与募兵是实际财政、兵员投入。
- **火船断桥**：李苗募百余人从马渚上游乘船夜下，纵火船焚河桥；尔朱军争相北渡，桥断后溺死甚众。李苗泊小洲等待南援，官军未至，所部尽死，自己赴水。桥梁毁坏、溺亡与孤军覆没均是实际成本。
- **战线外移**：世隆北遁后，朝廷以源子恭步骑一万走西道、杨昱募士八千走东道；子恭镇太行丹谷并筑垒。世隆拔建州，杀城中人无遗；诸尔朱部推长广王曄即帝位，分授军政职位，仲远由徐州向洛。
- **朝廷指挥失效**：城阳王徽总内外，却轻敌、嫉能并阻他人献策；赏赐或少、或被中减、或给后追回，形成“徒有糜费而恩不感物”的实际财政组织失败。贺拔胜被郑先护猜忌置营外，在滑台东败降仲远。
- **丹谷突破**：十二月尔朱兆攻丹谷，崔伯凤战死、史仵龙开壁降，源子恭退。兆轻骑倍道，从河桥西涉渡；皇帝基于黄河深广判断其不能猝渡，又受华山王鷙劝说，未亲自迎击。当日河水不及马腹，兆骑骤至宫门，宿卫始觉而溃。
- **洛阳陷落**：孝庄帝被执，锁永宁寺楼；尔朱兆扑杀皇子、辱嫔御妃主、纵兵大掠，杀临淮王彧等。城阳王徽逃亡后被寇祖仁为赏格杀害，但祖仁也被兆因财物拷掠致死。
- **帝被迁杀**：尔朱兆监阅河梁财资，迁帝至晋阳，最终在三级佛寺缢杀并杀陈留王宽。高欢曾致书劝其勿害天子，未被采纳。
