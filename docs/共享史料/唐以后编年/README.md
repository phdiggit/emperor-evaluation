## 文件约定

- `volume-*.events.json` 或 `volume-*.compact.json`：每卷唯一事实源；
- `volume-*.registry.json`：由事实源确定性生成的四域路由登记；
- `volume-*.md`：由事实源确定性生成的人工阅读视图；
- `00-全局审计/post-tang-chronicle-manifest.json`：范围、数量、史源索引身份和 Gate 总表；
- `00-全局审计/post-tang-events-strict.json`：事件、ID 和引文严格校验结果；
- `00-全局审计/post-tang-derivatives-idempotency.json`：registry/Markdown 双跑幂等结果。

五代十国卷266沿用原验收文件名 `volume-266.compact.json`、`volume-266.registry.json` 和 `卷266-四域同读视图.md`，不为统一命名改写已验收事实。
