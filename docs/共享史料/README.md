# 共享史料与通读卡

本目录保存可由多个评分项共同消费的史料通读总结和卡片定位索引。它是证据事实层，不属于任何单一评分项；各评分项负责自己的准入、归责、去重、档位和计分。

当前正式共享材料：

- [`唐以前编年/README.md`](唐以前编年/README.md)：《资治通鉴》秦至唐260卷通读总结卷表；
- [`唐以前编年/00-战争卡审计索引.md`](唐以前编年/00-战争卡审计索引.md)：`WAR-*`卡号到卷文件和标题行的人工审计入口；
- [`唐以前编年/00-战争卡审计索引.json`](唐以前编年/00-战争卡审计索引.json)：同一索引的机器读取入口。
- [`唐以后编年/README.md`](唐以后编年/README.md)：五代十国、宋、辽、金、西夏、元、明、清九组436卷可审计通读产物及全局终审入口。

唐以后新增编年材料遵循[`编年体史料通读工作流`](../证据规则/编年体史料通读工作流.md)：运行草稿、固定缓存和审计暂存只写项目 `tmp/chronicle/**`；逐卷验收后的事实 JSON、确定性 registry、Markdown 阅读视图及其 manifest/索引写入本目录对应史书子目录。未通过预检、相邻卷审计或幂等检查的产物不得进入本目录。

共享只意味着共同引用，不意味着不同评分项可以重复加总同一事实。创业统一、财政民生、军事边疆、文明整合和历史负债仍分别依照各自规则消费。
