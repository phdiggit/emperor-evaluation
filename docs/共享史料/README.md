# 共享史料与通读卡

本目录保存可由多个评分项共同消费的史料通读总结和卡片定位索引。它是证据事实层，不属于任何单一评分项；各评分项负责自己的准入、归责、去重、档位和计分。

当前正式共享材料：

- [`资治通鉴/README.md`](资治通鉴/README.md)：秦至唐中期260卷通读总结卷表；
- [`资治通鉴/00-战争卡审计索引.md`](资治通鉴/00-战争卡审计索引.md)：`WAR-*`卡号到卷文件和标题行的人工审计入口；
- [`资治通鉴/00-战争卡审计索引.json`](资治通鉴/00-战争卡审计索引.json)：同一索引的机器读取入口。

共享只意味着共同引用，不意味着不同评分项可以重复加总同一事实。创业统一、财政民生、军事边疆、文明整合和历史负债仍分别依照各自规则消费。
