# 第五项统治者政治素质规则与计分合同

> `formal_settlement_published / negative_tail_replayed / database_write_closed`。正式逐人裁决局部维护；规则修订须复核全池覆盖、横向一致性与确定性导出。

## 1. 评价对象与结构

第五项评价统治者本人跨情境、可重复的政治行为与稳定素质，不评价国家和社会已经取得的业务成果，最高120分、最低-18分：

| 分项 | 名称 | 分值 |
|---|---|---:|
| A | 履职与认知稳定性 | 35 |
| B | 人事与权力管理 | 50 |
| C | 政治克制与品格 | 35 |
| **合计范围** |  | **-18—120** |

适用全部评价对象；创业团队结果不妨碍准入，也不重复换分。

本合同定义三轴准入、归责、合成与输出。旧I5B只作史料lineage，不恢复旧数值、人才换分、团队分或排名。

## 2. 固定材料池与全池工作顺序

先消费前四项canonical/accepted材料、公共登记和可追溯旧线索，不从名人或开放搜索开始。

1. 对全名册建立唯一、稳定的`ruler_id / task_code`矩阵；
2. 对前四项和旧I5B材料机械全池筛查，A、B、C广召回，不预设每人候选条数；
3. 标记来源分项、本人选择、归责强度、行为、反馈、继续或纠正、方向、同链键、只有结果噪声、跨项重复风险和证据状态；
4. 排除无法形成本人行为命题的纯结果，把可由本人授权、维持、纠正或放任闭合的材料恢复为行为链；
5. 按同一人物或权力关系、同一政策或战役、同一因果链聚合；
6. 对每个命中链完成正负双向语义复核，再确定是否进入核心链、佐证、例外或补证队列；
7. 只有完成全池聚类和复核后，才应用最多七条的最终行为预算。

`NO_OBSERVED_CANDIDATE`、`SUPPORTING_CONTEXT_ONLY`、`UNRESOLVED_EVIDENCE_GAP`不等于0。定向补证闭合已发现行为/归责/反馈/例外；仍无候选进统一发现队列，不给名人额外预算。

本人连续主干史源＋最多两组可改档专题；档位稳定即停，不建事件/臣子全集。

### 2.1 三层检索、客观皇帝基线与豁免

每个轴必须按固定顺序完成三层正反复核：

1. 本地通读总结；
2. 本地缓存史料、前四项正式结算、公共成果、授权周期及既有第五项召回或补证产物；
3. 前两层仍缺少可能改变方向或强度的关键闭环时，联网检索并回到可定位的正史、实录、政书、诏令奏议或可靠学术来源。

三层按需完成，主要阶段和正反入口已查且无中等以上偏离正常履职，才为`VERIFIED_NORMAL_BASELINE=G3-LOW`；理由列范围轨迹，不将缺料或未见负面作中性/美德。

缺环为`UNRESOLVED_EVIDENCE_GAP`。无实权或实权极短不可观察者`EXEMPT_NO_BACKFILL`，不计分排名；短任但有足够权力行为仍正常复核。

人物页同时供行为定位与基础画像；非核心命中也须保留以下处置：

- `BEHAVIOR_CHAIN_LOCATOR`：已经指出可能闭合的本人行为、反馈或持续性位置；
- `BASELINE_PROFILE_SUPPORT`：不足以单独计分，但能描述本轴的基本正负画像、阶段变化或反向复核方向；
- `PENDING_CONTEXT_OR_SOURCE`：语义可能有关，尚缺上下文、本人归责或可靠来源；
- `RESULT_ONLY_OR_OTHER_SUBJECT`：只有结果、他人行为或错期内容，明确排除。

有画像线索但未成链记`MATERIAL_GAP_WITH_PROFILE_CUES`或部分观察，不称无材料；只供补证、反查与名望反差审计。

## 3. 最小充分统治行为链

唯一核心裁决单位是`ruler_behavior_chain`：

`情境与压力 → 本人实际权力与可选空间 → 本人行为或可归责维持/放任 → 可检验的直接结果或后果 → 若后续反馈实际发生，再记录本人继续、修正、撤权或复发`

一条核心链至少必须闭合：

- 发生在本人实际掌权窗口；
- 存在本人可以采取的现实替代方案；
- 能识别本人行动、授权、否决、维持、纠正或明确放任；
- 有足以判断行为是否合理的直接结果、后果或同期检验；
- 后续反馈实际发生时，能说明本人继续、修正、撤权、补救或复发；事件已直接交付终局时，不得为了形式闭环强造中途反馈；
- 已声明成果、损害和跨期后果的主计分项目。

纯结果不成链，但可验证已证选择/授权；“未观察到纠正”不改为“从未纠正”，无中途反馈不强造缺口。

链内保存`repeat_count`、时长、范围、责任、后果和纠错；重复证模式，不逐条加分。异文/多源同果只增置信度。

## 4. 皇帝归责与授权推定

国家级行动进入最高授权复核；不因只记执行者免责，也不把所有臣行归帝。

| 归责状态 | 适用条件 | 第五项处理 |
|---|---|---|
| `DIRECT_EXPLICIT` | 明载本人命令、任命、批准、否决、亲征、撤换、保护或惩处 | 可直接建立本人行为命题 |
| `STATE_ACTION_PRESUMED` | 国家级行动发生在本人实际掌权期，按当时权力结构通常不能绕开最高授权，且没有相反证据 | 进入本人责任复核；必须同时检查例外 |
| `JOINT_OR_SHARED` | 摄政、共治、军政集团或多人共同决定，无法全部归于一人 | 只消费可分离的本人部分；否则降为佐证 |
| `SUBORDINATE_AUTONOMY` | 明载擅自行动、矫诏、抗命、自行投降、开门、弃城或独立叛乱 | 不把初始行为归给皇帝；只审查其事前配置与事后处置 |
| `INHERITED_PREDECESSOR_CHAIN` | 任命、授权或权力结构由前任建立，本人只被动接收 | 不递归归责；本人后续确认、维持、调整或撤换可另成链 |
| `PUPPET_OR_NO_REAL_POWER` | 有证据证明本人被架空、受控制或不掌握相关决定权 | 撤销相应本人推定，转向实际掌权者或记证据缺口 |

第三项`ruler_role_status=unresolved`只限亲自指挥推定，不否定已载命将等授权；第五项可取授权，不搬战果和净收益。

归责强度与方向、行为合理性分开记录。名义上的最高责任不能自动形成负向；实际成功也不能自动证明授权合理。

## 5. 与其他项目的边界

- 制度、行政、民生、军事、文明成果归前四项；第五项只消费本人行为方式。
- 第一项B消费创业团队独立成果和组织化结果；第五项B只消费本人识别、配置、授权、纠偏、容人及权力关系管理行为。
- 第二项B1消费官僚体系整体质量，第二项B2消费日常反馈机制是否运行，第二项D3消费交班结构结果；第五项只消费本人面对人事、反馈和权力关系时的行为模式。
- 第三项消费军事安全、控制与成本收益；第五项B只消费选将、授权边界、临阵换将、失败纠正和军头权力关系管理，不消费战场军纪表现。
- 第四项消费教育文化、知识生态和文明整合结果；第五项C只消费本人在文化强制、迫害、保护和宽容中的最高权力伦理。
- 具名重大决策产生的创业、治理、军事或文明结果分别归第一至第四项；第五项A只看跨多个普通或持续治理情境的认知和履职模式，不另设决策分。
- 跨期社会、军事或文明损害的规模与持续性归对应结果项；第五项C只评价本人行为性质和稳定模式，不另设历史负债扣分。

跨项共证须写新增本人行为命题，不重复换成果规模、时长、价值或历史影响。

## 6. A履职与认知稳定性（35）

### 6.1 评价问题

A评持续履职、理解约束、学习与反证更新，不评勤聪名望或单次成败。

### 6.2 正向触发

- 在多个阶段持续处理核心政务，并能区分轻重缓急；
- 主动理解陌生、复杂或专业问题，而不是完全依赖近臣代断；
- 面对可验证反证修正事实判断、政策理解或工作方法；
- 能识别自身能力、健康和信息边界，进行可监督、可撤回的职务安排；
- 在压力、个人偏好或短期诱惑下仍保持基本履职和认知纪律。

奏章数量、批阅时长、诏令数量、早起晚睡和个人博学只作入口，不能直接换分。单次纳谏、一次认错或一次危机止损通常只证明局部能力。

### 6.3 负向触发

- 长期不履行核心职责、沉迷或把国家职能交给不可监督的私人圈层；
- 在已有明确反证后仍反复坚持同一事实错误；
- 对基本政策机制和现实约束持续表现出严重误解；
- 明知自身失能却拒绝建立可运行的替代履职安排；
- 纠正后迅速复发，形成跨场景的认知或纪律失常模式。

疾病、年龄和客观信息不足本身不作道德扣分；只有在仍有现实替代方案时，本人的安排、拒绝安排或持续错误才进入A。

### 6.4 轴边界

制度反馈归第二项B2，认知模式归A，人事授权归B，强制伦理归C；单次历史节点无模式复验只入结果项。

## 7. B人事与权力管理（50）

### 7.1 评价问题

B评识人、配置、授权、监督及私人/集团权力管理，不建臣子排名。

### 7.2 五类触发

| 类型 | 评价内容 |
|---|---|
| 识别与岗位匹配 | 是否根据当时可观察能力和任务需要选择合适对象，而非事后借成果反推识才 |
| 授权与责任边界 | 是否给予完成职责所需权限，同时保留复核、问责、收权和退出边界 |
| 监督、纠偏与撤换 | 后续反馈实际出现时，能否留任、调整、收权、撤换、惩处或补救；未发生后续反馈不构成独立缺项 |
| 容人保护与反徇私 | 是否保护专业履职和合理异议，防止亲属、宠信和私人恩怨压过公共责任 |
| 权力集团管理 | 是否配置、制衡和处置外戚、宦官、宗室、权臣、军头及共治集团 |

继承与交班材料只有在能够分离出本人的储位安排、顾命配置、军权约束或权力集团处置时进入B；王朝是否顺利延续的结果仍归第二项D3。

### 7.3 准入与排除

授官、沿用、名臣数或受任结果不独立成链；成果只验岗位授权效力，不搬规模时长影响。

公共画像只证当时可见能力，不将`ordinary / usable / important / top / historic`转分；发现能力须首次实用前识别、验证或突破接近障碍证据，不从后果倒推。

同对象连续任用、失控、纠偏合链；岗位权限反馈责任均不同且各自闭合才拆。

### 7.4 正负判断

正向须适配、清楚授权、交付、容人反私或制衡高于基线；负向看误用、失控、私情、压反馈、纵损与知错不改/复发。反馈仅实际发生时审查。

核心国家责任提高代表性，不把国家成果转卓越用人分。

B4授权事实须任务—人选—独立权限—归责结果闭合；强度看难度压力、成果质量规模、独立完成、跨任务稳定与错误授权。难度成果复用正式军事/公共登记，不临时重评或搬战果分，不借皇帝亲征给授权加分；数量不单独定强度。

### 7.5 领域合成不得丢失极性

领域分别保存最强正负、持续、压力、反馈纠正、证据及适用性，不将以下语义混称`MEDIUM`：

- 多次高于基线但尚未达到强档的正向；
- 正负实质并存的混合领域；
- 明确低于基线但尚未形成严重失控的负向；
- 仅有普通履职、结果线索或极性未闭合的领域。

领域至少分`STRONG_POSITIVE`、`MEDIUM_POSITIVE`、`MIXED_BALANCED`、`MEDIUM_NEGATIVE`、`STRONG_NEGATIVE`、`NEUTRAL_BASELINE`、`UNRESOLVED`。中性/未解数量不抬档，独立正向可增强模式；缺失、不适用和弱表现分开。

## 8. C政治克制与品格（35）

### 8.1 评价问题

C评现实诱因/优势下对公共对象的守信、克制与程序，不评私人美德或温和名声。

皇室资源、强制供给及特权是公共权力问题，须持续且显著偏离同期合格基线才成链；生活习惯、一次节省或标签不准入。

### 8.2 正向触发

- 有现实报复、清洗、毁约或扩大惩罚的诱因时仍选择有限处置；
- 保护无辜者、合理异议者或依法履职者免受私人报复；
- 对政治对手、降者、功臣或政治合作对象遵守已作承诺；
- 在拥有绝对优势时仍保留申辩、复核、区分责任或减轻株连；
- 发现冤错、滥权或过度惩罚后实施可验证的纠正和补救。

普通未作恶、缺少迫害记载、例行赦免和无现实诱因的宽容不自动形成正向核心链。

### 8.3 负向触发

- 构陷、滥杀、酷刑、株连、任意剥夺或以私人好恶替代责任判断；
- 对投降、议和、归附、功臣或政治合作对象故意毁约；
- 系统性迫害异见者、学者、群体或无辜相关者；
- 明知执行者扩大伤害仍授权、维持、包庇或拒绝纠正；
- 同类侵害跨阶段复发并成为稳定统治工具。

社会损害规模和跨期后果仍归对应结果项；C只消费最高权力的选择性质、重复性、范围、可逆性和纠错状态。

### 8.4 时代校准

时代只校准替代、难度及常见程度；有可行替代的主动暴行不因时代普遍而中性化。

### 8.5 战场军纪排除

战场军纪及征服中屠杀、劫掠、强征、降俘处置等正负行为均不入第五项核心、佐证、锚或负门；亲征、命令、知情、追认或纠正不解除排除。

相关事实按军事及民生文明对象分账；第五项可另证选将、军头关系及独立政治承诺/司法伦理，不借此重入战场军纪。

## 9. 十领域画像、聚类与七条解释预算

轴级裁决固定消费十个领域画像：A1核心履职可靠性与自身边界、A2信息反馈与认知更新；B1文官与行政人才授权、B2法务监察与专业监督、B3关键权力关系管理、B4军事指挥授权；C1惩罚、株连与强制比例、C2异议者、无辜者与履职者保护、C3守信、合作对象与反报复、C4公共资源与最高权力特权克制。B领域内的主题只用于召回、定位和去重，不是六个或更多等权子分，也不要求逐主题齐全。

全部独立链先合领域画像再合轴；每人最多展示七链、B最多四链，正负共占预算。未展示同链事实仍证持续、范围、反证与纠错，不作新增链；七条不截断证据。

处理顺序固定为：

1. 全池召回，不限每人条数；
2. 同因果链聚类，并保留重复次数、持续性、范围、后果和纠错状态；
3. A、B、C分别完成正负双向复核；
4. 在不知道最终分数的条件下，完成十领域画像和轴级正负合成；
5. 轴级档位冻结后，按公共责任、模式代表性、独立反馈、反证强度和证据质量选择最多七条代表链，用于解释已经形成的档位。

A/C有合格链各留一槽，无链不补；余槽按模式/负门解释力分配，不按名望、材料数或预期分。展示选择不反改已冻结档。

同链只设一个`primary_axis`；其他轴记`supporting_axes`及独立辅助命题，不拆重复计分。

## 10. 正负合成与硬负向门禁

每轴先分别判断正向模式、负向模式和纠错状态，再形成一个轴级档位。不得按正负材料条数相减，也不得以多数低强度正向抵消少数高强度反证。

方向强度相对情境中的合格统治者职责基线，不相对本人峰值；正常作背景，时代不免责。

峰值回落后仍高于基线，只降正强度或限制满档，不改负向；显著偏离须由持续、范围、责任、程序、替代、后果及反馈选择证明。

每条进入合成的行为链必须显式记录：`objective_baseline`、`baseline_deviation`（`POSITIVE`/`NEGATIVE`/`NEUTRAL`/`UNRESOLVED`）、`magnitude`、阶段变化、可行替代、持续性、范围、后果和纠错状态。相对自身的阶段变化只用于描述轨迹和限制档位，不能代替客观基线判断。

纵向归并后、七条选择前，同领域跨人物用同基线、方向及强度复核；归责、替代、持续、范围、后果和纠错解释不了的倒挂全退回，不冻结。名望、峰值、旧排名不作标准。

轴级合成依次回答：

1. 正向是否跨独立情境或阶段重复；
2. 负向是孤立失误、阶段性短板，还是稳定主模式；
3. 本人收到何种反馈，是否及时纠正、补救或复发；
4. 高责任、高压力场景是否推翻普通场景表现；
5. 是否触发以下上限门禁。

| 门禁 | 条件 | 轴级上限 |
|---|---|---:|
| `H1_MAJOR_UNCORRECTED` | 一次高责任重大反证，反馈明确且仍未纠正，但尚未成为跨场景主模式 | G3-HIGH |
| `H2_REPEATED_OR_SYSTEMIC` | 同类重大反证跨阶段复发，或形成系统性安排，且本人直接授权、维持或包庇 | G2-HIGH |
| `H3_DOMINANT_DESTRUCTIVE_PATTERN` | 严重失能、权力失控或强制侵害成为主要统治模式，且没有实质纠正 | G1-HIGH；符合G0定义时进入G0 |
| `H4_HISTORICAL_DESTRUCTIVE_PATTERN` | 同轴HISTORICAL纯负向成为跨阶段主模式，或多个独立STRONG纯负向共同达到跨时代罕见破坏性，且本人直接维持、反馈后继续、没有实质纠正 | G-1；完整生命周期为`MIXED_NEGATIVE`或归责不足时最高G0 |

负门逐轴适用，不跨轴抵扣；有效持续纠正可降反证层级，不删除既成严重行为。

### 10.1 混合生命周期

混合链不拆正负抵销，保留阶段基线、持续及反馈，再裁主导：

- `MIXED_POSITIVE`：负向阶段是局部或已被及时、有效、持续纠正，完整生命周期仍显著高于客观基线；
- `MIXED_NEGATIVE`：正向阶段只是局部缓解、迟来修复或未能阻止主要负向模式，完整生命周期仍显著低于客观基线；
- `MIXED_BALANCED`：正负阶段均有实质承载，现有证据不足以确定主导方向。

原始`MIXED`未判主导只给`PARTIAL_DIRECTIONAL_OBSERVATION`。纠正可降负强度/门禁，不抹既成伤害；阶段不按条数/幅度相减。

## 11. 档位与计分

三轴统一采用G-1至G5档和LOW/MID/HIGH。G-1不是“材料比G0更多”，而是历史级纯负向已经超过非负下限的专门尾部：

| 档位 | 共同含义 |
|---:|---|
| G-1 | 历史级纯负向构成跨阶段主导模式，反馈后仍持续，且没有足以改变主模式的纠正；只评价本轴本人行为，不读取国家结果规模。 |
| G0 | 反向行为构成稳定主模式，或关键基本能力严重缺失。 |
| G1 | 偶有正向行为，但不稳定、强依赖个案或被主要反证压倒。 |
| G2 | 明确低于合格基线：虽有局部能力或正向反证，但明显短板、阶段断裂或重大反证仍占较大权重。 |
| G3 | 合格基线至稳定正向。G3-LOW是经过完整正反复核的正常履职基线；MID、HIGH依次要求更稳定、更广或更强的正向模式。 |
| G4 | 跨阶段、跨压力情境持续表现优秀，并能处理重要反证。 |
| G5 | 达到历史高位，在强压力和多类情境下仍稳定，且没有主导性结构短板。 |

| 档位 | LOW | MID | HIGH |
|---:|---:|---:|---:|
| G-1 | -15% | -10% | -5% |
| G0 | 0% | 5% | 10% |
| G1 | 15% | 20% | 25% |
| G2 | 30% | 37% | 44% |
| G3 | 50% | 57% | 64% |
| G4 | 70% | 77% | 84% |
| G5 | 90% | 95% | 100% |

`分项得分 = 分项权重 × 得分率`，保留一位小数。

正式消费器按以下语义骨架合成，不作领域分值相加：

| 同轴主导画像 | 默认落点 | 调整条件 |
|---|---|---|
| HISTORICAL纯负向且构成跨阶段主模式 | G-1；完整生命周期为`MIXED_NEGATIVE`、存在实质纠正或本人归责不足时进入G0至G1 | 只由本人行为链的持续性、适用范围、反馈后继续和跨时代横向校准触发；国家崩溃、伤亡或结果规模不得反推 |
| STRONG纯负向 | G1；存在同等强正向阶段或跨领域实质反证时可到G2 | 重复、系统性、终局失能和未纠正向LOW移动；阶段受限或有效纠正向HIGH移动 |
| STRONG的`MIXED_NEGATIVE` | G2 | 正向阶段是真实但非主导反证；只有另有纯STRONG负向或触发H2/H3时才进入G1 |
| MEDIUM负向 | G2 | 与STRONG以上正向并存时按主导性进入G2-HIGH至G3-HIGH，不作算术抵销 |
| VERIFIED_NORMAL_BASELINE | G3-LOW | 必须完成主要阶段和正反复核；普通未命中不适用 |
| MEDIUM正向 | G3-MID至G3-HIGH | 跨阶段、范围和反证处理决定档内位置 |
| STRONG正向 | G4 | 有重大未纠正反证时应用H1/H2，而不是按弱负面条数降档 |
| HISTORICAL正向 | G5；缺少同轴独立支持时暂落G4-HIGH | 必须通过跨时代同领域校准，历史级不限单人 |

`MIXED_POSITIVE`按正向主模式处理，但相反阶段限制档内位置或触发门禁；`MIXED_NEGATIVE`按负向主模式处理，真实正向阶段使其与同强度纯负向拉开一档，但不能使其回到合格基线；`MIXED_BALANCED`通常落在G2-HIGH至G3-LOW，只有完成主导性裁决后才能离开该区间。LOW、MID、HIGH由持续性、压力、适用范围、反馈后选择和反证处理共同确定，不由观察领域数或材料条数机械决定。

单一情境且缺少反向复核时只形成`PARTIAL_DIRECTIONAL_OBSERVATION`，不因方向正负而直接落入低档。一个经过完整正反复核、覆盖主要阶段的领域画像可以独立承载轴级档位，不按其聚类后只剩一条记录而降格。`VERIFIED_NORMAL_BASELINE`固定进入G3-LOW；进入G4必须有STRONG以上代表性正向领域并通过跨阶段或跨压力复验；进入G5必须有HISTORICAL正向领域、同轴其他适用领域或独立情境支持，并通过跨时代锚点比较，且没有H1以上门禁。

覆盖主要任期、持续压力、反馈及反向复核的纵向链是独立准入路线；聚类后一条`behavior_chain_ref`不降为单次孤证。

合成顺序：最强正负与主导→重复持续压力范围反馈→负门。不等权加领域、不按条数相减，弱证不稀释强证；混合反面限制位置/上限。

三轴消费器必须显式实现以下高档路径，不能只在合同中保留档名：

| 轴 | G4最低可执行路径 | G5最低可执行路径 |
|---|---|---|
| A | 高强纵向正向履职或认知更新模式，另经独立压力或反证情境复验，主要阶段稳定且无H2以上门禁 | 在G4基础上通过跨时代同领域锚点，强压力与多类认知/履职情境仍处历史高位，且无H1以上门禁或关键功能短板 |
| B | 一个代表性领域达到STRONG，并以任务匹配、真实权限和可归责交付完成授权单元；另有适用领域正向支持或同领域跨阶段复验。后续反馈仅在实际发生时计入，不要求皇帝二次介入；领域缺失不得冒充领域弱项 | 至少一个领域达到HISTORICAL，另有两个适用领域达到STRONG或形成等价的跨阶段、跨权力类型历史高位组合；不得由单一人才、单一战役或单一制度结果支撑，且无H1以上门禁 |
| C | 至少两个独立克制或保护主题，其中包含跨阶段或高压力检验；重大反证已实质纠正或不占主导，且无H2以上门禁 | 在G4基础上通过跨时代同领域锚点，多类强制权力情境仍保持历史高位，且无H1以上门禁或主导性伦理短板 |

表为可执行下限，不按链数自动升档；消费者须有G4/G5路径，实证可无人命中。

表现、充分度、置信度分开；少料不直接判低。仅知方向/上限而主模式未定，输出`PARTIAL_DIRECTIONAL_OBSERVATION`或`UNRESOLVED_EVIDENCE_GAP`，不强给档。

G0须稳定本人反向模式或基本功能严重缺失；G-1另过`H4_HISTORICAL_DESTRUCTIVE_PATTERN`并同轴HISTORICAL/STRONG逐人校准，不因新增材料多自动降档。缺证不记0。

短任可凭完整窗口内多个关键节点、重复高责任同向选择及反馈后继续形成主模式；长任/料多不自动加重同性质行为。跨人物比较本人选择、可行替代和纠正，不搬国家损失或C1—C3档差。

三轴均可判才合总分；缺轴处理统一见§11.1。

### 11.1 缺材料轴的计分处理

证据状态与计分状态严格分离：

| 轴级状态 | 允许输出 | 计分处理 |
|---|---|---|
| `GRADE_CANDIDATE` | 轴级档位、档内位置、证据充分度和置信度 | 通过正式门禁后换算轴分 |
| `VERIFIED_NORMAL_BASELINE` | G3-LOW、三层检索轨迹、基线复核范围和证据充分度 | 视为可判档结论；通过正式门禁后换算正式轴分 |
| `PARTIAL_DIRECTIONAL_OBSERVATION` | 已观察方向、当前上限、缺少的反向复核或独立情境 | `axis_score=null` |
| `UNRESOLVED_EVIDENCE_GAP` | 已完成的检索范围和仍缺材料类型 | `axis_score=null` |
| `EXEMPT_NO_BACKFILL` | 无实权、傀儡或实权极短的依据 | 不生成轴分和总分，不参加排名 |

缺轴不得插补：

- 记零、记中档或记基础分；
- 按已有轴重标为120分；
- 用同朝代、同类型统治者、人物名望或前四项得分插补；
- 用材料数量、传记篇幅或未发现负面推定正常表现。

三轴均为`GRADE_CANDIDATE`/`VERIFIED_NORMAL_BASELINE`且各自冻结才可总分排名；否则公开已判轴和缺口，总分为`null`、资格为`INELIGIBLE_EVIDENCE_GAP`。豁免另列。

### 11.2 分轴名望画像反差门

名望只查分轴异常，不作事实、先验或泛明昏君比较。

每轮轴级冻结前，使用正负对称、跨时代的分轴锚点检查全部已判档人物，并将结果归入：

- `ALIGNED`：方向和强度大体一致；
- `EXPLAINED_AXIS_SCOPE`：表面反差可以由本轴边界、跨项去重或混合生命周期解释；
- `MATERIAL_GAP`：画像提示可能漏链，但当前材料不足，不直接改档；
- `DIRECTION_CONTRAST`：已判方向与分轴画像明显相反；
- `UNRESOLVED_STRENGTH_TENSION`：方向一致但强弱显著反常，且不能由归责、替代、持续性、范围、后果或纠错解释。

`DIRECTION_CONTRAST`/`UNRESOLVED_STRENGTH_TENSION`退回材料、聚类、强度、映射四层，解决前不冻结；`MATERIAL_GAP`留部分观察，不直接降档、补事实或转中性。

### 11.3 档位分布健康门

分布只检量尺可达、方向对称及证据偏差，不设钟形、配额或美观调分。

正式冻结前至少通过：

1. **结构可达性**：A、B、C的G-1—G5及LOW/MID/HIGH均存在明确、可执行的证据组合路径；不得出现合同有档、消费器无路径；
2. **单调性**：同领域中持续性、压力、范围、后果和纠错更强的正向模式不得反而更低，重复或系统性负向不得反而更高；
3. **正负对称**：相同证据充分度下，正向与负向形成档位的准入门槛对称；不得把单个负向直接落档而把同强度正向长期留在部分观察；
4. **高低锚点实现**：已闭合的强正向、强负向跨时代锚点应能实际进入相应高低尾部；若已知强锚点仍全部挤在G1/G2，视为映射压缩而非历史分布结论；
5. **覆盖敏感性**：剔除低置信、单领域或材料特别密集群体后，分布形状不得发生无法由史实解释的剧烈变化；
6. **跨项形状复核**：可与前四项相关子项比较量尺形状，只作异常提示，不作能力等值换算或分位数对齐。

结构不可达、三轴异常挤低或高尾仅偶然出现，须修准入/聚合/映射并复核，不用配额或降低历史标准修形。
