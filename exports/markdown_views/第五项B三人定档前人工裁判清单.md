# 第五项B三人定档前人工裁判清单

本文件是第五项B三人试点进入定档前的人工裁判清单。它不提供分数、排名或总榜，只列出定档前必须人工确认的问题、通过条件和阻断条件。

## 一、通用裁判门槛

### A. 正向高位门槛

进入高位候选前必须同时满足：

1. 正向证据覆盖不止一个单点人物或单一事件。
2. 证据直接指向识人、用人、授权、反馈入口或人才生态。
3. 已剥离战功、政绩、边疆收益、政策效果、治世光环。
4. 至少完成一轮反向检索。
5. 负向证据没有直接推翻人才生态的核心安全感。

### B. 极正门槛

极正只能由证据组层面人工确认，不能由单张证据卡、总体历史地位或治世光环推出。必须满足：

1. 多类型覆盖：识人、授权、容谏、异质人才整合、长期人才生态至少覆盖多项。
2. 横向代表性强：核心人才类型包括文臣、武将、谏臣、旧敌或后进人才中的多类。
3. 负证拦截通过：没有系统性功臣/谏臣安全破坏硬证。
4. 相邻项剥离后仍保留极强证据剩余。

### C. 强负门槛

强负候选必须确认：

1. 是否直接损害人才安全感、表达安全、容谏入口或授权生态。
2. 是否只是政权安全、司法残酷、政治残酷性或行政威慑。
3. 若相邻项高度重叠，必须先剥离后再判断第五项B剩余强度。
4. 单卡强负可以进入强负候选组，但最终权重要经过人工裁判。

## 二、人物人工裁判清单

### 1. 李世民

当前净裁量草案：高位强正，保留极正上探资格。

必须人工确认：

- 房杜、魏征、李靖、马周、李勣等材料是否足以构成多类型人才生态，而非单纯名臣堆叠。
- 马周线是否真正增加寒门/后进通道新维度。
- 李勣线是否确实可计为功臣安全与长期授权秩序，而非继承安排或政治权术。
- 张亮、侯君集、魏征身后材料是否存在更强的系统性人才安全破坏含义。
- 魏征复碑与身后追责是否足以把负向限制在弱负剩余。

通过条件：

- 极正上探需确认正向多维度证据组成立，且负证不足以破坏核心人才生态。
- 若对李勣线归项存疑，则仍可保留强正，但极正上探应更谨慎。

阻断条件：

- 若发现系统性功臣/谏臣恐惧、清洗或表达寒蝉硬证，不能进入极正。

### 2. 刘秀

当前净裁量草案：强正基础上受强负明显压制。

必须人工确认：

- 邓禹、冯异、吴汉、寇恂、耿弇是否主要集中于创业期军事/军政授权，是否缺少长期中枢治理型人才生态。
- 韩歆、桓谭、尚书近臣捶扑牵曳三线是否足以构成表达安全的结构性强负。
- 桓谭案中谶纬认知因素切第五项E后，B项仍保留多少人才表达安全损害。
- 申屠刚材料中行政威慑和政治残酷性剥离后，B项仍保留多少群臣莫敢正言的影响。
- 韩歆案中灾异/政策判断因素切走后，B项仍保留多少容谏安全损害。

通过条件：

- 若长期中枢与文臣治理型人才补证较强，刘秀可保持强正受压制的净方向。
- 若负向三线经剥离后仍高度直接，净裁量不得简单给高位。

阻断条件：

- 若后续证实更广泛、长期的表达寒蝉或人才生态损害，不得上探高位强正。

### 3. 刘庄

当前净裁量草案：中正正证不足以抵消强负候选，最终幅度取决于楚狱负证剥离后的剩余权重。

必须人工确认：

- 邓禹、刘苍辅政结构是否属于刘庄主动识人用人，还是更多是即位初期政治安排。
- 日食后极言无讳是否构成真实反馈入口，还是偏常规灾异求言诏。
- 班超线中刘庄本人的直接归属是否足够，还是主要为窦固识别与前线推荐。
- 楚狱材料在切走政权安全、司法残酷、政治残酷性后，B项还剩多少人才安全感损害。
- 廷杖/尚书郎线若仍未可靠回源，不得作为硬负证参与定档。

通过条件：

- 若楚狱剥离后仍对人才安全感构成强影响，刘庄 I5B 净裁量应明显受压。
- 若发现更直接的刘庄用人正证，可提升正向厚度，但不能用西域成果反推授权强度。

阻断条件：

- 未可靠回源的廷杖材料不得入证据组、不得入定档。
- 班超后续西域成果不得回填为刘庄识人极强。
