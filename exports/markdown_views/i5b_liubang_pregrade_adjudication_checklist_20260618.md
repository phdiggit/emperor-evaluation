## 二、人工裁判核心问题

### 问题 1：强正能力底盘是否成立？

依据：

- 三杰材料证明多类型人才识别与分工；
- 张良材料证明反馈入口和采纳建议；
- 陈平材料证明异质人才整合和抗群议授权；
- 韩信齐王线证明在压力下接受谋臣修正并给予高自主权；
- 陈平补查材料证明异质人才整合具有一定持续性。

- 三杰材料带结果论污染；
- 韩信齐王授权带被动妥协；
- 陈平持续任用不能覆盖功臣安全和表达安全缺口。

```text

```

### 问题 2：强负安全生态拦截是否成立？

待裁判答案：倾向成立。

依据：

- 韩信、彭越、英布链条证明高功臣安全感与同功群体恐惧；
- 英布“同功一体，自疑祸及身”是强负外溢核心；
- 萧何补查证明非异姓王最高功臣也存在疑忌和安全压力；
- 樊哙补查证明近臣功臣晚年亦存在安全压力。

限制：

- 韩信、彭越均有政权安全或强嫌疑背景；
- 萧何被赦出，存在纠偏；
- 樊哙材料有陈平、周勃缓冲，且后续恢复爵邑；
- 一般列侯/普通功臣群体仍未横向复核。

人工裁判项：

```text
强负安全生态拦截：可成立 / 仅中负 / 需再补证
```

### 问题 3：负证是否足以阻断极高档？

待裁判答案：倾向足以阻断极高档。

理由：

- 正向证据强，但并不干净到能压过后期安全生态问题；
- 负向不是单一安全案件，而有同功群体恐惧外溢；
- 补查后负证范围扩展到萧何、樊哙，说明不完全局限于异姓王。

限制：

- 负向还不足以直接推到极负；
- 正向也不能因负向存在而被抹平。

人工裁判项：

```text
极高档阻断：阻断 / 不阻断 / 待一般功臣横向复核
```

### 问题 4：正负关系是抵消，还是分维度共存？

待裁判答案：分维度共存，不作简单抵消。

理由：

- 正向主要证明识人、授权、反馈、异质人才整合；
- 负向主要证明功臣安全感、授权预期和人才生态压力；
- 二者不是同一维度的相反证据，不能机械加减。

人工裁判项：

```text
正负关系：分维度共存 / 可部分抵消 / 需重组证据组
```

### 问题 5：萧何、樊哙补查对负证强度的影响是什么？

待裁判答案：扩大负证适用范围，但不单独抬到极负。

理由：

- 萧何是非异姓王最高功臣，存在疑忌、自污和廷尉处置；
- 樊哙是近臣功臣，晚年出现强制性处置风险；
- 二者说明安全压力不限于异姓王集团。

限制：

- 萧何最终被赦出；
- 樊哙被陈平、周勃缓冲，后续恢复爵邑；
- 二者都是中负，不是强负核心。

人工裁判项：

```text
补查影响：扩大负证范围 / 仅作弱补充 / 需继续补一般功臣
```

### 问题 6：陈平持续任用对正向稳定性的影响是什么？

待裁判答案：中正补强。

理由：

- 陈平不是单次受任；
- 后续封赏、改封、继续参与关键事务，说明异质人才整合有延续；
- 能削弱“刘邦只是一时用陈平”的疑虑。

限制：

- 陈平材料与战事和计策结果纠缠，需剥离；
- 它不能直接证明广泛表达安全或功臣安全。

人工裁判项：

```text
陈平补强：中正补强 / 弱正补强 / 不计入
```
