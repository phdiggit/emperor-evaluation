# 全局总标尺执行简报

状态：V3.2 上位标尺已确认 / G9 已批准第五项B正式分值与子项排名发布

## 一、上位标准

1. 最终得分采用 `正收益总分 - 历史负债`。
2. 正收益总盘为 1500 分。
3. 历史负债为第七项，按 0—300 扣分处理。
4. 七大项及权重已经由 V3.2 driver 定义。
5. 第五项B《用人与授权》的正式上限为 45 分。

## 二、当前仍未完成的不是“总标尺”

V3.2 已定义正式目标标尺；G9 已批准第五项B人物级正式分值与子项排名发布，其他发布范围仍需各自满足执行门槛：

1. 各子项证据、锚点、负证拦截和相邻项剥离完整性。
2. V3.2 正式档位到子项绝对分的映射规则。
3. 压制、封顶、负证拦截的分值规则。
4. 规则与算法版本审查、回归验证和正式发布门槛。

## 三、方案 C 的当前含义

方案 C 只作为实施和发布门槛，而不再表示总分结构未知。

在证据、锚点、子项档位映射、规则与算法版本审查、回归验证和正式发布门槛完成前，非授权范围仍只保留相对档位和内部诊断指数；本阶段只发布第五项B正式分值和子项排名，不发布阶段总榜或总榜。

## 四、第五项B

1. 第五项B正式上限 45 分已经明确。
2. G8 正式算法已释放，第五项B可以确定 V3.2 九档、45 分档内区间和确定性候选值。
3. G9 已批准，第五项B可以发布人物级正式分值和子项排名。
4. 旧内部100制相对试算指数不得直接换算为 45 分正式分值。

## 五、结论

1. V3.2 的 1500 正收益总盘、0—300 历史负债和第五项B 45 分上限已经确认。
2. 本阶段发布第五项B正式分值和子项排名，但继续禁止阶段总榜和总榜。
3. 方案 C 是发布门槛和实施顺序，不是总标尺缺失结论。
4. 第五项B正式算法版本已释放；G9 publication PR 只打开第五项B人物级正式值和子项排名。
