# 第五项B自动结算规则敏感点清单

本文件只列抽象规则问题和默认处理方式，不审人物个案、不计分、不排名。

## 规则敏感点

### RULE-I5B-BOUNDARY-WEAK-TO-MEDIUM

- **规则问题**：弱负上调为中负的边界负证是否阻断极正或高位上探？
- **默认处理**：不阻断；只降低置信度，不进入强负核心。
- **治理意义**：避免把带 mitigation_flag / upper_bound_flag 的轻边界直接抬成拦截项。

### RULE-I5B-BOUNDARY-MEDIUM-TO-STRONG

- **规则问题**：中负上调为强负的边界负证是否阻断极正或高位上探？
- **默认处理**：阻断；进入强负核心或强负拦截候选，但仍不得机械扩大到极负。
- **治理意义**：把真正破坏表达安全、人才安全或授权可信度的负证与普通边界负证分开。

### RULE-I5B-SINGLE-DIMENSION-STRONG-POS-THREE-CORE

- **规则问题**：单一维度强正是否可以上探极正？
- **默认处理**：默认强正封顶；但同一维度内若至少存在三个强正核心、均为第五项B直接证据，且覆盖识人任用、授权专任、人才生态三类核心，才允许上探极正候选。
- **治理意义**：把“单维同类证据堆叠封顶”与“单维但覆盖三核心的极正候选”区分开。

### RULE-I5B-ADJACENT-STRONG-NEG-RESIDUAL-DETAIL

- **规则问题**：相邻项强负剥离后，第五项B剩余如何执行？
- **默认处理**：大案本身严重不等于第五项B强负；若剥离后仅剩人才安全/表达安全的轻微外溢，则默认中负剩余；若出现群臣莫敢正言、明显寒蝉、人才退缩或授权可信度破坏等硬证，才保留强负核心。
- **治理意义**：把政权安全、司法残酷、行政威慑与B项剩余影响分开。

### RULE-I5B-STRONG-NEG-CORE-SUPPRESSES-STRONG-POS

- **规则问题**：强正底盘已经成立时，强负核心如何影响上探？
- **默认处理**：保留强正基础，但自动标记为强正受压制，不上探极正；若强负核心呈结构性寒蝉，可进一步压低到中正受强负压制。
- **治理意义**：防止强正掩盖对表达安全和人才安全的硬伤。

## 规则使用方式

1. 先看规则问题是否被当前 cluster 命中。
2. 弱负升中负的边界只降置信度，不阻断极正/高位上探，也不进入强负核心。
3. 中负升强负的边界阻断极正/高位上探，只在有明确突破中负封顶的硬证时进入强负核心。
4. 若规则仍无法抽象化，才把问题后移到规则层审核。
