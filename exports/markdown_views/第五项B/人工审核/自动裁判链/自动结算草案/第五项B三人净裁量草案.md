# 第五项B三人净裁量草案

本文件为第五项B三人试点的净裁量草案。它不是最终评分表，不给分、不排名、不进入总榜；仅用于在证据组层面完成正负抵消、相邻项剥离和后续定档前判断。

## 一、净裁量方法

1. 先比较正负证据组的候选强度，但不得机械相减。
2. 先剥离相邻项：战果、边疆收益、政策效果、政权安全、司法残酷、治世光环均不得回填第五项B。
3. 再看剩余证据是否直接指向识人、用人、授权、反馈入口、人才安全感和人才生态。
4. 只形成净裁量方向，不形成档位、得分或排名。

## 三、人物分案说明

### 李世民

李世民正向证据组已经覆盖幕府聚才、旧敌转用、关键军事授权、容谏反馈、寒门/后进通道、功臣安全秩序等多维度。负向证据组中，张亮案有强安全风险但存在追悔减轻，侯君集案有确认谋反链条，魏征身后追责未外溢且有复碑反转。剥离政权安全、司法严酷和战功因素后，负向剩余不足以推翻其 I5B 高位候选。

净裁量草案：李世民为高位强正，保留极正上探资格；最终是否极正，需要人工确认极正门槛是否由证据组而非历史光环支撑。

### 刘秀

刘秀正向证据组集中在创业期关键人才识别与授权，包括邓禹、冯异、吴汉、寇恂、耿弇等。该组能支撑强正候选。但负向证据组直接命中容谏安全与表达生态：韩歆直言不容并父子自杀、桓谭反谶几至下斩、尚书近臣捶扑牵曳与群臣莫敢正言。这些不是外围负证，而是直接打在第五项B的反馈入口和人才安全感上。

净裁量草案：刘秀不能简单定为强正，也不能因负证直接压成负向；更合理的是强正基础上受强负明显压制。后续需要补长期中枢与文臣治理线，判断正向是否有足够广度抵消负向表达生态损害。

### 刘庄

刘庄正向证据包括邓禹与刘苍辅政结构、日食求言无讳、班超授权线。三条均为中正，显示其不是没有用人和反馈入口材料。但正向厚度和直接帝王归属都不够强。负向楚狱材料力度大，坐死徙者以千数，对宗室、臣僚和潜在人才安全感有明显负面；但该材料与政权安全、司法残酷和政治残酷性高度相邻，不能全部压入第五项B。

净裁量草案：刘庄当前净方向偏负面压制，中正正证不足以抵消楚狱负证的剩余影响；但最终负向幅度取决于相邻项剥离后仍保留多少人才生态损害。

## 四、后续裁判清单

1. 李世民：确认极正门槛是否满足；重点不是继续补正证，而是确认无系统性强反证。
2. 刘秀：补长期中枢用人、文臣治理型人才、功臣安全机制；并复查表达寒蝉是否有长期系统性。
3. 刘庄：继续回源廷杖/尚书郎线；补查直接帝王归属更强的用人正证；人工判定楚狱负证在B项的剩余权重。

## 五、不得越界事项

1. 不得由本草案推出分数、排名或总榜。
2. 不得把战役胜负、边疆收益、政策效果、治世光环回填第五项B。
3. 不得把政权安全、司法严酷、政治残酷性完整压入第五项B；只能保留对人才安全感和表达生态的剩余影响。
4. 不得把候选强度机械相减为最终结论。
