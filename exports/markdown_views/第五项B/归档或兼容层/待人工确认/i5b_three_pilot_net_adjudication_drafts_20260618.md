## 一、共同裁量口径

第五项B净裁量必须分清三类问题：

1. **能力底盘**：是否能识人、授权、纳谏、吸纳异质人才、组织人才结构。
2. **安全生态**：能臣、谏臣、功臣、近臣是否具有稳定表达与安全预期。
3. **相邻项剥离后剩余影响**：战果、政策效果、政权安全、司法残酷、皇帝认知等切出后，B项还剩多少。

强正与强负并存时，不得机械抵消。若正向证明能力，负向证明安全生态，则应分维度共存，并触发人工裁判。

## 二、李世民净裁量草案

### 1. 已成立的正向结构

李世民正向证据组为强正候选，覆盖：

- 幕府聚才与多类型人才结构；
- 旧敌阵营人才转用；
- 顶级谏臣反馈入口；
- 顶级将帅授权专任；
- 寒门/后进人才通道；
- 功臣安全与长期授权秩序。

对象锚点上，房杜、魏征、李靖、李勣、马周均能提高正向证据权重，但各自战功、政绩、政策纠错和盛世光环必须切出。

### 2. 已成立的负向/限制结构

李世民负向证据组为中负候选，覆盖：

- 张亮案中的功臣处置争议；
- 侯君集案中的确认安全风险下弱负；
- 魏征身后信用反转。

对象锚点上，魏征是顶级谏臣，因此身后信用反转需要被单列；但魏征生前长期受重用、身后有复碑反转，负向强度受限。张亮、侯君集均高度相邻第五项C/D，不宜抬高为强负核心。

### 3. 净裁量方向

```text
强正人才生态与授权底盘成立；
中负人才安全/信任风险存在；
负证暂不足以形成强负高档位拦截；
魏征线需保留同一顶级谏臣正负反转的证据组备注，但单证层已自动定为中负封顶。
```

### 4. 仍需人工裁判

1. 魏征生前强正与身后中负封顶是否应明确写成“同一对象反转但减轻”？

3. 李世民负向组是否确认不足以触发强负拦截？
4. 正向组是否可在对象锚点加权后维持强正，但不得直接上探极正？

## 三、刘秀净裁量草案

### 1. 已成立的正向结构

刘秀正向证据组为强正候选，覆盖：

- 邓禹早期持节分兵与自选偏裨；
- 冯异进言被采纳；

- 寇恂与冯异跨区域协同授权；

对象锚点上，邓禹、冯异、吴汉、寇恂、耿弇都是高价值创业期军政人才，能支撑刘秀识人、授权、纳言和文武协同能力。

### 2. 已成立的负向结构

刘秀负向证据组为强负候选，覆盖：

- 韩歆直言不容与谏臣保护失败；
- 桓谭反谶受压；
- 申屠刚线中近臣受辱与群臣表达安全受损。

对象锚点上，韩歆、桓谭分别对应直言型人才和思想/谏诤型人才，申屠刚线则是表达安全机制对象。负证不是单一人物个案，而涉及表达生态和谏臣保护。

### 3. 净裁量方向

```text
强正创业期人才授权底盘成立；
强负表达安全与谏臣保护拦截成立；
二者不同维度，不得机械抵消；
是否阻断高档位上探，必须人工裁判。
```

### 4. 仍需人工裁判

1. 正向是否过度集中于创业期军政授权，缺少长期中枢/文臣治理对象？
2. 负向表达安全问题是否足以构成高档位强拦截？
3. 韩歆、桓谭、申屠刚线是否形成结构性表达寒蝉，而非三条孤证？
4. 负向是否有上探极负风险，还是保持强负候选即可？
5. 若强负拦截成立，是否仍保留刘秀强正能力底盘，而非机械压低？
