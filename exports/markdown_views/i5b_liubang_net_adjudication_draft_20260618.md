项目：第五项B《用人与授权》

> 本草案基于已合并的刘邦 source/evidence/cluster 批次、《刘邦净证据池与裁量复核视图》以及第一批补查证据整理。它只给出定档前的净裁量方向，不生成正式档位、不计分、不排名。

## 一、净裁量总判断（非定档）

刘邦第五项B当前呈现为：

```text
强正能力底盘 + 强负安全生态拦截；补查后确认安全压力不限于异姓王集团
```

正向方面，刘邦确有较强的识人、用人、授权、纳谏与异质人才整合能力。证据不止停留在“三杰”一条结果论材料，还包括张良反复进策并被采纳、陈平跨阵营来降后在群议中获护军中尉授权、韩信齐王线中的高自主权授权。补查后，陈平后续持续封赏、改封和继续任用，也对“异质人才整合具有一定延续性”形成中正补强。

负向方面，韩信、彭越、英布链条构成功臣安全感与同功群体寒蝉效应的强负候选。单看韩信、彭越，均有政权安全或强嫌疑背景，不能机械定为纯粹无端疑忌；但英布“同功一体，自疑祸及身”直接呈现同功群体恐惧外溢，使负向证据具有第五项B内部的结构性意义。补查后，萧何疑忌/自污/廷尉处置与樊哙晚年近臣安全压力进一步显示：安全生态问题并非完全局限于异姓王集团。

因此，本项暂不宜简单归纳为“刘邦会用人所以高位”，也不宜简单归纳为“功臣安全负证所以低位”。当前更合理的裁量框架是：

- 创业/争夺阶段，用人与授权能力强；
- 异质人才整合和持续任用有一定正向延续；
- 后期高功臣、最高功臣与近臣安全感均出现不同程度压力；
- 正向能力底盘可以成立，但高档位上探必须被负证组拦截；
- 三杰正证不得直接抵消同功群体恐惧外溢与非异姓王补查负证。

## 二、正向证据组裁量

### 1. 可确认的正向维度

刘邦正向组至少覆盖五个第五项B核心维度：

1. **识人分工**：张良、萧何、韩信三类核心人才分工明确，并由刘邦以“吾能用之”自归其功。
2. **反馈入口**：张良多次进策，刘邦善之、常用其策；霸上场景中，张良、樊哙劝谏能改变刘邦行动。
3. **异质人才整合**：陈平自楚来降且受诸将讥毁，刘邦问明后仍谢而厚赐，并授护军中尉。
4. **授权专任**：韩信齐王线显示刘邦在压力下接受张良修正，对关键军事人才给予高自主权托付。
5. **持续任用补强**：陈平后续封户牖侯、改封曲逆侯，并继续以护军中尉参与关键事务，说明异质人才整合并非完全一次性。

### 2. 正向组强度

当前可维持为：

```text
强正候选
```

理由：正向组跨越识人、授权、纳谏、异质人才整合和一定持续任用，不是单点亮点，也不是纯粹事后美化。

但暂不宜上探极正，原因包括：

- 三杰材料带有明显结果论污染风险；
- 韩信齐王授权有初怒、被动妥协、政治风险控制背景；
- 已有后期信任反转强负组，说明“授权秩序的稳定性”存在重大缺口；
- 陈平持续任用虽能补强异质人才整合，但不能覆盖功臣安全与表达安全缺口；
- 张良退隐/晚年谏争材料仍处于 source_review_pending，尚未形成干净强正证据卡。

## 三、负向证据组裁量

### 1. 可确认的负向维度

刘邦负向组至少覆盖五个第五项B核心负向维度：

1. **高功臣安全感受损**：韩信、彭越链条显示核心授权对象后期安全预期受损。
2. **授权预期反转**：前期核心授权对象，后期出现控制、降封、追责等反向信号。
3. **同功群体寒蝉外溢**：英布线直接呈现“同功一体，自疑祸及身”的群体恐惧。
4. **非异姓王最高功臣安全压力**：萧何线显示疑忌、自污与廷尉处置，说明安全压力不完全局限于异姓王。
5. **近臣功臣安全压力**：樊哙线显示晚年在负面报告触发下出现近臣强制性处置风险，虽被陈平、周勃缓冲。

### 2. 负向组强度

当前可维持为：

```text
强负候选；但不直接上探极负
```

理由：负向组的关键不是处置数量，而是英布线直接证明了处置外溢到同功群体恐惧；萧何、樊哙补查进一步说明非异姓王功臣与近臣也存在安全压力。

但暂不宜直接上探极负，原因包括：

- 韩信案有陈豨案与政权安全背景；
- 彭越案有征兵不至、有司认为反形已具等安全风险背景；
- 英布本人后续确有叛乱，军事威胁和异姓王控制应切第五项C；
- 萧何被赦出，且王卫尉进言形成一定纠偏；
- 樊哙案最终由陈平、周勃缓冲，且后续赦复爵邑；
- 当前仍缺一般列侯/普通功臣群体的横向安全生态复核。

## 五、当前仍未解决的定档前问题

第一批补查已解决的问题：

1. **负证是否完全局限于异姓王集团？**  
   初步答案：否。萧何、樊哙材料显示，非异姓王最高功臣和近臣也存在安全压力。

2. **陈平是否只是单点授权？**  
   初步答案：否。后续封赏、改封和继续护军中尉任用，说明异质人才整合有一定延续。

仍未解决的问题：

1. 张良线材料混合：既有安全退隐，也有太子争议、储位政治和“轻士善骂”评价，暂未形成干净证据卡。
2. 晚年容谏/拒谏材料仍不足，尚不能判断早期反馈入口是否稳定延续。
3. 一般列侯/普通功臣群体安全生态尚未横向复核。
4. 三杰材料的结果论污染仍需在正式定档时降权处理。
5. 萧何、樊哙补查证据均为中负，能扩展负证范围，但不能单独把负向组推到极负。
