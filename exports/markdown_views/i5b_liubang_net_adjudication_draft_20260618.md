## 一、净裁量总判断（非定档）

刘邦第五项B当前呈现为：

```text
强正能力底盘 + 强负安全生态拦截
```

正向方面，刘邦确有较强的识人、用人、授权、纳谏与异质人才整合能力。证据不止停留在“三杰”一条结果论材料，还包括张良反复进策并被采纳、陈平跨阵营来降后在群议中获护军中尉授权、韩信齐王线中的高自主权授权。

负向方面，韩信、彭越、英布链条构成功臣安全感与同功群体寒蝉效应的强负候选。单看韩信、彭越，均有政权安全或谋反嫌疑背景，不能机械定为无端杀功臣；但英布“同功一体，自疑祸及身”直接呈现同功群体恐惧外溢，使负向证据具有第五项B内部的结构性意义。

因此，本项暂不宜简单归纳为“刘邦会用人所以高位”，也不宜简单归纳为“杀功臣所以低位”。当前更合理的裁量框架是：

- 创业/争夺阶段，用人与授权能力强；
- 后期高功臣安全感与授权预期明显受损；
- 正向能力底盘可以成立，但高档位上探必须被负证组拦截；
- 三杰正证不得直接抵消同功群体恐惧外溢。

## 二、正向证据组裁量

### 1. 可确认的正向维度

刘邦正向组至少覆盖四个第五项B核心维度：

1. **识人分工**：张良、萧何、韩信三类核心人才分工明确，并由刘邦以“吾能用之”自归其功。
2. **反馈入口**：张良多次进策，刘邦善之、常用其策；霸上场景中，张良、樊哙劝谏能改变刘邦行动。
3. **异质人才整合**：陈平自楚来降且受诸将讥毁，刘邦问明后仍谢而厚赐，并授护军中尉。
4. **授权专任**：韩信齐王线显示刘邦在压力下接受张良修正，对关键军事人才给予高自主权托付。

### 2. 正向组强度

当前可维持为：

```text
强正候选
```

理由：正向组跨越识人、授权、纳谏、异质人才整合，不是单点亮点，也不是纯粹事后美化。

但暂不宜上探极正，原因包括：

- 三杰材料带有明显结果论污染风险；
- 韩信齐王授权有初怒、被动妥协、政治风险控制背景；
- 已有后期信任反转强负组，说明“授权秩序的稳定性”存在重大缺口；
- 尚缺更干净的长期表达安全、功臣安全正向材料。

## 三、负向证据组裁量

### 1. 可确认的负向维度

刘邦负向组至少覆盖三个第五项B核心负向维度：

1. **高功臣安全感受损**：韩信云梦被缚、降封并最终被诛；彭越先赦后复被族灭。
2. **授权预期反转**：前期核心授权对象，后期出现被控制、降封、诛杀等反向信号。
3. **同功群体寒蝉外溢**：英布见彭越醢而大恐，薛公以“同功一体，自疑祸及身”解释其反。

### 2. 负向组强度

当前可维持为：

```text
强负候选
```

理由：负向组的关键不是杀功臣条数，而是英布线直接证明了处置外溢到同功群体恐惧，命中第五项B的人才安全感和功臣生态。

但暂不宜直接上探极负，原因包括：

- 韩信案有陈豨案与谋反事实背景；
- 彭越案有征兵不至、有司认为反形已具等安全风险背景；
- 英布本人后续确实反叛，军事威胁和异姓王控制应切第五项C；
- 目前负向证据主要集中在异姓王/高功臣集团，尚需复核是否扩展到一般功臣、谋臣、谏臣群体。

## 五、当前定档前阻断点

本草案仍不应进入正式定档，原因是存在以下阻断点：

1. 负向强证主要集中于异姓王集团，需要判断其能否代表更广泛的人才生态。
2. 需要补查非异姓王功臣、谋臣、谏臣的后期安全感与表达安全。
3. 需要复核萧何、张良、陈平、樊哙等核心人物的后期处境，判断“强负外溢”是否被局部限制。
4. 需要补查刘邦晚年容谏/拒谏材料，判断反馈入口是否随时间恶化。
5. 需要确认三杰材料的结果论污染是否足以降低正向组强度。
