## 一、审计依据

本轮按最新方法论检查以下要求：

1. 项目/子项启动时应有最小对象锚点池。
2. 对象锚点只作证据权重标签，不作为对象本身评分。
3. 强正与强负并存时，不得机械抵消。
4. 能力正证与安全生态负证通常应分维度共存。
5. 同一对象正负反转、对象层级影响强度、负证高档位拦截应先完成单证自动定级；只有证据组结算或高档位拦截仍有争议时才进入人工裁判。
6. 旧数据若能追溯 source / evidence / cluster，不应推倒重跑；优先做兼容性标注和审计视图。
