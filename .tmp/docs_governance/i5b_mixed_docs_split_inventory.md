## 人工审核栏位判定

旧文档中的人工栏位拆分为两类：

- 可保留：史料回源、上下文充分性、数据质量核验、相邻项剥离、规则/算法版本审查、发布门槛。
- 不保留为当前语义：人物级人工最终档位、人物级人工最终分数、手工覆盖自动结算、单人特判、person-specific override。
