# Post-G10-S1 Retired Platform Scripts

This directory is the documented retired location for large Post-G10-S1 platform script assets moved by Issue #346.

The files here are retained for audit and restore only. They are not default validation routes, not public CLI entrypoints, and not active execution paths. `scripts/platform/__init__.py` keeps them importable for historical tests while the scripts registry records their retired lifecycle state.
