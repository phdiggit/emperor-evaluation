# 综合阅读层：帝王三镜

将净收益、九轴人物画像、历史影响组织为“结果—能力—后效”的并列阅读体验。入口是人物，总览用于发现，人物页承载结论，对照页帮助理解差异，展开依据完成追溯。页面不新增评分或综合排名。

## 信息结构

| 层级 | 读者问题 | 展示与交互 |
| --- | --- | --- |
| 人物总览 | 想看谁？有哪些不同？ | 姓名与权力窗口、净收益分数及既有名次、八轴能力与C5权力风格的中文名称及字母等级、历史影响公众档与性质；姓名/帝号搜索，朝代、样本范围、影响档位筛选 |
| 人物阅读 | 这个人留下什么、如何做事、改变什么？ | 三块简明概览：净收益构成、九轴画像、历史影响总档与四维；下方按主题展开完整依据 |
| 并列对照 | 两人的不同落在哪里？ | 两人按相同维度对齐；展示净收益构成、九轴各自档位、影响四维、主链及个人因果边界；进入各自依据 |
| 展开依据 | 为什么这样评价？ | 定档依据、反例、材料限制、影响主链、最近可行反事实、共享归责、来源与核对范围 |

默认按历史顺序浏览；可切换净收益分数或历史影响总档排序。能力不设排序入口。影响同档按稳定ID排版，不生成档内名次。原有净收益名次始终保留其完整入榜池口径，筛选不重新排名。

人物页先展示三套简明概览，八个能力轴和C5权力运用风格同在画像卡内；完整依据移到下方宽版章节，按需展开。八轴固定读取配置中的能力轴顺序；对照按八轴能力、C5独立画像分组，各组内部沿配置顺序。雷达只是档位投影辅助图，不能按面积、均值或比例评价整体能力；有空值不补零、不连接完整多边形。

视觉采用浅纸色、墨色正文、绿色收益、金色能力、朱砂影响；颜色区分体系，不表示人格褒贬。桌面三栏，窄屏依次堆叠；对照表保留横向滚动。正文优先，首版不依赖肖像或AI人物卡；既有人物卡制作SOP继续适用于其自身产物。

## 数据与解释边界

- 从`config/project.yml`取得正式入口，复用仓库朝代分片加载器，以`ruler_id`连接；构建只读裁决，不重算档位。主池和入榜人数动态读取规范池与实际记录，不使用配置中的人数摘要作展示常量。
- 净收益只消费正式总榜及其分项构成；第一项原分与折算附加F分开，人物画像与历史影响不进入总分。未入榜保留就绪状态，不补零。第一项不适用不表示能力失败。
- 八轴逐轴保留档位、位置、投影、发布模式、置信度、依据与限制。C5作为独立行为风格轴与八个能力轴共同展示。置信度与材料模式不转换成惩罚分。
- 历史影响直接显示已裁公众档位、四维、性质和置信度，不数值化，不与其他体系换算。池外历史影响样本另列；其其他体系不在本展示主池，不据此断言其他地方没有材料。
- 跨体系解释先并列展示各自证据。不得由分数、字母差或姓名自动生成“高能低效”“暴君”“名不副实”等人物判断。未来若加入一句话导读，应逐人审定并可追溯，不能成为第二份裁决源。
- 来源链接返回正式入口；历史影响原文与核对范围可在页面内展开。图表外仍提供精确档位及文本，不要求读者依赖颜色或图形理解。

## 可运行样稿

在仓库根目录运行：

```powershell
python reader/build.py
```

只读检查生成页是否与当前正式数据、模板及本地来源状态一致：`python reader/build.py --check`。相关回归检查为`python -m pytest tests/test_reader.py -q`；覆盖全池投影同值、页面渲染、发布状态、来源保留和章节定位，不固定人物分数或人数。

全量检查当前本地引用能否定位：`python reader/check_references.py`。该命令需要Node.js，直接复用页面中的JSON与Markdown定位函数，离线核对当前文件、稳定ID、路径、章节和行号；临时运行脚本放在`.tmp/reader-reference-check/`，不会写入正式裁决。返回`PASS`才表示当前受检引用全部可定位，不能替代史料归责和评分语义复核。

打开[index.html](index.html)即可离线使用，无网络字体、外部脚本或服务依赖。浏览器预览使用：

```powershell
python -m pip install -r reader/requirements.txt
python reader/serve.py
```

访问[本地阅读层](http://127.0.0.1:8765/reader/index.html)。依赖仅需首次安装。服务以仓库根目录为根，显式声明UTF-8编码；Markdown来源显示为带目录、文内查找、固定表头和人物定位的HTML阅读页，通过“查看原始Markdown”保留原文入口。来源的章节锚点和`#L行号`定位优先保留；可通过`--port`更换端口。

`index.template.html`是布局与交互源，`build.py`负责确定性投影，`index.html`是可直接交付的生成样稿。更新正式数据后重新构建，不手工编辑内嵌数据。样稿不登记为新的评分入口，也没有修改既有结算。

本次交付覆盖总览、筛选、单人页、双人对照、依据展开和原文入口。未引入新增裁决、跨体系综合指数、自动因果导读或在线发布流程。

人物页设章节导航，筛选支持一键清除。正文保留分段、强调与代码样式；结构化正负情境按原有父链引用展开具体事实，父链编号与史源收在该情境的来源详情中。导出仍保留原有字段，情境正文仅为正式父链的确定性投影。

## 阅读层等级与信息展开

能力与独立画像统一以18级字母展示：G5对应S−/S/S+，G4对应A−/A/A+，G3对应B−/B/B+，G2对应C−/C/C+，G1对应D−/D/D+，G0对应E−/E/E+，每组三档依次对应LOW/MID/HIGH。正式G档、档内位置与雷达值保持原样；不适用、未定档及位置缺失单列，不补默认等级。历史影响沿用正式字母标签。

总览显示中文轴名与等级；人物概览只显示轴名与字母，点击轴名展开人物表现、反例及适用范围；定档、档内定位和限制原文保存在“裁决详情”，不删除或改写裁决。画像正文中的已定义G档、材料与PS/DW/AM代码作确定性术语转译，原始字段保留在内嵌数据与详情中；未定义术语不猜译。净收益说明仅解释正式分数构成，不自动推断排名的历史原因。

净收益详情按奠基、治理手段、财政民生、交接、军事与文明整合保留分组；历史影响按主链、反事实、归责、范式、判断边界分别展开。对照先搜索选定两人，不自动安排第二人；支持更换、交换左右及地址恢复。表内逐轴展开双方依据、限制与来源。“隐藏相同数值／等级”会同时隐藏该行依据，相同等级不表示情境或证据相同，取消勾选可完整对照。

逐轴发布状态同样读取正式记录：`UNRESOLVED_EVIDENCE_GAP`显示待补证，`REASSESSMENT_REQUIRED`显示待重裁，`display_point_only`只保留历史参考。上述记录不显示当前字母等级，也不绘入雷达；全池已入选不等于每轴都已完成当前裁决。

M2按现行合同完成终局核对后，无可证外交能力者以`NO_DEMONSTRATED_CAPABILITY`记录并发布E；与已证实外交失能分别说明。范围、来源和限制保留在正式记录及阅读页中，不将材料未见宣称为穷尽历史的结论。

人物依据同时保留定档理由、档内定位、典型表现、限制与本轴来源；历史影响另列公众总档定档理由。来源中的已退役或缺失文件保留原引用并标注当前不可用，不生成失效链接，也不自动换成同人物的其他材料。Markdown阅读器保留中文标题章节锚点、同名标题序号、显式人物锚点和源行定位。

人物路由支持含中文的稳定ID，并对损坏的地址编码显示未找到。来源兼容`文件.md:行号`与`#L行号`两种现存定位形式；外部史源使用原始URL打开，本地构建与验证不请求外网。

对照双方写入地址，刷新和分享地址保留人物选择。来源阅读器兼容旧`section-N`章节号；短标题或材料编号只有唯一匹配时才自动定位，多匹配、缺失及越界行号明确提示，不以人物搜索结果冒充原引用位置。

本地服务将JSON来源呈现为只读结构化阅读页，复用正式分片加载器，支持稳定ID、`字段=编号`、数组路径及旧`traits/A2/0`领域路径。显示匹配对象的实际数据路径，找不到时明确提示；“查看原始JSON”仍返回磁盘原文。直接以文件方式打开综合页时不启用此服务视图。


净收益总分旁可展开分数口径、第一项原分与附加分区别，以及正式总榜已有的有限权重情景名次范围。读取`weight_sensitivity`原值，不重新计算，不称为置信区间或史料不确定性。画像和历史影响各有就地等级说明，两套字母不换算。所有改动仅涉及阅读投影、布局与交互，不新增人物评价。
